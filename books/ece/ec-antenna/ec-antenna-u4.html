4.1 S-parameters and the scattering matrix

At microwave frequencies a component is not tested with a multimeter. Power enters and leaves through ports, and each port is a transmission-line cross-section with a fixed reference impedance Z₀, usually 50 Ω. The scattering matrix S collects the ratios of the waves leaving the ports to the waves arriving at them. It describes amplifiers, filters, couplers and antennas from about 1 GHz to 100 GHz, and every later chapter describes its component by its S-matrix.

You need: reflection coefficient Γ, VSWR and return loss on a transmission line (see Reflection coefficient, standing waves and VSWR), and complex numbers in polar form.

Waves in and out of a port

Z, Y, h and ABCD parameters need open-circuit or short-circuit tests. Above about 1 GHz an open end radiates, a short has inductance, and a transistor may oscillate when its port is shorted. A matched load is easy to build, so a microwave device is described by travelling waves at matched ports.

At port i, let aᵢ be the wave travelling into the device and bᵢ the wave travelling out. With RMS values, as used here, |aᵢ|² is the power arriving and |bᵢ|² the power leaving, in watts.

aᵢ = (Vᵢ + Z₀Iᵢ)/(2√Z₀),   bᵢ = (Vᵢ − Z₀Iᵢ)/(2√Z₀)

Vᵢ and Iᵢ are the total voltage and current at port i, Z₀ is the real reference impedance, aᵢ the incident wave and bᵢ the outgoing wave, both in √W.

For N ports the outgoing waves are linear combinations of the incoming ones: b = S a, where a and b are column vectors of length N and S is an N × N matrix. Each element is

Sᵢⱼ = bᵢ / aⱼ with aₖ = 0 for every k ≠ j

every port except j ends in a matched load, so no wave enters it. Sᵢⱼ is a complex number: |Sᵢⱼ| is the amplitude ratio and its angle is the phase shift from port j to port i.

The array S is called the scattering matrix (S-matrix). Some syllabi write it as [S] and the waves as [b] = [S][a].

The four S-parameters of a two-port

Match port 2 (a₂ = 0) and drive port 1. Then b₁ = S₁₁a₁ and b₂ = S₂₁a₁. Match port 1 (a₁ = 0) and drive port 2: b₁ = S₁₂a₂ and b₂ = S₂₂a₂.

  • S₁₁: input reflection coefficient, port 2 matched.
  • S₂₁: forward transmission coefficient (forward voltage gain), port 2 matched.
  • S₁₂: reverse transmission coefficient, port 1 matched.
  • S₂₂: output reflection coefficient, port 1 matched.

Each magnitude is quoted in dB as a power ratio, so 20 log of the wave ratio.

QuantityFormulaWhat the number tells you
Return lossRL = −20 log₁₀|S₁₁| dBhow far the reflected power is below the incident power
Insertion lossIL = −20 log₁₀|S₂₁| dBhow far the power delivered to a matched load is below the incident power
Input VSWR(1 + |S₁₁|)/(1 − |S₁₁|)standing-wave ratio at port 1 with port 2 matched
Reverse isolation−20 log₁₀|S₁₂| dBhow far reverse transmission is below the incident power

When port 2 is not matched but ends in a load with reflection coefficient ΓL, the input reflection is no longer S₁₁:

Γin = S₁₁ + S₁₂S₂₁Γ<sub>L</sub> / (1 − S₂₂Γ<sub>L</sub>)

the second term is the wave that crosses to port 2, reflects from the load and comes back. With ΓL = 0 it vanishes and Γin = S₁₁.

Properties that check any S-matrix

Three tests catch most errors in an exam answer. Apply all three to every matrix you write.

  • Reciprocal (no ferrite, no active device, no plasma): S = Sᵀ, so Sᵢⱼ = Sⱼᵢ. The matrix is symmetric.
  • Lossless: S†S = I, where S† is the conjugate transpose and I the identity. Each column has Σᵢ|Sᵢⱼ|² = 1 (all the power sent in at port j comes out somewhere), and any two different columns are orthogonal: Σᵢ Sᵢⱼ S*ᵢₖ = 0. A matrix with S†S = I is called unitary.
  • Matched at port i: Sᵢᵢ = 0. A fully matched device has a zero diagonal.

For a lossy device the column sums are less than 1, and 1 − Σᵢ|Sᵢⱼ|² is the fraction of the power entering port j that turns into heat.

The reference plane matters. Moving the reference plane of port n outward by a length l of matched line adds a phase θₙ = βl, where β = 2π/λg is the phase constant and λg the guide wavelength. A term Sᵢⱼ picks up e−j(θᵢ + θⱼ): an off-diagonal term touching the moved port once gets e−jθ, and the diagonal term Sₙₙ, whose wave crosses the extra line twice, gets e−j2θ. Magnitudes do not change. S-parameters also depend on frequency and on Z₀, so quote both with every matrix.

Worked example

Question. A 50 Ω two-port at 10 GHz has S₁₁ = 0.2∠0°, S₂₁ = 0.9∠−30°, S₁₂ = 0 and S₂₂ = 0.1∠0°. Find (a) the return loss at port 1, (b) the insertion loss, (c) the input VSWR with port 2 matched and (d) the reverse isolation. Is the device reciprocal?

  1. Port 2 is matched, so a₂ = 0 and Γin = S₁₁ = 0.2∠0°; |S₁₁| = 0.2.
  2. Return loss: RL = −20 log₁₀(0.2) = −20 × (−0.6990) = 13.98 dB.
  3. Insertion loss: IL = −20 log₁₀(0.9) = −20 × (−0.04576) = 0.92 dB. The phase −30° is a delay and does not change the loss.
  4. Input VSWR = (1 + 0.2)/(1 − 0.2) = 1.2/0.8 = 1.5.
  5. S₁₂ = 0, so reverse isolation = −20 log₁₀(0) → ∞ dB: no wave travels from port 2 to port 1.
  6. Reciprocity test: S₁₂ = 0 but S₂₁ = 0.9∠−30°, so S ≠ Sᵀ. The device is not reciprocal; it is unilateral, like an ideal buffer amplifier or an isolator.

Answer. RL = 13.98 dB, IL = 0.92 dB, input VSWR = 1.5, reverse isolation infinite; the device is not reciprocal.

Worked example 2

Question. A 50 Ω two-port has S₁₁ = 0.2∠0°, S₁₂ = S₂₁ = 0.8∠−60° and S₂₂ = 0.3∠0°. (a) Is it reciprocal? Is it lossless? (b) What fraction of the power entering port 1 is lost as heat when port 2 is matched? (c) Find Γin and the return loss at port 1 when port 2 is short-circuited. (d) Find the new S₁₁ and S₂₁ if the port-1 reference plane is moved outward by βl = 45°.

  1. Reciprocal: S₁₂ = S₂₁ = 0.8∠−60°, so S = Sᵀ. Yes.
  2. Lossless test on column 1: |S₁₁|² + |S₂₁|² = 0.04 + 0.64 = 0.68 ≠ 1. Column 2: 0.64 + 0.09 = 0.73. The matrix is not unitary, so the device is lossy.
  3. Heat with port 2 matched: 1 − 0.68 = 0.32, so 32 % of the power entering port 1 is absorbed; 4 % reflects and 64 % reaches the load.
  4. Short at port 2: ΓL = −1. Γin = 0.2 + (0.8∠−60°)²(−1)/(1 − 0.3 × (−1)) = 0.2 − 0.64∠−120°/1.3 = 0.2 − 0.4923∠−120°.
  5. −0.4923∠−120° = 0.4923∠60° = 0.2462 + j0.4264, so Γin = 0.4462 + j0.4264 = 0.617∠43.7°.
  6. Return loss = −20 log₁₀(0.617) = 4.19 dB: the wave reflected by the short comes back through the device.
  7. Port-1 plane moved out by θ = 45°: S₁₁′ = 0.2∠−90° (twice θ); S₂₁′ = 0.8∠−105° (once); S₂₂ unchanged.

Answer. Reciprocal but lossy (32 % absorbed); with port 2 shorted Γin = 0.617∠43.7° and RL = 4.19 dB; after the 45° shift S₁₁′ = 0.2∠−90° and S₂₁′ = 0.8∠−105°.

Exam traps

  • Treating |S₂₁| as a dB value. A magnitude of 0.9 is −0.92 dB; convert with 20 log₁₀|S₂₁|.
  • Using S₁₁ as the input reflection when port 2 is not matched. With a load ΓL ≠ 0, use Γin = S₁₁ + S₁₂S₂₁ΓL/(1 − S₂₂ΓL).
  • Shifting every S-parameter by the same phase when a reference plane moves. Sₙₙ gets twice the line phase, an off-diagonal term once, and terms not touching port n none.
  • Calling a matrix lossless because its diagonal is zero. Matched and lossless are different tests: check the column sums |S₁ⱼ|² + |S₂ⱼ|² + … = 1.
  • Swapping S₁₂ and S₂₁. The first index is the port the wave leaves, the second the port it enters: S₂₁ is from 1 to 2.

Check yourself

Remember Define S₂₁ of a two-port. 2 marks

S₂₁ = b₂/a₁ with a₂ = 0, that is, with port 2 ended in a matched load. It is the forward transmission coefficient from port 1 to port 2.

Understand Why are S-parameters preferred to Z- or Y-parameters at microwave frequencies? 3 marks

Z and Y need open or short terminations. At microwave frequencies an open end radiates, a short has inductance and an active device may oscillate. S-parameters need only matched loads, which are easy to make, and they relate directly to power through |Sᵢⱼ|².

Apply A two-port has |S₁₁| = 0.1 and |S₂₁| = 0.5. Find the return loss, input VSWR and insertion loss. 4 marks

RL = −20 log₁₀(0.1) = 20 dB. VSWR = 1.1/0.9 = 1.22. IL = −20 log₁₀(0.5) = 6.02 dB. Since 0.01 + 0.25 = 0.26 < 1, the device absorbs 74 % of the power: it is lossy.

Apply A matched attenuator has |S₂₁| = 0.316. Find its insertion loss. 2 marks

IL = −20 log₁₀(0.316) = 10.0 dB: one tenth of the power gets through.

Analyze A reciprocal two-port has S₁₁ = S₂₂ = 0 and |S₂₁| = 1. Show that it is lossless. 5 marks

Reciprocal gives S₁₂ = S₂₁. Column 1: |S₁₁|² + |S₂₁|² = 0 + 1 = 1; column 2: |S₁₂|² + |S₂₂|² = 1. Columns 1 and 2 are orthogonal: S₁₁S*₁₂ + S₂₁S*₂₂ = 0 + 0 = 0. So S†S = I: it is a matched lossless line section.

Analyze An isolator has S₂₁ = 0.95 and S₁₂ = 0.03 with both ports matched. Is it reciprocal? Is it lossless? 4 marks

Not reciprocal, since S₁₂ ≠ S₂₁. Not lossless: column 2 gives |S₁₂|² + |S₂₂|² = 0.0009, far below 1, so almost all the reverse power is absorbed. That absorption is the job of an isolator.

Understand The port-2 reference plane of a device is moved outward by βl = 30°. How do S₁₁, S₂₁ and S₂₂ change? 3 marks

S₁₁ does not touch port 2, so it is unchanged. S₂₁ gets e−j30° (30° more lag). S₂₂ crosses the extra line twice and gets e−j60°. No magnitude changes.

4.2 Waveguide tees: E-plane, H-plane and magic tee

A waveguide tee is a three-port junction: a branch guide joined to the side of a through guide, splitting power from one guide into two or combining two into one. A branch on the broad wall makes an E-plane tee, on the narrow wall an H-plane tee. A magic tee puts both on one junction and becomes a matched four-port with two isolated pairs of arms. Tees feed antenna pairs, balanced mixers, radar comparators and tuners.

You need: the TE₁₀ mode of a rectangular guide (see Rectangular and circular waveguides: TE and TM modes) and the S-matrix tests in S-parameters and the scattering matrix.

E-plane and H-plane tees

Ports 1 and 2 are the ends of the through (collinear) guide and port 3 is the branch. In the TE₁₀ mode E runs across the narrow dimension b; the broad wall has width a.

  • E-plane tee (series tee): the branch is joined to the broad wall, so its axis lies in the plane of E. A wave fed into port 3 leaves ports 1 and 2 with equal power and 180° apart, because the E-field lines turn opposite ways into the two arms. Seen from the branch, the two arms are in series.
  • H-plane tee (shunt tee): the branch is joined to the narrow wall, so its axis lies in the plane of the magnetic field H. A wave fed into port 3 leaves ports 1 and 2 with equal power and in phase. Seen from the branch, the arms are in parallel.

With the branch matched (S₃₃ = 0), the usual matrices are

H-plane: S = [ ½  −½  1/√2 ;  −½  ½  1/√2 ;  1/√2  1/√2  0 ]
E-plane: S = [ ½  ½  1/√2 ;  ½  ½  −1/√2 ;  1/√2  −1/√2  0 ]

rows and columns are ports 1, 2, 3. The signs of S₁₃ and S₂₃ carry the in-phase (H) or opposite (E) split. Both matrices are symmetric (reciprocal) and every column has |S₁ⱼ|² + |S₂ⱼ|² + |S₃ⱼ|² = ¼ + ¼ + ½ = 1 (lossless).

S₁₁ = S₂₂ = ½: a collinear port reflects a quarter of the power fed into it. No three-port tee can do better, as the next section shows.

Why a three-port tee cannot be matched

Suppose a lossless reciprocal three-port were matched: S₁₁ = S₂₂ = S₃₃ = 0. Apply S†S = I.

  1. Column sums (each must be 1): |S₁₂|² + |S₁₃|² = 1, |S₁₂|² + |S₂₃|² = 1, |S₁₃|² + |S₂₃|² = 1.
  2. Add the three and halve: |S₁₂|² + |S₁₃|² + |S₂₃|² = 3/2. Subtract each equation in turn: |S₁₂|² = |S₁₃|² = |S₂₃|² = ½, so none of the three can be zero.
  3. Columns 1 and 2 must be orthogonal: S₁₁S*₁₂ + S₂₁S*₂₂ + S₃₁S*₃₂ = 0. With S₁₁ = S₂₂ = 0 this leaves S₃₁S*₃₂ = S₁₃S*₂₃ = 0.
  4. A product of two numbers of magnitude 1/√2 cannot be zero. The assumption is false: a lossless reciprocal three-port cannot be matched at every port.

So a real tee always reflects at some port. Two ways round this are used: add a fourth port (the magic tee and the couplers of Directional couplers and hybrid rings) or accept loss (the Wilkinson divider of Power dividers and attenuators).

Magic tee: sum and difference

A magic tee (hybrid tee) is an E-plane and an H-plane branch on the same junction. Ports 1 and 2 are collinear, port 3 is the H-arm and port 4 is the E-arm. Matching posts or irises inside the junction make all four ports matched; the geometry then gives the rest.

  • Power into the H-arm splits equally and in phase to ports 1 and 2; none reaches the E-arm (S₄₃ = 0).
  • Power into the E-arm splits equally and 180° apart to ports 1 and 2; none reaches the H-arm. The E-arm field is odd about the centre plane of the junction, the H-arm field is even, so they cannot couple.
  • Ports 1 and 2 are isolated from each other (S₁₂ = 0).
  • Waves fed into ports 1 and 2 together: their sum leaves the H-arm and their difference leaves the E-arm. For this reason the H-arm is called the sum (Σ) port and the E-arm the difference (Δ) port.
S = (1/√2) [ 0 0 1 1 ;  0 0 1 −1 ;  1 1 0 0 ;  1 −1 0 0 ]

rows and columns are ports 1, 2, 3 (H), 4 (E). Check: symmetric, so reciprocal; each column has two entries of magnitude 1/√2, so Σ|Sᵢⱼ|² = 1; columns 1 and 2 give ½ − ½ = 0, so they are orthogonal. The matrix is unitary and matched.

Some syllabi list corners, bends and twists with tees, because tee arms reach their loads through them. A mitred corner or a smooth E-plane or H-plane bend turns a guide by 90° with little reflection; a twist rotates the cross-section, so an arm can feed a guide whose broad wall faces the other way. An E-H tuner is a magic tee with sliding shorts in the E- and H-arms, used to match an unknown load.

Worked example

Question. An ideal H-plane tee (S-matrix above) has 10 mW fed into collinear port 1, with ports 2 and 3 ended in matched loads. Find the power reflected at port 1, the power at ports 2 and 3, and the input VSWR at port 1.

  1. The incident wave is a₁ = √10 mW½ = 3.162; a₂ = a₃ = 0.
  2. Outgoing waves are column 1 of S times a₁: b₁ = ½ × 3.162 = 1.581, b₂ = −½ × 3.162 = −1.581, b₃ = (1/√2) × 3.162 = 2.236.
  3. Powers: P₁(reflected) = 1.581² = 2.5 mW, P₂ = 2.5 mW, P₃ = 2.236² = 5.0 mW.
  4. Balance: 2.5 + 2.5 + 5.0 = 10.0 mW, so the tee is lossless as its matrix says.
  5. Input VSWR at port 1: |S₁₁| = 0.5, so VSWR = (1 + 0.5)/(1 − 0.5) = 3.0. Return loss = −20 log₁₀ 0.5 = 6.02 dB.

Answer. 2.5 mW reflects at port 1, 2.5 mW leaves port 2, 5 mW leaves the branch; the input VSWR is 3.0. Only the branch is matched, as the three-port proof requires.

Worked example 2

Question. Two in-phase signals of 8 W and 2 W are fed into ports 1 and 2 of an ideal magic tee; ports 3 (H) and 4 (E) are matched. Find the power leaving the H-arm and the E-arm. Repeat when the 2 W signal is 180° out of phase.

  1. Wave amplitudes: a₁ = √8 = 2.828 W½, a₂ = √2 = 1.414 W½.
  2. From row 3 of S: b₃ = (a₁ + a₂)/√2 = (2.828 + 1.414)/1.414 = 3.0, so P₃ = 9.0 W.
  3. From row 4: b₄ = (a₁ − a₂)/√2 = 1.414/1.414 = 1.0, so P₄ = 1.0 W.
  4. Rows 1 and 2 have zeros in columns 1 and 2, so b₁ = b₂ = 0: nothing reflects. Total out = 9 + 1 = 10 W, equal to the input.
  5. With a₂ = −1.414 (180°): b₃ = (2.828 − 1.414)/1.414 = 1.0 → P₃ = 1 W, and b₄ = (2.828 + 1.414)/1.414 = 3.0 → P₄ = 9 W. The sum and difference ports swap roles.

Answer. In phase: 9 W from the H-arm and 1 W from the E-arm. Antiphase: 1 W from the H-arm and 9 W from the E-arm. Equal in-phase inputs would give all the power at the H-arm and none at the E-arm.

Exam traps

  • Swapping the arms. The H-arm (narrow-wall branch) gives the in-phase split; the E-arm (broad-wall branch) gives the 180° split.
  • Writing a fully matched lossless three-port tee. It cannot exist; an ideal tee has S₁₁ = S₂₂ = ½.
  • Adding powers instead of waves. With 8 W and 2 W in phase, the H-arm gives (√8 + √2)²/2 = 9 W, not 10 W; the other 1 W leaves the E-arm.
  • Renumbering ports in the middle of an answer. Keep 1 and 2 collinear, 3 the H-arm and 4 the E-arm, or the signs in the matrix change.

The broad wall, so the branch axis lies in the plane of E. Ports 1 and 2 leave with equal power, 180° apart.

Remember State the two isolation conditions of an ideal magic tee. 2 marks

S₃₄ = S₄₃ = 0 between the H-arm and the E-arm, and S₁₂ = S₂₁ = 0 between the two collinear arms.

Understand Write the S-matrix of an ideal magic tee (port 3 H-arm, port 4 E-arm) and show that it is unitary. 4 marks

S = (1/√2)[0 0 1 1; 0 0 1 −1; 1 1 0 0; 1 −1 0 0]. Each column has two entries of magnitude 1/√2, so Σ|Sᵢⱼ|² = ½ + ½ = 1. Columns 1 and 2: (1·1 + 1·(−1))/2 = 0; columns 3 and 4 likewise give 0; other pairs share no non-zero row. So S†S = I.

Apply An ideal magic tee has 4 W fed into its E-arm. Find the power at ports 1, 2 and 3 and the phase between ports 1 and 2. 4 marks

Column 4 of S: b₁ = +2/√2, b₂ = −2/√2 (a₄ = 2 W½), so P₁ = P₂ = 2 W, 180° apart. S₃₄ = 0, so P₃ = 0.

Analyze A real magic tee reflects 4 % of the power at each collinear port and has 0.3 dB loss. Which properties of the ideal matrix fail, and how is the tee corrected? 5 marks

|S₁₁| = |S₂₂| = √0.04 = 0.2, so the diagonal is no longer zero (return loss 14 dB); the loss makes each column sum about 10−0.03 = 0.933 instead of 1, so S is not unitary. A matching post and iris inside the junction (or tuning screws) bring the reflections down over the band; the matrix of the real tee is measured with a network analyser.

Analyze Two equal in-phase signals feed ports 1 and 2 of a magic tee. Why does the E-arm receive nothing, and what changes if one signal shifts by 90°? 4 marks

The E-arm output is (a₁ − a₂)/√2, which is zero for equal in-phase waves. With a 90° shift, a₂ = ja₁: |b₄|² = |a₁|²|1 − j|²/2 = |a₁|², so the E- and H-arms each get half the total power.

4.3 Directional couplers and hybrid rings

A directional coupler is a four-port that sends a small, known sample of the wave travelling from port 1 to port 2 to a coupled port, while a wave travelling the other way is sent elsewhere. A meter can then watch the forward and reflected waves without disturbing the line. A hybrid splits power equally: the rat-race gives outputs in phase or 180° apart, the branch-line hybrid 90°. They serve power monitors, reflectometers, balanced mixers and antenna feeds.

You need: S-matrix tests and dB ratios from S-parameters and the scattering matrix, and guide wavelength λg.

Ports, coupling, directivity and isolation

Port 1 is the input, port 2 the through, port 3 the coupled and port 4 the isolated port, all matched. Three positive dB numbers describe the coupler.

C = 10 log₁₀(P₁/P₃) = −20 log₁₀|S₃₁| dB
D = 10 log₁₀(P₃/P₄) = 20 log₁₀(|S₃₁|/|S₄₁|) dB
I = 10 log₁₀(P₁/P₄) = −20 log₁₀|S₄₁| dB = C + D

P₁ is the power fed into port 1 and P₃, P₄ the powers leaving ports 3 and 4. C is the coupling, D the directivity and I the isolation.

A 10 dB coupler sends one tenth of the input to port 3; a 20 dB coupler one hundredth. Directivity says how well the coupler tells forward from reverse; good waveguide couplers reach 30 to 40 dB. The sampled power leaves the main line, so the through port has a coupling loss of −10 log₁₀(1 − 10−C/10) dB: 0.46 dB for a 10 dB coupler.

An ideal coupler is matched, reciprocal and lossless, with the isolated port receiving nothing. Its S-matrix, with |S₂₁| = α, |S₃₁| = β and α² + β² = 1, is

S = [ 0 α jβ 0 ;  α 0 0 jβ ;  jβ 0 0 α ;  0 jβ α 0 ]

rows and columns are ports 1 to 4; the coupled wave leads the through wave by 90°. A wave entering port 2 couples to port 4, so port 4 samples a reflected wave. Check: symmetric, each column sums to α² + β² = 1, and columns are orthogonal.

Two-hole coupler

Two guides share a broad wall with two small holes λg/4 apart. Each hole leaks a little of the main wave into the auxiliary guide, both ways along it.

  • Forward direction (towards port 3): the wave leaking through hole A travels λg/4 in the auxiliary guide to reach hole B; the main wave also travels λg/4 before leaking through B. The two leaked waves have travelled the same distance, so they arrive in phase and add.
  • Reverse direction (towards port 4): the wave from hole B travels back λg/4 to hole A, while the main wave from hole A did not travel at all. The two paths differ by 2 × λg/4 = λg/2, a 180° difference, so the waves cancel.

The cancellation is exact only where the spacing is λg/4, so directivity falls away from the design frequency; multi-hole couplers with graded hole sizes keep it over a wider band. In WR-90 guide at 10 GHz, λg = 39.8 mm, so the holes are 9.9 mm apart.

Hybrid ring (rat-race) and branch-line hybrid

A hybrid ring is a closed ring of line with a circumference of 1.5λg and four ports. Going round the ring, number them 1, 2, 3, 4. The arcs are 1–2: λg/4, 2–3: 3λg/4, 3–4: λg/4 and 4–1: λg/4 (total 1.5λg). Each arc is a line of impedance √2 Z₀ (70.7 Ω in a 50 Ω system).

A wave fed into a port runs both ways round the ring. At another port the two parts add when their paths differ by whole wavelengths and cancel when they differ by λg/2.

Exam traps

  • Mixing up coupling and directivity. Coupling compares port 3 with port 1; directivity compares port 3 with port 4; isolation compares port 1 with port 4, and I = C + D.
  • Using 10 log with |S| values. |S| is a wave ratio, so C = −20 log₁₀|S₃₁|; with powers use 10 log₁₀(P₁/P₃). Mixing them doubles or halves every answer.
  • Numbering a rat-race wrongly. The isolated pair is the two ports whose paths differ by λg/2; with the 3λg/4 arc between ports 2 and 3, ports 1 and 3 are isolated and port 1 is the sum port.
  • Saying the 3λg/4 arc "gives 180°". It is 270° of line; the 180° is its difference from a λg/4 arc.
  • Assuming port 4 receives zero. Finite directivity leaks power there, which limits how small a reflection a reflectometer can measure.

4.4 Power dividers and attenuators

A power divider takes one input and delivers set fractions of it to two or more outputs; run backwards it is a combiner. An attenuator lowers the power by a known number of decibels while staying matched at both ends. Together they set signal levels in antenna feeds, phased arrays, receiver front ends and test benches. The questions to ask of each are the same: are the ports matched, are the outputs isolated, and where does any lost power go?

You need: dB and dBm, and the S-matrix tests in S-parameters and the scattering matrix, including the proof in Waveguide tees that a lossless reciprocal three-port cannot be matched.

T-junction and resistive dividers

A lossless T-junction joins an input line of impedance Z₀ to two output lines Z₁ and Z₂. For the input to be matched, the two outputs in parallel must equal Z₀: 1/Z₁ + 1/Z₂ = 1/Z₀. The input voltage is shared, so each output takes power in proportion to 1/Z.

P₂/P₁ = Z₀/Z₁, P₃/P₁ = Z₀/Z₂

P₁ is the input power and P₂, P₃ the output powers. For a 2 : 1 split from 50 Ω: Z₁ = 75 Ω takes ⅔ and Z₂ = 150 Ω takes ⅓; 75 ∥ 150 = 50 Ω.

The input is matched, but the outputs are not: looking back into the 75 Ω arm one sees 50 ∥ 150 = 37.5 Ω, a reflection of (37.5 − 75)/(37.5 + 75) = −0.333. The outputs are also not isolated. That is the three-port theorem at work.

A resistive divider puts a resistor of Z₀/3 (16.7 Ω in a 50 Ω system) in series with each of three ports, joined at a star point. Every port is matched and the network is reciprocal, but half the input power is turned into heat: each output gets P₁/4, which is 6.02 dB below the input. The outputs are not isolated either (S₂₃ = ½, a 6 dB path). It is broadband and cheap, which suits test benches.

Wilkinson divider

The equal-split Wilkinson divider feeds two quarter-wave lines of impedance √2 Z₀ (70.7 Ω for Z₀ = 50 Ω) from the input, and joins their output ends with a resistor R = 2Z₀ (100 Ω).

  • Driven from port 1 with matched outputs, the two output ends are at the same voltage, so no current flows in R. Each λ/4 line transforms the Z₀ load into (√2 Z₀)²/Z₀ = 2Z₀, and two of these in parallel give Z₀: port 1 is matched and the divider is lossless, with half the power at each output (−3.01 dB).
  • A wave entering output 2 splits: half travels the λ/4 line to port 1, and half crosses R, where it meets the part that went round through the other line. The two parts reaching port 3 are equal and opposite, so port 3 gets nothing: the outputs are isolated, and ports 2 and 3 are matched. The power that does not reach port 1 is absorbed in R.

S = (−j/√2) [ 0 1 1 ; 1 0 0 ; 1 0 0 ]

rows and columns are ports 1 (input), 2 and 3. Matched (zero diagonal), reciprocal (symmetric), isolated (S₂₃ = 0). Column 1 sums to ½ + ½ = 1, but columns 2 and 3 sum to only ½: the matrix is not unitary, and the missing half is the power the resistor absorbs when an output is driven.

So the Wilkinson escapes the three-port theorem by being lossy, but only for waves coming back from the outputs. Match and isolation are exact only at the design frequency, where the lines are a quarter-wave long, and degrade slowly on either side; multi-section versions widen the band. Unequal splits use unequal line impedances and a different resistor.

Attenuators

An attenuator reduces power by A dB and presents Z₀ at both ports. A fixed attenuator (pad) is a T or π network of resistors; a step attenuator switches pads in fixed steps such as 1 dB or 10 dB; a variable attenuator uses a PIN diode whose RF resistance follows its DC bias, or in waveguide a resistive vane moved into the field (the rotary-vane attenuator sets loss by the angle of its vane).

A = 10 log₁₀(P<sub>in</sub>/P<sub>out</sub>) dB,   P<sub>out</sub> = P<sub>in</sub> × 10<sup>−A/10</sup>

Pin and Pout in watts; pads in cascade add: A = A₁ + A₂. A level in dBm falls by A dB through the pad.

T pad: series arms R₁ = Z₀(K − 1)/(K + 1), shunt arm R₂ = 2Z₀K/(K² − 1),   K = 10<sup>A/20</sup>

K is the voltage ratio of the pad. For 10 dB in 50 Ω: K = 3.162, R₁ = 25.97 Ω, R₂ = 35.14 Ω. A π pad of the same loss has series 71.15 Ω and two shunt arms of 96.25 Ω.

The S-matrix of a matched pad is [0 1/K ; 1/K 0]: matched and reciprocal, with column sums 1/K² = 10−A/10 < 1, so it is lossy by design. The pad must be rated for the power it absorbs, Pin − Pout, which for a large pad is nearly all of the input. A pad between a source and a poorly matched load also improves the match the source sees, because a reflection crosses the pad twice and returns 2A dB weaker.

Exam traps

  • Taking 3 dB as half the voltage. A 3 dB split halves the power; each output voltage is 1/√2 of the input.
  • Calling the Wilkinson lossless in every case. It is lossless only from the input with matched outputs; power coming back from an output is half absorbed in the resistor.
  • Giving a resistive divider a 3 dB loss. Each output of the equal resistive divider is 6.02 dB down, because half the power is dissipated.
  • Adding dBm to dBm. 20 dBm − 6 dB = 14 dBm; two 20 dBm (100 mW) signals combined make 200 mW = 23 dBm, not 40 dBm.
  • Rating a pad by its output power. A 20 dB pad fed with 1 W absorbs 0.99 W and must be rated for it.

4.5 Ferrite devices: isolators, circulators and phase shifters

A biased ferrite treats a wave travelling one way differently from one travelling back, which breaks reciprocity; no metal, dielectric or resistor can do that. The isolator passes power one way and absorbs it the other, the circulator hands power from port to port in a fixed rotation, and the ferrite phase shifter sets a phase by a coil current. They protect transmitters, let a radar share one antenna, and steer phased arrays.

You need: the reciprocity and losslessness tests in S-parameters and the scattering matrix.

Ferrite under DC bias

A ferrite is a ceramic of iron oxide with other metal oxides, such as yttrium iron garnet (YIG). It is a low-loss insulator (εr about 10 to 15), so a wave travels through it, yet it is strongly magnetic.

A bias field B₀ makes the electron spins precess about B₀ at f₀ ≈ 28 GHz per tesla of internal field. An RF magnetic field rotating with the precession interacts strongly; one rotating the other way hardly does. So the permeability is a tensor, and a circular wave sees μ₊ or μ₋ by its sense of rotation; near f₀ the matching sense is absorbed (ferromagnetic resonance).

A linearly polarised wave is the sum of two equal circular waves rotating in opposite senses. Along a ferrite rod biased along its axis they travel with phase constants β₊ and β₋, so after a length L one has slipped in phase against the other and the plane of polarisation has turned. This is Faraday rotation.

θ = (β₋ − β₊) L / 2

θ is the rotation of the plane of polarisation in radians, β₊ and β₋ the phase constants of the two circular waves in rad/m, and L the ferrite length in m. The bias strength sets β₊ − β₋, so it sets θ.

The sense of rotation is fixed by B₀, not by the direction of travel. A wave turns +θ going forward and +θ again coming back, so the round trip gives 2θ instead of zero; a dielectric would undo its effect on the way back.

Isolators

Faraday-rotation isolator: a ferrite rod in a circular guide turns the polarisation by 45°. The input and output rectangular guides are twisted 45° to each other, and each end has a resistive card parallel to its broad wall, which a correctly polarised wave (E across the card) does not heat.

  • Forward: the ferrite turns the wave 45°, lining it up with the output guide; it passes with small loss.
  • Reverse: a reflected wave is turned a further 45° in the same sense and reaches the input at 90° to it, with E along the card, which absorbs it.

Resonance isolator: a ferrite slab sits in a rectangular guide at the point where the TE₁₀ magnetic field is circularly polarised. The sense of rotation there depends on the direction of travel, so with B₀ set for resonance one direction is absorbed and the other passes. Its S-matrix, ideally, is

S = [ 0 0 ; 1 0 ]

S₂₁ = 1, S₁₂ = 0, both ports matched. Not symmetric (nonreciprocal); column 2 sums to 0, not 1, so the reverse power is absorbed (lossy).

A real isolator is quoted by its insertion loss (forward, about 0.3 to 1 dB) and isolation (reverse, 20 dB or more).

Circulators

The common circulator is a Y-junction: three guides or striplines at 120° meeting over a ferrite disc with a small magnet across it. The bias makes the field pattern in the disc rotate so that power entering port 1 leaves at port 2, power entering 2 leaves at 3, and power entering 3 leaves at 1. Reversing the magnet reverses the rotation.

S = [ 0 0 1 ; 1 0 0 ; 0 1 0 ]

row = output port, column = input port: S₂₁ = S₃₂ = S₁₃ = 1. Matched and unitary (each column has a single 1), so lossless, but not symmetric, so nonreciprocal: a matched lossless three-port is possible only without reciprocity.

With port 3 ended in a matched load, the circulator becomes an isolator: 1 → 2 passes, and power returning into port 2 goes to port 3 and is absorbed. A reflection from that load would circulate on to port 1, so it must stay matched.

A real circulator has insertion loss with the rotation and isolation against it; by the 120° symmetry the leaks 2 → 1, 3 → 2 and 1 → 3 are equal. A radar duplexer uses one: transmitter on port 1, antenna on 2, receiver on 3 (see Radar antennas, transmitters, receivers and duplexers).

Phase shifters. A reciprocal one gives the same shift both ways (a dielectric vane, or PIN diodes switching line lengths). A ferrite phase shifter changes β by its bias current, φ = (β − β₀)L, with no moving parts, and steers phased arrays (see Binomial, Chebyshev and phased arrays). A gyrator is a two-port whose forward and reverse phase shifts differ by 180°.

Exam traps

  • Drawing the rotation the wrong way. Read the arrow on the device; reversing the magnet turns 1 → 2 → 3 into 1 → 3 → 2.
  • Treating an isolator as reciprocal. S₂₁ ≈ 1 and S₁₂ ≈ 0, so its loss is not the same both ways.
  • Calling the ideal circulator lossy because it is nonreciprocal. Its matrix is unitary: it is lossless and matched, but not symmetric.
  • Leaving a circulator port open. Its reflection circulates to the next port and isolation collapses.
  • Confusing isolation with return loss. Isolation is reverse transmission (−20 log₁₀|S₁₂|); return loss is reflection at a port (−20 log₁₀|S₁₁|), both quoted as positive dB.

4.6 Microwave tubes: klystron, reflex klystron, magnetron, TWT

The highest microwave powers still come from electrons flying through vacuum. A microwave tube makes a DC electron beam hand its kinetic energy to an RF field. The klystron amplifies by bunching the beam in cavities, the reflex klystron oscillates by turning its beam back through one cavity, the magnetron oscillates at high power in crossed fields, and the travelling-wave tube (TWT) amplifies over a wide band along a helix. Radar, satellite links, accelerators and microwave ovens use them.

You need: cavity resonators (see Microwave resonators and Q factor) and ½mv² = eV.

Two-cavity klystron: velocity modulation and bunching

A gun forms a beam of current I₀ accelerated through V₀, so electrons enter at v₀ = √(2eV₀/m) = 0.593 × 10⁶ √V₀ m/s. The beam crosses the input cavity (buncher) gap, where the RF input sets up V₁ sin ωt.

Take as reference the electron that crosses when the gap voltage is zero and rising. Earlier electrons met a retarding field and leave slower; later ones meet an accelerating field and leave faster. In the drift space the fast late electrons catch up with the slow early ones, and the beam gathers into one bunch per RF cycle: velocity modulation becomes current modulation.

v(t) = v₀[1 + (β<sub>i</sub>V₁/2V₀) sin ωt],   X = (β<sub>i</sub>V₁/2V₀) θ₀,   θ₀ = ωL/v₀

βi = sin(θg/2)/(θg/2) is the beam coupling coefficient of a gap of transit angle θg = ωd/v₀ (d = gap width); θ₀ is the drift transit angle over the drift length L; X is the bunching parameter.

The fundamental RF current of the bunched beam is 2I₀J₁(X), largest at X = 1.841, where J₁ = 0.582. The bunches cross the output cavity (catcher) gap while its field retards them and give it energy. The efficiency is η = β₀V₂J₁(X)/V₀ for an output gap voltage V₂, so it is at most J₁(1.841) = 58.2 % when β₀V₂ ≈ V₀; real tubes give less. Multicavity klystrons add idle cavities to sharpen the bunches and raise the gain.

Reflex klystron: one cavity and a repeller

A reflex klystron is an oscillator. The beam crosses one cavity and meets a repeller at −VR with respect to the cathode. The retarding field (VR + V₀)/L sends the electrons back through the same gap, bunched by the round trip; if the bunches return while the gap field opposes them, they feed the cavity and oscillation builds up.

ωT′ = 2πN,   N = n + ¾ (n = 0, 1, 2 …);   V₀/(V<sub>R</sub> + V₀)² = (2πN)² e / (8ω²L²m)

T′ is the round-trip time, N the mode number (¾, 1¾, 2¾ …), VR the repeller voltage magnitude and L the repeller distance.

Each mode has its own repeller voltage, and only modes with VR > 0 exist. Small changes of VR pull the frequency within a mode (electronic tuning); a tuning screw changing the cavity moves the centre frequency (mechanical tuning). The best efficiency of a mode is 2X′J₁(X′)/(2πN) with X′ = 2.408: 22.7 % in the 1¾ mode. Output is milliwatts; it served as a radar local oscillator and bench source.

Magnetron and travelling-wave tube

A cylindrical magnetron has a cathode of radius a inside an anode of radius b cut into N cavities. V₀ gives a radial electric field and a magnet an axial field B₀. With no RF, electrons curve back before reaching the anode when B₀ exceeds the Hull cutoff field (or V₀ is below the Hull cutoff voltage).

B₀c = √(8V₀m/e) / [b(1 − a²/b²)],   V₀c = (e/8m) B₀² b² (1 − a²/b²)²,   f<sub>c</sub> = eB₀/(2πm) ≈ 28 GHz × B₀

B₀c in tesla, V₀c in volts, a and b in metres; fc is the cyclotron frequency with B₀ in tesla.

Above cutoff the electrons form a rotating space-charge wheel whose spokes keep step with the RF field across the cavity gaps. In the π-mode the phase step between cavities is 2πn/N with n = N/2, so neighbours are 180° apart; straps on alternate vanes keep the tube in it. Magnetrons give megawatt pulses at 40 % to 70 % efficiency, but each pulse starts with a random phase.

A TWT has no resonant cavity. A wire helix slows the RF wave to the beam speed: the wave follows the turns at nearly c, so its axial velocity is about c × p/(2πa) for pitch p and radius a. With the beam slightly faster, electrons bunch and feed the wave all along the helix. The helix is not resonant, so one tube covers an octave or more. Its gain is

A<sub>p</sub> = −9.54 + 47.3 N C dB,   C = (I₀Z₀ / 4V₀)<sup>1/3</sup>

C is the gain parameter, Z₀ the helix impedance, I₀ and V₀ the beam current and voltage, and N the helix length in electronic wavelengths.

4.7 Solid-state sources: Gunn, IMPATT, TRAPATT, tunnel diodes

A solid-state microwave source turns DC into RF inside a small piece of semiconductor, with no vacuum and no heated cathode. Each one relies on negative resistance: over part of its range, more voltage gives less current, so the device feeds energy into a resonant circuit instead of taking it. The Gunn diode gets it from electrons moving between energy valleys, the IMPATT and TRAPATT diodes from an avalanche and a transit delay, and the tunnel diode from quantum tunnelling. They are small, need a few volts to about a hundred volts, and serve in radar front ends, police speed guns, motion sensors and local oscillators.

You need: p–n junctions and reverse breakdown, drift velocity and mobility, and cavity resonators (see Microwave resonators and Q factor).

Gunn diode: transferred electrons

A Gunn diode is a slab of n-type GaAs (or InP) of length L with ohmic contacts at both ends. It has no p–n junction: it is a transferred-electron device (TED). The conduction band of GaAs has a low central valley, where electrons are light and fast (mobility about 8500 cm²/V·s), and a satellite valley about 0.3 eV higher, where they are heavy and slow.

At low field all electrons sit in the central valley and the drift velocity rises with field. Above a threshold field of about 3.2 kV/cm, electrons gain enough energy to move to the satellite valley, so the average velocity falls as the field rises. A falling velocity means a falling current: negative differential resistance (NDR). At still higher fields the velocity levels off near 10⁷ cm/s.

A uniform field in the NDR region is unstable. A small region of high field (a domain) forms near the cathode, grows, drifts to the anode at about the saturated velocity, and is absorbed; then the next one forms. Each domain arrival gives a current pulse, so the current oscillates at the transit-time frequency.

f = vd/L

f in hertz, vd the domain drift velocity (about 10⁵ m/s) and L the active length in metres. A 10 µm slab oscillates near 10 GHz.

  • Transit-time mode: needs n₀L > 10¹² cm⁻² (n₀ = doping in cm⁻³, L in cm) so that domains can form; frequency fixed by L.
  • Delayed and quenched domain modes: a resonant circuit sets the frequency a little below or above vd/L by delaying or quenching domain formation.
  • LSA mode (limited space-charge accumulation): the field swings through the NDR region faster than a domain can form, for 2 × 10⁴ < n₀/f < 2 × 10⁵ s/cm³; frequency set by the cavity, not by L, so higher frequency and power are possible.

The diode sits in a cavity that fixes the frequency; a varactor or YIG sphere tunes it. Output is milliwatts to about a watt, at a few per cent efficiency.

IMPATT, TRAPATT and BARITT diodes

An IMPATT (impact-ionisation avalanche transit-time) diode is a reverse-biased junction held at breakdown, for example the Read structure p⁺–n–i–n⁺: a thin avalanche region followed by a drift region of length Ld. Negative resistance comes from two delays that add up to half a cycle:

  1. Avalanche delay: the carrier current in the avalanche keeps growing as long as the RF voltage is above breakdown, so it peaks a quarter cycle (90°) after the voltage peak.
  2. Transit delay: the injected carrier pulse crosses the drift region at the saturated velocity vs and is designed to take about another quarter cycle at the terminals, so the terminal current lags the voltage by about 180°.
  3. A current 180° out of phase with the voltage means negative resistance: the diode delivers RF power to the circuit.

f ≈ vs / (2Ld)

vs ≈ 10⁵ m/s in silicon and Ld the drift length in metres; a 5 µm drift region gives about 10 GHz.

IMPATTs give the most power of any solid-state source at millimetre waves, with efficiency typically several per cent up to about 15 %, but the avalanche makes them noisy. TRAPATT (trapped plasma avalanche triggered transit) is a large-signal mode of a similar diode: a voltage pulse drives an avalanche front across the whole diode, filling it with a dense electron-hole plasma that drops the voltage to a low value, and the plasma is then extracted slowly. Because the extraction takes much longer than the IMPATT transit time, TRAPATTs run at lower frequencies (below about 10 GHz), in pulses, with high efficiency (tens of per cent). A BARITT diode injects carriers over a forward-biased barrier by punch-through instead of avalanche: much lower noise, much lower power.

Tunnel diode and choosing a source

A tunnel diode is a p–n junction doped so heavily that its depletion layer is only about 10 nm thick, so electrons tunnel through the barrier. Its current rises to a peak Ip at voltage Vp, falls to a valley Iv at Vv, then rises again as an ordinary diode. Between Vp and Vv the slope is negative.

Bias the diode at a DC voltage between Vp and Vv, inside the negative-slope region, and connect a resonator: it oscillates. Tunnelling is very fast, so the device works at high frequency, but the voltage swing is a few tenths of a volt, so the power is only microwatts to milliwatts. Tunnel diodes serve as low-power oscillators, fast switches and low-noise amplifiers.

4.8 Microwave measurements: VSWR, power, frequency, network analyzer

At microwave frequencies a multimeter cannot read a voltage that changes every few millimetres along a line. The bench instead measures quantities that stand still: the standing-wave pattern on a slotted line (giving VSWR, guide wavelength and load impedance), the heating effect of power, the resonance of a cavity (giving frequency), and, with a vector network analyser, the complex S-parameters themselves. Every component in the earlier chapters is checked this way before it goes into a system.

You need: Γ, VSWR and the standing-wave pattern (see Reflection coefficient, standing waves and VSWR), guide wavelength in a rectangular guide, and S-parameters and directional couplers.

Slotted line: VSWR, wavelength and load impedance

A slotted line is a length of waveguide (or coaxial line) with a thin slot along the centre of its broad wall, where it cuts no wall current. A small probe dips through the slot, samples the electric field, and feeds a crystal detector and meter. Sliding the probe maps the standing wave set up by the load.

VSWR S = V<sub>max</sub>/V<sub>min</sub>,   |Γ| = (S − 1)/(S + 1),   λg = 2 × (distance between adjacent minima)

Vmax and Vmin are probe readings proportional to field strength; minima are λg/2 apart. Minima are sharper than maxima, so they are used for positions.

A crystal detector at low level is square-law: its output follows RF power, so a meter reading M goes as V². If the meter is calibrated in voltage (the VSWR meters on lab benches are), use the readings as they are. If it reads power, take square roots first: S = √(Mmax/Mmin) and |Γ| = (√Mmax − √Mmin)/(√Mmax + √Mmin).

Frequency follows from λg: for the TE₁₀ mode, 1/λ₀² = 1/λg² + 1/λc² with λc = 2a. Load impedance: replace the load by a short and mark a minimum (a point a whole number of λg/2 from the load plane); refit the load and measure how far the minimum moves towards the load, dmin. Then

z<sub>L</sub> = Z<sub>L</sub>/Z₀ = (1 − jS tan βd<sub>min</sub>) / (S − j tan βd<sub>min</sub>),   β = 2π/λg

dmin is the distance from the load to the first voltage minimum. The same result comes from the Smith chart: go dmin towards the load from the r = 1/S point on the real axis.

High VSWR (above about 10): the minimum is too shallow to read against the maximum, and a square-law detector cannot cover the range. The double-minimum method measures the width W between the two points either side of a minimum where the detector reads twice the minimum power; then S ≈ λg/(πW).

Power, attenuation and frequency

  • Bolometer or thermistor mount: a small resistor whose resistance changes with temperature forms one arm of a self-balancing bridge. With no RF, the bridge supplies DC current I₁ to hold the element at its balance resistance R. RF heating then lets the bridge reduce the current to I₂ to keep R. The RF power equals the DC power removed: PRF = (I₁² − I₂²)R. This DC substitution makes the method absolute.
  • Thermocouple sensor: RF power heats the hot junction of a thin-film thermocouple; the emf comes from the temperature difference between the hot and cold junctions and is proportional to the absorbed power.
  • Diode sensor: fast and sensitive (down to about −70 dBm), square-law at low level and linear at high level.
  • High power: measure a known fraction through a directional coupler and fixed pads, then add back their dB values; at very high power a water-load calorimeter measures the heat directly.

Attenuation and insertion loss are measured by substitution: read the power with a direct connection (P₁), insert the device, read again (P₂); A = 10 log₁₀(P₁/P₂) dB. Reflection with a reflectometer: two couplers facing opposite ways sample the incident and reflected powers, and |Γ| = √(Prefl/Pinc).

Frequency: a cavity wavemeter is a high-Q cavity tuned by a micrometer plunger and coupled to the line. When it is tuned to the signal it absorbs power and the detector reading dips; the calibrated dial gives the frequency. An electronic counter with a prescaler or a down-converter reads frequency digitally to many digits; a spectrum analyser shows it with the spectrum.

Vector network analyser and SOLT calibration

A vector network analyser (VNA) sends a swept test signal into one port and uses directional couplers to separate the incident, reflected and transmitted waves. Receivers measure their amplitude and phase, and the instrument divides them: S₁₁ = b₁/a₁, S₂₁ = b₂/a₁, then the same with the source switched to port 2. It shows the matrix of S-parameters and the scattering matrix directly, in magnitude and phase, over frequency.

Raw readings carry systematic errors: finite coupler directivity, the source and load match of the test ports, and frequency tracking of the receivers (12 error terms for a full two-port). Calibration measures known standards at the reference plane and solves for those terms. SOLT uses a Short (Γ = −1), an Open (Γ = +1), a matched Load (Γ = 0) at each port, and a Thru connecting the ports; TRL (thru, reflect, line) suits on-wafer and waveguide work. After calibration the VNA corrects every sweep; check it with a known airline or pad before trusting a measurement.

  • Taking the distance between adjacent minima as λg. It is λg/2.
  • Square-rooting readings from a voltage-calibrated VSWR meter, or not square-rooting power readings. Check how the meter is calibrated first.

4.9 Microwave integrated circuits and MMIC

A microwave integrated circuit (MIC) builds a whole microwave circuit as flat patterns on one substrate, so that every connection is a short, controlled transmission line. In a hybrid MIC the lines and passive parts are printed on a ceramic board and the transistors and diodes are attached afterwards. In a monolithic MIC (MMIC) every part, transistors included, is made inside one semiconductor wafer. Phones, radar modules, satellite receivers and 5G base stations use them because they are small, repeatable and still behave above 1 GHz.

You need: microstrip and coplanar lines, εeff and λg (see Microstrip, stripline and printed lines), and S-parameters.

Hybrid MIC: printed passives, mounted devices

In a hybrid MIC the substrate carries the passive pattern: microstrip or coplanar lines, couplers, filters, matching stubs and thin-film resistors. Transistors, diodes and chip capacitors are made separately, fixed by epoxy or solder, and joined to the pattern with short gold bond wires. Hybrids are easy to tune by trimming, handle more power, and are quick to prototype; but each bond wire adds about 1 nH per millimetre, which matters at high frequency.

  • Alumina (Al₂O₃): εr ≈ 9.8, hard, cheap and a good heat conductor; the usual hybrid substrate, 0.25 mm or 0.635 mm thick.
  • Fused silica (quartz): εr ≈ 3.8, very low loss, used for fine lines at millimetre waves.
  • PTFE laminates (εr about 2.2 to 3.5): soft board for low-cost hybrids.
  • LTCC (low-temperature co-fired ceramic): many thin layers, so buried striplines and 3-D passives fit inside one package.

Line geometry sets impedance: a microstrip of width w on height h and permittivity εr has an impedance Z₀ and an effective permittivity εeff between 1 and εr, because part of the field is in air; the guided wavelength is λg = λ₀/√εeff. Thin-film patterns (sputtered metal, photolithography) give fine, stable lines and resistors; thick-film printing is cheaper and coarser.

MMIC: the whole circuit in one wafer

A monolithic microwave integrated circuit forms transistors, resistors, capacitors, inductors and lines in or on one semi-insulating wafer, usually GaAs (resistivity above 10⁷ Ω·cm, εr = 12.9), also GaN on SiC for power, InP above 100 GHz, and silicon (RF-CMOS, SiGe) for high volume. One wafer run yields thousands of identical circuits with no bond wires inside them.

  • Transistor: MESFET or HEMT on GaAs and GaN; HBT on GaAs, InP or SiGe; MOSFET in RF-CMOS. Above its corner frequency a transistor's current gain falls about 6 dB per octave, so a device with 20 dB more gain than needed at 2 GHz has about none to spare at 20 GHz (3.3 octaves higher).
  • Resistor: thin film (NiCr or TaN) or the implanted active layer; R = Rs × (length/width), with Rs the sheet resistance in Ω per square.
  • MIM capacitor: metal, thin silicon nitride, metal; C = ε₀εrA/d. With εr = 7.5 and d = 0.2 µm it gives about 0.33 fF per µm², so values are a fraction of a pF to a few pF.
  • Spiral inductor: a flat metal spiral, a few nH at most; series metal resistance and substrate loss keep its Q near 10 to 20.
  • Airbridge: a thick plated metal strap (the second metal) that leaves the surface and crosses over another line or a spiral's turns with air beneath, so its crossing capacitance is small. Via holes through the thinned wafer connect top-side grounds to the back metal.

A typical GaAs process: form the active layer; isolate devices; make ohmic contacts and gates; deposit nitride and build MIM capacitors and resistors; pattern the first metal (lines, spiral turns, capacitor plates); plate the airbridge metal; thin the wafer to about 100 µm, etch back-side vias and metallise the back as ground.

Distributed lines are long on a chip. A 50 Ω microstrip on 100 µm GaAs has εeff ≈ 8.4, so a quarter-wave line at 10 GHz is 2.6 mm long and at 2 GHz 13 mm, larger than most chips. Below about 20 GHz MMICs therefore use lumped spirals and MIM capacitors for matching; above it, lines become short enough to use.

Trade-offs, packaging and test

  • MMIC strengths: small, light, repeatable from chip to chip, broadband (no bond wires inside), and cheap per piece in volume.
  • MMIC limits: an expensive mask set and wafer run, no tuning after fabrication, low-Q passives, chip area costly, and power limited by heat in a thin die.
  • Hybrid MIC: higher power and Q, tunable, cheap tooling, quick to change; larger and less repeatable.

Packaging is part of the design. The die sits in a metal or ceramic package, connected by bond wires, flip-chip bumps or a coplanar launch to a connector. Bond wires add series inductance, and the package cavity must not resonate in the band: a cavity 15 mm by 15 mm has its first resonance near 14 GHz, so a 20 GHz chip needs a smaller cavity or absorber in the lid.

Test structures on the same wafer settle the process: a microstrip ring or half-wave resonator gives εeff from its resonant frequency and the loss from its Q. The finished chips are measured on-wafer with probes and a network analyser (see Microwave measurements). The amplifiers, mixers and oscillators built from these parts are treated in RF circuits and transceivers.

Worked example

Question. A GaAs MMIC matching network needs (a) a 2 pF MIM capacitor using silicon nitride with εr = 7.5 and d = 0.2 µm, and (b) a 100 Ω thin-film resistor in a 50 Ω/□ film, 10 µm wide. Question. An on-chip spiral of 2 nH has Q = 12 at 2 GHz. (a) Find its series resistance. (b) Placed in series in a 50 Ω line, what is |S₂₁| and the power lost in it? (c) A 0.5 mm bond wire (about 0.5 nH) joins a hybrid amplifier at 10 GHz: find its reactance.

Exam traps

  • Calling every flat microwave board an MMIC. It is monolithic only if the transistors are made in the wafer; a board with mounted transistors is a hybrid MIC.
  • Treating on-chip spirals as ideal. Their Q is only about 10 to 20, so matching networks built from them lose signal and add noise.
  • Using εr where εeff belongs. Microstrip λg = λ₀/√εeff, with εeff < εr because part of the field is in air.
  • Forgetting that bond wires and vias are inductors, about 1 nH per millimetre: 0.5 nH is already 31 Ω at 10 GHz.
  • Mixing up the airbridge and the first metal. The airbridge is the plated second metal that crosses over lines with air beneath; lines, spiral turns and lower capacitor plates are the first metal.

Takeaways

  1. At microwave frequencies waves, not voltages and currents, describe a network: b = S a, with S = Sᵀ for a reciprocal network and S†S = I for a lossless one.
  2. A lossless reciprocal three-port cannot be matched at all ports, so a tee reflects, a resistive divider loses 6.02 dB per output, and a Wilkinson adds a resistor that works only for signals entering an output.
  3. The magic tee and the rat-race are both 180° hybrids: sum at one port, difference at another, with those two ports isolated; the tee gets this from symmetry, the ring from path lengths.
  4. A directional coupler is fixed by three numbers, and I = C + D: a 10 dB, 20 dB-directivity coupler sends 10 mW, 0.1 mW and 89.9 mW of every 100 mW to its coupled, isolated and through ports.
  5. Decibels of power add along a chain: dBm − dB = dBm, and matched pads in cascade add their dB.
  6. A biased ferrite breaks reciprocity; that is what makes an isolator absorb reverse power and a circulator stay matched and lossless as a three-port.
  7. Tubes win on power: a klystron bunches a beam by velocity modulation (at most 58.2 % with two cavities), a magnetron works above the Hull cutoff field, and a TWT amplifies over an octave along a helix.
  8. Solid-state sources work by negative resistance: Gunn f = vd/L at a few per cent efficiency, IMPATT f = vs/(2Ld) with more power and more noise, tunnel diodes at microwatt levels.
  9. Bench measurements are indirect: λg = 2 × (distance between adjacent minima), VSWR from Vmax/Vmin (square-rooted for a power-reading detector), and S-parameters only after a VNA calibration.
  10. An MMIC forms every part in one wafer: small, repeatable and broadband, but low in power and passive Q, and impossible to tune after fabrication.

Analyze Compare microwave tubes and solid-state sources. Which would you choose for a pulsed search radar needing 1 MW peak and for a 10 GHz motion sensor needing 10 mW? Support the choice with the DC power each needs. 13 marks

Points to cover. what limits each: electron beam in vacuum against a small semiconductor die; table: power, frequency, efficiency, voltage, size, life, noise, cost; radar: magnetron (or klystron for coherent radar); duty cycle and average power; sensor: Gunn diode; DC power and heat; closing numeric comparison.

Model answer.

  1. Why the two families differ. A tube moves an electron beam through vacuum, where it can carry a large current at tens of kilovolts with nothing to overheat but the collector and anode, which can be large and cooled. A solid-state source makes its power inside a semiconductor a few micrometres thick: the transit length must be short for high frequency, the voltage is limited by breakdown, and the heat comes out through a tiny area. So tubes win on power at a given frequency, and semiconductors on size, voltage and life.

If the radar must be coherent (pulse-Doppler, moving-target indication), a klystron amplifier or a TWT driven by a stable source is used instead, because each magnetron pulse starts with a random phase.

  1. Both are four-port 180° hybrids. A signal into the sum port leaves the two outputs equal and in phase; a signal into the difference port leaves them equal and in antiphase; the sum and difference ports are isolated. Evaluate Prove that a lossless reciprocal three-port cannot be matched at all its ports.   1. Assume a three-port that is matched (Sᵢᵢ = 0), reciprocal (Sᵢⱼ = Sⱼᵢ) and lossless (S†S = I):
    S = [ 0  S₁₂  S₁₃ ;  S₁₂  0  S₂₃ ;  S₁₃  S₂₃  0 ]

                         |S₁₃|² + |S₂₃|² = 1   (3)

Glossary

Airbridge
A plated metal strap that crosses over other lines on an MMIC with air underneath, so with little capacitance.
Attenuator pad
A T or π resistor network that gives a set loss in dB while presenting Z₀ at both ports.
Circulator
A ferrite multi-port that routes power in a fixed cyclic order, such as 1 to 2, 2 to 3, 3 to 1.
Directivity
D = 10 log₁₀(P₃/P₄) dB, how well a coupler separates the forward wave from the reverse wave.
Faraday rotation
Turning of the polarisation plane of a wave in a biased ferrite, in a sense set by the bias.
Ferrite
A magnetic ceramic insulator whose permeability becomes a nonreciprocal tensor under a DC magnetic bias.
Hull cutoff
The magnetic field (or voltage) at which magnetron electrons just graze the anode with no RF present.
Hybrid ring
A 1.5λg ring hybrid (rat-race) whose sum and difference ports are opposite each other and isolated.
Insertion loss
−20 log₁₀|S₂₁| dB: the loss in transmission through a two-port.
Lossless network
A network that absorbs no power; its scattering matrix is unitary, S†S = I.
LSA mode
A Gunn mode in which the field swings through the negative-resistance region faster than a domain can form; the cavity sets the frequency.
Magic tee
A four-port waveguide hybrid with an E-arm and an H-arm on one junction; all four ports matched, E- and H-arms isolated, collinear arms isolated.
Matched load
A load whose impedance equals the reference impedance, so no wave reflects from it.
MMIC
A monolithic microwave integrated circuit: all active and passive parts made in or on one semiconductor chip.
Negative differential resistance
A part of a device curve where current falls as voltage rises, so the device can feed power to a resonator.
Network analyser
A calibrated instrument that measures the magnitude and phase of S-parameters over frequency.
Port
A terminal pair or waveguide opening where power enters or leaves a microwave network.
Reciprocal network
A network whose scattering matrix is symmetric, Sᵢⱼ = Sⱼᵢ; any network without ferrite, plasma or active devices.
Reference plane
The position on each port line at which the incident and outgoing waves are defined; moving it by βl changes the phase of S.
Repeller
The negative electrode of a reflex klystron that turns the beam back through its cavity.
Return loss
−20 log₁₀|Γ| dB: how far the reflected wave is below the incident one.
Slow-wave structure
A helix or coupled cavities that slow the RF wave to about the beam speed in a TWT.
Square-law detector
A diode detector whose output is proportional to RF power, that is to the square of the RF voltage.
Velocity modulation
Speeding up and slowing down electrons of a beam by an RF gap voltage, so that they later form bunches.
Wilkinson divider
A three-port divider with quarter-wave arms and an isolation resistor, matched at all ports with isolated outputs.
