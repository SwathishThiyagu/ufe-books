3.1 Two-element arrays and pattern multiplication

An array is a group of identical antennas fed from one source so that their fields add in some directions and cancel in others. The smallest array has two elements. Its far-field pattern is the pattern of one element multiplied by an array factor, a term that depends only on the spacing, the wavelength and the phase difference between the two feed currents. Designers use it to point a beam or place a null without redesigning the element, from AM broadcast towers to mobile base-station panels.

You need: the radiation pattern, the field and power patterns and the half-wave dipole pattern from the antenna fundamentals topic.

The two-source model and the array factor

Take two identical isotropic radiators (an isotropic element radiates equally in every direction). Put element 1 at the origin and element 2 on the +z axis, a distance d away; the z axis is the array axis. Feed element 1 with current I and element 2 with I ejα, so α is the phase by which element 2 leads element 1, in radians. Measure the direction θ from the +z axis.

A far-field point in direction θ is closer to element 2 by the path difference d cosθ. The wave from element 2 therefore arrives ahead in phase by βd cosθ, where β = 2π/λ is the phase constant and λ the free-space wavelength. Adding the feed lead α, the total phase of wave 2 relative to wave 1 is ψ. Adding two equal phasors 1 and ejψ and taking the magnitude gives the array factor.

ψ = βd cosθ + α

ψ is the total phase difference between the two waves in radians; β = 2π/λ in rad/m; d is the spacing in metres; θ is the angle from the array axis; α is the feed-current phase of element 2 relative to element 1.

|AF| = |1 + ejψ| = 2|cos(ψ/2)|

AF is the array factor (a field ratio). Its largest value is 2. Dividing by 2 gives the normalized array factor |cos(ψ/2)|, which peaks at 1; the normalized power pattern is cos²(ψ/2).

Maxima and nulls

The waves add fully when ψ = 0, ±2π, … (|AF| = 2) and cancel when ψ = ±π, ±3π, … (AF = 0). Only the values of ψ that a real angle can produce matter: as θ runs from 0° to 180°, cosθ runs from +1 to −1, so ψ sweeps the visible range from βd + α down to −βd + α.

Three cases cover most exam questions. With d = λ/2 and α = 0, ψ = π cosθ: the maximum is at θ = 90° (broadside) and the nulls are at 0° and 180°, along the axis. With d = λ/2 and α = π, the maxima move to both ends of the axis and the null to 90°. With d = λ/4 and α = −π/2, ψ = (π/2)(cosθ − 1): ψ = 0 at θ = 0° and ψ = −π at θ = 180°, so the array fires one way along the axis and is silent the other way. This one-sided cardioid is the idea behind the Yagi-Uda reflector.

A beam points toward the element whose current lags. Measured from broadside instead of from the axis, cosθ becomes sinθ; keep one reference for the whole problem.

Pattern multiplication

Real elements are not isotropic. For identical, identically oriented elements, the total field is the field of one element at the origin times the array factor, because the second element radiates the same shape shifted by d and multiplied by ejψ. This is the principle of pattern multiplication:

E(θ, φ) = Ee(θ, φ) × AF(θ, φ)

Ee is the field pattern of one element; AF carries the spacing and phasing; the power pattern is |Ee|² × |AF|². The nulls of the total pattern are all the nulls of Ee together with all the nulls of AF.

Two half-wave dipoles mounted parallel to the x axis and spaced along z show it. The dipole has its own null along x, its axis; the array factor adds its nulls along z. The rule also works for groups: an array of identical groups has the pattern of one group times the array factor of the groups. It fails when the elements differ, point different ways, or couple so strongly that their currents are unequal.

Worked example

Question. Two identical isotropic radiators are spaced d = λ/2 along the z axis and element 2 leads element 1 by α = 90°. Find the direction of maximum radiation, the null, and the normalized field and power at θ = 0°, with θ measured from the array axis.

  1. βd = (2π/λ)(λ/2) = π rad and α = π/2 rad, so ψ = π cosθ + π/2.
  2. The visible range of ψ runs from π + π/2 = 3π/2 (at θ = 0°) to −π + π/2 = −π/2 (at θ = 180°).
  3. Maximum: ψ = 0 lies in the range. π cosθ = −π/2 gives cosθ = −0.5, so θ = 120°.
  4. Null: ψ = π lies in the range (ψ = −π does not). π cosθ = π/2 gives cosθ = 0.5, so θ = 60°.
  5. At θ = 0°: ψ = 3π/2 and the normalized field is |cos(3π/4)| = 0.707; the normalized power is 0.707² = 0.5, that is −3 dB.
  6. Half power: |cos(ψ/2)| = 0.707 needs ψ = ±π/2, that is cosθ = 0 or cosθ = −1, so θ = 90° and 180°. The main beam stays above half power from 90° all the way to 180°.

Answer. Maximum at θ = 120°, null at θ = 60°; at θ = 0° the field is 0.707 and the power 0.5 (−3 dB) of the maximum. The beam has swung from broadside toward element 1, the lagging element.

Worked example 2

Question. Four isotropic sources lie on the z axis with spacing λ/2, all fed in phase. Treat them as two pairs: pair A is sources 1 and 2, pair B is sources 3 and 4, and the pair centres are λ apart. Use pattern multiplication to find every null, and check the result at θ = 60°.

  1. One pair (d = λ/2, α = 0) has normalized factor |cos((π/2)cosθ)|, with nulls where (π/2)cosθ = ±π/2, that is θ = 0° and 180°.
  2. The two pair centres are λ apart, in phase: ψ = 2π cosθ and the factor is |cos(π cosθ)|, with nulls where π cosθ = ±π/2, that is cosθ = ±0.5, θ = 60° and 120°.
  3. Total pattern = pair pattern × pair-array factor = |cos((π/2)cosθ)| × |cos(π cosθ)|. Its nulls are the union: θ = 0°, 60°, 120° and 180°.
  4. At θ = 60°: cosθ = 0.5, pair pattern = cos(π/4) = 0.707, group factor = cos(π/2) = 0, product = 0, a null as predicted.
  5. At θ = 75°: pair pattern 0.918 × group factor 0.687 = 0.631, the same as the direct four-element sum.

Answer. Nulls at 0°, 60°, 120° and 180° with the main beam at 90°. The same four nulls come out of the N-element formula of the uniform linear array, which confirms the product rule.

Exam traps

  • Adding the powers of the two elements. Add the fields as phasors, then square: two equal in-phase fields give four times the power of one, not twice.
  • Getting the sign of βd cosθ backwards. The far point is closer to the element on the +z side, so that element’s wave arrives ahead; with α as its feed lead, ψ = βd cosθ + α.
  • Setting ψ = 0 for a null. A null needs ψ = ±π, ±3π, …, and only the values inside the visible range βd + α to −βd + α give real angles.
  • Writing βd = π/2 for d = λ/2. It is π; for d = λ/4 it is π/2. Convert α to radians before adding it.
  • Forgetting the element’s own nulls. With pattern multiplication the total pattern has every null of the element and every null of the array factor.

3.2 Uniform linear arrays: broadside and end-fire

A uniform linear array (ULA) is N identical elements on a straight line with equal spacing d, equal current amplitude and a constant phase step α from one element to the next. Adding elements narrows the beam and raises directivity without making any single element larger. With α = 0 the beam is broadside, at right angles to the line; with α = −βd it is end-fire, along the line. Sector panels on mobile towers are broadside arrays; a long end-fire array suits a mast or a boom that points at the target.

You need: the two-element array factor and pattern multiplication from two-element arrays, and beamwidth and directivity from the antenna fundamentals topic.

The array factor of N elements

Number the elements 0 to N − 1 along the z axis. Element n has current I ejnα, and its wave reaches a far point in direction θ (measured from the axis) ahead by nβd cosθ. Every neighbour pair therefore differs by the same ψ = βd cosθ + α, and the array factor is a geometric series:

AF = Σ ejnψ (n = 0 … N − 1)

The sum of N unit phasors, each turned ψ further than the last.

|AFn| = |sin(Nψ/2) / (N sin(ψ/2))|

AFn is the array factor normalized to 1 at ψ = 0; N is the number of elements; ψ = βd cosθ + α in radians.

The main lobe is at ψ = 0. Nulls are at Nψ/2 = ±mπ, that is ψ = ±2πm/N with m = 1, 2, … but not a multiple of N. Between nulls lie sidelobes; for N = 4 the first sidelobe is 0.272 of the peak (−11.3 dB), and for large N it tends to −13.3 dB. When ψ reaches ±2π inside the visible range (βd + α down to −βd + α), the phasors line up again and a second full-size beam, a grating lobe, appears.

Broadside and end-fire conditions

Broadside: α = 0, so ψ = βd cosθ and ψ = 0 at θ = 90°. The beam is a disc around the array axis. The first nulls satisfy cosθ = ±λ/(Nd). The visible range is ±βd, so a grating lobe (ψ = ±2π) appears at the ends of the axis once d ≥ λ.

Ordinary end-fire: α = −βd, so ψ = βd(cosθ − 1), which is 0 at θ = 0°. The beam points along +z, toward the lagging end; α = +βd turns it to θ = 180°. The visible range is now 0 down to −2βd, so a grating lobe at the back (ψ = −2π at θ = 180°) appears once d ≥ λ/2. An end-fire array therefore needs d < λ/2, and λ/4 is the usual choice.

Hansen-Woodyard end-fire: some syllabi add α = −(βd + π/N). The extra phase makes the beam narrower and raises directivity about 1.8 times above ordinary end-fire, at the cost of higher sidelobes and a tight tolerance on the phase.

Worked example

Question. A 4-element broadside array has spacing d = λ/2 and equal in-phase currents. Find (a) the main-beam direction, (b) the first nulls and the first-null beamwidth, (c) the half-power beamwidth, and (d) the level of the first sidelobe.

  1. βd = π and α = 0, so ψ = π cosθ. The visible range is −π to π.
  2. (a) ψ = 0 gives cosθ = 0, so the beam is at θ = 90°.
  3. (b) First nulls: ψ = ±2π/4 = ±π/2, so cosθ = ±0.5 and θ = 60° and 120°. FNBW = 120° − 60° = 60°. The formula agrees: 2 sin⁻¹(λ/(4 × 0.5λ)) = 2 sin⁻¹(0.5) = 60°.
  4. Second nulls: ψ = ±π gives cosθ = ±1, θ = 0° and 180°.
  5. (c) Half power: sin(2ψ)/(4 sin(ψ/2)) = 0.707 is solved numerically at ψ = ±0.715 rad. Then cosθ = ±0.715/π = ±0.228, so θ = 76.8° and 103.2° and HPBW = 26.3°. The long-array estimate 50.8/(Nd/λ) = 50.8/2 = 25.4° is close.
  6. (d) The sidelobe between the first and second null peaks at θ = 42.9° (and 137.1°) with |AFn| = 0.272, that is 20 log 0.272 = −11.3 dB.

Answer. Beam at 90°, first nulls at 60° and 120° (FNBW 60°), HPBW 26.3°, first sidelobe −11.3 dB at 42.9° and 137.1°.

Exam traps

  • Using the broadside spacing rule for an end-fire array. Broadside is free of grating lobes up to d < λ; end-fire already has a full back lobe at d = λ/2.
  • Leaving α out of ψ. A zero of cosθ is the main beam only when α = 0.
  • Counting the m = N null. Nψ/2 = ±Nπ is ψ = ±2π, a grating lobe, not a null.
  • Quoting the broadside beamwidth formula for end-fire. End-fire beamwidths use cos⁻¹(1 − …) and are much wider for the same length.
  • Thinking more elements always means a wider band of nulls. More elements give more nulls, each closer to the beam, and a narrower main lobe.

3.3 Binomial, Chebyshev and phased arrays

A uniform array has the narrowest beam for its length, but its first sidelobe is only about 13 dB down, too high for a radar that must ignore a strong echo off to one side. Giving the centre elements more current than the edge elements, an amplitude taper, lowers the sidelobes and widens the beam. The binomial taper removes the sidelobes completely; the Dolph-Chebyshev taper holds every sidelobe at one chosen level and gives the narrowest beam for that level. A progressive phase step, set electronically, then steers the beam: that is a phased array.

You need: the N-element array factor and the broadside and end-fire conditions from uniform linear arrays.

Binomial arrays

Keep the elements on the z axis with spacing d, angle θ from the axis and ψ = βd cosθ + α. With amplitudes an the array factor is AF = Σ an ejnψ. The binomial array copies the two-element pattern N − 1 times over: (1 + ejψ)N−1. Expanding the power gives the amplitudes as the rows of Pascal’s triangle.

an = C(N − 1, n), n = 0 … N − 1

C(N − 1, n) is “N − 1 choose n”: 1, 1 for N = 2; 1, 2, 1 for N = 3; 1, 3, 3, 1 for N = 4; 1, 4, 6, 4, 1 for N = 5.

|AF| = |2 cos(ψ/2)|N−1

The normalized pattern is |cos(ψ/2)|N−1. For d = λ/2 and α = 0 the visible range is −π ≤ ψ ≤ π, where |cos(ψ/2)| falls from 1 to 0 with no second peak.

So a broadside binomial array with d ≤ λ/2 has no sidelobes at all. The price is a wide beam and low directivity: for N = 5 the half-power beamwidth is 30.3° (the estimate 1.06/√(N − 1) rad gives 30.4°), against 20.8° for the uniform array of the same length, and the edge currents shrink fast (1/6 of the centre for N = 5).

Dolph-Chebyshev arrays

Dolph saw that the Chebyshev polynomial Tm(x) = cos(m cos⁻¹x) swings between −1 and +1 for |x| ≤ 1 and then rises steeply. If the array factor of an N-element symmetric broadside array is made equal to TN−1(x0 cos u), with u = ψ/2, the swings become sidelobes of height 1 and the steep part becomes a main beam of height R. Every sidelobe is then 1/R of the peak, and no taper gives a narrower first-null beamwidth for that level.

R = 10SLL/20

R is the main-beam to sidelobe voltage ratio; SLL is how far the sidelobes sit below the peak in dB, taken as a positive number. A −20 dB sidelobe gives R = 10; −30 dB gives R = 31.6.

x0 = cosh[cosh⁻¹(R)/(N − 1)]

x0 is the point where TN−1(x0) = R; it maps the main-beam peak (u = 0).

  1. Find R from the sidelobe level and x0 from the formula above.
  2. Write the array factor of the symmetric array as a cosine series: for odd N = 2M + 1, AF = I0 + 2I1 cos 2u + … + 2IM cos 2Mu, where I0 is the centre current.
  3. Write each cos 2ku as powers of cos u, put cos u = x/x0, and match the coefficients of TN−1(x), highest power first.
  4. Normalize the currents, usually to the edge element.

Phased arrays: steering with the phase step

The beam of a uniform-phase-step array sits where ψ = 0. To point it at θ0 from the axis, set the step α so that ψ is zero there. Each element gets its phase from a phase shifter fed by a power divider; changing the shifter settings moves the beam in microseconds with nothing turning. Phase-shifter hardware belongs to the microwave components topic.

α = −βd cosθ0

θ0 is the scan direction measured from the array axis (θ0 = 90° is broadside). Radar books often measure the scan angle θs = 90° − θ0 from broadside; then α = −βd sinθs.

d/λ < 1/(1 + |cosθ0|)

The condition for no grating lobe in visible space when the beam is steered to θ0. At broadside it allows d < λ; at end-fire it requires d < λ/2. So d = λ/2 is safe for every scan angle short of end-fire.

Phase shifters give a fixed phase, not a fixed time delay, so the beam moves when the frequency changes: cosθ0(f) = −αc/(2πfd). This is beam squint. A beam set 40° off broadside at 10 GHz sits only 32.4° off broadside at 12 GHz. True-time-delay lines or digital beamforming remove it in wideband systems.

3.4 Yagi-Uda and log-periodic antennas

A Yagi-Uda antenna gets a directional beam from one driven dipole and a row of rods that are not connected to anything. It is cheap and light and gives 7 to 15 dBi, but only over a few per cent of bandwidth. A log-periodic dipole array (LPDA) makes the opposite trade: every dipole is fed, the dipoles grow in a fixed ratio from front to back, and the antenna keeps its pattern over a 3:1 or 10:1 band. Yagis point at TV transmitters from rooftops across India; LPDAs serve EMC test labs, HF stations and wideband monitoring.

You need: two-element arrays for the one-sided cardioid pair, uniform linear arrays for end-fire, and the half-wave and folded dipoles from the antenna fundamentals topic.

The Yagi-Uda antenna

Shintaro Uda built and studied the array in Japan in the 1920s and Hidetsugu Yagi published it in English, so both names stay. One element is driven: a half-wave dipole, often a folded dipole, whose input resistance of about 300 Ω suits a twin feeder. The other rods are parasitic: they sit on the boom but are not wired to the feed.

  • Driven element: 0.46λ to 0.48λ long, λ being the free-space wavelength at the design frequency.
  • Reflector: one rod behind the driven element, 0.50λ to 0.55λ long, 0.15λ to 0.25λ away.
  • Directors: rods in front, 0.40λ to 0.45λ long, each a little shorter than the one behind it, 0.15λ to 0.35λ apart.
  • Gain: about 7 dBi with one reflector and one director, 9 to 11 dBi with five elements, up to about 15 dBi for long booms; bandwidth 2 to 5 % of the design frequency.

Each parasitic rod carries a current induced by the driven element’s field and re-radiates. A rod longer than its resonant length (about λ/2) is inductive, a shorter one capacitive, so the rod length sets the phase of the induced current relative to the field that induces it; the spacing adds a path phase. With the reflector about 0.2λ behind, the two together make the reflector behave like the rear element of the cardioid pair (λ/4 apart, rear current leading by 90°): its wave cancels the driven element’s wave toward the back and adds toward the front. The directors are phased so that their waves stay in step with the wave moving forward along the boom, which makes the Yagi an end-fire array firing away from the reflector.

The phases come from lengths and spacings, so they are right only near one frequency. More directors raise the gain with diminishing returns: doubling the boom length adds roughly 2 to 3 dB.

The log-periodic dipole array

A log-periodic antenna repeats its geometry at sizes in a fixed ratio, so its behaviour at frequency f repeats at f/τ, f/τ², and so on; if the steps are small, the properties hardly change in between. In the dipole version the dipoles shrink by τ from back to front, their tips lie on two straight lines from an apex, and the spacings shrink in step.

τ = Ln+1/Ln = dn+1/dn

τ is the scale factor (less than 1, typically 0.8 to 0.95); Ln is the length of dipole n counted from the longest; dn is the gap between dipoles n and n + 1.

σ = dn/(2Ln)

σ is the spacing factor, typically 0.06 to 0.2; the half apex angle is α = tan⁻¹[(1 − τ)/(4σ)].

N = 1 + ln(B)/ln(1/τ), B = fmax/fmin

N is the number of dipoles, rounded up; B is the bandwidth ratio. The longest dipole is about λ/2 at fmin: L1 (m) = 150/fmin (MHz).

All dipoles are fed from a two-wire line along the boom, with the connections crossed between neighbours, and the cable is connected at the short front end. At a given frequency only the few dipoles near half a wavelength carry large current: the active region. The crossed feed makes the active dipoles fire toward the short end. Behind the active region the longer dipoles carry little current; in front of it the short dipoles are too small to radiate. As the frequency rises the active region slides forward.

3.5 Aperture and horn antennas; Babinet's principle

An aperture antenna radiates from an opening, not from a thin wire: the field spread across the opening sets the beam, and the wider the opening in wavelengths, the narrower the beam. A horn is the commonest aperture: a waveguide whose walls flare out so that the guided wave grows gently to a large opening instead of meeting free space at an abrupt end. Babinet’s principle links a slot cut in a metal sheet to a metal strip of the same shape, so the slot antennas on aircraft skins and waveguide walls can be worked out from dipole results.

You need: the TE10 mode of rectangular waveguide from the waveguide topic, and directivity, gain and effective aperture from the antenna fundamentals topic.

Aperture fields and effective area

Across the opening the field has an amplitude and a phase at every point; this aperture field is the source of the far field. A field of equal amplitude and phase everywhere (uniform illumination) gives the narrowest beam for the size but high sidelobes. A field that falls toward the edges (a taper) lowers the sidelobes and widens the beam, just as the amplitude tapers of arrays do. A phase that varies across the opening spoils the beam further.

Ae = ηap A

Ae is the effective aperture in m²; A is the physical area of the opening in m²; ηap is the aperture efficiency (0 to 1), which counts taper and phase error.

D = 4πAe/λ²

D is the directivity as a ratio; λ is the free-space wavelength in m. For a horn with negligible wall loss the gain G equals D; with loss, G = erD, where er is the radiation efficiency.

A rectangular waveguide fed in the TE10 mode already has a cosine taper across its broad wall, so even a perfect horn opening has ηap ≈ 0.81 from taper alone; the phase error of a practical flare brings it down to about 0.5. Aperture efficiency is not radiation efficiency: one is about how well the opening is used, the other about power lost as heat.

Horn antennas

Flaring only the walls in the plane of the electric field (the narrow walls of the TE10 guide) gives an E-plane sectoral horn; flaring only the broad walls, in the plane of the magnetic field, gives an H-plane sectoral horn; flaring both gives the pyramidal horn, the usual gain standard. A conical horn flares a circular guide; a corrugated horn has rings cut inside, which give equal E- and H-plane patterns and low cross-polarization for reflector feeds.

The wave inside the flare spreads from the apex as a cylindrical or spherical front, so it reaches the edge of the opening later than the centre. For an opening of width a and a length ℓ from the apex, the extra path at the edge is about δ = a²/(8ℓ). A short horn with a wide flare has a large δ, which fills the nulls, raises the sidelobes and lowers the gain. The optimum horn gives the most gain for its length; it allows δ = 0.25λ in the E-plane and δ = 0.375λ in the H-plane (the H-plane can take more because the cosine taper already weakens the edges):

ℓE = B²/(2λ), ℓH = A²/(3λ)

A is the H-plane width and B the E-plane height of the opening; ℓE and ℓH are the apex-to-aperture lengths for optimum flares. An optimum pyramidal horn has ηap ≈ 0.5.

HPBWE ≈ 56λ/B, HPBWH ≈ 67λ/A

Half-power beamwidths in degrees of an optimum horn. The H-plane beam is wider for the same size because of the cosine taper.

Babinet’s principle and slot antennas

Babinet’s principle in optics says that the fields behind a screen with a hole and behind the complementary screen (a flat piece the shape of the hole) add up to the field with no screen at all. Booker extended it to electromagnetic waves: the complementary screen must also swap the electric and magnetic fields, so the sum is a vector sum with the polarization turned through 90°.

The useful result: a narrow slot cut in a large conducting sheet radiates the same pattern as a dipole of the same length and shape, with E and H interchanged. A horizontal slot therefore radiates like a vertical dipole. The pattern is shared, but the impedance is not:

Zslot Zdipole = η0²/4

η0 = 120π ≈ 377 Ω is the impedance of free space, so η0²/4 ≈ 35 530 Ω². Zslot and Zdipole are the input impedances of the slot and its complementary strip dipole.

Since a dipole is a low-impedance antenna, its complementary slot is a high-impedance one, and a dipole that is inductive gives a slot that is capacitive. Slots are flush with the surface, so they suit aircraft and missiles; rows of slots cut in a waveguide wall make the slotted-waveguide arrays of marine radars.

3.6 Parabolic reflector antennas

A parabolic reflector, the dish, takes the spherical wave spreading from a small feed at its focus and sends it out as a plane wave across its whole mouth. A plane wave over an aperture many wavelengths wide gives very high gain and a very narrow beam: a 3 m dish at 4 GHz gives about 40 dBi with a beam under 2° wide. Dishes carry satellite TV, radar, deep-space links and microwave hops between towers. The design questions are where to put the feed, how strongly to light the rim, and how much gain and beamwidth result.

You need: effective aperture and aperture efficiency from aperture and horn antennas, and gain and beamwidth from the antenna fundamentals topic.

Why a parabola makes a plane wave

A parabola is the set of points equally far from a fixed point, the focus, and a fixed line, the directrix. Turn it about its axis and you get a paraboloid. With the vertex at the origin and the axis along z, the surface is z = r²/(4f), where r is the distance from the axis and f the focal length, the distance from the vertex to the focus. A dish of diameter D has its rim at r = D/2.

Every ray from the focus reflects parallel to the axis, and every such ray travels the same total distance from the focus to any plane across the mouth. All of them arrive in phase, so the spherical front from the feed becomes a plane front of width D. By reciprocity the dish works the same way on receive, collecting a plane wave into the feed.

tan(ψ0/2) = D/(4f)

ψ0 is the half angle the rim subtends at the focus: the feed must light ±ψ0. Small f/D (a deep dish) means a wide ψ0; f/D is usually 0.25 to 0.5.

Feeds, spillover and aperture efficiency

Prime focus: a horn at the focus looks back at the dish. It is simple, but the feed, its cable and its struts sit in front of the aperture and block part of it. Cassegrain: a small hyperbolic subreflector placed between the vertex and the focus sends the beam back through a hole at the vertex to a feed behind the dish, so the receiver sits close to the feed with a short, low-loss line; only the subreflector shadows the centre. Gregorian: a concave ellipsoidal subreflector placed beyond the focus does the same job. An offset dish, the kind on most DTH roofs, uses only one side of a paraboloid so that the feed is out of the beam altogether.

The feed’s own pattern decides how the dish is lit. Power aimed past the rim is spillover: it is lost and, on receive, picks up warm ground noise. A feed that lights the rim weakly cuts spillover but wastes the outer part of the dish (taper loss). The best compromise lights the rim about 10 dB below the centre. Blockage, cross-polarization and surface error take more: Ruze’s rule says a surface with RMS error ε loses the factor e−(4πε/λ)², so ε = λ/16 already costs 2.7 dB and ε = λ/30 costs 0.8 dB. Practical dishes reach an overall η = 0.55 to 0.7.

Gain and beamwidth

G = η(πD/λ)²

G is the gain as a ratio; η is the aperture efficiency; D is the diameter and λ the wavelength in the same unit. It is the aperture formula G = 4πAe/λ² with Ae = η πD²/4.

HPBW ≈ 70λ/D deg, BWFN ≈ 140λ/D deg

HPBW is the half-power beamwidth and BWFN the beamwidth between first nulls, in degrees. 70λ/D suits the usual tapered feed; a uniformly lit circular aperture gives 58λ/D for the half-power width.

Two scaling facts follow. The same dish at twice the frequency has four times the gain (+6 dB) and half the beamwidth, until the surface error becomes a sizeable fraction of λ. And (πD/λ)² equals 4π times the mouth area counted in square wavelengths, which is the aperture formula again, not the number of square wavelengths itself.

3.7 Microstrip patch antennas

A microstrip patch antenna is a flat piece of copper printed on one side of a thin dielectric board, with a solid copper ground on the other side. The patch and the ground form a cavity that resonates when the patch is about half a wavelength long in the board, and the field that fringes out at two of its edges radiates. It costs almost nothing to etch with the rest of a circuit, so it sits in phones, Wi-Fi routers, GPS receivers, FASTag readers and radar panels. Its price is a narrow band and modest gain.

You need: the microstrip line and its effective permittivity from the transmission-line topic, and gain and polarization from the antenna fundamentals topic.

How the patch radiates

A rectangular patch has length L (the resonant dimension) and width W, on a substrate of thickness h and relative permittivity εr. In the dominant TM10 mode the electric field under the patch is vertical, with a half-cosine variation along L: strongest at the two edges a distance L apart, zero at the centre line, and of opposite sign at the two ends.

At each of those two edges the field fringes out of the board. At the edge where it points down it runs from the patch out to the ground beyond; at the edge where it points up it runs from the ground back in to the patch. Seen from above, both horizontal parts therefore point the same way, while the vertical parts are opposite and cancel in the far field. The two edges act as two narrow slots radiating in phase, a broadside pair about half a guided wavelength apart, with the beam straight up from the board and the polarization along L. The two side edges along L radiate little.

The substrate decides size and band. A higher εr shrinks the patch; a thicker board with low εr (foam, εr ≈ 1.1) widens the band and raises the efficiency but launches more surface wave. On 1.6 mm FR-4 (εr ≈ 4.4) a 2.4 GHz patch has a band of only about 1 to 3 % and a gain of about 5 to 7 dBi.

Transmission-line model: design equations

The model treats the patch as a short length of wide microstrip line, open at both ends. The fringing makes each end look longer by ΔL, so resonance needs L + 2ΔL = λg/2, where λg = λ0/√εeff. Design in this order:

W = (c/2f) √(2/(εr + 1))

W is the width in m for good radiation efficiency; c = 3 × 10⁸ m/s; f is the design frequency in Hz. This step uses εr, not εeff.

εeff = (εr + 1)/2 + (εr − 1)/(2√(1 + 12h/W))

εeff is the effective permittivity, between 1 and εr because part of the field is in air.

ΔL = 0.412h (εeff + 0.3)(W/h + 0.264) / [(εeff − 0.258)(W/h + 0.8)]

ΔL is the extra length added by the fringing field at one open end, in m (Hammerstad’s formula).

L = c/(2f√εeff) − 2ΔL

L is the physical patch length in m.

The input resistance is highest at a radiating edge (a few hundred ohms on a thin board) and falls toward zero at the centre. A simple estimate takes one radiating slot of conductance G1 ≈ W/(120λ0) for W < λ0, so the edge resistance is Redge ≈ 1/(2G1); coupling between the two slots lowers the true value somewhat. A feed point moved in by y0 sees R(y0) = Redge cos²(πy0/L).

Feeds, bandwidth and arrays

An inset microstrip feed cuts a notch so the line meets the patch at the 50 Ω point; it is printed with the patch but its line radiates a little. A coaxial probe comes up through the ground to the 50 Ω point; on a thick board the long probe adds series inductance that detunes the match, so thick designs add a capacitive gap or an L-shaped probe. An aperture-coupled feed couples through a slot in the ground from a line on a second board, which keeps feed radiation away from the patch.

Feeding the patch at two points on adjacent sides with equal amplitude and 90° phase difference, or trimming two opposite corners, makes it circularly polarized, which is how GPS patches are built. Patches are combined into arrays exactly as in uniform linear arrays, usually spaced about λ0/2 and fed by a printed corporate network; tapered and steered versions follow phased arrays.

3.8 Antenna measurements: gain, pattern, polarization

An antenna is qualified by measuring three things: its gain, its pattern (where the beam points, how wide it is, how high the sidelobes are) and its polarization. All three need the test antenna to sit in the far field of a source antenna, on a range that keeps reflections out of the measurement. Gain is found by comparing the test antenna with a standard horn of known gain, the pattern by turning the test antenna and recording the received power, and the polarization by turning a linear probe or by using two crossed probes.

You need: gain, directivity, the radiation pattern and polarization from the antenna fundamentals topic, and the standard gain horn from aperture and horn antennas.

The far-field condition and the test range

Near an antenna the wavefront arriving from a source is curved, so the test aperture is not lit in phase, the nulls fill in and the gain reads low. The usual rule keeps the extra path at the aperture edge below λ/16:

R ≥ 2D²/λ

R is the distance between the phase centres of the two antennas in m; D is the largest dimension of the test antenna in m (when the source antenna is also large, use the larger of the two, or check both); λ is the wavelength in m. R must also be many times D and λ.

A 0.3 m horn at 10 GHz needs only 6 m; a 3 m dish at 6 GHz needs 360 m, which is why big antennas are measured outdoors or by other means. Outdoor ranges raise both antennas on towers so that the ground reflection is weak. Anechoic chambers line a room with pyramidal absorber so that walls reflect almost nothing and the weather stays out. A compact range uses a large reflector to make a plane wave inside a small room, and a near-field scanner moves a probe close to the antenna and computes the far field by a transform.

Reflections that reach the receiver add to or cancel the direct wave and ripple the measured pattern. Keep the path clear, use absorber, and where the receiver allows it, time-gate the direct pulse. Every cable, attenuator and connector between the antenna and the instrument must be the same in both halves of a comparison, or measured and subtracted, on the transmit side as well as the receive side.

Gain measurement

Gain by substitution (gain transfer): a fixed source antenna transmits. The receiver records Pstd with a standard gain horn of known gain Gstd at the test point, then Ptest with the test antenna in the same place, same polarization and same cable. With powers in dBm and gains in dBi:

Gtest = Gstd + (Ptest − Pstd)

Gtest and Gstd in dBi; Ptest and Pstd in dBm. More received power means more gain.

Two-antenna method: with two identical antennas R apart, the Friis equation gives each gain directly: 2G = Pr − Pt + 20 log(4πR/λ), all in dB. Three-antenna method: with three different antennas measured in pairs, the three pair sums G1 + G2, G1 + G3 and G2 + G3 are three equations for three unknowns, so no standard is needed. Both need an accurate R and the far-field condition.

Pattern and polarization

For a pattern cut, the test antenna (usually receiving, by reciprocity the same pattern as transmitting) turns on a positioner about its phase centre while the receiver records power against angle. The E-plane cut contains the electric field and the beam axis; the H-plane cut contains the magnetic field and the beam axis. Normalize to the peak, plot in dB and read the HPBW, the first nulls and the sidelobe level. Repeating with the source turned 90° gives the cross-polar pattern.

For polarization, a linear probe is spun about the line joining the antennas. A linearly polarized test antenna gives a deep minimum when the probe is crossed; a circular one gives a constant reading; an elliptical one swings between Emax and Emin. Two crossed probes measure the two components and their phase: equal amplitudes 90° apart give circular polarization, and which component leads fixes the sense, right-hand or left-hand. Checking against a known right-hand and left-hand circular horn confirms it.

AR = Emax/Emin, ARdB = 20 log AR

AR is the axial ratio: 1 (0 dB) for circular, infinite for linear. A received-power swing of 6 dB as the probe turns means AR = 2.

A linear antenna turned ψ away from a linear source receives only cos²ψ of the matched power, the polarization loss factor: 30° costs 1.25 dB, 45° costs 3 dB and 90° in principle everything.

Question. A 10 GHz test antenna has a largest dimension of 0.3 m.   4. With the extra adaptor, the −25 dBm reading is 0.4 dB lower than the antenna delivered, so the true gain is 20 + 0.4 = 20.4 dBi; ignoring it would under-read by 0.4 dB.

Answer. R ≥ 6 m and Gtest = 20 dBi; with the uncorrected 0.4 dB adaptor the true gain is 20.4 dBi.

Worked example 2

  • Swapping the E-plane and H-plane cuts. The E-plane contains the electric field vector of the antenna’s main polarization.
  • Giving linear polarization an axial ratio of 0 dB. Circular is 0 dB (AR = 1); linear is infinite.

3.9 Ground, sky and space wave propagation; ionosphere

Propagation is the route a radio wave takes from the transmitting antenna to the receiving one. Below about 3 MHz a ground wave hugs the earth; from 3 to 30 MHz a sky wave goes up, is bent back by the ionosphere and lands hundreds or thousands of kilometres away; above 30 MHz a space wave travels in a near-straight line and needs line of sight. The frequency, the distance and the time of day decide which route works, which is why an AM station carries farther at night and an HF operator changes frequency at dusk.

You need: frequency bands and polarization from the antenna fundamentals topic.

Ground, sky and space waves

Ground wave (surface wave): at LF and MF, roughly 30 kHz to 3 MHz, the wave travels along the surface, held by the conducting earth. It needs vertical polarization, because the earth shorts out a horizontal electric field. Its loss rises with frequency and over poor ground: it goes farthest over sea water and least over dry sand. AM medium-wave broadcasting and maritime radio use it.

Sky wave: at HF, roughly 3 to 30 MHz, the ionosphere refracts the wave back to earth, and one or more hops cover thousands of kilometres. It depends on the sun, the season and the time of day. Shortwave broadcasting, amateur radio and long-distance aviation HF use it.

Space wave: above about 30 MHz the ionosphere lets the wave through, so links rely on a direct ray (with a ground-reflected ray beside it) between antennas that can see each other. FM, TV, mobile networks, Wi-Fi, microwave hops and satellite links use it.

The ionosphere and sky waves

Solar ultraviolet and X-rays free electrons from the gas between about 60 and 400 km up. The refractive index of this plasma is n = √(1 − 81N/f²), with N in electrons per m³ and f in Hz, so n falls as N rises. A wave climbing into denser plasma bends away from the vertical and, if N is large enough, turns back down.

  • D layer, 60 to 90 km: daytime only; it does not return HF but absorbs MF and low HF, which is why medium-wave sky waves vanish by day.
  • E layer, 90 to 150 km: daytime refraction for MF and low HF, and occasional sporadic E.
  • F1, 150 to 250 km, and F2, 250 to 400 km: by day two layers, at night one F layer; F2 has the highest density and carries most long-distance HF.

fc = 9√Nmax

fc is the critical frequency in Hz, the highest frequency a layer returns at vertical incidence; Nmax is the layer’s peak electron density per m³.

MUF = fc sec φ = fc/cos φ

MUF is the maximum usable frequency of an oblique path; φ is the angle of the ray from the vertical where it meets the layer. This is the secant law.

For a flat-earth layer at virtual height h and a ground distance D between the stations, cos φ = h/√(h² + D²/4), so MUF = fc√(1 + (D/2h)²). Working the other way, a frequency f above fc cannot come down closer than the skip distance Dskip = 2h√((f/fc)² − 1). Between the end of the ground-wave range and the skip distance lies the skip zone, where neither wave is heard. Links are usually run at the optimum working frequency, about 0.85 × MUF, to leave room for changes in the layer. Fading comes from several rays arriving with changing path lengths, and from changes in the layer’s height and density.

Space waves and the radio horizon

The geometric horizon of an antenna h metres high is √(2Reh), with Re = 6371 km, which is 3.57√h km. Air density falls with height, so the refractive index falls too and the ray bends slightly downward, following the earth farther. The standard allowance replaces Re by 4/3 of itself, which gives the radio horizon:

d ≈ 4.12(√ht + √hr) km

d is the maximum line-of-sight range in km over a smooth earth with standard refraction; ht and hr are the transmit and receive antenna heights in metres.

Beyond the horizon, two effects can still carry a VHF to SHF signal: tropospheric scatter from irregularities in the lower atmosphere, weak but steady, and ducting, when a temperature inversion or a sharp moisture change, common over the sea, traps the wave in a layer and carries it far beyond the normal range, sometimes causing interference between distant stations.

  • Expecting a skip zone at frequencies below fc. Below fc even a vertical ray returns, so there is no skip zone.

Not for the exam. HF users plan frequencies with ionospheric models fed by ionosondes, which sweep a signal upward and time the echoes to find fc and h. Takeaways

  1. An array pattern is the element pattern times an array factor that depends only on spacing, phase step and number of elements.
  2. For two elements |AF| = 2|cos(ψ/2)| with ψ = βd cosθ + α; beams sit at ψ = 0 and nulls at ψ = ±π inside the visible range.
  3. Broadside needs α = 0 and d < λ; end-fire needs α = −βd and d < λ/2. End-fire is wider in angle but twice as directive for the same length.
  4. Tapers trade beamwidth for sidelobes: for five elements, uniform −12 dB at 20.8°, Chebyshev −20 dB at 23.7°, binomial none at 30.3°.
  5. A phase step α = −βd cosθ₀ steers the beam; fixed phase shifters make it squint with frequency.
  6. A Yagi gets its phases from rod lengths and spacings and is narrowband; an LPDA scales its geometry by τ and stays wideband as its active region slides.
  7. Horns and dishes are apertures: G = 4πAe/λ²; a dish gives η(πD/λ)², 39.8 dBi and 1.75° for 3 m at 4 GHz.
  8. A patch is about half a guided wavelength long, radiates from two in-phase edges and needs an inset or probe to reach 50 Ω.
  9. Measure in the far field (R ≥ 2D²/λ): gain by substitution or the two- and three-antenna methods, pattern by rotation, polarization by a spinning probe.
  10. Ground waves serve LF and MF, sky waves HF (fc = 9√N, MUF = fc sec φ), and space waves VHF and above up to the radio horizon.

Understand Describe the construction and working of the Yagi-Uda antenna and the log-periodic dipole array. Define the active region, explain why the LPDA is wideband, and give the design relations with an example. 10 marks

Points to cover. Yagi: driven element, reflector, directors, typical lengths and spacings; Why the beam goes toward the directors; narrow band; LPDA: τ, σ, apex angle, crossed feed, active region; N = 1 + ln B/ln(1/τ), L₁ = λmax/2; Worked numbers and comparison.

Model answer.

  1. Yagi-Uda construction. A boom carries one driven half-wave (often folded) dipole of 0.46λ to 0.48λ, one reflector of 0.50λ to 0.55λ placed 0.15λ to 0.25λ behind it, and directors of 0.40λ to 0.45λ, 0.15λ to 0.35λ apart, in front. Only the driven element is connected to the feeder.
  2. How it works. The driven element’s field induces currents in the parasitic rods. A rod longer than resonance is inductive, a shorter rod capacitive, so length sets the phase of the induced current; spacing adds a path phase. The reflector then acts like the rear element of a cardioid pair and cancels radiation toward the back, while the directors stay in step with the forward-moving wave: the Yagi is an end-fire array firing toward the directors.
  3. Yagi numbers. At 500 MHz (λ = 600 mm): reflector 300 mm, driven element 282 mm, director 270 mm, spacings 150 mm and 120 mm, gain about 7 dBi. Gain rises with more directors (9 to 11 dBi for five elements), but the phases are right only near the design frequency, so the band is 2 to 5 %.
  4. LPDA construction. Dipoles shrink by the scale factor τ = Ln+1/Ln from back to front; the spacing factor is σ = dn/(2Ln); the dipole tips lie on lines from an apex at half angle α = tan⁻¹[(1 − τ)/(4σ)]. All dipoles hang on a two-wire line with crossed connections, fed at the short end.
  5. Active region. At any frequency only the dipoles near λ/2 carry large current; these few form the active region. Longer dipoles behind it are inductive and weak, shorter ones in front are too small. Model answer.

  1. Aperture radiation. A horn is a flared waveguide. The TE10 field grows with the flare to fill a large opening, and this aperture field radiates. Its gain follows G = 4πAe/λ², with Ae = ηapA; the flare also lowers the reflection that an open waveguide end would cause.
  2. Types. E-plane sectoral (narrow walls flared), H-plane sectoral (broad walls flared), pyramidal (both, the usual gain standard), conical (circular guide) and corrugated (ringed walls, symmetric pattern, low cross-polarization).

Model answer.

Model answer.

  1. Far field. The source wave must be nearly plane over the test aperture. Limiting the extra path at the aperture edge to λ/16 gives R ≥ 2D²/λ, with R between phase centres and D the largest dimension. Here λ = 0.03 m and R ≥ 2 × 0.09/0.03 = 6 m.
  2. Range. Use an anechoic chamber or an elevated outdoor range; keep reflections out (absorber, clear path, time gating) and keep cables and connectors identical between readings, on both transmit and receive sides.

Points to cover. Flat-earth MUF = fc√(1 + (D/2h)²); Day and night values, OWF = 0.85 MUF; Skip distance at the OWF; D-layer absorption and night fall of fc; Line-of-sight range for comparison.

Model answer.

  1. Method. For stations D apart and a layer at h, the ray meets the layer at φ with tanφ = (D/2)/h, so sec φ = √(1 + (D/2h)²) and MUF = fc sec φ. The optimum working frequency is taken as 0.85 × MUF.
  2. Day. D/2h = 1500/600 = 2.5; sec φ = √7.25 = 2.693 (φ = 68.2°). MUF = 10 × 2.693 = 26.9 MHz; OWF = 22.9 MHz.
  3. Night. D/2h = 1500/700 = 2.143; sec φ = √5.592 = 2.365 (φ = 65.0°). MUF = 4 × 2.365 = 9.46 MHz; OWF = 8.0 MHz.
  4. Skip check. Dskip = 2h√((f/fc)² − 1). Day at 22.9 MHz: 600 × √(2.289² − 1) = 600 × 2.059 = 1235 km. Night at 8.0 MHz: 700 × √(2.010² − 1) = 700 × 1.744 = 1221 km. Both are under 1500 km, so the receiver lies beyond the skip zone.

    fchsec φMUFOWFDskip at OWF
    Day10 MHz300 km2.69326.9 MHz22.9 MHz1235 km
    Night4 MHz350 km2.3659.46 MHz8.0 MHz1221 km

Glossary

Active region
The few log-periodic dipoles near half a wavelength long that carry most of the current at a given frequency.
Aperture efficiency
The ratio of effective aperture to physical aperture area; it counts amplitude taper, phase error, spillover and blockage.
Array factor
The pattern of an array of isotropic elements; multiplied by the element pattern it gives the array pattern.
Axial ratio
The ratio of the largest to the smallest field in one turn of the polarization ellipse; 1 (0 dB) for circular.
Beam squint
The movement of a phased-array beam with frequency when the steering uses fixed phase shifts.
Binomial array
An array whose currents follow Pascal’s triangle; it has no sidelobes when d ≤ λ/2.
Booker relation
ZslotZdipole = η₀²/4, linking a slot’s impedance to that of its complementary dipole.
Broadside array
An array whose beam is perpendicular to its axis, obtained with equal phases.
Cassegrain feed
A reflector feed that uses a hyperbolic subreflector inside the focus to place the feed behind the dish.
Critical frequency
The highest frequency an ionospheric layer returns at vertical incidence, fc = 9√Nmax.
Dolph-Chebyshev array
An array whose currents make every sidelobe equal to a chosen level and the beam as narrow as possible for it.
End-fire array
An array whose beam lies along its axis, obtained with a phase step α = −βd.
Far-field distance
The distance 2D²/λ beyond which the measured pattern no longer depends on distance.
Grating lobe
A second full-size beam that appears when the element spacing is too large for the scan angle.
Hansen-Woodyard array
An end-fire array with an extra phase π/N per element, giving about 1.8 times the directivity.
Log-periodic dipole array
A wideband array of dipoles whose lengths and spacings scale by a fixed ratio τ.
Maximum usable frequency
The highest frequency that returns over a given oblique sky-wave path, fc sec φ.
Optimum horn
A horn whose flare gives the most gain for its length, with edge phase error 0.25λ (E-plane) and 0.375λ (H-plane).
Parasitic element
A Yagi rod not connected to the feed, driven by the field of the driven element.
Pattern multiplication
The rule that an array of identical, identically oriented elements has the element pattern times the array factor.
Phased array
An array whose beam is steered electronically by setting the phase of each element.
Radio horizon
The line-of-sight range with standard refraction, 4.12√h km for h in metres.
Skip distance
The shortest ground distance at which a sky wave of a given frequency returns.
Skip zone
The region between the end of the ground wave and the skip distance where no signal is received.
Spillover
Feed power that misses a reflector, wasting power and adding ground noise on receive.
Visible range
The values of ψ that real directions produce, from βd + α down to −βd + α.
