3.1 Two-element arrays and pattern multiplication

An array combines several antennas to shape its radiation. The two-element array is the smallest array. Its total pattern is the element's own pattern multiplied by an array factor. That factor depends only on spacing, wavelength and current phase. Designers use it to steer a beam or place a null without redesigning the antenna element, in Wi-Fi access points, radar and mobile base stations.

You need the radiation pattern, field and power patterns, and the half-wave dipole pattern from Unit 2.

The two-source model and array factor

Take two identical isotropic radiators. Isotropic means the element radiates equally in every direction. Place element 1 at the origin and element 2 on the +z side, separated by d metres; this line is the array axis. Feed element 1 with current I₁ and element 2 with I₂ = I₁ ejα. Here α is the current phase difference of element 2 relative to element 1, in radians. At a far-field point in direction θ measured from the array axis, the wave from element 1 travels d cosθ farther than the wave from element 2. This shorter path advances the phase of element 2 by βd cosθ, where β = 2π/λ is the phase constant and λ is the free-space wavelength. The total phase difference between the two waves is ψ = βd cosθ + α. Adding two equal phasors with phase difference ψ gives the array factor AF = 2 cos(ψ/2). AF is the field pattern of the array when the elements are isotropic. Its maximum magnitude is 2; the normalized array factor is |cos(ψ/2)|. The power pattern is |AF|² = 4 cos²(ψ/2), with maximum 4. Dividing by 4 gives the normalized power pattern cos²(ψ/2), which peaks at 1.

AF = 2 cos(ψ/2)
ψ = βd cosθ + α

AF is the array factor (field); ψ is total phase difference in radians; β = 2π/λ is the phase constant; d is element spacing in metres; θ is angle from the array axis; α is current phase difference in radians.

Pattern multiplication

Real elements are not isotropic. A dipole has its own element factor Ee(θ,φ). Pattern multiplication says the far-field pattern of identical elements is Etotal(θ,φ) = Ee(θ,φ) × AF(θ,φ). The array factor carries spacing and phase; the element factor carries the single antenna's shape. For power, Ptotal = Pe × |AF|². Take two half-wave dipoles with their axes along x, spaced a distance d apart along z, so the array axis z is not the dipole null direction. The dipole pattern supplies the null along the dipole axis (x), while AF adds array nulls. If the elements are not identical, or point different ways, simple multiplication is not exact. To use it: choose one angle reference, write ψ, compute AF = 2cos(ψ/2), multiply by the element field, square for power, and normalize. The product remains valid because the far field is linear: the total field is the sum of two scaled copies of the same element field. The standard name is pattern multiplication, also called the multiplication-of-patterns or pattern-multiplication theorem. The N-element version is in uniform linear arrays.

Maxima, nulls and beam position

Maxima of AF occur when cos(ψ/2) = ±1, that is ψ = 2mπ for integer m. Then |AF| = 2. Nulls occur when cos(ψ/2) = 0, that is ψ = (2m+1)π. At a null the two waves cancel. For d = λ/2 and α = 0, ψ = π cosθ. Nulls lie at θ = 0° and 180°; the maximum is at θ = 90°, broadside. For d = λ/2 and α = 90°, ψ = π cosθ + π/2. Maximum at ψ = 0 gives cosθ = −1/2, so θ = 120°. First null at ψ = π gives cosθ = 1/2, so θ = 60°. Increasing α moves the main beam toward larger θ for this spacing; progressive phase is how phased arrays steer. See phased arrays. If θ is measured from broadside instead, replace cosθ by sinθ throughout; do not mix references.

Worked example

Question. Two identical isotropic radiators are spaced d = λ/2 apart and fed with a 90° current phase difference. Find the angle of maximum radiation and the first null, with θ measured from the array axis.

  1. The phase constant is β = 2π/λ. With d = λ/2, the spacing phase is βd = (2π/λ)(λ/2) = π rad.
  2. The current phase difference is α = 90° = π/2 rad.
  3. The total phase difference is ψ = βd cosθ + α = π cosθ + π/2.
  4. Maximum radiation occurs when ψ = 0, because then AF = 2 cos(0) = 2. Solve π cosθ + π/2 = 0.
  5. Divide by π: cosθ + 1/2 = 0, so cosθ = −1/2. The angle in 0° to 180° is θ = 120°.
  6. The first null occurs when ψ = π, because then AF = 2 cos(π/2) = 0. Solve π cosθ + π/2 = π.
  7. This gives π cosθ = π/2, so cosθ = 1/2. The angle is θ = 60°.

Answer. Maximum radiation is at θ = 120°; the first null is at θ = 60°.

Exam traps

  • Do not add the powers of the two elements. Add or multiply the fields, then square for power.
  • Keep θ measured from one fixed reference. From the array axis the phase term is βd cosθ; from broadside it is βd sinθ. Mixing them gives the wrong angle.
  • AF = 2 cos(ψ/2) can be negative. The normalized field pattern uses |cos(ψ/2)|, and power uses cos²(ψ/2).
  • A maximum is at ψ = 0, 2π, …; a null is at ψ = π, 3π, …. Do not set ψ = 0 for a null.
  • For d = λ/2, βd = π, not π/2. Convert α to radians before putting it into ψ.

3.2 Uniform linear arrays: broadside and end-fire

A uniform linear array (ULA) is N identical antennas placed in a straight line with equal spacing d and equal current amplitude. It gives a narrow, high-gain beam from small elements. With zero progressive phase the beam points broadside, at 90° to the array axis. With a phase step of −βd it points end-fire, along the axis. Cell-tower panels, radar faces and Wi-Fi routers use this idea to concentrate power without making each antenna large.

You need: the two-element array factor and pattern multiplication from chapter 3.1, and beamwidth and directivity from Unit 2, Antenna Fundamentals and Radiation.

Array factor for N elements

For N elements spaced d metres apart, the normalized array factor is the pattern of the array alone, with one element treated as a point source.

AF = |sin(Nψ/2) / [N sin(ψ/2)]|

N is the number of elements. ψ = βd cosθ + α is the total phase difference between neighbouring elements, in radians. β = 2π/λ rad/m. λ is the free-space wavelength in metres. d is the element spacing in metres. θ is the angle measured from the array axis, from 0° to 180°. α is the progressive phase shift in radians between adjacent elements. AF is the magnitude of the normalized array factor, scaled so its maximum is 1.

The main lobe occurs when ψ = 0. Nulls occur when Nψ/2 = ±mπ, with m = 1, 2, … and m not a multiple of N. Since θ runs from 0° to 180°, the visible range of ψ is βd + α down to −βd + α. The full antenna pattern is AF multiplied by the single-element pattern.

Broadside array

Set α = 0, so every element is fed in phase. Then ψ = βd cosθ. The main lobe needs ψ = 0, so cosθ = 0 and θ = 90°. The beam is perpendicular to the line of the array. The array axis is not the beam direction here; the beam is at right angles to it.

For d = λ/2, βd = π. Nulls satisfy π cosθ = ±2πm/N. For N = 4, m = 1 gives cosθ = ±1/2, so the first nulls are at θ = 60° and 120°. The first-null beamwidth is 120° − 60° = 60°. A broadside array is used when the array face points at the coverage area, as in a sector panel on a rooftop. If α is nonzero the maximum moves, so use α = 0 only when the question says broadside.

End-fire array

Set α = −βd. Then ψ = βd(cosθ − 1). At θ = 0°, cosθ = 1 and ψ = 0, so the maximum lies along the axis. Reversing the sign to α = +βd puts the maximum at θ = 180° instead.

For d = λ/2 and N = 4, nulls need 1 − cosθ = 2m/N = m/2. For m = 1, cosθ = 1/2, giving θ = 60°. There is no matching null on the other side because the visible range is limited. With d = λ/2 there is also a grating lobe at θ = 180° because ψ = −2π, so for end-fire d must be less than λ/2 to avoid grating lobes. End-fire arrays are long and thin and give a beam along the line of elements, useful on a mast or a vehicle. The enhanced end-fire case adds a small extra phase, α = −βd − π/N, and is called Hansen-Woodyard in some syllabi. It raises directivity a little but narrows the bandwidth.

Beamwidth, grating lobes and gain

For a broadside array the first null occurs at cosθ = λ/(Nd), so the first-null beamwidth is FNBW = 2 arcsin(λ/(Nd)). The half-power beamwidth is about 0.886 λ/(Nd) radians. Directivity is about 2Nd/λ for isotropic elements, so gain rises with both N and d.

For a broadside array, spacing of one wavelength or more creates grating lobes. These are extra directions where ψ = ±2πk also satisfies the main-lobe condition. They waste power and cause angle ambiguity in radar. For an end-fire array, grating lobes appear when d ≥ λ/2, so d must be kept below λ/2 to avoid them. A broadside design keeps d close to λ/2; an end-fire design must use a smaller spacing for the same reason.

Worked example

Question. A 4-element uniform linear array has equal in-phase currents and element spacing d = λ/2. Find (a) the main-beam direction, (b) the first nulls, and (c) the first-null beamwidth.

  1. Spacing d = λ/2, so βd = (2π/λ)(λ/2) = π rad.
  2. The currents are in phase, so α = 0. This is a broadside array.
  3. The main lobe needs ψ = 0. With ψ = π cosθ, cosθ = 0, so θ = 90°.
  4. Nulls need Nψ/2 = ±π. With N = 4, ψ = ±π/2.
  5. Then π cosθ = ±π/2, so cosθ = ±1/2. The first nulls are θ = 60° and θ = 120°.
  6. First-null beamwidth = 120° − 60° = 60°.

Answer. The main beam is at θ = 90°, the first nulls are at 60° and 120°, and the first-null beamwidth is 60°.

Exam traps

  • Using α = 0 for broadside but α = −βd for ordinary end-fire; the sign of α decides whether the end-fire beam points to 0° or 180°.
  • Measuring θ from broadside instead of from the array axis. Broadside is θ = 90°, not θ = 0°.
  • Forgetting that ψ contains α. A zero in cosθ alone is not the main-beam condition.
  • For broadside, d ≥ λ creates grating lobes and d = λ/2 is safe. For end-fire, d ≥ λ/2 creates grating lobes, so keep d < λ/2 for end-fire.
  • Confusing first-null beamwidth with half-power beamwidth. Nulls use Nψ/2 = ±mπ; half power uses a different level.

3.3 Binomial, Chebyshev and phased arrays

An array shapes its pattern by changing element amplitudes or phases. Amplitude tapering trades main-beam width against sidelobes: binomial coefficients remove sidelobes, Chebyshev coefficients give the narrowest beam for a stated sidelobe level. A constant phase step steers the beam without moving the array. Radar, satellite links and 5G base stations use these trades.

You need: the array factor and broadside/end-fire phasing from Chapter 3.2.

Amplitude tapering: binomial and Chebyshev

Take N equally spaced elements on a line, spacing d metres, real amplitudes an and progressive phase α radians per element. Measure θ from broadside. The array factor sums element contributions. The element pattern multiplies it; see Chapter 3.1.

AF(θ) = Σ<sub>n=0</sub><sup>N−1</sup> a<sub>n</sub> e<sup>j n ψ</sup>,  ψ = βd sinθ + α

AF(θ) is the array factor at angle θ; N is the number of elements; an is the amplitude of element n; ψ is the total electrical phase step between adjacent elements; β = 2π/λ is the phase constant in rad/m; d is the element spacing in m; θ is measured from broadside; α is the progressive phase shift in rad.

A uniform array sets an = 1. Its first sidelobe is about −13 dB. Tapering makes edge elements smaller than centre elements; the main beam widens and sidelobes fall. Binomial taper uses Pascal-triangle coefficients: 1; 1 1; 1 2 1; 1 3 3 1.

an = C(N−1, n), n = 0, 1, ..., N−1

C(N−1,n) is the binomial coefficient, read as (N−1) choose n. For N = 4 the amplitudes are 1, 3, 3, 1.

With d = λ/2 and α = 0, the binomial array factor is proportional to |cos(ψ/2)|N−1, ψ = βd sinθ. In −π ≤ ψ ≤ π it peaks once at ψ = 0, so no sidelobes. The cost is a wide main beam and low aperture efficiency. For d > λ/2 the visible range grows and this property fails.

Chebyshev (Dolph-Chebyshev) sets all sidelobes to one chosen level. For voltage ratio R, the design parameter is x0. Coefficients come from a Chebyshev polynomial mapped into visible space. For given N and sidelobe level, this gives minimum main-beam width. Coefficients need tables or a computer.

x<sub>0</sub> = cosh( (1/(N−1)) cosh<sup>−1</sup> R ),  SLL<sub>dB</sub> = −20 log<sub>10</sub> R

R is main-lobe to sidelobe voltage ratio, R > 1; x0 is the Chebyshev design parameter; SLLdB is sidelobe level relative to the main lobe in dB, negative. A −20 dB sidelobe means R = 10.

Phased array: steering with a phase step

Keep amplitudes fixed and change only α. The main beam sits where ψ = 0, because every element then adds in phase. Rearranging ψ = βd sinθ + α = 0 gives the steering law. A negative α steers to positive θ, and a positive α steers to negative θ.

sinθ<sub>0</sub> = −α/(βd),  α = −βd sinθ<sub>0</sub>

θ0 is the main-beam angle from broadside in rad; α is the progressive phase shift in rad; β = 2π/λ in rad/m; d is the spacing in m. For d = λ/2, βd = π, so α = −π sinθ0.

A phased array uses one phase shifter per element after a power divider. The beam can jump to a new angle in microseconds because nothing mechanical moves. Phase-shifter circuits are covered in Unit 4, Microwave Components, Devices and Measurements. The same array can also use an amplitude taper, so steering and sidelobe control are separate adjustments.

Large element spacing creates grating lobes: extra directions where ψ = ±2πm also gives a maximum. For a beam steered to θ0, the first grating lobe stays outside visible space when d/λ is small enough. The usual choice d = λ/2 avoids grating lobes for every scan angle of a linear array.

d/λ ≤ 1/(1 + |sinθ0|)

d is the element spacing in m; λ is the free-space wavelength in m; θ0 is the scan angle from broadside. At broadside this allows d ≤ λ; at endfire it allows d ≤ λ/2.

Fixed phase shifters make the beam angle depend on frequency. This is beam squint. At design frequency f0, α is set for θ0. At another frequency f, β changes but α stays fixed, so the beam moves. A higher frequency makes |sinθ0| smaller, so the beam moves toward broadside. Wideband systems use true-time-delay units or digital beamforming to reduce squint.

sinθ0(f) = −α c/(2π f d)

f is frequency in Hz; c is the speed of light in m/s; α is the fixed progressive phase in rad; d is spacing in m; θ0(f) is the beam angle at frequency f.

Choosing a taper and a steering method

Use the taper to meet a sidelobe specification and the phase to meet a scan requirement. A binomial array suits a short array that must avoid sidelobes, such as a simple low-interference link. A Chebyshev array suits radar or point-to-point links where a strong jammer or nearby transmitter must be rejected while keeping a narrow beam. A phased array suits any system that must scan quickly: radar, satellite user terminals and 5G base stations.

Worked example

Question. A 4-element linear phased array has element spacing d = λ/2 and equal amplitudes. It must steer its main beam to θ₀ = 30° from broadside. Find the progressive phase shift α between adjacent elements and list the phase of each element.

  1. Identify the data: N = 4, d = λ/2, θ₀ = 30°, equal amplitudes.
  2. Compute βd. β = 2π/λ, so βd = (2π/λ)(λ/2) = π rad.
  3. Use the steering law sinθ₀ = −α/(βd). Rearrange: α = −βd sinθ₀.
  4. Substitute: α = −π sin 30° = −π × 0.5 = −π/2 rad.
  5. Convert to degrees: α = −90°.
  6. Element n has phase nα for n = 0, 1, 2, 3. The phases are 0°, −90°, −180° and −270°.

Answer. The progressive phase shift is α = −π/2 rad = −90° per element, and the element phases are 0°, −90°, −180° and −270°.

Exam traps

  • Chebyshev does not remove sidelobes; it sets them all to a chosen level, such as −20 dB. Binomial removes sidelobes, only for d ≤ λ/2.
  • With θ from broadside, use α = −βd sinθ₀. Using cosθ₀ steers wrongly. If θ is from the array axis, sine and cosine swap.
  • A binomial array with d > λ/2 gains extra lobes because the visible ψ range extends past ±π.
  • Sidelobe dB has a sign. A −20 dB sidelobe gives voltage ratio R = 10, not 0.01. Use R = 10−SLLdB/20.
  • Grating lobes are extra main beams from large spacing, not sidelobes. Check d/λ ≤ 1/(1 + |sinθ₀|) before blaming the taper.

3.4 Yagi-Uda and log-periodic antennas

A Yagi-Uda antenna gets a directional beam from one driven dipole and a row of passive rods that are not connected to the feed. It is cheap and compact, gives about 7–15 dBi, but only over a narrow band. A log-periodic dipole array takes the opposite trade: many dipoles of different lengths, each handling a small slice of frequency, so one antenna covers a wide band. Yagis sit on rooftops for TV and inside RFID readers; log-periodic arrays serve EMC measurement, HF radio and TV reception.

You need: Chapter 3.1 for pattern multiplication, Chapter 3.2 for end-fire arrays, and the half-wave and folded dipole from Unit 2.

The Yagi-Uda antenna

Shintaro Uda built this array in 1920s Japan and Hidetsugu Yagi published it, so both names stick; the short form Yagi is common. One element is driven: a half-wave dipole, often a folded dipole, because its input impedance near 300 Ω suits a twin-line feeder (Unit 2). Every other rod is parasitic: mounted on the boom, insulated from it, and not wired to the feed.

  • Driven element: 0.47λ to 0.48λ long, where λ is the free-space wavelength at the design frequency.
  • Reflector: placed behind the driven element, 0.50λ to 0.55λ long, spaced 0.15λ to 0.25λ away.
  • Directors: placed in front, 0.40λ to 0.45λ long, each slightly shorter than the previous one, spaced about 0.2λ to 0.4λ apart.
  • Gain: about 7 dBi with one reflector and one director, 9–11 dBi for five elements, up to about 15 dBi for very long arrays.
  • Bandwidth: only 2–5% of the design frequency.

Feeding is simple: one cable, no power dividers, no phase shifters. That is why a Yagi costs a few hundred rupees and hangs on every Indian rooftop for Doordarshan and cable TV reception.

Why the beam points at the directors

Parasitic does not mean inactive. The field of the driven element induces a current in every rod, and each rod re-radiates. The total pattern is the element pattern multiplied by an array factor set by those induced currents (Chapter 3.1). Element length and spacing fix the phase of each current.

The reflector is longer than resonance, so its current lags. Placed about 0.2λ behind, its re-radiated field cancels the driven element's field to the rear and adds to it in front. Directors are shorter than resonance, so their currents lead, and the spacing is chosen so that their fields add toward the front. The result is an end-fire array (Chapter 3.2), firing along the boom away from the reflector.

Because the phases come from geometry, not from a feed network, a Yagi can not be retuned after it is built. Adding directors raises gain with diminishing returns, and each added director narrows the band further.

The log-periodic dipole array

A log-periodic antenna repeats its shape at scaled sizes, so its properties stay roughly constant over frequency. In the dipole version, the LPDA, parallel dipoles get steadily shorter from back to front and the spacings shrink with them.

τ = L(n+1) / L(n)

τ is the scaling factor, dimensionless, typically 0.7 to 0.95; L(n) is the length of the n-th dipole counting from the longest at the rear.

σ = d(n) / (2 L(n))

σ is the spacing factor, dimensionless, typically 0.06 to 0.2; d(n) is the gap between dipole n and dipole n+1; L(n) is the length of dipole n.

All dipoles are fed from a two-wire line along the boom, with the connections crossed between neighbours so adjacent dipoles are driven in antiphase. Only the dipoles near resonance, with L close to λ/2, carry large current: this is the active region. At the lowest frequency the longest rear dipole is active; as frequency rises the active region moves toward the short front end. The longest dipole works at the lowest frequency, never the reverse.

N = 1 + ln(B) / ln(1/τ), where B = fmax / fmin

N is the number of elements, rounded up to a whole number; B is the bandwidth ratio, dimensionless; fmax and fmin are the band edges in Hz; τ is the scaling factor.

A printed variant, the log-periodic tooth antenna, uses triangular teeth on a microstrip line and is common in TV and EMC work.

Design steps and comparison

  1. Fix the band and compute B = fmax / fmin.
  2. Pick τ (0.8 to 0.9 is a common compromise between size and gain).
  3. Compute N = 1 + ln(B)/ln(1/τ) and round up.
  4. Set the longest dipole to about half a wavelength at fmin: L(1) = 150 / fmin, with fmin in MHz and L(1) in metres.
  5. Find the shortest dipole from L(N) = L(1) τ^(N−1).
  6. Choose σ (near 0.15 for moderate gain) and lay out the boom.

Question. A log-periodic dipole array must cover 200 MHz to 600 MHz. Use τ = 0.9 and a longest dipole of 750 mm. Find the bandwidth ratio, the number of elements and the length of the shortest dipole.

  1. Bandwidth ratio: B = fmax / fmin = 600 MHz / 200 MHz = 3, dimensionless.
  2. ln B = ln 3 = 1.0986. ln(1/τ) = ln(1/0.9) = 0.10536.
  3. N = 1 + 1.0986/0.10536 = 1 + 10.43 = 11.43, rounded up to 12 elements.
  4. Shortest dipole: L(12) = 750 mm × 0.9¹¹. Now 0.9¹¹ = 0.3138, so L(12) = 235.4 mm.
  5. Check the longest dipole: 750 mm is half a wavelength at 200 MHz, since λ = 300/200 = 1.5 m = 1500 mm and 1500/2 = 750 mm. The design is consistent.

Exam traps

  • In an LPDA the longest dipole works at the lowest frequency. The active region moves to the short front elements as frequency rises.
  • The reflector is not a mirror or a dish. It is a rod slightly longer than resonance that re-radiates with the right phase.
  • Do not swap τ and σ: τ compares adjacent dipole lengths, σ compares spacing with length.

3.5 Aperture and horn antennas; Babinet's principle

An aperture antenna radiates from an open surface rather than a thin wire. A horn is a waveguide whose open end is flared, so the guided wave spreads gradually into free space with little reflection. The useful measure is effective area, not physical area. Babinet's principle connects a slot cut in a screen to a metal dipole of the same shape: their patterns are related, and their impedances obey the Booker relation. Horns feed reflectors and test ranges; slots appear on aircraft and waveguide walls. This chapter explains all three.

You need: rectangular waveguide modes from Unit 1 and effective aperture and directivity from Unit 2; see Chapter 3.1 for array pattern ideas.

Aperture antennas and effective area

An aperture antenna is an opening that radiates. The field across the opening, called the aperture field, decides the far-field pattern. A large aperture compared with wavelength gives a narrow beam. A small aperture gives a wide beam.

Uniform illumination means the aperture field has the same amplitude everywhere. It gives the narrowest beam for a given size, but sidelobes are high. Tapered illumination reduces the field near the edges. Sidelobes fall, the main beam widens, and directivity drops. Practical horns use a mild taper.

Ae = ηap A

Ae is effective area in m²; A is physical aperture area in m²; ηap is aperture efficiency, from 0 to 1.

D = 4πAe / λ²

D is directivity (unitless); λ is free-space wavelength in m. Use Ae, not A, in this formula.

A uniform aperture has ηap close to 1 in theory. Real horns reach about 0.4 to 0.6 because of phase error and edge taper. Aperture efficiency is not radiation efficiency. It describes how well the aperture area is used, not conductor or dielectric loss.

Horn antennas: flaring the waveguide

A horn is a waveguide with a gradual flare. The flare changes the guided mode into a free-space beam. The gradual change avoids a sudden impedance step at the open end, so reflection stays small.

An E-plane horn flares in the plane of the electric field. An H-plane horn flares in the plane of the magnetic field. A pyramidal horn flares in both planes and is common in test ranges. A conical horn uses a circular waveguide. A corrugated horn has rings inside the flare; it gives a symmetric pattern and low cross-polarization.

Flare angle sets a trade-off. A small flare angle needs a long horn, but the phase across the aperture stays nearly constant. A large flare angle makes a short horn, but the phase varies across the aperture. That phase error widens the beam, lowers gain, and raises sidelobes. Gain follows D = 4πAe / λ², with Ae = ηap A.

Horns are used as reflector feeds (see Chapter 3.6), as gain standards, and as direct radiators in microwave links. A pyramidal horn is often the standard-gain antenna in a measurement lab (see Chapter 3.8).

Babinet's principle and slot antennas

Babinet's principle compares two complementary screens. Place a metal screen with a slot in a plane. Its complement is a metal strip of the same shape as the slot. For the two cases, the fields add to the field with no screen at all. This is the field form of Babinet's principle.

For a slot cut in an infinite conducting plane, the radiation pattern is the same as that of a dipole shaped like the slot. The electric and magnetic fields are interchanged. The slot is a magnetic dipole; the metal dipole is an electric dipole. The pattern is the same, but the impedance is not.

Z<sub>slot</sub> × Z<sub>dipole</sub> = η<sub>0</sub>² / 4

Zslot is slot impedance in Ω; Zdipole is the complementary dipole impedance in Ω; η0 = 120π Ω ≈ 377 Ω is the impedance of free space.

This is the Booker relation. A half-wave dipole has about 73 Ω resistance. The relation predicts a resonant slot near 35530 / 73 ≈ 487 Ω, so a slot is a high-impedance antenna. Feed it from a waveguide or a balanced line. Slot arrays are flush-mounted on aircraft and on waveguide walls.

Worked example

Question. A pyramidal horn has a rectangular aperture 10 cm × 8 cm at 10 GHz. Its aperture efficiency is 0.5. Find the physical area, effective area, wavelength, directivity as a ratio, and directivity in dBi.

  1. A = 10 cm × 8 cm = 80 cm² = 80 × 10⁻⁴ m² = 0.0080 m².
  2. Ae = ηapA = 0.5 × 80 cm² = 40 cm² = 0.0040 m².
  3. λ = c / f = (3 × 10⁸ m/s) / (10 × 10⁹ Hz) = 0.030 m = 3.0 cm.
  4. D = 4πAe / λ² = 4π(0.0040) / (0.030)² = 0.05027 / 0.0009 = 55.85.
  5. D(dBi) = 10 log10(55.85) = 17.47 dBi ≈ 17.5 dBi.

Answer. Effective area is 40 cm²; directivity is 55.85, or about 17.5 dBi.

Exam traps

  • Use effective area Ae in D = 4πAe/λ². Using physical area A overestimates directivity.
  • Babinet gives the slot pattern from the dipole, not the same impedance. Use the Booker relation for impedance.
  • Convert cm² to m² by multiplying by 10⁻⁴. A 40 cm² aperture is 0.0040 m², not 0.40 m².
  • A larger flare angle does not always raise gain. Phase error across the aperture can lower it.
  • Aperture efficiency is not radiation efficiency. It covers illumination and phase, not conductor or dielectric loss.

3.6 Parabolic reflector antennas

A parabolic reflector — a dish antenna — takes the spreading spherical wave from a small feed at its focus and reflects it as a plane wave. A flat wavefront across a large aperture gives high gain and a very narrow beam: a 3 m dish at 4 GHz gives about 40 dBi with a beam under 2° wide. Dishes carry satellite television, radar, deep-space links and microwave point-to-point hops. This chapter covers the geometry, the feed arrangements, the losses that set aperture efficiency, and the gain and beamwidth formulas.

You need: aperture antennas and effective area (Chapter 3.5), plus the gain and beamwidth definitions from Unit 2.

Why a dish turns a spherical wave into a plane wave

A horn or a dipole radiates over a wide angle because its mouth is small compared with a wavelength. A narrow beam needs a large aperture, metres wide. A waveguide that wide would support unwanted modes and would weigh far too much. A parabolic dish solves this: the guiding surface is opened out into space and is fed by a small source.

A parabola is the set of points equally distant from a fixed point, the focus, and a fixed line, the directrix. For a dish whose axis is z, the surface is z = r²/(4f). Here r is the radius measured from the axis in metres, f is the focal length in metres (focus to vertex), and z is the depth of the surface at that radius in metres.

A ray leaving the focus reflects off the dish parallel to the axis — that is the defining reflection property of a parabola. Every such ray travels the same total distance from focus to any plane perpendicular to the axis, so all rays arrive in phase. The spherical wavefront from the feed becomes a plane wave across the dish mouth. A large in-phase aperture means high gain and a narrow beam, exactly as an aperture antenna predicts (Chapter 3.5). By reciprocity the same dish works on receive.

  • D is the dish diameter; f/D, the focal length divided by the diameter, is usually between 0.25 and 0.5.
  • Small f/D is a deep, compact dish; the feed sees the rim at a wide angle.
  • Large f/D is a shallow dish with the feed far out; easier to build, longer structure.

Feeds, spillover, taper and aperture efficiency

Prime focus. A horn at the focus points back at the dish. Simple and cheap, but the feed and its struts sit in front of the aperture and block part of it — aperture blockage — which slightly lowers gain and raises sidelobes.

Cassegrain. A small hyperbolic subreflector near the focus throws the beam back through a hole at the vertex, so the feed and receiver sit behind the dish. The feed causes no blockage and is easy to service, but the subreflector still shadows the centre. Gregorian uses a concave ellipsoidal subreflector placed beyond the focus; the result is similar with a different magnification.

Spillover and taper. The feed radiates over a wide angle of its own. Power that misses the dish spills past the rim and becomes wide-angle sidelobes and ground noise. A feed that lights the centre strongly and the rim weakly — a tapered illumination — cuts spillover, but the outer part of the dish then does little work and the effective aperture shrinks. Good design balances the two.

Aperture efficiency η collects all these effects: spillover, taper, blockage, cross-polarisation, and surface error (a common rule is to keep the RMS surface deviation below about λ/16). Real dishes give η between 0.5 and 0.7, that is 50–70%.

Two practical notes. Moving the feed sideways off the focus tilts the phase front and scans the beam by a few beamwidths. A radome — a fabric or fibreglass cover — shields the dish from wind, rain and ice at the cost of a small loss.

Gain and beamwidth

G = η (πD/λ)²

G is the gain as a power ratio (dimensionless); η is the aperture efficiency, typically 0.5 to 0.7; D is the dish diameter in metres; λ is the free-space wavelength in metres.

G = 4πA<sub>e</sub> / λ²,  with  A<sub>e</sub> = η π D² / 4

Ae is the effective aperture area in square metres, the physical mouth area πD²/4 reduced by the efficiency η.

HPBW ≈ 70 λ / D  degrees  (same as 1.22 λ / D radians)

HPBW is the half-power beamwidth in degrees; λ and D must be in the same unit, for example both in metres.

The factor (πD/λ)² equals 4π times the mouth area measured in square wavelengths: (πD/λ)² = 4π × (πD²/4)/λ². Equivalently, gain = η × 4π × (physical aperture area in square wavelengths). Double the frequency and the same dish gains about 6 dB, until surface errors and the feed set a limit. Sidelobes of a well-tapered dish are typically −20 dB or lower. Dishes are used for satellite television, radar, radio telescopes and long microwave links.

Worked example

Question. A parabolic dish of diameter 3 m works at 4 GHz with an aperture efficiency of 0.6. Find the wavelength, D/λ, the gain as a ratio, the gain in dBi, and the half-power beamwidth.

  2. Electrical size: D/λ = 3 m / 0.075 m = 40.
  3. Aperture factor: πD/λ = π × 40 = 125.66.
  4. Square it: (πD/λ)² = 125.66² = 15,791.
  5. Gain ratio: G = η (πD/λ)² = 0.6 × 15,791 = 9475.
  6. Gain in dBi: G(dBi) = 10 log₁₀(9475) = 10 × 3.976 = 39.8 dBi.
  7. Beamwidth: HPBW ≈ 70 λ / D = 70 × 0.075 m / 3 m = 70 × 0.025 = 1.75°.

Exam traps

  • The feed goes at the focus, a distance f in front of the vertex, not on the dish surface itself (not on the metal at the vertex). Sketches with the feed on the metal lose marks.
  • Gain uses η inside the bracket's square: G = η(πD/λ)². Dropping η overstates gain by about 2.2 dB at η = 0.6, and using (D/λ)² instead of (πD/λ)² is wrong by a factor of π².

  • f/D is a shape ratio, not an efficiency. A deep dish with small f/D is not automatically higher gain.
  • Cassegrain and Gregorian are not lenses. The Cassegrain subreflector is hyperbolic and sits between focus and vertex; the Gregorian subreflector is ellipsoidal and sits beyond the focus.

3.7 Microstrip patch antennas

A microstrip patch antenna is a thin metal patch printed on a grounded dielectric sheet. The patch and ground form a resonant cavity; the electric field fringes at the patch edges and those fringing fields radiate. It is cheap, flat and easy to etch onto a circuit board, so it sits inside phones, Wi-Fi routers, GPS receivers and radar panels. Its price is narrow bandwidth and modest gain. This chapter shows why the patch resonates, how to size a rectangular patch, and how feeds and arrays make it useful.

You need: microstrip line behaviour from Unit 1 and antenna parameters from Unit 2; array ideas appear later in chapter 3.1.

The patch as a resonant radiator

A rectangular patch of length L and width W is etched on a substrate of thickness h and relative permittivity εr. A continuous copper ground plane sits under the substrate. The patch is a resonator, not a travelling-wave line: at resonance the voltage is maximum at the two edges separated by L and near zero at the centre. The field between patch and ground is mostly inside the dielectric, but some field spills past the edges.

This fringing field has a vertical component at the edges. The two edges perpendicular to L therefore act like narrow radiating slots. The other pair of edges radiates weakly and mostly in unwanted directions. A patch is low profile, light and can be made by PCB etching. It is used in Wi-Fi, Bluetooth, GPS, mobile handsets and phased-array radar. Substrate choice controls size and bandwidth: higher εr shrinks the patch; thicker, lower-εr foam gives more bandwidth but can launch surface waves.

Transmission-line model and design

Treat the patch as a microstrip transmission line of width W and length L, open-circuited at both ends. The open ends are not perfect magnetic walls: the field fringes by a length ΔL beyond each edge. The electrical length is therefore L + 2ΔL, and resonance occurs when this length is half a wavelength in the effective medium. The effective permittivity εeff accounts for fields in both dielectric and air. First pick W for good radiation and reasonable impedance.

W = c/(2f) × √(2/(εr+1))

W is patch width in metres; c = 3 × 10⁸ m/s; f is resonant frequency in Hz; εr is substrate relative permittivity.

ε<sub>eff</sub> = (ε<sub>r</sub>+1)/2 + ((ε<sub>r</sub>−1)/2) × [1 + 12h/W]<sup>−1/2</sup>

εeff is effective relative permittivity; h is substrate thickness in metres; W is patch width in metres.

ΔL/h = 0.412 × ((ε<sub>eff</sub>+0.3)(W/h+0.264)) / ((ε<sub>eff</sub>−0.258)(W/h+0.8))

ΔL is the fringing extension at one open edge in metres; εeff is from the previous formula.

L = c/(2f√εeff) − 2ΔL

L is patch length in metres; the first term is half a guided wavelength; 2ΔL corrects both open ends.

The dominant mode is TM10. The fringing length makes L slightly shorter than half the guided wavelength. The resonant frequency is f = c/(2(L+2ΔL)√εeff).

Feeds, bandwidth and arrays

Three feeds are common. An inset feed cuts a microstrip line into the patch; the inset depth sets the input resistance. A probe feed comes up through the ground and substrate from a coaxial line; it works well on thick substrates. An aperture feed couples through a slot in the ground from a line below; it reduces spurious radiation from the feed line. The patch itself is a thin resonator, so its impedance bandwidth is only a few percent. Thicker substrate, lower εr, parasitic patches and slots can widen it.

A single patch has modest gain, often about 5–8 dBi. A patch array multiplies the element pattern by an array factor, as in chapter 3.1; spacing and phase follow the uniform and tapered arrays of chapter 3.2 and chapter 3.3. Feed networks and MMIC integration belong to Unit 4. Some syllabi add fractal patches or millimetre-wave patches for 5G; only a few universities examine fractal design in detail.

  4. Effective permittivity: εeff = (4.4+1)/2 + ((4.4−1)/2)[1 + 12(1.6/38.036)]−1/2. The bracket is [1 + 0.5048]−1/2 = 0.8152. So εeff = 2.7 + 1.7 × 0.8152 = 4.086.
  5. Fringing extension: ΔL/h = 0.412 × ((4.086+0.3)(23.77+0.264)) / ((4.086−0.258)(23.77+0.8)) = 0.412 × (105.42/94.06) = 0.4618. Thus ΔL = 0.4618 × 1.6 mm = 0.739 mm.
  6. Half guided wavelength: c/(2f√εeff) = 0.0625/√4.086 = 0.0625/2.021 = 0.03092 m = 30.92 mm.
  7. Patch length: L = 30.92 − 2(0.739) = 29.441 mm.
  8. The dominant mode is TM10, with radiation mainly from the two edges separated by L.

Answer. The patch is W ≈ 38.036 mm and L ≈ 29.441 mm, with εeff ≈ 4.086 and ΔL ≈ 0.739 mm, operating in the TM10 mode.

Exam traps

  • Do not use λ₀/2 for the patch length. The dielectric slows the wave, so use εeff and subtract the fringing length 2ΔL.
  • Do not substitute εeff into the width formula. W uses the substrate εr; εeff is used for the guided wavelength and ΔL.
  • The patch edge is not a 50 Ω point. The input resistance changes with inset depth or probe position; a direct edge feed is often a few hundred ohms.
  • The patch is narrowband, not wideband. A thicker substrate or lower εr helps, but it also increases surface waves and unwanted radiation.

3.8 Antenna measurements: gain, pattern, polarization

Antenna measurements answer three practical questions: how much gain an antenna has, where its beam points, and how it is polarized. The test antenna is placed in the far field of a transmit antenna and its received power is compared with a standard gain horn. The same range records pattern cuts by rotating the antenna, and polarization by using a spinning dipole or crossed probes. These measurements qualify dish, horn, patch and array hardware before it goes into a link, radar or satellite terminal.

You need: Unit 2 for gain, pattern and polarization, and Chapter 3.5 for the standard gain horn.

Far-field range and the test site

An antenna pattern is meaningful only in the far field. The usual minimum separation is set by the largest dimension of the test antenna. A small antenna may need only a few metres; a 3 m dish at 6 GHz needs about 360 m. Inside this distance the wavefront is curved, the phase is not uniform across the aperture, and the measured pattern is a near-field pattern, not the far-field pattern.

R ≥ 2D²/λ

R is the minimum separation in metres; D is the largest dimension of the test antenna in metres; λ is the free-space wavelength in metres.

The test site is either an outdoor range or an indoor anechoic chamber lined with absorber. The chamber removes weather and most reflections, but large antennas may not fit. An outdoor range gives space but suffers multipath from ground and buildings. Multipath adds to or cancels the direct wave and ripples the pattern. Keep the range clear, use absorber, raise the antennas, and time-gate the direct pulse if the receiver allows. Cable loss also matters: a long cable lowers received power. Record cable and attenuator losses and correct for them, or use the same cable for the standard and the test antenna.

Gain by substitution

Gain is measured by substitution, also called the gain-transfer method. A standard gain horn of known gain is connected to the generator as the transmit antenna. A fixed receive antenna, the distance, the generator power and the receiver settings stay unchanged. The received power is recorded. The horn is then replaced by the test antenna at the same place, and the new received power is recorded. With both powers in dBm and gains in dBi, the test gain follows. A positive power difference means the test antenna transmits more strongly and has more gain. Do not reverse the subtraction.

G_test = G_std + (P_test − P_std)

G_test is the test-antenna gain in dBi; G_std is the standard horn gain in dBi; P_test and P_std are the received powers in dBm with the test antenna and the horn transmitting.

  1. Connect the standard gain horn to the generator and align the fixed receive antenna on boresight.
  2. Record P_std in dBm and the horn gain G_std in dBi.
  3. Replace the horn with the test antenna, keeping the same position, distance and polarization.
  4. Record P_test in dBm at the same generator setting.
  5. Compute G_test = G_std + (P_test − P_std).
  6. Repeat at several frequencies if the antenna is broadband.

Pattern cuts and polarization

A pattern cut is taken by rotating the antenna about its phase centre or by moving a probe. The E-plane cut contains the electric field vector and the beam axis. The H-plane cut contains the magnetic field vector and the beam axis and is at 90° to the E-plane. Record received power against angle, normalise to the peak, and plot in dB. Note the half-power beamwidth, first nulls and sidelobe level. Keep the probe in the far field and use the same polarization as the wanted component. A cross-polar cut uses an orthogonal probe and shows unwanted polarization.

Polarization measurement finds the tip of the electric field vector. A linearly polarized probe can be spun about the range axis. For a linear test antenna the received power falls to a minimum when the probe is crossed; for a circular antenna the level stays constant. Two crossed dipoles measure the two orthogonal components. Equal amplitudes with a 90° phase difference give circular polarization; unequal amplitudes give elliptical polarization. The axial ratio is the ratio of the maximum to the minimum field in one rotation. Circular polarization has AR = 1, or 0 dB; linear polarization has AR → ∞.

AR = E_max / E_min; AR_dB = 20 log₁₀(AR)

E_max and E_min are the maximum and minimum field magnitudes in one rotation; AR is the axial ratio; AR_dB is the axial ratio in dB.

Worked example

Question. A 10 GHz test antenna has maximum dimension 0.3 m. With a standard gain horn of 15 dBi transmitting, the receiver reads −30 dBm. With the test antenna transmitting at the same setting, the receiver reads −25 dBm. Find the minimum far-field distance and the test antenna gain.

  1. λ = c/f = 3×10⁸ / 10×10⁹ = 0.03 m.
  2. R_min = 2D²/λ = 2 × (0.3)² / 0.03 = 2 × 0.09 / 0.03 = 6 m.
  3. Power difference = P_test − P_std = −25 − (−30) = +5 dB.
  4. G_test = G_std + power difference = 15 + 5 = 20 dBi.

Answer. R_min = 6 m and G_test = 20 dBi.

Exam traps

  • Measuring inside 2D²/λ gives a near-field measurement, not a far-field pattern.
  • Keep the sign of dB differences: higher received power means higher gain.
  • Using a different cable, attenuator or amplifier setting for the standard and the test antenna adds an error equal to that difference.
  • Do not swap E-plane and H-plane: the E-plane contains the electric field vector.
  • Axial ratio is 0 dB for circular polarization, not for linear polarization; linear has AR → ∞.

3.9 Ground, sky and space wave propagation; ionosphere

Propagation is how a radio wave travels from a transmitting antenna to a receiving antenna. Three routes matter. A ground wave follows the curve of the earth at low frequency. A sky wave goes up to the ionosphere and is bent back, giving long HF links. A space wave goes almost straight and needs line of sight, so it serves VHF, UHF and microwave systems. The choice depends on frequency, distance and time of day. The same transmitter can use one route by day and another by night.

You need: Unit 2 basic wave propagation and frequency bands, and antenna polarization from Chapter 3.8.

Three routes: ground, sky and space

Propagation is the path a radio wave takes from transmitter to receiver. The path depends on frequency and on what lies between the antennas. Engineers group the paths into three modes: ground wave, sky wave and space wave. Some syllabi call the whole subject wave propagation.

Ground wave: the wave travels along the earth's surface. It is useful at LF and MF, roughly 30 kHz to 3 MHz, where the earth and the lower atmosphere guide it. The electric field must be vertical; a horizontal field is shorted by the conducting earth and dies quickly. Attenuation grows with frequency, with distance, and over poor ground such as dry sand. AM broadcast and maritime radio use it.

Sky wave: the wave travels upward, is refracted by the ionosphere, and returns to earth. It works at HF, roughly 3 MHz to 30 MHz, and can cover thousands of kilometres with one hop or several hops. It depends on solar activity and time of day.

Space wave: the wave travels directly from antenna to antenna, with a ground-reflected ray close by. It works at VHF, UHF and SHF, roughly 30 MHz upward. It needs line of sight, so antenna height sets the range. FM radio, TV, cellular, Wi-Fi and microwave links use it.

The ionosphere and sky waves

Solar ultraviolet and X-rays knock electrons from gas molecules in the upper atmosphere. The result is the ionosphere, a region from about 60 km to 400 km with free electrons. The electron density N, in electrons per cubic metre, changes with height, season and sunspot cycle. A radio wave entering a region of rising N slows and bends away from the vertical. This refraction, often called reflection, can turn an HF wave back toward earth.

Four layers matter. The D layer, 60–90 km, exists mainly by day. Its high collision rate absorbs MF and lower HF energy, so daytime HF signals are weaker. The E layer, 90–150 km, gives some daytime refraction and occasional strong sporadic E. The F1 layer, 150–250 km, appears by day and merges with F2 at night. The F2 layer, 250–400 km, is the main refracting layer for long-distance HF day and night.

Critical frequency: send a wave straight up. The highest frequency that the layer returns is fc = 9√Nmax. Here fc is in hertz and Nmax is the peak electron density in electrons per cubic metre. Frequencies above fc pass through that layer. For an oblique path, the wave cuts the layer at an angle. The maximum usable frequency is MUF = fc sec φ. φ is the angle between the ray and the vertical at the layer; sec φ = 1/cos φ. MUF is higher than fc because the longer slant path lets a higher frequency bend back. A frequency above the MUF escapes to space.

fc = 9√Nmax, MUF = fc sec φ

fc is the critical frequency in hertz; Nmax is the peak electron density in electrons per cubic metre; φ is the angle of the ray from the vertical at the layer; sec φ = 1/cos φ; MUF is in the same unit as fc.

Skip distance is the shortest ground distance at which a sky wave of a given frequency returns. Inside the skip distance lies the skip zone, which runs from the limit of ground-wave coverage out to the first sky-wave return; within it no sky-wave signal is received. Skip distance grows as frequency rises toward the MUF. Fading comes from several rays arriving with different path lengths and phases, and from changing ionospheric height. It can be slow, fast or selective across a band.

Space waves and the radio horizon

At VHF and above, the ionosphere is usually too thin in electron density to bend the wave back. The wave leaves the antenna, travels in a nearly straight line, and is blocked by the curved earth. This is the space wave. It includes the direct ray and a ground-reflected ray; the two can add or cancel as antenna height changes.

The geometric horizon is set by earth curvature. The geometric horizon distance is d ≈ 3.57√h, where d is in kilometres and h is the antenna height in metres. The atmosphere has a refractive index that falls with height, so the ray bends slightly around the earth. With standard atmospheric refraction (4/3 earth radius), the radio horizon is d ≈ 4.12√h. For two antennas, add the horizon distance of each. A 25 m mast has a geometric horizon at 17.9 km and a radio horizon at about 20.6 km.

Tropospheric scatter uses irregularities in the lower atmosphere to scatter a small part of a UHF or SHF beam beyond the horizon. Ducting occurs when a temperature inversion or a sharp moisture gradient traps the wave in a layer; the signal then travels much farther than the normal horizon, sometimes causing interference. Space waves serve FM and TV broadcast, mobile networks, Wi-Fi, point-to-point microwave links and satellite links.

Worked example

Question. The critical frequency of an ionospheric layer is 5 MHz. A sky-wave link uses a ray that arrives at the layer at 60° measured from the vertical. Find the maximum usable frequency (MUF) for this path. State the unit.

  1. Given: critical frequency fc = 5 MHz; angle from the vertical φ = 60°.
  2. Use MUF = fc sec φ = fc / cos φ.
  3. cos 60° = 0.5, so sec 60° = 1 / 0.5 = 2.
  4. MUF = 5 MHz × 2 = 10 MHz.

Answer. The maximum usable frequency is 10 MHz.

Exam traps

  • Using cos φ instead of sec φ in the MUF formula. At 60°, cos 60° = 0.5 gives 2.5 MHz, but the correct MUF is 10 MHz.
  • Calling MUF the critical frequency. Critical frequency is for vertical incidence; MUF is for an oblique path and is always at least fc.
  • Saying the D layer reflects HF. It mainly absorbs; the F2 layer does the long-distance refraction.
  • Using sky wave for VHF or UHF beyond the horizon. Normal ionospheric sky wave is an HF effect; VHF and UHF beyond the horizon usually mean tropospheric scatter or ducting.
  • Using 3.57√h as the radio horizon. The geometric horizon is d ≈ 3.57√h; with standard refraction the radio horizon is d ≈ 4.12√h. Both give d in kilometres only when h is in metres.
