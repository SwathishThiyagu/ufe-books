4.1 Sampling theorem, aliasing and reconstruction

Sampling turns a continuous signal into numbers taken at fixed instants. It exists because digital storage, PCM speech and software radio cannot carry a continuous waveform directly. If the samples are close enough, the original signal can be rebuilt exactly. If they are too far apart, high frequencies fold down and pretend to be low frequencies, and the damage cannot be undone. This chapter states the sampling theorem, defines the rates, computes aliases, and shows ideal and flat-top reconstruction.

You need: Fourier transform, bandwidth and spectra from Unit 1; pulse modulation follows in Chapter 4.2.

The theorem and the sample rate

A lowpass signal has no frequency content above fm hertz. The sampling theorem says it can be rebuilt exactly from samples taken at fs ≥ 2fm. Here fs is the sampling rate in samples per second, and fm is the highest message frequency in hertz. The sampling interval is Ts = 1/fs seconds. The Nyquist rate is 2fm samples per second. The Nyquist interval is 1/(2fm) seconds.

Ideal sampling multiplies m(t) by an impulse train with spacing Ts. The sampled spectrum is fs times a sum of shifted copies of the message spectrum. Proof sketch: the impulse train has a spectrum that is also an impulse train at spacing fs; multiplication in time becomes convolution in frequency, so each impulse shifts a copy of M(f) to kfs. If fs ≥ 2fm, the copies occupy separate intervals and an ideal lowpass filter from 0 to fm recovers M(f) exactly. If fs < 2fm, the copies overlap.

s(t) = Σ m(nTs) δ(t − nTs)   and   S(f) = fs Σ M(f − kfs)

s(t) is the ideal sampled signal; m(t) is the message; Ts = 1/fs is the sampling interval in seconds; δ is the unit impulse; S(f) and M(f) are their spectra; fs is the sampling rate; k and n are integers.

A practical sampler is preceded by an anti-alias lowpass filter. It removes noise and interference above fm before sampling, because once folded they cannot be separated from the message. After sampling, a reconstruction lowpass filter removes the replicas. Some syllabi call this the Nyquist–Shannon theorem or the Whittaker theorem.

Aliasing and folding

A tone at f0 above fs/2 does not disappear. Sampling makes it look like a lower tone. The apparent frequency is fa = |f0 − kfs|, with integer k chosen so that 0 ≤ fa ≤ fs/2. Every sampled tone repeats in fs, so f0 and f0 ± fs give the same samples. If f0 is only a little above fs/2, one subtraction is enough. If f0 is much larger, subtract multiples of fs until the result lies in the baseband.

Take fs = 7 kHz with tones at 1 kHz and 4 kHz. The 1 kHz tone is below 3.5 kHz, so it stays at 1 kHz. The 4 kHz tone is above 3.5 kHz; with k = 1, fa = |4 − 7| = 3 kHz. The sampler output therefore contains a 3 kHz component that was not in the input. This folding is aliasing. The figure shows the original lines, the folded line at 3 kHz, and replicas at 6, 8 and 11 kHz.

Prevent aliasing by keeping all input components below fs/2. Put an anti-alias lowpass filter before the sampler. It passes 0 to fm and stops at fs − fm, so noise above fm cannot fold into the message. A guard band between fm and fs − fm allows a real filter with a gradual roll-off. Telephone speech often uses fm ≈ 3.4 kHz and fs = 8 kHz for this reason.

Reconstruction and aperture effect

Ideal reconstruction uses sinc interpolation: m(t) = Σ m(nTs) sinc((t − nTs)/Ts). Here sinc(x) = sin(πx)/(πx), and sinc(0) = 1. Each sample creates a sinc pulse; the sum passes through every sample and has no content above fm. This needs exact sample times and an ideal lowpass filter. Real filters approximate it.

Zero-order hold (ZOH), also called flat-top reconstruction, holds each sample value for Ts seconds. Its response is H(f) = Ts sinc(fTs), apart from a delay. The sinc factor attenuates high frequencies inside the baseband; this is the aperture effect. A compensation filter with a rising response can flatten it. In natural sampling the pulse top follows the message during the pulse. In flat-top sampling the top is flat at the sample value. PAM circuits use both names.

Sampling leads to pulse modulation: PAM varies pulse amplitude, PWM varies width, and PPM varies position; see Chapter 4.2. Bandpass sampling is a separate note. A signal in a band from fL to fH can be sampled below 2fH if the shifted copies do not overlap. Choose fs so the band lands inside 0 to fs/2 without collision. Radio receivers use this to sample a bandpass signal directly.

Worked example

Question. A signal m(t) = 3 cos(2π·1000t) + 2 cos(2π·4000t) is sampled at fs = 7000 samples/s. Find the Nyquist rate, decide whether aliasing occurs, and give the alias frequency of the 4 kHz tone. State where the 1 kHz tone appears.

  1. Identify the tones: f1 = 1000 Hz and f2 = 4000 Hz. The highest message frequency is fm = 4000 Hz.
  2. Nyquist rate = 2fm = 2 × 4000 = 8000 samples/s. Nyquist interval = 1/8000 = 0.000125 s = 0.125 ms.
  3. The actual rate is fs = 7000 samples/s. Compare: 7000 < 8000, so fs < 2fm and aliasing occurs.
  4. For the 4 kHz tone, fold with k = 1: fa = |4000 − 7000| = 3000 Hz. This lies between 0 and fs/2 = 3500 Hz, so the alias is 3 kHz.
  5. For the 1 kHz tone, 1000 Hz is below 3500 Hz. It is not folded and appears at 1 kHz.

Answer. Nyquist rate = 8000 samples/s; aliasing occurs; the 4 kHz tone appears at 3 kHz, and the 1 kHz tone stays at 1 kHz.

Exam traps

  • fs = 2fm is the theoretical limit, not a practical design value. Real anti-alias filters need a guard band, so most systems use fs > 2fm.
  • The alias must lie in 0 to fs/2. If f0 > fs, subtract multiples of fs; one subtraction can still leave a frequency above fs/2.
  • Nyquist rate is 2fm samples/s; Nyquist interval is 1/(2fm) seconds. Do not swap them.
  • The replicas in the sampled spectrum are spaced fs, not fm. Sketch centres at 0, ±fs, ±2fs.
  • Flat-top sampling is not ideal impulse sampling. Its sinc response droops the baseband; that is the aperture effect, not aliasing.

4.2 PAM, PWM and PPM

Analog pulse modulation sends a narrow pulse again and again. The message rides on one pulse property: height in PAM, width in PWM, or position in PPM. The receiver looks only at that property. The pulse period Ts stays fixed; only one pulse parameter carries the message. The circuit stays simple. PAM is the first step towards PCM; PWM and PPM are used in cheap control links, lamp dimming, servo signals and optical pulse links. Here you see how each is made, what its spectrum looks like, and why constant-amplitude forms resist noise better.

You need: Chapter 4.1 for sampling at fs ≥ 2fm, and Fourier series and spectra from Unit 1.

Pulse train, PAM and flat-top sampling

Take a periodic pulse train p(t) with period Ts = 1/fs, pulse width τ, and height A. The duty cycle is d = τ/Ts. The sampling rate must satisfy fs ≥ 2fm, as in Chapter 4.1; fm is the highest message frequency.

In pulse amplitude modulation (PAM), the height of each pulse follows the sample value: pulse k has height m(kTs). Natural PAM keeps the pulse shape and lets the top follow m(t). Flat-top PAM holds each sample constant for τ, so a sample-and-hold circuit can make it. The receiver recovers m(t) by low-pass filtering at fm.

P<sub>PAM</sub>(f) = (1/T<sub>s</sub>) Σ<sub>n</sub> M(f − n f<sub>s</sub>) · P(f)

PPAM(f) is the flat-top PAM spectrum; M(f) is the message spectrum; n is an integer; P(f) is the spectrum of one rectangular pulse: P(f) = A τ sinc(f τ), with sinc(x) = sin(πx)/(πx). For natural PAM the spectrum is Σ cn M(f − n fs) with cn = (τ/Ts) sinc(n τ/Ts), a weighted set of replicas, not M(f) multiplied by P(f).

The message spectrum repeats every fs, and the pulse shape acts as a low-pass filter. A flat-top pulse has nulls at f = 1/τ, 2/τ, … . This sinc attenuates high message frequencies; the loss is the aperture effect. An equalizer with a 1/sinc response can compensate. PAM is still an analog signal: it becomes digital only after quantization and coding, in Chapter 4.4.

PWM and PPM

PWM keeps the pulse height A fixed and varies the width. Pulse-duration modulation (PDM) is often the same thing; a few texts separate pulse-duration modulation (one edge fixed) from pulse-width modulation (both edges move). If the unmodulated width is τ0, then τ(t) = τ0 + kw m(t), where kw is the width sensitivity in seconds per volt. The duty cycle d(t) = τ(t)/Ts follows the message.

A comparator with a sawtooth reference at fs makes PWM. The comparator output is high while m(t) is above the sawtooth. A larger m(t) gives a wider high time. A low-pass filter averages the PWM wave and recovers m(t); the average is proportional to duty cycle.

Pulse-position modulation (PPM) keeps height and width fixed and slides the whole pulse earlier or later about its nominal slot by an amount proportional to m(t). Generate PPM from PWM by taking one edge per PWM period, usually the modulated trailing edge. A monostable, or a differentiator plus rectifier, turns that edge into one short pulse per PWM period. The pulse position then carries the sample.

PPM needs more bandwidth than PWM because narrow pulses have a wide sinc spectrum. PWM needs more bandwidth than PAM. Both PWM and PPM keep amplitude constant, so amplitude noise changes height less; timing jitter becomes the main error.

Worked example

Question. A 1 kHz tone is sampled at 8 kHz. Each flat-top PAM pulse is 25 μs wide. Find the sampling interval, the duty cycle, and the first null of the pulse spectrum.

  1. Sampling interval: Ts = 1/fs = 1/(8×103 Hz) = 125×10−6 s = 125 μs.
  2. Duty cycle: d = τ/Ts = 25 μs / 125 μs = 0.20 = 20%.
  3. First null: fnull = 1/τ = 1/(25×10−6 s) = 40×103 Hz = 40 kHz.
  4. Check sampling: fs = 8 kHz > 2fm = 2 kHz, so no aliasing.

Answer. Ts = 125 μs, duty cycle = 0.20 (20%), and the first null is at 40 kHz.

Exam traps

  • PAM is not PCM. PAM is analog until quantization; PCM adds binary coding.
  • PPM shifts pulse position, not width; PWM changes width at constant height.
  • Duty cycle is τ/Ts, not τ·Ts, and it is dimensionless.
  • The first spectral null of a rectangular pulse is at 1/τ, not 1/(2τ).
  • Constant amplitude does not mean no noise; timing jitter and limited bandwidth still hurt PPM and PWM.

4.3 Uniform and non-uniform quantization; companding

Quantization rounds each sample to one of L allowed levels. In a uniform quantizer the levels are equally spaced by Δ, so every sample carries the same worst-case error. Speech has small samples far more often than large ones, so uniform steps waste resolution on quiet passages and clip loud peaks. Non-uniform quantization gives fine steps near zero and coarse steps at high amplitude; companding is the practical way to get this. Telephone PCM, VoIP and audio codecs use these ideas.

You need: Chapter 4.1 for sampling, and Unit 1 for random variables and noise power.

Uniform quantization

A quantizer maps a continuous sample x to the nearest of L discrete levels. When the step between neighbouring levels is the same everywhere, the quantizer is uniform. For an n-bit code, L = 2ⁿ. If the full-scale range is from −V to +V, the total width is 2V, so the step is Δ = 2V / L. Each sample is replaced by the level closest to it; the difference is the quantization error e = q(x) − x.

Δ = 2V / L,  L = 2ⁿ,  −Δ/2 ≤ e ≤ Δ/2,  P<sub>q</sub> = Δ²/12

V is the maximum input magnitude in volts; L is the number of levels; n is the number of bits per sample; Δ is the step in volts; e is quantization error in volts; Pq is quantization noise power in V², for a uniformly distributed error.

For a smooth signal and a fine step, e is almost uniformly spread over one step, so its mean is zero and its power is Δ²/12. This is granular noise: it exists even when the channel is perfect. A sample outside ±V is clipped to the end level, giving overload distortion. Overload is not included in Δ²/12.

The signal-to-quantization-noise ratio for a full-scale sinusoid x(t) = V sin(2πft) is SQNR = (V²/2) / (Δ²/12). Substituting Δ = 2V/2ⁿ gives SQNR = (3/2)2²ⁿ, or in decibels SQNR = 6.02n + 1.76 dB. Each extra bit adds about 6 dB. This formula assumes the sine uses the full range; a quiet talker gets much less.

SQNRdB = 6.02n + 1.76

SQNRdB is the signal-to-quantization-noise ratio in decibels for a full-scale sinusoid; n is bits per sample. For other signals use 10 log₁₀(Psignal / Pq).

Non-uniform quantization and companding

Uniform steps give the same absolute error at all amplitudes. Speech statistics are closer to logarithmic: quiet sounds need small absolute error to sound clean, loud sounds can tolerate larger error. A non-uniform quantizer uses small Δ near zero and larger Δ at large |x|. The step size becomes a function of x, so Pq is not simply Δ²/12 with one Δ.

Companding means compressing at the transmitter and expanding at the receiver. A compander is the pair: compressor before the uniform quantizer, expander after reconstruction. The compressor y = C(x) boosts small inputs, so after uniform quantization the small inputs have effectively finer steps. The expander applies C⁻¹. In telephony the compressor is a smooth curve, implemented by a segmented approximation in PCM chips.

y = sgn(x) · ln(1 + μ|x|/V) / ln(1 + μ),  |x| ≤ V

x is the input sample in volts; V is full scale; y is the normalized compressed output; sgn(x) is +1 for x > 0 and −1 for x < 0; μ controls the amount of compression. μ = 255 is standard for 8-bit speech PCM in North America and Japan.

y = sgn(x) · A|x|/V / (1 + ln A)  for |x|/V ≤ 1/A;  y = sgn(x) · (1 + ln(A|x|/V)) / (1 + ln A)  for 1/A < |x|/V ≤ 1

A is the compression parameter; A = 87.6 is standard in Europe and much of the world. The first segment is linear; the rest is logarithmic.

Both laws make the SQNR roughly constant over a wide range of input levels. Idle-channel noise is the audible quantization noise heard when the talker is silent; with fine steps near zero it is reduced but not eliminated. A-law and μ-law are not compatible, so international calls need conversion.

Limits and practical reading

Companding improves small-signal SNR. It cannot prevent overload when the input exceeds the designed full scale. A shout or a sudden transient still clips at the peak level.

In a uniform system, a sinusoid smaller than full scale by a factor k has signal power k² times smaller, so SQNR falls by 20 log₁₀(1/k) dB. A companded system reduces that fall, but the improvement depends on the law and the code.

Δ²/12 is quantization noise only. Thermal noise, crosstalk and bit errors add separately, so total noise power is the sum of the powers. Some syllabi call non-uniform quantization logarithmic quantization or companded PCM.

  • Use 6.02n + 1.76 dB only for a full-scale sine; for speech use measured active-speech power.
  • Keep V as peak full scale; Δ = 2V/L uses the full peak-to-peak width.
  • Do not expect companding to remove clipping; it only reshapes the error at normal levels.

Worked example

Question. An 8-bit uniform PCM system encodes a full-scale sinusoid in the range ±1 V. Find the number of levels, the step size, the quantization noise power, and the SQNR in dB.

  1. Number of levels: L = 2ⁿ with n = 8, so L = 2⁸ = 256 levels.
  2. Full-scale range is from −1 V to +1 V, so the total width is 2V = 2 V. Step: Δ = 2 V / 256 = 0.0078125 V = 7.8125 mV.
  3. Quantization noise power: P_q = Δ²/12 = (0.0078125 V)² / 12 = 6.1035×10⁻⁵ / 12 = 5.0863×10⁻⁶ V².
  4. For a full-scale sine, signal power is V²/2 = (1 V)²/2 = 0.5 V². SQNR = 0.5 / 5.0863×10⁻⁶ = 98,304.
  5. In dB: SQNR_dB = 10 log₁₀(98,304) ≈ 49.9 dB. The shortcut gives 6.02×8 + 1.76 = 49.92 dB; the small difference is rounding in 6.02.

Answer. L = 256 levels, Δ = 7.8125 mV, P_q = 5.086×10⁻⁶ V², and SQNR ≈ 49.9 dB.

Exam traps

  • Using 6.02n + 1.76 dB for any signal. It is only for a full-scale sine wave; for speech or arbitrary signals use actual signal power.
  • Mixing peak V and peak-to-peak 2V. The step is Δ = 2V/L, not V/L.
  • Claiming companding removes overload. It gives finer steps at low levels but cannot stop clipping beyond full scale.
  • Treating Δ²/12 as total noise. It is quantization noise only; channel noise, crosstalk and bit errors add separately.
  • Confusing the compressor with the expander, or swapping the standard values μ = 255 and A = 87.6.

4.4 Pulse code modulation (PCM)

Pulse code modulation (PCM) turns each quantized sample into a fixed-length binary code word. A sample is first limited to the message band, sampled, rounded to one of L levels, and encoded as n bits. The bit rate is Rb = fs n, so telephone speech at fs = 8 kHz with n = 8 gives 64 kbit/s. PCM is the base of digital telephone networks, voice recorders and any link that must send analog signals as bits.

You need: sampling and aliasing, quantization and companding, and the noise ideas from Unit 1.

The PCM chain and its bit rate

The message m(t) is the analog voltage to be sent. An anti-alias lowpass filter (LPF) first removes frequencies above fm, the highest message frequency, so later sampling cannot fold them down. The sampler then takes values at rate fs, with fs ≥ 2fm. The quantizer replaces each sample by the nearest of L allowed levels. The encoder writes that level as an n-bit code word, where L = 2ⁿ. A channel carries the bits; regenerators reshape the pulses at intervals. The decoder turns each code word back into a level, and a reconstruction LPF smooths the staircase into an output waveform.

  1. Filter m(t) to fm to prevent aliasing.
  2. Sample at fs ≥ 2fm samples per second.
  3. Quantize each sample to one of L = 2ⁿ levels.
  4. Encode each level as an n-bit word; send bits with duration Tb.
  5. Decode and lowpass-filter to recover the message.

Rb = fs × n, Tb = 1/Rb

Rb is the bit rate in bit/s; fs is the sampling rate in samples/s; n is the number of bits per sample; Tb is one bit duration in seconds.

Bandwidth, noise and regeneration

Two bandwidth numbers are easy to mix. For ideal Nyquist pulses with no intersymbol interference, the minimum baseband bandwidth is Bmin = Rb/2. For a non-return-to-zero (NRZ) rectangular pulse, the first null of the spectrum is at Rb, so the main lobe needs about Rb. A practical PCM link uses more than Rb/2, often around Rb or somewhat above, because real pulses, filtering and timing need margin. 64 kbit/s is a bit rate; 32 kHz is the ideal minimum baseband bandwidth, not 64 kHz.

Bmin = Rb/2

Bmin is the ideal minimum baseband bandwidth in Hz for Nyquist pulses; Rb is the bit rate in bit/s.

Quantization adds an error between the true sample and the chosen level. For a full-scale sine wave and uniform quantization, the signal-to-quantization-noise ratio is SQNR = 6.02n + 1.76 dB. Each extra bit adds about 6 dB.

SQNR = 6.02n + 1.76 dB

SQNR is the signal-to-quantization-noise ratio for a full-scale sine; n is the number of bits per sample.

A regenerator decides whether each received pulse is 0 or 1 and creates a fresh pulse. Noise added between repeaters is removed, so long links do not accumulate analog noise. A wrong decision is a bit error and travels onward; regeneration does not correct it. Channel coding, see Unit 7, handles that. With companding, small speech samples get finer steps. Standard companded PCM for speech uses 8 bits at 8 kHz, giving 64 kbit/s.

Frames and destination SNR

PCM bits are sent in frames. A frame holds one code word for each channel plus a synchronization word that lets the receiver find the start. In a simple single-channel link the sync word may appear only at the start of a recorded file; in a multiplexed link it repeats every frame. The details of frame structure belong to TDM in 4.7.

Destination SNR in PCM with noise has two parts. Quantization noise is fixed by n and the step size. Channel noise causes bit errors, and each wrong bit moves the decoded sample to a different level, producing an extra error or a click. At low bit-error probability the quantization part dominates; at high error probability the bit-error part dominates. The exact expression depends on the code and error pattern, so block-level treatment is enough here.

Worked example

Question. Telephone speech is bandlimited to 3.4 kHz and sampled at 8 kHz with 8 bits per sample. Find the bit rate, minimum ideal baseband bandwidth, number of quantization levels, and SQNR for a full-scale sine.

4.5 Differential PCM and adaptive DPCM

Differential pulse-code modulation (DPCM) sends the difference between each sample and a prediction made from past samples, not the full sample. Speech, audio and many sensor signals change slowly from one sample to the next, so this difference is small and needs fewer bits than PCM for the same quality. The receiver rebuilds the signal by adding back the same prediction. Adaptive DPCM (ADPCM) also changes the quantizer step with the signal’s short-term energy. Telephone speech at 32 kbit/s from 64 kbit/s PCM is a standard use.

You need quantization, PCM, and correlation from Unit 1.

Predict, subtract, encode

Let x[n] be the sample at time index n, and let x̂[n] be its prediction from earlier samples. DPCM sends the prediction error e[n] = x[n] − x̂[n]. If the signal is smooth, e[n] is small. The quantizer replaces e[n] by one of L = 2R allowed levels, and the encoder sends that level as an R-bit code word. The bit rate is fs·R bit/s, where fs is the sampling frequency in samples per second and R is the number of bits per sample. This is the same form as PCM, but R can be smaller because the error has lower variance than the original signal.

e[n] = x[n] − x̂[n]

x[n] is the input sample at index n; x̂[n] is the predicted value; e[n] is the prediction error sent to the quantizer.

For a simple predictor x̂[n] = x̃[n−1], where x̃ is the reconstructed past sample, the error depends on how strongly adjacent samples are correlated. For a first-order Markov source with variance σ² and adjacent-sample correlation ρ, the prediction-error variance is σ_e² = 2σ²(1−ρ). A value of ρ close to 1 means a slow signal and a small error.

Closed-loop predictor in transmitter and receiver

The figure shows the order: subtractor, quantizer, encoder, channel, decoder, adder, predictor. The transmitter also needs a local decoder. After quantizing e[n] to q[n], it forms the reconstructed sample x̃[n] = x̂[n] + q[n] and stores x̃[n] for the next prediction.

  1. Predict x̂[n] from stored reconstructed samples.
  2. Subtract to get e[n] = x[n] − x̂[n].
  3. Quantize e[n] to q[n] and encode its level index.
  4. In the transmitter, add x̂[n] + q[n] to get x̃[n].
  5. Send the index; the receiver decodes q[n], adds the same x̂[n], and updates its predictor.

Both predictors must use x̃, not the true input x. If the transmitter predicts from x[n] but the receiver has only x̃[n], their predictions diverge. Each decoded error then adds to a wrong prediction, and the error can grow from sample to sample. Because the quantizer sits inside the closed loop and the same q[n] is added on both sides, the transmitter and receiver predictors hold identical values, so quantizer noise does not accumulate.

Prediction gain and ADPCM

G_DPCM = 10 log₁₀(σ² / σ_e²) = 10 log₁₀[1 / (2(1−ρ))] dB

G_DPCM is the improvement over PCM at the same number of bits; σ² is signal variance; σ_e² is prediction-error variance; ρ is adjacent-sample correlation.

A larger ρ gives a larger gain. With ρ = 0, the formula gives −3 dB, so DPCM is worse; the gain is not automatic. The full names are differential pulse-code modulation and adaptive differential pulse-code modulation. Some syllabi use the short forms DPCM and ADPCM.

ADPCM changes the quantizer step Δ[n] with short-term signal energy. A loud segment gets a large step to avoid overload; a quiet segment gets a small step to avoid granular noise. The predictor coefficients may also adapt. Standard speech ADPCM at 32 kbit/s carries 4-bit differences at 8 kHz, half the 64 kbit/s PCM rate. This is adaptation, not companding: companding uses a fixed non-uniform curve, while ADPCM changes with time.

Worked example

Question. A first-order Markov source has variance σ² = 1 V² and adjacent-sample correlation ρ = 0.9. DPCM uses x̂[n] = x̃[n−1]. Find the prediction-error variance and the DPCM gain over PCM at the same number of bits.

  1. Write the given values: σ² = 1 V² and ρ = 0.9.
  2. Use σ_e² = 2σ²(1−ρ) = 2 × 1 × (1 − 0.9) = 2 × 0.1 = 0.2 V².
  3. Use G_DPCM = 10 log₁₀(σ² / σ_e²) = 10 log₁₀(1 / 0.2) = 10 log₁₀(5).
  4. log₁₀(5) = 0.69897, so G_DPCM = 6.9897 dB ≈ 6.99 dB.

Answer. The prediction-error variance is 0.2 V², and the DPCM gain over PCM is 6.99 dB, about 7 dB.

Exam traps

  • The transmitter predictor must use the same reconstructed past samples as the receiver. Using the true input x[n] instead of x̃[n] causes predictor mismatch and growing error.
  • DPCM is not delta modulation. DPCM can send many bits per difference; delta modulation sends one bit per sample with a fixed step, covered in Chapter 4.6.
  • ADPCM adaptation is not companding. Both help small signals, but companding is a fixed non-uniform quantizer curve, while ADPCM changes the step from the short-term signal.
  • The DPCM gain formula assumes a first-order predictor and the same bit rate for PCM and DPCM. A weak correlation, or ρ near 0, can make DPCM worse than PCM.

4.6 Delta and adaptive delta modulation

Delta modulation (DM) is a one-bit differential coder. At every sampling instant it compares the input with a staircase built from past bits, and sends 1 if the input is above the staircase or 0 if it is below. The staircase moves by a fixed step Δ. Adaptive delta modulation (ADM) changes Δ with the signal slope. DM and ADM are used in low-cost speech links, voice storage and simple sensor telemetry where a low bit rate and simple hardware matter more than high fidelity.

You need: Chapter 4.5 DPCM for prediction from past samples, Chapter 4.1 for sampling rate, and the slope of a sinusoid from Unit 1.

How delta modulation works

Delta modulation (DM) sends one bit for every sample. The transmitter keeps a staircase estimate x̂(t) of the input x(t). A comparator asks one question at each clock tick: is x(t) above or below x̂(t)? A 1 means above, a 0 means below. That single bit is transmitted. The same bit drives an integrator, which adds Δ for a 1 and subtracts Δ for a 0. So x̂(t) moves one step of Δ volts toward the input. Δ is the step size.

  1. Sample the comparator output at f_s.
  2. Send 1 if x(t) > x̂(t); otherwise send 0.
  3. Move the staircase by +Δ for 1 and -Δ for 0.
  4. Repeat at the next clock tick.

R_b = f_s

R_b is the DM bit rate in bits per second; f_s is the sampling rate in samples per second. DM sends one bit per sample.

At the receiver, an integrator repeats the same staircase from the received bits: +Δ for 1, -Δ for 0. A lowpass filter then smooths the staircase into an estimate of x(t). The receiver needs no code-word boundary or multi-level decoder, only the bit clock. The staircase is not the final audio; it is the running estimate. DM is the 1-bit limiting case of DPCM, covered in Chapter 4.5.

Slope overload and granular noise

The staircase can change only by Δ at each sample, so its fastest possible slope is Δf_s volts per second. If |dx/dt| exceeds this, x̂(t) lags behind. The modulator then sends a long run of 1s or 0s, but the staircase still cannot catch the input. This is slope overload. It causes large errors on steep parts of the signal.

Δ f_s ≥ 2π f A

Δ is the step size in volts; f_s is the sampling rate in samples per second; f is the sinusoid frequency in hertz; A is its peak amplitude in volts. This is the no-slope-overload condition for x(t) = A sin(2πft).

For x(t)=A sin(2πft), dx/dt=2πfA cos(2πft). The largest magnitude is 2πfA. Slope overload is avoided when Δf_s is at least 2πfA.

A large Δ prevents overload but makes the staircase jump too far around a slowly varying input. The estimate then oscillates up and down near x(t), producing granular noise. A small Δ reduces this buzz but overloads on steep slopes. Fixed DM must choose one compromise between slope overload and granular noise. Granular noise is the DM quantization noise; it is not the same as slope overload.

Adaptive delta modulation and PCM comparison

ADM varies Δ with the signal. The receiver can deduce the same changes from the received bits, so no extra bits are sent. A common rule: after a run of equal bits (say three or four 1s, or three or four 0s), the staircase is being pushed one way, so multiply Δ by a factor above 1. When bits alternate, the staircase is hovering, so multiply Δ by a factor below 1. Keep Δ between Δ_min and Δ_max.

During steep slopes Δ grows, so ADM tracks without slope overload. During quiet parts Δ shrinks, so granular noise falls. This gives a more constant signal-to-noise ratio over a wide amplitude range than fixed DM. ADM still sends one bit per sample: R_b=f_s.

DM needs only a comparator, clock and integrator; PCM needs a multi-level quantizer and an n-bit encoder. PCM bit rate is f_s n, so 8 kHz speech with 8 bits is 64 kbit/s. DM at 64 kbit/s uses f_s = 64 kHz, one bit per sample. That high sampling helps slope tracking, but DM still has coarser quantization and a fixed-step trade-off. ADM improves dynamic range while keeping one bit per sample. For the same quality DM often needs a higher f_s than PCM, so its bandwidth is not automatically lower.

DM and ADM appear in low-cost voice recorders, simple telemetry and some speech codecs. DPCM in Chapter 4.5 generalizes the same prediction idea to n-bit differences.

Worked example

Question. A 1 kHz sinusoid of peak amplitude 2 V is encoded by delta modulation with step size Δ = 0.1 V and sampling rate f_s = 32 kHz. (a) Find the maximum slope of the sinusoid.   2. 2π×1000×2=12,566.37 V/s, rounded to 12,566 V/s.
  3. DM staircase maximum slope = Δf_s = 0.1×32,000 = 3,200 V/s.
  4. 12,566 > 3,200 V/s, so slope overload occurs.
  5. Minimum f_s = (2πfA)/Δ = 12,566.37/0.1 = 125,663.7 Hz, about 125,660 Hz or 126 kHz.

Answer. Slope overload occurs; to avoid it f_s must be at least about 126 kHz (125,660 Hz using the rounded slope).

  • ADM adapts Δ from the received bit pattern. It does not send extra side bits, so its bit rate is still f_s.

4.7 Time division multiplexing

Time division multiplexing (TDM) lets many signals share one link by giving each signal a repeating slice of time called a slot. All signals use the full bandwidth of the link, but only one signal uses it at a time. A receiver knows the slot order from a frame marker, so it can separate the samples. Telephone trunks, digital exchanges and PCM systems use TDM. In India an E1 line at 2.048 Mbit/s carries 32 such slots, enough for 30 speech calls plus signalling and synchronisation.

You need: Chapter 4.1 for the sampling rate, Chapter 4.2 for PAM, and Chapter 4.4 for PCM code words.

Frame, slot and the TDM idea

TDM is time sharing. One frame is one complete round of all channels. Its duration is Tf = 1/fs, where Tf is the frame duration in seconds and fs is the sampling rate in samples per second. For a 4 kHz voice signal sampled at 8 kHz, Tf = 125 μs.

Inside the frame each channel gets a slot. In PCM the slot carries the n-bit code word of one sample. A guard time is a small idle gap between slots; it absorbs timing error at the cost of some capacity. A synchronisation bit or word marks the start of the frame.

Each input is called a channel. For N equal channels the frame has N data slots plus sync. The figure shows four 8-bit channel slots and one sync bit in a 125 μs frame. The order repeats every frame. The frame rate equals fs, not the bit rate. If one bit lasts Tb seconds, an n-bit slot lasts nTb seconds, plus any guard time.

PAM, PCM and the bit rate

With PAM, each slot holds one analog sample. The multiplexer samples channel 1, then channel 2, and so on; the receiver uses a sample-and-hold circuit to stretch each sample. With PCM, each quantised sample becomes an n-bit code word. The multiplexer can interleave whole words, so a channel's n bits stay together, or interleave bit by bit, so the bits of one word are spread over n rounds and must be reassembled.

Rb = (N n + S) fs

Rb is the multiplexed bit rate in bit/s; N is the number of data channels; n is the number of bits per sample per channel; S is the number of synchronisation and signalling bits per frame; fs is the frame rate in frames/s.

E1 is a standard example: 8 kHz frames, 32 slots, 8 bits per slot. Rb = 32 × 8 × 8000 = 2.048 Mbit/s. Thirty slots carry speech, slot 0 carries framing and alarms, and slot 16 carries signalling.

TDM is the multiplexing idea. TDMA is multiple access, where users take turns on a shared radio channel. Some syllabi write TDMA for that access method.

Synchronisation, clock recovery and cross-talk

The receiver must know where each frame and slot starts. A single sync bit per frame is a weak marker, because a data bit in the same position can look like sync. Many systems therefore use a longer sync word, sent every frame or spread over a multiframe, to avoid false locking. The clock is recovered from transitions in the received line signal; line coding is covered in Chapter 4.8.

Timing error causes cross-talk. If the receiver samples early, it may read the tail of the previous slot; if it samples late, it may read the start of the next slot. Guard time reduces this. If sync is lost, the receiver may slip by one slot and route channel 1 into channel 2; this is a slot slip (loss of frame alignment). A frame slip is the loss or repetition of a whole frame when the receiver clock drifts.

TDM shares time, not frequency. FDM, covered in Unit 2, gives each signal a band of frequencies for all time. TDM gives each signal the full band for a short slot. The receiver's clock must match the transmitter's clock closely; small drift is corrected by the sync pattern. Large drift cannot be corrected and causes errors.

Worked example

Question. Four 4 kHz signals are sampled at 8 kHz and coded with 8-bit PCM. One synchronisation bit is added per frame. Find the frame duration, bits per frame, and bit rate.

  1. The sampling rate is fs = 8 kHz, so Tf = 1/fs = 1/8000 s = 125 μs.
  2. Each channel sends one 8-bit word per frame. Data bits = 4 × 8 = 32 bits.
  3. Add one sync bit: total bits per frame = 32 + 1 = 33 bits.
  4. Rb = total bits / Tf = 33 / 125 μs = 264,000 bit/s = 264 kbit/s. Equivalently Rb = (4×8 + 1) × 8000 = 264 kbit/s.
  5. One bit lasts 125 μs / 33 = 3.79 μs, so an 8-bit slot lasts 30.3 μs.

Answer. Tf = 125 μs, 33 bits per frame (32 data plus 1 sync), and Rb = 264 kbit/s.

Exam traps

  • Frame rate is fs, not Rb. A 264 kbit/s stream with 33 bits per frame still has 8000 frames/s.
  • Do not forget sync bits, alarm bits or a signalling slot. Use (N n + S) fs, not N n fs.
  • TDM shares time; FDM shares frequency. TDMA is multiple access, not the same word as TDM.
  • Slot duration and bit duration differ. In the example an 8-bit slot is 30.3 μs, while one bit is 3.79 μs.
  • Keep units: 125 μs = 125 × 10⁻⁶ s (or 125 × 10-6 s); 264,000 bit/s = 264 kbit/s = 0.264 Mbit/s.

4.8 Line coding: NRZ, RZ, Manchester and their spectra

Line coding is the rule that turns a PCM bit stream into voltage or current levels on a baseband link. It exists because the receiver must recover both bits and timing from a waveform that may pass through cables, transformers and AC-coupled circuits. NRZ, RZ and Manchester are the three basic schemes; they trade DC content, clock recovery and spectral width. You meet them in PCM links, TDM backplanes and legacy Ethernet.

You need: Chapter 4.4 PCM bit stream and Chapter 4.7 TDM; Unit 5 pulse shaping and Nyquist bandwidth.

Mapping bits to line levels

Line code maps each bit, or group of bits, to a level for one bit duration Tb. Rb = 1/Tb is the bit rate in bit/s. V is a fixed peak level in volts.

Three families. Unipolar uses 0 and +V. Polar uses +V and −V. Bipolar (AMI) uses +V, 0 and −V, and alternates the sign for successive 1s.

NRZ means no return to zero: the level lasts the full Tb. Unipolar NRZ sends 1 = +V, 0 = 0. Polar NRZ-L sends 1 = +V, 0 = −V. NRZ-I changes level at the start of a 1 and keeps level for a 0; data sits in transitions, not absolute level.

RZ returns to zero in the second half of every bit. Polar RZ sends 1 = +V then 0, 0 = −V then 0. Unipolar RZ sends 1 = +V then 0, 0 = 0 then 0.

Manchester splits each bit into two halves with opposite levels. With 1 = low-to-high and 0 = high-to-low, every bit has a centre transition. Some syllabi call it biphase or split-phase. Differential Manchester always has the centre transition; the start-of-bit transition, present or absent, carries the data. It is also called CDP.

For 10110, polar NRZ is +V, −V, +V, +V, −V; RZ adds a zero in each second half; Manchester is low-high, high-low, low-high, low-high, high-low.

Spectra and first nulls

Power spectral density (PSD) shows how signal power spreads over frequency. For equally likely polar NRZ with rectangular pulses, pNRZ(f) = V2 Tb sinc2(f Tb), where pNRZ(f) is the PSD in W/Hz, V is the peak level in volts, Tb is the bit duration in seconds, f is frequency in Hz, and sinc(x) = sin(πx)/(πx). The first null is at f = 1/Tb = Rb. The main lobe runs from 0 to Rb.

Unipolar NRZ has a similar sinc² shape but also a discrete component at DC, because its mean level is not zero. Polar NRZ has zero mean only when 1 and 0 are equally likely and levels are symmetric.

RZ uses a pulse of width Tb/2, so its first null is at 2Rb. Manchester uses two half-bit levels; its PSD contains a half-bit sinc² factor multiplied by sin²(πfTb/2), which forces zero at DC for equal bits. Its first null is at 2Rb, and the symbol rate is 2Rb. Differential Manchester has the same bandwidth.

Bandwidth efficiency: NRZ gives the narrowest main lobe for a given Rb. RZ and Manchester need about twice the bandwidth. A full PSD derivation from the autocorrelation is advanced; only a few universities teach it.

Clock recovery and choice

The receiver needs a clock at Rb to sample each bit at its centre. A clock-recovery circuit, often a phase-locked loop, locks to transitions in the received waveform. Long runs of 1s or 0s in NRZ have no transitions, so the clock can drift and bits slip.

RZ returns to zero every bit, so it supplies a transition. Manchester supplies a guaranteed centre transition every bit, so it is self-synchronising. Differential Manchester also has a centre transition every bit. Manchester is used where the clock must be recovered through AC coupling, because every bit has a centre transition. Where the pair may be swapped (polarity inversion), differential Manchester is the safer choice: its data lives in the start-of-bit transition, so inverted wires give the same bits, while plain Manchester would read them inverted.

The cost is bandwidth and symbol rate. Manchester needs two half-bit levels per bit, so it is less bandwidth-efficient than NRZ. NRZ has the narrowest main lobe but needs scrambling or framing to break long runs. RZ and Manchester both cost about twice the bandwidth; RZ buys one transition per bit, Manchester buys a guaranteed centre transition and zero DC. See Unit 5 for pulse shaping and intersymbol interference.

Worked example

Question. A binary sequence 1 0 1 1 0 is sent at 1 kbit/s. Find the bit duration and the first spectral null of polar NRZ, RZ and Manchester. State which code has no DC and self-clocking. Use the convention 1 = low-to-high, 0 = high-to-low for Manchester.

  1. Rb = 1 kbit/s = 1000 bit/s.
  2. Tb = 1/Rb = 1/1000 s = 0.001 s = 1 ms.
  3. Polar NRZ first null: f1 = 1/Tb = 1/0.001 = 1000 Hz = 1 kHz.
  4. RZ first null: f2 = 2/Tb = 2/0.001 = 2000 Hz = 2 kHz.
  5. Manchester uses two half-bit levels per bit, so symbol rate = 2Rb = 2000 symbol/s; first null f3 = 2/Tb = 2000 Hz = 2 kHz.
  6. Manchester has equal positive and negative halves for any data pattern, so zero DC; it has a centre transition every bit, so it is self-clocking. Polar RZ is also DC-free for equally likely bits and gives one transition per bit; Manchester is singled out because it is DC-free for any data pattern and its centre transition is guaranteed whatever the bits.

Answer. The bit duration is 0.001 s (1 ms); the first nulls are 1000 Hz (1 kHz) for polar NRZ and 2000 Hz (2 kHz) for RZ and Manchester; Manchester is the code asked for: it is DC-free for any data pattern and self-clocking. Polar RZ is also DC-free for equally likely bits and gives one transition per bit.

Exam traps

  • For Manchester the symbol rate is 2Rb because each bit has two half-bit levels; the first null is 2Rb, not Rb.
  • Long runs of 1s or 0s in NRZ cause clock loss; RZ and Manchester restore transitions at a bandwidth cost.
  • Do not call unipolar NRZ DC-free: for equally likely bits its mean is V/2, so it has a DC component.
  • NRZ-I is not NRZ-L: NRZ-I stores data in transitions, NRZ-L in absolute level. Differential Manchester is not plain Manchester: data is in the start transition, not the centre-transition direction.

Takeaways

  1. Sampling at fs ≥ 2fm keeps all information; sampling slower folds high frequencies down as aliasing and the loss cannot be undone.
  2. PAM, PWM and PPM all carry the message on a pulse train; PAM is easiest to build, PWM and PPM trade bandwidth for noise immunity.
  3. Uniform quantization gives equal steps and error power Δ²/12; the SNR falls by 6 dB for every halving of signal amplitude.
  4. Companding bends the step sizes so quiet talkers get as good an SNR as loud ones, which is why telephony uses μ-law or A-law.
  5. PCM bit rate is fs·n, so 8 kHz sampling with 8 bits gives 64 kbit/s, the standard telephone channel.
  6. DPCM and ADPCM send prediction error instead of the sample, and correlated speech makes that error much smaller than the sample.
  7. Delta modulation is a 1-bit DPCM with a two-level quantizer; adaptive step size is what makes it usable on real speech.
  8. TDM shares one link by giving every channel a fixed repeating slot, and the frame rate must equal the sampling rate.
  9. Line codes trade DC content, clock recovery and bandwidth: Manchester is DC-free and self-clocking but needs twice the bandwidth of NRZ.

Remember Compare PAM, PWM and PPM on the message-carrying parameter, pulse amplitude, pulse width, bandwidth needed and noise immunity. 10 marks

Understand Derive the quantization noise power Δ²/12 for a uniform quantizer and hence write the output SNR for a full-scale sinusoid. 10 marks

Apply

Apply A speech signal is bandlimited to 3.4 kHz and sampled at 8 kHz with 8-bit uniform PCM. Find the bit rate, the first-null bandwidth and the SNR in dB for a full-scale sinusoid. 10 marks

Rb = fs·n = 8000 × 8 = 64 kbit/s; Nyquist rate 6.8 kHz < 8 kHz so no aliasing; Bandwidth ≈ Rb/2 = 32 kHz for a polar NRZ null-to-null; SNR = 1.5 × (2⁸)² = 1.5 × 65536 ≈ 98,304 → about 50 dB; Quick rule: SNR ≈ 6n + 1.8 dB.

Apply Sixteen PCM channels, each sampled at 8 kHz with 8 bits per sample, are time division multiplexed. Find the frame duration, the slot width and the line bit rate, and say how much guard time you would keep. 10 marks

Frame duration = 1/fs = 125 µs; Bits per frame = 16 × 8 = 128 bits; Rb = 128/125 µs = 1.024 Mbit/s; Slot width = 125 µs/16 = 7.8125 µs; Slot holds 8 bits; a small guard time or one sync bit per frame absorbs jitter; Add synchronisation bits and recompute if asked.

Apply A 4 kHz lowpass signal is sampled at 6 kHz. A 3 kHz interferer is present at the input. Find the alias frequency and state the design change that removes it. 8 marks

fs = 6 kHz, so fs/2 = 3 kHz; the interferer sits exactly at the fold point; Any tone at f > fs/2 folds to fs − f; a tone at 3 kHz maps to 3 kHz (fold point); Use a second example, e.g. a 5 kHz tone folding to 6 − 5 = 1 kHz; Place an anti-alias lowpass at about 3 kHz before the sampler; Raising fs also helps but costs bit rate.

Apply For an 8-bit PCM system with a full-scale range of ±2 V, find the step size, the maximum quantization error and the noise power, and compare with a 12-bit system. 10 marks

L = 256, total range 4 V, Δ = 4/256 = 15.6 mV; Maximum error = Δ/2 = 7.8 mV; Noise power = Δ²/12 ≈ 2.03 × 10⁻⁵ W, i.e. 20.3 µW; 12 bits: Δ = 4/4096 ≈ 0.98 mV, noise power ≈ 7.9 × 10⁻⁸ W; Every extra bit is 6 dB better SNR.

Apply Sketch the waveforms of NRZ-L, RZ, Manchester and differential Manchester for the bit stream 1 0 1 1 0 0 1 and comment on clock recovery and DC content. 12 marks

NRZ-L: level held for the full bit, level change only on data change; RZ: pulse in the first half of the bit, zero for the second half; Manchester: mid-bit transition, low-to-high for 1, high-to-low for 0 (state convention); Differential Manchester: data in the presence or absence of a start-of-bit transition, always a mid-bit transition; Manchester and RZ have a spectral line at the bit rate, so clock recovery is easy; Manchester and RZ have little DC; NRZ can drift.

Analyze and evaluate

Analyze Compare PCM, DPCM and delta modulation for speech on the basis of bit rate, complexity, SNR and behaviour on quiet passages. 12 marks

PCM at 64 kbit/s gives about 6n dB SNR and is simple but wasteful on redundancy; DPCM saves 2 to 4 bits per sample at equal quality; DM at 1 bit per sample needs a high clock (tens of kHz) and shows slope overload and granular noise; ADPCM and ADM solve the quiet-signal problem by adapting the step; Complexity order: DM < DPCM < ADPCM < PCM with companding; Recommend by application: telephony uses companded PCM or ADPCM, local links use DM.

Evaluate Explain why companding is used in speech PCM. Draw the μ-law and A-law compression curves and compare the SNR for weak and strong talkers. 12 marks

Uniform PCM SNR falls by 6 dB each time signal amplitude halves, so quiet talkers get poor quality; Companding gives small amplitudes fine steps and large amplitudes coarse steps; μ-law: y = sgn(x)·ln(1 + μ|x|)/ln(1 + μ), μ = 255 in North America and Japan; A-law: piecewise linear, A = 87.6, used in Europe and much of the world; Quantization noise becomes roughly proportional to signal power, so SNR stays near-constant over a wide range; Cost: extra hardware or software, and a slight idle-channel noise floor.

Analyze Design a TDM-PCM system for 30 telephone channels. Choose sampling rate, bits per sample, frame structure with synchronisation, and line bit rate; discuss guard time and timing jitter. 13 marks

fs = 8 kHz, frame = 125 µs, 8 bits per channel; 30 voice channels plus one sync channel gives 31 slots, 8 bits each = 248 bits per frame; Rb = 248/125 µs ≈ 1.984 Mbit/s; rounding to 2.048 Mbit/s is the standard E1 figure; Slot width = 125/32 = 3.9 µs when a 32-slot frame is used; Guard time absorbs jitter between multiplexer and demultiplexer clocks; Sync word must be chosen to avoid false locking; discuss jitter accumulation with many repeaters.

Glossary

A-law
Piecewise-logarithmic companding law with A = 87.6 used in European and many other telephone networks.
Adaptive step
A step size that grows when the encoder makes repeated same-direction decisions and shrinks when it alternates.
Aperture effect
Slight amplitude droop caused by holding the sample over the pulse width, corrected by a sinc equaliser.
Bipolar line code
Three-level code in which successive marks alternate in polarity (also called AMI).
Bit rate
The number of bits sent per second, in bits per second (bit/s).
Code word
The n-bit binary number that represents one quantized sample in PCM.
Flat-top sampling
PAM in which each pulse is a rectangle whose height equals the sample; needs an equaliser for the aperture effect.
Fold-over frequency
fs/2, the highest frequency a sampler can represent without aliasing.
Idle channel noise
The granular noise heard when the input is silent in delta modulation or DPCM.
Natural sampling
PAM in which the pulse keeps the shape of the original waveform during the on time.
Non-uniform quantization
Quantization whose steps are small near zero and large at high amplitude.
Nyquist bandwidth
The minimum baseband bandwidth Rb/2 needed to send Rb bits per second without intersymbol interference.
Polar line code
Line code that uses both positive and negative levels, so the average is zero for balanced data.
Prediction error
The difference between the actual sample and the value predicted from earlier samples; this is what DPCM sends.
Predictor
A filter that forms the estimate of the current sample from a weighted sum of past reconstructed samples.
Quantizer
A device that maps a continuous range of sample values onto L discrete output levels.
Regenerative repeater
A PCM receiver-transmitter pair that decides each bit and retransmits a clean pulse, so noise does not accumulate.
Sampling
Converting a continuous-time signal into a sequence of values taken at instants spaced Ts = 1/fs apart.
Self-clocking code
A line code whose waveform always contains transitions from which the receiver can recover the bit clock.
Step size
The gap Δ between two neighbouring quantization levels.
Synchronisation word
A fixed bit pattern in each TDM frame that lets the receiver find the slot boundaries.
TDM frame
One complete set of time slots, one per channel, repeated every 1/fs seconds.
Unipolar line code
Line code that uses one polarity and zero, so it has a non-zero average and a DC component.
μ-law
Logarithmic companding law with μ = 255 used for speech PCM in North America and Japan.
