6.1 Ideal op-amp, virtual ground and open-loop characteristics

An op-amp is a differential amplifier with enormous gain. A few microvolts between its inputs slam the output against a supply rail. So we define an ideal op-amp — infinite gain, infinite input resistance, zero output resistance — and use it only with negative feedback. Feedback forces the two inputs to almost the same voltage (the virtual short), and the inputs draw no current. These rules turn transistor circuits into resistor arithmetic and underlie every amplifier, filter, integrator and converter in this unit.

You need: the differential pair, common-mode gain, offset, bias current and slew rate from Unit 5, and negative feedback and loop gain from Unit 4, Feedback Amplifiers and Oscillators.

The ideal op-amp and its five promises

An op-amp has two inputs and one output. The output responds only to the difference between the input voltages, not to their common value. The non-inverting input is v₊ and the inverting input v₋, both measured to ground.

v_d = v₊ − v₋

v_d is the differential input voltage in volts; v₊ and v₋ are the input pin voltages in volts, each to ground.

v_out = AOL · v_d

v_out is the output voltage in volts; AOL is the open-loop gain, a pure number, measured with no feedback; v_d is the differential input in volts.

An ideal op-amp pushes five properties to their limits: infinite open-loop gain AOL; infinite input resistance Rin; zero output resistance Ro; infinite bandwidth, so gain and zero phase shift hold at every frequency; and zero offset, zero drift and zero bias current. Some syllabi call this the IOA model.

The model is a controlled source AOL·v_d at the output, with Rin across the inputs and Ro in series. Infinite Rin means no current enters either pin. Zero Ro means the output does not sag under load. Both keep the design equations linear, so gain is set by resistor ratios alone.

The open-loop characteristic and saturation

Plot v_out vertically against v_d. You get a straight line through the origin with slope AOL, and the line flattens at the supply rails. The output can never exceed the supplies, so it saturates about 1 V inside them: with ±12 V supplies the flat top sits near +11 V and the flat bottom near −11 V.

The steep straight part is the linear region, and its width is tiny.

width of linear strip = 2V<sub>sat</sub> / A<sub>OL</sub>

Vsat is the saturation output magnitude in volts, roughly supply minus 1 V; AOL is the open-loop gain, a pure number; the result is in volts and is the total span of v_d that keeps the output linear.

Take Vsat = 11 V and AOL = 2 × 10⁵. The strip is 22 / (2 × 10⁵) = 110 µV, that is ±55 µV. One millivolt of input is twenty times too big. So an op-amp is useless as a linear amplifier with no feedback: you cannot hold the input difference that steady. Used deliberately without feedback, the same device is a comparator giving one rail or the other, covered in 6.9.

Negative feedback changes the picture. The feedback network returns a fraction of the output to v₋, so v_d only has to supply the small difference between the input and that fraction. The operating point slides back into the steep region and stays there.

Virtual short and virtual ground

Split the output equation into its two factors.

v_d = v_out / AOL

v_d is the differential input in volts; v_out is the output in volts; AOL is the open-loop gain.

If the output is 5 V and AOL is 10⁵, v_d is only 50 µV. Per volt at the output you need just 10 µV at the input. So while the output is inside the linear range, the two inputs sit at almost the same voltage: v₊ ≈ v₋. This is the virtual short. It is a voltage condition only. The pins are not wired together, and since Rin is infinite the current between them is zero.

When v₊ is tied to ground, the rule says v₋ also sits at 0 V even though that pin is not grounded. This is the virtual ground, the engine of the inverting amplifier in 6.2, the summing amplifier in 6.3, the integrator in 6.5 and the voltage-to-current converter in 6.6.

Two conditions must both hold: negative feedback must be present, and the computed output must lie between the supply rails. Run this check first.

  1. Trace a path from the output pin back to an input pin.
  2. Confirm it returns to v₋. A path to v₊ is positive feedback and gives no virtual short.
  3. Solve assuming v₊ = v₋ and check the answer lies inside the saturation limits.
  4. If outside, the op-amp is saturated and v_out is fixed at the rail.
  5. Then set both input currents to zero and solve the resistor network with Ohm's and Kirchhoff's laws.

Break either condition and the rule dies. Positive feedback gives no virtual short, and the two thresholds are set by the resistors instead (see 6.9). A circuit whose ideal output would be 20 V on ±12 V supplies is simply saturated at +11 V, and the input difference is no longer near zero.

Worked example

Question. An op-amp has an open-loop gain AOL = 2 × 10⁵ and runs on ±12 V supplies, saturating about 1 V inside each rail. (a) Find the output for v_d = 100 µV. (b) Find the largest v_d that still keeps the amplifier in its linear region.

  1. Convert the input to volts: v_d = 100 µV = 100 × 10⁻⁶ V = 1 × 10⁻⁴ V.
  2. Apply the open-loop law: v_out = AOL · v_d = (2 × 10⁵) × (1 × 10⁻⁴) = 20 V.
  3. The rails are ±12 V, so the output cannot pass about +11 V.
  4. 20 V > 11 V, so the amplifier saturates. The actual output is v_out = +11 V, not 20 V.
  5. For (b), the edge of the linear region is where AOL · v_d,max = Vsat.
  6. So v_d,max = Vsat / AOL = 11 / (2 × 10⁵) = 5.5 × 10⁻⁵ V = 55 µV.
  7. The full linear strip is twice this, 110 µV wide. Any differential input larger than 55 µV drives this op-amp into saturation when it is used open loop.

Answer. For v_d = 100 µV the ideal output is 20 V, so the amplifier saturates at about +11 V; the largest input that keeps it linear is 55 µV.

Exam traps

  • Writing v₊ = v₋ for an open-loop or positive-feedback circuit. The virtual short holds only while negative feedback keeps the output inside the linear range.
  • Treating the virtual short as a wire. No current flows between the input pins, but the resistor currents around them are certainly not zero.
  • Reporting the ideal output when it is beyond the rails. A computed 20 V on ±12 V supplies must be corrected to about +11 V.
  • Unit slips between microvolts and volts: 100 µV is 1 × 10⁻⁴ V, not 1 × 10⁻⁶ V. A factor of 100 in v_d becomes a factor of 100 in v_out.
  • Assuming ideal infinite bandwidth means the real gain stays at AOL at every frequency. Open-loop gain rolls off with frequency, as covered in Unit 3.

Beyond the syllabus

Not for the exam. Real design starts where the ideal model stops: offset voltage becomes a systematic error that must be trimmed or auto-zeroed, and bias current turns into an offset through your feedback resistors. Chopper-stabilised and zero-drift op-amps cancel offset continuously, which is why they suit medical instrumentation and load-cell weighing. The same ideal rules apply to the operational transconductance amplifier, whose output is a current g_m·v_d, and to fully differential op-amps with a common-mode feedback loop.

6.2 Inverting and non-inverting amplifiers; voltage follower

An op-amp with two resistors sets a precise gain. In the inverting amplifier, R₁ feeds a virtual ground and R_f returns from the output, so v_out = −(R_f/R₁)v_in. In the non-inverting amplifier, the input goes to the + terminal, so v_out = (1 + R_f/R₁)v_in and the input draws almost no current. The voltage follower is the non-inverting case with R₁ open: gain 1, very high input resistance, low output resistance. These circuits buffer sensors, set audio gain and isolate reference dividers.

You need: Chapter 6.1 for the ideal model and virtual ground, and Unit 4 for negative feedback.

Inverting amplifier

The inverting amplifier grounds the + input and places R₁ between the source and the − input, with R_f from output to − input. Negative feedback forces the − input to the same 0 V as the + input. That point is a virtual ground: it sits at 0 V but the op-amp does not sink current there.

The input current is i = v_in/R₁. The op-amp input draws no current, so the same i must flow through R_f. The output must supply v_out = 0 − iR_f = −(R_f/R₁)v_in. The minus sign means inversion.

A_v = v_out / v_in = −R_f / R₁

A_v is the voltage gain; R_f is the feedback resistor from output to the inverting input; R₁ is the input resistor from source to the inverting input.

  • Input resistance is exactly R₁ because the inverting node is at 0 V.
  • Keep R₁ above about 1 kΩ to avoid loading the source.
  • Choose R_f = |A_v|R₁ and keep R_f below about 1 MΩ.
  • For bias-current balance, add R_comp = R₁ parallel R_f from the + input to ground.

Non-inverting amplifier and voltage follower

The non-inverting amplifier connects v_in to the + input and uses a divider: R_f from output to − input, R₁ from − input to ground. Negative feedback makes v₋ = v_in. The current in R₁ is v_in/R₁, and the same current flows in R_f because the op-amp input draws none. The output is v_out = v_in + iR_f = (1 + R_f/R₁)v_in.

A_v = v_out / v_in = 1 + R_f / R₁

R_f is the feedback resistor from output to the inverting input; R₁ is the resistor from the inverting input to ground; A_v is always at least 1.

The input resistance is set by the op-amp and is very high; the output resistance is low. The gain cannot be less than 1.

The voltage follower, also called a buffer or unity-gain amplifier, is this circuit with R₁ open and R_f = 0. Then v_out = v_in. It gives no voltage gain but gives current gain: a weak sensor can drive a heavy load, and a divider is not loaded by the next stage.

Design, cascading and real limits

For a target non-inverting gain G, pick R₁ between about 1 kΩ and 100 kΩ, then R_f = (G − 1)R₁, keeping R_f below about 1 MΩ. For an inverting gain −G, use R_f = G R₁. Add the compensating resistor only when bias-current error matters. Cascade two stages by multiplying their gains; the sign of each stage also multiplies.

Finite open-loop gain A_OL makes the closed-loop gain slightly smaller than ideal. The fractional error is about (1 + R_f/R₁)/A_OL for both connections. A gain of 10 with A_OL = 10⁵ has about 0.011 % error; a gain of 100 has about 0.1 %. More open-loop gain buys more accuracy.

The inverting input resistance is R₁; the non-inverting input resistance is the op-amp input resistance, usually very high. Output resistance is the op-amp output resistance divided by roughly (1 + loop gain), so it is low. Stray capacitance at the inverting node causes peaking; keep R_f modest or add a small feedback capacitor. Closed-loop frequency response is covered in Unit 3.

Worked example

Question. An inverting amplifier uses R₁ = 10 kΩ and R_f = 100 kΩ with v_in = 0.2 V. Find the ideal gain, output and input current. Repeat for the non-inverting connection with the same resistors. For the inverting circuit, take A_OL = 10⁵ and estimate the actual gain and its percentage error.

  1. Inverting ideal gain: A_v = −R_f/R₁ = −100 kΩ / 10 kΩ = −10.
  2. Inverting output: v_out = A_v v_in = −10 × 0.2 V = −2 V.
  3. Input current: i = v_in/R₁ = 0.2 V / 10 kΩ = 20 µA. The same 20 µA flows in R_f.
  4. Non-inverting gain: A_v = 1 + R_f/R₁ = 1 + 100 kΩ / 10 kΩ = 11.
  5. Non-inverting output: v_out = 11 × 0.2 V = 2.2 V.
  6. Finite A_OL: loop factor is 1 + R_f/R₁ = 11, so gain ≈ −10 / (1 + 11/10⁵) = −9.9989.
  7. Magnitude error = (10 − 9.9989)/10 × 100 = 0.011 %.

Answer. The inverting amplifier gives gain −10 and output −2 V with 20 µA input current; the non-inverting amplifier gives gain 11 and output 2.2 V; finite A_OL lowers the inverting magnitude to 9.9989, an error of 0.011 %.

Exam traps

  • Using R_f/R₁ for the non-inverting gain. The correct non-inverting gain is 1 + R_f/R₁; the extra 1 is the input signal itself.
  • Calling the inverting input a high-resistance node. The source sees R₁ to a virtual ground, so input resistance is R₁.
  • Dropping the minus sign in the inverting gain, or expecting a negative output from the non-inverting circuit.
  • Leaving R₁ in place for a voltage follower. The follower is the non-inverting case with R₁ open and R_f = 0, so gain is 1.
  • Choosing R_f above about 1 MΩ or R₁ below about 1 kΩ without reason; bias current, stray capacitance and source loading grow.

6.3 Summing and difference amplifiers

A summing amplifier adds several voltages into one output. The inverting summer sends each input through its own resistor to a virtual ground, so their currents add and one feedback resistor turns the total back into a voltage. A difference amplifier subtracts one input from another using four resistors. These circuits mix audio, shift voltage levels, read bridge sensors and remove offsets. The key is the resistor matching condition; resistor tolerance sets the real rejection.

You need: Chapter 6.1 (virtual ground and ideal op-amp), Chapter 6.2 (inverting and non-inverting gains), and superposition from basic circuit theory.

Inverting summer: currents add at a virtual ground

The inverting summer has n inputs v₁ to vₙ, each through its own resistor R₁ to Rₙ to the inverting input. The non-inverting input is grounded. The feedback resistor R_f returns the output to the inverting input. Negative feedback holds the inverting node at 0 V, a virtual ground (Chapter 6.1). The op-amp input draws no current, so all input current flows through R_f.

Each input current is i_k = v_k/R_k. KCL at the virtual ground gives Σ i_k + v_out/R_f = 0, so:

v_out = −R_f (v₁/R₁ + v₂/R₂ + … + vₙ/Rₙ)

R_f is the feedback resistor in ohms; R_k and v_k are the k-th input resistor in ohms and input voltage in volts; v_out is the output in volts.

This is a weighted sum: a large v_k or a small R_k gives a large contribution. With equal input resistors R, the output is −(R_f/R)(v₁ + … + vₙ). Set R_f = R/n to get the negative average. Set binary weights, such as R, R/2 and R/4, to make a simple DAC; see Unit 7 for full DAC design.

Non-inverting summer and the subtractor

A non-inverting summer feeds the inputs through resistors to the non-inverting input. A resistor R_g from that node to ground and the feedback divider R_f, R₁ set the gain. Superposition gives v₊ = (Σ v_k/R_k)/(Σ 1/R_k + 1/R_g) and v_out = (1 + R_f/R₁)v₊. Most designers choose the inverting summer because its summing node is a true 0 V virtual ground. The op-amp inputs then see no common-mode voltage. The non-inverting summer has a signal-dependent common-mode voltage and needs matched resistors.

The subtractor uses four resistors. v₁ drives R₁ to the inverting input; R_f feeds back from the output to that node. v₂ drives R₂ to the non-inverting input; R₃ goes from that node to ground. Derive by superposition.

  1. Set v₂ = 0. The non-inverting node is at 0 V. The circuit is an inverting amplifier: v_out1 = −(R_f/R₁)v₁.
  2. Set v₁ = 0. The non-inverting node is v₊ = v₂R₃/(R₂ + R₃). The gain to the output is 1 + R_f/R₁, so v_out2 = (1 + R_f/R₁)v₂R₃/(R₂ + R₃).
  3. Add the outputs. If R₃/R₂ = R_f/R₁ = k, then R₃/(R₂ + R₃) = k/(1 + k) and 1 + R_f/R₁ = 1 + k. The product is k, so v_out = k(v₂ − v₁).

v_out = (R_f/R₁)(v₂ − v₁) when R₃/R₂ = R_f/R₁

R_f, R₁, R₂ and R₃ are in ohms; v₁, v₂ and v_out are in volts. The ratio condition makes the common-mode terms cancel.

Resistor tolerance and practical uses

The subtractor removes a common voltage only when its resistor ratios match. Let t be the fractional tolerance, for example t = 0.01 for 1 % resistors. Mismatch makes the common-mode gain nonzero. A useful worst-case estimate is CMRR ≈ 1/(4t). For 1 % resistors, CMRR ≈ 1/(4 × 0.01) = 25, which is 20 log₁₀ 25 ≈ 28 dB. That is poor when a small signal sits on a large common-mode voltage.

CMRR ≈ 1/(4t), CMRR_dB = 20 log₁₀(1/(4t))

t is fractional tolerance (0.01 for 1 %); CMRR is differential gain divided by common-mode gain; CMRR_dB is that ratio in decibels.

Trim one resistor or use a matched network for exact ratios. In a bridge measurement, the subtractor keeps the small difference between the two bridge outputs. In a sensor circuit, it removes a fixed offset before the ADC. Audio mixers use the inverting summer to add channels. Level shifting adds or subtracts a DC voltage. In the subtractor the op-amp offset voltage appears at the output multiplied by the noise gain 1 + R_f/R₁. In an n-input inverting summer the same offset is multiplied by 1 + R_f/R_eq, where R_eq = R₁∥R₂∥…∥Rₙ, so keep R_f no larger than needed. Neither gain is the signal gain.

Worked example

Question. An inverting summer has R_f = 10 kΩ with v₁ = 1 V through R₁ = 10 kΩ, v₂ = 0.5 V through R₂ = 20 kΩ, and v₃ = 0.2 V through R₃ = 4 kΩ. Find v_out. Next, a subtractor has R₁ = R₂ = R₃ = R_f = 10 kΩ, v₁ = 2 V at the inverting input and v₂ = 1.5 V at the non-inverting input; find v_out.

  1. The inverting input is a virtual ground at 0 V. The input currents are i₁ = 1 V / 10 kΩ = 100 µA, i₂ = 0.5 V / 20 kΩ = 25 µA, and i₃ = 0.2 V / 4 kΩ = 50 µA.
  2. All three currents flow into the virtual ground, so the total current through R_f is i_f = 100 µA + 25 µA + 50 µA = 175 µA.
  3. The output is v_out = −i_f R_f = −175 µA × 10 kΩ = −1.75 V.
  4. For the subtractor, the resistor ratios match: R₃/R₂ = 1 and R_f/R₁ = 1. Use v_out = (R_f/R₁)(v₂ − v₁) = 1 × (1.5 V − 2 V) = −0.5 V.

Answer. The inverting summer output is −1.75 V, and the subtractor output is −0.5 V.

Exam traps

  • Dropping the minus sign in an inverting summer. All currents enter the virtual ground, so the output is negative when the inputs are positive.
  • Thinking equal input resistors alone give the average. You also need R_f = R/n to get −(average).
  • Assuming a difference amplifier rejects common-mode perfectly. It does so only when R₃/R₂ = R_f/R₁. With 1 % resistors the worst-case CMRR is about 25, or 28 dB.
  • Using k(v₂ − v₁) for a subtractor without checking the ratio condition. If the four resistors are not matched, a common-mode input also produces an output.
  • Forgetting that op-amp offset voltage is amplified by the noise gain of the circuit (1 + R_f/R₁ for the subtractor, 1 + R_f/R_eq for the summer), not by its signal gain.

6.4 Instrumentation amplifier

An instrumentation amplifier is a difference amplifier with two buffered inputs. Two non-inverting buffers share one resistor R_G, so the differential input appears across R_G and the first stage gives a gain of 1 + 2R/R_G while passing the common-mode voltage at a gain of exactly 1. A second difference amplifier subtracts that common mode. Input resistance is 10⁹ Ω or more and equal on both sides, and CMRR above 100 dB is routine. Strain-gauge load cells in weighing scales, ECG and EEG front ends, thermocouples and shunt current sensing all use it.

You need: 6.1 for the virtual short, 6.2 for the non-inverting gain 1 + R_f/R₁, and 6.3 for the difference amplifier and its resistor-matching limit.

Why one difference amplifier is not enough

The difference amplifier of 6.3 looks like the whole answer: two inputs, one output, common mode removed. Put it straight on a real sensor and two problems appear.

First, it loads the sensor. Each input shunts the source with about R₁ to ground. With R₁ = 10 kΩ and a source resistance of 100 kΩ the divider passes only about 9 % of the signal. Worse, if the two source resistances differ, the two dividers differ, so common-mode noise turns into a false differential signal.

Second, its CMRR is set by resistor tolerance, not by the op-amp. Cancellation needs R₁/R_f to match on both sides. Ordinary 1 % resistors leave roughly 50 dB of CMRR, and raising the gain does not help. A bridge sitting on a 2 V common mode with a 5 mV signal needs far better.

A bridge, a thermocouple or a skin electrode therefore asks for four things: input resistance above 10⁹ Ω, the same resistance on both inputs, gain set by one resistor, and CMRR above 100 dB. The three-op-amp instrumentation amplifier gives all four.

The three-op-amp instrumentation amplifier

A₁ and A₂ are non-inverting amplifiers. Each has a feedback resistor R from its output to its own inverting input. One resistor R_G joins the two inverting inputs. The inputs v₁ and v₂ go to the non-inverting inputs.

By the virtual short of 6.1, the inverting input of A₁ sits at v₁ and that of A₂ at v₂, so the whole difference v₁ − v₂ appears across R_G and the current through it is i = (v₁ − v₂)/R_G.

No current enters an op-amp input, so the same i flows through both R's. From the output of A₂ to the output of A₁ the path crosses R_G and two R's, so the voltage between the two outputs is i(R_G + 2R).

v_o1 − v_o2 = (1 + 2R/R_G)(v₁ − v₂)

v_o1 and v_o2 are the two first-stage outputs in volts; v₁ and v₂ are the input voltages in volts; R is the feedback resistor of each buffer in ohms, equal on both sides; R_G is the gain resistor between the two inverting inputs in ohms.

Set v₁ = v₂ = v_cm. Then i = 0, no voltage drops across the R's, and both outputs sit at v_cm. The common-mode gain of this stage is exactly 1, fixed by the buffers and independent of resistor tolerance.

A₃, the difference amplifier of 6.3, takes the two outputs. Its differential gain is R_f/R₁ and its common-mode gain is near zero when its four resistors match. Multiply the stages:

A_d = (1 + 2R/R_G) × (R_f/R₁)

A_d is the differential gain, a pure number; R and R_G are as above; R_f is the feedback resistor and R₁ the input resistor of the second stage, in ohms, matched on both sides.

The input resistance seen by the sensor is the op-amp input resistance, 10⁹ Ω to 10¹² Ω, the same on both inputs.

Gain, CMRR and where the errors come from

  • Gain setting: most designs fix the second stage at 1 (all four resistors equal) and use R_G as the only knob. For large gain A_d ≈ 2R/R_G, so a 1 % error in R_G gives about 1 % gain error. Use a 0.1 % metal-film resistor for R_G.
  • Design formula: invert the gain equation, R_G = 2R/(A_d R₁/R_f − 1). With A_d = 1000, R = 25 kΩ and a unity second stage, R_G is about 50 Ω — small enough that the resistance of the switch, socket and PCB track adds to it and spoils gain accuracy.
  • CMRR: the input stage passes the common mode at gain 1, so it does not limit the CMRR. The overall CMRR is set by the matching of the second-stage resistors, or in a monolithic part by their on-chip trimming: 100 dB to 120 dB at gain 10. Built from discrete op-amps, the second-stage resistors decide the CMRR however good the op-amps are.
  • Bandwidth: the closed-loop bandwidth is the op-amp gain-bandwidth product divided by A_d (see Unit 3), so gain 1000 on a 1 MHz op-amp leaves about 1 kHz.
  • Two-op-amp version: it saves one op-amp and two resistors, but its inputs are not alike. One is a high-resistance non-inverting input; the other is a resistor to a virtual node. Unequal source resistances then convert common mode into differential error.

Where it is used, and practical points

  • Strain-gauge bridge: four gauges on a beam inside a load cell give a few millivolts on top of a large common-mode level. The in-amp is the first block of a weighing scale.
  • ECG and EEG: skin electrodes have thousands of ohms of source resistance and pick up metres of 50 Hz mains coupling as common mode. The in-amp must not load the electrodes and must reject that mains.
  • Thermocouple: a few tens of microvolts on a slowly drifting common-mode voltage; the in-amp feeds the cold-junction correction and an ADC.
  • Shunt current sensing: a shunt of a fraction of an ohm carries the load current. The in-amp measures the small drop across it while both terminals swing with the motor supply.
  • Practical: keep the two input leads short, equal and twisted together. Drive the cable shield from the common-mode voltage — the midpoint of R_G if R_G is two equal halves, or the average of the two buffer outputs — so the shield moves with the common mode, not with the signal, and cable capacitance is not charged by the signal. Mount R_G close to the chip and return the bridge supply ground to one point.

Worked example

Question. An instrumentation amplifier is built with R = 25 kΩ in each first-stage feedback path, R_G = 1 kΩ, and a second-stage difference amplifier in which all four resistors are 10 kΩ. The differential input is 5 mV riding on a common-mode voltage of 2 V, and the amplifier's CMRR is 100 dB. (a) Find the total differential gain. (b) Find the output caused by the differential part. (c) Find the output error caused by the 2 V common mode.

  1. First stage: 1 + 2R/R_G = 1 + 2(25 kΩ)/(1 kΩ) = 51.
  2. Second stage: R_f/R₁ = 10 kΩ/10 kΩ = 1.
  3. Total differential gain: A_d = 51 × 1 = 51.
  4. Differential part of the output: 51 × 5 mV = 255 mV.
  5. CMRR ratio: 10^(100/20) = 10⁵, so A_cm = A_d/CMRR = 51/10⁵ = 5.1 × 10⁻⁴.
  6. Output error from 2 V of common mode: 2 V × 5.1 × 10⁻⁴ = 1.02 mV, about 0.4 % of the 255 mV wanted signal.

Answer. The total gain is 51, the differential output is 255 mV, and the 2 V common mode adds only about 1.02 mV at the output.

Exam traps

  • Writing the first-stage gain as 1 + R/R_G and losing the factor 2. There are two resistors R, one in each buffer's feedback path.
  • Blaming R_G for poor CMRR. R_G sets the gain; the CMRR is set by the matching of the second-stage resistors, or by the trimming inside a monolithic part.
  • Saying the input stage has zero common-mode gain. It has exactly 1; the whole common-mode voltage appears at both outputs and the difference amplifier removes it.
  • Adding the two stage gains instead of multiplying them. Gains in cascade multiply: A_d = (1 + 2R/R_G)(R_f/R₁).
  • Treating an instrumentation amplifier as just another difference amplifier. The difference is the buffered, equal, gigaohm input resistance and the CMRR above 100 dB.

6.5 Integrator and differentiator

Replace the feedback resistor of an inverting amplifier with a capacitor. The virtual ground holds the input end of the capacitor at 0 V, so the current set by the input resistor charges the capacitor. The output becomes proportional to the integral of the input. Swap the resistor and capacitor and the output becomes proportional to the derivative. These two circuits are analog building blocks for proportional–integral–derivative (PID) controllers, analog computers, waveform shaping, edge detection and charge amplifiers. This chapter gives the ideal formulas, the practical fixes for drift and noise, and the frequency response.

You need: Chapter 6.2 for the inverting configuration and virtual ground, and the capacitor relation i = C dv/dt from basic circuit theory.

Ideal integrator: capacitor in the feedback path

Start from the inverting amplifier in Chapter 6.2. The input resistor R₁ carries i = vin/R₁ into the virtual ground. If the feedback element is a capacitor C, that same current must flow into C. The capacitor relation is i = C d(vC)/dt, and vC = 0 − vout = −vout because the left plate is at virtual ground. Therefore vout = −(1/(R₁C))∫vin dt.

v<sub>out</sub> = −(1/(R₁C))∫₀ᵗ v<sub>in</sub>(τ) dτ + v<sub>out</sub>(0)

vout is the output voltage in volts; vin is the input voltage in volts; R₁ is the input resistor in ohms; C is the feedback capacitor in farads; R₁C is the time constant in seconds; τ is the dummy time variable in seconds.

The product R₁C is the integrator time constant. A positive step of height V gives a negative ramp: vout = −(V/(R₁C))t. A square wave gives a triangle wave. The circuit is called an integrator because the output at time t is the area under the input up to t, scaled by −1/(R₁C).

In the frequency domain the gain magnitude is 1/(ωR₁C), where ω = 2πf is angular frequency in rad/s. Above the corner f = 1/(2πR₁C) the gain falls at 20 dB per decade. A differentiator has the opposite slope: its gain rises at 20 dB per decade and crosses 0 dB at the same frequency. The figure uses R₁C = 100 µs, so the crossing is about 1.6 kHz.

Practical integrator: stopping DC drift

An ideal integrator has infinite DC gain. Any op-amp offset voltage or input bias current then charges C without limit, and the output walks to a supply rail. Add a resistor Rf in parallel with C. At DC the capacitor is open, so the gain is only −Rf/R₁. The circuit now integrates only above fc = 1/(2πRfC); below fc it behaves as an inverting amplifier.

ADC = −Rf/R₁

ADC is the closed-loop gain at zero frequency in V/V; Rf is the feedback resistor in ohms; R₁ is the input resistor in ohms.

Choose Rf large enough not to spoil the integration band but small enough to hold the offset. Add a bias-current compensation resistor from the non-inverting input to ground. Its value is Rcomp = R₁ || Rf, where || means the parallel combination. At DC this equalises the resistance seen by both inputs, so the bias currents produce nearly the same voltage drop.

Some syllabi call a non-inverting high-input-resistance version a Deboo integrator; it uses a resistor bridge and a capacitor, so the source does not drive R₁ to ground. A charge amplifier is the same idea: a current input flows into C and the output is −q/C, where q is the charge in coulombs; it measures charge from a piezoelectric sensor.

Differentiator: capacitor at the input

Swap R and C. The input capacitor C feeds the virtual ground, and the feedback resistor R converts the current into voltage. The capacitor current is i = C dvin/dt, so vout = −R C dvin/dt. A triangle input gives a square output because the slope is constant and changes sign at each peak. A sine input gives a cosine output, shifted by 90°.

vout = −R C (dvin/dt)

vout is the output voltage in volts; R is the feedback resistor in ohms; C is the input capacitor in farads; dvin/dt is the input slope in volts per second.

The ideal differentiator gain rises with frequency without limit. High-frequency noise, stray capacitance and the op-amp's finite gain-bandwidth product (GBP) then dominate; the output can look like noise or oscillate. Add a series resistor R₁ with C. The high-frequency gain is capped at −R/R₁, and the differentiator works below f = 1/(2πR₁C). Add a small capacitor Cf across R to roll off the gain further.

Use these circuits in PID controllers, analog computers, waveform shaping, edge detection and charge amplifiers. In a PID loop the integrator removes steady error and the differentiator reacts to fast changes. In edge detection a differentiator turns a slow logic transition into a short pulse.

6.6 Voltage-to-current and current-to-voltage converters

A voltage-to-current converter turns an input voltage into a current that the load cannot change. The op-amp holds a fixed voltage across a resistor R, so Ohm's law fixes the current through R, and that same current must flow through the load. The reverse circuit, the current-to-voltage converter, pins its input at zero volts and turns an input current into a proportional output voltage. Both sit inside LED drivers, 4–20 mA transmitters, photodiode receivers and DAC output stages, wherever current is the quantity that matters.

You need: Chapter 6.1 for the virtual short and saturation, Chapter 6.2 for the inverting configuration, and Ohm's law.

Floating load: current set by R

Many loads want a set current, not a set voltage. An LED's brightness, the pull of a coil and the signal in a 4–20 mA loop all follow current. Drive them from a voltage divider and the current changes the moment the load resistance changes. A voltage-to-current converter removes that dependence.

Connect the input voltage vin to the non-inverting input. Put resistor R from the inverting input to ground. Put the load RL from the op-amp output back to the inverting input. The load floats: neither of its ends is at ground.

Negative feedback gives a virtual short, so the inverting input sits at vin (see Chapter 6.1). The op-amp inputs draw no current, so every ampere that flows through R must arrive through the load. The voltage across R is vin, so the load current is vin/R.

IL = vin / R

vin is the input voltage in volts (V), R is the sense resistor in ohms (Ω), and IL is the load current in amperes (A).

The current depends on vin and R alone. Change RL and the op-amp moves its output instead: vout = vin + ILRL = vin(1 + RL/R). The bottom of the load rides at vin, which is why it must float. LED and laser diode drivers use this circuit directly, because light output follows current.

Grounded load: the Howland current pump

A floating load is awkward. Many sensors and LEDs need one end at ground. The Howland current pump drives a grounded load. It places the sense resistor R in series with the load and compares the drop across R with vin, using a bridge of four resistors R1 to R4. When the bridge ratios match, R1/R2 = R3/R4, the op-amp drives its output until that drop equals vin.

The load current is again vin/R, and the output is vin plus the load voltage. Raise RL and the output rises; the current stays.

I<sub>L</sub> = v<sub>in</sub> / R,   v<sub>out</sub> = v<sub>in</sub> + I<sub>L</sub>R<sub>L</sub>

R is the sense resistor (Ω), RL the grounded load (Ω), vout the op-amp output (V). Matched ratios R1/R2 = R3/R4 keep IL free of RL.

Matching matters. A 1 % error in one resistor makes part of the output current follow the load voltage, so IL drifts as RL changes. Use a matched resistor array or trim one resistor.

The op-amp output cannot pass its saturation level Vsat, about the supply rail minus 1 V to 2 V. The largest load it can drive is (Vsat − vin)/IL. Past that value the op-amp saturates, the drop across R falls below vin and the current collapses. This allowed load range is the compliance of the source.

R<sub>L(max)</sub> = (V<sub>sat</sub> − v<sub>in</sub>) / I<sub>L</sub>

Vsat is the saturation output, close to the supply rail (V); IL = vin/R (A); RL(max) in ohms (Ω).

Current to voltage: the transimpedance amplifier

Some sources deliver a current: a photodiode, a current-output DAC, a 4–20 mA receiver. Passing that current through a resistor to ground gives a voltage, but the source then sees a voltage that swings with its own current. A photodiode's capacitance must charge and discharge through that swing, which slows the circuit.

The transimpedance amplifier holds the source node still. The current Iin enters the inverting input, Rf goes from the output to that input, and the non-inverting input is grounded. The virtual short pins the inverting node at 0 V, so the input resistance is close to zero and all of Iin flows in Rf.

v<sub>out</sub> = −I<sub>in</sub> R<sub>f</sub>

Iin is the input current in amperes (A), Rf the feedback resistor in ohms (Ω), vout in volts (V). Input resistance ≈ 0 Ω because the node is a virtual ground.

The minus sign says the output falls when current is pushed into the node. A photodiode delivering 10 µA through Rf = 100 kΩ gives −1 V, and its own capacitance never charges because its terminal stays at 0 V. That is why this front end is fast.

Source capacitance Cs and Rf form a pole that can peak the response and even oscillate. Add Cf across Rf. Its pole at 1/(2πRfCf) rolls off the loop gain before the crossing and trades bandwidth for a clean output. Too small a Cf rings; too large slows the receiver.

  • LED and laser diode drivers: current sets light output, and the diode is protected from overcurrent.
  • 4–20 mA transmitters: a sensor voltage becomes a loop current that survives long cables and voltage drops.
  • Photodiode front ends: the transimpedance stage turns microamps of light current into volts for an ADC.
  • DAC outputs: a current-steering DAC feeds a transimpedance stage to give a clean voltage.

Worked example

Question. A Howland current pump uses R = 1 kΩ with v_in = 2 V to drive a grounded load R_L = 500 Ω. The op-amp runs on ±12 V supplies and saturates at 12 V. (a) Find the load current and the load voltage. (b) Find the op-amp output voltage and check it against the rails. (c) Find the largest load resistance for which the circuit still acts as a current source. (d) A photodiode sends 10 µA into a transimpedance amplifier with R_f = 100 kΩ; find v_out.

  1. The bridge is matched, so the drop across R is held at v_in = 2 V.
  2. I_L = v_in/R = 2 V / 1 kΩ = 2 mA. This value does not contain R_L.
  3. V_L = I_L R_L = 2 mA × 500 Ω = 1 V.
  4. v_out = v_in + V_L = 3 V. The rails are ±12 V, so 3 V is well inside them and the op-amp can source 2 mA.
  5. At the compliance limit v_out = V_sat = 12 V, so R_L(max) = (12 V − 2 V) / 2 mA = 5 kΩ.
  6. Transimpedance stage: v_out = −I_in R_f = −(10 µA)(100 kΩ) = −1 V.

Answer. The load current is 2 mA, the load voltage 1 V, the op-amp output 3 V, the largest load resistance 5 kΩ, and the photodiode output −1 V.

Exam traps

  • Assuming the current holds for any load. Past the compliance limit the op-amp saturates and the current collapses; always check that v_in + I_L R_L is inside the rails.
  • Using V_sat/I_L as the largest load. The sense resistor takes v_in first, so R_L(max) = (V_sat − v_in)/I_L, a smaller value.
  • Mismatched Howland resistors. With R1/R2 ≠ R3/R4 part of the output current follows the load voltage, so the circuit is no longer a current source.
  • Calling the transimpedance input resistance R_f. It is near zero, because the input node is a virtual ground.
  • Sign and unit slips: v_out = −I_in R_f, and 10 µA × 100 kΩ = 1 V. Watch µA against kΩ and mA against kΩ.

v_out = −25 µA × 47 kΩ = −1.175 V.

Understand Why is C_f added across R_f in a transimpedance amplifier? 3 marks

Source capacitance with R_f makes a pole that peaks the response or oscillates. C_f adds a feedback pole that rolls off the loop gain first, trading bandwidth for stability.

6.7 Log and antilog amplifiers; analog multipliers

A diode or transistor in the op-amp feedback path makes the output proportional to the logarithm of the input voltage. Put an exponential element at the input instead, and the same op-amp gives an antilog. Add two log outputs in a summer and pass the sum through an antilog stage, and the circuit multiplies. Log amplifiers compress a wide range into a few volts, so they serve in decibel readout, RMS measurement, automatic gain control and telephone companding. The circuit is simple; its temperature drift is not.

You need: Chapter 6.2 for the inverting amplifier, Chapter 6.3 for the summing amplifier, the diode equation from Unit 1, and the BJT exponential law from Unit 2.

Diode log amplifier

Build the inverting amplifier of Chapter 6.2, but replace the feedback resistor R_f with a diode. The inverting input is a virtual ground from Chapter 6.1. The input resistor R carries current I = v_in/R into that node. The same current must flow in the diode, because the op-amp input draws no current. A forward-biased diode obeys I = I_S exp(V_D/V_T), so the diode voltage becomes a logarithm of I and therefore of v_in. With the diode connected so that its forward drop is −v_out, the output falls below zero for a positive input.

v_out = −V_T ln(v_in / (I_S R))

v_out is the output voltage in volts; v_in is the positive input voltage in volts; V_T is the thermal voltage, about 26 mV at 300 K; I_S is the diode reverse saturation current in amperes; R is the input resistor in ohms; ln is the natural logarithm.

v_in must be positive. A negative input reverse-biases the diode, the feedback path opens, and the output saturates near a rail. For a positive input the output is negative, so keep the minus sign. A ×10 increase in v_in raises the diode current by ×10 and changes the diode voltage by V_T ln 10. At 300 K, V_T ≈ 26 mV, so this is 0.026 × 2.303 ≈ 60 mV per decade. The log amp compresses many decades of input into a few volts of output. Both V_T and I_S move with temperature, so the output drifts; that is the main weakness.

BJT log amplifier and drift

Replace the diode with a BJT whose collector is at the virtual ground and whose emitter drives the output, and the same log law appears with the collector current. The BJT holds its exponential relation over more decades than a simple diode, so it is the usual choice in an IC. The equation is still v_out = −V_T ln(v_in/(I_S R)), with I_S now the BJT saturation current. An input of 1 V through 10 kΩ gives 100 µA, a current that a small transistor handles easily.

Uncompensated drift is large. The matched-transistor version uses two identical transistors at the same temperature, one carrying the signal current and one a reference current. Taking the difference of their base-emitter voltages gives a term proportional to ln(I_signal/I_ref); I_S cancels because both transistors have the same I_S. A difference of two logs also removes part of the drift when the same input is measured against a reference. A thermistor or a temperature-sensitive feedback network can correct the remaining V_T drift. At fixed current, a silicon base-emitter voltage falls by about 2 mV for every 1°C rise, so a careless design drifts by millivolts per degree.

Antilog amplifier and log–antilog multiplier

An antilog amplifier reverses the blocks. Put the diode or BJT in the input path and a resistor R_f in the feedback path. The input voltage sets the diode current, I = I_S exp(v_in/V_T). That current flows through R_f, so the output is v_out = −I_S R_f exp(v_in/V_T). The output is an exponential of the input. The input range is small, often only a few hundred millivolts, because the exponential rises fast.

To multiply, take the log of each input, add the two logs, and take the antilog. The identity is ln v₁ + ln v₂ = ln(v₁v₂). A summer from Chapter 6.3 performs the addition. The antilog stage turns the sum back into a product. With scaling, the output is v_out = v₁v₂/k, where v₁ and v₂ are positive input voltages in volts, v_out is the output voltage, and k is a scaling voltage in volts set by the antilog reference. For v₁ = 2 V, v₂ = 3 V and k = 10 V, v_out = 0.6 V. Change the summer to subtraction and the same chain divides: ln v₁ − ln v₂ = ln(v₁/v₂). Feed one input to both logs and it squares.

These blocks are used for decibel readout, RMS-to-DC conversion, companding in telephony, automatic gain control and power measurement. Most integrated multipliers use a Gilbert cell, a variable-transconductance circuit; only a few syllabi analyze its internals. Treat the log–antilog chain as the explanation of the function, not as the only hardware.

Worked example

Question. A diode log amplifier has R = 10 kΩ, I_S = 10⁻¹⁴ A and V_T = 26 mV. Find v_out for v_in = 1 V, then for v_in = 0.1 V, and the change per decade. Then find the output of a log–antilog multiplier with v₁ = 2 V, v₂ = 3 V and scaling voltage k = 10 V.

  1. Input current at 1 V: I₁ = v_in/R = 1 V / 10,000 Ω = 0.0001 A = 100 µA.
  2. Current ratio: I₁/I_S = 100 × 10⁻⁶ A / 10⁻¹⁴ A = 1.0 × 10¹⁰. Natural log: ln(1.0 × 10¹⁰) = 23.0259.
  3. Output at 1 V: v_out1 = −0.026 V × 23.0259 = −0.5987 V.
  4. Input current at 0.1 V: I₂ = 0.1 V / 10,000 Ω = 0.00001 A = 10 µA. Ratio I₂/I_S = 1.0 × 10⁹ and ln(1.0 × 10⁹) = 20.7233.
  5. Output at 0.1 V: v_out2 = −0.026 V × 20.7233 = −0.5388 V.
  6. Change from 1 V to 0.1 V: v_out2 − v_out1 = −0.5388 V − (−0.5987 V) = 0.0599 V. The magnitude is 59.9 mV per decade; for a ×10 increase in input, the signed change is −0.0599 V.
  7. Multiplier output: v_out = v₁v₂/k = (2 V × 3 V) / 10 V = 0.6 V.

Answer. v_out ≈ −0.5987 V at 1 V, ≈ −0.5388 V at 0.1 V, a magnitude of ≈59.9 mV (0.0599 V) per decade; the multiplier output is 0.6 V.

Exam traps

  • Dropping the minus sign: a positive v_in gives a negative v_out in the inverting log amplifier.
  • Forgetting temperature: V_T and I_S both move, so an uncompensated log amp drifts by millivolts per degree.
  • Applying a negative or zero input: the diode cuts off, the feedback path opens, and the log law fails.
  • Swapping the positions: a log amp has the diode in the feedback path; an antilog amp has the diode in the input path.
  • Using v_out = v₁v₂ without scaling: the multiplier output is v₁v₂/k and must stay inside the op-amp rails.

6.8 Precision rectifiers, peak detector and sample-and-hold

A silicon diode needs about 0.6–0.7 V before it conducts, so a 10 mV signal through a plain diode rectifier gives no output. Putting the diode inside an op-amp feedback loop divides that drop by the loop gain, and millivolt signals rectify accurately. A capacitor after the rectifier holds the peak, and a switch plus capacitor samples the wave and holds it while an ADC converts. These circuits appear in digital multimeters, peak-reading meters, AM demodulators and ADC front ends.

You need: Chapter 6.1 for the virtual short and open-loop gain, Chapter 6.2 for inverting gain, and diode behaviour from Unit 1.

The diode inside the loop

A plain half-wave rectifier loses the first 0.6–0.7 V of every half cycle. A 10 mV peak sine therefore produces 0 V at the load; the diode never turns on. The loss is not a small error, it is the whole signal.

Place the diode in the negative-feedback path of an op-amp. The op-amp compares the output with the input and drives its own output past the diode drop until the feedback node reaches the value the closed loop demands. The diode still drops 0.6–0.7 V at the op-amp output, but the feedback node, which is the circuit output, is accurate.

v_D,eff = v_D / (A_OL β)

v_D is the diode drop in volts; A_OL is the op-amp open-loop gain, a pure number; β is the feedback factor, a pure number. For the inverting rectifier β = R₁/(R₁+R_f), and for the unity-gain non-inverting follower β = 1. R₁ and R_f are the input and feedback resistors in ohms. With v_D = 0.7 V, A_OL = 10⁵ and β = 0.5 (R₁ = R_f), v_D,eff = 0.7/(10⁵ × 0.5) V = 14 µV.

In the inverting half-wave precision rectifier, input resistor R₁ and feedback resistor R_f set the gain when the diode conducts: v_out = −(R_f/R₁)v_in. On the other half cycle the diode is off, no current flows through R_f, and v_out = 0 V. Choose R₁ = R_f for gain −1.

Non-inverting and full-wave precision rectifiers

A non-inverting precision rectifier applies v_in to the + input and uses a diode in the feedback path to the − input. For the half cycle that forward-biases the diode, the output follows v_in; for the other half, the diode is off and the output stays near 0 V. The op-amp may swing to a rail while the diode is off, so it must recover quickly when the next half cycle starts.

A full-wave precision rectifier uses two op-amps and two diodes. The first op-amp produces a precision half-wave signal. The second op-amp is a summing amplifier: it adds the original input and the half-wave signal with the correct signs, so the output is |v_in|. The waveform at the first op-amp output is a half-wave; the second output is the full-wave rectified sine.

These circuits work from DC to a few kHz, or tens of kHz with a fast op-amp. At higher frequency the open-loop gain falls, the loop gain available to hide the diode drop falls, and slew rate limits the output. The op-amp also takes time to come out of saturation after the diode-off half cycle.

Peak detector

A peak detector stores the highest input voltage on a capacitor. The non-inverting input receives v_in. A diode from the op-amp output charges hold capacitor C_H. Feedback from C_H to the inverting input keeps the diode drop inside the loop. A buffer after C_H gives a low-impedance output and stops the load from discharging the capacitor.

While v_in rises above the stored value, the op-amp drives the diode on and C_H charges. When v_in falls, the diode turns off and C_H holds the peak. A reset switch across C_H discharges it before a new measurement.

droop rate = I_leak / C_H

I_leak is the total leakage current in amperes (capacitor leakage, diode reverse leakage, op-amp bias current); C_H is the hold capacitance in farads. For I_leak = 1 nA and C_H = 0.01 µF = 10 nF, droop = 0.1 V/s = 0.1 mV/ms.

Peak detectors are used in peak-reading meters and AM demodulation.

Sample-and-hold

A sample-and-hold, also called a track-and-hold, follows the input while the control is in track mode and freezes the last value in hold mode. An analog switch connects v_in to hold capacitor C_H. A buffer isolates C_H from the load. In track mode the buffer output follows v_in; when the switch opens, C_H holds the voltage.

An ADC needs this because its conversion takes time. If v_in changes during conversion, the digital code is uncertain. The sample-and-hold freezes the input so the ADC sees a steady voltage.

  • Acquisition time: time from switch closing until C_H settles to within a specified error of v_in.
  • Aperture time: delay between the hold command and the switch actually opening.
  • Droop rate: I_leak/C_H, the fall of the held voltage.
  • Hold-mode feedthrough: fraction of a changing input that couples to C_H through switch capacitance while the switch is open.

Applications include the digital multimeter, peak-reading meter, AM demodulator and ADC front end.

Worked example

Question. A 10 mV peak sine is applied to a half-wave rectifier with R₁ = R_f = 10 kΩ. (a) Find the output with a plain silicon diode. (b) Find the output with the diode inside the op-amp loop. (c) A peak detector holds 1 V on C = 0.01 µF with 1 nA leakage. Find the droop rate in V/s and mV/ms.

  1. When the diode conducts, gain = −R_f/R₁ = −10 kΩ/10 kΩ = −1.
  2. Plain diode: the 10 mV peak is below about 0.7 V, so the diode never conducts. v_out = 0 V for both half cycles.
  3. Precision version: the loop hides the 0.7 V. On the conducting half cycle, v_out = −1 × 10 mV = −10 mV. On the other half cycle the diode is off and v_out = 0 V.
  4. Hold capacitance: C = 0.01 µF = 0.01 × 10⁻⁶ F = 10 nF = 10 × 10⁻⁹ F.
  5. Droop rate = I/C = 1 nA / 10 nF = (1 × 10⁻⁹ A)/(10 × 10⁻⁹ F) = 0.1 V/s.
  6. Convert: 0.1 V/s = 100 mV/s = 0.1 mV/ms.

Answer. Plain diode gives 0 V; the precision rectifier gives −10 mV on one half cycle and 0 V on the other; droop is 0.1 V/s = 0.1 mV/ms.

Exam traps

  • Using a precision rectifier above a few kHz: falling open-loop gain and slew rate distort the output, and the op-amp takes time to leave saturation.
  • Thinking the circuit output sits at the op-amp output: the 0.7 V diode drop appears at the op-amp output, not at the feedback node.
  • Confusing droop rate with ripple: droop uses I_leak/C_H and has units V/s or mV/ms; ripple belongs to power-supply filters in Unit 1.
  • Forgetting the reset switch in a peak detector: the capacitor keeps the old peak and the next reading is wrong.
  • Making the hold capacitor very small for fast acquisition: hold-mode feedthrough and charge injection then spoil the held voltage.

6.9 Comparators, Schmitt trigger and window detector

An op-amp without negative feedback has only two useful outputs: near the positive supply or near the negative supply. That makes it a comparator, a one-bit analog-to-digital block. A comparator turns a sensor voltage into a logic level. Add positive feedback and it becomes a Schmitt trigger with two thresholds, so noise cannot make the output chatter. Two comparators with an AND gate form a window detector that is high only inside a voltage band. These blocks sit in flash ADCs, thermostats, over-voltage trips, zero-crossing dimmers and counting circuits.

You need: Chapter 6.1 for saturation and the open-loop transfer curve, and Unit 4 for positive feedback and two stable states.

Comparator: open loop to a logic level

An op-amp with no negative feedback is a comparator. Its open-loop gain is very large, so a very small differential voltage drives the output to one rail. The output is +Vsat or −Vsat, where Vsat is the saturated output magnitude, a little below the supply rail; it is not a smooth copy of the input. For an ideal comparator, vout = +Vsat when v+ > v−, and −Vsat when v+ < v−. A zero-crossing detector is the simple case with one input at 0 V: the output changes state each time the input crosses zero. The comparator converts an analog level into a logic level for a digital input, a timer or a counter.

Speed is set by propagation delay and slew rate, not by the closed-loop bandwidth of an amplifier. An open-collector or open-drain comparator needs a pull-up resistor; without it the output can sink current but cannot rise. Do not use a slow op-amp as a fast comparator without checking recovery from saturation. Stored charge in its internal nodes can delay the next edge.

Schmitt trigger: two thresholds from positive feedback

A Schmitt trigger is a comparator with positive feedback. In the inverting version, the input drives the − input. R₂ feeds the output back to the + input, and R₁ connects the + input to ground. This feedback reinforces the present state, so the circuit has two stable output states. Some syllabi call it a regenerative comparator.

With Vref = 0 V, the divider gives β = R₁/(R₁ + R₂). When the output is +Vsat, the + input is at +βVsat, so the upper threshold is UTP = +βVsat. The output stays high while vin < UTP, and goes low when vin rises above UTP. When the output is −Vsat, the + input is at −βVsat, so the lower threshold is LTP = −βVsat. The output stays low while vin > LTP, and goes high when vin falls below LTP. The gap is the hysteresis width W = UTP − LTP = 2βVsat.

β = R₁/(R₁ + R₂),  UTP = +βV<sub>sat</sub>,  LTP = −βV<sub>sat</sub>,  W = UTP − LTP = 2βV<sub>sat</sub>

β is the feedback fraction; R₁ is the resistor from the + input to ground; R₂ is the resistor from the output to the + input; Vsat is the saturated output magnitude with Vref = 0 V; UTP is the upper threshold; LTP is the lower threshold; W is the hysteresis width.

A noisy input that wiggles by less than W cannot cause extra output transitions. The same idea cleans a slow signal in a counter or a zero-crossing detector. The non-inverting version applies the signal to the + input; its threshold algebra is different, so derive it from the node equation. For design, pick β from the required W, then choose R₁ and R₂ in the same ratio.

Window detector and applications

A window detector answers one question: is the input inside a band? Use two comparators. Comparator 1 output is high when vin > VL. Comparator 2 output is high when vin < VU. An AND gate combines their outputs. The final output is high only while VL < vin < VU; outside the band it is low. Diode logic or open-collector wired-AND can replace the gate when the comparator outputs are compatible.

This block is used as an over-voltage and under-voltage trip, a thermostat window, and a comparator bank in a flash ADC. In a lamp dimmer, a zero-crossing detector marks the AC mains crossing; the control circuit then delays the thyristor trigger. A window detector can also check that a sensor stays inside a safe range before a relay or alarm is enabled. Set VL below VU; swapping them gives no high output at all.

Worked example

Question. An inverting Schmitt trigger runs on ±12 V supplies and saturates at ±11 V. The + input divider has R₁ = 10 kΩ to ground and R₂ = 20 kΩ to the output. The input drives the − input, and V_ref = 0 V. Find β, UTP, LTP and hysteresis width. A window detector on the same supplies uses V_L = 3 V and V_U = 5 V; state its high range.

  1. The divider fraction is β = R₁/(R₁ + R₂) = 10 kΩ/(10 kΩ + 20 kΩ) = 10/30 = 0.333.
  2. With the output at +11 V, UTP = βV_sat = 0.333 × 11 V = 3.666 V ≈ 3.67 V.
  3. With the output at −11 V, LTP = −βV_sat = −3.666 V ≈ −3.67 V.
  4. Hysteresis width W = UTP − LTP = 3.666 V − (−3.666 V) = 7.333 V ≈ 7.33 V, also 2βV_sat = 2 × 0.333 × 11 V = 7.333 V.
  5. The guaranteed high band is 3 V < v_in < 5 V. At exactly 3 V or 5 V the comparator sits at its switching point and the output is indeterminate in practice; treat the band edges as uncertain.

Answer. β ≈ 0.33, UTP ≈ +3.67 V, LTP ≈ −3.67 V, hysteresis width ≈ 7.33 V; the window output is high for 3 V < v_in < 5 V.

Exam traps

  • Using R₂/(R₁ + R₂) instead of R₁/(R₁ + R₂) gives the wrong thresholds.
  • A plain comparator has no hysteresis; a slow noisy input makes the output chatter.
  • The saturation level is not the supply rail; use V_sat, not ±V_CC, in threshold calculations.
  • An open-collector comparator needs a pull-up; without it the output cannot go high.
  • For an inverting Schmitt trigger the input drives the − input; do not swap the UTP and LTP signs.

Takeaways

  1. An ideal op-amp has infinite gain, infinite input resistance and zero output resistance, so with negative feedback the input pair becomes a virtual short that draws no current.
  2. Two resistors and a virtual ground give every linear op-amp circuit its gain: −R_f/R₁ inverting, 1 + R_f/R₁ non-inverting, and 1 for the follower.
  3. Sums and differences are just currents meeting at a virtual ground, which is why one op-amp can add several inputs or subtract two.
  4. The instrumentation amplifier adds buffered inputs to a difference stage, giving very high input resistance and CMRR for measuring small signals on a large common voltage.
  5. Swapping a resistor for a capacitor turns the same inverting stage into an integrator or a differentiator.
  6. Feedback lets the op-amp set a voltage across a resistor, so the current through it, and through the load, is fixed by the input alone.
  7. A diode or transistor in the feedback loop gives log and antilog responses, and combining them multiplies or divides signals.
  8. Feedback around a diode removes its turn-on drop, and a capacitor after it holds a peak or a sample; without feedback the same op-amp becomes a comparator with two output states.

Exam question bank

Long answers usually ask for the circuit diagram, the derivation from the virtual-short idea, the final gain or output formula with units, and one practical limitation such as finite gain, resistor tolerance or the diode drop.

Remember and understand

Understand Explain the virtual short and virtual ground concepts. Why does an ideal op-amp with negative feedback behave this way? 10 marks

Ideal op-amp: A_OL → ∞, R_in → ∞, R_out → 0; Output v_o = A_OL(v₊ − v₋); with finite v_o and infinite gain the difference must be zero; Negative feedback returns part of v_o to v₋ so the loop can settle at v₊ = v₋; If v₊ = 0 V then v₋ sits at 0 V without being grounded: virtual ground; Zero input current follows from infinite R_in, so the same current flows in R₁ and R_f.

Remember List the ideal op-amp characteristics and compare them with a practical op-amp such as the 741. 8 marks

Ideal: infinite gain, infinite input resistance, zero output resistance, infinite bandwidth, zero offset and drift; Practical 741: A_OL about 2×10⁵, R_in about 2 MΩ, R_out about 75 Ω, unity-gain bandwidth about 1 MHz; Offset voltage of a few mV, bias current of tens of nA, finite slew rate 0.5 V/µs; Consequence: gain formula is approximate, offsets appear at the output multiplied by the closed-loop gain; CMRR finite, typically 90 dB.

Understand Why is a voltage follower used as a buffer? Explain with an example of a sensor driving a heavy load. 8 marks

Gain = 1 because R₁ is open and R_f = 0; output follows input in phase and magnitude; Input resistance is very high (MΩ), so it does not load a high-impedance source; Output resistance is very low, so it can drive a low-resistance load; Example: a divider of two 100 kΩ resistors feeding a 1 kΩ load collapses without a buffer; Feedback keeps v₋ = v₊, so the output copies the input.

Understand Explain how an op-amp works as a comparator and describe its output states with ±15 V supplies. 8 marks

No feedback, so output is open-loop: v_o = A_OL(v₊ − v₋); If v₊ > v₋ output swings to +V_sat, about +14 V; if v₊ < v₋ it swings to −V_sat; Output is two-state, not linear; the transition is fast; Reference can be 0 V or a DC level set by a divider; Practical points: no hysteresis so noise causes chatter, limited slew rate, output must be limited for logic loads.

Apply

Apply Design an inverting amplifier of gain −25 using a 741 on ±15 V supplies. Choose resistors, state the input resistance, and give two guidelines for resistor selection. 10 marks

Gain = −R_f/R₁ = −25, so R_f = 25R₁; Pick R₁ = 4.7 kΩ and R_f = 120 kΩ (nearest standard) or R₁ = 1 kΩ, R_f = 25 kΩ; Input resistance seen by the source equals R₁; Keep R₁ above about 1 kΩ so the bias-current offset stays small; keep R_f below about 1 MΩ so stray capacitance does not slow the response; Output offset ≈ offset voltage × 25, so offset nulling may be needed.

Apply An inverting summer has R₁ = R₂ = R₃ = 10 kΩ and R_f = 20 kΩ. The inputs are 1 V, 2 V and −0.5 V. Find the output and the current in R_f. 10 marks

v_o = −R_f(v₁/R₁ + v₂/R₂ + v₃/R₃); Each term: 0.1 mA, 0.2 mA, −0.05 mA; sum = 0.25 mA; v_o = −20 kΩ × 0.25 mA = −5 V; Virtual ground holds the summing node at 0 V, so each input current is set by its own resistor only; Current in R_f equals the sum, 0.25 mA, flowing from the node to the output; Check supplies: −5 V is inside ±15 V, so no clipping.

Apply An instrumentation amplifier uses R = 25 kΩ, R_f = 100 kΩ and R₁ = 10 kΩ. Find R_G for a total gain of 100 and explain why this circuit suits a bridge measurement. 12 marks

Total gain = (1 + 2R/R_G)(R_f/R₁); Second stage gain = 100 kΩ/10 kΩ = 10, so the first stage must give 10; 1 + 2(25 kΩ)/R_G = 10 gives 2(25 kΩ)/R_G = 9, so R_G = 50 kΩ/9 ≈ 5.56 kΩ; Only R_G sets the gain, so one variable resistor trims the whole amplifier; Both inputs go to non-inverting terminals, giving very high input resistance; Mismatch in the difference stage sets CMRR; typical CMRR above 100 dB.

Apply An integrator has R₁ = 10 kΩ and C = 10 nF. A 1 V step is applied at t = 0. Find the output after 1 ms and sketch the response for a 1 kHz square wave. 12 marks

v_o = −(1/R₁C)∫v_in dt, time constant R₁C = 10 kΩ × 10 nF = 100 µs; Slope = −v_in/(R₁C) = −1 V/100 µs = −10 V/ms; After 1 ms, v_o = −10 V (clipped if the supply is ±15 V and the step lasts longer); For a square wave the output is triangular; amplitude = v_in/(4fR₁C); With 1 kHz and 1 V peak, amplitude = 1/(4 × 1000 × 100×10⁻⁶) = 2.5 V; A resistor across C is added in practice to stop drift and set a DC limit.

Apply Design a voltage-to-current converter that drives 5 mA through a grounded load from a 1 V input, and show that the load value does not change the current. 10 marks

Use a non-inverting input at v_in with feedback that holds the same voltage across a sense resistor R; I_L = v_in/R; for 1 V and 5 mA choose R = 200 Ω; Virtual short keeps the sense resistor voltage equal to v_in, whatever the load is; Explain with a floating-load version: load in the feedback path, current set by R; For a grounded load, a Howland-type or an added buffer stage is used; Limits: the op-amp must supply the load current, so add a transistor for currents above about 20 mA.

Analyze and evaluate

Analyze Derive the output of a log amplifier using a diode in the feedback loop. Explain its temperature dependence and how an antilog stage with a summer makes an analog multiplier. 12 marks

Input current I = v_in/R flows through the diode because the summing node is at virtual ground; Diode equation I = I_s(e^(v_D/V_T) − 1), so v_D = V_T ln(I/I_s) with V_T = kT/q ≈ 26 mV at 300 K; Output v_o = −v_D = −V_T ln(v_in/(I_s R)), so it is proportional to log of the input; Slope is about 60 mV per decade of input current at room temperature; V_T and I_s both drift with temperature, so matched transistor pairs and temperature compensation are used; Multiplier: log v₁ + log v₂ summed, then antilog gives v₁v₂; division subtracts the logs.

Evaluate Compare a precision half-wave rectifier with a plain diode rectifier for a 100 mV, 1 kHz sine input. Explain where the diode drop goes and what limits the precision circuit. 12 marks

Plain diode: output is zero until v_in exceeds about 0.7 V, so a 100 mV signal never appears; Precision circuit: diode inside the feedback loop; the op-amp output rises until v₋ = v₊, so the drop is supplied by the op-amp, not taken from the signal; Effective error is about 0.7 V/A_OL, i.e. microvolts; Limits: op-amp slew rate and gain-bandwidth at high frequency; the op-amp must come out of saturation quickly when the input reverses; Use a second diode or a resistor to keep the loop closed near zero crossing and avoid dead time; Full-wave version uses two diodes and a summing stage.

Analyze Design a Schmitt trigger with thresholds at +2 V and −2 V using ±12 V supplies. Derive the threshold expressions and explain why hysteresis rejects noise. 12 marks

Positive feedback from output to v₊ through R₂, input through R₁; output is at ±V_sat; Upper threshold V_UT = +V_sat·R₁/(R₁+R₂) + V_ref·R₂/(R₁+R₂) when output is high; Lower threshold V_LT with −V_sat in the same expression; Choose R₁/R₂ from V_UT = 2 V with V_sat ≈ 11 V; a reference shifts the band if needed; Hysteresis width V_UT − V_LT keeps noise smaller than the band from causing extra output changes; Uses: squaring up slow waves, zero-crossing detectors, removing contact bounce.

Evaluate Compare the inverting and non-inverting configurations for input resistance, gain accuracy, common-mode voltage at the input and bandwidth. Which one would you pick to buffer a high-impedance sensor? 15 marks

Inverting: input resistance = R₁, gain −R_f/R₁, inputs stay at virtual ground so no common-mode voltage, but low input resistance loads the source; Non-inverting: input resistance very high (set by the op-amp), gain 1 + R_f/R₁, both inputs move with the signal so CMRR and input capacitance matter; Noise gain is 1 + R_f/R₁ in both cases, so closed-loop bandwidth = f_T/(1 + R_f/R₁); Gain error comes from finite A_OL and resistor tolerance; the non-inverting form gives a slightly lower gain than calculated; For a high-impedance sensor use the non-inverting form or a follower first, then an inverting stage for gain; Both are limited by offset voltage times the DC gain at the output.

Evaluate Explain how feedback around a diode and a capacitor produces a peak detector and a sample-and-hold. Include the role of the switch, the hold capacitor and the droop. 14 marks

Precision peak detector: diode in the feedback loop charges C to the input peak; the op-amp compensates the diode drop; When the input falls, the diode blocks unless a reset switch or resistor is added; Droop: C discharges through leakage and bias current, so v falls at I/C; a larger C and a FET-input op-amp reduce it; Sample-and-hold: an analog switch connects v_in to C during the sample interval; the buffer holds the value when the switch opens; Acquisition time is set by the switch resistance and C; aperture time is the switching delay; Used in ADCs, DMMs and peak-reading meters; the buffer after C must have very high input resistance.

Glossary

Bias current
The small DC current that flows into each input terminal.
CMRR
The ratio of differential gain to common-mode gain, usually quoted in dB.
Difference amplifier
A circuit that amplifies the voltage difference between two inputs and rejects the common part.
Differentiator
A circuit whose output is proportional to the rate of change of the input.
Gain-bandwidth product
The frequency at which open-loop gain falls to 1, equal to closed-loop gain times closed-loop bandwidth.
Hysteresis
The gap between the upper and lower threshold voltages that stops a comparator from chattering on noise.
Instrumentation amplifier
A three-op-amp circuit with very high input resistance and CMRR, used for sensor and bridge signals.
Integrator
A circuit whose output is proportional to the time integral of the input, made with a capacitor in feedback.
Inverting amplifier
An op-amp stage whose gain is −R_f/R₁ and whose output is 180° out of phase with the input.
Logarithmic amplifier
A circuit using the exponential diode or transistor characteristic to give an output proportional to log of the input.
Non-inverting amplifier
An op-amp stage whose gain is 1 + R_f/R₁ with the output in phase with the input.
Offset voltage
The small differential voltage needed at the input to make the output exactly zero.
Op-amp
A high-gain differential amplifier in one package, usually with two inputs and one output.
Open-loop gain
The gain of the op-amp with no feedback path, very large at DC and falling with frequency.
Peak detector
A diode and capacitor circuit that stores the highest input voltage reached.
Precision rectifier
A rectifier with the diode inside the op-amp feedback loop, so it works down to millivolts.
Sample-and-hold
A circuit that tracks the input and then freezes it on a capacitor when a switch opens.
Slew rate
The fastest rate at which the output can change, in V/µs.
Summing amplifier
A circuit that adds several input voltages, each scaled by its own resistor.
Transconductance
Ratio of output current to input voltage, the quantity a V-I converter sets.
Transimpedance
Ratio of output voltage to input current, set by R_f in a current-to-voltage converter.
Virtual ground
A node held at 0 V by feedback even though it is not connected to ground.
Virtual short
The near-zero voltage difference between the two inputs of an op-amp working with negative feedback.
Voltage follower
A gain-of-one buffer made from an op-amp with the output tied to the inverting input.
Window detector
A pair of comparators that flags when an input lies outside an allowed voltage band.
