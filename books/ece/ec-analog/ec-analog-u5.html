5.1 BJT and MOSFET differential pairs

A differential pair is two matched transistors with emitters, or sources, joined and fed by one constant tail current IEE. Inputs v1 and v2 steer that fixed current: raise v1 and Q1 takes more, Q2 less; the sum stays IEE. The output depends on vid = v1 − v2, not on the average (v1 + v2)/2. That is why the pair sits at every op-amp input: it amplifies the wanted difference and rejects hum and noise common to both wires. Rejection is covered in 5.2.

You need Unit 2, Transistor Biasing and Small-Signal Amplifiers — the DC operating point, gm = IC/VT for a BJT, gm = 2ID/VOV for a MOSFET, and CE and CS gain expressions.

Two matched devices sharing one tail current

Take two identical BJTs Q1 and Q2. Join their emitters to a current source IEE sinking to −VEE. Connect collectors to VCC through equal RC. Drive bases from v1 and v2. The MOSFET version is identical: sources joined, tail IEE to ground or −VSS, drains to VDD through equal RD.

Define vid = v1 − v2 (difference input, volts) and vicm = (v1 + v2)/2 (common-mode input, volts). Then v1 = vicm + vid/2 and v2 = vicm − vid/2.

At vid = 0 both devices have the same VBE or VGS, so they split the tail equally: IC1 = IC2 = IEE/2. Collector voltages are equal, VC = VCC − (IEE/2)RC, and the output difference is zero.

Raise v1 and lower v2: Q1 needs more current, Q2 less. The tail holds the total at IEE, so Q1's gain is Q2's loss. The input difference decides the split; the tail decides only the sum.

Small signals: each device gets half the difference

For small vid the joined node does not move; each base-emitter voltage changes by vid/2 with opposite signs. So ΔIC1 = +gm vid/2 and ΔIC2 = −gm vid/2.

vod = vC1 − vC2 = −gm RC vid,   Ad = vod/vid = −gm RC

vod is the differential output voltage between collectors, in volts; gm is transconductance in siemens; RC is collector resistance in ohms; vid is differential input in volts. The minus sign means output falls when v1 rises.

Single-collector gain is half: Av1 = vc1/vid = −gm RC/2. A differential output doubles it and cancels shared components.

gm = IC/VT (BJT),   gm = 2ID/VOV = √(2µnCox(W/L)ID) (MOSFET)

IC and ID are DC currents at balance, IEE/2, in amperes; VT = kT/q ≈ 26 mV at room temperature; VOV = VGS − VTH is overdrive voltage in volts; µn is electron mobility, Cox gate capacitance per unit area, W/L channel width-to-length ratio.

With IEE/2, BJT gm = IEE/(2VT) and MOSFET gm = IEE/VOV. The tail current sets gain, so a current mirror usually biases the pair (5.3).

The joined node: virtual ground or follower

Differential signals move v1 up and v2 down equally. Q1 pushes current into the joined node while Q2 pulls the same out, so its voltage does not change. For vid the emitter or source is a virtual ground, and each half is a CE or CS stage of gain gm RC.

Common-mode signals move both inputs together. Both devices try to conduct more; the tail source resists with high output resistance REE. The joined node follows the input like a follower, so VBE and collector currents barely change. Common-mode gain is small, about −RC/(2REE) for a BJT pair, against −gm RC for differential gain.

A current-source tail is the point: a resistor tail changes current when common-mode voltage changes, but a good current source holds current almost constant. The gain ratio is CMRR, covered in 5.2.

On the bench, a BJT pair's joined node sits about VBE (0.7 V) below the input DC level; a MOSFET pair's sits about VGS below it.

Where you meet it

  • Every op-amp and comparator input stage is a differential pair, the first block in 5.5.
  • Balanced audio and instrumentation cables: hum couples equally onto both wires and is rejected as common mode.
  • High-speed serial links such as USB and HDMI drive and receive data differentially, so supply noise disturbs both wires and cancels.

Worked example

Question. A BJT differential pair has IEE = 1 mA, VCC = 12 V, RC = 5 kΩ on each collector, and VT = 26 mV. β is very large. (a) Find IC1 and IC2 at vid = 0. (b) Find gm and the single-ended differential gain at collector 1. (c) For vid = 5 mV, find vC1, vC2 and the differential output voltage.

  1. At vid = 0 the pair is balanced: IC1 = IC2 = IEE/2 = 1 mA / 2 = 0.5 mA. With large β, IC ≈ IE.
  2. gm = IC/VT = 0.5 mA / 26 mV = 0.01923 S = 19.23 mS.
  3. Single-ended gain at collector 1: |Av1| = gm RC/2 = 19.23 mS × 5 kΩ / 2 = 96.15 / 2 = 48.08. A rising v1 turns Q1 on harder and drops vC1, so Av1 = −48.08, about 33.6 dB.
  4. For vid = 5 mV, ΔIC1 = gm vid/2 = 19.23 mS × 5 mV / 2 = 48.08 µA and ΔIC2 = −48.08 µA. So IC1 = 0.5 mA + 0.0481 mA = 0.5481 mA and IC2 = 0.5 mA − 0.0481 mA = 0.4519 mA.
  5. vC1 = VCC − IC1 RC = 12 − 0.5481 mA × 5 kΩ = 12 − 2.7404 = 9.2596 V. vC2 = 12 − 0.4519 mA × 5 kΩ = 12 − 2.2596 = 9.7404 V.
  6. vod = vC1 − vC2 = 9.2596 − 9.7404 = −0.4808 V. Check: −gm RC vid = −19.23 mS × 5 kΩ × 5 mV = −0.4808 V. 5 mV is well below 2VT = 52 mV, so the linear estimate is good to a few percent.

Exam traps

  • Using IC = IEE instead of IEE/2 at balance. Each device carries only half the tail current.
  • Dropping the 1/2 in a single-ended output. Gain at one collector or drain is gm RC/2; a differential output gives the full gm RC.
  • Treating the joined node as a virtual ground for common-mode signals. It is a virtual ground only for vid; for vicm it follows the input like a follower.
  • Sign confusion: a rising v1 raises IC1, so vC1 falls. Collector 1 is the inverting output; collector 2 is non-inverting.
  • Using the small-signal formula for large vid. Once vid approaches a few times VT (or VOV for a MOSFET), one device takes nearly all of IEE and output flattens at IEE·RC; gm is no longer constant.

5.2 Common-mode and differential-mode gain; CMRR

A differential amplifier has two inputs. The signal of interest is their difference; the average is often interference. Splitting the inputs into a difference vid and a common-mode average vicm lets us define two gains: differential gain Ad, which we want large, and common-mode gain Acm, which we want small. CMRR compares them. The idea is used in sensor front ends, ECG amplifiers, current sensing and every op-amp input stage.

You need: 5.1 for the matched pair and the small-signal models from Unit 2.

Difference and average of two inputs

Take two input voltages v1 and v2, both measured with respect to ground. Their difference is vid = v1 − v2. Their average is vicm = (v1 + v2)/2. The same pair can be rebuilt as v1 = vicm + vid/2 and v2 = vicm − vid/2. Here vid is the differential-mode input, in volts; vicm is the common-mode input, in volts. A differential amplifier should multiply vid by Ad and vicm by Acm. The output is the sum of these two contributions. The split matters because a wanted sensor signal usually appears as a difference, while mains hum, ground bounce and temperature drift often appear equally at both inputs, so they are common mode.

  1. Measure v1 and v2 with ground as reference.
  2. Subtract to get vid.
  3. Average to get vicm.
  4. Rebuild the inputs as vicm plus or minus vid/2.

vid = v1 − v2, vicm = (v1 + v2)/2

v1 and v2 are input voltages in V; vid is the differential-mode input in V; vicm is the common-mode input in V.

Differential gain and common-mode gain

For a single-ended output at one collector, call the output voltage vo, in volts. Then vo = Ad vid + Acm vicm, where Ad = vo/vid is the differential-mode gain and Acm = vo/vicm is the common-mode gain. Both are dimensionless, and each is measured with the other input component held at zero.

For a differential output, let vo1 and vo2 be the two collector voltages. The differential output is vod = vo1 − vo2, in volts; the common-mode output is voc = (vo1 + vo2)/2, in volts. Then vod = Ad vid + A_cm-dm vicm, where Ad = vod/vid is the differential gain and A_cm-dm = vod/vicm is the common-mode-to-differential gain. In a perfectly symmetric pair A_cm-dm = 0, because common-mode input appears equally at both collectors: it cancels in vod and shows up only in voc.

Use magnitudes when comparing gains, because either gain can be negative. For a BJT pair with collector resistors RC and a tail resistance REE, a single-ended output at one collector gives Ad = gm RC/2 and Acm ≈ −RC/(2REE). gm is the small-signal transconductance of each transistor, in A/V; RC is the collector resistor, in Ω; REE is the small-signal resistance of the tail, in Ω. The minus sign means a rise in common-mode input lowers that collector. A larger REE reduces |Acm|; an ideal tail current source has REE → ∞ and Acm → 0. With a differential output, perfect symmetry cancels common mode and the residual is set by mismatch, through A_cm-dm.

Ad = gm RC/2,   Acm ≈ −RC/(2REE),   CMRR ≈ REE/re

Single-ended output at one collector. gm is small-signal transconductance in A/V; RC is the collector resistor in Ω; REE is the tail small-signal resistance in Ω; re is the small-signal emitter resistance of each BJT in Ω, with re ≈ 1/gm. The last expression uses gm REE = REE/re.

CMRR, mismatch and input range

CMRR, the common-mode rejection ratio, is the ratio of the two gains: CMRR = |Ad/Acm|. In decibels, CMRRdB = 20 log10 |Ad/Acm|. The 20 is used because Ad and Acm are voltage gains. A CMRR of 80 dB means |Ad/Acm| = 10^(80/20) = 10^4. For a differential output, replace Acm by A_cm-dm in these ratios. A fractional mismatch δ = ΔRC/RC between the two collector resistors converts common-mode input into a differential output. To a first approximation |A_cm-dm/Ad| ≈ δ/(gm REE), so CMRR ≈ gm REE/δ = (REE/re)/δ. A 1% mismatch with REE/re = 4000 gives CMRR ≈ 400,000, or about 112 dB. Matched resistors and transistor pairs therefore matter. Common-mode input range is the range of vicm over which the pair still works: input transistors stay in the active region and the tail current source has enough voltage. Outside it, bias current changes or devices saturate, and CMRR collapses. In a fully differential amplifier, a common-mode feedback (CMFB) loop senses the average of the two outputs and adjusts a bias so that output average stays at a chosen reference. Measurement of op-amp CMRR is in 5.6.

CMRR = |Ad/Acm|,   CMRR<sub>dB</sub> = 20 log<sub>10</sub> |Ad/Acm|

Ad is differential-mode gain; Acm is common-mode gain; CMRR is the common-mode rejection ratio, dimensionless; CMRRdB is in decibels. For a differential output, use A_cm-dm in place of Acm.

Worked example

Question. An amplifier has a single-ended output with differential gain Ad = 200 and CMRR = 80 dB. Its inputs are v1 = 1.010 V and v2 = 0.990 V. Find vid, vicm, |Acm|, the differential and common-mode contributions to the output, and the worst-case total output magnitude.

  1. Difference: vid = v1 − v2 = 1.010 V − 0.990 V = 0.020 V = 20 mV.
  2. Average: vicm = (v1 + v2)/2 = (1.010 V + 0.990 V)/2 = 2.000 V/2 = 1.000 V.
  3. CMRR in dB: 80 = 20 log10(|Ad/Acm|), so |Ad/Acm| = 10^(80/20) = 10^4 = 10000.
  4. Common-mode gain magnitude: |Acm| = |Ad|/10000 = 200/10000 = 0.020.
  5. Differential contribution: Ad vid = 200 × 0.020 V = 4.000 V.
  6. Common-mode contribution: |Acm| vicm = 0.020 × 1.000 V = 0.020 V.
  7. Worst-case total magnitude: |Ad vid| + |Acm vicm| = 4.000 V + 0.020 V = 4.020 V. With opposite signs the magnitude is 4.000 V − 0.020 V = 3.980 V, which is smaller.

Answer. The inputs give vid = 20 mV and vicm = 1.000 V; |Acm| = 0.020; the differential contribution is 4.000 V, the common-mode contribution is 0.020 V, and the worst-case total output magnitude is 4.020 V.

Exam traps

  • Using vid = v1 + v2 or vicm = v1 + v2: the difference is a subtraction and the common mode is an average.
  • Using 10 log instead of 20 log for CMRR in dB: gains are voltages, so CMRRdB = 20 log10|Ad/Acm|.
  • Treating CMRR as Ad − Acm: it is a ratio |Ad/Acm|, not a difference.
  • Using the single-ended Acm formula when the output is taken differentially: perfect symmetry cancels common mode, and mismatch sets the residual.
  • Forgetting the common-mode input range: a pair can have good small-signal CMRR and still fail when vicm drives the tail current source out of compliance.

5.3 Current mirrors and current sources

A current mirror takes a reference current and copies it into another branch. The copy is set by transistor geometry and by the shared base or gate voltage. It exists because an IC cannot afford a precise resistor for every bias current, but it can match two nearby transistors. Mirrors bias differential pairs, supply active loads, and set op-amp internal currents. A simple BJT mirror copies with a small base-current error; a MOSFET mirror copies by width-to-length ratio. Cascode and Wilson versions raise output resistance so the copy changes less when the output voltage moves.

You need: 5.1 for the tail current source, and Unit 2 for BJT and MOSFET bias circuits.

BJT mirror: diode-connected reference

Connect the collector of Q1 to its base. Q1 is diode-connected: it has two terminals and sits at the base-emitter voltage VBE needed for the reference current. A resistor R from the positive supply VCC sets that current. Q2 is a matched transistor with the same VBE. If both transistors stay in the active region, Q2 copies Q1's collector current. The circuit is a current mirror. Some syllabi call these current mirror circuits; the name is the same.

I<sub>REF</sub> = (V<sub>CC</sub> − V<sub>BE</sub>) / R

IREF is the reference current in amperes; VCC is the positive supply in volts; VBE is the base-emitter voltage of Q1 in volts; R is the reference resistor in ohms.

The copy is not perfect. The reference current has to supply the collector of Q1 and the base currents of both transistors. For matched devices, IREF = IOUT(1 + 2/β), where β is the common-emitter current gain. Rearrange: IOUT = IREF / (1 + 2/β). With β = 100 the error is about 2 percent. Emitter resistors improve matching because a small resistor drops a voltage that corrects small VBE differences; the cost is extra voltage headroom.

IOUT = IREF / (1 + 2/β)

IOUT is the copied collector current in amperes; IREF is the reference current in amperes; β is the BJT current gain, dimensionless.

The output transistor must stay active. The compliance voltage is the minimum output voltage VOUT that keeps Q2 out of saturation. For a simple BJT mirror, VOUT ≥ VCE,sat, about 0.2 V to 0.3 V. Below that value the copy falls. A mirror often feeds the tail of the differential pair in 5.1. That tail current must stay fixed when the input common voltage moves, so the mirror's output resistance matters.

Raising output resistance

A current source should give the same current for any output voltage. A simple mirror does not: its output resistance is finite. For a BJT, ro = VA / IC, where VA is the Early voltage and IC is the collector current. For a MOSFET, ro = 1 / (λ ID), where λ is the channel-length modulation parameter and ID is the drain current. A larger ro means a better current source.

The Wilson mirror and the cascode mirror raise output resistance by stacking transistors and using local feedback. The cascode keeps the output device's drain or collector voltage nearly fixed, so its current changes less when VOUT moves. These mirrors need a larger compliance voltage because more devices sit in the stack. Use them when the copy must be stable, not when the available headroom is tiny.

The Widlar source gives a small output current without a small reference current. It puts a resistor R2 in the emitter of the output device. The relation is IOUT R2 = VT ln(IREF / IOUT), where VT ≈ 26 mV at room temperature. The current is set by R2 and a logarithmic ratio, so a few microamperes are practical. Its output resistance is lower than a cascode's, so check the application.

MOSFET mirror and compliance

In a MOSFET mirror, Q1 is diode-connected: gate tied to drain. Q2 shares the same gate-source voltage VGS. If both devices stay in saturation, the current ratio follows the width-to-length ratio: IOUT / IREF = (W/L)2 / (W/L)1. Here W is channel width, L is channel length, and W/L is dimensionless. A wider Q2 copies a larger current. Do not invert the ratio.

I<sub>OUT</sub> / I<sub>REF</sub> = (W/L)<sub>2</sub> / (W/L)<sub>1</sub>

IOUT is the copied drain current in amperes; IREF is the reference current in amperes; (W/L)1 and (W/L)2 are the width-to-length ratios of Q1 and Q2, dimensionless.

Channel-length modulation makes the copy depend on the drain-source voltage VDS. The output resistance is ro = 1/(λ ID), where λ is the channel-length modulation parameter in V−1. The compliance voltage of a simple MOSFET mirror is VOUT ≥ VGS − VTH, the overdrive voltage. Below it, Q2 leaves saturation and the copy falls. A cascode MOSFET mirror raises ro but needs about one more overdrive voltage of headroom.

A mirror is the usual tail bias for a differential pair. It turns one reference current into a stable tail current. It also sets bias currents inside op-amps; the full bias chain is in 5.5. Using a mirror as an active load is a separate idea, covered in 5.4.

Worked example

Question. Using a 5 V supply, design a simple BJT current mirror for an output current of about 1 mA. VBE = 0.7 V, β = 100, VA = 50 V. Find R for IREF = 1 mA, the actual IOUT, and ro. State the compliance limit.

  1. Set the reference current: IREF = 1 mA. R = (VCC − VBE) / IREF = (5 V − 0.7 V) / 1 mA = 4.3 kΩ.
  2. Apply the base-current error: IOUT = IREF / (1 + 2/β) = 1 mA / (1 + 2/100) = 1 mA / 1.02 = 0.98039 mA ≈ 0.9804 mA.
  3. Find output resistance: ro = VA / IOUT = 50 V / 0.98039 mA = 51.0 kΩ.
  4. Compliance: keep VOUT ≥ VCE,sat, about 0.2 V to 0.3 V. Below this value Q2 saturates and the copy drops.

Answer. R = 4.3 kΩ, IOUT ≈ 0.9804 mA, and ro ≈ 51.0 kΩ; the output must stay above about 0.2 V.

Exam traps

  • Treating IOUT as exactly IREF and forgetting the base-current error 2/β.
  • Expecting IOUT to stay fixed when VOUT changes; a real mirror has finite ro.
  • Inverting the MOSFET ratio; IOUT/IREF equals (W/L)2/(W/L)1.
  • Forgetting the compliance voltage; below VCE,sat or the overdrive the copy falls.
  • Confusing a Widlar source with a simple mirror: the Widlar uses an emitter resistor to get a small current.

5.4 Active loads and CMOS differential amplifiers

A resistor load wastes the gain of a differential pair: more gain needs a bigger resistor, and a bigger resistor drops more DC voltage and eats the output swing. Replace the resistors with a PMOS current mirror and the load becomes a high small-signal resistance that drops almost no DC voltage. The mirror also folds the two side currents into one node, so a differential input becomes a single-ended output. Every CMOS op-amp input stage is built this way.

You need 5.1 for the differential pair, 5.3 for the mirror, and the MOSFET output resistance ro = 1/(λID) from Unit 2, Small-signal models.

Why the load resistor limits gain

A differential pair with two drain resistors turns the input difference into a difference of drain currents, and the resistors turn that current back into a voltage. Taken at one drain only, the gain is small.

Ad = gm1RD/2

Ad is the single-ended voltage gain in V/V; gm1 is the transconductance of one input transistor in siemens (A/V); RD is the drain resistor in ohms. The ½ appears because an input difference vid moves each drain current by only gm1vid/2.

The resistor costs you twice. A large RD carries the bias current ID and drops IDRD volts, so the output node sits near a supply rail and the swing left for the signal is small. On-chip resistors are also inaccurate, often ±20 %, so the gain is inaccurate too. A current-source load changes both facts: the DC voltage across it is only a few hundred millivolts, while its small-signal resistance ro is tens to hundreds of kilohms. Gain then follows gmro, not gmRD.

The five-transistor CMOS active-loaded pair

The standard CMOS input stage uses five transistors. M1 and M2 are the NMOS input pair, M5 is the NMOS tail current source, and M3 and M4 form a PMOS current mirror that acts as the load. Some syllabi call the block an active-loaded differential amplifier; others call it a CMOS OTA core. Both names mean the same five-transistor circuit.

  1. M5 sinks a fixed tail current Itail; matched inputs share it equally, so each side carries Itail/2.
  2. Apply vid. M1's drain current rises by gm1vid/2 and M2's falls by the same amount (signs swap if you invert the input).
  3. M3 is diode-connected, so it absorbs M1's current and sets the gate voltage of M4.
  4. M4 shares that gate, so it copies M1's current into the drain of M2, change included.
  5. At the output node the two changes add: gm1vid/2 from M2 and gm1vid/2 from the mirror, giving gm1vid.
  6. That current flows into ron ‖ rop and becomes the output voltage.

Notice what the mirror bought you. The input difference produced a current gm1vid, and all of it arrives at one node, so the output is single-ended with no loss of the other half. No separate differential-to-single-ended stage is needed.

Gain, output resistance and the price

The resistance at the output node is ron of M2 in parallel with rop of M4. Both devices sit in saturation, so both are large and the parallel combination is close to half of the smaller one.

R<sub>out</sub> = r<sub>on</sub> ‖ r<sub>op</sub> = r<sub>on</sub>r<sub>op</sub>/(r<sub>on</sub> + r<sub>op</sub>),   A<sub>d</sub> = g<sub>m1</sub>R<sub>out</sub>

Rout is the small-signal resistance at the single-ended output node in ohms; ron is the output resistance of the NMOS M2 and rop that of the PMOS M4, both in ohms; gm1 is the transconductance of M1 in siemens; Ad is the differential voltage gain in V/V.

Exam traps

  • Using gmRD/2 for an active-loaded stage. The mirror adds both halves of the current, so the active load gives gm1(ron‖rop) with no ½.
  • Thinking the mirror load halves the gain or wastes half the signal. It does the opposite: it converts the differential current into a single-ended output current of full value gm1vid.
  • Forgetting the conversion. Before the mirror you have a differential current; after it you have one single-ended node, and that node's resistance is ron ‖ rop, not ron alone.
  • Treating ro as a constant. It falls as bias current rises (ro = 1/(λID)), so doubling the tail current does not double the gain.
  • Assuming the tail source is ideal. Its finite output resistance sets the common-mode gain, so a poor tail ruins CMRR even when the differential gain looks fine.

5.5 Op-amp internal stages: input, gain, level shifter, output

An op-amp is not one circuit. It is a chain of four jobs: read the difference between two inputs, multiply it by a very large number, move the DC level to where the output stage needs it, and drive current into a load. Each job is a separate stage. The stages share bias currents and are designed together. This chain explains why an op-amp has high input resistance, huge open-loop gain, and low output resistance. The 741 is the classic example.

You need: 5.1 and 5.4; Unit 4 negative feedback for closed-loop later.

Input stage: read the difference

The input stage is a differential pair. Two matched transistors, Q1 and Q2, share a tail current source. The input voltage difference v_id steers the tail current: one side takes more, the other less. An active-load current mirror turns this balanced change into a single-ended current at the next stage. The stage sets three important op-amp properties. Its bias current sets input resistance and input bias current. Mismatch between Q1 and Q2 and the load mirror sets input offset voltage. The tail source output resistance and the mirror matching set common-mode rejection ratio, CMRR. For a MOSFET pair the gate draws almost no DC current, so input resistance is set by the bias network; for a BJT pair base current sets it. The input stage also gives gain, Av1, but not the whole open-loop gain. In the 741 the first stage is this kind of differential pair with an active load. See 5.1 and 5.4.

Gain stage and level shifter

The gain stage gives most of the voltage gain. It is a common-emitter (CE) stage with a BJT, or a common-source (CS) stage with a MOSFET, loaded by a current source or current mirror. A high load resistance at the output node turns a small current change into a large voltage change. That is why Av2 in the worked example is 500, much larger than Av1. The same high-resistance node is where Miller compensation is placed: a capacitor from the gain-stage output back to its input, covered in 5.7.

The level shifter sits between the gain stage and the output stage. The gain-stage output has a DC level that is too high for the output stage input. The level shifter moves that DC level down without changing the signal much. Common forms are an emitter follower or source follower with a current source, or a resistor divider. Its signal gain is near 1, not a new gain stage; in the example Av3 = 0.5 shows it can even attenuate. It must present a light load to the gain stage, or it will reduce Av2. Some syllabi call the gain stage the intermediate stage and the output stage the output buffer.

Output stage and overall gain

The output stage is a class AB push-pull buffer. An NPN and a PNP transistor (or an NMOS and a PMOS) source or sink load current. Small bias diodes or a bias network keep both devices slightly on, so crossover distortion is low. The stage has voltage gain near 1, Av4 = 0.98 in the example, but it has current gain. That current gain gives low output resistance and the ability to drive a load such as a speaker, cable, or ADC input. A short-circuit limit protects the output devices when the load current is too high. The output swing is not the full supply: saturation voltages and device drops stop it short of the rails. The overall open-loop gain is the product of the four stage gains.

A_ol = Av1 × Av2 × Av3 × Av4, and A_dB = 20 log₁₀ |A_ol|

A_ol is the open-loop voltage gain in V/V; Av1 is the input-stage voltage gain; Av2 is the gain-stage voltage gain; Av3 is the level-shifter voltage gain; Av4 is the output-buffer voltage gain; A_dB is the same gain in decibels.

Worked example

Question. An op-amp has input-stage gain Av1 = 100, gain-stage gain Av2 = 500, level-shifter gain Av3 = 0.5, and output-buffer gain Av4 = 0.98, all in V/V. Find the open-loop gain in V/V and in dB. For a differential input vid = 1 mV, find the ideal output and say whether a ±12 V supply clips it.

  1. Write the stage gains: Av1 = 100, Av2 = 500, Av3 = 0.5, Av4 = 0.98.
  2. Multiply for open-loop gain: A_ol = 100 × 500 × 0.5 × 0.98.
  3. First product: 100 × 500 = 50,000.
  4. Next: 50,000 × 0.5 = 25,000.
  5. Final: 25,000 × 0.98 = 24,500 V/V.
  6. Convert to dB: A_dB = 20 log₁₀(24,500).
  7. log₁₀(24,500) = 4.3892, so A_dB = 20 × 4.3892 = 87.78 dB.
  8. Input in volts: vid = 1 mV = 0.001 V.
  9. Ideal output: Vout = A_ol × vid = 24,500 × 0.001 = 24.5 V.
  10. The supply is ±12 V, so the largest possible magnitude is about 12 V, and less in practice. Since 24.5 V is greater than 12 V, the output clips.

Answer. The open-loop gain is 24,500 V/V, or 87.78 dB; a 1 mV input difference would demand 24.5 V, so on ±12 V supplies the output clips.

Exam traps

  • Multiplying stage gains in dB, or adding linear gains and calling the sum decibels. Convert each stage to dB and add, or multiply linear gains and convert once at the end.
  • Thinking the level shifter adds gain. It moves DC; its signal gain is at most about 1 and may be below 1, as Av3 = 0.5 shows.
  • Assuming the output can reach the supply rails. Saturation voltages and output-device drops keep the real swing below the rails.
  • Ignoring the output current limit. A heavy load or a short circuit can hit the limit, so the output voltage collapses even when the gain formula predicts a larger value.

5.6 Op-amp parameters: offset, bias current, slew rate, PSRR

Real op-amps are not ideal. At DC, the input transistors draw bias currents IB+ and IB−, and mismatch between the two input halves creates input offset voltage VOS and offset current IOS. These appear as output errors, especially in high-gain or high-resistance circuits. At large signals or high frequencies, the output can move only so fast; slew rate SR limits it. Supply changes leak to the input as offset, measured by PSRR. Data sheets give all four, plus output swing, input common-mode range and drift. You use them when a sensor front end must hold microvolts, or a video buffer must swing volts quickly.

You need: CMRR from 5.2, the four op-amp stages from 5.5, and gain-bandwidth product from Unit 3.

Input offset voltage and bias current

Input offset voltage VOS is the differential DC voltage you must apply between the inputs to make Vout = 0. An ideal op-amp needs 0 V. A real one needs a few microvolts to a few millivolts because the input pair and load are not perfectly matched. The sign can be positive or negative. In a unity-gain buffer the output offset equals VOS. In a non-inverting amplifier the output error is VOS(1 + Rf/Ri).

Bias currents IB+ and IB− are the DC currents that flow into the non-inverting and inverting inputs. Their average is the input bias current IB. Their mismatch is the input offset current IOS. If a resistor R sits at an input, the bias current makes a voltage IBR that adds like an offset. For a buffer with source resistance Rs, the output error from the non-inverting input is IB+Rs. Use equal DC resistances on both inputs to cancel the average IB, but IOS still causes an error.

I<sub>B</sub> = (I<sub>B+</sub> + I<sub>B−</sub>)/2,   I<sub>OS</sub> = |I<sub>B+</sub> − I<sub>B−</sub>|

IB+ and IB− are the DC currents into the non-inverting and inverting inputs.

VOS and IB drift with temperature. Data sheets give drift in µV/°C and nA/°C. In a DC sensor front end these errors set the smallest signal you can resolve. Chopper or auto-zero amplifiers reduce them, at the cost of chopping noise and bandwidth.

Slew rate and full-power bandwidth

Slew rate SR is the maximum rate of change of the output: SR = max |dVout/dt|. It is a large-signal limit. A small sine wave may pass with good bandwidth, but a large step can still be limited. In a two-stage op-amp the input pair steers the tail current I5 into the compensation capacitor Cc, so SR = I5/Cc. The current charging Cc is I5 when the input is overdriven.

SR = I<sub>5</sub>/C<sub>c</sub>,   FPBW = SR/(2π V<sub>peak</sub>)

I5 is the tail current, Cc is the compensation capacitor, and Vpeak is the peak sine-wave output voltage.

For a step of size ΔV, the slewing time is t = ΔV/SR. For a sine wave Vout = Vpeak sin(2πft), the maximum slope is 2π f Vpeak. To avoid slew limiting, 2π f Vpeak ≤ SR. The full-power bandwidth is therefore FPBW = SR/(2π Vpeak). Use peak, not peak-to-peak. A 0.5 V/µs op-amp with 2 V peak gives 39.8 kHz.

The input transistor transition frequency fT rises with gm, the input-pair transconductance. Raising I5 to improve SR also raises gm and can hurt stability. Source degeneration lowers the input-pair gm, so for the same gm you can run a larger tail current I5. With the same Cc, SR = I5/Cc then rises. The cost is lower input-stage gain and lower fT. The choice of Cc is part of compensation, covered in 5.7.

PSRR, swing, common-mode range and drift

PSRR measures how much a supply change appears as an input offset. In linear form, PSRR = ΔVOS/ΔVsupply, often in µV/V. In dB, PSRRdB = 20 log10 |Ad/Asupply| = −20 log10 |ΔVOS/ΔVsupply|. Put the ratio in V/V inside the log. Example: PSRR = 100 µV/V = 1 × 10−4 V/V, so PSRRdB = −20 log10(1 × 10−4) = 80 dB. A positive linear PSRR means a positive supply step shifts VOS positive. Data sheets usually quote the magnitude; the dB form is positive for good rejection. PSRR is usually specified separately for +VS and −VS changes. PSRR falls with frequency, so a 1 MHz ripple may pass more easily than DC. CMRR is different: it is about common-mode input, defined in 5.2.

PSRR = ΔV<sub>OS</sub>/ΔV<sub>supply</sub>,   PSRR<sub>dB</sub> = 20 log<sub>10</sub> |A<sub>d</sub>/A<sub>supply</sub>|

Ad is the differential gain, Asupply is the gain from supply to output, and ΔVsupply is a supply change. Put the ratio in V/V inside the log.

Output swing is the largest Vout before clipping, given as VOH and VOL relative to the rails. Input common-mode range is the set of input voltages over which the input pair stays biased; outside it, gain falls and the output may reverse phase. Temperature drift changes VOS and IB; data sheets give µV/°C and nA/°C. These limits often decide whether you need a rail-to-rail op-amp.

5.7 Frequency compensation and two-stage CMOS op-amp

A two-stage CMOS op-amp has gain from two stages, so it has two poles. In feedback those poles can add enough phase lag to make a stable amplifier oscillate. Frequency compensation deliberately moves one pole low and the other high. The usual method is a Miller capacitor Cc from the second-stage output back to the first-stage output. The price is lower unity-gain bandwidth and a limited slew rate. Audio preamps, sensor interfaces and power-supply control loops all use compensated op-amps, so the trade-off is a practical design step, not a formula exercise.

You need: 5.4, 5.5, 5.6, and Unit 3 on poles and phase margin.

Why a two-stage op-amp needs compensation

The first stage is the active-loaded differential pair from 5.4. Its transconductance Gm1 converts the input difference into a current. The second stage is a common-source amplifier with transconductance Gm2 and output resistance R2. It gives voltage gain and drives the load. The first-stage output has resistance R1; the second-stage output has capacitance C2.

Each node with resistance and capacitance gives a pole. Two poles close in frequency add phase lag quickly. In unity-gain feedback the loop can reach 180° phase shift while the gain is still above one, so the circuit oscillates. Compensation makes the loop gain fall below one before the phase reaches that point.

C_Miller = Cc (1 + A2)

C_Miller is the capacitance seen at the first-stage output; Cc is the compensation capacitor; A2 is the voltage gain of the second stage.

Connect Cc from the second-stage output to the first-stage output. The second stage inverts, so Cc sees the full second-stage gain A2. At the first-stage output it looks like Cc(1+A2). That large Miller capacitance makes the first pole very low. The same capacitor also makes the second pole high. The two poles are split apart, which is what negative feedback needs.

Design equations: poles, unity gain and slew rate

Write angular poles in rad/s and ordinary frequencies in Hz. After Miller compensation the dominant pole and the second pole are approximately:

p1 ≈ 1/(Gm2 R1 R2 Cc)

p1 is the dominant pole in rad/s; Gm2 is the second-stage transconductance in A/V; R1 is the first-stage output resistance in Ω; R2 is the second-stage output resistance in Ω; Cc is the compensation capacitance in F.

p2 ≈ Gm2/C2

p2 is the second pole in rad/s; Gm2 is the second-stage transconductance in A/V; C2 is the total capacitance at the second-stage output in F.

The unity-gain frequency is set mainly by Gm1 and Cc:

f_u ≈ Gm1/(2π Cc)

f_u is the unity-gain frequency in Hz; Gm1 is the first-stage transconductance in A/V; Cc is the compensation capacitance in F.

At f_u the dominant pole gives about -90°. The second pole adds -arctan(f_u/f_p2). For 60° phase margin, place f_p2 at least about 2.2 f_u; many designs use 3 f_u to allow for the right-half-plane zero and process spread. The example uses 3 f_u.

The right-half-plane zero comes from signal feedthrough through Cc: f_z = Gm2/(2π Cc). It adds phase lag, not lead. Add a nulling resistor Rz = 1/Gm2 in series with Cc to push the zero high or into the left half plane.

SR = I5/Cc

SR is the slew rate in V/s; I5 is the first-stage tail current in A; Cc is the compensation capacitance in F.

If the input pair has overdrive VOV and Gm1 = I5/VOV, then SR = 2π f_u VOV. Some syllabi call this the transition-frequency to slew-rate relation. Raising f_u by lowering Cc raises SR for the same I5. Reducing Gm1 by source degeneration lets Cc be smaller for the same f_u, so SR rises; only a few universities teach that method in detail.

Design checklist before sign-off

  1. Fix Cc from the required f_u: Cc ≈ Gm1/(2π f_u).
  2. Check the dominant pole with p1 ≈ 1/(Gm2 R1 R2 Cc); it should be far below f_u.
  3. Place f_p2 at 3 f_u or more, then find Gm2 ≈ 2π f_p2 C2.
  4. Add Rz = 1/Gm2 in series with Cc if the right-half-plane zero reduces phase margin.
  5. Check large-signal speed with SR = I5/Cc; increase I5 or reduce Cc if SR is too low.

Worked example

Question. A two-stage CMOS op-amp has Gm1 = 1 mS, I5 = 200 µA, Cc = 2 pF, and C2 = 5 pF. Find the unity-gain frequency, the slew rate, and the minimum Gm2 for a second pole at 3 times the unity-gain frequency.

  1. Data: Gm1 = 1 mS = 1×10⁻³ A/V, I5 = 200 µA = 200×10⁻⁶ A, Cc = 2 pF = 2×10⁻¹² F, C2 = 5 pF = 5×10⁻¹² F.
  2. Unity-gain frequency: f_u = Gm1/(2π Cc) = (1×10⁻³)/(2π×2×10⁻¹²) = 7.9577×10⁷ Hz = 79.6 MHz.
  3. Slew rate: SR = I5/Cc = (200×10⁻⁶)/(2×10⁻¹²) = 1.00×10⁸ V/s = 100 V/µs.
  4. Required second pole: f_p2 = 3 f_u = 3×79.577 MHz = 238.7 MHz, so p2 = 2π f_p2 = 1.500×10⁹ rad/s.
  5. Second-stage transconductance: Gm2 = p2 C2 = (1.500×10⁹)(5×10⁻¹²) = 7.50×10⁻³ S = 7.5 mS.
  6. Exact check: Gm2 = 3 Gm1 C2/Cc = 3(1 mS)(5 pF)/(2 pF) = 7.5 mS.

Answer. f_u = 79.6 MHz, SR = 100 V/µs, and the minimum Gm2 is 7.5 mS.

Exam traps

  • Using Cc as the load capacitor: Cc is the Miller compensation capacitor across the second stage; C2 is the capacitance at the second-stage output.
  • Forgetting Miller multiplication: at the first-stage output, Cc looks like Cc(1+A2), so the dominant pole is much lower than a simple R1Cc estimate.
  • Placing Cc across the first stage instead of from the second-stage output to the first-stage output: compensation must close around the second gain stage.
  • Ignoring the right-half-plane zero: it adds phase lag near f_u, so a two-pole phase-margin calculation is optimistic unless a nulling resistor is used.
  • Mixing rad/s and Hz, or using I5/C2 for slew rate. Convert poles with 2π and use SR = I5/Cc.

5.8 Operational transconductance amplifier (OTA)

An operational transconductance amplifier (OTA) takes a voltage difference at its input and delivers a current at its output. The ratio of the two is the transconductance Gm, in siemens, that is, amperes per volt. Gm is not fixed: an external bias current IBIAS sets it, so the same chip can be made more or less sensitive while it runs. OTAs are the building block of tunable continuous-time filters, variable-gain amplifiers and sine-wave oscillators inside integrated circuits.

You need: the differential pair (5.1), the current mirror (5.3) and the active-load CMOS stage (5.4).

A voltage in, a current out

The OTA symbol is a triangle like an op-amp's, with one extra terminal: the bias input. One line describes its job.

Iout = Gm × vid = Gm × (v₊ − v₋)

Iout is the output current in A; Gm is the transconductance in A/V (siemens); v₊ and v₋ are the voltages at the two inputs, both in V; vid is their difference in V.

The output is a current source. A current source has a very high output resistance Rout, often hundreds of kilohms, so the output current barely changes when the voltage at the output node changes. Connect a resistor R from the output to ground and that current produces a voltage Gm × vid × R. Connect a capacitor C instead and the current charges it, so the output voltage becomes an integral of vid.

An op-amp is different. It has a voltage output, an output resistance of a few ohms or less, and enough open-loop gain that feedback fixes the closed-loop gain as a ratio of two resistors. An OTA has no such buffer: the voltage at its output is decided by whatever circuit you attach, and its gain Gm × R changes whenever the bias current changes.

Setting Gm with the bias current

Take the CMOS differential pair with a tail current source IBIAS and a current-mirror load. At vid = 0 the tail current splits equally, so each transistor carries ID = IBIAS/2 and sits at an overdrive VOV = VGS − VTH. The small-signal transconductance of one transistor is gm = 2ID/VOV = √(2k′(W/L)ID). A differential input vid shifts current from one side to the other; the difference of the two drain currents is the output current, Iout = Gm × vid, where Gm is the expression below.

Gm = IBIAS/VOV = √(2k′(W/L)ID) = √(k′(W/L)IBIAS)

Gm is the transconductance in A/V; IBIAS is the tail bias current in A; VOV = VGS − VTH is the quiescent overdrive in V; ID = IBIAS/2 is the drain current of each device in A; k′ = µCox is the process transconductance parameter in A/V²; W/L is the aspect ratio, dimensionless.

The last form is the tuning knob. Gm rises as the square root of IBIAS, so quadrupling the bias current only doubles Gm. The path stays biased with a balanced output and the input common-mode level can stay fixed, but ID and VOV do move with IBIAS: VOV changes as √IBIAS.

A BJT pair behaves differently. Its transconductance is IC/VT = IBIAS/(2VT), directly proportional to the bias current, and its transfer curve is Iout = IBIAS × tanh(vid/(2VT)), with VT ≈ 26 mV at room temperature.

Linear range, and where OTAs are used

The formula Iout = Gm × vid is a small-signal result. The pair is close to linear only for |vid| well below VOV — a few tens of millivolts for a few percent error of slope. At |vid| = VOV the slope Gm has already fallen by about 40 percent. The current saturates at |vid| = √2 × VOV, where one transistor takes the whole tail current. For a BJT pair the same flattening starts at about ±VT, only ±26 mV.

  • Gm-C filters: in a Gm-C filter each resistor is replaced by an OTA, the capacitor stays, and the cut-off frequency becomes Gm/C, which moves with IBIAS.
  • Variable-gain amplifiers: the gain Gm × R is set electrically, with no switched resistors.
  • Oscillators and waveform generators: an OTA feeding a capacitor makes an integrator whose time constant can be trimmed.
  • On-chip resistors: a precise resistor is hard to build in CMOS, so an OTA with feedback emulates one whose value is 1/Gm.

Some OTAs add an output buffer inside the package, so the part has a current-mode core and a voltage output. Without that buffer an OTA must drive a virtual ground or a high-impedance node, never a heavy load.

Worked example

Question. A simple CMOS OTA uses a differential pair with k′ = 100 µA/V², W/L = 25 and a tail bias current IBIAS = 100 µA. (a) Find the overdrive VOV of each device. (b) Find Gm. (c) Find the output current for vid = 10 mV. (d) State the limit of the linear range.

  1. Each device carries half the tail current: ID = IBIAS/2 = 100 µA / 2 = 50 µA.
  2. Square-law overdrive: VOV = √(2ID/(k′(W/L))) = √(2 × 50 µA / (100 µA/V² × 25)) = √(100 µA / 2500 µA/V²) = √0.04 V² = 0.2 V.
  3. Transconductance from the operating point: Gm = 2ID/VOV = 2 × 50 µA / 0.2 V = 100 µA / 0.2 V = 5 × 10⁻⁴ A/V = 0.5 mS.
  4. Cross-check with the bias form: Gm = IBIAS/VOV = 100 µA / 0.2 V = 5 × 10⁻⁴ A/V. Same value, so the arithmetic is consistent.
  5. Cross-check with the process form: Gm = √(2k′(W/L)ID) = √(2 × 100 µA/V² × 25 × 50 µA) = √(2.5 × 10⁻⁷ A²) = 5 × 10⁻⁴ A/V. Same again.
  6. Output current: Iout = Gm × vid = 5 × 10⁻⁴ A/V × 10 × 10⁻³ V = 5 × 10⁻⁶ A = 5 µA.
  7. This is 5 µA out of a 100 µA tail current, only 5 percent of the ±100 µA limit, so the small-signal formula is valid here.
  8. Linear range: close to linear only for |vid| well below VOV — a few tens of millivolts for a few percent slope error. At |vid| = VOV = 0.2 V the slope has already fallen by about 40 percent. The current saturates at |vid| = √2 × 0.2 V = 0.283 V, where one device carries the whole tail current.

Exam traps

  • Calling Gm a voltage gain. Gm is a conductance in A/V; a voltage gain is dimensionless. The OTA's voltage gain is Gm × R and depends on the load you attach.
  • Using Iout = Gm × vid outside the linear range. The output current cannot exceed ±IBIAS, and the slope collapses near |vid| = √2 × VOV.
  • Forgetting that Gm moves with IBIAS. In a Gm-C filter, changing the bias current changes the cut-off frequency, the gain and the distortion together.
  • Assuming the OTA can drive any load. With no buffer its output resistance is very high, so a heavy resistive load converts the current into a voltage and also destroys the intended transconductance.
  • Taking Iout as the drain current of one transistor. It is the difference of the two drain currents, which is why the bias current cancels and the common-mode input is rejected.

Remember Define transconductance and give its unit. 2 marks

Transconductance is the ratio of output current to input voltage difference, Gm = Iout/vid. Its unit is the siemens, S = A/V.

A buffer would lower the output resistance, so the output current would start to depend on the output voltage and the device would no longer behave as a current source. Buffers are added only in variants meant to drive loads directly.

Apply An OTA has Gm = 0.4 mS and VOV = 0.25 V. Find Iout for vid = 20 mV and say whether the small-signal formula is valid. 4 marks

Iout = Gm × vid = 0.4 × 10⁻³ A/V × 20 × 10⁻³ V = 8 × 10⁻⁶ A = 8 µA. Here |vid| = 20 mV is well below VOV = 0.25 V, so the pair is inside the linear range and the formula holds.

Apply The bias current of a CMOS OTA is raised from 50 µA to 200 µA. By what factor does Gm change? 4 marks

For a CMOS pair Gm = √(k′(W/L)IBIAS), so Gm is proportional to √IBIAS. The ratio is √(200/50) = √4 = 2, so Gm doubles.

Analyze Explain why Gm falls when vid becomes large. 5 marks

As vid grows, one device takes more of the tail current and the other less. The extra current available on the weaker side shrinks, so the incremental change in the difference current for a further increase in vid gets smaller. At |vid| = √2 × VOV one device takes the whole tail and the other is cut off; the current cannot rise further, so the slope dIout/dvid becomes zero.

Analyze Why is a tunable OTA preferred over a diffused resistor in an integrated continuous-time filter? 5 marks

An integrated resistor has a large process spread (its value can differ widely from chip to chip) and cannot be adjusted after fabrication, and its value drifts with temperature. In an OTA-C filter the equivalent resistance is 1/Gm, set by a bias current, so the cut-off frequency Gm/C can be trimmed on the bench or by a tuning loop, and several filters on one chip can track each other.

Takeaways

  1. A matched pair fed by one tail current sends more current down whichever side has the higher input, so it amplifies the difference and largely ignores what both inputs do together.
  2. Any two inputs can be written as a differential part plus a common-mode part; CMRR is the single number that says how well an amplifier multiplies the first and drops the second.
  3. A current mirror copies a reference current using geometry ratio, and its accuracy at the output is limited by the finite output resistance of the copying transistor.
  4. Replacing load resistors with a current-mirror active load raises output resistance, increases gain, and turns a differential input into a single-ended output in one step.
  5. An op-amp is four functions in a chain: differential input stage, high-gain stage, level shifter and output buffer.
  6. Offset voltage and bias current are the DC errors of a real op-amp; slew rate and PSRR describe how it behaves when the signal is fast or the supply is noisy.
  7. Miller compensation splits the two poles of a two-stage op-amp to buy phase margin, and the price is lower bandwidth and a slew rate fixed by I_TAIL/C_C.
  8. An OTA gives an output current proportional to input voltage, with transconductance set by a bias current, which makes it easy to tune and to use in filters.

The lowest-frequency pole of an amplifier; it sets the point where gain begins to roll off.
Gain-bandwidth product
The frequency at which the open-loop gain falls to unity; for a compensated op-amp it equals the unity-gain frequency.
Half-circuit
The single-transistor equivalent obtained by splitting a symmetric differential circuit for differential-mode analysis.
Input bias current
The DC current that flows into each input terminal of a real op-amp.
Input offset current
The difference between the two input bias currents.
Input offset voltage
The small differential DC voltage that must be applied to make a real op-amp's output zero.
Level shifter
A stage that shifts a DC voltage level without changing the signal amplitude, so the next stage is properly biased.
Matched pair
Two transistors made identically and placed close together so their parameters track over temperature and process.
Miller compensation
Using a capacitor across a high-gain stage so the Miller effect creates a low-frequency dominant pole.
Operational transconductance amplifier
An amplifier whose output is a current proportional to the differential input voltage, with transconductance set by bias.
Output buffer
A unity-gain stage that drives load current and presents a low output resistance.
Output resistance r_o
The small-signal resistance seen looking into a device or source; it decides how much current changes with output voltage.
Phase margin
180° minus the loop phase shift at the frequency where loop gain is unity; it measures stability in feedback.
Pole splitting
The effect of Miller compensation: the dominant pole moves lower and the second pole moves higher.
Power-supply rejection ratio
The ratio of a supply-voltage change to the equivalent input offset change it produces.
Push-pull stage
A pair of complementary transistors that source and sink current, usually biased in class AB.
Slew rate
The maximum rate of change of the output voltage, usually in V/µs.
Tail current
The constant current forced into the joined emitters or sources of a differential pair; it sets bias and limits output current.
Transition frequency f_T
The frequency at which a transistor's current gain falls to unity; it links device speed to slew rate.
