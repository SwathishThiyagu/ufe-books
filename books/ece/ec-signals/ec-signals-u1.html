1.1 Signals and systems defined; CT and DT signals

A signal carries information as a function of an independent variable. A system takes an input signal and produces an output signal. In continuous time the variable is a real number t, usually seconds. In discrete time it is an integer n, a plain count with no unit. Every phone, ECG monitor and power grid runs on this pair: measure a signal, pass it through a system, read the result. This chapter fixes the words and the notation x(t), x[n], y(t) and y[n] that the rest of the subject uses.

You need: basic trigonometry (sin and cos at standard angles such as π/2 and π) and the school idea of a function; no earlier chapter of this book.

A signal is a function that carries information

A signal is a function of an independent variable that carries information. Write x(t). Here x is the signal, t is the independent variable, and the number x(t) at one particular t is the amplitude. The amplitude carries units: volts on a microphone lead, amperes in a motor winding, °C in a room, rupees for a share price. Some syllabi call a signal a function of one or more independent variables; a photograph has two, row and column.

A continuous-time (CT) signal has a value for every real t in its range. Speech voltage from a microphone is CT: between t = 0.001 s and t = 0.0011 s there are infinitely many instants, and a voltage exists at each one.

A discrete-time (DT) signal has a value only at integer n. Write x[n]. The number n is a count, not a time: n = …, −2, −1, 0, 1, 2, … Nothing is defined at n = 2.5. Each value x[n] is called a sample, whether it was measured, counted or computed from a formula.

  • Daily closing price of one share on a stock exchange: one value per trading day, index n = 0, 1, 2, …
  • Number of UPI transactions completed each day: discrete by nature, no sampling needed.
  • Room temperature read by a sensor every 10 ms: discrete in the record, though the room itself is continuous.

x[n] = x(nTs), n = 0, ±1, ±2, …

x(t) is the CT signal; Ts is the sampling interval in seconds; n is the integer index; x[n] is the resulting sequence. This equality holds only for ideal sampling.

A system maps an input signal to an output signal

A system is an operator that turns an input signal into an output signal. Write y(t) = T{x(t)} for CT and y[n] = T{x[n]} for DT. T is the rule, x is the input, y is the output. Input and output share the same independent variable.

Treat the system as a black box. What matters is the rule from input to output, not the circuit inside. The box may be an op-amp board, a few lines of Python, or a physical room whose temperature reacts to a heater. Chapter 1.5 classifies CT and DT systems in detail.

Two examples fix the idea. An audio amplifier with y(t) = 100 x(t) takes an input of 20 mV and gives 2 V. A moving average that replaces each reading by the mean of the last five readings is a DT system: input x[n], output y[n], index n in both.

  1. Read the independent variable on the input. Real t in seconds means CT; integer n means DT.
  2. Check that the output uses the same variable. A CT input with a DT output, such as a sampler, makes a hybrid system: it converts CT to DT, so it is neither a pure CT nor a pure DT system.
  3. State the rule T in one line, then test it. Samplers and reconstruction are studied with the sampling theorem.

Discrete-time signals are not always sampled. Transactions per day and the daily close of a stock are discrete before any instrument touches them. Sampling is one way to make a DT signal, not the definition of it. The sampling theorem states how much of x(t) survives the sampler.

The two families need different tools. CT signals are analysed with the Fourier series, Fourier transform and Laplace transform (see Fourier series and Fourier transform, and Laplace transform analysis). DT signals use the DTFT, DFT and Z-transform. All of them build on the notation fixed here.

Worked example

Question. A vibration sensor on a pump gives the voltage x(t) = 4 sin(20πt) V with t in seconds. A sampler records it every Ts = 10 ms, producing x[n] = 4 sin(0.2πn) V. (a) Say which signal is CT and which is DT. (b) Show that sampling x(t) every 10 ms gives the stated x[n]. (c) Compute x(0.025 s) and x[5], each in volts.

  1. (a) x(t) is defined for every real t in seconds, so it is CT. x[n] is defined only at integer n, so it is DT.
  2. (b) Sampling means x[n] = x(nTs), with Ts = 10 ms = 0.01 s.
  3. 20π × 0.01 = 0.2π rad, so x[n] = 4 sin(20π × 0.01 n) = 4 sin(0.2πn) V. This matches the given sequence.
  4. (c) 20π × 0.025 = 0.5π rad = 90°, and sin 90° = 1. So x(0.025 s) = 4 × 1 = 4 V.
  5. 0.2π × 5 = π rad = 180°, and sin 180° = 0. So x[5] = 4 × 0 = 0 V.

Exam traps

  • x[n] is not x(nTs) in general. That equality needs ideal sampling; n is an integer count, never a time in seconds.
  • Brackets and parentheses are not decoration: x(t) is CT, x[n] is DT. Writing x(5) for a sequence loses marks.
  • The argument of sin and cos is in radians. 0.5π rad is 90°, not 0.5°; a calculator left in degree mode gives wrong answers.
  • A system is CT or DT by the variable on its input and output, not by its hardware. A filter running on a phone is still a DT system.
  • x(t) is the whole function; x(2) is one number. Saying 'the signal is 4 V' describes one amplitude, not the signal.

1.2 Classification: energy, power, periodic, even and odd signals

A signal is measured by its size, its repetition and its symmetry. Energy and average power answer how large the signal is over all time. Periodicity answers whether it repeats. Even and odd symmetry answers whether it is a mirror image about zero. These labels decide which transform applies, whether a Fourier series exists, and which terms vanish. You meet them in a mains voltage waveform, a heart-rate trace, and a log of UPI transactions sampled every second.

You need signal notation and the continuous-time (CT) versus discrete-time (DT) distinction from Chapter 1.1.

Energy and average power measure size

Total energy adds the squared signal over all time. Average power divides energy by the length of the observation window, then lets the window grow without limit. A finite pulse has finite energy and zero average power. A never-ending finite-amplitude wave has infinite energy and finite nonzero average power.

E = ∫−∞∞ |x(t)|² dt

E is total energy; x(t) is the CT signal; |x(t)|² is the normalised instantaneous power, the power x would deliver to a 1 Ω resistor; if x is in volts, E is then in joules.

P = lim (T → ∞) (1/T) ∫ |x(t)|² dt,  taken over −T/2 ≤ t ≤ T/2

P is the normalised average power (watts when x is a voltage across 1 Ω); T is the length of the averaging window in seconds; the window is centred on zero.

For DT signals replace the integral by a sum and the window length by the number of samples.

E = Σ |x[n]|²,  summed over all n
P = lim (N → ∞) (1/(2N + 1)) Σ |x[n]|²,  summed over −N ≤ n ≤ N

n is the integer sample index; 2N+1 is the number of samples from −N to N; E and P both have units of (sample value)², because 2N+1 is a pure count.

  • Energy signal: 0 < E < ∞ and P = 0. Example: a single rectangular pulse.
  • Power signal: 0 < P < ∞ and E = ∞. Example: a sine wave that never stops.
  • Neither: both E and P are infinite. Example: x(t) = t for all t.
  • Some syllabi call energy and power the size of a signal.

Periodic and aperiodic signals

A periodic signal repeats after a fixed shift. The smallest positive shift is the fundamental period. A signal that never repeats is aperiodic.

x(t) = x(t + T) for all t

T is any positive period in seconds; the fundamental period T0 is the smallest positive T; the fundamental frequency is f0 = 1/T0 Hz and the angular frequency is ω0 = 2π/T0 rad/s.

In DT the shift must be an integer number of samples.

x[n] = x[n + N] for all integer n

N is a positive integer period in samples; N0 is the smallest positive integer period.

A DT sinusoid cos(Ωn + φ) is periodic only when Ω/(2π) is a rational number. If Ω/(2π) = m/N in lowest terms, then N0 = N samples. In CT, a sum of two periodic signals is periodic only when the ratio T₁/T₂ of their periods is a rational number; its period is then the least common multiple of T₁ and T₂. In DT, a sum of periodic sequences is always periodic, because two integer periods always have a common multiple.

Even and odd signals

An even signal is unchanged by time reversal. An odd signal changes sign under time reversal. The definitions use the same rule for CT and DT, with −t replaced by −n.

Even: x(−t) = x(t); Odd: x(−t) = −x(t)

x(t) is the signal value at time t; −t is the reversed time; an odd signal must satisfy x(0) = 0.

Every signal splits into an even part and an odd part. Add and subtract the signal and its reversed copy.

xₑ(t) = (x(t) + x(−t))/2,   xₒ(t) = (x(t) − x(−t))/2

xₑ is the even part; xₒ is the odd part; x(t) = xₑ(t) + xₒ(t) for every t.

  • cos(ωt) and a constant are even; sin(ωt) and t are odd.
  • even × even = even; odd × odd = even; even × odd = odd.
  • A signal with a nonzero average has a nonzero even part.

Worked example

Question. For x(t) = 6 cos(200πt) + 3 V, find the fundamental period T0, the average power P normalized to 1 Ω, the total energy E, and the even and odd parts.

  1. Compare with A cos(ωt) + DC. Here A = 6 V, ω = 200π rad/s, and DC = 3 V.
  2. T0 = 2π/ω = 2π/(200π) = 0.01 s = 10 ms. The fundamental frequency is f0 = 1/T0 = 100 Hz.
  3. Average power of A cos(ωt) is A²/2 = 6²/2 = 18 W. Average power of the DC term is 3² = 9 W. The cross term averages to zero over whole periods.
  4. P = 18 + 9 = 27 W.
  5. Energy over one period is P × T0 = 27 × 0.01 = 0.27 J. The signal repeats forever, so E = 0.27 + 0.27 + … = ∞.
  6. cos(200πt) is even and the constant 3 is even, so x(−t) = x(t). Therefore xₑ(t) = x(t) and xₒ(t) = 0.

Answer. T0 = 0.01 s, P = 27 W, E = ∞, xₑ(t) = x(t), and xₒ(t) = 0.

Question. A DT signal is x[n] = 1, 2, 3 at n = 0, 1, 2 and 0 for every other n. (a) Find its energy E. (b) Find its even part xₑ[n] and odd part xₒ[n]. (c) Find the energy of each part and compare their sum with E.

  2. (b) Reverse the sequence: x[−n] = 3, 2, 1 at n = −2, −1, 0. Then xₑ[n] = (x[n] + x[−n])/2 and xₒ[n] = (x[n] − x[−n])/2, sample by sample, as in the table.

Exam traps

  • A periodic finite-amplitude signal is a power signal, not an energy signal. Its energy is infinite, not zero.
  • Do not confuse zero average value with zero average power. sin(t) has zero mean but P = 1/2 for unit amplitude.
  • For DT sinusoids, periodic in n needs Ω/(2π) rational. A sampled sine can look periodic on paper but be aperiodic in the sample index.
  • In the even-part formula, divide by 2. Forgetting the 2 gives twice the even part.
  • An odd signal must pass through zero at the origin, so x(0) = 0. A signal with x(0) ≠ 0 cannot be purely odd.

1.3 Standard signals: impulse, step, ramp, exponential

Standard signals are a small set of functions used as building blocks: the impulse δ(t), step u(t), ramp r(t)=t u(t), and exponential eat. Any piecewise signal can be written as a sum of shifted steps, ramps or exponentials. They are also the test inputs for a system, because the response to an impulse or step describes the system completely. In practice they model a switch closing (step), a quantity rising at a steady rate such as constant-velocity motion (ramp), a capacitor discharging (exponential), and a very short hit (impulse).

You need Chapter 1.1 for the meaning of t, n, CT and DT; Chapter 1.2 helps for energy and symmetry.

Impulse and step

Unit step u(t) is 0 for t<0 and 1 for t≥0. This book uses u(0)=1. In discrete time u[n]=1 for n≥0 and 0 for n<0. The step is a switch: it turns a signal on at t=0. A shifted step u(t−a) turns on at t=a; a negative step −u(t−a) turns off.

∫ x(t) δ(t − t₀) dt = x(t₀),  integral over all t

x(t) is the signal being sampled; it must be continuous at t=t0 for this to hold. t0 is the shifting instant; the integral is over all time.

Unit impulse δ(t) is not an ordinary function. It has δ(t)=0 for t≠0 and unit area ∫ δ(t) dt=1. The value δ(0) is not an ordinary number. Its meaning is the sifting property above: the impulse picks out one value of x.

In discrete time δ[n]=1 at n=0 and 0 elsewhere. It equals u[n]−u[n−1]. The scale rule is δ(at)=δ(t)/|a| for a≠0. The absolute value matters: δ(−2t)=δ(t)/2. Some syllabi call these singularity functions, elementary signals or commonly used signal models.

Ramp and exponential

r(t)=t u(t), r[n]=n u[n]

r(t) is the continuous-time unit ramp; r[n] is the discrete-time unit ramp; u is the unit step.

Unit ramp r(t)=t u(t): r(t)=0 for t<0 and r(t)=t for t≥0. In discrete time r[n]=n u[n]. The ramp is the integral of the step, so r′(t)=u(t). In the generalized sense u′(t)=δ(t). These derivative relations let you differentiate piecewise signals without splitting them into intervals.

ejωt = cos(ωt) + j sin(ωt)

e is the base of natural logarithms; j=√−1; ω is angular frequency in rad/s; t is time in s.

Real exponential x(t)=A eat u(t) with A and a real. If a<0 the exponential decays; if a>0 it grows; if a=0 it is the constant A. The quantity 1/|a| has units of time and is the time constant for decay. Complex exponential x(t)=ejωt has real part a cosine and imaginary part a sine.

In discrete time the complex exponential is ejΩn, with Ω in rad/sample; it is periodic only when Ω/(2π) is rational. Complex exponentials are the eigenfunctions of LTI systems, which is why Fourier analysis is built on them.

Building signals and test inputs

Any piecewise signal made of straight segments and jumps can be written with steps and ramps. A jump of height K at t=a is K u(t−a). A pulse of height 2 from t=1 to t=3 is 2u(t−1)−2u(t−3). A slope change at t=a uses a shifted ramp.

Exponentials describe charging, discharging and decay. The product eatu(t) means the exponential starts at t=0; before that it is zero. A short pulse can be approximated by an impulse when the system is much slower than the pulse width.

These signals are test inputs. The impulse response h(t) is the output to δ(t); the step response is the output to u(t). They are linked by differentiation and integration. Impulse response and convolution are developed under Continuous-time LTI systems; the Fourier and Laplace transforms of these signals come with Fourier series and Fourier transform and with Laplace transform analysis.

Related functions: signum, rectangular and triangular pulses, sinc, parabolic

Some syllabi list "singularity functions and related functions". The related ones are built from the step and the ramp, so they need no new theory.

  • Signum: sgn(t) = 1 for t > 0 and −1 for t < 0, so sgn(t) = 2u(t) − 1 everywhere except the single point t = 0. It is odd.
  • Rectangular pulse: rect(t/τ) = 1 for |t| < τ/2 and 0 for |t| > τ/2, so rect(t/τ) = u(t + τ/2) − u(t − τ/2). Its area is τ.
  • Triangular pulse: tri(t) = 1 − |t| for |t| ≤ 1 and 0 outside. With ramps, tri(t) = r(t + 1) − 2r(t) + r(t − 1).
  • Sinc: sinc(t) = sin(πt)/(πt), with sinc(0) = 1 and zeros at t = ±1, ±2, … Some books use Sa(t) = sin(t)/t instead, with zeros at multiples of π; check which one your textbook uses.
  • Unit parabolic: p(t) = (t²/2) u(t), the integral of the ramp, so p′(t) = r(t).

Together they form one chain: δ(t) → u(t) → r(t) → p(t), each the running integral of the one before. Differentiating walks back down the chain.

Worked example

Question. A voltage signal is x(t)=2u(t+1)−3u(t−2)+4e−2tu(t) V. Find x(0), x(3), and dx/dt. Use u(0)=1.

  1. At t=0: u(t+1)=u(1)=1; u(t−2)=u(−2)=0; e0u(0)=1×1=1. So x(0)=2(1)−3(0)+4(1)=6 V.
  2. At t=3: u(4)=1; u(1)=1; e−6u(3)=e−6=0.002479. So x(3)=2−3+4(0.002479)=−1+0.009915=−0.9901 V ≈ −0.990 V.
  3. Differentiate each term. d[2u(t+1)]/dt=2δ(t+1). d[−3u(t−2)]/dt=−3δ(t−2). For the exponential term use the product rule: d[e−2tu(t)]/dt=−2e−2tu(t)+e−2tδ(t). Since e−2tδ(t)=δ(t), d[4e−2tu(t)]/dt=−8e−2tu(t)+4δ(t).
  4. Add the three derivatives: dx/dt=2δ(t+1)−3δ(t−2)+4δ(t)−8e−2tu(t) V/s.

Exam traps

  • δ(t) is not a finite-height pulse. Its value at t=0 is not an ordinary number; use area and sifting only.
  • sinc has two conventions. sin(πt)/(πt) is zero at t = 1, but sin(t)/t is zero at t = π; quote the definition you use.
  • The scale rule uses |a|: δ(at)=δ(t)/|a|, so δ(−2t)=δ(t)/2, not −δ(t)/2.
  • When differentiating x(t)u(t), apply the product rule; the δ(t) term comes from the jump at t=0, not from the derivative of x(t).
  • In DT, δ[n] is 1 only at n=0; it is not a sampled δ(t), and u[n]−u[n−1] gives δ[n].

1.4 Operations on signals: shifting, scaling, reversal

A signal's shape can be moved along the time axis, squeezed or stretched, and flipped left-to-right — all by changing the independent variable inside the bracket. These three edits are shifting, scaling and reversal. Every delay line, playback-speed change and time-reversed echo is one of them. They also explain why the delay inside x(2t − 1) is 0.5 s, not 1 s. Reading the order correctly earns easy marks and gives correct code in a digital filter.

You need Chapter 1.1 for the notation x(t) and x[n], and Chapter 1.3 for the pulse and step shapes used here.

Shift: slide the signal along the time axis

Write y(t) = x(t − t₀). Here t₀ is the shift, in seconds. A feature that sits at time t₁ in x(t) sits at t₁ + t₀ in y(t).

For t₀ > 0 every feature moves right, so the signal is delayed. For t₀ < 0 it moves left, so the signal is advanced. A train announcement recorded at 9:00 and played 3 s later is x(t − 3). Only the position changes, never the shape.

Discrete time uses the same rule with an integer shift: y[n] = x[n − n₀], with n₀ a whole number. Samples keep their values and spacing; only their positions change. n₀ must be an integer because x[n] exists only at integer n, so x[n − 0.5] is not defined.

Shifting models every delay: an audio echo, a satellite hop, the queue buffer inside a router, a UPI confirmation that lands two seconds late.

Scale: squeeze or stretch the time axis

Write y(t) = x(at), with a a nonzero real number. The value that x had at t₁ now appears at t = t₁/a.

y(t) = x(at)  →  a feature at t₁ moves to t₁ / a

a is the scale factor; a > 1 compresses time (faster, shorter signal), 0 < a < 1 stretches time (slower, longer signal), and a < 0 combines scaling with reversal.

A four-minute song played at double speed is x(2t); it finishes in two minutes. A pulse of width 2 s becomes a pulse of width 2/a s.

Discrete time needs an integer index, so scaling splits in two. y[n] = x[Mn] with M a positive integer keeps every M-th sample — downsampling, or decimation — and the record becomes M times shorter. Upsampling inserts M − 1 zeros between samples and stretches the record M times. x[Mn] discards samples and can fold high frequencies downwards (see Aliasing and anti-aliasing filters).

Reverse: mirror about t = 0

Write y(t) = x(−t). Every feature at t₁ moves to −t₁. A pulse on 0 to 2 s becomes the same pulse on −2 to 0 s, with the same height 2.

x(−t) flips the time axis, not the amplitude. The vertical flip is −x(t), which turns a positive pulse into a negative one. Reversal answers 'when', inversion answers 'how much'.

Reversal appears in playing a recording backwards, in the even part (x(t) + x(−t))/2 from Chapter 1.2, and in convolution, where one signal is reversed before it slides past the other (see Convolution integral and its evaluation).

Shifting, scaling and reversal change the independent variable. Some syllabi also list operations on the amplitude: amplitude scaling A x(t), where a gain of 2 doubles every value; addition x₁(t) + x₂(t) and multiplication x₁(t)·x₂(t), taken instant by instant; and differentiation and integration.

Combined operations: choose one order and keep it

A general inside form is x(at − b). Both recipes below are correct; mixing them is the usual mistake.

  1. Scale first, then shift. x(at − b) = x(a(t − b/a)). Apply x(at), then delay the result by b/a; if b/a > 0 the move is to the right.
  2. Shift first, then scale. Start from x(t − b), which is x delayed by b seconds, then replace t by at to get x(at − b). The shift stays b, then the whole picture is compressed by a.
  3. Check with the edges. If x is nonzero for A ≤ argument ≤ B, solve A ≤ at − b ≤ B for t.

Both recipes agree when each is followed fully. For x(2t − 1): scale first gives x(2t), then a right shift of 0.5 s; shift first gives a 1 s delay, then compression by 2. The delay in seconds is b/a = 0.5 s, not 1 s.

Worked example

Question. A continuous-time signal is x(t) = 2 for 0 ≤ t ≤ 2 s and x(t) = 0 elsewhere. (a) Find the nonzero time interval and the amplitude of y(t) = x(2t − 1). (b) Find the nonzero time interval and the amplitude of z(t) = x(−t + 1). (c) Sketch both against x(t).

Exam traps

  • x(2t − 1) does not mean a delay of 1 s. Shifting x right by 1 s gives x(t − 1); replacing t by 2t then gives x(2t − 1), which is the same waveform, but the compression shrinks the 1 s delay to 0.5 s. Compressing first by 2 and then shifting right by 0.5 s gives the same x(2t − 1). Quoting the delay as 1 s is the mistake.
  • In x(at − b) the delay is b/a seconds, not b.
  • x(−t) is not −x(t). The first mirrors the signal in time, the second flips it upside down. A pulse on 0 to 2 s becomes a pulse on −2 to 0 s, not a dip on 0 to 2 s.
  • For discrete time, the shift n₀ must be an integer and the scale M must be a positive integer. x[2n] keeps samples 0, 2, 4, … and is not interpolation; zero insertion is the separate upsampling step.
  • Sign slip on shifts: x(t + 3) moves the signal 3 s to the left, because the feature at t₁ now occurs at t₁ − 3.

1.5 Classification of systems: CT and DT systems

A system is an operator that turns an input signal into an output signal. Write it as y(t)=T{x(t)} in continuous time and y[n]=T{x[n]} in discrete time. The same idea covers an RC filter, a car suspension and a monthly savings balance. Engineers classify systems by memory, causality, stability, linearity, time invariance and invertibility because each label predicts how the system will behave in analysis and design. This chapter sets out those labels and shows how blocks connect in series and parallel.

You need: Chapter 1.1 for CT and DT signals, and Chapter 1.3 for the unit step used in the example.

A system maps input to output

A system is any rule, device or process that acts on an input signal and produces an output signal. Write the action as an operator T. For a continuous-time (CT) input x(t), the output is y(t)=T{x(t)}. For a discrete-time (DT) input x[n], the output is y[n]=T{x[n]}. Here t is real time in seconds; n is an integer sample index with no unit. The set of allowed inputs is the input set, and the set of resulting outputs is the output set.

The label CT or DT comes from the independent variable of the signals, not from the hardware. An RC low-pass circuit with voltage vᵢ(t) in and vₒ(t) out is CT. A car suspension with road height as input and body height as output is CT. The on/off command sequence for a room heater, recorded once per minute, is DT. A bank balance updated once per month, with balance B[n], deposits d[n] and interest rate r, is DT: B[n]=B[n−1]+d[n]+rB[n−1].

A computer can simulate a CT model by taking small time steps. The model is still CT because its signals are defined for every real t. This distinction matters when you sample a CT signal for processing; see Sampling theorem and reconstruction of signals.

Series and parallel connection

Large systems are built from smaller blocks. Two connections appear everywhere. In a series or cascade connection, the output of the first system feeds the second: y(t)=T₂{T₁{x(t)}}. In a parallel connection, the same input drives both blocks and the outputs add: y(t)=T₁{x(t)}+T₂{x(t)}.

The DT forms are identical with square brackets: y[n]=T₂{T₁{x[n]}} for series, and y[n]=T₁{x[n]}+T₂{x[n]} for parallel. The order matters in series. A filter followed by an amplifier is not the same as the amplifier followed by the filter when the amplifier clips.

An audio chain is a series connection: microphone, equaliser, amplifier, speaker. A stereo mix is a parallel connection: left and right channels add into a sum. In a control loop the blocks also connect in feedback, but that needs transfer-function tools (see Laplace transform analysis).

When blocks are linear and time-invariant, let h₁(t) and h₂(t) be their impulse responses. A series connection has overall impulse response h₁(t)*h₂(t), a convolution; in DT use h₁[n]*h₂[n]. A parallel connection has h₁(t)+h₂(t), or h₁[n]+h₂[n] in DT. In the Laplace domain these become the product H₁(s)H₂(s) and the sum H₁(s)+H₂(s); in the z domain use H₁(z)H₂(z) and H₁(z)+H₂(z). Convolution itself is developed under Convolution integral and its evaluation.

Six labels used to classify systems

Classification answers practical questions before any calculation. The labels below are independent: a system can be, for example, causal and nonlinear.

  • Memoryless (static) or with memory (dynamic). A memoryless system uses only the present input. y(t)=3x(t)+2 is memoryless. A system with memory uses past or future inputs, or past outputs. y[n]=x[n]−x[n−1] has memory because it needs x[n−1].
  • Causal or noncausal. A causal system output at any time depends only on present and past inputs, never future inputs. y[n]=x[n]+x[n+1] is noncausal because it looks one step ahead. All real-time physical systems are causal; stored data can be processed noncausally.
  • Stable or unstable. A system is bounded-input bounded-output (BIBO) stable if every bounded input gives a bounded output. An audio amplifier with a fixed gain is stable; a microphone too close to its own speaker can become unstable.
  • Linear or nonlinear. A system is linear if it obeys superposition: T{a x₁+b x₂}=a T{x₁}+b T{x₂} for any inputs x₁ and x₂ and constants a and b. y(t)=3x(t)+2 is nonlinear because of the +2. y[n]=x[n]−x[n−1] is linear.
  • Time-invariant or time-varying. A time-invariant system does not change its rule with time: a shift in the input produces the same shift in the output. A resistor is time-invariant; a circuit switched on at t=0 may be time-varying during start-up.
  • Invertible or noninvertible. A system is invertible if different inputs always give different outputs, so an inverse system can recover the input. y(t)=3x(t) is invertible with inverse x(t)=y(t)/3. y[n]=x[n]² is not invertible over all real inputs because x and −x give the same output.

The formal tests for linearity, time invariance, causality and stability are in Chapter 1.6. Here the aim is the meaning, not the test routine. Some syllabi call this system classification and speak of a system as an interconnection of elements.

Reading a system equation

To classify a system from its equation, ask three questions in order. First, is the independent variable t or n? That fixes CT or DT. Second, does the output at an index use any other index? If yes, the system has memory; if no, it is memoryless. Third, does the output use a future index? If yes, it is noncausal.

  1. Write the output for a general input, not for one numerical input.
  2. List every input value that appears on the right-hand side.
  3. If only plain x(t) or plain x[n] appears, the system is memoryless. Any other argument means memory: a delay x(t−a) or x[n−k], an advance x(t+a) or x[n+k], or a scale x(2t) or x[2n] (a, k > 0).
  4. An advance makes the system noncausal, and so does a scale such as x(2t), because at t = 1 s it needs x(2), a future value. A delay alone keeps the system causal.
  5. Check any added constant or product of inputs: either can make the system nonlinear.

A CT model is used for a physical device described by differential equations. A DT model is used for software, sampled data and sequences. A single system, such as a digitally controlled motor, may need both: a CT model of the motor and a DT controller. Sampling links the two.

Worked example

Question. A CT system is y(t)=3x(t)+2 and a DT system is y[n]=x[n]−x[n−1]. Classify each as CT or DT, and as memoryless or with memory. For x(t)=u(t), find y(1); for x[n]=n u[n], find y[2]. Justify each label in one line.

  1. Read the independent variable. The first system uses t, so it is CT. The second uses n, so it is DT.
  2. Check memory. In y(t)=3x(t)+2 the output uses only x(t), so the CT system is memoryless. In y[n]=x[n]−x[n−1] the output uses x[n−1], so the DT system has memory.
  3. For the CT input x(t)=u(t), at t=1 the unit step value is x(1)=u(1)=1 because 1 is positive.
  4. Substitute: y(1)=3×1+2=5.
  5. For the DT input x[n]=n u[n], x[2]=2u[2]=2×1=2 and x[1]=1u[1]=1×1=1.
  6. Substitute: y[2]=x[2]−x[1]=2−1=1.

Answer. The CT system is memoryless with y(1)=5, and the DT system has memory with y[2]=1, in the units of the signals.

Exam traps

  • CT and DT describe the independent variable. A digital computer that simulates a CT model does not make the model DT.
  • Causal is not the same as memoryless. y[n]=x[n−1] is causal but has memory; y[n]=x[n+1] is noncausal.
  • A constant term breaks linearity. y(t)=3x(t)+2 is nonlinear and time-invariant, not linear.
  • Stability and time invariance are independent. A system can be time-invariant and unstable, for example y[n]=2y[n−1]+x[n], a recursive system whose feedback gain 2 doubles the output every step: for x[n] = δ[n] it gives y[n] = 2ⁿu[n], which grows without bound.
  • Squaring is not a small detail: y[n]=x[n]² is nonlinear over real inputs and not invertible, because x and −x give the same output.

1.6 System properties: linearity, time invariance, causality, stability

A system is judged by four separate questions. Does it obey superposition (linearity)? Does a delayed input give only a delayed output (time invariance)? Does the output at an instant depend only on past and present input (causality)? Does every bounded input give a bounded output (BIBO stability)? Each question has a short definition and is answered with a counterexample when the system fails. These four tests decide whether the LTI tools of convolution and the Laplace transform apply, so they are asked early in every signals and systems exam.

You need the system operator idea and CT/DT notation from Chapter 1.1, and the impulse response symbol h(t) or h[n] from Chapter 1.3.

Linearity: additivity plus scaling

Write the system as y = T{x}, where T is the operator, x is the input signal and y is the output signal. The system is linear when two inputs together give two outputs together, with constants kept outside.

T{a x₁ + b x₂} = a T{x₁} + b T{x₂}

x₁ and x₂ are any two input signals; a and b are any constants (real or complex); T{x₁} and T{x₂} are the outputs for those inputs.

The formula packs two rules. Set a = b = 1 to get additivity: T{x₁ + x₂} = T{x₁} + T{x₂}. Set b = 0 to get scaling (homogeneity): T{a x₁} = a T{x₁}. A system must pass both to be linear.

Linearity exists so that a complicated input can be split into simple pieces, each piece pushed through the system, and the outputs added. The impulse, step and exponential of Chapter 1.3 are exactly such pieces.

A quick test: a linear system must give zero output for zero input, because T{0} = T{0·x} = 0·T{x} = 0. So y(t) = x(t) + 2 is not linear, while y(t) = t x(t) is linear even though its coefficient changes with time.

Time invariance and causality

Time invariance is about shifts, not about the system ageing. Delay the input by t₀ seconds and the whole output must delay by the same t₀, unchanged in shape.

x(t − t₀) → y(t − t₀)   for every t₀;   x[n − n₀] → y[n − n₀] for every integer n₀

t₀ is the delay in seconds for continuous time (CT); n₀ is the delay in samples for discrete time (DT); y is the output produced by x.

  1. Take a test input x and find the output y = T{x}.
  2. Form the shifted input x(t − t₀) and compute T{x(t − t₀)}.
  3. Shift the original output to get y(t − t₀).
  4. Compare the two results symbolically. Equal for all t₀ means time-invariant; one t₀ with unequal results is a counterexample.

Causality: the output at a chosen instant t₀ may depend only on input values at times t ≤ t₀, never on future input. A system that needs the next 5 ms of input is non-causal. Live systems such as a phone call or a motor controller must be causal. Recorded-data work, such as smoothing a stored ECG file, is allowed to be non-causal.

For an LTI system, causality and BIBO stability both reduce to tests on the impulse response h(t). Causality holds if and only if h(t) = 0 for t < 0 (h[n] = 0 for n < 0 in DT); the stability test comes in Section 3. Convolution and these LTI tests are developed under Causality and BIBO stability of LTI systems.

BIBO stability

BIBO means bounded-input bounded-output. The system is BIBO stable when every input that never exceeds some finite size produces an output that also never exceeds some finite size.

if |x(t)| ≤ Mᵢₙ for all t, then |y(t)| ≤ Mₒᵤₜ for all t

Mᵢₙ is a finite bound on the input magnitude; Mₒᵤₜ is a finite bound on the output magnitude; the same statement with n in place of t covers DT.

For an LTI system the test moves onto h alone.

DomainBIBO stable iffCausal iff
CT∫ |h(t)| dt < ∞h(t) = 0 for t < 0
DTΣ |h[n]| < ∞h[n] = 0 for n < 0

The absolute value matters. A bounded input can be shaped to match the sign of h at every instant, so the output can reach the full sum of magnitudes. If that sum is infinite, one bounded input drives the output to infinity. Example: h(t) = u(t) (a pure integrator) is causal but not stable, since ∫|h(t)|dt over all time is infinite.

The four tests are independent. A system can be linear and unstable, causal and time-varying, or stable and non-causal. Answer them one by one.

Worked example

Question. A CT system is defined by y(t) = t x(t), with t in seconds and y in volt-seconds when x is in volts. Test it for linearity, time invariance, causality and BIBO stability. Use x(t) = 2 V as the bounded test input and the delay t₀ = 1 s.

  1. Linearity: T{a x₁ + b x₂} = t(a x₁ + b x₂) = a·t x₁ + b·t x₂ = a T{x₁} + b T{x₂}. Both additivity and scaling hold, so the system is linear.
  2. Time invariance: the input x(t − 1) gives the output t x(t − 1). The shifted original output is (t − 1) x(t − 1). Take x = 2 V and t = 2 s. First result: 2 × 2 = 4 V·s. Second result: (2 − 1) × 2 = 2 V·s. They differ, so the system is time-varying.
  3. Causality: the output at instant t uses x(t) at that same instant only, never a future value. The system is causal.
  4. Stability: take the bounded input x(t) = 2 V, so Mᵢₙ = 2 V. Then y(t) = 2t V·s. At t = 10 s, |y| = 20 V·s. As t → ∞ the output grows without limit, so no finite Mₒᵤₜ exists. The system is not BIBO stable.

Exam traps

  • Time invariance does not mean the system never changes with time. It means a shift in the input produces exactly that shift in the output. The coefficient t in t x(t) makes the system time-varying.
  • A constant added term breaks linearity. For y(t) = x(t) + 2, the zero input gives 2, not 0, so the superposition formula fails no matter how small the constant is.
  • Both linearity conditions are needed. Check scaling and additivity separately, because a system that fails either one is not linear. Example: y(t) = x²(t) fails scaling (T{a x} = a²x², not a x²) and fails additivity ((x₁ + x₂)² ≠ x₁² + x₂²).
  • Causality is about which input samples are used, not about how fast the output appears. A system using x(t + 1) is non-causal even if its output is delayed by an hour.
  • For LTI stability, take the absolute value inside the integral or sum. ∫h(t)dt finite does not guarantee stability; ∫|h(t)|dt must be finite.

Set a = 0 in the scaling rule: T{0·x} = 0·T{x} = 0. So T{0} = 0, and any system with a nonzero zero-input output is not linear.

Apply Test y[n] = x[2n] for time invariance. Use a counterexample with n₀ = 1. 4 marks

Shifted input x[n − 1] gives x[2n − 1]. The shifted output is y[n − 1] = x[2(n − 1)] = x[2n − 2]. At n = 1 these are x[1] and x[0], which differ in general, so the system is time-varying. It is a decimator: it uses every second sample.

Apply An LTI system has h(t) = e−2t u(t). Test it for causality and BIBO stability. Take the CT forms. 4 marks

Causality: h(t) = 0 for t < 0 because of u(t), so it is causal. Stability: ∫₀∞ e−2t dt = 1/2 = 0.5, which is finite, so the system is BIBO stable.

Analyze A system is causal and BIBO stable but not linear. Can it still be time-invariant? Give a one-line reason with an example. 4 marks

Yes. The four properties are independent. Example: y(t) = |x(t)| is causal (uses only present input), stable (|y| = |x| ≤ Mᵢₙ), time-invariant (a shift in x gives the same shift in |x|), but not linear, since |x₁ + x₂| is not always |x₁| + |x₂|.

Analyze Why does the stability test for an LTI system use ∫|h(t)|dt rather than ∫h(t)dt? 5 marks

A bounded input can be chosen to match the sign of h(t) at every instant, so every part of h adds with the same sign and the output can reach the full sum of magnitudes. If ∫|h(t)|dt is infinite, that bounded input produces an unbounded output. A finite ∫h(t)dt can still occur with signs cancelling, so it does not prove stability.

Understand Give one practical situation where a non-causal system is acceptable. 3 marks

Offline processing of a stored recording, such as smoothing a saved ECG or sharpening a photograph. The whole file is already available, so using future samples costs nothing and no real-time decision is delayed.

Beyond the syllabus

Not for the exam. The four tests are the gate to the LTI toolbox: once a system is linear and time-invariant, convolution with h(t) describes it completely, and the Laplace and Z transforms turn it into algebra on poles and zeros. Stability tests then become region-of-convergence checks on the Laplace and Z transforms instead of integrals. In control and communications practice, engineers also measure gain margin and phase margin, and for nonlinear blocks they linearise around an operating point before applying these tests. Search for BIBO stability, impulse response absolute summability, and bounded-input bounded-output in control texts to go further.

1.7 Signals as vectors: orthogonal signal space

A signal on an interval behaves like a vector with one component for every instant. Vector algebra then carries over. The inner product measures how much of one signal lies along another, the norm is the size of a signal (the square root of its energy), and two signals are orthogonal when their inner product is zero. The best approximation of one signal by a multiple of another is the projection you already use for vectors. The Fourier series and digital modems rest on this picture.

You need: Chapter 1.1 for signal notation and Chapter 1.2 for the energy of a signal.

Vectors and signals: the analogy

Take two vectors A and B. The component of A along B is cB, with c = A·B / |B|². What is left, the error vector e = A − cB, is perpendicular to B, and this c makes |e| as small as possible: any other multiple of B leaves a longer error.

A signal on an interval a ≤ t ≤ b has one component for every instant. Replace the sum Σ AₖBₖ of the dot product by an integral and you have the inner product of two signals.

⟨x, y⟩ = ∫ₐᵇ x(t) y*(t) dt

a and b are the interval limits in seconds; y*(t) is the complex conjugate of y(t), and for real signals y*(t) = y(t). In discrete time the integral becomes Σ x[n] y*[n] over the chosen samples.

‖x‖ = √⟨x, x⟩ = √(∫ₐᵇ |x(t)|² dt)

‖x‖ is the norm of x. ‖x‖² is the energy of x on [a, b] (Chapter 1.2), so the norm is the square root of the energy.

The inner product is one number. A large positive value means the two signals rise and fall together on the interval; a large negative value means one is close to a negative copy of the other; zero means neither has any component along the other. For complex signals judge the size |⟨x, y⟩|.

Approximating one signal by another

Approximate a real signal f₁(t) by c f₂(t) over t₁ < t < t₂. The error signal is fₑ(t) = f₁(t) − c f₂(t). Choose c to make the mean square error ε = (1/(t₂ − t₁)) ∫ fₑ²(t) dt as small as possible, by setting dε/dc = 0.

dε/dc = (1/(t₂ − t₁)) ∫ 2[f₁(t) − c f₂(t)][−f₂(t)] dt = 0
⇒  ∫ f₁(t) f₂(t) dt = c ∫ f₂²(t) dt
⇒  c₁₂ = ∫ f₁(t) f₂(t) dt / ∫ f₂²(t) dt = ⟨f₁, f₂⟩ / ‖f₂‖²

every integral runs from t₁ to t₂; c₁₂ is the component of f₁ along f₂, the same formula as c = A·B / |B|² for vectors.

With this c₁₂ the error energy is ‖f₁‖² − c₁₂²‖f₂‖²: the energy of f₁ minus the energy of the part that was kept. The first line above also says ∫ fₑ(t) f₂(t) dt = 0: the error left over is orthogonal to f₂, exactly like the perpendicular error vector.

If ⟨f₁, f₂⟩ = 0 then c₁₂ = 0. The signal f₂ cannot help to approximate f₁ at all, and the two are called orthogonal on that interval. Some syllabi call this topic the analogy between vectors and signals.

Orthogonal sets and the coefficient formula

A set of nonzero signals φ₁, φ₂, … is orthogonal on an interval when ⟨φₘ, φₙ⟩ = 0 for every m ≠ n. Write Kₙ = ‖φₙ‖² for the energy of φₙ; it is never zero, because the zero signal is not allowed in the set. The set is orthonormal when every Kₙ = 1.

Orthogonality makes the coefficients independent of each other. Write x ≈ Σ cₙφₙ and take the inner product of both sides with φₘ. Every term with n ≠ m gives zero, so a single term survives:

cₙ = ⟨x, φₙ⟩ / Kₙ = (1/Kₙ) ∫ₐᵇ x(t) φₙ*(t) dt

cₙ is the coefficient of φₙ; Kₙ = ∫ₐᵇ |φₙ(t)|² dt is the energy of φₙ on [a, b]; for an orthonormal set cₙ = ⟨x, φₙ⟩.

  1. Fix the interval; orthogonality means nothing without it.
  2. Check that the set is orthogonal on that interval.
  3. Compute each Kₙ by integrating |φₙ|².
  4. Compute each inner product ⟨x, φₙ⟩.
  5. Divide to get cₙ. The sum Σ cₙφₙ is the best approximation of x that the set can give.

Worked example

Question. A square wave is f(t) = 1 for 0 < t < π and f(t) = −1 for π < t < 2π. Approximate it over (0, 2π) by c sin t. (a) Find the best value of c. (b) Find the error energy and the mean square error. (c) What fraction of the energy of f does the approximation carry?

  1. Here f₁ = f and f₂ = sin t on t₁ = 0, t₂ = 2π, so c₁₂ = ∫ f(t) sin t dt / ∫ sin² t dt, both integrals over (0, 2π).
  2. Numerator: over (0, π), ∫ sin t dt = [−cos t] = −cos π + cos 0 = 2. Over (π, 2π), ∫ (−1) sin t dt = [cos t] = cos 2π − cos π = 2. Total 4.
  3. Denominator: ∫ sin² t dt = ∫ (1 − cos 2t)/2 dt = 2π/2 = π, because cos 2t integrates to zero over two whole periods.
  4. (a) c₁₂ = 4/π ≈ 1.273, so f(t) ≈ (4/π) sin t ≈ 1.273 sin t.
  5. (b) The energy of f is ‖f‖² = ∫ 1 dt = 2π ≈ 6.283, since f² = 1 everywhere. The part kept has energy c₁₂²‖sin t‖² = (16/π²)(π) = 16/π ≈ 5.093.
  6. Error energy = 2π − 16/π ≈ 6.283 − 5.093 = 1.190. Mean square error ε = 1.190/(2π) = 1 − 8/π² ≈ 0.189.
  7. (c) Fraction kept = (16/π)/(2π) = 8/π² ≈ 0.811, so one sine carries about 81 % of the energy.
  8. Check the minimum with another value, c = 1: error energy = ∫ (f − sin t)² dt = 2π − 2(1)(4) + (1)²π = 3π − 8 ≈ 1.425, larger than 1.190.

Answer. c₁₂ = 4/π ≈ 1.273; error energy 2π − 16/π ≈ 1.190 and mean square error 1 − 8/π² ≈ 0.189; the single sine carries 8/π² ≈ 81 % of the energy.

Worked example 2

Question. On 0 ≤ t ≤ 1 take φ₁(t) = 1 and φ₂(t) = 2t − 1. (a) Show that they are orthogonal. (b) Find K₁ and K₂. (c) Expand x(t) = t in this set.

  1. (a) ⟨φ₁, φ₂⟩ = ∫₀¹ (2t − 1) dt = [t² − t] from 0 to 1 = 0 − 0 = 0. Both signals are nonzero, so they are orthogonal on [0, 1].
  2. (b) K₁ = ∫₀¹ 1 dt = 1. K₂ = ∫₀¹ (4t² − 4t + 1) dt = 4/3 − 2 + 1 = 1/3.
  3. (c) ⟨t, φ₁⟩ = ∫₀¹ t dt = 1/2, so c₁ = (1/2)/1 = 1/2. ⟨t, φ₂⟩ = ∫₀¹ (2t² − t) dt = 2/3 − 1/2 = 1/6, so c₂ = (1/6)/(1/3) = 1/2.

Answer. ⟨φ₁, φ₂⟩ = 0; K₁ = 1 and K₂ = 1/3; t = (1/2)φ₁(t) + (1/2)φ₂(t) on [0, 1].

Exam traps

  • Orthogonality depends on the interval. φ₁ = 1 and φ₂ = 2t − 1 have inner product 0 on [0, 1], but ∫₀² (2t − 1) dt = 4 − 2 = 2 on [0, 2].
  • Divide by Kₙ = ‖φₙ‖², not by ‖φₙ‖. In worked example 2, dividing ⟨t, φ₂⟩ = 1/6 by ‖φ₂‖ = 0.577 gives 0.289 instead of the correct c₂ = 0.5.
  • For complex signals conjugate the second signal. Without the star, the inner product of ejt with itself over (0, 2π) comes out 0 instead of its energy 2π.
  • The best sine for the square wave is 1.273 sin t, not 1·sin t: it must be taller than the square wave to make up for being too low near t = 0 and t = π.

1.8 Complete sets of orthogonal functions and Parseval's relation

An orthogonal set is complete on an interval when adding more of its members drives the error energy of the approximation to zero, for every finite-energy signal on that interval. The signal then equals its orthogonal expansion, x = Σ cₙφₙ, and its energy splits exactly among the terms: E = Σ |cₙ|²Kₙ. That is Parseval's relation. The Fourier series is the most used complete set. Parseval gives the energy or power in each harmonic without a fresh integral.

You need the inner product, Kₙ and the coefficient formula cₙ = ⟨x, φₙ⟩/Kₙ from Chapter 1.7, and the energy and power of a signal from Chapter 1.2.

Error energy as terms are added

Approximate x(t) on [a, b] by the first N terms of an orthogonal set, Σ cₙφₙ(t) for n = 1 to N, with cₙ = ⟨x, φₙ⟩/Kₙ. Expand the error energy ε(N). Every cross term ⟨φₘ, φₙ⟩ with m ≠ n vanishes, and what is left is short.

ε(N) = ∫ₐᵇ |x(t) − Σ cₙφₙ(t)|² dt
     = ∫ₐᵇ |x(t)|² dt − Σ |cₙ|² Kₙ        (n = 1 to N)

ε(N) is the error energy left after N terms; ∫|x(t)|² dt is the energy E of x on [a, b]; |cₙ|²Kₙ is the energy carried by the n-th term.

  • Each new term lowers the error energy by |cₙ|²Kₙ and can never raise it.
  • Adding a term does not change the coefficients already found, because each cₙ is one inner product with its own φₙ. This is called the finality of coefficients.
  • Since ε(N) ≥ 0, Σ |cₙ|²Kₙ ≤ E for every N. This is Bessel's inequality: the terms can never carry more energy than the signal has.

Complete sets

The set {φₙ} is complete on [a, b] when ε(N) → 0 as N → ∞ for every signal of finite energy on [a, b]. An equivalent test: no nonzero finite-energy signal is orthogonal to every member of the set. For a complete set we write x(t) = Σ cₙφₙ(t), the generalised Fourier series of x.

The equality holds in energy. The two sides may still differ at isolated points: at the jump of a square wave a Fourier series gives the midpoint of the jump, but no energy is lost at a single point.

The sines {sin nt} on (0, 2π) represent the odd square wave of the worked example exactly, yet they are not complete there: cos t is orthogonal to every sin nt on (0, 2π), so all its sine coefficients are zero. Parseval's relation

For a complete set the error energy reaches zero, so the energy of x equals the sum of the energies of its components.

E = ∫ₐᵇ |x(t)|² dt = Σ |cₙ|² Kₙ

the sum runs over every member of the set. For an orthonormal set (every Kₙ = 1) it reads E = Σ |cₙ|², the signal version of Pythagoras' theorem.

For a periodic signal, divide both sides by T₀ to get average power. With the exponential set Kₙ = T₀, so P = (1/T₀) ∫ |x(t)|² dt = Σ |Dₙ|², summed over n = 0, ±1, ±2, …, where Dₙ are the exponential Fourier coefficients. With the trigonometric form x(t) = a₀ + Σ (aₙ cos nω₀t + bₙ sin nω₀t) it becomes P = a₀² + Σ (aₙ² + bₙ²)/2.

Check with Chapter 1.2: x(t) = 6 cos(200πt) + 3 has a₀ = 3 and a₁ = 6, so P = 3² + 6²/2 = 9 + 18 = 27 W, the value found there from the time signal. The power spectrum in Parseval's theorem, energy and power spectrum, rests on this relation.

Exam traps

  • Parseval's relation needs an orthogonal set. If ⟨φₘ, φₙ⟩ ≠ 0 the cross terms stay, and Σ |cₙ|²Kₙ is not the energy.
  • Multiply each |cₙ|² by Kₙ unless the set is orthonormal. For the sine set on (0, 2π), Kₙ = π; leaving it out gives Σ cₙ² = (16/π²)(π²/8) = 2 instead of the energy 2π.
  • Complete does not mean every finite sum is exact. The error reaches zero only in the limit: the square wave still has error energy 0.2538 after five nonzero terms.
  • Equality in energy is not equality at every point. At the jump t = π every sin nπ is 0, so the sine series gives 0, the midpoint of +1 and −1.

Takeaways

  1. A signal is a function of an independent variable that carries information, and a system maps input signals to output signals.
  2. Continuous-time signals use real t and discrete-time signals use integer n; sampling gives x[n] = x(nTₛ), but many DT signals are discrete by nature.
  3. Energy and power classify signals by finite energy or finite nonzero average power, while periodic, even, and odd properties simplify later work.
  4. The impulse, step, ramp, and exponential are standard building blocks and common test inputs for systems.
  5. Operations on the independent variable change the graph: shifting moves it, scaling compresses or stretches it, and reversal flips it.
  6. A system is CT or DT by the variable of its input and output, and its properties must be tested from definitions.
  7. Linearity, time invariance, causality, and BIBO stability are separate tests; one does not automatically imply another.
  8. Signals on an interval behave like vectors: the inner product measures how much of one lies along another, and c₁₂ = ⟨f₁, f₂⟩/‖f₂‖² gives the best approximation.
  9. In an orthogonal set each coefficient is one inner product, cₙ = ⟨x, φₙ⟩/Kₙ, found without the others.
  10. A complete orthogonal set drives the error energy to zero, and Parseval's relation E = Σ|cₙ|²Kₙ splits the energy among the terms.

Understand Define the unit impulse, unit step, ramp, and exponential signals. State the relations among impulse, step, and ramp in continuous time. 12 marks

Points to cover. Impulse: zero except at the origin, unit area, sifting property; Step: zero before the origin, one from the origin on; Ramp: r(t) = t u(t); Exponential: A eat real, ejωt complex; Relations: the step is the integral of the impulse, the ramp the integral of the step; differentiation walks back.

Model answer.

  1. Unit impulse. δ(t) = 0 for t ≠ 0 and ∫ δ(t) dt = 1 over all t. It is not an ordinary function: only its area and its sifting action are defined, ∫ x(t) δ(t − t₀) dt = x(t₀) for x continuous at t₀. Scaling rule: δ(at) = δ(t)/|a|. In DT, δ[n] = 1 at n = 0 and 0 elsewhere.
  2. Unit step. u(t) = 0 for t < 0 and 1 for t ≥ 0 (this book takes u(0) = 1). In DT, u[n] = 1 for n ≥ 0 and 0 for n < 0. It models a switch closing at t = 0; u(t − a) switches on at t = a.
  3. Unit ramp. r(t) = t u(t): zero for t < 0 and equal to t for t ≥ 0. In DT, r[n] = n u[n]. It models a quantity rising at a steady rate.
  4. Exponential. Real: x(t) = A eatu(t); it decays for a < 0 with time constant 1/|a|, grows for a > 0 and is constant for a = 0. Complex: ejωt = cos ωt + j sin ωt, with ω in rad/s.

    u(t) = ∫ δ(τ) dτ  over −∞ < τ ≤ t        δ(t) = du/dt
r(t) = ∫ u(τ) dτ  over −∞ < τ ≤ t        u(t) = dr/dt
chain:  δ(t) → u(t) → r(t) → (t²/2) u(t)

Expand the square wave f(t) = 1 on (0, π), −1 on (π, 2π) in the set {sin nt}, tabulate the energy captured as terms are added, find how many nonzero terms are needed for 95 % of the energy, and explain whether the sine set is complete. 16 marks

Points to cover. ∫ sin nt sin mt dt = 0 for m ≠ n; Kₙ = π; cₙ = 4/(nπ) for odd n, 0 for even n; Term energy 16/(n²π); running total against 2π; 95 % needs five nonzero terms (n = 1 to 9): 95.96 %, while four give 94.96 %; Parseval check with Σ 1/n² = π²/8 over odd n; cos t shows the sines alone are not complete.

Model answer.

  1. Orthogonality. Use the product-to-sum identity:
    sin nt sin mt = [cos(n − m)t − cos(n + m)t]/2
∫ sin nt sin mt dt over (0, 2π) = 0 − 0 = 0     for m ≠ n (whole periods of each cosine)
Kₙ = ∫ sin² nt dt = ∫ (1 − cos 2nt)/2 dt = π
  2. Coefficients.
    ⟨f, sin nt⟩ = ∫ sin nt dt over (0, π) − ∫ sin nt dt over (π, 2π)
           = (1 − cos nπ)/n + (1 − cos nπ)/n = 2(1 − cos nπ)/n
odd n:  4/n  ⇒ cₙ = 4/(nπ)
even n: 0    ⇒ cₙ = 0

Glossary

Amplitude
The value or strength of a signal at a chosen point or its peak scale.
BIBO stable system
A system in which every bounded input produces a bounded output.
Causal system
A system whose output does not depend on future input values.
Complete orthogonal set
An orthogonal set whose N-term error energy tends to zero for every finite-energy signal on the interval.
Continuous-time signal
A signal defined for every real value of time t.
Discrete-time signal
A signal defined only at integer index n.
Energy signal
A signal whose total energy E=∫|x(t)|²dt is finite.
Even signal
A signal that satisfies x(−t)=x(t).
Exponential signal
A signal of the form A·exp(st), where s may be real or complex.
Fundamental period
The smallest positive T for which a periodic signal repeats.
Independent variable
The quantity on which a signal depends, usually time t or integer index n.
Inner product
For signals, ⟨x,y⟩=∫x(t)y*(t)dt; it measures similarity and projection.
Linear system
A system that obeys superposition for all inputs and constants.
Odd signal
A signal that satisfies x(−t)=−x(t).
Orthogonal signals
Signals whose inner product is zero on the chosen interval.
Parseval's relation
For a complete orthogonal set, the energy of a signal equals Σ |cₙ|²Kₙ, the sum of the energies of its components.
Periodic signal
A signal that satisfies x(t+T)=x(t) for all t with some T>0.
Power signal
A signal whose average power is finite and nonzero.
Ramp signal
A signal that is zero before the origin and rises linearly after it.
Sample
Each value x[n] of a discrete-time signal; for a sampled signal it is x(nTₛ).
Signal
A function of an independent variable that carries information.
Signum function
sgn(t) = 1 for t > 0 and −1 for t < 0; sgn(t) = 2u(t) − 1 except at t = 0.
Sinc function
sinc(t) = sin(πt)/(πt), with sinc(0) = 1 and zeros at nonzero integers; some books use sin(t)/t instead.
System
An operator that maps an input signal to an output signal.
Time reversal
A change x(t)→x(−t) that flips a signal about the origin.
Time scaling
A change x(t)→x(at) that compresses or stretches a signal in time.
Time shift
A change x(t)→x(t−t₀) that moves a signal in time.
Time-invariant system
A system whose response does not depend on the absolute time of the input.
Unit impulse
A generalized signal with zero width, unit area, and zero value except at the origin.
Unit step
A signal that is zero before the origin and one from the origin on (u(0) = 1 in this book).
