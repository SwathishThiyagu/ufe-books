2.1 Linear time-invariant (LTI) systems

An LTI system is a system that is both linear and time-invariant. Linearity means scaling and adding inputs scales and adds the outputs. Time invariance means a delayed input gives the same output, delayed by the same amount. These two rules make a system easy to analyse: its impulse response fixes its behaviour for every input. LTI models describe audio filters, control loops, transmission lines and many sensor circuits. Indian examples include the smoothing filter in a payment app and the low-pass filter in a phone charger.

You need Unit 1: system definition, linearity, time invariance, impulse and step signals.

Definition and meaning

Write a continuous-time system as an operator T. Input x(t) gives output y(t)=T{x(t)}. t is time in seconds. The system is linear if the next formula holds for all inputs and constants.

T{a x₁(t) + b x₂(t)} = a T{x₁(t)} + b T{x₂(t)}

T is the system operator; x₁(t) and x₂(t) are any two inputs; a and b are any real constants; the output is y(t)=T{x(t)}.

This is superposition: scaling and adding inputs scales and adds outputs. Put a=b=0. A linear system must give T{0}=0. This zero-input test is necessary, not sufficient.

If y(t)=T{x(t)}, then T{x(t−τ)} = y(t−τ)

τ is the delay in seconds; positive τ means a delayed input; the output is delayed by the same τ.

Time invariance means the rule does not change with clock time. A delayed input gives the same output, delayed by τ. Some syllabi call it shift invariance. An LTI system passes both tests. LTI does not imply causal or stable; see <a href='#causality-and-bibo-stability-of-lti-systems'>2.5. Continuous time only here; discrete-time LTI comes in Unit 5.

LTI matters because the impulse response h(t) and convolution follow; see <a href='#impulse-response-and-step-response'>2.2 and <a href='#convolution-integral-and-its-evaluation'>2.3.

How to test a formula

Do not assume a formula is LTI because it looks simple. Use a short procedure.

  1. Write T{x} from y(t).
  2. Test linearity. Pick two easy inputs and two constants. Compute both sides of the linearity formula. One mismatch rejects the system.
  3. Quick check: if T{0}≠0, the system is not linear.
  4. Test time invariance. Replace t by t−τ in the input, pass through T, and compare with y(t−τ). One mismatch rejects the system.
  5. Only systems that pass both tests are LTI.

A common mistake is to test with one input pair and declare linear. A pass for one choice is not proof. The formula must match for all inputs and constants. An offset such as +2 breaks linearity because T{0}=2, but it does not break time invariance. The scaling y(t)=x(2t) is time-varying: with x(t)=t and τ=1 s, delayed input x(t−1)=t−1 gives output 2t−1, while shifted output y(t−1)=2t−2. At t=1 s they give 1 and 0.

Why LTI is worth the trouble

For an LTI system, the response to an impulse δ(t) is h(t), the impulse response. Every input can be treated as a sum of shifted impulses. The output is then the convolution integral y(t)=∫x(τ)h(t−τ)dτ. This turns a system problem into one integral. In the frequency domain, an LTI system multiplies the input spectrum by a frequency response. In the Laplace domain, it gives a transfer function; see Unit 4, Laplace Transform Analysis. Non-LTI systems, such as squarers, limiters and time-scaling circuits, need other methods. Many physical systems are only approximately LTI over a small range. LTI analysis still gives the first design estimate.

Worked example

Question. Test y(t)=3x(t)+2 for linearity and time invariance. Use x₁(t)=1, x₂(t)=2, a=2, b=3 for linearity, and x(t)=t with delay τ=2 s for time invariance. Evaluate the delay test at t=5 s. State whether the system is LTI.

  1. Write the system: y(t)=3x(t)+2, so T{x}=3x+2.
  2. Linearity test: take x₁=1, x₂=2, a=2, b=3.
  3. Left side at t=0: a x₁ + b x₂ = 2(1)+3(2)=8. T{8}=3(8)+2=26.
  4. Right side: T{x₁}=3(1)+2=5. T{x₂}=3(2)+2=8. 2(5)+3(8)=10+24=34.
  5. Since 26 ≠ 34, the system is not linear. One counterexample is enough.
  6. Time-invariance test: use x(t)=t and τ=2 s. Original output y(t)=3t+2.
  7. Delayed input: x(t−2)=t−2. System output: T{x(t−2)}=3(t−2)+2=3t−4.
  8. Shifted original output: y(t−2)=3(t−2)+2=3t−4.
  9. At t=5 s, both expressions give 3(5)−4=11. They match for all t, so the system is time-invariant.
  10. The system is time-invariant but not linear, so it is not LTI.

Answer. The system is time-invariant (both sides give 11 at t = 5 s) but not linear (26 ≠ 34), so it is not an LTI system.

Exam traps

  • A formula with no explicit t need not be time-invariant. y(t)=x(2t) has no t in the multiplier but is time-varying.
  • An offset +2 breaks linearity but not time invariance. The system is time-invariant, not LTI.
  • T{0}=0 is necessary for linearity, not sufficient. A nonlinear system can also give zero for zero input.
  • One matching test does not prove linearity or time invariance. Use the full formula or compare expressions for all t.
  • Time-invariant does not mean the output is constant in time. It means the rule does not change with time.

2.2 Impulse response and step response

The impulse response h(t) is the output of an LTI system when the input is the unit impulse δ(t). The step response s(t) is the output when the input is the unit step u(t). These two signals describe the system completely: s(t) is the running integral of h(t), and h(t) is the derivative of s(t). Engineers measure them on filters, motors and circuits because one short test can predict the response to many inputs. The link is used in oscilloscope probing, control tuning and audio rooms.

You need Unit 1 standard signals δ(t) and u(t), and Chapter 2.1 on LTI systems.

Impulse response is the system fingerprint

An impulse is a very short input with unit area. Apply δ(t) to a continuous-time LTI system at rest. The output is h(t), the impulse response. Some syllabi call h(t) the weighting function because it tells how strongly an impulse at time zero affects the output at later times.

h(t) belongs to the system, not to the input. A causal system has h(t)=0 for negative t: it cannot answer before the impulse arrives. Because the system is time invariant, an impulse delayed to time t0 produces h(t−t0). This shift rule is the seed of the convolution integral.

The unit of h(t) comes from the system. For the RC low-pass below, h(t)=(1/τ)e−t/τu(t) and the factor 1/τ has unit s−1. The factor sets both the height and the unit; dropping it gives a wrong number and a wrong dimension.

An LTI system is fully described by h(t). Once h(t) is known, every zero-state output follows from superposition. Causality and stability are also read from h(t).

Step response is the integral of h(t)

The step response s(t) is the output when the input is the unit step u(t), again from rest. Only a few books use the name indicial response for the same signal.

An impulse is the derivative of a step, so the step is the running integral of the impulse. For an LTI system:

s(t) = ∫−∞t h(λ) dλ

s(t) is the step response, h(λ) is the impulse response at time λ, and λ is a dummy variable. The lower limit −∞ keeps any response before t=0.

For a causal system h(λ)=0 for negative λ, so s(t)=∫0t h(λ)dλ for t≥0. Differentiate the integral:

h(t) = ds(t)/dt

ds/dt is the slope of the step response. If s(t) jumps at t=0, the derivative adds an impulse at that instant; a continuous rise gives no impulse. Do not swap the two responses: s(t) is not h(t).

For the RC low-pass with τ=RC, h(t)=(1/τ)e−t/τu(t). Integrate from 0 to t: s(t)=(1−e−t/τ)u(t). The capacitor voltage starts at 0, reaches 63.2% of its final value at t=τ, 95.0% at 3τ, and 99.3% at 5τ. The differential-equation route to the same result is in Section 2.6.

Reading the two curves

The figure plots the same RC filter against t/τ. The falling curve is τh(t)=e−t/τ; the rising curve is s(t)=1−e−t/τ. At t/τ=0, τh=1 and s=0. At t/τ=1, τh=e−1=0.368 and s=1−e−1=0.632. At t/τ=5, s=0.993, so the response is settled for most engineering work.

Notice the slopes. The slope of s(t) at any time equals h(t). A large h means a fast rise; a small h means a slow rise. This is why h(t) is the derivative of s(t) and s(t) is the integral of h(t).

On a lab bench, a narrow pulse approximates δ(t), and a square wave with a long period gives repeated step inputs. The two measurements must agree through the integral and derivative relations. If they do not, check the time constant, the load resistance, and the probe capacitance.

Worked example

Question. An RC low-pass filter has R=1 kΩ and C=1 μF. The output is the capacitor voltage. Find τ, h(t), s(t), and their values at t=1 ms.

  1. τ=RC=(1×103 Ω)(1×10−6 F)=1×10−3 s=1 ms.
  2. For this first-order low-pass, h(t)=(1/τ)e−t/τu(t). Substitute τ=0.001 s: h(t)=(1/0.001)e−t/0.001u(t)=1000 e−1000tu(t) s−1.
  3. s(t)=∫0t h(λ)dλ=∫0t(1/τ)e−λ/τdλ=[−e−λ/τ]0t=1−e−t/τ for t≥0. Thus s(t)=(1−e−1000t)u(t).
  4. At t=1 ms=1×10−3 s, t/τ=1. h=1000e−1=1000×0.367879=368 s−1.
  5. At the same time, s=1−e−1=1−0.367879=0.632.

Answer. τ=1 ms; h(t)=1000e−1000tu(t) s−1; s(t)=(1−e−1000t)u(t); at t=1 ms, h=368 s−1 and s=0.632.

Exam traps

  • Swapping h(t) and s(t): h(t) is the impulse response and s(t)=∫h; the step response is not the derivative of the impulse response.
  • Dropping u(t) and assuming the formula holds for all time: a causal RC filter has h(t)=0 and s(t)=0 for negative t.
  • Losing the 1/τ in h(t): for R=1 kΩ and C=1 μF, h(0)=1000 s−1, not 1.
  • Differentiating e−t/τ as −e−t/τ: the chain rule gives h(t)=(1/τ)e−t/τu(t), with the positive 1/τ.
  • Treating δ(t) as an ordinary finite pulse: the ideal impulse has unit area and zero width; a real pulse only approximates it if its width is much smaller than τ.

2.3 Convolution integral and its evaluation

The convolution integral gives the output of a continuous-time LTI system directly from its input and its impulse response. It adds shifted, scaled copies of the impulse response, one for every input value. Engineers use it to predict a circuit's response to a pulse, a loudspeaker's response to a click, and a communication channel's response to a symbol. The next step is to evaluate the integral reliably: flip the impulse response, shift it, multiply with the input, and integrate only over the overlap.

You need: Chapter 2.1 for LTI systems and Chapter 2.2 for the impulse response, plus Unit 1 for shifting and scaling of signals.

The superposition integral

An LTI system is fully described by h(t), its output when the input is an impulse δ(t). Split any input x(t) into narrow pulses. A pulse of width Δτ at time τ has area x(τ)Δτ, so the system replies with x(τ)Δτ h(t−τ). Add all pulses and let Δτ→0. The sum becomes an integral.

y(t) = ∫<sub>−∞</sub><sup>∞</sup> x(τ) h(t − τ) dτ

t is the output time in seconds; τ is the dummy integration time in seconds; x(τ) is the input; h(t−τ) is the impulse response reversed and shifted by t; y(t) is the output.

The symbol * means convolution: y(t)=x(t)*h(t). The integral is also called the superposition integral. h(t−τ) is not h(τ). At a fixed output time t, h(t−τ) is h(τ) flipped left-to-right and moved right by t. The variable τ runs over the input's history.

For a causal system, h(t)=0 for t<0, so h(t−τ)=0 when τ>t; the upper limit becomes t. If x(t)=0 for t<0, the lower limit becomes 0. The algebra of convolution is in Chapter 2.4.

Flip, shift, multiply, integrate

Graphical convolution is a five-step habit: sketch x(τ), sketch h(τ) and flip it, shift by t, multiply, integrate. It turns an abstract integral into areas you can see.

  1. Sketch x(τ) against τ.
  2. Sketch h(τ), then flip it to h(−τ).
  3. Shift by t to get h(t−τ).
  4. Multiply the two plots point by point.
  5. Integrate the product only where both are nonzero: the overlap.

For finite-duration signals, the overlap changes at breakpoints. Write separate time cases for before, during and after the overlap. Do not use 0 to t blindly. In the example below, x lasts from 0 to 2 s, so the upper limit is t for 0≤t<2 s but stays at 2 s for t≥2 s.

A short numerical check uses the trapezoid rule. At t=1 s, y(1)=∫01 eτ−1 dτ. With step 0.5 s, sample f(τ)=eτ−1 at τ=0, 0.5, 1 s: 0.3679, 0.6065, 1.0000. The trapezoid rule gives 0.5[0.5(0.3679+1.0000)+0.6065]=0.6452. The exact value is 0.6321. The 0.0131 difference is the rule's error; a smaller step reduces it. This check catches sign errors in the exponent.

Worked example

Question. Let x(t)=u(t)−u(t−2) and h(t)=e−tu(t). Find y(t)=x(t)*h(t) for all t. Give y(1), y(2), y(3) to three decimal places.

  1. Write y(t)=∫−∞∞ x(τ)h(t−τ)dτ. Here x(τ)=1 for 0≤τ≤2 and 0 elsewhere; h(t−τ)=e−(t−τ) for t−τ≥0, that is τ≤t.
  2. The product is nonzero only on 0≤τ≤2 and τ≤t. The overlap is 0≤τ≤min(2,t). This gives two time cases: 0≤t<2 and t≥2; for t<0, y(t)=0.
  3. Case 0≤t<2 s: y(t)=∫0t e−(t−τ)dτ = e−t∫0teτdτ = e−t(et−1)=1−e−t. At t=1 s, y(1)=1−e−1=0.632.
  4. Case t≥2: y(t)=∫02 e−(t−τ)dτ = e−t(e2−1)=e2−t−e−t. At t=2 s, y(2)=e0−e−2=1−0.135=0.865. At t=3 s, y(3)=e−1−e−3=0.368−0.050=0.318.
  5. At t=2 s both cases give 0.865, so the pieces join. For t<0, y(t)=0.

Answer. y(t)=0 for t<0 s; y(t)=1−e−t for 0≤t<2 s; y(t)=e2−t−e−t for t≥2 s. The values are y(1 s)=0.632, y(2 s)=0.865, y(3 s)=0.318.

Exam traps

  • The limits are the overlap of x(τ) and h(t−τ), not automatically 0 to t. For t≥2 in the example the upper limit stays at 2 s.
  • Flip h, not x, in y(t)=∫x(τ)h(t−τ)dτ. Flipping x gives a different integral.
  • h(t−τ)=e−(t−τ), not e−t−τ. The shift changes the sign inside the exponent.
  • For finite-duration signals, split time at every breakpoint: before, during and after the overlap. Missing the t≥2 case loses half the answer.
  • Keep t and τ in the same time unit. A limit of 2 means 2 s only if t is in seconds.

2.4 Properties of convolution

Convolution is not just an integral you evaluate once. It obeys an algebra: you can swap the two signals, regroup three signals, and split a sum. The impulse δ(t) is the identity, like 1 in ordinary multiplication. These rules let you shift known answers, predict durations, and check a long integral in seconds. Only a few universities teach this as a named chapter; the rules still appear inside convolution questions everywhere.

You need: the convolution integral from Chapter 2.3, the impulse response from Chapter 2.2, and δ(t) from Unit 1.

Convolution as an algebra

Write the convolution of x(t) and h(t) as y(t)=∫_{−∞}^{∞} x(τ)h(t−τ)dτ, where the integral runs over all τ. Here τ is the dummy time in seconds, t is the output time in seconds, x is the input, and h is the impulse response.

  • Commutative: x*h = h*x.
  • Associative: (x*h₁)*h₂ = x*(h₁*h₂).
  • Distributive: x*(h₁+h₂) = x*h₁ + x*h₂.
  • Identity: x(t)*δ(t) = x(t). The impulse has unit area.

Proofs are one line: substitute λ=t−τ for commutative; write a double integral and swap order for associative; split the integral for distributive. These are the same laws as ordinary multiplication, with one difference: not every signal has an inverse. When an inverse exists it satisfies h(t)*hinv(t)=δ(t), and the cascade of a system with its inverse is the identity system. There is no general rule for dividing one signal by another. The associative law means two cascaded LTI systems can be replaced by one system with impulse response h₁*h₂.

The identity is a signal, not a number: δ(t) is defined by its unit area and sifting property, not by any graph or width. The distributive law lets a parallel bank of systems be combined into one sum of impulse responses.

Shift, duration and calculus rules

Shift rule: if x(t)*h(t)=y(t), then x(t−t₁)*h(t−t₂)=y(t−t₁−t₂). The times t₁ and t₂ are in seconds. Delaying both inputs by t₁ and t₂ delays the output by t₁+t₂.

Duration rule: if x is nonzero only for T_x seconds and h only for T_h seconds, then y is nonzero for at most T_y=T_x+T_h seconds, for finite-duration signals. Widths add; heights do not.

For rectangles, peak = A_x A_h min(T_x,T_h). A_x and A_h are heights. A 2 s unit rectangle convolved with a 3 s unit rectangle gives a 5 s trapezoid with peak 2.

d/dt[x*h] = (dx/dt)*h = x*(dh/dt)

d/dt is the time derivative; this holds where the derivatives exist.

∫_{−∞}^t (x*h) dλ = (∫_{−∞}^t x dλ)*h = x*(∫_{−∞}^t h dλ)

λ is a dummy time in seconds; constants of integration are set by the lower limit.

Limits: the duration rule fails for infinite-duration signals, such as u(t) or cos(ωt). The associative law assumes the integrals converge. Convolution with δ(t−t₀) shifts the signal: x(t)*δ(t−t₀)=x(t−t₀).

Worked example

Question. Let x(t)=u(t)−u(t−2) and h(t)=u(t)−u(t−3). Using convolution properties, find the duration and peak value of y(t)=x(t)*h(t). State y(t) on each interval.

  1. x is a unit rectangle of width T_x=2 s; h is a unit rectangle of width T_h=3 s.
  2. Duration: T_y=T_x+T_h=2+3=5 s, so y is nonzero only for 0≤t≤5.
  3. Peak: peak = A_x A_h min(T_x,T_h)=1×1×min(2,3)=2.
  4. For 0≤t≤2, overlap length is t, so y=t.
  5. For 2≤t≤3, full 2 s overlap, so y=2.
  6. For 3≤t≤5, overlap length is 5−t, so y=5−t.
  7. Check endpoints: y(0)=0, y(2)=2, y(3)=2, y(5)=0.

Answer. Duration is 5 s and peak is 2 on 2≤t≤3 s; y=t for 0≤t≤2, y=2 for 2≤t≤3, y=5−t for 3≤t≤5, and zero otherwise.

Exam traps

  • Durations add only for finite-duration signals. A step u(t) has infinite duration, so the rule gives no finite number.
  • Heights multiply and then scale by overlap width; they do not add. Two rectangles of heights 2 and 3 and minimum width 1 s peak at 6, not 5.
  • δ(t) is the identity, not zero. x*δ=x and x*δ(t−t₀)=x(t−t₀), a shift.
  • Differentiation gives (dx/dt)*h or x*(dh/dt), never (dx/dt)*(dh/dt).

2.5 Causality and BIBO stability of LTI systems

A continuous-time LTI system is causal when its output never depends on future input. It is bounded-input bounded-output (BIBO) stable when every bounded input gives a bounded output. For an LTI system both tests reduce to one signal: the impulse response h(t), the output to δ(t). Causality asks where h(t) is zero; stability asks whether the area under |h(t)| is finite. Engineers use these tests on filters, sensors and control loops before trusting a design.

You need: Chapter 2.2 for h(t), and Unit 1 system properties for the words causal and stable.

Causality test on h(t)

A system is causal if y(t) uses only present and past input, never future input. For an LTI system, y(t)=∫x(τ)h(t−τ)dτ. If h(t−τ) is nonzero for τ>t, future input reaches y(t). So the test is h(t)=0 for t<0. The response must start at t=0 or later. At t=0, h(0) may be nonzero; only negative time is banned.

h(t) = 0 for t < 0

h(t) is the impulse response; t is time.

For example, e^{−2t}u(t) is causal, while u(t+1) is not. A causal h(t) can still have infinite area, as u(t) shows. Shift a noncausal h to the right and it can become causal; shift a causal h left and it can become noncausal. The test uses only where h(t) sits in time, not its size. A real-time filter cannot use a response that reacts before the impulse arrives.

BIBO stability test on h(t)

BIBO stable means every bounded input gives a bounded output. Let |x(t)|≤M_x<∞ and y(t)=∫h(τ)x(t−τ)dτ. Then |y(t)|≤M_x∫|h(τ)|dτ. A finite integral guarantees stability. The converse also holds: if the integral is infinite, some bounded input makes y(t) unbounded.

∫_{−∞}^{∞} |h(t)| dt < ∞

h(t) is the impulse response; |h(t)| is its absolute value; dt is a small time interval; the integral runs over all time.

This is the area under |h(t)|, called the L1 norm. Use absolute value; without it, positive and negative parts cancel and hide instability. For e^{−2t}u(t), area=∫_0^∞e^{−2t}dt=1/2, stable. For u(t), area=∫_0^∞1dt=∞, unstable. The input bound M_x is any finite number in the signal's units. The output bound M_y=M_x∫|h|dτ is finite when the area is finite. The units of ∫|h|dτ are seconds if h is dimensionless.

The two tests are independent

Causality and stability are independent. Causal does not imply stable: u(t) is zero for t<0 but has infinite area, so it is unstable. Stable does not imply causal: e^{2t}u(−t) has area 1/2 but is nonzero for t<0. Both can hold: e^{−2t}u(t). Neither can hold: e^{−t}u(−t) is nonzero for t<0 and its area is infinite. Only a few universities teach this as a separate chapter; most attach the tests to convolution.

  • causal stable: e^{−2t}u(t)
  • causal unstable: u(t)
  • noncausal stable: e^{2t}u(−t)
  • noncausal unstable: e^{−t}u(−t)

In an exam, run them one after the other. First check h(t) for t<0. Then integrate |h(t)| over all time. Do not infer one property from the other. A causal system can be unstable, and a stable system can be noncausal. The tests answer different questions: when does h(t) start, and how much total absolute area does it contain?

2.6 Systems described by differential equations

Many continuous-time LTI systems are built from resistors, capacitors, inductors, masses and dampers. Their input x(t) and output y(t) are tied by a linear constant-coefficient differential equation (LCCDE): a sum of y and its derivatives equals a sum of x and its derivatives, with constant multipliers. Solving it in time gives y(t) directly, including stored energy. RC and RL filters, motor drives and vehicle suspensions use this form. Unit 4 turns the same equation into a transfer function, but this chapter solves it with calculus.

You need: Chapter 2.1 for LTI, 2.2 for step response, and basic KVL and KCL from circuit theory.

From components to an LCCDE

An LCCDE writes the output y(t) and input x(t) with derivatives and constant multipliers:

a<sub>n</sub> d<sup>n</sup>y/dt<sup>n</sup> + ... + a<sub>1</sub> dy/dt + a<sub>0</sub> y = b<sub>m</sub> d<sup>m</sup>x/dt<sup>m</sup> + ... + b<sub>0</sub> x

y(t) is the output; x(t) is the input; n is the order, the highest derivative of y; ai and bj are real constants; m is the highest input derivative. The equation is linear because y and x appear only to the first power and are not multiplied, and it has constant coefficients because the multipliers do not change with t.

A circuit gives such an equation from Kirchhoff's laws. For a series RC circuit, let x(t) be the source voltage and y(t) the capacitor voltage. KVL gives x=vR+y. The resistor drop is vR=iR and the capacitor current is i=C dy/dt. Substitute:

RC dy/dt + y = x

R is resistance in ohms (Ω), C is capacitance in farads (F), and t is time in seconds (s).

With R=1 kΩ and C=1 μF, RC=(1000 Ω)(1×10−6 F)=0.001 s=1 ms. The order is one. A series RL circuit with current i as output follows L di/dt+R i=x, also first order, with time constant τ=L/R. A mechanical mass-damper follows M d²y/dt²+B dy/dt=F(t), which is second order.

Natural, forced, zero-input, zero-state

Solving an LCCDE has two parts. The natural response yn solves the homogeneous equation with the right side set to zero. The forced response yf is any particular solution that matches the input. The total is y=yn+yf. The constants in yn are fixed by the initial conditions after yf is added. In the zero-input case, x=0, so they depend only on stored energy. In the step example below, yf(0)=X and y(0)=0, so A=−X.

a<sub>n</sub>λ<sup>n</sup> + ... + a<sub>1</sub>λ + a<sub>0</sub> = 0

λ is the characteristic root; the roots give natural modes eλt. For first order τ dy/dt+y=x, the root is λ=−1/τ, so yn=Ae−t/τ, where A is a constant set by initial conditions.

For a step input x(t)=X u(t), X is the step height in volts and u(t) is the unit step, yf=X. If y(0)=0, A=−X and

y(t) = X(1 − e−t/τ)u(t)

τ is the time constant in seconds. At t=τ the output reaches 0.632X; as t→∞ it reaches X.

This is the zero-state step response: input present, initial stored energy zero. The zero-input response is the natural form with x=0, fixed by y(0). The two add. For RL, τ=L/R and a step voltage V gives i(t)=(V/R)(1−e−Rt/L)u(t) A.

Second-order mass-damper and initial conditions

For a mass M in kilograms sliding with viscous damping B in N·s/m under force F(t) in newtons, output displacement y(t) in metres obeys

M d²y/dt² + B dy/dt = F(t)

M is mass in kg, B is damping in N·s/m, F is applied force in N, and y is displacement in m.

The order is two, so two initial conditions are needed: y(0) and dy/dt at 0. The characteristic equation Mλ²+Bλ=0 has roots λ=0 and λ=−B/M. The natural response is C1+C2e−(B/M)t, where C1 and C2 are constants set by initial conditions. For a constant force F0, a particular solution is yf=(F0/B)t, a ramp at constant velocity F0/B. The total is C1+C2e−(B/M)t+(F0/B)t: a ramp plus a constant plus a decaying exponential. The constants fit the initial position and velocity.

Initial conditions belong to the output and its derivatives, not to the input. For a capacitor, y(0) is the voltage just after switching; for an inductor, i(0) is the current. These stored-energy values create the zero-input response. The same coefficients define the transfer function, a name used in Unit 4; here the time-domain solve is enough.

Worked example

Question. A series RC circuit has R=1 kΩ and C=1 μF. The input is x(t) V and the output y(t) V is the voltage across the capacitor. At t=0, y(0)=0. Find the time constant τ, the differential equation, y(t) for x(t)=u(t) V, and y at t=1 ms.

  1. τ=RC=(1000 Ω)(1×10−6 F)=0.001 s=1 ms.
  2. KVL gives x=vR+y. With vR=iR and i=C dy/dt, RC dy/dt+y=x. Divide by RC: dy/dt+(1/RC)y=(1/RC)x. Here 1/RC=1000 s−1. For t>0, x=1 V, so dy/dt+1000y=1000.
  3. Homogeneous equation: λ+1000=0, so λ=−1000 s−1 and yh=Ae−1000t V.
  4. For a constant particular solution yp=K, 0+1000K=1000, so K=1 V.
  5. y(0)=0 gives 0=A+1, so A=−1. Thus y(t)=(1−e−1000t)u(t) V.
  6. At t=1 ms=0.001 s, 1000t=1. e−1=0.367879, so y=1−0.367879=0.632121 V.

Answer. τ=1 ms, 1/RC=1000 s−1, y(t)=(1−e−1000t)u(t) V, and y(1 ms)=0.632 V.

Exam traps

  • Initial conditions are on y and its derivatives, not on the input. For a capacitor y(0) is the capacitor voltage after switching, not the source voltage.
  • For RC the time constant is τ=RC, not R+C. For RL it is τ=L/R, not LR. Check units: Ω·F=s and H/Ω=s.
  • The zero-input response and zero-state response add. Do not add a homogeneous solution twice or mix the two sets of constants.
  • The order is the highest derivative of the output, not the number of components. Two capacitors in some connections still give a first-order equation.
  • A step input makes the forced response constant only after t=0. For t below zero, x=0, so the particular solution is 0.

2.7 State variables and normal form of system equations

A state variable is a signal that stores part of a system's memory. Together, n state variables form the state vector x(t). For an LTI system, the state equations x′ = Ax + Bu and output equation y = Cx + Du replace one nth-order differential equation with n first-order equations. This normal form is used in control, circuit simulation and robotics. Only a few universities teach this advanced view in a signals course; others leave it to a later control course.

You need: Chapter 2.6 for LCCDEs and basic matrix notation (rows, columns, transpose).

State variables and the state model

Let y(t) be the output of a continuous-time LTI system. A state variable is one scalar signal xᵢ(t) such that the n values x₁(0),…,xₙ(0) plus the input u(t) for t≥0 determine all future behaviour. The state vector is the column x = [x₁ … xₙ]ᵀ.

x′ = A x + B u, y = C x + D u

x′ is dx/dt; x is the n×1 state vector; u is the m×1 input vector; y is the p×1 output vector; A is n×n, B is n×m, C is p×n, D is p×m. For one input and one output, B is n×1, C is 1×n, D is 1×1.

The matrix A holds the system dynamics; B says how input enters; C selects what we measure; D is direct feedthrough, often zero.

Normal form for a differential equation

Normal form, also called phase-variable or companion form, is a standard state choice for an LCCDE. It uses the output and its first n−1 derivatives as states. It never uses derivatives of the input.

  1. Write the equation with the highest derivative alone.
  2. Set x₁=y, x₂=y′, …, xₙ=y⁽ⁿ⁻¹⁾.
  3. Differentiate to get x₁′=x₂, …, xₙ₋₁′=xₙ.
  4. Substitute to get xₙ′ = −a₀x₁−…−aₙ₋₁xₙ + b u.
  5. Take the output as y=x₁.

The recipe above applies when the right side is b u, with no derivatives of u. If the right side contains u′, u″, …, choose states that cancel the input derivatives. For y″+a₁y′+a₀y=b₁u′+b₀u, take x₁=y and x₂=y′−b₁u. Here a₀, a₁, b₀, b₁ are constants, b₁ is the coefficient of u′ and b₀ is the coefficient of u. Then x₁′=x₂+b₁u and x₂′=−a₀x₁−a₁x₂+(b₀−a₁b₁)u. The matrix A is still the companion matrix [[0,1],[−a₀,−a₁]], but B=[b₁, b₀−a₁b₁]ᵀ, and C may change if the output is not x₁. For higher order, cancel each input derivative the same way.

For y″+3y′+2y=u, choose x₁=y and x₂=y′. Then x₁′=x₂ and x₂′=−2x₁−3x₂+u. The matrices are A=[[0,1],[−2,−3]], B=[0,1]ᵀ, C=[1,0], D=0. The 2×2 A has the coefficients in its last row; B is a column; C picks x₁.

Takeaways

  1. An LTI system is completely described by its impulse response h(t).
  2. Superposition and time invariance let you build the output from shifted scaled impulses.
  3. The step response is the running integral of the impulse response; h(t) is the derivative of s(t).
  4. Convolution is the time-domain rule y=x*h for any LTI system.
  5. Convolution is commutative, associative, distributive, and has δ(t) as identity.
  6. Causality is a support condition on h(t); BIBO stability is an area condition on |h(t)|.
  7. A linear constant-coefficient differential equation is an LTI system; its solution has natural and forced parts.
  8. Any nth-order differential equation can be written as n first-order state equations in normal form.

Exam question bank

Long answers usually ask for a definition plus derivation, a graphical convolution, a causality or stability test on h(t), or conversion of a differential equation to state form.

Remember and understand

Understand State the commutative, associative, distributive, and identity properties of continuous-time convolution. Give one system-level meaning of each property. 10 marks

Commutativity x*h=h*x; Associativity for cascade; Distributivity for parallel connection; Identity x*δ=x; Brief interpretation of each.

Understand Define causality and BIBO stability for a continuous-time LTI system. State the necessary and sufficient conditions on h(t) for each. 10 marks

Causal: output depends only on present and past input; Condition h(t)=0 for t<0; BIBO: bounded input yields bounded output; Condition ∫|h(t)|dt<∞; Sufficiency argument using a bound on x.

Apply Let x(t)=e^{−2t}u(t) and h(t)=u(t)−u(t−3). Evaluate y(t)=x(t)*h(t) by the convolution integral and give y(t) for all t. 12 marks

Apply A system is described by dy(t)/dt+3y(t)=2x(t). Find its impulse response h(t) and step response s(t) using time-domain reasoning. 12 marks

Solve homogeneous equation for t>0; Apply impulse matching or initial condition; h(t)=2e^{−3t}u(t); s(t)=∫h=(2/3)(1−e^{−3t})u(t); Check in the differential equation.

Apply For h(t)=e^{−4t}u(t), test causality and BIBO stability. Compute the area ∫|h(t)|dt and state the conclusion. 8 marks

h(t)=0 for t<0 so causal; Compute ∫_0^∞e^{−4t}dt=1/4; Finite area implies BIBO stable; State bounded-input argument; No contradiction with causality.

Apply Convert d²y/dt²+5dy/dt+6y=dx/dt+2x into state equations in normal form. Define the state variables clearly. 12 marks

Choose x₁=y, x₂=dy/dt; Write dx₁/dt=x₂; Write dx₂/dt=−6x₁−5x₂+dx/dt+2x; Handle input derivative by suitable state choice or input u and du/dt; Write matrix form and output equation.

Analyze and evaluate

Analyze Compare two LTI systems with h₁(t)=δ(t−1) and h₂(t)=e^{−t}u(t). Discuss causality, BIBO stability, memory, and the output when the input is u(t). 12 marks

h₁ causal and stable; pure delay; h₂ causal and stable; low-pass-like; Memory: h₁ has memory (delay), h₂ has infinite memory; Step responses: u(t−1) versus (1−e^{−t})u(t); Convolution with same input.

Analyze For the system d²y/dt²+3dy/dt+2y=x(t), discuss natural and forced response. Relate the impulse response to the characteristic roots. 12 marks

Characteristic equation r²+3r+2=0; Roots −1 and −2; Natural response c₁e^{−t}+c₂e^{−2t}; Forced response from input; h(t)=(e^{−t}−e^{−2t})u(t); Initial conditions and zero-input or zero-state parts.

Evaluate Explain the graphical evaluation of the convolution integral. Use x(t)=u(t)−u(t−2) and h(t)=u(t)−u(t−1) to obtain y(t), and comment on the duration and shape. 14 marks

Flip h(τ) to h(−τ); Shift by t; Find overlap intervals; Piecewise integral for t<0, 0≤t<1, 1≤t<2, 2≤t<3, t≥3; Result is trapezoid or triangle shape; Duration equals sum of input durations.

Evaluate A student claims: 'Every causal LTI system is BIBO stable.' Evaluate the claim. Either prove it or give a counterexample using h(t), and state the correct relation between causality and stability. 10 marks

Causality constrains support only; Counterexample h(t)=u(t) is causal but ∫|h|=∞; BIBO condition is absolute integrability; Causal stable example e^{−t}u(t); Conclusion: the properties are independent.

Glossary

Absolutely integrable
A signal h(t) with finite area under its absolute value, ∫|h(t)|dt<∞.
Additivity
Output to x₁+x₂ equals output to x₁ plus output to x₂.
Associative
Grouping of three convolved signals can be changed without changing the result.
BIBO stability
Every bounded input produces a bounded output.
Causality
A system property where the output at time t depends only on inputs up to time t.
Characteristic equation
The polynomial equation obtained by setting the homogeneous part of a differential equation to zero.
Commutative
Order of the two signals in convolution can be exchanged without changing the result.
Convolution
The operation y(t)=∫x(τ)h(t−τ)dτ that gives the output of an LTI system.
Differential equation
An equation relating an output and its derivatives to an input and its derivatives.
Distributive
Convolution distributes over addition of impulse responses.
Forced response
The zero-state part of the output, produced by the input.
Homogeneity
Output to a x(t) equals a times output to x(t) for any constant a.
Impulse response h(t)
The output of an LTI system to input δ(t) with zero initial conditions.
Linear constant-coefficient differential equation
A differential equation whose coefficients are constants and whose terms are linear in y, x, and derivatives.
Linearity
The property that a system obeys superposition: scaling and adding inputs scales and adds outputs.
LTI system
A system that is both linear and time-invariant.
Natural response
The zero-input part of the output, fixed by initial conditions and system roots.
Normal form
A first-order vector equation dx/dt=Ax+Bu plus output equation y=Cx+Du.
State equation
The equation dx/dt=Ax+Bu that updates the state vector.
State variable
A variable in a minimal set that, with the input, determines the future of the system.
State vector
A column vector collecting all state variables of a system.
Step response s(t)
The output of an LTI system to input u(t) with zero initial conditions.
Superposition
Output to a combination of inputs equals the same combination of individual outputs.
Time invariance
A time shift in the input produces the same time shift in the output.
Unit impulse δ(t)
A signal that is zero except at t=0, has unit area, and satisfies ∫δ(t)dt=1.
Unit step u(t)
A signal equal to 1 for t≥0 and 0 for t<0.
