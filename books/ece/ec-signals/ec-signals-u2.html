2.1 Linear time-invariant (LTI) systems

A continuous-time system is linear time-invariant (LTI) when it obeys two rules. Linearity: scaling and adding inputs scales and adds the outputs in the same way. Time invariance: an input delayed by t₀ seconds gives the same output, delayed by t₀ seconds. Together the two rules mean the system is fixed by one signal, its impulse response, so one convolution integral gives the output for every input. Audio equalisers, RC and RLC filters, amplifiers working in their linear range and transmission lines are all modelled as LTI systems.

You need: the classification of systems (linearity, time invariance, causality, stability) and the unit impulse δ(t) and unit step u(t).

The two rules

Write a continuous-time system as an operator T: the input x(t) goes in and the output y(t)=T{x(t)} comes out, with t in seconds. The system is linear if, for every pair of inputs and every pair of constants,

T{a x₁(t) + b x₂(t)} = a T{x₁(t)} + b T{x₂(t)}

x₁(t) and x₂(t) are any two inputs, a and b are any constants, and y₁=T{x₁}, y₂=T{x₂} are their outputs. The rule packs two properties: additivity (a=b=1) and homogeneity or scaling (b=0). Together they are called the superposition principle.

Put a=b=0 and the rule says T{0}=0: a linear system gives zero output for zero input. This zero-in, zero-out check is quick but only necessary; y(t)=x²(t) passes it and is still nonlinear.

if x(t) → y(t), then x(t − t₀) → y(t − t₀)

t₀ is any delay in seconds (positive t₀ delays, negative t₀ advances). The rule says the system's behaviour does not depend on clock time. Some syllabi call this shift invariance.

A system that obeys both rules is LTI. Being LTI says nothing about causality or stability; those are separate tests, done on the impulse response in causality and BIBO stability of LTI systems.

Testing a formula: two paths that must meet

Each test compares two paths through the system. If the two paths give different outputs for even one choice of inputs, the property fails.

  1. Linearity, path 1: combine first. Form a x₁ + b x₂, pass it through T.
  2. Linearity, path 2: pass x₁ and x₂ through T separately, then form a y₁ + b y₂.
  3. Compare. A mismatch for one choice of inputs proves the system nonlinear. A match for one choice proves nothing; to prove linearity, do the comparison with symbols for all inputs.
  4. Time invariance, path 1: delay the input to x(t − t₀), pass it through T. Write the result as yd(t), the output for the delayed input.
  5. Time invariance, path 2: take the original output y(t) and replace every t by t − t₀.
  6. Compare yd(t) with y(t − t₀). Equal for every t and t₀ means time-invariant.

Three patterns settle most exam systems. An added constant, y(t)=3x(t)+2, breaks linearity because T{0}=2, but it keeps time invariance. A multiplier that depends on t, y(t)=t·x(t), keeps linearity but breaks time invariance. Scaling the time axis, y(t)=x(2t), is linear but time-varying: with x(t)=t and t₀=1 s, the delayed input x(t−1)=t−1 gives yd(t)=2t−1, while y(t−1)=2(t−1)=2t−2. At t=1 s these are 1 and 0. The delay is squeezed along with the signal, so the two paths do not meet.

Why LTI is worth the trouble

Any input can be written as a continuous sum, that is an integral, of shifted impulses: x(t)=∫ x(τ)δ(t−τ)dτ, taken over all τ. This is the sifting property of δ(t); τ is a dummy variable that runs along the input's time axis. If the system's response to δ(t) is h(t), time invariance gives the response h(t−τ) to δ(t−τ), and linearity lets you weight each response by x(τ) and add them all. The result is the convolution integral of convolution integral and its evaluation.

So one measured signal, h(t), predicts the response to every input. The same fact gives the frequency response H(jω) and the transfer function H(s), treated in Fourier analysis and Laplace transform analysis. Squarers, limiters, rectifiers and time-scalers are not LTI and need other methods. Most real circuits are LTI only over a range: an op-amp stage is linear until its output saturates.

Worked example

Question. Test the system y(t)=3x(t)+2 for linearity and time invariance. For linearity use x₁(t)=1, x₂(t)=2, a=2 and b=3. For time invariance use x(t)=t and a delay t₀=2 s, and evaluate both paths at t=5 s. State whether the system is LTI.

  1. The system rule is T{x}=3x+2.
  2. Path 1 (combine first): a x₁ + b x₂ = 2(1)+3(2)=8. Then T{8}=3(8)+2=26.
  3. Path 2 (separately): T{x₁}=3(1)+2=5 and T{x₂}=3(2)+2=8. Then a y₁ + b y₂ = 2(5)+3(8)=10+24=34.
  4. 26 ≠ 34, so the system is not linear. One counterexample is enough. (Also T{0}=2 ≠ 0.)
  5. Time invariance, path 1: the delayed input is x(t−2)=t−2, so yd(t)=3(t−2)+2=3t−4.
  6. Path 2: the original output is y(t)=3t+2; replace t by t−2: y(t−2)=3(t−2)+2=3t−4.
  7. The two expressions are the same for every t; at t=5 s both give 3(5)−4=11. Because the rule 3x+2 has no t of its own, the same algebra works for any input and any delay, so the system is time-invariant.
  8. Linear fails, time invariance holds: the system is not LTI.

Answer. Not linear (26 ≠ 34) but time-invariant (both paths give 11 at t=5 s), so y(t)=3x(t)+2 is not an LTI system.

Worked example 2

Question. Test y(t)=t·x(t) for linearity and time invariance. For the time test use x(t)=u(t), t₀=1 s and evaluate at t=2 s.

  1. Linearity with symbols: T{a x₁ + b x₂}=t[a x₁(t)+b x₂(t)]=a·t x₁(t)+b·t x₂(t)=a y₁ + b y₂. This holds for every input and constant, so the system is linear.
  2. Delayed input: x(t−1)=u(t−1). The system multiplies whatever arrives by the present time t, so yd(t)=t·u(t−1). At t=2 s: yd(2)=2×1=2.
  3. Shifted output: y(t)=t·u(t), so y(t−1)=(t−1)·u(t−1). At t=2 s: y(2−1)=1×1=1.
  4. 2 ≠ 1, so the system is time-varying. The multiplier t is a clock inside the system.

Answer. Linear but time-varying (2 ≠ 1 at t=2 s), so not LTI.

Exam traps

  • Using t₀ for the delay and then replacing t by t − t₀ inside the system's own multiplier: for y(t)=t·x(t), only the input is delayed in path 1, so yd(t)=t·x(t−t₀), not (t−t₀)x(t−t₀).
  • Calling y(t)=x(2t) time-invariant because the rule has no t outside the input: the factor 2 scales the time axis itself, and the delay test fails (1 ≠ 0 at t=1 s with x(t)=t and t₀=1 s).
  • An added constant breaks linearity, not time invariance: y(t)=3x(t)+2 is time-invariant but not LTI. Some students call it "linear" because its graph against x is a straight line.
  • Proving linearity with one numerical pair: a match for one pair proves nothing. Use symbols, or one mismatch to disprove.
  • Time-invariant does not mean the output is constant in time. It means the rule that turns input into output does not change with time.

2.2 Impulse response and step response

The impulse response h(t) is the output of an LTI system when the input is the unit impulse δ(t) and the system starts at rest (no stored energy). The step response s(t) is the output when the input is the unit step u(t), again from rest. The two carry the same information: s(t) is the running integral of h(t), and h(t) is the slope of s(t). A step is easy to apply on a lab bench (close a switch), so engineers often measure s(t) and differentiate it to get h(t), which then predicts the response to any input.

You need: linear time-invariant (LTI) systems, and the unit impulse and unit step with u′(t)=δ(t).

The impulse response describes the system

δ(t) is zero for every t ≠ 0 and has unit area. Applied to an LTI system at rest, it gives h(t). Some syllabi call h(t) the weighting function, because h(t−τ) says how strongly the input at time τ is weighted in the output at time t.

h(t) belongs to the system, not to any input. Time invariance turns an impulse at t₀ into h(t−t₀); linearity turns an impulse of area A into A·h(t). These two facts give the convolution integral. A causal system has h(t)=0 for t<0: it cannot answer before the impulse arrives.

For an RC low-pass filter (output across C) with time constant τ=RC, h(t)=(1/τ)e−t/τu(t). In this chapter τ means the time constant, not a dummy variable. When input and output are both voltages, h(t) has unit s−1: the factor 1/τ sets both its height and its unit.

The step response is the running integral of h(t)

A unit step is the running integral of the unit impulse: u(t)=∫−∞t δ(λ)dλ, with λ a dummy variable. An LTI system commutes with integration (integration is itself an LTI operation), so the step response is the running integral of the impulse response:

s(t) = ∫−∞t h(λ) dλ

s(t) is the step response, h(λ) is the impulse response at time λ, and λ is a dummy variable of integration. The lower limit −∞ collects h(λ) for every λ before t. For a causal system h(λ)=0 when λ<0, so the integral starts at 0 and s(t)=∫0t h(λ)dλ for t≥0.

h(t) = ds(t)/dt

the impulse response is the slope of the step response. If s(t) jumps by J at t=0, the derivative contains J·δ(t): a jump in s means an impulse in h. A smooth rise gives no impulse.

For the RC filter, s(t)=∫0t(1/τ)e−λ/τdλ=(1−e−t/τ)u(t). The capacitor voltage reaches 63.2% of its final value at t=τ, 95.0% at 3τ and 99.3% at 5τ. The same result comes from solving the circuit's differential equation in systems described by differential equations.

Reading the two curves

Figure 2.2.1 plots h(t) and s(t) for the RC filter of the worked example (τ=1 ms). At t=0, h=1000 s−1 and s=0; at t=1 ms, h=368 s−1 and s=0.632. Where h is large, s climbs steeply; as h dies out, s levels off at 1. The final value of s equals the total area under h, which is the system's DC gain.

On a bench, a narrow pulse stands in for δ(t) if its width is much shorter than τ, and a square wave with a long period gives repeated steps. The two measurements must agree through the integral and derivative relations; if they do not, suspect the probe capacitance or the load.

Exam traps

  • Swapping the relations: s(t) is the integral of h(t) and h(t) is the derivative of s(t), never the other way round.
  • Dropping u(t): the RC filter has h(t)=0 and s(t)=0 for t<0. Writing h(t)=1000e−1000t with no u(t) claims a huge output before the impulse arrives.

  • Missing the impulse when s(t) jumps: s(t)=(1−0.5e−2t)u(t) jumps by 0.5 at t=0, so h(t) contains 0.5δ(t).

2.3 Convolution integral and its evaluation

The convolution integral gives the output of a continuous-time LTI system from its input x(t) and its impulse response h(t): y(t)=x(t)*h(t). It adds up one shifted, scaled copy of h for every instant of the input. To evaluate it, flip h, slide it across x, multiply the two where they overlap and take the area. Engineers use it to predict a filter's response to a pulse, a loudspeaker's response to a click and a channel's response to one data symbol.

You need: linear time-invariant (LTI) systems and impulse response and step response.

From shifted impulses to an integral

Cut the input into narrow strips of width Δτ. The strip at time τ is close to an impulse of area x(τ)Δτ placed at τ. By time invariance and scaling the system answers it with x(τ)Δτ·h(t−τ). By additivity the output is the sum of all these answers. As Δτ→0 the sum becomes an integral:

y(t)=∫−∞∞ x(τ)h(t−τ)dτ

t is the output time (s), the instant at which you want y; τ is the dummy integration variable (s) that runs along the input's past and future; x(τ) is the input; h(t−τ) is the impulse response flipped and slid to t; y(t) is the output. The integral is also called the superposition integral.

Two common cases shorten the limits. If the system is causal, h(t−τ)=0 whenever t−τ<0, that is whenever τ>t, so the upper limit becomes t. If the input starts at zero, x(τ)=0 for τ<0, so the lower limit becomes 0. With both, y(t)=∫0t x(τ)h(t−τ)dτ for t≥0. Use this short form only when both conditions hold.

Flip, slide, multiply, integrate

Graphical convolution is a five-step routine. It turns the integral into areas you can see, and it shows where the limits come from.

  1. Sketch x(τ) on a τ axis.
  2. Sketch h(τ) and flip it about τ=0 to get h(−τ).
  3. Slide the flipped copy right by t to get h(t−τ); its right edge sits at τ=t.
  4. Multiply x(τ) by h(t−τ) at every τ.
  5. Integrate the product over the overlap only. Repeat for each range of t in which the overlap has the same shape.

The edges of the overlap change at breakpoints: values of t where an edge of h(t−τ) crosses an edge of x(τ). Each range between breakpoints is a separate case with its own limits. In the worked example x lasts from 0 to 2 s and h starts at 0, so the breakpoints are t=0 and t=2 s: for 0≤t<2 s the overlap is 0≤τ≤t, and for t≥2 s it is 0≤τ≤2.

Numerical convolution as a check

Some syllabi ask for numerical convolution: sample the integrand and add areas. At t=1 s in the worked example the integrand is f(τ)=eτ−1 on 0≤τ≤1. With step 0.5 s the samples at τ=0, 0.5, 1 are 0.3679, 0.6065 and 1.0000. The trapezoid rule gives 0.5×[0.5(0.3679+1.0000)+0.6065]=0.6452. The exact value is 0.6321, so the error is 0.0131; halving the step to 0.25 s gives 0.6354, an error of 0.0033. A quick numerical check like this catches sign slips in exponents, because a wrong sign changes the answer by far more than the rule's error.

Worked example

Question. Let x(t)=u(t)−u(t−2) (a 2 s unit pulse) and h(t)=e−tu(t), t in seconds. Find y(t)=x(t)*h(t) for all t, and give y(1), y(2) and y(3) to three decimal places.

  1. Set up: y(t)=∫x(τ)h(t−τ)dτ. Here x(τ)=1 for 0≤τ<2 and 0 elsewhere. h(t−τ)=e−(t−τ) when t−τ≥0, that is when τ≤t, and 0 otherwise.
  2. The product is nonzero only where 0≤τ<2 and τ≤t. Breakpoints: t=0 and t=2 s. Cases: t<0, 0≤t<2, t≥2.
  3. Case t<0: the flipped h lies entirely left of τ=0 and does not reach the pulse, so y(t)=0.
  4. Case 0≤t<2: the overlap is 0≤τ≤t. y(t)=∫0te−(t−τ)dτ=e−t∫0teτdτ=e−t(et−1)=1−e−t. So y(1)=1−e−1=1−0.368=0.632.
  5. Case t≥2: the overlap is the whole pulse, 0≤τ≤2. y(t)=∫02e−(t−τ)dτ=e−t(e2−1)=e2−t−e−t. So y(2)=1−e−2=1−0.135=0.865 and y(3)=e−1−e−3=0.368−0.050=0.318.
  6. Check continuity at the breakpoint: the first case gives 1−e−2=0.865 at t=2 and the second gives e0−e−2=0.865. The pieces join, as they must when neither signal contains an impulse.

Answer. y(t)=0 for t<0; y(t)=1−e−t for 0≤t<2 s; y(t)=e2−t−e−t for t≥2 s. y(1)=0.632, y(2)=0.865, y(3)=0.318.

Exam traps

  • The limits come from the overlap, not automatically 0 to t. In the worked example the upper limit stays at 2 for every t≥2 s.
  • h(t−τ)=e−(t−τ)=e−t+τ, not e−t−τ. Writing the wrong sign gives y(1)=e−1(1−e−1)=0.233 instead of 0.632.
  • Flip one signal only. In ∫x(τ)h(t−τ)dτ it is h that is flipped; flipping both, or neither, is a different integral.
  • Missing a case: for two finite pulses there are usually four or five ranges of t (no overlap, entering, full, leaving, no overlap). Write the case for t<0 and the last case too.
  • The output does not stop when the input stops. For t>2 s, x(t)=0 but y(t)=e2−t−e−t≠0, because the system remembers the past input.

2.4 Properties of convolution

Convolution obeys an algebra much like multiplication: you can swap the two signals, regroup three of them and split a sum, and δ(t) plays the part of 1. These rules turn block diagrams of LTI systems into single impulse responses, predict where an output starts and ends, and let you check a long integral in a few lines. Only a few universities teach this as a chapter of its own; the rules still appear inside convolution questions everywhere.

You need: convolution integral and its evaluation.

The four laws and what they mean for systems

Here x*h means ∫−∞∞x(τ)h(t−τ)dτ, with τ the dummy variable and t the output time.

  • Commutative: x*h=h*x. Input and impulse response can trade places. Proof: substitute λ=t−τ.
  • Associative: (x*h₁)*h₂=x*(h₁*h₂). Two LTI systems in cascade act as one system with impulse response h₁*h₂, in either order. Proof: write the double integral and swap the order of integration.
  • Distributive: x*(h₁+h₂)=x*h₁+x*h₂. Two systems in parallel whose outputs are added act as one system with impulse response h₁+h₂.
  • Identity: x*δ=x, by the sifting property. More generally x(t)*δ(t−t₀)=x(t−t₀): convolving with a shifted impulse delays the signal by t₀.

The analogy with multiplication stops at division. Some systems have an inverse system hinv(t) with h*hinv=δ, so a cascade of the two passes any input unchanged; undoing a convolution this way is called deconvolution. An echo channel h(t)=δ(t)+0.5δ(t−1) has the inverse hinv(t)=δ(t)−0.5δ(t−1)+0.25δ(t−2)−…, since every term after δ(t) cancels in pairs. Other systems have no inverse at all: an ideal low-pass filter removes high frequencies completely, and nothing can bring them back.

Shift, width and calculus rules

Shift: if x(t)*h(t)=y(t), then x(t−t₁)*h(t−t₂)=y(t−t₁−t₂). Delays add.

Width: if x is nonzero only on ax≤t≤bx and h only on ah≤t≤bh, then y is nonzero only on ax+ah≤t≤bx+bh. Start times add, end times add and so widths add: Ty=Tx+Th. The rule needs finite widths; u(t) or cos ωt give no finite answer.

Two rectangles: heights Ax and Ah, widths Tx and Th, give a trapezoid of peak AxAh·min(Tx, Th); equal widths give a triangle.

Derivative and integral: d/dt(x*h)=(dx/dt)*h=x*(dh/dt), and the running integral of x*h equals (running integral of x)*h. The step response is a case of the second rule: s=u*h is the running integral of δ*h=h.

Worked example

Question. Let x(t)=u(t)−u(t−2) and h(t)=u(t)−u(t−3), t in seconds. Use the properties to find where y=x*h is nonzero and its peak value, then write y(t) on each interval and check the area.

  1. x is a unit rectangle on 0≤t≤2 (Tx=2 s) and h is a unit rectangle on 0≤t≤3 (Th=3 s).
  2. Width rule: start 0+0=0, end 2+3=5. y is nonzero on 0≤t≤5, a width of 5 s.
  3. Peak: AxAh·min(2, 3)=1×1×2=2, reached while the 2 s pulse lies fully inside the 3 s pulse.
  4. Rising edge, 0≤t≤2: the overlap length is t, so y=t.
  5. Flat top, 2≤t≤3: the overlap is the whole 2 s, so y=2.
  6. Falling edge, 3≤t≤5: the overlap length is 5−t, so y=5−t.
  7. Area check: the area of a convolution is the product of the areas, 2×3=6. Trapezoid area = ½(5+1)×2=6. They agree.

Answer. y is nonzero for 0≤t≤5 s with peak 2 on 2≤t≤3 s: y=t (0≤t≤2), y=2 (2≤t≤3), y=5−t (3≤t≤5), and 0 elsewhere.

Exam traps

  • The width rule needs finite widths: u(t) lasts forever, so u*h has no finite width.
  • Heights multiply, then the overlap width scales them; they never add. Heights 2 and 3 with the shorter width 1 s peak at 2×3×1=6, not 5.
  • δ(t) is the identity, not zero: x*δ=x. And x*δ(t−t₀)=x(t−t₀) is a delay, not a product with δ.
  • The derivative rule moves the derivative onto one signal only: d/dt(x*h)=(dx/dt)*h, never (dx/dt)*(dh/dt).

2.5 Causality and BIBO stability of LTI systems

An LTI system is causal when its output never depends on future input, and BIBO stable (bounded-input, bounded-output) when every bounded input gives a bounded output. For an LTI system both questions are answered by the impulse response alone. Causality asks where h(t) lives: it must be zero for t<0. Stability asks how big h(t) is overall: the area under |h(t)| must be finite. Only a few universities teach these tests as a chapter of their own, but every syllabus asks them, and designers run them on any filter or control loop before building it.

You need: convolution integral and its evaluation.

Causality: where h(t) lives

Write the output as y(t)=∫−∞∞h(τ)x(t−τ)dτ. The term at τ uses the input at time t−τ. For τ<0 that input lies in the future. The output can be free of future input for every x only if those weights are zero:

h(t) = 0 for t < 0

the condition is necessary and sufficient for a causal LTI system. h(0) may be nonzero: only negative time is ruled out.

So e−2tu(t) is causal and u(t+1) is not, because it switches on at t=−1 s. A causal h can still be unstable: u(t) is causal with infinite area. A noncausal h can be made causal by delaying it: h(t−T) starts T seconds later. Offline processing (a recorded song, a stored image) may use noncausal filters, because the "future" samples are already stored.

A memoryless system is the special case h(t)=Kδ(t): y(t)=Kx(t) depends only on the present input.

BIBO stability: how big h(t) is

∫−∞∞ |h(t)| dt < ∞

h(t) is the impulse response and |h(t)| its absolute value. A signal that meets this is called absolutely integrable. The condition is necessary and sufficient for BIBO stability of an LTI system.

Sufficient. Let the input be bounded, |x(t)|≤Mx for all t. Then |y(t)|≤∫|h(τ)||x(t−τ)|dτ≤Mx∫|h(τ)|dτ. If the area is finite, every output is bounded by Mx times the area.

Necessary. Suppose the area is infinite. Choose the bounded input x(t)=sgn[h(−t)], which is +1, −1 or 0. Then y(0)=∫h(τ)x(−τ)dτ=∫|h(τ)|dτ, which is infinite. One bounded input with an unbounded output is enough to fail.

The absolute value matters: without it, positive and negative lobes can cancel and hide an unstable system. When input and output share a unit, h(t) has unit s−1 and the area is a pure number: the worst-case gain My/Mx.

The two tests are independent

Neither property implies the other. Figure 2.5.1 shows one impulse response of each kind:

  • causal and stable: e−2tu(t), area 1/2;
  • causal and unstable: u(t), area ∞;
  • noncausal and stable: e2tu(−t), area 1/2;
  • noncausal and unstable: e−tu(−t), which grows without limit as t→−∞, area ∞.

In an exam, run the two tests one after the other: first look at h(t) for t<0, then integrate |h(t)| over all time. For a causal h(t) built from exponentials, the same answer appears in Laplace transform analysis as "all poles in the left half of the s-plane".

Worked example

Question. Test h₁(t)=e−2tu(t), h₂(t)=e2tu(−t) and h₃(t)=u(t) for causality and BIBO stability. Give the area under |h| in each case.

  2. h₂ is nonzero for t<0 (for example h₂(−1)=e−2=0.135), so it is not causal. Area=∫−∞0e2tdt=[e2t/2]−∞0=1/2−0=1/2. Finite, so stable.
  3. h₃ is zero for t<0, so it is causal. Area=∫0∞1 dt, which grows without limit. Not stable: the bounded input u(t) gives the ramp y(t)=t·u(t).
  4. Bound check for h₁: an input with |x|≤5 V gives |y|≤5×1/2=2.5 V.

Exam traps

  • Causal does not imply stable: u(t) is zero for t<0 but its area is infinite.
  • Stable does not imply causal: e2tu(−t) has finite area 1/2 but is nonzero before t=0.
  • Leaving out the absolute value: the ideal low-pass impulse response h(t)=sin(t)/(πt) has net area exactly 1, yet the area under |h(t)| is infinite, so it is not BIBO stable.
  • Causality allows h(0)≠0; it forbids only t<0. δ(t) itself is causal.
  • BIBO is tested on h(t), not on one chosen input. A single bounded input that gives a bounded output proves nothing.

2.6 Systems described by differential equations

Circuits of resistors, capacitors and inductors, and machines of masses, springs and dampers, tie their input x(t) and output y(t) by a linear constant-coefficient differential equation (LCCDE): a weighted sum of y and its derivatives equals a weighted sum of x and its derivatives, with constant weights. With the system at rest such an equation is an LTI system. Solving it in the time domain gives the full response, including the part caused by energy already stored in a capacitor or inductor. RC and RL filters, motor drives and vehicle suspensions are all designed this way.

You need: impulse response and step response, and first-order differential equations from mathematics.

From components to an LCCDE

aₙ dⁿy/dtⁿ + … + a₁ dy/dt + a₀ y = bₘ dᵐx/dtᵐ + … + b₁ dx/dt + b₀ x

y(t) is the output, x(t) the input, and the a's and b's are real constants. The order n is the highest derivative of y. The equation is linear because y, x and their derivatives appear only to the first power and are never multiplied together; it has constant coefficients because no weight changes with t. Constant coefficients give time invariance.

Kirchhoff's laws give the equation. In a series RC circuit, let x(t) be the source voltage and y(t) the capacitor voltage. KVL: x=vR+y. The resistor drop is vR=iR and the capacitor current is i=C dy/dt. Substituting:

RC dy/dt + y = x

R in ohms (Ω), C in farads (F), t in seconds. RC has the unit of time (Ω·F=s) and is the time constant τ.

A series RL circuit with current i as output gives L di/dt+Ri=x, time constant τ=L/R (H/Ω=s). A mass M pushed by force F(t) against viscous damping B gives M d²y/dt²+B dy/dt=F(t), which is second order and needs two initial conditions.

Natural and forced, zero-input and zero-state

The natural response yn solves the equation with the right side set to zero. Try eλt: each derivative brings a factor λ, which gives the characteristic equation

aₙλⁿ + … + a₁λ + a₀ = 0

λ is a characteristic root (unit s−1); each root gives a mode eλt. For τ dy/dt+y=x the root is λ=−1/τ, so yn=Ae−t/τ.

The forced response yf is a particular solution with the shape of the input: a constant for a step, a ramp for a ramp. The total is y=yn+yf, and the constants in yn are fitted to the initial conditions after yf is added, so they depend on both the stored energy and the input.

The same total can be split another way. The zero-input response is what the stored energy alone produces (x=0). The zero-state response is what the input alone produces from rest; it is the convolution x*h, and it is the part that is LTI. Total = zero-input + zero-state. Worked example 2 shows both splits with numbers.

For a unit step from rest, y(t)=(1−e−t/τ)u(t). The rise time from 10% to 90% of the final value is τ ln 9=2.2τ. Differentiating gives the impulse response h(t)=(1/τ)e−t/τu(t), the same as in impulse response and step response.

The same equation in frequency

Put x=ejωt into RC dy/dt+y=x. The output is H(jω)ejωt with H(jω)=1/(1+jωRC). For RC=1 ms, at ω=1000 rad/s (f=159 Hz), |H|=1/√2=0.707 and the phase is −45°. Replacing jω by s gives the transfer function H(s)=1/(1+sRC). The full frequency-domain and s-domain treatment belongs to Fourier analysis and Laplace transform analysis; here the time-domain solution is enough.

2.7 State variables and normal form of system equations

A state variable is a signal that holds part of a system's memory, such as a capacitor voltage, an inductor current, or a position and a velocity. An nth-order system needs n of them, collected in the state vector. The state model replaces one nth-order differential equation by n first-order equations, written in matrix form. This normal form is what computers integrate, and it is the starting point of modern control and of circuit simulation. Only a few universities teach it in a signals course; others leave it to a later control course.

You need: systems described by differential equations.

State variables and the state model

In state models the input is written u(t), because the letter x now names the state; most control texts do the same. The state variables x₁(t), …, xₙ(t) are chosen so that their values at t=0, together with u(t) for t≥0, fix the whole future of the system. They form the column vector x=[x₁ … xₙ]T. A natural choice is one variable per energy store: each capacitor voltage and each inductor current.

x′ = A x + B u, y = C x + D u

x′=dx/dt; for one input and one output, A is n×n (the dynamics), B is n×1 (how the input enters), C is 1×n (what is measured) and D is 1×1 (direct feed from input to output, often 0). With m inputs and p outputs, B is n×m, C is p×n and D is p×m.

The first line is the state equation and the second the output equation. A set of n first-order equations, each solved for one derivative, is called the normal form of the system equations. The state choice is not unique: any invertible change of variables gives another valid state model of the same system.

From an LCCDE to normal form

For y⁽ⁿ⁾+aₙ₋₁y⁽ⁿ⁻¹⁾+…+a₁y′+a₀y=b₀u (no derivatives of u on the right), use the output and its derivatives as states, the phase variables:

  1. Solve for the highest derivative: y⁽ⁿ⁾=−a₀y−a₁y′−…−aₙ₋₁y⁽ⁿ⁻¹⁾+b₀u.
  2. Set x₁=y, x₂=y′, …, xₙ=y⁽ⁿ⁻¹⁾.
  3. Each state's derivative is the next state: x₁′=x₂, …, xₙ₋₁′=xₙ.
  4. The last one comes from step 1: xₙ′=−a₀x₁−a₁x₂−…−aₙ₋₁xₙ+b₀u.
  5. The output is y=x₁, so C=[1 0 … 0] and D=0.

The A matrix has 1s just above the diagonal and the negated coefficients −a₀, −a₁, … in its last row; it is called the companion (or phase-variable) form. If the right side also contains u′, the plain choice x₂=y′ fails, because x₂′ would contain u′. For y″+a₁y′+a₀y=b₁u′+b₀u, choose x₁=y and x₂=y′−b₁u. Then x₁′=x₂+b₁u and x₂′=−a₀x₁−a₁x₂+(b₀−a₁b₁)u, so A is unchanged, B=[b₁, b₀−a₁b₁]T, C=[1 0] and D=0.

Figure 2.7.1 draws the state model of the worked example as a block diagram: two integrators in a chain, with feedback gains −3 and −2 into a summing junction. Each integrator's output is one state variable.

  • If the right side has u′, x₂=y′ is not a valid state for x′=Ax+Bu; use x₂=y′−b₁u.

Takeaways

  1. An LTI system obeys superposition and time invariance; test each with two paths, and one mismatch is enough to fail.
  2. Because every input is an integral of shifted impulses, the impulse response h(t) fixes the output for every input.
  3. The step response is the running integral of h(t), and h(t) is its slope; a jump in s(t) is an impulse in h(t).
  4. Convolution y=x*h is evaluated by flip, slide, multiply and integrate over the overlap, with a separate case between each pair of breakpoints.
  5. Convolution is commutative, associative and distributive with δ(t) as identity: cascades multiply into h₁*h₂, parallel branches add into h₁+h₂.
  6. Causality is a condition on where h(t) lives (zero for t<0); BIBO stability is a condition on its absolute area. Neither implies the other.
  7. A linear constant-coefficient differential equation is an LTI system from rest; its solution splits into natural plus forced, or zero-input plus zero-state.
  8. An nth-order differential equation becomes n first-order state equations x′=Ax+Bu, y=Cx+Du, which computers integrate directly.

Understand Define a continuous-time LTI system. Explain the superposition and time-invariance properties, and show why an LTI system is fully characterised by its impulse response. 10 marks

Points to cover. Definition of linearity: additivity and homogeneity; Definition of time invariance with a shifted input; Input written as an integral of shifted impulses; Impulse response as the response to δ(t); Output as the convolution of the input with h(t).

Model answer.

  1. System. A continuous-time system maps an input x(t) to an output y(t)=T{x(t)}, with t in seconds. It is LTI when it is both linear and time-invariant.
  2. Linearity (superposition). For all inputs x₁, x₂ and all constants a, b:
    T{a x₁(t) + b x₂(t)} = a T{x₁(t)} + b T{x₂(t)} = a y₁(t) + b y₂(t)
  3. Superposition combines two properties: additivity (a=b=1: the response to a sum is the sum of responses) and homogeneity (b=0: scaling the input scales the output). Putting a=b=0 gives T{0}=0, so a linear system gives zero output for zero input. This is necessary but not sufficient.
  4. Time invariance. A delay of the input by any t₀ delays the output by the same t₀; the rule does not depend on clock time:
    if x(t) → y(t), then x(t − t₀) → y(t − t₀) for every t₀
  5. Testing the two properties on y(t)=3x(t)+2. Linearity with x₁=1, x₂=2, a=2, b=3: combining first gives T{8}=26; applying T separately gives 2(5)+3(8)=34. 26≠34, so the system is not linear. Time invariance with x(t)=t, t₀=2 s: both paths give 3t−4, which is 11 at t=5 s, so the system is time-invariant. It is not LTI.
    TestPath 1Path 2Result
    LinearityT{2·1+3·2}=T{8}=262·T{1}+3·T{2}=10+24=34not linear
    Time invariance (t=5 s)T{t−2}=3t−4 → 11y(t−2)=3t−4 → 11time-invariant
  6. Impulse response. h(t) is the output when the input is the unit impulse δ(t) and the system starts at rest.
  7. Input as impulses. By the sifting property, any input is an integral of shifted, weighted impulses, with τ a dummy variable along the input's time axis:
    x(t) = ∫ x(τ) δ(t − τ) dτ,   τ from −∞ to ∞
  8. Apply the two properties. Time invariance: δ(t−τ) gives h(t−τ). Homogeneity: the weighted impulse x(τ)dτ·δ(t−τ) gives x(τ)dτ·h(t−τ). Additivity: the response to the whole integral is the integral of the responses.
  9. Result.
    y(t) = ∫ x(τ) h(t − τ) dτ = x(t) * h(t),   τ from −∞ to ∞
  10. Conclusion. Once h(t) is known, the convolution integral gives the output for every input, so h(t) characterises the system completely. Causality and stability can also be read from h(t). This needs both properties: for a non-LTI system the response to δ(t−τ) is not a shifted copy of one signal, and responses cannot be added.
  11. Why both properties are needed. Take the linear but time-varying system y(t)=t·x(t). Its response to δ(t−τ) is t·δ(t−τ)=τ·δ(t−τ), which is not a shifted copy of its response to δ(t) (that response is 0·δ(t)=0). So no single h(t) describes it, and the convolution integral does not apply. Linearity alone lets responses be added; time invariance makes every response a shifted copy of the same h.
  12. What else h(t) gives. Because h(t) fixes the system, every other property can be read from it: memoryless if h=Kδ(t); causal if h=0 for t<0; BIBO stable if ∫|h|dt is finite; the frequency response H(jω) and transfer function H(s) are its Fourier and Laplace transforms, treated in Fourier analysis and Laplace transform analysis.
  13. Closing check with numbers. An RC filter with R=1 kΩ, C=1 μF has h(t)=1000e−1000tu(t) s−1. For x(t)=u(t), y(t)=∫0t1000e−1000(t−τ)dτ=1−e−1000t for t≥0, so y(1 ms)=1−e−1=0.632 V for a 1 V step: exactly the capacitor voltage that the circuit's own equation gives.
Remember Define the impulse response h(t) and the step response s(t) of a continuous-time LTI system. Derive the relations s(t)=∫−∞th(λ)dλ and h(t)=ds(t)/dt. 10 marks

Points to cover. Definitions with the system initially at rest; Step response as the convolution of u(t) with h(t); Limits from u(t−λ); Differentiate the step response; Jumps in s(t) give impulses in h(t).

Model answer.

  1. Impulse response. h(t) is the output of the LTI system when the input is δ(t), with no energy stored at the start.
  2. Step response. s(t) is the output when the input is the unit step u(t), again from rest. Some books call it the indicial response.
  3. Step response by convolution. The output for any input is the convolution of the input with h. For x=u, using the commutative form and λ as the dummy variable:
    s(t) = ∫ h(λ) u(t − λ) dλ,   λ from −∞ to ∞
  4. Limits. u(t−λ)=1 when t−λ≥0, that is when λ≤t, and 0 when λ>t. So the integrand is h(λ) up to λ=t and zero beyond:
    s(t) = ∫ h(λ) dλ,   λ from −∞ to t
  5. For a causal system h(λ)=0 for λ<0, so the lower limit becomes 0: s(t)=∫0th(λ)dλ for t≥0 and s(t)=0 for t<0.
  6. Derivative relation. By the fundamental theorem of calculus, differentiating an integral with respect to its upper limit gives the integrand at that limit: h(t)=ds(t)/dt. The same result follows from u′(t)=δ(t): differentiating the input differentiates the output of an LTI system.
  7. Jumps. If s(t) jumps by J at an instant, ds/dt contains J·δ at that instant. A step response that rises smoothly from zero gives an h with no impulse.
  8. Example 1 (smooth rise). RC filter, τ=1 ms: h(t)=1000e−1000tu(t) s−1.

So integrating the input first or the output afterwards gives the same result: the response to the integral of δ, which is s, equals the integral of the response to δ, which is ∫h.
  11. Why engineers use the relation. A step is easy to apply in a laboratory (close a switch), while a true impulse is not. So s(t) is measured and h(t) is obtained as its slope. The final value s(∞) is the DC gain of the system.

Understand State the commutative, associative, distributive and identity properties of continuous-time convolution. Give one system-level meaning of each property. 10 marks

Points to cover. Commutativity x*h=h*x; Associativity: cascade; Distributivity: parallel connection; Identity x*δ=x and the shift x*δ(t−t₀); A numerical check.

Model answer.

  1. Notation. x*h means ∫x(τ)h(t−τ)dτ over all τ, where τ is the dummy variable and t the output time.
  2. Commutative. x*h=h*x. Proof: put λ=t−τ, so dτ=−dλ and the limits swap; the integral becomes ∫h(λ)x(t−λ)dλ.
    ∫ x(τ) h(t−τ) dτ  =  ∫ h(λ) x(t−λ) dλ
  3. System meaning: the roles of input and impulse response can be exchanged. A system with impulse response h driven by x gives the same output as a system with impulse response x driven by h. In practice you flip whichever signal is simpler.
  4. Associative. (x*h₁)*h₂=x*(h₁*h₂). Proof: write the double integral and swap the order of integration. System meaning: two LTI systems in cascade equal one system with impulse response h₁*h₂; together with commutativity, the order of the two blocks does not matter.
  5. Distributive. x*(h₁+h₂)=x*h₁+x*h₂. Proof: the integral of a sum is the sum of integrals. System meaning: two LTI systems fed by the same input, with their outputs added, equal one system with impulse response h₁+h₂.
  6. Identity. x*δ=x, because ∫x(τ)δ(t−τ)dτ picks out x(t) (sifting). More generally x(t)*δ(t−t₀)=x(t−t₀). System meaning: h(t)=δ(t) is a plain wire, and h(t)=δ(t−t₀) is an ideal delay of t₀ seconds.
  7. Worked check of associativity (cascade). Let h₁(t)=e−tu(t) and h₂(t)=e−2tu(t). For t≥0:
    h₁*h₂ = ∫₀ᵗ e−τ e−2(t−τ) dτ = e−2t ∫₀ᵗ eτ dτ = e−2t(et − 1)
      = (e−t − e−2t) u(t)
  8. So the cascade acts as one system with h(t)=(e−t−e−2t)u(t). Swapping the blocks gives h₂*h₁, which by commutativity is the same signal.
  9. Associativity in detail. Writing out both sides as double integrals:

put τ = σ + λ:  = ∫ x(σ) [ ∫ h₁(λ) h₂(t−σ−λ) dλ ] dσ = [x*(h₁*h₂)](t)

Understand Define causality and BIBO stability for a continuous-time LTI system. State the necessary and sufficient conditions on h(t) for each, and justify them. 10 marks

Points to cover. Causal: output depends only on present and past input; Condition h(t)=0 for t<0; BIBO: every bounded input gives a bounded output; Condition ∫|h(t)|dt<∞; Sufficiency and necessity arguments; Examples with areas.

Model answer.

  1. Causality. A system is causal if the output at any time t depends only on the input at times up to t, never on future input.
  2. Condition. Write the output in the commutative form:
    y(t) = ∫ h(τ) x(t − τ) dτ,   τ from −∞ to ∞
  3. The weight h(τ) multiplies the input at time t−τ. For τ<0, t−τ>t lies in the future. The output is free of future input for every x only if all these weights vanish. So an LTI system is causal if and only if h(t)=0 for t<0. h(0) may be nonzero.
  4. BIBO stability. A system is bounded-input bounded-output stable if every input with |x(t)|≤Mx<∞ for all t gives an output with |y(t)|≤My<∞ for all t.
  5. Condition. An LTI system is BIBO stable if and only if h(t) is absolutely integrable:
    ∫ |h(t)| dt < ∞,   t from −∞ to ∞
  6. Sufficiency. If the area S=∫|h|dt is finite and |x|≤Mx:
    |y(t)| ≤ ∫ |h(τ)| |x(t−τ)| dτ ≤ Mx ∫ |h(τ)| dτ = Mx · S
  7. So every output is bounded by Mx·S.
  8. Necessity. Suppose S is infinite. Choose the bounded input x(t)=sgn[h(−t)], equal to +1, −1 or 0. Then y(0)=∫h(τ)x(−τ)dτ=∫h(τ)sgn[h(τ)]dτ=∫|h(τ)|dτ=∞. A bounded input has produced an unbounded output, so the system is not stable.
  9. Examples.
    h(t)zero for t<0?∫|h| dtVerdict
    e−2tu(t)yes1/2causal, stable
    u(t)yes∞causal, unstable
    e2tu(−t)no1/2noncausal, stable
    δ(t−1)yes1causal, stable (pure delay)
  10. Independence. The table shows that neither property implies the other: one is about where h lives, the other about how much absolute area it has.
  11. Examples of the causality test. e−2tu(t) and δ(t−1) are zero before t=0, so causal. u(t+1) switches on at t=−1 s, so noncausal. A smoothing filter that averages x over t−1 to t+1 has h=0.5 on −1≤t≤1, so it uses future input and is noncausal; it is still usable offline on stored data.
  12. Examples of the stability test. e−2|t| has area 2×(1/2)=1, so it is stable although noncausal. The ideal low-pass impulse response sin(t)/(πt) has net area 1 but infinite absolute area, so it is not BIBO stable: the absolute value in the test matters.
  13. How to answer in an exam. State each definition, state each condition on h(t), give the one-line sufficiency bound and the sgn[h(−t)] input for necessity, then test one causal-stable and one causal-unstable example to show the properties are independent.
  14. Mistakes that cost marks. Stating the stability test without the absolute value; claiming causal implies stable (u(t) is a counterexample); using h(0)=0 as part of the causality condition (δ(t) itself is causal); and testing stability with one bounded input, which proves nothing: the condition is on h(t).
  15. Closing check with numbers. For h(t)=e−2tu(t) and an input bounded by 5 V, the output is bounded by 5×0.5=2.5 V. The constant input x=5 V (for all t) gives y=5∫0∞e−2τdτ=2.5 V, which reaches the bound, so the bound is tight.

Evaluate A student claims: "Every causal LTI system is BIBO stable." Evaluate the claim. Either prove it or give a counterexample using h(t), and state the correct relation between causality and stability. 10 marks

Points to cover. Causality constrains where h(t) lives; Counterexample h(t)=u(t): causal but ∫|h|=∞; Bounded input with unbounded output; BIBO condition is absolute integrability; Conclusion: the properties are independent.

Model answer.

  1. What each property says. Causality: h(t)=0 for t<0. BIBO stability: ∫|h(t)|dt<∞. The first is about the time support of h, the second about its absolute area. Nothing in the first limits the second.
  2. Counterexample. Take h(t)=u(t), the ideal integrator y(t)=∫−∞tx(τ)dτ. It is zero for t<0, so it is causal.
  3. Absolute area. ∫|u(t)|dt=∫0∞1 dt grows without limit, so the stability condition fails.
  4. A bounded input with an unbounded output. Apply x(t)=u(t), bounded by 1:
    y(t) = ∫₀ᵗ 1 dτ = t,   t ≥ 0
  5. The output is the ramp t·u(t): 10 at t=10 s, 1000 at t=1000 s. No finite bound exists, so the system is not BIBO stable. The claim is false.
  6. A second counterexample. h(t)=etu(t) is causal; its area ∫0∞etdt is infinite, and the step input gives y=(et−1)u(t), which is 1.72 at 1 s and 22,025 at 10 s.
  7. The converse is false too. h(t)=e2tu(−t) is noncausal but has area 1/2, so it is stable.
    h(t)Causal?∫|h| dtStable?
    e−tu(t)yes1yes
    u(t)yes∞no
    etu(t)yes∞no
    e2tu(−t)no1/2yes
  8. Correct relation. Causality and BIBO stability are independent properties of an LTI system. Causality ⇔ h(t)=0 for t<0. BIBO stability ⇔ ∫|h(t)|dt<∞. Both must be tested on h(t) separately, and all four combinations occur.
  9. Where the student's idea comes from. Many familiar causal systems (RC filters, damped springs) are also stable, so it is tempting to link the two. But stability in those systems comes from energy loss (resistance, damping), not from causality.
  10. Physical counterexample. A capacitor charged by a current source: v(t)=(1/C)∫i dt. It is causal, and a constant current of 1 mA into 1 μF raises the voltage by 1 V every millisecond without limit, until the capacitor breaks down. Its impulse response (1/C)u(t) is not absolutely integrable.
  11. The correct statement for exponential systems. For a causal h(t) made of terms c·eλtu(t), each term has finite area only if its λ is negative (or has a negative real part). So a causal system of this kind is stable exactly when every λ has a negative real part; Laplace transform analysis restates this as all poles in the left half of the s-plane. Causality alone says nothing about the signs of the λs.
  12. Verdict. The claim is false; the correct relation is independence, with both conditions checked on h(t).
  13. Closing check. For the stable causal case e−tu(t) the same step input gives y=1−e−t, bounded by 1 = area of h, so the bound Mx·∫|h| holds there and fails only where the area is infinite.

Glossary

Absolutely integrable
A signal with finite area under its absolute value, ∫|h(t)|dt<∞.
Additivity
The output for x₁+x₂ equals the output for x₁ plus the output for x₂.
BIBO stability
Every bounded input produces a bounded output; for an LTI system, ∫|h(t)|dt<∞.
Breakpoint
A value of t at which an edge of h(t−τ) crosses an edge of x(τ), so the limits of the convolution integral change.
Cascade
Systems connected in series; for LTI systems the overall impulse response is h₁*h₂.
Causal system
A system whose output never depends on future input; for an LTI system, h(t)=0 for t<0.
Characteristic equation
The polynomial equation in λ obtained by trying y=eλt in the equation with zero input; its roots give the natural modes.
Companion form
The phase-variable state model whose A matrix has 1s above the diagonal and the negated equation coefficients in its last row.
Convolution
The operation y(t)=∫x(τ)h(t−τ)dτ that gives the output of an LTI system.
Dummy variable
The integration variable τ in the convolution integral; it disappears once the integral is evaluated.
Forced response
A particular solution with the shape of the input, such as a constant for a step input.
Homogeneity
The output for a·x(t) equals a times the output for x(t), for any constant a.
Impulse response h(t)
The output of an LTI system for input δ(t), starting at rest.
Inverse system
A system whose impulse response satisfies h*hinv=δ, so it undoes the first system; using it is called deconvolution.
LCCDE
Linear constant-coefficient differential equation: a weighted sum of y and its derivatives equals a weighted sum of x and its derivatives, with constant weights.
Linearity
The property that a system obeys superposition: scaling and adding inputs scales and adds outputs.
LTI system
A system that is both linear and time-invariant.
Memoryless system
A system whose output depends only on the present input; for an LTI system, h(t)=Kδ(t).
Natural response
The part of the solution that solves the equation with zero input, built from the characteristic modes.
Normal form
A system written as n first-order equations, each solved for the derivative of one state variable.
State equation
The first-order matrix equation x′=Ax+Bu that updates the state vector.
State variable
One of a set of signals whose values at one instant, with the future input, fix the system's future behaviour.
Step response s(t)
The output of an LTI system for input u(t), starting at rest; also called the indicial response.
Time constant
τ=RC for an RC circuit or L/R for an RL circuit; the first-order step response reaches 63.2% of its final value at t=τ.
Time invariance
A delay of the input by t₀ produces the same output delayed by t₀; also called shift invariance.
Unit impulse δ(t)
A generalised signal that is zero for t≠0, has unit area and picks out a value under an integral: ∫x(τ)δ(t−τ)dτ=x(t).
Unit step u(t)
A signal equal to 1 for t≥0 and 0 for t<0; its derivative is δ(t).
Zero-input response
The output due to stored energy (initial conditions) alone, with the input set to zero.
Zero-state response
The output due to the input alone, with the system starting at rest; it equals x*h.
