2.1 Mesh analysis and supermesh

Mesh analysis replaces KVL around every loop with a small set of linear equations. A mesh is a loop with no loop inside it. Assign one current to each mesh, all clockwise. Branch currents are sums and differences of mesh currents. The method needs a planar circuit, one you can draw on a flat sheet without crossing branches. It is used for DC circuits, transistor bias networks, and as a matrix method for planar networks. When two meshes share an ideal current source, one supermesh equation plus one current constraint replaces KVL through the source.

You need: KVL, KCL, Ohm's law and source models from Unit 1, Foundations; the dual method is in nodal analysis and supernode.

Mesh currents and KVL

Planar circuit: draw it on paper with no branch crossing another. A mesh is a loop that contains no other loop. In the figure, the left mesh is 1-2-3-4 and the right mesh is 2-5-6-3. The shared branch 2-3 carries two mesh currents in opposite directions.

Give every mesh its own current, usually clockwise: i₁ for the left mesh, i₂ for the right. A mesh current is not a physical branch current; it is a bookkeeping variable. The actual current in a branch is the mesh current if only one mesh uses that branch, and the difference if two meshes share it. For branch 2-3, i₁ points down and i₂ points up, so the downward current is i₁ − i₂.

Write KVL around each mesh: the sum of resistor voltage drops equals the sum of source rises, with a rise counted positive when you go from − to +. For a two-mesh circuit with no shared current source, the equations are R₁₁i₁ + R₁₂i₂ = v₁ and R₂₁i₁ + R₂₂i₂ = v₂. R₁₁ is the total resistance in mesh 1; R₂₂ is the total in mesh 2; R₁₂ = R₂₁ = −(resistance shared by meshes 1 and 2); v₁ and v₂ are the net voltage rises in each mesh. The mutual entry is negative because the shared resistor carries the two mesh currents in opposite reference senses.

Matrix setup and dependent sources

Build the resistance matrix by inspection. The diagonal entry R_kk is the sum of all resistors in mesh k. The off-diagonal R_kj is minus the sum of resistors shared by meshes k and j. The right side is the algebraic sum of voltage rises in mesh k, positive if the source pushes current in the assumed clockwise direction.

  1. Check that the circuit is planar; label its meshes.
  2. Assign clockwise currents i₁ to i_m.
  3. For each mesh, sum its resistances; subtract shared resistances from mutual terms.
  4. Put voltage rises on the right side with the clockwise sign rule.
  5. Solve the linear system by elimination or Cramer's rule.

Dependent sources add a constraint. Replace the dependent source value by its controlling variable, then express that variable in mesh currents. Example: a current-controlled voltage source 3i_x has i_x = i₁ − i₂, so its KVL term is 3(i₁ − i₂). Do not create a new unknown for the dependent source; it is not independent. If a current source lies on an outer branch, it fixes one mesh current to ±I_s; remove that mesh KVL equation and solve the rest.

Supermesh

When an ideal current source lies on a branch shared by meshes 1 and 2, KVL around a mesh containing the source would introduce the source's unknown voltage, so it cannot be used alone. Use a supermesh instead. Remove the shared branch from the loop, write one KVL around the outer boundary of the two meshes, and add one current constraint from the source.

For the figure, remove branch 2-3. The outer loop is 1-2-5-6-3-4-1. KVL gives 2i₁ + 4i₂ = 12. The 5 A source points down from 2 to 3. The downward current in the shared branch is i₁ − i₂, so i₁ − i₂ = 5. Solve the two equations: i₁ = 16/3 A and i₂ = 1/3 A.

Sign rule: if the source arrow agrees with mesh 1's direction through the shared branch, write i₁ − i₂ = I_s; if it opposes, write i₂ − i₁ = I_s. A supermesh gives one KVL equation plus one constraint, not two KVL equations. A current source lies on a branch shared by at most two meshes. If it is shared, use one supermesh KVL and one current constraint. If there are several current sources, add one constraint for each.

Some syllabi call this loop analysis. The method is for planar circuits only; non-planar circuits need nodal analysis or graph methods.

2.2 Nodal analysis and supernode

Node analysis replaces a circuit by unknown node voltages measured from one reference node. KCL at every non-reference node gives one linear equation per unknown, so a circuit with many branches becomes a small matrix problem. A voltage source between two non-reference nodes hides its branch current; the two nodes then form a supernode with one KCL equation plus one voltage constraint. The method is used in DC bias checks, SPICE input decks, and hand checks of power-supply rails before simulation.

You need: KCL, node, branch, resistor, and independent and dependent source ideas from Unit 1; superposition and Thevenin come later in 2.3 and 2.4.

Node voltages and KCL

Pick one node as the reference and call its voltage 0 V. The node voltage vₖ is the potential of node k relative to this reference. It is a signed quantity in volts. Every non-reference node gets one unknown voltage.

At each non-reference node write KCL: currents leaving through resistors plus currents leaving through sources equal zero. For a resistor between k and j, Ohm's law gives the current leaving k as (vₖ − vⱼ)/R.

Σⱼ (vₖ − vⱼ)/Rₖⱼ = iₖ

vₖ is the voltage at node k in volts; vⱼ is the voltage at a neighbour j in volts; Rₖⱼ is the resistance between them in ohms; iₖ is the current injected into node k by current sources in amperes, positive entering.

Write G = 1/R in siemens, the conductance. Collecting terms at node k gives (Σⱼ Gₖⱼ)vₖ − Σⱼ Gₖⱼvⱼ = iₖ. For n non-reference nodes this is the matrix equation Gv = i. With resistors only, G is symmetric: diagonal entries are sums of conductances, and off-diagonal entries are negative conductances. Some syllabi call this the node-voltage method.

The supernode

An ideal voltage source fixes a voltage but its current is unknown. KCL at either end of the source would need that unknown branch current, so the two end nodes are combined.

Draw a boundary around the two nodes and the voltage source. This is a supernode. Write one KCL equation for all resistor and current-source branches crossing the boundary. Leave the voltage-source branch out of that KCL. Add one voltage constraint for the source. The mesh dual is the supermesh in 2.1.

vₐ − v_b = V_s

vₐ is the voltage at the node connected to the positive terminal of the source; v_b is the voltage at the node connected to the negative terminal; V_s is the source voltage in volts, positive when the positive terminal is at a.

For a dependent source, express its value in terms of node voltages. If the control voltage is vₓ = vₐ − v_b, a voltage-controlled current source gₘvₓ contributes gₘ(vₐ − v_b) to the KCL, with the sign set by its current direction. The matrix can then lose symmetry. A voltage source from a non-reference node to the reference is not a supernode; it simply sets that node voltage.

Matrix form with three unknowns

For three non-reference nodes with only current sources and resistors, the system is Gv = i.

G = [G₁₁  −G₁₂  −G₁₃ ; −G₁₂  G₂₂  −G₂₃ ; −G₁₃  −G₂₃  G₃₃],  v = [v₁ v₂ v₃]ᵀ,  i = [i₁ i₂ i₃]ᵀ

G₁₁ is the sum of conductances touching node 1; G₁₂ = G₂₁ is the conductance joining nodes 1 and 2; i₁ is current injected into node 1 by current sources, positive entering; v₁, v₂, v₃ are node voltages in volts.

A voltage source between non-reference nodes replaces the two node KCL rows by one supernode KCL equation and one voltage-constraint equation, so the total number of equations stays equal to the number of unknown node voltages. Solve by substitution or elimination. For AC, replace conductance by complex admittance; phasor nodal equations are in 2.7.

Question. In the circuit of the figure, node 0 is the reference. The 5 V source has its positive terminal at node 1. The 6 A source injects current into node 2. Find v₁ and v₂.

Exam traps

  • Leaving the voltage-source branch in the supernode KCL adds an unknown current; omit that branch and use it only in the constraint.
  • Reversing the constraint: v₁ − v₂ = 5 V because the positive terminal is at node 1. Writing v₂ − v₁ = 5 V gives the wrong result; for this circuit it gives v₁ = 5.2 V and v₂ = 10.2 V instead of v₁ = 9.2 V and v₂ = 4.2 V.
  • Using resistance instead of conductance in the matrix: diagonal entries are sums of 1/R, and off-diagonals are −1/R.
  • For a dependent source, forgetting to replace the control voltage by node voltages leaves an extra unknown.
  • A voltage source from a non-reference node to the reference is not a supernode; it sets that node voltage directly.

2.3 Linearity and superposition theorem

Real circuits often have several sources. Superposition solves the circuit once per independent source and adds the answers, because a linear circuit's equations are linear. This chapter states linearity, shows how to switch a source off (voltage source → short, current source → open), keeps dependent sources alive, and shows that power does not obey superposition.

You need: independent and dependent sources, series and parallel resistors, and voltage and current division from Unit 1, plus the solving routine from 2.1 and 2.2.

Linearity means scaling and adding

Pick one source as input and any voltage or current as output. Feed 1 A and measure 4 V; feed 3 A and a linear circuit gives 12 V. That is homogeneity: input × k gives output × k for every k, positive or negative.

If the output for two inputs together equals the sum of the outputs each gives alone, the circuit is additive.

A circuit is linear when both hold. Resistors, ideal capacitors and inductors are linear: v = Ri, v = L di/dt and i = C dv/dt are straight lines through the origin. Dependent sources are linear if their gain (μ, g, r or β) is constant. Independent sources are the inputs, not tested for linearity.

y = a₁x₁ + a₂x₂ + … + a_N x_N

y is any circuit response (a voltage in V or a current in A); x_k is the value of independent source k; a_k is a constant fixed by the resistors and dependent-source gains, with units that turn x_k into y; N is the number of independent sources.

Why it works: nodal analysis writes KCL at each node with constant coefficients; mesh analysis does the same with KVL. The solution is a linear combination of the right-hand sides, the source values.

Switching sources off, then adding

Superposition turns one circuit with N independent sources into N circuits with one source each. Switching a source off means setting it to zero, so it acts like nothing at all.

  1. List the N independent sources.
  2. Keep source 1 and set every other independent source to zero. A 0 V voltage source has no voltage across it: replace it by a short circuit (wire). A 0 A current source carries no current: replace it by an open circuit (gap).
  3. Do not touch dependent sources. Their value is set elsewhere, so zeroing one changes the circuit.
  4. Solve the reduced circuit for the required voltage or current by nodal or mesh analysis. Keep signs: a node voltage above ground is positive; a current opposite its arrow is negative.
  5. Repeat for every independent source, one at a time.
  6. Add algebraically: y = y₁ + y₂ + … + y_N.
  • Sources may be switched off in groups; partial answers still add.
  • Every reduced circuit keeps the same resistors and dependent sources; only independent sources differ.

y = y₁ + y₂ + … + y_N

y is the total response with all sources on; y_k is the response with independent source k on and every other independent source off (voltage sources shorted, current sources opened); N is the number of independent sources.

Power does not obey superposition

Voltages and currents add; power does not. P = I²R or V²/R is quadratic, and (I₁ + I₂)²R ≠ I₁²R + I₂²R.

In the example, the 6 Ω resistor carries 1.5 A with the 12 V source alone, dissipating 13.5 W. With the 6 A source alone it carries 1.5 A, another 13.5 W. With both on, V = 18 V, I = 3 A, P = 54 W. Partial powers add to 27 W, not 54 W. Superpose voltage or current first, then compute power once.

Dependent sources are the second trap. A 2V_c source must stay in every reduced circuit and be re-evaluated; switching it off deletes a real term.

Superposition is used in op-amp summing amplifiers, audio mixers, bridge circuits with excitation plus offset, and supplies with reference and feedback. It justifies treating a small AC signal on a DC bias as two runs. For one-frequency sinusoids it works on phasors (see 2.7).

Question. A 12 V independent source is in series with a 2 Ω resistor and feeds node A. 2.4 Thevenin's and Norton's theorems

Any linear network with two output terminals, however many resistors and sources sit inside it, behaves at those terminals like one voltage source in series with one resistor. Thevenin's theorem names that source V_th and that resistor R_th; Norton's theorem describes the same network as one current source I_N in parallel with R_N. The two forms are one circuit seen from outside. Engineers use them to replace a messy supply or bias network by two numbers, so load current and load voltage follow from a single loop.

You need: 2.1 and 2.2 to solve for the open-circuit voltage and the short-circuit current, plus source transformation from Unit 1.

Thevenin's theorem: open-circuit voltage and dead network

Thevenin's theorem: any linear two-terminal network can be replaced, at its terminals a and b, by one voltage source V_th in series with one resistance R_th. V_th is the open-circuit voltage, the voltage across a-b with the load removed. R_th is the resistance seen looking into a-b with every independent source set to zero.

Those two numbers do all the work. Whatever load you attach, the current it draws depends on the network only through V_th and R_th. A 12 V battery with 0.5 Ω internal resistance, a sensor bridge, the bias network inside an amplifier: each collapses to this pair.

  1. Remove the load between a and b and mark the polarity of V_th, for example a positive with respect to b.
  2. Solve the network for the voltage across a-b with the load off. That value is V_th; use nodal or mesh analysis.
  3. Set every independent source to zero: short each ideal voltage source, open each ideal current source. Leave dependent sources as they are.
  4. Look into a-b, combine series and parallel resistances, and that is R_th.
  5. Check by shorting a to b, finding I_sc, and testing R_th = V_th / I_sc.

Setting a source to zero does not delete it. A 0 V voltage source is a perfect wire and a 0 A current source is a gap; the element keeps its place, only its value becomes zero. In circuits with dependent sources R_th can even come out negative. That is a real result, not an arithmetic error.

Norton's form and the swap between the two

Norton's theorem replaces the same network by a current source I_N in parallel with a resistance R_N. I_N is the short-circuit current, the current that flows from a to b through a wire joining the terminals. R_N is found exactly like R_th, with all independent sources dead, and the two resistances are equal: R_N = R_th.

The two forms are linked by source transformation: V_th = I_N R_th and I_N = V_th / R_th. Nodal analysis hands you V_th naturally; mesh analysis hands you I_sc naturally. Choose whichever keeps the arithmetic short.

Dependent sources: the test-source method

A dependent source has no value of its own; it copies a voltage or current elsewhere in the circuit. It therefore cannot be set to zero when you look for R_th. Only the independent sources die, series-parallel usually cannot finish the job, and you use a test source.

  1. Dead every independent source and leave every dependent source in place.
  2. Connect a test voltage source V_t across a-b, positive terminal at a. V_t = 1 V keeps the numbers short; any value works.
  3. Solve the circuit with the dependent source inside the equations and find I_t, the current entering terminal a.
  4. Compute R_th = V_t / I_t. If you injected a test current instead, use the voltage that appears at a-b as V_t.
  5. V_th is still the open-circuit voltage, measured before anything is deaded.

A small setup. Terminals a-b. Inside sits a 3 Ω resistor from a to an internal node c, and a dependent voltage source of value 2V_x whose positive terminal is at c and negative terminal at b, so V_c − V_b = 2V_x (with b as reference, V_c = 2V_x). Here V_x is the voltage across the 3 Ω resistor, so V_x = V_a − V_c. Apply V_t at a with b as reference. The dependent source forces V_c = 2(V_t − V_c), giving V_c = (2/3)V_t and V_x = V_t/3. The test current is I_t = V_x / 3 = V_t / 9, so R_th = V_t / I_t = 9 Ω. No independent source exists, so V_th = 0 and the equivalent is a bare 9 Ω resistor.

Worked example

Question. A 12 V independent voltage source is in series with a 4 Ω resistor, and this combination feeds a 6 Ω load connected across the output terminals a-b. Find the Thevenin voltage V_th, the Thevenin resistance R_th, the short-circuit current I_sc and the Norton current I_N of the network seen by the load.

  1. The load is the 6 Ω resistor. Remove it and what remains between a and b is the network: the 12 V source in series with the 4 Ω resistor, with a-b open at the far end of the 4 Ω.
  2. With the load off, no current flows, so there is no drop across the 4 Ω resistor. The open-circuit voltage equals the source voltage: V_th = 12 V, with terminal a positive with respect to b.
  3. Dead the 12 V source: replace it by a short circuit. Looking into a-b, only the 4 Ω resistor remains: R_th = 4 Ω.
  4. For the short-circuit current, join a to b with a wire. The whole 12 V appears across the 4 Ω resistor: I_sc = 12/4 = 3 A.
  5. Check consistency: V_th / R_th = 12/4 = 3 A, which equals I_sc, so the two measurements agree.
  6. The Norton form uses the same resistance and the short-circuit current: I_N = I_sc = 3 A and R_N = R_th = 4 Ω.

Answer. V_th = 12 V, R_th = 4 Ω, I_sc = 3 A, I_N = 3 A and R_N = 4 Ω.

Exam traps

  • Deading a source the wrong way. A voltage source becomes a short wire; a current source becomes an open gap. Reversing them spoils every later parallel-series step.
  • Removing a resistor that is part of the network and calling it the load. The load is only the element you deliberately detach; everything else stays.
  • Forgetting the test source when a dependent source is present, or deading the dependent source too. Its value depends on the circuit, so it must stay in the equations.
  • Sign of I_N. Fix it as current leaving terminal a into the external short. A sign slip makes the voltage and current forms disagree in direction. Computing R_th = V_th/I_sc from a wrongly signed I_sc gives a false negative R_th; a real negative R_th comes only from dependent sources.
  • Applying the theorem to a diode or a saturated amplifier. Over a wide range that network is not linear; a Thevenin equivalent then holds only near one operating point.

2.5 Maximum power transfer theorem

A Thevenin source has a fixed open-circuit voltage Vth and a fixed series resistance Rth. Connect any load RL across its terminals. The power delivered to the load rises, reaches a peak, then falls as RL grows. The maximum power transfer theorem states that this peak occurs at RL = Rth, and its value is Pmax = Vth²/(4Rth). The result guides impedance matching: audio amplifiers driving speakers, radio antennas feeding receivers, and sensor circuits passing weak signals to an amplifier. This chapter derives the peak and explains why maximum power is not maximum efficiency.

You need 2.4 Thevenin's and Norton's theorems to replace the fixed source by Vth and Rth.

Power delivered to the load

Take the Thevenin equivalent of the fixed network: a voltage source Vth in series with Rth. Attach a load resistor RL. The same current I flows through both resistors, so I = Vth/(Rth + RL). The load power is PL = I² RL. Substitute I:

P<sub>L</sub> = V<sub>th</sub>² R<sub>L</sub>/(R<sub>th</sub> + R<sub>L</sub>)²

Vth is the fixed Thevenin voltage in volts; Rth is the fixed Thevenin resistance in ohms; RL is the load resistance in ohms; PL is the power delivered to the load in watts.

Two limits show the peak must lie between them. As RL → 0, PL → 0 because the load is a short circuit. As RL → ∞, PL → 0 because the current tends to zero. For finite positive RL the power is positive, so a maximum exists. The next section locates it. The figure uses Vth = 12 V and Rth = 4 Ω; the peak is 9 W at RL = 4 Ω. The power produced by the source is Ps = Vth²/(Rth + RL); it is not the same as PL. This difference matters for efficiency.

Derivative gives RL = Rth

Differentiate PL with respect to RL, holding Vth and Rth fixed. Write PL = Vth² RL (Rth + RL)⁻² and use the product rule.

dP<sub>L</sub>/dR<sub>L</sub> = V<sub>th</sub>² (R<sub>th</sub> − R<sub>L</sub>)/(R<sub>th</sub> + R<sub>L</sub>)³

dPL/dRL is the rate of change of load power with load resistance; all other symbols are as defined above.

Set the derivative to zero. The numerator must vanish: Rth − RL = 0, so RL = Rth. The derivative is positive when RL < Rth and negative when RL > Rth, so the point is a maximum. Substitute RL = Rth:

P<sub>max</sub> = V<sub>th</sub>² R<sub>th</sub>/(R<sub>th</sub> + R<sub>th</sub>)² = V<sub>th</sub>²/(4R<sub>th</sub>)

Pmax is the largest load power in watts; Vth is the Thevenin voltage in volts; Rth is the Thevenin resistance in ohms.

At the peak the current is Vth/(2Rth), and the load power is (Vth/(2Rth))² Rth = Vth²/(4Rth). The source resistance dissipates the same power as the load.

Maximum power is not maximum efficiency

Efficiency is the fraction of the source's generated power that reaches the load. The source produces Ps = Vth²/(Rth + RL). Therefore η = PL/Ps = RL/(Rth + RL). At RL = Rth, η = 0.5, that is 50%. Half the generated power is lost inside Rth. If RL is much larger than Rth, η approaches 100%, but PL becomes small because the current is small. The theorem answers one question: for a fixed Rth, which RL extracts the most power? It does not give the most efficient load or the largest load voltage. Use RL = Rth only when Rth is fixed and the source is a linear Thevenin equivalent. For AC circuits the condition becomes ZL = Zth*, the complex conjugate; see 2.7.

Worked example

Question. A DC network has a Thevenin equivalent with Vth = 12 V and Rth = 4 Ω. Find the load resistance that receives maximum power and the maximum power itself. Also state the efficiency at that point.

  1. The source is fixed: Vth = 12 V and Rth = 4 Ω.
  2. Maximum power occurs when RL = Rth, so RL = 4 Ω.
  3. At this load the total series resistance is Rth + RL = 4 + 4 = 8 Ω. The current is I = Vth/(Rth + RL) = 12/8 = 1.5 A.
  4. The load power is PL = I² RL = (1.5)² × 4 = 2.25 × 4 = 9 W. Using the formula directly: Pmax = Vth²/(4Rth) = 144/16 = 9 W.
  5. The source generates Ps = Vth I = 12 × 1.5 = 18 W. Efficiency is η = PL/Ps = 9/18 = 0.5 = 50%.

Answer. RL = 4 Ω gives maximum power, Pmax = 9 W, and the efficiency there is 50%.

Exam traps

  • Saying maximum power occurs at maximum efficiency. At RL = Rth the efficiency is only 50%.
  • Applying RL = Rth when Rth is not fixed or when the source is not a fixed Thevenin resistance.
  • Using PL = Vth²/RL instead of PL = Vth² RL/(Rth + RL)². The denominator must contain the total resistance.
  • In AC circuits, using RL = Rth instead of the conjugate match ZL = Zth*. The DC theorem alone is not enough.
  • Assuming the load receives all the source power at the maximum-power point. Half is lost in Rth.

2.6 Reciprocity, Millman's and Tellegen's theorems

Reciprocity swaps the source and the response in a linear bilateral network. Millman's theorem collapses parallel branches into one voltage source plus one resistor, so a node voltage appears in a single line. Tellegen's theorem says the signed sum of v_k i_k over every branch is zero when KCL and KVL hold. These three results are checks and shortcuts: reciprocity validates transfer measurements, Millman solves parallel-source nodes quickly, and Tellegen audits power balance in any circuit, linear or not.

You need nodal analysis for KCL at a node and the source transformation step used in Thevenin's theorem.

Reciprocity theorem

Reciprocity is a property of linear bilateral networks. Bilateral means every element behaves the same in both directions; resistors, inductors and capacitors qualify. Dependent sources normally break it.

Take a network with no dependent sources. Turn off every other independent source: short every voltage source and open every current source, leaving only the single source used for the test. Put an ideal voltage source V_s in branch 1 and measure current I_2 in branch 2. Now remove the source, put the same V_s in branch 2, and measure current I_1 in branch 1. Reciprocity says I_1 = I_2. The ratio I_2/V_s is the same as I_1/V_s. A current-source form also holds under the same condition: with branch 2 open, a current source in branch 1 produces voltage V_2 across branch 2; with branch 1 open and the same source placed in branch 2, it produces the same voltage V_1 across branch 1.

The theorem does not say all currents stay unchanged. Only the swapped source and response pair has the same value. Use it to avoid a second measurement or a second full solution. In lab work, if a reciprocal network gives different transfer readings after swapping source and meter, the network contains a dependent source, an active device, or a wiring error.

Millman's theorem

Millman's theorem handles parallel branches between two nodes A and B. Each branch is a voltage source V_k in series with R_k. Let B be reference. V_k is positive when its positive terminal faces A. Source transformation turns branch k into a current source V_k/R_k in parallel with R_k. All current sources add and all resistors combine.

V_AB = (Σ V_k/R_k) / (Σ 1/R_k)

V_AB is the node voltage from A to B in volts; V_k is the source voltage in branch k in volts, positive at A; R_k is the branch resistance in ohms; the sums run over all parallel branches.

Branch current from A to B is I_k = (V_AB − V_k)/R_k. Current into A is J_k = (V_k − V_AB)/R_k. Nodes A and B are the only nodes of the parallel group, so the branch currents into A are the only currents at that node; hence Σ J_k = 0. If a further element or source connects to A, its current must be included in the KCL sum at A.

  1. Mark B as reference, 0 V.
  2. Give each source a sign: plus if its positive terminal faces A, minus if it faces B.
  3. Compute numerator Σ V_k/R_k and denominator Σ 1/R_k with the same branch order.
  4. Divide to get V_AB. Substitute back for any branch current.

If a branch has no source, set V_k = 0; it still contributes 1/R_k to the denominator. The formula also works with conductances: V_AB = Σ V_k G_k / Σ G_k.

Tellegen's theorem

Tellegen's theorem applies to any network that satisfies KCL and KVL. It does not need linear elements. Number the branches k = 1 to b. Let v_k be the voltage across branch k and i_k the current through it. Use the passive sign convention: i_k enters the positive terminal of v_k. Then

Σ v_k i_k = 0

v_k is the voltage across branch k in volts; i_k is the current through branch k in amperes, entering the positive terminal; the sum runs over all b branches and has units of watts.

The sum is over all branches, and each term v_k i_k is the power absorbed by that branch in watts. A resistor has positive v_k i_k. A source that delivers power has negative v_k i_k. The theorem is conservation of power written branch by branch: total absorbed power is zero.

Use Tellegen as an audit. After solving a circuit, compute v_k i_k for every element and add. A nonzero sum means a sign error, a missing branch, or a KCL/KVL slip. Because the statement depends only on KCL and KVL, it is an instantaneous statement: it holds for nonlinear resistors, time-varying elements and dependent sources at every instant, using the v_k and i_k of that instant. Only a few universities ask for the full proof; the statement and the power check are the examinable core.

Worked example

Question. Three parallel branches join nodes A and B. Branch 1: 10 V source in series with 2 Ω. Branch 2: 4 V source in series with 1 Ω. Branch 3: 0 V source in series with 4 Ω. All source positives face A. Find V_AB and the three branch currents into A.

  1. Take B as reference, so V_B = 0 V. All source positives face A, so V_1 = 10 V, V_2 = 4 V, V_3 = 0 V.
  2. Numerator: Σ V_k/R_k = 10/2 + 4/1 + 0/4 = 5 + 4 + 0 = 9 A.
  3. Denominator: Σ 1/R_k = 1/2 + 1/1 + 1/4 = 0.5 + 1 + 0.25 = 1.75 S.
  4. V_AB = 9/1.75 = 5.142857 V ≈ 5.143 V.
  5. Current into A: J_k = (V_k − V_AB)/R_k. J_1 = (10 − 5.142857)/2 = 4.857143/2 = 2.428571 A ≈ 2.429 A.
  6. J_2 = (4 − 5.142857)/1 = −1.142857 A ≈ −1.143 A. J_3 = (0 − 5.142857)/4 = −1.285714 A ≈ −1.286 A.
  7. Check: J_1 + J_2 + J_3 = 2.428571 − 1.142857 − 1.285714 = 0.000000 A.

Answer. V_AB = 5.143 V; the currents into A are 2.429 A, −1.143 A and −1.286 A, so the negative signs mean those two currents leave A.

Exam traps

  • Using Millman's formula with V_k entered as a magnitude only. A source whose positive terminal faces B must enter the numerator as −V_k.
  • Applying reciprocity with a dependent source present, or with a nonlinear element. The theorem needs a linear bilateral network.
  • Thinking reciprocity keeps every current unchanged. Only the swapped source-and-response pair has the same value.
  • In Tellegen's sum, dropping the passive sign convention. If current leaves the positive terminal, v_k i_k is negative.
  • Confusing Millman's theorem with Thevenin's theorem. Millman gives one node voltage directly; Thevenin replaces a two-terminal network seen from a load.

2.7 Applying network theorems to AC circuits

Every network theorem you learned for DC circuits also holds for AC circuits once resistance becomes complex impedance. Replace each sinusoidal source by its phasor, each R by Z = R + jX, and solve with complex numbers. The same algebra gives Thevenin, Norton, superposition and maximum power. Engineers use this for matching antennas, audio drivers, filters and power-factor correction; any outlet circuit with L and C needs it. The main change is that impedances carry phase, so a conjugate match replaces a simple equality.

You need: Thevenin and Norton, maximum power transfer, and Unit 3 phasors and impedance.

Replace R with Z and DC values with phasors

In DC, Thevenin gives a source V_th and a resistor R_th. In AC steady state, the source is a phasor V_th = |V_th|∠θ, and the element is an impedance Z_th = R_th + jX_th. The symbol j means √(−1). R_th is the real part in ohms; X_th is the reactance in ohms. An inductor has Z_L = jωL. A capacitor has Z_C = 1/(jωC) = −j/(ωC). Here ω = 2πf is angular frequency in rad/s, L is inductance in henry, C is capacitance in farad, and f is frequency in hertz.

Z = R + jX

Z is impedance in ohms (Ω); R is resistance in Ω; X is reactance in Ω; j = √(−1).

The circuit laws do not change. KCL and KVL use the same sums, but every current and voltage is a phasor and every ratio is a complex impedance. The voltage divider becomes V_out = V_s Z₂/(Z₁+Z₂). The current divider uses admittances Y = 1/Z. Admittance is in siemens (S).

  1. Solve the circuit at one frequency ω using phasors and complex impedances.
  2. Keep real and imaginary parts separate until the final step.
  3. Convert the final phasor back to v(t) = |V|√2 cos(ωt+θ) if |V| is RMS; for a peak phasor omit √2.

Superposition: one frequency at a time

Superposition holds because the circuit is linear. For sources at the same frequency, kill all but one independent source, solve the phasor response, and add the phasors. A dead ideal voltage source becomes a short circuit (0 V). A dead ideal current source becomes an open circuit (0 A). Dependent sources stay in the circuit; only independent sources are killed.

For sources at different frequencies, phasors cannot be added. A phasor has meaning only at one frequency. Solve a separate circuit at each frequency. Convert each phasor answer to a time-domain waveform. Then add the real waveforms.

v(t) = Σ_k |V_k| cos(ω_k t + φ_k)

v(t) is the total voltage in volts; |V_k| is the peak amplitude of the k-th frequency component in volts; ω_k is its angular frequency in rad/s; φ_k is its phase in radians; Σ means sum over all frequencies.

  1. List every independent source frequency.
  2. For each frequency, set all other independent sources to zero.
  3. Solve for the required phasor with complex impedances.
  4. Write the time waveform for that frequency.
  5. Add the waveforms in the time domain.

This is also why a 50 Hz phasor and a 60 Hz phasor cannot sit in one phasor diagram: they rotate at different rates.

Thevenin, Norton and the conjugate match

Remove the load. The open-circuit phasor is V_th. Dead all independent sources. Combine the impedances to get Z_th. Or find the short-circuit current phasor I_sc and use Z_th = V_th/I_sc. The Norton equivalent is I_N = V_th/Z_th in parallel with Z_N = Z_th. These are the same rules as DC, with R replaced by Z.

Z_L = Z_th* = R_th − jX_th

Z_L is the load impedance in Ω; Z_th* is the complex conjugate of Z_th; R_th is the Thevenin resistance in Ω; X_th is the Thevenin reactance in Ω.

For average power, let V_th be an RMS phasor. The load receives P = |V_th|² R_L / |Z_th + Z_L|². P is average power in watt; R_L is the load resistance in Ω. The maximum occurs when the reactance cancels and the resistance matches: X_L = −X_th and R_L = R_th. Then Z_L = Z_th*.

P_max = |V_th|²/(4R_th)

P_max is maximum average power in W; V_th is the RMS open-circuit voltage phasor in V; R_th is the real part of Z_th in Ω.

If V_th is a peak phasor, divide this result by 2. Check the unit: V² divided by Ω gives W.

  7. P_max = |V_th|²/(4R_th) = 50/(4×2)=50/8=6.25 W.

  • Leaving the load connected while finding Z_th. Remove the load first, then dead the independent sources.

Remember State the AC Thevenin equivalent of a linear two-terminal network at one frequency. 2 marks

A voltage phasor V_th in series with a complex impedance Z_th = R_th + jX_th.

Understand Why can you not add phasor responses from a 50 Hz source and a 60 Hz source directly? 3 marks

The two phasors rotate at different rates. A phasor is defined at one frequency. You must convert each response to a time waveform and add the waveforms.

Apply A source V_s = 20∠0° V RMS has a series impedance Z₁ = 4 + j3 Ω and a shunt impedance Z₂ = 4 − j3 Ω. Find V_th and Z_th. 4 marks

Z₁+Z₂ = 8 Ω. V_th = 20 × (4−j3)/8 = 10−j7.5 V = 12.5∠−36.87° V RMS. Z_th = (4+j3)(4−j3)/8 = 25/8 = 3.125 Ω.

Analyze A Thevenin impedance is Z_th = 3 + j4 Ω. What load gives maximum average power? Why is a 3 Ω resistor not enough? 5 marks

Z_L = Z_th* = 3 − j4 Ω. A 3 Ω resistor cancels no reactance, so the total series reactance remains +j4 Ω and the current is smaller than at the conjugate match.

Apply V_th = 8∠0° V RMS and Z_th = 4 + j3 Ω. Find P_max. 4 marks

P_max = |V_th|²/(4R_th) = 64/(4×4) = 64/16 = 4 W.

Remember Write I_N in terms of V_th and Z_th. 2 marks

I_N = V_th/Z_th, with Z_N = Z_th.

Understand What happens to ideal voltage and current sources when they are dead for superposition or Thevenin? 3 marks

A dead ideal voltage source becomes a short circuit (0 V). A dead ideal current source becomes an open circuit (0 A).

Analyze A load R_L = 5 Ω is connected to V_th = 10 V RMS and Z_th = 5 + j10 Ω. Is the load receiving maximum power? Compute the actual power and the maximum possible power. 6 marks

No. Z_th + Z_L = 10 + j10 Ω, so |Z_th + Z_L|² = 200 Ω². P = |V_th|² R_L / |Z_th + Z_L|² = 100×5/200 = 2.5 W. Maximum needs Z_L = 5 − j10 Ω, giving P_max = 100/(4×5) = 5 W.

Beyond the syllabus

Not for the exam. In radio-frequency design, the same conjugate match sets antenna and low-noise-amplifier impedances, often with LC matching networks. In audio, a loudspeaker's complex impedance changes with frequency, so a real amplifier is not a perfect Thevenin source. In power systems, maximum power transfer is rarely the goal; engineers prefer high efficiency and a stable voltage, and power-factor correction cancels reactance instead. Takeaways

  1. Mesh analysis writes KVL around each mesh and solves for mesh currents; a shared current source becomes one supermesh equation plus a current constraint.
  2. Nodal analysis writes KCL at each non-reference node and solves for node voltages; a floating voltage source becomes one supernode equation plus a voltage constraint.
  3. Superposition applies only to linear circuits, and only to voltages and currents, never directly to power.
  4. Any linear two-terminal network reduces to a single source and a single resistance, which makes load calculations one-step.
  5. A source delivers maximum power to a load when the load resistance equals the source resistance, but the efficiency then is only 50 per cent.
  6. Reciprocity, Millman and Tellegen give fast checks on a solution without re-solving the whole circuit.
  7. In AC circuits, every theorem survives if resistance is replaced by impedance and numbers become phasors at one frequency.

Exam question bank

Long answers in this unit almost always ask for a full worked circuit: state the law used, number the meshes or nodes on a diagram, solve the simultaneous equations, and close with a verification step such as Tellegen's sum or a power balance.

Remember and understand

Understand Define a mesh and a node. List, in order, the steps of mesh analysis for a planar DC circuit containing only voltage sources, and explain why a current source needs special handling. 8 marks

Mesh = innermost closed loop; node = junction of two or more elements; Assign clockwise mesh currents i₁, i₂, …; Write KVL per mesh: sum of resistance drops minus shared drops = sum of source emfs; Current source inside one mesh fixes that mesh current directly; Current source shared by two meshes needs a supermesh plus a constraint equation.

Understand State the superposition theorem. Explain what 'setting an independent source to zero' means for an ideal voltage source and for an ideal current source, and why power cannot be found by superposition. 8 marks

Statement: total response = algebraic sum of responses to each independent source acting alone; Zero voltage source = short circuit (0 V); Zero current source = open circuit (0 A); Only one independent source active at a time; dependent sources stay in place; Power is proportional to current squared or voltage squared, so it is not linear; Powers of individual responses are not added.

Remember State Thevenin's theorem and Norton's theorem. Give the relations between V_th, I_N, R_th and R_N, and state how R_th is measured when dependent sources are present. 8 marks

Thevenin: V_th in series with R_th; Norton: I_N in parallel with R_N; R_N = R_th; I_N = V_th/R_th; V_th = I_N R_N; R_th = V_oc/I_sc at the terminals; With dependent sources, V_oc and I_sc must be measured; cannot simply kill all sources.

Understand State the maximum power transfer theorem for a DC source and derive the condition R_L = R_th with the value P_max = V_th²/(4R_th). State the efficiency at that point. 10 marks

P_L = i²R_L with i = V_th/(R_th + R_L); P_L = V_th²R_L/(R_th + R_L)²; Differentiate with respect to R_L and set to zero; (R_th + R_L)² − 2R_L(R_th + R_L) = 0 → R_L = R_th; P_max = V_th²/(4R_th); Efficiency = P_L/P_generated = 50 per cent.

Apply

Apply A planar DC network has three meshes; a 4 A current source is shared between meshes 2 and 3. Write the mesh equations including the supermesh equation, and solve for all three mesh currents. 13 marks

Draw and label the three clockwise mesh currents; Write KVL for meshes 1 and 3 in full; Combine meshes 2 and 3 into one supermesh; write KVL around the outer path of the supermesh; Constraint from the shared source: i₃ − i₂ = 4 (sign from assigned directions); Solve the three simultaneous equations; Check by substituting into an unused KVL around an outer loop.

Apply For a circuit with four nodes and a 12 V source connected directly between two non-reference nodes, write the nodal equations using a supernode and find all node voltages. 13 marks

Mark the reference node and label V_a, V_b, V_c; Write KCL at ordinary nodes in the form (V − V_neighbour)/R; Enclose the 12 V source in a supernode; write one KCL for the supernode; Constraint: V_a − V_b = 12 V; Solve the simultaneous equations; Check that KCL is satisfied at the reference node.

Apply A resistive circuit has a 10 V voltage source and a 2 A current source. Use superposition to find the current through a specified 5 Ω resistor, then compute the power in it and explain why the power is not the sum of the two partial powers. 13 marks

Kill the current source (open) and solve for I'; Kill the voltage source (short) and solve for I''; Add with signs: I = I' + I''; P = I²R using the total current; I'²R + I''²R ≠ (I' + I'')²R because of the cross term 2I'I''R; Power is a nonlinear (squared) quantity.

Apply Find the Thevenin equivalent of a two-terminal network that contains one dependent source and two independent sources, then use it to find the current in a 6 Ω load. 13 marks

Remove the load; find V_oc by any method (nodal or mesh); Find I_sc by shorting the terminals; R_th = V_oc/I_sc; dependent sources stay in place; Draw the Thevenin circuit: V_th in series with R_th; I_L = V_th/(R_th + 6); Note that killing the dependent source is wrong.

Apply Three parallel branches hold 10 V with 2 Ω, 6 V with 3 Ω, and 4 V with 6 Ω. Use Millman's theorem to find the common node voltage and the current in each branch. 8 marks

V = Σ(V_k/R_k)/Σ(1/R_k); Numerator: 10/2 + 6/3 + 4/6 = 5 + 2 + 0.667 = 7.667 A; Denominator: 1/2 + 1/3 + 1/6 = 1 S; V = 7.667 V; I_k = (V_k − V)/R_k for each branch; Check ΣI_k = 0 at the node.

Apply An AC network with a 50 Hz source has R = 4 Ω in series with L = 10 mH. Find the Thevenin impedance seen by the load, then the load impedance for maximum power transfer. 13 marks

Z_th = 4 + j(2π × 50 × 0.01) = 4 + j3.14 Ω; |Z_th| = 5.09 Ω, angle 38.1 degrees; Conjugate match: Z_L = 4 − j3.14 Ω; P_max = |V_th|²/(4R_th), with R_th = 4 Ω; Reactance is cancelled, so the load looks purely resistive to the source; Note that equal-impedance (not conjugate) matching wastes power.

Analyze and evaluate

Analyze Compare mesh analysis and nodal analysis for a given planar network. State which method gives fewer equations for a circuit with 6 meshes and 4 non-reference nodes, and justify each choice. 10 marks

Mesh needs b − n + 1 equations; nodal needs n − 1 equations; Here 6 mesh equations versus 4 nodal equations, so nodal is shorter; Mesh suits networks with many parallel branches and few loops; Current sources suit nodal analysis; voltage sources suit mesh analysis; Presence of a supernode or supermesh adds one equation but removes one unknown; Both methods reduce to solving a linear system.

Evaluate A lamp fed from a long cable dims when a heater is switched on. Use Thevenin's theorem to model the cable-plus-supply as a source, and show how the terminal voltage falls with load current. 13 marks

Supply and cable reduce to V_th in series with R_th; Terminal voltage V = V_th − I R_th; Higher load current gives a bigger drop across R_th; Lamp current falls from its no-load value; Fault diagnosis: measure V_oc and V_under_load, then R_th = (V_oc − V_load)/I_load; Choose a thicker cable to reduce R_th.

Analyze For a given DC circuit, verify Tellegen's theorem by computing Σ v_k i_k over all elements, and explain what the zero sum tells you about power balance. 10 marks

Solve the circuit for all element voltages and currents; Use the passive sign convention for every element, including sources; Sources give negative products; resistors give positive products; The sum Σ v_k i_k = 0; Meaning: total power supplied equals total power absorbed; Any nonzero total signals an arithmetic error.

Evaluate A signal source of 50 Ω internal resistance feeds a load. Discuss when to use the conjugate match and when to use a matched-impedance or low-reflection connection, and compute the power lost in each case. 13 marks

Conjugate match Z_L = Z_th* maximises load power; Half the power is lost in R_th at that point; In power systems, maximum efficiency (R_L much greater than R_th) is preferred over maximum power; In communication and RF, maximum power matters more than efficiency; Reflection coefficient Γ = (Z_L − Z_th)/(Z_L + Z_th); Γ = 0 only for a matched-impedance, non-conjugate case; State the application before choosing the criterion.

Glossary

Additivity
The response to a sum of sources equals the sum of the responses to each source alone.
Bilateral element
An element that behaves the same when its terminals are swapped, such as a resistor.
Branch
A single element or a series of elements carrying the same current between two nodes.
Dependent source
A source whose value is controlled by a voltage or current elsewhere in the circuit; it is never set to zero in superposition.
Efficiency
Useful output power divided by total power supplied, expressed as a percentage.
Homogeneity
Scaling every source by a factor k scales every response by the same k.
Impedance Z
The complex ratio V/I in the phasor domain, written Z = R + jX with R in ohms and X the reactance in ohms.
KCL
Kirchhoff's current law: the algebraic sum of currents leaving a node is zero.
KVL
Kirchhoff's voltage law: the algebraic sum of voltages around any closed loop is zero.
Linear element
An element whose voltage-current relation is a straight line through the origin, such as an ideal resistor.
Load
The element or network connected to the two output terminals of a source network.
Loop
Any closed path in a circuit; a mesh is a loop with no other loop inside it.
Mesh current
A fictitious circulating current assigned to one mesh, used as the unknown in mesh analysis.
Millman's theorem
A formula that turns several parallel voltage-source branches into one equivalent source and resistance.
Node
A point where two or more circuit elements meet.
Open-circuit voltage V_oc
The voltage across two terminals when no load is connected.
Phasor
A complex number representing the amplitude and phase of a sinusoid at one fixed frequency.
Reciprocity
The property that a source in branch 1 and an ammeter in branch 2 give the same reading when their roles are swapped.
Reference node
The node chosen as 0 V so that all other node voltages are measured against it.
Short-circuit current I_sc
The current that flows through a zero-ohm link placed across two terminals.
Source transformation
Swapping a voltage source in series with a resistor for a current source in parallel with the same resistor, or the reverse.
Supermesh
The combined outer loop formed by two meshes that share a current source.
Supernode
The closed surface formed by two nodes joined by a voltage source, treated as one node for KCL.
Tellegen's theorem
Conservation of power in network form: Σ v_k i_k = 0 for every network obeying KCL and KVL, linear or not.
