5.1 Number systems, conversions, 2's complement and BCD

A digital circuit stores and moves only bits. Binary, octal, hexadecimal, 2's complement and BCD are reading rules for the same bit pattern. Binary uses base 2, octal base 8, hex base 16. 2's complement gives negative numbers a single zero and turns subtraction into addition. BCD stores one decimal digit in four bits for displays and clocks. Memory addresses, register maps, sensor readings and embedded control code all use these forms, so converting and checking the range by hand is a daily skill.

Place value and base conversion

Every base-r number is a sum of digit times weight. The weight at position i is ri, with i=0 at the rightmost digit. For 1011₂ the weights are 8,4,2,1, so 1011₂ = 8+0+2+1 = 11₁₀. A subscript names the base; r is the radix. Digits run from 0 to r−1. Hex uses A=10, B=11, C=12, D=13, E=14, F=15.

N = Σ d<sub>i</sub> r<sup>i</sup> from i=0 to n−1

N is the decimal value; di is the digit at position i; r is the base; n is the number of digits.

Decimal to base r uses repeated division. For 45: 45÷2 = 22 remainder 1; 22÷2 = 11 remainder 0; 11÷2 = 5 remainder 1; 5÷2 = 2 remainder 1; 2÷2 = 1 remainder 0; 1÷2 = 0 remainder 1. Read the remainders upward: 101101₂. Pad to 8 bits: 0010 1101.

Binary to octal groups 3 bits, binary to hex groups 4 bits. Start at the decimal point and group outward; pad the outer group with zeros. 101101.01₂ = 101 101 . 010 = 55.2₈. In hex, 0010 1101 . 0100 = 2D.4₁₆.

An n-bit unsigned word holds 0 to 2n−1. An 8-bit byte holds 0 to 255. A 4-bit nibble holds 0 to 15.

2's complement and signed subtraction

Sign-magnitude keeps the left bit as sign and the rest as magnitude. It has two zeros, +0 and −0. 1's complement makes a negative by inverting every bit; it also has two zeros. 2's complement makes a negative by inverting every bit and adding 1. It has one zero and needs no separate subtractor.

A − B = (A + (2<sup>n</sup> − B)) mod 2<sup>n</sup>

A and B are n-bit unsigned patterns; B is subtracted by adding its 2's complement; the final carry out of bit n is discarded.

  1. Write the n-bit magnitude of the number.
  2. Invert every bit (1's complement).
  3. Add 1 and keep only n bits.

For 8 bits, 0100 1110 is 78. Invert: 1011 0001. Add 1: 1011 0010. This pattern is −78. Adding 0010 1101 (45) gives 1101 1111. The carry out is 0. Invert and add 1 to read it: 0010 0001 = 33, so the value is −33.

Signed range for n bits is −2n−1 to 2n−1−1. For 8 bits it is −128 to 127. Overflow occurs when the carry into the sign bit differs from the carry out of the sign bit. Overflow is not the same as a carry out of the word.

BCD 8421 and add-6 correction

BCD (binary-coded decimal) stores one decimal digit in four bits, weights 8,4,2,1. 0 to 9 are 0000 to 1001. The six patterns 1010 to 1111 are invalid in BCD.

To add BCD numbers, add each 4-bit nibble as binary. If a nibble sum is greater than 9, or if it produces a carry out, add 0110 (6) to that nibble. Any carry moves to the next nibble. Correct only the nibble that failed; adding 0110 everywhere gives a wrong answer.

Example: 8 + 7. 1000 + 0111 = 1111. 1111 exceeds 9, so add 0110: 1111 + 0110 = 1 0101. The low nibble is 0101 and the carry makes the next nibble 0001, so the answer is 0001 0101, which is BCD 15.

Clocks and seven-segment displays use BCD because each digit is easy to drive.

Worked example

Question. Subtract 45 − 78 in 8-bit 2's complement arithmetic. Then add the BCD numbers 8 and 7, showing the correction.

  1. 45 = 32+8+4+1 = 0010 1101₂. 78 = 64+8+4+2 = 0100 1110₂.
  2. 2's complement of 78: invert 0100 1110 to 1011 0001; add 1 to get 1011 0010. This is −78 in 8 bits.
  3. Add: 0010 1101 + 1011 0010 = 1101 1111. The carry out of bit 7 is 0.
  4. Read 1101 1111: sign bit is 1. Invert: 0010 0000. Add 1: 0010 0001 = 33. So the value is −33.
  5. BCD: 8 = 1000, 7 = 0111. Binary sum 1000 + 0111 = 1111.
  6. 1111 is greater than 9, so add 0110 to the low nibble: 1111 + 0110 = 1 0101. Low nibble 0101, carry 1 to next nibble: 0001 0101 = BCD 15.

Answer. In 8-bit 2's complement, 45 − 78 = −33; in BCD, 8 + 7 = 15.

Exam traps

  • Reading a 2's complement pattern as unsigned: 1101 1111 is −33, not 223.
  • Adding 0110 to every BCD nibble instead of only the nibble above 9 or with carry out.
  • Grouping hex or octal from the left; group from the decimal point outward and pad the outer group.
  • Calling a carry out of the word overflow; overflow needs different carries into and out of the sign bit.
  • Mixing 1's complement (invert only) with 2's complement (invert and add 1).

5.2 Boolean algebra, logic gates and universal gates

A logic gate is a small switch network that computes one Boolean operation on bits. Boolean algebra is the set of rules that lets you replace one gate network with another that gives the same output. This matters because fewer gates mean fewer transistors, less power and a smaller chip. The same rules let you read a truth table, write an expression and build it from NAND or NOR gates only. Adders, multiplexers and microcontroller instruction paths are built this way.

You need: Chapter 5.1 for the 0/1 bit patterns and the row order of a truth table.

Gates, symbols and truth tables

A logic gate has inputs and one output. Each input and output is a bit: 0 for low voltage, 1 for high voltage. This is the positive-logic convention; negative logic swaps the two. NOT writes A′ (A prime): output 1 when A=0. AND writes AB: output 1 only when A=1 and B=1. OR writes A+B: output 1 when at least one input is 1. NAND is (AB)′. NOR is (A+B)′.

XOR writes A⊕B = A′B + AB′. It is 1 when the inputs are not equal. XNOR is its complement and is 1 when they are equal. For three inputs, A⊕B⊕C is 1 when an odd number of inputs are 1; this is parity. A 3-input AND is ABC; a 3-input OR is A+B+C.

Identities and De Morgan

Two expressions are equal when they give the same output for every input row. These named identities do that rewriting.

  • Identity: A+0=A; A·1=A.
  • Null: A+1=1; A·0=0.
  • Idempotent: A+A=A; A·A=A.
  • Complement: A+A′=1; A·A′=0.
  • Involution: (A′)′=A.
  • Distributive: A(B+C)=AB+AC; A+BC=(A+B)(A+C).
  • Absorption: A+AB=A; A(A+B)=A.
  • Combine: A+A′B=A+B.

A+A′B=A+B: if A=1 the output is 1; if A=0 the second term gives B. De Morgan's theorems are (A+B)′=A′B′ and (AB)′=A′+B′. In words: break the bar and change the sign. An OR inside becomes AND outside; an AND becomes OR. Every variable gets its own bar. So (A+B)′ is A′B′, not A′+B′.

Universal gates: NAND and NOR

A universal gate can build NOT, AND and OR, and so any Boolean function. NAND and NOR are universal. AND and OR are not: alone they cannot invert a bit.

  1. NOT from NAND: tie both inputs to A. Output (A·A)′=A′.
  2. AND from NAND: NAND A and B, then invert that output with a NAND tied to itself. Output ((AB)′)′=AB. Two gates.
  3. OR from NAND: invert A and B with two NANDs, then NAND the two inverted signals. Output (A′B′)′=A+B. Three gates.

NOR works the same way. Tie both inputs for NOT. OR from NOR takes two gates: NOR A and B, then invert that output with a NOR tied to itself. AND from NOR takes three gates: invert A, invert B, then NOR the two inverted signals, giving (A′+B′)′=AB. In CMOS, a 2-input NAND is usually smaller than a 2-input NOR, so NAND is the common choice. This is why chip libraries are built around NAND.

Truth table to expression, and cost

From a truth table, take each row with output 1. Write a product: use A if A=1, A′ if A=0. OR the products. Row A=1, B=0, C=1 gives AB′C. This is sum of products (SOP). To go back, list rows in binary order and evaluate each gate.

A two-level network has one layer feeding one final gate: AND gates feeding one OR gate for SOP, or OR gates feeding one AND gate for POS. Gate count is the number of gates. Fan-in is the number of inputs on one gate. A 3-input NAND is one gate with fan-in 3. Fewer gates and lower fan-in usually cost less.

K-maps in Chapter 5.3 remove variables from these expressions. Adders in Chapter 5.4 use these gates.

Worked example

Question. Reduce F = AB + A(B + C) + B(B + C) and realize the result with only 2-input NAND gates. State the gate count.

  1. Expand the brackets: F = AB + AB + AC + BB + BC.
  2. Use BB = B and AB + AB = AB: F = AB + AC + B + BC.
  3. Use B + BC = B(1 + C) = B: F = AB + AC + B.
  4. Use B + AB = B(1 + A) = B: F = B + AC.
  5. NAND realization: N1 = NAND(A, C) = (AC)′.
  6. N2 = NAND(B, B) = B′.
  7. N3 = NAND(N2, N1) = (B′·(AC)′)′ = B + AC by De Morgan.

Answer. F = B + AC, built with three 2-input NAND gates.

Exam traps

  • De Morgan: (A + B)′ = A′B′, not A′ + B′; breaking a bar changes the sign.
  • XOR is not universal. XOR with the constant 1 gives NOT (A⊕1 = A′) and with 0 gives a buffer, but every XOR-and-constant circuit is affine in its inputs (F = c ⊕ a₁A ⊕ a₂B ⊕ ...), so it can never produce AND or OR.
  • A + AB = A, not A + B. The identity A + A′B = A + B has a prime on A inside the product.
  • A NAND with both inputs at A is NOT, not AND. An AND is NAND followed by an inverter.
  • AND and OR are not universal; NAND and NOR are.

Analyze Why can AND and OR not be universal gates? 5 marks

AND and OR are monotone: changing any input from 0 to 1 never changes the output from 1 to 0. NOT is not monotone (1 → 0). 5.3 SOP and POS forms; K-map minimization

A truth table can be written as a sum of minterms or a product of maxterms. Both are exact and canonical: no simplification yet. A Karnaugh map redraws the truth table so cells that differ in one bit touch; grouping touching 1s removes the variables that change. The result is a cheaper SOP expression. Grouping 0s gives POS. This is used whenever a small logic function must become a few gates, as in adders, selectors and control logic.

You need: 5.2 Boolean algebra, logic gates and universal gates for truth tables and Boolean identities.

Minterms and maxterms

A product term is variables ANDed; a sum term is variables ORed. A minterm of n variables is a product term that contains every variable once, plain or complemented. A maxterm is a sum term that contains every variable once, plain or complemented. Number the row by reading the input bits as a binary number, A as MSB. In a minterm a 1 gives the plain variable and a 0 gives its complement. In a maxterm a 0 gives the plain variable and a 1 gives its complement. Minterm mi is 1 only on row i. Maxterm Mi is 0 only on row i. For row 0101 (i = 5), m5 = A'BC'D and M5 = A + B' + C + D'.

F = Σ m<sub>i</sub> for rows with F = 1; F = Π M<sub>i</sub> for rows with F = 0

mi is the minterm numbered i; Mi is the maxterm numbered i; Σ means OR of terms; Π means AND of terms; i runs over 0 to 2n−1.

  • Canonical SOP is the OR of all minterms where F = 1, written Σm(...).
  • Canonical POS is the AND of all maxterms where F = 0, written ΠM(...).
  • The two index lists are complements: if S is the minterm list, the maxterm list is every index from 0 to 2n−1 not in S.

K-map layout and grouping

The K-map is a truth table folded into a grid. Rows and columns follow Gray order 00, 01, 11, 10, so any two neighbouring cells differ in exactly one input bit. A 2-variable map has 4 cells; a 3-variable map has 8; a 4-variable map has 16. The edges wrap: top row touches bottom row, left column touches right column, and the four corners are mutually adjacent. A group must be a rectangle of 1, 2, 4, 8 or 16 cells — any power of two — never 3 or 6. So a 4-variable map with all sixteen cells at 1 can be taken as one block, giving the constant 1. Larger groups are better because each doubling removes one variable.

For SOP, group the 1s: a variable that is 1 in every cell of the group stays plain, one that is 0 in every cell stays complemented, and one that changes is dropped. Prime implicants are groups that cannot be made larger. Essential prime implicants cover a 1 that no other prime implicant covers. Don't-care cells, marked X, may be treated as 1 or 0 only when they enlarge a group. Some syllabi call the map a Veitch diagram.

SOP and POS minimization

SOP minimization is the main exam method: mark 1s, cover every 1 with the largest possible groups, and OR the terms. POS uses the same map but you group the 0s. Each group of 0s gives one sum term. A variable that is 0 in every cell of the group is written plain; a variable that is 1 in every cell is written complemented; a changing variable is omitted. AND the sum terms. Never complement the whole answer after grouping zeros. If 1s are fewer, SOP is shorter; if 0s are fewer, POS is shorter.

Worked example

Question. Minimize F(A,B,C,D) = Σm(0,2,5,7,8,10,13,15) on a 4-variable K-map. Give the minimized SOP and POS forms. Show the groups and the literal rule.

  1. Write each minterm as a 4-bit code A B C D: m0 = 0000, m2 = 0010, m5 = 0101, m7 = 0111, m8 = 1000, m10 = 1010, m13 = 1101, m15 = 1111. Put 1 in these cells.
  2. Group the corners m0, m2, m8, m10. In all four B = 0 and D = 0; A and C change. A fixed 0 gives a complemented literal in SOP, so the term is B'D'.
  3. Group the middle four m5, m7, m13, m15. In all four B = 1 and D = 1; A and C change. The term is BD.
  4. SOP: F = B'D' + BD.
  5. For POS, group the 0s. Group m1, m3, m9, m11: B = 0, D = 1, A and C change. In POS a fixed 0 gives the plain variable and a fixed 1 gives the complement, so the sum term is (B + D').
  6. Group m4, m6, m12, m14: B = 1, D = 0, so the sum term is (B' + D). AND them: F = (B + D')(B' + D).

Answer. Minimized SOP is F = B'D' + BD; minimized POS is F = (B + D')(B' + D).

Exam traps

  • Using row/column order 00, 01, 10, 11 instead of Gray 00, 01, 11, 10; then touching cells may differ in two bits.
  • Forgetting wrap-around: top-bottom, left-right and the four corners are adjacent.
  • In POS, copying the SOP literal rule. Grouping 0s: a 0 gives the plain variable, a 1 gives the complement.
  • Taking a group of 3 or 6 cells; only powers of two are legal.
  • Using a don't-care X to make a group that covers no 1 (SOP) or no 0 (POS); X is used only to enlarge an existing group.

5.4 Half adder, full adder and BCD adder

An adder is the first combinational circuit that does arithmetic with bits. Adding two bits gives a sum bit and a carry bit, and both are Boolean functions: sum is XOR, carry is AND. A half adder computes this for two bits but cannot accept a carry from a lower bit. A full adder adds three bits, and chaining full adders gives a multi-bit adder. A BCD adder adds decimal digits stored as 4-bit codes and corrects the result. Adders sit inside processors, calculators, timers, digital clocks and address counters.

You need 5.2 for XOR and AND gates, 5.3 for writing the correction condition, and 5.1 for BCD codes.

Half adder: two bits in, sum and carry out

A half adder adds two input bits A and B. It produces a sum bit S and a carry bit C. The carry is 1 only when both inputs are 1, because 1 + 1 is 10 in binary: sum 0, carry 1.

The Boolean equations are S = A ⊕ B and C = A·B. The symbol ⊕ is XOR: it gives 1 when the inputs differ. The dot is AND.

Full adder and the ripple-carry adder

A full adder adds three bits: A, B and Cin. Cin is the carry coming from the previous lower column. The outputs are sum S and carry Cout.

S = A ⊕ B ⊕ C<sub>in</sub>;  C<sub>out</sub> = A·B + C<sub>in</sub>·(A ⊕ B)

A and B are input bits; Cin is the input carry; S is the sum bit; Cout is the output carry; ⊕ is XOR, · is AND, + is OR.

Build it from two half adders and one OR gate. Half adder 1 adds A and B: S1 = A ⊕ B, C1 = A·B. Half adder 2 adds S1 and Cin: S = S1 ⊕ Cin, C2 = S1·Cin. The OR gate gives Cout = C1 + C2. The OR is needed because a carry may come from either half adder. Dropping it loses a carry.

A 4-bit ripple-carry adder chains four full adders. Bit 0 adds the least significant bits and produces a carry into bit 1. Bit 1 adds its bits plus that carry, and so on. The final carry out is the fifth sum bit.

The carry must pass through every stage in turn, so the worst-case delay grows with the number of bits. This is why wide adders use faster carry circuits.

BCD adder and the correction step

A BCD digit uses four bits for decimal 0 to 9. The patterns 1010 to 1111 are invalid as BCD digits. When two BCD digits are added with a 4-bit binary adder, the raw sum can land in 10 to 19. It then needs correction.

Add 0110 (decimal 6) when the raw 4-bit sum is above 9 or when the adder gives a carry out. Adding 6 skips the six invalid codes and pushes the result into the next decimal digit. Let S3, S2, S1, S0 be the raw sum bits, with S3 the 8's bit. The correction signal is Ccorr = Cout + S3S2 + S3S1. Here S3S2 means S3 AND S2, and + means OR. If Ccorr = 1, add 0110 to the raw sum.

The carry-out case matters. For 9 + 9, the raw sum is 1 0010. The low nibble 0010 is below 10, but Cout = 1. Correction gives 0010 + 0110 = 1000, so the answer is 1 1000 in BCD, decimal 18.

Worked example

Question. Add the 4-bit binary numbers 1011 and 0110 with a 4-bit ripple-carry adder. Then add the BCD digits 6 and 5 with a BCD adder. Show every carry and the correction.

  1. Label the bits from right to left: 1011 has A3A2A1A0 = 1 0 1 1; 0110 has B3B2B1B0 = 0 1 1 0. Start with Cin = 0 at bit 0.
  2. Bit 0: 1 + 0 + 0 = 1, so S0 = 1 and carry into bit 1 is 0.
  3. Bit 1: 1 + 1 + 0 = 2 = 102, so S1 = 0 and carry into bit 2 is 1.
  4. Bit 2: 0 + 1 + 1 = 2 = 102, so S2 = 0 and carry into bit 3 is 1.
  5. Bit 3: 1 + 0 + 1 = 2 = 102, so S3 = 0 and final carry Cout = 1.
  6. The sum bits are S3S2S1S0 = 0001 and Cout = 1, so the binary result is 1 00012 = 17. Check: 10112 = 11 and 01102 = 6, and 11 + 6 = 17.
  7. BCD: 6 = 0110 and 5 = 0101. The 4-bit binary adder gives 0110 + 0101 = 1011, decimal 11. Here S3=1, S2=0, S1=1, Cout=0, so Ccorr = S3S1 = 1; the raw sum is above 9 and needs correction.
  8. Add 0110 to 1011: 1011 + 0110 = 1 0001. The corrected low digit is 0001 and the carry to the next BCD digit is 1, so the two BCD digits are 0001 0001, decimal 11.

Answer. The binary sum is 1 00012 = 17, and the BCD result is 0001 0001 = 11.

Exam traps

  • Building a full adder from two half adders but forgetting the OR gate, so C1 or C2 is lost and the carry is wrong.
  • Applying BCD correction only for raw sums 1010 to 1111 and ignoring Cout; 9 + 9 = 1 0010 needs correction even though the low nibble 0010 is below 10.
  • Confusing the binary carry weight 2 with the BCD correction value 0110, decimal 6. The correction is not decimal 10.
  • Trying to chain half adders directly for multi-bit addition; a half adder has no Cin, so every column except the first needs a full adder.
  • Forgetting that the correction adder can itself produce a carry, as in 6 + 5, where 1011 + 0110 becomes 1 0001.

5.5 Multiplexers and demultiplexers

Digital systems often have many signals and only one wire to carry them. A multiplexer, or MUX, is a digitally controlled selector: n select lines choose one of 2ⁿ data inputs and pass it to one output. A demultiplexer, or DEMUX, does the reverse: it sends one data input to one of 2ⁿ outputs. Because the select code acts as an address, a MUX can also hold a truth table and generate any Boolean function. MUXes route signals onto shared buses, convert parallel data to serial, and drive displays.

You need: 5.3 for truth tables and minterms, and 5.2 for the AND-OR view of a logic circuit.

The 2:1 and 4:1 multiplexer

A multiplexer, or MUX, is a data selector. It has 2ⁿ data inputs I0 to I2ⁿ−1, n select lines S(n−1) to S0, and one output Y. The binary number on the select lines is the address of the input that reaches Y. A 2:1 MUX has one select line S and two inputs.

Y = S' I0 + S I1

Y is the output; I0 and I1 are the two data inputs; S is the select line; S' is NOT S.

When S = 0, Y = I0; when S = 1, Y = I1.

SY
0I0
1I1

A 4:1 MUX has two select lines S1 and S0 and four data inputs. Only one product term is 1 for a given select code.

Y = S1' S0' I0 + S1' S0 I1 + S1 S0' I2 + S1 S0 I3

S1 and S0 are the select lines; I0 to I3 are data inputs; Y is the selected input.

Many MUXes also have an enable input. An active-low enable EN' = 0 lets data pass. On a simple MUX, EN' = 1 forces Y = 0. To share one bus between several MUX outputs, the disabled outputs must go to high impedance (tri-state), not 0, so only the enabled MUX drives the bus.

A 4:1 MUX from three 2:1 MUXes

Build a 4:1 MUX as a tree of three 2:1 MUXes. The first two 2:1 MUXes use S0. The upper one selects between I0 and I1; the lower one selects between I2 and I3. The final 2:1 MUX uses S1. It selects between the two intermediate outputs.

  1. Connect I0 and I1 to the upper 2:1 MUX and use S0 as its select. Call its output U.
  2. Connect I2 and I3 to the lower 2:1 MUX and use S0 as its select. Call its output L.
  3. Connect U to input 0 of the final 2:1 MUX and L to input 1. Use S1 as its select.

When S1 = 0 the upper pair is passed; when S1 = 1 the lower pair is passed. The order is I0, I1, I2, I3 for select codes 00, 01, 10, 11. For the 4:1 tree above, the delay is two MUX delays: the two first-stage MUXes work in parallel, so their delays do not add. An 8:1 MUX with three select lines uses seven 2:1 MUXes, and the 8:1 tree has three MUX delays, one per stage.

Implementing a Boolean function on a 4:1 MUX

A 4:1 MUX can generate any three-variable Boolean function. Use two variables as the select lines and the third variable as data. The select code holds the truth table row group; the data input holds what F does inside that group. For variables A, B, C, put A on S1 and B on S0. Then each select code fixes AB and leaves C free.

  1. Write F for all eight minterms.
  2. Group rows by AB: 00, 01, 10, 11.
  3. In each group compare the two F values for C = 0 and C = 1.
  4. Set the data input by the rule: 0,0 → 0; 0,1 → C; 1,0 → C'; 1,1 → 1.
  5. Connect the four data inputs in the order I0 to I3.

The rule works because the MUX output is one product term: for select code 01, Y = I1. If I1 = C, the MUX outputs C when AB = 01; if I1 = C', it outputs C'. No gate is needed for the two select variables. This is function generation by table lookup.

The demultiplexer and its uses

A demultiplexer, or DEMUX, is a data distributor. It has one data input D, n select lines, and 2ⁿ outputs. The select code decides which output receives D; all other outputs stay 0. A 1:4 DEMUX has two select lines S1 and S0.

S1 S0Output = DOther outputs

Its equations are Y0 = D S1' S0', Y1 = D S1' S0, Y2 = D S1 S0', Y3 = D S1 S0. A 2-to-4 decoder is the address part of this DEMUX. The decoder turns S1 S0 into four lines with exactly one line high: one-hot means exactly one line is 1 and all the others are 0. Tie D to the enable of the decoder and the enabled line carries D.

Applications: a MUX converts parallel bits to serial by selecting one bit after another; a DEMUX converts serial back to parallel. MUXes route one of many signals onto a shared bus. A seven-segment display uses a decoder or DEMUX to turn a code into segment or digit lines. Microcontrollers use MUXes to share pins and ADC channels; see 5.7.

Worked example

Question. Implement F(A,B,C) = Σm(1,2,6,7) on a 4:1 multiplexer. Use A and B as the select lines, with A on the more significant select line S1. Find the connection for each data input I0 to I3.

  1. The minterms are 1, 2, 6 and 7. In binary A B C: m1 = 001, m2 = 010, m6 = 110, m7 = 111.
  2. Write F for m0 to m7: 0, 1, 1, 0, 0, 0, 1, 1.
  3. Group by AB. AB = 00 covers m0 and m1. F is 0 for C = 0 and 1 for C = 1, so I0 = C.
  4. AB = 01 covers m2 and m3. F is 1 for C = 0 and 0 for C = 1, so I1 = C'.
  5. AB = 10 covers m4 and m5. F is 0 for both C values, so I2 = 0.
  6. AB = 11 covers m6 and m7. F is 1 for both C values, so I3 = 1.
  7. Connect A to S1, B to S0, I0 = C, I1 = C', I2 = 0 and I3 = 1.

Answer. F is generated with A → S1, B → S0, I0 = C, I1 = C', I2 = 0 and I3 = 1.

Exam traps

  • Putting A on S0 and B on S1. The select code reads S1 S0, so A must drive the more significant line.
  • Trying to put all three variables A, B and C on the select lines of a 4:1 MUX. A 4:1 MUX has only two select lines; the third variable must feed the data inputs as 0, 1, C or C'.
  • Forgetting the enable input. An active-low enable EN' = 0 lets the MUX pass data; on a simple MUX EN' = 1 forces the output to 0. Sharing one bus needs tri-state outputs, which go to high impedance when disabled.
  • Calling a demultiplexer a multiplexer. A MUX has many inputs and one output; a DEMUX has one input and many outputs.
  • Assuming the decoder and the demultiplexer are unrelated. The 2-to-4 decoder is the address-selection part of a 1:4 demultiplexer; tie data D to the decoder enable to get the DEMUX.

5.6 Flip-flops

A flip-flop stores one bit by feeding its own output back to its input, so the value stays after the input is removed. This memory separates it from the gates of 5.2. It holds flags and forms registers. Only a few universities teach this inside the introductory electrical and electronics unit. The same cell is also called a latch or a bistable multivibrator. A register is n flip-flops sharing one clock.

You need: 5.2 for NAND and NOR gates and feedback.

SR latch: feedback stores a bit

A latch is two gates with their outputs fed back. In the NOR version, R means reset and S means set. Q and Q̄ are the two outputs, normally complements.

S=1, R=0: NOR 2 sees S=1, so Q̄=0; NOR 1 then sees R=0 and Q̄=0, so Q=1. Remove S and Q stays 1. R=1, S=0 resets Q to 0. S=R=0 holds the old bit. S=R=1 forces both outputs to 0, so Q and Q̄ stop being complements; when both inputs return to 0 the next state is unpredictable. That state is forbidden.

SRQ(next)
00Q (hold)
101 (set)
010 (reset)
11forbidden

This level-triggered cell is also called a bistable multivibrator: it has two stable states. The feedback loop is the memory. A clock is not needed for this basic latch.

Clocked SR, D and T flip-flops

A clock tells the memory when to change. In a clocked SR latch, clock C enables two input gates. C=0 blocks S and R, so Q holds. C=1 makes the latch transparent and it follows S and R.

A D flip-flop has data input D. At the active clock edge Q becomes D; between edges Q holds. A T flip-flop has input T. At each active edge Q toggles if T=1 and holds if T=0.

Level triggering acts for the whole high or low time. Edge triggering samples only at 0→1 or 1→0. A transparent latch is level-triggered; a true flip-flop is edge-triggered. The clock edge is the single instant that changes the stored bit. D stands for data; T stands for toggle. The active edge is marked on the clock symbol.

JK flip-flop, race-around and registers

JK removes the forbidden state. J sets, K resets, and J=K=1 toggles.

JKQ(next)
00Q (hold)
010 (reset)
101 (set)
11Q̄ (toggle)

One-line characteristic table: Q(next) = J·Q̄ + K̄·Q at the active edge. The characteristic table lists hold, reset, set and toggle.

In a level-triggered JK with J=K=1, Q toggles and feeds back while the clock is still high, so it toggles many times in one pulse. This is race-around. The output frequency can exceed the clock frequency, and the final state is uncertain. Edge triggering samples once and avoids it.

A register is n flip-flops sharing one clock, so n bits update together. A 4-bit register uses four D flip-flops. All four see the same clock edge. CPU registers use this; see 5.7.

Worked example

Question. A positive edge-triggered JK flip-flop starts with Q = 0. Clock pulses arrive with (J,K) = (1,0), (1,1), (0,1), (1,1). Find Q after each pulse.

  2. Pulse 2: J=K=1 toggles, so Q=0.
  3. Pulse 3: J=0, K=1 resets, so Q=0.
  4. Pulse 4: J=K=1 toggles, so Q=1.

Answer. After four clock edges Q = 1; the sequence is 1, 0, 0, 1.

Exam traps

  • S=R=1 is forbidden: both outputs become 0, so Q and Q̄ are not complements and the next state is unpredictable.
  • A level-triggered JK with J=K=1 can toggle many times in one high clock. That is race-around, not one toggle.
  • D means data, not toggle. A T flip-flop with T=0 holds; it does not reset.

5.7 Microprocessors and microcontrollers: architecture and applications

A microprocessor is a whole CPU on one chip: it can add, compare and decide, but it cannot store a program or drive a motor alone. A microcontroller is that CPU plus program memory, working memory, timers and input/output pins on the same chip. The first suits computing power; the second suits a cheap, small, low-power chip controlling one device — a washing machine, an energy meter, a traffic light.

You need: the ALU from 5.2, the adder from 5.4, bus selection from 5.5, and registers from 5.6.

The microprocessor: a CPU on one chip

A microprocessor is a single silicon chip holding the central processing unit (CPU) of a computer. It fetches instructions, does arithmetic and makes decisions, and contains nothing else. Program memory, data memory, timers and input/output circuits sit on other chips, wired to it. The 8085 and 8086 are early examples; the processor in a laptop is the same idea built larger.

  • ALU (arithmetic logic unit): adds, subtracts, ANDs, ORs and compares, built from the gates of 5.2 and the adder of 5.4.
  • Register file: fast storage cells (5.6) holding the numbers being worked on now.
  • Program counter (PC): address of the next instruction to be fetched.
  • Instruction register (IR): the instruction being decoded now.
  • Control unit: switches the other blocks on in the right order.
  • Address bus: one-way; with n lines it selects 2ⁿ memory locations.
  • Data bus: two-way, carries numbers in and out.
  • Control bus: carries read/write, clock and interrupt signals.
  1. Fetch: the control unit puts the PC value on the address bus, reads the byte stored there into the IR, and increments the PC.
  2. Decode: the control unit works out what the instruction means and which registers and ALU operation it needs.
  3. Execute: operands are read, the ALU or a register does the work, the result is written back.
  4. Repeat from step 1.

t = CPI ÷ f

t is the time for one instruction in seconds, CPI is the average number of clock cycles that instruction needs (a pure number), f is the clock frequency in hertz.

Word length is the number of bits the ALU handles at a time: 8 bits for an 8-bit chip, 32 for a 32-bit chip. It usually, not always, matches the data bus width — the 8088 has a 16-bit word and an 8-bit data bus. It sets the largest number the CPU can handle in one operation.

The microcontroller: the whole computer on one chip

A microcontroller (MCU) is a microprocessor plus the support circuits it needs, all on one chip. That is why one small package can run a whole appliance with no extra chips.

  • Flash or ROM program memory: keeps the program after power is removed.
  • RAM: working data; it loses its contents when power goes.
  • Timers and counters: count clock pulses to make delays or count events.
  • ADC (analog-to-digital converter): turns a sensor voltage into a number; many microcontrollers have it on chip, but the classic 8051 needs an external ADC0808 read through a port.
  • UART (universal asynchronous receiver-transmitter), a serial port: sends and receives characters, for example to a PC.
  • GPIO (general purpose input/output) pins: digital pins set by software to drive a relay, LED or transistor, or read a switch.

Two one-line comparisons. Von Neumann architecture uses one memory for program and data; Harvard architecture has separate program and data memories, so both can be read at once. CISC (complex instruction set computer) offers many powerful instructions; RISC (reduced instruction set computer) offers few simple, fast ones.

The 8051 family is the standard teaching chip: 8-bit CPU, 4 KB on-chip program memory, 128 bytes RAM, 32 input/output pins as four 8-bit ports, and two 16-bit timers. One timer counts from 0 to 65535 and overflows, so a longer delay is made by counting overflows.

Embedded systems and their applications

An embedded system is a computer built inside a product to control that product, not to be a general-purpose computer. It runs one fixed program, usually forever, and its user never sees an operating system. A microcontroller is its typical heart.

  • Washing machine: reads the water-level sensor through the ADC, runs the motor for a set time using a timer, drives relays and LEDs from GPIO pins.
  • Microwave oven: timer for the cooking period, GPIO for the door switch, magnetron relay and display.
  • Air-conditioner: reads a temperature sensor, compares it with the set value, switches the compressor through a relay.
  • Car engine control: reads sensors and fires the fuel injector at the exact instant using timers.
  • Energy meter: counts pulses proportional to energy, keeps the total in memory, sends it over the serial port.
  • Traffic light: a timer drives the red, yellow and green lamps in sequence.

The choice is the same each time. If the job needs a keyboard, a screen and a large program, use a microprocessor with separate memory. If the job is to sense, time and switch a few loads, use a microcontroller: one chip, fewer wires, lower cost, lower power.

Worked example

Question. A washing machine controller must read a water-level sensor whose output is an analog voltage, run the motor for 5 minutes, light an LED when the cycle ends, and sound a buzzer. The controller uses an 8051-family chip: 8-bit CPU, 4 KB program memory, 128 bytes RAM, two 16-bit timers, 32 input/output pins, and a 12 MHz crystal with 12 clock cycles per machine cycle. The program is 3.5 KB. The variables are: water level 1 byte, two 16-bit timer counts (2 bytes each), flags 1 byte. Four pins are used. Find the free program memory in bytes, the free RAM in bytes, the free I/O pins, and the number of 16-bit timer overflows needed for the 5-minute run. Then say whether a microprocessor or a microcontroller is the right choice.

  1. Blocks needed: an ADC input for the analog sensor (on-chip on ADC-equipped variants, otherwise an external ADC0808 read through a port), a timer for the 5-minute run, GPIO outputs for the motor relay, LED and buzzer, and program memory and RAM.
  2. Program memory: 3.5 KB = 3.5 × 1024 = 3584 bytes. Flash 4096 bytes. Free = 4096 − 3584 = 512 bytes.
  3. RAM used: 1 + 2 + 2 + 1 = 6 bytes. Free = 128 − 6 = 122 bytes.
  4. Pins used: motor relay, LED, buzzer = 3 outputs; sensor input = 1; total 4. Free = 32 − 4 = 28 pins.
  5. Timer resolution: 12 MHz ÷ 12 = 1 MHz machine cycle, so 1 count = 1 µs.
  6. Run time: 5 minutes = 300 s = 300 × 10⁶ µs = 300,000,000 counts.
  7. One 16-bit timer counts 65536 before overflowing. Overflows = 300,000,000 ÷ 65536 = 4577.64, so 4578 overflows (the last is partial).
  8. Decision: timer, GPIO, program memory and RAM are on chip; only the ADC is outside (built in on ADC-equipped variants), so a microcontroller is still right. A microprocessor would need separate ROM, RAM, timer and ADC chips plus more wiring.

Answer. Free program memory 512 bytes, free RAM 122 bytes, free I/O pins 28, and 4578 timer overflows for the 5-minute run; a microcontroller such as the 8051 family is the right choice.

Exam traps

  • Swapping the definitions: a microprocessor does not have RAM, timers or GPIO on chip; a microcontroller has its own program memory.
  • Judging a chip by clock speed alone: time per instruction is CPI ÷ f, so a 16 MHz chip needing 4 cycles per instruction can be slower than an 8 MHz chip needing 1.
  • Confusing the address bus with the data bus: n address lines give 2ⁿ locations; the data bus carries data, and its width usually but not always equals the word length.
  • Calling the 8051's 4 KB program memory ‘RAM’: the 4 KB is Flash/ROM for the program and only 128 bytes are RAM.
  • Thinking the 8051 timer counts seconds: it counts machine cycles, so divide the crystal frequency by 12 to get the count rate.

Takeaways

  1. One pattern of bits can be read as unsigned binary, 2's complement, octal, hexadecimal or BCD; the reading rule fixes the value.
  2. Subtraction is done as 2's complement addition, so a single adder circuit handles both operations.
  3. NAND alone, or NOR alone, can build NOT, AND, OR and therefore every logic circuit.
  4. A truth table has exactly one canonical SOP form and one canonical POS form; K-map grouping removes the variables that change inside a group.
  5. A half adder is just the truth table of one-column binary addition, and cascading full adders gives multi-bit addition.
  6. A multiplexer with n select lines can implement any n-variable Boolean function without any other gate.
  7. A flip-flop stores a bit only because its output feeds its input, so feedback is the basis of all digital memory.
  8. A microcontroller is a CPU with program memory, data memory, timers and GPIO pins on one chip, built to control a device.
  9. Bus width decides how much memory a CPU can address and how fast data moves; the address bus is one-way, the data bus is two-way.
  10. Harvard architecture and a reduced instruction set both raise speed at the cost of simpler, more predictable hardware.

Glossary

1's complement
The result of inverting every bit of a binary number.
2's complement
The 1's complement plus 1, used to represent negative numbers and to turn subtraction into addition.
ADC
A circuit that converts a continuous analog voltage into a proportional binary number.
BCD
A decimal code in which each digit 0–9 is written as a separate 4-bit binary group.
Binary number system
A positional number system with base 2 in which each place value is a power of 2.
Boolean algebra
The algebra of two values 0 and 1 with the operations AND, OR and NOT, used to describe logic circuits.
Bus
A group of parallel wires that carries addresses, data or control signals between the parts of a computer.
Clock
A periodic square wave that decides when a sequential circuit is allowed to change state.
Combinational circuit
A circuit whose output depends only on the present inputs, with no memory of earlier inputs.
De Morgan's laws
The pair of identities (A·B)' = A' + B' and (A + B)' = A'·B'.
Don't-care condition
An input combination that never occurs in practice, so its output may be chosen as 0 or 1 to simplify the circuit.
GPIO
A general purpose input/output pin whose direction and logic level are set by the running program.
Gray code
A binary code in which consecutive values differ in exactly one bit, used for K-map labels and position encoders.
Hexadecimal number system
A base-16 system using 0–9 and A–F, where one hex digit stands for exactly four bits.
Karnaugh map
A rectangular map of a truth table arranged so that adjacent cells differ in one variable, allowing visual minimisation.
Logic gate
A physical circuit with one output whose state is fixed by its input states according to one Boolean operation.
Maxterm
A sum of all the variables of a function, each either complemented or not, that is 0 for exactly one input row.
Microcontroller
A single chip containing a CPU, program memory, data memory, timers and input/output pins for controlling a device.
Minterm
A product of all the variables of a function, each either complemented or not, that is 1 for exactly one input row.
Multiplexer
A digital selector that connects one of several data inputs to a single output under the control of select lines.
Octal number system
A base-8 system using digits 0 to 7, where one octal digit stands for exactly three bits.
Product of sums (POS)
A Boolean expression written as an AND of several OR terms.
Sequential circuit
A circuit whose output depends on the present inputs and on the stored past state.
Sum of products (SOP)
A Boolean expression written as an OR of several AND terms.
Truth table
A table listing every input combination of a logic function and the output for each.
Universal gate
A gate from which all other gates can be constructed; NAND and NOR have this property.
