3.1 Sequences of real numbers and their convergence

A sequence is an endless ordered list of real numbers, a₁, a₂, a₃, …, and its limit is the single number the list settles on. Convergence makes 'settles on' precise: after some index N, every term lies inside any band you draw around the limit. This idea is the foundation of infinite series, numerical iteration, and every approximation that improves as you take more terms. A phone's GPS, a bank's compound interest, and a weather model all produce sequences whose convergence or divergence decides whether the answer is trustworthy.

You need: the idea of a function and of inequalities from Unit 1, and the absolute value |x| as the distance from x to 0 on the number line.

A sequence is a function on the natural numbers

A sequence of real numbers is a function a: ℕ → ℝ. The input n is a natural number 1, 2, 3, …, and the output is written aₙ. The list a₁, a₂, a₃, … is the sequence; n counts position, not a quantity you choose freely. For example, aₙ = 1/n gives 1, 1/2, 1/3, …; bₙ = (−1)ⁿ gives −1, 1, −1, 1, …; cₙ = n² gives 1, 4, 9, ….

A sequence is bounded above if aₙ ≤ M for all n for some real M, bounded below if aₙ ≥ m for all n for some real m, and bounded if both hold. The sequence 1/n is bounded because 0 < 1/n ≤ 1. The sequence n² is bounded below but not above. The sequence (−1)ⁿ is bounded between −1 and 1.

A sequence is increasing if aₙ₊₁ ≥ aₙ for every n, decreasing if aₙ₊₁ ≤ aₙ, and monotone if it is one of these. The sequence 1/n is decreasing. The sequence (3n+1)/(n+2) is increasing: 4/3, 7/4, 2, … rises toward 3. A sequence is eventually monotone if it is monotone from some index onward; the first few terms do not affect convergence.

Convergence: every band around L

aₙ → L means: for every real ε > 0 there is an integer N such that |aₙ − L| < ε for all n ≥ N.

ε (epsilon) is the chosen half-width of a band around L; N is an index that may depend on ε; |aₙ − L| is the distance from aₙ to L.

Every band (L − ε, L + ε), however thin, contains all terms from N onward; only finitely many terms lie outside. The number N is not unique: if N works, every larger integer works too. A sequence has at most one limit. If aₙ → L and aₙ → M with L ≠ M, take ε = |L − M|/2. The bands around L and M do not overlap, so no term can be within ε of both for large n. Hence L = M.

Limits follow arithmetic: if aₙ → A and bₙ → B, then aₙ + bₙ → A + B, aₙbₙ → AB, and aₙ/bₙ → A/B when B ≠ 0 and bₙ ≠ 0 for large n. These rules compute limits from known pieces without returning to ε and N each time.

The Archimedean property says that for any real x there is a natural number greater than x. It supplies N: given ε, choose N > 1/ε, so 1/N < ε. To prove aₙ → L from the definition, simplify |aₙ − L|, bound it by something like C/n, solve C/n < ε, and take N larger than C/ε.

Bounded is not enough; subsequences and limsup

Boundedness does not force convergence. The sequence aₙ = (−1)ⁿ is bounded between −1 and 1 but never settles: its terms jump between −1 and 1. A subsequence is formed by choosing indices n₁ < n₂ < n₃ < … and reading aₙ₁, aₙ₂, aₙ₃, …. If aₙ → L, every subsequence also → L. Having some convergent subsequences is not enough, however: (−1)ⁿ has subsequences constant at 1 and at −1, yet the whole sequence diverges. (Convergence of every subsequence to the same L does force aₙ → L; see Quiz Q8.)

A monotone sequence that is bounded converges. If aₙ is increasing and bounded above, its terms approach the least upper bound L. This theorem proves that a limit exists without naming it first. A bounded sequence that is not monotone may still converge, but monotonicity plus boundedness is a convenient sufficient condition.

For a bounded sequence: limsup aₙ = largest limit of a convergent subsequence; liminf aₙ = smallest limit of a convergent subsequence. For unbounded sequences one allows the values +∞ and −∞.

For aₙ = (−1)ⁿ, limsup = 1 and liminf = −1. A sequence converges to a real L exactly when limsup = liminf = L.

This language describes oscillation and is developed in 3.8.

Worked example

Question. Using the ε-N definition, show that limₙ→∞ (3n+1)/(n+2) = 3. Then find an N that works for ε = 0.01.

  1. Start with the distance: |aₙ − 3| = |(3n+1)/(n+2) − 3|.
  2. Put over a common denominator: (3n+1 − 3(n+2))/(n+2) = (3n+1 − 3n − 6)/(n+2) = −5/(n+2).
  3. Take absolute value: |−5/(n+2)| = 5/(n+2), since n ≥ 1 makes n+2 > 0.
  4. We need 5/(n+2) < ε. This is the same as n + 2 > 5/ε, i.e. n > 5/ε − 2.
  5. For ε = 0.01, 5/ε = 5/0.01 = 500. So n > 500 − 2 = 498. The smallest integer N is 499.
  6. Check n = 499: 5/(499+2) = 5/501 ≈ 0.00998004 < 0.01. For every n ≥ 499 the denominator is larger, so the distance is even smaller.

Answer. The limit is 3; for ε = 0.01, N = 499 works, and at n = 499 the distance is 5/501 ≈ 0.00998004.

Exam traps

  • Replacing 'for all n ≥ N' by 'for infinitely many n'. The sequence 1, 0, 1, 0, … meets the band around 1 infinitely often but does not converge to 1.
  • Assuming a bounded sequence must converge. (−1)ⁿ is bounded and divergent.
  • Checking only one side of |aₙ − L| < ε. The terms must stay above L − ε and below L + ε.
  • Using one N for every ε. N depends on ε: a smaller ε needs a larger N.
  • Confusing a sequence with its series. The sequence is the list aₙ; the series Σaₙ is its partial-sum limit, treated in 3.2.

3.2 Infinite series of real numbers

An infinite series adds infinitely many real numbers: a₁ + a₂ + a₃ + … . You cannot finish the addition, so the sum is defined as a limit. Add the first N terms to get the partial sum S_N. If the sequence S_N converges to a real number S, the series converges and S is its sum. Otherwise it diverges. This turns every series question into a sequence question from 3.1. Series are used in payment plans with interest, function approximations, and sampled signals.

You need 3.1 for the limit of a sequence and the notation aₙ → L.

Definition through partial sums

A series of real numbers is a sum with infinitely many terms: Σ_{n=1}∞ aₙ = a₁ + a₂ + a₃ + … . Each aₙ is a real number called a term. The N-th partial sum is S_N = a₁ + a₂ + … + a_N. This is an ordinary finite sum. The sequence of partial sums is S₁, S₂, S₃, … . The series converges to a real number S when lim_{N→∞} S_N = S. Then we write Σ_{n=1}∞ aₙ = S. If the limit does not exist as a finite real number, the series diverges. Some syllabi stress the sequence of partial sums; the convergence of that sequence is what defines the sum of the series.

Infinite addition has no last term, so the limit supplies the missing meaning. A series is not a number until its partial sums settle. If S_N alternates between 0 and 1, the series diverges.

Σ_{n=1}∞ aₙ = lim_{N→∞} S_N, where S_N = a₁ + a₂ + … + a_N

aₙ are the terms; S_N is the N-th partial sum; S is the sum when the limit exists.

Every convergence question about a series is a convergence question about the sequence S_N from 3.1. Whether aₙ tends to 0 alone does not decide it. The convergence question is decided by the partial sums S_N.

Geometric and telescoping series

A geometric series has each term r times the previous term. The first term is a and the common ratio is r. Then Σ_{n=1}∞ a r^{n−1} = a + ar + ar² + … . For r ≠ 1, S_N = a(1 − r^N)/(1 − r). If |r| < 1, then r^N → 0, so S_N → a/(1 − r). The series converges and its sum is a/(1 − r). If |r| ≥ 1, it diverges, except the zero series with a = 0. The first term a carries the unit; r is a pure number.

In a telescoping series, each term splits as a difference bₙ − b_{n+1}. Then S_N = (b₁ − b₂) + (b₂ − b₃) + … + (b_N − b_{N+1}) = b₁ − b_{N+1}. The middle terms cancel. If b_{N+1} → L, the sum is b₁ − L. The worked example uses bₙ = 1/n.

The nth term test and algebra

The nth term test. If Σaₙ converges, then aₙ → 0. Reason: aₙ = S_n − S_{n−1}, and both partial sums tend to the same S, so their difference tends to 0. Contrapositive: if aₙ does not tend to 0, the series diverges. This test can prove divergence only. It cannot prove convergence. The harmonic series has aₙ = 1/n → 0 but diverges.

Algebra of convergent series. If Σaₙ = A and Σbₙ = B, both finite, then Σ(aₙ + bₙ) = A + B and Σ c aₙ = cA for any real constant c. Also Σ(aₙ − bₙ) = A − B. If Σaₙ converges and Σbₙ diverges, then Σ(aₙ + bₙ) diverges. Otherwise subtracting the convergent series would make Σbₙ converge. Adding or removing finitely many initial terms changes the sum but not convergence. For deeper tests see 3.3.

Σ(aₙ + bₙ) = Σaₙ + Σbₙ, Σ c aₙ = c Σaₙ

valid when both series on the right converge; c is a real constant.

Cauchy criterion and the harmonic series

Cauchy criterion for series. The series Σaₙ converges if and only if for every ε > 0 there is an integer N such that for all m > n ≥ N, |a_{n+1} + a_{n+2} + … + a_m| < ε. Here ε is any positive tolerance. The sum inside is a tail block of consecutive terms. This is exactly the Cauchy criterion for the partial sums S_N. The real line is complete, so a Cauchy sequence of partial sums has a real limit; see 3.8.

Harmonic series. Σ_{n=1}∞ 1/n diverges. Group terms after the first 1 and 1/2: 1 + 1/2 + (1/3 + 1/4) + (1/5 + … + 1/8) + … . For k ≥ 1, the block from 1/(2^k + 1) to 1/2^{k+1} has 2^k terms, each at least 1/2^{k+1}. The terms 1 and 1/2 stand outside the blocks. So each block sums to at least 2^k · 1/2^{k+1} = 1/2. Infinitely many blocks make partial sums larger than any bound. Thus S_N → ∞ and the series diverges. The integral comparison in 3.3 gives the same result through log N.

1 + 1/2 + (1/3 + 1/4) + (1/5 + … + 1/8) + …

each bracket after the first two terms has sum at least 1/2; the brackets continue forever.

Worked example

Question. Find the sum of the series Σ_{n=1}∞ 1/(n(n+1)). Show that the series converges.

  1. Write the term with partial fractions. 1/(n(n+1)) = A/n + B/(n+1). Multiply by n(n+1): 1 = A(n+1) + B n = (A+B)n + A. So A = 1 and A+B = 0, giving B = −1. Hence 1/(n(n+1)) = 1/n − 1/(n+1).
  2. Form S_N = Σ_{n=1}^N (1/n − 1/(n+1)). Expand: (1 − 1/2) + (1/2 − 1/3) + … + (1/N − 1/(N+1)).
  3. All middle terms cancel. S_N = 1 − 1/(N+1).
  4. Take the limit: lim_{N→∞} S_N = 1 − 0 = 1.
  5. The partial sums converge to the finite number 1, so the series converges and its sum is 1.

Answer. The series converges to the sum 1.

Exam traps

  • aₙ → 0 does not prove Σaₙ converges. The harmonic series has 1/n → 0 and diverges.
  • The sum of a series is not the limit of its terms. It is the limit of its partial sums.
  • Use a/(1−r) only for a geometric series with |r| < 1. Here a is the first term, not the common ratio.
  • In telescoping, S_N ends at b₁ − b_{N+1}. Keeping b₁ − b_N leaves the wrong last term.
  • The Cauchy criterion for series looks at a whole block a_{n+1} + … + a_m, not only at one pair a_{n+1}.

3.3 Comparison, integral, ratio and root tests

Four tests decide whether a series of positive terms converges, without adding infinitely many terms. Comparison places the series beside a known p-series. The integral test replaces the sum by an area. The ratio and root tests watch how fast terms shrink. These tools are used in probability, numerical error bounds and algorithm analysis. Only a few universities teach all four in one unit. This chapter keeps every term positive; signs come later.

You need: 3.1 and 3.2, limits from Unit 1, and improper integrals from Unit 2.

Comparison with a p-series

A series Σaₙ with aₙ > 0 for every n is a positive-term series. Its partial sums increase, so it either converges or tends to +∞. The p-series Σ 1/nᵖ converges exactly when p > 1 and diverges when p ≤ 1. Here p is a fixed real number and n starts at 1.

Direct comparison: if 0 ≤ aₙ ≤ bₙ for all large n, then Σbₙ convergent forces Σaₙ convergent; Σaₙ divergent forces Σbₙ divergent. The smaller series is squeezed under the larger.

Limit comparison: let bₙ > 0 and L = lim (aₙ/bₙ). If 0 < L < ∞, then Σaₙ and Σbₙ both converge or both diverge. If L = 0 and Σbₙ converges, then Σaₙ converges. If L = ∞ and Σbₙ diverges, then Σaₙ diverges. Choose bₙ as a simple p-series with the same growth. For example, aₙ = (2n+1)/(n³+5). For large n, aₙ behaves like 2n/n³ = 2/n². Take bₙ = 1/n². Then (aₙ/bₙ) → 2, and 0 < 2 < ∞. Since Σ1/n² converges (p=2>1), Σaₙ converges.

Integral test

Let f be positive, continuous and decreasing on [1, ∞), and let aₙ = f(n). Then Σ_{n=1}∞ aₙ and ∫₁∞ f(x) dx both converge or both diverge. The sum is the area of rectangles of height f(n); the integral is the area under the curve. If the integral is finite, the rectangles fit under a finite area plus the first term. If the integral is infinite, the rectangles cover an infinite area.

  1. Check that f(x) is positive, continuous and decreasing for x ≥ 1, where aₙ = f(n).
  2. Compute ∫₁^N f(x) dx.
  3. Take N → ∞. A finite limit means Σaₙ converges; an infinite limit means it diverges.

For Σ 1/n², take f(x)=1/x². It is positive, continuous and decreasing. ∫₁∞ x⁻² dx = [−1/x]₁∞ = 1, a finite number. So Σ1/n² converges. For a p-series, ∫₁∞ x⁻ᵖ dx is finite exactly when p > 1.

Ratio and root tests

L = lim |aₙ₊₁/aₙ|

aₙ is the nth term of the series; L is the limit of the absolute ratio as n → ∞.

Ratio test: if L < 1, Σaₙ converges absolutely. If L > 1 (including L = ∞), it diverges. If L = 1, the test gives no conclusion. Factorials cancel in the ratio, so this test suits factorials and powers.

Root test: let L = lim |aₙ|^{1/n}. The same three rules hold. nth powers collapse under the nth root. Some syllabi call these D'Alembert's ratio test and Cauchy's root test.

Cauchy condensation: for a decreasing positive sequence, Σaₙ converges if and only if Σ2ⁿa_{2ⁿ} converges. This one-line variant handles series beyond p-series. For example, Σ1/(n log n) gives Σ2ⁿ/(2ⁿ log 2ⁿ) = (1/log 2)Σ1/n, which diverges, so Σ1/(n log n) diverges; the test also settles Σ1/(n(log n)²), which converges. When L = 1, switch to comparison or Raabe's test in 3.7. Do not call the series convergent.

Worked example

Question. Test the series Σ_{n=1}∞ n²/2ⁿ for convergence.

  1. The terms aₙ = n²/2ⁿ are positive for n ≥ 1.
  2. Form the ratio: aₙ₊₁/aₙ = ((n+1)²/2^{n+1})/(n²/2ⁿ).
  3. Simplify: = ((n+1)²/n²)·(2ⁿ/2^{n+1}) = (1+1/n)²·(1/2) = (1+1/n)²/2.
  4. Take the limit: as n → ∞, 1+1/n → 1, so L = 1²/2 = 1/2 = 0.5.
  5. Since L = 0.5 < 1, the ratio test says the series converges.

Answer. The series Σ n²/2ⁿ converges; the ratio limit is 1/2.

Exam traps

  • If the ratio or root test gives L = 1, it gives no information. Do not write convergent; use comparison or Raabe's test.
  • In direct comparison, a series larger than a divergent series diverges; a series smaller than a convergent series converges. The other two directions fail.
  • The p-series Σ1/nᵖ diverges at p = 1 and converges for every p > 1, even p = 1.0001. Check the exponent, not the number of terms.
  • The integral test needs f decreasing. A positive continuous f that rises first may break the rectangle comparison.
  • Limit comparison needs 0 < L < ∞. If L = 0 or L = ∞, only one direction follows.

3.4 Alternating series and Leibnitz test

An alternating series has terms whose signs flip: plus, minus, plus, minus. If the sizes of the terms shrink steadily to zero, the partial sums cannot run away; they step above and below one limit and close in on it. This gives a quick convergence test that needs no comparison series, and it estimates the error from the first omitted term. It appears in series solutions, Fourier series, and numerical approximations where cancelling terms improve accuracy.

You need Chapter 3.2 for partial sums and Chapter 3.1 for limits.

What an alternating series is

An alternating series is a series of the form Σn=1∞ (−1)n+1 bn = b1 − b2 + b3 − b4 + ⋯, where every bn > 0. The factor (−1)n+1 gives + for n = 1, − for n = 2, + for n = 3, and so on. The number bn is the size of the nth term without its sign. The partial sum is SN = b1 − b2 + ⋯ + (−1)N+1 bN, and the series converges when SN tends to a finite limit S as N → ∞. The standard example is the alternating harmonic series 1 − 1/2 + 1/3 − 1/4 + ⋯, with bn = 1/n. Its sum is ln 2 ≈ 0.693. The first partial sums are S1 = 1, S2 = 0.5000, S3 = 0.8333, S4 = 0.5833, S5 = 0.7833, S6 = 0.6167, S7 = 0.7595, S8 = 0.6345, S9 = 0.7456, S10 = 0.6456. They jump above and below ln 2 and move closer to it. The plain harmonic series 1 + 1/2 + 1/3 + ⋯ diverges, so the minus signs are doing real work.

The Leibnitz test and the remainder bound

Leibnitz test. Suppose bn > 0 for all n, bn+1 ≤ bn for all n (or for all n beyond some N), and bn → 0. Then Σ (−1)n+1 bn converges. The test is also spelled Leibniz; both names mean the same result. Why it works: the even partial sums S2, S4, S6, … increase because S2m − S2m−2 = b2m−1 − b2m ≥ 0. They are bounded above by b1. The odd partial sums S1, S3, S5, … decrease and are bounded below by 0. Each list has a limit. Their gap is S2m − S2m−1 = −b2m → 0, so both lists share one limit S. Remainder estimate: if SN is the Nth partial sum, then |S − SN| ≤ bN+1. The error after stopping is no larger than the first omitted size. The sign of S − SN is the sign of the first omitted term. This test does not say Σ bn converges; that separate idea is absolute convergence, covered in Chapter 3.5.

Using the test and reading its limits

Check the three conditions in order: (1) write bn and confirm bn > 0; (2) show bn → 0; (3) show bn decreases, often by comparing bn+1 with bn or by checking the derivative of f(x) with f(n) = bn. A failure of any condition means the test gives no conclusion, not that the series diverges. If bn does not tend to 0, the terms do not tend to 0, so the series diverges by the nth-term test. If bn → 0 but does not decrease, the series may converge or diverge; another test is needed. For example, bn = 1/n for odd n and bn = 1/n² for even n gives bn → 0 but no decrease; the positive odd terms form a divergent harmonic tail, so Σ (−1)n+1 bn diverges. A decrease from some index onward is enough. A finite number of early terms does not affect convergence. Use the remainder bound to stop a computation when bN+1 is below the required tolerance.

Worked example

Question. Test the series Σn=1∞ (−1)n+1 n/(n²+1) for convergence. Also give b1, b10, b100 and f′(2) for f(x) = x/(x²+1), rounded to four decimal places.

  1. The signs alternate because of (−1)n+1. Set bn = n/(n²+1). For n ≥ 1, bn > 0.
  2. Limit: bn = (1/n)/(1+1/n²) → 0 as n → ∞.
  3. Decrease: f′(x) = [(x²+1) − x(2x)]/(x²+1)² = (1−x²)/(x²+1)². For x ≥ 1, 1−x² ≤ 0, so f′(x) ≤ 0. Therefore bn+1 ≤ bn.
  4. The two conditions of the Leibnitz test hold: bn decreases and bn → 0. The series converges.
  5. Numbers: b1 = 1/2 = 0.5000; b10 = 10/101 = 0.0990; b100 = 100/10001 = 0.0100; f′(2) = (1−4)/(4+1)² = −3/25 = −0.1200.

Answer. The series converges by the Leibnitz test, with b1 = 0.5000, b10 = 0.0990, b100 = 0.0100 and f′(2) = −0.1200.

Exam traps

  • Checking only bn → 0. The Leibnitz test also needs bn decreasing; both conditions form the hypothesis.
  • Using bN in the remainder bound instead of bN+1. The first omitted term is bN+1.
  • Treating a failed test as a proof of divergence. The Leibnitz test is sufficient only; if decrease fails, another test may still show convergence.
  • Forgetting bn > 0. If bn carries its own sign, separate the alternating sign before applying the test.
  • Mixing the sign start. (−1)n+1 starts with +, while (−1)n starts with −; a shifted sign changes the remainder sign but not convergence.

3.5 Absolute and conditional convergence

Write Σan for the infinite series with terms an. Ordinary convergence asks whether its partial sums settle at one limit. Absolute convergence asks a stricter question: does the series of sizes Σ|an| converge? The distinction matters because a convergent series can have positive and negative terms cancel, while its sizes may still add to infinity. That weaker case is conditional convergence. The idea is used when rearranging series, in Fourier series, and in numerical work where the order of terms can change the computed sum.

You need: 3.2 for series and partial sums, 3.3 for positive-term tests, and 3.4 for alternating series.

Two definitions and one theorem

Let Σan be a series with real terms an. The series is absolutely convergent when Σ|an| converges. The same series is conditionally convergent when Σan converges but Σ|an| diverges. Some books write “Σan converges absolutely” instead of “Σan is absolutely convergent”. Absolute convergence is stronger: it controls the sizes of all terms, not just their signed sum.

The main theorem: if Σ|an| converges, then Σan converges. Reason: for any tail from m to N, |am+⋯+aN| ≤ |am|+⋯+|aN|. If Σ|an| converges, those positive tails become small, so the partial sums of Σan have a real limit. The converse is false.

Σ|a<sub>n</sub>| converges ⇒ Σa<sub>n</sub> converges

an are real terms; |an| is the absolute value; the arrow means “implies”.

The standard counterexample is the alternating harmonic series Σ(−1)n+1/n. It converges by the Leibnitz test: the sizes 1/n decrease to 0. Its absolute version is the harmonic series Σ1/n, which diverges (p=1). Therefore the alternating harmonic series is convergent but not absolutely convergent, so it is conditionally convergent. Two absolutely convergent examples: Σ1/n² (p=2) and Σ1/2n, which is geometric with ratio 1/2 and so converges. Read Σ1/2n as Σ(1/2)n. The different series Σ1/(2n) is half the harmonic series and diverges.

How to test a signed series

Do not start with the signs. First make every term positive by taking |an|, then apply the tests from 3.3: comparison, integral, ratio or root. If Σ|an| converges, stop: the original Σan is absolutely convergent, and therefore convergent.

  1. Form AN = Σn=1N |an| and decide whether AN has a finite limit using 3.3.
  2. If AN converges, the original series is absolutely convergent. No further sign test is needed.
  3. If AN diverges, the original may still converge. Test Σan itself, often with the alternating test in 3.4 when the signs alternate.
  4. If the original converges and the absolute series diverges, label it conditionally convergent. If the original also diverges, label it divergent.

A p-series Σ1/np converges for p>1 and diverges for p≤1. A shift such as 1/√(n+1) does not change p. Ratio test limit L=1 is inconclusive, so switch to another test; do not guess.

Why the distinction changes answers

For a finite sum, order does not matter: 1−1/2+1/3 and 1/3−1/2+1 are the same. For infinite conditionally convergent series, order can matter. The Riemann rearrangement theorem says: if Σan converges conditionally and S is any real number (or ±∞), then some rearrangement of its terms has sum S. We state it only; the proof belongs with later analysis. Absolutely convergent series are safe: every rearrangement has the same sum.

This is the practical reason to test absolute convergence first. If a series is absolutely convergent, you may regroup and reorder terms as if it were a finite sum. If it is only conditionally convergent, keep the given order unless the problem explicitly asks about rearrangements. The usual alternating harmonic series sums to ln 2, but a rearrangement can change that sum. Power series use absolute convergence inside the radius of convergence; see 3.6.

Worked example

Question. Classify the series Σn=1∞ (−1)n/√(n+1) as absolutely convergent, conditionally convergent, or divergent. Name each test you use and give the p-value of the comparison series.

  1. Set an = (−1)n/√(n+1). Then |an| = 1/√(n+1) = 1/(n+1)1/2.
  2. The absolute series is Σn=1∞ 1/(n+1)1/2. Shift m = n+1 to get Σm=2∞ 1/m1/2. This is a p-series with p = 1/2 = 0.5. Since p ≤ 1, it diverges. Hence the original series is not absolutely convergent.
  3. The original series is alternating because (−1)n flips sign. Put bn = 1/√(n+1) > 0. As n increases, n+1 increases, √(n+1) increases, so bn decreases. Also bn → 0 as n → ∞.
  4. By the Leibnitz test in 3.4, Σan converges. It converges but its absolute series diverges, so it is conditionally convergent.

Answer. The series is conditionally convergent: it converges by the Leibnitz test, but its absolute series has p=1/2=0.5 and diverges.

Exam traps

  • Do not write “convergent” when the question asks “absolutely convergent”. Every absolutely convergent series converges, but the converse fails for Σ(−1)n+1/n.
  • If Σ|an| diverges, the original Σan may still converge. The correct label can be conditionally convergent.
  • Do not apply the alternating series test to Σ|an|; all its terms are positive. Use positive-term tests first.
  • A shift in the index does not change a p-series exponent: Σ1/√(n+1) has p=1/2 and diverges, just like Σ1/√n.
  • Only absolutely convergent series may be rearranged freely. A conditionally convergent series can change its sum under rearrangement.

3.6 Power series and radius of convergence

A power series is an infinite polynomial, Σ cₙ(x−a)ⁿ, where a is a fixed centre and cₙ are fixed coefficients. Put in a value of x and you get a numerical series, which may converge or diverge. The surprise is that the x values that work always form one interval centred at a, and its half-width is the radius of convergence R. Most scientific calculators and numerical libraries compute sin x, eˣ and log x from short polynomial approximations built from these series.

You need: sequences (3.1), series (3.2), the ratio and root tests (3.3), the Leibnitz test (3.4) and absolute convergence (3.5).

Definition and the shape of the convergence set

Fix a real number a, called the centre, and a sequence of real numbers c₀, c₁, c₂, … called the coefficients. The expression Σ cₙ(x−a)ⁿ is a power series in (x−a). The variable is x; a and all the cₙ stay fixed.

Σ_{n=0}^{∞} cₙ(x−a)ⁿ = c₀ + c₁(x−a) + c₂(x−a)² + ⋯

a is the centre; cₙ is the coefficient of (x−a)ⁿ; x is the variable. Some syllabi call the case a = 0 a power series in x.

For example Σ xⁿ/n! has a = 0 and cₙ = 1/n!. Putting x = 2 turns it into the numerical series Σ 2ⁿ/n!, which is judged by the rules of 3.2.

The set of x where it converges has a rigid shape. Suppose the series converges at some point b ≠ a. Then cₙ(b−a)ⁿ → 0, so these terms are bounded: there is M with |cₙ(b−a)ⁿ| ≤ M for every n. Take any x with |x−a| < |b−a| and write r = |x−a|/|b−a|, so 0 ≤ r < 1. Then |cₙ(x−a)ⁿ| ≤ M rⁿ, and Σ M rⁿ is a convergent geometric series. Comparison gives absolute convergence at x.

So convergence at one point drags in every point closer to a, and the convergence set is centred at a: either the single point a, or an interval (a−R, a+R) with either end possibly included, or the whole real line. One number, the radius of convergence R, measures it. R is a distance, so R ≥ 0, and R = ∞ is allowed.

Finding R from the coefficients

Hold x fixed and write uₙ = cₙ(x−a)ⁿ for the nth term. The ratio test of 3.3 compares consecutive terms.

|uₙ₊₁/uₙ| = |cₙ₊₁/cₙ| · |x−a| → L|x−a|

L = lim_{n→∞} |cₙ₊₁/cₙ|, assumed to exist; x ≠ a so that division is allowed.

The ratio test gives absolute convergence when L|x−a| < 1 and divergence when L|x−a| > 1. Read the first condition as |x−a| < 1/L. That half-width is the radius.

R = lim_{n→∞} |cₙ/cₙ₊₁|

R is the radius of convergence; cₙ, cₙ₊₁ are consecutive coefficients. If the limit is 0 then R = 0; if the limit is ∞ then R = ∞.

When this limit fails, or some cₙ are zero, the root test of 3.3 still works.

R = 1 / limsup_{n→∞} |cₙ|^(1/n)

limsup is the largest limit point of the sequence |cₙ|^(1/n); take R = ∞ when it is 0 and R = 0 when it is ∞.

  • Σ n! xⁿ: cₙ = n!, so |cₙ/cₙ₊₁| = 1/(n+1) → 0 and R = 0. Only x = 0 works.
  • Σ xⁿ/n!: |cₙ/cₙ₊₁| = n+1 → ∞, so R = ∞ and every x works.
  • Mind the direction: R = lim |cₙ/cₙ₊₁|, not lim |cₙ₊₁/cₙ|. The flipped limit equals 1/R.

Endpoints and the interval of convergence

For |x−a| < R the series converges absolutely. For |x−a| > R it diverges, and the terms do not even tend to 0. At |x−a| = R the ratio test returns exactly 1, its inconclusive case, so the two endpoints need separate work.

At x = a + R the series becomes the numerical series Σ cₙRⁿ; at x = a − R it becomes Σ cₙ(−R)ⁿ. Test each one on its own, using comparison, the integral test or the Leibnitz test (3.4) and absolute convergence (3.5). Both may converge, both may diverge, or one may do each.

The full answer is the interval of convergence: (a−R, a+R), [a−R, a+R), (a−R, a+R] or [a−R, a+R], depending on the two endpoint verdicts.

Inside R the series defines a function f(x) = Σ cₙ(x−a)ⁿ, and f can be differentiated and integrated term by term; the new series keeps the same R, though its endpoints may move. Taylor's theorem in Unit 1 builds such series for known functions; this chapter runs the other way, from coefficients to the x values that work.

One use: Σ xⁿ/n at the endpoint x = −1 gives −ln 2 ≈ −0.6931, so ln 2 = 1 − 1/2 + 1/3 − ⋯. Calculators evaluate sin, cos and eˣ the same way, with x kept inside a small interval where a few terms are enough.

Worked example

Question. Find the radius of convergence and the interval of convergence of Σ_{n=1}^{∞} xⁿ/n. At x = −1, state the sum of the resulting series.

  1. Identify the centre and coefficients: a = 0, cₙ = 1/n, and the nth term is uₙ = xⁿ/n.
  2. Form the ratio: |uₙ₊₁/uₙ| = (|x|ⁿ⁺¹/(n+1)) ÷ (|x|ⁿ/n) = (n/(n+1))|x|.
  3. Let n → ∞: n/(n+1) → 1, so the limit is |x|. The ratio test gives absolute convergence for |x| < 1 and divergence for |x| > 1. Hence R = 1.
  4. Check with the coefficient formula: R = lim |cₙ/cₙ₊₁| = lim (1/n) ÷ (1/(n+1)) = lim (n+1)/n = 1. Same answer.
  5. Endpoint x = 1: the series becomes Σ 1/n, the harmonic series, which diverges (integral test or comparison).
  6. Endpoint x = −1: the series becomes Σ (−1)ⁿ/n. The sizes bₙ = 1/n decrease to 0, so the Leibnitz test gives convergence. Since Σ 1/n diverges, this convergence is conditional.
  7. Assemble: include −1, exclude 1. The interval of convergence is [−1, 1).
  8. Value at x = −1: Σ (−1)ⁿ/n = −ln 2 ≈ −0.6931, since ln 2 = 1 − 1/2 + 1/3 − ⋯.

Answer. R = 1, the interval of convergence is [−1, 1), and at x = −1 the series sums to −ln 2 ≈ −0.6931.

Exam traps

  • Stopping at R = 1 and writing (−1, 1). The endpoints x = −1 and x = 1 are separate numerical series and can answer differently; here −1 is in and 1 is out.
  • Flipping the coefficient ratio. R = lim |cₙ/cₙ₊₁|; writing lim |cₙ₊₁/cₙ| gives 1/R and a wrong interval.
  • Forgetting the shift. Σ (x−2)ⁿ/3ⁿ has R = 3 and centre 2, so the open interval is (−1, 5), not (−3, 3).
  • Assuming both endpoints behave alike, or that endpoint convergence is absolute. At x = −1 the series Σ (−1)ⁿ/n converges only conditionally, because Σ 1/n diverges.
  • Applying the ratio test to cₙ alone, without the factor |x−a|, and then declaring the whole series convergent instead of finding R.

3.7 Raabe's test and logarithmic test

The ratio test in 3.3 often returns 1 and leaves a positive-term series undecided. Raabe's test breaks that tie by measuring how far the ratio aₙ/aₙ₊₁ sits from 1: it multiplies the gap by n and compares the limit with 1. The logarithmic test does the same comparison on a log scale, reading the growth of 1/aₙ as a power of n. Both are refinements, not replacements. Only a few universities teach these tests; they appear in advanced calculus syllabi.

You need: 3.2 and 3.3; factorial and product notation.

Raabe's test: measuring the gap

The ratio test in 3.3 looks at ρ = lim aₙ₊₁/aₙ. If ρ = 1, it gives no answer. The gap ρ − 1 is too small. Raabe's test multiplies that gap by n, which is large enough to expose the hidden power of n.

Rₙ = n(aₙ/aₙ₊₁ − 1) → L

aₙ > 0 is the nth term; aₙ₊₁ is the next term; Rₙ is the Raabe expression; L is its limit.

If aₙ behaves like C/n^p, then aₙ/aₙ₊₁ = (1+1/n)^p = 1 + p/n + smaller terms. So Rₙ → p. Since Σ1/n^p converges exactly when p > 1, the threshold is L = 1. This is why the test is a refinement, not a replacement.

  1. Check aₙ > 0 and ratio limit 1.
  2. Form aₙ/aₙ₊₁.
  3. Subtract 1 and multiply by n.
  4. Take the limit L.
  5. L > 1: converge; L < 1: diverge; L = 1: no conclusion.

The logarithmic test

The logarithmic test reads the same exponent from a logarithm. Let aₙ > 0 and suppose (log(1/aₙ))/(log n) → L. Here log is natural logarithm. Then Σaₙ converges for L > 1, diverges for L < 1, and is undecided for L = 1.

(log(1/aₙ))/(log n) → L

aₙ is the nth positive term; n is the index; log is natural logarithm; L is the limiting exponent.

Why: if aₙ ≈ C/n^L, then log(1/aₙ) = L log n − log C. Divide by log n: L − (log C)/(log n) → L. The test is handy when log aₙ is a sum, such as a factorial product.

  • L > 1: terms shrink faster than 1/n; converge.
  • L < 1: terms shrink slower than 1/n; diverge.
  • L = 1: no conclusion; use comparison or integral test.

Use Raabe's reciprocal aₙ/aₙ₊₁, never aₙ₊₁/aₙ. Both tests need positive terms. They refine 3.3; for signed series study Σ|aₙ| as in 3.5. The commonest slip is writing the ratio upside down: it turns a divergent example into a false convergent one.

Worked example

Question. Test Σ_{n=1}∞ aₙ, where aₙ = (1·3·5···(2n−1))/(2·4·6···2n).

  1. Write aₙ₊₁ = aₙ · (2n+1)/(2n+2).
  2. So aₙ₊₁/aₙ = (2n+1)/(2n+2) → 1. The ratio test is inconclusive.
  3. Raabe needs the reciprocal: aₙ/aₙ₊₁ = (2n+2)/(2n+1).
  4. Subtract 1: (2n+2)/(2n+1) − 1 = 1/(2n+1).
  5. Multiply by n: Rₙ = n/(2n+1).
  6. Limit: Rₙ = 1/(2+1/n) → 1/2.
  7. L = 1/2 < 1, so the series diverges.

Answer. The series diverges by Raabe's test, because L = 1/2 < 1.

Exam traps

  • Writing aₙ₊₁/aₙ in Raabe. Use aₙ/aₙ₊₁; the reciprocal can reverse the conclusion.
  • Forgetting to subtract 1 before multiplying by n.
  • Treating L = 1 as convergence. It is no conclusion.
  • Using Raabe on a series with negative terms without checking positivity.
  • In the log test, using log aₙ instead of log(1/aₙ); this flips the sign of L.

3.8 Cauchy sequences and completeness of real numbers

A Cauchy sequence is a list of real numbers whose terms become close to each other, not necessarily close to a known limit. The idea exists because many convergence proofs need a test that does not name the limit. In ℝ, every Cauchy sequence has a real limit; this is completeness. Only a few universities teach this topic. Numerical methods and series tests use it to prove that approximations settle down.

You need: convergence of sequences from 3.1, series and partial sums from 3.2, and absolute value inequalities.

The Cauchy condition

The definition asks the terms to crowd together. For every real ε > 0 there is an integer N such that |a_m − a_n| < ε for all m, n ≥ N. Here ε is the allowed gap; N depends only on ε, never on m or n. The sequence is a_n, and |x| is absolute value.

Every convergent sequence is Cauchy. If a_n → L, choose N so |a_n − L| < ε/2 for n ≥ N. For m, n ≥ N, the triangle inequality gives |a_m − a_n| ≤ |a_m − L| + |L − a_n| < ε/2 + ε/2 = ε.

The converse is deeper. In ℝ it is true: every Cauchy sequence converges. In ℚ it can fail, as Section 2 shows. The Cauchy condition is limit-free, but it certifies convergence only when the space has no gaps.

Completeness and the rational gap

Completeness of ℝ has an equivalent form: every nonempty set of real numbers bounded above has a least upper bound, called the supremum. The supremum is the smallest real number ≥ every element. This property fills all gaps in the line.

The Archimedean property follows: for every real x there is a natural number n with n > x. It lets 1/n be made smaller than any chosen ε. For example, to force 2/N < ε = 0.01, you need N > 200.

The rationals ℚ have gaps. Decimal truncations of √2, such as 1.4, 1.41, 1.414, …, are rational and Cauchy, but their limit √2 is irrational. So they have no limit in ℚ.

The Cauchy criterion for series: Σ a_n converges if and only if its partial sums are Cauchy. Equivalently, for every ε > 0 there is N such that |a_{N+1} + … + a_m| < ε for all m > N. This tests a series without finding its sum.

Worked example

Question. Show that a_n = 1/n is Cauchy. For ε = 0.01, find an N that satisfies the definition, and verify the bound at that N.

  1. Take m, n ≥ N with N a positive integer. Since m, n ≥ N > 0, 1/m ≤ 1/N and 1/n ≤ 1/N.
  2. By the triangle inequality, |1/m − 1/n| ≤ 1/m + 1/n ≤ 1/N + 1/N = 2/N.
  3. Need 2/N < ε = 0.01, that is N > 200.
  4. Take N = 201, the smallest integer greater than 200. Then 2/N = 2/201 ≈ 0.00995 < 0.01.
  5. For all m, n ≥ 201, |1/m − 1/n| ≤ 2/201 < 0.01. Hence a_n is Cauchy; in ℝ it converges to 0.

Answer. The choice N = 201 makes |1/m − 1/n| ≤ 2/201 ≈ 0.00995 < 0.01 for all m, n ≥ 201, so a_n = 1/n is Cauchy.

Exam traps

  • Saying Cauchy implies convergence in every ordered field. It fails in ℚ; completeness is a property of ℝ.
  • Choosing N after seeing m and n. N may depend on ε only and must work for all m, n ≥ N.
  • Confusing the series Cauchy criterion with the term test. Terms tending to 0 is necessary, not sufficient.
  • Claiming the rational truncations of √2 converge in ℚ. They converge in ℝ to irrational √2.

Beyond the syllabus

Not for the exam. The same idea defines complete metric spaces and Banach spaces in functional analysis. Numerical analysis uses Cauchy sequences to prove iterative methods settle even when the limit is unknown. Takeaways

  1. A sequence converges when its terms eventually enter and stay inside every band around the limit.
  2. An infinite series is not a sum done at once; it is the limit of its partial sums.
  3. The comparison, integral, ratio and root tests all reduce a new series to a known or simpler one.
  4. When signs alternate and sizes fall to zero, the alternating series test gives convergence.
  5. Absolute convergence is stronger than ordinary convergence and permits rearrangement.
  6. A power series converges on a symmetric interval around its centre, with endpoint behaviour decided separately.
  7. Raabe's and logarithmic tests are refinements for the case where the ratio test is inconclusive.
  8. The completeness of R says Cauchy sequences have real limits; the rationals do not have this property.

Glossary

Absolute convergence
The convergence of Σ|aₙ|.
Alternating series
A series whose successive terms have opposite signs.
Bounded sequence
A sequence whose terms all lie between two fixed real numbers.
Cauchy sequence
A sequence whose terms become arbitrarily close to one another for large indices.
Comparison test
A test that decides series convergence by comparing terms with a known series.
Completeness
The property that every Cauchy sequence in a space has a limit in that space.
Conditional convergence
Convergence of Σaₙ together with divergence of Σ|aₙ|.
Convergent sequence
A sequence that has a finite real limit.
Divergent sequence
A sequence that does not converge to a finite real limit.
Geometric series
A series Σarⁿ, convergent when |r| < 1.
Harmonic series
The divergent series Σ1/n.
Integral test
A test comparing Σf(n) with an improper integral of f.
Interval of convergence
The set of x values for which a power series converges, including any convergent endpoints.
Leibnitz test
A test for alternating series whose term sizes decrease to zero.
Logarithmic test
A refinement using the limit of n log(aₙ/aₙ₊₁) when the ratio test is inconclusive.
Monotone sequence
A sequence that is either nondecreasing or nonincreasing.
p-series
A series Σ1/nᵖ, convergent when p > 1 and divergent when p ≤ 1.
Partial sum
The finite sum Sₙ = a₁ + a₂ + … + aₙ.
Power series
A series Σcₙ(x − a)ⁿ in powers of x − a.
Raabe's test
A refinement using the limit of n(aₙ/aₙ₊₁ − 1) when the ratio test is inconclusive.
Radius of convergence
The largest R such that a power series converges for |x − a| < R.
Ratio test
A test using the limit of |aₙ₊₁/aₙ|.
Root test
A test using the limit of |aₙ|^(1/n).
Sequence
A function from the natural numbers to the real numbers, written a₁, a₂, a₃, ….
Series
An expression Σaₙ formed from the terms of a sequence.
