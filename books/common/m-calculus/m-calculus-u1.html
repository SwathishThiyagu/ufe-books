1.1 Functions, graphs and new functions from old

A function is a rule that gives exactly one output for each allowed input. Its graph turns that rule into a picture, so you can see where it rises, falls, or repeats. Engineers read such pictures before they trust a formula: a voltage curve, a cost curve, a sensor reading. New functions often come from old ones by shifting, stretching, reflecting, composing, or inverting. This chapter builds that vocabulary and the habits for reading a graph, not just a formula.

A function gives one output per input

Function. A function f from a set A to a set B assigns exactly one element f(x) in B to each x in A. The set A is the domain: the allowed inputs. The set of actual values f(x) is the range. The codomain B is the declared output set; the range may be smaller.

Graph. The graph of f is the set of points (x, f(x)) in the xy-plane. Read x along the horizontal axis and y along the vertical axis. A curve is the graph of a function if every vertical line meets it at most once. This is the vertical line test. A circle fails it.

Piecewise and standard functions. A piecewise function uses different formulas on different parts of its domain. The absolute value |x| equals x for x≥0 and −x for x<0. Standard building blocks include constant, linear, quadratic, polynomial, rational, square-root, trigonometric, exponential and logarithmic functions.

Why it exists. Many engineering quantities depend on another quantity: cost depends on units produced, voltage on time, distance on speed. A function records that dependence in a form you can calculate and draw.

Shifts, stretches and reflections

Start with y=f(x). Each change below makes a new function.

  • y=f(x)+k: move up k when k>0, down when k<0.
  • y=f(x−h): move right h when h>0, left when h<0. Inside changes act opposite to the sign.
  • y=a f(x): vertical stretch by |a|. If a<0, reflect about the x-axis.
  • y=f(bx): horizontal compression by 1/|b| when |b|>1, stretch when 0<|b|<1. If b<0, reflect about the y-axis.

y = a f(b(x − h)) + k

y is the output; x is the input; a is the vertical stretch factor; b is the horizontal scale factor; h is the horizontal shift; k is the vertical shift.

For y=a f(b(x−h))+k, apply the inside changes (b and h) before the outside changes (a and k). A common error is to shift before scaling when the formula has b outside. Example: y=2(x−3)²+4 is x² shifted right 3, stretched vertically by 2, then shifted up 4. Its vertex is (3,4).

The derivative in 1.3 is another way to build a new function from an old one.

Composition and inverse

Composition. The composition (f∘g)(x)=f(g(x)) works from inside out. The domain needs x in the domain of g, and g(x) in the domain of f. Example: f(x)=√x and g(x)=x−3 give (f∘g)(x)=√(x−3), with domain x≥3.

Inverse. If f is one-to-one, its inverse f⁻¹ satisfies f⁻¹(f(x))=x and f(f⁻¹(y))=y. The graph of f⁻¹ is the reflection of the graph of f in the line y=x. Domain and range swap. f⁻¹(x) is not 1/f(x). f(x)=x² on x≥0 has inverse f⁻¹(x)=√x; on all real x it has no inverse because f(2)=f(−2).

Worked example

Question. Let f(x)=x². For y=f(x−2)+1, state the transformation, the vertex, the domain and the range. Sketch the graph.

  1. Start with f(x)=x². Its vertex is (0,0); domain is all real x; range is [0,∞).
  2. Replace x by x−2: f(x−2)=(x−2)². At x=2 this gives 0, the old value at x=0, so the graph moves right by 2 units.
  3. Add 1: y=(x−2)²+1. Every output rises by 1, so the graph moves up by 1 unit.
  4. Vertex: (0,0) moves right 2 and up 1, giving (2,1). The parabola opens upward.
  5. Domain: no new restriction, so all real x. Range: (x−2)²≥0, so y≥1; in interval form [1,∞).
  6. Check points: x=1 and x=3 give y=2; x=0 gives y=5. Sketch through these points with vertex (2,1).

Answer. The graph is y=x² moved 2 units right and 1 unit up; vertex (2,1); domain = all real numbers; range = [1,∞).

Exam traps

  • f(x−2) moves the graph right by 2; f(x+2) moves it left by 2. Inside changes act opposite to the sign.
  • f⁻¹(x) is the inverse function, not 1/f(x). The reciprocal is a different function.
  • A circle is not the graph of a function because a vertical line can meet it twice. Use the vertical line test before finding domain or range.
  • For composition f(g(x)), x must be in the domain of g, and g(x) must be in the domain of f. Both conditions are needed.
  • The examiner's favourite question is to compare y=f(x−2) with y=f(x)+2: one moves right, the other moves up.

1.2 Limit of a function and continuity

A limit answers a narrow question: as x gets close to a number a, what value does f(x) get close to? The function may never reach that value, or may not even be defined at a. Continuity turns this into a stronger promise: the graph has no break, jump or hole at a. Limits are the base of the derivative, of numerical tolerances in code, and of every smooth curve in physics and engineering.

You need Chapter 1.1: reading a graph, domain and range, and piecewise definitions.

One-sided and two-sided limits

Write limx→a f(x) = L. Read it: the limit of f(x) as x tends to a equals L. L is the single real number that f(x) approaches when x is close to a but not equal to a. The point a itself is excluded.

The left limit limx→a⁻ f(x) uses x < a. The right limit limx→a⁺ f(x) uses x > a. A two-sided limit exists exactly when both one-sided limits exist and are equal.

lim<sub>x→a</sub> f(x) = L ⇔ lim<sub>x→a⁻</sub> f(x) = L and lim<sub>x→a⁺</sub> f(x) = L

L is the common one-sided value; ⇔ means if and only if; a is the point being approached.

Limit notation ignores the value at a. A function can have a limit at a point where it is undefined. The figure shows a jump: the left branch ends at y = 1, while the right branch starts at y = 3.

Limit laws and limits at infinity

Limit laws split a complicated limit into simple ones. They hold when every limit on the right side exists as a real number.

  • Sum: lim(f + g) = lim f + lim g.
  • Constant multiple: lim(cf) = c lim f.
  • Product: lim(fg) = (lim f)(lim g).
  • Quotient: lim(f/g) = (lim f)/(lim g), if lim g ≠ 0.
  • Power: lim(fn) = (lim f)n, and similarly for roots where defined.

For a polynomial p(x), direct substitution works: limx→a p(x) = p(a). For a rational function, substitute if the denominator is not zero. If you get 0/0, factor or simplify first; see Chapter 1.6.

At infinity, limx→∞ 1/x = 0 and limx→−∞ 1/x = 0. For a rational function, divide numerator and denominator by the highest power of x in the denominator. The limit is the ratio of leading coefficients if the degrees match, 0 if the denominator degree is larger, and unbounded if the numerator degree is larger. If limx→∞ f(x) = L, the line y = L is a horizontal asymptote.

An infinite limit such as limx→0⁺ 1/x = ∞ means 1/x grows without bound. The symbol ∞ is not a real limit value. The line x = 0 is a vertical asymptote.

For a bounded function near a, the limit superior is the largest value approached and the limit inferior the smallest. A limit exists exactly when these two are equal. Sequences use the same idea; see Unit 3, Sequences and Infinite Series.

Continuity at a point and on an interval

A function f is continuous at x = a when three conditions hold.

  1. f(a) is defined.
  2. limx→a f(x) exists, so the two one-sided limits agree.
  3. limx→a f(x) = f(a).

If any condition fails, f is discontinuous at a. Continuity on an open interval (p, q) means continuity at every point inside. On a closed interval [p, q], also require the one-sided limits at the endpoints to match the endpoint values: limx→p⁺ f(x) = f(p) and limx→q⁻ f(x) = f(q).

Polynomials are continuous everywhere. Rational functions are continuous wherever the denominator is not zero. sin x and cos x are continuous everywhere, and ex is continuous everywhere.

  • Removable discontinuity: the limit exists, but f(a) is missing or different. The graph has a hole.
  • Jump discontinuity: the one-sided limits exist but differ. The graph breaks vertically.
  • Infinite discontinuity: f(x) grows without bound near a. The graph has a vertical asymptote.

Continuity is necessary for differentiability but not sufficient: |x| is continuous at 0 and not differentiable there. See Chapter 1.3.

Worked example

Question. Let f(x) = x² for x < 1 and f(x) = 3 for x ≥ 1. Find limx→1⁻ f(x), limx→1⁺ f(x), and f(1). Does limx→1 f(x) exist? Is f continuous at x = 1?

  1. For x < 1 use f(x) = x². As x→1 from the left, x²→1² = 1. The left limit is 1.
  2. For x > 1 use f(x) = 3. The constant 3 does not change, so the right limit is 3.
  3. The one-sided limits are 1 and 3. They are not equal, so the two-sided limit limx→1 f(x) does not exist.
  4. At x = 1 the rule x ≥ 1 applies, so f(1) = 3.
  5. Continuity at x = 1 needs the two-sided limit to exist and equal f(1). The limit does not exist, so f is not continuous at x = 1. This is a jump discontinuity.

Answer. Left limit = 1, right limit = 3, f(1) = 3, the two-sided limit does not exist, and f is not continuous at x = 1 (jump discontinuity).

Exam traps

  • A limit can exist where f(a) is undefined. Do not plug in a first and declare the limit missing; look at nearby values.
  • Do not write lim f(x) = ∞ and then treat ∞ as a number. It only says f(x) grows without bound; the limit as a real number does not exist.
  • For a piecewise function, the branch with ≥ or ≤ gives f(a), but each one-sided limit uses x < a or x > a, not the value at a.
  • Cancelling (x − a) in a ratio changes the domain at x = a. The simplified expression is valid only for x ≠ a; the limit can still exist.

1.3 Derivative as a function and differentiability

A derivative is a new function. At each input x it returns the slope of the graph of f at that point, or the instantaneous rate of change of f. It exists only when the limit of a difference quotient exists. This idea turns a curve into a slope machine: speed from distance, marginal cost from total cost, and a tangent line from a graph. Engineers use it to find best values of settings, and analysts use it to read rates in data.

You need function notation and graphs from Chapter 1.1 and limits and continuity from Chapter 1.2.

From difference quotient to f′(x)

Fix a point x. Move a small distance h to x+h. The average slope between the two points on y=f(x) is the difference quotient. It is rise divided by run:

Q(h) = [f(x+h) − f(x)] / h, h ≠ 0

Q(h) is the average slope over [x, x+h]; h is a nonzero change in input; f(x+h)−f(x) is the change in output.

Let h shrink toward 0. If Q(h) has a limit, that limit is the derivative at x and is written f′(x). The derivative as a function assigns this value to every x where the limit exists.

f′(x) = limh→0 [f(x+h) − f(x)] / h

f′(x) is the derivative function; x is an input in its domain; h is the input change tending to 0.

Other notation: y′ and dy/dx. In dy/dx, dy and dx are not separate ordinary numbers; the symbol means the same limit, read as the derivative of y with respect to x. The value at a single point a is f′(a), a number. As x varies, f′(x) is a new function. The tangent at a is y−f(a)=f′(a)(x−a).

Differentiability and continuity

A function is differentiable at a if f′(a) exists. It is differentiable on an interval if it is differentiable at every point of the interval. Differentiability is local: it depends on behaviour close to a.

If f is differentiable at a, then f is continuous at a. Reason: write f(a+h)−f(a)=([f(a+h)−f(a)]/h)h. As h→0, the bracket tends to f′(a) and h tends to 0, so f(a+h)→f(a).

The converse fails. The absolute value f(x)=|x| is continuous at 0 but not differentiable there. For h>0, [|0+h|−|0|]/h=h/h=1. For h<0, it is (−h)/h=−1. The left and right limits differ, so the limit does not exist. The graph has a corner at x=0.

A cusp is a sharper corner where slopes run to opposite infinities; y=x2/3 at x=0 is one. A jump, a hole, or a vertical tangent also blocks a finite derivative. A function can be continuous everywhere yet fail at one point. For two or three variables, differentiability is stronger and needs a linear approximation; see Unit 4, Functions of Several Variables.

Worked example

Question. For f(x)=x², use the difference quotient to find f′(3). Then write the tangent line at x=3.

  1. At x=3, form Q(h)=[f(3+h)−f(3)]/h with h≠0.

Exam traps

  • Differentiable implies continuous, not the reverse: |x| at 0 is continuous but has no derivative.
  • f′(a) is a number at one point; f′(x) is a function. Do not mix the value with the rule.
  • dy/dx is one symbol, not a fraction of two ordinary numbers; do not cancel dx.
  • A corner or cusp gives no derivative; a vertical tangent also gives no finite derivative.
  • In the chain rule, multiply by the inner derivative; leaving out g′(x) is the commonest error.

1.4 Rolle's theorem and mean value theorems

A smooth curve that starts and ends at the same height must turn at least once. Rolle's theorem makes that statement exact. The mean value theorem goes further: somewhere the tangent is parallel to the chord joining the endpoints. These two theorems turn average change into a statement about an instantaneous derivative. They are used to prove Taylor's theorem and many error bounds. In exams they appear as short verification questions: check the hypotheses, compute the derivative, solve for the point c.

You need continuity on a closed interval and differentiability on an open interval from Chapters 1.2 and 1.3.

Rolle's theorem

Let f be continuous on the closed interval [a,b] and differentiable on the open interval (a,b). Suppose f(a)=f(b). Then some c in (a,b) satisfies f′(c)=0. Here a and b are the endpoints, c is an interior point, and f′ is the derivative from Chapter 1.3.

Why it is true: a continuous f on [a,b] has a highest and a lowest value. If f is constant, every c works. Otherwise, since f(a)=f(b), at least one of the highest and lowest values is attained at an interior point c of (a,b). At that interior maximum or minimum, the graph has a horizontal tangent, so f′(c)=0. This is the same critical-point idea used later in maxima and minima (Chapter 1.7).

Geometric meaning: the endpoints are at the same height, so the chord is horizontal. The graph must flatten somewhere between them. The tangent at c is parallel to that chord.

Rolle is a test for a zero derivative, not a method for finding every zero. There may be more than one c. The theorem says at least one exists.

The hypotheses matter. For f(x)=|x| on [−1,1], f(−1)=f(1)=1 and f is continuous, but f is not differentiable at 0. No c has f′(c)=0: the derivative is −1 on the left and +1 on the right. So the conclusion can fail when differentiability fails.

The mean value theorem

Mean value theorem (Lagrange form). Let f be continuous on [a,b] and differentiable on (a,b). Then some c in (a,b) satisfies f′(c) = (f(b) − f(a))/(b − a). The numerator is the change in f; the denominator is the length b−a; the right side is the average slope from a to b.

f′(c) = (f(b) − f(a)) / (b − a)

c is an interior point in (a,b); f(b)−f(a) is the change in f; b−a is the interval length; the right side is the average slope.

Geometric meaning: draw the chord from (a,f(a)) to (b,f(b)). Its slope is the average slope. At c the tangent is parallel to this chord. Rolle is the special case f(a)=f(b): then the average slope is 0, so f′(c)=0.

Proof idea: define g(x)=f(x) − [f(a)+m(x−a)], where m=(f(b)−f(a))/(b−a). This g is the vertical gap between f and the chord. It is continuous on [a,b], differentiable on (a,b), and g(a)=g(b)=0. Rolle gives c with g′(c)=0. Since g′(x)=f′(x)−m, we get f′(c)=m.

Use: a car covers 120 km in 2 hours, so the average speed is 60 km/h. If its speed varies smoothly, the mean value theorem says that at some instant the speedometer reads exactly 60 km/h. The point c need not be unique, and it need not be the midpoint.

MVT converts information about average change into information about an instantaneous derivative. It is the engine behind error bounds and Taylor's theorem (Chapter 1.5).

Checking a mean value question

Follow the hypotheses before solving for c. The order matters in an exam.

  1. Step 1: Write a and b, and name f.
  2. Step 2: Check continuity on [a,b]. Polynomials, sin x, cos x and e^x are continuous everywhere. A quotient needs its denominator nonzero on the interval.
  3. Step 3: Check differentiability on (a,b). Points with corners, cusps or vertical tangents break it.
  4. Step 4: For Rolle, check f(a)=f(b). If they differ, Rolle does not apply; use MVT instead.
  5. Step 5: Compute f′(x).
  6. Step 6: For Rolle solve f′(c)=0. For MVT solve f′(c)=(f(b)−f(a))/(b−a).
  7. Step 7: Keep only solutions with a<c<b. Endpoints are not allowed.

Finding c needs f′(c), not f(c). A common mistake is to solve f(c)=0. That gives an x-intercept, not a horizontal tangent.

Polynomials are the easy case: they are continuous and differentiable everywhere, so only the endpoint condition for Rolle needs checking. For f(x)=x on [0,1], Rolle fails because f(0)=0 and f(1)=1 differ. MVT still holds: f′(x)=1, average slope is 1, so every c in (0,1) works.

Worked example

Question. Verify Rolle's theorem for f(x)=x²−2x on [0,2] and find the value c.

  1. a=0 and b=2. f is a polynomial, so it is continuous on [0,2] and differentiable on (0,2).
  2. f(0)=0²−2·0=0.
  3. f(2)=2²−2·2=4−4=0. The endpoint values are equal.
  4. f′(x)=2x−2.
  5. Set f′(c)=0: 2c−2=0, so 2c=2 and c=1.
  6. c=1 lies in (0,2). Rolle's theorem is verified.

Answer. The Rolle point is c=1; it has no units.

Exam traps

  • Applying Rolle without checking f(a)=f(b). Equal endpoints are a hypothesis, not an optional detail.
  • Solving f(c)=0 instead of f′(c)=0. Rolle needs a horizontal tangent, not an x-intercept.
  • Keeping a root at c=a or c=b. The theorem requires c in the open interval (a,b).
  • Assuming c is unique. Rolle and MVT guarantee at least one point, not exactly one.
  • For MVT, writing f′(c)=f(b)−f(a) and forgetting to divide by b−a.

1.5 Taylor's and Maclaurin's theorems for one variable

Taylor's theorem replaces a smooth function near a point by a polynomial plus a small error term. The polynomial is built from the function's derivatives at that point, so a computer can evaluate e0.1, sin 0.2 or log 1.05 using only addition and multiplication. Engineers use it for linearisation, error control in numerical software, and small-angle approximations in physics. Maclaurin's theorem is the special case where the centre is zero. The remainder tells how wrong the polynomial is.

You need derivatives and the mean value theorems from Chapter 1.3 and Chapter 1.4.

Taylor polynomial at a point

Choose a centre a and a whole number n. The Taylor polynomial of degree n at a uses the value and the first n derivatives of f at a. It is the best polynomial of that degree for matching f close to a.

P<sub>n</sub>(x) = Σ<sub>k=0</sub><sup>n</sup> [f<sup>(k)</sup>(a) / k!] (x − a)<sup>k</sup>

Pn(x) is the Taylor polynomial; f(k)(a) is the k-th derivative of f at a, with f(0)(a) = f(a); k! = 1×2×…×k and 0! = 1; a is the centre; x is the point near a.

The theorem writes f(x) = Pn(x) + Rn(x). The remainder Rn(x) is the error left after the polynomial. When a = 0 the polynomial is called the Maclaurin polynomial. For example, the degree 2 Maclaurin polynomial of ex is 1 + x + x²/2.

  • P1 matches value and slope at a: the tangent line.
  • P2 also matches curvature at a.
  • Higher n matches more derivatives, so the error usually shrinks near a.

Lagrange remainder and error bounds

The Lagrange form of the remainder gives the error as one extra derivative evaluated at an unknown point c. You do not need the exact c. You bound the derivative over the interval between a and x.

R<sub>n</sub>(x) = [f<sup>(n+1)</sup>(c) / (n+1)!] (x − a)<sup>n+1</sup>

c is some point between a and x; f(n+1)(c) is the next derivative after the polynomial's last derivative; (n+1)! is the factorial of n+1; |x − a| is the distance from the centre.

To bound the error, find the largest possible |f(n+1)(c)| on that interval, call it M. Then |Rn(x)| ≤ M |x − a|n+1 / (n+1)!.

  1. Identify f, a, n and x.
  2. Write the Lagrange remainder using c between a and x.
  3. Bound the next derivative on that interval by a number M.
  4. Substitute M, |x − a| and (n+1)! into the bound.

Standard Maclaurin expansions

These expansions are worth memorising for small x. The factorial grows fast, so low-degree polynomials often give good accuracy near zero. Signs alternate in sin, cos and log(1+x).

For small x, sin x ≈ x and cos x ≈ 1 − x²/2. These are the small-angle approximations used in pendulums and AC circuit phasors.

Worked example

Question. Use the Maclaurin polynomial of degree 2 for ex to approximate e0.1. Give the Lagrange remainder bound for the error.

Exam traps

  • Using derivatives at x instead of at the centre a. The polynomial is built at a and then evaluated at x.
  • Forgetting the factorial: the coefficient is f(k)(a)/k!, not f(k)(a).
  • Sign slips in sin, cos and log(1+x). Check the first two or three terms.
  • Treating the remainder as zero. The remainder is not zero in general; it is identically zero only when f is a polynomial of degree at most n.
  • In the error bound, using xn+1 instead of |x−a|n+1 when the centre is not zero.

1.6 Indeterminate forms and L'Hôpital's rule

Some limits put a zero or an infinity in both the top and bottom of a fraction. The value is not visible from the fraction alone. L'Hôpital's rule replaces the fraction by one built from derivatives. It turns a hard limit into an easier limit, but only after you check the form. Use it for limits in physics, economics and engineering models. Only a few universities teach it in first-year calculus.

You need: limits and continuity from Chapter 1.2 and derivatives from Chapter 1.3.

Check the form first

An indeterminate form is a limit shape that does not decide the answer. The core forms are 0/0 and ∞/∞. The same shape can hide different limits: x/x² grows without bound as x→0⁺, x²/x → 0 and 3x/x → 3 as x→0. The form is only a signal to work further.

lim<sub>x→a</sub> f(x)/g(x) = lim<sub>x→a</sub> f′(x)/g′(x)

f and g are differentiable near a, g′(x) ≠ 0 near a, the left side has form 0/0 or ∞/∞, and the right-side limit exists or is ±∞.

Do not use the rule on 2/0, 3/7 or 5/∞. These are not indeterminate. Differentiate top and bottom separately, not the whole quotient.

Convert other forms

Other forms need conversion: 0·∞, ∞−∞, 1∞, 00 and ∞0. For 0·∞ write fg = f/(1/g). For ∞−∞ combine into one fraction. For powers set y = fg, take ln y = g ln f, find that limit, then exponentiate.

  1. Write the limit as y.
  2. Take ln y and simplify to a fraction.
  3. Apply L'Hôpital to the fraction.
  4. Exponentiate: limit y = elimit ln y.

Repeat, then stop

After one use the new fraction may still be 0/0 or ∞/∞. Check again and repeat if needed. Stop when the form is no longer indeterminate, or when the new limit is worse.

A loop example: limx→∞ x/√(x²+1). It is ∞/∞. One use gives √(x²+1)/x, still ∞/∞. Another returns x/√(x²+1), the original. The rule cycles. Divide top and bottom by x instead: 1/√(1+1/x²) → 1.

A failure example: limx→∞ (x+sin x)/x. This is ∞/∞. Derivatives give (1+cos x)/1, which has no limit as x→∞. The original limit is 1. The rule's condition is not met: the derivative ratio must have a limit.

Worked example

Question. Find limx→0 (1−cos x)/x² using L'Hôpital's rule.

  1. At x = 0, top = 1−cos 0 = 1−1 = 0 and bottom = 0² = 0, so the form is 0/0. The rule can be used.
  2. Differentiate top: d/dx(1−cos x) = sin x. Differentiate bottom: d/dx(x²) = 2x. The new limit is limx→0 sin x/(2x).
  3. At x = 0 this is 0/0 again. Use the rule again: derivative of sin x is cos x; derivative of 2x is 2. New limit is limx→0 cos x/2.
  4. At x = 0, cos 0 = 1, so the limit is 1/2 = 0.5.

Answer. The limit is 1/2, or 0.5.

Exam traps

  • Applying the rule to a non-indeterminate form such as 2/0 or 3/7; the rule is invalid there.
  • Differentiating the whole quotient with the quotient rule; differentiate numerator and denominator separately.
  • For 0·∞ or powers, forgetting the conversion or the final exponentiation.
  • Continuing when the derivative ratio has no limit or returns to the original form; the rule then gives no answer.

1.7 Maxima and minima of functions of one variable

The derivative measures slope. Where a smooth graph turns from rising to falling, the slope is zero. Setting f′(x)=0 and testing the sign change locates local maxima and minima. On a closed interval, the endpoints can beat every interior peak, so they must be checked too. This finds the cheapest order size, the strongest beam, the peak of a profit curve. Only a few universities teach this as a separate topic; most fold it into derivative applications.

You need derivatives (Chapter 1.3) and the mean value theorem (Chapter 1.4).

Critical points and the first derivative test

A function f has a local maximum at c if f(c) ≥ f(x) for every x near c. It has a local minimum at c if f(c) ≤ f(x) near c. The word local means 'in a small neighbourhood'; an absolute maximum on a set S satisfies f(c) ≥ f(x) for all x in S. A critical point is a number c in the domain where f′(c)=0 or f′(c) does not exist. Extrema can occur only at critical points or at endpoints.

The first derivative test: if f′ changes from positive to negative at c, f has a local maximum there; from negative to positive, a local minimum; if the sign does not change, no extremum. Example: f(x)=x³ has f′(0)=0 but f′ is positive on both sides, so x=0 is not an extremum.

Second derivative test and absolute extrema

Suppose f′ and f″ exist at c and f′(c)=0. If f″(c)>0, then c is a local minimum. If f″(c)<0, then c is a local maximum. If f″(c)=0 the test is inconclusive; use the first derivative test.

To find the absolute maximum and minimum of a continuous f on a closed interval [a,b]:

  1. Find f′ and solve f′(x)=0 for critical points inside (a,b).
  2. Evaluate f at each critical point.
  3. Evaluate f at the endpoints a and b.
  4. The largest value is the absolute maximum, the smallest the absolute minimum.

On a closed interval [a,b] a continuous function attains both an absolute maximum and an absolute minimum. These may occur at interior critical points or at the endpoints.

Worked example

Question. Find and classify the local extrema of f(x)=x³−3x on [−2,2], then give the absolute maximum and minimum on that interval.

  1. Differentiate: f′(x)=3x²−3=3(x²−1).
  2. Solve f′(x)=0: x²=1, so x=1 and x=−1. Both lie inside (−2,2).
  3. Second derivative: f″(x)=6x. At x=−1, f″(−1)=−6<0, so x=−1 is a local maximum.
  4. At x=1, f″(1)=6>0, so x=1 is a local minimum.
  5. Values: f(−1)=−1+3=2 and f(1)=1−3=−2.
  6. Endpoints: f(−2)=−8+6=−2 and f(2)=8−6=2.
  7. Compare values 2, −2, −2, 2: absolute maximum is 2 at x=−1 and x=2; absolute minimum is −2 at x=−2 and x=1.

  • The sign of f′ must change. A zero derivative alone is not enough.
  • On a closed interval, always check the endpoints; they can be the absolute extrema.
  • f″(c)=0 is inconclusive, not a saddle point. Fall back to the first derivative test.
  • A local maximum need not be the absolute maximum on the whole interval.

1.8 Shape of a graph: concavity and points of inflection

The first derivative gives slope. The second derivative gives how slope changes, so it tells whether a curve bends upward (concave up) or downward (concave down). A point where the bending changes is an inflection point. Engineers use this to read shapes: a UPI transaction curve that steepens, a stress–strain curve that turns over, a cost curve whose growth slows then speeds up. Only a few universities teach this as a separate topic; it is advanced but short.

You need: the second derivative from Chapter 1.3, and the second derivative test from Chapter 1.7.

What concavity means

On an interval, f is concave up when the slope f′ increases as x moves right. The curve holds water like a cup. f is concave down when f′ decreases; the curve spills water like a cap. Here f″ is the derivative of f′.

f″(x) > 0 → concave up, f″(x) < 0 → concave down

f″ is the second derivative; the sign is tested on an open interval.

The standard definition is that f′ increases across the interval. Checking f″(x) > 0 at every interior point is a convenient sufficient test: isolated points where f″ = 0 do not break concavity. For f = x⁴, f″ = 12x² is zero at x = 0, yet the curve is concave up everywhere.

A straight line has f″ = 0 everywhere, so the second-derivative test says nothing. Under the f′-increasing definition it counts as both concave up and concave down, and it has no inflection point. For y = x², f″ = 2 > 0, so it is concave up everywhere. For y = −x², f″ = −2 < 0, so it is concave down everywhere. For y = x³ − 6x² + 9x, f″ = 6x − 12, negative for x < 2 and positive for x > 2; the bending changes at x = 2.

Finding inflection points

An inflection point is a point on the graph where concavity changes from up to down or down to up. At that point the curve crosses its tangent nearby.

  1. Compute f″(x).
  2. Solve f″(x) = 0 and list points where f″ is undefined.
  3. Test the sign of f″ on each side of each candidate.
  4. If the sign changes, it is an inflection point; if not, it is not.

For f = x³, f″ = 6x, so x = 0 is an inflection point: f″ changes sign. For f = x⁴, f″ = 12x², so f″(0) = 0 but f″ ≥ 0 on both sides; (0, 0) is not an inflection point. The figure shows x³ − 6x² + 9x: f″ = 6x − 12 changes sign at x = 2. A vertical tangent or cusp can also change shape, so check the graph and the domain, not only f″ = 0.

Link to the second derivative test

At a critical point c, f′(c) = 0. If f″(c) > 0, the graph is concave up, so c is a local minimum. If f″(c) < 0, the graph is concave down, so c is a local maximum. If f″(c) = 0, the test fails; use the first derivative test from Chapter 1.7.

For the cubic, f′(x) = 3x² − 12x + 9 = 3(x − 1)(x − 3). Critical points are x = 1 and x = 3. f″(1) = −6 < 0, so local maximum at (1, 4). f″(3) = 6 > 0, so local minimum at (3, 0). The inflection point x = 2 sits between them. This is why a cubic can have one local maximum, one local minimum, and one inflection point. Second partials do this in two variables; see Unit 4.

Worked example

Question. Find the intervals of concavity and the inflection point of f(x) = x³ − 6x² + 9x. Also classify the critical points x = 1 and x = 3 using the second derivative test.

  1. Differentiate: f′(x) = 3x² − 12x + 9.
  2. Differentiate again: f″(x) = 6x − 12.
  3. Solve f″(x) = 0: 6x − 12 = 0 gives x = 2. Then f(2) = 8 − 24 + 18 = 2, so the candidate point is (2, 2).

  • Do not confuse concave up with increasing. A curve can be increasing and concave down.
  • A vertical tangent or a cusp can change shape even where f″ does not exist.
  • If f″(c) = 0 at a critical point, the second derivative test gives no answer; use the first derivative test.

Taylor polynomialPₙ(x) = Σ(k=0 to n) f⁽ᵏ⁾(a) (x−a)ᵏ / k!, the degree-n polynomial matching f and its first n derivatives at a.1.5
Lagrange remainderRₙ(x) = f(x) − Pₙ(x) = f⁽ⁿ⁺¹⁾(c)(x−a)ⁿ⁺¹/(n+1)! for some c between a and x.1.5
Indeterminate formA limit that first reads as 0/0, ∞/∞, 0·∞, ∞−∞, 1^∞, 0⁰ or ∞⁰; the value is not fixed by the form alone.1.6
L'Hôpital's ruleFor 0/0 or ∞/∞, lim f(x)/g(x) = lim f′(x)/g′(x), provided the second limit exists (finite or infinite).1.6
Critical pointA point c in the domain where f′(c) = 0 or f′(c) does not exist.1.7
Second derivative testIf f′(c) = 0 and f″(c) > 0 then c is a local minimum; if f″(c) < 0 then c is a local maximum; if f″(c) = 0 the test gives no answer.1.7
Concavityf is concave up where f″ > 0 (graph bends upward) and concave down where f″ < 0.1.8
Point of inflectionA point where the concavity of f changes sign; often f″ = 0 there, but f″ = 0 alone is not enough.1.8

Takeaways

  1. A function gives exactly one output per allowed input, and every new function built by shifting, stretching, composing or inverting keeps that rule.
  2. A limit describes the value f approaches near a point, not the value at the point, so f(a) may be missing or different and the limit can still exist.
  3. Continuity at a point is three conditions in one line: f(a) exists, the limit exists, and the two are equal.
  4. The derivative is itself a function, produced by taking the limit of the difference quotient; differentiability at a point forces continuity there.
  5. Rolle's theorem is the flat-tangent case of the mean value theorem, and the mean value theorem turns information about f′ into information about f.
  6. Taylor's theorem replaces a smooth function near a point by a polynomial plus a remainder, and the remainder controls how large the error can be.
  7. L'Hôpital's rule converts a 0/0 or ∞/∞ limit into a new limit of derivatives, and it is valid only when that new limit exists.
  8. Derivatives find the critical points; a sign test on f′ or the value of f″ at the critical point classifies them, and on a closed interval the endpoints must also be checked.
  9. The sign of f″ decides where the graph bends up or down, and a change of that sign marks an inflection point.

Glossary

Absolute maximum
The largest value f(c) taken by f on its whole domain or on a stated interval.
Asymptote
A line that the graph of a function approaches without necessarily meeting, either as x → ±∞ or as f(x) → ±∞.
Composition
The function f∘g defined by (f∘g)(x) = f(g(x)) wherever both steps are defined.
Concave up
A graph shape where f″ > 0, so the curve lies above its tangent lines and slopes increase.
Continuous at a point
The state where f(a) is defined, lim(x→a) f(x) exists, and the two are equal.
Critical point
A point c in the domain of f where f′(c) = 0 or f′(c) fails to exist.
Derivative
The function f′ whose value at x is the limit of the difference quotient, giving the slope of the tangent.
Difference quotient
The ratio [f(x+h) − f(x)]/h, the slope of a secant line, whose limit is the derivative.
Differentiable
Having a derivative at the point, that is, the difference quotient has a finite two-sided limit there.
Discontinuity
A point where continuity fails; removable if the limit exists, jump if one-sided limits differ, infinite if the function blows up.
Domain
The set of all inputs for which the function rule is defined.
Extreme value theorem
A function continuous on a closed interval [a,b] attains both an absolute maximum and an absolute minimum there.
Indeterminate form
An expression such as 0/0 or ∞/∞ whose limiting value depends on the functions, not on the form.
Inflection point
A point on a curve where the direction of concavity changes.
Inverse function
The function f⁻¹ that sends each output of a one-to-one f back to its input.
Limit of a function
The value L that f(x) approaches as x approaches a, regardless of the value at a itself.
Local maximum
A value f(c) that is at least as large as f(x) for all x in some open interval around c.
Mean value theorem
The theorem that a differentiable curve has a tangent parallel to the chord joining its endpoints somewhere in between.
One-sided limit
The limit computed using only x on one side of the point, written lim(x→a⁻) or lim(x→a⁺).
Piecewise function
A function defined by different formulas on different parts of its domain.
Range
The set of all values actually taken by the function.
Remainder
The difference f(x) − Pₙ(x) between a function and its Taylor polynomial, which measures the error of the approximation.
Rolle's theorem
The special case of the mean value theorem in which the two endpoint values are equal, so some interior derivative is zero.
Taylor polynomial
The polynomial of degree n that matches f and its first n derivatives at a chosen point.
