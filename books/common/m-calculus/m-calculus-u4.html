4.1 Limits and continuity in two variables; two-path test

A function of two variables has limit L at a point (x₀, y₀) when f(x, y) can be made as close to L as we like by taking (x, y) close enough to (x₀, y₀) from every direction. This matters because a surface may look steady on one route to the point and jump on another. The two-path test turns that idea into a quick disproof: two routes with different limiting values prove that no single limit exists. Engineers meet this when a formula has a hole, a corner or a zero denominator, as in error surfaces and circuit models.

You need: limits, continuity and the algebra of limits for one variable from Unit 1, especially Limit of a function and continuity.

Limit at a point and open disks

Write a point in the plane as P = (x, y) and a fixed base point as P₀ = (x₀, y₀). The distance between them is √((x−x₀)² + (y−y₀)²). A neighbourhood of P₀ is the set of points whose distance from P₀ is less than some δ > 0. It is an open disk, the two-variable version of an open interval.

The formal definition uses ε for the allowed error in f and δ for the allowed distance in the input.

lim [(x, y) → (x₀, y₀)] f(x, y) = L

L is the limiting value; (x₀, y₀) is the base point; f is defined on a punctured disk around (x₀, y₀).

for every ε > 0 there is a δ > 0 such that 0 < √((x−x₀)² + (y−y₀)²) < δ gives |f(x, y) − L| < ε

ε is the allowed error in the output; δ is the allowed distance in the input; the square root is the Euclidean distance from (x, y) to (x₀, y₀).

If f → L and g → M as (x, y) → P₀, then f + g → L + M, fg → LM, and f/g → L/M provided g ≠ 0 on a punctured disk around P₀ and M ≠ 0. These rules are the algebra of limits, the same as in one variable. A function is continuous at P₀ when f(P₀) is defined, the limit exists, and the limit equals f(P₀). It is continuous on a region when it is continuous at every point of that region.

The two-path test

To disprove a limit at P₀, find two curves through P₀ that give different limiting values. This is the two-path test; some syllabi call it the path test.

  1. Choose two paths through P₀. For a general base point P₀ = (x₀, y₀), common straight-line paths are y − y₀ = m(x − x₀) and x = x₀. At the origin these become y = mx and x = 0. A curve through P₀ is also allowed; for the origin, y = x² is an example.
  2. Substitute the path into f. The result is a function of one variable, usually x or a parameter m.
  3. Take the one-variable limit along each path.
  4. If the two values differ, the two-variable limit does not exist. If they agree, you have no proof; try more paths, a polar bound, or the ε-δ definition.

If the one-variable limit along even one path fails to exist (for example, by oscillation along that path), then the two-variable limit does not exist.

For f(x, y) = xy/(x² + y²) with (x, y) ≠ (0, 0), take y = mx. Then f = mx²/(x² + m²x²) = m/(1 + m²) for x ≠ 0. With m = 1 this is 1/2; with m = 0 it is 0. Two paths, two values, so the limit at the origin does not exist.

The polar route writes x = x₀ + r cos θ and y = y₀ + r sin θ. At the origin this is x = r cos θ, y = r sin θ. For the same f, f = (r cos θ)(r sin θ)/r² = cos θ sin θ = (1/2) sin 2θ. The expression cos θ sin θ is independent of r; as r → 0, the limit along the ray is cos θ sin θ, which depends on θ. To prove a limit by polar form, you need a bound |f − L| ≤ g(r) where g(r) → 0 and the bound does not depend on θ.

Continuity from formulas

A polynomial in x and y is a sum of terms a x^m y^n, where a is a number and m, n are non-negative integers. Every polynomial is continuous at every point of the plane. A rational function P(x, y)/Q(x, y) is continuous at every point where Q(x, y) ≠ 0. At a point where Q = 0, the formula is undefined there; test the limit by paths before deciding anything about continuity.

A piecewise definition can fill the hole. For f(x, y) = xy/(x² + y²) when (x, y) ≠ (0, 0) and f(0, 0) = 0, the hole is filled, but the limit still fails, so f is not continuous at the origin. By contrast, g(x, y) = x²y/(x² + y²) for (x, y) ≠ (0, 0), with g(0, 0) = 0, satisfies |g| ≤ |y|, so g → 0 and g is continuous at the origin. Continuity at a point is a local property: only a small disk around the point matters.

Worked example

Question. Let f(x, y) = xy/(x² + y²) for (x, y) ≠ (0, 0), and f(0, 0) = 0. Test whether lim [(x, y) → (0, 0)] f(x, y) exists. Use the paths y = x and y = 0. Then write f in polar coordinates.

  1. On y = x, substitute y = x: f(x, x) = x²/(x² + x²) = 1/2 for x ≠ 0. The limit along this path is 0.5.
  2. On y = 0, substitute y = 0: f(x, 0) = 0/(x²) = 0 for x ≠ 0. The limit along this path is 0.0.
  3. 0.5 ≠ 0.0. Different paths give different values. The two-variable limit does not exist. The function is not continuous at the origin, regardless of f(0, 0) = 0.
  4. Polar form: x = r cos θ, y = r sin θ. Then f = (r cos θ)(r sin θ)/(r² cos²θ + r² sin²θ) = cos θ sin θ = (1/2) sin 2θ. The expression is independent of r; as r → 0 the limit is cos θ sin θ, which depends on θ. At θ = π/4 it is 0.5; at θ = 0 it is 0.0.

Answer. Along y = x the limit is 0.5; along y = 0 it is 0.0. Since they differ, the two-variable limit does not exist and f is not continuous at the origin.

Exam traps

  • The iterated limits lim_{x→0} lim_{y→0} f and lim_{y→0} lim_{x→0} f may exist and agree while the two-variable limit fails. They are not the same object.
  • Straight lines y − y₀ = m(x − x₀) do not cover every path through P₀; at the origin this is y = mx. A function can give the same value for every m and still fail along a curve such as y = x² (at the origin).
  • The value f(x₀, y₀) does not affect the limit. The definition uses 0 < distance < δ, so the base point is excluded.
  • In polar form, fixing θ and letting r → 0 is only one ray. A proof needs a bound independent of θ.
  • Agreement on two paths never proves a limit. The two-path test is only a disproof tool.

4.2 Partial derivatives and higher order partials

A partial derivative answers a narrow question: if x changes a little and y is held fixed, how fast does f change? It exists because most real quantities depend on several inputs, and we often need the effect of just one. In a price formula with tax and quantity, or a hill height with east and north distances, the partial derivative gives the slope along one direction while every other input stays frozen. The same idea extends to second derivatives and to implicit surfaces.

You need: one-variable differentiation rules from Unit 1 and the two-path idea of limits in two variables.

Freeze one variable at a time

Take f(x, y) defined near (x₀, y₀). Freeze y at y₀. The rule x ↦ f(x, y₀) is a one-variable function. Its ordinary derivative at x₀ is the partial derivative of f with respect to x at (x₀, y₀). Read ∂ as “partial”. The notation fx means the same thing. ∂f/∂y is defined the same way, with x frozen and y moving.

∂f/∂x at (x₀, y₀) = lim<sub>h→0</sub> [f(x₀+h, y₀) − f(x₀, y₀)] / h

h is a real increment; x₀ and y₀ are fixed numbers; ∂f/∂y is defined the same way with y changed and x frozen.

Geometrically, the plane y = y₀ cuts the surface z = f(x, y) in a curve. fx at (x₀, y₀) is the slope of the tangent to that curve at the point (x₀, y₀, f(x₀, y₀)). This slope is along the x-direction only. The two-path test for limits is a different idea: a partial derivative uses only one straight path, so its existence says nothing about continuity in two variables.

First partials, then second partials

To compute fx, mark y as a constant, differentiate in x with the Unit 1 rules, and leave y in the answer. Do not set y to zero. For fy, reverse the roles. Products need the product rule with the frozen factor: while finding fx, y cos(xy) has constant factor y, so its x-derivative is −y² sin(xy). While finding fy, x cos(xy) has constant factor x, so its y-derivative is −x² sin(xy).

  1. Freeze every variable except the one named in the derivative.
  2. Differentiate with the one-variable power, product, quotient and chain rules; the frozen letters behave as constants.
  3. Keep the frozen letters in the result; they record where the derivative was taken.

Differentiate fx again to get fxx and fxy. Differentiate fy again to get fyx and fyy. We write fxy for (fx)y: first x, then y.

f<sub>xy</sub> = ∂/∂y (∂f/∂x),  f<sub>yx</sub> = ∂/∂x (∂f/∂y)

fxy means: first differentiate with respect to x, then with respect to y; fyx does the two steps in the other order.

Clairaut/Schwarz theorem: if fxy and fyx exist and are continuous in a neighbourhood of the point, then fxy = fyx there. The continuity hypothesis is part of the theorem. Without it, mixed partials can disagree; only a few universities chase an explicit counterexample. For polynomials and sine/cosine expressions in this unit, continuity usually holds, so the two mixed partials match.

Three variables and implicit surfaces

For f(x, y, z), ∂f/∂x freezes y and z. The notation fx is the same. Higher partials such as fxy and fxxz are made by repeated freezing. Suppose F(x, y, z) = 0 defines z as a function z(x, y) near a point, and Fz ≠ 0 there. Differentiate F(x, y, z(x, y)) = 0 with respect to x, holding y fixed: Fx + Fz zx = 0. Therefore zx = −Fx/Fz. Similarly zy = −Fy/Fz.

z<sub>x</sub> = −F<sub>x</sub>/F<sub>z</sub>,  z<sub>y</sub> = −F<sub>y</sub>/F<sub>z</sub>

Fx, Fy, Fz are the partial derivatives of F; zx and zy are the partial derivatives of the implicit function z(x, y); the formulas need Fz ≠ 0.

Here Fx, Fy, Fz are derivatives of F, not of z. The condition Fz ≠ 0 lets us divide. For the sphere x² + y² + z² = 1, this gives zx = −x/z and zy = −y/z for z ≠ 0.

Worked example

Question. Let f(x, y) = x³y² + sin(xy). (a) Find fx and fy. (b) Find fxy and fyx. (c) Evaluate all four at (x, y) = (1, 0).

  1. For fx, freeze y. The derivative of x³y² in x is 3x²y². The derivative of sin(xy) in x is cos(xy)·y. So fx = 3x²y² + y cos(xy).
  2. For fy, freeze x. The derivative of x³y² in y is 2x³y. The derivative of sin(xy) in y is x cos(xy). So fy = 2x³y + x cos(xy).
  3. fxy = ∂/∂y [3x²y² + y cos(xy)]. The first term gives 6x²y. The product y cos(xy) gives cos(xy) + y(−sin(xy)·x) = cos(xy) − xy sin(xy). So fxy = 6x²y + cos(xy) − xy sin(xy).
  4. fyx = ∂/∂x [2x³y + x cos(xy)]. The first term gives 6x²y. The product x cos(xy) gives cos(xy) + x(−sin(xy)·y) = cos(xy) − xy sin(xy). So fyx = 6x²y + cos(xy) − xy sin(xy). The two mixed partials agree.
  5. At (1, 0), sin(1·0) = sin 0 = 0 and cos(1·0) = cos 0 = 1. So fx(1, 0) = 3·1²·0² + 0·1 = 0. fy(1, 0) = 2·1³·0 + 1·1 = 1. fxy(1, 0) = 6·1²·0 + 1 − 0 = 1. fyx(1, 0) = 1.

Answer. At (1, 0): fx = 0, fy = 1, fxy = 1 and fyx = 1.

Exam traps

  • In y cos(xy) while finding fx, the outside y stays as a factor and the inside y from the chain also appears: the derivative is −y² sin(xy), not −y sin(xy).
  • fxy = fyx is a theorem with a continuity hypothesis, not a definition. State the hypothesis when the examiner asks why the mixed partials agree.
  • In F(x, y, z) = 0, the formula is zx = −Fx/Fz. The minus sign is easy to drop, and Fz must be nonzero.
  • Do not replace the frozen variable by zero. Freezing y at y₀ is not setting y = 0 unless y₀ = 0.
  • Check your exam's convention for fxy: this book means first x, then y. Reversing the notation does not change the value when the mixed partials are continuous.

4.3 Total derivative, differentiability and chain rule

A small change in two inputs can be approximated by a flat plane, not by two separate one-variable ideas. The total derivative makes this precise: the change in f is linear in Δx and Δy plus an error smaller than the distance moved. This test is stronger than having both partial derivatives. The chain rule then tracks how that change travels when x and y themselves depend on t, on u and v, or on each other through an equation. Engineers use it for sensitivity, error propagation and rates in linked systems such as power grids and payment flows.

You need Chapter 4.2 for partial derivatives, Chapter 4.1 for the two-path test, and Unit 1 for the one-variable chain rule.

Differentiability and the total differential

Write f(x₀+Δx, y₀+Δy) − f(x₀,y₀) as Δf. Put ρ = √(Δx² + Δy²). The number ρ is the distance moved in the input plane.

Δf = f_x Δx + f_y Δy + ε ρ

Δf is the change in f; f_x and f_y are the partial derivatives at (x₀,y₀); Δx and Δy are input increments; ρ is the input distance; ε depends on Δx and Δy and ε → 0 as ρ → 0.

The function f is differentiable at (x₀,y₀) when this formula holds. The first two terms are a linear approximation. The term ερ is the error. The error shrinks faster than ρ because ε → 0, so ερ/ρ → 0.

The linear part is the total differential: df = f_x dx + f_y dy. Here dx and dy are small changes in x and y, and df estimates the change in f. Geometrically df is the rise along the tangent plane; the tangent-plane reading is finished in Chapter 4.8.

Differentiability implies continuity and gives both partials. The converse fails. In Chapter 4.1, f(x,y)=xy/(x²+y²) for (x,y)≠(0,0) and f(0,0)=0 has f_x(0,0)=0 and f_y(0,0)=0. It is not continuous at the origin because along y=x it tends to 1/2. Two partials do not make a function differentiable.

Chain rule along a curve

Let z=f(x,y), x=x(t), y=y(t). A small t-change Δt moves x by Δx≈x′(t)Δt and y by Δy≈y′(t)Δt. Differentiability gives Δz≈f_x Δx+f_y Δy. Divide by Δt and let Δt→0.

dz/dt = f_x dx/dt + f_y dy/dt

z=f(x,y); x and y are differentiable functions of t; f_x and f_y are evaluated at (x(t),y(t)); dx/dt and dy/dt are ordinary derivatives.

The formula is a sum over routes. A change in t reaches z through x and also through y; the two partial rates add. If only x depends on t, the y-term is zero. If z=f(x,y,t) with explicit t, add f_t. The derivative dz/dt is sometimes called the total derivative.

Do not write dz/dx in this setting. After substituting x(t), y(t), z is a function of t alone. Writing dz/dx when x and y both change hides a second route and usually gives a wrong answer. Use the dependency tree: t → x,y → z → dz/dt.

Several inputs and implicit differentiation

∂z/∂u = f_x ∂x/∂u + f_y ∂y/∂u, ∂z/∂v = f_x ∂x/∂v + f_y ∂y/∂v

z=f(x,y); x=x(u,v) and y=y(u,v); f_x and f_y are evaluated at (x(u,v),y(u,v)); the other variable is held constant in each partial.

Each variable u or v gets its own sum. Hold v constant for ∂z/∂u and hold u constant for ∂z/∂v. The dependency tree has two input branches u and v, each reaching z through x and through y.

For an implicit curve F(x,y)=0, take the differential: F_x dx + F_y dy = 0. If F_y ≠ 0, dy/dx = −F_x/F_y. The minus sign is part of the formula. Example: x²+y²=25 gives dy/dx=−(2x)/(2y)=−x/y.

Euler's theorem for homogeneous functions: if f(tx,ty)=tⁿ f(x,y) for all t>0, then x f_x + y f_y = n f. It is a quick check on partials and appears with this section in some syllabi. It needs the function to be homogeneous of degree n and differentiable.

Worked example

Question. Let z = x²y + y³, where x = t² and y = t. Find dz/dt at t = 1 by the chain rule, and check by substituting first.

  1. At t=1: x=1²=1 and y=1.
  2. Partial derivatives: f_x=2xy and f_y=x²+3y². At (1,1): f_x=2·1·1=2 and f_y=1+3=4.
  3. Derivatives of inputs: dx/dt=2t and dy/dt=1. At t=1: dx/dt=2 and dy/dt=1.
  4. Chain rule: dz/dt = f_x dx/dt + f_y dy/dt = 2·2 + 4·1 = 4+4 = 8.
  5. Check by substitution: z = (t²)²(t)+(t)³ = t⁵ + t³. Then dz/dt=5t⁴+3t². At t=1: 5·1+3·1=8.

Answer. At t = 1, dz/dt = 8 per unit of t.

Exam traps

  • Having f_x and f_y at a point is not differentiability. The function xy/(x²+y²) with value 0 at the origin has both partials 0 there but is not continuous, so it is not differentiable.
  • Do not replace dz/dt by dz/dx when x and y both depend on t; after substitution z is a function of t alone.
  • The total differential is a linear estimate, not the exact change. The leftover ερ can be nonzero for a finite move.
  • For implicit differentiation keep the minus sign: dy/dx = −F_x/F_y, and require F_y ≠ 0 near the point.
  • Euler's theorem needs homogeneity of degree n; it does not apply to every function.

4.4 Jacobians and their properties

A change of variables turns a hard region into an easy one. The Jacobian is a single number, built from first partial derivatives, that records how much that change stretches area or volume at a point. It is the determinant of the matrix of partials, with rows for the new variables and columns for the old. Engineers use it to switch a double integral to polar coordinates, to convert between coordinate frames in robotics, and to track how small errors grow through a chain of measurements.

You need: partial derivatives from Chapter 4.2 and 2×2 and 3×3 determinants from Unit 1.

Definition: a determinant of first partials

Take two old variables x and y and two new ones u = u(x, y), v = v(x, y). Write ux for ∂u/∂x, and so on. The Jacobian is the determinant of the 2×2 array of first partials, with one row per new variable and one column per old variable.

∂(u, v)/∂(x, y) = det [ u<sub>x</sub>  u<sub>y</sub> ; v<sub>x</sub>  v<sub>y</sub> ] = u<sub>x</sub>v<sub>y</sub> − u<sub>y</sub>v<sub>x</sub>

u and v are the new variables; x and y are the old ones; ux = ∂u/∂x, and so on; det means determinant.

For three new variables u, v, w in three old ones x, y, z, the array is 3×3 and you expand it along any row. Some syllabi call the number the Jacobian determinant and the matrix alone the Jacobian matrix.

∂(u, v, w)/∂(x, y, z) = det [ u<sub>x</sub> u<sub>y</sub> u<sub>z</sub> ; v<sub>x</sub> v<sub>y</sub> v<sub>z</sub> ; w<sub>x</sub> w<sub>y</sub> w<sub>z</sub> ]

each row is one new variable; each column is one old variable.

  • The notation ∂(u, v)/∂(x, y) reads “u, v with respect to x, y”.
  • Rows are the new variables; columns are the old ones.
  • Swapping two rows changes the sign of the determinant.
  • The determinant is unchanged if you swap rows with columns, because a matrix and its transpose have the same determinant.
  1. Differentiate each new variable with respect to each old variable.
  2. Place ux, uy in the first row and vx, vy in the second row.
  3. Expand the determinant using uxvy − uyvx.
  4. For three variables, expand the 3×3 determinant along a row with easy zeros.

Three properties that do the work

The chain rule multiplies Jacobians. If u and v depend on s and t, and s and t depend on x and y, the overall Jacobian is the product of the two Jacobians in the order written.

∂(u, v)/∂(x, y) = ∂(u, v)/∂(s, t) × ∂(s, t)/∂(x, y)

u, v depend on the intermediate variables s, t; s, t depend on the original variables x, y.

The inverse rule says a map and its inverse have reciprocal Jacobians. Do not confuse the inverse map with the transpose: ∂(x, y)/∂(u, v) is 1 divided by ∂(u, v)/∂(x, y), not the same number.

∂(u, v)/∂(x, y) × ∂(x, y)/∂(u, v) = 1

the map is one-to-one and its Jacobian is not zero.

The third property is the useful test. J = 0 exactly where the map loses independence, that is, where u and v are functionally related. For example, u = x + y and v = 2x + 2y give fuxvy − uyvx = (1)(2) − (1)(2) = 0, and indeed v = 2u. Only a few universities prove the general statement; in an exam you use it as a test. A nonzero Jacobian means the map is locally invertible near that point.

Three Jacobians come up so often that you should carry them in memory. Here ρ is the distance from the z-axis in cylindrical coordinates, and in spherical coordinates ρ is the distance from the origin, φ is the angle from the positive z-axis, and θ is the angle in the xy-plane.

Worked example

Question. For u = x² − y² and v = 2xy, find ∂(u, v)/∂(x, y) at (x, y) = (1, 2). Then find ∂(x, y)/∂(u, v) at the image point and verify the inverse rule.

Exam traps

  • Swapping the two rows changes the sign of the determinant, so fix an order: new variables down the rows, old variables across the columns.
  • Do not write ∂(x, y)/∂(u, v) as the transpose of the matrix. The determinant of the transpose is the same, but the inverse Jacobian is the reciprocal 1/J.
  • Sign slips in the 2×2 expansion are common: the formula has a minus between uxvy and uyvx.
  • In an area integral use |J|. Forgetting the absolute value gives a negative area when the map reverses orientation.
  • J = 0 is a dependence test, not a statement that the functions are constant. u = x + y and v = 2x + 2y have J = 0 but neither u nor v is constant.

4.5 Taylor's series for functions of two variables

A smooth surface can be rebuilt near a point from its partial derivatives at that point. Give two small increments, h in x and k in y; each partial derivative supplies a coefficient, and the terms are grouped by degree. Degree one is the tangent plane. Degree two is the bend. Higher degrees sharpen the fit. Engineers use this to replace a complicated formula by a short polynomial near an operating point: a transistor model around its bias point, a lens near its optical axis, a share price near today's value. The leftover after the last kept term is the remainder, and it tells you how wrong the short answer can be.

You need: partial derivatives and higher order partials, differentiability and the chain rule, and Taylor's theorem for one variable (Unit 1).

From one variable to two

For one variable, Taylor's theorem rebuilds f near a: f(a + h) = f(a) + h f′(a) + (h²/2!) f″(a) + ⋯. Two variables bring two increments, so the same job needs two sets of partial derivatives.

Fix a base point (a, b). Move by h along x and by k along y, reaching (a + h, b + k). Suppose f has continuous partial derivatives up to one order more than the last term you keep. Then the expansion below holds for small h and k.

f(a + h, b + k) = f + (h f_x + k f_y) + (1/2!)(h² f_xx + 2hk f_xy + k² f_yy) + ⋯

f, f_x, f_y, f_xx, f_xy, f_yy are all evaluated at the base point (a, b), not at the moved point. h is the increment in x, k is the increment in y. f_xy means ∂²f/∂x∂y, taken x first then y.

Read it degree by degree. Degree one, h f_x + k f_y, is the tangent plane: it changes linearly and gives the best flat fit. Degree two adds the bend through a quadratic form in (h, k).

The sign of that quadratic form decides whether the surface curves up, down, or one way in one direction and the other way in another. That decision belongs to maxima, minima and saddle points.

The third-degree term, the condition, the remainder

f = f + (h f_x + k f_y) + (1/2!)(h² f_xx + 2hk f_xy + k² f_yy) + (1/3!)(h³ f_xxx + 3h²k f_xxy + 3hk² f_xyy + k³ f_yyy) + ⋯

every partial on the right is taken at (a, b). The left side means f(a + h, b + k).

The coefficients 1, 3, 3, 1 are the binomial coefficients. In general the degree-n block is (1/n!)(h ∂/∂x + k ∂/∂y)ⁿ f, taken at (a, b). Expanding that operator reproduces every term with the right binomial weight.

Condition: the partials must be continuous up to one order beyond the term you keep. Keeping degree two needs continuous third partials, because the error is controlled by degree three.

R_n = (1/(n+1)!) (h ∂/∂x + k ∂/∂y)ⁿ⁺¹ f(a + θh, b + θk), 0 < θ < 1

R_n is the remainder after the degree-n terms, and θ is some number strictly between 0 and 1. Only a few universities write this Lagrange form for two variables; most stop at stating that a remainder exists and is of the next order.

Maclaurin form is the case a = b = 0, so h = x and k = y. Then f(x, y) = f(0,0) + (x f_x + y f_y) + (1/2)(x² f_xx + 2xy f_xy + y² f_yy) + ⋯, all partials at the origin.

Approximating with a known error

  1. Choose the base point (a, b) and the increments h, k that reach your target.
  2. Compute f and every partial up to the needed order, at (a, b).
  3. Add the degree-1, degree-2, … blocks in order.
  4. Bound the remainder using the degree n+1 block, replacing each partial by its largest magnitude M on the segment from (a, b) to (a + h, b + k).
  5. Report the approximation and the bound together. The bound shrinks fast as h and k shrink.

|R_2| ≤ (M/3!) (|h| + |k|)³

M is an upper bound for |f_xxx|, |f_xxy|, |f_xyy|, |f_yyy| on the segment; the binomial coefficients 1, 3, 3, 1 turn the sum of four terms into the cube.

Worked numbers for f = eˣ sin y near the origin, with h = 0.1 and k = 0.2. On that small segment eˣ ≤ e^0.1 ≈ 1.106 and |sin y|, |cos y| ≤ 1, so M ≈ 1.106. Then |R_2| ≤ (1.106/6)(0.3)³ = 0.00124? No: (0.3)³ = 0.027, and 1.106 × 0.027 ÷ 6 = 0.005. The second-degree answer is therefore right to within about 0.005, a safe bound rather than a tight one.

Worked example

Question. Expand f(x, y) = eˣ sin y about (0, 0) up to the second degree. Use the expansion to estimate f(0.1, 0.2) and compare with the exact value.

  • The mixed term. Inside the bracket it is 2hk f_xy and the outside factor is 1/2, so they cancel and hk f_xy appears with coefficient 1. Writing 2f_xy hk or ½f_xy hk loses the mark.

4.6 Maxima, minima and saddle points

A surface can peak, bottom out, or twist like a mountain pass. Near a flat point it is almost a quadratic form, and three second partials decide which shape. This chapter gives the test, why it works, and the routine for absolute extrema on a closed region. Cost curves, error surfaces and yield surfaces all ask: where is the best value, and is it best or worst?

You need: partial derivatives and higher-order partials (4.2), Taylor's series for two variables (4.5), and maxima and minima of one variable from Unit 1.

Local maxima, minima and critical points

A function f(x, y) has a local maximum at an interior point (a, b) when f(a, b) ≥ f(x, y) for every point (x, y) in some disk centred at (a, b). It has a local minimum when f(a, b) ≤ f(x, y) on such a disk. The disk makes the word local: values far from (a, b) may be larger or smaller.

At a smooth peak or pit the surface is flat. If both partials exist at an interior extremum then f_x(a, b) = 0 and f_y(a, b) = 0. A point where both partials vanish is a critical point, also called a stationary point. A point where a partial fails to exist is also critical. Every interior extremum is critical; not every critical point is an extremum.

f_x(a, b) = 0 and f_y(a, b) = 0

f_x and f_y are the partial derivatives (chapter 4.2) and (a, b) is an interior point of the domain.

The simplest failure is f(x, y) = x² − y². Here f_x = 2x and f_y = −2y, so (0, 0) is critical. Along the x-axis f = x² > 0 for x ≠ 0, so the point is a bottom in that direction. Along the y-axis f = −y² < 0 for y ≠ 0, so the point is a top in that direction. A point that is a bottom along one line and a top along another is a saddle point, so (0, 0) is a saddle point of f.

The second derivative test

Taylor's series (chapter 4.5) gives, for small h and k, f(a+h, b+k) = f(a, b) + ½(f_xx h² + 2f_xy hk + f_yy k²) + shrinking terms. All partials are at (a, b). The first-degree terms are missing because f_x = f_y = 0. So the sign of f − f(a, b) is the sign of Q(h, k) = f_xx h² + 2f_xy hk + f_yy k².

The form is positive for every nonzero (h, k) exactly when f_xx > 0 and D > 0; then the surface rises in every direction and f(a, b) is a local minimum. It is negative for every nonzero (h, k) exactly when f_xx < 0 and D > 0; then f(a, b) is a local maximum. If D < 0 the form takes both signs, so the surface rises along one line through the point and falls along another, and the point is a saddle.

D = f_xx f_yy − f_xy²

f_xx and f_yy are the pure second partials, f_xy is the mixed partial, all evaluated at (a, b). D is called the discriminant; some syllabi call it the Hessian determinant.

  1. Solve f_x = 0 and f_y = 0 together for interior critical points.
  2. At each, compute f_xx, f_yy, f_xy and D = f_xx f_yy − f_xy².
  3. D > 0 with f_xx > 0: local minimum. D > 0 with f_xx < 0: local maximum.
  4. D < 0: saddle point. D = 0: test fails, look deeper.

Absolute extrema on a closed bounded region

A continuous f on a closed bounded region such as a rectangle or a disk attains an absolute maximum and an absolute minimum. Find them in three stages.

  1. Find every interior critical point and record f there.
  2. Handle the boundary as a one-variable problem: substitute the edge equation into f, then use Unit 1 maxima and minima on the resulting single-variable function.
  3. Compare interior and boundary values. The largest is the absolute maximum, the smallest the absolute minimum.

Applied shape problem. An open tank with rectangular base x by y and height z holds 32 m³, so z = 32/(xy). The wetted surface is S = xy + 2xz + 2yz = xy + 64/x + 64/y m². Then S_x = y − 64/x² and S_y = x − 64/y². Setting both to zero gives x²y = 64 and xy² = 64, so x = y = 4 m and z = 2 m. Check: S_xx = 128/x³ = 2, S_yy = 2, S_xy = 1, so D = 4 − 1 = 3 > 0 with S_xx > 0, a minimum. The least wetted surface is S = 16 + 16 + 16 = 48 m².

On rectangles the boundary often carries the answer, because edges and corners give values no interior critical point reaches.

Worked example

Question. Find and classify all critical points of f(x, y) = x³ + y³ − 3xy, and give the value of f at each. (6 marks)

  2. Set f_x = 0: y = x². Set f_y = 0: x = y².
  3. Substitute: x = (x²)² = x⁴, so x(x³ − 1) = 0, giving x = 0 or 1.
  4. x = 0 gives y = 0. x = 1 gives y = 1. Critical points: (0, 0) and (1, 1).
  5. Second partials: f_xx = 6x, f_yy = 6y, f_xy = −3, so D = 36xy − 9.

  • Stopping at interior points. On a closed bounded region the largest value may sit on an edge or corner.
  • Treating D = 0 as a saddle. D = 0 decides nothing: x⁴ + y⁴ is a minimum at the origin and x⁴ − y⁴ is a saddle there, both with D = 0.
  • Reporting the point but forgetting f(a, b), usually the final answer.

4.7 Constrained extrema: Lagrange's multiplier method

A constrained extremum is the best value of a function f(x, y) when the point (x, y) is not free but must lie on a curve g(x, y) = c. Such problems are everywhere: the strongest beam cut from a fixed log, the cheapest UPI transaction fee under a cap, the largest tank built from a fixed sheet of steel. Lagrange's multiplier method turns the search into algebra. At the best point the level curve of f just touches the constraint, so the two gradients are parallel. Setting ∇f = λ∇g together with g = c gives three equations in x, y and λ.

You need: Chapter 4.6 for unconstrained extrema, and Chapter 4.2 for gradients written out as partials.

Why the gradients line up

Take a function f(x, y) and a constraint curve g(x, y) = c. Among the points that lie on that curve you want the largest or the smallest value of f. Draw the level curves of f, that is the curves f = k for various constants k. As you walk along the constraint the value of f changes, and it stops changing exactly where the constraint runs along a level curve of f.

At a best point the constraint does not cross the level curve, it touches it. At a touch the two curves share a tangent line. The gradient of a function is perpendicular to its level curve. So ∇f and ∇g are both perpendicular to that same tangent line, and they are parallel:

∇f = λ ∇g

∇f = (f_x, f_y) is the gradient of f; ∇g = (g_x, g_y) is the gradient of the constraint function g; λ is a number called the Lagrange multiplier.

Written as components, the gradient condition and the constraint together give three equations.

f_x = λ g_x, f_y = λ g_y, g(x, y) = c

f_x, f_y are the partial derivatives of f with respect to x and y; g_x, g_y are the partials of g; c is the fixed constraint value; λ is an unknown like x and y.

Three equations, three unknowns x, y, λ. Solve them and you have candidate points. The method produces candidates only; comparing f at each candidate decides which is the maximum and which the minimum.

Solving a constrained problem step by step

  1. Write the constraint as g(x, y) = c, and compute g_x and g_y.
  2. Check whether ∇g = (g_x, g_y) can be zero at a point of the constraint. The multiplier condition cannot see such a point, so test it by hand.
  3. Write f_x = λ g_x and f_y = λ g_y, and keep g(x, y) = c as the third equation.
  4. Solve. Before dividing by a variable, treat separately the case where that variable is zero, or you lose a candidate.
  5. Compute f at every candidate, and at the endpoints if the constraint is a finite arc. The largest value is the maximum, the smallest is the minimum.

A picture explains the first step. If the level curve of f crosses the constraint, you can slide along the constraint and improve f, so that crossing point is not optimal. Only a touching point survives, and touching means parallel gradients.

Engineering use: the shape with the most volume for a fixed surface area. A closed rectangular box with sides x, y, z metres has volume V = xyz m³ and surface area S = 2(xy + yz + zx) m². Fix S = A and maximise V. The multiplier equations force x = y = z, so the best box is a cube: 6a² = A gives a = √(A/6) metres and V = (A/6)^(3/2) m³.

What λ means, and the two-constraint form

λ carries information, not just arithmetic. Move a small step (dx, dy) along the constraint. Because g stays equal to c, g_x dx + g_y dy = 0. Then the change in f is f_x dx + f_y dy = λ(g_x dx + g_y dy) = 0. That is exactly why the point is optimal: to first order, no allowed move changes f.

Now change c. The best value f* depends on c, and df*/dc = λ. So λ is the rate at which the optimum responds to loosening the constraint, in units of f per unit of c. If λ = 2 and c is allowed to grow by 0.01, the best value grows by about 0.02. Check on a known case: maximise xy subject to x + y = c. Then y = λ and x = λ, so x = y = c/2, f* = c²/4, and df*/dc = c/2 = λ.

Two constraints: optimise f(x, y, z) subject to g = c and h = d. At the optimum ∇f is a combination of the two normals.

∇f = λ ∇g + μ ∇h, g = c, h = d

λ and μ are two multipliers; the five equations are solved for x, y, z, λ, μ. Only a few universities teach this case, so knowing the shape of the equations is enough.

Worked example

Question. Maximise f(x, y) = x²y subject to x + y = 3, with x ≥ 0 and y ≥ 0.

  1. Constraint: g(x, y) = x + y with c = 3. Then g_x = 1 and g_y = 1, so ∇g = (1, 1), which is never zero. There are no special points to test separately.
  2. Partials of f: f_x = 2xy and f_y = x².
  3. Lagrange equations: 2xy = λ·1 and x² = λ·1, together with x + y = 3.
  4. Equate the two expressions for λ: 2xy = x², so x(2y − x) = 0.
  5. Case x = 0: then y = 3, and f(0, 3) = 0.
  6. Case 2y − x = 0, that is x = 2y: then 2y + y = 3, so y = 1, x = 2, and f(2, 1) = 4 × 1 = 4.
  7. Endpoints of the constraint arc: (3, 0) gives f = 9 × 0 = 0, and (0, 3) is already listed.
  8. Compare 0 and 4: the maximum is 4 at (2, 1); the minimum is 0 at (0, 3) and (3, 0).
  9. The multiplier is λ = x² = 4, so raising c from 3 to 3.01 would raise the maximum by about 4 × 0.01 = 0.04.

Answer. The maximum value is 4, at (x, y) = (2, 1); the minimum on the arc is 0 at (0, 3) and (3, 0), and λ = 4.

Exam traps

  • Dividing 2xy = x² by x before checking x = 0. That silently deletes the candidate (0, 3).
  • Solving ∇f = 0 instead of ∇f = λ∇g. The free maximum is usually not on the constraint at all.
  • Leaving out g(x, y) = c. Without it the system is underdetermined and λ has no meaning.
  • Declaring the first solution the maximum. Several points satisfy the equations; f must be evaluated at every one, plus the endpoints of a finite constraint arc.
  • Reading λ as the maximum value. λ is df*/dc, a rate; the optimum value is f itself.

4.8 Tangent planes and normal lines to surfaces

A surface in space can be written as F(x, y, z) = 0. At any point P on it, the gradient ∇F gives one vector that points straight out of the surface. That single vector builds two objects: the plane that just touches the surface at P, and the line that pierces it there. The plane is what the surface looks like under a microscope, so it is used to read slopes of hills, set cutting tools in a workshop, and compute lighting in 3D graphics.

You need: Chapter 4.2 for partial derivatives and Chapter 4.3 for the total differential as the change along a tangent plane.

The gradient is perpendicular to the surface

The level curve f(x, y) = c has a gradient ∇f = (f_x, f_y) that is perpendicular to it, and Chapter 4.7 used exactly that. The same idea lifts to three variables.

Write the surface as F(x, y, z) = c, where F is a function of three variables and c is a constant. Move everything to one side so that c = 0. Take any smooth curve r(t) = (x(t), y(t), z(t)) lying on the surface and passing through P at t = 0.

Along that curve F(r(t)) = c for every t. Differentiate with the chain rule: F_x x′(t) + F_y y′(t) + F_z z′(t) = 0, that is ∇F · r′(t) = 0. The vector r′(0) is a tangent direction of the surface at P. Every tangent direction at P comes from some such curve, so ∇F is perpendicular to all of them at once.

So ∇F at P is the normal vector to the surface at P. One condition is needed: ∇F ≠ 0 at P. Where the gradient vanishes the point is singular and may have no single tangent plane, like the tip of a cone.

n = ∇F(P) = (F_x, F_y, F_z)

F_x = ∂F/∂x at P, and similarly F_y, F_z; n is perpendicular to the surface F = 0 at P.

Tangent plane and normal line

The tangent plane at P = (x₀, y₀, z₀) is the plane through P perpendicular to n. A point (x, y, z) lies on it exactly when the vector (x − x₀, y − y₀, z − z₀), which joins P to that point, is perpendicular to n.

F_x(x − x₀) + F_y(y − y₀) + F_z(z − z₀) = 0

the three partials are numbers, evaluated at P; (x₀, y₀, z₀) is the point of contact.

The normal line is the line through P along n, so its direction ratios are the same three partials.

(x − x₀)/F_x = (y − y₀)/F_y = (z − z₀)/F_z

each denominator is that partial derivative evaluated at P; these are direction ratios, not lengths.

If a partial is zero, do not divide by it. Keep that equation in product form: F_y = 0 means y = y₀, and the other two ratios are equal.

  1. Move everything to one side to get F(x, y, z) = 0.
  2. Differentiate to get F_x, F_y, F_z.
  3. Substitute P = (x₀, y₀, z₀) into all three.
  4. Put P and n into F_x(x − x₀) + F_y(y − y₀) + F_z(z − z₀) = 0.
  5. Simplify, then check that P satisfies the plane equation.

Surfaces given as z = f(x, y)

Most surfaces here arrive as z = f(x, y). Put F = f(x, y) − z. Then F_x = f_x, F_y = f_y and F_z = −1, so at P the normal is (f_x, f_y, −1).

The minus sign on the z-component is not decoration. Using (f_x, f_y, +1) gives f_x Δx + f_y Δy + (z − z₀) = 0, which rearranges to z − z₀ = −f_x Δx − f_y Δy: every slope comes out reversed.

Solved for z, the correct plane reads z = z₀ + f_x Δx + f_y Δy, where Δx = x − x₀ and Δy = y − y₀. That is the total differential of Chapter 4.3, Δz ≈ f_x Δx + f_y Δy. The tangent plane is the linear approximation, drawn.

Two surfaces meeting at P meet at the angle between their normals n₁ and n₂: cos θ = (n₁ · n₂)/(|n₁||n₂|), where the dot is the sum of products and |n| is the length √(n₁² + n₂² + n₃²).

The tangent plane also tracks the surface near P: any small step along the plane changes z by the total differential, so it is the flat stand-in for the surface in error estimates and in optimisation.

Exam traps

  • For z = f(x, y) the normal is (f_x, f_y, −1), not (f_x, f_y, +1). With +1 the plane equation reverses the sign of both slopes.
  • Evaluate the partials at P before writing the plane. A plane equation still containing x and y is not a plane.
  • The gradient of F has three components; the gradient of f has two. Do not drop the z-entry.
  • If a partial vanishes at P, do not put a zero in a denominator. Write that variable as equal to its value at P and equate the other two ratios.
  • Check the final plane by substituting P. A sign slip in the constant is the most common lost mark in this question.

Takeaways

  1. A limit in two variables exists only if every path into the point agrees, so one pair of disagreeing paths is enough to prove the limit fails.
  2. A partial derivative is just an ordinary derivative with the other variables frozen, so all the single-variable rules carry over unchanged.
  3. Having both partial derivatives at a point does not make a function differentiable there; the error must shrink faster than the distance moved.
  4. The Jacobian determinant turns a change of variables into a multiplication: areas (and later integrals) scale by its absolute value.
  5. Taylor's series replaces the single-variable tangent line with a full quadratic form, and that form decides the shape of the surface near a point.
  6. The second derivative test is the two-variable version of the sign of f″: the discriminant D tells you bowl, cap or saddle.
  7. Lagrange multipliers say the gradients are parallel at the constrained optimum, which turns a constrained problem into a system of equations plus the constraint.
  8. The gradient of F(x, y, z) is normal to the surface, which gives the tangent plane and normal line in one step.

Level curves of f and the constraint curve; motion along the constraint; At an interior optimum the rate of change of f along the constraint is zero; Hence ∇f is perpendicular to the constraint tangent, so parallel to ∇g; Equations f_x = λg_x, f_y = λg_y, g = 0; failure when ∇g = 0 at the optimum or the constraint has a corner.

Evaluate Examine the surface f(x, y) = x⁴ + y⁴ − 4xy + 1: locate all critical points, classify them, and describe the shape of the surface near the origin. 16 marks

f_x = 4x³ − 4y, f_y = 4y³ − 4x; solve to get (0,0), (1,1), (−1,−1); Hessian entries: 12x², −4, 12y²; (0,0): D = −16 < 0, saddle; show f is positive on y = 0 and negative on y = x near the origin; (1,1) and (−1,−1): D = 144 − 16 > 0 and f_xx > 0, local minima.

Evaluate For f(x, y) = x²y + y³, check continuity and differentiability everywhere, find the gradient, write the tangent plane to z = f(x, y) at (1, 1), and find any local extrema. 16 marks

f is a polynomial, hence continuous and differentiable everywhere; f_x = 2xy, f_y = x² + 3y²; gradient exists at every point; Tangent plane z − 2 = 2(x − 1) + 4(y − 1); Only critical point (0, 0); D = f_xx f_yy − f_xy² = 0 there, so the test is inconclusive and a direct sign check is needed.

Analyze State and prove the chain rule for z = f(u, v) where u = u(x, y) and v = v(x, y). Then show how the Jacobian of the composed map is the product of the two Jacobian matrices. 14 marks

Increment argument: Δz = f_u Δu + f_v Δv + small error; Divide by Δx and let Δx → 0 to get z_x = f_u u_x + f_v v_x; Same for z_y; Matrix form: J(composite) = J(f with respect to (u, v)) × J((u, v) with respect to (x, y)).

Glossary

Clairaut's theorem
If the mixed partials f_xy and f_yx are continuous, they are equal.
Constraint
An equation such as g(x, y) = 0 that the variables must satisfy.
Continuous function
A function whose value at every point of its domain equals its limit there.
Differentiable
A function whose change is well approximated by a linear expression in the increments.
Domain
The set of points (x, y) where f(x, y) is defined.
Function of two variables
A rule that assigns one real number f(x, y) to each point (x, y) in a region of the plane.
Gradient
The vector ∇f = (f_x, f_y) pointing in the direction of steepest increase of f.
Hessian matrix
The symmetric matrix of second partial derivatives of f at a point.
Higher order partial
A partial derivative of a partial derivative, such as f_xx or f_xy.
Increment
The small changes Δx and Δy in the inputs, and the resulting change Δf in the output.
Jacobian determinant
The determinant of the Jacobian matrix; it gives the local area scaling factor of a change of variables.
Jacobian matrix
The matrix of all first partials of a set of functions with respect to a set of variables.
Level curve
The set of points where f(x, y) equals a constant c.
Local maximum
A point where f is at least as large as at every nearby point.
Local minimum
A point where f is at most as large as at every nearby point.
Neighbourhood of a point
The set of all points within some small distance δ of the point (a, b).
Normal vector
A vector perpendicular to a surface or curve at a point.
Partial derivative
The rate of change of f with respect to one variable while the others are held fixed.
Path
A curve (x(t), y(t)) through the point (a, b) as t approaches some value.
Quadratic form
An expression such as a h² + 2b hk + c k², whose sign pattern classifies the shape of a surface.
Smooth surface
A surface given by F(x, y, z) = 0 where ∇F is continuous and never zero.
Stationary point
A point where the gradient is zero; also called a critical point.
Tangent plane
The plane that just touches a surface at a point and matches its slopes there.
