7.1 Random processes and their classification

A random process attaches a random variable to every time instant. One run of the experiment gives one whole sample path, not just one number. Queue length through a day, voltage from a sensor, and the count of arrivals at a UPI server are examples. Engineers use it to describe uncertainty that changes with time. This chapter defines the index set and state space, shows how to read a sample path, and classifies processes by time, state and dependence.

You need: random variables and distributions (see Unit 2, Probability and Random Variables), especially pmf, pdf and expectation.

Definition and sample path

A random process is a family of random variables {X(t): t ∈ T}. The set T is the index set, the allowed time values. The set S is the state space, the allowed values of X(t). If T is countable we call it discrete time; if T is an interval we call continuous time. Some syllabi say stochastic process for random process.

Fix one outcome ω of the underlying experiment. The function t ↦ X(t, ω) is one sample path or realization. Some syllabi say sample function. At one fixed time t, X(t) is a random variable across outcomes; the collection of these values across outcomes is the ensemble. One experiment gives one whole path, not the full ensemble.

  • T answers when: the time values where the process is observed.
  • S answers what value: the possible states of X(t).
  • A sample path is one observed graph of X(t) against t.
  • The ensemble is the collection of all possible paths at a fixed time.

Time and state classify the process

Two independent choices give four common types. Time asks whether T is countable or an interval. State asks whether S is countable or continuous. The table gives one engineering example for each cell.

Dependence between times

A second classification asks how X(t) depends on other times. An independent process has X(t) independent of X(s) for all t ≠ s. A Markov process allows dependence, but the future depends on the present state, not on the full past. A stationary process has joint distributions unchanged when all times are shifted by the same amount. Stationarity details are in 7.2; Markov chains start in 7.4.

The Poisson process is the standard continuous-time discrete-state example with independent increments. It is developed in 7.3. A random walk or coin-count process is a discrete-time Markov chain. These names classify dependence, while time and state classify the index set and values.

Ensemble average means averaging across many paths at a fixed t. Time average means averaging one long path along t. They are different objects; ergodicity is the special case where one long record can estimate the ensemble average. That idea is treated in 7.2.

Worked example

Question. A fair coin is tossed repeatedly. Let X(n) be the number of heads after n tosses, with X(0)=0. The toss sequence is H, T, H. (a) Give the index set T and state space S. (b) Write the sample path for n=0,1,2,3. (c) Classify the process by time and state. (d) State X(3).

  1. The index set is the set of time values: T = {0,1,2,...}, because n counts tosses.
  2. The state space is the set of possible head counts: S = {0,1,2,...}.
  3. Start at n=0: X(0)=0, so the path begins with 0.
  4. Toss 1 is H. Add 1: X(1)=0+1=1.
  5. Toss 2 is T. Add 0: X(2)=1+0=1.
  6. Toss 3 is H. Add 1: X(3)=1+1=2.
  7. The sample path is X(0), X(1), X(2), X(3) = 0, 1, 1, 2.
  8. T is countable, so the process is discrete-time. S is countable, so the process is discrete-state. The value after three tosses is X(3)=2 heads.

Answer. The index set is T={0,1,2,...}, the state space is S={0,1,2,...}, the sample path is 0,1,1,2, and X(3)=2 heads after three tosses; the process is discrete-time and discrete-state.

Exam traps

  • The state space S is the set of values X(t), not the set of time values T. In the coin example, n comes from T but the path values 0,1,1,2 come from S.
  • Discrete time does not mean discrete state. A voltage sampled every second has discrete time and continuous state.
  • Continuous time does not mean continuous state. A Poisson count has continuous time and discrete state {0,1,2,...}.
  • Markov is not the same as independent or stationary. A Markov process may have dependence through the present state; stationarity is a separate shift-invariance property.
  • An ensemble average and a time average are different. One long sample path does not automatically give the ensemble average; ergodicity is the special case where it does.

7.2 Stationary processes: strict sense, wide sense; ergodicity

A stationary process has statistics that do not depend on where the clock starts. Shift the whole record by an hour and its probability laws look the same. Strict stationarity demands this for every finite-dimensional distribution; wide-sense stationarity asks it only of the mean and autocovariance. Ergodicity goes further: one long record can estimate those statistics. These ideas let engineers treat a noisy signal or a server load trace as one sample path, not a fresh experiment at every instant.

You need Unit 2 expectation, Unit 4 covariance, and 7.1 for random processes and sample paths.

Strict-sense stationarity

Let X(t) be a random process: a random variable at each time t. Pick times t₁, t₂, …, tₙ and a shift h. The process is strict-sense stationary (SSS) if the joint CDF of (X(t₁),…,X(tₙ)) equals the joint CDF of (X(t₁+h),…,X(tₙ+h)) for every n, every set of times, and every shift h. Only the spacing between times matters, not the absolute clock. If X(t)=A with A random but fixed in time, every sample path is constant; at every t the value has the distribution of A, so the process is SSS. Strict stationarity does not require a finite variance.

F_X(x₁,…,xₙ; t₁,…,tₙ) = F_X(x₁,…,xₙ; t₁+h,…,tₙ+h)

F_X is the joint CDF; x₁,…,xₙ are values; t₁,…,tₙ are times; h is any time shift.

Wide-sense stationarity and autocorrelation

Wide-sense stationarity (WSS) keeps only the first two moments fixed. A process X(t) is WSS when its mean μ_X=E[X(t)] is constant, its variance is finite, and its autocovariance C_X(t₁,t₂)=Cov(X(t₁),X(t₂)) depends only on the lag τ=t₂−t₁. Some syllabi call this weakly stationary. Define the autocorrelation R_X(τ)=E[X(t)X(t+τ)]. Then C_X(τ)=R_X(τ)−μ_X².

R_X(τ)=E[X(t)X(t+τ)], C_X(τ)=R_X(τ)−μ_X²

R_X(τ) is the autocorrelation at lag τ; C_X(τ) is the autocovariance; μ_X=E[X(t)] is the constant mean; τ is the time lag.

  • R_X(0)=E[X(t)²]=μ_X²+σ_X²: zero lag gives the mean square, not the variance.
  • R_X(−τ)=R_X(τ): the autocorrelation curve is even.
  • |R_X(τ)|≤R_X(0), by the Cauchy–Schwarz inequality.
  • SSS with finite second moment implies WSS; the converse fails because WSS says nothing about higher moments or the shape of the distribution.

Ergodicity in mean and autocorrelation

Ergodicity means a time average from one long sample path converges to the ensemble average, the expectation over all sample paths. For ergodicity in mean, the time average below tends to μ_X as T→∞, in mean square or probability depending on the definition. For ergodicity in autocorrelation, the time average of X(t)X(t+τ) tends to R_X(τ). Ergodicity is a property of the process, not of one finite record. WSS does not imply ergodicity. If X(t)=A with random A and E[A²] finite, the process is WSS, but its time average is A, not μ_X=E[A]. A random constant offset never forgets its draw, so one record cannot reveal the ensemble mean.

(1/T)∫₀ᵀ X(t)dt → μ_X as T→∞

T is the length of the record; μ_X is the ensemble mean; convergence is in mean square or probability.

Worked example

Question. Let X(t)=2 cos(2πt+Θ) volts, where Θ is uniform on [0,2π). (a) Find μ_X. (b) Find R_X(τ). (c) Find the variance. (d) Is X WSS? (e) Find the time average over a whole number of cycles and compare it with μ_X.

  1. Mean: μ_X=E[2 cos(2πt+Θ)] = 2·(1/2π)∫₀^{2π} cos(2πt+θ)dθ = 0 V, because the integral of cosine over a full period is zero.
  2. Autocorrelation: R_X(τ)=E[4 cos(2πt+Θ) cos(2π(t+τ)+Θ)]. Use cos A cos B = ½[cos(A−B)+cos(A+B)]. Here A−B=−2πτ, so cos(A−B)=cos(2πτ). The term cos(4πt+2πτ+2Θ) averages to 0 over Θ. Hence R_X(τ)=4·½ cos(2πτ)=2 cos(2πτ) V².
  3. Variance: Var(X(t))=E[X(t)²]−μ_X²=R_X(0)−0²=2 cos 0=2 V².
  4. WSS check: μ_X=0 V constant; variance=2 V² finite; C_X(τ)=R_X(τ)−μ_X²=2 cos(2πτ) V² depends only on τ. So X is WSS.
  5. Time average over n whole cycles, period T=1 s: (1/(nT))∫₀^{nT}2 cos(2πt+θ)dt=0 V for every θ, because each full cycle integrates to zero. This equals μ_X, so the time average agrees with the ensemble mean.

Answer. μ_X=0 V, R_X(τ)=2 cos(2πτ) V², variance=2 V²; X is WSS, and its time average over whole cycles is 0 V, equal to μ_X.

Exam traps

  • WSS does not require a Gaussian distribution, and it does not require ergodicity. It fixes only the mean and autocovariance.
  • Strict stationarity with infinite variance need not be WSS; WSS needs a finite second moment.
  • Do not replace R_X(0) by variance. R_X(0)=E[X²]=μ_X²+σ_X²; variance=R_X(0)−μ_X².
  • Ergodicity is about one long sample path. A WSS process with a random constant offset is a standard counterexample.
  • Autocorrelation R_X(τ) and autocovariance C_X(τ) differ by μ_X². They are equal only when the mean is zero.

7.3 Poisson process and renewal processes

A Poisson process counts events that arrive one at a time, independently, at a constant average rate. It answers questions such as how many UPI requests hit a server in the next minute, or how long until the next bus. The count in an interval has a Poisson distribution, and the gaps between events have an exponential distribution. A renewal process keeps the independent-gap idea but allows any gap law. These models feed queueing, reliability and the continuous-time Markov chains of 7.6.

You need: the Poisson and exponential distributions from Unit 3; 7.1 for the idea of a random process.

What a Poisson process counts

A Poisson process models events that arrive one at a time, independently, at a constant average rate. Write N(t) for the number of events in the time interval [0,t]. The rate is λ events per unit time. For example, λ=0.5 per hour means half a call per hour on average.

The process has three defining properties. N(0)=0. Counts in disjoint time intervals are independent (independent increments). The count in any interval of length t has the same distribution wherever the interval sits (stationary increments).

P(N(t) = k) = e<sup>−λt</sup> (λt)<sup>k</sup> / k!, k = 0, 1, 2, ...

N(t) is the count by time t; λ is the rate per unit time; e is 2.718...; k! = 1×2×...×k. The mean and variance are both λt.

Mean and variance equal λt. A Poisson count therefore has spread equal to its average. Over 6 hours at λ=0.5 per hour, N(6) has mean 3 and variance 3. Some syllabi call the Poisson process a pure birth process because the count only goes up by one.

Interarrival times, merging and thinning

Let T1, T2, ... be the gaps between successive events. For a Poisson process these interarrival times are independent and identically distributed exponential random variables with mean 1/λ. The exponential distribution is memoryless: after a wait, the remaining wait has the same distribution (see Unit 3, Exponential distribution and the memoryless property).

P(T > t) = e−λt, t ≥ 0

T is one interarrival time; λ is the rate per unit time; the mean is 1/λ and the variance is 1/λ².

The k-th arrival time Sk = T1 + ... + Tk is gamma (Erlang) with shape k and rate λ. Its mean is k/λ. The first three arrival times in the figure are 2 h, 6 h and 7 h.

  • Merging: if two independent Poisson processes have rates λ1 and λ2, their combined events form a Poisson process with rate λ1+λ2.
  • Thinning: if each event is kept independently with probability p, the kept events form a Poisson process with rate λp.

These two rules let you split or combine call streams. A help desk with two independent call types can be analysed as one stream, or one stream can be split by type.

Renewal processes: the same idea with any gap law

A renewal process keeps the independent interarrival idea but drops the exponential requirement. The interarrival times T1, T2, ... are iid with mean μ and variance σ². N(t) still counts events by time t. The process renews after every event.

The renewal function is m(t)=E[N(t)], the expected number of renewals by time t. For a Poisson process μ=1/λ and m(t)=λt exactly. For general interarrival laws m(t) is not simply t/μ at small t.

m(t)/t → 1/μ as t → ∞

m(t) is the expected count by time t; μ is the mean interarrival time; the limit is the elementary renewal theorem. The long-run renewal rate is 1/μ events per unit time.

Use renewal models for machine replacement, warranty claims and repairable systems. The exponential case is the Poisson process; other gap laws give the same long-run rate but different short-run behaviour. Continuous-time Markov chains in 7.6 use exponential sojourns, so the Poisson process is their simplest counting example.

Worked example

Question. A help desk receives calls as a Poisson process with rate λ=0.5 per hour. (a) Find the probability of no call in 2 hours. (b) Find the mean and variance of the number of calls in 6 hours. (c) The first three interarrival times are 2 h, 4 h and 1 h; find the first three arrival times.

  1. Write λ=0.5 h⁻¹. For an interval of length t, N(t) is Poisson with mean λt.
  2. (a) t=2 h, so λt=0.5×2=1. P(N(2)=0)=e−1×10/0!=e−1=0.3679.
  3. (b) t=6 h, so λt=0.5×6=3. For a Poisson random variable mean=λt=3 and variance=λt=3.
  4. (c) Arrival times are cumulative sums. S1=2 h. S2=2+4=6 h. S3=6+1=7 h.

Answer. The probability of no call in 2 hours is 0.3679; in 6 hours the mean and variance are both 3 calls; the first three arrival times are 2 h, 6 h and 7 h.

Exam traps

  • Do not use e−λt for the count probability when k>0; use e−λt(λt)k/k!.
  • The exponential formula gives waiting time, not count. P(T>t)=e−λt is for the gap, not P(N(t)=k).
  • Use the interval length in λt. A rate of 0.5 per hour over 30 minutes gives λt=0.25, not 0.5.
  • Mean and variance of a Poisson count are equal. If a question asks for standard deviation, take √(λt).
  • In a renewal process with non-exponential gaps, m(t) is not λt. Only the long-run rate 1/μ is simple.

7.4 Discrete-time Markov chains: transition matrix, classification of states

A discrete-time Markov chain is a random process that moves between states at integer times. Its defining feature is the Markov property: once the present state is known, the past tells you nothing more about the next state. One matrix, the transition matrix P, stores every one-step probability. Powers of P give two-step, three-step and n-step probabilities. Weather forecasts, queue lengths at a ticket counter, credit ratings and page-rank all use this model because it turns a random story into matrix arithmetic.

You need: conditional probability from Unit 2, joint distributions from Unit 4, and 7.1 on random processes.

The Markov property and P

Take a system observed at integer times n = 0, 1, 2, …. At each time it sits in one state. The random variable Xₙ is the state at time n. The set of possible states is the state space S; write S = {1, 2, …, N} when it has N states. A discrete-time Markov chain has the Markov property: for every i and j, P(Xn+1 = j | Xn = i, past) = P(Xn+1 = j | Xn = i). The left side conditions on the whole past; the right side uses only the present. The chain forgets the past once the present is fixed.

The chain is homogeneous if P(Xn+1 = j | Xn = i) does not depend on n. Then define Pij = P(Xn+1 = j | Xn = i). The matrix P has rows labelled by current state i and columns by next state j. Its entry in row i, column j is Pij. Every entry satisfies Pij ≥ 0, and every row sums to 1: Σj Pij = 1. The row sum is 1 because from state i the next state must be one of the states j. Some syllabi call P the transition probability matrix. The weather chain in the figure uses states S (sunny) and R (rainy).

Multi-step probabilities

The n-step transition probability is Pij(n) = P(Xn = j | X0 = i). For n = 2, condition on the middle state X1 = k and sum over k. This gives the Chapman–Kolmogorov equation Pij(n+m) = Σk Pik(n) Pkj(m). The sum runs over every state k; it is the probability of going from i to k in n steps and then k to j in m steps.

In matrix form, P(n) = Pn, the ordinary n-fold matrix product. So P² = P × P, not the elementwise square. The (i, j) entry of P² is Σk Pik Pkj. Three-step probabilities come from P³ = P² × P. Every Pn is again a transition matrix: its entries are non-negative and its rows sum to 1. This is the engine of the chapter: one P generates every future probability. Steady-state limits are in 7.5.

Classifying states

State j is accessible from state i if Pij(n) > 0 for some n ≥ 0. States i and j communicate if i is accessible from j and j is accessible from i. Communication splits the state space into classes. A chain is irreducible if it has one class: every state can reach every other state.

A state i is recurrent if the probability of returning to i at some future time, starting from i, is 1. It is transient if that probability is less than 1. A recurrent state is positive recurrent if its expected return time is finite. In a finite irreducible chain every state is positive recurrent.

The period of state i is d(i) = gcd{ n ≥ 1 : Pii(n) > 0 }, the greatest common divisor of the times at which a return is possible. If d(i) = 1 the state is aperiodic. A self-loop Pii > 0 makes d(i) = 1. A state with Pii = 1 is absorbing: once entered, the chain never leaves. An irreducible positive recurrent aperiodic chain is called ergodic in some syllabi.

Keep the words apart. Accessible is one-way; communicate is two-way. Recurrent is about return probability; positive recurrent is about finite mean return time. Periodic is about the gcd of return times, not about whether a return is possible.

Worked example

Question. A weather chain has states S (sunny) and R (rainy). Its one-step transition matrix is P = [[0.8, 0.2], [0.3, 0.7]], with rows S, R. (a) Draw the state diagram. (b) Find P². (c) Classify the chain: irreducible? aperiodic? recurrent? positive recurrent?

  1. Read the rows. From S: PSS = 0.8 and PSR = 0.2. From R: PRS = 0.3 and PRR = 0.7. Each row sums to 1.0. Draw self-loops S→S and R→R, and cross arrows S→R with 0.2 and R→S with 0.3.
  2. Compute the (S, S) entry of P²: PSSPSS + PSRPRS = 0.8×0.8 + 0.2×0.3 = 0.64 + 0.06 = 0.70.
  3. Compute the (S, R) entry: PSSPSR + PSRPRR = 0.8×0.2 + 0.2×0.7 = 0.16 + 0.14 = 0.30. Row S sums to 1.00.
  4. Compute the (R, S) entry: PRSPSS + PRRPRS = 0.3×0.8 + 0.7×0.3 = 0.24 + 0.21 = 0.45.
  5. Compute the (R, R) entry: PRSPSR + PRRPRR = 0.3×0.2 + 0.7×0.7 = 0.06 + 0.49 = 0.55. Row R sums to 1.00. So P² = [[0.70, 0.30], [0.45, 0.55]].
  6. Irreducible: S reaches R in one step with probability 0.2, and R reaches S in one step with probability 0.3. All states communicate, so there is one class.
  7. Aperiodic: PSS = 0.8 > 0, so S has a self-loop and period 1. PRR = 0.7 > 0, so R also has period 1.
  8. Recurrent and positive recurrent: the chain is finite and irreducible, so every state is recurrent. A finite irreducible chain is positive recurrent.

Answer. P² = [[0.70, 0.30], [0.45, 0.55]]; the chain is irreducible, aperiodic and positive recurrent.

Exam traps

  • Rows sum to 1, not columns. This book uses row-stochastic P. A column-stochastic version is the transpose; check which convention your exam uses.
  • P² is the matrix product P × P, not the elementwise square. Elementwise squaring gives wrong two-step probabilities.
  • Pij = 0 does not mean j is unreachable. Reachability allows some n ≥ 1 through other states.
  • Period is the gcd of return times. A state can have Pii = 0 and still be aperiodic if returns occur at times with gcd 1, such as 2 and 3.
  • Irreducible does not mean recurrent for infinite state spaces. A finite irreducible chain is recurrent and positive recurrent; an infinite irreducible chain can be transient.

7.5 Limiting and steady-state distributions

A Markov chain moves probabilities from state to state. A steady-state distribution is a probability vector π that the transition matrix leaves unchanged: after one step the distribution is still π. A limiting distribution is the long-run distribution that pn approaches as n grows. For a finite, irreducible, aperiodic chain the two coincide and are unique. Engineers use this to predict long-run load, failure rates, queue occupancy, and weather-like repeated experiments without simulating every step.

You need: transition matrices and state classification from 7.4, and probability vectors from Unit 2, Probability and Random Variables.

Stationary distribution: the fixed point

Let pn be a row vector. Its i-th entry is the probability that the chain is in state i after n steps. Let P be the one-step transition matrix; Pij is the probability of moving from i to j in one step. The chain updates by pn+1 = pnP. A stationary distribution is a row vector π with non-negative entries that sum to 1 and satisfies π = πP. If the chain starts with distribution π, then every later distribution is also π. The chain's probability mass is balanced: the flow into each state equals the flow out.

π = πP,  Σ<sub>i</sub> π<sub>i</sub> = 1,  π<sub>i</sub> ≥ 0

π is a row probability vector; P is the transition matrix; πi is the long-run fraction of time in state i under the conditions in the next section.

For a finite, irreducible, aperiodic chain, exactly one such π exists. Irreducible means every state can reach every other state. Aperiodic means the chain is not forced to return only at times that are multiples of some period greater than 1. Some syllabi call π the equilibrium distribution or the invariant distribution. It is not generally the vector of one-step transition probabilities, and it is not the same as the initial distribution.

Limit, periodicity and recurrence

The limiting distribution is the vector limn→∞ pn, when this limit exists and does not depend on the starting distribution. For a finite irreducible aperiodic chain, the limit exists and equals the unique stationary π. Then πi is also the long-run fraction of steps spent in state i.

Periodicity breaks the equality. Take P = [[0,1],[1,0]]. The stationary distribution is π = (1/2,1/2). If p0 = (1,0), then p1 = (0,1), p2 = (1,0), and so on. The sequence has no limit, although π is stationary. Reducibility also breaks uniqueness: a chain with two separate closed classes can have many stationary distributions.

The mean recurrence time mi is the expected number of steps between two successive visits to state i, including the return step. For an irreducible positive recurrent chain, mi = 1/πi. A large πi means state i is common and returns quickly; a small πi means it is rare and returns slowly.

Solving the equations

Write the unknown row vector π = (π1,...,πk). The matrix equation π = πP gives k scalar equations. One equation is redundant because the rows of P sum to 1. Replace any one equation with the normalisation Σπi=1, then solve the remaining linear system. Check every πi ≥ 0.

  1. Write π = πP as π(I − P) = 0, where I is the identity matrix.
  2. Drop one dependent scalar equation.
  3. Add Σπi = 1.
  4. Solve for π1,...,πk.
  5. Check πi ≥ 0 and Σπi = 1.

For two states with P = [[1−a, a],[b, 1−b]], where a is the probability of leaving state 1 and b is the probability of leaving state 2, the stationary distribution is π = (b/(a+b), a/(a+b)) when a+b > 0. This shortcut comes from π1(1−a)+π2b = π1, which simplifies to aπ1 = bπ2. The same equation plus π1+π2=1 gives the result.

Worked example

Question. Days in a city are either Sunny (S) or Rainy (R). The one-step transition matrix is P = [[0.8,0.2],[0.3,0.7]], with rows S and R. On day 0 it is Sunny, so p0 = (1,0).   4. Then πS=1−0.4=0.6. Thus π=(0.6,0.4).
  5. For this two-state chain a=0.2 and b=0.3. The second eigenvalue is 1−a−b=0.5. Hence pn(S)=πS+(p0(S)−πS)(0.5)n = 0.6+(1−0.6)(0.5)n = 0.6+0.4(0.5)n.
  6. Check n=0: 0.6+0.4=1. Check n=1: 0.6+0.2=0.8, which equals PSS=0.8.
  7. As n→∞, (0.5)n→0, so the limit is 0.6.
  8. Mean recurrence time of S is 1/πS=1/0.6=1.6666666666666667 days. For R it is 1/0.4=2.5 days.

Exam traps

  • A stationary distribution can exist while the limit does not: P=[[0,1],[1,0]] has π=(1/2,1/2), but pn alternates from (1,0).
  • Do not omit Σπi=1. The equation π=πP alone leaves any multiple of π as a solution.
  • For a reducible chain, stationary distributions are not unique. The long-run fraction can depend on the starting state.
  • Use row vectors with π=πP for the convention in this chapter. Writing Pπ=π with column vectors is also valid, but mixing the two transposes the matrix.
  • Mean recurrence time is 1/πi, not πi. If πi=0.2, the mean return is 5 steps, not 0.2.

7.6 Continuous-time Markov chains and Markov processes

A continuous-time Markov chain moves at random times, not on a fixed clock. After entering a state it waits for an exponential sojourn, then jumps to another state. The memoryless exponential keeps the future dependent only on the present state. Engineers use it for queues, call centres, machine failure and repair, and chemical reaction networks. Rates, not probabilities, describe the motion, so the generator matrix replaces the discrete transition matrix.

You need discrete-time chains for the jump chain and Unit 3, the exponential distribution for sojourn times.

The clock waits, then jumps

Let {X(t): t ≥ 0} be a random process with a countable state space S. It is a continuous-time Markov chain (CTMC) when, for every state j and every history up to time s, P(X(t+s)=j | X(u), 0≤u≤s) = P(X(t+s)=j | X(s)). The future depends on the past only through the present state. The general name is a Markov process; a CTMC is the countable-state case.

After the chain enters state i, it stays there for a random sojourn T_i, then jumps. In a CTMC, T_i is exponential with rate λ_i > 0: P(T_i > t)=e−λ_i t and E[T_i]=1/λ_i. The exponential is memoryless (Unit 3), so however long the chain has already waited in i, the remaining wait has the same distribution. That property makes the Markov description valid at every instant.

Transition probabilities are P_ij(t)=P(X(t)=j | X(0)=i), the chance of being in j after t time units given a start in i. Collect them in the matrix P(t). Then P(0)=I, the identity.

P_ij(t) = P(X(t) = j | X(0) = i), P(0) = I

P_ij(t) is the transition probability from state i to state j in t time units; P(t) is the matrix of these probabilities; I is the identity matrix.

Generator Q and the jump chain

Rates replace one-step probabilities. For i≠j, q_ij ≥ 0 is the rate of jumps from i to j, with unit 1/time. Some syllabi call Q the infinitesimal generator or rate matrix. The diagonal entry is q_ii = −Σ_{j≠i} q_ij. Thus every row of Q sums to 0, and q_ii ≤ 0.

The total rate out of state i is λ_i = −q_ii. The sojourn time in i is exponential with rate λ_i and mean 1/λ_i. On a jump from i, the next state is j with probability p_ij = q_ij / (−q_ii) for j≠i, and p_ii=0. The discrete chain with these p_ij is the jump chain: it records where the chain goes, not when.

q_ii = −Σ_{j≠i} q_ij, p_ij = q_ij / (−q_ii)

q_ij for i≠j is the jump rate from i to j; q_ii is the negative total exit rate; p_ij is the probability that the jump chain goes from i to j.

Figure values: q_01=2 per hour and q_10=3 per hour. Then q_00=−2, q_11=−3, and Q = [[−2, 2], [3, −3]]. The jump chain has p_01=1 and p_10=1 because each state has only one exit.

Kolmogorov equations and steady state

Kolmogorov equations tie P(t) to Q. The forward equations are P′(t)=P(t)Q, and the backward equations are P′(t)=QP(t), with P(0)=I. In entries, P′_ij(t)=Σ_k P_ik(t) q_kj for the forward form. For a finite state space these equations give all transition probabilities from the rates.

A stationary distribution π is a probability vector with πQ=0 and Σ_i π_i=1. It gives the long-run fraction of time in each state when the chain is irreducible and positive recurrent. Do not confuse π with a row of P(t). The stationary distribution of the jump chain generally differs because the CTMC spends longer in slowly exited states.

πQ = 0, Σ_i π_i = 1

π is the stationary row vector; π_i is the long-run fraction of time in state i; Q is the generator.

Birth–death process: states 0,1,2,...; from n the chain goes to n+1 at rate λ_n or to n−1 at rate μ_n (μ_0=0). Its generator has q_n,n+1=λ_n, q_n,n−1=μ_n, and q_nn=−(λ_n+μ_n). A Poisson process is the pure-birth case μ_n=0 and λ_n=λ: counts rise by one at rate λ and never fall. See 7.3.

Question. A two-state CTMC has jump rate 2 per hour from state 0 to state 1 and 3 per hour from state 1 to state 0. (a) Write Q. (b) Find the stationary distribution. (c) Find the mean sojourn time in each state in hours and minutes.

  2. Rate out of state 1 is 3 per hour, so q_11 = −3 and q_10 = 3. Thus Q = [[−2, 2], [3, −3]].

Exam traps

  • Q row sums are zero, not one. The off-diagonal rates in a row add to −q_ii, not to 1.
  • Off-diagonal q_ij are rates, so they can exceed 1 and carry unit 1/time. They are not probabilities.
  • q_ii is negative, or zero for an absorbing state. Forgetting the sign gives a negative mean sojourn time.
  • Mean sojourn in state i is 1/(−q_ii), using the total exit rate. It is not 1/q_ij for one chosen exit j.
  • The stationary distribution solves πQ=0 with Σπ_i=1. Do not normalise Q rows or use the discrete-time equation π=πP.

7.7 Autocorrelation, cross-correlation and power spectral density

Autocorrelation compares a random signal with a delayed copy of itself. Cross-correlation compares two different signals at different lags. The Fourier transform of the autocorrelation gives the power spectral density (PSD), which shows how power is spread over frequency; the transform of the cross-correlation gives the cross-PSD. Engineers use these tools to find hidden periods in sensor data, to detect a radar echo, to tune filters, and to describe noise in a communication link. The ideas need only wide-sense stationarity: a constant mean and an autocorrelation that depends on the lag alone.

You need: <a href='#stationary-processes-strict-sense-wide-sense-ergodicity'>7.2 Stationary processes for wide-sense stationarity, and Unit 4, Covariance.

Autocorrelation of a WSS process

A wide-sense stationary (WSS) process X(t) has a constant mean μX and an autocorrelation that depends only on the time lag τ. The autocorrelation is RX(τ)=E[X(t)X(t+τ)]. Here E[·] is expectation, t is any time, and τ is the shift in seconds. RX(τ) measures how strongly a sample at time t resembles a sample τ seconds later.

At τ=0, RX(0)=E[X²(t)]. This is the mean-square value, also called the total average power of the process. If X(t) is a voltage in volts, RX(τ) has units of volts squared. The autocovariance removes the mean: CX(τ)=RX(τ)−μX². At τ=0 it gives the variance σX²=CX(0). When μX=0, autocorrelation and autocovariance are the same.

R<sub>X</sub>(τ)=E[X(t)X(t+τ)],   C<sub>X</sub>(τ)=R<sub>X</sub>(τ)−μ<sub>X</sub><sup>2</sup>

RX(τ) is the autocorrelation; CX(τ) is the autocovariance; μX=E[X(t)] is the constant mean; τ is the time lag.

Three properties are useful in exams. First, RX(−τ)=RX(τ): autocorrelation is even for a real process. Second, |RX(τ)|≤RX(0): the peak is at zero lag. Third, a periodic component in X(t) leaves a periodic ripple in RX(τ), which is how period detection works.

Cross-correlation and power spectral density

For two WSS processes X(t) and Y(t), the cross-correlation is RXY(τ)=E[X(t)Y(t+τ)]. It measures how much X at time t looks like Y, τ seconds later. The order matters: RYX(τ)=RXY(−τ). Cross-correlation is not even in general. The cross-covariance is CXY(τ)=RXY(τ)−μXμY.

The power spectral density (PSD) shows how the average power of X(t) is distributed over frequency. The Wiener–Khinchin theorem says the PSD is the Fourier transform of the autocorrelation.

S<sub>X</sub>(ω)=∫<sub>−∞</sub><sup>∞</sup> R<sub>X</sub>(τ)e<sup>−jωτ</sup>dτ,   R<sub>X</sub>(τ)=(1/2π)∫<sub>−∞</sub><sup>∞</sup> S<sub>X</sub>(ω)e<sup>jωτ</sup>dω

SX(ω) is the power spectral density; ω is angular frequency in rad/s; j is the imaginary unit; the integrals run over all real values.

For a real process, SX(ω) is real, even, and non-negative: SX(ω)≥0 for every ω. A computed PSD that goes negative signals an algebra error.

Total average power is recovered by integrating the PSD: RX(0)=(1/2π)∫−∞∞ SX(ω)dω. The factor 1/(2π) appears because the transform is in ω, not in ordinary frequency f=ω/(2π). For two processes, the cross-PSD is SXY(ω)=∫RXY(τ)e−jωτdτ. It is complex in general.

Autocorrelation matrix for a random vector

For a random vector X=[X1,...,Xn]T, the autocorrelation matrix RX is an n×n matrix with entries (RX)ij=E[XiXj]. Its diagonal entry (RX)ii=E[Xi²] is a mean-square value, not a variance unless E[Xi]=0.

The matrix is symmetric and positive semidefinite. For any real vector a, aTRXa=E[(aTX)²]≥0. The autocovariance matrix is CX=RX−μμT, where μ=E[X] is the mean vector. These matrices appear in array processing, beamforming, and principal component analysis.

Worked example

Question. A zero-mean WSS process X(t) has autocorrelation RX(τ)=4e−2|τ|, with τ in seconds. Find the variance, the total average power, and the power spectral density SX(ω).

  1. The mean is μX=0. The variance is CX(0)=RX(0)−μX².
  2. RX(0)=4e0=4. Thus variance = 4−0 = 4 (power units; volts squared if X is a voltage).
  3. Total average power = RX(0)=4.
  4. Use the standard transform ∫−∞∞e−a|τ|e−jωτdτ=2a/(a²+ω²) for a>0.
  5. Here a=2, so SX(ω)=4·(2·2)/(2²+ω²)=16/(4+ω²).

Answer. Variance = 4, total average power = 4, and SX(ω)=16/(4+ω²) (power units per rad/s).

Exam traps

  • RX(0) is total average power, not variance unless μX=0. For variance, use CX(0)=RX(0)−μX².
  • The PSD transform is over the lag τ, not over t. Writing ∫RX(t)e−jωtdt confuses the time index with the lag.
  • RXY(τ) is not even in general. Check the order: RYX(τ)=RXY(−τ). Reversing the signals changes the sign of the lag.
  • The inverse formula needs 1/(2π) when ω is in rad/s. Dropping it makes the total power too large by 2π.
  • The diagonal of RX is E[Xi²], not Var(Xi), unless the mean is zero.

7.8 Linear time-invariant systems with random inputs

An LTI system is a filter: input in, output out, and a time shift at the input shifts the output only. A random input gives a random output. Its mean and power spectral density (PSD) pass through simply: one constant for the mean, one factor per frequency for the PSD. Engineers use this to predict noise, design filters, and model sensor drift.

You need: 7.7 for autocorrelation and PSD, and Unit 4 for expectation and covariance.

What an LTI system does to a random input

An LTI system is fixed by its impulse response h(t), the output for a unit spike at time 0. For input X(t), output Y(t) = ∫ h(u) X(t−u) du. Here u is a lag in seconds. h(u) is the impulse-response weight at lag u; the input u seconds earlier is weighted by h(u)du, so h has units of 1/s when input and output share units. Y(t) is a weighted sum of random variables, so it is random.

Take expectations: E[Y(t)] = ∫ h(u) E[X(t−u)] du. For a WSS input with mean μ_X this gives μ_Y = μ_X H(0), where H(0) = ∫ h(u) du is the DC gain. Unit DC gain keeps the mean; H(0) = 0 removes it.

μ_Y = H(0) μ_X

μ_X is the input mean (input units); H(0) = ∫h(u)du is the DC gain, dimensionless if input and output share units; μ_Y is the output mean.

A stable system has ∫|h(u)| du < ∞. Then start-up dies out, and a WSS input gives a WSS output.

Power spectral density through the filter

A sinusoid at frequency ω passes an LTI system unchanged in frequency, scaled by H(ω) = ∫ h(u) e−juω du, the frequency response. Power at ω scales by |H(ω)|², real and non-negative. A stable system creates no new frequencies, so the output PSD is the input PSD times that factor.

S_Y(ω) = |H(ω)|² S_X(ω)

S_X(ω) and S_Y(ω) are power spectral densities in power per rad/s; H(ω) is the frequency response; |H(ω)|² is the power gain at ω.

The same result in time is R_Y(τ) = h(τ) * h(−τ) * R_X(τ), a double convolution. White noise has a flat two-sided PSD. In power per rad/s it is S_X(ω) = N₀/(4π), where N₀ is the one-sided PSD in power per Hz (the two-sided density per Hz is N₀/2). Through a filter it becomes S_Y(ω) = |H(ω)|² N₀/(4π). Average output power is R_Y(0) = (1/2π) ∫ S_Y(ω) dω, because ω is in rad/s.

Worked example

Question. WSS white noise X(t) with two-sided PSD S_X(ω) = 2 power per rad/s drives an RC low-pass filter H(ω) = 1/(1 + j0.5ω), ω in rad/s. Find S_Y(ω), the output mean, and average output power.

  1. |H(ω)|² = 1/(1 + (0.5ω)²) = 1/(1 + 0.25ω²).
  2. S_Y(ω) = 2/(1 + 0.25ω²) power per rad/s.
  3. H(0) = 1, so μ_Y = 1 × 0 = 0.
  4. Power = (1/2π) ∫ 2/(1 + 0.25ω²) dω. Use ∫dω/(1 + a²ω²) = π/a with a = 0.5, giving 2π. So the integral is 4π and power = 4π/(2π) = 2.

Answer. S_Y(ω) = 2/(1 + 0.25ω²) power per rad/s, μ_Y = 0, and average output power is 2.0 units.

Exam traps

  • Use |H(ω)|², not H(ω). A complex or negative S_Y means you forgot the magnitude squared.
  • Output mean is H(0)μ_X. It is zero only if the input mean or H(0) is zero.
  • Two-sided versus one-sided PSD: dropping or adding factor 2 doubles or halves power. For white noise per rad/s, use N₀/(4π), not N₀/2.
  • The average power integral needs 1/2π. Omitting it gives 4π instead of 2 in the worked example.
  • WSS output needs a stable filter, ∫|h(u)|du < ∞.

7.9 Gaussian processes and noise

A Gaussian process is a random process whose values at any finite set of times have a multivariate normal distribution. Its mean function and covariance function fix every such distribution, so these two functions describe the whole process. Gaussian noise uses the same idea for fluctuations: zero mean and a flat power spectral density. Engineers use it for thermal noise in receivers, for sensor errors, and for smoothing noisy data. The model is common because linear operations keep it Gaussian and because only first and second moments are needed.

You need: the multivariate normal from Unit 4, wide-sense stationarity from 7.2, and power spectral density from 7.7.

Definition and why mean and covariance suffice

A random process X(t) is Gaussian if, for every integer n ≥ 1 and every choice of times t₁,…,tₙ, the vector (X(t₁),…,X(tₙ)) has a multivariate normal distribution. Some syllabi call this a normal process. The finite-dimensional condition is the definition; having a normal marginal at each single time is not enough.

X(t) is Gaussian ⇔ (X(t₁),…,X(tₙ)) ~ N(μ, C) for every n and times t₁,…,tₙ

μ is the mean vector with entries μ(tᵢ)=E[X(tᵢ)]; C is the covariance matrix with entries C(tᵢ,tⱼ)=Cov(X(tᵢ),X(tⱼ)).

The mean function μ(t) gives the centre at each time. The covariance function C(s,t) gives the covariance between two times. For a Gaussian process these two functions determine every finite joint density, because a multivariate normal density is fixed by its mean vector and covariance matrix. No higher moments are needed.

If a Gaussian process is wide-sense stationary, μ(t)=μ is constant and C(s,t)=C(s−t)=C(τ). A time shift changes neither the constant mean nor any time difference, so every finite joint distribution is unchanged. Therefore a WSS Gaussian process is strictly stationary. This implication is special to Gaussian processes.

White Gaussian noise

White Gaussian noise W(t) is a Gaussian process with zero mean and autocorrelation R_W(τ)=(N₀/2)δ(τ). Here N₀ is the one-sided noise power spectral density in watts per hertz, δ(τ) is the Dirac delta with unit 1/s, and the factor 1/2 comes from the two-sided convention. The corresponding two-sided power spectral density is flat: S_W(ω)=N₀/2 for all ω.

R_W(τ) = (N₀/2) δ(τ), S_W(ω) = N₀/2

R_W(τ) is the autocorrelation at lag τ in watts; N₀ is the one-sided PSD in W/Hz; δ(τ) is the Dirac delta; S_W(ω) is the two-sided PSD in W/Hz.

Samples at distinct times are uncorrelated because R_W(τ)=0 for τ≠0. They are jointly Gaussian, so uncorrelated implies independent. Thus the ideal continuous-time model has independent samples at every distinct time.

The word white describes the flat spectrum. The word Gaussian describes the amplitude distribution. In the ideal model R_W(0) is infinite, so the variance is infinite; this is a mathematical idealisation. Real thermal noise is bandlimited and has finite power. A receiver's front end is often modelled as white Gaussian noise passed through a bandlimiting filter.

Filtering and receiver noise

Pass a Gaussian process through a linear time-invariant (LTI) system. Every finite collection of output values is a linear combination of jointly Gaussian input values, so the output is also Gaussian. The mean and covariance change according to the system, but Gaussianity is preserved. This is why Gaussian models survive filtering, amplification and mixing.

For an LTI system with frequency response H(ω), the output mean is μ_Y=H(0)μ_X and the output power spectral density is S_Y(ω)=|H(ω)|²S_X(ω). These are the filtering rules from 7.8. For white Gaussian noise input, S_Y(ω)=|H(ω)|²N₀/2; the output is coloured Gaussian noise, not white unless |H(ω)| is constant.

Thermal noise in an antenna or resistor is modelled as white Gaussian noise over the receiver band. Receiver noise adds more such noise. The noise figure measures how much the receiver degrades the signal-to-noise ratio. A bandpass filter around a carrier gives narrowband Gaussian noise, common in radio receivers. In a simulation, you generate independent normal samples, then filter them.

Worked example

Question. A Gaussian process X(t) has mean μ=2 and covariance C(τ)=9e^{−|τ|/2}, where τ is the time lag in seconds. (a) Find P(X(0)≤5). (b) Find Var[X(3)−X(0)]. Use Φ(1)=0.8413.

  1. At t=0, X(0) is normal with mean 2 and variance C(0)=9e⁰=9. Its standard deviation is √9 = 3.
  2. Standardise: P(X(0)≤5)=P(Z≤(5−2)/3)=P(Z≤1)=Φ(1).
  3. From the normal table, Φ(1)=0.8413.
  4. For the difference, Var[X(3)−X(0)] = Var X(3)+Var X(0)−2Cov(X(3),X(0)).
  5. Var X(3)=C(0)=9 and Var X(0)=9.
  6. Cov(X(3),X(0))=C(3−0)=9e^{−|3|/2}=9e^{−1.5}=9×0.22313=2.0082.
  7. So the variance is 9+9−2(2.0082)=18−4.0164=13.9836≈13.98.

Answer. P(X(0)≤5)=0.8413 and Var[X(3)−X(0)]≈13.98 in squared units of X.

Exam traps

  • Normal marginal distributions do not make a Gaussian process. Every finite joint distribution must be multivariate normal.
  • For a WSS Gaussian process, wide-sense stationarity implies strict stationarity. For a non-Gaussian WSS process, it does not.
  • The autocorrelation of ideal white noise is a Dirac delta, not a finite spike. R_W(0) is infinite in the ideal model.
  • N₀/2 is a two-sided PSD. The one-sided PSD is N₀; mixing the factor 2 halves or doubles the noise power.
  • Linear filtering changes the PSD and covariance of Gaussian noise but preserves Gaussianity. Do not assume the output is white.

Takeaways

  1. A random process is one probability space plus a rule that turns each outcome into a whole time function.
  2. Stationarity is about invariance under a time shift; ergodicity is about replacing an ensemble average by a time average.
  3. The Poisson process is the renewal process with exponential interarrivals, and it is the only memoryless one.
  4. The Markov property cuts history down to the present state, so P and its powers carry all the probability information.
  5. For an irreducible aperiodic chain the limiting distribution exists, is unique, and equals the stationary distribution.
  6. In continuous time, exponential sojourn times plus a jump chain give the generator matrix Q, and πQ = 0 replaces π = πP.
  7. The pair R_X(τ) and S_X(ω) are a Fourier pair, so autocorrelation in time and power spread in frequency say the same thing.
  8. An LTI system scales each frequency by |H(ω)|², so it shifts a random signal's mean but never creates new frequencies.
  9. A Gaussian process is fully fixed by its mean and covariance functions, which makes it the standard model for noise.

Glossary

Absorbing state
A state with pᵢᵢ = 1, from which the chain never leaves.
Autocorrelation function
R_X(t₁,t₂) = E[X(t₁)X(t₂)], the expected product of the process at two instants.
Autocovariance
C_X(τ) = R_X(τ) − μ², the autocorrelation with the mean removed.
Communicating states
States i and j communicate when each can be reached from the other with positive probability.
Counting process
A process N(t) that counts the number of events up to time t and never decreases.
Covariance function
K(s,t) = E[(X(s) − μ(s))(X(t) − μ(t))], the second central moment of a process at two instants.
Cross-correlation
R_XY(τ) = E[X(t)Y(t+τ)], the expected product of two different processes at a lag τ.
Embedded jump chain
The discrete chain of successive states visited, ignoring the waiting times.
Independent increments
Counts in disjoint time intervals are independent random variables.
Index set
The set T of time instants at which the process is observed; discrete for sequences, continuous for signals.
Lag
The time difference τ = t₂ − t₁ at which a WSS autocorrelation is evaluated.
Mean function
μ_X(t) = E[X(t)], the average value of the process at time t.
Memoryless property
P(X > s + t | X > s) = P(X > t); only the exponential and geometric laws have it.
Narrowband process
A process whose power spectral density is concentrated around a single carrier frequency.
Period of a state
The greatest common divisor of the return times n with pᵢᵢ⁽ⁿ⁾ > 0.
Positive recurrent
A recurrent state whose mean recurrence time is finite.
Renewal function
m(t) = E[N(t)], the expected number of renewals up to time t.
Sojourn time
The random time a continuous-time chain spends in a state before jumping; exponential with rate −qᵢᵢ.
State space
The set of values the random variable X(t) can take.
Stationary increments
The distribution of the count in an interval depends only on the interval length.
Transfer function H(ω)
The frequency response of an LTI system, equal to the Fourier transform of its impulse response.
Transient state
A state the chain may leave and never return to; Σₙ pᵢᵢ⁽ⁿ⁾ converges.
White noise
A zero-mean WSS process whose autocorrelation is a delta and whose spectrum is flat.
Wiener–Khinchin theorem
The power spectral density is the Fourier transform of the autocorrelation function of a WSS process.
