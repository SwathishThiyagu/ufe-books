3.1 Binomial distribution

A binomial count is the number of successes in a fixed number of independent yes/no trials, when every trial has the same success probability p. It exists because many real counts are made of repeated yes/no actions: payments that fail, cricket balls that hit a boundary, components that pass inspection. The binomial probability mass function gives the chance of exactly k successes in n trials. You will use it for quality checks, surveys, risk counts and A/B test results.

You need: random variables, expectation and variance from Unit 2; factorials; and binomial coefficients C(n,k).

Bernoulli trials and the binomial count

Call one trial Bernoulli when it has exactly two outcomes: success and failure. The success probability p is the same on every trial. Trials are independent: the result of one trial does not change p for the next.

Fix n before you start. Let X be the number of successes in those n trials. X can take only whole values 0,1,...,n. This X has a binomial distribution, written X ~ Bin(n,p). Some syllabi call it the Bernoulli counting distribution; the single-trial version is sometimes called the point binomial.

The probability of exactly k successes comes from two parts. First, choose which k of the n trials are successes; this can be done in C(n,k) ways. Second, every such pattern has probability pᵏ(1−p)ⁿ⁻ᵏ. Multiply.

P(X = k) = C(n,k) pᵏ(1 − p)ⁿ⁻ᵏ, k = 0,1,...,n

n is the fixed number of trials; p is the success probability on one trial; k is the number of successes; C(n,k) = n!/(k!(n−k)!) is the number of ways to choose k successes; 1 − p is the failure probability.

A single term P(X=k) is the probability mass function (pmf). The values add to 1 over k=0,...,n. In a phone exam, use a calculator or a binomial table for C(n,k); do not expand factorials by hand unless n is small.

Mean, variance and adding binomial counts

For X ~ Bin(n,p), the mean is E[X]=np. If you check 50 payments and each fails with p=0.1, the average number of failures is 50×0.1=5 payments. The variance is Var(X)=np(1−p). Its square root is the standard deviation. These formulas come from writing X as a sum of n independent 0/1 trial counts.

E[X] = np,   Var(X) = np(1 − p),   SD(X) = √(np(1 − p))

E[X] is the mean count; Var(X) is the variance; SD(X) is the standard deviation; n is the number of trials; p is the success probability.

The shape depends on p. At p = 0.5 the pmf is symmetric: P(X = k) = P(X = n − k). If p < 0.5 the pmf is skewed right, with a longer right tail. If p > 0.5 it is skewed left, with a longer left tail. For small n, read the pmf from the formula. For rare events with large n and small p, see Poisson distribution. For large n with np and n(1−p) both not small, the normal approximation is in normal distribution.

Independent binomial counts with the same p add. If X ~ Bin(n,p) and Y ~ Bin(m,p) are independent, then X+Y ~ Bin(n+m,p). The same p is required. Counts from groups with different p do not add to a binomial. This rule is used when two shifts or two servers combine counts under one failure rate.

Cumulative probabilities and complements

You often need a range, not one exact value. P(X ≤ a) is the sum of the pmf from k=0 to k=a. For "at least a", use P(X ≥ a)=1−P(X ≤ a−1). For "between a and b" with whole-number limits, use P(X ≤ b)−P(X ≤ a−1). This avoids adding many terms one by one.

  1. Write the range you need as whole-number limits for k.
  2. For P(X ≤ a), add P(X=k) from k=0 to k=a.
  3. For P(X ≥ a), compute 1 − P(X ≤ a−1).
  4. For P(a ≤ X ≤ b), compute P(X ≤ b) − P(X ≤ a−1).

Check that every probability lies between 0 and 1. Check that the terms over all k add to 1; this catches a missing binomial coefficient. If n is large, direct sums are slow. The Poisson approximation helps when n is large and p is small; see Poisson distribution. The normal approximation helps when np and n(1−p) are both not small; see normal distribution. For exact exam answers, use the binomial formula or a binomial table unless the question asks for an approximation.

Worked example

Question. A UPI payment fails with probability 0.2 independently. In 10 payments, find P(X = 3) and P(X ≤ 2).

  1. Define X = number of failed payments in n=10. X ~ Bin(10,0.2), so p=0.2 and q=1−p=0.8.
  2. For P(X=3), compute C(10,3)=10!/(3!7!)=120.
  3. Compute p³=0.2³=0.008 and q⁷=0.8⁷=0.2097152.
  4. P(X=3)=120×0.008×0.2097152=0.201326592≈0.2013.
  5. For P(X≤2)=P0+P1+P2.
  6. P0=0.8¹⁰=0.1073741824.
  7. P1=10×0.2×0.8⁹=10×0.2×0.134217728=0.268435456.
  8. P2=C(10,2)×0.2²×0.8⁸=45×0.04×0.16777216=0.301989888.
  9. Sum: 0.1073741824+0.268435456+0.301989888=0.6777995264≈0.6778.

Answer. P(X = 3) = 0.2013 and P(X ≤ 2) = 0.6778; the chance of exactly three failures is 0.2013, and the chance of at most two failures is 0.6778.

Exam traps

  • Using the binomial when p changes between trials. If each trial has a different success probability, the count is not Bin(n,p).
  • Forgetting the binomial coefficient C(n,k). The factor pᵏ(1−p)ⁿ⁻ᵏ alone is the probability of one particular pattern, not of all patterns with k successes.
  • "At most 2" means k=0,1,2, not k≤3. "At least 2" means k=2,...,n, often computed as 1−P(X≤1). "At least one" is 1−P(X=0).
  • Adding two binomial counts with different p. X+Y is binomial only when the success probability is the same and the groups are independent.
  • Confusing variance np(1−p) with standard deviation. The standard deviation is √(np(1−p)).

3.2 Poisson distribution

The Poisson distribution counts how many times a rare event happens in a fixed interval—one minute, one page, one kilometre—when events do not affect each other and the average rate stays constant. It exists because binomial counting becomes awkward when trials are many and successes are few. A call centre uses it to plan staffing for calls per minute; insurance uses it for claims per day; networks use it for packet arrivals. This chapter gives the probability formula, the mean and variance, the binomial limit, and the addition rule.

You need: discrete random variables, expectation and variance from Unit 2, and the binomial distribution from Chapter 3.1.

The Poisson probability formula

Call the count X. X is Poisson with mean λ (Greek lambda) when it counts events in a fixed interval, events occur one at a time, one event does not change the chance of another, and the average rate is constant for that interval. λ has units of events per interval. For calls per minute, λ=4 means four calls per minute on average.

P(X = k) = e^−λ λ^k / k!, k = 0, 1, 2, ...

P(X = k) is the probability of exactly k events; λ is the mean number of events per interval; e = 2.71828... is Euler's number; k! = 1×2×...×k and 0! = 1.

P(X = 0) = e^−λ and P(X = 1) = λ e^−λ. The mean is E(X) = λ and the variance is Var(X) = λ, so the standard deviation is √λ. For λ=4, P(X=3)=e^−4 4^3/3!=0.1954 and P(X=4)=e^−4 4^4/4!=0.1954.

The values k have no fixed upper limit; P(X=k) becomes small but never exactly zero. For λ=4 the largest probabilities are at k=3 and k=4.

From binomial to Poisson

The binomial count X~Bin(n,p) counts successes in n independent trials, each with success probability p. Its pmf is P(X=k)=C(n,k)p^k(1−p)^{n−k}, where C(n,k)=n!/(k!(n−k)!). Fix λ=np, the average count. Let n grow and p shrink.

P(X = k) = C(n,k) p^k (1−p)^{n−k} → e^−λ λ^k / k!

λ = np is held fixed; n → ∞ and p → 0; C(n,k) is the binomial coefficient.

Step by step, write p=λ/n. Then C(n,k)p^k = [n(n−1)...(n−k+1)/n^k] (λ^k/k!). The bracket tends to 1. Also (1−λ/n)^n tends to e^−λ and (1−λ/n)^{−k} tends to 1. The product gives the Poisson pmf. This limit is why some syllabi call it the law of rare events. It works well when n is large, p is small and λ=np is moderate; it is a guide, not a proof for a given dataset.

The recurrence P(X=k) = (λ/k) P(X=k−1), for k≥1, builds each probability from the previous one. Start with P(X=0)=e^−λ.

Changing the interval and adding independent counts

λ scales with the length of the interval. If calls arrive at λ=4 per minute, then in 5 minutes λ=20 and in 30 seconds λ=2. P(no calls in 30 seconds)=e^−2=0.1353. P(no calls in 5 minutes)=e^−20=2.06×10^−9. A common mistake is to use the one-minute λ for a five-minute question.

X ~ Poisson(λ₁), Y ~ Poisson(λ₂), independent → X + Y ~ Poisson(λ₁ + λ₂)

X and Y are counts in the same interval type; λ₁ and λ₂ are their mean counts; the counts must be independent.

Adding counts follows from the convolution. For k ≥ 0, P(X+Y=k) = Σ (i from 0 to k) [e^−λ₁ λ₁^i/i!] × [e^−λ₂ λ₂^(k−i)/(k−i)!]. Factor out e^−(λ₁+λ₂) and use the binomial theorem to get e^−(λ₁+λ₂) × (λ₁+λ₂)^k/k!, so X+Y ~ Poisson(λ₁+λ₂). The product e^−λ₁ e^−λ₂ = e^−(λ₁+λ₂) is only the k = 0 case (no events in either count). The mean of the sum is λ₁+λ₂, as the rule requires. Mean equals variance is only a check on a Poisson model, not proof that a count is Poisson. Data with variance much larger than the mean are overdispersed; the negative binomial is a common next model.

The process version, where λ can vary with time, is in Unit 7; the waiting time between events is in Chapter 3.5.

Worked example

Question. A call centre receives on average 4 calls per minute, following a Poisson distribution. (a) Find the probability of exactly 3 calls in one minute. (b) Find the probability of at least 2 calls in one minute.

  1. Set λ = 4 calls per minute. Let X be the number of calls in one minute, so X ~ Poisson(4).
  2. For exactly 3 calls: P(X=3)=e^−4 4^3/3!. First compute e^−4=0.0183156 and 4^3/3!=64/6=10.6667. Then P(X=3)=0.0183156×10.6667=0.1953668.
  3. For at least 2 calls: P(X≥2)=1−P(X=0)−P(X=1). Compute P(X=0)=e^−4=0.0183156. Compute P(X=1)=4e^−4=0.0732626.
  4. Add the two small probabilities: P(X<2)=0.0183156+0.0732626=0.0915782. Then P(X≥2)=1−0.0915782=0.9084218.

Answer. P(X=3)=0.1953668148 and P(X≥2)=0.9084218056 for one minute with mean 4 calls per minute.

Exam traps

  • Using λ for the wrong interval: if λ=4 per minute, a five-minute count uses λ=20, not 4.
  • Treating Poisson as bounded: k can be 0,1,2,... with no maximum, even if large k is very unlikely.
  • Thinking mean=variance proves Poisson: it is a check, not a proof; overdispersed counts fail it.
  • Using Poisson when events are dependent or p is not small: a queue with busy periods can violate the constant-rate condition.
  • Forgetting k! and 0!: P(X=0)=e^−λ, not 0, and 3!=6.

3.3 Geometric and negative binomial distributions

The geometric and negative binomial distributions answer a waiting question. You repeat independent yes/no trials with the same success probability p and count trials until a fixed number of successes arrives. The geometric stops at the first success; the negative binomial stops at the r-th success. Cricket wickets per over, quality checks for defective items, and insurance claims use this count. The key number is the trial on which the required success lands, not the number of failures.

You need: independent Bernoulli trials and the binomial count from Chapter 3.1, plus conditional probability from Unit 2.

Waiting for the first success

Toss a biased coin until the first head. Each toss is an independent trial with success probability p, and T is the trial number of that first success. For the first success to land on trial k, the first k − 1 trials must all fail and trial k must succeed. Independence multiplies the probabilities. Put q = 1 − p, the failure probability. The geometric pmf is below. The support starts at 1; T = 0 is not a trial count.

P(T = k) = (1 − p)<sup>k − 1</sup> p, k = 1, 2, 3, ...

T is the number of trials up to and including the first success; p is the success probability on one trial; (1 − p) is the failure probability.

The probabilities sum to 1: Σk=1∞ (1 − p)k − 1 p = 1. Its mean is E[T] = 1/p. If p = 0.3, you expect 1/0.3 ≈ 3.33 overs for the first wicket. Its variance is Var(T) = (1 − p)/p², so a small p gives a long and highly variable wait. Some syllabi call this the waiting-time distribution. If X counts failures before the first success, then P(X = x) = (1 − p)x p for x = 0, 1, 2, ..., with mean (1 − p)/p. That X is T − 1.

Waiting for the r-th success

Fix r, the required number of successes. Let T be the trial number on which the r-th success lands. Trial k is a success, and among the first k − 1 trials there are exactly r − 1 successes. Choose those r − 1 positions in C(k − 1, r − 1) ways. The probability of any one such pattern is pr − 1(1 − p)k − r, and trial k adds one more p. So the negative binomial pmf is below. Its support starts at k = r.

P(T = k) = C(k − 1, r − 1) p<sup>r</sup> (1 − p)<sup>k − r</sup>, k = r, r + 1, ...

T is the trial number of the r-th success; r is the fixed number of successes; p is the success probability on one trial; C(k − 1, r − 1) is the number of ways to place the first r − 1 successes among the first k − 1 trials.

Its mean is E[T] = r/p and its variance is Var(T) = r(1 − p)/p². The geometric is the r = 1 case. Some syllabi call this the Pascal distribution. If Y counts failures before the r-th success, then Y = T − r, P(Y = y) = C(y + r − 1, y) pr(1 − p)y, and E[Y] = r(1 − p)/p.

Memoryless property and use

The geometric distribution is discrete memoryless. For nonnegative integers m and n, P(T > m + n | T > m) = P(T > n). After m failures, the chance of n more failures is the same as at the start. Proof: P(T > m) = (1 − p)m and P(T > m + n) = (1 − p)m + n; their ratio is (1 − p)n. A bowler who has not taken a wicket for 10 overs does not get a 'due' wicket: if overs are independent, p stays 0.3.

The negative binomial is a sum of r independent geometric waiting times with the same p, so its mean and variance are r times those of the geometric. Use these models for quality inspection until r defective items, insurance claims until r claims, and cricket wickets per over when overs are independent. For continuous waiting, see Chapter 3.5.

Worked example

Question. A bowler takes a wicket with probability 0.3 each over, independently. Find P(first wicket in the 4th over) and P(second wicket in the 5th over).

  1. Set p = 0.3 and q = 1 − p = 0.7. Let T1 be the over of the first wicket.
  2. First wicket in over 4: overs 1 to 3 have no wicket, and over 4 has a wicket. P(T1 = 4) = q³p = 0.7³ × 0.3.
  3. Compute 0.7³ = 0.343. Then 0.343 × 0.3 = 0.1029.
  4. Second wicket in over 5: over 5 has a wicket, and among overs 1 to 4 there is exactly 1 wicket. Choose its over in C(4,1) = 4 ways. P(T2 = 5) = C(4,1) p² q³.
  5. Compute p² = 0.3² = 0.09 and q³ = 0.7³ = 0.343. Then 0.09 × 0.343 = 0.03087. Multiply by 4: 0.03087 × 4 = 0.12348, about 0.1235.

Answer. P(first wicket in the 4th over) = 0.1029 and P(second wicket in the 5th over) = 0.1235, about 10.29% and 12.35%.

Exam traps

  • Counting failures instead of trials: the geometric pmf (1 − p)k − 1p has support k = 1, 2, ..., so P(T = 0) is not allowed. If Y counts failures before the first success, then P(Y = y) = (1 − p)yp with y = 0, 1, 2, ...
  • Using C(k, r) instead of C(k − 1, r − 1) in the negative binomial. Trial k is fixed as the r-th success, so only the first k − 1 trials are arranged.
  • Forgetting that the negative binomial support starts at k = r. Values below r have probability 0.
  • Treating the memoryless property as 'the next trial must succeed after many failures'. It says the conditional chance stays p, not that a success is due.
  • Using the failure-count mean (1 − p)/p as the trial-count mean. The geometric trial-count mean is 1/p.

3.4 Uniform distribution

The uniform distribution gives equal probability density to every point in an interval. It models a random quantity with no preferred value inside fixed bounds: a train arrival, a rounding error, a random number between 0 and 1. On [a,b], the density is a flat rectangle of height 1/(b − a). Interval probability is interval length divided by b − a. The mean is the midpoint. Variance grows with the square of the interval width. Use it as a simple model and as the base for simulation.

You need: continuous random variables, pdf and CDF, and basic integration from Unit 2; the exponential distribution later replaces the flat density with a falling one.

The flat density

A continuous random variable X is uniform on the interval [a,b] when every point in [a,b] has the same density. The word continuous matters: X can take any real value in the interval, not just whole numbers. The density is flat because no subinterval is favoured. Some syllabi call this the rectangular distribution, after the shape of its graph.

f(x) = 1/(b − a) for a ≤ x ≤ b; f(x) = 0 otherwise

a is the left end, b is the right end, a < b; b − a is the interval length; f(x) is the probability density at x, measured in probability per unit of x.

The total area under a density must be 1. The graph is a rectangle of width b − a and height h. Set h(b − a) = 1 to get h = 1/(b − a). For a wait W uniform on 0 to 10 minutes, the height is 1/10 = 0.1 per minute.

  • The density can be above 1 if b − a is less than 1. A density is not a probability.
  • The support is [a,b]. Outside it, the density is 0.
  • Area, not height, gives probability.

CDF and interval probability

The cumulative distribution function F(x) gives P(X ≤ x). For a uniform variable it rises in a straight line from 0 at a to 1 at b.

F(x) = 0 for x < a; F(x) = (x − a)/(b − a) for a ≤ x ≤ b; F(x) = 1 for x > b

F(x) is the probability that X is at most x; a and b are the interval ends; x is the value at which you evaluate the CDF.

For any interval [c,d] inside [a,b], probability equals length divided by total length.

P(c ≤ X ≤ d) = (d − c)/(b − a)

c is the lower endpoint, d is the upper endpoint, with a ≤ c ≤ d ≤ b; d − c is the interval length in the same units as X.

A single point has width 0. Its area is 0. So P(X = c) = 0 for every c. This makes P(X ≤ c) and P(X < c) equal. For W uniform on 0 to 10 minutes, P(W ≤ 3) = (3 − 0)/(10 − 0) = 0.3. Also P(W = 3) = 0. The events W ≤ 3 and W < 3 have the same probability.

Mean, variance and uses

By symmetry the average sits at the midpoint of the interval. The spread depends only on the interval length.

E(X) = (a + b)/2

E(X) is the mean or expected value; a and b are the interval ends; the answer is in the same units as X.

Var(X) = (b − a)²/12 and σ = (b − a)/√12

Var(X) is the variance, in squared units of X; σ is the standard deviation, back in the original units; a and b are the interval ends.

For X uniform on 0 to 1, the mean is 0.5 and the variance is 1/12 ≈ 0.0833. For X uniform on 2 to 8, the mean is 5 and the variance is 36/12 = 3. The flat model fits a random arrival inside a fixed schedule, a rounding error with known bounds, and a random number from a generator. Simulation builds on uniform random numbers; a short note appears in the Beyond box at the end. When waits are more likely to be short than long, the exponential distribution is the better model.

Worked example

Question. A metro train runs every 10 minutes. You reach the platform at a random time, and your wait W in minutes is uniform on (0,10). (a) Find P(W ≤ 3). (b) Find E(W).

  1. Step 1: Set the model. W ~ U(0,10), so a = 0 min and b = 10 min. The density is f(w) = 1/10 = 0.1 per minute for 0 ≤ w ≤ 10, and 0 outside.
  2. Step 2: Convert the event to an interval. P(W ≤ 3) = P(0 ≤ W ≤ 3). The endpoint 0 has probability 0, so include it freely.
  3. Step 3: Use length over total length. Length = 3 − 0 = 3 min. Total length = 10 − 0 = 10 min. P = 3/10 = 0.3.
  4. Step 4: Find the mean by the midpoint formula. E(W) = (0 + 10)/2 = 5 min.

Answer. P(W ≤ 3) = 0.3, and the expected wait is 5 minutes.

Exam traps

  • The height f(x) = 1/(b − a) is a density, not a probability. Probability comes from area, so P(X = c) = 0 for every single c.
  • For a continuous uniform variable, P(X ≤ c) = P(X < c) and P(X ≥ c) = P(X > c). Do not add a point mass at c.
  • Use the density 1/(b − a) only inside [a,b]. Outside, f(x) = 0. Writing 0.1 for a wait of 12 minutes on U(0,10) is wrong.
  • Variance is (b − a)²/12, with squared units. The standard deviation is (b − a)/√12, back in original units. Examiners often ask for both.
  • Discrete uniform on {1,...,n} gives each point probability 1/n. Continuous uniform gives each point probability 0 and each interval probability length/(b − a). Do not mix them.

3.5 Exponential distribution and the memoryless property

A call centre gets calls at a steady average rate. A component fails at a steady average rate. The exponential distribution is the model for the wait until the next such event when the rate stays constant and the past tells you nothing. One number, the rate λ, gives the whole curve: the density, the mean, the tail and the memoryless rule. It is the standard model for lifetimes, interarrival waits and decay times, and it is the continuous cousin of the geometric distribution.

You need Unit 2 (continuous random variables, pdf, CDF, conditional probability) and the discrete waiting model in Chapter 3.3.

The model: waiting at a constant rate

Events arrive one at a time at a constant average rate: a call reaches a helpline, a component fails, a nucleus decays. Let λ (lambda, a positive number) be that rate in events per unit time. Let T be the wait from now until the next event. T is continuous, and its distribution is the exponential.

f(t) = λe^(−λt), t ≥ 0; f(t) = 0, t < 0

λ > 0 is the rate in events per unit time; t is elapsed time in the same unit; e ≈ 2.71828 is the base of natural logs.

The density starts at height λ at t = 0 and falls smoothly. Short waits are common, long waits are rare but never impossible. Doubling λ halves every typical wait.

E[T] = 1/λ, Var(T) = 1/λ², SD(T) = 1/λ

E[T] is the mean wait in time units; Var(T) is the variance in squared time units; SD(T) is the standard deviation.

The mean and the standard deviation are equal. A server component with mean life 2 years has λ = 1/2 = 0.5 per year, and its SD is also 2 years.

The exponential counts down in continuous time; the geometric distribution does the same job in whole trials. The count of events in a fixed interval is Poisson, covered in Chapter 3.2.

CDF and survival function

F(t) = P(T ≤ t) = 1 − e^(−λt),   S(t) = P(T > t) = e^(−λt)

F is the CDF, the chance the event has happened by time t; S is the survival function, the chance it has not happened by time t; both are probabilities between 0 and 1.

With λ = 0.5 per year, P(T > 3) = e^(−1.5) = 0.2231, so P(T ≤ 3) = 1 − 0.2231 = 0.7769. The median m solves e^(−0.5m) = 0.5, giving m = ln 2 / 0.5 = 1.386 years: half of all components fail before that age.

The ratio h(t) = f(t)/S(t) is the hazard rate, the failure risk at time t given survival so far. For the exponential, h(t) = λe^(−λt) / e^(−λt) = λ, a constant. Among continuous lifetime models, only the exponential has a flat hazard; a few syllabi make this the defining property.

Memoryless: the past is dropped

Suppose the component has already run for s years and is still working. The remaining wait T − s has exactly the same exponential distribution as a brand-new component. The distribution forgets the s years already spent.

P(T > s + t | T > s) = P(T > t) for all s ≥ 0, t ≥ 0

T is the exponential lifetime; s is the time already survived; t is the further time asked about; | means given that.

  1. Write the conditional probability as a ratio: P(T > s + t | T > s) = P(T > s + t and T > s) / P(T > s).
  2. Since s + t > s, the event {T > s + t} sits inside {T > s}, so the numerator is just P(T > s + t).
  3. Put in the survival form: e^(−λ(s+t)) / e^(−λs).
  4. Subtract the exponents: e^(−λs − λt + λs) = e^(−λt) = P(T > t).

Numbers with λ = 0.5 per year, s = 3, t = 2: e^(−2.5) / e^(−1.5) = e^(−1) = 0.3679, which is exactly P(T > 2). The 3 years already used add nothing to the risk.

The uniform distribution does not do this. If a bus is equally likely to come at any moment in the next 10 minutes, waiting 9 minutes leaves only 1 minute on average, not 5. The exponential forgets; the uniform remembers.

Two consequences for exams. Old working parts and new parts have the same remaining lifetime distribution. And P(T > 5 | T > 3) is not P(T > 5); it is P(T > 2).

Worked example

Question. The lifetime T, in years, of a server component is exponential with mean 2 years. (a) Find P(T > 3). (b) Find P(T > 5 | T > 3). (c) Find the median lifetime.

  1. Convert the mean to the rate: λ = 1/mean = 1/2 = 0.5 per year.
  2. (a) Survival form: P(T > 3) = e^(−0.5 × 3) = e^(−1.5) = 0.2231.
  3. (b) By memorylessness with s = 3 and t = 2: P(T > 5 | T > 3) = P(T > 2) = e^(−0.5 × 2) = e^(−1) = 0.3679. Check directly: e^(−2.5) / e^(−1.5) = e^(−1) = 0.3679.
  4. (c) Median: set F(m) = 0.5, so 1 − e^(−0.5m) = 0.5, giving e^(−0.5m) = 0.5 and m = ln 2 / 0.5 = 0.6931 / 0.5 = 1.3863 years.

Answer. P(T > 3) = 0.2231, P(T > 5 | T > 3) = 0.3679, and the median lifetime is 1.3863 years.

Exam traps

  • Using the mean where the rate belongs. For mean 2 years, λ = 0.5, not 2; writing e^(−3) instead of e^(−1.5) is the classic slip.
  • Memoryless does not mean P(T > 5 | T > 3) = P(T > 5). It equals P(T > 2), the wait for the next 2 years only.
  • Writing the survival as 1 − e^(−λt). That is the CDF. The tail is e^(−λt) alone.
  • Mixing the geometric and the exponential. Geometric counts whole trials with qⁿ; exponential measures continuous time with e^(−λt).
  • Losing the time unit. A rate of 0.5 per year becomes 1/24 per month, so state λ in the same unit as t before substituting.

3.6 Normal distribution and its properties

The normal distribution is the symmetric bell curve that appears when many small independent errors add together. It is fixed by two numbers: the mean μ sets the centre, and the standard deviation σ sets the spread. Because so many measurements behave this way, the normal model is used for exam marks, measurement errors, manufacturing sizes and noise. Every question is answered by converting to the standard normal Z and reading one table. Some syllabi call it the Gaussian distribution.

You need Unit 2 on continuous random variables, expectation and variance, a standard normal table, and Chapter 3.1 for the binomial approximation.

The bell curve and its pdf

A continuous random variable X is normal with mean μ and standard deviation σ, written X ~ N(μ, σ²), when its probability density is the curve below. The symbol σ is always positive; σ² is the variance. The constants π and e are the usual mathematical constants. The density is positive for every real x and its total area is 1.

f(x) = 1/(σ√(2π)) · exp(−(x−μ)²/(2σ²)),  −∞ < x < ∞

f(x) is the density at x; μ is the mean; σ is the standard deviation; σ² is the variance; π ≈ 3.1416 and e ≈ 2.7183.

The curve is symmetric about μ: f(μ−a)=f(μ+a) for every a. So the mean, median and mode all equal μ. The standard deviation σ decides the width. About 68.27% of the area lies within μ±σ, about 95.45% within μ±2σ, and about 99.73% within μ±3σ. This is the 68–95–99.7 rule.

With marks X ~ N(60, 8²), about 68% of students score between 52 and 68, about 95% between 44 and 76, and almost all between 36 and 84. The figure shows this curve; its peak is at 60 and its height falls as we move away.

Standard normal Z and table use

Subtract the mean and divide by the standard deviation: Z=(X−μ)/σ. Then Z ~ N(0,1), the standard normal. The table gives Φ(z)=P(Z≤z), the area to the left of z. For negative z use Φ(−z)=1−Φ(z).

P(a < X < b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)

a and b are the interval limits; μ is the mean; σ is the standard deviation; Φ is the standard normal cumulative probability.

  1. Sketch the curve and mark the limits a and b.
  2. Convert both limits to z-scores using z=(x−μ)/σ.
  3. Read Φ at each z-score from the standard normal table.
  4. Subtract the smaller area from the larger area for an interval.

For an inverse problem, the area is given and x is unknown. Find the z with that left-tail area from the table, then undo the standardisation: x=μ+σz. For example, the z with left area 0.90 is about 1.28, so the 90th percentile of N(60,8²) is 60+8×1.28=70.2 marks. Area between two values always uses the difference of two Φ values.

Adding normals and approximating counts

If X₁,...,Xₙ are independent normal, and a₁,...,aₙ are constants, then Y=ΣaᵢXᵢ is normal with mean Σaᵢμᵢ and variance Σaᵢ²σᵢ². For two independent normals, X₁−X₂ has mean μ₁−μ₂ and variance σ₁²+σ₂²; variances add even when we subtract.

Y = Σ aᵢXᵢ, E(Y) = Σ aᵢμᵢ, Var(Y) = Σ aᵢ²σᵢ²

Xᵢ are independent normal variables with means μᵢ and variances σᵢ²; aᵢ are fixed constants; Y is also normal.

When X ~ Bin(n,p) and both np and n(1−p) are at least about 5, X is approximately normal with μ=np and σ²=np(1−p). Because X is discrete, use a continuity correction: replace k by k+0.5 for P(X≤k), and k−0.5 for P(X≥k). For P(a≤X≤b) use limits a−0.5 and b+0.5.

The approximation fails when p is near 0 or 1 or n is small; then use the binomial distribution exactly. For rare events use the Poisson model. This approximation is behind many large-sample tests in Unit 6. The bivariate normal is a joint distribution; see Unit 4. For positive skewed data, see the log-normal distribution.

Worked example

Question. Exam marks X are normal with mean μ=60 and standard deviation σ=8. Find P(50 < X < 70).

  1. The limits are a=50 and b=70. Standardise: z₁=(50−60)/8=−10/8=−1.25 and z₂=(70−60)/8=10/8=1.25.
  2. P(50<X<70)=Φ(1.25)−Φ(−1.25).
  3. By symmetry Φ(−1.25)=1−Φ(1.25), so the probability is 2Φ(1.25)−1.
  4. From the standard normal table, Φ(1.25)=0.89435.
  5. Probability = 2×0.89435−1 = 1.78870−1 = 0.78870, about 0.7887.

Answer. P(50<X<70) ≈ 0.7887, so about 78.87% of students score between 50 and 70 marks.

Exam traps

  • Putting σ² in the denominator of the pdf instead of σ: the normal density has σ√(2π) and 2σ².
  • Forgetting the continuity correction when a binomial count is approximated by a normal curve.
  • Reading the table as a right-tail area. The standard table gives Φ(z)=P(Z≤z), the left-tail area.
  • Adding standard deviations for a sum or difference of independent normals. Variances add, so X₁−X₂ has variance σ₁²+σ₂², not (σ₁−σ₂)².
  • Using the normal approximation when np or n(1−p) is too small; then the binomial shape is skewed and the approximation is poor.

3.7 Gamma, Weibull and log-normal distributions

Some waits are sums of smaller waits; some lifetimes wear out; some quantities grow by multiplying many small factors. Gamma, Weibull and log-normal distributions model these three positive, right-skewed situations. Gamma is for the time to the k-th event in a Poisson process. Weibull is for component life and failure rates that change with age. Log-normal is for positive data whose logarithm is normal, such as incomes, claim sizes and prices. All three appear in reliability, insurance, hydrology and finance. Gamma and Weibull are defined for t ≥ 0: at t = 0 their density may be zero, finite or infinite, depending on the shape. Log-normal is defined only for t > 0.

You need continuous random variables and pdfs (Unit 2), the exponential wait, the normal curve, and the gamma function Γ(·).

Gamma distribution: sum of waits

The gamma distribution describes the wait for the k-th event in a Poisson process with rate λ. The pdf is:

f(t) = λ<sup>k</sup> t<sup>k−1</sup> e<sup>−λt</sup> / Γ(k),  t ≥ 0

k > 0 is the shape, λ > 0 is the rate, t is time, e is the base of natural logs, and Γ(k) = ∫₀∞ uk−1 e−u du is the gamma function.

The mean is k/λ and the variance is k/λ². With scale θ = 1/λ the pdf becomes f(t) = tk−1 e−t/θ / (θk Γ(k)) and the mean is kθ. When k = 1 the gamma is the exponential in Chapter 3.5. When k is a positive integer it is the sum of k independent exponential waits. Chi-square is a gamma special case; Unit 5 gives the details. Gamma is used for call-center waiting, insurance claim totals and rainfall totals.

Weibull distribution: lifetime and hazard

Weibull models time to failure. Its pdf is:

f(t) = (β/η)(t/η)<sup>β−1</sup> exp(−(t/η)<sup>β</sup>),  t ≥ 0

β > 0 is the shape, η > 0 is the scale or characteristic life, and exp means e raised to the power shown.

The mean is ηΓ(1 + 1/β). The survival function is S(t) = exp(−(t/η)β). The hazard rate is h(t) = (β/η)(t/η)β−1: the chance of failure just after t given survival to t. If β = 1, h = 1/η is constant and Weibull is exponential. If β > 1, hazard rises with age, which fits wear-out. If β < 1, hazard falls, which fits infant mortality. Reliability engineers use it for bulbs, bearings and wind speed. β is not a rate; η sets the time scale.

Log-normal distribution: multiplicative effects

X is log-normal when ln X is normal. Write Y = ln X ~ N(μ, σ²); then X = eY. The pdf is:

f(t) = 1/(t σ √(2π)) exp(−(ln t − μ)<sup>2</sup>/(2σ<sup>2</sup>)),  t > 0

μ and σ are the mean and standard deviation of ln X, not of X; ln is natural log and π is 3.14159.

The median is eμ. The mean is eμ+σ²/2, so mean > median when σ > 0 and the density is right-skewed. Log-normal is used for incomes, insurance claim sizes, stock prices, particle sizes and rainfall. To use the normal table, take logs first. It is not the log of a normal variable; it is the variable whose log is normal.

Worked example

Question. For Gamma(shape 2, rate 1), Weibull(shape 2, scale 1) and Log-normal(μ = 0, σ = 0.5), compare the densities at t = 2 and state which is largest.

  2. Weibull: β = 2, η = 1, t = 2. f(t) = (2/1)(2/1)1 exp(−(2/1)2) = 4 e−4. e−4 = 0.018316, so f(2) = 0.073263.
  3. Log-normal: μ = 0, σ = 0.5, t = 2. ln 2 = 0.693147. The exponent is −(0.693147)2/(2 × 0.25) = −0.960906, and exp(−0.960906) = 0.382546. The prefactor is 1/(2 × 0.5 × √(2π)) = 0.398942. So f(2) = 0.398942 × 0.382546 = 0.152610.

Exam traps

  • Log-normal is the distribution of X when ln X is normal; it is not the logarithm of a normal variable.
  • Gamma rate λ and scale θ are reciprocals: mean is k/λ with rate, but kθ with scale. Mixing them flips the mean.
  • Weibull β is shape, not rate. β = 1 gives the exponential with rate 1/η.
  • Weibull mean is ηΓ(1 + 1/β), not ηΓ(1 + β).
  • A gamma with integer shape k is a sum of k exponential waits; for non-integer k it is still a gamma but not that sum. Chi-square is a gamma special case.

Median = eμ = e0.2 = 1.2214.

Analyze A Weibull fit to failure times gives β = 0.7 and η = 500 hours. What does β say about the hazard and the type of failures? 4 marks

β = 0.7 < 1, so the hazard decreases with time. Early failures are more likely than later ones, which fits infant mortality rather than wear-out. The scale η = 500 hours sets the time scale but does not make the hazard constant.

Beyond the syllabus

Not for the exam. Reliability engineers estimate Weibull β from failure data to choose maintenance schedules. Actuaries model claim sizes with log-normal and gamma distributions. The Black-Scholes model uses log-normal prices. Survival analysis extends these ideas with covariates. Search 'Weibull analysis', 'log-normal Black-Scholes' and 'gamma process'.

Takeaways

  1. Counts of yes/no outcomes in n independent trials of the same chance follow the binomial distribution, fixed by n and p alone.
  2. Rare events in a fixed interval follow the Poisson distribution, which has one parameter λ and variance equal to its mean.
  3. The geometric and negative binomial distributions count trials until successes, not successes in a fixed number of trials.
  4. The uniform distribution is flat: equal density everywhere on its interval, so probability equals length of subinterval divided by total length.
  5. The exponential distribution is the only continuous waiting-time law that is memoryless, and it comes directly from a constant-rate Poisson process.
  6. The normal curve is fixed by μ and σ, and every normal probability is a standard normal probability after the z-transform.
  7. Squaring and summing exponentials gives gamma; stretching a lifetime law gives Weibull; exponentiating a normal gives log-normal.
  8. Choose a distribution from how the data are generated — counts, waits, or positive skewed measurements — not from which formula looks easy.

Exam question bank

Long answers in this unit are scored on stating the assumptions clearly, deriving the mean and variance, and finishing with a correct numerical probability worked from the standard tables.

Remember and understand

Understand State the assumptions of the binomial distribution. Derive its mean and variance, and explain what happens to the shape as p moves away from 0.5. 12 marks

Four assumptions: fixed n, two outcomes per trial, constant p, independent trials; Write P(X = x) = C(n, x) pˣ qⁿ⁻ˣ and name every symbol; Mean from Σ x P(x) using x C(n, x) = n C(n−1, x−1); answer np; Variance from E(X²) − (E(X))²; answer npq; Shape: symmetric at p = 0.5, right-skewed for small p, left-skewed for large p.

Understand Define the Poisson distribution. Obtain it as a limiting case of the binomial distribution and give its mean and variance. 12 marks

Statement of the pmf P(X = x) = e^(−λ) λˣ ÷ x!; Set λ = np, let n → ∞ and p → 0 with λ fixed; Expand C(n, x) pˣ qⁿ⁻ˣ and apply the limits (1 − λ/n)ⁿ → e^(−λ); Mean = variance = λ, so standard deviation is √λ; Two or three examples of rare-event counts: defects, accidents, calls.

Understand Define the exponential distribution, derive its mean and variance, and prove the memoryless property. 10 marks

Density f(x) = λ e^(−λx), x ≥ 0, and CDF F(x) = 1 − e^(−λx); Mean 1/λ by integration by parts, variance 1/λ²; Write the conditional probability in ratio form; Use P(X > s + t) = e^(−λ(s+t)) and P(X > s) = e^(−λs); The ratio is e^(−λt) = P(X > t): the proof ends here.

Understand List the properties of the normal distribution and explain how the standard normal table is used to find any normal probability. 12 marks

Density formula with μ and σ written out and symbols defined; Symmetry about x = μ, mean = median = mode, total area 1; Points of inflexion at μ ± σ; the curve never touches the axis; Any linear combination of independent normals is normal; z = (x − μ)/σ, then read the table; P(X ≤ a) = Φ((a − μ)/σ); Use of the complementary rule and of P(a ≤ X ≤ b).

Understand Distinguish the geometric and negative binomial distributions, and state the mean and variance of each. 8 marks

Geometric = trials up to the first success; negative binomial = trials up to the r-th success; Write both pmfs and define the support; Geometric is the special case r = 1 of the negative binomial; Means 1/p and r/p; variances q/p² and rq/p²; Both are memoryless in the discrete sense.

Apply

Apply A machine produces bolts of which 5% are defective. In a box of 20 bolts, find the probability that exactly 2 are defective and the probability that at most 2 are defective. State the mean and standard deviation of the defect count. 10 marks

Recognise a binomial with n = 20, p = 0.05, q = 0.95; P(X = 2) = C(20, 2)(0.05)²(0.95)¹⁸ ≈ 0.189; P(X ≤ 2) = P(0) + P(1) + P(2) ≈ 0.358 + 0.377 + 0.189 ≈ 0.925; Mean np = 1, variance npq = 0.95, standard deviation ≈ 0.975; Comment that the Poisson with λ = 1 gives a close check.

Apply Telephone calls reach an office at an average rate of 3 per minute. Assuming a Poisson process, find the probability of exactly 5 calls in a minute, of no calls in a minute, and of at least 2 calls in two minutes. 10 marks

State X ~ Poisson(λ) with λ = 3 per minute; P(X = 5) = e^(−3) 3⁵ ÷ 5! ≈ 0.1008; P(X = 0) = e^(−3) ≈ 0.0498; For two minutes take λ = 6 and compute 1 − P(0) − P(1) ≈ 0.9826; Note that the rate scales linearly with the length of the interval.

Apply A student answers a multiple-choice test by guessing; each question has 4 options. Find the probability that the first correct answer is on the fifth question, and the expected number of questions until the first correct answer. 8 marks

Geometric model with p = 0.25, q = 0.75; P(X = 5) = (0.75)⁴ × 0.25 ≈ 0.0791; Mean 1/p = 4 questions; Variance q/p² = 12, standard deviation ≈ 3.46; Interpret the mean as a long-run average over many attempts.

Apply A city bus on a route arrives uniformly anywhere between 0 and 20 minutes after you reach the stop. Find the probability you wait between 5 and 12 minutes, the mean wait, and the standard deviation of the wait. 8 marks

Uniform U(0, 20); density 1/20; Probability = (12 − 5)/20 = 0.35; Mean (0 + 20)/2 = 10 minutes; Variance (20 − 0)²/12 = 33.33, standard deviation ≈ 5.77 minutes; Explain that probability here is an area of a rectangle.

Apply The marks in a paper are normally distributed with mean 58 and standard deviation 12. Find the probability that a student scores above 75, and the mark exceeded by the top 10% of students. 10 marks

Convert to z: z = (75 − 58)/12 = 1.4167; P(X > 75) = 1 − Φ(1.42) ≈ 0.0778; For the top 10%, find z with Φ(z) = 0.90, so z ≈ 1.2816; Solve x = μ + zσ = 58 + 1.2816 × 12 ≈ 73.4; State the table values used and round sensibly.

Analyze and evaluate

Analyze Compare the binomial and Poisson distributions. Explain when the Poisson approximation is justified, and check it numerically for n = 100, p = 0.02 at x = 3. 12 marks

Binomial: fixed n, parameter p; Poisson: count over a continuum of trials, parameter λ; Binomial variance npq < np = mean; Poisson variance equals mean; Approximation is good when n ≥ 20 or so, p ≤ 0.05, np moderate; Binomial value C(100, 3)(0.02)³(0.98)⁹⁷ ≈ 0.1823; Poisson value with λ = 2: e^(−2) 2³ ÷ 3! ≈ 0.1804; Comment on the small difference and on when it becomes unsafe.

Evaluate A component's lifetime is modelled by the exponential distribution. Discuss whether this is a reasonable model, and compare it with the Weibull and log-normal alternatives for wear-out and for multiplicative damage. 13 marks

Exponential has a constant hazard rate; suitable for random failures, not for ageing; Memoryless property and what it means physically; Weibull shape k: k < 1 infant mortality, k = 1 exponential, k > 1 wear-out; Log-normal arises from products of small positive effects; right-skewed, heavy tail; How to choose: plot failure data, check hazard shape, use goodness of fit; Recommendation with justification for each of the three regimes.

Analyze Explain the memoryless property in both the geometric and the exponential distributions. Show the discrete and continuous proofs and give one real situation where the property fails. 12 marks

Discrete statement P(X > m + n | X > m) = P(X > n) with q powers; Continuous statement with the exponential ratio of survival functions; Both hold because of the constant hazard rate; Example where it holds: calls in a Poisson process after a random time; Example where it fails: a machine that wears out, or a battery near end of life; Conclude that memorylessness is a modelling assumption, not a law of nature.

Evaluate Explain the normal approximation to the binomial distribution with continuity correction. Apply it to n = 200, p = 0.4 to estimate P(X ≤ 70) and compare with the exact answer. 12 marks

Conditions: np ≥ 5 and nq ≥ 5, better when p is near 0.5; Mean np = 80, variance npq = 48, standard deviation ≈ 6.93; Use the continuity correction: P(X ≤ 70) becomes P(X ≤ 70.5); z = (70.5 − 80)/6.93 ≈ −1.371, so probability ≈ 0.0853; Exact binomial ≈ 0.0846; state the size of the error; Why the correction matters when n is only moderately large.

Evaluate Two identical components work independently, each with exponential lifetime of mean 1000 hours. Find the probability that a series system survives 500 hours and that a parallel system survives 500 hours. Comment on the design conclusion. 13 marks

λ = 1/1000 per hour; P(single survives 500 h) = e^(−0.5) ≈ 0.6065; Series: product of the two probabilities ≈ 0.3679; Parallel: 1 − (1 − 0.6065)² ≈ 0.8452; Show the general formulas p² and 1 − (1 − p)²; Comment: redundancy raises short-run survival sharply but costs double; Note the independence and constant-hazard assumptions and their limits.

Glossary

Continuity correction
Adding or subtracting 0.5 when a discrete count is approximated by a continuous curve.
Continuous random variable
A random variable whose values fill an interval, such as a time or a length.
Cumulative distribution function
F(x) = P(X ≤ x), the probability of all values up to x.
Discrete random variable
A random variable whose possible values can be listed, such as a count.
Expected value
The long-run average of a random variable, written E(X) or μ.
Gamma function
Γ(α) = ∫₀^∞ xᵅ⁻¹ e^(−x) dx, with Γ(n) = (n − 1)! for a positive integer n.
Hazard rate
The instantaneous failure rate at time t given survival up to t.
Independence
Two events are independent when P(A and B) = P(A) × P(B).
Parameter
A fixed number in a probability law, such as p, λ, μ or σ, that selects one member of the family.
Poisson process
A counting process in which events occur independently at a constant average rate.
Probability density function
A function f(x) whose area over an interval gives the probability that a continuous variable lies in that interval.
Probability mass function
The function P(X = x) giving the probability of each value of a discrete random variable.
Random variable
A rule that assigns a real number to each outcome of a random experiment.
Reliability
The probability that a component or system performs its function for a stated time.
Scale parameter
A parameter that stretches or shrinks the axis, such as b − a, 1/λ or λ in the Weibull.
Shape parameter
A parameter that changes the form of the curve, such as α in the gamma or k in the Weibull.
Skewness
A measure of how lopsided a distribution is; a long right tail means positive skew.
Standard deviation
The positive square root of the variance, in the same units as the variable.
Standard normal table
A table of Φ(z) = P(Z ≤ z) for the N(0, 1) distribution, used after converting to z.
Survival function
S(t) = P(X > t), the probability that a lifetime or wait exceeds t.
Variance
E(X²) − (E(X))², the average squared distance of the variable from its mean.
z-score
z = (x − μ)/σ, the number of standard deviations x lies from the mean.
