2.1 Sample space, events and axioms of probability

Probability turns uncertainty into numbers between 0 and 1. A random experiment has outcomes; the set of all outcomes is the sample space Ω. An event is a subset of Ω. Three axioms fix how probability behaves on these sets. From them we derive useful rules: the probability of the empty set is 0, the complement rule, and the addition rule for A∪B. Engineers use these rules when they estimate failure rates, queue overload, or the chance that a UPI payment fails. The same language prepares you for conditional probability and random variables later.

You need: basic set notation (∈, ⊆, ∪, ∩, complement) and fractions; Unit 1 descriptive statistics is context only.

Outcomes, sample space and events

A random experiment is a process with a known set of possible results and an uncertain result on any one run. One result is an outcome, written ω. The sample space Ω is the set of all outcomes. An event A is a subset of Ω: A⊆Ω. The sure event is Ω itself; the impossible event is ∅. Some syllabi call Ω the universal set and events subsets of it.

Events combine like sets. A∪B is the event that A or B or both occur. A∩B is the event that both occur. Aᶜ is the complement: A does not occur. A−B is A∩Bᶜ: A occurs and B does not. De Morgan's laws hold: (A∪B)ᶜ=Aᶜ∩Bᶜ and (A∩B)ᶜ=Aᶜ∪Bᶜ.

Two events are mutually exclusive if A∩B=∅; they cannot occur together. They are exhaustive if A∪B=Ω; together they cover every outcome. For a die, A={2,4,6} and B={3,6} are not mutually exclusive because 6 is in both. C={1,3,5} and A are mutually exclusive and exhaustive for Ω={1,2,3,4,5,6}.

Axioms and rules that follow

The three axioms are the definition. For every event A in Ω:

  • P(Ω)=1.
  • P(A)≥0 for every event A.
  • If A₁,A₂,... are pairwise disjoint (Aᵢ∩Aⱼ=∅ for i≠j), then P(A₁∪A₂∪...)=ΣP(Aᵢ).

Derive two facts. Ω and ∅ are disjoint and Ω∪∅=Ω, so 1=P(Ω)=P(Ω)+P(∅), giving P(∅)=0. A and Aᶜ are disjoint and A∪Aᶜ=Ω, so 1=P(A)+P(Aᶜ), giving P(Aᶜ)=1−P(A).

P(A∪B) = P(A) + P(B) − P(A∩B)

P(A) is the probability of event A; P(B) is the probability of event B; P(A∩B) is the probability that both A and B occur. If A∩B=∅, then P(A∩B)=0 and P(A∪B)=P(A)+P(B).

Write A∪B as A∪(B∩Aᶜ); these are disjoint. Also B=(B∩A)∪(B∩Aᶜ), disjoint. So P(A∪B)=P(A)+P(B∩Aᶜ)=P(A)+P(B)−P(A∩B). If A⊆B, then B=A∪(B∩Aᶜ) with disjoint parts, so P(B)=P(A)+P(B∩Aᶜ)≥P(A). This is monotonicity.

For equally likely outcomes, P(A)=|A|/|Ω|, where |A| is the number of outcomes in A. For repeated trials, relative frequency n(A)/n often settles near P(A) as n grows. These motivate the axioms but do not replace them. Conditional probability later restricts Ω to an event B: see Conditional probability and independent events.

A routine for first-step problems

Three rules solve most first-step problems. Write Ω and list the outcomes. Write each event as a set. If outcomes are equally likely, count outcomes: P(A)=|A|/|Ω|. For a fair die, |Ω|=6, so each single outcome has probability 1/6. Relative frequency is not a proof; the axioms are the definition.

RuleFormulaWhen to use
ComplementP(Aᶜ)=1−P(A)'not A' is easier to count
AdditionP(A∪B)=P(A)+P(B)−P(A∩B)'A or B'
Disjoint additionP(A∪B)=P(A)+P(B) if A∩B=∅A and B cannot both happen
MonotonicityP(A)≤P(B) if A⊆BA is contained in B

The addition rule is the one examiners test most: subtract P(A∩B) once because A and B both contain it. If A and B are mutually exclusive, P(A∩B)=0 and the subtraction disappears.

Worked example

Question. A fair six-sided die is rolled once. The sample space is Ω={1,2,3,4,5,6}. Let A={2,4,6} and B={3,6}. Find P(A), P(B), P(A∩B), P(A∪B), and P(Aᶜ).

  1. Each outcome is equally likely, so P({k})=1/6 for k=1,2,3,4,5,6.
  2. A={2,4,6} has 3 outcomes, so P(A)=3/6=1/2.
  3. B={3,6} has 2 outcomes, so P(B)=2/6=1/3.
  4. A∩B={6} has 1 outcome, so P(A∩B)=1/6.
  5. By the addition rule, P(A∪B)=1/2+1/3−1/6=3/6+2/6−1/6=4/6=2/3.
  6. By the complement rule, P(Aᶜ)=1−P(A)=1−1/2=1/2. Check: Aᶜ={1,3,5}, which has 3 outcomes, and 3/6=1/2.

Answer. P(A)=1/2, P(B)=1/3, P(A∩B)=1/6, P(A∪B)=2/3, and P(Aᶜ)=1/2.

Exam traps

  • Adding P(A)+P(B) counts A∩B twice. Subtract P(A∩B) once.
  • Events are sets of outcomes, not single outcomes. P(A) is not the probability of one outcome in A.
  • P(∅)=0 is derived from the axioms, not a fourth axiom in the standard list.
  • Mutually exclusive (A∩B=∅) is not the same as independent. Independence comes in Conditional probability and independent events.
  • The complement is taken inside Ω. P(Aᶜ)=1−P(A) only when Aᶜ means 'not A within Ω'.

2.2 Conditional probability and independent events

Conditional probability answers a narrower question: given that B has happened, how likely is A? We divide by P(B) because B becomes the new sample space. Independence is the special case where knowing B leaves P(A) unchanged, so P(A∩B)=P(A)P(B). These ideas drive risk checks in UPI fraud, medical test reading, quality sampling and weather chains. This chapter builds the formula, tree diagrams for two-stage draws, and the difference between independent and mutually exclusive events.

You need: Chapter 2.1 on events, complements and the addition rule.

Conditioning shrinks the sample space

An event is a set of outcomes. A condition B cuts the sample space down to B. Outcomes outside B are removed. To keep probabilities inside B adding to 1, divide by P(B).

P(A|B) = P(A ∩ B) ÷ P(B), P(B) > 0

P(A|B) is the probability of A given B; A ∩ B is the event that both A and B occur; P(B) is the probability of the condition.

Multiply both sides by P(B). This gives the multiplication rule. Use whichever condition is easier to observe.

P(A ∩ B) = P(A|B) P(B) = P(B|A) P(A)

P(A ∩ B) is the joint probability of A and B; P(A|B) and P(B|A) are conditional probabilities; P(A) and P(B) are unconditional probabilities.

A tree diagram for a two-stage experiment has one branch for each result of the first stage. The second-stage branches carry conditional probabilities. Multiply along a path to get the probability of that sequence. Add the paths that make up an event.

Independence changes nothing

Events A and B are independent when P(A|B)=P(A), for P(B)>0. The condition B does not change the chance of A. The multiplication rule then becomes P(A∩B)=P(A)P(B). Use this product form as the definition; it also covers P(B)=0.

P(A ∩ B) = P(A) P(B)

A and B are independent events; P(A ∩ B) is the probability both occur; P(A) and P(B) are their individual probabilities.

For three events, pairwise independence checks each pair: P(A∩B)=P(A)P(B), P(A∩C)=P(A)P(C), P(B∩C)=P(B)P(C). Mutual independence needs all three pair equations plus P(A∩B∩C)=P(A)P(B)P(C). Mutual independence implies pairwise independence. Pairwise independence can fail the triple test.

Independent is not the same as mutually exclusive. Mutually exclusive events cannot happen together, so P(A∩B)=0. If P(A)>0 and P(B)>0, that makes them dependent: one occurring rules out the other.

Conditional independence given C means P(A∩B|C)=P(A|C)P(B|C). Events can be dependent overall but independent inside each group C. Zero correlation only removes a linear trend; it does not prove independence. Reversing a condition is the job of 2.3.

With and without replacement

A bag has 4 red and 6 blue balls. Without replacement, the first draw removes one ball. If the first ball is blue, 4 red and 5 blue remain: 9 balls. So P(second red | first blue)=4/9. If the first ball is red, 3 red and 6 blue remain: P(second red | first red)=3/9.

With replacement, the first ball is put back. The bag returns to 4 red and 6 blue. Then P(second red | first blue)=4/10, which equals P(second red). The two draws are independent.

The tree in this chapter shows the without-replacement case. First branch: blue 6/10, red 4/10. Under blue: blue 5/9, red 4/9. Under red: blue 6/9, red 3/9. Each pair of second branches sums to 1. The highlighted path gives P(first blue and second red)=(6/10)(4/9)=4/15.

Sampling with replacement gives independent draws. Sampling without replacement gives dependent draws in general. The unconditional P(second red) stays 4/10 by symmetry, but the conditional value changes.

2.3 Total probability and Bayes' theorem

An event B often arrives as the sum of parts. If the sample space is cut into cases A₁, …, Aₙ that do not overlap and together cover everything, then P(B) is the sum of P(B|Aᵢ)P(Aᵢ). That is total probability. Bayes' theorem runs the same arithmetic backwards: from P(B|Aⱼ) it gives P(Aⱼ|B). Spam filters, medical test reports, quality control on a shop floor and UPI fraud scoring all use this reversal.

You need: Chapter 2.2 for conditional probability and the multiplication rule.

A partition turns one event into weighted cases

A partition of the sample space Ω is a list of events A₁, A₂, …, Aₙ with two properties. They are pairwise disjoint: Aᵢ ∩ Aⱼ = ∅ when i ≠ j, so no outcome sits in two cases. They cover the space: A₁ ∪ A₂ ∪ … ∪ Aₙ = Ω, so every outcome sits in some case. Each case also needs P(Aᵢ) > 0, otherwise P(B|Aᵢ) is undefined.

A partition breaks one hard probability into n easy ones. Count B inside each case, then weight by the size of that case.

P(B) = Σᵢ P(B|Aᵢ) P(Aᵢ)

B is any event; A₁, …, Aₙ is a partition of Ω; P(Aᵢ) is the probability of case i, also called its weight; P(B|Aᵢ) is the conditional probability of B inside case i.

  1. Name the cases and check them: disjoint, and union equal to Ω.
  2. Write down each weight P(Aᵢ).
  3. Write down each conditional probability P(B|Aᵢ).
  4. Multiply each pair and add the products.
  5. Check that the answer lies between 0 and 1.

Each term P(B|Aᵢ)P(Aᵢ) equals P(B ∩ Aᵢ) by the multiplication rule from Chapter 2.2. The pieces B ∩ A₁, …, B ∩ Aₙ are disjoint and their union is B, so their probabilities add. That is the whole proof. A shop floor gets items from two machines: M1 makes 60% and M2 makes 40%, with defect rates 2% and 5%. Bayes' theorem reverses the condition

Total probability travels from the cases to B. Bayes' theorem travels back: it turns P(B|Aⱼ) into P(Aⱼ|B).

P(Aⱼ|B) = P(B|Aⱼ) P(Aⱼ) / P(B) = P(B|Aⱼ) P(Aⱼ) / Σᵢ P(B|Aᵢ) P(Aᵢ)

Aⱼ is the case you are asking about; B is the observed event; P(Aⱼ) is the prior; P(B|Aⱼ) is the likelihood; Σᵢ P(B|Aᵢ)P(Aᵢ) is the evidence, the total probability of B.

  • Prior P(Aⱼ): what you believed about case j before seeing B.
  • Likelihood P(B|Aⱼ): how well case j explains the evidence B.
  • Evidence P(B): how likely B is under all cases together.
  • Posterior P(Aⱼ|B): what you believe about case j after seeing B.

The denominator is compulsory. The numerator P(B|Aⱼ)P(Aⱼ) is only the joint probability P(Aⱼ ∩ B). Dividing by P(B) turns it into a conditional probability, and it rescales the n products so that the posteriors over all cases add to 1.

In an exam, write the denominator as the full sum before you put in any numbers. A forgotten case then shows up immediately as a wrong total.

Base rates: why a 99% test can still be wrong

A base rate is the prior P(A) when that prior is small, and a small prior pulls the posterior down hard. A condition affects 1 person in 1000, so P(D) = 0.001. A test is positive for 99% of affected people, P(+|D) = 0.99, and for 5% of unaffected people, P(+|Dᶜ) = 0.05. One person tests positive. What is P(D|+)?

Out of 100000 people, 99 + 4995 = 5094 test positive, and only 99 of those are affected. So P(D|+) = 99/5094 ≈ 0.0194. The formula gives the same number: P(D|+) = (0.99 × 0.001) / (0.99 × 0.001 + 0.05 × 0.999) = 0.00099 / 0.05094 ≈ 0.0194.

A positive result lifts the chance from 0.001 to about 0.019, roughly nineteen times higher, and still under 2%. The likelihood 0.99 was never the answer. A two-way table of counts is the fastest way to see this, and it works on any base-rate question.

Worked example

Question. Machine M1 makes 60% of the items in a lot and machine M2 makes the remaining 40%. The defect rate of M1 is 2% and the defect rate of M2 is 5%. An item is picked at random. (a) Find the probability that it is defective. (b) Given that it is defective, find the probability that it came from M1.

  1. Define the events: A₁ = "item came from M1", A₂ = "item came from M2", D = "item is defective".
  2. Read the weights and likelihoods: P(A₁) = 0.60, P(A₂) = 0.40, P(D|A₁) = 0.02, P(D|A₂) = 0.05.
  3. Check the partition: A₁ and A₂ are disjoint and together cover every item, and both weights are positive.
  4. Joint contributions: P(D ∩ A₁) = 0.60 × 0.02 = 0.012 and P(D ∩ A₂) = 0.40 × 0.05 = 0.020.
  5. Total probability: P(D) = 0.012 + 0.020 = 0.032, that is 3.2% of items are defective.
  6. Bayes: P(A₁|D) = 0.012 / 0.032 = 0.375.
  7. Check: P(A₂|D) = 0.020 / 0.032 = 0.625, and 0.375 + 0.625 = 1, so the posteriors add correctly.

Answer. P(defective) = 0.032 and P(M1 | defective) = 0.375, so 37.5% of the defectives come from M1 even though M1 makes 60% of the output.

Exam traps

  • Dropping P(B) from the denominator. P(A|B) and P(B|A) are different numbers, and the denominator is exactly what turns one into the other.
  • Swapping the condition. Here P(defective|M1) = 0.02 while P(M1|defective) = 0.375; the two answer different questions.
  • A partition that overlaps or leaves a gap. If the cases share outcomes or miss part of Ω, the sum for P(B) is wrong even if every multiplication is right.
  • Using the likelihood alone as the weight. Every term needs P(B|Aᵢ) multiplied by P(Aᵢ); a 0.99 likelihood on a rare case still gives a small joint probability.

2.4 Discrete and continuous random variables: pmf, pdf and CDF

Probability starts with events; most questions ask for a number attached to an event, such as a payment amount or a count of failures. A random variable turns each outcome into a real number, so you can add, compare and integrate. Discrete variables count; continuous variables measure. Their pmf, pdf and CDF answer the same question in three forms: how much probability sits at a value, over an interval, or up to a point. This chapter builds those tools; later units use them for named distributions, expectations and tests.

You need: Chapter 2.1 for events and axioms, and basic integration for continuous densities.

Random variable and its support

A random variable X is a function X: Ω → ℝ. Ω is the sample space, the set of all outcomes; ω is one outcome; X(ω) is the real number assigned to it. Example: roll a die, Ω={1,...,6}; X(ω)=ω. Or a UPI payment: the outcome is a transaction record; X is its amount in rupees.

A discrete random variable has possible values in a finite or countably infinite set, such as 0,1,2,... failures. A continuous random variable has possible values filling an interval, such as time until a Chennai power cut ends, in minutes. Often the question states the type; if not, decide from the support — a list of separate values means discrete, an interval means continuous.

The support is the smallest set that carries all probability. For discrete X, support is values x with p(x)>0. For continuous X, support is where f(x)>0; endpoints do not matter because single points have probability 0. Write support explicitly: f(x)=2x for 0≤x≤1 and f(x)=0 otherwise. Without the “otherwise” the density is incomplete.

pmf and pdf: probability at a value or over an interval

For discrete X the probability mass function (pmf) is p(x)=P(X=x). p(x) is the probability that X equals x; it is a number from 0 to 1. Two conditions: p(x)≥0 for every x, and Σ p(x)=1, sum over support. Then P(X∈A)=Σ p(x) for x in A. For a fair die, p(k)=1/6 for k=1,...,6; the sum is 1.

p(x) = P(X = x), Σ p(x) = 1

p(x) is the probability mass at value x; the sum runs over all support values of X.

For continuous X the probability density function (pdf) f(x) gives probability by area, not by height. Conditions: f(x)≥0 for all x, and ∫ f(x) dx = 1 over all real x. For any interval, P(a<X≤b)=∫ₐᵇ f(x) dx. The probability at a single point is zero: P(X=x)=0. So P(a<X≤b)=P(a≤X≤b)=P(a<X<b). A pdf value can exceed 1; f(0.9)=1.8 in f(x)=2x is allowed because an interval of tiny width carries a small area.

P(a < X ≤ b) = ∫ₐᵇ f(x) dx

f(x) is the probability density; the integral is the area under f from a to b. The total area over all real x is 1.

Some syllabi say probability mass function for pmf and probability density function for pdf; a few call the pmf a discrete density. Keep the symbols: p for mass, f for density. Use p with sums and f with integrals. Mixing them is the commonest error.

CDF and the link to pmf or pdf

The cumulative distribution function (CDF) is F(x)=P(X≤x), for both discrete and continuous X. F(x) is the probability that X is at most x. It uses ≤; the value at x includes x. For any a<b, P(a<X≤b)=F(b)−F(a). This interval formula is the safest way to use a CDF. Some syllabi call F the distribution function.

F(x) = P(X ≤ x), P(a < X ≤ b) = F(b) − F(a)

F(x) is the CDF at x; a and b are real numbers with a < b.

  • F is nondecreasing: if x₁<x₂ then F(x₁)≤F(x₂).
  • F is right-continuous: the limit from the right, F(x+)=lim over h→0⁺ of F(x+h), equals F(x).
  • F(x)→0 as x→−∞ and F(x)→1 as x→∞.
  • 0≤F(x)≤1 for every x.

For continuous X, F(x)=∫ from −∞ to x of f(t) dt. Where F is differentiable, f(x)=F′(x). The CDF removes the interval issue: P(0.2<X≤0.6)=F(0.6)−F(0.2). In the figure, F(x)=x², so the probability is 0.36−0.04=0.32.

For discrete X, F is a step function: F(x)=Σ p(t) for t≤x. It is flat between support values and jumps at each support value x by p(x). Example: p(0)=0.2, p(1)=0.5, p(2)=0.3 gives F(x)=0 for x<0; 0.2 for 0≤x<1; 0.7 for 1≤x<2; 1 for x≥2. At a jump the CDF takes the upper value because of ≤.

Worked example

Question. A continuous random variable X has pdf f(x)=2x for 0≤x≤1, and f(x)=0 otherwise. Find the CDF F(x) and P(0.2<X≤0.6).

  1. Check that f is valid: ∫₀¹ 2x dx = [x²]₀¹ = 1, so total area is 1.
  2. For x<0, F(x)=P(X≤x)=0 because the density is zero below 0.
  3. For 0≤x≤1, F(x)=∫₀ˣ 2t dt = x². At x=0.6, F(0.6)=0.6²=0.36.
  4. For x>1, F(x)=1 because all probability is below 1.
  5. P(0.2<X≤0.6)=F(0.6)−F(0.2)=0.36−0.04=0.32. The intermediate F(0.2)=0.2²=0.04.

Answer. The CDF is F(x)=0 for x less than 0; F(x)=x² for 0≤x≤1; F(x)=1 for x greater than 1. The probability P(0.2 < X ≤ 0.6)=0.32 (unitless).

Exam traps

  • A pdf value is not a probability; f(x) can exceed 1. Probability is area over an interval, and P(X=x)=0 for continuous X.
  • Use intervals for continuous X. Asking for P(X=0.5) gives 0, not f(0.5).
  • The CDF uses ≤: P(a<X≤b)=F(b)−F(a). For discrete X, P(a≤X≤b) needs F(b)−F(a−) or p(a) added.
  • Always state the support. f(x)=2x alone is incomplete; it needs 0≤x≤1 and zero otherwise. Likewise the pmf sums only over support.
  • Do not mix sums and integrals: pmf uses Σ p(x)=1, pdf uses ∫ f(x) dx=1. A “density” can mean pdf, not pmf.

2.5 Expectation, variance and moments

Expectation is the long-run weighted average of a random variable. Variance measures how far values spread around that average. Together they turn a whole pmf or pdf into two usable numbers. Moments extend the same weighted-sum idea to powers of X, recording shape. Engineers use them to compare noise, signal strength, waiting times and risk. The formulas below cover discrete and continuous variables, the linearity shortcut, and the traps that cost marks.

You need: Chapter 2.4 for pmf, pdf and CDF, and basic summation and integration.

Expectation as a weighted average

For a discrete random variable X with pmf p(x)=P(X=x), the expectation is E[X]=Σ x p(x). The sum runs over every value x with p(x)>0. The weights p(x) must sum to 1. For a continuous random variable with pdf f(x), replace the sum by an integral: E[X]=∫ x f(x) dx over the support. The integral must converge absolutely: ∫ |x| f(x) dx < ∞. Absolute convergence stops the answer depending on the order of terms or on cancellation.

E[X] = Σ<sub>x</sub> x p(x) = ∫<sub>−∞</sub><sup>∞</sup> x f(x) dx

p(x) is the discrete pmf; f(x) is the continuous pdf; x is a real value of X.

Expectation is linear. For constants a and b, E[aX+b]=aE[X]+b. For two random variables, E[X+Y]=E[X]+E[Y] when the expectations exist. This holds even if X and Y are dependent. Linearity is why averages are easy to combine.

To average a function g(X), do not transform the mean. Use E[g(X)]=Σ g(x)p(x) for discrete X, or E[g(X)]=∫ g(x)f(x)dx for continuous X. For example, E[X²] weights x² by the same probabilities.

Variance and standard deviation

Let μ=E[X]. The variance is Var(X)=E[(X−μ)²]. It is the expected squared distance from the mean. The unit of variance is the square of the unit of X. The standard deviation is σ=√Var(X), in the same unit as X.

Var(X) = E[(X−μ)²] = E[X²] − μ²

μ=E[X]; E[X²]=Σ x² p(x) or ∫ x² f(x)dx; σ=√Var(X).

Use E[X²]−μ² for calculation. Expand the square: E[(X−μ)²]=E[X²−2μX+μ²]=E[X²]−2μE[X]+μ²=E[X²]−μ². The shortcut fails if you subtract in the wrong order.

For constants a and b, Var(aX+b)=a²Var(X). Adding b moves every value but does not change spread. Multiplying by a scales distances by |a|, so squared distances scale by a². In particular, Var(b)=0.

Moments record shape

The r-th raw moment is μ′r=E[Xr]. The first raw moment is the mean: μ′1=E[X]=μ. The r-th central moment is μr=E[(X−μ)r]. The second central moment is the variance: μ2=Var(X). The first central moment is always zero, because E[X−μ]=0.

μ′<sub>r</sub> = E[X<sup>r</sup>], μ<sub>r</sub> = E[(X−μ)<sup>r</sup>]

r=1,2,...; μ=E[X]; raw moments are about 0; central moments are about the mean.

Skewness and kurtosis are standardized third and fourth central moments; Unit 1 covers their formulas and interpretation.

For discrete X, μ′r=Σ xrp(x) and μr=Σ (x−μ)rp(x). For continuous X, replace Σ by ∫ and p(x) by f(x). The same absolute-convergence caution applies when r is large.

Conditional expectation E[X|B] uses the conditional pmf or pdf from Chapter 2.2; replace p(x) by p(x|B) or f(x) by f(x|B).

Worked example

Question. X is the number of heads in two fair coin tosses. Find E[X], E[X²] and Var(X).

  1. List the possible values and their probabilities: P(X=0)=1/4, P(X=1)=1/2, P(X=2)=1/4. The probabilities sum to 1.
  2. Compute E[X]=0×(1/4)+1×(1/2)+2×(1/4)=0+0.5+0.5=1 head.
  3. Compute E[X²]=0²×(1/4)+1²×(1/2)+2²×(1/4)=0+0.5+1=1.5 heads².
  4. Compute Var(X)=E[X²]−(E[X])²=1.5−1²=1.5−1=0.5 heads².

Answer. E[X]=1 head, E[X²]=1.5 heads², and Var(X)=0.5 heads².

Exam traps

  • E[X²] is not (E[X])². For two coin tosses, E[X²]=1.5 but (E[X])²=1.
  • Var(X) is not E[X²]. You must subtract μ². Reporting 1.5 instead of 0.5 is a common lost mark.
  • Check that probabilities sum to 1 before using Σx p(x). If they sum to 0.9, the formula gives a weighted total, not an expectation.
  • Var(aX+b)=a²Var(X), not aVar(X)+b. Adding a constant shifts the mean but does not change spread.
  • For continuous variables, the expectation integral must converge absolutely. A symmetric-looking integral can hide two divergent tails.

2.6 Moment generating functions

A moment generating function turns a whole probability distribution into one function M_X(t)=E[e^(tX)]. Collect the probabilities or density, multiply by e^(tx), and add or integrate. The payoff is derivative bookkeeping: differentiating M_X at t=0 gives E[X], E[X²], and all higher moments. This makes MGFs useful for sums of independent random variables, especially in queues, risk, and signal models.

You need: Chapter 2.5 for expectation and moments, and the exponential series from algebra.

What an MGF is

Take a random variable X with pmf p_X(x) when X is discrete, or pdf f_X(x) when X is continuous. For a real number t, the moment generating function is the expected value of e^(tX). It is a function of t, not of x. The sum or integral must be finite for every t in some open interval −h<t<h around 0.

M_X(t)=E[e<sup>tX</sup>]=Σ_x e<sup>tx</sup> p_X(x) for discrete X, or ∫ e<sup>tx</sup> f_X(x) dx for continuous X

p_X(x) is the pmf, f_X(x) is the pdf, and the sum or integral runs over all values with positive probability or density.

Expand etx=1+tx+(tx)²/2!+… and take the expectation term by term. The result is a power series in t whose coefficients are the raw moments.

M_X(t)=1+μ₁′t+μ₂′t²/2!+μ₃′t³/3!+…

μ_r′=E[X^r] is the rth raw moment; the constant term is 1.

The constant term is 1 because total probability is 1, so M_X(0)=1 whenever the MGF exists. If the MGF is finite only at t=0, it cannot supply moments by differentiation.

Derivatives give moments

The coefficient of t^r/r! in the series is μ_r′. Differentiate r times and put t=0. This single formula replaces a separate sum or integral for every moment.

μ_r′=M_X(r)(0)

M_X(r)(0) is the rth derivative of M_X evaluated at t=0.

For r=1, M_X′(0)=E[X]. For r=2, M_X″(0)=E[X²]. Then Var(X)=M_X″(0)−[M_X′(0)]². The order matters: differentiate first, then set t=0. Setting t=0 inside e^(tx) before differentiating freezes the function at 1 and gives zero derivatives. The open interval around 0 is needed because the Taylor series is about 0 and term-by-term differentiation requires convergence there. A quick check after any computation is M_X(0)=1. A different value means an algebra slip or a missing probability. This check catches many exam errors before the derivatives are used.

Linear changes, sums and uniqueness

For constants a and b, a linear change gives M_(aX+b)(t)=e^(bt)M_X(at). Shifting by b multiplies the MGF by e^(bt); scaling by a replaces t by at. If X and Y are independent, M_(X+Y)(t)=E[e^(tX)e^(tY)]=M_X(t)M_Y(t). Sums become products, which is easier than convolving pmfs or pdfs. If an MGF exists on an open interval around 0, it is unique: two distributions with the same MGF there are the same distribution. This is why MGFs identify distributions and help prove limit theorems. For heavy-tailed variables the MGF may fail to exist. The characteristic function φ(t)=E[eitX] uses i=√−1 and always exists because |eitX|=1. Advanced courses compute it; here we only note it as the safe alternative. Standard MGFs for named distributions are listed in Unit 3.

M_(aX+b)(t)=e^(bt) M_X(at), and M_(X+Y)(t)=M_X(t) M_Y(t) for independent X and Y

a and b are constants; independence is required for the product rule.

Worked example

Question. A discrete random variable X has P(X=0)=1/2, P(X=1)=1/3, P(X=2)=1/6. (a) Find M_X(t). (b) Use derivatives at t=0 to find E[X], E[X²] and Var(X).

  1. By definition, M_X(t)=Σ e^(tx)P(X=x)=(1/2)e^(0t)+(1/3)e^(1t)+(1/6)e^(2t). So M_X(t)=1/2+(1/3)e^t+(1/6)e^(2t). Check at t=0: 1/2+1/3+1/6=1.
  2. Differentiate once: M_X′(t)=(1/3)e^t+(2/6)e^(2t). At t=0, M_X′(0)=1/3+2/6=1/3+1/3=2/3. Hence E[X]=2/3.
  3. Differentiate again: M_X″(t)=(1/3)e^t+(4/6)e^(2t). At t=0, M_X″(0)=1/3+4/6=1/3+2/3=1. Hence E[X²]=1.
  4. Var(X)=E[X²]−(E[X])²=1−(2/3)²=1−4/9=5/9.

Answer. M_X(t)=1/2+(1/3)e^t+(1/6)e^(2t), E[X]=2/3, E[X²]=1 and Var(X)=5/9.

Exam traps

  • Differentiate first, then put t=0. Putting t=0 first gives M_X=1 and zero derivatives, which are not the moments.
  • An MGF must be finite on an open interval around 0. For some heavy-tailed variables, E[e^(tX)] is infinite for every t≠0, so moment derivatives are not available.
  • M_X(0)=1 is a quick check. A computed MGF that gives another value at t=0 is wrong.
  • Same MGF means same distribution only when the MGF exists in a neighbourhood of 0. Matching a few moments alone does not prove equality of distributions.
  • Do not confuse M_X′(0)=E[X] with M_X′(t) at a general t; the derivative function equals the mean only at t=0.

2.7 Chebyshev's inequality

Chebyshev's inequality puts a guaranteed ceiling on the probability that a random variable sits far from its mean. It needs only two numbers, the mean μ and the standard deviation σ. That makes it useful when the exact distribution is unknown, or when only summary data are available. Engineers use it for tolerance and risk statements: a measurement lies within k standard deviations with probability at least 1 − 1/k². The price is looseness. The bound is safe for every distribution, so it can sit far below the true probability.

You need: mean, variance and moments from Chapter 2.5, and the idea of a random variable from Chapter 2.4.

The two moment inequalities

Markov's inequality is the simpler tool. It applies to a random variable X that cannot be negative, so X ≥ 0. For any positive number a, the probability that X reaches a is at most the mean divided by a. If the mean is small, large values are rare.

P(X ≥ a) ≤ E[X] / a

X is a random variable with X ≥ 0; a is a positive number; E[X] is the mean of X.

Chebyshev's inequality adds spread. It applies to any random variable with finite mean μ and finite standard deviation σ. For k > 1, the probability that X lies at least k standard deviations away from μ is at most 1/k². The probability that X lies strictly inside k standard deviations is at least 1 − 1/k². Both forms describe the same event from opposite sides.

P(|X − μ| ≥ kσ) ≤ 1/k²    and    P(|X − μ| < kσ) ≥ 1 − 1/k²

μ = E[X] is the mean; σ = √Var(X) is the standard deviation; k > 1 is the number of standard deviations; |·| is absolute value.

The number k is not a value of X. It is a distance measured in standard deviations. At k = 2, no more than 1/4 of the probability can sit at or beyond two standard deviations. At least 3/4 must sit inside. Some syllabi call Markov and Chebyshev moment inequalities because between them they use the first moment E[X] and the second central moment E[(X − μ)²] = σ².

The statement is distribution-free. You do not need a pmf, a pdf or a named model. The mean and the standard deviation are enough. That is why the result survives when only a summary table is available.

Proof by squaring

The proof turns Chebyshev into Markov. Start with Y = (X − μ)². Y is a square, so Y ≥ 0. Its mean is E[Y] = E[(X − μ)²] = σ².

Choose a = k²σ². This is positive when k > 0 and σ > 0. Markov's inequality gives P(Y ≥ a) ≤ E[Y]/a.

P((X − μ)² ≥ k²σ²) ≤ E[(X − μ)²] / (k²σ²) = σ² / (k²σ²) = 1/k²

The first step applies Markov to Y = (X − μ)² ≥ 0 with a = k²σ²; E[(X − μ)²] = σ² by definition of variance.

The event Y ≥ a is exactly (X − μ)² ≥ k²σ². Taking square roots, |X − μ| ≥ kσ. The right side is σ²/(k²σ²) = 1/k². That proves the upper-tail form.

The inside form follows by complement. The complement of the event |X − μ| ≥ kσ is |X − μ| < kσ. So P(|X − μ| < kσ) = 1 − P(|X − μ| ≥ kσ) ≥ 1 − 1/k². This step needs kσ > 0, that is k > 0 and σ > 0. If σ = 0, X is constant and the bound is trivial; the usual statement assumes σ > 0.

Notice where k > 1 is used. For k ≤ 1, the right side 1/k² is at least 1, so the bound is true but useless. The useful content starts just above k = 1.

Using and misreading the bound

To apply Chebyshev, write the event as a distance from the mean. For P(|X − μ| ≥ d), compute k = d/σ. The probability is at most 1/k². For a symmetric interval P(μ − d < X < μ + d), the half-width is d. Compute k = d/σ; the probability is at least 1 − 1/k².

Strict and non-strict signs matter. Chebyshev controls P(|X − μ| ≥ kσ) from above. The inside form with < is the complement. For an interval written with < or ≤, convert to a distance statement first. Do not mix the two forms.

The bound is safe but often loose. A distribution with most of its mass near the mean can put far more than 1 − 1/k² inside the interval. Chebyshev still tells the truth: the true probability is at least the bound. A small lower bound is not evidence that the inside event is rare; it is only the worst case guaranteed by μ and σ.

The same inequality is the engine behind the weak law of large numbers. A sample mean of n independent observations has variance σ²/n, so Chebyshev shows that the sample mean moves toward μ as n grows. See Unit 4, Law of large numbers, for that argument. Exact tail probabilities need the distribution; see Unit 3.

A quick table shows the guarantee. At k = 1.5 the bound is 1 − 1/2.25 = 0.5556. At k = 2 it is 0.75. At k = 3 it is 0.8889. The return for extra k is slow: each extra standard deviation buys less.

Worked example

Question. A random variable X has mean μ = 60 and standard deviation σ = 8. Use Chebyshev's inequality to bound (a) P(|X − 60| ≥ 16) and (b) P(48 < X < 72).

  1. Write the given values: μ = 60 and σ = 8.
  2. For (a), the deviation is d = 16. Compute k = d/σ = 16/8 = 2.
  3. Apply the upper form: P(|X − 60| ≥ 2×8) ≤ 1/2² = 1/4 = 0.25.
  4. For (b), the interval 48 < X < 72 is centred at (48 + 72)/2 = 60. Its half-width is d = (72 − 48)/2 = 12. The event is |X − 60| < 12.
  5. Compute k = 12/8 = 1.5. Apply the inside form: P(|X − 60| < 1.5×8) ≥ 1 − 1/(1.5)².
  6. Compute (1.5)² = 2.25. Then 1/2.25 = 4/9, and 1 − 4/9 = 5/9 ≈ 0.5556.

Answer. The bound is P(|X − 60| ≥ 16) ≤ 0.25 and P(48 < X < 72) ≥ 0.5556 (exactly 5/9).

Exam traps

  • A Chebyshev answer is a bound, not an exact probability. Do not write P = 0.25 when the question asks for a bound; write P ≤ 0.25.
  • The denominator uses the standard deviation σ, not the variance σ². Convert σ² to σ before computing k.
  • Markov's inequality needs X ≥ 0. Applying it to a variable that can be negative gives a meaningless or false bound.
  • For k ≤ 1 the Chebyshev bound is at least 1 and carries no information; the standard statement uses k > 1.
  • Check strict against non-strict. P(|X − μ| ≥ kσ) ≤ 1/k² pairs with P(|X − μ| < kσ) ≥ 1 − 1/k²; mixing ≤ and < shifts the event by a boundary.

2.8 Functions and transformations of a random variable

A random variable X can be fed into a function g. The result Y=g(X) is itself random: each outcome that gave X=x now gives Y=g(x). Its distribution is inherited from X, not chosen separately. This matters when a meter reports voltage but you need power, when a bank records a ratio, or when a model squares an error. The job is to find the support of Y, then its pmf or pdf. Discrete variables add probabilities of preimages; continuous variables use the CDF or a derivative formula.

You need Chapter 2.4 for pmf, pdf and CDF, and Chapter 2.5 to check answers by expectation.

Discrete case: add over preimages

Suppose X is discrete with pmf p_X(x)=P(X=x). Fix a real number y. The event Y=y happens exactly when X takes some value x with g(x)=y. Those x values are disjoint, so add their probabilities:

p_Y(y)=Σ_{x:g(x)=y} p_X(x)

p_Y(y) is the pmf of Y; the sum runs over every x in the support of X that maps to y; p_X(x) is the old pmf. If no x maps to y, p_Y(y)=0.

The support is the set {g(x): p_X(x)>0}. Write it every time.

Example: X takes -1, 0, 1 with probability 1/3 each. Y=X². Then y=0 has one preimage x=0, so p_Y(0)=1/3. y=1 has two preimages x=-1 and x=1, so p_Y(1)=1/3+1/3=2/3. Support is {0,1}. All other y have probability 0.

Sort a table of x, p_X(x), g(x) by y and add p_X in each group. The total remains 1. The map y=g(x) need not be one-to-one; two x values can land on the same y. That is why the sum, not a single term, is the definition.

Some syllabi call this transformation of variables. Nothing about X changes; only our description of Y is new.

Continuous case: CDF first, then derivative

For continuous X with pdf f_X, start from the CDF of Y:

F_Y(y)=P(Y≤y)=P(g(X)≤y)

F_Y is the CDF of Y. Solve g(X)≤y for X, use the known CDF of X, then differentiate:

f_Y(y)=d/dy F_Y(y)

f_Y is the pdf of Y.

If g is strictly increasing or strictly decreasing on the support, use:

f_Y(y)=f_X(g⁻¹(y)) |d/dy g⁻¹(y)|

g⁻¹(y) is the x that gives g(x)=y; f_X is evaluated at that x; |d/dy g⁻¹(y)| is the absolute derivative of the inverse. The absolute value is needed because a decreasing g reverses intervals but a pdf cannot be negative.

The formula holds only for y in the support of Y. Outside it, f_Y(y)=0. State the support with the formula.

  1. Write the support of X and the map y=g(x).
  2. Find the range of g; that is the support of Y.
  3. Check whether g is one-to-one on the support.
  4. If yes, invert x=g⁻¹(y), compute the derivative, substitute, and simplify.
  5. If no, split into monotone branches and add contributions.
  6. Check that the total area is 1.

For non-monotone maps, the direct formula has one term per preimage:

f_Y(y)=Σ_i f_X(x_i(y)) |dx_i/dy|

x_i(y) are the distinct solutions of g(x)=y and dx_i/dy is the derivative of each branch. This is the continuous version of adding preimages. When two variables transform together, the joint distribution needs a Jacobian; that is Unit 4.

Linear maps and two standard nonlinear maps

Linear map Y=aX+b. Here a and b are constants with a≠0. The inverse is x=(y-b)/a and dx/dy=1/a. The formula gives

f_Y(y)= (1/|a|) f_X((y-b)/a)

|a| is the absolute value of a, for y in the range. If X lies in (α,β), then Y lies between aα+b and aβ+b, with endpoints ordered. A positive a preserves order; a negative a flips it. The factor 1/|a| stretches the density upward when |a|<1 (and squeezes it downward when |a|>1), so the total area stays 1.

Square map Y=X². Take X uniform on (0,1), so f_X(x)=1 for 0<x<1. On this support g is increasing. The inverse is x=√y and dx/dy=1/(2√y). Thus

f_Y(y)=1/(2√y), 0<y<1

√y is the positive square root. The density blows up near 0 but the area is finite and equals 1. The support is (0,1), not all y≥0.

Square root map Y=√X. With the same X, inverse x=y² and dx/dy=2y. Then f_Y(y)=2y for 0<y<1. Both maps are one-to-one on (0,1), so no branch sum is needed.

A non-monotone case: X symmetric on (-1,1) and Y=X². Each y in (0,1) has two preimages, x=√y and x=-√y. Add both branch contributions; the support starts at 0.

Worked example

Question. X is uniform on (0,1), so f_X(x)=1 for 0<x<1. Let Y=X². Find the pdf of Y, state its support, find P(Y≤1/4), and evaluate f_Y(1/4).

  1. Support of X is (0,1). The map y=x² is increasing there, so the range and support of Y are (0,1).
  2. Inverse: x=√y. Derivative: dx/dy=1/(2√y), which is positive.
  3. f_Y(y)=f_X(√y)·|dx/dy| = 1·1/(2√y)=1/(2√y) for 0<y<1; zero elsewhere.
  4. P(Y≤1/4)=∫_0^{1/4} 1/(2√y) dy = [√y]_0^{1/4}=1/2. Same as P(X≤1/2)=1/2.
  5. f_Y(1/4)=1/(2√(1/4))=1/(2×0.5)=1.

Answer. The pdf is f_Y(y)=1/(2√y) for 0<y<1 and 0 outside; P(Y≤1/4)=0.5; f_Y(1/4)=1.

Exam traps

  • Omitting the absolute derivative; a decreasing inverse has negative derivative, so the density would come out negative.
  • Forgetting a second preimage in a non-monotone map, such as Y=X² on a symmetric support.
  • Writing f_Y(y) for y outside the support; state the range every time.
  • Treating y=g(x) as one-to-one when it is not; check the support for turning points.
  • Not checking that the resulting density integrates to 1; this catches missing branches and wrong constants.

Takeaways

  1. Probability is a set function obeying three axioms, so every rule you use later is a consequence of those axioms, not a separate assumption.
  2. Conditioning shrinks the sample space to B and rescales all probabilities by 1/P(B); independence is exactly the case where this rescaling changes nothing.
  3. The law of total probability breaks an event into cases over a partition, and Bayes' theorem runs the same arithmetic backwards to turn P(A|B) into P(B|A).
  4. A random variable converts outcomes into numbers, and the pmf, pdf or CDF then carries all the probability information in a form you can compute with.
  5. Expectation is a weighted average and variance is the average squared gap from it; both are linear-friendly tools, with Var(aX + b) = a² Var(X).
  6. The MGF packages all moments into one function, so a single differentiation gives E[X], a double differentiation gives E[X²], and matching MGFs proves two distributions are the same.
  7. Chebyshev's inequality gives a worst-case bound from only μ and σ, useful when the exact distribution is unknown, though it is usually loose.
  8. When Y = g(X), the density is not simply g(f_X(x)); you must transform the variable, use the Jacobian |dx/dy|, and add a term for every pre-image of y.

Glossary

Central moment
μᵣ = E[(X − μ)r], the r-th moment about the mean; μ₂ is the variance.
Complementary event
The event Ac that A does not occur; P(Ac) = 1 − P(A).
Conditional probability
P(A|B) = P(A ∩ B)/P(B), the probability of A once B is known to have occurred.
Continuous random variable
A random variable whose CDF is a continuous function, described by a density.
Discrete random variable
A random variable whose set of possible values is finite or countably infinite.
Distribution function
F(x) = P(X ≤ x), valid for both discrete and continuous random variables.
Equally likely outcomes
A sample space in which every outcome has the same probability, giving P(A) = number of favourable outcomes ÷ total outcomes.
Event
A subset of the sample space, to which a probability is assigned.
Exhaustive events
A collection of events whose union is the whole sample space.
Expectation
The probability-weighted average of the values of a random variable, written E[X] or μ.
Independent events
Events satisfying P(A ∩ B) = P(A)P(B); knowing one occurred gives no information about the other.
Jacobian
The factor |dx/dy| (or its multivariate determinant) that corrects for the stretching of scale in a change of variable.
Likelihood
The conditional probability P(A|Bᵢ) of the observed evidence under a particular case.
Moment generating function
M_X(t) = E[etX], whose derivatives at t = 0 give the raw moments.
Mutually exclusive events
Events that cannot occur together, so their intersection is empty and their probabilities add.
Outcome
A single result of one run of the experiment; one element of S.
Partition
A collection of pairwise disjoint events whose union is the sample space.
Posterior probability
The updated probability P(Bᵢ|A) computed by Bayes' theorem after the evidence A is observed.
Prior probability
The probability P(Bᵢ) of a case before any evidence about event A is used.
Probability density function
A non-negative function f whose integral over an interval gives the probability that X lies in that interval.
Probability mass function
The function p(x) = P(X = x) for a discrete random variable.
Random experiment
A procedure whose outcome cannot be predicted with certainty but whose set of possible outcomes is known.
Random variable
A real-valued function defined on the sample space.
Raw moment
μ′ᵣ = E[Xr], the r-th moment about the origin.
Sample space
The set S of all possible outcomes of a random experiment.
Standard deviation
The square root of the variance, in the same units as X.
Variance
The expected squared deviation from the mean, Var(X) = E[X²] − (E[X])².
