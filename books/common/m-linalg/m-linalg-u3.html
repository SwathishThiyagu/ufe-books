3.1 Linear transformations and linear maps

Most functions bend and twist. A linear map is the special kind that keeps the two operations of a vector space intact: add two vectors and then transform, and you get the same answer as transforming each one and adding afterwards. That single promise makes a linear map completely predictable — it is fixed once you know where the basis vectors go, which is why one matrix can store it. Rotations in a graphics engine, a weighted credit score, and the derivative of a polynomial all rest on this idea.

You need: vector spaces, subspaces and linear combinations from Unit 2, Vector Spaces.

The two rules

A linear map is a function from one vector space to another that keeps both vector operations intact. Write it T: V → W, read "T from V to W". V is the domain, W is the codomain, and both are vector spaces over the same field F — in this unit usually R or C.

T(u + v) = T(u) + T(v) and T(cu) = c·T(u)

T: V → W is a function between vector spaces over the same field F; u, v are any vectors in V; c is any scalar in F. The first rule is additivity, the second is homogeneity (scaling). A map that satisfies both for all choices is called linear.

The two rules are really one. If T respects addition and scaling separately, it respects every linear combination: T(a u + b v) = a T(u) + b T(v). Checking that single line is enough, and most proofs use this combined form.

  • T(0) = 0. Put u = v = 0 in additivity: T(0) = T(0) + T(0), then subtract T(0) from both sides.
  • T(−v) = −T(v). Apply scaling with c = −1.
  • A linear map carries the zero vector of V to the zero vector of W. This is the fastest way to reject a candidate map.
  • A linear map sends each line through the origin to a line through the origin (or to {0}): T(tv) = t·T(v), so the image of the line spanned by v is the line spanned by T(v). The line may be stretched, shrunk or flattened, but it is never bent and it never moves off the origin.

Examples that pass, examples that fail

Six standard maps pass the test.

MapRuleLinear?
Zero mapT(v) = 0Yes
IdentityT(v) = vYes
ScalingT(v) = cvYes
Rotation by θ in R²T(x, y) = (x cos θ − y sin θ, x sin θ + y cos θ)Yes
Derivative on polynomialsD(p) = p′Yes
Matrix mapT(x) = AxYes
ShiftT(x, y) = (x + 1, y)No: T(0, 0) = (1, 0)
SquareT(x) = x²No: T(2x) = 4x² ≠ 2x²
Coordinate productT(x, y) = xyNo: T(2, 2) = 4 ≠ 2·T(1, 1)

Every yes row passes for the same reason: the rule is built only from sums and scalar multiples. For the derivative, (p + q)′ = p′ + q′ and (cp)′ = c·p′ are the usual rules of calculus. Rotation is multiplication by a 2×2 matrix, so it inherits linearity from matrix multiplication. Scaling by c multiplies every length by |c| (a stretch when |c| > 1, a shrink when |c| < 1), keeps each direction when c > 0, reverses it when c < 0, and sends everything to 0 when c = 0.

The no rows fail in different ways. A constant shift moves the origin, so T(0) ≠ 0 — instant rejection. Squaring and coordinate products break scaling: doubling the input quadruples x² and doubles xy. Note that T(x) = x² does send 0 to 0, so the origin test can reject a map but can never prove linearity.

Operators, composition, and words

When domain and codomain are the same space, T: V → V is called a linear operator. Identity, scaling, rotation about the origin, projection onto a subspace, and the derivative on polynomials are all operators. Operators are the objects that get diagonalised later, in Unit 4, Eigenvalues, Diagonalization and Quadratic Forms.

(T ∘ S)(u) = T(S(u))

S: U → V and T: V → W are linear maps; u is any vector in U; T ∘ S, read "T after S", is the composition, a map from U to W.

Composition keeps linearity in one line: (T ∘ S)(u + v) = T(S(u + v)) [definition of ∘] = T(S(u) + S(v)) [additivity of S] = T(S(u)) + T(S(v)) [additivity of T] = (T ∘ S)(u) + (T ∘ S)(v) [definition of ∘]. The scaling line is the same: (T ∘ S)(cu) = T(c·S(u)) = c·T(S(u)). Composition is not commutative in general: rotating then reflecting differs from reflecting then rotating. Sums and scalar multiples of linear maps are linear too, so the linear maps from V to W form a vector space of their own.

Two names, one idea. Some syllabi say linear transformation, others linear mapping; both mean the rule above. Once you choose bases, a linear map is stored as a matrix — that is matrix of a linear transformation and change of basis. Which inputs land on 0, and which outputs you can reach, comes next in kernel and range.

Worked example

Question. Define T: R² → R² by T(x, y) = (2x + y, x − 3y). (a) Show that T is linear. (b) Find T(1, 2). (c) Find T(e₁) and T(e₂), where e₁ = (1, 0) and e₂ = (0, 1).

  1. Let u = (x, y) and v = (x′, y′) be any vectors in R², and let c be any real scalar.
  2. Additivity: u + v = (x + x′, y + y′). Then T(u + v) = (2(x + x′) + (y + y′), (x + x′) − 3(y + y′)) = (2x + y + 2x′ + y′, x − 3y + x′ − 3y′) = T(u) + T(v).
  3. Homogeneity: cu = (cx, cy). Then T(cu) = (2cx + cy, cx − 3cy) = c(2x + y, x − 3y) = c·T(u).
  4. Both rules hold for every u, v and c, so T is linear. Origin check: T(0, 0) = (0, 0), as a linear map must give.
  5. (b) T(1, 2) = (2·1 + 2, 1 − 3·2) = (4, 1 − 6) = (4, −5).
  6. (c) e₁ = (1, 0) gives T(e₁) = (2·1 + 0, 1 − 3·0) = (2, 1). e₂ = (0, 1) gives T(e₂) = (2·0 + 1, 0 − 3·1) = (1, −3).

Answer. T is linear; T(1, 2) = (4, −5), T(e₁) = (2, 1) and T(e₂) = (1, −3).

Exam traps

  • T(0) = 0 is a quick rejection test, not a proof. T(x) = x² sends 0 to 0 and is still not linear.
  • A constant shift such as T(x, y) = (x + 1, y) is never linear, because T(0, 0) = (1, 0) ≠ (0, 0).
  • You must check both rules. Also test scaling with c = −1 and c = 1/2, not just whole numbers — maps that survive integers often fail on fractions or negatives.
  • The school "linear function" f(x) = mx + c is a linear map only when c = 0. The word is stricter here.
  • Domain and codomain must sit over the same field. If V is over C and W over R, the scalar i makes T(cu) = c·T(u) meaningless.

Apply Let D: P₂ → P₂ send each polynomial to its derivative. Show D is linear using p(t) = t² + 3t and q(t) = 2t. 5 marks

D(p) = 2t + 3 and D(q) = 2. p + q = t² + 5t, so D(p + q) = 2t + 5 = D(p) + D(q). For c = 4, D(4p) = D(4t² + 12t) = 8t + 12 = 4(2t + 3) = 4·D(p). Both rules hold, and the same argument works for all p, q, c.

Analyze Let T: R² → R be linear with T(1, 0) = 3 and T(0, 1) = −2. Find T(x, y) for general (x, y), then T(4, 5). 6 marks

Any (x, y) = x(1, 0) + y(0, 1), so by linearity T(x, y) = x·T(1, 0) + y·T(0, 1) = 3x − 2y. Then T(4, 5) = 12 − 10 = 2. A linear map on R² is completely fixed by its two values on e₁ and e₂.

Analyze Is T(x, y) = (x + y, xy) linear? Justify with a single counterexample. 5 marks

No. Take u = (1, 1) and v = (1, 1). T(u) = (2, 1) and T(u + v) = T(2, 2) = (4, 4), but T(u) + T(v) = (4, 2). Additivity fails, and scaling fails too: T(2, 2) = (4, 4) while 2·T(1, 1) = (4, 2).

Beyond the syllabus

Not for the exam. Linear maps are the workhorses of applied mathematics: a graphics card pushes every vertex through a rotation and scaling matrix, and a control system tracks a state through a linear operator at each time step. Machine learning uses x ↦ Wx + b, which is affine rather than linear — the bias b is exactly the constant shift that breaks the rule. Signal processing relies on the fact that the discrete Fourier transform is linear, so a sum of signals transforms to the sum of transformed signals. Search next for "affine map", "linear operator norm", and "matrix representation of a linear transformation".

3.2 Kernel and range of a linear map

Every linear map T from V to W answers two questions. Which inputs are crushed to zero? Which outputs can appear? The set of crushed inputs is the kernel ker T = {v ∈ V : T(v) = 0}. The set of possible outputs is the range im T = {T(v) : v ∈ V}. These two sets turn injectivity and surjectivity into subspace tests. Engineers use them to detect lost information in sensors and to know which states a control system can reach. In data compression, a nonzero kernel means different inputs become the same output.

You need: linear maps, and from Unit 2 the ideas of subspaces, span and basis.

Kernel and range: the two sets

Fix a linear map T: V → W. The kernel is the set of inputs that T sends to the zero vector of W:

ker T = { v ∈ V : T(v) = 0 }

V is the domain, W is the codomain, 0 is the zero vector of W, and v is an input vector.

The range is the set of outputs that actually occur:

im T = { T(v) : v ∈ V }

T(v) is the output of v under T, and the set collects every output that occurs.

Some syllabi say null space for kernel and image for range. For a matrix map T(x) = A x, ker T is the solution set of A x = 0, and im T is the column space of A. A nonzero kernel means two different inputs can share one output. The range tells which outputs are reachable. A larger kernel means more input directions are collapsed into one output.

Why both sets are subspaces

The kernel is a subspace of V. First, T(0) = 0, so 0 ∈ ker T. If u, v ∈ ker T, then T(u + v) = T(u) + T(v) = 0 + 0 = 0, so u + v ∈ ker T. If c is a scalar and u ∈ ker T, then T(c u) = c T(u) = c · 0 = 0, so c u ∈ ker T.

The range is a subspace of W. First, T(0) = 0, so 0 ∈ im T. If y₁ = T(v₁) and y₂ = T(v₂), then y₁ + y₂ = T(v₁ + v₂), so the sum is in im T. If c is a scalar, c y₁ = T(c v₁), so the scalar multiple is in im T. Closure under addition and scalar multiplication makes both sets subspaces.

Testing injectivity, surjectivity, and finding bases

T is one-to-one exactly when ker T = {0}. If T(u) = T(v), then T(u − v) = 0, so u − v is in the kernel. If the kernel holds only 0, then u = v. The converse is immediate. T is onto exactly when im T = W, because the range is already the set of all outputs.

To find a basis of ker T, solve T(v) = 0. Write the general solution using free variables. The vectors multiplying each free variable form a basis. To find a basis of im T for T(x) = A x, row reduce A. The pivot columns of the original matrix A give a basis of the column space, which is im T. The number dim(ker T) is the nullity, and dim(im T) is the rank.

  1. Write the equations T(v) = 0.
  2. Solve and express v with free parameters.
  3. Take the coefficient vectors as a kernel basis.
  4. For a matrix map, row reduce A; pivot columns of A give a range basis.

The rank-nullity theorem connects these dimensions; its proof is in chapter 3.3.

Worked example

Question. Let T: R³ → R² be T(x, y, z) = (x + 2y − z, 2x + 4y − 2z). Find a basis for ker T and for im T. State the nullity and rank.

  1. Kernel: set both components to 0: x + 2y − z = 0 and 2x + 4y − 2z = 0.
  2. The second equation is 2 times the first. So z = x + 2y.
  3. Let x = a and y = b. Then z = a + 2b, and (x, y, z) = a(1, 0, 1) + b(0, 1, 2).
  4. The vectors (1, 0, 1) and (0, 1, 2) are independent, so they form a basis of ker T. Nullity = 2.
  5. Range: T(x, y, z) = (s, 2s) with s = x + 2y − z. As x, y, z vary, s can be any real number.
  6. Thus im T = span{(1, 2)}. The single vector is nonzero, so rank = 1.

Answer. A basis of ker T is {(1, 0, 1), (0, 1, 2)} with nullity 2; a basis of im T is {(1, 2)} with rank 1.

Exam traps

  • The kernel always contains 0. It is never empty; an empty answer is wrong even for an injective map.
  • im T is a subspace of W, not all of W unless T is onto. Do not write im T = W after finding one output.
  • For ker T solve T(v) = 0, not T(v) = w. Solving T(v) = w gives preimages of one chosen output.
  • For T(x) = A x, the kernel is the null space of A and the range is the column space. Do not use the row space as the range.
  • A basis cannot contain the zero vector. Drop it if a free-variable solution produces it.

3.3 Rank-nullity (dimension) theorem

The rank-nullity theorem counts two subspaces of a linear map T: V → W. The kernel collects inputs sent to zero; the range collects all outputs. For finite-dimensional V, dim V = rank T + nullity T. It holds because a basis of the kernel can be extended to a basis of V, and the extra vectors map one-to-one onto a basis of the range. Engineers use it to count free variables in linear systems, test whether a transform is invertible, and check dimensions in coding and control.

You need: Chapter 3.1, Chapter 3.2, and Unit 2 on basis and dimension.

Definitions and the statement

Let T: V → W be linear, with V finite-dimensional. The rank of T is rank T = dim(im T), the dimension of the range. The nullity of T is nullity T = dim(ker T), the dimension of the kernel. Both are non-negative integers. The range is a subspace of W, so rank T ≤ dim W. The kernel is a subspace of V, so nullity T ≤ dim V.

dim V = rank T + nullity T

V is finite-dimensional; rank T = dim(im T); nullity T = dim(ker T).

The theorem is a counting identity. It says the input space splits into two parts: directions killed by T and directions that survive as independent output directions. Some syllabi call it the dimension theorem or Sylvester’s law of nullity. For matrices, if A is m × n, then A represents T: Rⁿ → Rᵐ, and n = rank A + nullity A.

Proof by extending a kernel basis

  1. Let nullity T = k. Pick a basis {v₁, …, v_k} of ker T.
  2. Extend it to a basis {v₁, …, v_k, u₁, …, u_{n−k}} of V, where n = dim V. This uses the basis extension theorem from Unit 2.
  3. Show the n − k vectors T(u₁), …, T(u_{n−k}) are independent. Suppose Σ c_j T(u_j) = 0. By linearity, T(Σ c_j u_j) = 0, so Σ c_j u_j lies in ker T. Write it as Σ a_i v_i, so Σ c_j u_j − Σ a_i v_i = 0. The list {v₁, …, v_k, u₁, …, u_{n−k}} is a basis, hence independent, so every coefficient is 0, in particular all c_j = 0.
  4. Show they span im T. Any v in V is Σ a_i v_i + Σ b_j u_j. Then T(v) = Σ b_j T(u_j), because T(v_i) = 0. So these images span the range.
  5. The n − k images form a basis of im T. Hence rank T = n − k, and n = k + (n − k) = nullity T + rank T.

This proof shows why finite dimension is needed: we extend a finite basis and count its vectors. The same identity needs more care for infinite-dimensional V.

Corollaries and the matrix version

  • T is injective ⇔ ker T = {0} ⇔ nullity T = 0 ⇔ rank T = dim V.
  • If dim V = dim W < ∞, then T is injective ⇔ T is surjective ⇔ T is bijective. Reason: rank T = dim V forces range dimension dim W, so range = W; surjectivity gives rank T = dim W = dim V, so nullity T = 0.
  • For A m × n, rank A is the number of pivots in row echelon form. nullity A = n − rank A is the number of free variables in Ax = 0. The solution space of Ax = 0 has dimension nullity A.
  • A homogeneous system with more unknowns than equations, n > m, has nullity ≥ n − m > 0, so it has nonzero solutions.

rank A + nullity A = n

A is m × n; rank A = dim(column space of A); nullity A = dim(null space of A); n is the number of columns.

Worked example

Question. Let T: R⁴ → R³ be T(x₁, x₂, x₃, x₄) = (x₁ + x₂, x₃, x₄ − x₂). Find rank T and nullity T, and verify the rank-nullity theorem.

  1. Write the standard matrix A of T. Its rows come from the output coordinates: A = [[1, 1, 0, 0], [0, 0, 1, 0], [0, −1, 0, 1]].
  2. Find the kernel by solving Ax = 0: x₁ + x₂ = 0, x₃ = 0, x₄ − x₂ = 0. Let x₂ = t. Then x₁ = −t, x₃ = 0, x₄ = t.
  3. So ker T = {t(−1, 1, 0, 1): t ∈ R}. A basis is {(−1, 1, 0, 1)}, so nullity T = 1.
  4. The columns of A are c₁ = (1, 0, 0), c₂ = (1, 0, −1), c₃ = (0, 1, 0), c₄ = (0, 0, 1). The columns c₁, c₃, c₄ are independent and span R³, so rank T = 3.
  5. Verify: dim R⁴ = 4, and rank T + nullity T = 3 + 1 = 4.

Answer. rank T = 3, nullity T = 1, and dim R⁴ = 4 = 3 + 1, so the theorem holds.

Exam traps

  • The theorem requires V finite-dimensional. It does not require W finite-dimensional, but rank T must still be finite.
  • rank T is dim(range T), not the number of rows of a matrix. A matrix can have many rows and still have small rank.
  • nullity T is dim(ker T), not the number of zero columns. Zero columns are only one possible source of kernel vectors.
  • For A of size m × n, always write n = rank A + nullity A, using the number of columns. The number of rows m does not appear. Do not write m = rank A + nullity A unless the matrix is square, where m = n.

3.4 Matrix of a linear transformation and change of basis

A linear map can look abstract, but once you choose a basis it becomes a matrix. Coordinates turn each vector into a column, and the matrix stores where each basis vector goes. This lets a computer multiply matrices instead of calling the map directly. The same map has different matrices in different bases, linked by conjugation. Engineers use this to pick a basis where calculations are simple, such as axes aligned with a robot arm. Some syllabi call this the matrix representation of a linear transformation.

You need: chapters 3.1, 3.2, 3.3; Unit 1 matrix multiplication; and Unit 2 basis and coordinates.

Coordinates: a vector becomes a column

Fix an ordered basis B = (b1, ..., bn) of a vector space V. Ordered means b1 is first, b2 is second, and so on. Every v in V is a unique combination v = c1b1 + ... + cnbn. The coordinate vector is [v]B = (c1, ..., cn)T. The numbers ci are coordinates, not the vector itself. Changing the order of the basis changes the coordinate column.

Example in R² with B = ((1,1), (1,2)). The vector (3,−2) equals 8(1,1) − 5(1,2) = (8−5, 8−10) = (3,−2). So [(3,−2)]B = (8,−5)T. The ordinary column (3,−2)T is the coordinate vector in the standard basis E = (e1, e2).

Let P be the change-of-basis matrix from B to the standard basis. Its columns are the basis vectors written in standard coordinates. Here P = [[1,1], [1,2]]. Then [v]E = P[v]B, and [v]B = P−1[v]E. The matrix P must have the basis vectors as columns, in the chosen order.

The matrix of T in chosen bases

Take T: V → W linear, B = (b1, ..., bn) a basis of V, and C = (c1, ..., cm) a basis of W. The matrix [T]C←B has size m × n. Its j-th column is [T(bj)]C, the coordinate vector of the output in basis C. To build it: apply T to each domain basis vector, write the result in the codomain basis, and place the column in order.

[T(v)]<sub>C</sub> = [T]<sub>C←B</sub> [v]<sub>B</sub>

[T]C←B is the matrix of T from basis B to basis C; [v]B is the coordinate column of v in B; [T(v)]C is the coordinate column of the output in C.

Let A be the standard matrix of T when V = Rn and W = Rm with standard bases. Let B and C also name the matrices whose columns are those basis vectors. Then [T]C←B = C−1A B. If C is standard, C = I, so [T]E←B = A B. The order C−1A B matters. The matrix B acts first, changing B-coordinates to standard coordinates. Then A applies T. Then C−1 changes standard coordinates to C-coordinates.

Change of basis is conjugation

When domain and codomain use the same basis B, write [T]B for [T]B←B. With A the standard matrix and P the matrix whose columns are B, [T]B = P−1A P. This operation is conjugation. Two matrices related this way represent the same linear map in two bases. They are called similar; Unit 4 studies similarity and diagonalization in detail.

Use it when the standard matrix is messy. A basis of eigenvectors, for example, can make the matrix diagonal, but finding eigenvectors belongs to Unit 4. For now, use conjugation only to translate between bases. Keep the two P matrices on the correct sides. A quick check: the size of P−1A P must equal the size of A, and its columns must be the coordinate vectors of T(bj) in B.

Worked example

Question. Let T: R² → R² be T(x, y) = (2x + y, x − 3y), and let B = {(1, 1), (1, 2)}. Find [T]B by building its columns, then check using P−1A P.

  1. Standard matrix: A = [[2, 1], [1, −3]], because T(1,0) = (2,1) and T(0,1) = (1,−3).
  2. Basis matrix: P = [[1, 1], [1, 2]]; det P = 1·2 − 1·1 = 1; P−1 = [[2, −1], [−1, 1]].
  3. First column: T(1,1) = (2·1 + 1, 1 − 3·1) = (3,−2). Solve (3,−2) = c1(1,1) + c2(1,2). Equations c1 + c2 = 3, c1 + 2c2 = −2 give c2 = −5, c1 = 8. So [T(1,1)]B = (8,−5)T.
  4. Second column: T(1,2) = (2·1 + 2, 1 − 3·2) = (4,−5). Solve c1 + c2 = 4, c1 + 2c2 = −5. Subtract: c2 = −9, c1 = 13. So [T(1,2)]B = (13,−9)T.
  5. Place the columns in order: [T]B = [[8, 13], [−5, −9]].
  6. Check: A P = [[3, 4], [−2, −5]]. Then P−1A P = [[2,−1], [−1,1]] [[3,4], [−2,−5]] = [[8,13], [−5,−9]].

Answer. The matrix is [T]B = [[8, 13], [−5, −9]] for B = {(1,1), (1,2)}.

Exam traps

  • Basis order matters: swapping b1 and b2 swaps the columns of P and permutes the rows of [T]B.
  • For different domain and codomain bases use [T]C←B = C−1A B, not B−1A C.
  • Do not put T(bj) in standard coordinates into the B-matrix without converting; the j-th column is [T(bj)]C, a coordinate vector.
  • A common slip is to write P−1A P with P columns in one order and the coordinate columns in another order.

3.5 Invertible linear maps and isomorphisms

An invertible linear map is a linear map that another linear map can undo. It pairs each output with exactly one input. This lets us translate problems between two vector spaces without losing information. It appears in coordinate changes, computer graphics, and solving equations. Only a few universities teach this chapter. In finite dimensions, the practical test is simple: the matrix must be square and its determinant nonzero.

You need: linear maps, kernel and range, rank-nullity, matrices of linear maps, and Unit 1 on invertible matrices and determinants (see Unit 1, Matrices and Systems of Linear Equations).

Definition and the inverse map

Let V and W be vector spaces over the same field F. A linear map T: V → W is invertible if there is a map T⁻¹: W → V such that T⁻¹T = I_V and TT⁻¹ = I_W. Here I_V(v)=v for every v in V, and I_W(w)=w for every w in W. The inverse is unique. Equivalently, T is invertible exactly when T is bijective: one-to-one and onto. Some syllabi call this a non-singular linear transformation.

T⁻¹(T(v)) = v for all v ∈ V, and T(T⁻¹(w)) = w for all w ∈ W.

v is any input in V; w is any input in W; I_V and I_W are identity maps.

The inverse T⁻¹ is itself linear. Take w₁, w₂ ∈ W and a ∈ F. Let v₁=T⁻¹(w₁) and v₂=T⁻¹(w₂). Then T(v₁+v₂)=w₁+w₂, so T⁻¹(w₁+w₂)=v₁+v₂=T⁻¹(w₁)+T⁻¹(w₂). Also T(a v₁)=a w₁, so T⁻¹(a w₁)=a v₁=aT⁻¹(w₁). Linearity of T⁻¹ follows.

Finite-dimensional test and isomorphisms

For finite-dimensional V and W, T: V → W is invertible if and only if dim V = dim W and ker T = {0}. The kernel is the set of inputs mapped to zero, covered in kernel and range. If dim V = dim W and ker T = {0}, then rank-nullity gives rank T = dim V = dim W. The range is a subspace of W with the same dimension, so range T = W; T is onto. Kernel zero makes T one-to-one. Conversely, invertible T has both properties.

Choose bases. The matrix A of T is square only when dim V = dim W. Then T is invertible exactly when det A ≠ 0. This determinant test needs a square matrix. When T is invertible, the matrix of T⁻¹ is A⁻¹. An isomorphism is an invertible linear map. Two spaces are isomorphic, written V ≅ W, when such a map exists. Finite-dimensional spaces over the same field are isomorphic exactly when their dimensions are equal. Over R, every n-dimensional space is isomorphic to Rⁿ.

Worked example

Question. Let T: R² → R² be T(x, y) = (2x + y, x − 3y). Show T is invertible. Find T⁻¹(1, 0).

  1. Write the matrix in the standard basis: A = [[2, 1], [1, −3]].
  2. det A = (2)(−3) − (1)(1) = −6 − 1 = −7.
  3. det A = −7 ≠ 0, so A is invertible and T is invertible.
  4. Solve A [x; y] = [1; 0]: 2x + y = 1 and x − 3y = 0.
  5. From x = 3y, substitute: 6y + y = 1, so 7y = 1 and y = 1/7.
  6. Then x = 3/7.
  7. The inverse matrix is A⁻¹ = (1/−7)[[−3, −1], [−1, 2]] = [[3/7, 1/7], [1/7, −2/7]].

Answer. T is invertible because det A = −7 ≠ 0, and T⁻¹(1, 0) = (3/7, 1/7).

Exam traps

  • A linear map can be one-to-one without being onto when dim V ≠ dim W. Check dimensions before calling it invertible.
  • A square matrix with determinant 0 is not invertible. It may still map some nonzero vector to zero.
  • Do not call T invertible just because one equation T(v)=w has a solution. Every w in W must have exactly one solution.
  • The determinant test applies only to square matrices. A 2×3 matrix has no determinant and cannot represent an invertible map between R³ and R².

3.6 Linear functionals and dual spaces

A linear functional is a linear map from a vector space to its field of scalars: it eats a vector and returns one number. The set of all such maps on V is again a vector space, written V* and called the dual space. This small idea makes coordinates precise, turns 'row vector times column vector' into a theorem, and gives the language used in linear programming, signal processing and differential forms. Only a few universities teach this chapter in a first linear algebra course; the rest meet it later.

You need: Chapter 3.1 for linear maps, Chapter 3.4 for coordinate columns, and Unit 2 for basis and dimension.

Linear functional: a map to the field

Fix a field F, either R or C. A linear functional on a vector space V is a linear map f: V → F. It takes one vector and returns one scalar. Some syllabi call it a linear form. Linearity means both rules below hold for all u, v in V and all scalars c.

f(u + v) = f(u) + f(v)

u, v are vectors in V; f(u), f(v) are scalars in F.

f(c·u) = c·f(u)

c is a scalar in F; f(c·u) and f(u) are scalars.

On R², f(x, y) = 3x − 2y is linear. On n × n matrices, f(A) = trace(A), the sum of the diagonal entries, is linear. On polynomials, f(p) = p(2) and f(p) = ∫₀¹ p(t) dt are linear. Two non-examples: f(x, y) = x + 1 fails because f(0, 0) = 1, not 0; f(x) = |x| fails because f(−1) = 1 but −f(1) = −1.

The dual space V*

The dual space V* is the set of all linear functionals on V, with pointwise operations. A sum of two functionals is again linear, so V* is a vector space over the same field F. The zero functional sends every vector to 0.

(f + g)(v) = f(v) + g(v), (cf)(v) = c·f(v)

f, g are functionals in V*; v is a vector in V; c is a scalar in F; the answers are scalars.

A functional is fixed by its values on a basis. Take B = {b₁, …, bₙ} and write v = c₁b₁ + … + cₙbₙ. Linearity gives f(v) = c₁f(b₁) + … + cₙf(bₙ). The n scalars f(b₁), …, f(bₙ) can be chosen freely, so dim V* = n = dim V and V* is isomorphic to Fⁿ. The isomorphism depends on the chosen basis.

The dual basis

For a basis B = {b₁, …, bₙ}, define n functionals by fᵢ(bⱼ) = δᵢⱼ, where δᵢⱼ (the Kronecker delta) is 1 when i = j and 0 otherwise. Linearity fixes fᵢ on all of V: if v = c₁b₁ + … + cₙbₙ then fᵢ(v) = cᵢ, the i-th coordinate of v.

f = f(b₁)f₁ + f(b₂)f₂ + … + f(bₙ)fₙ

f is any functional in V*; fᵢ are the dual basis functionals; f(bᵢ) are scalars in F.

The functionals f₁, …, fₙ form the dual basis of B. They are independent: applying Σ aᵢfᵢ = 0 to bⱼ gives aⱼ = 0. There are n of them and dim V* = n, so they span V* as well.

The double dual V** = (V*)* collects functionals on V*. Each v in V gives one, sending f to f(v). For finite dimension this map is an isomorphism V ≅ V**, and it needs no basis, unlike V ≅ V*.

Worked example

Question. Let V = R² and f(x, y) = 3x − 2y. (a) Show f is a linear functional. (b) For the basis B = {(1, 1), (1, −1)} of R², find the dual basis f₁, f₂. (c) Compute f(1, 4).

  1. (a) Take u = (x₁, y₁) and v = (x₂, y₂). Then f(u + v) = 3(x₁ + x₂) − 2(y₁ + y₂) = (3x₁ − 2y₁) + (3x₂ − 2y₂) = f(u) + f(v). Also f(cu) = 3cx₁ − 2cy₁ = c·f(u). Outputs are real numbers, so f: R² → R is a linear functional.
  2. (b) Let fᵢ(x, y) = ax + by. The dual condition gives two equations per functional: fᵢ(1, 1) = a + b and fᵢ(1, −1) = a − b.
  3. For f₁: a + b = 1 and a − b = 0, so a = 1/2, b = 1/2, giving f₁(x, y) = (x + y)/2.
  4. For f₂: a + b = 0 and a − b = 1, so a = 1/2, b = −1/2, giving f₂(x, y) = (x − y)/2.
  5. Check: f₁(1, 1) = 1, f₁(1, −1) = 0, f₂(1, 1) = 0, f₂(1, −1) = 1, so fᵢ(bⱼ) = δᵢⱼ holds.
  6. (c) f(1, 4) = 3(1) − 2(4) = 3 − 8 = −5.

Output

-5
1.0
0.0
0.0
1.0

Answer. f is a linear functional, the dual basis is f₁(x, y) = (x + y)/2 and f₂(x, y) = (x − y)/2, and f(1, 4) = −5.

Exam traps

  • A functional returns a scalar, never a vector: f(v) lies in F, not in V.
  • The dual basis follows the order of the original basis; swapping b₁ and b₂ swaps f₁ and f₂.
  • Students write only fᵢ(bᵢ) = 1 and forget the off-diagonal zeros fᵢ(bⱼ) = 0 for i ≠ j, which is the real work.
  • V* and V have the same dimension but are different spaces; the isomorphism V ≅ V* needs a basis, while V ≅ V** does not.
  • Do not reach for an inner product here. In this chapter f is any linear map to F, not a dot product with a fixed vector; that is Unit 5.

Takeaways

  1. Linearity is exactly two checks: T(u+v) = T(u)+T(v) and T(cu) = cT(u); once both hold, T(c₁v₁ + … + cₙvₙ) = c₁T(v₁) + … + cₙT(vₙ) follows free.
  2. The kernel measures what a map destroys and the range measures what it produces; both are subspaces, and T is one-to-one exactly when the kernel is {0}.
  3. The rank-nullity theorem is a conservation law: dimensions of input = dimensions kept as output + dimensions collapsed to zero.
  4. Choosing bases turns an abstract linear map into a concrete matrix, and the columns of that matrix are just the images of the basis vectors written in the target basis.
  5. Changing basis replaces M by P⁻¹MP, so rank, nullity, determinant, trace and eigenvalues are properties of the map, not of the matrix you happened to write down.
  6. A linear map is invertible if and only if it is both one-to-one and onto, and over finite dimensions that is equivalent to rank T = dim V = dim W.
  7. Two finite-dimensional spaces over the same field are isomorphic exactly when they have the same dimension, so every n-dimensional space is a copy of Fⁿ.
  8. A linear functional is a linear map into the field; the dual space V* has the same dimension as V, but its vectors are functionals, not arrows.

Apply For an m × n matrix A, prove that the solution space of the homogeneous system Ax = 0 has dimension n − rank(A), and use this to describe the solutions of a consistent non-homogeneous system Ax = b. 12 marks

View A as the matrix of a linear map T: Fⁿ → Fᵐ; ker T is exactly the solution set of Ax = 0; Apply rank-nullity: n = rank A + nullity A; General solution = one particular solution + the null space.

Analyze and evaluate

Analyze For linear maps S: U → V and T: V → W, prove that T ∘ S is linear, that ker S ⊆ ker(T ∘ S), and that Range(T ∘ S) ⊆ Range T. Show with an example that rank(T ∘ S) can be strictly smaller than both ranks. 14 marks

Check additivity and homogeneity of the composition; Element-wise inclusion proofs; Example: two nilpotent maps on R² with composition zero; Connect composition to matrix multiplication of the representing matrices.

Analyze State and prove Sylvester's law of nullity: for linear maps S: U → V and T: V → W with U finite-dimensional, rank(T ∘ S) ≥ rank T + rank S − dim V. 14 marks

Restrict T to Range S and apply rank-nullity there; ker(T restricted to Range S) = Range S ∩ ker T; Use dim(Range S ∩ ker T) ≤ nullity T; Rearrange to obtain the inequality; Give the matrix version rank(AB) ≥ rank A + rank B − n.

Evaluate Let D: P₃ → P₃ be the differentiation map D(p) = p′. Write its matrix in the basis {1, x, x², x³}, find its kernel and range, decide whether D is invertible, and explain what the rank-nullity theorem says here. 14 marks

Columns are images of 1, x, x², x³: 0, 1, 2x, 3x²; Matrix is nilpotent with zeros on and above a shifted diagonal; ker D = constants, nullity 1; Range D = P₂, rank 3; 4 = 3 + 1 confirms the theorem; D is not invertible and the matrix is singular; D⁴ = 0.

Evaluate Show that isomorphism is an equivalence relation on vector spaces, that a linear map carries a basis of V to a spanning set of Range T, and explain why the dual space V* is isomorphic to V but is not the same space. 14 marks

Reflexive: identity map; symmetric: inverse of an isomorphism is linear; transitive: composition of isomorphisms; Images of a basis span the range; drop dependent vectors to get a basis of the range; dim V* = dim V, so V* ≅ V for finite dimension; An isomorphism V → V* needs a chosen basis unless an inner product is given; elements are functionals, not vectors.

Analyze Two matrices represent the same linear operator in different bases exactly when they are similar. Prove this, and use it to argue that rank, nullity, determinant, trace and characteristic polynomial are basis-independent. 14 marks

If B and A represent T in bases B and C, then B = P⁻¹AP with P the change-of-basis matrix; Conversely, given B = P⁻¹AP, read P as a change of basis and recover T; Similar matrices have equal rank (P and P⁻¹ invertible) and equal determinant and trace; Characteristic polynomial: det(P⁻¹AP − λI) = det(P⁻¹(A − λI)P) = det(A − λI).

Glossary

Annihilator
The set of functionals that vanish on every vector of a given subspace.
Basis
A linearly independent set that spans the space; every vector then has a unique coordinate representation.
Change of basis matrix
The invertible matrix P that converts old coordinates to new coordinates.
Coordinate vector
The column of scalars giving a vector as a combination of a chosen basis.
Dimension
The number of vectors in any basis of a finite-dimensional space.
Dual basis
The basis of V* dual to a basis of V, defined by fⁱ(vⱼ) = 1 if i = j and 0 otherwise.
Dual space
The vector space of all linear functionals on V, denoted V*, with pointwise operations.
Identity map
I(v) = v for all v; it is linear and invertible.
Invertible map
A bijective linear map; its inverse is automatically linear.
Isomorphic spaces
Spaces for which some isomorphism exists; over a fixed field this happens exactly when the dimensions agree.
Isomorphism
An invertible linear map between two vector spaces.
Kernel
The set of vectors mapped to zero by a linear map; a subspace of the domain.
Linear functional
A linear map from a vector space to its field of scalars.
Linear map
A function between vector spaces preserving addition and scalar multiplication.
Matrix representation
The array whose j-th column is the coordinate vector of the image of the j-th basis vector.
Nilpotent operator
An operator T with Tⁿ = 0 for some positive integer n, such as differentiation on polynomials of bounded degree.
Nullity
The dimension of the kernel.
One-to-one (injective)
Distinct inputs give distinct outputs; for linear maps this means the kernel is {0}.
Onto (surjective)
Every vector of the codomain is hit by the map; equivalently the range equals the codomain.
Range
The set of all outputs of a linear map; a subspace of the codomain.
Rank
The dimension of the range.
Rank of a matrix
The dimension of its column space, which equals the dimension of its row space.
Similar matrices
Matrices A and B with B = P⁻¹AP for some invertible P.
Subspace
A non-empty subset of a vector space closed under addition and scalar multiplication.
Vector space
A set with addition and scalar multiplication over a field F satisfying the usual eight axioms.
Zero map
The map sending every vector to 0; it is linear and its kernel is the whole space.
