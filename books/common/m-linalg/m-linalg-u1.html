1.1 Systems of linear equations: homogeneous and non-homogeneous

A linear system is a list of straight-line conditions that must all hold at the same time. Writing it as Ax = b puts every coefficient into one matrix A, the unknowns into one column x, and the right-hand numbers into one column b. That split is useful, because the pattern of solutions depends on A and b, not on the letters x, y, z. Engineers solve mesh currents this way, price puzzles reduce to it, and every elimination method from Gaussian elimination onwards begins by writing Ax = b.

You need: multiplying a matrix by a column vector, and plotting a straight line from ax + by = c.

Coefficients kept apart from answers

A linear equation has no squares, no products of unknowns, no roots of unknowns. 2x + 3y − z = 7 is linear. xy = 6 and x² + y = 1 are not. A linear system is m such equations in n unknowns, all required to be true together.

A x = b

A is the m×n coefficient matrix: m rows, one per equation; n columns, one per unknown. The entry aᵢⱼ multiplies xⱼ in equation i. x is the n×1 column of unknowns. b is the m×1 column of right-hand sides.

The row index i counts equations, the column index j counts unknowns. Row 2 of A holds the coefficients of x₁, …, xₙ in the second equation. Multiplying A by x gives one number per equation — the left-hand side — and each must equal the matching entry of b.

Glue b to the right of A, after a vertical bar, to get the augmented matrix [A|b]. It stores every number in the problem, so the equations can be rebuilt from it. Row moves in elementary row operations act on the whole of [A|b], the b column included.

Homogeneous and non-homogeneous

If b = 0 the system is homogeneous. If b ≠ 0 it is non-homogeneous. Homogeneous systems are special: x = 0, every unknown zero, always satisfies A0 = 0. That is called the trivial solution.

A x = 0

the 0 on the right is the m×1 zero column; x = 0 means x₁ = x₂ = ⋯ = xₙ = 0.

So a homogeneous system is never short of a solution. The real question is whether other solutions exist, and that depends on the coefficients. x + y = 0 with x − y = 0 forces x = 0, y = 0 only. But x + y = 0 with 2x + 2y = 0 accepts (1, −1), (2, −2) and every multiple — a whole line of non-trivial solutions.

A non-homogeneous system can fail outright: x + y = 2 and x + y = 5 cannot both hold.

Two words carry the verdict. A system with at least one solution is consistent. A system with no solution is inconsistent. Every homogeneous system is consistent.

Three outcomes for two unknowns

For n = 2 each equation ax + by = c, with a and b not both zero, is a straight line, so solving the system means finding points that lie on all the lines at once. Three things can happen.

  • The lines meet at one point: one solution, consistent. x + y = 3 and x − y = 1 meet at (2, 1).
  • The lines are parallel: no solution, inconsistent. x + y = 3 and x + y = 5 never meet.
  • The lines coincide: infinitely many solutions, consistent. x + y = 3 and 2x + 2y = 6 are the same line.

For n = 3 each equation is a plane, and planes can miss each other, touch at a point, meet along a line, or sit on top of each other. The three outcomes do not change with size; only the pictures get harder to draw.

This is why the matrix form matters. The coefficient matrix A, not the letters x, y, z, fixes the shape of the solution set. Which of the three outcomes you get is settled by rank, as the chapter on rank and consistency shows.

Worked example

Question. For the system x + y + z = 6, x − y + 2z = 5, 2x + y − z = 1, write it in the form Ax = b, form the augmented matrix, and check whether x = 1, y = 2, z = 3 is a solution.

  1. Count: m = 3 equations and n = 3 unknowns, so A is 3×3, x is 3×1 and b is 3×1.
  2. Read coefficients row by row. Row 1: x + y + z = 6 gives coefficients 1, 1, 1 and b₁ = 6.
  3. Row 2: x − y + 2z = 5 gives coefficients 1, −1, 2 and b₂ = 5.
  4. Row 3: 2x + y − z = 1 gives coefficients 2, 1, −1 and b₃ = 1.
  5. So A = [[1, 1, 1], [1, −1, 2], [2, 1, −1]], b = [6, 5, 1]ᵗ and x = [x, y, z]ᵗ. The equation is Ax = b.
  6. The augmented matrix is [1 1 1 | 6; 1 −1 2 | 5; 2 1 −1 | 1].
  7. Check equation 1: 1 + 2 + 3 = 6, which equals b₁ = 6. Holds.
  8. Check equation 2: 1 − 2 + 2(3) = 1 − 2 + 6 = 5, which equals b₂ = 5. Holds.
  9. Check equation 3: 2(1) + 2 − 3 = 2 + 2 − 3 = 1, which equals b₃ = 1. Holds.
  10. All three equations are satisfied, so (1, 2, 3) is a solution and the system is consistent.

Output

Left-hand sides at (1, 2, 3): 6, 5, 1 — matching b₁, b₂, b₃.

Answer. A = [[1, 1, 1], [1, −1, 2], [2, 1, −1]], b = [6, 5, 1]ᵗ, the augmented matrix is [1 1 1 | 6; 1 −1 2 | 5; 2 1 −1 | 1], and x = 1, y = 2, z = 3 is a solution since the three left-hand sides come out as 6, 5 and 1.

Exam traps

  • Assuming every homogeneous system has only x = 0. The trivial solution always exists; extra solutions depend on the coefficients, not on the word 'homogeneous'.
  • A row operation must act on the whole augmented row, including the b column. Changing A alone silently changes the solution set.
  • Reading 'non-homogeneous' as 'inconsistent'. It only means b ≠ 0; such a system may have one solution, infinitely many, or none.
  • Confusing consistent with 'has a unique solution'. Consistent means at least one solution, so the infinite case counts too.
  • Writing A as m×n and then writing b as a row. b is a column, m×1, and it becomes the extra (n+1)-th column of [A|b].

1.2 Elementary row operations and row echelon form

You can solve a linear system without ever touching the unknowns, by pushing the augmented matrix into a staircase shape. Three reversible row moves change how the matrix looks but not which values of x, y, z satisfy it. Repeat the moves and the equations practically solve themselves: the last row gives one unknown, then you work upward. Every solver you use — a calculator, a Python call, an exam answer — runs on these moves, and the staircase form is also the natural first step in later work on rank, on LU factorization and on determinants.

You need: Chapter 1.1 for the augmented matrix [A | b] and for what counts as a solution of a linear system.

Three legal moves

Each row of an augmented matrix is one equation. An elementary row operation changes the matrix but must leave the solution set exactly as it was. Three moves pass that test.

Swap Ri ↔ Rj: exchange two rows. Undo it by swapping the same two rows back.

Scale kRi: multiply every entry of row i by a nonzero number k. Undo it by (1/k)Ri. The condition k ≠ 0 matters: 0·Ri wipes an equation out and no move brings it back.

Add a multiple Ri + kRj: replace row i by itself plus k times row j, with i ≠ j. Undo it by Ri − kRj. Here k = 0 is allowed but useless — nothing changes.

Each move is reversible, and its reverse is again one of the three. So the solution set stays fixed at every step: any solution of the old system satisfies the new rows, and reversing the step gives the old rows back. Two matrices joined by a chain of elementary row operations are row equivalent, written A ~ B.

Apply each move to the whole row, augmented column included. Those last-column numbers are part of each equation, and leaving them behind is the single most common arithmetic slip in an exam.

These moves are the engine of the unit: Chapter 1.3 strings them into an algorithm, and Chapter 1.5 stores the multipliers as a matrix.

Pivot, echelon form, reduced echelon form

The pivot (also called the leading entry) of a row is its first nonzero entry, counting from the left. A row of all zeros has no pivot.

Row echelon form (REF) is a staircase. A matrix is in echelon form when:

  • every nonzero row lies above every zero row;
  • each pivot is strictly to the right of the pivot in the row above;
  • every entry below a pivot is 0.

The pivots step down and to the right. Entries above a pivot and to its right may be anything at all.

Reduced row echelon form (RREF) keeps that staircase and cleans it further: every pivot equals 1, and every pivot is the only nonzero entry in its column, so zeros stand above it as well as below. Some syllabi call RREF the row canonical form or the fully reduced normal form.

Echelon form is not unique: two students can stop at different valid staircases for the same matrix and both be right. RREF is unique — a matrix has exactly one reduced form, whatever legal order of moves you choose. That is why a checked answer is quoted in RREF.

Reaching the staircase

  1. Start at the top row. Find the leftmost column that still has a nonzero entry at or below the current row; if that entry sits lower down, swap it up. It becomes the new pivot.
  2. Clear below: for each row under the pivot, apply Ri + kRj so the pivot column entry becomes 0.
  3. Move one row down and one column right, and repeat until rows or columns run out. You now hold an echelon form.
  4. To reach RREF, work upward: scale each pivot row so its pivot becomes 1, then clear the entries above each pivot with Ri + kRj.
R<sub>i</sub> ← R<sub>i</sub> + kR<sub>p</sub>,  k = −a<sub>ic</sub> / a<sub>pc</sub>

row p holds the pivot apc in pivot column c; aic is the entry being cleared in row i; k is the multiplier that makes the new entry in column c equal 0.

Scaling a pivot row to 1 first keeps the arithmetic in small numbers; many examiners accept either order. The flow chart below shows the two passes, downward then upward, from the augmented matrix to the unique reduced form. Worked counts for a longer system are in Chapter 1.3.

Worked example

Question. Solve the system x + 2y + z = 4, 2x + 5y + 3z = 9, x + 3y + 3z = 6 by reducing its augmented matrix to echelon form, then to reduced row echelon form.

  1. Write the augmented matrix: [[1, 2, 1, 4], [2, 5, 3, 9], [1, 3, 3, 6]].
  2. Pivot is 1 in row 1, column 1. R₂ − 2R₁ gives [2−2, 5−4, 3−2, 9−8] = [0, 1, 1, 1].
  3. R₃ − R₁ gives [1−1, 3−2, 3−1, 6−4] = [0, 1, 2, 2].
  4. Pivot is 1 in row 2, column 2. R₃ − R₂ gives [0, 1−1, 2−1, 2−1] = [0, 0, 1, 1].
  5. Echelon form: [[1, 2, 1, 4], [0, 1, 1, 1], [0, 0, 1, 1]]. The last row reads z = 1.
  6. Clear above the pivot in column 3: R₂ − R₃ gives [0, 1, 0, 0], so y = 0.
  7. R₁ − R₃ gives [1, 2, 0, 3]. R₁ − 2R₂ gives [1, 0, 0, 3], so x = 3.
  8. Reduced row echelon form: [[1, 0, 0, 3], [0, 1, 0, 0], [0, 0, 1, 1]].
  9. Check in the original equations: 3 + 0 + 1 = 4; 6 + 0 + 3 = 9; 3 + 0 + 3 = 6. All three hold.

Exam traps

  • Multiplying a row by 0 to 'clear' it. Only k ≠ 0 is legal in kRi; a zeroed row cannot be recovered and the solution set is destroyed.
  • Forgetting the augmented column. R₂ − 2R₁ must be applied to the entry in [A | b] too, not only to the coefficient columns.
  • Believing echelon form is unique. Two different correct staircases of the same matrix are both right; finish both to RREF before deciding anything is wrong.
  • Writing 2R₁ − R₂ where the needed step is R₂ − 2R₁. The first form rescales row 1 and moves the pivot; the second keeps row 1 untouched.
  • Leaving a zero row between two nonzero rows. Echelon form demands every zero row sit at the bottom.

Analyze A student reduces one matrix to two different echelon forms. Must at least one be wrong? 5 marks

No. Echelon form is not unique, and different orders of legal moves give different staircases. Test by finishing both to RREF: RREF is unique, so both must reach the same matrix.

Analyze Explain why every elementary row operation preserves the solution set, and hence why row-equivalent matrices have the same solutions. 6 marks

Each operation is undone by another operation of the same type. So every solution of the original system satisfies the new rows, and the reverse step shows every solution of the new system satisfies the original rows. The two solution sets are equal, and a chain of such steps carries the equality along.

Understand Why must each pivot be scaled to 1 in RREF but not in echelon form? 3 marks

Forcing pivots to 1 removes the freedom left by scaling, so only one reduced matrix can result and the answer can be read off directly. Echelon form allows any nonzero pivot.

Beyond the syllabus

Not for the exam. RREF is a canonical form: every matrix in a row-equivalence class has exactly one, which is why computer algebra systems can compare two matrices for row equivalence by comparing RREFs. Over exact arithmetic the reduction is done with fractions or with fraction-free variants such as the Bareiss algorithm, which keeps entries integral. In floating point, the choice of pivot becomes a numerical question — partial pivoting picks the largest available entry to limit rounding error — and this is what library solvers actually do. Search 'partial pivoting', 'Bareiss algorithm' or 'reduced row echelon form uniqueness proof' to go further.

1.3 Gaussian elimination and Gauss-Jordan method

Gaussian elimination is the working method behind every linear solver: use row operations to push zeros under each pivot until the augmented matrix is a staircase, then read the unknowns bottom-up. Gauss–Jordan keeps going, clearing above the pivots too, so the answers sit in the last column with no substitution. The recipe needs no matrix inverse and no guesswork, which is why it is used to solve circuit equations, fit curves to data, balance chemical reactions, and settle large systems inside engineering software.

You need: 1.1 for writing Ax = b, and 1.2 for the three row operations and the echelon staircase.

The elimination recipe: forward phase, then back substitution

Elimination on the augmented matrix [A|b] has two phases. The forward phase pushes zeros below each pivot and stops at staircase (echelon) form. The backward phase recovers the unknowns, either by substituting upward or by pushing zeros above the pivots too.

A pivot is the first non-zero number in a row after elimination; it is the number you divide by to get that unknown. The multiplier is the factor that kills the entry below a pivot.

a_ij ← a_ij − m·a_kj, m = a_ik / a_kk

a_kk is the pivot in row k (never 0); a_ik is the entry in row i, column k, that must become 0; m is the multiplier; a_ij and a_kj are the column-j entries of rows i and k.

  1. Write the system as [A|b]: coefficients on the left, constants in the last column.
  2. Take the leftmost column with a non-zero entry at or below the current row. That entry is the pivot.
  3. For each row i below the pivot: m = a_ik / a_kk, then R_i ← R_i − m·R_k. The entry a_ik becomes exactly 0.
  4. Move down one row and right one column and repeat, until no further pivots appear. You now have echelon form.
  5. Back substitute: solve the last pivot row for its single unknown, then work upward, putting known values into the row above.

Nothing is inverted, and each step is one division plus a few subtractions. Hand elimination on a 3 × 3 system is about a page of work. Used this way, the same three row operations from 1.2 carry the whole system to an answer.

Gauss–Jordan: clear above the pivot and read the answer

Gauss–Jordan deletes the backward phase by doing more work in the forward phase. It also clears the entries above each pivot, then scales the pivot to 1, so every pivot column looks like a column of the identity matrix.

  1. Find the pivot in column k; swap rows if the entry there is 0.
  2. Scale: R_k ← R_k / a_kk, so the pivot becomes 1.
  3. Clear the whole column: for every other row i, R_i ← R_i − a_ik·R_k. Column k now holds 1 in row k and 0 in every other row.
  4. Repeat for each pivot, working left to right.
  5. The matrix is in reduced row echelon form (RREF) and x_k = b′_k is read straight from the last column, with no substitution.

The same reduction on [A|I] turns A into I, and the right block becomes A⁻¹; that is the standard hand method for inverses, and Unit 3 explains when the inverse exists. The price is arithmetic: about n³/2 multiplications against n³/3 for Gaussian elimination on an n × n system. Gauss–Jordan is easier to read on paper; production software prefers the cheaper triangular approach, which is the LU factorization of 1.5.

Zero pivots, skipped columns and free variables

A zero pivot is not a failure. Search column k at and below the current row for a non-zero entry, swap that row up, and continue. A row swap is a legal elementary row operation, so the solution set does not change.

If the whole pivot column at and below the current row is zero, no pivot can be made. Skip that column, move one column right, and finish the elimination. The unknown of a skipped column is not tied to any pivot: it is a free variable and may take any real value.

free parameters = n − r

n is the number of unknowns (columns of A) and r is the number of pivots in the echelon form. If r = n there is one solution; if r < n there are infinitely many, written with parameters t₁, t₂, …; a row like [0 0 0 | c] with c ≠ 0 means no solution, as 1.4 develops.

Partial pivoting: always swap the entry of largest absolute value in the pivot column into the pivot position. Every multiplier then satisfies |m| ≤ 1, so entries do not blow up and rounding error stays small. Hand calculations also get easier, because the numbers stay small.

|m| = |a_ik| / max|a_jk| ≤ 1

a_jk runs over the rows at and below the pivot row; choosing the largest one as the pivot keeps every multiplier at or below 1 in size.

Worked example

Question. Solve the system x + y + z = 3, 2x + 2y + 2z = 6, x − y = 0 by Gaussian elimination, and give the general solution with its free parameter.

  1. Write the augmented matrix: R1 = [1, 1, 1 | 3], R2 = [2, 2, 2 | 6], R3 = [1, −1, 0 | 0].
  2. Pivot a₁₁ = 1. Multiplier for R2: m = 2/1 = 2. R2 ← R2 − 2R1 gives [0, 0, 0 | 0].
  3. Multiplier for R3: m = 1/1 = 1. R3 ← R3 − R1 gives [0, −2, −1 | −3].
  4. Swap the zero row to the bottom (R2 ↔ R3): [1, 1, 1 | 3], [0, −2, −1 | −3], [0, 0, 0 | 0].
  5. Pivot in column 2 is −2. Scale R2 by −1/2: [0, 1, 1/2 | 3/2]. Echelon form reached.
  6. Count: r = 2 pivots among n = 3 unknowns, so n − r = 1 free parameter. Column 3 has no pivot, so z is free: put z = t.
  7. Back substitution, row 2: y + z/2 = 3/2, so y = (3 − t)/2. Row 1: x + y + z = 3, so x = 3 − (3 − t)/2 − t = (3 − t)/2.
  8. Check at t = 1: x = 1, y = 1, z = 1. Row 1: 1 + 1 + 1 = 3 ✓. Row 2: 2 + 2 + 2 = 6 ✓. Row 3: 1 − 1 = 0 ✓.

Exam traps

  • Dividing by a zero pivot instead of swapping in a lower row first. The swap is legal and costs nothing; the division is undefined.
  • Treating a column with no pivot as if it had one. A skipped column means a free variable, not a missing equation.
  • Using the first row's multiplier on the wrong row: R_i ← R_i − m·R_k zeroes a_ik only when m = a_ik / a_kk taken from the current matrix, not from the original one.
  • Forgetting that a zero row [0 0 0 | 0] carries no information, while [0 0 0 | c] with c ≠ 0 means no solution at all.
  • Sign slips in back substitution: y + z/2 = 3/2 gives y = (3 − t)/2, but multiplying only the left side by 2 gives a wrong answer.

1.4 Rank of a matrix and consistency of systems

Rank counts the independent rows, and in practice it counts the pivots left after elimination. One number r = rank A and one extra number r′ = rank [A|b] decide everything: a contradiction, a single point, or a whole family of solutions. Engineers use this test before solving large models: power-flow equations, circuit nets, and regression fits all begin by checking whether the equations agree. It also tells you how many free parameters remain, which is the first step to describing every solution.

You need: row echelon form and Gaussian elimination.

What rank counts

Take a matrix A with m rows and n columns. Reduce it to row echelon form. A pivot is the first nonzero entry of a nonzero row. The rank of A, written rank A or r, is the number of nonzero rows in any echelon form. This equals the number of pivots. It is an integer with 0 ≤ r ≤ min(m, n).

Row rank is the dimension of the row space. Column rank is the dimension of the column space. For every matrix, row rank = column rank, and this common value is rank A. Sketch: row operations preserve all linear relations among columns, so column rank does not change. In echelon form, the pivot columns are independent; every other column is a combination of earlier pivot columns. The pivot count is therefore the column rank. The same count is the number of nonzero rows, so it is also the row rank.

Some syllabi define rank as the order of the largest non-vanishing minor. A minor is the determinant of a square submatrix. The largest size with a nonzero determinant equals the pivot count. An r×r minor on pivot rows and pivot columns is nonzero, and every larger minor is zero because the rows are dependent. Both definitions give the same r.

The three-number consistency test

Write the system as Ax = b. A is the m×n coefficient matrix, x is the n×1 vector of unknowns, b is the m×1 right-hand side. Form the augmented matrix [A|b]. Let r = rank A and r′ = rank [A|b]. The extra column can add at most one pivot, so r′ is r or r + 1.

r < r′ → no solution; r = r′ = n → one solution; r = r′ = r < n → n − r free variables

r is rank A; r′ is rank [A|b]; n is the number of unknowns; a free variable is an unknown without a pivot.

If r < r′, echelon form contains a row [0 ... 0 | c] with c ≠ 0, which reads 0 = c. No x can satisfy it. If r = r′ = n, every unknown is a pivot column, so back substitution fixes one value for each unknown. If r = r′ = r < n, the system is consistent and n − r unknowns have no pivot. Give each a parameter; the others are fixed by back substitution. The solution set is infinite.

Homogeneous systems and nullity

Set b = 0. The homogeneous system Ax = 0 is always consistent: x = 0 is a solution. If rank A = n, this zero solution is the only one. If rank A = r < n, there are nonzero solutions. The number of free variables is n − r. The solution set has dimension n − r; this number is the nullity of A. The dimension statement is proved in Unit 3, rank-nullity. Here you can count parameters: choose n − r free unknowns, and back substitution gives the rest. A common mistake is to say a homogeneous system always has infinitely many solutions. That happens only when r < n.

Worked example

Question. For the system x + 2y + 3z = 4, 2x + 4y + 6z = 8, x + y + z = 3, decide whether it has no solution, a unique solution, or infinitely many solutions. If it has infinitely many, write the solution set with a parameter.

  1. Write the augmented matrix [A|b] = [[1, 2, 3 | 4], [2, 4, 6 | 8], [1, 1, 1 | 3]].
  2. Apply R2 ← R2 − 2R1. Row 2 becomes [0, 0, 0 | 0].
  3. Apply R3 ← R3 − R1. Row 3 becomes [0, −1, −2 | −1].
  4. An echelon form is [[1, 2, 3 | 4], [0, −1, −2 | −1], [0, 0, 0 | 0]]. Pivot columns are 1 and 2, so rank A = 2 and rank [A|b] = 2. Here n = 3.
  5. Since r = r′ = 2 < 3, the system is consistent with n − r = 1 free variable. Let z = t.
  6. Row 2 gives −y − 2z = −1, so y = 1 − 2z = 1 − 2t. Row 1 gives x + 2y + 3z = 4, so x = 4 − 2(1 − 2t) − 3t = 2 + t.
  7. Check t = 1, giving (x, y, z) = (3, −1, 1): 3 + 2(−1) + 3 = 4, 6 − 4 + 6 = 8, 3 − 1 + 1 = 3.

Answer. The system has infinitely many solutions: (x, y, z) = (2 + t, 1 − 2t, t) for any real t, with rank A = 2, rank [A|b] = 2, n = 3, and n − r = 1 free variable.

Exam traps

  • Checking rank A = rank [A|b] and calling the answer unique. You must also compare the common rank with n.
  • Thinking rank A < n alone gives infinitely many solutions. First check rank A = rank [A|b]; otherwise the system is inconsistent.
  • Counting equations instead of pivots. Rank can be smaller than both m and n.
  • For a homogeneous system, saying it always has nonzero solutions. Nonzero solutions need r < n.
  • Mixing row rank and column rank. They are equal for every matrix, so use either count.

Beyond the syllabus

Not for the exam. Rank is the backbone of data compression and recommender systems: a low-rank matrix approximates a large user-item table. In control and circuit analysis, rank shows whether sensors or equations are redundant. Numerical rank uses a tolerance on singular values, because round-off makes exact zeros rare. 1.5 LU factorization

LU factorization writes a square matrix as A = LU, where L is unit lower triangular and U is upper triangular. It exists to avoid repeating Gaussian elimination for every right-hand side. Factor once, then solve two triangular systems for each new b. This is useful in circuit simulation, structural analysis, and any code that solves the same Ax = b with many b. Only a few universities teach this as an exam topic.

You need row operations and Gaussian elimination from 1.2 and 1.3.

The product A = LU

For an n × n matrix A, write A = LU. L is unit lower triangular: 1s on the diagonal, zeros above it, and the elimination multipliers below it. U is upper triangular: zeros below the diagonal, and it is the echelon form after elimination. This is the Doolittle form. Crout form puts the pivots in L instead. The multiplier ℓik = aik/akk clears entry (i,k).

A = LU without row swaps works when every leading principal minor of A is nonzero: the determinants of the top-left 1×1, 2×2, ..., n×n blocks. If a zero pivot appears, swap rows: PA = LU, where P records the swaps.

The factors store the whole elimination history: U is the final staircase, and L records each row operation as a number. The product multiplies back to A exactly.

Building L and U

  1. Copy A into U and make L the n × n identity matrix.
  2. For k = 1 to n−1, use U[k][k] as the pivot; if it is 0, stop, because a row swap is needed.
  3. For i = k+1 to n, set ℓik = U[i][k]/U[k][k] and store it in L[i][k].
  4. For j = k to n, replace U[i][j] by U[i][j] − ℓikU[k][j].
  5. After the last column, A = LU.

Store the multiplier before changing the row. The factorization costs about 2n3/3 operations. Each new right-hand side costs about 2n2 operations for the two triangular solves, so reusing L and U is much cheaper than fresh elimination. No division by zero is allowed; a zero pivot stops the no-swap factorization.

Two triangular solves

To solve Ax = b, write LUx = b and set y = Ux. First solve Ly = b forward, from the top. Then solve Ux = y backward, from the bottom.

y<sub>i</sub> = b<sub>i</sub> − Σ<sub>j=1</sub><sup>i−1</sup> ℓ<sub>ij</sub>y<sub>j</sub>,   x<sub>i</sub> = (y<sub>i</sub> − Σ<sub>j=i+1</sub><sup>n</sup> u<sub>ij</sub>x<sub>j</sub>) / u<sub>ii</sub>

yi is the forward-solve value; xi is the unknown; ℓij and uij are entries of L and U; bi is the right-hand side.

The formulas use the top-to-bottom order for L and bottom-to-top order for U. The two solves are cheap and simple loops.

Worked example

Question. Factor A = [[2,1,1],[4,3,3],[8,7,9]] as A = LU, then solve Ax = b for b = (4,10,24).

  1. Start with U = A and L = I. Column 1 pivot is 2.
  2. Row 2 multiplier: 4/2 = 2; row 2 becomes [0,1,1]. Row 3 multiplier: 8/2 = 4; row 3 becomes [0,3,5].
  3. Column 2 pivot is 1. Row 3 multiplier: 3/1 = 3; row 3 becomes [0,0,2].
  4. So L = [[1,0,0],[2,1,0],[4,3,1]] and U = [[2,1,1],[0,1,1],[0,0,2]].
  5. Forward solve Ly = b = (4,10,24): y1 = 4; 2(4)+y2 = 10 gives y2 = 2; 4(4)+3(2)+y3 = 24 gives y3 = 2.
  6. Back solve Ux = y = (4,2,2): 2x3 = 2 gives x3 = 1; x2+x3 = 2 gives x2 = 1; 2x1+x2+x3 = 4 gives x1 = 1.

Answer. The solution is x = (1,1,1).

Exam traps

  • Putting multipliers in U instead of L; L must hold them below the diagonal.
  • Assuming every square matrix has A = LU with no row swap; a zero pivot needs PA = LU.
  • Forgetting the 1s on the diagonal of L.
  • Solving Ux = b before Ly = b; forward solve comes first.

Takeaways

  1. A linear system is a set of linear constraints, and Ax=b separates the coefficient pattern A from the data b.
  2. Elementary row operations are reversible, so they change the matrix but not the solution set of the system.
  3. REF shows the staircase of pivots; RREF goes further and makes the solution readable without back substitution.
  4. Gaussian elimination does forward elimination then back substitution; Gauss-Jordan continues to RREF.
  5. Rank counts pivots, and comparing rank A, rank [A|b], and n classifies the system as inconsistent, unique, or infinite.
  6. A homogeneous system Ax=0 is always consistent; it has nonzero solutions exactly when rank A is less than the number of unknowns.
  7. LU factorization stores elimination in two triangular matrices, so repeated solves with the same A need only forward and back substitution.
  8. Row swaps may be needed for a zero pivot, leading to PA=LU rather than plain A=LU.

Glossary

Augmented matrix
The matrix [A|b] formed by attaching the right-hand side column b to A.
Back substitution
Solving a triangular system from the bottom equation upward.
Coefficient matrix
The matrix A formed by the coefficients of the unknowns in Ax=b.
Consistent system
A system that has at least one solution.
Elementary row operation
One of swap, scale by a nonzero number, or add a multiple of one row to another.
Forward substitution
Solving a lower triangular system from the top equation downward.
Free variable
A variable corresponding to a column without a pivot, whose value may be chosen freely.
Gauss-Jordan method
Row reduction to RREF, which gives the solution without a separate back substitution step.
Gaussian elimination
The process of forward elimination to REF followed by back substitution.
Homogeneous system
A system of the form Ax=0.
Inconsistent system
A system that has no solution.
Leading entry
The first nonzero entry in a row of a matrix; in REF it is the pivot.
Linear equation
An equation in which each unknown appears only to the first power and no products of unknowns occur.
LU factorization
A factorization A=LU with L unit lower triangular and U upper triangular.
Non-homogeneous system
A system Ax=b in which b is not the zero vector.
Nullity
The number n−rank(A), equal to the dimension of the null space of A.
Permutation matrix
A matrix obtained by permuting rows of the identity, used to record row swaps in PA=LU.
Pivot
The first nonzero entry of a row when a matrix is in echelon form.
Rank
The number of pivots, equivalently the number of nonzero rows in any REF of the matrix.
Reduced row echelon form
An echelon form with pivot 1 and zeros above and below every pivot.
Right-hand side vector
The column vector b in Ax=b, containing the constants on the right of the equations.
Row echelon form
A staircase form with zero rows at the bottom and zeros below each pivot.
Row equivalent matrices
Matrices that can be changed into each other by elementary row operations.
Solution vector
A column vector whose entries satisfy every equation of the system.
System of linear equations
A collection of linear equations in the same unknowns that must hold together.
Trivial solution
The solution x=0 of a homogeneous system.
