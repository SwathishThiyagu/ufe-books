2.1 Vector spaces over real and complex fields

A vector space is a set whose elements you can add and scale by numbers from a field, and the result stays in the set. The rules are the same ones you already use for arrows in the plane: addition is commutative and has a zero, and scaling distributes over sums. Engineers use this abstraction because one proof about Rⁿ then covers matrices, polynomials, signals and solutions of linear systems. Some syllabi write the field as F and say “V is a vector space over F”.

You need Unit 1 for Rⁿ and matrix arithmetic.

The field of scalars

A field is a set F with two operations, + and ×, that obey ordinary arithmetic. The real numbers R and complex numbers C are fields; the rationals Q also work. The integers Z do not, because 2 has no inverse in Z. For all a, b, c in F:

  • a + b = b + a and a × b = b × a.
  • (a + b) + c = a + (b + c); (a × b) × c = a × (b × c).
  • There are 0 and 1 with a + 0 = a and a × 1 = a.
  • Each a has −a with a + (−a) = 0; each nonzero a has a⁻¹ with a × a⁻¹ = 1.
  • a × (b + c) = a × b + a × c.

These are the field axioms. You do not prove them for R or C here; you use them. The field supplies the scalars. A scalar is an element of F: real when F = R, complex when F = C. The choice matters: i = √(−1) is a scalar over C, not over R. Dimension will depend on the field.

The vector space axioms

Fix a field F. A vector space over F is a set V with vector addition u + v ∈ V and scalar multiplication a·v ∈ V for a ∈ F, v ∈ V. The eight core rules split into two groups.

  1. u + v = v + u.
  2. (u + v) + w = u + (v + w).
  3. There is a zero vector 0 with v + 0 = v.
  4. Each v has −v with v + (−v) = 0.
  5. 1·v = v.
  6. (ab)·v = a·(b·v).
  7. a·(u + v) = a·u + a·v.
  8. (a + b)·v = a·v + b·v.

Closure is rules 9 and 10 in books that count it: u + v and a·v must lie in V. Check closure first in exams. “V is a vector space over F” means all rules hold with scalars from F. Elements of V are vectors, even when they are matrices or functions. The zero vector 0 is not the scalar 0.

Five properties you can prove

These five facts follow from the axioms; they are not extra assumptions.

  • 1. 0·v = 0. Put a = 0 in axiom 8: (0 + 0)·v = 0·v + 0·v. The left side is 0·v. Subtract 0·v to get 0 = 0·v.
  • 2. a·0 = 0. Use axiom 7 with u = v = 0: a·(0 + 0) = a·0 + a·0. Since 0 + 0 = 0, the left side is a·0, so a·0 = a·0 + a·0. Subtract a·0 (i.e. add its negative) from both sides to get 0 = a·0.
  • 3. (−1)·v = −v. v + (−1)·v = 1·v + (−1)·v = (1 + (−1))·v = 0·v = 0. The inverse of v is unique, so (−1)·v = −v.
  • 4. If a·v = 0 then a = 0 or v = 0. If a ≠ 0, apply a⁻¹ to both sides: a⁻¹·(a·v) = a⁻¹·0. The left side is (a⁻¹a)·v = 1·v = v. The right side is 0 by property 2. Hence v = 0.
  • 5. Cancellation: if u + w = v + w then u = v. Add −w to both sides.

Every proof uses only the axioms, so it holds in every vector space.

Examples and non-examples

  • Rⁿ over R. Vectors are n-tuples (x₁,…,xₙ) of real numbers; add coordinatewise, scale each coordinate. Zero is (0,…,0).
  • Cⁿ over C. Same with complex entries. Cⁿ is also a vector space over R by restricting scalars to real numbers. Same set, different field.
  • Mm×n(R). All m by n real matrices; entrywise addition and scaling. Zero matrix is 0.
  • Pn(t). Polynomials in t of degree at most n with real coefficients. The zero polynomial is 0. Degree exactly n fails: tⁿ and −tⁿ both have degree n, but their sum tⁿ + (−tⁿ) is the zero polynomial, which is not of degree n. So the set of polynomials of degree exactly n is not closed under addition.
  • C[0,1]. Continuous real functions on [0,1]; (f + g)(x) = f(x) + g(x), (a·f)(x) = a f(x). Zero function is 0.
  • Homogeneous systems. Solutions of Ax = 0 form a vector space. Ax = b with b ≠ 0 is not; x = 0 is missing.
  • Non-example. S = {(x,y) ∈ R² : x + 2y = 1}. Zero fails: 0 + 2·0 = 0 ≠ 1. Closure also fails; see the worked example.

Worked example

Question. Decide whether S = {(x, y) ∈ R² : x + 2y = 1}, with the usual addition and scalar multiplication, is a vector space over R.

  1. The zero vector must lie in S. Test (0, 0): 0 + 2·0 = 0, and 0 ≠ 1, so (0, 0) ∉ S.
  2. Closure under addition must hold. The point (1, 0) lies in S because 1 + 2·0 = 1.
  3. The point (−1, 1) lies in S because −1 + 2·1 = 1.
  4. Their sum is (1, 0) + (−1, 1) = (0, 1).
  5. Test the sum in S: 0 + 2·1 = 2, and 2 ≠ 1, so (0, 1) ∉ S.
  6. The zero vector is missing and closure under addition fails. Therefore S is not a vector space.

Answer. S is not a vector space over R: it fails both the zero-vector test and closure under addition.

Exam traps

  • Checking closure under addition and forgetting scalar multiplication. Both must be tested.
  • Forgetting the zero vector. A line like x + 2y = 1 fails already because (0, 0) is missing, even before closure fails.
  • Assuming every subset of a vector space is a vector space. The subset must contain 0 and be closed; see Chapter 2.2.
  • Mixing the scalar 0 with the zero vector 0. They are different objects in different sets.
  • Forgetting that the field decides dimension: C² has dimension 2 over C but 4 over R.

2.2 Subspaces, sums and direct sums

A subspace is a subset of a vector space that is a vector space with the same addition and scaling. It lets you work inside a smaller world: a plane through the origin, a line through the origin, the solutions of Ax = 0. Sums build bigger subspaces from two smaller ones, and a direct sum guarantees that each vector splits in only one way. These ideas organise solutions of linear systems and later decompositions in signals, graphics and data.

You need: the vector-space axioms and examples from Chapter 2.1.

Subspace and the three-step test

A subset W of a vector space V is a subspace when W is itself a vector space under the same addition and scalar multiplication. Every subspace must contain the zero vector 0 of V, because a vector space has an additive identity.

The three-step test is the safe way to check a candidate. Use the same 0 as V.

  1. Check 0 ∈ W.
  2. For all u, v ∈ W, check u + v ∈ W.
  3. For all u ∈ W and all scalars a, check au ∈ W.
  4. If all three hold, W is a subspace of V.

A one-line version: W is non-empty and au + bv ∈ W for all u, v ∈ W and all scalars a, b. Non-empty plus closure under au + bv gives 0 by taking a = b = 0.

Standard examples: a line through the origin in R²; a plane through the origin in R³; the set of symmetric n×n matrices; the solution set of a homogeneous system Ax = 0 in Rⁿ.

Non-examples matter. The line y = x + 1 in R² misses 0, so it is not a subspace. The union of the x-axis and the y-axis in R² contains 0 and is closed under scaling, but (1,0) + (0,1) = (1,1) is outside the union, so addition fails.

Intersections, unions and sums

The intersection U ∩ W of two subspaces is always a subspace. If x, y ∈ U ∩ W, then x, y lie in both U and W, so x + y and ax lie in both.

The union U ∪ W is usually not a subspace. It is a subspace only when one of U, W contains the other; otherwise adding a vector from U to a vector from W leaves the union.

U + W = {u + w : u ∈ U and w ∈ W}

U and W are subspaces of the same vector space V; u and w are vectors.

The sum U + W is the smallest subspace of V that contains both U and W. The sum is direct, written U ⊕ W, when every vector in U + W has exactly one decomposition u + w. Equivalently, U ∩ W = {0}.

U ⊕ W ⇔ U ∩ W = {0}

U and W are subspaces of V; {0} is the zero subspace.

Why the two conditions agree: Take any vector u + w in U + W with u ∈ U, w ∈ W. If a non-zero v lies in U ∩ W, then u + w = (u + v) + (w − v), where u + v ∈ U and w − v ∈ W. Since v ≠ 0, the pair (u + v, w − v) differs from (u, w), so this is a second decomposition. Conversely, if u + w = u′ + w′ with u, u′ ∈ U and w, w′ ∈ W, then u − u′ = w′ − w lies in U ∩ W, so a non-zero intersection breaks uniqueness.

Dimension formula and how to use it

dim(U + W) = dim U + dim W − dim(U ∩ W)

dim means dimension over the same field; U and W are finite-dimensional subspaces of V.

Use the formula in three moves. Find a basis and dimension for U. Find a basis and dimension for W. Find the intersection U ∩ W and its dimension; then subtract.

Example: in R³, the x-axis U = {(a,0,0)} and the z-axis W = {(0,0,c)}. dim U = 1 and dim W = 1. Their intersection is {0}, dimension 0. So dim(U + W) = 1 + 1 − 0 = 2. The sum is the xz-plane, and it is direct.

If dim(U + W) equals dim V and U ∩ W = {0}, then V = U ⊕ W. If dim(U ∩ W) > 0, the sum is not direct, and then dim(U + W) = dim U + dim W − dim(U ∩ W) is strictly less than dim U + dim W.

Worked example

Question. In R³ let U = {(a, b, 0) : a, b ∈ R} be the xy-plane and W = {(0, b, c) : b, c ∈ R} be the yz-plane. Find dim U, dim W, dim(U ∩ W) and dim(U + W). Is U + W a direct sum? Give two decompositions of (1, 2, 3) as u + w with u ∈ U and w ∈ W.

  1. The xy-plane U has basis (1,0,0) and (0,1,0). Hence dim U = 2.
  2. The yz-plane W has basis (0,1,0) and (0,0,1). Hence dim W = 2.
  3. A vector (x,y,z) lies in both U and W exactly when z = 0 from U and x = 0 from W. So the intersection is {(0,y,0) : y ∈ R}, the y-axis, of dimension 1.
  4. By the dimension formula, dim(U + W) = 2 + 2 − 1 = 3. Since U + W is a subspace of R³ of dimension 3, U + W = R³.
  5. The intersection is not {0}, so the sum is not direct.
  6. Two decompositions of (1,2,3): (1,2,0) + (0,0,3) and (1,1,0) + (0,1,3). Each first vector lies in U and each second vector lies in W.

Answer. dim U = 2, dim W = 2, dim(U ∩ W) = 1, dim(U + W) = 3; the sum is not direct. Two decompositions of (1,2,3) are (1,2,0) + (0,0,3) and (1,1,0) + (0,1,3).

Exam traps

  • Calling U ∪ W a subspace. The union of two different lines through the origin is not closed under addition.
  • Testing only scaling and forgetting addition. The union of the two axes in R² passes scaling but fails addition.
  • Saying a sum is direct without checking the intersection. Direct means U ∩ W = {0}. The test dim(U + W) = dim U + dim W is equivalent to this, so it also works, but computing U ∩ W directly is safer.
  • Forgetting the zero test. A line such as y = x + 1 in R² is not a subspace because 0 is missing.
  • Using the dimension formula with a sign slip: dim(U + W) = dim U + dim W − dim(U ∩ W), not plus the intersection.

2.3 Linear combinations and linear span

A vector space gives you exactly two moves: scale a vector, and add two vectors. A linear combination is one round of both — multiply each vector by a number, then add. Gather every vector you can build this way from a set S and you have the span of S, the smallest subspace that holds S. Spans turn a short list of vectors into a whole line, plane or space, so they describe solution sets, the reachable states of a control system, and every column of a matrix at once.

You need: Chapter 2.1 for the ten vector space rules and Chapter 2.2 for the subspace test, plus Unit 1 for solving linear systems by elimination.

Linear combinations

Take vectors v₁, v₂, …, vₖ from a vector space V over a field F, and scalars c₁, c₂, …, cₖ from F. The single vector c₁v₁ + c₂v₂ + ⋯ + cₖvₖ is a linear combination of v₁, …, vₖ. The scalars cᵢ are its coefficients.

c₁v₁ + c₂v₂ + ⋯ + cₖvₖ, cᵢ ∈ F

vᵢ are vectors in V; cᵢ are scalars (coefficients) from the field F, which is R or C here; k ≥ 1 is a finite count.

Only two operations appear: scalar multiplication and addition. There are no powers, no products of two vectors, and no constant term added at the end. That is why the combination is called linear.

In R³ take v₁ = (1, 2, 0) and v₂ = (0, 1, 1). Then 3v₁ − v₂ = (3, 6, 0) − (0, 1, 1) = (3, 5, −1) is a linear combination with c₁ = 3 and c₂ = −1. The choice c₁ = c₂ = 0 gives the zero vector (0, 0, 0).

Every combination uses finitely many vectors. Addition and scaling act on two or three vectors at a time; the definition has no infinite sum in it.

The span of a set is a subspace

For a set S ⊆ V, the span of S, written span(S), is the set of all linear combinations of finitely many vectors of S.

span(S) = { c₁v₁ + ⋯ + cₖvₖ : k ≥ 0, vᵢ ∈ S, cᵢ ∈ F }

k = 0 is allowed and gives the empty sum, which is the zero vector; the vectors vᵢ are picked from S and may repeat.

Two conventions follow. span(∅) = {0}, because the only combination you can form is the empty one. And 0 always lies in span(S), by setting every cᵢ = 0.

  1. 0 = 0·v₁ + ⋯ + 0·vₖ, so the zero vector is in span(S).
  2. If u = Σaᵢvᵢ and w = Σbⱼwⱼ are in span(S), then u + w = Σaᵢvᵢ + Σbⱼwⱼ is again a finite combination of vectors of S.
  3. If c ∈ F, then cu = Σ(caᵢ)vᵢ is in span(S), since each caᵢ is still a scalar.
  4. These three facts are exactly the subspace test of Chapter 2.2, so span(S) is a subspace of V.

It is also the smallest subspace containing S. Let W be any subspace with S ⊆ W. A subspace is closed under scaling and addition, so W already holds every combination of vectors of S; hence span(S) ⊆ W. Therefore span(S) sits inside every subspace that contains S, and the span is their intersection: span(S) = ⋂ {W : W is a subspace of V and S ⊆ W}.

Membership test, pictures and spanning sets

Membership test. Given v₁, …, vₖ in Fⁿ and a target b, ask whether b = c₁v₁ + ⋯ + cₖvₖ has a solution. Put the vᵢ as the columns of A = [v₁ ⋯ vₖ] and let x = (c₁, …, cₖ)ᵗ. Then b lies in span{v₁, …, vₖ} exactly when Ax = b is consistent, which happens exactly when rank(A) = rank([A | b]). Test it by Gaussian elimination, as in Unit 1.

Pictures. One non-zero vector v in R³ spans the line {cv : c ∈ R} through the origin. Two vectors that are not multiples of each other span a plane through the origin. A single vector, or the zero vector alone, gives only that line or only the origin — the count of vectors never settles the shape on its own.

Spanning sets. When span(S) = V we say S spans V, and S is a spanning set of V. Some syllabi write generating set, linear hull, or closed linear span for the same object. Adding vectors to S can only enlarge the span. Removing a vector that already lies in the span of the others leaves the span unchanged, so a spanning set can be trimmed without losing reach; that trimming idea becomes the basis in Chapter 2.5.

Worked example

Question. In R³ let v₁ = (1, 2, 0) and v₂ = (0, 1, 1). Is the vector (2, 5, 1) in span{v₁, v₂}? If yes, give the coefficients.

  1. We need scalars a, b with a(1, 2, 0) + b(0, 1, 1) = (2, 5, 1). Reading coordinates separately gives three scalar equations.
  2. First coordinate: a·1 + b·0 = 2, so a = 2.
  3. Third coordinate: a·0 + b·1 = 1, so b = 1.
  4. Second coordinate must then read 2a + b = 2(2) + 1 = 5. The target's second coordinate is 5, so the equation holds and the system is consistent.
  5. Verify the vector equation: 2(1, 2, 0) + 1(0, 1, 1) = (2, 4, 0) + (0, 1, 1) = (2, 5, 1). Correct.

Answer. Yes, (2, 5, 1) lies in span{v₁, v₂}, namely (2, 5, 1) = 2v₁ + 1v₂, with coefficients a = 2 and b = 1.

Exam traps

  • Writing the target vector as a row when the given vectors are columns. The system changes shape and so does the answer; keep the vᵢ as columns of A and b on the right.
  • Assuming more vectors means a bigger span. In R³ three vectors that are all multiples of one vector span only a line, and two vectors with one a multiple of the other span only a line too.
  • Confusing S with span(S). The span is usually far larger than S, and it always contains 0 even when S does not.
  • Treating span(A) ∪ span(B) as a subspace. It is usually not one; the honest statement is span(A ∪ B) = span(A) + span(B), the sum of subspaces from Chapter 2.2.
  • Stopping after two coordinates. The remaining equations are the test: a = 2 and b = 1 must also satisfy the second coordinate, and an examiner will ask for that check.

Analyze True or false: if v₃ ∈ span{v₁, v₂}, then span{v₁, v₂, v₃} = span{v₁, v₂}. Justify. 6 marks

True. Write v₃ = αv₁ + βv₂. Any c₁v₁ + c₂v₂ + c₃v₃ becomes (c₁ + c₃α)v₁ + (c₂ + c₃β)v₂, a combination of v₁ and v₂. The reverse inclusion is immediate since both v₁, v₂ are in span{v₁, v₂, v₃}.

Not for the exam. 2.4 Linear dependence and independence

A list of vectors is linearly independent when the only way to combine them into the zero vector is to multiply every vector by zero. That one test decides whether a spanning set carries spare vectors, whether a coordinate list is unique, and whether two solutions of a differential equation are really different. Independence is the check behind basis, dimension and rank, and it is used wherever a system must have one answer and not many.

You need: linear combinations from chapter 2.3, and row reduction from Unit 1, Gaussian elimination.

The only combination that gives zero

V is a vector space over a field F — take F = R or F = C, as in chapter 2.1. A set S = {v₁, v₂, …, vₖ} of vectors in V is linearly independent when

c₁v₁ + c₂v₂ + ⋯ + cₖvₖ = 0  ⟹  c₁ = c₂ = ⋯ = cₖ = 0

v₁ … vₖ are vectors in V; c₁ … cₖ are scalars from F; 0 on the right is the zero vector of V, not the number zero.

If some scalars, not all zero, add up to the zero vector, then S is linearly dependent, and that choice of scalars is a non-trivial relation.

The zero choice always works: 0v₁ + ⋯ + 0vₖ = 0. Independence says nothing else works. Dependence says something else does.

Dependence has a second face. Suppose c₁ ≠ 0 in a non-trivial relation. Then v₁ = −(c₂/c₁)v₂ − ⋯ − (cₖ/c₁)vₖ, so v₁ is a linear combination of the other members (chapter 2.3). A dependent set has at least one vector that the rest already span. That vector is spare.

Say "a linearly independent set of vectors", as most syllabi do. Independence belongs to the set, not to one vector on its own.

Facts you can prove in one line

  • Zero vector. Any set containing 0 is dependent, because 1·0 + 0v₂ + ⋯ + 0vₖ = 0 with coefficient 1 ≠ 0.
  • Subsets. A subset of an independent set is independent. Pad any relation on the subset with zeros for the missing vectors; the large set has only the trivial relation, so the small one does too.
  • Supersets. A superset of a dependent set is dependent. Keep the non-trivial relation and give every new vector the coefficient 0.
  • Two vectors. {u, v} is dependent exactly when one is a scalar multiple of the other: u = λv gives 1·u − λ·v = 0; and au + bv = 0 with a ≠ 0 gives u = −(b/a)v.
  • Rⁿ. Any n + 1 vectors in Rⁿ are dependent. Write a homogeneous system with n equations and n + 1 unknowns; more unknowns than equations leaves a free variable, so a non-zero solution exists (see Unit 1, Gaussian elimination). That solution is a non-trivial relation among the columns.

For three or more vectors, "no vector is a multiple of another" proves nothing. In R³ the vectors (1, 0, 0), (0, 1, 0), (1, 1, 0) have no such multiple, yet the third is the sum of the first two, so the set is dependent.

The pivot test

To test v₁, …, vₖ in Rⁿ, make them the columns of a matrix A with k columns, then row reduce it (Unit 1). S is independent exactly when every column of A is a pivot column, that is, when rank A = k.

Why it works: a column without a pivot is a free variable, so Ax = 0 has a non-zero solution x, and x is a non-trivial relation among the columns. Chapter 2.6 reads the same test through the null space. Row operations change the columns but keep the relations between them, so the pivot count is safe to read off the reduced matrix.

Square case: n vectors in Rⁿ are independent exactly when det A ≠ 0, because rank n means A is invertible.

Functions are vectors too (chapter 2.1). Two solutions y₁, y₂ of a linear homogeneous differential equation are independent functions when the Wronskian W(x) = y₁y₂′ − y₁′y₂ is not identically zero. For solutions of a second-order equation with continuous coefficients, one point x₀ with W(x₀) ≠ 0 settles independence, and then W is never zero on that interval.

Worked example

Question. In R³ take v₁ = (1, 2, 3), v₂ = (2, 4, 6), v₃ = (1, 0, 1). (a) Show that {v₁, v₂, v₃} is dependent by giving a non-trivial relation. (b) Show that {v₁, v₃} is independent. (c) Confirm both answers with the pivot test.

Exam traps

  • One failed attempt at finding a relation proves nothing. Independence needs a proof from the equations, not a hunch that no relation exists.
  • The field matters. {1, i} is independent over R but dependent over C, because i·1 − 1·i = 0 uses the scalar i. Check which field the question uses.
  • "No vector is a scalar multiple of another" decides only the two-vector case. With three vectors you must test all combinations, as (1, 0, 0), (0, 1, 0), (1, 1, 0) shows.
  • A set containing the zero vector is always dependent, and a set listing the same vector twice is always dependent; examiners ask for both as one-mark parts.
  • Independent is not the same as orthogonal, and dependent is not the same as parallel in a picture. Independence is about coefficients, not about angles.

2.5 Basis and dimension

A basis is a list of vectors that is independent and spanning at the same time. Independence stops duplicates and hidden relations; spanning reaches every vector. Together they give each vector one coordinate list, like an address that cannot be written two ways. Engineers use coordinates to store, compress and solve. A photo is a list of numbers in a pixel basis; a UPI fraud model works on feature vectors in a chosen basis. The size of any basis is the dimension, a single number that tells you how much room the space has.

You need: linear combinations and span and linear dependence and independence.

Definition and coordinates

A basis of a vector space V is a set B = {v₁, v₂, …, vₙ} of vectors in V with two properties. The set is independent: c₁v₁ + c₂v₂ + ⋯ + cₙvₙ = 0 forces c₁ = c₂ = ⋯ = cₙ = 0. The set spans V: every vector v in V can be written as v = c₁v₁ + ⋯ + cₙvₙ for some scalars c₁, …, cₙ. The scalars are real for a real space and complex for a complex space.

v = c₁v₁ + c₂v₂ + ⋯ + cₙvₙ

v is any vector in V; v₁, …, vₙ are the basis vectors; c₁, …, cₙ are the coordinates of v in that basis.

The two properties together make the list unique. If v = a₁v₁ + ⋯ + aₙvₙ and also v = b₁v₁ + ⋯ + bₙvₙ, subtract: (a₁ − b₁)v₁ + ⋯ + (aₙ − bₙ)vₙ = 0. Independence gives aᵢ − bᵢ = 0 for every i. So aᵢ = bᵢ.

A basis is a set; once we fix an order for its vectors we call it an ordered basis. For an ordered basis, the coordinate vector (c₁, …, cₙ) is unique. The ordered list (c₁, …, cₙ) is the coordinate vector of v in the basis B. The standard basis of Rⁿ is e₁ = (1, 0, …, 0), e₂ = (0, 1, 0, …, 0), …, eₙ = (0, …, 0, 1). The standard basis of Cⁿ over C is the same list. In R³, (2, −5, 7) = 2e₁ − 5e₂ + 7e₃, so its coordinates are (2, −5, 7).

Dimension and standard examples

Any two bases of the same finite-dimensional vector space have the same number of vectors. That common number is the dimension, written dim V. A space with a basis of n vectors has dimension n. The zero space {0} has empty basis and dim{0} = 0.

  • dim Rⁿ = n, because e₁, …, eₙ form a basis.
  • dim Cⁿ = n over C. Over R, Cⁿ has dimension 2n, since each complex coordinate needs a real and an imaginary part.
  • The polynomials of degree at most n, written Pₙ, have basis {1, t, t², …, tⁿ}. There are n + 1 vectors, so dim Pₙ = n + 1. The polynomial 4 − 3t + 2t² in P₂ has coordinates (4, −3, 2).
  • The space M_{m×n} of all m × n matrices has the matrix units E_{ij}. E_{ij} has 1 in row i and column j, and 0 everywhere else. There are mn such matrices, so dim M_{m×n} = mn.

The coordinate list of a vector in a basis of dimension n always has exactly n entries. Coordinates are written using an ordered basis, because swapping two basis vectors changes the coordinate list.

Working rules in dimension n

Let dim V = n.

  • Any set of exactly n vectors taken from V is a basis if it spans V.
  • Any set of exactly n vectors taken from V is a basis if it is independent.

These rules save time in exams, but the count must be exact. n vectors that are dependent cannot span all of V, so they are not a basis. n + 1 vectors cannot be independent. A subspace W of a finite-dimensional space V has dim W ≤ dim V. Equality dim W = dim V happens only when W = V, so a proper subspace is always thinner.

Every spanning set contains a basis: throw away vectors that are combinations of the others until none is redundant. Every independent set sits inside a basis: add vectors until the set spans. The proofs are in the replacement theorem. A new basis changes coordinates; that is the change of basis used in Unit 3.

Worked example

Question. Is S = {(1, 1, 0), (0, 1, 1), (1, 0, 1)} a basis of R³? Give the dimension.

  1. Write a(1, 1, 0) + b(0, 1, 1) + c(1, 0, 1) = (0, 0, 0), where a, b, c are real numbers.
  2. Compare coordinates: a + c = 0, a + b = 0, b + c = 0.
  3. From a + c = 0, c = −a. From a + b = 0, b = −a. Substitute in b + c = 0: (−a) + (−a) = −2a = 0, so a = 0. Then b = 0 and c = 0.
  4. Only the zero combination gives the zero vector, so S is independent.
  5. S has 3 vectors and dim R³ = 3. An independent set of 3 vectors in a 3-dimensional space is a basis. So S is a basis of R³.

Answer. S is a basis of R³; the coefficients are a = b = c = 0, and dim R³ = 3.

Exam traps

  • Thinking a basis must be orthogonal or must contain e₁, e₂, e₃. The set {(1, 1), (2, 1)} is a basis of R²: its determinant is 1×1 − 2×1 = −1 ≠ 0, it contains neither e₁ nor e₂, and (1, 1)·(2, 1) = 3 ≠ 0, so it is not orthogonal.
  • Calling every spanning set a basis. {e₁, e₂, e₁ + e₂} spans R² but is dependent, so it is not a basis.
  • Treating dimension as a property of a chosen list. R³ has dimension 3 even if you write down seven vectors from it.
  • Assuming any n vectors in an n-dimensional space form a basis. Three dependent vectors in R³ do not span R³.
  • Forgetting that coordinates depend on the ordered basis. Reordering the basis vectors reorders the coordinate list.

2.6 Row space, column space and null space

Take a real matrix A with m rows and n columns. It carries three subspaces. The row space is spanned by its rows and lives in Rⁿ. The column space is spanned by its columns and lives in Rᵐ. The null space is every x in Rⁿ with Ax = 0. Row reduction keeps the row space and reveals a basis; the pivot columns of A give a basis of the column space. The shared dimension is the rank r, and n − r is the nullity. These ideas decide whether a system has no, one or many solutions, and they sit inside least squares, data compression and network flow.

You need Unit 1 for row reduction and consistency, and 2.3, 2.4 and 2.5 for span, independence, basis and dimension.

Three subspaces from one matrix

Fix a real matrix A of size m × n. It has m rows and n columns. A row is an n-tuple, so the row space Row A is a subspace of Rⁿ. A column is an m-tuple, so the column space Col A is a subspace of Rᵐ. The null space Null A is the set of all n-vectors x that solve Ax = 0. The zero on the right is the m-vector of zeros. The row space is the span of the rows; the column space is the span of the columns. The column space is also the set of all outputs Ax as x runs over Rⁿ. The null space records the inputs that produce the zero output. These are different subspaces in different spaces, so compare them only through dimension. A 2×3 matrix has row space and null space inside R³, but column space inside R².

Row A = span{r₁, …, rₘ} ⊆ Rⁿ,  Col A = span{c₁, …, cₙ} ⊆ Rᵐ,  Null A = {x ∈ Rⁿ : Ax = 0}

r₁, …, rₘ are the rows of A; c₁, …, cₙ are the columns; m is the number of rows; n is the number of columns; 0 is the zero vector in Rᵐ.

Row operations, pivots and rank

Row operations are swap, multiply a row by a nonzero scalar, and add a multiple of one row to another. Each new row is a linear combination of old rows. So the row space of the new matrix sits inside the old row space. Each operation is reversible, so the old row space sits inside the new one. The two row spaces are equal. Apply Gaussian elimination and reach a row echelon form U. The nonzero rows of U are independent, because each has a pivot in a column where earlier rows are zero. Those nonzero rows form a basis of Row A. The number of them is the rank r. Pivots also control the column space. Do not take columns of U: row operations change the column space. They do keep every linear relation between columns. If a set of columns of U is independent, the same columns of A are independent. The pivot columns of U mark which columns of A to use. Those columns of A form a basis of Col A. Hence column rank equals row rank, and both equal r.

rank A = dim Row A = dim Col A = r

rank A is the number of pivots in a row echelon form of A; dim V is the dimension of subspace V; r is the shared rank.

Null space and counting solutions

Solve Ax = 0 by row reducing A to U. Let r be the number of pivots. There are n − r free variables. Set one free variable to 1 and the others to 0, solve for the pivot variables, and get one null vector. Repeat for each free variable. These vectors are independent and span Null A, so they form a basis. The nullity is n − r. This gives the rank-nullity theorem for a matrix: r + (n − r) = n. The same rank decides consistency for Ax = b. Form the augmented matrix [A|b]. The system is consistent exactly when rank A = rank [A|b]. If ranks differ, a row like 0 = 1 appears. If they agree, pick one particular solution x_p. Every solution is x_p + x_h, where x_h is in Null A. The system has one solution when nullity is 0, and infinitely many when nullity is positive.

rank A + nullity A = n

rank A is the dimension of Row A and Col A; nullity A = dim Null A = n − r; n is the number of columns of A.

Worked example

Question. Let A = [[1, 2, 3], [2, 4, 7]]. Find a basis of the row space, a basis of the column space, a basis of the null space, the rank and the nullity. Check rank + nullity = n.

  1. A is 2×3, so m = 2 rows and n = 3 columns.
  2. Replace row 2 by row 2 − 2·row 1: [2, 4, 7] − [2, 4, 6] = [0, 0, 1]. The echelon matrix is U = [[1, 2, 3], [0, 0, 1]].
  3. The nonzero rows of U are (1, 2, 3) and (0, 0, 1). They are independent, so they form a basis of Row A.
  4. Pivot columns of U: column 1 has the first pivot; column 2 has entries 2 and 0, so it is not a pivot column; column 3 has the second pivot. Pivot columns are 1 and 3.
  5. Columns 1 and 3 of the original matrix A are c₁ = (1, 2) and c₃ = (3, 7). They form a basis of Col A.
  6. Solve Ux = 0 with x = (x, y, z). Equations: x + 2y + 3z = 0 and z = 0. So z = 0 and x = −2y. The variable y is free.
  7. Set y = 1. Then x = −2 and z = 0. A basis of Null A is (−2, 1, 0).
  8. Rank = number of pivots = 2. Nullity = n − rank = 3 − 2 = 1. Check: 2 + 1 = 3, which is n.

  • Putting null vectors in Rᵐ. A null vector x has n entries because Ax needs x in Rⁿ; m is the number of rows of A.
  • Testing consistency with rank A alone. For Ax = b you must compare rank A with rank [A|b].
  • Saying a zero row in U removes a dimension from the row space. The zero row is ignored; the nonzero rows of U give the row space basis.
  • Confusing rank with the number of rows of A. Rank is the number of pivots in a row echelon form, at most min(m, n).

2.7 Quotient spaces and the replacement theorem

A quotient space glues together vectors that differ only by a subspace W. The result is a new vector space V/W whose points are cosets v+W. This idea exists because many questions care about a vector only up to a harmless shift inside W: in R², all points on the same horizontal line differ by a point on the x-axis. Only a few universities teach this topic. It is used in linear algebra proofs and in error-correcting codes.

You need: vector spaces, subspaces, linear independence, and basis and dimension.

Cosets and the quotient space

Fix a vector space V and a subspace W. For a vector v in V, the coset v+W is the set of all vectors v+w with w in W. Two vectors lie in the same coset exactly when their difference lies in W. The quotient space V/W is the set of all cosets. Its zero is W itself, because 0+W=W. The negative of v+W is −v+W.

v+W = {v+w : w∈W}; V/W = {v+W : v∈V}

v is a vector in V; W is a subspace; w runs over W; V/W is the quotient space.

The operations on V/W are (u+W)+(v+W)=(u+v)+W and a(v+W)=av+W. They are well defined. If u+W=u′+W and v+W=v′+W, then u−u′∈W and v−v′∈W. Hence (u+v)−(u′+v′)=(u−u′)+(v−v′)∈W, so the sum is the same for every choice of representatives. Also av−av′=a(v−v′)∈W, so the scalar product is independent of the representative.

For finite-dimensional V, dim V/W = dim V − dim W. The quotient map sends each v to v+W; its kernel is W.

Replacement, deletion and extension

The replacement theorem, also called Steinitz exchange, compares a basis with an independent set. Let B={v₁,...,v_n} be a basis of V and let I={u₁,...,u_m} be an independent set. Then m≤n. After reordering B, some m of its vectors can be replaced by u₁,...,u_m and the result is still a basis.

Proof by exchange. Add u₁ to B. The enlarged set is dependent, so u₁ is a non-zero combination of B; some basis vector v_i has non-zero coefficient. Remove v_i. The new set spans V and has n vectors, so it is a basis. Repeat for u₂,...,u_m. Independence makes the next u_j lie outside the span of the earlier u's, so a basis vector with non-zero coefficient remains to remove.

Two consequences follow. The deletion theorem: a finite spanning set S contains a basis; delete one vector at a time while the span stays the same. The extension theorem: an independent set in a finite-dimensional space can be grown to a basis; add vectors until maximal. Also, any two bases have the same size: replacement gives m≤n and n≤m.

Worked example

Question. Let V=R² and W=span{(1,0)}, the x-axis. (a) Describe the coset (a,b)+W. (b) State when (a,b)+W=(a′,b′)+W. (c) Find dim V/W and check dim V/W=dim V−dim W.

  1. W consists of all (x,0) with x∈R. Thus (a,b)+W={(a+x,b):x∈R}, the horizontal line y=b.
  2. Two cosets are equal exactly when (a,b)−(a′,b′)=(a−a′,b−b′) lies in W. This happens exactly when b−b′=0, so b=b′.
  3. The map f((a,b)+W)=b is well defined by step 2. It is one-to-one: equal b means equal cosets. It is onto R: b comes from (0,b)+W.
  4. dim W=1, because W is spanned by one non-zero vector. dim V=2. Hence dim V/W=dim V−dim W=2−1=1.

Answer. The coset is the horizontal line y=b; cosets are equal exactly when b=b′; dim V/W=1, which equals 2−1.

Exam traps

  • Adding cosets through different representatives needs proof; the sum is independent only because u−u′∈W and v−v′∈W imply (u+v)−(u′+v′)∈W.
  • The dimension formula is dim V/W = dim V − dim W, not dim W and not dim V + dim W.
  • The zero of V/W is W = 0+W, not the zero vector of V.
  • A coset v+W is a subspace only when v∈W; otherwise it misses the zero vector.

Takeaways

  1. A vector space is any set whose addition and scalar multiplication obey the ten familiar rules; arrows, polynomials, matrices and continuous functions all qualify.
  2. Four shortcuts follow from the ten rules: 0·v = 0, a·0 = 0, (−1)·v = −v, and a·v = 0 forces a = 0 or v = 0.
  3. A subspace needs only three checks: non-empty, closed under addition, closed under scalar multiplication.
  4. The span of a set is the smallest subspace containing it, so 'does S span V' is a membership question for one vector at a time.
  5. Independence means the zero vector has only the trivial representation; dependence means one vector is redundant.
  6. A basis is independent and spanning, and both facts together give every vector a unique coordinate list of length dim V.
  7. Row operations preserve the row space and the null space, while pivot columns identify a basis of the column space.
  8. Rank plus nullity equals the number of columns, which is why a homogeneous system with more unknowns than equations has a non-zero solution.
  9. The quotient space V/W treats vectors that differ by an element of W as one point, and its dimension is dim V − dim W.

Glossary

Additive inverse
For each v there is a vector −v with v + (−v) = 0.
Closure
A set is closed under an operation when applying the operation to members of the set always gives a member of the set.
Coefficient
The scalar multiplying a vector inside a linear combination.
Coordinate vector
The list (a₁, …, aₙ) of coefficients expressing v in a fixed basis B.
Coset
The set v + W = {v + w : w ∈ W}, one point of the quotient space V/W.
Extension of a set
Adding new vectors to a set until it becomes a basis of the whole space.
Finite-dimensional
A vector space that has a finite spanning set, equivalently a basis with finitely many members.
Free variable
An unknown of a homogeneous system that corresponds to a non-pivot column and can take any value.
Homogeneous system
A system Ax = 0; its solution set is always a subspace and is never empty.
Inner product
A pairing of two vectors giving a scalar, generalising the dot product.
Matrix space M_m×n
All m by n matrices with entries in F, a vector space of dimension mn.
Non-example
A set that fails at least one axiom or one closure test, such as the first quadrant of R² under usual addition.
Norm
A length function on a vector space, written ‖v‖, obeying positivity, scaling and the triangle inequality.
Nullity
The dimension of the null space, equal to n − rank(A) for an n-column matrix A.
Pivot
The first non-zero entry of a row in the row echelon form of a matrix.
Polynomial space Pₙ
All polynomials of degree at most n with real coefficients, a vector space of dimension n + 1.
Rank
The dimension of the row space, equal to the dimension of the column space and to the number of pivots.
Rank–nullity relation
For A with n columns, rank(A) + nullity(A) = n.
Reduced row echelon form
Row echelon form in which every pivot is 1 and is the only non-zero entry in its column.
Row echelon form
A matrix form in which each pivot lies to the right of the pivot above it and rows of zeros sit at the bottom.
Scalar
An element of the field F used to multiply vectors, a real or complex number in this unit.
Trivial combination
The linear combination in which every coefficient is zero.
Zero vector
The unique vector 0 with v + 0 = v for every v in the space.
