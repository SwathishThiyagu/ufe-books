1.1 Order, degree and linearity of an ODE

Every method here starts by classifying the equation. Order counts the highest derivative. Degree is the power of that derivative after clearing fractions and radicals in the derivatives. Linearity asks whether y and its derivatives appear only to power one, multiplied by functions of x. Correct labels choose the method: integrating factor for linear first order, direct integration for separable. Wrong labels break the working.

You need: first-year calculus — derivatives, the chain rule and basic integrals. Nothing more.

Ordinary or partial, and the order

An equation containing a derivative is a differential equation. One independent variable (x) and one unknown function y gives an ordinary differential equation (ODE). Two or more independent variables with partial derivatives gives a partial differential equation (PDE). Unit 1 covers ODEs; Unit 4 starts PDEs.

The order is the order of the highest derivative present. y′ + xy = 0 has order 1. y″ + 3y′ + 2y = 0 has order 2. (y′)² + y = x has order 1: the square does not raise the order.

Notation: y′ = dy/dx, y″ = d²y/dx², and y⁽ⁿ⁾ = dⁿy/dxⁿ. The order is the largest n that actually appears.

Use: a first-order ODE tracks one quantity against one variable — tea cooling, a UPI wallet earning interest, a capacitor discharging in a power cut.

Degree: read it only after clearing

Degree exists only when the equation is a polynomial in all derivatives. It is then the power of the highest-order derivative.

  1. Find the highest-order derivative; that fixes the order.
  2. Clear fractions and radicals in the derivatives.
  3. Read the power of that highest derivative — that is the degree.

Example: (y″)1/2 = y. Squaring gives y″ = y². The equation is now polynomial in y″, with power 1, so degree is 1, not 1/2. Squaring can add solutions; check the final answer.

(d²y/dx²)³ + x(dy/dx)⁵ = y is polynomial. Order 2, from y″. Degree 3, the power of y″.

Some equations have no degree. sin(y′) = x and ey′ = x are not polynomial in y′, so the degree is not defined. Say that; do not invent a number.

Linearity: what is allowed in y

aₙ(x)y⁽ⁿ⁾ + aₙ₋₁(x)y⁽ⁿ⁻¹⁾ + … + a₁(x)y′ + a₀(x)y = f(x)

y is the unknown function of x; y⁽ᵏ⁾ is its k-th derivative; aₙ(x), …, a₀(x) depend on x only; f(x) is the forcing term.

Allowed: y and every derivative to power one, multiplied only by functions of x, then added. Banned: products such as y·y′, powers above one (y², (y′)³), and nonlinear functions (sin y, ey, √y).

Linearity is about y, not x. x²y′ + cos(x)·y = ex is linear: x², cos x and ex are only coefficients in x.

A first-order ODE can be written in three ways: solved form y′ = f(x, y); differential form M(x, y)dx + N(x, y)dy = 0, used for exact equations; and dy/dx = −M/N, after dividing by N dx.

A first-order linear equation is y′ + P(x)y = Q(x); 1.5 solves it with an integrating factor. Bernoulli's equation 1.6 has this shape but is nonlinear and needs a substitution.

Counting constants, and Clairaut's form

The general solution of an nth-order ODE has exactly n arbitrary constants. Fixing them, usually from a condition such as y(0) = 3, gives a particular solution. Example: y′ = 2x gives y = x² + C; y(0) = 3 forces C = 3, so y = x² + 3.

A family of curves defines an ODE. Take y = ax² + b. Then y′ = 2ax, y″ = 2a. Eliminate a and b: a = y″/2, so y′ = 2·(y″/2)·x, that is x y″ = y′. Two constants gave a second-order ODE.

y = px + f(p), p = dy/dx

f(p) is any differentiable function of p. Clairaut's form is first order: y appears only to the first power, while p may appear in any way. If f(p) is a polynomial, the degree is its power (degree 2 for y = px + p²); otherwise degree is not defined.

Method: differentiate with respect to x, using dy/dx = p. Then p = p + x(dp/dx) + f′(p)(dp/dx), so (x + f′(p))(dp/dx) = 0. If dp/dx = 0, p = c and y = cx + f(c) is the general solution. If x + f′(p) = 0, p is a function of x and y gives a singular solution — an extra curve touching every member of the family.

Worked example

Question. Classify each equation by order, degree and linearity: (i) (d²y/dx²)³ + x(dy/dx)⁵ = y; (ii) y′ = y² + x; (iii) y = px + p² where p = dy/dx. Then solve (iii).

  1. (i) Highest derivative d²y/dx² → order 2. Power of d²y/dx² is 3 → degree 3. A derivative has power 3 → nonlinear.
  2. (ii) Highest derivative y′ → order 1, power 1 → degree 1. y² on the right → nonlinear.
  3. (iii) y = xp + p²: order 1. Polynomial in p with highest power 2 → degree 2. p² makes it nonlinear.
  4. (iii) Differentiate, using dy/dx = p and d(p²)/dx = 2p dp/dx: p = p + x dp/dx + 2p dp/dx.
  5. (iii) Cancel p: (x + 2p) dp/dx = 0.
  6. (iii) Branch dp/dx = 0: p = c, so y = cx + c², the general solution.
  7. (iii) Branch x + 2p = 0: p = −x/2, so y = x(−x/2) + x²/4 = −x²/4, the singular solution.
  8. (iii) Check c = 3: y = 3x + 9 equals xp + p² with p = 3. At x = 4, p = −2 gives xp + p² = −4 = −x²/4.

Exam traps

  • Degree exists only after the equation is polynomial in derivatives. (y″)1/2 = y squares to y″ = y², so degree is 1, not 1/2. Radicals are a favourite mark-loser.
  • Linearity is about y and its derivatives, not x. x²y′ + cos(x)·y = 0 is linear; coefficients may be ugly.
  • Order comes from highest derivative, not highest power. (y′)⁴ + y″ = 0 has order 2, not 4.
  • y′ = y² has y′ to power one, so students call it linear. It is nonlinear because y has power 2.
  • In Clairaut's equation, factor out dp/dx; never divide by it. Dividing loses the singular solution y = −x²/4 in y = px + p².

1.2 Variables separable equations

A separable equation lets you move all y-terms to one side and all x-terms to the other, then integrate each side alone. The right side must factor as g(x)h(y). This turns a two-variable differential equation into two one-variable integrals. The method is used for Newton's law of cooling, radioactive decay, population growth and many rate laws in chemistry and biology. It is the first and most direct solution method for first order equations.

You need 1.1 for order and linearity, plus integration by substitution and partial fractions.

Separate, integrate, add one constant

A first order equation is separable when its right side factors as g(x)h(y). Write it as dy/dx = g(x)h(y), where g depends only on x and h only on y. The differential form M(x)dx + N(y)dy = 0 means the same: M has no y and N has no x.

dy/dx = g(x) h(y) or M(x) dx + N(y) dy = 0

g(x) is a function of x only; h(y) is a function of y only; M(x) has no y; N(y) has no x.

  1. Factor the right side and identify g(x) and h(y).
  2. Assume h(y) ≠ 0 and divide: dy/h(y) = g(x) dx.
  3. Integrate both sides.
  4. Add one constant C. Do not add a constant on both sides.
  5. Apply the initial condition to fix C.
  6. Check h(y) = 0 separately for constant solutions.

After integration you get an implicit solution F(x,y) = C. Keep it implicit when solving for y is messy. An explicit y(x) is better when the initial condition asks for a value.

Lost solutions and substitutions

Division by h(y) can erase solutions. If h(y₀) = 0, then y = y₀ is constant and dy/dx = 0, so it satisfies the equation. For dy/dx = y² − 1, h(y) = (y − 1)(y + 1), so y = 1 and y = −1 are solutions. The general solution from separation misses both unless you add them.

Some equations turn separable after a change of variable. For y′ = (x + y + 1)², put v = x + y + 1, so v′ = 1 + y′. Then v′ = 1 + v², dv/(1 + v²) = dx, tan⁻¹v = x + C, v = tan(x + C), and y = tan(x + C) − x − 1. For y′ = e^(x+y) = eˣ eʸ, separate directly: e⁻ʸ dy = eˣ dx, so −e⁻ʸ = eˣ + C.

If the right side depends only on y/x, use v = y/x; see 1.3. That substitution always gives a separable equation in v and x.

Cooling, decay and growth

Newton's law of cooling: dT/dt = −k(T − T₀). T is the body temperature, T₀ is the surrounding temperature, k is a positive rate per minute and t is minutes. Separate dT/(T − T₀) = −k dt, integrate, and get T = T₀ + (T(0) − T₀)e^(−kt). Example: coffee at 90°C in a 25°C room with k = 0.02 per minute gives T(10) = 25 + 65e^(−0.2) ≈ 78.2°C.

Radioactive decay: dN/dt = −λN. N is the number of nuclei, λ is the decay constant per unit time and t is time. The solution is N = N₀e^(−λt). Half-life is T₁/₂ = ln2/λ. Carbon-14 has T₁/₂ ≈ 5730 years, so λ ≈ 1.21 × 10⁻⁴ per year.

Simple population growth: dP/dt = rP. P is population, r is the growth rate per year and t is years. The solution is P = P₀e^(rt). With P₀ = 1,00,000 and r = 0.02 per year, after 10 years P ≈ 1,22,140.

The same phrase, separation of variables, appears again for PDEs in Unit 5. There it separates two independent variables, not y from x.

Worked example

Question. Solve dy/dx = (1 + y²)/(1 + x²) with y(0) = 1. Find the constant C and the value of y at x = 0.5.

  1. Separate: dy/(1 + y²) = dx/(1 + x²).
  2. Integrate: tan⁻¹y = tan⁻¹x + C.
  3. Use y(0) = 1: tan⁻¹1 = tan⁻¹0 + C, so C = π/4 ≈ 0.785398.
  4. Thus tan⁻¹y = tan⁻¹x + π/4. Using tan(A+B) = (tanA + tanB)/(1 − tanA tanB), y = (x + 1)/(1 − x).
  5. At x = 0.5, y = (1 + 0.5)/(1 − 0.5) = 3.0.
  6. The solution is valid for x < 1, where it blows up.

Answer. C = π/4 ≈ 0.785398 and y(0.5) = 3.0; the explicit solution is y = (1 + x)/(1 − x), valid for x < 1.

Exam traps

  • Dividing by h(y) silently drops constant solutions h(y) = 0. For y′ = y² − 1, both y = 1 and y = −1 are lost unless added back.
  • Add one constant only. Writing +C on both sides creates a false extra parameter.
  • Apply the initial condition to fix C before rearranging the solution; changing branches after squaring can lose the sign.
  • Separable means g(x)h(y), a product. The sum x + y is not separable; it belongs with the methods in 1.5.
  • In cooling and decay, k and λ must match the time unit. A rate per minute with t in hours gives a wrong exponent.

1.3 Homogeneous first order equations

Some first order equations do not separate in x and y, but separate in the ratio y/x. Call such an equation homogeneous: the right side depends on x and y only through y/x. Writing v = y/x turns it into a separable equation in v and x. After a shift of origin, the same trick handles right sides that are a ratio of two linear expressions in x and y.

You need 1.1 for classifying the equation, and 1.2, because the substitution ends in a separable equation.

Homogeneous functions and homogeneous equations

A function f(x, y) is homogeneous of degree n when f(λx, λy) = λⁿf(x, y) for every λ > 0. Here λ is a positive scaling factor and n is a fixed number, not necessarily a whole number.

  • x² + xy: degree 2, since (λx)² + (λx)(λy) = λ²(x² + xy).
  • x + y: degree 1.
  • 1/(x + y): degree −1, since 1/(λx + λy) = λ⁻¹/(x + y).
  • x² + y: not homogeneous; it gives λ²x² + λy, not a single power of λ times the original.

A first order equation M dx + N dy = 0 is homogeneous when M and N are homogeneous of the same degree n. Then M/N is homogeneous of degree 0, so it depends only on y/x. Writing f(y/x) = −M/N gives dy/dx = f(y/x).

M dx + N dy = 0 is homogeneous ⟺ dy/dx = f(y/x)

M and N are functions of x and y, both homogeneous of the same degree n; f is a function of the single ratio y/x.

Quick test: replace x by λx and y by λy on the right side. If every λ cancels, the equation is homogeneous and the substitution below applies.

The substitution v = y/x

Set v = y/x, that is y = vx. Here v is a new unknown function of x. Differentiate y = vx by the product rule, remembering that v changes with x.

y = vx ⟹ dy/dx = v + x dv/dx

v = y/x is the new dependent variable, y is the original dependent variable, x is the independent variable.

  1. Check that the right side is homogeneous and write it as dy/dx = f(y/x).
  2. Put y = vx and dy/dx = v + x dv/dx.
  3. Substitute and cancel v: x dv/dx = f(v) − v.
  4. Separate: dv/(f(v) − v) = dx/x.
  5. Integrate both sides and keep one arbitrary constant C.
  6. Replace v by y/x and simplify.
  7. Apply any initial condition to fix C.

Step 3 makes the equation separable; 1.2 finishes it. Step 4 divides by f(v) − v, so every root v₀ of f(v) = v gives a possible straight line y = v₀x. Test those roots separately in the original equation.

Polar coordinates often tidy the answer. Put x = r cos θ and y = r sin θ, where r is distance from the origin and θ is angle from the x-axis. Then y/x = tan θ and x² + y² = r², so inverse tangents of y/x become plain θ.

Reducible to homogeneous form

The shape dy/dx = (a₁x + b₁y + c₁)/(a₂x + b₂y + c₂) is not homogeneous when any c is nonzero. Here a₁, b₁, c₁, a₂, b₂, c₂ are constants. Two cases are decided by a₁b₂ − a₂b₁.

  • Case a₁b₂ ≠ a₂b₁: the lines a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 meet at one point (h, k). Shift the origin with X = x − h and Y = y − k, where h and k solve a₁h + b₁k + c₁ = 0 and a₂h + b₂k + c₂ = 0. The equation becomes dY/dX = (a₁X + b₁Y)/(a₂X + b₂Y), which is homogeneous. Solve with v = Y/X and put X, Y back.
  • Case a₁b₂ = a₂b₁: the lines are parallel or identical, so no (h, k) exists. Put v = a₁x + b₁y. Then dv/dx = a₁ + b₁ dy/dx, and the equation separates in v and x.

Worked case a₁b₂ = a₂b₁: dy/dx = (2x + 3y − 1)/(4x + 6y − 5). Here 2·6 = 12 = 4·3, so the shift fails. With v = 2x + 3y, dv/dx = 2 + 3(v − 1)/(2v − 5) = (7v − 13)/(2v − 5), hence (2v − 5)dv/(7v − 13) = dx. Integrating gives (2/7)v − (9/49)ln|7v − 13| = x + C, and v = 2x + 3y finishes it.

Worked case a₁b₂ ≠ a₂b₁: dy/dx = (x + y + 1)/(x − y + 3). Solving h + k + 1 = 0 and h − k + 3 = 0 gives h = −2, k = 1. Then dY/dX = (X + Y)/(X − Y), the equation solved in the example below.

Worked example

Question. Solve dy/dx = (x + y)/(x − y) with y = 0 when x = 1. Give the solution in polar form and find y at x = 0.5.

  1. The right side is (x + y)/(x − y). Numerator and denominator are homogeneous of degree 1, so the equation is homogeneous.
  2. Put y = vx, so dy/dx = v + x dv/dx.
  3. Then v + x dv/dx = (1 + v)/(1 − v).
  4. Subtract v: x dv/dx = (1 + v²)/(1 − v).
  5. Separate: (1 − v)dv/(1 + v²) = dx/x.
  6. Integrate: tan⁻¹v − ½ln(1 + v²) = ln|x| + C.
  7. Put v = y/x. Since 1 + y²/x² = (x² + y²)/x², this becomes tan⁻¹(y/x) = ½ln(x² + y²) + C.
  8. Apply y = 0 at x = 1: tan⁻¹0 = ½ln 1 + C, so C = 0. Thus tan⁻¹(y/x) = ½ln(x² + y²).
  9. In polar form, y/x = tan θ and x² + y² = r², so θ = ln r, that is r = e^θ.
  10. At x = 0.5, e^θ cos θ = 0.5. Solving gives θ ≈ 1.4537 rad, r ≈ 4.279, and y = r sin θ ≈ 4.249.

Answer. The solution is tan⁻¹(y/x) = ½ln(x² + y²), equivalently θ = ln r with r = e^θ, and y ≈ 4.249 when x = 0.5.

Exam traps

  • For y = vx, dy/dx = v + x dv/dx. Writing only x dv/dx drops v and gives a wrong integral.
  • M and N must have the same degree. M = x² + y, N = xy looks homogeneous but mixes degrees 2 and 1; the substitution then fails.
  • Dividing by f(v) − v can lose lines y = v₀x where f(v₀) = v₀. Test those roots in the original equation.
  • In the linear-ratio form, compute a₁b₂ − a₂b₁ before shifting. If it is zero, the lines never meet and no (h, k) exists.
  • Finish by replacing v with y/x. An answer left in v has not solved the equation in x and y.

Not for the exam. Homogeneous functions obey Euler's theorem: if f is homogeneous of degree n, then x ∂f/∂x + y ∂f/∂y = n f(x, y). Economists use it to test returns to scale in Cobb–Douglas production functions. In fluid mechanics and heat transfer, similarity solutions assume a quantity depends only on a ratio of variables, the homogeneous substitution in disguise, turning a partial differential equation into an ordinary one.

1.4 Exact equations and integrating factors

An equation M dx + N dy = 0 is exact when its left side is the total differential of one function F(x, y). Then the solution is simply F(x, y) = C. The test is My = Nx. Some equations fail the test but become exact after multiplying by a factor μ. This gives a direct route for equations that are not separable or homogeneous, and it appears in thermodynamics, circuit balance and potential problems.

You need order and degree, separable equations, homogeneous equations, partial derivatives and the total differential.

The exactness test

Write the equation as M(x, y) dx + N(x, y) dy = 0. M is the coefficient of dx; N is the coefficient of dy. The equation is exact if there is a function F(x, y) with Fx = M and Fy = N.

Then the left side is the total differential dF = Fx dx + Fy dy, so the equation says dF = 0. Its general solution is F(x, y) = C, where C is a constant.

The test follows in three lines. Suppose F has continuous second partials. If F exists, then My = Fxy = Fyx = Nx. So exactness requires My = Nx. Here My means ∂M/∂y and Nx means ∂N/∂x. The converse also holds on a rectangle: when My = Nx, such an F exists.

My = Nx

My = ∂M/∂y; Nx = ∂N/∂x; both partial derivatives are continuous.

Solving an exact equation

Once the test passes, find F by integration. Two routes give the same F; use the one with easier integrals.

  1. Integrate M with respect to x, treating y as a constant: F = ∫M dx + g(y). The function g(y) is the constant of integration, but here it may depend on y.
  2. Differentiate this F with respect to y: Fy = ∂/∂y(∫M dx) + g′(y). Set it equal to N.
  3. Solve for g′(y). It must contain only y; if x remains, the equation was not exact or an integration slip occurred.
  4. Integrate g′(y) to get g(y). Write F and the answer F(x, y) = C.

The mirror route integrates N with respect to y first, giving F = ∫N dy + h(x), and finds h′(x) from M. End every solution with a check: differentiate your F. Fx must equal M and Fy must equal N. This catches a wrong g(y) and a sign error. The answer is a family of curves, one curve for each C. An initial condition fixes C, as in 1.7.

Integrating factors

When My ≠ Nx, try to multiply the whole equation by a nonzero function μ(x, y). The new equation μM dx + μN dy = 0 is exact if (μM)y = (μN)x. The function μ is an integrating factor. Two standard rules cover many exam problems.

  • Rule 1. Compute R = (My − Nx)/N, with N ≠ 0. If R depends on x alone, then μ(x) = e∫R dx.
  • Rule 2. Compute S = (Nx − My)/M, with M ≠ 0. If S depends on y alone, then μ(y) = e∫S dy.
  • In each rule, first simplify R or S. If the result still contains both x and y, that rule does not apply. Multiply both M and N by μ, then repeat the exactness test.

For simple combinations, grouping is faster than the rules. Learn this table.

Worked example

Question. Solve each equation and find the constant C in F(x, y) = C. (a) (2xy + y²)dx + (x² + 2xy)dy = 0 with y(1) = 2. (b) (3xy + y²)dx + (x² + xy)dy = 0 with y(1) = 1.

  1. (a) M = 2xy + y², N = x² + 2xy.
  2. My = 2x + 2y and Nx = 2x + 2y, so the equation is exact.
  3. F = ∫M dx = x²y + xy² + g(y).
  4. Fy = x² + 2xy + g′(y). Set Fy = N: x² + 2xy + g′(y) = x² + 2xy, so g′(y) = 0 and g is constant.
  5. Solution: x²y + xy² = C.
  6. At (1, 2): C = 1²·2 + 1·2² = 2 + 4 = 6.
  7. (b) M = 3xy + y², N = x² + xy.
  8. My = 3x + 2y and Nx = 2x + y, not equal.
  9. (My − Nx)/N = (x + y)/(x² + xy) = 1/x, a function of x alone, so μ = e∫dx/x = x.
  10. Multiply: (3x²y + xy²)dx + (x³ + x²y)dy = 0.
  11. μ = x is nonzero only for x ≠ 0, so the curve x = 0 must be checked separately against the original equation.
  12. Now My = 3x² + 2xy = Nx, so it is exact.
  13. F = ∫(3x²y + xy²)dx = x³y + x²y²/2 + g(y).
  14. Fy = x³ + x²y + g′(y) = x³ + x²y, so g′ = 0.
  15. Solution: x³y + x²y²/2 = C.
  16. At (1, 1): C = 1³·1 + 1²·1²/2 = 1 + 0.5 = 1.5.

Exam traps

  • The test is My = Nx, not Mx = Ny. The variables are crossed: differentiate M by y and N by x.
  • An integrating factor multiplies both M and N. Multiplying only one changes the equation and usually destroys exactness.
  • After integrating M with respect to x, the constant of integration is a function g(y), not a number. Dropping g(y) loses terms that may contain y only.
  • In Rule 2 the numerator order is Nx − My. Reversing the order gives S′ = −S, so the integrating factor becomes e−∫S dy = 1/μ, not −μ. Both work, but pick one order and keep it.
  • Always re-test after multiplying by μ. A μ from a rule that only nearly fits can still leave the equation inexact.

1.5 Linear first order (Leibnitz) equations

A linear first-order equation has the shape y′ + P(x)y = Q(x). The unknown y and its derivative appear only to the first power. Such equations model circuits, cooling, mixing and money growth. One multiplication by a cleverly chosen function turns the left side into the derivative of a product. After that, a single integration gives the solution. The function is called the integrating factor, and some syllabi call the method Leibnitz's linear equation.

You need: the integration practice of 1.2 and the integrating-factor idea of 1.4.

Standard form and the integrating factor

A first-order linear equation is y′ + P(x)y = Q(x). Here y′ = dy/dx, P(x) and Q(x) are continuous functions on an interval I, and y is the unknown function. The coefficient of y′ must be 1. If an equation arrives as a(x)y′ + b(x)y = c(x), divide by a(x) first; this step is where many marks are lost.

The left side y′ + P y does not integrate directly. Multiply the whole equation by a positive function μ(x), still unknown. The left becomes μ y′ + μ P y. The product rule gives (μ y)′ = μ y′ + μ′ y. These match exactly when μ′ = μ P. Solving dμ/dx = P μ separates to dμ/μ = P dx, so ln μ = ∫P dx and μ = e∫P dx.

μ(x) = e∫P(x) dx

μ is the integrating factor; P is the coefficient of y in standard form; use any one antiderivative of P, with no added constant.

This μ is the integrating factor, shortened IF. Adding a constant to ∫P dx only multiplies μ by a constant, which cancels later, so choose the simplest antiderivative. The IF is always positive. Some syllabi call this Leibnitz's linear equation; others call it the first-order linear equation. Section 1.4 reaches the same idea from exactness; here it is a direct product-rule trick.

Solving the equation

After multiplying by μ, the equation becomes (μ y)′ = μ Q. Integrate both sides with respect to x: μ y = ∫ μ Q dx + C, where C is the constant of integration. Divide by μ.

y = μ−1(∫ Q μ dx + C)

y is the solution; μ = e∫P dx; C is fixed by an initial condition; all integrals are with respect to x.

  1. Write the equation in standard form, with coefficient 1 on y′.
  2. Read P and Q; keep the sign of P.
  3. Compute μ = e∫P dx using one antiderivative.
  4. Multiply both sides by μ and replace the left side by (μ y)′.
  5. Integrate once: μ y = ∫ μ Q dx + C.
  6. Divide by μ, then use y(x₀)=y₀ to find C.

A short check: y′ + 2y = e−x has P=2, Q=e−x, μ=e2x. Then (y e2x)′ = ex, so y e2x = ex + C and y = e−x + C e−2x.

In a series RL circuit, L di/dt + R i = E(t). L is inductance in henry, R is resistance in ohm, E(t) is applied voltage in volt, i is current in ampere, and t is time in second. Divide by L: i′ + (R/L)i = E(t)/L. The IF is eRt/L. If E is a constant E₀, i = E₀/R + C e−Rt/L; the first term is the steady current and the second decays with time constant L/R.

Reduction to linear form

Some equations become linear after a substitution. Suppose the equation can be written f′(y) dy/dx + P(x) f(y) = Q(x). Here f is a known differentiable function. Put u = f(y). Then du/dx = f′(y) dy/dx by the chain rule. The equation becomes u′ + P(x)u = Q(x), which is linear in u. Solve it by the integrating factor, then invert y = f−1(u).

  • Bernoulli case: for y′ + P y = Q yn, take f(y)=y1−n. The equation is linear in u=y1−n; the full method is in 1.6.
  • Root case: for y′/(2√y) + P√y = Q with y>0, take u=√y. Then u′ = y′/(2√y), so u′ + P u = Q, linear in u. The equation y′ + P√y = Q itself does not have this form and is not linearized this way.
  • Log case: for y′/y + P ln y = Q with y>0, take u=ln y. Then u′ = y′/y, so u′ + P u = Q, linear in u. The equation y′ + P ln y = Q is not of this template form.

After solving for u, invert only on the interval where f has an inverse. Check the original equation, because the substitution can lose solutions where f′(y)=0 or where a division by yn was made.

Worked example

Question. Solve the initial value problem x dy/dx + 2y = x², y(1)=1. State the interval and find y(2).

  6. Divide: y = x²/4 + C/x².
  7. Use y(1)=1: 1 = 1/4 + C, so C = 3/4.
  8. Particular solution: y = x²/4 + 3/(4x²). At x=2, y = 4/4 + 3/(16) = 1 + 0.1875 = 1.1875.

Answer. The solution is y = x²/4 + 3/(4x²) on x>0, with C=3/4, and y(2)=1.1875; x and y are treated as dimensionless here.

  • The sign of P stays inside the integral: y′−3y=1 gives μ=e−3x, not e3x.
  • Use one antiderivative for ∫P dx; a constant only rescales μ and cancels.
  • Q must be the right side after division by the coefficient of y′, and any x=0 division removes the point x=0 from the interval.
  • The left side becomes (μ y)′, not μ′ y′; check the product before integrating.

1.6 Bernoulli's equation

Bernoulli's equation is y′ + P(x)y = Q(x)yn with n not 0 or 1. The power of y stops it being linear, so an integrating factor cannot be used directly. Dividing by yn and substituting z = y1−n turn it into a linear equation in z. Solve that with the integrating factor from 1.5, then return to y. It appears in population models with crowding, fluid flow with drag, and circuits with nonlinear parts.

You need 1.5 Linear first order for the integrating factor, and 1.2 Variables separable for the n = 1 case.

The form and the substitution

Write the equation in standard form: y′ + P(x)y = Q(x)yn. Here y′ = dy/dx, P(x) and Q(x) are known functions of x, and n is a real number. Work on an interval where y ≠ 0 and the powers are defined. The cases n = 0 and n = 1 are not new. n = 0 gives y′ + Py = Q, which is linear (1.5). n = 1 gives y′ + Py = Qy, which is linear after moving Qy left, or separable (1.2).

For other n, divide by yn. This gives y−ny′ + P y1−n = Q. Put z = y1−n. Differentiate: z′ = (1−n)y−ny′. So y−ny′ = z′/(1−n). Substitute: z′/(1−n) + P z = Q. Multiply by (1−n): z′ + (1−n)P z = (1−n)Q. This is linear in z. The factor (1−n) multiplies both P and Q; losing it is the commonest error.

y′ + P(x)y = Q(x)yn

P(x) and Q(x) are known functions of x; n is a real number; y′ = dy/dx.

z′ + (1−n)P(x)z = (1−n)Q(x)

z = y1−n; P and Q come from the Bernoulli form; n ≠ 0, 1.

Solve the linear equation in z

  1. Put the equation in y′ + P y = Q yn form; list P, Q and n.
  2. If n = 0 or n = 1, use the earlier methods; do not substitute z.
  3. Divide by yn. For n > 0, record that y = 0 is a solution.
  4. Set z = y1−n; replace y−ny′ by z′/(1−n).
  5. Multiply to get z′ + (1−n)P z = (1−n)Q.
  6. Find μ = e∫(1−n)P dx; solve (μ z)′ = μ(1−n)Q.
  7. Integrate, put z = y1−n back, simplify; add y = 0 if n > 0.

The integrating factor μ(x) = e∫(1−n)P dx makes the left side (μ z)′. After integration, one constant C appears. Back substitution uses z = y1−n, so y = z1/(1−n). Check the sign of 1−n: for n = 2 it is negative, for n = −1 it is positive. That sign changes the linear equation and the final power.

Where it is used and the name

Population growth with crowding uses dN/dt = rN − aN², with N(t) the population, r the growth rate and a the crowding constant. This is Bernoulli with n = 2 in the variable N. In a circuit with a nonlinear resistor, the current can obey a Bernoulli equation. In fluid mechanics, the Bernoulli equation is a different statement about energy along a streamline; the family name is the same, but that equation is not in this unit.

1.7 Initial value problems: existence and uniqueness, Picard iteration

An initial value problem fixes both the equation y′ = f(x, y) and one point y(x₀) = y₀ that the curve must pass through. Two questions come before any formula: does a solution exist, and is it unique? Continuity of f gives existence; a Lipschitz condition on f gives uniqueness. Picard's iteration proves both by building the solution from repeated integrals. Circuit simulators, orbit software and drug dosing models rest on this guarantee.

You need: Chapter 1.1 for what an ODE is, the ability to integrate polynomials and ex, and the idea of a sequence of functions closing in on a limit.

The initial value problem and its geometry

A first order initial value problem (IVP) is y′ = f(x, y), y(x₀) = y₀. Here f is a known function of two variables, x is the independent variable, y(x) is the unknown, and x₀, y₀ are given numbers. A solution is a differentiable function y(x), defined on an interval containing x₀, with y(x₀) = y₀ and y′(x) = f(x, y(x)) at every point of that interval.

Geometry: f paints a slope at every point of the plane — a slope field — and a solution is a curve that always travels along the painted slope, starting at the pin (x₀, y₀). For y′ = y, y(0) = 1, the curve y = ex starts at (0, 1) with height always equal to slope.

Three questions come before any formula: does a solution exist, is it unique, and how wide is the interval where it lives? The methods of 1.2 to 1.6 quietly assume the answers are favourable. They are not always. The problem y′ = 1/x, y(0) = 1 has no solution: f = 1/x is undefined at x = 0, so nothing fixes a slope at the starting pin.

Continuity, the Lipschitz condition, and Picard's theorem

Take a closed rectangle R = {|x − x₀| ≤ a, |y − y₀| ≤ b} around the initial point, with a > 0 and b > 0. Let M be the largest value of |f(x, y)| on R: a bound on how steep the slope can get there.

Peano's theorem. If f is continuous on R, the IVP has at least one solution on |x − x₀| ≤ h, where h = min(a, b/M). Leaving the pin, y can rise or fall by at most M per unit of x, so the curve cannot leave the strip |y − y₀| ≤ b before |x − x₀| = b/M. The a appears because f is only known inside the rectangle.

Continuity does not give uniqueness. For y′ = √y, y(0) = 0, both y = 0 and y = x²/4 (for x ≥ 0) are solutions: in the second, y′ = x/2 and √y = x/2. One IVP, two solutions.

Lipschitz condition. f is Lipschitz in y on R if |f(x, y₁) − f(x, y₂)| ≤ L |y₁ − y₂| at every point of R, with L > 0 the Lipschitz constant. If ∂f/∂y exists and |∂f/∂y| ≤ L on R, the mean value theorem in y gives the condition with that L. For f = √y, ∂f/∂y = 1/(2√y) grows without bound as y → 0; no L works near y = 0, exactly where uniqueness broke.

Picard's theorem (Picard–Lindelöf). If f is continuous on R and Lipschitz in y on R, the IVP has exactly one solution on |x − x₀| ≤ h with h = min(a, b/M).

Picard iteration builds the solution

Integrate y′ = f(t, y) from x₀ to x and use y(x₀) = y₀: y(x) = y₀ + ∫ f(t, y(t)) dt from x₀ to x. Solving the IVP is the same as finding a fixed point of this integral operator.

y<sub>n+1</sub>(x) = y₀ + ∫<sub>x₀</sub><sup>x</sup> f(t, y<sub>n</sub>(t)) dt,   n = 0, 1, 2, …

yn is the n-th Picard iterate, an approximate solution; y₀(x) = y₀ is the constant starting iterate; t is the dummy variable of integration; x stays inside |x − x₀| ≤ h.

Under Picard's hypotheses these iterates exist on |x − x₀| ≤ h and converge uniformly to the unique solution. The first iterate y₁ passes through the pin with the same slope f(x₀, y₀) as the true solution; it is the straight tangent line only when f does not depend on y (for example f = y, giving y₁ = 1 + x).

  1. Write the IVP and its integral form.
  2. Start from the constant y₀(x) = y₀, not from f.
  3. Integrate f(t, yn(t)) from x₀ to x to get yn+1(x).
  4. Repeat, spot the pattern (often a Taylor or geometric series), and take the limit.

For y′ = y, y(0) = 1 the recipe gives y₁ = 1 + x, y₂ = 1 + x + x²/2, y₃ = 1 + x + x²/2 + x³/6. The limit is ex.

One numerical step: Euler and fourth-order Runge–Kutta

Some syllabi examine numerical solution here, as the practical face of Picard's iteration. Split the range of x into steps of size h, so xn = x₀ + nh, and write yn for the computed value at xn.

y<sub>n+1</sub> = y<sub>n</sub> + h f(x<sub>n</sub>, y<sub>n</sub>)

yn ≈ y(xn) is the computed value; h is the step size in x; f(xn, yn) is the slope at the left end of the step.

Fourth-order Runge–Kutta averages four slopes: k₁ = f(xn, yn), k₂ = f(xn + h/2, yn + h k₁/2), k₃ = f(xn + h/2, yn + h k₂/2), k₄ = f(xn + h, yn + h k₃), then yn+1 = yn + h(k₁ + 2k₂ + 2k₃ + k₄)/6.

One step of y′ = y, y(0) = 1 with h = 0.5. Euler gives y₁ = 1 + 0.5(1) = 1.5. Runge–Kutta gives k₁ = 1, k₂ = 1.25, k₃ = 1.3125, k₄ = 1.65625, so y₁ = 1 + 0.5(1 + 2.5 + 2.625 + 1.65625)/6 = 1.6484375. The exact value is e0.5 = 1.648721.

Worked example

Question. For y′ = y, y(0) = 1: (a) verify the Lipschitz condition and state L; (b) on the rectangle |x| ≤ 1, |y − 1| ≤ 1 find M and the guaranteed h; (c) compute the Picard iterates y₁, y₂, y₃ and evaluate y₃(0.5) against e0.5.

  1. f(x, y) = y, x₀ = 0, y₀ = 1. Since ∂f/∂y = 1, |f(x, y₁) − f(x, y₂)| = |y₁ − y₂|, so the condition holds everywhere with L = 1.
  2. On the rectangle a = 1, b = 1 and |f| = |y| ≤ 2, so M = 2. Then h = min(a, b/M) = min(1, 1/2) = 0.5: one unique solution is guaranteed at least for |x| ≤ 0.5.
  3. Zeroth iterate: y₀(x) = 1.
  4. y₁ = 1 + ∫ from 0 to x of 1 dt = 1 + x. Then y₂ = 1 + x + x²/2 and y₃ = 1 + x + x²/2 + x³/6.
  5. The iterates are the Taylor polynomials of ex, so they converge to y = ex, the unique solution.
  6. At x = 0.5: y₃(0.5) = 1 + 0.5 + 0.125 + 0.020833 = 1.645833, against e0.5 = 1.648721. The error is 0.002888, under 0.2 percent.

Answer. L = 1, M = 2, h = 0.5; the iterates are 1, 1 + x, 1 + x + x²/2, 1 + x + x²/2 + x³/6, and y₃(0.5) = 1.645833 against e0.5 = 1.648721.

Exam traps

  • Continuity alone gives existence, not uniqueness — that is Peano's theorem. Uniqueness needs the Lipschitz condition; one point where it fails (y = 0 for √y) is enough to lose it.
  • Take M on the rectangle R, not as a global maximum of |f|. The promised h = min(a, b/M) can be far shorter than the interval where the solution really lives.
  • Start the iteration from the constant y₀(x) = y₀, never from f(x, y₀). Note y₀ names both the initial value and the zeroth iterate.
  • Lipschitz in y, not in x: L controls differences in y at fixed x. A bounded ∂f/∂y is sufficient, not necessary.
  • y′ = 1/x, y(0) = 1 is not an IVP at all — f is undefined at x₀.

Beyond the syllabus

Not for the exam. Picard's iteration is the contraction mapping principle applied to an integral operator, and the same fixed-point idea proves Picard–Lindelöf in any number of dimensions. Lipschitz constants reappear in control theory as stability margins and in stochastic differential equations. Gronwall's inequality turns a Lipschitz bound into an explicit estimate of how fast two solutions can separate. Search: Picard–Lindelöf theorem, contraction mapping, Gronwall's inequality.

Takeaways

  1. Classify first: order, degree and linearity tell you which later method can even apply.
  2. Separable equations are solved by moving all y terms to one side and all x terms to the other, then integrating each side alone.
  3. A homogeneous first-order equation depends on y/x, and v = y/x turns it into a separable equation in v and x.
  4. An exact equation passes the test ∂M/∂y = ∂N/∂x and is solved by finding F(x,y)=C.
  5. For y′ + P(x)y = Q(x), the integrating factor e^(∫P dx) turns the left side into the derivative of one product.
  6. Bernoulli equations become linear after z = y^(1−n).
  7. Continuity of f gives existence near x₀; continuity plus a Lipschitz condition in y gives uniqueness.
  8. Picard iteration builds the solution as a limit of repeated integrations.

Glossary

Bernoulli equation
An equation y′ + P(x)y = Q(x)yⁿ with n not 0 or 1.
Constant of integration
The arbitrary constant produced by an indefinite integration; in an ODE it often becomes the parameter of the general solution.
Degree
The power of the highest derivative after the equation is cleared of radicals and fractions in derivatives.
Exact differential
An expression M dx + N dy that equals dF for some function F.
Existence theorem
A theorem giving conditions under which an IVP has at least one solution.
General solution
A solution family containing arbitrary constants equal in number to the order of the ODE.
Homogeneous function
A function f with f(λx,λy)=λⁿf(x,y); in first-order equations this often means the right side depends only on y/x.
Initial value problem
A differential equation with a prescribed value of the solution at one point.
Integrating factor
A multiplier that changes an equation into an exact or linear equation.
Linear first-order equation
An equation of the form y′ + P(x)y = Q(x).
Linear ODE
An ODE in which the unknown and its derivatives appear only to the first power and are not multiplied together.
Lipschitz condition
A bound |f(x,y₁)−f(x,y₂)| ≤ L|y₁−y₂| that controls how fast f changes with y.
Nonlinear ODE
An ODE that is not linear, for example because y or y′ appears squared or in a product.
Order
The highest derivative present in the differential equation.
Ordinary differential equation
An equation containing an unknown function of one variable and one or more of its derivatives.
Particular solution
A single solution obtained by fixing the arbitrary constants in the general solution.
Picard iteration
Repeated integration starting from y₀ to build a sequence of approximations to the IVP solution.
Potential function
A function F(x,y) whose partial derivatives equal M and N in an exact equation.
Separable equation
A first-order equation that can be written as dy/dx = g(x)h(y).
Singular solution
A solution that cannot be obtained from the general solution by any choice of constants.
Total differential
dF = F_x dx + F_y dy, the differential of a function F(x,y).
Uniqueness theorem
A theorem giving conditions under which an IVP has at most one solution.
