5.1 Linear homogeneous PDEs with constant coefficients

A linear homogeneous PDE with constant coefficients looks hard, but the operators ∂/∂x and ∂/∂y behave like ordinary algebra symbols. Write D = ∂/∂x and D′ = ∂/∂y, and the PDE becomes a polynomial in D and D′. A polynomial splits into linear factors, and each factor (D − mD′)u = 0 has an easy answer: an arbitrary function of y + mx. Add one such function for every factor and you have the general solution. Exam questions use this to get the full family of solutions before any boundary data is fitted, and to see which directions a disturbance can travel.

You need: PDE notation and the elimination ideas from Unit 4, First Order PDEs; and the characteristic-equation method for constant-coefficient ODEs from Unit 2.

The operator becomes a polynomial

Write D = ∂/∂x and D′ = ∂/∂y. These are operators: they act on u and produce u_x and u_y. Applied twice, D²u = u_xx, DD′u = u_xy, D′²u = u_yy.

A linear homogeneous PDE with constant coefficients becomes P(D, D′)u = 0, where P is a polynomial with plain numbers in it. Homogeneous means every term contains u, so there is no term left over on the right side. For the second order equation A u_xx + B u_xy + C u_yy = 0 the polynomial is A D² + B DD′ + C D′². Since A, B, C are constants, this factors exactly like a quadratic.

Take a single linear factor written as (D − mD′). Multiplying two of them gives u_xx − (m₁ + m₂)u_xy + m₁m₂u_yy. Matching with A u_xx + B u_xy + C u_yy shows that m₁ and m₂ are the roots of A m² + B m + C = 0. This is the auxiliary equation. Watch the plus sign on B: the factor carries a minus, so the equation carries a plus.

A u_xx + B u_xy + C u_yy = A(D − m₁D′)(D − m₂D′)u = 0

A, B, C are constants with A ≠ 0; D = ∂/∂x and D′ = ∂/∂y; m₁ and m₂ are the roots of A m² + B m + C = 0.

One factor, one arbitrary function

Solve (D − mD′)u = 0, that is u_x = m u_y. Try u = f(y + mx) for any differentiable f. Then u_x = m f′(y + mx) and u_y = f′(y + mx), so u_x − m u_y = m f′ − m f′ = 0. The solution survives because the combination y + mx is exactly what the operator cannot see.

  1. Write the PDE as P(D, D′)u = 0.
  2. Factor P into linear factors (D − mD′) with constant m.
  3. For each distinct factor take u = f(y + mx), with an independent arbitrary function f.
  4. For a repeated factor (D − mD′)^n take f₁(y + mx) + x f₂(y + mx) + … + x^(n−1) fₙ(y + mx).
  5. Add the pieces. The total number of arbitrary functions equals the order of the PDE.
  6. State that f, g, … are differentiable as many times as the equation needs.

Repeated factors, higher order, extra terms

Each factor supplies one arbitrary function. With distinct roots the general solution is u = f(y + m₁x) + g(y + m₂x). Each term is constant along the straight lines y + mx = constant, so it is a travelling wave; the physical reading is in 5.4.

For a repeated factor, add an x multiplier. Apply (D − mD′) to x g(y + mx): the product rule leaves g(y + mx). One more application kills it, so (D − mD′)² u = 0 is satisfied by x g(y + mx). Generalise to n repeats with powers x, x², …, x^(n−1).

Lower order terms change the answer. A factor (D − mD′ − k) with constant k gives u = e^(kx) f(y + mx); substitute and the three terms cancel. Solutions of different factors add, because the operators in the product act one after the other and each factor still annihilates its own piece.

The method is limited to constant coefficients. Variable-coefficient equations need other tools, and classification by type is the topic of 5.2.

Exam traps

  • Sign slip in the auxiliary equation. The factor is (D − mD′) but the equation to solve is A m² + B m + C = 0, with a plus on B. Using A m² − B m + C = 0 gives m = −2, −3 and a wrong answer.
  • Wrong argument in the arbitrary function. (D − 4D′)u = 0 is solved by f(y + 4x), not f(x + 4y) and not f(x + y). The multiplier m belongs with x.
  • Adding constants where the answer needs arbitrary functions. Write f(y + 2x) + g(y + 3x), never C₁ + C₂.
  • Dropping the x multiplier for a repeated factor. (D − mD′)²u = 0 needs f(y + mx) + x g(y + mx); the plain sum f + g is not the general solution.
  • Forgetting differentiability. The order of the PDE fixes how many derivatives f and g must have, and the answer should say so.

5.2 Classification: elliptic, parabolic and hyperbolic equations

Every second order linear PDE in two variables carries a single number that sorts it into one of three families. That number is the discriminant Δ = B² − 4AC, built from the coefficients of u_xx, u_xy and u_yy. The sign of Δ says how information spreads through the solution: along two crossing families of curves, along one family, or in every direction at once. The three prototypes are the wave equation, the heat equation and Laplace's equation. Engineers use this test before choosing a method or a computer solver, because each family needs different data and a different algorithm.

You need: partial derivative notation and the operator idea from 5.1, and PDE formation from Unit 4, First Order Partial Differential Equations.

The discriminant test

Write the equation with every term on the left and zero on the right. The unknown is u(x, y), and A, B, C, D, E, F, G may depend on x and y but never on u itself or its derivatives.

A u_xx + B u_xy + C u_yy + D u_x + E u_y + F u = G

u_xx is ∂²u/∂x², u_xy is ∂²u/∂x∂y, u_x is ∂u/∂x, and so on; A, B, C, D, E, F are given coefficients; G is the given right hand side.

Only A, B and C matter for the type. The lower terms affect the solution but not the family it belongs to.

Δ = B² − 4AC

Δ (the discriminant) is a number, or a function of x and y when the coefficients vary; A is the coefficient of u_xx, B of u_xy, C of u_yy, with their signs.

  1. Move all terms to the left side so the right side is 0.
  2. Read A from u_xx, B from u_xy, C from u_yy, keeping signs.
  3. Compute Δ = B² − 4AC at the point (x, y) you care about.
  4. Compare with zero: Δ < 0 gives elliptic, Δ = 0 gives parabolic, Δ > 0 gives hyperbolic.

Multiplying the whole equation by −1 flips A, B and C together. B² is unchanged and AC is unchanged, because both factors flip. So Δ keeps its sign and the type is a property of the equation, not of how you wrote it.

Three prototypes

The three standard equations of mathematical physics sit one in each family. For the heat and wave equations the two independent variables are x and t, so you read A, B, C in that order: A on u_xx, B on u_xt, C on u_tt.

EquationA, B, CΔ = B² − 4ACType

The type tells you which data to supply. Elliptic equations need values on a closed boundary, which is why 5.6 solves them as boundary value problems. Hyperbolic equations carry two travelling waves, so they need initial position and initial velocity; that is the setup of 5.4. Parabolic equations need an initial profile and spread it forward in time, as in 5.5.

Variable coefficients and the factor-of-2 convention

When A, B, C depend on x and y, Δ is a function and the type can change from point to point. Take y u_xx + u_yy = 0. Here A = y, B = 0, C = 1, so Δ = 0 − 4y = −4y. Above the x-axis, y > 0 gives Δ < 0, elliptic. On the axis, y = 0 gives Δ = 0, parabolic. Below the axis, y < 0 gives Δ > 0, hyperbolic. A single equation, three regions — so always name the point where you evaluated the test.

Some books put the factor 2 into the mixed term and write A u_xx + 2B u_xy + C u_yy + … = 0. Their B is half of ours. Their test is B² − AC. The two tests agree because 4(B² − AC) = (2B)² − 4AC, and the multiplier 4 is positive, so the sign, and therefore the type, is the same.

Once the type is fixed, the standard solving tools apply: separation of variables from 5.3 for all three families, and Fourier series from 5.7 to fit the boundary or initial data. For constant coefficients, factoring the operator as in 5.1 is often quicker.

Worked example

Question. Classify the equation u_xx + 4u_xy + 3u_yy = 0. State the value of the discriminant and the type of the equation.

  1. All terms are already on the left side, so A = 1 (coefficient of u_xx), B = 4 (coefficient of u_xy), C = 3 (coefficient of u_yy).
  2. Compute the discriminant: Δ = B² − 4AC = 4² − 4(1)(3).
  3. Square and multiply: 4² = 16 and 4(1)(3) = 12, so Δ = 16 − 12 = 4.
  4. Compare with zero: Δ = 4 > 0.
  5. The coefficients are constants, so the sign is the same at every point (x, y).

Answer. The discriminant is Δ = 4, which is greater than zero, so the equation is hyperbolic everywhere.

Worked example 2

Question. Classify the equation 2u_xx − 4u_xy + 2u_yy = 0.

  1. Coefficients: A = 2, B = −4, C = 2.
  2. Δ = B² − 4AC = (−4)² − 4(2)(2) = 16 − 16 = 0.
  3. Δ = 0 means parabolic.
  4. Same equation written as u_xx − 2u_xy + u_yy = 0 gives Δ = 4 − 4 = 0 — unchanged, since multiplying by 1/2 did not flip signs.

Answer. Δ = 0, so the equation is parabolic everywhere; the operator factors as 2(∂/∂x − ∂/∂y)²u = 0, that is 2(u_xx − 2u_xy + u_yy) = 0, which is why Δ = 0.

Exam traps

  • When the mixed term is written 2B u_xy, the coefficient of u_xy is 2B. Put that full coefficient into Δ = (coefficient of u_xy)² − 4AC, which gives 4B² − 4AC and the correct sign. If you halve the coefficient to B, then you must use B² − AC instead; mixing the halved B with B² − 4AC is the error.
  • Reading the coefficients before moving every term to one side; a term shifted across the equals sign changes its sign.
  • Mixing up the order of the variables in the heat and wave equations. Fix the pair first (x, t), then take A from u_xx, B from u_xt, C from u_tt.
  • Reporting one type for an equation with variable coefficients. Δ = −4y changes sign at y = 0, so the answer must name the region or the point.
  • Thinking Δ < 0 means no solution or a complex answer. Δ only names the family; Laplace's equation is elliptic and has plenty of real solutions.

5.3 Method of separation of variables

Separation of variables is a way to solve a PDE by guessing that the unknown u is a product of functions, each of one variable only. Put u=X(x)Y(y) or u=X(x)T(t). Substitute, divide by the product, and the two sides depend on different variables. They can be equal only if both equal a constant, the separation constant. This splits one PDE into ordinary differential equations. Engineers use it for heat flow in a bar, waves on a string, and steady potentials in a rectangle or disk.

You need: second order linear ODEs from Unit 2 and PDE notation from 5.1.

The product guess and the separation constant

Start with a linear homogeneous PDE in two independent variables, say u_xx+u_yy=0. Assume u(x,y)=X(x)Y(y). X is a function of x only; Y is a function of y only; primes mean derivatives in the own variable. Substitute: X″Y+XY″=0. Divide by XY, assuming XY is not zero: X″/X+Y″/Y=0. Rearrange: X″/X = −Y″/Y. The left side depends only on x. The right side depends only on y. A function of x cannot equal a function of y for all x and y unless both are constant. Call this common constant λ. Then X″−λX=0 and Y″+λY=0. Some syllabi call this the product method or Fourier method.

u(x,y)=X(x)Y(y), X″/X = −Y″/Y = λ

u is the unknown function; X and Y are one-variable functions; primes are derivatives in the own variable; λ (lambda) is the separation constant, a number not depending on x or y.

For λ=4 this gives X″−4X=0 and Y″+4Y=0. A book may use −λ instead; the two ODEs then swap. Stay with one sign convention in a problem.

Boundary conditions turn λ into eigenvalues

Solve the two ODEs with homogeneous boundary conditions. For zero ends Y(0)=Y(L)=0, take Y″+λY=0. If λ>0, put λ=k², so Y=C cos ky+D sin ky. Y(0)=0 gives C=0. Y(L)=0 gives D sin kL=0. A nonzero D needs sin kL=0, so kL=nπ with n=1,2,3,... Thus λ_n=(nπ/L)² and Y_n=sin(nπy/L). These are eigenvalues and eigenfunctions. If λ=0, Y=C+Dy, and both zero ends force C=D=0. If λ<0, put λ=−k², Y=C cosh ky+D sinh ky, and again both zero ends give only Y=0. So nonzero solutions need λ>0. For L=π, λ_n=n²: 1,4,9. The value λ=4 is n=2, Y=sin 2y.

Superposition and scope

Each product u_n=X_nY_n solves the PDE and the homogeneous boundary conditions. A finite sum ΣB_nu_n also solves them because the PDE and boundary conditions are linear and homogeneous. The constants B_n are fixed by the remaining initial or boundary data; that step uses orthogonality and Fourier series, covered in 5.7. For the wave equation u_tt=c²u_xx, put u=X(x)T(t). Then X″/X=T″/(c²T)=−k², giving X″+k²X=0 and T″+c²k²T=0. For the heat equation u_t=αu_xx, put u=X(x)T(t). Then X″/X=T′/(αT)=−k², giving X″+k²X=0 and T′+αk²T=0. Separation here keeps two independent variables.

Worked example

Question. Solve u_xx+u_yy=0 for 0<y<π with homogeneous boundary conditions u(x,0)=0 and u(x,π)=0. Use the separation constant λ=4. Find the allowed y-eigenfunction Y(y), the integer n, and the value Y(π/4). Write the product solution.

  1. Put u=X(x)Y(y). Then X″Y+XY″=0.
  2. Divide by XY: X″/X = −Y″/Y = λ. With λ=4: X″−4X=0 and Y″+4Y=0.
  3. Solve X: characteristic equation r²−4=0, so r=±2 and X=Ae^{2x}+Be^{−2x}. A and B are constants.
  4. Solve Y: characteristic equation r²+4=0, so r=±2i and Y=C cos2y+D sin2y. C and D are constants.
  5. Boundary Y(0)=0: C cos0+D sin0=C=0. So Y=D sin2y.
  6. Boundary Y(π)=0: D sin(2π)=D·0=0, satisfied for any D. Take D=1 for the sine mode; any nonzero D gives the same eigenfunction up to a constant. In a general problem this condition would read sin kπ=0, giving k=n; here λ=4 was given, so k=2 and n=2.
  7. Here k=2 and L=π, so n=kL/π=2π/π=2. The eigenvalue is λ=4.
  8. At y=π/4: Y=sin(2·π/4)=sin(π/2)=1.
  9. The product solution is u=(Ae^{2x}+Be^{−2x}) sin2y.

Answer. λ=4, n=2, Y(y)=sin2y, Y(π/4)=1, and u=(Ae^{2x}+Be^{−2x})sin2y.

Exam traps

  • Using Y″−λY=0 for zero ends at both sides. Positive λ gives exponentials; only the zero solution meets both zero ends. Use Y″+λY=0 for sine.
  • Setting X″/X=Y″/Y without the minus sign. For u_xx+u_yy=0 the correct split is X″/X=−Y″/Y.
  • Treating λ as any real number after boundary conditions. Homogeneous zero ends allow only discrete λ_n=(nπ/L)².
  • Setting the arbitrary constant D to zero. Eigenfunctions may be multiplied by any nonzero constant; D=0 loses the mode.
  • Switching sign convention halfway. A book may call the constant −λ; the two ODEs swap but the final product is the same.

5.4 One-dimensional wave equation and D'Alembert's solution

The wave equation u_tt=c²u_xx describes a disturbance moving at speed c without change of shape. It models a plucked string, a sound pulse in air, and a voltage step on a transmission line. D'Alembert's idea is to split the disturbance into two travelling waves, one moving right and one moving left, then fit them to the initial displacement f and initial velocity g. The result is a closed formula for u(x,t) on an infinite line. Finite strings need boundary conditions and Fourier series.

You need: second order PDE classification from Chapter 5.2, separation ideas from Chapter 5.3, and linear ODEs from Unit 2.

Equation and characteristics

The one-dimensional wave equation is u_tt = c² u_xx. Here u(x,t) is displacement, x is position, t is time, and c is the wave speed with units metre per second. The subscripts mean partial derivatives: u_tt is ∂²u/∂t² and u_xx is ∂²u/∂x². The equation is hyperbolic by the discriminant test in Chapter 5.2. Some syllabi call it the vibrating string equation.

Factor the operator: ∂t² − c²∂x² = (∂t − c∂x)(∂t + c∂x). Introduce characteristics ξ = x − ct and η = x + ct. On a line ξ = constant, the point moves right at speed c. On η = constant, it moves left at speed c. Changing variables turns the PDE into uξη = 0. Integrate twice: first in ξ, then in η. The general solution is u = F(ξ) + G(η) = F(x − ct) + G(x + ct). F and G are arbitrary functions fixed by initial data. F(x − ct) is a right-moving wave; G(x + ct) is a left-moving wave.

u_tt = c² u_xx

u(x,t) is displacement in m; c is wave speed in m/s; t is time in s; x is position in m.

D'Alembert's formula

For an infinite string, give the initial displacement and initial velocity at t = 0: u(x,0)=f(x) and u_t(x,0)=g(x). Put t = 0 in the general solution: F(x)+G(x)=f(x). Differentiate in time: −cF'(x)+cG'(x)=g(x). Integrate the second relation from x−ct to x+ct and combine with the first. The result is D'Alembert's formula.

u(x,t) = ½[f(x−ct) + f(x+ct)] + 1/(2c) ∫ from x−ct to x+ct g(s) ds

f is initial displacement; g is initial velocity; c is wave speed; s is a dummy variable.

The first bracket is the average of two copies of the initial shape: one shifted right by ct, one shifted left by ct. The integral adds the effect of the initial velocity. If g = 0, the shape splits into two half-size copies moving apart. If f = 0, the velocity creates two ramp-shaped waves, one on each side.

Check the formula at t = 0: the bracket gives ½[f(x)+f(x)] = f(x), and the integral has zero width, so u = f(x). Differentiate in t and set t = 0 to recover u_t = g(x). The factor 1/(2c) is essential.

Finite string and reflections

A real string has ends. On 0 < x < L with fixed ends, the boundary conditions are u(0,t)=0 and u(L,t)=0. A right-moving wave reaches x = L, reflects, and returns as a left-moving wave. At a fixed end the reflected displacement has opposite sign, so a crest returns as a trough. The two travelling waves superpose. D'Alembert's formula still describes each piece between reflections, but the boundary conditions are awkward to impose directly.

The standard method is separation of variables, covered in Chapter 5.3. Write u(x,t)=X(x)T(t). The boundary conditions force X(0)=X(L)=0, so X is a sine series. The time factor oscillates at frequencies set by the wave speed and the length. Fitting the initial displacement and velocity needs Fourier series, done in Chapter 5.7. Use D'Alembert for the whole line or for short times before a reflection returns; use Fourier series for a finite string over long times.

Worked example

Question. Solve u_tt = 4u_xx on the whole line, with u(x,0)=sin x and u_t(x,0)=0. Here x is in metres and the sine argument is in radians; u is in metres. Find u(x,t), simplify it, and evaluate u at x=π/2 m, t=0.5 s.

  3. D'Alembert gives u=½[sin(x−2t)+sin(x+2t)].
  4. Use sin A+sin B=2 sin((A+B)/2)cos((A−B)/2) with A=x−2t and B=x+2t. Then (A+B)/2=x and (A−B)/2=−2t. Since cos is even, u=sin x cos 2t.
  5. At x=π/2 and t=0.5, 2t=1 rad. So u=sin(π/2)cos(1)=1×0.540302=0.540302 m.

Exam traps

  • Dropping the factor 1/(2c) in the velocity integral; then the units and the initial slope are wrong.
  • Mixing the signs: the right-moving wave is F(x−ct); the left-moving wave is G(x+ct). Reversing them changes the direction of travel.
  • Using D'Alembert on a finite string without accounting for reflections. Boundary conditions need odd extensions or Fourier series.
  • Forgetting that g is u_t, not u. The integral uses velocity, not displacement.
  • Assuming c is the coefficient in u_tt=c²u_xx. The speed is c=√(coefficient), so u_tt=4u_xx gives c=2, not 4.

5.5 One-dimensional heat equation

Hold one end of a metal rod in boiling water and the rest warms slowly, the sharpest temperature differences fading first. The one-dimensional heat equation describes this: the rate of change of temperature at a point is proportional to the curvature of the temperature profile there. It is used in heat-sink design, in cooling models for transformers and chips, and in finance under another name. This chapter solves it by separation, giving sine modes whose heights decay exponentially in time.

You need separation of variables from 5.3, second order ODEs from Unit 2, and later 5.7 for general initial data.

The rod, the diffusivity and the two ends

Take a thin rod along the x-axis, length L metres. Let u(x,t) be the temperature in °C at position x metres and time t seconds.

ut = α² uxx

ut = ∂u/∂t is the rate of temperature change (°C/s); uxx = ∂²u/∂x² is the curvature of the profile; α² is the thermal diffusivity of the material in m²/s.

Here the diffusivity is written α²; some books write ut = α uxx and call α the diffusivity. This book follows 5.3, so α² carries the units m²/s and the value 1.1 × 10⁻⁴ m²/s for copper.

α² is a material property, not a speed. Copper has α² ≈ 1.1 × 10⁻⁴ m²/s; wood is roughly a thousand times smaller, which is why a wooden handle stays cool while a copper base spreads heat quickly.

The equation reads: a point under a hot hump (uxx < 0) cools, a point in a cold dip (uxx > 0) warms. Sharp corners have large curvature, so they smooth out first. That is the whole mechanism.

  • Fixed temperature (Dirichlet): u(0,t) = 0 means the end is held at 0 °C, say in an ice bath.
  • Insulated end (Neumann): ux(0,t) = 0. Heat flux is −k ux, so zero slope means no heat crosses.
  • Initial condition: u(x,0) = f(x), the starting profile in °C.

For the steady state, set ut = 0. Then uxx = 0, so u = Ax + B: a straight line joining the two end temperatures, reached only as t → ∞.

Separation: sine modes that fade

  1. Assume u(x,t) = X(x)T(t), the product guess of 5.3.
  2. Substitute: X T′ = α² X″ T, then divide by α² X T to get T′/(α²T) = X″/X.
  3. The left side depends only on t and the right only on x, so both equal a constant, written −λ.
  4. This splits into T′ = −λα²T and X″ = −λX.

Solve the x-equation first, because the ends impose conditions there. For zero ends X(0) = X(L) = 0, only λ > 0 gives a nonzero X.

λ<sub>n</sub> = n²π²/L², X<sub>n</sub>(x) = sin(nπx/L), n = 1, 2, 3, …

λn is the nth eigenvalue; L is the rod length in m; Xn is the nth sine mode.

Tn(t) = e−α²n²π²t/L²

Tn is the amplitude of mode n at time t; the exponent is in 1/s because α² (m²/s) times n²π²/L² (1/m²) gives 1/s.

For zero ends (u = 0 at both ends), the general solution is u(x,t) = Σ<sub>n=1</sub><sup>∞</sup> b<sub>n</sub> sin(nπx/L) e<sup>−α²n²π²t/L²</sup>

bn are Fourier coefficients fixed by u(x,0) = f(x); see 5.7.

Mode n fades n² times faster than mode 1. The slowest mode sets the clock: after time L²/(α²π²) the first mode has dropped to 1/e ≈ 0.37 of its start.

If both ends are insulated, the condition is X′ = 0 and the modes become cosines.

Xn(x) = cos(nπx/L), n = 0, 1, 2, …

n = 0 is the constant mode; it never decays, so a fully insulated rod keeps its average temperature.

Ends held at different temperatures

A rod of length L has its left end at T₁ and right end at T₂, both fixed for all time. The profile drifts to a straight line, and the leftover transient still obeys the heat equation.

  1. Write u(x,t) = v(x) + w(x,t), steady part plus transient.
  2. Solve v″ = 0 with v(0) = T₁, v(L) = T₂: v(x) = T₁ + (T₂ − T₁)x/L.
  3. Then wt = α² wxx with w(0,t) = w(L,t) = 0 and w(x,0) = f(x) − v(x).
  4. Solve w by sine modes; it decays to zero, so u → v.

Numbers: L = 1 m, T₁ = 0 °C, T₂ = 100 °C give v(x) = 100x °C, so the midpoint settles at 50 °C. The same split models a chip package, where boundary temperatures fix the steady part and switching creates the transient.

Exam traps

  • Writing ut = α uxx instead of α² uxx. Check units: α² uxx gives (m²/s)(°C/m²) = °C/s, while α uxx does not.

5.6 Laplace's equation in Cartesian and polar coordinates

Laplace's equation describes a steady state with no sources or sinks: temperature after a long time, electric potential in a charge-free region, or ideal fluid flow. In two dimensions it is uxx+uyy=0. Coordinates decide the method. A rectangle suits x and y. A disk suits radius r and angle θ. Both reduce the PDE to ordinary equations, and boundary values choose the constants. The same equation covers many physical problems.

You need: separation of variables from Chapter 5.3, second order linear ODEs from Unit 2, and the idea of fitting series from Chapter 5.7.

Steady potentials

Write u(x,y) for the unknown steady potential. The equation uxx+uyy=0 says the second derivatives cancel. A solution is called harmonic. The equation has no time variable and no source term. Heat flow with no internal heating reaches this form after transients die out. Electrostatics with no charge gives this form for potential. The boundary condition fixes the solution; Laplace's equation alone has infinitely many solutions. On a boundary ∂D of a domain D, one may give the value of u (Dirichlet), its normal derivative (Neumann), or a mix. For a disk, the usual data is u(a,θ) on the circle r=a. For a rectangle, data sits on four sides. A harmonic function cannot have a strict maximum inside the region unless it is constant. That maximum principle explains why boundary values determine it. A solution with no interior peak is fixed by its rim. Some syllabi call it the potential equation.

Separation in a rectangle

Take a rectangle 0<x<a, 0<y<b. Try u=X(x)Y(y). Substitute and divide by XY: X″/X + Y″/Y = 0. The first term depends on x only, the second on y only, so both equal a constant. Write X″+λX=0 and Y″−λY=0; λ is the separation constant. The sign of λ is chosen by the boundary conditions. If X(0)=X(a)=0, only λ=(nπ/a)² works, with Xn=sin(nπx/a) and n=1,2,3,.... Then Yn is sinh(nπy/a) or cosh(nπy/a) or a combination. The product sin(nπx/a) sinh(nπy/a) is zero on x=0, x=a and y=0. It grows with y, so it fits a nonzero top side. If the top side is zero and the bottom is nonzero, use sinh(nπ(b−y)/a) instead. For λ=0, X is linear; zero end values force X=0, so no term. For λ<0, the x solution uses sinh and cannot vanish at both ends unless it is zero. Sum the allowed products with coefficients.

u(x,y)=Σ<sub>n=1</sub><sup>∞</sup> A<sub>n</sub> sin(nπx/a) sinh(nπy/a)

An are constants fixed by the top boundary; a is the rectangle width; n runs over positive integers.

Polar coordinates and a disk

In polar coordinates x=r cosθ, y=r sinθ, the Laplacian becomes urr+(1/r)ur+(1/r²)uθθ=0. The 1/r and 1/r² are part of the geometry, not optional. Try u=R(r)Θ(θ). Then r²R″/R + rR′/R = −Θ″/Θ = n². The angle equation is Θ″+n²Θ=0, so Θ is cos nθ or sin nθ when n is a whole number. Periodic Θ(θ+2π)=Θ(θ) forces that. The radius equation is r²R″+rR′−n²R=0. Its solutions are rn and r−n for n≥1. For n=0, they are 1 and ln r. Inside a disk that contains the origin, r−n and ln r blow up at r=0, so we reject them. The bounded building blocks are 1, rncos nθ, and rnsin nθ. On the circle r=a, the term rncos nθ becomes ancos nθ.

Matching boundary data

Inside a disk of radius a, write u(r,θ)=A0/2 + Σn=1∞ rn(Ancos nθ+Bnsin nθ). The constant A0/2 is the average rim value. Put r=a. The boundary function f(θ)=u(a,θ) must equal A0/2 + Σn=1∞ an(Ancos nθ+Bnsin nθ). This is a Fourier series. The coefficients follow from orthogonality; the formulas and general fitting are in Chapter 5.7. A single cosine or sine on the rim needs no long series: match its frequency and solve for one constant. If the rim value has cos 2θ, only the n=2 cosine term is active. The power of a divides the coefficient. For r=2 and cos 2θ, the factor is 2²=4, not 2. At r=0 all rn terms vanish except the constant, so finiteness is automatic.

Worked example

Question. Solve ∇²u=0 inside the disk r<2, with u(2,θ)=cos 2θ and u finite at r=0. Give the solution and the value at r=1, θ=0.

Exam traps

  • Dropping 1/r or 1/r² from the polar Laplacian; both are part of the geometry and change the separated equations.
  • Keeping r−n or ln r inside a disk that contains the origin; these terms blow up at r=0 and violate finiteness.
  • Using the wrong power of the boundary radius. For r=2 and mode n=2, the rim factor is 2²=4, not 2.
  • Mixing sinh and cosh with sin and cos in a rectangle. The boundary that must vanish decides the function and its argument.
  • Assuming the separation constant is positive without checking the boundary conditions; λ=0 and λ<0 are separate cases.

5.7 Fourier series solutions of boundary value problems

Fourier series fit given boundary or initial data by writing it as a sum of sine and cosine modes. Orthogonality extracts one coefficient at a time. Each coefficient then scales a separated mode solution of the PDE. The sum is the full solution. Engineers use this for cooling fins, vibrating beams, and steady plate temperatures. The method turns an arbitrary profile into numbers that the PDE can carry forward in time.

You need: separation of variables in 5.3, the heat and wave mode solutions in 5.5 and 5.4, and orthogonal eigenfunctions from Unit 3.

Sine and cosine series on 0 < x < L

On 0<x<L the data is only half a period. You may extend it as an odd function and use sine terms, or as an even function and use cosine terms. This is a half-range expansion.

f(x) = Σ_{n=1}^{∞} b_n sin(nπx/L)

b_n = (2/L)∫_0^L f(x) sin(nπx/L) dx; b_n is the sine coefficient, n=1,2,3,...; L is the interval length in metres or another unit.

f(x) = a_0/2 + Σ_{n=1}^{∞} a_n cos(nπx/L)

a_0 = (2/L)∫_0^L f(x) dx; a_n = (2/L)∫_0^L f(x) cos(nπx/L) dx; a_0 is the mean level; a_n is the cosine coefficient.

The factor 2/L comes from orthogonality. Each family is orthogonal on 0 < x < L: ∫₀^L sin(mπx/L) sin(nπx/L) dx = L/2 when m=n and 0 otherwise, and the cosine family obeys the same rule. Sine and cosine together are orthogonal only on the full period −L < x < L, not on 0 < x < L, so do not mix the two families on a half interval. Multiplying the series by one mode and integrating kills every other term, leaving its coefficient. A full periodic series on −L < x < L uses both sine and cosine; the half-range series above is what boundary value problems need.

Putting coefficients into mode solutions

For the heat equation u_t=αu_xx on 0<x<L with u(0,t)=u(L,t)=0, separation gives u(x,t)=Σ b_n e^{−α n²π² t/L²} sin(nπx/L). The b_n are exactly the sine coefficients of u(x,0). For the wave equation u_tt=c²u_xx with fixed ends, u(x,t)=Σ [a_n cos(nπct/L)+b_n sin(nπct/L)] sin(nπx/L); a_n fits initial displacement, and b_n fits initial velocity after division by nπc/L.

For Laplace's equation in a rectangle with three zero edges, the same sine coefficients fit the fourth edge, while the time factor is replaced by sinh or exponential terms in the other coordinate. At a jump, the series converges to the average of the left and right values. Away from the jump it converges to f(x) under the usual piecewise smooth conditions. Boundary conditions decide whether sine or cosine is legal.

A safe calculation order

  1. State the interval and the boundary conditions. Use sine for two zero ends, cosine for two insulated ends.
  2. Write the correct half-range coefficient formula with the factor 2/L.
  3. Integrate, then simplify using cos(nπ)=(−1)^n.
  4. Put each coefficient into the mode solution with its time factor: exponential for heat, cosine and sine for wave.
  5. Check the initial profile, both boundaries, and the units of every coefficient.

Sine modes vanish at x=0 and x=L, so they cannot carry a nonzero edge value. Cosine modes have zero slope at x=0 and x=L, so they fit insulated ends. A mixed condition needs a different eigenfunction, not a quick sine-cosine swap.

  2. Separate u=X(x)T(t): X''/X=T'/T=−λ. The boundary conditions give λ=n²π² and X_n=sin(nπx).
  3. Then T'=−n²π²T, so T_n(t)=e^{−n²π² t}. The general solution is u=Σ b_n e^{−n²π² t} sin(nπx).
  4. At t=0, 100=Σ b_n sin(nπx), so b_n=2∫_0^1 100 sin(nπx) dx.
  5. Integrate: ∫ sin(nπx)dx=−cos(nπx)/(nπ). Thus b_n=200[1−cos(nπ)]/(nπ)=200[1−(−1)^n]/(nπ).
  6. For even n, 1−(−1)^n=0, so b_n=0. For odd n, b_n=400/(nπ).
  7. The first three nonzero values are b_1=400/π≈127.324, b_3=400/(3π)≈42.441, b_5=400/(5π)≈25.465.
  8. Therefore u(x,t)=Σ_{n odd} 400/(nπ)e^{−n²π² t}sin(nπx).

Answer. u(x,t)=Σ_{n odd} 400/(nπ)e^{−n²π² t}sin(nπx), with b1≈127.324, b3≈42.441 and b5≈25.465 in the same temperature units as the initial data.

Exam traps

  • Using 1/L instead of 2/L in a half-range sine or cosine coefficient.
  • Mixing sine and cosine modes when the boundary data permit only one family.
  • Forgetting e^{−α n²π²t/L²} for heat or the cosine and sine time factors for wave.
  • Replacing cos(nπ) with 1 instead of (−1)^n, so odd coefficients vanish by mistake.
  • Applying u(x,0)=100 before inserting the time factor, then treating the answer as time-independent.

Remember State the half-range sine coefficient formula on 0<x<L. 2 marks

Understand Why does the factor 2/L appear in half-range coefficients? 3 marks

The sine or cosine modes are orthogonal on 0<x<L with integral L/2 when the indices match. Dividing by L/2 gives 2/L.

Apply For f(x)=100 on 0<x<1, find b1 in its sine series. 3 marks

Analyze A student uses a cosine series for a heat problem with u(0,t)=u(L,t)=0. What goes wrong at x=0? 4 marks

Every cosine mode equals 1 at x=0, so the series generally gives a nonzero value there. It cannot satisfy u(0,t)=0 unless all coefficients vanish.

Understand What value does a Fourier series converge to at a jump discontinuity? 3 marks

It converges to the average of the left-hand and right-hand limits at the jump.

Analyze For a fixed-end wave problem with zero initial velocity, which coefficients vanish and why? 4 marks

The b_n vanish. The initial velocity series contains (nπc/L)b_n sin(nπx/L); setting it to zero for all x forces every b_n=0.

Takeaways

  1. Constant coefficients let you factor the operator, and every first order factor gives one arbitrary function of a combined variable.
  2. The sign of B² − 4AC decides the type: elliptic has no real characteristics, parabolic one family, hyperbolic two families.
  3. Separation of variables turns one PDE into two ODEs joined by a single constant, and the boundary conditions pick the allowed values of that constant.
  4. The wave equation carries the initial shape in two directions at speed c; D'Alembert's formula writes exactly that.
  5. The heat equation damps high modes fastest, so the temperature profile flattens as time grows and only the longest mode survives.
  6. Laplace's equation gives steady potentials: sinh and sine in a rectangle, powers r^n and cos nθ in a disk.
  7. Fourier series are the fitting tool; orthogonality pulls out each coefficient from the initial or boundary data.
  8. The PDE alone is not the problem; boundary and initial conditions choose which modes exist and how fast they decay.

Exam question bank

Long answers almost always ask for a full boundary value problem: classify the equation, separate it, find the eigenvalues, fit the data with Fourier coefficients and write the final series, so show every stage.

Apply Solve (D² − 3DD′ + 2D′²)z = 0. 10 marks

Apply Classify u_xx + x u_yy = 0 at every point of the plane and describe the geometry of the three regions. 10 marks

Apply A rod of length 1 m has both ends held at 0 °C and initial temperature u(x,0) = 100 sin(πx) °C, with α² = 1 m²/s. Find u(x,t) and the time at which the midpoint falls to 50 °C. 14 marks

Apply Solve Laplace's equation in the rectangle 0 < x < a, 0 < y < b, with u = 0 on x = 0, x = a and y = 0, and u(x,b) = f(x). 14 marks

Apply Solve Laplace's equation inside a disk of radius a with boundary value u(a,θ) = f(θ), and justify why some separated solutions are thrown away. 14 marks

Analyze and evaluate

Analyze Compare the heat equation and the wave equation mode by mode, and explain why one smooths the initial data while the other preserves its shape. 12 marks

Both separate into the same sine modes in x with λ = n²π²/L²; Time factors: e^(−α²λt) for heat, cos(√λ ct) and sin(√λ ct) for the wave equation; Heat amplitudes decay at a rate proportional to n², so high modes die fast and corners round off; Wave amplitudes oscillate without decay, so the profile repeats and information travels along characteristics; Consequence: heat solutions become smooth for any t > 0; wave solutions keep discontinuities along the lines x ± ct = constant; Mention that only the wave equation is reversible in time.

Analyze Explain how the type of a second order PDE with variable coefficients can change from point to point, using u_xx + x u_yy = 0, and say what this means for solving it. 12 marks

Compute Δ = −4x, which depends on position; Region x < 0 hyperbolic, line x = 0 parabolic, region x > 0 elliptic; In the hyperbolic region two real characteristic families exist and a D'Alembert-type solution is possible; In the elliptic region there are no real characteristics; boundary value data on a closed curve is the natural problem; On x = 0 the equation degenerates and the usual classification tools fail; Conclude that a single global formula is not available; solutions are usually matched across the parabolic line.

Evaluate A semi-infinite string occupies x ≥ 0 with the end x = 0 fixed. Explain how D'Alembert's solution is extended to cover this case and why an odd extension is the correct choice. 12 marks

Start with the infinite-string formula for the odd extension of the initial data; The fixed end demands u(0,t) = 0 for all t; The forward wave F(x − ct) reaching x = 0 must be cancelled by a reflected wave, which the odd extension supplies; Oddness gives f(−s) = −f(s), so the two contributions at x = 0 add to zero; State that the reflected pulse returns inverted, as observed on a string tied at one end; Note the same idea extends to a finite string by repeated reflections.

Glossary

Boundary value problem
A PDE together with conditions on the boundary of the region, whose solution is sought inside the region.
Dirichlet condition
A boundary condition that prescribes the value of the unknown function itself on the boundary.
Eigenfunction
The nonzero solution corresponding to an eigenvalue, for example sin(nπx/L).
Eigenvalue of a boundary value problem
A value of the separation constant for which a nonzero solution satisfying the boundary conditions exists.
Fourier coefficient
The weight of a particular sine or cosine term, found by integrating the data against that term.
Fourier series
An expansion of a periodic function as a sum of sines and cosines of increasing frequency.
Fundamental mode
The lowest-frequency separated solution, with n = 1; it decays slowest in the heat problem and has the largest period in the wave problem.
Half-range sine series
The Fourier sine expansion of a function given only on 0 < x < L, obtained by odd extension.
Homogeneous PDE
A linear PDE with no term free of the unknown function, so the zero function is always a solution.
Initial condition
Data given at one time level, needed because the heat and wave equations are first order in time or second order in time.
Linear PDE
A PDE in which the unknown function and its derivatives appear only to the first power and are not multiplied together.
Maximum principle
A property of harmonic functions: the largest and smallest values occur on the boundary, not inside.
Neumann condition
A boundary condition that prescribes the normal derivative of the unknown function on the boundary.
Node
A point of a standing wave where the displacement stays zero for all time.
Order
The order of the highest derivative appearing in the equation.
Partial differential equation
An equation involving an unknown function of two or more variables and its partial derivatives.
Steady state
The time-independent solution that a time-dependent problem approaches as t grows; it satisfies Laplace's equation.
Superposition principle
Any finite sum of solutions of a linear homogeneous PDE is again a solution.
Thermal diffusivity
The constant α² in the heat equation, in m²/s, measuring how quickly temperature differences spread.
Transient
The part of a solution that decays with time, leaving only the steady state.
Wave speed
The constant c in the wave equation, in m/s, at which each travelling disturbance moves.
Well-posed problem
A problem whose solution exists, is unique, and depends continuously on the given data.
