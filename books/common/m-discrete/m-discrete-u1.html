1.1 Propositions, connectives, truth tables and tautologies

A proposition is a declarative statement that is definitely true or definitely false. Propositional logic gives it symbols and connectives, so a sentence can be turned into a formula whose truth table shows every possible case. Truth tables expose tautologies, formulas that are true in every row, and they are the base for proof rules, digital circuits, program conditions and database filters. This chapter sets up the connectives, the table method and the three classifications you will use in later chapters on equivalence, normal forms and inference.

Statements and connectives

A proposition is a declarative statement that has exactly one truth value: T (true) or F (false). '7 is prime' is a proposition with value T. '2+2=5' is a proposition with value F. 'Close the door' is a command, 'Is it raining?' is a question, and 'x+3=10' has no fixed value until x is chosen. These are not propositions in this chapter. A propositional variable such as p, q or r stands for a proposition. A compound proposition is built from variables and connectives.

  • Negation ¬p is 'not p'; it is T when p is F, and F when p is T.
  • Conjunction p∧q is 'p and q'; it is T only when both p and q are T.
  • Disjunction p∨q is 'p or q' in the inclusive sense; it is T when at least one of p, q is T.
  • Exclusive or p⊕q is T when exactly one of p, q is T; some syllabi call it XOR.
  • Implication p→q is 'if p then q'; it is F only in the row p=T, q=F. p is the antecedent and q is the consequent.
  • Biconditional p↔q is 'p if and only if q'; it is T when p and q have the same truth value; some syllabi call it equivalence.

The connectives turn small statements into larger formulas. The figure's formula, (p→q)∨(q→p), says 'either p implies q, or q implies p'. Its table is built in the example.

Truth tables and classification

A truth table lists every assignment of T and F to the variables and shows the value of each subformula. With n variables there are 2n rows. Two variables use 4 rows; three variables use 8 rows.

  1. Write the variables in a fixed order, then add one column for each connective, working from the innermost brackets outward.
  2. Fill the variable columns with all 2n assignments. For two variables a reliable order is TT, TF, FT, FF.
  3. Evaluate negation first, then conjunction, then disjunction or exclusive or, then implication, then biconditional. Brackets override this order.
  4. Read the final column. If every entry is T, the formula is a tautology. If every entry is F, it is a contradiction. If it has both T and F, it is a contingency.

For example, p∨¬p is a tautology: if p is T the left part is T, and if p is F the negation is T. p∧¬p is a contradiction: no assignment makes both p and not p true. p→q is a contingency: it is T in three rows and F in the row p=T, q=F. The figure's formula is a tautology because its final column has T in all four rows. Logical equivalences are proved with such tables; see 1.2. Normal forms record the rows that matter; see 1.3.

Precedence and a bitwise view

Precedence fixes the order when brackets are missing. From tightest to loosest: ¬, then ∧, then ∨ and ⊕, then →, then ↔. So ¬p∨q∧r→s is read as ((¬p)∨(q∧r))→s. When in doubt, add brackets; the examiner marks the table, not your memory of precedence.

((¬p) ∨ (q ∧ r)) → s

p, q, r and s are propositions; ¬ is negation, ∧ is and, ∨ is or, and → is implication. Brackets show the grouping forced by precedence.

Boolean values also appear as bits inside integers. In C, C++, Java and Python, & is bitwise AND, | is bitwise OR, and ^ is bitwise XOR. Take 6 and 3. In binary, 6 = 110₂ and 3 = 011₂. Bit by bit: 6 & 3 = 010₂ = 2; 6 | 3 = 111₂ = 7; 6 ^ 3 = 101₂ = 5. Each bit position behaves like one row of a truth table, but the whole integer is not a proposition. The same connectives drive logic gates and program conditions.

Propositional formulas become arguments when you attach premises and a conclusion. The validity rules are in 1.4. Quantifiers, which let a formula speak about all or some objects, are in 1.6.

Worked example

Question. Construct the truth table for (p→q)∨(q→p). Classify the formula as a tautology, contradiction or contingency.

  1. Two variables p and q give 2² = 4 rows: (T,T), (T,F), (F,T), (F,F).
  2. Compute p→q. It is F only for (T,F); the column is T, F, T, T.
  3. Compute q→p. It is F only for (F,T); the column is T, T, F, T.
  4. OR the two columns row by row: T∨T=T; F∨T=T; T∨F=T; T∨T=T. Final column: T, T, T, T, encoded as 1, 1, 1, 1.
  5. Every row is T, so no assignment makes the formula false.

Answer. The formula (p→q)∨(q→p) is a tautology; its final column is T in all four rows, encoded as 1, 1, 1, 1.

Exam traps

  • p→q is false only when p is T and q is F. A common error is to mark it false when p is F; then the implication is T by definition. Also p→q is not q→p.
  • The English word 'or' can be inclusive or exclusive. In p∨q, assume inclusive unless the question says XOR (⊕).
  • ¬ binds tighter than ∧, and ∧ tighter than ∨. Without brackets, ¬p∨q means (¬p)∨q, not ¬(p∨q).
  • A tautology needs T in every row, not T in the rows you checked. With three variables there are 8 rows; missing rows is the usual lost mark.
  • p↔q is true when both are T or both are F. Do not confuse it with p→q, which is true in three of the four rows.

1.2 Logical equivalences, laws of logic, converse and contrapositive

Logical equivalence is when two formulas have the same truth value in every row of a truth table. Laws of logic are named equivalences that let you replace one formula by another without changing its meaning. They turn long expressions into short ones and expose structure. The contrapositive is the one rewrite of an implication that is always safe. These ideas are used in circuit design, program verification and clear proof writing.

You need: truth tables and connectives from 1.1.

Logical equivalence

Two formulas are logically equivalent when they have the same truth value in every row of their joint truth table. Write p ≡ q. The definition is exact: p ≡ q when p↔q is a tautology. A tautology is a formula that is true in every row, as covered in 1.1.

Example: ¬(p∧q) ≡ ¬p∨¬q. Check the four rows of p and q. Both sides are false only when p and q are both true; in the other three rows both sides are true. The two formulas match in every row.

Laws of logic are equivalences you can use as rewrite rules. The substitution principle says: if a formula A is equivalent to B, you may replace A by B inside any larger formula and the truth value does not change. Some syllabi call these laws identities.

Converse, inverse and contrapositive

For the implication p→q, three related formulas are named. The converse is q→p. The inverse is ¬p→¬q. The contrapositive is ¬q→¬p. The original and the contrapositive are logically equivalent. The converse and the inverse are not equivalent to the original; they are equivalent to each other.

Look at the one false row of p→q: p true and q false. The contrapositive is false in exactly the same assignment: ¬q true and ¬p false means q false and p true. The converse is false when q true and p false, a different row. The inverse is false in that same different row, so the converse and inverse match each other.

Proof by contrapositive proves p→q by proving ¬q→¬p. This is a standard proof method; see 1.7. A common error is to prove the converse and call it the original.

Worked example

Question. Simplify ((p→q)∧(p∨q)) using laws of logic. Also write the converse and contrapositive of p→q. Verify by truth table that the simplified formula matches q.

  1. Remove the implication using p→q ≡ ¬p∨q. The formula becomes (¬p∨q)∧(p∨q).
  2. Factor q using the distributive law: (¬p∨q)∧(p∨q) ≡ (¬p∧p)∨q.
  3. Apply the negation law: ¬p∧p ≡ F. The formula becomes F∨q.
  4. Apply the identity law: F∨q ≡ q. The simplified formula is q.
  5. The converse of p→q is q→p. The contrapositive of p→q is ¬q→¬p.
  6. Check the four rows for p and q: (T,T), (T,F), (F,T), (F,F). The original expression (p→q)∧(p∨q) is true in 2 of 4 rows, namely (T,T) and (F,T). The formula q is true in the same 2 of 4 rows.

Answer. The formula simplifies to q. The converse is q→p and the contrapositive is ¬q→¬p. Both the original expression (p→q)∧(p∨q) and q are true in 2 of 4 truth-table rows.

Exam traps

  • Do not treat the converse q→p as equivalent to p→q. Only the contrapositive ¬q→¬p is equivalent.
  • Do not confuse the inverse ¬p→¬q with the original. The inverse is equivalent to the converse, not to p→q.
  • De Morgan: ¬(p∧q) is ¬p∨¬q, not ¬p∧¬q. The operator flips when the not moves inside.
  • Do not use p→q ≡ ¬p∨q and then forget the brackets. For example, ¬p∨q∧r is not the same as (¬p∨q)∧r.
  • Absorption only removes a term of the form p∧(p∨q) or p∨(p∧q). It does not remove unrelated terms such as p∨(q∧r).

1.3 Normal forms: DNF, CNF, PDNF and PCNF

A normal form rewrites a formula into a fixed shape: an OR of AND terms (DNF) or an AND of OR terms (CNF). The principal forms go further. PDNF is an OR of minterms, one for each truth-table row where the formula is true. PCNF is an AND of maxterms, one for each row where it is false. They matter because two formulas are equivalent exactly when their principal forms match, and because software can test, simplify or solve a formula when it is in a standard shape.

You need: Chapter 1.1 for truth tables and Chapter 1.2 for the laws used in conversion.

Literals, minterms and maxterms

A literal is a variable or its negation: p, ¬p, q, ¬q. A product term is an AND of literals, such as p∧¬q. A sum term is an OR of literals, such as p∨¬q.

m = l₁ ∧ l₂ ∧ … ∧ lₙ

m is a minterm for an n-variable row; lᵢ is pᵢ when the row has pᵢ = 1, and lᵢ is ¬pᵢ when the row has pᵢ = 0.

For n variables there are 2ⁿ rows, hence 2ⁿ minterms and 2ⁿ maxterms. A minterm is true on exactly one row. A maxterm is false on exactly one row. For a maxterm on the same row, reverse the rule: use pᵢ when the row bit is 0, and ¬pᵢ when it is 1. Write Mᵢ for the maxterm of row i.

For p=0, q=1, the binary index is 01, decimal 1. The minterm is ¬p∧q = m₁. The maxterm is p∨¬q = M₁. The minterm is true only there; the maxterm is false only there.

DNF, CNF, PDNF and PCNF

A formula is in disjunctive normal form (DNF) when it is an OR of product terms. It is in conjunctive normal form (CNF) when it is an AND of sum terms. A single literal counts as a one-literal term. CNF is the clause shape used by resolution in Chapter 1.9.

The principal disjunctive normal form (PDNF) is a DNF in which every product term is a minterm. It is the OR of the minterms for the true rows. Some syllabi call it full DNF. PDNF(f) = mᵢ₁ ∨ mᵢ₂ ∨ … for true rows i₁, i₂, … .

PDNF(f) = mᵢ₁ ∨ mᵢ₂ ∨ … for true rows;  PCNF(f) = Mᵢ₁ ∧ Mᵢ₂ ∧ … for false rows

mᵢ is the minterm of row i; Mᵢ is the maxterm of row i; ∨ means OR over the listed rows; ∧ means AND over the listed rows.

The principal conjunctive normal form (PCNF) is a CNF in which every sum term is a maxterm. It is the AND of the maxterms for the false rows. Some syllabi call it full CNF. Both principal forms are unique up to term order. A DNF is not automatically PDNF: a term may miss a variable. Expand it using X∨¬X = 1.

Reading from a truth table and converting by laws

  1. Build the truth table for all 2ⁿ rows of the variables in a fixed order, such as p first, q second.
  2. For PDNF, keep every row with output 1. For each such row write its minterm. Join the minterms with ∨.
  3. For PCNF, keep every row with output 0. For each such row write its maxterm. Join the maxterms with ∧.
  4. To convert by laws, remove ↔ and →, push ¬ inward with De Morgan, then distribute ∧ over ∨ for DNF or ∨ over ∧ for CNF.
  5. Expand short terms with X = X∧(Y∨¬Y) for DNF, or X = X∨(Y∧¬Y) for CNF, until every term has all variables.

The truth-table route is safe and gives the principal form directly. The law route is faster for a simple formula, but check that every term has all variables; otherwise expand it before calling the result principal. The figure shows XOR. The two output-1 rows become the PDNF minterms; the two output-0 rows become the PCNF maxterms.

Worked example

Question. Find the PDNF and PCNF of f(p,q)=p⊕q. Give both the minterm/maxterm notation and the literal formulas.

  1. Write the rows in order (p,q): (0,0) gives f=0; (0,1) gives f=1; (1,0) gives f=1; (1,1) gives f=0.
  2. True rows are (0,1), index 0×2+1=1, and (1,0), index 1×2+0=2.
  3. Row (0,1): p is 0 so use ¬p; q is 1 so use q. Minterm m₁=¬p∧q.
  4. Row (1,0): p is 1 so use p; q is 0 so use ¬q. Minterm m₂=p∧¬q.
  5. PDNF = m₁∨m₂ = (¬p∧q)∨(p∧¬q) = Σm(1,2).
  6. False rows are (0,0), index 0, and (1,1), index 3.
  7. Row (0,0): p=0, q=0, so maxterm M₀=p∨q. Row (1,1): p=1, q=1, so maxterm M₃=¬p∨¬q.
  8. PCNF = M₀∧M₃ = (p∨q)∧(¬p∨¬q) = ΠM(0,3).

Answer. The PDNF is (¬p∧q)∨(p∧¬q), written Σm(1,2); the PCNF is (p∨q)∧(¬p∨¬q), written ΠM(0,3).

Exam traps

  • For a minterm, a variable is unnegated when its row bit is 1. For a maxterm, it is negated when its row bit is 1. Swapping these is the most common error.
  • PDNF uses true rows; PCNF uses false rows. Using true rows for both gives a wrong PCNF.
  • A DNF such as p∨q is not PDNF for two variables. Each product term must contain both p and q.
  • Keep the variable order fixed. The index of row p=0,q=1 is 1 when p is the first bit; it changes if q is first.
  • If f is false on every row, its PDNF is false; if f is true on every row, its PCNF is true. Do not invent a minterm or maxterm for an empty set.

1.4 Rules of inference and valid arguments

An argument is a set of statements where some, the premises, are offered as reasons for another, the conclusion. The argument is valid when the conclusion cannot be false while every premise is true. Checking that row by row in a truth table is slow, so logicians give names to a small set of argument forms that are always valid: modus ponens, modus tollens, and a handful more. A proof is then a numbered chain in which every line is a premise or follows from earlier lines by one named rule. Programmers meet this in program verification, in Prolog, and in every bug report that must name one cause.

You need: 1.1 for connectives and truth tables, and 1.2 for tautologies and the contrapositive.

Argument, premises, conclusion, validity

An argument is a set of statements. The premises give the reasons; one conclusion is the claim they support. We write P₁, P₂, …, Pₙ ⊢ C, where the symbol ⊢ is read "therefore". Take: "If the server is down, UPI payments fail. UPI payments failed. Therefore the server is down." Its shape is q, p→q ⊢ p.

An argument is valid when no situation makes all the premises true and the conclusion false. Validity is about form, not about whether the premises happen to be true in the real world. A valid argument whose premises are all true is called sound. Swap Chennai for any other city in a valid form and it stays valid.

P₁ ∧ P₂ ∧ … ∧ Pₙ → C is a tautology

P₁ to Pₙ are the premises, C is the conclusion, ∧ means and, → means implies. The argument is valid exactly when this one formula is true in every row of its truth table.

With k propositional variables the truth table has 2^k rows. Hunt for a single row where every premise is true and C is false. If no such row exists, the argument is valid (this is the tautology test of 1.1). Two rules carry most of the work. Modus ponens (MP): from p and p→q infer q. Modus tollens (MT): from ¬q and p→q infer ¬p. MT applies modus ponens to the contrapositive: p→q is equivalent to ¬q→¬p, so from ¬q we get ¬p (see 1.2).

Addition looks odd: from "it is raining" you infer "it is raining or the bus is late". The conclusion is weaker than the premise, and a weaker statement is never false when the stronger one is true. The two dilemmas are just case splits — the constructive one says: the world is in case p or in case r; p forces q and r forces s; so q∨s holds either way.

Writing a formal proof

A formal proof is a numbered column. Every line is either a premise or a formula obtained from earlier lines by exactly one named rule, and the last line is the conclusion. Nothing is written because it "looks obvious".

  1. Number every line, starting at 1.
  2. Write the formula on that line.
  3. Write the justification: the word premise, or a rule name plus the line numbers it was applied to.
  4. Stop when the required conclusion appears; the proof is complete.

Two look-alike patterns are invalid and appear in exams every year. Affirming the consequent: from q and p→q, inferring p. Denying the antecedent: from ¬p and p→q, inferring ¬q. Both fail because p→q tells you nothing when p is false. Let p be "the power is cut" and q be "the room is dark": the room can be dark at night with power on, so q with p→q does not give p.

Of the rules that use one implication together with one of its parts, only MP (from p) and MT (from ¬q) are valid. HS, CD and DD are also valid, but combine two implications or add a case split. Machines use a single rule, resolution, instead of all nine; that is the subject of 1.9.

Worked example

Question. The premises are p→q, q→r and p. (a) Prove r with a numbered formal proof, naming the rule used at every line. (b) Confirm validity by counting: how many rows does the truth table have, how many rows make all three premises true, and how many of those rows make r false?

  1. Line 1: p — premise.
  2. Line 2: p→q — premise.
  3. Line 3: q — modus ponens on lines 1 and 2.
  4. Line 4: q→r — premise.
  5. Line 5: r — modus ponens on lines 3 and 4. This is the conclusion, so the proof ends.
  6. Part (b). Three variables p, q, r, so the truth table has 2³ = 8 rows.
  7. Keep only rows where p is true: 4 rows. In each of those, p→q forces q = T, which leaves 2 rows (q = T, r still free).
  8. With q = T, q→r forces r = T, so exactly 1 row satisfies all three premises, namely p = T, q = T, r = T.
  9. In that row r is true, so the number of rows with all premises true and r false is 0.

Answer. r follows from p and q by two applications of modus ponens; the truth table has 8 rows, exactly 1 satisfies all premises, and 0 of those make r false, so the argument is valid.

Exam traps

  • Affirming the consequent (q, p→q ⊢ p) and denying the antecedent (¬p, p→q ⊢ ¬q) are invalid. They are the examiner's favourite distractors; of the rules that use one implication together with one of its parts, only MP (from p) and MT (from ¬q) are valid. HS, CD and DD are also valid but combine two implications or add a case split.
  • Valid is not the same as true. A valid argument may have false premises; validity asks only whether the form can carry true premises to a false conclusion. Sound means valid plus all premises true.
  • Simplification works on ∧ only. From p∨q you may not infer p; that needs a case split, not simplification.
  • Disjunctive syllogism needs the negation of one disjunct: p∨q with ¬p gives q. From p∨q with p you cannot infer ¬q.
  • Marks come from the justification column. A line written with no rule name, or with the wrong line numbers, loses credit even when the formula is right.

1.5 Consistency, inconsistency and the CP rule

A set of premises is consistent when one single truth assignment makes all of them true together; if no such assignment exists, the set is inconsistent. The CP rule, short for conditional proof, proves P → Q by assuming P for a while, deriving Q, then discharging that assumption. Consistency checks catch a contradictory specification before money is spent on it. Only a few universities teach this material.

You need 1.4 for modus ponens and 1.1 for truth tables.

Consistent and inconsistent premises

A truth assignment gives every propositional variable the value T (true) or F (false). A set of premises S = {P₁, P₂, …, Pₙ} is consistent when one assignment makes every Pᵢ true at the same time. If no assignment does that, S is inconsistent.

Consistency belongs to the whole set, not to one formula. Taken alone, p → q and p are each satisfiable, yet {p → q, p, ¬q} is inconsistent.

  1. Count the distinct variables, n; the truth table has 2ⁿ rows.
  2. Fill T or F for each premise in every row.
  3. One row with all premises T means consistent; no such row means inconsistent.

A second test is derivation. Apply the rules of inference from 1.4. If two lines give Q and ¬Q, the set is inconsistent. For {p → q, q → r, p, ¬r}: p with p → q gives q, then q with q → r gives r, which clashes with ¬r.

The CP rule

The CP rule proves an implication P → Q without building a truth table. Assume P, derive Q, then close the assumption and write P → Q.

  1. Write “Assume P — CP” and mark the line as temporary.
  2. Derive Q using the premises and the rules of inference.
  3. Discharge P: write P → Q, citing the assumption line and the line where Q appeared.
  4. Lines inside the sub-proof stay shut after discharge, except through the new implication.

The assumption is not a premise of the theorem. p → r is proved from p → q and q → r alone; p was borrowed and returned.

CP nests. For P → (Q → R): assume P, assume Q, derive R, discharge Q to get Q → R, then discharge P. Discharge in the reverse order of assumption.

The inconsistency method

An argument with premises Γ and conclusion C is valid exactly when Γ ∪ {¬C} is inconsistent. To prove C, add ¬C as a temporary assumption and derive a contradiction; ¬C must then be false, so C holds.

  1. Negate the conclusion C and add ¬C to the premises.
  2. Derive some formula and its negation.
  3. Reject ¬C, conclude C, and drop ¬C from the premise list.

This is the indirect proof of 1.7 in propositional form. CP and this method say the same thing: assuming P and reaching Q is finding P ∧ ¬Q impossible.

Worked example

Question. Prove p → r from the premises p → q and q → r using the CP rule. Then decide whether the four formulas p → q, q → r, p, ¬r are consistent.

  1. Line 1: p → q, premise. Line 2: q → r, premise.
  2. Line 3: assume p, CP start, marked temporary.
  3. Line 4: q, by modus ponens on line 1 (p → q) and line 3 (p).
  4. Line 5: r, by modus ponens on line 2 (q → r) and line 4 (q).
  5. Line 6: discharge p and write p → r by CP, citing lines 3 to 5.
  6. Consistency test: p with p → q gives q; q with q → r gives r; r clashes with ¬r. A truth table over 3 variables has 8 rows, and 0 rows make all four premises true.

Answer. p → r is proved by CP, and the premises p → q, q → r, p, ¬r are inconsistent: 0 of 8 rows satisfy all four.

Exam traps

  • The CP assumption is temporary: discharge it before the final line and never list it as a premise.
  • Rows are 2ⁿ for n variables, not 2n.
  • A valid argument may have inconsistent premises; anything then follows from them.
  • Discharge the very formula you assumed: the CP line must be P → Q with that same P.
  • Consistency is checked row by row for the whole set, not formula by formula.

1.6 Predicates, quantifiers and universe of discourse

Propositional logic cannot say every student passes or someone forgot the ID. A predicate P(x) is a statement whose truth depends on a variable x. Replace x by a value from a chosen set, the universe of discourse, and P(x) becomes a proposition. Quantifiers let one statement speak about all values (∀) or at least one value (∃) in that universe. Program specifications, database queries, and mathematics use this language to state rules once and apply them to many objects.

You need 1.1 for propositions, connectives and truth tables, and 1.4 for valid arguments and modus ponens.

Predicates, variables and the universe

A predicate has places. P(x): x is even is a predicate. With x free, P(x) is not true or false until x gets a value. A variable is a symbol that stands for a member of the universe. The universe of discourse, also called the domain, is the set U of values allowed for the variable. For P(x): x is even, take U = {1,2,3,4}. P(2) is true and P(3) is false. If U = {2,4,6}, then P(x) is true for every x in U. A predicate can have more than one variable: R(x,y): x < y.

The universe changes truth. Let Q(x): x > 0. With U = {1,2,3}, ∀x Q(x) is true. With U = {-1,0,1}, the same formula is false because x = -1 gives Q(-1) false. Fix U before you judge any quantified statement. In exams, write U in words, such as all integers or all BTech students, before you write ∀ or ∃.

Universal and existential quantifiers

∀x P(x) is read for all x in U, P(x). It is true exactly when P(a) is true for every a in U. ∃x P(x) is read there exists x in U such that P(x). It is true when at least one a in U makes P(a) true. ∃!x P(x) adds exactly one: one a makes P(a) true and no other a does.

Let U = {1,2,3}. ∀x (x² ≥ 1) is true. ∃x (x + 2 = 5) is true, because x = 3 works. ∃!x (x² = 4) is true, because only x = 2 works in U. For a finite U, test every element for ∀; for ∃, stop at the first witness. The order of quantifiers matters when both appear: ∀x∃y R(x,y) is not the same as ∃y∀x R(x,y).

Negation, equivalence and free variables

Negation swaps the quantifier and negates the body: ¬∀x P(x) ≡ ∃x ¬P(x), and ¬∃x P(x) ≡ ∀x ¬P(x). So not every BTech student studies discrete mathematics means some BTech student does not study it. It does not mean every BTech student does not study it.

Quantifiers distribute over some connectives only: ∀x(P(x)∧Q(x)) ≡ ∀xP(x)∧∀xQ(x); ∃x(P(x)∨Q(x)) ≡ ∃xP(x)∨∃xQ(x). They do not distribute over ∨ for ∀ or over ∧ for ∃ in general. Binding: in ∀x P(x,y), x is bound and y is free. A formula with a free variable is not a proposition until that variable is assigned. The scope of a quantifier is the part it controls. Uniqueness negation: ¬∃!xP(x) means none or at least two, not ∃!x¬P(x).

Rules of specification and generalization

Universal specification, also called universal instantiation, says: from ∀xP(x) infer P(c) for any named c in U. Existential specification is more delicate: from ∃xP(x) infer P(c) only for a fresh name c, not one already used.

Universal generalization says: if P(c) is proved for an arbitrary c in U with no special assumption, infer ∀xP(x). Existential generalization says: from P(c) for some c in U infer ∃xP(x). A quantified argument is valid when every universe and every interpretation that makes all premises true also makes the conclusion true. A single counterexample universe kills validity. The full proof templates and the CP rule appear in 1.7.

  • ¬∀xP(x) is ∃x¬P(x), not ∀x¬P(x). The quantifier flips.
  • In ∀xP(x,y), y is free; the formula is not a proposition until y is assigned.

  • ¬∃!xP(x) means zero or at least two values satisfy P, not exactly one value satisfies ¬P.

1.7 Proof methods: direct, indirect and by contradiction

A proof is a chain of statements that turns what is given into what must be shown. The same claim may be proved by several routes: direct proof starts from the hypothesis; indirect proof uses the contrapositive; contradiction assumes the opposite. Choosing the route matters because one method can shorten a long calculation to two lines. You use these methods in algorithm correctness, safety arguments for software, and rules for money transfers.

You need: 1.1, 1.2 for implication and contrapositive, and 1.6 for quantifiers.

Direct proof

A direct proof of an implication P → Q starts by assuming P is true and ends by showing Q is true. Each line follows from earlier lines, a definition, or algebra. Definitions are the fuel. An integer n is even when n = 2k for some integer k. It is odd when n = 2k + 1 for some integer k. A real number r is rational when r = a/b with integers a and b and b ≠ 0.

  1. State the claim and the method: direct proof.
  2. Write the hypothesis using a definition and a new integer symbol.
  3. Substitute and simplify with algebra.
  4. End in the exact form required by the conclusion.

The figure proves n odd → n² odd. Assume n = 2k + 1 with k an integer. Squaring gives n² = 4k² + 4k + 1. Group the first two terms: n² = 2(2k² + 2k) + 1. The bracket is an integer because k is an integer. Thus n² has the form 2m + 1 with m = 2k² + 2k, so n² is odd.

Indirect proof: contrapositive and contradiction

To prove P → Q by contrapositive, prove ¬Q → ¬P instead. The two implications have the same truth value, so one proof gives the other. Some syllabi call indirect proof the contrapositive method; others also use “indirect” for contradiction. Check the wording in the question. Example: if n² is even then n is even. The contrapositive is: if n is odd then n² is odd. The direct proof above proves that contrapositive, so the original claim follows.

P → Q ≡ ¬Q → ¬P

P and Q are propositions; ¬ means not, → means implies, and ≡ means both sides have the same truth value.

To prove P → Q by contradiction, assume P ∧ ¬Q and derive a contradiction R ∧ ¬R for some statement R. Do not assume only ¬Q; the hypothesis P must be kept. To prove a statement P alone by contradiction, assume ¬P and derive a contradiction. The contradiction must be explicit: a statement and its negation, not just a calculation that looks wrong.

Existence, counterexamples and proof writing

An existence proof proves ∃x P(x). A constructive proof gives a value or a rule for x. A nonconstructive proof shows that at least one x must exist, often by contradiction. A counterexample is one object a in the universe with P(a) false; it disproves ∀x P(x). For example, “every prime integer is odd” is false because 2 is prime and even.

A proof written for marks states the method first. It names each definition, introduces every symbol, and keeps the universe of discourse visible. It ends with the exact claim. Statements over all natural numbers often need induction, covered in 1.8; divisibility proofs belong to Unit 4.

  • To prove P → Q directly: assume P, derive Q.
  • To prove P → Q by contrapositive: assume ¬Q, derive ¬P.
  • To prove P → Q by contradiction: assume P ∧ ¬Q, derive R ∧ ¬R.
  • To disprove ∀x P(x): give one counterexample a with P(a) false.

Worked example

Question. Question (5 marks). Prove directly that if n is an odd integer, then n² is odd. Then apply the proof to n = 7: write n = 2k + 1, compute n², and give the integer m with n² = 2m + 1.

  1. Assume n is odd. By definition n = 2k + 1 for some integer k.
  2. Square: n² = (2k + 1)² = 4k² + 4k + 1.
  3. Regroup: n² = 2(2k² + 2k) + 1.
  4. The number m = 2k² + 2k is an integer, so n² = 2m + 1; hence n² is odd.
  5. For n = 7, solve 7 = 2k + 1, so k = 3.
  6. Then n² = 49. Also m = 2(3²) + 2(3) = 18 + 6 = 24, and 2(24) + 1 = 49.
  7. The proof is complete and the check values are k = 3, n² = 49, m = 24.

Exam traps

  • In a contradiction proof of P → Q, assume P ∧ ¬Q, not only ¬Q. Dropping P proves a different statement.
  • The contrapositive of P → Q is ¬Q → ¬P. The converse Q → P is not equivalent, so it cannot replace the original.
  • One example cannot prove a universal claim; it can only disprove it. To disprove ∀x P(x), one counterexample is enough.
  • In an existence proof, say whether it is constructive or nonconstructive. A formula for x is stronger than “some x exists.”
  • Check the universe. A claim true for all integers may fail for all real numbers; the domain is part of the statement.

1.8 Mathematical induction, strong induction and Peano axioms

Mathematical induction proves an infinite family of statements P(n) with two checks: a base case and a step that carries truth from one case to the next. It exists because no one can verify infinitely many cases one by one. Think of falling dominoes: push the first, and each falling domino pushes the next. It is used for sums, inequalities, divisibility, loop invariants and recurrence bounds. The principle, strong form, well-ordering link and Peano axioms are below.

You need: proof methods and quantifiers from Chapter 1.7 and Chapter 1.6.

The principle of mathematical induction

Let P(n) be a statement about an integer n. Fix a starting integer n₀. The principle says: if (1) P(n₀) is true, and (2) for every integer k ≥ n₀, P(k) true implies P(k+1) true, then P(n) is true for every integer n ≥ n₀.

The base step proves P(n₀). The inductive step is an implication, not an assumption that P(k) is true for all k. You assume P(k) for one arbitrary k ≥ n₀, called the inductive hypothesis, and derive P(k+1).

Some syllabi start at n=1, others at n=0. Always state n₀ and use it in both places. The base case must lie in the range where P(n) is asserted or defined. If the claim is only stated for n≥3, use n₀=3. If P(1) is defined and the inductive step is proved for all k≥1, starting at 1 is valid, though stronger than needed.

Induction does not guess the formula; it verifies a formula you already have. The odd-number sum in the figure shows the mechanism: prove P(1), assume the sum to 2k−1 is k², add the next odd term 2k+1, and factor to (k+1)².

Strong induction and well-ordering

Strong induction changes only the hypothesis. To prove P(k+1), assume P(n₀), P(n₀+1), …, P(k) are all true. This is not a stronger theorem; weak and strong induction prove the same statements. Strong induction is convenient when P(k+1) depends on a smaller case not equal to k, such as factoring an integer or splitting a recurrence.

For example, every integer n≥2 is prime or a product of primes. If n is not prime, write n=ab with 2≤a,b<n; strong induction applies to a and b, and multiplying their prime factorisations gives one for n.

The well-ordering principle says every nonempty set of nonnegative integers has a least element. It is equivalent to induction. One common proof assumes n₀≥0; if n₀<0, replace P(n) by Q(t)=P(t+n₀) with t≥0. Suppose P(n) fails for some n≥n₀. The set of counterexamples n≥n₀ has a least element m. Since m≥n₀, either m=n₀ or m>n₀. If m=n₀, the base step is contradicted. If m>n₀, then m−1≥n₀ and P(m−1) is true, and the inductive step gives P(m), again a contradiction.

Divisibility claims fit induction. To prove 3 divides n³−n for every n≥0: base n=0 gives 0=3×0. Assume k³−k=3m for some integer m. Then (k+1)³−(k+1)=k³+3k²+3k+1−k−1=(k³−k)+3(k²+k)=3(m+k²+k), which is divisible by 3. Hence the claim holds for all n≥0.

Peano axioms and the formal natural numbers

The Peano axioms define the natural numbers from two ideas: a starting object 0 and a successor function S. The usual list says: 0 is a natural number; every natural number n has a successor S(n); no successor equals 0; if S(m)=S(n) then m=n; and if a set contains 0 and contains S(n) whenever it contains n, then it contains every natural number.

The last axiom is induction in set form. Addition and multiplication are defined recursively, for example m+0=m and m+S(n)=S(m+n). Induction then proves their usual laws, such as associativity and distributivity. In this course we use the everyday natural numbers and apply the induction principle to P(n); the Peano list explains why that principle is accepted as part of the definition.

Worked example

Question. Prove by induction that 1+3+5+…+(2n−1)=n² for every integer n≥1. Then check the claim numerically at n=1 and at k=3 by adding the next odd term.

  1. Let P(n) be the statement 1+3+5+…+(2n−1)=n².
  2. Base step, n=1: the left side has only the term 2×1−1=1. The right side is 1²=1. So P(1) is true.
  3. Inductive hypothesis: assume P(k) is true for some integer k≥1, that is 1+3+…+(2k−1)=k².
  4. We must prove P(k+1). The next odd term is 2(k+1)−1=2k+1. Add it to both sides: 1+3+…+(2k−1)+(2k+1)=k²+(2k+1).
  5. Factor the right side: k²+2k+1=(k+1)². The left side is now the sum of odd terms up to 2(k+1)−1, so P(k+1) is true.
  6. By the principle of mathematical induction, P(n) is true for every n≥1.
  7. Numeric check at n=1: left side=1, right side=1²=1.
  8. Numeric check at k=3: 1+3+5=9=3². The next odd term is 2×4−1=7. Adding gives 9+7=16=4².

Answer. The identity holds for every integer n≥1; the numeric checks give 1=1, 9=9 and 16=16.

Exam traps

  • A proof with only the inductive step is incomplete. The implication P(k)→P(k+1) can be true while P(n) is false for every n; without a true base case nothing starts.
  • In weak induction assume P(k) only. Assuming P(k+1), or assuming the result for all n, is circular.
  • The base case must lie in the range where P(n) is asserted or defined, and the step range must match. If the claim is only stated for n≥3, use n₀=3; if P(1) is defined and the step covers k≥1, starting at 1 is valid, though stronger than needed.
  • When adding the next term, use P(k+1) minus P(k), not a guessed term. For sums of odd numbers the next term is 2k+1, not 2k−1.
  • Divisibility proofs must show an integer multiple, for example 3(m+k²+k), not just that the expression looks divisible.

Understand Why is the inductive step written as P(k)→P(k+1) and not as “P(k) is true for all k”? 3 marks

The step proves an implication for one arbitrary k≥n₀. It does not assume the result for every k; that would be circular. The base case supplies the first true case, and the implication carries truth forward.

Apply Use induction to prove 1+2+…+n = n(n+1)/2 for every integer n≥1. 4 marks

Base n=1: left side 1, right side 1×2/2=1. Assume 1+2+…+k=k(k+1)/2. Add k+1: k(k+1)/2+(k+1)=(k+1)(k+2)/2, which is the formula for k+1. Hence true for all n≥1.

Apply Prove 2ⁿ ≥ n+1 for every integer n≥0. 4 marks

Base n=0: 2⁰=1 and 0+1=1, so 1≥1. Assume 2^k≥k+1. Then 2^(k+1)=2×2^k≥2(k+1)=2k+2. Since k≥0, 2k+2≥k+2. Thus 2^(k+1)≥(k+1)+1.

Analyze Explain when strong induction is preferable to weak induction, and state the hypothesis difference. 5 marks

Strong induction assumes P(n₀), P(n₀+1), …, P(k) to prove P(k+1). It is preferable when P(k+1) depends on several smaller cases, such as factorisation into primes. Weak induction assumes only P(k). Both principles prove the same statements.

Analyze A student proves P(n): 1+3+…+(2n−1)=n² by saying “assume P(k), add 2k+1, factor”. The base n=1 is missing. Is the proof valid? What exactly is missing? 5 marks

The proof is not valid. The inductive step is present, but no case is known to be true. The missing base step must show P(1): 1=1².

Understand Write the Peano induction axiom and explain how it relates to the base and inductive step. 3 marks

If a set contains 0 and contains S(n) whenever it contains n, then it contains every natural number. This is the set form: containing 0 is the base, and closure under successor is the inductive step.

Apply Prove 3 divides n³−n for every integer n≥0. 5 marks

Base n=0: 0³−0=0=3×0. Assume k³−k=3m. Then (k+1)³−(k+1)=(k³−k)+3(k²+k)=3(m+k²+k). So the claim holds for k+1, and by induction for all n≥0.

1.9 Resolution in propositional and predicate logic

Resolution is a single proof rule for clauses. A clause is a disjunction of literals. To prove a goal, you negate it, add that clause to the premises, and resolve until the empty clause □ appears. □ is false, so the clause set is unsatisfiable and the goal follows. Only a few universities teach this in the first logic unit, but SAT solvers, Prolog-style systems and program verifiers use it.

You need: CNF from 1.3, and predicates and quantifiers from 1.6.

Clauses, CNF and the resolution rule

A literal is an atom p or its negation ¬p. A clause is a disjunction of literals, such as p∨¬q∨r. CNF (conjunctive normal form) is a conjunction of clauses. Resolution uses two clauses that contain complementary literals p and ¬p. Delete both and take the union of what remains.

(C ∨ p), (D ∨ ¬p) ⟹ (C ∨ D)

C and D are clauses, possibly empty; p is an atom; ⟹ here means 'resolves to': the right side is the resolvent of the two left clauses. The symbol ⊢ is kept for derivability, as in P ⊢ G.

If C and D are empty, the result is □. The rule is sound: if both parent clauses are true, the resolvent is true.

  1. Convert every premise and the negated goal ¬G to CNF.
  2. Write the clause set; remove duplicate literals and duplicate clauses.
  3. Resolve two clauses with complementary literals.
  4. Add the resolvent; repeat.
  5. Stop at □. If no new clause appears, no proof exists.

Resolution proves G from premises P when P plus ¬G gives □. This is proof by contradiction; see 1.7.

Predicate logic: substitution, unification, Skolemization

Predicate clauses contain terms. First rename bound variables so no two quantifiers use the same variable name; this is 'renaming apart'. Then remove quantifiers in this order: Skolemize ∃ while the quantifier prefix is still visible, then drop the remaining ∀ quantifiers. For ∃y: if no ∀ surrounds it, replace y by a Skolem constant a; if ∀x surrounds it, replace y by a Skolem function f(x) of every enclosing ∀ variable. For example, ∀x∃y Loves(x,y): ∃y sits under ∀x, so y becomes f(x), giving Loves(x,f(x)). Do not use one constant for y: the loved person may depend on x, and f(x) records that dependency. Only after Skolemization do you drop ∀x, leaving Loves(x,f(x)).

Resolution then needs unification: a substitution θ makes two atoms identical. Before unifying, rename the variables of one parent clause so the two clauses share no variable names; then unify. From {P(x), Q(x)} and {¬P(a)} use θ={x/a}; the resolvent is {Q(a)}. Apply θ to every remaining literal. In propositional logic, unification is trivial; in predicate logic it is the extra step.

Full unification algorithms and completeness proofs are left to advanced courses.

Worked example

Question. Use resolution to prove q from the premises p∨q and ¬p. Show the clause form and every resolvent.

  1. The premises p∨q and ¬p are already clauses: {p,q} and {¬p}.
  2. The goal is q. Negate it: ¬q. Add the clause {¬q}.
  3. Resolve {p,q} with {¬p} on p. Remove p and ¬p. The resolvent is {q}.
  4. Resolve {q} with {¬q} on q. Remove q and ¬q. No literals remain, so the resolvent is □.
  5. □ means {p∨q, ¬p, ¬q} is unsatisfiable. Therefore p∨q and ¬p entail q.

Answer. The empty clause □ is derived, so q is proved from p∨q and ¬p.

Exam traps

  • Do not resolve an implication directly. Convert p→q to ¬p∨q first, then resolve.
  • Resolution proves by refutation: negate the goal and add it as a clause. Forgetting ¬G gives no empty clause.
  • The resolvent keeps all remaining literals. Resolving {p,q} with {¬p,q} gives {q}, not □.
  • In predicate logic, unify before resolving. A wrong substitution such as {x/a} when atoms need {x/f(a)} gives an invalid resolvent.
  • □ is false, not a normal clause. It signals a contradiction, so the original clause set is unsatisfiable.

The complementary pair p and ¬p is removed. The literal q remains in both parents, so the resolvent is {q}. □ appears only when no literals remain.

The witness y may depend on x. A single constant fixes one person for all x, which is stronger than the premise. f(x) keeps the dependency and preserves satisfiability.

Takeaways

  1. A proposition has a truth value; connectives build bigger formulas whose values are read off a truth table.
  2. Tautologies are the valid formulas, and every law of logic is the statement that some pair of formulas is equivalent.
  3. An implication and its contrapositive say the same thing; the converse and inverse do not.
  4. Any formula has a unique PDNF and PCNF up to ordering, and these are read directly from the truth table.
  5. An argument is valid when its premises imply its conclusion; the truth of the conclusion alone never makes an argument valid.
  6. Premises are consistent when some single assignment makes them all true; an inconsistent premise set implies anything.
  7. Quantifiers turn predicates into propositions, and ∀ and ∃ obey De Morgan-style negation laws.
  8. Direct, contrapositive, contradiction and induction are routes to the same claim; choose the one that gives you the easiest algebra.
  9. Induction needs both the base case and the step; a missing or wrong base case breaks the whole proof.
  10. Resolution finishes a proof by deriving the empty clause from the negated claim written in clause form.

Glossary

Base case
The first value of n for which an induction proof checks P(n) directly.
Biconditional
p ↔ q, true when p and q have the same truth value.
Clause
A disjunction of literals; a formula in clause form is a conjunction of clauses, the input to resolution.
Conjunction
p ∧ q, true only when both p and q are true.
Connective
A symbol such as ¬, ∧, ∨, →, ↔ that joins one or two propositions into a new proposition.
Contrapositive
The implication ¬q → ¬p, logically equivalent to p → q.
Counterexample
A single case in which the claim fails, enough to disprove a universal statement.
De Morgan's laws
¬(p ∧ q) ⇔ ¬p ∨ ¬q and ¬(p ∨ q) ⇔ ¬p ∧ ¬q.
Disjunction
p ∨ q, true when at least one of p and q is true; in logic it is inclusive unless stated otherwise.
Disjunctive syllogism
From p ∨ q and ¬p, infer q.
Empty clause
The clause with no literals, always false; deriving it in resolution proves the clause set unsatisfiable.
Free variable
A variable in a predicate that is not bound by any quantifier, so the formula is not yet a proposition.
Hypothetical syllogism
From p → q and q → r, infer p → r.
Implication
p → q, false only in the single case where p is true and q is false.
Maxterm
A disjunction containing each variable exactly once, plain or negated; it is false in exactly one row.
Minterm
A conjunction containing each variable of the formula exactly once, either plain or negated; it is true in exactly one row of the truth table.
Modus ponens
From p and p → q, infer q.
Modus tollens
From ¬q and p → q, infer ¬p.
Negation
¬p, the proposition that is true exactly when p is false.
Peano axioms
The standard axioms for the natural numbers, including a successor function and the induction axiom schema.
Resolvent
The clause (A ∨ B) obtained by resolving (A ∨ p) with (B ∨ ¬p).
Strong induction
A variant where the step assumes P(m) for all m ≤ k, not just P(k), to prove P(k+1).
Universal generalization
From P(c) for an arbitrary element c, infer ∀x P(x).
Universal instantiation
From ∀x P(x), infer P(c) for a particular element c of the universe.
Vacuous proof
A proof of p → q that shows p is false, so the implication is true regardless of q.
Well-formed formula
A formula built from variables, connectives and brackets by the syntax rules, so it has an unambiguous truth table.
