4.1 Semigroups and monoids

Multiply two powers of 2 and you land on another power of 2. That small fact carries this whole chapter: a set with an operation that never leaves the set, and that lets you regroup brackets without changing the answer. Add a do-nothing element and you have a monoid — the shape behind string building, matrix products and log buffers in code. Groups, the next step, demand one thing more: inverses.

You need: sets, subsets and function composition from Unit 2, Sets, Relations and Functions, plus the number systems ℕ, ℤ, ℚ and ℝ.

Binary operations, closure and associativity

A binary operation ∗ on a set S is a rule that takes an ordered pair (a, b) of elements of S and returns exactly one element, written a ∗ b. Some books build closure into the definition by saying ∗ is a function from S × S to S; others state closure as a separate law. Both mean the same thing here: the answer must stay inside S.

Closure: for every a, b in S, the result a ∗ b also lies in S. On the positive integers ℤ⁺ = {1, 2, 3, …}, addition is closed, because a sum of two positive integers is positive. Subtraction is not closed: 3 − 5 = −2, and −2 is not in ℤ⁺. Division is not closed on ℤ either: 3 ÷ 5 = 0.6.

Associativity: (a ∗ b) ∗ c = a ∗ (b ∗ c) for all a, b, c in S. Subtraction fails it: (5 − 3) − 1 = 1, while 5 − (3 − 1) = 3. Matrix multiplication is associative, and so is composition of functions.

(a ∗ b) ∗ c = a ∗ (b ∗ c)

a, b, c are any elements of the set S; ∗ is the binary operation on S.

Associativity lets you drop brackets: a ∗ b ∗ c is one well-defined element. Commutativity is a separate question. Matrix multiplication is associative but not commutative: for A = [[1,1],[0,1]] and B = [[1,0],[1,1]], AB = [[2,1],[1,1]] while BA = [[1,1],[1,2]].

Semigroups

A semigroup is a pair (S, ∗) where ∗ is a binary operation on S that is closed and associative. Nothing more is demanded: no identity element, no inverses. Some syllabi spell it 'semi-group'.

  • (ℤ⁺, +): a sum of two positive integers is positive, and addition is associative. There is no identity, because 0 is not in ℤ⁺. This is a semigroup and not a monoid.
  • (Σ⁺, concatenation): Σ is an alphabet, say {a, b}, and Σ⁺ is the set of all non-empty strings over Σ. Joining two non-empty strings gives a non-empty string, and concatenation is associative.
  • (M₂(ℝ), ×): the 2 × 2 matrices with real entries. The product of two of them is again a 2 × 2 matrix with real entries, and matrix multiplication is associative.

The order of the pair matters: set first, operation second. Change the operation and the answer changes. (ℤ⁺, +) is a semigroup, but (ℤ⁺, −) is not even closed, and (ℤ, −) is closed yet not associative, so neither is a semigroup.

Monoids, identity and submonoids

An identity element of (S, ∗) is an element e in S with e ∗ a = a ∗ e = a for every a in S. A monoid is a semigroup that has an identity. Some books write 'semigroup with identity' instead of monoid.

The identity is unique. Suppose e and f are both identities. Then e = e ∗ f, because f is an identity, and e ∗ f = f, because e is an identity. So e = f. A commutative monoid is a monoid whose operation is also commutative.

  • (ℕ₀, +) with ℕ₀ = {0, 1, 2, …}: identity 0, since 0 + a = a + 0 = a. Commutative monoid.
  • (Σ*, concatenation): all strings including the empty string ε. εw = wε = w, so ε is the identity. This monoid is called the free monoid on Σ.
  • (M₂(ℝ), ×): identity is I = [[1,0],[0,1]]. Matrix product is not commutative, so this is a monoid but not a commutative monoid.
  • (ℤ, ×): identity 1. The element 0 has no inverse, and a monoid is allowed to have such elements.

A submonoid is a subset T of a monoid (M, ∗) such that the identity e of M lies in T and T is closed under ∗. For example, the even numbers {0, 2, 4, …} form a submonoid of (ℕ₀, +): 0 is even, and a sum of two even numbers is even. Groups need one more axiom; see 4.2 Groups and subgroups.

Worked example

Question. Let M = {1, 2, 4, 8, 16, …} = {2ⁿ | n ≥ 0} under ordinary multiplication. Show that M is a monoid but not a group. Use a = 3 and b = 5 to check closure.

  1. List the set: M = {2⁰, 2¹, 2², …} = {1, 2, 4, 8, 16, …}. Every element is 2ⁿ with n a non-negative integer.
  2. Closure: take 2ᵃ and 2ᵇ in M, so a ≥ 0 and b ≥ 0. Then 2ᵃ · 2ᵇ = 2ᵃ⁺ᵇ, and a + b ≥ 0, so the product is in M. Numerically with a = 3, b = 5: 2³ = 8 and 2⁵ = 32, and 8 × 32 = 256 = 2⁸, which is in M.
  3. Associativity: multiplication of real numbers is associative, and M sits inside ℝ, so (2ᵃ · 2ᵇ) · 2ᶜ = 2ᵃ · (2ᵇ · 2ᶜ).
  4. Identity: 1 = 2⁰ is in M, and 1 · 2ᵃ = 2ᵃ · 1 = 2ᵃ for every a ≥ 0. So 1 is the identity.
  5. M is a semigroup with identity, hence a monoid. It is also commutative, since 2ᵃ · 2ᵇ = 2ᵃ⁺ᵇ = 2ᵇ⁺ᵃ = 2ᵇ · 2ᵃ, so it is a commutative monoid.
  6. Inverse test: an inverse of 2 inside M would be an element x in M with 2 · x = 1, so x = 1/2 = 0.5. But every element 2ⁿ with n ≥ 0 satisfies 2ⁿ ≥ 1, so 0.5 is not in M.
  7. The element 2 therefore has no inverse in M, so M fails the group axiom that every element is invertible.

Exam traps

  • Checking only closure and associativity. A monoid also needs an identity. (ℤ⁺, +) is closed and associative but is only a semigroup, because 0 is missing.
  • Putting the identity outside the set. The even positive integers {2, 4, 6, …} under multiplication are closed and associative, but 1 is not in the set, so there is no monoid.
  • Forgetting the empty string. Σ* with concatenation is a monoid with identity ε; drop ε and Σ⁺ is only a semigroup.
  • Mixing up associative and commutative. Matrix multiplication is the standard counterexample: associative, not commutative.
  • Calling every monoid a group. A monoid may contain elements with no inverse, like 2 in the powers of 2, or 0 in (ℤ, ×).

4.2 Groups and subgroups

A group is a set with one operation that combines any two elements to a third, is associative, has an identity, and gives every element an inverse. It exists because many systems — integers under addition, non-zero fractions under multiplication, clock arithmetic, rotations of a square — obey the same four rules. Once the rules are proved, one theorem works for all of them. Groups model error-correcting codes, cryptography, symmetry in chemistry and physics, and state machines in software. A subgroup is a smaller group sitting inside a group under the same operation.

You need: 4.1 Semigroups and monoids for closure, associativity and identity, and Unit 2, Sets, Relations and Functions for subsets and set notation.

Group axioms and order

A group (G, ∗) is a set G with a binary operation ∗: G×G→G. Compared with a monoid from 4.1, a group adds one demand: every element has an inverse. Four axioms hold. Closure: a,b∈G implies a∗b∈G. Associativity: (a∗b)∗c = a∗(b∗c). Identity: an element e∈G satisfies e∗a = a∗e = a. Inverse: each a∈G has a⁻¹∈G with a∗a⁻¹ = a⁻¹∗a = e.

The order of G, written |G|, is the number of elements. G is abelian if a∗b = b∗a for all a,b∈G. The pair (G,∗) names the set and the operation; a set may be a group under one operation and not another.

  • (Z, +): integers under addition; identity 0; inverse of n is −n; infinite; abelian.
  • (Q, +): fractions under addition; identity 0; inverse of p/q is −p/q; infinite; abelian.
  • (Q\{0}, ×): non-zero fractions under multiplication; identity 1; inverse of p/q is q/p; zero is removed because 0 has no multiplicative inverse.
  • Zₙ under addition modulo n: residues {0,1,…,n−1}; identity 0; inverse of a is −a mod n; |Zₙ|=n; abelian. For n=8, G=Z₈={0,1,2,3,4,5,6,7}.
  • Symmetry groups: rotations of a square form a group of order 4; all eight rotations and reflections form the dihedral group of order 8. The operation is composition of motions.

Subgroups and the subgroup tests

A subgroup H of (G,∗) is a nonempty subset H⊆G that is itself a group under the same operation ∗. Its identity must be the identity e of G; its inverses are the inverses in G. Every group has the trivial subgroup {e} and the improper subgroup G. A proper subgroup is any subgroup other than G. Some syllabi write 'sub-group'.

  1. Two-step test. H is nonempty. Closure: for all a,b∈H, a∗b∈H. Inverse: for all a∈H, a⁻¹∈H. Associativity is inherited from G, and the identity appears because a∗a⁻¹=e for any a∈H.
  2. One-step test. H is nonempty. For all a,b∈H, a∗b⁻¹∈H. Put b=a to get e; put a=e to get b⁻¹; then a∗b∈H follows.

If H and K are subgroups of G, then H∩K is a subgroup. It contains e, so it is nonempty. If a,b∈H∩K, then a,b∈H and a,b∈K; closure in H and K gives a∗b∈H∩K; inverse in H and K gives a⁻¹∈H∩K. This uses the two-step test.

Why the tests are enough

Associativity is never checked inside H. For a,b,c∈H, the equation (a∗b)∗c = a∗(b∗c) is already true in G, and H uses the same operation. Closure keeps a∗b inside H, so the inherited equation stays inside H.

The identity is forced by nonemptiness plus inverse. Pick any a∈H. The inverse condition gives a⁻¹∈H, and closure gives a∗a⁻¹=e∈H. For every h∈H, e∗h=h∗e=h, so e is the identity of H.

The one-step test a∗b⁻¹∈H packs closure and inverse into one condition. Nonemptiness is still required; the empty set would pass the condition vacuously.

Worked example

Question. Let G = Z₈ = {0,1,2,3,4,5,6,7} under addition modulo 8. Show that H = {0,4} is a subgroup. List every subgroup of G. State |G|, |H| and the number of subgroups.

  1. The operation is addition modulo 8: a+b is reduced by subtracting 8 when the sum is at least 8.
  2. Nonempty: H has two elements, 0 and 4.
  3. Closure: compute all four sums. 0+0=0, 0+4=4, 4+0=4, 4+4=8≡0 (mod 8). Each result is in H.
  4. Identity: 0∈H; for every h∈H, h+0=h.
  5. Inverses: −0=0∈H. −4≡8−4=4 (mod 8)∈H. Every element has its inverse in H.
  6. Associativity is inherited from Z₈. H is a subgroup. |G|=8 and |H|=2.
  7. Subgroups: {0} of order 1, {0,4} of order 2, {0,2,4,6} of order 4, and G=Z₈ of order 8. These are all: any subgroup containing 1,3,5 or 7 is G; containing 2 but not 1 gives even residues; containing 4 gives {0,4}; otherwise {0}.

Exam traps

  • Checking closure alone. In (Z,+), the non-negative integers are closed and contain 0, but 1 has no inverse, so they are not a subgroup.
  • Using a different identity. The identity of H must be the identity e of G, not a new element invented for H.
  • Forgetting nonemptiness. The empty set satisfies closure and inverse conditions vacuously but is not a subgroup.
  • Mixing operations. A subset may be a group under a different operation; a subgroup must use the same operation as G.
  • Assuming a union of subgroups is a subgroup. Closure can fail; H∪K is not automatically a subgroup. The intersection H∩K always is.

4.3 Cyclic groups, permutation groups and Cayley's theorem

A cyclic group is built from one element: every element is a power of that generator. Every cyclic group is isomorphic to Z or to Zn; these two families are the complete list. This makes modular arithmetic easy to reason about. Cayley's theorem goes further: every group, however abstract, is isomorphic to a group of permutations. The proof uses left multiplication, Lₐ(g)=a·g. These ideas appear in symmetry, coding theory, cryptography and the group algorithms inside computer algebra systems.

You need: groups and subgroups from 4.2; permutations from Unit 3; bijections from Unit 2.

Cyclic groups and generators

Take a group G with identity e. The order of G, written |G|, is its number of elements. The order of an element a, written ord(a), is the smallest positive integer n with an=e. If no positive n has an = e, then a has infinite order and we write ord(a) = ∞. In additive notation this is n·a=0. The cyclic subgroup generated by a is ⟨a⟩={ak : k∈Z}. If G=⟨a⟩, then G is cyclic and a is a generator. Z under addition is cyclic with generator 1. Zn under addition modulo n is cyclic with generator 1. A finite cyclic group of order n is isomorphic to Zn; an infinite cyclic group is isomorphic to Z. Every subgroup of a cyclic group is cyclic: a subgroup of ⟨a⟩ is ⟨am⟩ for some integer m. Example: in Z6, ⟨2⟩={0,2,4}, so ord(2)=3. The group has order 6, the element has order 3. Do not mix these two numbers.

ord(a) = min{ n ≥ 1 : an = e }

ord(a) is the order of the element a; e is the identity of G; n is a positive integer.

Permutation groups and cycle notation

Fix a set X with n elements. A permutation of X is a bijection X→X. The set of all permutations of X under composition is the symmetric group Sn. It has n! elements. Write a cycle (a1 a2 ... ak) for the permutation sending a1→a2, ..., ak→a1, and fixing other points. Disjoint cycles commute, and every permutation is a product of disjoint cycles. A transposition is a 2-cycle (a b). Every cycle is a product of transpositions: (a1 ... ak)=(a1 ak)...(a1 a2). A permutation is even if it is a product of an even number of transpositions, odd otherwise. Parity is well defined. For n ≥ 2, the even permutations form the alternating group An, a subgroup of Sn with n!/2 elements. In S3, (1 2 3) is even and (1 2) is odd.

Cayley's theorem

Cayley's theorem: every group G is isomorphic to a permutation group. For each a∈G define left multiplication La:G→G by La(g)=a·g. First La is a bijection: its inverse is La-1, because La-1(La(g)) = a-1(a·g) = (a-1a)g = e·g = g. So La is a permutation of the set G. Define φ:G→SG by φ(a)=La. For a,b,g∈G, φ(ab)(g)=(ab)g=a(bg)=φ(a)(φ(b)(g)). Thus φ(ab)=φ(a)∘φ(b), so φ is a homomorphism. If φ(a)=φ(b), then La(e)=Lb(e), so a=b. Thus φ is injective. Therefore G is isomorphic to the image φ(G), which is a subgroup of SG. If |G|=n, then SG is Sn. Some syllabi state the theorem as: every group is isomorphic to a permutation group. The image need not be all of Sn. For Z3 the image has 3 permutations inside S3, which has 6.

φ(ab) = φ(a) ∘ φ(b), φ(a)(g) = a·g

φ maps each a in G to the permutation L_a; ∘ is composition; e is the identity; S_G is the permutation group of the set G.

Worked example

Question. Let G=Z₃={0,1,2} under addition modulo 3. (a) Write L₀,L₁,L₂ as permutations of {0,1,2}. (b) Verify Cayley's theorem for G. (c) Find ⟨1⟩ and ord(1).

  1. Use L_a(g)=a+g mod 3.
  2. L₀: 0→0, 1→1, 2→2, so L₀=(0)(1)(2).
  3. L₁: 0→1, 1→2, 2→0, so L₁=(0 1 2).
  4. L₂: 0→2, 1→0, 2→1, so L₂=(0 2 1).
  5. The three permutations are distinct, so the map a↦L_a is injective. Check one product: L₁∘L₂ sends 0→0, 1→1, 2→2, so L₁∘L₂=L₀=L_{1+2}. Hence it is a homomorphism.
  6. Thus G≅{L₀,L₁,L₂}≤S₃. The image has 3 elements; S₃ has 6.
  7. ⟨1⟩={0,1,2}: starting at 0, adding 1 gives 1, then 2, then 0. So ⟨1⟩=G and ord(1)=3.

Answer. L₀=(0)(1)(2), L₁=(0 1 2), L₂=(0 2 1); G is isomorphic to {L₀,L₁,L₂}≤S₃; ⟨1⟩=Z₃ and ord(1)=3.

Exam traps

  • |G| is the number of elements, while ord(a) is the least positive n with an=e. In Z6, |G|=6 but ord(2)=3.
  • Cayley's theorem says G is isomorphic to a permutation group, not that G is cyclic and not that the image is all of Sn.
  • In additive groups an exponent means repeated addition: an becomes n·a, and an=e becomes n·a=0.
  • Order matters: La(g)=a·g is left multiplication. For nonabelian groups, right multiplication Ra(g)=g·a is a different map.
  • Do not call every permutation a transposition; transpositions are only 2-cycles, and parity counts transpositions, not cycles.

4.4 Cosets and Lagrange's theorem

A subgroup H sits inside a group G. Fix an element a and multiply every element of H by a; the result aH is a left coset. Cosets are equal-sized blocks that split G without overlap. Lagrange's theorem states that for a finite group, |H| divides |G|. This one counting fact controls possible subgroup sizes and element orders. It is used in modular arithmetic, cryptography, error-correcting codes and in proving that groups of prime order are cyclic.

You need groups and subgroups and cyclic groups; equivalence classes from Unit 2 are the model for the partition proof.

Left cosets, right cosets and index

Let (G, ·) be a group with identity e, and let H ≤ G be a subgroup. For a ∈ G, the left coset of H by a is aH = {a h : h ∈ H}. The right coset is Ha = {h a : h ∈ H}. In an abelian group the two are equal. In Z₈ under addition, take H = {0,4}. The left cosets are 0+H = {0,4}, 1+H = {1,5}, 2+H = {2,6}, 3+H = {3,7}. The coset 4+H equals {4,0}, which is 0+H, so it is not new.

The index of H in G, written [G:H], is the number of distinct left cosets. Here [Z₈:H] = 4. Every a lies in its own coset aH because e ∈ H. The coset aH is a subgroup exactly when a ∈ H; otherwise it does not contain e. For example, 1+H = {1,5} is not a subgroup of Z₈.

aH = bH ⇔ a⁻¹b ∈ H

aH and bH are left cosets of H in G; a,b ∈ G; a⁻¹ is the inverse of a; e is the identity.

Cosets partition the group

Define a relation on G by a ~ b when a⁻¹b ∈ H. This is an equivalence relation. Reflexive: a⁻¹a = e ∈ H. Symmetric: if a⁻¹b ∈ H, then (a⁻¹b)⁻¹ = b⁻¹a ∈ H. Transitive: if a⁻¹b ∈ H and b⁻¹c ∈ H, then a⁻¹c = (a⁻¹b)(b⁻¹c) ∈ H, because H is closed. The equivalence class of a is {b : a⁻¹b ∈ H}. The condition a⁻¹b ∈ H is the same as b = a h for some h ∈ H, so the class is exactly aH.

Two cosets are either identical or disjoint. If c ∈ aH ∩ bH, then c = a h₁ = b h₂ for some h₁,h₂ ∈ H. So a⁻¹b = h₁ h₂⁻¹ ∈ H, and the equality test gives aH = bH. Therefore the distinct left cosets form a partition of G.

The map h ↦ a h is a bijection from H to aH. Its inverse is x ↦ a⁻¹x. Hence every coset has the same size as H: |aH| = |H|. This holds for finite groups as an equality of counts. The same proof works for right cosets.

Lagrange's theorem and consequences

|G| = [G:H] · |H|

G is a finite group, H ≤ G, [G:H] is the index, |H| is the number of elements in H.

Proof: the distinct left cosets partition G. If there are k = [G:H] cosets and each has |H| elements, then |G| = k |H|. Thus |H| divides |G|. For Z₈ and H={0,4}, |G|=8, |H|=2 and [G:H]=4, so 8 = 4·2.

For any g ∈ G, the subgroup ⟨g⟩ generated by g has order equal to the order of g. Here ord(g), the order of g, is the smallest positive integer n with gⁿ = e (written n·g = 0 in additive notation). By Lagrange, ord(g) divides |G|. So g^{|G|} = e. In additive notation, |G|·g = 0. Example: in Z₈, ord(2)=4 and ord(3)=8; both divide 8.

If |G| = p is prime, any nonidentity g has a subgroup ⟨g⟩ whose order is greater than 1 and divides p. The only possibility is p, so ⟨g⟩ = G and G is cyclic. In the symmetric group S₃ on {1,2,3}, |S₃|=6. For H={e,(12)}, |H|=2, so any left coset has 2 elements and the index is 3. One left coset is (13)H = {(13),(123)}. The right coset H(13) = {(13),(132)} is different, so aH need not equal Ha.

Exam traps

  • aH = Ha is not automatic. It holds for every a exactly when H is normal. In S₃ with H={e,(12)}, (13)H ≠ H(13).
  • A coset is not usually a subgroup. aH contains e only when a ∈ H; otherwise it is just a translate of H.
  • Use the correct equality test: aH=bH iff a⁻¹b∈H, while Ha=Hb iff ab⁻¹∈H. Mixing the inverse order is a common error.
  • Lagrange says |H| divides |G| for a subgroup H. The converse is false: a divisor of |G| need not be the order of a subgroup. Also, Lagrange applies only to finite groups.
  • Do not count repeated cosets: [G:H] is the number of distinct cosets, not |G|.

4.5 Normal subgroups and group homomorphisms

A group homomorphism is a function between groups that respects the operation: f(ab)=f(a)f(b). Its kernel collects the elements sent to the identity. Kernels are always normal subgroups: for H=ker f, gHg⁻¹=H for every g ∈ G. So the cosets of the kernel form a quotient group. The first isomorphism theorem says the quotient by the kernel is isomorphic to the image. This idea is used to compare groups, prove non-isomorphism, and reduce questions about a group to smaller quotient groups.

You need: groups and subgroups from 4.2, cosets and Lagrange from 4.4, and functions from Unit 2.

Homomorphisms and their basic properties

Let G and G′ be groups, with identities e and e′. A group homomorphism is a function f: G → G′ such that f(ab)=f(a)f(b) for all a,b in G. Here ab is the product in G, while f(a)f(b) is the product in G′. The order of the factors matters: in a non-abelian group ab and ba can be different. Two consequences follow from the definition. First, f(e)=e′: apply f to ee=e and cancel f(e). Second, f(a⁻¹)=f(a)⁻¹: apply f to aa⁻¹=e. These are not extra axioms; they are derived. The kernel is ker f = {g ∈ G : f(g)=e′}. The image is im f = {f(g) : g ∈ G}. The kernel measures what f collapses to the identity; the image is the part of G′ actually reached. A bijective homomorphism is an isomorphism. Isomorphic groups have the same group-theoretic structure.

Normal subgroups and quotient groups

Fix a subgroup H of G. H is normal if gHg⁻¹=H for every g ∈ G, where gHg⁻¹ = {ghg⁻¹ : h ∈ H}. Equivalently, gH=Hg for every g: left cosets and right cosets agree as sets. The kernel of any homomorphism f: G→G′ is normal. Proof: take k ∈ ker f and g ∈ G. Then f(gkg⁻¹)=f(g)f(k)f(g⁻¹)=f(g)e′f(g)⁻¹=e′, so gkg⁻¹ ∈ ker f. Thus g(ker f)g⁻¹ ⊆ ker f; replacing g by g⁻¹ gives equality. When H is normal, the set G/H of cosets becomes a group under (aH)(bH)=abH. The identity is H, and the inverse of aH is a⁻¹H. Well-definedness needs normality: if aH=a′H and bH=b′H, then a′b′H=abH. The group G/H is the quotient group. When G is additive, such as Z, we write cosets as r+6Z and the operation as (r+6Z)+(s+6Z)=(r+s)+6Z; this is the same coset construction as aH above. Its order is [G:H], the index of H, and |G|=|H|[G:H] when G is finite.

First isomorphism theorem and examples

First isomorphism theorem. Let f: G→G′ be a homomorphism. Then G/ker f ≅ im f. The isomorphism is φ: G/ker f → im f, φ(g ker f)=f(g). It is well-defined because if g ker f = g′ ker f, then g′⁻¹g ∈ ker f, so f(g′)=f(g). It is a homomorphism because φ((a ker f)(b ker f))=φ(ab ker f)=f(ab)=f(a)f(b). It is injective: φ(g ker f)=e′ means g ∈ ker f, so g ker f = ker f. It is surjective onto im f by definition. Example 1: f: Z→Zₙ, f(m)=m mod n. The kernel is nZ={…,−n,0,n,2n,…}; the image is Zₙ; so Z/nZ ≅ Zₙ. Example 2: the sign map sgn: Sₙ→{1,−1} for n≥2. Here Sₙ is the group of all permutations of n symbols under composition, and sign(σ)=+1 for even permutations and −1 for odd permutations. It is a homomorphism because sign(στ)=sign(σ)sign(τ). The kernel is the alternating group Aₙ, and Sₙ/Aₙ ≅ {1,−1}. The quotient has two cosets, Aₙ and the odd permutations.

  • Treating f(e)=e′ and f(a⁻¹)=f(a)⁻¹ as extra axioms. They follow from f(ab)=f(a)f(b); still check them in calculations.

4.6 Divisibility, primes, GCD and Euclidean algorithm

Divisibility is the arithmetic of remainders: a divides b when b = a·k for some integer k. Primes are the integers that cannot be split this way, and every integer is built from them. The greatest common divisor measures what two integers share; the Euclidean algorithm finds it by repeated division instead of factoring. These ideas sit behind fraction reduction, error-checking codes, RSA keys and hashing. The core results are the basic divisibility rules, the infinitude of primes, and gcd(252,105) by hand and by the extended algorithm.

You need: basic integer arithmetic and proof by contradiction (see Unit 1, Proof methods: direct, indirect and by contradiction).

Divisibility and its basic rules

For integers a and b, write a|b (read “a divides b”) when b = a·k for some integer k. Here a is a divisor of b, and b is a multiple of a. For example, 3|12 because 12 = 3·4, while 5∤12. For a ≠ 0, a|0 because 0 = a·0. Do not confuse a|b with the fraction a/b.

  • If a|b and b|c, then a|c. Proof: b = ak and c = bm, so c = a(km).
  • If a|b and a|c, then a|(bx + cy) for all integers x and y. Proof: b = ak and c = al, so bx + cy = a(kx + ly).
  • If a|b, then a|bc for every integer c. Proof: if b = ak, then bc = a(kc), so a|bc.
  • If a|b and b|a with a and b nonzero, then a = ±b. Proof: b = ak and a = bl, so a = a(kl); hence kl = 1, so k = l = 1 or k = l = −1.

Primes, unique factorization and counting primes

A prime is an integer p > 1 whose only positive divisors are 1 and p. A composite is an integer n > 1 that is not prime. The number 1 is neither prime nor composite. The only even prime is 2.

The fundamental theorem of arithmetic says every integer n > 1 has a prime factorization n = p₁e₁p₂e₂…pᵣeᵣ, with primes pᵢ and positive integer exponents eᵢ. The factorization is unique up to the order of the factors. For example, 252 = 2²·3²·7 and 105 = 3·5·7.

Suppose there are finitely many primes p₁, p₂, …, pₖ. Let N = p₁p₂…pₖ + 1. N > 1. Each pᵢ divides the product p₁p₂…pₖ, so pᵢ does not divide N, because N leaves remainder 1 on division by pᵢ. Thus N has no prime factor from the list. But N is either prime itself or has a prime factor. Either way there is a prime outside the list, contradicting the assumption. Hence infinitely many primes exist.

Let π(n) be the number of primes ≤ n. The prime number theorem states π(n) ~ n/ln n; the ratio π(n)/(n/ln n) tends to 1 as n grows. Here ln is the natural logarithm. For n = 10, π(10) = 4 (the primes 2, 3, 5, 7), close to 10/ln 10 ≈ 4.34.

GCD, LCM and prime factorization

For integers a and b, not both zero, gcd(a,b) is the largest positive integer d with d|a and d|b. For nonzero integers a and b, lcm(a,b) is the smallest positive integer m with a|m and b|m. Example: gcd(252,105) = 21 and lcm(252,105) = 1260. Note that lcm(0,b) is not defined, which is why the product formula is restricted to nonzero a and b.

Prime factorization gives both values at once. Write each integer as a product of prime powers, using exponent 0 for a prime that is missing. For each prime p, let α be its exponent in a and β its exponent in b. Then gcd uses pmin(α,β) and lcm uses pmax(α,β).

gcd(a,b)·lcm(a,b) = |ab|

a and b are nonzero integers; |ab| is the absolute value of their product.

Why: for each prime p, the exponents min(α,β) and max(α,β) add to α + β. The product on the left therefore has the same prime exponents as |ab|. This formula fails if one number is zero, so use it for nonzero integers. For 252 = 2²·3²·7 and 105 = 3·5·7: gcd = 3·7 = 21; lcm = 2²·3²·5·7 = 1260.

Euclidean algorithm, extended algorithm and Bezout

The division algorithm says that for an integer a and an integer b > 0, there are unique integers q and r with a = qb + r and 0 ≤ r < b. Here q is the quotient and r is the remainder. If b > 0, then gcd(a,b) = gcd(b,r).

Reason: any common divisor of a and b divides r = a − qb, so it divides b and r. Conversely, any common divisor of b and r divides a = qb + r, so it divides a and b. The two pairs have exactly the same common divisors, hence the same gcd.

Repeat the division with (b,r) until the remainder is 0. The remainders strictly decrease: r < b, then the next remainder is less than r, and so on. The process must stop. The last nonzero remainder is gcd(a,b). This is the Euclidean algorithm; some syllabi call it the repeated-division method.

The extended Euclidean algorithm also back-substitutes each remainder as a combination of the previous two numbers. It produces integers x and y with ax + by = gcd(a,b). Bezout's theorem states that such integers x and y always exist for integers a and b not both zero. The next chapter, modular arithmetic, uses this to invert numbers modulo n.

Worked example

Question. Use the Euclidean algorithm to find gcd(252,105). Then write 21 as a linear combination of 252 and 105, and verify the combination.

  1. Divide 252 by 105: 252 = 2·105 + 42. Remainder 42.
  2. Divide 105 by 42: 105 = 2·42 + 21. Remainder 21.
  3. Divide 42 by 21: 42 = 2·21 + 0. Remainder 0, so stop.
  4. The last nonzero remainder is 21, so gcd(252,105) = 21.
  5. Back-substitute: 21 = 105 − 2·42.
  6. Replace 42 = 252 − 2·105: 21 = 105 − 2(252 − 2·105) = 105 − 2·252 + 4·105 = 5·105 − 2·252.
  7. Thus 21 = (−2)·252 + 5·105. Check: (−2)·252 + 5·105 = −504 + 525 = 21.

Answer. gcd(252,105) = 21, and 21 = (−2)·252 + 5·105.

  • Calling 1 a prime. By definition a prime must exceed 1; 1 is neither prime nor composite.
  • Sign errors in back substitution. Check the final Bezout form by substituting the numbers.
  • Using gcd(a,b)·lcm(a,b) = ab without absolute value or with zero; use |ab| and nonzero a,b.
  • Swapping min and max exponents: gcd takes the smaller exponent, lcm takes the larger.

4.7 Modular arithmetic, congruences and Chinese remainder theorem

Modular arithmetic keeps only the remainder after division by a fixed positive integer n. Two integers with the same remainder are called congruent. This turns the infinite integers into n residue classes, a finite set written Zn. The Chinese remainder theorem goes the other way: several congruences with coprime moduli combine into one congruence modulo their product. These ideas appear in clock arithmetic, check digits, hash tables, and in the arithmetic behind UPI references and digital signatures.

You need: 4.6 Divisibility, primes, GCD and Euclidean algorithm for gcd and the extended Euclidean method, and equivalence classes from Unit 2.

Congruence and the residue classes

Fix a positive integer n, called the modulus. We say a ≡ b (mod n) when n divides a − b. For example, 23 ≡ 2 (mod 3), because 3 divides 21. The remainder of a on division by n is the unique r with 0 ≤ r < n and a ≡ r (mod n).

a ≡ b (mod n) ⇔ n | (a − b)

a and b are integers; n is the positive modulus; | means divides.

The residue class of a modulo n is [a]n = {a + kn : k ∈ Z}. There are exactly n classes, [0]n through [n−1]n. Their set is Zn. Addition and multiplication on classes are defined by [a]+[b]=[a+b] and [a][b]=[ab]. These operations are well defined: changing a or b by a multiple of n changes the answer by a multiple of n. For example, in Z12, [10]+[5]=[15]=[3], which is clock arithmetic: 10 o'clock plus 5 hours is 3 o'clock.

Under addition, Zn is a cyclic group of order n (see 4.3). Under multiplication it is not a group: [0] has no inverse, and [2] has no inverse modulo 4. The invertible classes are those [a] with gcd(a,n)=1.

Linear congruences and modular inverses

A linear congruence has the form ax ≡ b (mod n). Here a and b are integers and x is the unknown class modulo n. Let d = gcd(a,n). The congruence has a solution if and only if d divides b. When it has solutions, there are exactly d different solutions modulo n.

Case d=1. Then a has an inverse modulo n: a number a−1 with aa−1 ≡ 1 (mod n). Multiply both sides by a−1 to get the unique solution x ≡ a−1b (mod n). The extended Euclidean algorithm finds this inverse. Run it on a and n to get integers s,t with as + nt = 1. Then s ≡ a−1 (mod n). For example, 3x ≡ 1 (mod 7). The algorithm gives 3·5 + 7·(−2) = 1, so 3−1 ≡ 5 (mod 7). Then 3x ≡ 2 (mod 7) has x ≡ 5·2 = 10 ≡ 3 (mod 7).

Case d>1 and d divides b. Divide the congruence and the modulus by d: (a/d)x ≡ (b/d) (mod n/d). Now gcd(a/d,n/d)=1, so solve as above. The single solution modulo n/d gives d solutions modulo n, namely x0, x0 + n/d, ..., x0 + (d−1)n/d. Example: 6x ≡ 4 (mod 8). Here d=2, and 2 divides 4. Divide by 2: 3x ≡ 2 (mod 4). Since 3−1 ≡ 3 (mod 4), x ≡ 6 ≡ 2 (mod 4). Modulo 8 the solutions are x ≡ 2 and x ≡ 6.

Chinese remainder theorem and number-theory theorems

The Chinese remainder theorem (CRT) solves simultaneous congruences. Let n1, n2, ..., nk be positive integers that are pairwise coprime: gcd(ni,nj)=1 for i≠j. Let N=n1n2...nk. The system x ≡ a1 (mod n1), ..., x ≡ ak (mod nk) has exactly one solution modulo N. If the moduli are not pairwise coprime, the theorem does not apply directly; the system may have no solution or a solution modulo a smaller number, depending on compatibility.

To solve by hand, combine two congruences at a time. Write the first as x = a1 + n1t. Put it into the second, solve for t modulo n2, and substitute back. The result is one congruence modulo n1n2. Repeat with the next congruence. The worked example below uses this method.

Euler's totient φ(n) counts the integers k with 1 ≤ k ≤ n and gcd(k,n)=1. For a prime p, φ(p)=p−1. For distinct primes p,q, φ(pq)=(p−1)(q−1). For example, φ(10)=4, counting 1,3,7,9.

Wilson's theorem: if p is prime, then (p−1)! ≡ −1 (mod p). For p=5, 4! = 24 ≡ 4 ≡ −1 (mod 5).

Euler's totient theorem: if gcd(a,n)=1, then aφ(n) ≡ 1 (mod n). Fermat's little theorem is the prime case: if p is prime and p does not divide a, then ap−1 ≡ 1 (mod p). For example, φ(10)=4 and 34=81≡1 (mod 10); and modulo 7, 26=64≡1 (mod 7).

Worked example

Question. Solve the system x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7). Give the general solution and the least non-negative solution.

  1. Combine the first two congruences. Write x = 2 + 3t with t an integer.
  2. Put this into x ≡ 3 (mod 5): 2 + 3t ≡ 3 (mod 5), so 3t ≡ 1 (mod 5).
  3. The inverse of 3 modulo 5 is 2, because 3·2 = 6 ≡ 1 (mod 5). So t ≡ 2 (mod 5).
  4. Write t = 2 + 5s. Then x = 2 + 3(2 + 5s) = 8 + 15s. Thus x ≡ 8 (mod 15).
  5. Now put x = 8 + 15s into x ≡ 2 (mod 7): 8 + 15s ≡ 2 (mod 7).
  6. Reduce modulo 7: 8 ≡ 1 and 15 ≡ 1, so 1 + s ≡ 2 (mod 7). Hence s ≡ 1 (mod 7).
  7. Write s = 1 + 7r. Then x = 8 + 15(1 + 7r) = 23 + 105r.
  8. The general solution is x ≡ 23 (mod 105). The least non-negative solution is 23.
  9. Check: 23 mod 3 = 2, 23 mod 5 = 3, and 23 mod 7 = 2.

Answer. The solution is x ≡ 23 (mod 105); the least non-negative solution is 23.

Exam traps

  • Do not apply the Chinese remainder theorem unless the moduli are pairwise coprime. If they are not, check compatibility first. For example, x ≡ 1 (mod 4) and x ≡ 2 (mod 6) has no solution because modulo 2 it demands x odd and x even.
  • A congruence ax ≡ b (mod n) may have solutions even when gcd(a,n) ≠ 1. It is solvable exactly when gcd(a,n) divides b; do not declare it impossible just because a has no inverse.
  • When gcd(a,n)=d divides b, the number of solutions modulo n is d, not 1. After dividing by d, the modulus becomes n/d, and then you lift back to d classes modulo n.
  • Fermat's little theorem needs a prime modulus p and p not dividing a. Euler's theorem needs gcd(a,n)=1. Applying either without its condition gives wrong answers.
  • An inverse from the extended Euclidean algorithm may be negative. Reduce it modulo n to the range 0 to n−1 before using it in the final answer.

Beyond the syllabus

Not for the exam. The Chinese remainder theorem is used to speed up big-integer arithmetic by splitting numbers into residues modulo several coprime primes. RSA and other public-key systems rely on modular exponentiation, Euler's theorem and modular inverses. Hash tables and error-detecting codes use remainders and congruence checks. Takeaways

  1. A semigroup only needs closure and associativity; adding an identity gives a monoid, and adding inverses too gives a group.
  2. Groups describe symmetry: every group is a set of reversible actions that can be composed and undone.
  3. A cyclic group is the simplest group — one element builds everything, and ℤₙ under addition is the standard model.
  4. Cayley's theorem removes the mystery from abstract groups: each one is just a group of permutations in disguise.
  5. Cosets cut a group into equal disjoint blocks, and that is exactly why Lagrange's theorem works.
  6. Lagrange's theorem gives a fast test: a subset of size that does not divide |G| can never be a subgroup.
  7. Normal subgroups are the ones whose cosets can be multiplied together, so they are the ones that give quotient groups.
  8. The Euclidean algorithm finds gcd(a, b) in very few steps, and the same steps give the integers x, y with ax + by = gcd(a, b).
  9. Congruence modulo n is an equivalence relation, so modular arithmetic works with classes instead of numbers.
  10. The Chinese remainder theorem turns one hard congruence modulo a big number into several easy ones modulo coprime factors.

Exam question bank

Long answers in this unit usually ask for a full proof — closure and associativity checked term by term, a coset or subgroup computation shown in full, or a Euclidean-algorithm run with every division written out.

Remember and understand

Understand Define a binary operation, a semigroup, a monoid and a group. Give one example of each, and one example of a semigroup that is not a monoid. 10 marks

Binary operation on S is a map S × S → S, written a∗b; Semigroup: closure plus associativity (a∗b)∗c = a∗(b∗c); Monoid: semigroup plus identity e with e∗a = a∗e = a; Group: monoid plus inverse a⁻¹ for every element; Examples: positive integers under addition form a semigroup but have no identity, so not a monoid; (ℕ₀, +) is a monoid but not a group; (ℤ, +) is a group.

Understand State Lagrange's theorem. Using it, prove that in a finite group the order of every element divides the order of the group. 10 marks

Statement: if H ≤ G and |G| is finite then |H| divides |G|; The order of an element a is the order of the cyclic subgroup ⟨a⟩; ⟨a⟩ is a subgroup, so its order divides |G| by Lagrange; Conclude a^|G| = e for every a, with proof of why a^k = e exactly for multiples of the order.

Understand State and prove Cayley's theorem, and write down the permutation of the four elements of ℤ₄ given by addition of 1. 13 marks

Statement: every group G is isomorphic to a subgroup of the permutation group on the set G; For each a ∈ G define the map φ_a : G → G by φ_a(x) = a∗x; Show φ_a is a bijection: injective from left cancellation, surjective because x = a∗(a⁻¹∗x); Show the map a ↦ φ_a is a homomorphism and has trivial kernel; Example: on ℤ₄, adding 1 gives the 4-cycle (0 1 2 3).

Understand Define a normal subgroup and a group homomorphism. Prove that the kernel of a group homomorphism is a normal subgroup. 12 marks

Definitions of normal subgroup (g h g⁻¹ ∈ H) and of homomorphism φ(a∗b) = φ(a)∗′φ(b); ker φ is nonempty because φ(e) = e′; Closure: φ(a∗b⁻¹) = φ(a)∗′(φ(b))⁻¹ = e′, so ab⁻¹ ∈ ker φ; Normality: φ(g h g⁻¹) = φ(g)e′φ(g)⁻¹ = e′ for h ∈ ker φ; Hence ker φ ⊲ G, and φ is one-one iff ker φ = {e}.

Apply

Apply Use the Euclidean algorithm to find gcd(1001, 429) and write it in the form 1001a + 429b. State the value of a and b. 8 marks

1001 = 2·429 + 143; 429 = 3·143 + 0, so gcd = 143; Back-substitute: 143 = 1001 − 2·429; Check: 143 divides both numbers and no larger common divisor exists; Answer a = 1, b = −2.

Apply List all subgroups of ℤ₁₂ and, for H = {0, 4, 8}, write all cosets in ℤ₁₂. Verify Lagrange's theorem for this H. 10 marks

Subgroups correspond to divisors of 12: orders 1, 2, 3, 4, 6, 12; ⟨4⟩ = {0, 4, 8} has order 3; Cosets: 0 + H = {0, 4, 8}, 1 + H = {1, 5, 9}, 2 + H = {2, 6, 10}, 3 + H = {3, 7, 11}; The four cosets are disjoint and cover ℤ₁₂; Index is 4 = 12 ÷ 3, matching Lagrange's theorem.

Apply Find all solutions of the simultaneous congruences x ≡ 1 (mod 3), x ≡ 2 (mod 5), x ≡ 3 (mod 7) using the Chinese remainder theorem. 10 marks

Moduli 3, 5, 7 are pairwise coprime, so a unique solution exists modulo 105; Build x = 1·M₁·y₁ + 2·M₂·y₂ + 3·M₃·y₃ with M₁ = 35, M₂ = 21, M₃ = 15; Find the inverses: y₁ = 2 (35·2 ≡ 1 mod 3), y₂ = 1 (21 ≡ 1 mod 5), y₃ = 1 (15 ≡ 1 mod 7); x = 70 + 42 + 45 = 157 ≡ 52 (mod 105); Verify 52 satisfies all three congruences.

Apply Show that the set of units modulo 9 forms a group under multiplication modulo 9, find the order of each element, and decide whether the group is cyclic. 10 marks

Units U(9) = {1, 2, 4, 5, 7, 8}; an element is a unit iff gcd(a, 9) = 1; Closure, associativity inherited from ℤ, identity 1, each element self-inverse or paired: 2·5 ≡ 1, 4·7 ≡ 1, 8·8 ≡ 1; Orders: 1 has order 1; 8 has order 2; 2, 4, 5, 7 have order 6; Powers of 2: 2, 4, 8, 7, 5, 1, so ⟨2⟩ = U(9) and the group is cyclic; Number of generators is φ(6) = 2, namely 2 and 5.

Apply Prove that congruence modulo n is an equivalence relation on ℤ, list the residue classes modulo 5, and find the inverse of 3 modulo 7. 10 marks

Reflexive: n divides a − a; symmetric: sign change; transitive: n divides the sum of two multiples of n; Classes: [0], [1], [2], [3], [4], each an infinite arithmetic progression with common difference 5; The classes are disjoint and cover ℤ; Inverse of 3 mod 7: solve 3x ≡ 1 (mod 7), giving x ≡ 5 since 15 ≡ 1; The inverse exists because gcd(3, 7) = 1.

Analyze and evaluate

Analyze Prove that every group of prime order is cyclic, and classify all groups of order 4 up to isomorphism. 13 marks

Take a ≠ e in G of prime order p; the subgroup ⟨a⟩ has order dividing p and greater than 1, so it is p; Hence G = ⟨a⟩ and G ≅ ℤ_p; For order 4: if some element has order 4 the group is ℤ₄; Otherwise every non-identity element has order 2, so the group is abelian and is the Klein four-group V₄; ℤ₄ and V₄ are not isomorphic because ℤ₄ has an element of order 3? — no: because ℤ₄ has an element of order 4 and V₄ has none.

Analyze Let H be a subgroup of G. Prove that H is normal if and only if every left coset of H equals the corresponding right coset, and use this to build the quotient group ℤ/nℤ. 13 marks

H normal means g h g⁻¹ ∈ H for all g, h; This is equivalent to gH ⊆ Hg, and applying it to g⁻¹ gives the reverse inclusion; Coset multiplication (aH)(bH) = abH is well defined exactly when H is normal; check it does not depend on representatives; In the abelian group ℤ every subgroup nℤ is normal, so the cosets form ℤ/nℤ; ℤ/nℤ has n elements and addition is carried out modulo n.

Evaluate Prove that every finite cyclic group of order n is isomorphic to ℤₙ under addition, and count the generators of ℤ₁₂. 12 marks

Let G = ⟨a⟩ with aⁿ = e; define φ : ℤₙ → G by φ(k) = aᵏ; φ is well defined because aᵏ depends only on k mod n; φ is a homomorphism: φ(j + k) = a^{j+k} = aʲaᵏ; φ is onto by definition of cyclic and one-one because the powers a⁰, …, a^{n−1} are distinct; Generators of ℤ₁₂ are the classes coprime to 12: 1, 5, 7, 11, so φ(12) = 4.

Evaluate State the fundamental theorem of arithmetic. Use it to find gcd(720, 1350) and lcm(720, 1350), then compare the work with the Euclidean algorithm. 13 marks

Statement: every integer greater than 1 is a product of primes, unique up to order; 720 = 2⁴ · 3² · 5 and 1350 = 2 · 3³ · 5²; gcd takes the smaller exponent of each prime: 2 · 3² · 5 = 90; lcm takes the larger exponent: 2⁴ · 3³ · 5² = 10800; Check gcd × lcm = 720 × 1350; the Euclidean algorithm needs no factorisation and is faster for large numbers.

Evaluate Using Lagrange's theorem, prove Fermat's little theorem, and apply it to compute 3¹⁰⁰ mod 7. 12 marks

The nonzero classes modulo p form a group of order p − 1 under multiplication; The class of a has order dividing p − 1, so a^{p−1} ≡ 1 (mod p) when p does not divide a; For p = 7: 3⁶ ≡ 1 (mod 7); 100 = 6·16 + 4, so 3¹⁰⁰ ≡ 3⁴ = 81 ≡ 4 (mod 7); Check the exponent reduction is valid because the powers repeat with period dividing 6.

Glossary

Abelian group
A group in which a∗b = b∗a for all elements; named after Niels Henrik Abel.
Associativity
The law (a∗b)∗c = a∗(b∗c), which lets us drop brackets when combining three or more elements.
Binary operation
A rule that assigns to each ordered pair (a, b) of elements of a set S exactly one element a∗b of S.
Bézout identity
For integers a and b there exist integers x and y with ax + by = gcd(a, b).
Chinese remainder theorem
A system of congruences with pairwise coprime moduli has a unique solution modulo the product of the moduli.
Closure
A property of a subset or set: applying the operation to two members always gives a member of the same set.
Coset
A translate aH = {a∗h : h ∈ H} or Ha = {h∗a : h ∈ H} of a subgroup H.
Cyclic group
A group in which every element is a power of a single element.
Divisibility
a divides b, written a | b, when b = ak for some integer k.
Greatest common divisor
gcd(a, b) is the largest positive integer dividing both a and b; it is 1 when a and b are coprime.
Group
A set with an associative operation, an identity, and an inverse for each element.
Homomorphism
A map between groups that preserves the operation: φ(a∗b) = φ(a)∗′φ(b).
Index of a subgroup
The number [G : H] of distinct cosets of H in G.
Isomorphism
A bijective homomorphism; two groups related by one are structurally the same.
Kernel
The set of elements a homomorphism sends to the identity; it measures how far the map is from being one-one.
Monoid
A semigroup with an identity element.
Normal subgroup
A subgroup H with gHg⁻¹ = H for every g in G, so that its cosets form a group.
Order of an element
The smallest positive integer k with aᵏ = e; it equals the order of the subgroup ⟨a⟩.
Permutation
A bijection from a finite set to itself, usually written in two-line or cycle notation.
Quotient group
G/H, the group of cosets of a normal subgroup H, with multiplication (aH)(bH) = abH.
Residue class
The set [a] = {a + kn : k ∈ ℤ} of all integers congruent to a modulo n.
Semigroup
A set with a closed associative binary operation.
Subgroup
A nonempty subset H of a group G closed under the operation and under taking inverses.
Symmetric group
The group Sₙ of all permutations of n symbols under composition, with order n!.
