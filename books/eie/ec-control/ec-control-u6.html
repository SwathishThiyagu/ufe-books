6.1 State, state variables and state model

A system's future depends on a small set of present numbers: the state. Stack them into a column vector x, and the dynamics become ẋ = Ax + Bu, y = Cx + Du. This form handles many inputs and outputs, suits computer control, and fits biomedical models such as lung mechanics and blood glucose regulation.

You need first-order differential equations and the transfer function idea from Unit 1, Modelling of Physical Systems.

State, state variables, state vector

The state at time t₀ is the smallest set of numbers that, with the input from t₀ onwards, fixes the whole future. Once known, the past stops mattering.

Each number is a state variable x₁, x₂, …, xₙ. The count n is the order. Stacked in a column they form the state vector x = [x₁ x₂ … xₙ]ᵀ; ᵀ means transpose.

Example: a 12 V battery charging an RC circuit has capacitor voltage as its state. A car on the Chennai bypass has position and velocity, order 2.

For a physical system, independent energy storage fixes n: each independent capacitor voltage or inductor current adds one. A mass–spring–damper adds one for position and one for velocity.

State variables are a choice. Position in metres plus velocity, or position plus momentum, both work for the same car. The physics stays; the numbers change.

The state model in matrix form

Write the state model for n states, m inputs and p outputs.

ẋ = Ax + Bu , y = Cx + Du

ẋ = dx/dt is the n×1 derivative of the state vector; x is n×1; u is the m×1 input vector; y is the p×1 output vector; A is n×n, B is n×m, C is p×n, D is p×m.

MatrixSizeWhat it carries
An × ninternal dynamics, how states drive each other
Bn × mhow each input pushes each state
Cp × nwhich mix of states is measured
Dp × mdirect input-to-output feedthrough

A is the system matrix. Its eigenvalues are the poles when the model is minimal, that is, when no mode is hidden from the input or the output. B is the input matrix. C is the output matrix. D is usually zero, because a real output rarely follows an input instantly.

Integrator picture: ẋ passes through n integrators to give x. The integrators are memory. B injects u; A feeds states back; C taps states for y. With u = 0 the loop through A alone decides how the state drifts, which is exactly the free response.

Set m = p = 1 with n = 2: two first-order equations replace one second-order equation. One second-order equation carries two initial conditions; a 2-state model carries the same two.

Phase variables: from a differential equation to a state model

Take y⁽ⁿ⁾ + a₁y⁽ⁿ⁻¹⁾ + … + aₙy = b u, with y the output and u the input. Build the model in five steps.

  1. Isolate the highest derivative: y⁽ⁿ⁾ = −a₁y⁽ⁿ⁻¹⁾ − … − aₙy + b u.
  2. Choose phase variables x₁ = y, x₂ = ẏ, …, xₙ = y⁽ⁿ⁻¹⁾.
  3. Differentiate each: ẋ₁ = x₂, ẋ₂ = x₃, …, ẋₙ₋₁ = xₙ, and ẋₙ = −aₙx₁ − aₙ₋₁x₂ − … − a₁xₙ + b u.
  4. Read A off step 3: ones on the superdiagonal, last row the negatives of the coefficients in reverse order. B is a column of zeros with b at the bottom.
  5. The output is y = x₁, so C = [1 0 … 0] and D = 0.

For n = 2 the matrices are A = [[0, 1], [−a₂, −a₁]], B = [0; b], C = [1 0]. This layout is called the phase-variable form; other layouts are in 6.2.

Check by counting: number of state variables = order = number of independent initial conditions. For a physical circuit that usually equals the number of independent capacitors and inductors; after x̄ = Tx, states may be mixtures with no single storage element behind each.

Where the model is used

Digital control runs on this form. A microcontroller updates x[k+1] = Φx[k] + Γu[k], where Φ = eAT is the state transition matrix over one sample period T and Γ = ∫₀T eAτ dτ B is the input matrix for the sampled input. Both are covered in 6.3.

Biomedical models use the same equations. In a one-compartment lung model the state is lung volume V; flow is an output, V̇ = (P − V/C_L)/R, where P is ventilator pressure, R is airway resistance and C_L is lung compliance. A two-compartment lung carries two volumes. Blood glucose regulation uses two or three compartments — plasma glucose, plasma insulin, insulin action — as states, with a meal as input. These are applications, not new theory.

The solution, the state transition matrix, is in 6.3.

Worked example

Question. A system obeys y'' + 5y' + 6y = 2u, where y is the output and u the input. Using phase variables x₁ = y and x₂ = y', find the matrices A, B, C and D of the state model.

  1. Isolate: y'' = −5y' − 6y + 2u. Here a₁ = 5, a₂ = 6, b = 2.
  2. Choose x₁ = y, x₂ = y'; n = 2.
  3. ẋ₁ = y' = x₂, so first row of A is [0, 1] and first B element is 0.
  4. ẋ₂ = y'' = −6y − 5y' + 2u = −6x₁ − 5x₂ + 2u, so second row of A is [−6, −5] and second B element is 2.
  5. Assemble A = [[0, 1], [−6, −5]] (2×2) and B = [0; 2] (2×1).
  6. y = x₁, so C = [1 0] (1×2) and D = 0 (1×1).
  7. Sizes: n = 2, m = 1, p = 1; A 2×2, B 2×1, C 1×2, D 1×1. All consistent.

Answer. A = [[0, 1], [−6, −5]], B = [0; 2], C = [1 0], D = 0.

Exam traps

  • Sign slip in A: the last row holds −a₂ and −a₁. y'' + 5y' + 6y = 2u gives −6 and −5, never +6 or +5.
  • B is a column for one input (n×1), not a row. B = [0 2] is 1×2 and breaks Ax + Bu.
  • State variables are not unique. Any invertible T gives x̄ = Tx and changes A, B, C while the system stays the same. Check by reproducing the differential equation, not by matching one fixed matrix.
  • D = 0 does not mean delay or first order. It only means no instant feedthrough from input to output.
  • A 3×3 A matrix means a third-order system with three state variables, hence three independent initial conditions. For a physical circuit that usually equals the number of independent capacitors and inductors.

6.2 State models from transfer functions; canonical forms

A transfer function describes input-output behaviour. A state model describes the internal variables that produce that behaviour. Converting one to the other lets you use matrix methods for simulation, feedback and controllability checks. The controllable, observable and diagonal forms are standard arrangements. Each form writes the same G(s) with different A, B, C, D matrices. Use them when a problem gives G(s) and asks for state equations, or when a state model must be checked against a transfer function.

You need: Chapter 6.1 for the state model, Unit 1 for transfer functions, and Unit 3 for the characteristic equation.

Controllable canonical form

Write the denominator as P(s)=sⁿ+aₙ₋₁sⁿ⁻¹+⋯+a₁s+a₀. Write the numerator as N(s)=bₘsᵐ+⋯+b₁s+b₀. The a's and b's are real coefficients. Strictly proper means deg N<deg P, so there is no direct input-output path. If deg N=deg P, divide N by P first: G(s)=d+N₁(s)/P(s). The constant d is the feedthrough term. N₁ has degree at most n−1.

The controllable canonical form uses the denominator coefficients directly. Its states are phase variables: x₁ is the output of the first integrator in a chain, x₂ the second, and so on. Some syllabi call this phase variable form or companion form. For N₁(s)=bₙ₋₁sⁿ⁻¹+⋯+b₁s+b₀ and feedthrough d, the matrices are:

A = [0 1 0 … 0; 0 0 1 … 0; ⋮; −a₀ −a₁ −a₂ … −aₙ₋₁],  B = [0 … 0 1]ᵀ,  C = [b₀ b₁ … bₙ₋₁],  D = d

A is n×n; B is n×1; C is 1×n; D is 1×1; ᵀ means transpose; a_i and b_i are coefficients in ascending powers.

The last row of A carries −a₀,−a₁,...,−aₙ₋₁. The top row is 0 1 0 ... 0. B has a single 1 in the last row. C carries the numerator coefficients b₀,b₁,...,bₙ₋₁ in ascending order. D=d. For a strictly proper system d=0.

Observable and diagonal forms

Observable canonical form is the dual of controllable form. For the same G(s), take A_o=A_cᵀ, B_o=C_cᵀ, C_o=B_cᵀ, D_o=D. The subscript c means the controllable-form matrices. This form makes the output equation carry the state chain; it is useful in observer design. The transfer function is unchanged because the triple is transposed in the standard dual way.

Diagonal form uses partial fractions. For distinct real poles p₁,...,pₙ, write G(s)=d+Σ_{i=1}^{n} r_i/(s−p_i). The residue r_i is the coefficient of 1/(s−p_i). Then A=diag(p₁,...,pₙ), B=[1 … 1]ᵀ, C=[r₁ … rₙ], D=d. In scalar equations, ẋ_i=p_i x_i+u and y=Σ r_i x_i+d u. Each state is decoupled from the others. Complex poles need real 2×2 blocks. Repeated poles need Jordan form; only a few universities teach it.

Recovering the transfer function

Any state model returns to a transfer function by G(s)=C(sI−A)⁻¹B+D. Here I is the n×n identity matrix, s is the Laplace variable, and the matrices have the dimensions of the model. For one input and one output, the product is a scalar rational function. Its denominator is det(sI−A), the characteristic polynomial. Its roots are the eigenvalues of A, so they are the poles of G(s). The numerator comes from C, B and the adjugate of sI−A. Use this formula to check a canonical model.

G(s) = C(sI − A)⁻¹B + D

C is 1×n, A is n×n, B is n×1, D is 1×1, and I is the n×n identity matrix.

The formula also shows why many different A, B, C triples can give the same G(s): the product cancels internal details. The poles are fixed by A, but the zeros also depend on B and C. A quick numerical check at s=0 gives G(0)=−CA⁻¹B+D when A is invertible. At s→∞, G(s)→D. If D≠0, the numerator and denominator degrees are equal; if D=0, the model is strictly proper. See Chapter 6.3 for solving the state equation.

Worked example

Question. For G(s)=(2s+3)/(s²+5s+6), write a controllable canonical state model and recover G(s) from that model.

  1. Compare degrees: deg numerator = 1, deg denominator = 2, so the system is strictly proper and D = 0.
  2. Read denominator s²+5s+6: a₀=6, a₁=5, n=2.
  3. Read numerator 2s+3 in ascending powers: b₀=3, b₁=2.
  4. Fill matrices: A=[[0,1],[−a₀,−a₁]]=[[0,1],[−6,−5]], B=[0;1], C=[b₀,b₁]=[3,2], D=0.
  5. Compute sI−A=[[s,−1],[6,s+5]].
  6. Determinant: det(sI−A)=s(s+5)+6=s²+5s+6.
  7. Inverse times B: (sI−A)⁻¹B=[1; s]/(s²+5s+6).
  8. Multiply C: [3,2]·[1; s]/det=(3+2s)/(s²+5s+6).

Answer. A=[[0,1],[−6,−5]], B=[0;1], C=[3,2], D=0; the recovered transfer function is (2s+3)/(s²+5s+6).

Exam traps

  • Mixing ascending and descending order: in controllable form C carries b₀,b₁,... in ascending powers, not the written numerator order.
  • Sign slip in the last row of A: the entries are −a₀,−a₁,..., not +a₀,+a₁.
  • Putting D nonzero for every proper system: D is nonzero only when numerator and denominator degrees are equal.
  • Using the controllable C and B inside the observable form: the observable form uses transposed dual matrices.
  • Taking numerator coefficients as residues in diagonal form: the residues r_i come from partial fractions, not directly from N(s).

Beyond the syllabus

Not for the exam. State-space models are used in software for controller design, observer design and simulation. Model order reduction keeps the input-output behaviour while shrinking A. Subspace identification builds state models directly from measured data. Search terms: controllable canonical form, observable canonical form, companion matrix, state-space realization.

6.3 Solution of state equations; state transition matrix

A state equation gives the slope of the state vector at every instant. To predict the state later, we need a closed-form map from the present state and past input to the future state. That map is the state transition matrix Φ(t)=eAt. It is used to simulate circuits, motors and drones, to check stability, and to design observers and state feedback. The same formula also turns a matrix differential equation into an ordinary convolution.

You need: Chapter 6.1 for state models, Laplace transforms from mathematics, and see Unit 2, Time Response Analysis, for first-order and second-order responses.

Zero-input and zero-state parts

The state equation is x′(t) = A x(t) + B u(t). Here x is the n×1 state vector, x′ is its time derivative, u is the m×1 input vector, A is the n×n system matrix and B is the n×m input matrix. The initial state is x(0). The equation is linear, so its solution splits into two parts: the part caused by x(0) with u = 0, and the part caused by u with x(0) = 0.

The zero-input part is Φ(t)x(0). Φ(t) is the n×n state transition matrix. It carries the state from time 0 to time t when no input is present. The zero-state part is a convolution of the input with the same matrix: ∫0t Φ(t−τ)B u(τ)dτ. τ is a dummy time variable. B u(τ) is the input vector mapped into state space.

x(t) = Φ(t)x(0) + ∫<sub>0</sub><sup>t</sup> Φ(t − τ) B u(τ) dτ

x(t) is the n×1 state at time t; Φ(t)=eAt is the n×n state transition matrix; x(0) is the initial state; B is the n×m input matrix; u(τ) is the m×1 input at time τ; τ is the integration variable.

For a single-input system B is n×1. For a free system u=0, so x(t)=Φ(t)x(0). If x(0)=0, only the convolution remains. This split is why the matrix exponential is the central object of state-space analysis.

State transition matrix from Laplace

Take the Laplace transform of x′=Ax+Bu term by term. Let X(s) be the transform of x(t) and U(s) the transform of u(t). The derivative rule gives sX(s)−x(0)=A X(s)+B U(s). Collect X(s): (sI−A)X(s)=x(0)+B U(s). I is the n×n identity matrix. Therefore X(s)=(sI−A)−1x(0)+(sI−A)−1B U(s).

The matrix (sI−A)−1 is called the resolvent. Its inverse Laplace transform is Φ(t). So Φ(t)=L−1[(sI−A)−1]. Compare the transformed solution with the time-domain formula. The first term gives Φ(t)x(0). The second term gives the convolution, because a product in the s-domain is a convolution in time. This is the standard route for a 2×2 or 3×3 model.

Φ(t) = e<sup>At</sup> = L<sup>−1</sup>[(sI − A)<sup>−1</sup>]

Φ(t) is the state transition matrix; A is the system matrix; I is the identity matrix; L−1 means inverse Laplace transform; s is the Laplace variable.

  • Φ(0)=I.
  • Φ(t1+t2)=Φ(t1)Φ(t2).
  • Φ−1(t)=Φ(−t).
  • dΦ/dt = AΦ(t)=Φ(t)A.

Computing Φ(t) for a 2×2 A

For a 2×2 matrix A, compute sI−A, its determinant Δ(s), and the inverse. Δ(s) is the characteristic polynomial. Its roots are the eigenvalues λ1 and λ2. They are also the poles of the system. After inverse Laplace, each entry of Φ(t) is a sum of terms eλ1t and eλ2t. If a root repeats, a term t eλt appears.

  1. Write A and form sI−A.
  2. Find det(sI−A)=(s−λ1)(s−λ2).
  3. Use (sI−A)−1=adj(sI−A)/det(sI−A).
  4. Split each entry by partial fractions.
  5. Take inverse Laplace to get Φ(t).

With distinct eigenvalues, an equivalent method is Φ(t)=M diag(eλ1t, eλ2t) M−1. M has eigenvectors of A as columns. The diagonal matrix holds the two modes. This is faster when eigenvectors are easy. Do not exponentiate A entry by entry: eAt is a matrix defined by the series I+At+(At)²/2!+…, not by applying eat to each element.

Some syllabi also use the Cayley–Hamilton series: for 2×2, eAt=α0(t)I+α1(t)A; find α0, α1 from the eigenvalues. Only a few universities teach this in detail.

Worked example

Question. For A = [[0, 1], [−2, −3]], find Φ(t). Then find x(t) for u = 0 and x(0) = [1; 0]. Give the state at t = 0.5 s.

  1. With u=0, the solution is x(t)=Φ(t)x(0). Form sI−A = [[s, −1], [2, s+3]].
  2. The determinant is s(s+3)+2 = s²+3s+2 = (s+1)(s+2). The eigenvalues are −1 and −2.
  3. The inverse is (sI−A)−1 = 1/[(s+1)(s+2)] [[s+3, 1], [−2, s]].
  4. Partial fractions: (s+3)/… = 2/(s+1)−1/(s+2); 1/… = 1/(s+1)−1/(s+2); −2/… = −2/(s+1)+2/(s+2); s/… = −1/(s+1)+2/(s+2).
  5. Inverse Laplace gives Φ(t) = [[2e−t−e−2t, e−t−e−2t], [−2e−t+2e−2t, −e−t+2e−2t]].
  6. Multiply by x(0)=[1; 0]: x(t) = [2e−t−e−2t; −2e−t+2e−2t].
  7. At t = 0.5 s, e−0.5=0.6065306597 and e−1=0.3678794412. Then Φ(0.5) = [[0.8451818783, 0.2386512185], [−0.4773024371, 0.1292282226]] and x(0.5) = [0.8451818783; −0.4773024371].

Answer. Φ(t) = [[2e−t−e−2t, e−t−e−2t], [−2e−t+2e−2t, −e−t+2e−2t]] and x(t) = [2e−t−e−2t; −2e−t+2e−2t]; at t = 0.5 s, Φ(0.5) = [[0.8451818783, 0.2386512185], [−0.4773024371, 0.1292282226]] and x(0.5) = [0.8451818783; −0.4773024371].

Exam traps

  • eAt is not found by taking e to each entry of A. Use (sI−A)−1 or eigenvalues.
  • Sign slip in sI−A: diagonal entries are s−aii, off-diagonal entries are −aij. A missed minus changes the determinant.
  • Do not mix zero-input and zero-state: Φ(t)x(0) uses the initial state; the convolution uses the input. Setting u=0 removes the convolution, not Φ(t)x(0).
  • Φ(0)=I, not A and not the zero matrix. Check every computed Φ(t) at t=0.
  • For repeated eigenvalues, simple eλt terms may not be enough; a t eλt term can appear.

6.4 Controllability and observability

Controllability and observability are two structural questions about a state model. Controllability asks whether the input u can move every state variable. Observability asks whether the output y can reveal every initial state. A system can be stable and still fail either test. The tests use matrix rank: Qc = [B AB ... An−1B] for controllability and Qo = [C; CA; ...; CAn−1] for observability. Engineers use these checks before state feedback, pole placement and state estimation, where an uncontrollable or unobservable state silently blocks the design.

You need: Chapter 6.2 and Chapter 6.3, plus the idea of matrix rank.

Controllability and the Qc rank test

Write a linear time-invariant (LTI) state model as xdot = A x + B u, y = C x + D u. x is the n×1 state vector, u is the m×1 input vector, y is the p×1 output vector, A is n×n, B is n×m, C is p×n and D is p×m. The pair (A, B) is controllable when u can drive x from any initial value to any chosen final value in finite time.

The controllability matrix is Qc = [B AB A²B ... An−1B]. It has n rows and nm columns. Its columns are B, AB, and so on up to n−1 powers of A. Rank means the number of independent rows or columns. The test is rank(Qc) = n. If rank(Qc) < n, some state combination cannot be reached, whatever input is applied.

Q<sub>c</sub> = [B  AB  A<sup>2</sup>B  ...  A<sup>n−1</sup>B],   rank(Q<sub>c</sub>) = n

A is n×n; B is n×m; n is the number of states; m is the number of inputs; rank(Qc) is the number of independent columns of Qc.

  1. Count the states n from A.
  2. Form the n blocks B, AB, ..., An−1B.
  3. Place them side by side as columns of Qc.
  4. Find rank(Qc). Rank n means controllable; rank below n means not controllable.

For one input (m = 1), Qc is square n×n, so det(Qc) ≠ 0 is the quick test. The figure at the end of this chapter shows the two-state model used in the worked example: u enters x2, the states are coupled, and x1 reaches y.

Observability and the Qo rank test

The pair (A, C) is observable when y over a finite time interval is enough to determine the initial state x(0). If two initial states produce the same output for all time, the hidden difference cannot be seen. The output is the only evidence of that hidden state.

The observability matrix stacks rows: Qo = [C; CA; ...; CAn−1]. It has pn rows and n columns, where p is the number of outputs. The test is rank(Qo) = n. If rank(Qo) < n, some state combination cannot be recovered from the output. For one output (p = 1), Qo is square n×n, so det(Qo) ≠ 0 proves observability.

Q<sub>o</sub> = [C; CA; ...; CA<sup>n−1</sup>],   rank(Q<sub>o</sub>) = n

C is p×n; A is n×n; n is the number of states; p is the number of outputs; the semicolons stack rows.

Duality: (A, B) is controllable iff (AT, BT) is observable, with BT as the output matrix. The PBH test checks rank [λI − A B] = n for every eigenvalue λ of A for controllability, and rank [λI − A; C] = n for observability. λ is an eigenvalue of A and I is the n×n identity matrix. Only a few universities teach PBH in detail; the Qc and Qo rank tests are the standard exam route.

Stability does not guarantee controllability

Stability and controllability answer different questions. Stability says a disturbed state returns to rest by itself. Controllability says the input can place the state wherever you want. A stable mode can be completely disconnected from the input, so it decays but cannot be steered.

Example: A = diag(−1, −2), B = [0; 1]. The eigenvalues are −1 and −2, so the system is stable. AB = [0; −2], and Qc = [B AB] = [[0, 0], [1, −2]]. The two columns are proportional; rank(Qc) = 1 < 2. The input moves x2 only. State x1 has no path from u, so it is uncontrollable even though it decays to zero.

The same reading applies to observability. A stable hidden state can fade away, so the output looks well behaved, yet the initial value of that state cannot be recovered. Before pole placement, check Qc; state feedback cannot move an uncontrollable state. Before building an observer, check Qo; an unobservable state cannot be estimated. The next chapter uses these tests directly for state feedback and pole placement.

Worked example

Question. For A = [[0, 1], [−2, −3]], B = [0; 1] and C = [1, 0], use rank tests to decide controllability and observability. Give the determinants.

  1. n = 2. B is the 2×1 column [0; 1].
  2. AB = A B = [[0, 1], [−2, −3]] [0; 1] = [1; −3].
  3. Qc = [B AB] = [[0, 1], [1, −3]]. det(Qc) = (0)(−3) − (1)(1) = −1. Rank(Qc) = 2 = n, so controllable.
  4. CA = C A = [1, 0] [[0, 1], [−2, −3]] = [0, 1].
  5. Qo = [C; CA] = [[1, 0], [0, 1]]. det(Qo) = (1)(1) − (0)(0) = 1. Rank(Qo) = 2 = n, so observable.
  6. Answer: rank(Qc) = 2, rank(Qo) = 2, det(Qc) = −1, det(Qo) = 1.

Answer. The system is controllable (rank Qc = 2) and observable (rank Qo = 2); det Qc = −1 and det Qo = 1.

Exam traps

  • Always form all n blocks before deciding; a single block can prove controllability only in the special case where B alone already has rank n, which is rare.
  • Qc is n×nm, not always square. For m > 1, rank n is the test; determinant exists only for m = 1.
  • Stable does not mean controllable. Diag(−1, −2) with B = [0; 1] is stable but rank Qc = 1 < 2.
  • Qc stacks B, AB, ... as columns. Qo stacks C, CA, ... as rows. Reversing this gives wrong dimensions.
  • Controllability and observability are separate. Duality compares (A, B) with (AT, BT), not with the same system's (A, C).

6.5 State feedback and pole placement

The poles of a system decide how fast it settles and how much it overshoots. In state space you can move those poles to chosen positions, provided the system is controllable. Measure every state, multiply the state vector by a gain row K, and subtract it from the reference: u = r − Kx. The closed-loop matrix becomes A − BK, and its eigenvalues are the new poles. Aircraft autopilots, servo drives and inverted-pendulum rigs use this when a fast, well-damped response is demanded and the states are already on the sensor list.

You need: Chapter 6.4 for the controllability test, Chapter 6.1 for the state model, and Unit 3, Stability and Root Locus, for deciding where the poles should sit.

Close the loop around every state

Output feedback in Unit 5 uses one signal y and one gain. State feedback uses the whole state vector x, an n × 1 column of measured variables, and a gain matrix K. For a single input, K is a 1 × n row of numbers. The control law is u = r − Kx: the scalar input u is the reference r minus the weighted sum Kx of all the states.

Put this law into the state equation x' = Ax + Bu:

x' = Ax + B(r − Kx) = (A − BK)x + Br

x is the n × 1 state vector; A is the n × n plant matrix; B is the n × 1 input matrix; K is the 1 × n gain row; r is the scalar reference; A − BK is the closed-loop matrix; Br acts as the input to the closed loop.

The closed-loop poles are the eigenvalues of A − BK, that is the roots of det(sI − (A − BK)) = 0. Eigenvalues fix the decay rates and the damping, as Chapter 6.3 shows. Choose K and you choose those roots. This is pole placement, also called pole assignment.

Root locus design (Unit 3) also moves poles, but a single scalar gain slides them along fixed paths. K carries n independent numbers, one per state, so all n poles can be steered to chosen places — provided the pair (A, B) is controllable.

Pole placement by matching polynomials

For a single-input system with n states the design is pure algebra, done in five steps.

  1. Test controllability: the matrix Qc = [B AB A²B … An−1B] must have rank n (Chapter 6.4). If it does not, stop; no K exists.
  2. Write the desired polynomial from the target poles p1 to pn: φ(s) = (s − p1)(s − p2) … (s − pn) = sn + an−1sn−1 + … + a0. For a stable design every pi has a negative real part.
  3. Write A − BK with the gains k1, k2, …, kn left as unknowns.
  4. Expand det(sI − (A − BK)) and collect powers of s. Each coefficient is a straight-line expression in the ki.
  5. Equate coefficients with φ(s) from the highest power down. The n linear equations give the n gains.

The coefficient equations are linear, so they have a unique solution exactly when the system is controllable. Complex target poles are allowed; they must appear in conjugate pairs so that K stays real. Placing poles far to the left gives a fast loop but needs large gains and large control effort, which real actuators may not supply.

Ackermann's formula for one input

Matching coefficients by hand is fine for two or three states. For a larger single-input system, one matrix formula does the whole job.

K = [0 0 … 0 1] Q<sub>c</sub><sup>−1</sup> φ(A)

Qc = [B AB … An−1B] is the controllability matrix; φ(A) = An + an−1An−1 + … + a0I is the desired polynomial with the matrix A substituted for s; the row [0 0 … 0 1] picks the last row of Qc−1; K is 1 × n.

The matrix inverse exists only when Qc is nonsingular, which is the controllability test again. The formula assumes one input; with several inputs you solve the coefficient equations and may use the extra freedom for other goals.

Worked example

Question. A plant has A = [[0, 1], [0, 0]] and B = [0, 1]T, with both states available for measurement. The control law is u = r − Kx, where K = [k1 k2]. (a) Check that pole placement is possible. (b) Find K so that the closed-loop poles sit at −2 and −3. (c) Verify the result.

  1. Controllability: AB = A·B = [[0,1],[0,0]]·[0,1]T = [1, 0]T. So Qc = [B AB] = [[0,1],[1,0]]. det Qc = (0)(0) − (1)(1) = −1, which is not zero, so the rank is 2 and the system is controllable. Placement is allowed.
  2. Desired polynomial: φ(s) = (s + 2)(s + 3) = s² + 5s + 6. Matching form s² + a1s + a0 gives a1 = 5 and a0 = 6.
  3. Form BK: BK = [0, 1]T[k1 k2] = [[0, 0], [k1, k2]]. Therefore A − BK = [[0, 1], [−k1, −k2]].
  4. Characteristic polynomial: det(sI − (A − BK)) = det[[s, −1], [k1, s + k2]] = s(s + k2) − (−1)(k1) = s² + k2s + k1.
  5. Equate coefficients: the s coefficient gives k2 = 5; the constant term gives k1 = 6. Hence K = [6 5].
  6. Verification: the roots of s² + 5s + 6 are s = (−5 ± √(25 − 24))/2 = (−5 ± 1)/2, that is −2 and −3. Both lie in the left half plane, so with r = 0 the state decays as a combination of e−2t and e−3t.

Answer. K = [6 5] places the closed-loop poles exactly at −2 and −3, as demanded.

Exam traps

  • Sign of K: u = r − Kx gives A − BK. If you write u = r + Kx the closed-loop matrix is A + BK and every gain changes sign, so the same K places different poles.
  • Placing poles without testing controllability. If Qc is singular, no K exists and the coefficient equations contradict each other; the examiner looks for the rank check first.
  • Swapping the gains in a 2×2 problem. For A = [[0,1],[0,0]] the constant term of det(sI − (A − BK)) is k1 and the s coefficient is k2; match the highest power first and work down.
  • Calling K a PID gain. K is a row of n gains, one per state; the P, PI and PID gains of Unit 5 act on the single error signal and cannot place n poles.
  • Forgetting that the law needs every state measured. If only y is available, K alone is not enough; an observer must estimate x first.

Takeaways

  1. A state model replaces one nth-order differential equation with n first-order equations written as ẋ = Ax + Bu, y = Cx + Du.
  2. The order n equals the number of independent energy-storage elements; for a transfer function it is the degree of the denominator.
  3. The poles of the system are the eigenvalues of A, found from det(sI − A) = 0.
  4. Any transfer function can be turned into a state model in controllable, observable or diagonal canonical form, and the choice is yours.
  5. The reverse trip uses G(s) = C(sI − A)⁻¹B + D, which must reduce to the original transfer function.
  6. The free response is x(t) = e^{At}x(0), so the whole behaviour of the system sits inside the state transition matrix.
  7. Controllability is a rank test on [B AB … Aⁿ⁻¹B]; observability is a rank test on the stacked CAⁱ rows.
  8. A pole-zero cancellation in G(s) makes that mode either uncontrollable or unobservable, even though the transfer function looks innocent.
  9. Pole placement by state feedback works exactly when the system is controllable, and the gain is found from Ackermann's formula or by matching coefficients.
