7.1 Common nonlinearities: saturation, dead zone, backlash

Real control elements do not keep a fixed gain for every input. A valve stops opening past its travel limit, a motor does not move until the drive overcomes friction, and a gear train loses motion in the gap between teeth. Saturation and dead zone are static nonlinearities y=f(x): the output at an instant depends only on the input at that instant. Backlash is a nonlinearity with memory: its output depends on direction and history, so one input can give two outputs. Three shapes cover many such cases: saturation, dead zone and backlash. They explain why a loop that is stable for small signals can show error, slow response or a steady oscillation.

You need: Unit 1 block diagrams and Unit 5 on-off control; this chapter does not repeat them.

Static nonlinearity and saturation

Static nonlinearity. A linear block obeys y=Gx for all x. A static nonlinearity obeys y=f(x): f is a fixed curve, not a differential equation. The output has no memory of past inputs. Real valves, amplifiers, sensors and gears are linear only over a range. Outside that range the curve bends; the loop behaves differently for large signals.

y = kx for |x| ≤ a; y = M for x > a; y = −M for x < −a; M = k a

x is input; y is output; k is the linear gain; a is the input saturation threshold; M is the output limit. Some syllabi call this a limiter or clipping.

Saturation means the element cannot deliver more than M. Below a, the slope is k. Above a, the slope is zero, so the incremental gain falls. In a closed loop, small errors see full gain, but a large error cannot push harder. The loop may look fast for small steps and slow for large steps. A controller with integral action may keep integrating while the actuator is stuck at M; that is integrator windup, and it needs anti-windup logic.

  • A 4–20 mA transmitter clips near 20 mA.
  • An op-amp output clips at its supply rail.
  • A valve stops at fully open or fully closed.

Dead zone

A dead zone is a flat interval around zero. The element produces no output until the input is large enough to overcome it.

y = 0 for |x| < δ; y = k(x − δ) for x ≥ δ; y = k(x + δ) for x ≤ −δ

δ is the dead-zone half-width; k is the slope outside the dead zone. Some syllabi call this a deadband.

Inside |x|<δ, the slope is zero. Outside, the slope is k but the curve is shifted. A small sine input may produce no output, or a distorted output. In a feedback loop, a small error gives no corrective action, so the error can stay. This is a common cause of steady-state error in valves with stiction or in sensors with a deadband. The effect is worst when the dead zone is comparable with the required accuracy.

Backlash

Backlash is a gap between two moving parts. The input must move through the gap before the output moves. The output therefore depends on direction and on where the input has been.

At a reversal, y stays at its last value until x has moved 2b; then y = x − b when x increases; y = x + b when x decreases

b is the half-gap; the total gap is 2b. Some syllabi call this play or lash.

At a reversal, the output does not follow immediately. This memory makes backlash a multi-valued relation: one x can give two y values. In a loop, backlash causes lost motion. The controller pushes, the output lags, then catches up and overshoots. Repeated reversals can produce hunting or a limit cycle. A gear train, a leadscrew nut and a loose linkage all show backlash. Describing-function analysis (see 7.2) uses these shapes to predict oscillation; limit cycles are treated in 7.4.

Worked example

Question. Three separate elements have: saturation M=10 mA, a=2 mA, k=5; dead zone δ=0.2 mA, k=5; backlash b=0.1 mA. For x=3 mA, find each output; backlash input increases from 0.

  1. Saturation: compare x=3 mA with a=2 mA. Since 3 > 2, the output is clamped at the limit M. So y=10 mA.
  2. Dead zone: compare x=3 mA with δ=0.2 mA. Since 3 > 0.2, use y=k(x−δ)=5(3−0.2) mA = 5×2.8 mA = 14 mA.
  3. Backlash: the input is increasing from 0, so use y=x−b=(3−0.1) mA = 2.9 mA.

Answer. Saturation gives 10 mA, dead zone gives 14 mA, and backlash gives 2.9 mA.

Exam traps

  • Backlash is not a single curve: the same x can give two outputs. You must state direction and starting point.
  • Saturation threshold a is an input value; M is the output limit. M=ka holds only when the linear segment reaches the limit.
  • Dead zone and saturation both create flat parts, but dead zone is near zero and removes small signals; saturation is far from zero and limits large signals.
  • At the boundary |x|=a or |x|=δ, both pieces of the equation must give the same value; a mismatch means the piecewise rule is wrong.

7.2 Describing function analysis

A describing function replaces a nonlinear element by an amplitude-dependent gain N(A). The input is a sine wave A sin ωt. N(A)=Y1/A is the complex ratio of the fundamental output phasor Y1 to the input phasor A; its magnitude is the output-to-input fundamental amplitude ratio and its angle is the fundamental phase shift. N(A) is real when the nonlinearity causes no phase shift, e.g. saturation and an ideal relay. The linear plant is assumed to pass only that fundamental. A linear frequency-domain test then predicts a limit cycle: plot G(jω) and −1/N(A); their intersection gives the oscillation amplitude and frequency. Engineers use this on saturating actuators, relays and control valves with backlash, where exact simulation is slow and a quick estimate is enough.

You need: Unit 4 Nyquist plot and frequency response, and 7.1 Common nonlinearities.

The sinusoidal describing function

The method treats the nonlinear block as a black box. Feed x(t)=A sin(ωt), where A is the input amplitude in volts and ω is angular frequency in rad/s. The output n(x) is periodic but not sinusoidal. Fourier analysis splits it into a fundamental at ω plus harmonics at 2ω, 3ω and so on.

Two assumptions make the method work. The nonlinearity must be odd, n(−x)=−n(x), and time-invariant. For single-valued nonlinearities such as saturation and an ideal relay, it is also memoryless: the output at any instant depends only on the input at that instant. Memory-type nonlinearities such as backlash and relays with hysteresis break the memoryless condition: their describing function is derived over one full input period, is complex, and depends on the hysteresis width as well as on A. The linear plant G(jω) must be low-pass: its gain at 2ω, 3ω, ... is small enough to ignore. Then only the fundamental reaches the feedback loop.

The describing function is the complex ratio of the fundamental output phasor to the input phasor: N(A)=Y1/A. Here Y1 is the fundamental output phasor; its magnitude is the fundamental output amplitude and its angle is measured relative to the input. If the nonlinearity has no phase shift, N(A) is real. For a linear gain n(x)=kx, N(A)=k for all A. For a nonlinearity, N(A) changes with A; this is the whole point. N(A) is not the local slope at x=0. Some syllabi call the method harmonic linearization or the sinusoidal describing function.

Saturation, relay and backlash

Take saturation with linear gain k and limit a. For |x|≤a, n(x)=kx. For x>a, n(x)=ka. For x<−a, n(x)=−ka. Here k is the unsaturated slope, dimensionless; a is the input limit in volts.

N(A)=k for A≤a;  N(A)=(2k/π)[sin⁻¹(a/A)+(a/A)√(1−(a/A)²)] for A>a

A is the sine amplitude in V; a is the saturation limit in V; k is the unsaturated slope (dimensionless); sin⁻¹ returns radians.

At A=a the two branches meet at N=k. As A grows, N falls. A relay with output levels ±M has N(A)=4M/(πA), where M is the relay output height in volts and A is input amplitude in volts. The formula ignores relay hysteresis. Backlash gives a complex N(A) with phase lag; it is not a single real curve.

Limit-cycle prediction

Set the loop to 1+N(A)G(jω)=0. Rearranged, G(jω)=−1/N(A). The right side is a locus in the complex plane as A varies. On the same Nyquist plot, draw G(jω) for ω from 0 to ∞. Each intersection is a candidate limit cycle: read A from the −1/N locus and ω from the G locus.

  1. Write n(x), then find N(A) for the nonlinear block.
  2. Draw G(jω) from the linear part.
  3. Draw −1/N(A) for A from 0 to ∞, with an arrow for increasing A.
  4. Mark intersections; read amplitude A and frequency ω.
  5. Check the crossing direction: for a single intersection, the limit cycle is stable if, as A increases through the intersection, the point on the −1/N locus crosses from inside the G(jω) locus to outside. Also check the ω direction along G(jω). Unstable crossings do not produce a sustained oscillation. A limit cycle is an estimate, not a proof.

Some syllabi call the intersection the describing-function limit cycle. Use it as an estimate, not a proof: harmonics are ignored. See 7.4 Limit cycles for the exact definition of an isolated closed path.

Worked example

Question. A saturating amplifier has linear gain k=5 and saturation limit a=2 V. A sine input of amplitude A=4 V drives it. Find N(A).

  1. Check the branch: A=4 V > a=2 V, so use the saturation formula.
  2. Compute a/A=2/4=0.5.
  3. Find sin⁻¹(0.5)=0.5236 rad.
  4. Compute √(1−0.5²)=√0.75=0.8660.
  5. Substitute: N=(2×5/π)(0.5236+0.5×0.8660).
  6. Simplify: N=(10/π)(0.5236+0.4330)=(3.1831)(0.9566)=3.045.

Answer. N(4 V)=3.045, dimensionless.

Exam traps

  • N(A) is not the slope at the origin. For saturation the slope near zero is k, while N(A) falls once A exceeds a.
  • The −1/N locus can be a curve with phase, especially for backlash. Do not treat it as a fixed point on the negative real axis.
  • The method assumes the plant filters harmonics. If the plant passes 2ω or 3ω strongly, the sine-wave prediction can be badly wrong.
  • For a relay, N=4M/(πA) uses the relay output height M, not the peak-to-peak value 2M.

7.3 Phase plane analysis

Phase plane analysis draws a second-order autonomous system as a picture. Write the two states as x₁ and x₂. Plot x₂ on the vertical axis against x₁ on the horizontal axis. Each solution becomes a curve, called a trajectory. The set of all trajectories is the phase portrait. The picture shows at a glance whether the system settles, grows, or oscillates. Engineers use it for a nonlinear servo, a swinging generator rotor, or a saturating amplifier, where one look at the arrows tells more than a long simulation.

You need: state variables and the state model from Unit 6, State Space Analysis, and second-order damping from Unit 2, Time Response Analysis.

The state plane and the vector field

An autonomous system has no explicit time in its equations. For two states, write ẋ₁ = x₂ and ẋ₂ = f(x₁, x₂). Here x₁ and x₂ are the state variables, ẋ means dx/dt, t is time in seconds, and f is a function that contains the nonlinear terms. The plane with axes x₁ and x₂ is the state plane or phase plane. At every point (x₁, x₂), the pair (ẋ₁, ẋ₂) is a velocity vector. Drawing small arrows for many points gives the vector field. A solution that starts at a point follows the arrows and traces a trajectory. The full family of trajectories is the phase portrait. Some syllabi call this the trajectory method.

An equilibrium point is a point where both derivatives are zero: x₂ = 0 and f(x₁, x₂) = 0. At that point the vector is zero, so a trajectory started there stays there. For the system in the worked example, the origin is the only real equilibrium.

The method exists because nonlinear equations rarely have closed-form solutions. The shape of the portrait gives stability and oscillation without solving for x₁(t) and x₂(t). A generator rotor during a fault is a common case: plot angle error and speed error, and see whether the path spirals back or runs away. Closed paths that trap nearby paths are limit cycles; see 7.4.

Isoclines and nullclines

To sketch a portrait by hand, use the slope of a trajectory. Along a trajectory, the slope is the ratio of the two derivatives.

dx₂/dx₁ = f(x₁, x₂) / x₂

x₁ and x₂ are the states; f is the right side of ẋ₂ = f(x₁, x₂); the slope is defined when x₂ ≠ 0.

When x₂ = 0, the trajectory has a vertical tangent or the vector is zero. An isocline is a curve on which every trajectory has the same slope c. Set f / x₂ = c, so f(x₁, x₂) = c x₂. Draw short line segments of slope c on this curve. A few isoclines, with arrows from the vector field, are enough for a sketch.

A nullcline is a curve where one derivative is zero. The x₂ = 0 line is the horizontal-axis nullcline; on it ẋ₁ = 0, so arrows are vertical. The curve f(x₁, x₂) = 0 is the other nullcline; on it ẋ₂ = 0, so arrows are horizontal. Equilibria lie where the two nullclines cross. For ẋ₁ = x₂, ẋ₂ = −x₁ − 0.2x₂ − x₁³, the nullclines are x₂ = 0 and −x₁ − 0.2x₂ − x₁³ = 0. They meet at (0,0).

Linearization and eigenvalue classes

Take an equilibrium at (0,0); move other equilibria to the origin by a change of variables. Near the origin, expand f in a Taylor series and keep first-order terms. Then the linear model is δẋ = J δx, where δx is a small deviation and J is the Jacobian matrix.

J = [[0, 1], [∂f/∂x₁, ∂f/∂x₂]]

J is the Jacobian at the equilibrium; ∂f/∂x₁ and ∂f/∂x₂ are partial derivatives of f, evaluated at the equilibrium.

The eigenvalues λ solve det(λI − J) = 0, where I is the identity matrix. For this J, λ² − (∂f/∂x₂)λ − (∂f/∂x₁) = 0. Here j is the imaginary unit, j² = −1.

  • Both λ real and negative: stable node.
  • Both λ real and positive: unstable node.
  • Real λ with opposite signs: saddle, always unstable.
  • Complex λ with negative real part: stable focus.
  • Complex λ with positive real part: unstable focus.
  • Purely imaginary λ: center, constant-amplitude oscillation in the linear model.

A node has no oscillation; a focus spirals. The worked example gives λ = −0.1 ± j0.995, so the origin is a stable focus. Linearization is local: it classifies only a small neighbourhood. A center may become a stable or unstable focus in the nonlinear system. A proof without linearization uses a Lyapunov function; see 7.5.

Worked example

Question. For the system ẋ₁ = x₂, ẋ₂ = −x₁ − 0.2x₂ − x₁³, find all real equilibria and the Jacobian at the origin. Classify the origin using eigenvalues.

  1. Set both derivatives to zero. ẋ₁ = 0 gives x₂ = 0. ẋ₂ = 0 gives −x₁ − 0.2x₂ − x₁³ = 0.
  2. Substitute x₂ = 0: −x₁ − x₁³ = 0, so x₁(1 + x₁²) = 0. For real x₁, 1 + x₁² is always positive, so x₁ = 0. The only real equilibrium is (0,0).
  3. Write f = −x₁ − 0.2x₂ − x₁³. Then ∂f/∂x₁ = −1 − 3x₁² and ∂f/∂x₂ = −0.2. At the origin, ∂f/∂x₁ = −1 and ∂f/∂x₂ = −0.2.
  4. The Jacobian at the origin is J = [[0, 1], [−1, −0.2]].
  5. The characteristic equation is λ² − (trace)λ + det = 0. trace = −0.2 and det = 1, so λ² + 0.2λ + 1 = 0.
  6. The discriminant is 0.2² − 4(1)(1) = 0.04 − 4 = −3.96. Thus λ = (−0.2 ± j√3.96)/2 = −0.1 ± j0.994987... = −0.1 ± j0.995 to three decimals.
  7. The real part is −0.1 < 0 and the eigenvalues are a complex pair, so the origin is a stable focus.

Answer. The only real equilibrium is (0,0); J = [[0,1],[−1,−0.2]]; λ = −0.1 ± j0.995; the origin is a stable focus.

Exam traps

  • Linearization classifies only a small neighbourhood of an equilibrium. A linear center may become a stable or unstable focus in the nonlinear system; check another method before you trust the center.
  • f = 0 is not enough for an equilibrium. You also need x₂ = 0. The intersection of both nullclines gives the equilibrium.
  • The slope formula dx₂/dx₁ = f/x₂ fails on the line x₂ = 0. Do not divide by zero; treat that line separately as a place with vertical tangents or zero vector.
  • A saddle has one positive and one negative real eigenvalue, so it is unstable even though one direction attracts. Do not call it stable from the negative eigenvalue alone.
  • Node and focus are not the same. A node has real eigenvalues and no spiralling; a focus has complex eigenvalues and trajectories spiral.

7.4 Limit cycles

A limit cycle is a closed path in the phase plane that nearby trajectories approach or leave. It is isolated, so it is not one orbit of a continuum. It gives a self-sustained oscillation of fixed amplitude and frequency, set by the system, not by the initial state. Relay-controlled furnaces, valve stiction and van der Pol circuits show it. In control, a limit cycle is often unwanted hunting; in oscillators it is the product. Describing functions predict its amplitude and frequency; the phase plane shows its shape and stability.

You need describing function analysis and phase plane analysis; common nonlinearities explains the relay and saturation shapes.

Isolated closed orbits

A limit cycle is a closed curve in the phase plane that is isolated: no other closed orbit lies arbitrarily close to it. The state moves round and round on the curve. A nearby state inside the curve and a nearby state outside may spiral towards it. Then the oscillation settles to a fixed amplitude and frequency, fixed by the system, not by the initial state. That is a stable limit cycle.

An unstable limit cycle repels nearby states; they spiral away. A semi-stable limit cycle attracts from one side and repels from the other. In each case the cycle is isolated.

Do not confuse it with a linear centre. The system ẍ + ω²x = 0 has a whole family of closed orbits, one for each initial amplitude. There is no isolation and no single amplitude. Do not confuse it with a forced response either. With a sine input the steady output has the input frequency; a limit cycle has its own frequency and needs no periodic input.

Some syllabi call a stable limit cycle self-oscillation, or hunting when it is unwanted, as in a valve that keeps cycling.

Existence: Poincaré–Bendixson

For a second-order autonomous system, ẋ₁ = f₁(x₁,x₂), ẋ₂ = f₂(x₁,x₂), the Poincaré–Bendixson theorem gives an existence test. Take a bounded region R in the plane. Suppose a trajectory enters R and never leaves. Suppose R contains no equilibrium point. Then the trajectory must approach a closed orbit in R. The limit set is a closed orbit.

The theorem needs the plane. It gives existence, not stability. A closed orbit may be stable, unstable or semi-stable; the theorem does not decide which. Check nearby trajectories separately.

The van der Pol equation is the standard example: ẍ − μ(1 − x²)ẋ + x = 0, with μ > 0. Here x is displacement and μ is a positive parameter. For small |x|, the term −μ(1−x²) is negative damping: energy is pumped in, so amplitude grows. For large |x|, the term becomes positive damping: energy is removed. The two effects balance on a closed orbit. The result is a stable limit cycle, and nearby phase-plane paths approach the closed curve.

A relay loop with a plant that has phase lag can show the same behaviour: a fixed-amplitude oscillation appears with no sine input.

Predicting amplitude and frequency

The describing function replaces the nonlinear element by a gain N(A) that depends on the amplitude A of the sine at its input. The linear plant is G(jω). A limit cycle is predicted when the loop equation holds:

1 + N(A)G(jω) = 0

N(A) is the describing function of the nonlinear element at input amplitude A; G(jω) is the plant frequency response at frequency ω.

Rearrange to G(jω) = −1/N(A). The left side is a curve in the complex plane as ω varies. The right side is a curve as A varies. An intersection gives a candidate limit cycle: read ω from the G curve and A from the −1/N curve.

For a relay with output levels ±M, the describing function is N(A) = 4M/(πA). Here A is the amplitude of the sine at the relay input, not the relay output. Then −1/N(A) = −πA/(4M). On the complex plane this is a line along the negative real axis, moving left as A increases.

  1. Write N(A) for the nonlinearity using the input amplitude A.
  2. Plot G(jω) for ω > 0 and −1/N(A) for A > 0 on the same complex plane.
  3. Find an intersection; record ω and A.
  4. Treat it as a candidate. A separate stability check decides whether the oscillation is stable. The method is approximate because it keeps only the first harmonic.

Worked example

Question. A relay with output ±1 drives G(s)=1/[s(s+1)(s+2)] in a unity-feedback loop. The relay describing function is N(A)=4/(πA). Find the limit-cycle frequency ω in rad/s and the sine amplitude A at the relay input.

  1. Put s=jω. (jω+1)(jω+2)=2+3jω−ω². Multiply by jω: denominator = −3ω² + jω(2−ω²).
  2. For G to be real and negative, the imaginary part is zero: ω(2−ω²)=0. With ω>0, ω=√2=1.414 rad/s.
  3. At this ω, denominator = −3(2)+0 = −6, so G(j√2)=−1/6=−0.1667.
  4. Loop condition: G=−1/N, so −1/6 = −πA/4. Thus πA/4=1/6.
  5. A=4/(6π)=2/(3π)=0.2122. The relay output is ±1, but A is the input sine amplitude.

7.5 Lyapunov stability

Solving a nonlinear state equation is usually impossible, so stability must be judged without solving it. A Lyapunov function V(x) is an energy-like scalar, positive everywhere except at the equilibrium, that never increases along a trajectory. If V always falls, the equilibrium is asymptotically stable. The test needs one scalar function and one derivative, not a closed-form solution. Engineers use it to certify aircraft, power converters, robot arms and motor drives.

You need: the state model and state transition matrix of Unit 6, State Space Analysis, and the stability definitions of Unit 3, Stability and Root Locus.

Equilibrium points and what stability means

A nonlinear autonomous system is written ẋ = f(x). Here x is the n×1 state vector, ẋ is its time derivative, and f is a nonlinear vector function. An equilibrium point x_e is a state where the system stops moving: f(x_e) = 0. A pendulum hanging straight down, a motor at rest, a DC-DC converter at its set point — each has such a state.

Shift the coordinates so the equilibrium sits at the origin: replace x by x − x_e. Every definition below is then about the origin, and x = 0 means the system is exactly at equilibrium.

The equilibrium is stable (in the Lyapunov sense) if for every ε > 0 there is a δ > 0 such that ||x(0)|| < δ guarantees ||x(t)|| < ε for all t ≥ 0. Here ||x|| = √(x₁² + … + xₙ²) is the distance from the origin. Start close enough and you stay close forever, though you may never arrive.

The equilibrium is asymptotically stable if it is stable and x(t) → 0 as t → ∞. The set of starting points that end at the origin is the region of attraction. If that region is the whole state space, the origin is globally asymptotically stable.

Linearising answers a local question only, and when the Jacobian eigenvalues sit on the imaginary axis it answers nothing. A Lyapunov function can settle the whole state space in one calculation.

The Lyapunov function and the direct method

A Lyapunov function is a scalar function V(x), continuous with continuous partial derivatives, that behaves like stored energy. Two conditions make it admissible: V(0) = 0, and V(x) > 0 for every x ≠ 0. This is called positive definite. A bowl shape is the picture to keep.

Differentiate V along the trajectories of the system, using the chain rule:

V̇ = ∇V · f(x) = (∂V/∂x₁)ẋ₁ + … + (∂V/∂xₙ)ẋₙ

V̇ (read V-dot) is the rate of change of V along a solution; ∇V is the row vector of partial derivatives; ẋᵢ is replaced by the i-th component of f(x). No solution x(t) is needed.

  • V̇(x) ≤ 0 everywhere → the origin is stable.
  • V̇(x) < 0 for every x ≠ 0 (negative definite) → the origin is asymptotically stable.
  • V̇ < 0 and V(x) → ∞ as ||x|| → ∞ → the origin is globally asymptotically stable.

The last extra condition is radial unboundedness: V must grow without limit in every direction, so the level curves cannot flatten out and leave a distant region where V̇ is silent. Some syllabi call this approach the direct method or Lyapunov's second method.

  1. Write the system as ẋ = f(x) with the equilibrium moved to the origin.
  2. Propose V(x): a quadratic form ½xᵀx, a sum of squares, or the physical energy of the plant.
  3. Check V(0) = 0 and V(x) > 0 for x ≠ 0.
  4. Compute V̇ = ∇V · f(x) and simplify, cancelling cross terms.
  5. Test the sign of V̇; check radial unboundedness before claiming a global result.

The method proves stability without solving anything, but it is only sufficient. Failing to find a V proves nothing, and no general recipe exists for inventing one.

Linear systems and the Lyapunov equation

For the linear system ẋ = Ax, try V(x) = xᵀPx, where P is a symmetric positive definite matrix. Positive definiteness of P is exactly the condition V(x) > 0 for x ≠ 0. Differentiating gives:

V̇ = xᵀ(AᵀP + PA)x = −xᵀQx

A is the n×n system matrix; P and Q are symmetric positive definite matrices; Q is chosen (usually the identity) and P is solved for.

Setting AᵀP + PA = −Q turns the search for V into a linear matrix equation, the Lyapunov equation. The theorem: A has all eigenvalues in the left half plane (it is Hurwitz) if and only if for every positive definite Q there is a unique positive definite P solving the equation. For A = [[0, 1], [−2, −3]] and Q = I, the solution is P = [[1.25, 0.25], [0.25, 0.25]], which is positive definite, so the system is stable. The level curves of xᵀPx are nested ellipses.

The Krasovskii method avoids guessing. Take V(x) = f(x)ᵀf(x) and form the Jacobian J(x) = ∂f/∂x. If Jᵀ + J is negative definite everywhere, the origin is asymptotically stable; if in addition V(x) → ∞ as ||x|| → ∞, the origin is globally asymptotically stable, provided the origin is the only equilibrium. It works directly on f with a fixed formula.

Worked example

Question. The system ẋ₁ = −x₁ + x₂, ẋ₂ = −x₁ − x₂ − x₂³ has an equilibrium at the origin. Using V(x) = ½(x₁² + x₂²), show that the origin is globally asymptotically stable. Evaluate V and V̇ at x₁ = 1, x₂ = 2, with time in seconds.

  1. Equilibrium check: f(0,0) = (0, 0), so the origin is an equilibrium.
  2. Positivity: V(0,0) = 0, and V = ½(x₁² + x₂²) > 0 whenever x ≠ 0.
  3. Radial unboundedness: as ||x|| → ∞, V = ½||x||² → ∞.
  4. Derivative: V̇ = x₁ẋ₁ + x₂ẋ₂.
  5. Substitute: V̇ = x₁(−x₁ + x₂) + x₂(−x₁ − x₂ − x₂³).
  6. Expand: V̇ = −x₁² + x₁x₂ − x₁x₂ − x₂² − x₂⁴; the cross terms cancel.
  7. Result: V̇ = −x₁² − x₂² − x₂⁴ = −(x₁² + x₂² + x₂⁴) < 0 for every x ≠ 0.
  8. So V̇ is negative definite and V is radially unbounded: globally asymptotically stable.
  9. At x₁ = 1, x₂ = 2: V = ½(1² + 2²) = 2.5.
  10. At the same point: V̇ = −(1 + 4 + 16) = −21 per second.

Answer. V̇ = −x₁² − x₂² − x₂⁴ is negative definite and V → ∞ radially, so the origin is globally asymptotically stable; at (1, 2) V = 2.5 and V̇ = −21 per second.

Exam traps

  • V̇ ≤ 0 proves stability only. When V̇ merely vanishes on a line and the examiner asks about asymptotic stability, the safe answer is that this V does not prove asymptotic stability; the system may still be asymptotically stable, and an extra argument such as LaSalle's invariance principle is what turns the answer into yes.
  • V must be positive definite. A negative or sign-indefinite V is not a Lyapunov function, and multiplying a correct V by −1 destroys the test.
  • Sign slips in V̇: the partial ∂V/∂x₁ multiplies ẋ₁, not x₁. Cross terms like x₁x₂ usually cancel — if they do not, check the algebra before the conclusion.
  • A global claim needs radial unboundedness. V = x₁²/(1 + x₁²) + x₂² is positive definite but bounded along x₁, so it gives no global result.
  • Do not confuse Jacobian linearisation, which is local, with Lyapunov's direct method, which can be global. Failure to find a V proves nothing — the method is sufficient, not necessary.

7.6 Optimal control and linear quadratic regulator

Optimal control chooses the input u(t) that makes a total cost as small as possible, instead of merely making the system stable. For a linear plant and a quadratic cost J = ∫₀^∞ (xᵀQx + uᵀRu) dt, the best control is a state feedback u = −Kx. The gain K comes from solving the Riccati equation. LQR is used in drone flight, motor drives, satellite attitude control and process loops, where fast response must be balanced against actuator effort.

You need: state feedback and controllability from Unit 6, State Space Analysis, and the quadratic Lyapunov form from 7.5 Lyapunov stability.

Cost sets the goal

An optimal control problem has a plant, a cost, and a class of allowed inputs. For LQR the plant is linear: ẋ = Ax + Bu. Here x is the state vector (n × 1), u is the control vector (m × 1), A is the state matrix (n × n), and B is the input matrix (n × m). The pair (A, B) must be controllable; otherwise no feedback can move every state.

J = ∫₀^∞ (xᵀQx + uᵀRu) dt

J is the total cost. Q is n × n, symmetric and positive semidefinite (Q = Qᵀ ≥ 0). R is m × m, symmetric and positive definite (R = Rᵀ > 0). xᵀQx penalises state error and uᵀRu penalises control effort.

The cost is one number: squared state error plus squared control effort, integrated over all future time. The infinite horizon means the settled response matters more than a fixed final time. A drone holding position in wind shows the setting: quick correction is good, but violent motor commands waste battery and stress the frame. LQR turns a design argument into two matrices. Choose Q and R from acceptable deviation and acceptable effort, then compute the best feedback.

LQR is useful when a controller must respect actuator limits indirectly. A motor drive should reach speed fast without excessive current. A satellite should point accurately without burning too much fuel. The weights Q and R state that balance before any gain is calculated.

Riccati equation gives the gain

For the infinite-horizon problem, define P as the n × n symmetric positive semidefinite solution of the algebraic Riccati equation (ARE):

AᵀP + PA − PBR⁻¹BᵀP + Q = 0

A, B, Q and R are the plant and weight matrices above. P is the cost-to-go matrix. For a scalar plant, P is one positive number.

Once P is known, the gain is K = R⁻¹BᵀP. K is m × n. The optimal control is u = −Kx. The minus sign is feedback: a positive state produces a negative input that pulls the state back.

  1. Check (A, B) is controllable and the weights satisfy Q ≥ 0, R > 0.
  2. Solve the ARE for the positive semidefinite P. Reject any other solution.
  3. Compute K = R⁻¹BᵀP.
  4. Form the closed loop ẋ = (A − BK)x and check its poles.
  5. Simulate, then adjust Q and R if the response or the control effort is unacceptable.

The closed-loop matrix is A − BK. LQR guarantees that all its eigenvalues lie in the open left half plane when Q ≥ 0, R > 0 and (A, B) is controllable. This is the central result: the cost itself selects a stabilising feedback gain.

Weights, stability and limits

Q and R are not unique. Scaling both by the same positive number leaves K unchanged, because P scales by the same number and the factors cancel in R⁻¹BᵀP. Only the relative sizes matter. Increase a diagonal entry of Q to force that state to zero faster. Increase a diagonal entry of R to make that input smaller and smoother. Fast response usually costs larger control amplitude or a more oscillatory transient.

Q may have zero diagonal entries; it only needs to be positive semidefinite. R must be strictly positive, never zero, because free control makes the cost unbounded. Some syllabi call this LQ control or the quadratic regulator.

The proof assumes u can be any size. Real actuators saturate, so check the design against 7.1 Common nonlinearities. Model error changes A and B, so K may be suboptimal on the real plant. Integral action is added separately for constant disturbances. Output feedback needs an observer when only y is measured. Finite-horizon problems make P time-varying; this chapter stays with the infinite-horizon continuous case.

Worked example

Question. For the plant ẋ = −x + u with cost J = ∫₀^∞ (x² + u²) dt, find the LQR gain K and the closed-loop pole. Use the infinite-horizon Riccati equation.

  1. Match with ẋ = Ax + Bu: A = −1, B = 1. Match with J = ∫(xᵀQx + uᵀRu)dt: Q = 1, R = 1.
  2. Write the scalar ARE: AᵀP + PA − PBR⁻¹BᵀP + Q = 0.
  3. Substitute: (−1)P + P(−1) − P(1)(1)⁻¹(1)P + 1 = 0. This gives −2P − P² + 1 = 0, or P² + 2P − 1 = 0.
  4. Solve: P = [−2 ± √(2² + 4)]/2 = −1 ± √2. The positive solution is P = −1 + √2 ≈ 0.414. The negative value −1 − √2 ≈ −2.414 is rejected.
  5. Gain: K = R⁻¹BᵀP = (1)⁻¹(1)P = 0.414. Control: u = −Kx = −0.414x.
  6. Closed loop: ẋ = −x + u = −x − 0.414x = −1.414x. The pole is −1.414, in the left half plane.

Answer. P ≈ 0.414, K ≈ 0.414, and the closed-loop pole is −1.414.

Exam traps

  • Choosing the negative root of the ARE. Reject P = −1 − √2 in the example; it gives K = −2.414 and closed-loop pole +1.414, which is unstable.
  • Setting R = 0. R must be positive definite; zero control cost leads to unbounded or impulsive solutions, not a normal LQR gain.
  • Using Q < 0 or an indefinite Q. Q must be symmetric positive semidefinite; a negative weight has no physical meaning.
  • Forgetting controllability. If (A, B) is not controllable, the ARE may not have a stabilising positive semidefinite solution.
  • Confusing LQR with pole placement. Pole placement picks poles first; LQR picks Q and R first, then the poles follow.

Takeaways

  1. Real elements lose their fixed gain once the signal is large, small, or reversed in direction, and saturation, dead zone and backlash are the three common shapes of that loss.
  2. The describing function N(A) buys a frequency-domain test at the price of assuming a sinusoidal input, a single nonlinear block and good low-pass filtering by the linear part.
  3. In a phase portrait the geometry is the answer: spirals mean oscillation with decay, closed curves mean sustained oscillation, and saddles mean a direction of escape.
  4. A limit cycle is self-excited and amplitude-fixed by the system, unlike the undamped linear oscillator whose amplitude comes from the initial condition.
  5. A Lyapunov function proves stability by showing an energy-like quantity always falls, so no differential equation has to be solved.
  6. The Lyapunov equation AᵀP + PA = −Q turns the search for a quadratic Lyapunov function into a linear matrix equation.
  7. Optimal control states the goal as a cost and lets the mathematics pick the control, instead of tuning gains by hand.
  8. For a linear plant with a quadratic cost the optimal control is always a linear state feedback u = −Kx, so LQR is the workhorse of modern design.
  9. The weights Q and R are the design knobs: larger Q gives faster, harder control, larger R gives a gentler control that uses less effort.

N(A) = 4M/(πA); find the phase-crossover frequency of G(jω) where ∠G = −180°; At that ω, |G(jω)| = 1/(ω·√(ω²+1)·√(ω²+4)) with ω = √2; Limit cycle condition G(jω)N(A) = −1, i.e. N(A) = 1/|G(jω)|; Solve 4M/(πA) = 1/|G(jω)| for A; Check stability of the cycle by perturbing A and seeing whether the intersection moves back.

Apply Derive the describing function of a saturation element with slope k and saturation level a, and use it to explain why a high-gain loop with saturation can oscillate. 13 marks

Output is periodic and odd; integrate over one quarter cycle; N(A) = k for A ≤ a; N(A) = (2k/π)[sin⁻¹(a/A) + (a/A)√(1 − (a/A)²)] for A > a; N falls monotonically from k to 0 as A grows; the effective open-loop gain shrinks with amplitude; Where the Nyquist plot of the linear part cuts the −1/N(A) locus, a limit cycle is predicted; Physical reading: the loop is stable for small signals and for very large ones but may settle at an in-between amplitude.

Apply Draw the phase portrait of ẍ + 0.6ẋ + x = 0 and of ẍ + x = 0, and label singular points and trajectory shapes. 12 marks

State variables x₁ = x, x₂ = ẋ; write the two first-order equations; Eigenvalues of the matrix for the damped case: −0.3 ± j0.954, complex with negative real part, so the origin is a stable focus; Damped case: inward spirals; Undamped case: eigenvalues ±j, centre, closed curves, amplitude from initial conditions; Isocline method as a sketching aid.

Apply Show that V(x) = x₁² + x₂² proves asymptotic stability of the origin for ẋ₁ = x₂, ẋ₂ = −x₁ − x₂. 13 marks

V is positive definite and radially unbounded; V̇ = 2x₁ẋ₁ + 2x₂ẋ₂ = 2x₁x₂ + 2x₂(−x₁ − x₂) = −2x₂²; V̇ ≤ 0 only, not strictly negative definite; use LaSalle or note V̇ = 0 only on the line x₂ = 0, where ẋ₂ = −x₁ ≠ 0 unless x₁ = 0; Hence no whole trajectory stays in V̇ = 0 except the origin, so the origin is asymptotically stable; Radial unboundedness makes it global.

Apply For A = [[0, 1], [−2, −3]], B = [[0],[1]], Q = I, R = 1, solve the Riccati equation and find the LQR gain K. 13 marks

Write P = [[p₁₁, p₁₂],[p₁₂, p₂₂]] and substitute into AᵀP + PA − PBR⁻¹BᵀP + Q = 0; Three scalar equations in p₁₁, p₁₂, p₂₂; Solve, keeping the positive definite root; K = R⁻¹BᵀP gives the feedback gains; Check that A − BK is stable by its eigenvalues.

Apply Use the Krasovskii method to test asymptotic stability of ẋ₁ = x₂, ẋ₂ = −x₂ − x₁³ at the origin. 12 marks

Form the Jacobian J(x) = [[0, 1],[−3x₁², −1]]; Choose P = I and compute JᵀP + PJ = [[−6x₁², 0],[0, −2]]; Matrix is negative definite for x₁ ≠ 0; at the origin it becomes negative definite too; Conclusion: origin is asymptotically stable; Note Krasovskii gives a sufficient condition only — failing it proves nothing.

Analyze and evaluate

Analyze Compare describing function analysis with phase plane analysis: what each can handle, what each assumes, and which questions each answers best. 13 marks

DF: frequency domain, higher-order systems, one static nonlinearity, sinusoidal-input assumption, predicts limit cycle amplitude and frequency, cannot show transient or multiple equilibria; Phase plane: exact for second order, no sinusoidal assumption, shows global picture, transients, separatrices; limited to two state variables and often graphical; DF is approximate and quantitative; phase plane is exact and qualitative; Use DF to predict oscillation of a loop with a valve or relay; use phase plane to see whether a start point escapes to another equilibrium; Both are tools for suspicion plus design, not substitutes for simulation.

Evaluate State the Lyapunov stability theorems. Explain why a Lyapunov function proving stability is a sufficient condition, not a necessary one, and why radial unboundedness is needed for the global claim. 13 marks

Stability: V positive definite, V̇ ≤ 0 locally. Asymptotic: V̇ negative definite; Sufficiency: finding one V settles the question; failing to find one settles nothing; Conditions are sufficient because many V may exist, and a bad guess can fail on a stable system; Global claim needs V̇ < 0 for all x and V(x) → ∞ as ‖x‖ → ∞, otherwise trajectories can escape to infinity while V stays bounded; Example: V = x₁²/(1 + x₁²) type functions that fail radial unboundedness.

Evaluate Explain the linear quadratic regulator. Justify the form u = −Kx, derive the Riccati equation, and discuss how Q and R affect the closed-loop response. 14 marks

Plant ẋ = Ax + Bu, cost J = ∫₀^∞ (xᵀQx + uᵀRu) dt with Q ≥ 0, R > 0; Hamiltonian or completion-of-squares argument gives u = −R⁻¹BᵀPx; P solves AᵀP + PA − PBR⁻¹BᵀP + Q = 0, the algebraic Riccati equation; P ≥ 0 for stabilisable and detectable systems; Increasing Q makes the state decay faster at the cost of larger u; increasing R penalises effort and slows the response; Gain margin and robustness properties of LQR; LQR is optimal for the stated model, so model error still matters.

Analyze A pendulum model ẋ₁ = x₂, ẋ₂ = −sin x₁ − 0.2x₂ is given. Find all equilibrium points, sketch the phase portrait near each, and use a Lyapunov argument to discuss the stability of the hanging position. 14 marks

Equilibria at x₂ = 0 and sin x₁ = 0, i.e. x₁ = 0, ±π, ±2π, …; Jacobian [[0,1],[−cos x₁, −0.2]]; at x₁ = 0 eigenvalues have negative real part, stable focus; At x₁ = π the eigenvalues are real with opposite signs: saddle, so the upright position is unstable; Energy candidate V = (1 − cos x₁) + x₂²/2 is positive definite near the origin and V̇ = −0.2x₂² ≤ 0; LaSalle plus the damping argument gives asymptotic stability of the hanging position; no limit cycle exists because the damping removes energy everywhere except the equilibrium.

Glossary

Admissible control
A control signal that is physically allowed and drives the plant from the given start to the required end.
Asymptotic stability
Stability plus the property that nearby trajectories actually converge to the equilibrium.
Backlash
A hysteresis-type nonlinearity caused by looseness in a mechanical linkage, where the output lags the input by a fixed gap.
Cost functional
A scalar integral that scores a control trajectory, usually penalising state error and control effort.
Dead zone
A range of input around zero for which the output stays zero, common in valves and gears with slack.
Describing function
An amplitude-dependent complex gain equal to the fundamental component of the output divided by a sinusoidal input.
Equilibrium point
A state at which all derivatives are zero, so the system remains there for all time.
Harmonic linearisation
Another name for the describing function method, because the nonlinearity is replaced by a gain at the fundamental frequency.
Limit cycle
An isolated closed trajectory that neighbouring trajectories approach or leave, giving a self-sustained oscillation.
Linear quadratic regulator
The optimal state-feedback controller for a linear plant with a quadratic performance index.
Lyapunov equation
The linear matrix equation AᵀP + PA = −Q, solved for P to build a quadratic Lyapunov function.
Lyapunov function
A positive definite scalar function of the state whose time derivative along the system trajectories is negative or zero.
Nonlinear system
A system whose response does not obey superposition, so its behaviour depends on the size and sign of the input and on the starting state.
Optimal control
The problem of choosing a control signal that minimises a stated cost while satisfying the plant dynamics.
Phase plane
The plane whose axes are the two states of a second-order autonomous system.
Phase portrait
The complete picture of trajectories of a system drawn in the phase plane.
Positive definite function
A function that is zero at the origin and strictly positive everywhere else in a region around it.
Radially unbounded
A property of a function that grows without limit as the state moves arbitrarily far from the origin in any direction.
Riccati equation
A quadratic matrix equation whose solution gives the optimal feedback gain in LQR and in linear quadratic Gaussian design.
Saddle point
An equilibrium with one stable and one unstable direction; paths approach along one line and leave along another.
Saturation
A nonlinearity whose output stops growing once the input passes a limit, so the incremental gain becomes zero.
Separatrix
A special trajectory that divides the phase plane into regions with qualitatively different behaviour.
Stable equilibrium
An equilibrium where trajectories starting close enough remain close for all future time.
Stable focus
An equilibrium surrounded by spiralling trajectories that wind inward towards it.
Static nonlinearity
A memoryless nonlinear element whose output at an instant is a fixed function of the input at that same instant.
Trajectory
The curve traced by the state of a system as time runs, plotted in the state space.
