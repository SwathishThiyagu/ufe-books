3.1 BIBO stability, characteristic equation and s-plane

A linear time-invariant system is BIBO stable when every bounded input produces a bounded output. This is decided by the poles of the closed-loop transfer function. If every pole lies strictly inside the left half of the s-plane, all natural modes decay. If any pole sits on the jω axis or to its right, some bounded input drives the output to infinity. Every stability test in this unit locates those poles without factorising the denominator.

You need: Unit 1 for transfer functions, poles, zeros and block diagrams; Unit 2 for step and ramp inputs.

Bounded in, bounded out

Take input u(t) and output y(t). An input is bounded when a finite number M exists with |u(t)| ≤ M for all t ≥ 0. An output is bounded the same way, with some finite N. The system is BIBO stable when every bounded input produces a bounded output.

For an LTI system with impulse response h(t), the test is ∫₀^∞ |h(t)| dt < ∞. For a rational transfer function this becomes a pole condition.

T(s) = G(s) / (1 + G(s)H(s))

T(s) is the closed-loop transfer function; G(s) is the forward-path transfer function; H(s) is the feedback-path transfer function; G(s)H(s) is the loop gain. For unity feedback H(s) = 1 and T(s) = G(s)/(1 + G(s)).

BIBO stability is a property of the input–output pair only. It says nothing about the internal states of the system.

The characteristic equation

Write T(s) = N(s)/D(s) with all fractions cleared. D(s) is the characteristic polynomial and D(s) = 0 the characteristic equation. In general the characteristic equation is:

1 + G(s)H(s) = 0

G(s) is the forward path and H(s) the feedback path; with H(s) = 1 it becomes 1 + G(s) = 0. After clearing fractions this is a polynomial in s whose roots are the closed-loop poles.

Poles are values of s where T(s) becomes infinite: roots of D(s). Zeros are values where T(s) = 0: roots of N(s). A transfer function with n poles and m zeros has n − m zeros at infinity when n > m. Every pole is real or one of a complex-conjugate pair, because coefficients are real.

A pole–zero plot marks poles as × and zeros as ○ on the complex s-plane. The horizontal axis is σ, the real part. The vertical axis is jω, the imaginary part, and is the boundary between left and right half-planes.

Three regions of the s-plane

Partial fractions turn each pole p = σ + jω into a term K ept, where K is set by the residues.

e<sup>pt</sup> = e<sup>σt</sup>(cos ωt + j sin ωt)

σ is the real part of the pole, in per second; it sets growth or decay. ω is the imaginary part, in rad/s; it sets oscillation frequency.

  • Negative real part, open left half-plane: eσt decays, so the response settles. BIBO stable.
  • Zero real part, on the jω axis: constant-amplitude oscillation. Called marginally stable, and limitedly stable in some syllabi.
  • Positive real part, open right half-plane: eσt grows without limit. Unstable.

A simple pole at s = 0 gives a constant impulse response, but a step input is 1/s, so the pole at the origin appears twice and the output contains a t term that grows without limit. The case that survives a step is a simple pair at s = ±jω₀: the step response is a bounded oscillation, but an input sin ω₀t makes those poles double and the response grows. A repeated pole at the origin gives t even for an impulse. So a simple jω pair is only marginally stable; repeated jω poles are unstable. The closed-loop pole or pair closest to the jω axis decides settling speed, as dominant poles explains.

Feedback moves the poles

Feedback shifts the closed-loop poles away from the open-loop poles. Take G(s) = 1/(s(s + 2)) with unity feedback. The open-loop poles are 0 and −2, so the open loop is only marginally stable; its impulse response does not decay. The characteristic equation is s² + 2s + 1 = 0, a double pole at −1: the closed loop is stable.

The reverse happens too. G(s) = 100/((s + 1)(s + 2)(s + 3)) is open-loop stable, with poles at −1, −2 and −3. Unity feedback gives s³ + 6s² + 11s + 106 = 0, whose roots include a pair in the right half-plane; Unit 4 reaches the same conclusion from the Nyquist plot. Testing the poles of G(s) alone is therefore a mistake.

Asymptotic stability demands more: every mode must decay, including modes that a zero cancels. A pole cancelled by a zero never appears in T(s), so the input–output test cannot see it. Checking it needs the state model of Unit 6; only a few universities teach that distinction at this stage. Use the Routh–Hurwitz criterion when the polynomial is too large to factorise.

Worked example

Question. T(s) = (s + 5)/((s + 3)(s² + 2s + 5)). (a) List poles and zeros. (b) Decide BIBO stability. (c) Find the steady value of its unit-step response. (d) Repeat (b) for T(s) = (s + 5)/((s − 1)(s² + 2s + 5)).

  1. Zeros: s + 5 = 0 gives s = −5.
  2. Poles: s + 3 = 0 gives s = −3. For s² + 2s + 5 = 0, s = (−2 ± √(2² − 4·1·5))/(2·1) = (−2 ± √−16)/2 = −1 ± j2.
  3. All real parts are −3, −1, −1, all negative, so every mode decays and the system is BIBO stable.
  4. Final value: T(0) = 5/(3 × 5) = 1/3 = 0.333 of the step size.
  5. Part (d): s − 1 gives a pole at +1. Its mode et grows without bound; no final value exists and the system is unstable.

Output

-1.0
2.0
-2.0

Answer. Poles −3 and −1 ± j2; zero −5; first system BIBO stable with c(∞) = 0.333; second unstable, no steady value.

Exam traps

  • Testing the poles of G(s) instead of the roots of 1 + G(s)H(s). The plant 100/((s + 1)(s + 2)(s + 3)) is open-loop stable, yet the closed loop is unstable.
  • Calling a pole on the jω axis stable. A simple pair at s = ±j2 passes a step input but fails a sine at 2 rad/s, which makes the pair double and gives t·sin 2t. A simple pole at s = 0 fails even a step input: the step doubles the origin pole and the output is a ramp.
  • Sign slip: the root of s + 3 = 0 is s = −3, not +3. Solve the factor; do not read off the constant.
  • Forgetting that repeated jω poles grow. A factor (s² + 4)² contributes t·sin 2t, not a bounded oscillation.
  • Assuming a cancelled pole–zero pair has vanished. It disappears from T(s) only; the mode still lives inside the system.

3.2 Routh-Hurwitz stability criterion

The Routh–Hurwitz criterion decides stability from the coefficients of the characteristic polynomial alone, without solving for the roots. You write the coefficients into a table called the Routh array, then count sign changes down its first column. Each sign change is one root in the right half of the s-plane. Because the arithmetic is simple and exact, the test is used in design: choosing a controller gain K, checking a closed-loop transfer function, and reading off the gain at which a system starts to oscillate.

You need 3.1 for the characteristic equation and why a right-half-plane root means instability, plus school algebra of polynomials.

The necessary condition: no missing or negative coefficients

Write the characteristic equation in the standard form a₀sⁿ + a₁sⁿ⁻¹ + … + aₙ = 0, with a₀ > 0.

The necessary condition for stability is that every coefficient a₀, a₁, …, aₙ exists and is positive. No power of s may be missing, so no coefficient may be zero. No coefficient may be negative.

Why this works: if a coefficient is zero or negative, at least one root lies in the right half plane or on the jω axis. A system with such a root cannot settle.

The condition is necessary, not sufficient. The polynomial s³ + s² + s + 6 has all coefficients positive, yet it factors as (s + 2)(s² − s + 3). The quadratic gives s = 0.5 ± j(√11)/2, two roots with positive real part. The system is unstable. Only the full array settles the question.

Building the array and counting sign changes

For a polynomial of degree n, the array has n + 1 rows, labelled sⁿ down to s⁰. Pad each row with zeros on the right.

  1. Copy the coefficients into the first two rows, taking alternate coefficients: row sⁿ gets a₀, a₂, a₄, …; row sⁿ⁻¹ gets a₁, a₃, a₅, … .
  2. Each entry in a later row is a 2×2 determinant divided by the first entry of the row just above.
  3. Count sign changes in the first column, from sⁿ down to s⁰.
  4. The number of sign changes equals the number of roots in the right half plane. Zero sign changes means no root is in the right half plane. If no zero row and no zero first-column entry occurred, every root is strictly in the left half plane and the system is stable; if an auxiliary row was needed, zero sign changes means the system is marginally stable, with the jω-axis roots given by A(s) = 0.

b₁ = (a₁a₂ − a₀a₃) / a₁

a₀ … a₄ are the coefficients of a₀s⁴ + a₁s³ + a₂s² + a₃s + a₄; b₁ is the first entry of row s². The next entry uses a₅ in place of a₃, and so on.

Some syllabi call this table Routh's table or the Routh–Hurwitz array. The Hurwitz determinant form, taught by only a few universities, gives the same answer through determinants of the coefficient matrix.

Two special cases

Special case 1: a zero in the first column. If the first entry of a row is zero but other entries are not, replace the zero by a small positive number ε. Complete the array in terms of ε. Then let ε → 0 and read the signs. Use ε only when at least one other entry in that row is nonzero; if the whole row is zero, use Special case 2 instead.

Special case 2: an entire row of zeros. This means roots occur in equal and opposite pairs, symmetric about the origin. Form the auxiliary equation A(s) from the row above the zero row, using only even powers:

A(s) = c₁sᵏ + c₂sᵏ⁻² + c₃sᵏ⁻⁴ + …

c₁, c₂, c₃, … are the entries of the row above the zero row; k is the power of s for that row.

Differentiate A(s) with respect to s. Put the coefficients of dA/ds into the zero row, then continue. The auxiliary equation also gives the symmetric roots; often these are ±jω on the jω axis.

Unknown gain K

Often one coefficient contains a design gain K. Build the array in terms of K. For stability, every entry in the first column must have the same sign. Solve those inequalities together. The answer is usually an interval such as 0 < K < 66. At the end point of the interval, a row of zeros appears and the auxiliary equation gives the frequency of oscillation.

Worked example

Question. (a) Use the Routh array to test s⁴ + 2s³ + 3s² + 4s + 5 = 0. State the number of right-half-plane roots. (b) For s³ + 6s² + 11s + K = 0, find the range of K for stability and the frequency of oscillation at the boundary.

  1. (a) Row s⁴: 1, 3, 5. Row s³: 2, 4, 0.
  2. Row s²: b₁ = (2×3 − 1×4)/2 = 1; b₂ = (2×5 − 1×0)/2 = 5.
  3. Row s¹: c₁ = (1×4 − 2×5)/1 = −6.
  4. Row s⁰: d₁ = (−6×5 − 1×0)/(−6) = 5.
  5. First column: 1, 2, 1, −6, 5. Signs: +, +, +, −, +. Two sign changes. Two roots lie in the right half plane; the system is unstable.
  6. (b) Row s³: 1, 11. Row s²: 6, K.
  7. Row s¹: (6×11 − 1×K)/6 = (66 − K)/6. Row s⁰: K.
  8. First column: 1, 6, (66 − K)/6, K. All must be positive: K > 0 and 66 − K > 0, so 0 < K < 66.
  9. At K = 66 the s¹ row becomes zero. Auxiliary from row s²: 6s² + 66 = 0, so s² = −11 and s = ±j3.32 rad/s.

Answer. The polynomial in (a) has two right-half-plane roots and is unstable; the gain range in (b) is 0 < K < 66, with oscillation at 3.32 rad/s at K = 66.

Exam traps

  • All coefficients positive is necessary, not sufficient. s³ + s² + s + 6 passes the sign test and still has two right-half-plane roots.
  • A row of zeros must be replaced by the coefficients of dA/ds, where A(s) comes from the row above. Continuing with zeros gives nonsense.
  • A single zero in the first column is not a row of zeros. Replace it with ε, complete the array, and let ε → 0.
  • Count sign changes only in the first column. Counting elsewhere gives a wrong number of unstable roots.
  • A missing term means a zero coefficient, which already violates the necessary condition. Do not start the array.

Beyond the syllabus

Not for the exam. The same determinant idea, written as Hurwitz determinants, extends to polynomials with symbolic parameters and to the Kharitonov theorem for interval coefficients. Software such as MATLAB, Python's control library and Scilab builds the array symbolically inside design loops. For systems with time delay, the characteristic equation becomes a quasi-polynomial and the plain Routh test fails; the Nyquist criterion in Unit 4 is the usual tool. Search terms: Hurwitz matrix, Kharitonov theorem, parametric stability, delay-independent stability.

3.3 Relative stability and dominant poles

A complex pole at −σ ± jω gives a term e^(−σt)cos(ωt + φ), where σ is how far the pole sits left of the jω axis. A real pole at −σ gives only e^(−σt). A pole close to the axis decays slowly and keeps influencing the response; a pole far left dies quickly. Relative stability measures that distance. The pole or pair nearest the axis, the dominant poles, fixes the settling time and overshoot: a complex pair if the nearest poles are complex, a single real pole if a real pole sits closest. Engineers use this to judge a design, choose a gain, and decide whether a small change in a pole or zero will slow or speed up a drive, a power supply, or a control loop.

You need 3.2 for the Routh test on a shifted polynomial, and Unit 2 for second-order step response, ζ, ωn, settling time and peak overshoot.

Relative stability is distance from the jω axis

BIBO stability only says every closed-loop pole is left of the jω axis. It does not say how far left. A pole p = −σ + jω gives a term e^(−σt)cos(ωt), where σ > 0 is the distance from the axis in rad/s and the real part is −σ. Small σ means slow decay. Relative stability measures this margin.

To test whether every pole is left of the line s = −σ, shift the origin. Put s = z − σ, so z = s + σ. The line s = −σ becomes z = 0. Expand D(s) in z:

D_σ(z) = D(z − σ) = a_n z^n + a_(n−1) z^(n−1) + … + a_0

D(s) is the characteristic polynomial; D_σ(z) is the same polynomial after the shift; a_n … a_0 are its new real coefficients.

All s-poles lie strictly left of s = −σ exactly when every root of D_σ(z) has negative real part. Run the Routh array of 3.2 on D_σ(z). No sign change in the first column means margin at least σ; each sign change counts roots to the right of the line. Increase σ until the array turns marginal. That largest σ is the distance of the nearest pole.

Dominant poles and the second-order estimate

Not all poles shape the response equally. The term e^(−σt) dies; the pole with smallest σ lasts longest. A complex pair nearest the axis is the dominant pair when every other pole is at least five times farther left and its residue, the weight in the partial-fraction expansion, is small. The five-times rule is a rule of thumb, not a theorem.

For a dominant pair at −ζωn ± jωn√(1 − ζ²), ζ is the damping ratio and ωn is the natural frequency in rad/s. The damped frequency is ωd = ωn√(1 − ζ²). The second-order approximation is T(s) ≈ Kωn²/(s² + 2ζωn s + ωn²), where K is the DC gain of the closed-loop system, so T(0) = K; the denominator carries ζ and ωn.

t_s(2%) ≈ 4/(ζωn), M_p ≈ e^(−πζ/√(1 − ζ²))

t_s is the 2% settling time in seconds; M_p is peak overshoot as a fraction; ζ is dimensionless; valid for 0 < ζ < 1.

Use these numbers only after the dominance check. A pole at −3 next to a pair at −1 ± j3 is only three times farther and changes both settling and overshoot. The pair-only formulas can then be too optimistic about speed.

Effect of an added pole or zero

Adding an open-loop real pole, such as a sensor lag, adds a branch to the root locus. In a typical low-order loop the locus bends right, the dominant pair moves closer to the jω axis or to a lower damping ratio, the response slows, and overshoot usually rises. The extra closed-loop real pole can partly mask this, but the trend is lower relative stability, not higher. Adding an open-loop zero bends the locus left, acts like derivative action, speeds the response, and usually raises overshoot. These are trends, not guarantees; confirm on the 3.4 locus.

If a zero is close to a pole, their partial-fraction contributions largely cancel. The mode is weak but not gone unless the positions are exactly equal. In a transfer function this looks harmless; in hardware an unstable hidden pole can still drift, so do not rely on cancelling a right-half-plane pole.

Worked example

Question. A unity-feedback system has closed-loop transfer function T(s) = 100/((s + 10)(s² + 2s + 10)). (a) Find all poles. (b) Name the dominant pair and give ζ and ωn. (c) Estimate the 2% settling time and the peak overshoot.

  1. Expand the denominator: (s + 10)(s² + 2s + 10) = s³ + 12s² + 30s + 100.
  2. One pole is s = −10. For the quadratic s² + 2s + 10 = 0, s = [−2 ± √(4 − 40)]/2 = −1 ± j3.
  3. The pair −1 ± j3 is nearest the jω axis. The real pole at −10 is 10/1 = 10 times farther left, more than five times, so the pair is dominant.
  4. Compare −1 ± j3 with −ζωn ± jωn√(1 − ζ²). Then ζωn = 1 and ωn√(1 − ζ²) = 3, so ωn² = 1² + 3² = 10 and ωn = 3.162 rad/s. ζ = 1/ωn = 1/√10 = 0.316.
  5. 2% settling time ≈ 4/(ζωn) = 4/1 = 4.0 s.
  6. Peak overshoot ≈ e^(−πζ/√(1 − ζ²)) = e^(−π × 0.316/0.949) = e^(−1.047) = 0.3509, about 35.1%.

Answer. The poles are −10 and −1 ± j3; the dominant pair gives ωn = 3.162 rad/s and ζ = 0.316, with 2% settling time ≈ 4.0 s and peak overshoot ≈ 0.3509 (35.1%).

Exam traps

  • Calling a complex pair dominant just because it is the only pair, when a real pole sits two or three times closer to the jω axis.
  • Quoting overshoot from ζ before checking that every neglected pole is at least about five times farther left and has a small residue.
  • Treating a stable pole at −0.2 as good enough: it is stable, but its slow decay gives a long settling time and weak relative stability.
  • Reversing the shift: s = z − σ moves the line s = −σ to z = 0, and all roots must lie left of z = 0, not right.
  • Assuming every added zero improves the response; a zero can speed the loop but also raise overshoot and reduce damping.

Analyze A system has a dominant pair at −1 ± j3 and a real pole at −3. A student uses the second-order formulas. Is the estimate reliable? Explain. 4 marks

No. The real pole is only three times farther left, less than the five-times rule of thumb, and its residue may not be small. The pair-only settling and overshoot values can be wrong; use the full third-order response.

Analyze Why can a zero placed very close to a slow pole make a root-locus design look better than the hardware behaves? 5 marks

The zero and pole almost cancel, so the slow mode has a small residue in the transfer function and is barely visible. Unless the positions are exactly equal, the mode still exists. In hardware, an unstable or poorly damped hidden state can drift even when the input-output response looks clean.

Beyond the syllabus

Not for the exam. Model-order reduction uses the same idea: keep the slow dominant modes and discard fast ones, with balanced truncation giving an error bound. In digital control, sampling adds poles that can become dominant even when the continuous design looks fast. In power electronics, a slow thermal or battery pole often sets the outer-loop bandwidth, so designers check it before tuning the current loop. Search next for dominant pole approximation, model order reduction, balanced truncation, and pole-zero cancellation in robust control.

3.4 Root locus: construction rules, breakaway points, asymptotes

As gain K rises from 0 to ∞, closed-loop poles move along fixed paths: the root locus. Eight rules draw them from open-loop poles and zeros alone. The locus helps choose a gain for desired overshoot and settling time, and place compensator poles and zeros. It is a first pass when tuning a motor drive or a temperature loop.

You need 3.1 for 1 + G H = 0, 3.2 for the Routh jω crossing, and Unit 1 for reducing a block diagram to G(s)H(s).

Where the locus comes from

Unity feedback with forward path K G(s) and sensor path H(s). Closed-loop poles solve:

1 + K G(s)H(s) = 0 → G(s)H(s) = −1/K

K is gain (positive real); G(s)H(s) is the open-loop transfer function; s = σ + jω is complex frequency, σ real part (1/s), ω imaginary part (rad/s).

A complex number equals a real negative number only when magnitude and angle match:

|G(s)H(s)| = 1/K and ∠G(s)H(s) = (2q + 1)180°

q = 0, ±1, ±2, …; |·| is magnitude and ∠ is phase in degrees. The angle condition fixes shape; the magnitude condition gives K at a point.

The angle condition has no K. Points whose open-loop phase is an odd multiple of 180° are fixed by pole and zero positions. K only decides where along that set the poles sit. Phase at s is sum of angles from zeros minus sum from poles. A real pole or zero to the right of s adds 180°; a complex pair adds 360°, which is zero. So only the count to the right matters on the real axis.

The eight construction rules

  1. Rule 1 — branches: there are n branches, where n is number of open-loop poles and m is number of open-loop zeros.
  2. Rule 2 — symmetry: real coefficients give conjugate poles, so the locus mirrors about the real axis.
  3. Rule 3 — endpoints: at K = 0 a branch starts at an open-loop pole. As K → ∞ it ends at an open-loop zero; remaining n − m go to infinity.
  4. Rule 4 — real axis: a point is on the locus when real poles and zeros strictly to its right total an odd count. Test intervals, not individual poles.
  5. Rule 5 — asymptotes: the n − m branches to infinity have angles (2q + 1)180°/(n − m) and meet at centroid σ = (Σ poles − Σ zeros)/(n − m), using real parts only.
  6. Rule 6 — breakaway: where branches meet and split, dK/ds = 0. From K = −1/(G H), differentiate, solve, and keep roots on a rule-4 segment.
  7. Rule 7 — jω crossing: put the characteristic polynomial in a Routh array. The gain where the s¹ row vanishes makes the loop marginal; the auxiliary equation from the s² row gives ω.
  8. Rule 8 — departure angle: at a complex pole p, θ_d = 180° + (sum of angles from other poles to p) − (sum of angles from zeros to p). For arrival at a complex zero, reverse the signs: θ_a = 180° + Σ(angles from zeros) − Σ(angles from poles).

Rules 1 to 5 fix the skeleton. Rules 6 to 8 give the numbers an examiner asks for.

Sketching a third-order system

Use G(s)H(s) = K/(s(s + 2)(s + 4)) with unity feedback. The poles are 0, −2, −4; there are no zeros, so n = 3 and m = 0.

  • Three branches start at 0, −2, −4 and all run to infinity.
  • Real-axis parts are (−2, 0) and (−∞, −4). The stretch (−4, −2) has two poles to its right, so it is not on the locus.
  • The centroid is (0 − 2 − 4)/3 = −2. Asymptote angles are 60°, 180° and 300°, from −2.
  • The branches from 0 and −2 meet at breakaway s = −0.85, K = 3.1. They leave as a complex pair, bend toward 60° and 300°, and cross to the right half plane at K = 48, ω = 2.83 rad/s.

Add a pole at −6: n − m = 4, so asymptote angles are 45°, 135°, 225°, 315° and centroid is −3. Breakaway moves to about s = −0.77 (K ≈ 16), and the jω crossing moves to K = 160 at ω = 2 rad/s. A pole does not always lower critical gain; work the Routh array. Add a zero at −1: n − m = 2, asymptotes are 90° and 270°, centroid is (0 − 2 − 4 + 1)/2 = −2.5. The zero attracts a branch and bends the complex pair left. The loop is stable for every K > 0. That leftward pull is why a compensator zero is placed before a slow pole (see Unit 5, Controllers and Compensators).

Worked example

Question. A unity feedback loop has G(s)H(s) = K/(s(s + 2)(s + 4)). Sketch the root locus and find the gain K at marginal stability, with the oscillation frequency there.

Python program.

import math
n,m=3,0
sigma=(0-2-4)/n
angles=[(2*q+1)*180/(n-m) for q in (0,1,-1)]
a,b,c=3,12,8
disc=b*b-4*a*c
r1=(-b+math.sqrt(disc))/(2*a)
r2=(-b-math.sqrt(disc))/(2*a)
brk=max(r1,r2)
K_brk=-(brk**3+6*brk**2+8*brk)
K_cross=48.0
omega=math.sqrt(K_cross/6)
print("roots of dK/ds =",round(r1,3),round(r2,3))
print("breakaway s =",round(brk,3))
print("K at breakaway =",round(K_brk,2))
print("centroid =",sigma)
print("asymptote angles =",[round(x,1) for x in angles])
print("K at crossing =",K_cross)
print("omega at crossing =",round(omega,2))
  1. Poles 0, −2, −4; no zeros. n = 3, m = 0; three branches go to infinity.
  2. Real-axis parts: (−2, 0) and (−∞, −4). (−4, −2) is not on the locus.
  3. Asymptotes: (2q + 1)180°/3 = 60°, 180°, −60°. Centroid = (0 − 2 − 4)/3 = −2.
  4. K = −(s³ + 6s² + 8s). dK/ds = −(3s² + 12s + 8) = 0 gives s = −0.845 and −3.155.
  5. Reject −3.155: it lies in (−4, −2), not on the locus. Breakaway is s = −0.845.
  6. K at breakaway = 0.845 × 1.155 × 3.155 = 3.08 ≈ 3.1.
  7. Characteristic equation: s³ + 6s² + 8s + K = 0. Routh rows: s³: 1, 8; s²: 6, K; s¹: (48 − K)/6; s⁰: K.
  8. Marginal stability: 48 − K = 0, so K = 48.
  9. Auxiliary equation: 6s² + K = 0. With K = 48, s² = −8, so ω = 2.83 rad/s.

Answer. The locus has branches at poles 0, −2, −4; real-axis parts (−2, 0) and (−∞, −4); asymptotes 60°, 180°, −60° from centroid −2; breakaway s = −0.845 with K ≈ 3.1. The loop is marginal at K = 48, oscillating at ω = 2.83 rad/s.

Exam traps

  • Accepting every root of dK/ds = 0. Here −3.155 lies in (−4, −2), not on the locus, so reject it. Test roots against rule 4.
  • Writing n asymptotes instead of n − m. With n = 3 and m = 1, use two at 90° and 270°.
  • Forgetting zeros in rule 4. Count both real poles and real zeros to the right.
  • Calling every touch a breakaway. A root of dK/ds = 0 on the locus is a breakaway if branches leave the real axis; it is a break-in if they arrive. Decide by branch direction, or by local minimum or maximum of K along that segment.
  • Reading the crossing frequency from the s¹ row. The s¹ row gives K; the auxiliary equation from the s² row gives ω.

Takeaways

  1. For an LTI system, BIBO stability is decided entirely by the locations of the roots of the characteristic equation.
  2. A root in the open left half plane decays with time; a root on the jω axis oscillates without decay; a root in the right half plane grows.
  3. The Routh–Hurwitz test finds the number of right-half-plane roots by counting sign changes in the first column, without solving the polynomial.
  4. Dominant poles are the slowest poles, so they decide settling time and overshoot more than distant fast poles.
  5. The root locus shows how closed-loop poles move as gain changes, so it connects stability to transient shape.
  6. Eight construction rules give the root-locus shape from open-loop poles and zeros, without solving the characteristic equation for every K.
  7. A breakaway point occurs where two real-axis branches meet and leave the real axis; it satisfies dK/ds = 0.
  8. The jω-axis crossing marks the gain at which a stable closed-loop system becomes marginal or unstable.

Glossary

Angle of departure
The angle at which a root-locus branch leaves a complex pole.
Asymptote
A straight-line path followed by root-locus branches at large gain.
Asymptotic stability
Every initial condition decays to zero as time tends to infinity.
Auxiliary equation
An equation taken from the row above a zero row in the Routh array.
BIBO stability
Every bounded input produces a bounded output.
Branch
The path of one closed-loop pole on the root locus.
Breakaway point
A point where root-locus branches meet and leave the real axis.
Characteristic polynomial
The denominator polynomial of the closed-loop transfer function.
Characteristic root
A root of the characteristic equation; a closed-loop pole.
Damping ratio
A dimensionless number ζ that sets overshoot and decay for a second-order pair.
Dominant pole
A closed-loop pole closest to the jω axis whose term decays slowest.
First column
The leftmost column of the Routh array whose sign changes give the number of right-half-plane roots.
jω-axis crossing
The point where a root-locus branch crosses the imaginary axis, marking marginal stability.
Left half plane
The region of the s-plane where Re(s) < 0.
Marginal stability
The response is bounded but does not decay to zero.
Natural frequency
The undamped oscillation frequency ω_n of a second-order pair.
Pole
A complex frequency at which the transfer function becomes infinite.
Relative stability
A measure of how far the closed-loop poles are from the jω axis.
Root locus
The set of closed-loop pole locations as a gain K varies from 0 to ∞.
Routh array
A coefficient table used to count right-half-plane roots without solving the polynomial.
s-plane
The complex plane used to plot poles and zeros of s = σ + jω.
Settling time
Time after which the response stays within a specified band around its final value.
Zero
A complex frequency at which the transfer function becomes zero.
