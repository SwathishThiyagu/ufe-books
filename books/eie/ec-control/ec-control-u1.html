1.1 Open-loop and closed-loop control systems

Every control system tries to hold one physical quantity at a value you choose. A room heater, a water tank, a car's speed — each has a target and a measured result. Open-loop control acts on the target alone and never looks at the result. Closed-loop control measures the result, compares it with the target, and uses the difference to correct itself. That one idea, feedback, separates the two families. It explains why a toaster burns toast but a fridge does not freeze the milk, and how a drone holds its height in wind.

You need: only school algebra and the idea of a function of time; Laplace and transfer functions start in 1.3.

The parts of a control system

A control system forces one physical quantity to follow a target. That quantity is the output, written y(t). The target is the reference or set point, written r(t). Both change with time t, measured in seconds.

  • Plant — the physical process being controlled: the room, the motor, the water tank.
  • Controller — the device that decides what to do, from the reference and the error.
  • Actuator — the part that turns the decision into real action: heater coil, motor drive, valve.
  • Sensor — the measuring element that converts the output into a signal the controller can compare: thermometer, tachometer, float switch.

The error is the gap between target and result. With negative feedback it is the subtraction at the summing junction.

e(t) = r(t) − y(t)

e(t) is the error in the same unit as the reference (for example °C); r(t) is the reference or set point; y(t) is the measured output. The minus sign is the whole point — the controller pushes in the direction that shrinks the gap.

A disturbance is any unwanted input that pushes the output away from the target: a window opened in a heated room, a load torque on a motor, cold water entering a tank.

The path from reference to output is the forward path. The path that carries the measured output back to the comparison is the feedback path.

Open-loop control

Open-loop control drives the plant from the reference alone. There is no sensor, no feedback path, no comparison. The controller is really a schedule: it knows what to do, not what happened. The block order is reference → controller → actuator → plant → output.

  • A toaster runs a timer; it has no colour sensor.
  • A washing machine runs a fixed wash cycle at fixed agitator speed.
  • A traffic light steps through a fixed timing sequence.
  • A stepper motor is moved a fixed number of steps with no encoder.
  • A room heater is switched on for 20 min at 0.5 °C/min from 20 °C, so the room reaches 30 °C — small room, large room, or open window alike.

Advantages: no sensor to buy or calibrate, so it is cheap and simple. The output cannot oscillate because of feedback, since there is no feedback; stability depends only on the forward path.

Disadvantages: a disturbance runs its full course uncorrected. Component drift — an ageing heater, a worn pump — shifts the output with nothing to pull it back. Accuracy depends entirely on calibration done beforehand, and a wrong setting gives a wrong result silently.

Closed-loop control and negative feedback

Closed-loop control measures the output and uses the error. One cycle of operation:

  1. The sensor measures the output y(t).
  2. At the summing junction the reference is compared with the measurement: e(t) = r(t) − y(t).
  3. The controller converts e(t) into an actuator signal.
  4. The actuator drives the plant, so the output moves.
  5. One cycle later the sensor measures again. The loop repeats.

When the sensor gain is exactly 1, so that the fed-back signal is in the same units as the reference, the loop is called unity negative feedback. A sensor with gain H(s) is handled by the feedback rule in 1.8.

The simplest closed-loop action is two-position (on-off) control: the actuator is either fully on or fully off. The output then swings in a small band around the target — the fridge compressor, the electric iron, the water heater in a Chennai flat. Proportional, PI and PID actions come in Unit 5.

Advantages: disturbances are corrected, parameter drift is corrected, and the final output can be far more accurate than the individual components.

Disadvantages: the sensor costs money and needs calibration, sensor noise enters the loop, and too much loop gain causes oscillation or instability (Unit 3). More parts mean more failure points.

Labels: one reference and one output is SISO, single-input single-output. Several inputs and outputs is MIMO. The room heater is SISO; a car with throttle and steering is MIMO.

Physiological example: the body holds core temperature near 37 °C. Sensors in the skin and hypothalamus measure, the hypothalamus acts as controller, and sweating and shivering are the actuators. Fever is a disturbance that shifts the set point itself.

Worked example

Question. A room heater raises the room temperature at 0.5 °C/min while it is on, and the room cools negligibly. The room starts at 20 °C. (a) Open-loop: the heater is switched on for 20 min. Find the final temperature. (b) Closed-loop: a thermostat with target 25 °C checks the sensor once every minute and keeps the heater on while T < 25 °C. Find the heater on-time and the final temperature.

  1. Open-loop temperature rise = rate × time = 0.5 °C/min × 20 min = 10 °C.
  2. Open-loop final temperature = 20 °C + 10 °C = 30 °C. Heater on-time = 20 min.
  3. Closed-loop rise needed = target − start = 25 °C − 20 °C = 5 °C.
  4. Time needed at 0.5 °C/min = 5 °C ÷ 0.5 °C/min = 10 min.
  5. Minute check: after 1 min T = 20.5 °C < 25 °C, heater stays on; after 9 min T = 24.5 °C < 25 °C, still on; after 10 min T = 25.0 °C, which is not less than 25 °C, so the heater switches off.
  6. Closed-loop final temperature = 25 °C, heater on-time = 10 min. The open-loop heater overshoots the target by 5 °C and stays there.

Answer. Open-loop: final temperature 30 °C with 20 min on-time. Closed-loop: final temperature 25 °C with 10 min on-time.

Exam traps

  • A controller does not make a system closed-loop. Without a sensor and a feedback path back to the summing junction, the loop is open — a timer with a fancy display is still a timer.
  • Summing-junction sign: negative feedback subtracts, so e = r − y. If you add, you get positive feedback, which drives the output away from the target.
  • On-off (two-position) control is closed-loop but not proportional. The actuator has only two states, so a small steady oscillation around the target is normal, not a fault.
  • Disturbance versus reference change: a disturbance enters at the plant, a reference change is a new target. The error signal looks similar in both cases; read where the signal enters before deciding.
  • Sensor gain: if a thermometer outputs 10 mV per °C, the feedback path is not unity. Convert to the reference's units before subtracting, or the error carries a hidden scale factor.

1.2 Effects of feedback

Negative feedback subtracts a measured part of the output from the input. It lets an inaccurate forward path behave more accurately, because the loop corrects what the forward path gets wrong. The price is lower forward gain. The same idea gives closed-loop gain, loop gain and sensitivity, and it changes gain, bandwidth, disturbance rejection, noise and stability. Op-amp circuits, motor speed controls and inverter voltage loops holding 230 V use it.

You need: Chapter 1.1 for open-loop and closed-loop control and the meaning of a summing junction.

Closed-loop gain and loop gain

In the block diagram, R(s) is the reference input and C(s) is the output. The feedback path measures C(s) and returns B(s) = H(s)C(s). The summing junction forms the error E(s) = R(s) − B(s). The forward path has gain G(s).

Negative feedback uses the minus sign. The equations are C = G E and E = R − H C. Substitute: C = G(R − H C). Bring C terms together: C(1 + GH) = G R. Divide by R: A(s) = C(s)/R(s) = G(s)/(1 + G(s)H(s)).

A = G / (1 + GH)

A is the closed-loop transfer function; G is the forward-path transfer function; H is the feedback-path transfer function; GH is the loop gain. All are functions of s.

GH is the loop gain. The factor 1 + GH is the desensitivity factor D. For the figure, G = 100 and H = 0.1, so GH = 10 and D = 11. The closed-loop gain is A = 100/11 = 9.0909. The forward gain fell from 100 to about 9.09.

With unity feedback H = 1, A = G/(1 + G). If the summing sign is positive, the denominator becomes 1 − GH; that is positive feedback.

Sensitivity and desensitivity

A small change in G changes A. Differentiate A = G/(1 + GH) with H fixed. dA/dG = 1/(1 + GH)². Divide by A: dA/A = [1/(1 + GH)] (dG/G).

dA/A = S · dG/G, S = 1/(1 + GH)

dA/A is the fractional change in closed-loop gain; dG/G is the fractional change in forward gain; S is the sensitivity of A with respect to G; GH is the loop gain. S is also called the fractional change ratio in some syllabi.

S = 1/D = 1/(1 + GH). For G = 100 and H = 0.1, S = 1/11 = 0.0909. A 10% change in G gives an estimated change in A of 0.0909 × 10% = 0.909%. The estimate is for a small change; it is good for a few percent.

High loop gain makes S small. If GH = 100, S ≈ 0.0099 and A ≈ 1/H for H fixed. The output then depends mostly on H, not G. Feedback does not remove dependence on H: if the sensor gain H drifts, A changes directly. In unity feedback, A = G/(1 + G) and S = 1/(1 + G).

What feedback changes

  • Overall gain: A is smaller than G by the factor D = 1 + GH. This is the gain sacrificed for accuracy.
  • Bandwidth: for a first-order forward path G = K/(1 + sτ) with unity feedback, the closed-loop pole is at −(1 + K)/τ. Bandwidth rises by about 1 + K; gain falls by the same factor, so gain × bandwidth is roughly constant.
  • Disturbance: a disturbance added inside the loop before the output is attenuated by about 1 + GH at low frequency. A disturbance added after the measurement point is not reduced.
  • Noise: feedback cannot separate sensor noise from the true output. Noise in H is fed back and can appear at the output; it is not automatically cancelled.
  • Stability: the closed-loop poles are roots of 1 + G(s)H(s) = 0. Feedback can make a slow system faster and less sensitive, but it can also reduce phase margin and cause oscillation. Stability tests come in Unit 3.
  • Positive feedback: with a plus sign at the summing junction, A = G/(1 − GH). It increases gain and usually drives the system toward saturation or instability.

Feedback reduces the effect of changes in G, not changes in H. It also does not make C exactly equal R; a nonzero error remains unless the loop gain is infinite at that frequency.

Worked example

Question. A negative-feedback loop has forward gain G = 100 and feedback factor H = 0.1. (a) Find the closed-loop gain A and the sensitivity S. (b) If G increases by 10%, estimate the percentage change in A.

  1. Loop gain GH = 100 × 0.1 = 10.
  2. Desensitivity D = 1 + GH = 1 + 10 = 11.
  3. Closed-loop gain A = G/D = 100/11 = 9.0909.
  4. Sensitivity S = 1/D = 1/11 = 0.0909.
  5. Fractional change in G = 10% = 0.10.
  6. dA/A ≈ S × dG/G = 0.0909 × 0.10 = 0.00909.
  7. Percentage change in A = 0.00909 × 100 = 0.909%.

Answer. A = 9.0909; S = 0.0909; a 10% rise in G gives about a 0.909% rise in A.

Exam traps

  • Using 1 + GH when the summing junction has a plus sign; positive feedback uses 1 − GH.
  • Saying feedback makes C exactly equal R. It only reduces the error; finite loop gain leaves a steady-state error.
  • Treating S as sensitivity to H. The formula S = 1/(1 + GH) is sensitivity of A to G.
  • Forgetting that S is a small-change ratio; for a 10% change the exact change differs slightly.
  • Assuming feedback always improves stability. It can reduce phase margin; check 1 + GH = 0 in Unit 3.

1.3 Transfer function and differential equation models

A transfer function is the Laplace-domain ratio of a system's output to its input, taken with zero initial conditions. It turns a linear time-invariant (LTI) differential equation into an algebraic expression in s. Engineers use it to predict response, join subsystems by block diagrams, and design controllers. In a UPI payment app, the server's response to a request can be modelled this way before code is written. The model is compact but assumes linearity and fixed parameters.

You need: 1.1 and 1.2 for the input-output idea, plus basic calculus and the Laplace transform of a derivative.

From differential equation to G(s)

An LTI system obeys a linear differential equation with constant coefficients. Let u(t) be the input and y(t) the output. A concrete case is 2y″(t) + 3y′(t) + y(t) = 4u(t). The Laplace transform converts a derivative into multiplication by s, but only after initial conditions are set to zero. Define U(s) = L{u(t)} and Y(s) = L{y(t)}.

L{y′(t)} = sY(s) − y(0);  L{y″(t)} = s²Y(s) − s y(0) − y′(0)

L is the Laplace transform; s is the complex frequency variable; y(0) and y′(0) are the output and its derivative at t = 0.

  1. Set y(0) = 0 and y′(0) = 0. This removes stored energy and leaves only the input-to-output relation.
  2. Transform each term: 2s²Y(s) + 3sY(s) + Y(s) = 4U(s).
  3. Factor Y(s): (2s² + 3s + 1)Y(s) = 4U(s).
  4. Divide by U(s): G(s) = Y(s)/U(s) = 4/(2s² + 3s + 1).

G(s) = Y(s)/U(s)

G(s) is the transfer function; Y(s) is the Laplace transform of the output; U(s) is the Laplace transform of the input; both transforms use zero initial conditions.

The same rule works for any order. Some syllabi call this the input-output model because it relates only terminal signals, not internal states.

Poles, zeros and properness

Write a SISO transfer function as G(s) = N(s)/D(s). N(s) and D(s) are polynomials in s with real coefficients, after cancelling common factors. Zeros are the roots of N(s) = 0. Poles are the roots of D(s) = 0. The equation D(s) = 0 is the characteristic equation. Poles shape the natural response and stability; zeros shape how inputs combine. For G(s) = 4/(2s² + 3s + 1), solve 2s² + 3s + 1 = 0. Factor as (2s + 1)(s + 1) = 0, so the poles are s = −0.5 rad/s and s = −1 rad/s. The numerator 4 has no finite zero.

  • Proper: degree of N(s) ≤ degree of D(s). A physical system often has this form.
  • Strictly proper: degree of N(s) < degree of D(s). The step response starts from zero.
  • Improper: degree of N(s) > degree of D(s). It differentiates the input and is not a usual physical model.
  • MIMO: with m inputs and p outputs, G(s) becomes a p × m matrix; each entry is one SISO transfer function. State-space models are in Unit 6.

Back to an ODE and what the model hides

  1. Start with G(s) = N(s)/D(s).
  2. Cross-multiply: D(s)Y(s) = N(s)U(s).
  3. Take the inverse Laplace transform with zero initial conditions.
  4. Replace s^k Y(s) by the k-th time derivative of y(t), and do the same for u(t).

For G(s) = 4/(2s² + 3s + 1), cross-multiplication gives (2s² + 3s + 1)Y(s) = 4U(s). Inverse Laplace gives 2y″(t) + 3y′(t) + y(t) = 4u(t). The two models carry the same information under the stated assumptions.

A transfer function exists only for a linear, time-invariant system with zero initial conditions. A nonlinear system, or one whose parameters change with time, does not have a single G(s). Initial conditions can be handled separately as an extra response. State-space models, which keep internal variables, are in Unit 6.

Worked example

Question. A system obeys 2y″(t) + 3y′(t) + y(t) = 4u(t), with zero initial conditions. Find the transfer function, its poles, and its DC gain.

  1. Take the Laplace transform with y(0) = 0 and y′(0) = 0: 2s²Y(s) + 3sY(s) + Y(s) = 4U(s).
  2. Factor: (2s² + 3s + 1)Y(s) = 4U(s).
  3. Divide: G(s) = Y(s)/U(s) = 4/(2s² + 3s + 1).
  4. Set the denominator to zero: 2s² + 3s + 1 = 0. Here a = 2, b = 3, c = 1.
  5. Discriminant: b² − 4ac = 9 − 8 = 1.
  6. Roots: s = (−3 ± √1)/(4), so s = −0.5 rad/s and s = −1 rad/s.
  7. DC gain: put s = 0 in G(s). G(0) = 4/(0 + 0 + 1) = 4.

Answer. G(s) = 4/(2s² + 3s + 1); poles at s = −0.5 rad/s and s = −1 rad/s; DC gain = 4.

Exam traps

  • Leaving y(0) or y′(0) in the Laplace transform. The transfer function definition requires zero initial conditions.
  • Treating a nonlinear or time-varying equation as if it has one G(s). Linearity and fixed parameters are both required.
  • Swapping poles and zeros. Poles are roots of the denominator, which gives the characteristic equation; zeros are roots of the numerator.
  • Forgetting to cancel common factors before naming poles and zeros. A cancelled pole-zero pair is not a pole of the reduced transfer function.
  • Calling G(s) the output. G(s) is a ratio; the actual output is Y(s) = G(s)U(s) plus any initial-condition response.

1.4 Mechanical translational and rotational systems

Mechanical systems move in straight lines or rotate. Newton's second law and its rotational twin turn forces and torques into differential equations. Mass stores kinetic energy, a spring stores elastic energy, and a damper removes energy. With zero initial conditions, the Laplace transform gives a transfer function. Engineers use these models for vehicle suspension, robot arms, motor shafts and door closers. Translational elements are mass m in kg, spring k in N/m and damper c in N·s/m. Rotational elements are inertia J in kg·m², torsional spring kt in N·m/rad and torsional damper b in N·m·s/rad. This chapter builds the equations and transfer functions.

You need: Chapter 1.3 for Laplace transforms and zero initial conditions, and basic Newton's laws.

Translational elements and free-body diagrams

Translational motion is along a straight line. Displacement x is in metres (m), measured from the rest position. Velocity is x′ in m/s and acceleration is x″ in m/s². A mass m in kg stores kinetic energy and gives inertia. A spring k in N/m stores elastic energy; its force on the mass is −k x when x is the extension. A viscous damper c in N·s/m removes energy; its force is −c x′, opposing velocity. Some syllabi call c the damping coefficient.

m x″ + c x′ + k x = F(t)

m is mass in kg; c is viscous damping coefficient in N·s/m; k is spring stiffness in N/m; x is displacement in m; F(t) is external force in N; x′ and x″ are first and second time derivatives.

  1. Draw the free-body diagram: mass as a point, external force F(t) in the positive direction.
  2. Draw spring force −k x and damper force −c x′ opposite to the chosen positive motion.
  3. Write Newton's second law: ΣF = m x″.
  4. Collect terms to get m x″ + c x′ + k x = F(t).
  5. Set zero initial conditions and take the Laplace transform.

If gravity acts, measure x from the static equilibrium position. The weight then cancels the initial spring deflection, so mg does not appear in the equation.

Rotational elements and torque balance

Rotational motion uses angle θ in radians (rad). Angular velocity is θ′ in rad/s and angular acceleration is θ″ in rad/s². Inertia J in kg·m² is the rotational mass. A torsional spring kt in N·m/rad gives torque −kt θ. A torsional damper b in N·m·s/rad gives torque −b θ′. External torque T(t) is in N·m. Newton's second law for rotation is ΣT = J θ″.

J θ″ + b θ′ + kt θ = T(t)

J is moment of inertia in kg·m²; b is torsional damping in N·m·s/rad; kt is torsional stiffness in N·m/rad; θ is angle in rad; T(t) is external torque in N·m.

Transfer functions with zero initial conditions

Take the Laplace transform with zero initial conditions: x(0) = 0, x′(0) = 0, θ(0) = 0 and θ′(0) = 0. Then L{x″} = s²X(s), L{x′} = sX(s) and L{x} = X(s). The translational equation becomes (m s² + c s + k)X(s) = F(s). The rotational equation becomes (J s² + b s + kt)Θ(s) = T(s).

G(s) = X(s)/F(s) = 1/(m s² + c s + k)

G(s) is the transfer function in m/N; X(s) is the Laplace transform of displacement; F(s) is the Laplace transform of force; s is the Laplace variable.

Θ(s)/T(s) = 1/(J s² + b s + kt)

Θ(s) is the Laplace transform of angle; T(s) is the Laplace transform of torque; the ratio has units rad/(N·m).

The denominator is the characteristic polynomial. Write it as s² + 2ζωns + ωn². For translation, ωn = √(k/m) rad/s and ζ = c/(2√(km)). For rotation, ωn = √(kt/J) rad/s and ζ = b/(2√(kt J)). ζ has no unit. The transfer function is valid only for zero initial conditions; nonzero initial values add extra terms to the numerator.

Worked example

Question. A mass m = 2 kg rests on a horizontal surface. It is connected to a spring k = 8 N/m and a viscous damper c = 2 N·s/m. An external force F(t) acts on the mass. Neglect friction. Find the transfer function X(s)/F(s), the natural frequency and the damping ratio.

  1. Data: m = 2 kg, c = 2 N·s/m, k = 8 N/m. Input is F(t) in N; output is x(t) in m.
  2. Free-body diagram: take x positive to the right. External force F acts to the right. Spring force is −8x N. Damper force is −2x′ N.
  3. Newton's second law: ΣF = m x″ gives 2x″ = F − 2x′ − 8x.
  4. Collect terms: 2x″ + 2x′ + 8x = F.
  5. Set zero initial conditions and take Laplace transforms: (2s² + 2s + 8)X(s) = F(s).
  6. Divide: X(s)/F(s) = 1/(2s² + 2s + 8).
  7. Divide numerator and denominator by 2: X(s)/F(s) = 0.5/(s² + s + 4).
  8. Natural frequency: ωn = √(k/m) = √(8/2) = 2 rad/s.
  9. Damping ratio: ζ = c/(2√(km)) = 2/(2√(8×2)) = 0.25.

Answer. The transfer function is X(s)/F(s) = 1/(2s² + 2s + 8) = 0.5/(s² + s + 4) m/N, with natural frequency 2 rad/s and damping ratio 0.25.

Exam traps

  • Sign slip: in ΣF = m x″ the spring and damper forces oppose motion. Writing +k x or +c x′ on the left gives wrong dynamics and often an unstable model.
  • Unit mix-up: c is N·s/m, not N/m; J is kg·m², not kg; kt is N·m/rad; θ is radians, not degrees.
  • Using the transfer function with nonzero initial conditions. G(s) is defined with zero initial displacement and zero initial velocity; extra initial-value terms change the output.
  • Forgetting static equilibrium when gravity acts. Measure x from the equilibrium position, otherwise mg appears twice or with the wrong sign.
  • Treating mass as weight. m is in kg; weight mg is a force in N and belongs on the force side only if you do not shift to equilibrium.

1.5 Electrical analogies of mechanical systems

A mass on a spring with a damper obeys the same second-order equation as an inductor, resistor and capacitor in series. So a mechanical system can be redrawn as an electrical circuit, and circuit tools — impedance, mesh analysis, simulation — then give the same transfer function. Two standard mappings exist: force–voltage and force–current. Engineers use them to test a vehicle suspension or a MEMS accelerometer in a circuit simulator, and examiners use them to check whether you see the equation behind the hardware.

You need: 1.4 for masses, springs and dampers, and 1.3 for the transfer function.

Why a circuit can stand in for a machine

Write Newton's second law for one mass m (kg) pulled by a force F(t) against a spring k (N/m) and a viscous damper b (N·s/m). The displacement is x (m). Then write Kirchhoff's voltage law for an inductor L (H), a resistor R (Ω) and a capacitor C (F) in series, driven by a voltage v(t), with charge q (C).

m ẍ + b ẋ + k x = F(t)   and   L q̈ + R q̇ + (1/C) q = v(t)

ẍ is d²x/dt² (m/s²), ẋ is dx/dt (m/s); q̇ is current i (A), q̈ is di/dt (A/s); L, R, C are inductance, resistance, capacitance.

The two equations have identical shape. Match term by term and the force–voltage (F–V) analogy falls out. It is also called the direct or impedance analogy.

Read the last row twice. The spring becomes the reciprocal of capacitance, so a stiff spring (large k) is a small capacitor. Most marks are lost exactly here.

The force–current analogy and how to build the circuit

The second mapping makes force the current instead of the voltage. It is called the force–current (F–I), inverse or mobility analogy. It exists because in a multi-mass mechanical system the same force passes through elements joined end to end, while velocity is shared only at a common junction. Making force the current lets those elements sit in series, as they do physically.

  1. Draw each mass separately and mark every force on it: applied force, spring force, damper force.
  2. Write the force balance for each mass, then compare it with the L–R–C equation to confirm the mapping.
  3. Replace each element by its electrical partner from the chosen table, keeping the numbers unchanged.
  4. Connect by the sharing rule: in F–V, elements with the same velocity go in series (same current); elements carrying the same force go in parallel (same voltage).
  5. Add the applied force as the source, then write the circuit equation and check it matches the mechanical one.

For a single mass on a wall, the mass, spring and damper all move at the same velocity, so all three are in series — exactly the L–R–C loop. The force F becomes a voltage source of value F volts in that loop.

Reading results back, and where the analogy is used

Once the circuit exists, every mechanical number has a circuit twin. The natural frequency and damping ratio are the same formulas written in two languages.

ωn = √(k/m) = 1/√(LC),   ζ = b / (2√(km)) = (R/2)·√(C/L)

ωn is the undamped natural frequency (rad/s), ζ is the damping ratio (no unit), and the right-hand forms use the analogous L, R, C.

  • Check both sides give the same ωn and ζ before trusting the mapping.
  • A circuit simulator then shows the step response without building the machine — used for vehicle suspensions, machine-tool mounts and MEMS sensors.
  • Only linear elements carry over. Coulomb friction and backlash do not have a resistor or capacitor twin, so the analogy stops there.

Worked example

Question. A translational system has m = 2 kg, b = 3 N·s/m and k = 4 N/m. Using the force–voltage analogy, find the equivalent inductance, resistance and capacitance. Also confirm the natural frequency and damping ratio of the circuit match the mechanical system.

  1. Force balance: m ẍ + b ẋ + k x = F(t), with m = 2 kg, b = 3 N·s/m, k = 4 N/m.
  2. Series RLC equation: L q̈ + R q̇ + q/C = v(t). Matching terms gives L = m, R = b, 1/C = k.
  3. Inductance: L = m = 2 H.
  4. Resistance: R = b = 3 Ω.
  5. Capacitance: C = 1/k = 1/4 = 0.25 F.
  6. Mechanical ωn = √(k/m) = √(4/2) = √2 = 1.4142 rad/s. Circuit ωn = 1/√(LC) = 1/√(2 × 0.25) = 1/√0.5 = 1.4142 rad/s. They agree.
  7. Mechanical ζ = b/(2√(km)) = 3/(2√8) = 3/5.6569 = 0.5303. Circuit ζ = (R/2)√(C/L) = (3/2)√(0.25/2) = 1.5 × 0.3536 = 0.5303. They agree.

Answer. The equivalent circuit is L = 2 H, R = 3 Ω and C = 0.25 F in series with a voltage source v = F, and it has ωn = 1.4142 rad/s and ζ = 0.5303, the same as the mechanical system.

Exam traps

  • In the force–voltage analogy the spring maps to 1/C, so k = 4 N/m gives C = 0.25 F, never C = 4 F.
  • In the force–current analogy the damper maps to conductance G = 1/R, so b = 3 N·s/m is G = 3 S, which is R = 0.333 Ω.
  • Mass is inductance only in the F–V analogy; in F–I the mass becomes a capacitance. Writing L = m in both is the commonest single error.
  • Do not mix the two analogies in one circuit. Pick one table and use it for every element and for the source.
  • Velocity maps to current, not to voltage, under F–V. Swapping them reverses the series/parallel rule and the circuit equation no longer matches.

1.6 Electromechanical systems and servomotors

A servomotor turns an electrical voltage into mechanical motion. The armature circuit has resistance and inductance, and it also produces a back emf proportional to speed. Current creates torque proportional to current. The torque drives a load with inertia and friction. Two equations, one electrical and one mechanical, join at torque and speed. This chapter derives the transfer function from armature voltage to shaft angle. It is used in position control of robot arms, printers, antenna drives and valve actuators. The same model appears in many lab experiments.

You need: 1.3 for Laplace transfer functions and 1.4 for J and b.

Two coupled equations

An armature-controlled DC servomotor has a fixed field. The control input is the armature voltage va(t). The armature circuit has resistance R (Ω) and inductance L (H). The current i(t) (A) obeys the voltage equation.

va = R i + L di/dt + Kb ω

va is armature voltage in V; i is armature current in A; R is armature resistance in Ω; L is armature inductance in H; ω is shaft speed in rad/s; Kb is the back-emf constant in V·s/rad.

Back emf: when the rotor turns, the armature cuts magnetic flux and acts as a generator. This back emf Kb ω opposes va. It is not a separate battery; it is a voltage inside the same winding.

The current produces torque. Kt is the torque constant in N·m/A. In SI units, Kt and Kb are often equal numerically when losses are ignored, but they are separate constants in the model.

T = Kt i

T is motor torque in N·m; Kt is torque constant in N·m/A; i is armature current in A.

The load has inertia J (kg·m²) and viscous friction b (N·m·s/rad). Newton's law for rotation gives the mechanical equation with zero load torque. The shaft angle θ (rad) satisfies dθ/dt = ω.

J dω/dt + b ω = T, dθ/dt = ω

J is load inertia in kg·m²; b is viscous friction in N·m·s/rad; ω is shaft speed in rad/s; T is motor torque in N·m; θ is shaft angle in rad.

Deriving θ(s)/Va(s)

Use Laplace transforms with zero initial conditions. Write ω(s) = s θ(s). The electrical equation becomes Va(s) = (R + Ls) I(s) + Kb s θ(s). The torque equation gives T(s) = Kt I(s). The mechanical equation becomes (Js + b) s θ(s) = T(s).

  1. From the mechanical side, write I(s) = (Js + b) s θ(s) / Kt.
  2. Substitute this I(s) into the electrical equation.
  3. Multiply both sides by Kt and collect the θ(s) terms.
  4. Divide to get the transfer function.
θ(s)/Va(s) = Kt / {s[(Ls + R)(Js + b) + Kt Kb]}

θ(s) is shaft angle in rad; Va(s) is armature voltage in V; Kt is torque constant in N·m/A; Kb is back-emf constant in V·s/rad; R is armature resistance in Ω; L is armature inductance in H; J is inertia in kg·m²; b is viscous friction in N·m·s/rad.

If the output is speed, the transfer function is ω(s)/Va(s) = Kt / [(Ls + R)(Js + b) + Kt Kb]. The angle transfer has one extra s because θ′ = ω. That extra s is an integrator. The denominator is cubic: one s from angle integration and a second-order electrical-mechanical part after it.

AC servomotors and use

A two-phase AC servomotor has a reference winding and a control winding. The control voltage sets the torque direction and size. It has low rotor inertia, so it starts and stops quickly. Detailed AC servo models need rotating-field theory; only a few universities teach that depth. Most first courses stay with the DC armature model above.

A position control loop uses this motor as the actuator. A command angle θr is compared with the measured angle θ. The error drives an amplifier, and the amplifier output is va. The motor transfer function gives θ(s)/Va(s). The sensor gain sits in the feedback path. Block diagram reduction (see 1.8) then gives the closed-loop transfer function. The same model explains why a printer head or robot joint settles slowly when J and b are large.

Some syllabi call this actuator modelling. The aim is one transfer function from voltage to motion. Speed control uses ω(s)/Va(s); position control uses θ(s)/Va(s). The difference is one factor s, so always check which output the question asks for.

Worked example

Question. An armature-controlled DC servomotor has R = 1 Ω, L = 0.1 H, Kt = 0.5 N·m/A, Kb = 0.5 V·s/rad, J = 0.01 kg·m² and b = 0.1 N·m·s/rad. The load torque is zero. Find θ(s)/Va(s).

  1. Write the electrical equation in Laplace form: Va(s) = (Ls + R)I(s) + Kb sθ(s). Insert L = 0.1 H and R = 1 Ω: Va = (0.1s + 1)I + 0.5sθ.
  2. Write the mechanical equation: (Js + b)sθ(s) = Kt I(s). Insert J = 0.01 kg·m², b = 0.1 N·m·s/rad and Kt = 0.5 N·m/A: (0.01s + 0.1)sθ = 0.5I.
  3. Use the derived form. The bracket is (Ls + R)(Js + b) + Kt Kb. Compute (0.1s + 1)(0.01s + 0.1) = 0.001s² + 0.02s + 0.1. Add Kt Kb = (0.5)(0.5) = 0.25. The bracket becomes 0.001s² + 0.02s + 0.35.
  4. Multiply the bracket by s and put Kt = 0.5 on top: θ(s)/Va(s) = 0.5/[s(0.001s² + 0.02s + 0.35)] = 0.5/(0.001s³ + 0.02s² + 0.35s).

Answer. θ(s)/Va(s) = 0.5/(0.001s³ + 0.02s² + 0.35s) rad/V.

Exam traps

  • Forgetting the back-emf term Kb sθ(s) in the Laplace electrical equation. This term is the feedback from speed to the armature circuit.
  • Using ω(s) when the question asks for θ(s). Angle adds one factor 1/s because ω = sθ.
  • Mixing units: Kb is in V·s/rad, not V/rad; Kt is in N·m/A, not N/A.
  • Cancelling Kt and Kb blindly. They are often equal numerically in SI when losses are ignored, but use the given values.
  • Adding a load torque when the question says zero load torque. With load torque TL, the mechanical equation becomes J dω/dt + bω = T − TL.

1.7 Thermal, liquid-level and pneumatic systems

Heat, liquid level and gas pressure change when material or energy flows in or out. Each store holds what enters and each resistance limits the flow, so a tank, a room and a pressure vessel share a first-order model. Engineers use these models to size heaters, tune water-plant level loops, and predict pressure in pneumatic lines. The same conservation law that gave mechanical and electrical models applies: input minus output accumulates in a store.

You need Chapter 1.3 for Laplace transforms and transfer functions.

Liquid-level tank as a first-order system

A tank of uniform area A (m²) holds liquid. Around an operating point with level h0 and outflow q0, let h (m), qin (m³/s) and qout (m³/s) be small deviations from their operating values. A sharp-edged outlet follows qout,abs = Cd a √(2 g h_abs). Linearising about h0 gives qout,abs = q0 + (h_abs − h0)/R, where R = 2h0/q0. In deviation variables h = h_abs − h0 and qout = qout,abs − q0, so qout = h/R. Here R (s/m²) is liquid resistance: a narrow outlet gives large R and slow draining. The stored volume changes by A h, so conservation of volume gives A dh/dt = qin − h/R.

A dh/dt = qin − h/R

A is tank area in m²; h is liquid-level deviation in m; qin is inflow deviation in m³/s; R is liquid resistance in s/m²; t is time in s.

Take Laplace with zero initial conditions: (A s + 1/R)H(s) = Qin(s). Hence H(s)/Qin(s) = R/(A R s + 1). The time constant is τ = A R, in seconds. The steady gain is R, in s/m². A step inflow Q gives final level change Q R. The model is linear only for small changes. A real sharp-edged outlet follows qout,abs = Cd a √(2 g h_abs), which is nonlinear; linearisation at an operating point gives the R used here.

Thermal storage and resistance

A body stores heat in its heat capacity Ct (J/°C). Heat flow qin (W) enters. Heat escapes to surroundings at temperature Ta through thermal resistance Rt (°C/W). Let θ = T − Ta be temperature rise above ambient, in °C. Energy balance gives the first formula below. The first term heats the body; the second leaks heat to ambient.

qin = Ct dT/dt + (T − Ta)/Rt

qin is heat flow in W; Ct is heat capacity in J/°C; T is body temperature in °C; Ta is ambient temperature in °C; Rt is thermal resistance in °C/W; t is time in s.

With θ(0) = 0, Laplace gives Θ(s)/Qin(s) = Rt/(Ct Rt s + 1). The time constant is τt = Ct Rt, in seconds. The steady gain is Rt, in °C/W. A room heater, a thermocouple bead and a hot-water tank use this form. Keep one reference: use ambient Ta for θ, or use absolute T everywhere, never mix. Radiation and fan cooling are nonlinear; the linear model holds for small changes. Some syllabi call these process models.

Pneumatic pressure and volume

A pneumatic system stores gas in a volume and resists flow through a restriction. Let p (Pa) be pressure and p0 a fixed reference. For small changes, pressure-flow resistance is Rp = Δp/q, where q is the flow variable. Volume capacitance Cp relates stored gas to pressure. For mass flow and isothermal small changes in an ideal gas in fixed volume V at absolute temperature T, Cp = V/(Rg T); Rg is the specific gas constant in J/(kg K). For adiabatic small changes, Cp = V/(γ Rg T), where γ is the ratio of specific heats.

Cp dp/dt = qin − (p − p0)/Rp

Cp is pneumatic capacitance in kg/Pa when q is mass flow; p is pressure in Pa; p0 is reference pressure in Pa; qin is mass inflow in kg/s; Rp is pressure-flow resistance in Pa/(kg/s); t is time in s.

Take small changes with zero initial conditions: P(s)/Qin(s) = Rp/(Rp Cp s + 1). The time constant is τp = Rp Cp. This first-order form is valid only near an operating pressure. Valve flow and gas compressibility are nonlinear; linearisation gives the small-signal Rp and Cp. For volumetric flow at reference density ρ (kg/m³), use Rp,vol = ρ Rp,mass and Cp,vol = Cp,mass/ρ = V/(ρ Rg T), or convert the volumetric flow to mass flow qmass = ρ qvol before using the mass-flow formula.

Worked example

Question. A tank has area A = 2 m² and a linear outflow qout = h/R with R = 5 s/m². The inflow is a step from 0 to qin = 0.1 m³/s at t = 0. Find H(s)/Qin(s), the time constant, and the final level.

  1. Conservation of volume: A dh/dt = qin − h/R.
  2. Substitute A = 2 m² and R = 5 s/m²: 2 dh/dt = qin − h/5.
  3. Take Laplace with zero initial conditions: (2s + 1/5)H(s) = Qin(s).
  4. Rearrange: H(s)/Qin(s) = 1/(2s + 1/5). Multiply top and bottom by 5: H(s)/Qin(s) = 5/(10s + 1) s/m².
  5. The denominator is 10s + 1, so the time constant is τ = 10 s.
  6. For final level use the steady balance qin = h/R, so h = R qin = 5 × 0.1 = 0.5 m.

Answer. H(s)/Qin(s) = 5/(10s + 1) s/m², the time constant is 10 s, and the final level is 0.5 m.

Exam traps

  • Mixing gauge and absolute references: with θ = T − Ta the loss term is θ/Rt; with absolute T the loss term is (T − Ta)/Rt. Do not use T in place of θ in one term and T − Ta in another.
  • Using the liquid-level model for large changes: qout = h/R is a linearised outflow, not the true sharp-edged orifice law qout ∝ √h.
  • Unit slip in thermal resistance: Rt is in °C/W, not W/°C. Ct Rt must give seconds.
  • Using A in cm² while R is in s/m²: convert area to m² before computing τ = A R or the time constant is wrong by 10⁴.
  • Using volume V directly as pneumatic capacitance: for a gas, Cp depends on V, Rg and T, and the flow type must match Rp.

1.8 Block diagram reduction

A block diagram draws a control system as boxes joined by arrows. Each box holds one transfer function. A circle with Σ adds or subtracts signals. Block diagram reduction replaces the whole network by one transfer function from input R(s) to output C(s). The rules are algebraic: series blocks multiply, parallel blocks add with sign, and a feedback loop becomes G/(1+GH). Engineers use this to get a single model before time-response or stability work. It also shows how a take-off point or summing point can be moved without changing the input-output relation.

You need: transfer functions from 1.3 and the feedback idea from 1.2.

Series, parallel, and feedback rules

Name every block by its transfer function. Let G1 and G2 be two transfer functions. Let R(s) be the input and C(s) the output. Some syllabi call these rules block diagram algebra.

G = G1 G2

G is the combined transfer function; G1 and G2 are in cascade with no branch between them.

Series rule: multiply blocks when no summing point or take-off point sits between them. Parallel rule: add or subtract paths that start at the same node and end at the same summing point.

G = G1 ± G2

G1 and G2 are parallel paths from the same input to the same summing point; use + for the same sign and − for opposite signs.

Canonical negative feedback has forward path G and feedback path H. The error is E = R − H C. The forward block gives C = G E. Eliminate E to get the closed-loop transfer function.

C(s)/R(s) = G/(1 + GH)

G is the forward-path transfer function, H is the feedback-path transfer function, and GH is the loop gain; this is for negative feedback. For positive feedback use 1 − GH.

The sign at Σ belongs to the rule. A minus feedback sign gives 1 + GH. A plus feedback sign gives 1 − GH. Ignoring this changes the denominator.

Moving a summing point or a take-off point

A summing point is the circle Σ. A take-off point is a dot where a signal branches without changing the main path. Use ahead for upstream, towards the input. Use behind for downstream, towards the output. In each rule below, G is the block that the summing point or take-off point is moved across.

  • Summing point moved ahead across G: insert 1/G in the branch that now crosses the block. Check: G(R ± X/G) = GR ± X.
  • Summing point moved behind across G: multiply each input that used to enter the sum by G. Check: G(R ± X) = GR ± GX.
  • Take-off point moved ahead across G: insert G in the take-off branch. The tapped signal stays GX.
  • Take-off point moved behind across G: insert 1/G in the take-off branch. The tapped signal stays X.
  1. Start at the innermost loop. Replace series and parallel groups inside it first.
  2. Eliminate each feedback loop with C/R = G/(1 + GH). Keep the minus sign for negative feedback.
  3. Move a summing point or take-off point only when a branch blocks reduction. Add the compensating block as above.
  4. Repeat until one block remains. Check the dc gain at s = 0 as a quick test.

Worked example

Question. Reduce the negative-feedback block diagram with G1 = 2/(s+1), G2 = 3/(s+2) in series and H = 1. Find C(s)/R(s). Also find the dc gain at s = 0.

  1. G1 and G2 are in series with no branch between them. G1 G2 = [2/(s+1)][3/(s+2)] = 6/((s+1)(s+2)) = 6/(s²+3s+2).
  2. The feedback path is H = 1 with a minus sign. Loop gain GH = G1 G2 H = 6/(s²+3s+2).
  3. Use the negative-feedback rule C/R = G/(1+GH). The denominator is 1 + 6/(s²+3s+2) = (s²+3s+2+6)/(s²+3s+2) = (s²+3s+8)/(s²+3s+2).
  4. Divide the forward path by that denominator: C/R = [6/(s²+3s+2)] / [(s²+3s+8)/(s²+3s+2)] = 6/(s²+3s+8).
  5. Set s = 0 for dc gain: C(0)/R(0) = 6/(0+0+8) = 6/8 = 0.75.

Answer. The closed-loop transfer function is C(s)/R(s) = 6/(s²+3s+8), and its dc gain is 0.75 (unitless).

Exam traps

  • Dropping the minus sign at the summing junction. Negative feedback gives 1+GH, not 1−GH; positive feedback gives 1−GH.
  • Moving a take-off point without the compensating factor. A branch taken before G must get 1/G if moved after G (the tapped signal is GX there, so divide by G to keep X); a branch taken after G must get G if moved before G (the tapped signal is X there, so multiply by G to keep GX).
  • Adding parallel blocks without checking signs. G1+G2 applies only when both paths reach the summing point with the same sign; otherwise use G1−G2.
  • Applying the feedback formula to a loop that still contains series or parallel paths. Reduce the forward path and feedback path to one block each before using G/(1+GH).
  • Treating a summing point as a take-off point. A summing point adds or subtracts signals; a take-off point copies a signal without change.

1.9 Signal flow graphs and Mason's gain formula

A signal flow graph draws the same equations as a block diagram using only nodes and directed branches. A node is a signal; a branch is a gain. Mason's gain formula then gives the transfer function by counting forward paths and loops, with no step-by-step redrawing. It exists because block diagram reduction gets slow when several loops share blocks. Engineers use it on multi-loop hardware — motor speed loops, feedback amplifiers, process control loops — and examiners use it to check whether you can count loops correctly.

You need: transfer functions (1.3) and block diagram reduction (1.8).

Signals become nodes, blocks become branches

A signal flow graph (SFG) is a directed graph that carries exactly the same information as the equations of the system. Each node is one signal, written by its name: R, E, C. Each branch is a directed line from one node to another, and its branch gain (also called transmittance) is written beside it. The relation y = a·x is drawn as a branch from node x to node y with gain a.

A node with only outgoing branches is a source node; it holds the input R(s). A node with only incoming branches is a sink node; it holds the output C(s). Every other node has both, and that is where signals get added.

  • Take every signal in the block diagram — input, error, output of each block, output of each summing point — as one node.
  • Take every block of transfer function G as a branch of gain G from its input node to its output node.
  • Take every summing point as a node; each input to it enters as a branch of gain +1, −1 or the feedback gain.
  • A signal used at two places is one node with two outgoing branches, so take-off points need no extra nodes.
  • A negative feedback path from C to the summing point becomes a branch from C to the error node with gain −H.

Mason's gain formula

A forward path goes from the source to the sink without visiting any node twice. Its path gain Pk is the product of the branch gains on it. A loop is a closed path that starts and ends at the same node without visiting any other node twice. Its loop gain Li is the product of branch gains around it, sign included: a branch of gain −H makes the loop gain negative.

Two loops are non-touching when they share no node at all. Sharing even one node makes them touching, and touching loops never appear together in one product.

Δ = 1 − ΣLi + ΣLiLj − ΣLiLjLk + …

Li is the gain of the i-th loop; LiLj is the product of one pair of non-touching loops; LiLjLk is a product of three mutually non-touching loops; signs alternate. Δ is the graph determinant.

T = C(s)/R(s) = (P1Δ1 + P2Δ2 + …)/Δ

Pk is the gain of the k-th forward path; Δk is Δ recomputed after deleting every loop that touches path k; if a path touches all loops, Δk = 1.

Δk is not a fresh formula. Write Δ, cross out the terms of the loops that touch path k, and what remains is Δk. A path that touches no loop keeps Δk = Δ.

Working order, and counting loops safely

  1. List the nodes in signal order, source first.
  2. Find every forward path from source to sink and write each Pk as a product.
  3. Find every loop and write each Li with its sign; count a set of nodes once, whichever way round you walk it.
  4. Compare node sets to separate touching loops from non-touching pairs and triples.
  5. Build Δ term by term, then Δk for each path.
  6. Substitute in T = ΣPkΔk / Δ and simplify.

A loop gain is negative when the loop holds an odd number of negative branches. With negative feedback, −ΣLi is positive, so Δ is larger than 1 — the same '1 + open-loop gain' that appears in the feedback rule of 1.8.

Two loops often look separate on paper but meet at one node. Test touching by listing nodes, never by looking at the drawing.

Worked example

Question. A negative-feedback system has forward blocks G1 = 2/(s+1) and G2 = 3/(s+2) in series, and feedback H = 1. Draw the signal flow graph and use Mason's gain formula to find C(s)/R(s).

  1. Nodes: R (source), E (error), X (output of G1), C (sink).
  2. Branches: R→E gain 1; E→X gain G1; X→C gain G2; C→E gain −H = −1.
  3. Forward paths: only R→E→X→C. P1 = 1 × G1 × G2 = 6/((s+1)(s+2)).
  4. Loops: only E→X→C→E. L1 = G1 × G2 × (−H) = −6/((s+1)(s+2)).
  5. No other loops and no loop pairs, so Δ = 1 − L1 = 1 + 6/((s+1)(s+2)) = (s² + 3s + 8)/((s+1)(s+2)).
  6. The loop uses nodes E, X, C, so it touches P1 and Δ1 = 1.
  7. T = P1Δ1/Δ = [6/((s+1)(s+2))] ÷ [(s² + 3s + 8)/((s+1)(s+2))] = 6/(s² + 3s + 8).
  8. Check at s = 1: G1 = 2/2 = 1, G2 = 3/3 = 1, so P1 = 1, L1 = −1, Δ = 2, T = 0.5. Direct formula gives 6/(1 + 3 + 8) = 6/12 = 0.5. Poles are at s = (−3 ± j√23)/2, both in the left half plane.

Answer. C(s)/R(s) = 6/(s² + 3s + 8); at s = 1 the gain is 0.5, matching P1 = 1 with Δ = 2.

Exam traps

  • Calling two loops non-touching when they share one node. One common node means touching, so no LiLj term exists for that pair.
  • Writing Δk = 1 blindly. Δk = 1 only when the path touches every loop; a non-touching loop must stay in Δk.
  • Dropping the minus sign of the feedback branch. Then Δ = 1 − |L1| instead of 1 + |L1|, and the denominator loses its correct sign.
  • Counting the same loop twice, once clockwise and once anticlockwise. A loop is defined by its set of nodes.
  • Using Δ1 for every forward path in a graph with two or more forward paths.

Passing a node twice would make the path contain a loop. Then the same signal would be counted both as a direct route and as a route through the loop, and Mason's formula would double-count it; loops are handled separately by Δ.

Takeaways

  1. Open-loop control sets the input blindly; closed-loop control measures the output and acts on the error, so it can correct what it did not predict.
  2. Negative feedback trades forward gain for wider bandwidth, smaller sensitivity to parameter drift and weaker disturbance and noise effects.
  3. A transfer function exists only for linear time-invariant systems with zero initial conditions; it is the Laplace ratio of output to input.
  4. Translational and rotational mechanical systems both follow the same form: inertia times acceleration plus damping plus stiffness equals the applied force or torque.
  5. Force-voltage and force-current analogies let a mechanical model be solved with ordinary circuit analysis, giving the same transfer function.
  6. In a DC servomotor the coupling is through the torque constant K_t and the back-emf constant K_b, which are numerically equal in SI units.
  7. Thermal, liquid-level and pneumatic systems reduce to resistance-capacitance networks, often first order.
  8. Block diagram reduction and Mason's gain formula are two routes to the same overall transfer function; the signal flow graph is usually faster for heavily interconnected systems.

Start from T = G/(1 + GH); differentiate with respect to G; Obtain S = 1/(1 + GH), so the fractional change in T is 1/(1 + GH) times that in G; Example: with GH = 99, a 10 % rise in G gives about 0.1 % rise in T; Price: forward gain drops by the same factor and the system needs a larger amplifier, more hardware and a wider bandwidth, which admits more high-frequency noise.

Analyze A disturbance d(t) enters at the plant input and separately at the plant output. Analyse its effect on the output for open-loop and closed-loop operation and compare. 12 marks

Plant input disturbance: output due to d is G_d/(1 + GH), attenuated by the loop; Output-side disturbance: output due to d is 1/(1 + GH) only if the sensor sees it; otherwise it is not corrected; Open-loop case: the output is G_d d with no attenuation; Conclusion: feedback suppresses disturbances inside the loop and leaves those in the feedback path unchanged.

Evaluate For a given mechanical translational system, draw the force-voltage analogous circuit, find the transfer function by circuit analysis, and judge whether the analogy or a direct mechanical solution is the better exam route. 13 marks

Write the mechanical equations of motion for each mass; Map each mass to an inductance, damper to resistance and spring to inverse capacitance; Write mesh equations of the analogous circuit and solve for the wanted variable; Show the two transfer functions are identical; Judge: the analogy is safer for coupled multi-mass problems; the direct route is faster for a single mass.

Evaluate Compare block diagram reduction and Mason's gain formula for finding the transfer function of a multi-loop system, and state when each method is preferable. 12 marks

Block reduction: graphical, rule based, error prone when take-off points must be shifted across summing points; Mason: one formula T = (1/Δ)ΣPₖΔₖ, no redrawing, but loop identification must be exhaustive; Mason's gain formula wins for many loops and non-touching loops; block reduction is clearer for a simple series-feedback chain; Both must give the same characteristic polynomial, which is the check on the answer.

Glossary

Actuator
The component that turns a control signal into the physical effort applied to the plant, such as a motor or a valve.
Back emf
The voltage induced in a rotating armature, proportional to speed, which opposes the applied armature voltage.
Block diagram
A drawing in which each system element is a block with its transfer function and arrows show the direction of signals.
Branch
A single directed line in a signal flow graph with a stated gain.
Characteristic equation
The denominator of the closed-loop transfer function set to zero; its roots decide the system's natural response and stability.
Closed-loop system
A system that measures its own output and uses the difference from the reference to drive the plant.
Damper
A viscous element producing a force or torque proportional to velocity, with coefficient c or D.
Disturbance
An unwanted input that enters the system and pushes the output away from the reference.
Feedback path
The blocks and sensor that carry the measured output back to the summing point.
Forward path
The blocks from the summing point through the controller, actuator and plant to the output; also a node-free path from source to sink in a signal flow graph.
Laplace transform
The integral transform F(s) = ∫₀^∞ f(t) e^(−st) dt that turns differential equations into algebraic equations in s.
Loop gain
The product of branch gains around a closed loop in a signal flow graph.
Mason's gain formula
T = (1/Δ) Σ Pₖ Δₖ, where Pₖ is a forward-path gain and Δ the graph determinant.
Node
A point in a signal flow graph representing a variable; the source node has only outgoing branches and the sink node only incoming ones.
Non-touching loops
Loops that share no node, so their gains multiply and appear with alternating sign in the graph determinant.
Open-loop system
A system whose input is fixed without any measurement of the output.
Plant
The physical process whose output is to be controlled.
Sensitivity
The fractional change in the overall transfer function divided by the fractional change in a parameter.
Sensor
The measuring device in the feedback path, for example a tachometer or a thermocouple.
Servomotor
A small motor used as an actuator in control loops, modelled with armature resistance, inductance, torque constant and back-emf constant.
Signal flow graph
A directed graph whose nodes are system variables and whose branches carry transfer-function gains.
Summing point
A junction where two or more signals are added or subtracted, marked with a cross and signs.
Take-off point
A point on a signal line from which the same signal is tapped and sent elsewhere.
Transfer function
The Laplace ratio of output to input of a linear time-invariant system with zero initial conditions.
