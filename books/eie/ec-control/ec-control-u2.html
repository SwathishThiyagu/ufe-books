2.1 Standard test signals

Every real command to a control system is messy: a switch clicks, a valve opens, a target moves. To compare systems fairly, engineers replace the mess with four ideal inputs: impulse, step, ramp and parabola. Each has a simple Laplace transform, so the response can be worked out by algebra. A servomotor tracking a satellite, a heater holding temperature, or a motor starting from rest is tested with these signals. The same signals later decide steady-state error.

You need Unit 1: the transfer function and the Laplace transform of standard functions.

The four standard inputs

Four ideal signals cover most commands. The unit impulse δ(t) is zero for every t except t = 0. At t = 0 it is a spike of area 1. It is defined by its area, not by a height. The unit step 1(t) is 0 for t < 0 and 1 for t ≥ 0. It is also written u(t). The unit ramp is t·1(t): zero before t = 0, then a straight line of slope 1. The unit parabolic input is (t²/2)·1(t): zero before t = 0, then a curve that rises as t²/2. The factor 1/2 makes its slope at time t equal to t, so its second derivative is 1.

L{δ(t)} = 1,   L{1(t)} = 1/s,   L{t·1(t)} = 1/s²,   L{(t²/2)·1(t)} = 1/s³

L{ } is the Laplace transform; s is the Laplace variable, in s⁻¹; δ(t) is the unit impulse; 1(t) is the unit step. Each transform follows from L{f(t)} = ∫₀∞ f(t)e−stdt with f(t) as defined.

Integral and derivative links

Each signal is the integral of the one before it. The step is the integral of the impulse: 1(t) = ∫ from −∞ to t δ(τ)dτ. The ramp is the integral of the step: t·1(t) = ∫ from −∞ to t 1(τ)dτ. The parabola is the integral of the ramp: (t²/2)·1(t) = ∫ from −∞ to t τ·1(τ)dτ. Going the other way, differentiate: d/dt 1(t) = δ(t), d/dt t·1(t) = 1(t), d/dt (t²/2)·1(t) = t·1(t).

The impulse has the sifting property: ∫ from −∞ to ∞ f(t)δ(t−a)dt = f(a), for f continuous at t = a. This property lets an impulse pick out one value of a signal. Scaling is simple. If r(t) = A·1(t), then R(s) = A/s. If r(t) = A t·1(t), then R(s) = A/s². If r(t) = A (t²/2)·1(t), then R(s) = A/s³. If r(t) = A δ(t), then R(s) = A. A is the amplitude or strength, in the same units as the signal.

Why these signals matter

Each ideal signal stands for a real event. A step is a switch closed, a valve opened, or a setpoint changed from one value to another. A ramp is a target moving at constant speed: an antenna tracking a satellite, or a radar following an aircraft. A parabola is a target with constant acceleration, such as a falling body or a missile under thrust. An impulse is a hammer blow, a very short pulse, or a lightning surge.

Engineers use these signals because the response to each one exposes a different property. The step shows speed and overshoot. The ramp shows lag and steady-state error to a moving target. The parabola shows error to an accelerating target. The impulse shows the system's natural modes in one shot. The signals also let two systems be compared like for like: same input, same graph axes. The input type later sets the steady-state error through the system type (see 2.2 and 2.6). The shape of the transient is covered in 2.3 and 2.4. Some syllabi call this chapter 'standard test inputs' or 'standard test signals and their importance'.

Worked example

Question. A command signal is r(t) = 2·1(t) + 3t·1(t) − 2δ(t), where 1(t) is the unit step and δ(t) is the unit impulse. Find the Laplace transform R(s).

  1. Use linearity: R(s) = L{2·1(t)} + L{3t·1(t)} + L{−2δ(t)}.
  2. Take the constant out: L{2·1(t)} = 2 L{1(t)} = 2 × (1/s) = 2/s.
  3. Take the constant out: L{3t·1(t)} = 3 L{t·1(t)} = 3 × (1/s²) = 3/s².
  4. Take the constant out: L{−2δ(t)} = −2 L{δ(t)} = −2 × 1 = −2.
  5. Add the three terms: R(s) = 2/s + 3/s² − 2.

Answer. R(s) = 2/s + 3/s² − 2.

Exam traps

  • The unit parabolic input is (t²/2)·1(t), not t²·1(t). Writing 1/s² for a parabola, or leaving out the factor 1/2, loses marks in almost every paper.
  • L{δ(t)} = 1, not 1/s. The impulse is not the step.
  • A step of amplitude A gives A/s. A ramp of slope A gives A/s². Do not swap the two.
  • In the sifting property, ∫f(t)δ(t−a)dt = f(a), not f(0) unless a = 0.
  • The derivative of the unit step is the impulse. The derivative of the unit ramp is the step. Do not reverse these links.

2.2 Type and order of a system

Every open-loop transfer function carries two labels that decide different things. The order counts the poles, so it sets how many natural modes shape the transient. The type counts only the poles at s = 0, so it sets the steady-state error for a step, ramp or parabola. A designer uses type to meet an accuracy target and order to know what transient to expect. In a motor position loop, a type-1 open loop gives zero step error; the order tells whether the response has one time constant or a ringing second-order pair.

You need Unit 1 transfer functions and Chapter 2.1 for step, ramp and parabola inputs.

Poles, zeros, order and type

Write the open-loop transfer function of a unity feedback system in pole-zero form: G(s) = K(s+z₁)(s+z₂)… / [sN(s+p₁)(s+p₂)…]. Here G(s) is the forward-path transfer function when the feedback path is H(s)=1; s is the Laplace variable in s⁻¹; K is the gain; z₁, z₂, … are the magnitudes of the zeros, so G(s)=0 at s = −z₁, −z₂, …; p₁, p₂, … are the magnitudes of the nonzero poles, so the nonzero poles sit at s = −p₁, −p₂, …; N is the number of poles at s = 0. A factor (s+3) means a zero of magnitude 3 at s = −3, and (s+5) means a pole of magnitude 5 at s = −5. A pole at s = 0 is an integrator, because 1/s integrates in time.

The order n is the degree of the denominator after cancelling common factors. Equivalently, n = N + number of nonzero poles. The type N is the number of poles at s = 0. Some syllabi call it system type or error type.

  • Type 0, order 2: G(s)=10/[(s+2)(s+5)]. No origin pole; two nonzero poles.
  • Type 1, order 2: G(s)=4/[s(s+3)]. One origin pole; one nonzero pole.
  • Type 2, order 4: G(s)=20(s+3)/[s²(s+1)(s+5)]. Two origin poles; two nonzero poles.
  • Type 3, order 4: G(s)=7/[s³(s+1)]. Three origin poles; one nonzero pole.

For a non-unity feedback system with forward path G(s) and feedback H(s), the error transfer function is E(s)/R(s)=1/[1+G(s)H(s)]. Write the equivalent open-loop (loop-gain) transfer function G(s)H(s) and count type and order from it, not from G(s) alone. Type fixes steady-state error; order fixes the transient shape.

Time-constant form

The time-constant form pulls the pole and zero magnitudes out of the factors: G(s) = K′(1+sT₁)(1+sT₂)… / [sN(1+sTa)(1+sTb)…]. K′ is the time-constant gain; T₁, T₂, … are zero time constants, with T₁=1/z₁, T₂=1/z₂, … in seconds when z is in rad/s; Ta, Tb, … are nonzero pole time constants, with Ta=1/pa, … in seconds when p is in rad/s. Pulling out the magnitudes gives K′ = K z₁ z₂ … / (p₁ p₂ …). In this gain formula, z and p are magnitudes. So K and K′ differ by the product of zero magnitudes divided by the product of nonzero pole magnitudes. The sN stays outside because origin poles have no finite time constant.

For G(s)=20(s+3)/[s²(s+1)(s+5)], K′=20×3/(1×5)=12, and G(s)=12(1+s/3)/[s²(1+s)(1+s/5)] = 12(1+0.333s)/[s²(1+s)(1+0.2s)]. The time constants are 0.333 s, 1 s and 0.2 s. For type 0, K′ equals G(0), the DC gain. For type 1 and higher, G(0) is infinite, so K′ is not a DC gain. Use K′ when you read a Bode plot; use K when you count gain in pole-zero form. The error constants in Chapter 2.6 take their own limits.

Why the labels matter

Type and order are read from the open-loop transfer function, not from the closed-loop one. They describe the plant plus controller before feedback closes. Adding an integrator in a PI controller raises the type by one. On a type-0 plant this removes the step error; on a type-1 plant it removes the ramp error. Either way it adds phase lag and eats phase margin. Adding a pole raises order, for example a motor's electrical time constant or a filter, so the transient gains one more mode. A distant pole contributes a small, fast decay and may be ignored as a dominant-pole approximation. A higher type is not automatically better: each origin pole adds 90° of phase lag, and stability must be checked in Unit 3. The labels are bookkeeping: type answers 'what error remains?', order answers 'what transient shape is possible?'. They also tell you which response formula to use: one time constant in Chapter 2.3, two in Chapter 2.4.

Worked example

Question. For G(s) = 20(s+3)/[s²(s+1)(s+5)], find the order, the type, and the time-constant form.

  1. Denominator: s²(s+1)(s+5). Its degree is 2 + 1 + 1 = 4, so the order is n = 4.
  2. Origin poles: s² gives two poles at s = 0, so the type is N = 2.
  3. Common factors: numerator has s+3; denominator has s, s, s+1, s+5. No common factor cancels, so order and type stay 4 and 2.
  4. Zero time constant: zero at s = −3 gives T = 1/3 s ≈ 0.333 s.
  5. Nonzero pole time constants: pole at s = −1 gives T = 1 s; pole at s = −5 gives T = 0.2 s.
  6. Gain: K = 20, zero magnitude product = 3, nonzero pole magnitude product = 1 × 5 = 5. K′ = 20 × 3 / 5 = 12.
  7. Time-constant form: G(s) = 12(1 + s/3)/[s²(1 + s)(1 + s/5)] = 12(1 + 0.333s)/[s²(1 + s)(1 + 0.2s)].

Answer. The system has order 4, type 2, time-constant gain K′ = 12, and time constants 0.333 s, 1 s and 0.2 s.

Exam traps

  • Counting every pole for type. Type counts only poles at s = 0, not poles at s = −1, −2 or −5.
  • Treating a small negative pole as an origin pole. A pole at s = −0.001 is not an integrator; it is type 0, though it can cause a slow tail.
  • Forgetting to cancel common factors before finding order. A factor s+a in both numerator and denominator lowers the true order by one.
  • Reading type and order from the closed-loop denominator or from G(s) alone in non-unity feedback. Use the loop gain G(s)H(s).
  • Mixing K and K′. K′ includes the product of zero magnitudes divided by the product of nonzero pole magnitudes.

2.3 First-order system response

A first-order system stores energy in one place, so its output cannot jump; it moves smoothly toward a new value. Its whole speed is set by one number, the time constant τ. This chapter turns the transfer function K/(1+τs) into time-domain formulas for step, ramp, impulse and parabolic inputs, and shows the 63.2%, 95% and 98% points that engineers use to judge speed. Such models describe RC charging, a heated room, a small motor and many liquid-level loops.

You need: Chapter 2.1 for the four test inputs and Chapter 2.2 for the meaning of order.

One pole, one time constant

The standard first-order transfer function is G(s) = K/(1 + τs). K is the steady gain, τ is the time constant in seconds, and s is the Laplace variable. The denominator 1 + τs = 0 gives one pole at s = −1/τ. K/(1 + τs) = (K/τ)/(s + 1/τ). Here a = 1/τ and the numerator becomes K/τ, not K. The DC gain is still K; only after re-labelling the numerator as K′ = K/τ does the form K′/(s + a) hold. A smaller τ puts the pole farther left; a larger τ puts it nearer the origin.

C(s) = K/(s(1 + τs)) = K/s − Kτ/(1 + τs), so c(t) = K(1 − e<sup>−t/τ</sup>) for t ≥ 0.

K is the steady gain and the final value for a unit step; τ is the time constant in seconds; s is the Laplace variable; e is the exponential base.

At t = 0 the output starts at zero and its slope is K/τ. At t = τ the output is 63.2% of K. At t = 2τ it is 86.5%, at 3τ about 95.0%, and at 4τ about 98.2%. A common engineering rule says 5τ is close to settled, where the output is 99.3% of K. Moving the pole left with a smaller τ makes the response faster; moving it right makes it slower.

For zero input and initial output c(0) = c₀, the response is c(t) = c₀e−t/τ. This is the initial-condition response: the stored energy decays with the same time constant.

Ramp, impulse and parabolic inputs

For a unit ramp input r(t) = t, the Laplace transform is 1/s². The output is:

c(t) = K(t − τ + τe−t/τ) for t ≥ 0.

K is the steady gain; τ is the time constant in seconds; e is the exponential base.

After the exponential term dies, c(t) ≈ K(t − τ). The output is a straight line of slope K, lagging the scaled input Kt by τ seconds. So τ appears as a time delay of τ seconds along the time axis; the vertical gap between the scaled input Kt and the steady ramp response K(t − τ) is Kτ, in output units.

For a unit impulse input δ(t), R(s) = 1. The output is:

c(t) = (K/τ)e−t/τ for t ≥ 0.

K is the steady gain; τ is the time constant in seconds; e is the exponential base.

The impulse response starts at K/τ and decays to zero. Its area is K. For a unit parabolic input r(t) = t²/2, the output is:

c(t) = K[t²/2 − τt + τ²(1 − e<sup>−t/τ</sup>)] for t ≥ 0.

K is the steady gain; τ is the time constant in seconds; e is the exponential base.

With K = 1, the error is e(t) = r(t) − c(t) = τt − τ²(1 − e−t/τ). This grows with t, so a first-order system has no finite steady-state error for a parabolic input. Only step and ramp inputs settle to a constant or constant-lag form.

Closed loop changes the time constant

Place G(s) = K/(1 + τs) in a unity negative-feedback loop. The closed-loop transfer function is T(s) = G/(1 + G) = K/(1 + τs + K). In standard form this is [K/(1 + K)]/[1 + sτ/(1 + K)]. The closed-loop time constant is τcl = τ/(1 + K), and the closed-loop pole is at −(1 + K)/τ.

Negative feedback moves the pole left by the factor 1 + K, so the closed-loop response is faster than the open-loop response. For a unit step, the closed-loop final value is K/(1 + K), not K. Some syllabi call the time-varying part of the response the transient part, and the exponential curve e−t/τ that sets its shape the exponential mode of the system.

Worked example

Question. A first-order system has G(s) = 10/(1 + 2s) and is given a unit step at t = 0, with zero initial conditions. (a) Write c(t). (b) Find the time to reach 9, which is 90% of the final value. (c) Give the steady-state output for a unit ramp input.

  1. Compare with G(s) = K/(1 + τs). Here K = 10 and τ = 2 s.
  2. For a unit step, c(t) = K(1 − e−t/τ) = 10(1 − e−t/2) for t ≥ 0.
  3. The final value is K = 10. The 90% level is 0.9 × 10 = 9.
  4. Solve 9 = 10(1 − e−t/2). Then e−t/2 = 0.1, so −t/2 = ln(0.1) and t = 2 ln(10) = 4.605 s.
  5. For a unit ramp, c(t) ≈ K(t − τ) = 10(t − 2). The output is a line of slope 10 lagging by 2 s.

Answer. The output reaches 9 at 4.605 s, and the unit-ramp steady-state output is 10(t − 2), a lag of 2 s.

Exam traps

  • τ is not the settling time. Reaching 98% takes 4τ; 5τ is only an engineering rule of thumb.
  • Do not drop K. The final value for a unit step is K, not 1, when the system has gain.
  • The initial slope of the step response is K/τ, not K and not 1/τ alone.
  • In unity feedback, the closed-loop time constant is τ/(1 + K), not the open-loop τ. The closed-loop final value is also smaller: K/(1 + K).
  • For a ramp, the output lags by τ seconds in time. The vertical difference from the scaled input Kt is Kτ, so do not mix the two.

2.4 Second-order system response and damping

A second-order system is the smallest system that can overshoot and ring, and its whole response is fixed by two numbers. ωn, the undamped natural frequency in rad/s, sets the speed. ζ, the damping ratio, a pure number, sets the shape. Servo motor datasheets, hard-disk head positioners and drone attitude loops quote these two numbers because they predict overshoot long before a wire is connected. This chapter writes the standard form, sorts the response into four damping cases, derives the step response of each, and reads ζ and ωn off the s-plane.

You need: Chapter 2.1 for the step input, Chapter 2.2 for the standard second-order form, and school-level quadratic roots and trigonometry.

Standard form and the two numbers

Divide numerator and denominator by the coefficient of s². If the DC gain is 1, the result is exactly the template below; if the gain is K, write K times the template and carry K separately.

G(s) = ωn² / (s² + 2ζωn s + ωn²)

G(s) is the transfer function, output over input; ωn is the undamped natural frequency in rad/s; ζ (zeta) is the damping ratio, unitless; s is the Laplace variable in rad/s.

Read the two numbers straight off the denominator. The constant term is ωn². The coefficient of s is 2ζωn, with the 2. At s = 0 the template gives G(0) = 1, so a unit step settles at 1. If your gain is not 1, carry that gain separately.

The two numbers answer two different questions. ωn is how fast the system would ring if all friction vanished. ζ is how much that ringing is eaten away. Neither is a component value; both come from the denominator alone.

s₁, s₂ = −ζωn ± ωn√(ζ² − 1) = −ζωn ± jωn√(1 − ζ²)

s₁, s₂ are the closed-loop poles in rad/s; the second form is used when ζ ≤ 1. The real part −ζωn is the same either way.

For ζ < 1 the square root is imaginary and the poles form a complex pair. For ζ ≥ 1 the poles are real. That sign is the whole classification.

  1. Factor: C(s) = ωn²/[s(s − s₁)(s − s₂)], with s₁,₂ = −ζωn ± jωd and ωd = ωn√(1 − ζ²).
  2. Split into A/s + (Bs + C)/(s² + 2ζωn s + ωn²). Solving gives A = 1, so the final value is 1.
  3. Invert each term: c(t) = 1 − e^(−ζωn t)[cos ωd t + (ζ/√(1−ζ²)) sin ωd t].
  4. Fold the bracket into a single sine with φ = cos⁻¹ζ: c(t) = 1 − (1/√(1−ζ²)) e^(−ζωn t) sin(ωd t + φ).

Read that line in three pieces. The 1 is the final value. The exponential e^(−ζωn t) shrinks the swing, with time constant 1/(ζωn). The sine at ωd swings the output back and forth. Raise ζ and the decay is faster and the first overshoot smaller, until at ζ = 1 the sine vanishes and the curve touches 1 from below without crossing it. At ζ = 0 nothing decays: c(t) = 1 − cos ωn t swings between 0 and 2 forever. Above ζ = 1 the two real poles separate, one fast and one slow, and the slow pole dominates.

Poles on a circle

Hold ωn fixed and let ζ change. Every pole stays at distance ωn from the origin, so it slides along a circle of radius ωn.

|s| = ωn, θ = cos⁻¹ ζ, ωd = ωn√(1 − ζ²)

|s| is the distance of a pole from the origin in rad/s; θ is the angle of the pole measured from the negative real axis, in radians; ωd is the damped frequency in rad/s.

ζ = 1 puts both poles on the negative real axis at −ωn, so θ = 0. ζ = 0 puts them on the imaginary axis at θ = π/2 rad (90°). A pole at θ = π/4 rad (45°) gives ζ = cos 45° = 0.707. The vertical height of the pole above the real axis is exactly ωd, the frequency you would measure on an oscilloscope.

Two knobs, two effects. Changing ωn scales the circle: the poles move radially and the whole response speeds up or slows down, because time is measured in units of 1/ωn. Changing ζ slides the poles around the circle: toward the real axis means less overshoot and faster settling, toward the imaginary axis means more ringing. This is what moving a pole in the s-plane means in practice.

An extra real pole far to the left, or a zero, bends this picture. Only a few universities examine that approximation here; treat the two-pole result above as the baseline.

Worked example

Question. A closed-loop system has transfer function G(s) = 25/(s² + 6s + 25). Find ωn, ζ, the damped frequency ωd, the peak overshoot in percent, and the peak time.

  1. Compare the denominator with s² + 2ζωn s + ωn². The constant term gives ωn² = 25, so ωn = 5 rad/s.
  2. The coefficient of s gives 2ζωn = 6, so ζ = 6/(2 × 5) = 0.6.
  3. Since 0 < 0.6 < 1, the system is underdamped and the sine forms apply.
  4. √(1 − ζ²) = √(1 − 0.36) = √0.64 = 0.8.
  5. ωd = ωn√(1 − ζ²) = 5 × 0.8 = 4 rad/s. Also φ = cos⁻¹ 0.6 = 0.9273 rad.
  6. Peak overshoot Mp = e^(−πζ/√(1−ζ²)) = e^(−π × 0.6/0.8) = e^(−2.3562) = 0.0948, that is 9.48%.
  7. Peak time tp = π/ωd = π/4 = 0.7854 s, about 0.785 s.

Answer. ωn = 5 rad/s, ζ = 0.6 (underdamped), ωd = 4 rad/s, peak overshoot 9.48%, peak time 0.785 s.

Exam traps

  • Forgetting the 2: the coefficient of s is 2ζωn, not ζωn. Half the wrong answers in this topic come from that slip.
  • Normalise first. ωn = √(constant term) only after the s² coefficient is 1; with 4s² + 3s + 9 you must divide everything by 4 before matching.
  • The underdamped formulas need √(1 − ζ²) real, so check ζ < 1 first. Plugging ζ = 1.5 into the sine form gives a nonsense imaginary frequency.
  • Angles inside exponentials and sines are in radians. πζ/√(1−ζ²) and ωd t are radian quantities; a calculator left in degrees gives a wrong overshoot.
  • Mp is a fraction of the final value. Report it as 9.48%, not as 0.0948, and remember it depends only on ζ, never on ωn.

2.5 Time-domain specifications

A second-order underdamped step response wiggles, overshoots and settles. Instead of drawing the whole curve, engineers quote five numbers: delay time, rise time, peak time, peak overshoot and settling time. These five numbers form a short specification sheet. Servo drives, power-supply loops and positioning systems use them to compare designs and to state what a customer will accept. This chapter defines each number with its measurement condition, gives formulas for the standard second-order transfer function, and shows how to go backwards from a specification to the damping ratio ζ and natural frequency ωn.

You need: the damping ratio ζ, natural frequency ωn, damped frequency ωd and phase φ from Chapter 2.4.

Five numbers on one specification sheet

A standard second-order system has G(s) = ωn²/(s² + 2ζωn s + ωn²). Here s is the Laplace variable, ωn is the undamped natural frequency in rad/s, and ζ is the damping ratio, dimensionless. The formulas in this chapter assume a unit-step input, zero initial conditions, unity DC gain G(0)=1, no zeros, and 0<ζ<1. The output then rises, overshoots and oscillates down to 1. Five numbers summarise that whole curve.

  • Delay time td: time to reach 50% of the final value for the first time.
  • Rise time tr: time to go from 0% to 100% of the final value for the first time. The 10–90% definition measures a different, smaller time; state which one is used.
  • Peak time tp: time of the first maximum.
  • Peak overshoot Mp: (first maximum − final value)/final value. It is a fraction; multiply by 100 for per cent.
  • Settling time ts: the time after which the response stays inside a band of ±2% (or ±5%) around the final value; that is, the last time the response enters the band. After ts it never leaves again.

A servo datasheet may quote only these five numbers. They let two designs be compared without drawing two curves. The same numbers also appear in frequency-domain work; see Unit 4, Frequency Response Analysis.

Formulas for the standard case

Write ωd = ωn√(1 − ζ²) for the damped frequency in rad/s, and φ = cos⁻¹ζ for the phase angle in radians. The formulas below follow from the underdamped response in Chapter 2.4.

td ≈ (1 + 0.7ζ)/ωn

td is the delay time in seconds; ζ is the damping ratio; ωn is the undamped natural frequency in rad/s. This is an approximation.

tr = (π − φ)/ωd, with φ = cos⁻¹ζ

tr is the 0–100% rise time in seconds; φ is in radians; ωd is the damped frequency in rad/s. For the 10–90% definition, tr is smaller and this formula does not apply.

tp = π/ωd

tp is the peak time in seconds; ωd is the damped frequency in rad/s.

Mp = e^(−πζ/√(1 − ζ²)), Mp% = 100 Mp

Mp is the peak overshoot as a fraction; Mp% is the same number in per cent; ζ is the damping ratio, dimensionless.

ts ≈ 4/(ζωn) for a 2% band;  ts ≈ 3/(ζωn) for a 5% band

ts is the settling time in seconds; ζ is the damping ratio; ωn is the undamped natural frequency in rad/s. The band is measured around the final value 1.

The settling-time approximations come from the envelope e^(−ζωn t)/√(1 − ζ²). For the 2% band, set the envelope to 0.02 and solve; for small ζ this gives about 4/(ζωn). For the 5% band, set it to 0.05 and the result is about 3/(ζωn).

From specifications back to ζ and ωn

Design often starts with Mp and ts and asks for ζ and ωn. Use the reverse formulas below. They apply only to the standard second-order model.

  1. Convert the overshoot to a fraction: Mp = Mp% / 100.
  2. Compute A = ln(1/Mp). For Mp = 0.163, A = 1.814.
  3. Find ζ = A/√(π² + A²).
  4. Choose the band. For 2%, ωn = 4/(ζ ts); for 5%, ωn = 3/(ζ ts).
  5. Check the result by recomputing tp and Mp from ζ and ωn.

ζ = ln(1/Mp)/√(π² + [ln(1/Mp)]²)

Mp is the peak overshoot as a fraction, not a percentage; ζ is the damping ratio, dimensionless.

A transfer function with a zero, a time delay, or a DC gain other than 1 will not follow these numbers exactly. The formulas are a design starting point, not a measurement.

Worked example

Question. For a standard second-order system with closed-loop transfer function T(s) = 16/(s² + 4s + 16), find the 0–100% rise time, peak time, peak overshoot and 2% settling time.

  1. Compare the denominator with s² + 2ζωn s + ωn². ωn² = 16, so ωn = 4 rad/s. 2ζωn = 4, so ζ = 4/(2 × 4) = 0.5.
  2. The damped frequency is ωd = ωn√(1 − ζ²) = 4√(1 − 0.25) = 4 × 0.8660 = 3.464 rad/s.
  3. The phase is φ = cos⁻¹0.5 = 1.047 rad. Rise time tr = (π − φ)/ωd = (3.1416 − 1.047)/3.464 = 2.0946/3.464 = 0.605 s.
  4. Peak time tp = π/ωd = 3.1416/3.464 = 0.907 s.
  5. Peak overshoot Mp = e^(−πζ/√(1 − ζ²)) = e^(−1.5708/0.8660) = e^(−1.8138) = 0.163. As a percentage, 16.3%.
  6. For a 2% band, ts = 4/(ζωn) = 4/(0.5 × 4) = 2 s.

Answer. tr = 0.605 s, tp = 0.907 s, Mp = 0.163 (16.3%), and ts = 2 s for the 2% band.

Exam traps

  • Using the 10–90% rise-time formula in a question that defines rise time as 0–100%. The two numbers differ; read the definition first.
  • Applying these formulas to G(s) with a zero, a time delay or a DC gain not equal to 1. The formulas are for the standard second-order form only.
  • Putting ωn instead of ζωn in the settling-time denominator, or ωn instead of ωd in tp. For ζ = 0.5 and ωn = 4 rad/s, ωd is 3.464 rad/s, not 4 rad/s.
  • Feeding a percentage overshoot straight into e^(−πζ/√(1 − ζ²)). Convert 16.3% to 0.163 first.
  • Forgetting that φ = cos⁻¹ζ is in radians when used in tr = (π − φ)/ωd.

2.6 Steady-state error and static error constants

A feedback loop rarely lands exactly on the commanded value. The wobble dies away, but a small offset often stays: the steady-state error, ess. It matters wherever tracking accuracy is the whole point — a servomotor holding an antenna angle, a temperature loop settling at its set point, a payment gateway settling its output. Three numbers, Kp, Kv and Ka, read straight off the open-loop transfer function, and the system type picks which one applies.

You need Chapter 2.2 for type, Chapter 2.1 for the standard inputs, and the final value theorem from Laplace transforms.

The error signal and the final value theorem

In a unity negative feedback loop the summing node subtracts C(s) from R(s) to give the error: E(s) = R(s) − C(s). The forward path gives C(s) = G(s)E(s). Substituting and rearranging:

E(s) = R(s) / (1 + G(s))

E(s) is the Laplace transform of the error at the comparator; R(s) is the transform of the reference input; G(s) is the open-loop forward-path transfer function, including the plant and any controller.

The steady-state error is e(t) as t → ∞. The final value theorem avoids the inverse transform: multiply E(s) by s and take s → 0.

e<sub>ss</sub> = lim<sub>t→∞</sub> e(t) = lim<sub>s→0</sub> s E(s) = lim<sub>s→0</sub> s R(s) / (1 + G(s))

ess is the steady-state error; the equality holds only if every pole of sE(s) lies in the left half of the s-plane, which in practice means the closed loop must be stable.

That condition is not decoration. An unstable closed loop never settles, so 'steady-state error' has no meaning. Confirm stability first — Unit 3, Stability and Root Locus — and only then apply the theorem.

Three static error constants

Feed each standard input into the limit and the G(s) terms separate. For a unit step R(s) = 1/s, so sR(s) = 1 and ess = 1/(1 + lim G(s)). For a unit ramp R(s) = 1/s², giving 1/lim sG(s). For a unit parabola R(s) = 1/s³, giving 1/lim s²G(s). Name the three limits once and every system is covered.

Kp = lim<sub>s→0</sub> G(s),   Kv = lim<sub>s→0</sub> s G(s),   Ka = lim<sub>s→0</sub> s² G(s)

Kp is the static position error constant; Kv is the static velocity error constant, with unit s⁻¹; Ka is the static acceleration error constant, with unit s⁻². All three are computed from the open-loop G(s), never from the closed-loop transfer function.

e<sub>ss</sub> = 1/(1 + Kp)  for unit step,   1/Kv for unit ramp,   1/Ka for unit parabola

the step error is dimensionless; a ramp of slope A gives A/Kv; a parabola of value A t²/2 gives A/Ka. A constant multiplier A on the input multiplies the error by the same A.

The constants come out finite, zero or infinite according to how many poles G(s) has at the origin — the system type, as defined in Chapter 2.2. A factor sN cancels the s and s² of the limits for N = 1 and N = 2, which is exactly why integrators remove error.

2.7 Generalized error series and dynamic error constants

Chapter 2.6 gives steady-state error for step, ramp or parabola inputs. Real commands drift or curve. The generalized error series answers: for any slowly varying r(t), what error remains? Expand E(s)/R(s) as a Maclaurin series about s = 0. The coefficients C₀, C₁, C₂, … are dynamic error coefficients. One formula then gives the steady-state error for any input whose derivatives settle.

You need static error constants Kp, Kv, Ka and system type from Chapter 2.6 and Chapter 2.2, plus the Maclaurin expansion from first-year mathematics.

Expand E(s)/R(s) about s = 0

In unity feedback, e(t) = r(t) − y(t), so E(s) = R(s)/(1 + G(s)). Divide by R(s).

E(s)/R(s) = 1/(1 + G(s)) = M(s)

E(s) is the Laplace transform of the error e(t) = r(t) − y(t); R(s) is the transform of the input r(t); G(s) is the open-loop transfer function of a unity feedback system; M(s) is the error transfer function.

Expand M(s) as a Maclaurin series about s = 0: a power series whose coefficients come from derivatives of M at the origin.

M(s) = C₀ + C₁s + (C₂/2!)s² + (C₃/3!)s³ + ⋯

C₀ = M(0); C₁ is dM/ds evaluated at s = 0; C₂ is d²M/ds² at s = 0; in general C_k is the k-th derivative of M at s = 0.

Why s = 0? Steady state is s → 0, and one power of s becomes one time derivative. Multiply by R(s) and invert term by term, with zero initial conditions and L{ṙ(t)} = sR(s).

e(t) = C₀r(t) + C₁ṙ(t) + (C₂/2!)r̈(t) + (C₃/3!)r⃛(t) + ⋯

ṙ(t) and r̈(t) are the first and second time derivatives of the input; C₀, C₁, C₂, … are the dynamic error coefficients.

This is the generalized error series. It gives the forced (steady-state) part of the error: the natural response of the closed loop is not contained in it. The right-hand side equals the actual error only after the transient has died out, which needs a stable closed loop.

Dynamic error coefficients and the static constants

The first coefficient is the positional constant in disguise. Put s = 0 in M(s).

C₀ = M(0) = 1/(1 + G(0)) = 1/(1 + Kp)

Kp = lim (s → 0) G(s) is the positional error constant from Chapter 2.6.

For type 1, G(0) = ∞ so C₀ = 0. M(s) behaves like s/Kv near the origin, so C₁ = 1/Kv, with Kv = lim (s → 0) sG(s). For type 2, C₀ = C₁ = 0 and C₂/2! = 1/Ka, so C₂ = 2/Ka.

The static constants are the first terms of this series, not separate theory. Once C₀, C₁, C₂ are known, any input with settling derivatives is handled in one line. The static method needs a new table row for each input shape; the series needs more derivatives of r(t).

Working recipe

Two expansions do the work: long division of N(s)/D(s), or the binomial 1/(1 + u) = 1 − u + u² − ⋯ when u is small. Here u carries s, so it is small near s = 0.

  1. Check the closed loop is stable (Unit 3). An unstable loop has no steady state.
  2. Write M(s) = 1/(1 + G(s)) = N(s)/D(s), with D(0) ≠ 0.
  3. Expand at s = 0. By long division, c_k = (N_k − Σ D_i·c_(k−i))/D₀, i = 1 to k; N_k and D_k are coefficients of s^k.
  4. Convert to dynamic error coefficients: C_k = k!·c_k, so C₀ = c₀, C₁ = c₁, C₂ = 2c₂, C₃ = 6c₃.
  5. Differentiate r(t) until terms vanish.
  6. Add them: e_ss = C₀r + C₁ṙ + (C₂/2!)r̈ + ⋯

For a step input, ṙ = r̈ = ⋯ = 0 for t > 0, so every term beyond C₀ vanishes: e_ss = C₀r. The higher coefficients are multiplied by zero derivatives.

Worked example

Question. (a) For G(s) = 10/[s(1 + 0.5s)] in unity feedback, find C₀, C₁, C₂. (b) Use the series for r(t) = 2 + 4t and check with static constants.

  1. E/R = 1/(1 + G) = s(1 + 0.5s)/[s(1 + 0.5s) + 10] = (s + 0.5s²)/(10 + s + 0.5s²).
  2. Write u = (s + 0.5s²)/10 = 0.1s + 0.05s². Then E/R = u/(1 + u).
  3. 1/(1 + u) = 1 − u + u² − ⋯, so u/(1 + u) = u − u² + ⋯. Up to s²: u = 0.1s + 0.05s² and u² = 0.01s² + 0.01s³ + ⋯, so keep 0.01s².
  4. E/R = 0.1s + 0.05s² − 0.01s² = 0.1s + 0.04s². So c₀ = 0, c₁ = 0.1, c₂ = 0.04.
  5. C_k = k!c_k: C₀ = 0, C₁ = 0.1, C₂ = 2 × 0.04 = 0.08. C₀ = 0 because the system is type 1.
  6. r(t) = 2 + 4t gives r = 2, ṙ = 4, r̈ = 0.
  7. e_ss = C₀r + C₁ṙ + (C₂/2!)r̈ = 0 × 2 + 0.1 × 4 + 0 = 0.4.
  8. Check: Kv = lim (s → 0) sG(s) = 10; ramp 4t gives 4/Kv = 0.4; constant 2 gives zero for type 1. Agree.

Exam traps

  • The factorial is inside the series: C₂ = 2c₂ and C₃ = 6c₃. Reporting c₂ as C₂ halves the parabolic error.
  • The series gives a usable number only if the closed loop is stable (Unit 3) and input derivatives settle.
  • Type 1 makes C₀ = 0, not the error zero. For a ramp the answer is in C₁ = 1/Kv.
  • Expand only as far as the input needs. For r = a + bt, C₂ multiplies r̈ = 0.
  • Keep e = r − y. Positive C₁ with positive ṙ gives positive lag; flipping the convention flips answers.

Analyze A student gets c₂ = 0.04 and reports C₂ = 0.04. What is wrong and what error for r = t²/2? 5 marks

C₂ = 2c₂ = 0.08. For r = t²/2, r̈ = 1; true term is C₂/2! = 0.04. Student gets 0.02, halved.

Analyze Why is the series answer meaningless if the closed loop is unstable, though coefficients are finite? 5 marks

The coefficients describe only the forced part. An unstable loop's natural response grows without bound, so no steady state exists and term-by-term inversion fails. Check stability first.

Takeaways

  1. Four ideal inputs — impulse, step, ramp, parabola — let every system be compared under the same conditions, because the response to one of them plus superposition gives the response to any input.
  2. Order decides how many state variables and what shape the transient has; type decides only what error remains after the transient ends.
  3. For a first-order system one number, τ, tells everything: 63.2% at τ, about 95% at 3τ, about 98% at 4τ.
  4. A second-order system is fully described by ωn for speed and ζ for shape, and ζ sorts it into undamped, underdamped, critically damped and overdamped.
  5. Peak overshoot depends on ζ alone, while peak time, rise time and settling time depend on ωn and ζ together.
  6. Steady-state error is zero for a type-1 system with a step input and for a type-2 system with a ramp input, but a type-0 system always leaves a finite error on a step.
  7. The static error constants K_p, K_v and K_a are just the first, second and third terms of the generalized error series, so both methods agree.
  8. When the input is not a pure step or ramp, the dynamic error coefficients C₀, C₁, C₂, … give the error as a weighted sum of the input and its derivatives.

Understand A second-order system has transfer function ωn²/(s² + 2ζωn s + ωn²). Explain how the step response changes as ζ is varied through 0, 0 < ζ < 1, ζ = 1 and ζ > 1. 10 marks

Analyze and evaluate

Analyze Compare the step responses of a first-order system and an underdamped second-order system having the same 2% settling time. Discuss which is preferable for a position control application and why. 13 marks

First-order response has no overshoot; settling is set by τ, with t_s ≈ 4τ; Second-order response with the same settling time must have ζωn equal to 1/τ; Smaller ζ gives faster rise but more overshoot and more control effort; Overshoot may be unacceptable where the load must not cross the set point; Conclusion: first-order-like behaviour (ζ near 0.7) is usually a good compromise.

Analyze A position control system must track a ramp input with zero steady-state error and must have a peak overshoot below 10%. Explain step by step how you would choose the system type and the damping ratio, and what trade-offs you face. 14 marks

Zero error on a ramp demands at least one pole at the origin, so type 1 or higher; M_p < 10% demands ζ ≥ about 0.6 from the M_p formula; Higher type improves accuracy but reduces stability margin; ωn is then chosen to meet the speed or settling-time requirement via t_s ≈ 4/(ζωn); Gain increase raises ωn but also changes ζ; check the closed-loop poles after design; Note the conflict between accuracy and transient shape.

Evaluate For a unity feedback system with G(s) = K/[s(s + a)(s + b)], examine the effect of increasing K on the transient specifications and on the steady-state error for a ramp input. Comment on the limits of increasing K. 14 marks

K_v = K/(ab), so ramp error falls as K rises; Closed-loop characteristic equation s³ + (a + b)s² + abs + K = 0; As K rises, the dominant pole pair becomes less damped and overshoot grows; At some K the poles cross into the right half-plane and the system becomes unstable; The third pole also moves; dominance assumption must be rechecked; Conclusion: K is bounded above by the stability and overshoot requirements.

Glossary

Acceleration error constant
K_a = lim(s→0) s²G(s); it sets the parabolic-input error as 1/K_a.
Actuating error signal
The signal at the summing point of a feedback loop, equal to the reference minus the fed-back output.
Characteristic equation
The denominator of the closed-loop transfer function set equal to zero; its roots are the closed-loop poles.
Damping
The loss of energy in a system that makes oscillations decay; measured by the damping ratio ζ.
Delay time
The time for the response to first reach 50% of its final value.
Dominant poles
The closed-loop poles nearest the imaginary axis; they decide the shape of the transient because all other poles decay faster.
Dominant-pole approximation
Treating a higher-order system as second order by keeping only the slowest pole pair, valid when the other poles are far to the left.
Final value theorem
lim(t→∞) f(t) = lim(s→0) sF(s), valid when all poles of sF(s) lie in the left half-plane.
Laplace transform
A rule that turns a time function f(t) into a function F(s) of the complex variable s, converting differential equations into algebra.
Open-loop transfer function
The product G(s)H(s) around the loop with the loop opened at the summing point.
Partial fraction expansion
Splitting a rational F(s) into simple terms whose inverse Laplace transforms are known.
Percentage overshoot
The amount by which the first peak exceeds the final value, expressed as a percentage of the final value.
Pole
A value of s at which the transfer function becomes infinite, that is, a root of the denominator.
Position error constant
K_p = lim(s→0) G(s); it sets the step-input error as 1/(1 + K_p).
S-plane
The complex plane on which poles and zeros of a transfer function are plotted, with s = σ + jω.
Steady-state accuracy
How closely the output follows the input long after the command is applied, measured by e_ss.
Steady-state error
The value of e(t) = r(t) − c(t) as t tends to infinity, written e_ss.
Steady-state response
The part of the response that remains after the transient has decayed; it has the same form as the input.
Transient response
The part of the response that dies away as t grows, produced by the poles of the closed-loop system.
Unity feedback
A feedback loop in which H(s) = 1, so the feedback signal is the output itself.
Velocity error constant
K_v = lim(s→0) sG(s); it sets the ramp-input error as 1/K_v.
Zero
A value of s at which the transfer function becomes zero, that is, a root of the numerator.
