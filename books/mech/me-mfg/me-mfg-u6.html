6.1 Evolution of NC, CNC and DNC

Numerical control (NC) means running a machine tool from numbers instead of from cams, stops and a skilled hand on the feed wheel. The numbers sit in a part program, and each line of that program is a block. In the first NC machines the program lived on punched tape; a reader fed it to a machine control unit, which pulsed the axis motors. CNC moved the program into a computer inside the machine. DNC moved the program store out to a central computer that serves many machines. This chapter follows that move and what each step bought the shop floor.

You need: Unit 5 for the slideways, leadscrew and axis motions of a lathe or a milling machine; the block format of a part program itself is in 6.4.

Punched tape and the machine control unit

On a centre lathe, cams, stops and change gears fix the sequence of cuts. Change the part, and you change the hardware. NC replaced that hardware with a program: a list of blocks, each block saying where the tool goes, how fast, and with what spindle speed.

The classic NC chain has four parts. The tape reader reads the punched tape one block at a time. The machine control unit (MCU) decodes the block. The axis drives turn the decoded numbers into motion of the slides. A feedback device, if one is fitted, reports the slide position back to the MCU.

  1. The reader pulls one block of characters off the tape.
  2. The MCU decodes the block: axis words, feed word, spindle word.
  3. The MCU generates pulses at a rate set by the feed word.
  4. Each pulse drives the axis motor, and the leadscrew moves the slide by one basic length unit (BLU).
  5. The MCU reads the next block and repeats.

v = fp × BLU

v is the slide feed in mm/s, fp is the pulse frequency in pulses per second, and BLU is the basic length unit in mm per pulse. Multiply v by 60 to get mm/min.

Early MCUs were hard-wired. The logic was a fixed circuit, so a canned cycle or a new interpolation scheme needed new boards. The tape itself was weak: it tore, it stretched in a hot shop, and one bad character stopped the job. To run the same part again you rewound the tape.

The reader is fast and the cutter is slow. A reader can hand over a block in a fraction of a second and then sit idle while the tool cuts. That idle time is the subject of the worked example.

What CNC adds on top of NC

CNC puts a computer inside the machine control unit. The part program is typed in or transferred once and stored in memory. The machine then runs from memory, and the tape reader disappears from the chain.

  • Editing at the machine: correct one feed value without punching a new tape.
  • Canned cycles: one block drills a whole row of holes with pecking, instead of a long list of blocks.
  • Tool length and cutter radius compensation: the programmer writes the part outline, and the real tool size is entered at the machine.
  • Diagnostics: the controller reports a failed board or a loose encoder instead of leaving you with a dead machine.
  • Graphics: the controller draws the tool path before the first cut.
  • Subprograms, macros and background editing: write the next job while the present one runs.

All six are software features. In hard-wired NC each one had to be built in hardware, so a control offered only the few features its boards were wired for, and any new one meant new boards. The heart of CNC is therefore not the computer itself but the stored program and the soft-wired logic that can be changed without a soldering iron. The controller side of this, including interpolation, is in 6.3.

A computer can also hold a file and talk to another computer. That is the door through which DNC walked in.

DNC: direct and distributed

DNC carries two meanings and they are often mixed. Always say which one you mean.

  • Direct numerical control (older meaning): one central computer holds the programs and drives a group of machines, usually with no tape reader on each machine.
  • Distributed numerical control (newer meaning): each machine keeps its own CNC controller, and a central server distributes part programs, collects production counts and tracks tool life over a shop network.

The older direct link was built in three ways.

  • Behind the tape reader (BTR): the computer feeds characters into the existing reader port, so the old MCU never knows the tape is gone. Cheapest, and it keeps the old machine.
  • Behind the MCU: the computer sends motion commands straight to the axis drives and the MCU becomes a slave. More capable, but tied to one maker's hardware.
  • Special machine control: the MCU is replaced outright by the central computer. Full control, and full dependence on that computer.

All three share one weakness: a computer failure stops the whole group. Distributed DNC fixes that. Each machine can run from its own memory, and the server is only a library.

Worked example

Question. An NC part program has 4,200 characters in 70 blocks. The tape reader reads 300 characters per second. Each block takes 25 s of machining time. Find (a) the characters per block, (b) the reading time per block, (c) the time the reader is idle per block, and (d) the percentage of the cycle for which the reader is idle.

  1. Characters per block = total characters ÷ number of blocks = 4,200 ÷ 70 = 60 characters per block.
  2. Reading time per block = characters per block ÷ reader speed = 60 ÷ 300 = 0.2 s.
  3. Machining time per block = 25 s is the time the tool cuts. So the total cycle is reading plus machining = 0.2 + 25 = 25.2 s, and the idle time is 25 − 0.2 = 24.8 s.
  4. Idle percentage is measured against the whole cycle, reading plus machining: idle time ÷ total cycle time × 100 = 24.8 ÷ 25.2 × 100 = 98.4 %.

Answer. The reader needs 0.2 s per block and is idle 24.8 s of every 25.2 s cycle, that is 98.4 % idle.

Exam traps

  • CNC is not simply 'NC plus a computer'. The examinable difference is the stored program in memory plus soft-wired logic; editing, compensation, canned cycles and diagnostics all follow from that.
  • DNC is not a control loop. DNC says where the program lives; open loop and closed loop say whether the slide is measured. See 6.3.
  • DNC has two meanings. Direct numerical control is one computer driving many MCUs; distributed numerical control is a server handing files to independent CNCs. Say which one you mean.
  • Unit slip: BLU is mm per pulse and pulse frequency is pulses per second, so v = fp × BLU comes out in mm/s. Multiply by 60 for mm/min.
  • A reader that is idle for almost the whole cycle is not a slow reader. It is a fast reader waiting for a slow cutter, and that is why the tool, not the tape, set the pace of an NC shop.

6.2 CNC machines: turning centres and machining centres

A CNC machine tool is a metal-cutting machine built stiff, so that motors can push the tool and the work along measured axes and the cut stays where the program put it. Two families cover most work: the turning centre spins the work and holds a turret of tools; the machining centre spins the tool and exchanges it from a magazine. Job shops making auto parts in Pune or pump shafts in Coimbatore buy one of these once batch sizes fall and drawings change every week.

You need: Chapter 6.1 for what the program does, and Unit 5, Metal Cutting and Machine Tools, for cutting force and spindle speed.

Two families: the work turns or the tool turns

A machine that turns the work is a lathe. Fitted with a program-driven turret, a tailstock and two controlled slides, it becomes a turning centre. The slides are X, across the bed, and Z, along it; X is usually programmed as a diameter, so the display matches the drawing. The bed is often slanted at 45° or 60° so chips fall clear of the ways. The turret holds 8 to 12 tools and indexes to the next in under a second. A tailstock supports long shafts. Add live tooling (small driven tools in the turret) and a C-axis that indexes the spindle, and the same machine mills flats or drills off-centre holes without a second setup.

A machine that turns the tool is a milling machine. Under CNC it becomes a machining centre: the spindle comes down from a column (vertical) or points sideways (horizontal), the table carries the work in X and Y, and Z feeds the spindle or the column. An automatic tool changer takes the next tool from a drum or chain magazine holding 20 to 40 tools. A pallet changer swaps a finished part for a fresh one while cutting continues, which is why horizontal machining centres suit boxy parts that need four faces. Five-axis machines add two rotary axes. CNC drilling and grinding machines are also built, for narrow single-purpose work.

Structure and guideways: hold still under load

Accuracy comes from stiffness, not from the controller. The bed and column must not deflect more than a few micrometres when the cutting force pushes back. Cast iron is the usual base: cheap to cast into ribbed shapes, and it damps vibration well. Welded steel bases are lighter, need no pattern and suit large one-off machines; they damp less, so they are sometimes filled with concrete.

Thermal symmetry matters as much. The spindle motor and its bearings make heat, and the column grows. If the heat sources sit symmetrically about the centre line, growth pushes the tool along one axis and the controller can compensate. If not, the spindle tilts and the error depends on height.

  • Dovetail and box ways slide metal on metal over an oil film: large contact area, good damping, but at very slow feeds the slide sticks and then breaks free — stick-slip.
  • Linear bearing carriages run on recirculating balls over a hardened rail: friction is low and stick-slip is gone, at the cost of damping.
  • Hydrostatic ways float the slide on pumped oil: no wear, fine for heavy loads, but they need a pump and a supply of clean oil.

A ball screw turns motor rotation into slide motion. A hardened screw and a nut carry recirculating steel balls between them, so the nut rolls instead of sliding. Lead is the distance the nut travels in one turn. Preload (two nuts with a shim between them, or oversize balls) removes play. Backlash is the lost motion when the slide reverses; the controller can compensate for it, but preload is the mechanical cure.

Spindle and feed drives

The spindle must deliver cutting power across a wide speed range. An older DC shunt motor is sped up by raising armature voltage up to base speed and by weakening the field above it; brushes wear out. A modern AC induction spindle runs from a vector drive, which holds the stator current in step with the rotor flux so torque stays high at low speed. A gear range or a built-in motor covers the top end.

v = π D N ÷ 1000

v is the cutting speed in m/min, D is the workpiece or cutter diameter in mm, and N is the spindle speed in rev/min.

Feed drives move the slide and must also hold it still against cutting force. A stepper motor turns a fixed angle per pulse: 1.8° gives 200 steps per turn. No encoder is fitted, so the controller counts pulses and assumes the slide followed — open loop. That is cheap and simple, but an overloaded stepper stalls silently and every later position is wrong. A servo motor, DC with a tacho or AC permanent-magnet synchronous, carries an encoder and compares commanded with measured position — closed loop.

The drive must match the load. Slide mass and screw inertia are reflected at the motor shaft; if the reflected inertia is far above the motor's own, the loop is hard to tune and the slide overshoots or hums. Belt or gear reduction helps. Axis letters follow a standard: Z along the spindle, X the main cross axis, Y the third linear axis, and A, B, C rotate about X, Y, Z.

steps per turn = 360 ÷ step angle;  resolution = lead ÷ steps per turn;  feed rate = pulse rate × resolution

step angle is in degrees per step, lead is in mm per turn, resolution is in mm per pulse, pulse rate is in pulses per second, and feed rate is in mm/s.

Worked example

Question. A stepper motor of step angle 1.8° drives the ball screw of a CNC table slide. The screw lead is 5 mm per revolution and the controller sends 2,000 pulses per second. Find the steps per revolution, the resolution in mm per step, and the feed rate in mm/s and mm/min.

  1. Steps per revolution = 360° ÷ step angle = 360 ÷ 1.8 = 200 steps.
  2. Resolution = lead ÷ steps per revolution = 5 mm ÷ 200 = 0.025 mm per step.
  3. Feed rate = pulse rate × resolution = 2000 pulses/s × 0.025 mm/pulse = 50 mm/s.
  4. Convert to mm/min: 50 × 60 = 3000 mm/min.

Answer. 200 steps per revolution, a resolution of 0.025 mm per step, and a feed rate of 50 mm/s, which is 3000 mm/min.

Exam traps

  • Lead is not pitch. Pitch is the gap between neighbouring threads; lead is the distance the nut moves in one turn. They are equal only for a single-start screw, and lead is twice the pitch for a two-start screw.
  • A stepper runs open loop, so nothing measures the slide and a stall raises no alarm. A servo drive with an encoder reports a following error instead.
  • A ball screw has low friction and is not self-locking: a vertical Z axis will drop when power is cut unless a brake is fitted. A power screw on a manual machine would hold.
  • On most turning-centre controls X is programmed as a diameter, so a 2 mm depth of cut changes the X word by 4 mm, not 2 mm.
  • The slant bed is for chip clearance and operator reach. It does not by itself make the machine more accurate — stiffness and thermal symmetry do.

6.3 CNC controllers, control systems and interpolators

A CNC controller is the computer that turns a part program into real slide motion. It reads one block, works out the intermediate points along the wanted path, sends a position command to every axis, measures where the slide actually is, and keeps driving until the two agree. Without the controller the machine is only a set of motors; with it, the same hardware can cut a straight line, an arc or a free-form die cavity. Every CNC lathe and machining centre in a job shop runs this loop thousands of times a second.

You need: 6.2 for the feed drive, ball screw and guideways, and 6.1 for how the part program reaches memory.

Inside the controller cabinet

A CNC controller is a computer with one special duty: keep several axes in step while also running the machine's housekeeping. The cabinet holds the usual PC parts plus dedicated boards for motion and for input/output.

The CPU runs the part program block by block (block syntax is in 6.4). Program memory stores the program and the tool offset table. The interpolator, usually software in the CPU, converts one block into a stream of position commands, one number per axis.

The PLC (programmable logic controller) is a second, separate processor for machine logic: coolant pump, tool changer, spindle orientation, door interlock, chip conveyor and alarm lamps. Motion and logic stay apart because motion must be smooth and on time, while a tool change is slow and event-driven.

The servo interface turns each position command into a signal the drive accepts: a pulse train, a ±10 V analogue demand, or a message on a digital fieldbus. The operator panel carries the display, jog keys, feed and spindle override, and the handwheel (MPG) used for setting up.

Three control systems and the loops inside them

  • Point-to-point: the axes move one at a time and only the final position matters. Drilling and punching tables work this way; the path between holes is irrelevant, so the machine can move fast.
  • Straight-cut (paraxial): the tool cuts along one axis at a controlled feed, or at 45° by pulsing two axes at the same rate. Used for simple rectangular milling.
  • Contouring (continuous path): two or more axes move together and the tool must stay on the wanted curve at every instant. Profiles, die cavities and turned tapers all need this, and it needs an interpolator.

Open loop means no measurement of the slide. A stepper motor turns a fixed angle per pulse and the controller trusts it. Cheap, but a heavy cut or a fast move can make it miss steps, and the error is never seen. Open loop is not 'no feedback from the program' — the program is followed in both types.

Closed loop means an encoder on the slide reports real position. The comparator subtracts feedback from the command and the leftover error drives the amplifier. Three loops nest: the current loop (fastest, controls motor torque), the velocity loop (tacho or differentiated encoder), and the position loop (outermost). The following error is the small lag between the commanded position and the measured position while the axis is moving; the position loop gain sets how large it is allowed to be.

Interpolators: pulses or words

A reference-pulse (incremental) interpolator outputs one pulse per basic length unit (BLU) on each axis. Pulse frequency sets the feed, and a counter converts pulses into position. It is simple and needs no feedback in an open-loop machine, and it suits stepper and older DC drives. Its limit is the pulse rate the counter and drive can accept.

A reference-word (absolute, sampled) interpolator does its arithmetic once every sample period T, typically 1 ms to 10 ms. Each axis receives a position word — 'be at 41.27 mm now'. The comparator subtracts the encoder count and the servo closes the loop. Modern AC servo machines work this way.

Linear interpolation finds the intermediate points on a straight line; circular interpolation finds them on an arc. The DDA (digital differential analyser) does both with adders: each axis holds an increment, adds it every iteration, and the carry-out becomes a pulse.

f = v / (60 × BLU)

f is the pulse frequency along the path (pulses/s); v is the feed rate (mm/min); BLU is the basic length unit, the distance moved per pulse (mm); 60 converts minutes to seconds.

e ≈ L² / (8R)

e is the chord error, the largest gap between the true arc and the straight chord (mm); L is the chord length (mm); R is the arc radius (mm). Small L and large R make e negligible.

Measuring the slide and checking the part

An incremental encoder has a slotted disc, a light source and a photocell. Channels A and B are 90° out of phase, and direction comes from which channel leads. Counting both edges of both channels gives four counts per grating line, so a 2500-line encoder yields 10 000 counts per revolution. A third Z channel marks one position per revolution for homing.

An absolute encoder reads a coded pattern and knows its position at power-on, so no homing is needed. A linear grating (glass scale) is fixed to the table and reads position directly, so screw pitch error and backlash stay outside the loop. A resolver is a small rotary transformer, rugged and analogue, still found on older machines.

A laser interferometer measures true distance along an axis to a fraction of a micrometre. It is used to check positioning accuracy and to fill the pitch-error compensation table inside the control.

For the part itself, a touch probe held in the spindle finds an edge or a bore and reports to the control; a coordinate measuring machine checks finished parts in a metrology room; in-process gauging measures during grinding and feeds the size back to the control.

Worked example

Question. A CNC milling centre has a basic length unit (resolution) of 0.01 mm. One block commands a straight line from P0 (0, 0) to P1 (60, 40) mm at a feed rate of 1200 mm/min. Using a reference-pulse interpolator, find (a) the path length, (b) the machining time, and (c) the pulse rate on the X and Y axes.

  1. Path length: L = √(60² + 40²) = √(3600 + 1600) = √5200 = 72.11 mm.
  2. Machining time: t = L / v = 72.11 / 1200 = 0.06009 min = 3.606 s.
  3. Pulses needed on X: 60 / 0.01 = 6000 pulses. On Y: 40 / 0.01 = 4000 pulses.
  4. X pulse rate = 6000 / 3.606 = 1664 pulses/s.
  5. Y pulse rate = 4000 / 3.606 = 1109 pulses/s.
  6. Check: the resultant pulse rate is √(1664² + 1109²) = √(2768896 + 1229881) = √3998777 ≈ 2000 pulses/s, which matches f = v / (60 × BLU) = 1200 / (60 × 0.01) = 2000 pulses/s.

Answer. Path length 72.11 mm, machining time 3.606 s, X pulse rate 1664 pulses/s and Y pulse rate 1109 pulses/s.

Exam traps

  • Open loop means no measurement of the slide, not 'no feedback from the program'. The part program drives both open-loop and closed-loop machines.
  • Quadrature gives four counts per grating line, not one. A 2500-line encoder on a 5 mm-pitch screw gives 5 / 10 000 = 0.0005 mm per count, not 0.002 mm.
  • Feed in mm/min and pulse rate in pulses/s differ by a factor of 60. Forgetting the 60 puts the answer out sixty times.
  • In point-to-point control the path is not controlled, so you cannot ask for the distance travelled between holes — only the final positions matter.
  • The chord error is L²/(8R), not L²/(2R). Work one numerical case with R = 50 mm and L = 1 mm to fix the factor 8 in your memory: e = 2.5 µm.

6.4 Manual NC part programming

A part program is a list of blocks. Each block tells the machine where to go, how fast to move, and which spindle and tool to use. Manual part programming means a person writes these blocks from a drawing, without CAM software. It still matters for small shops, repairs, simple profiles and learning what the controller actually does. A clear program also prevents crashes: the safe start block, work offset, tool length and cutter radius compensation are set before the first cut. The same G-code structure runs a milling machine and a lathe, with small differences in feed units and cycles.

You need 6.3 for interpolation and work offsets, and Unit 5 for cutting speed and feed.

Block and word format

One block is one line. A word is an address letter plus a number. N numbers the block. G selects a preparatory mode. X, Y, Z are coordinates; I, J, K are arc centre offsets from the arc start; R is the arc radius when a G02/G03 arc is written with a radius instead of I and J, and the retract plane level in a canned cycle. The working plane is selected by G17 (XY), G18 (ZX) or G19 (YZ), not by R. F is feed, S spindle speed, T tool, M a switching code. Write words in the order N, G, X, Y, Z, I, J, K, F, S, T, M. Most controllers accept another order, but this order is easy to check.

A modal word stays active in later blocks until replaced. G01 remains the motion mode after it is written; a later block with only X and Y still feeds. A non-modal word acts only in its own block, such as G04 dwell or G28 return to reference.

Start every program with a safe start block: N10 G21 G90 G54 G40 G49 G80. G21 selects millimetres, G90 absolute coordinates, G54 the first work offset, G40 cancels cutter radius compensation, G49 cancels tool length compensation, G80 cancels canned cycles. This puts the machine in a known state before the first move.

Motion, offsets and cycles

G00 is rapid traverse, not a cutting move. G01 is straight-line feed. G02 and G03 are circular arcs; G02 is clockwise and G03 counter-clockwise seen looking down the +Z axis towards the work. An arc block gives the end point and the centre via I and J from the arc start.

G90 uses absolute coordinates from work zero; G91 uses increments from the current point. From X50 Y20, G90 X80 Y40 reaches X80 Y40. G91 X30 Y20 also reaches X80 Y40. G54 to G59 are work offsets that store part zero relative to machine zero.

G41 and G42 switch cutter radius compensation on, left and right of the direction of travel. Program the part outline; the controller shifts the tool centre by the cutter radius from the D register. G40 cancels. G43 applies tool length compensation from the H register, so Z is measured to the tool tip. G49 cancels.

Canned cycles compress repeated motions. G81 drills to depth and retracts. G83 peck drills in steps to clear chips. G84 taps. On a lathe, G71 roughs a profile in two blocks and G70 finishes it.

F is mm/min on a mill and mm/rev on a lathe. S is rev/min. T selects a tool. M03 and M04 start the spindle forward and reverse, M05 stops it, M06 changes tool, M30 ends the program.

6.5 Computer-aided part programming

Computer-aided part programming turns a CAD model into a cutter path, then into machine code. CAM software decides where the tool centre goes; it does not write code for one controller. Its output is CL data, a neutral cutter-location file. A post-processor translates CL data into G-code blocks for a named machine and control. Shops use this for moulds, dies and parts with curved surfaces or many holes. Only a few universities teach this, so fix the division: tool path first, machine code second.

You need: 6.4 Manual NC part programming for the block format the post-processor must produce.

The neutral cutter path

CAD stores shape only: faces, edges and dimensions. It does not choose a cutter, an approach direction or a depth of cut. CAM software adds those decisions and produces a tool path. The path is written as CL data, short for cutter location data. Each CL record gives the tool tip position, tool axis direction, feed and spindle instructions. The cutter location is the tool tip, not the spindle face. CL data is machine-independent, so one file can be post-processed for a three-axis mill, a turning centre or another control.

The split exists because controls differ. A Fanuc control, a Siemens control and a small router do not use identical G-code words, canned cycles or arc formats. If CAM wrote machine code directly, every machine would need its own CAM output. With CL data, the path is computed once and translated many times. The post-processor maps CL records to the block format taught in 6.4.

APT-style geometry and motion

An APT-like language describes the part with geometry statements and the path with motion statements. Geometry statements name points, lines and circles. Motion statements move to named geometry or by an incremental distance. Geometry names are reused, so the path stays readable and editable.

Roughing, finishing and checking

Roughing removes most material quickly. It uses a larger stepdown, the depth between passes in Z, and a moderate stepover, the sideways distance between parallel passes in XY. Stepover is measured between tool-centre paths, not between cut edges. Finishing cuts a thin layer at small stepover to meet tolerance and surface finish. A lead-in enters the cut smoothly; a lead-out exits without leaving a mark. For a pocket, CAM starts at the centre and works outward in rings.

r<sub>max</sub> = R<sub>pocket</sub> − r<sub>cutter</sub>

rmax is the largest tool-centre ring radius; Rpocket is the pocket radius; rcutter is the cutter radius.

Before download, CAM simulates the path. It checks gouges, rapid moves through clamps, holder collisions and axis limits. Collision checking uses machine and fixture models, not only the part. Feature-based programming recognises a hole, pocket or slot and applies a stored strategy.

6.6 Electrical discharge machining (EDM)

Electrical discharge machining removes metal with sparks, not a cutting edge. A shaped tool electrode and the workpiece sit in a tank of dielectric fluid, a few tens of micrometres apart, and a pulse generator drives thousands of sparks per second across the gap. Each spark melts and flings away a crater of metal. The tool never touches the work, so there is no cutting force and very hard or very thin parts can be cut. Dies, moulds, press tools and hard alloys are the everyday work.

You need: 6.2 for servo feed drives, and the basic electrical ideas of voltage, current and energy.

The spark erosion cycle

EDM uses a shaped tool electrode and the workpiece, both dipped in dielectric fluid — kerosene for most die work, deionised water in wire machines. The tool is the cathode, wired to the negative side of a DC pulse generator. The workpiece is the anode, on the positive side. They never touch; a gap of a few tens of micrometres stays between them.

The dielectric insulates the gap between pulses, breaks down to form the spark channel, cools the gap, and carries the eroded debris out.

  1. The pulse generator raises the voltage across the gap and stresses the dielectric.
  2. At the narrowest point the dielectric breaks down into a thin plasma channel a few micrometres wide.
  3. Current heats the channel to several thousand degrees, so a tiny volume of tool and work melts and partly vaporises.
  4. The pulse switches off, the channel collapses, the molten metal is thrown out, and a crater is left in the work.
  5. Fresh dielectric sweeps the debris away and the servo head advances the electrode to restore the gap.

The gap sets everything. Too wide and no spark forms; too narrow and the electrode touches the work, or the spark becomes a continuous arc that burns the surface. Removal rate changes as the cavity deepens, so a fixed down-feed loses the gap. The servo head measures the average gap voltage, which rises as the gap widens, compares it with a set value, and moves the electrode to hold the gap. This is the closed-loop position control used on CNC feed drives (see 6.2).

Pulse parameters and electrode wear

One spark is described by its on-time, off-time, peak current and gap voltage. On-time ton is how long the pulse lasts. Off-time toff is the pause before the next pulse. Peak current Ip is the current the channel carries. Gap voltage Vg is the voltage across the gap during the discharge.

E<sub>s</sub> = V<sub>g</sub> × I<sub>p</sub> × t<sub>on</sub>

Es is the energy of one spark in joules (J); Vg is the gap voltage in volts (V); Ip is the peak current in amperes (A); ton is the pulse on-time in seconds (s).

f = 1 ÷ (t<sub>on</sub> + t<sub>off</sub>),   duty cycle = t<sub>on</sub> ÷ (t<sub>on</sub> + t<sub>off</sub>),   P<sub>avg</sub> = E<sub>s</sub> × f

f is the pulse frequency in hertz, that is sparks per second; the duty cycle is a fraction (or a percentage); Pavg is the average power delivered to the gap in watts (W).

A long on-time and a high peak current make a bigger, hotter spark: removal is faster, but the crater is larger, so the surface is rougher and the recast layer thicker. A short off-time leaves too little time to flush; the gap fills with conducting particles and the spark wanders into stray arcs that damage the surface.

The tool erodes as well as the work. The wear ratio is the volume of electrode lost divided by the volume of work removed. Graphite gives fast cutting at high current with low wear and is used for roughing. Copper gives a better surface at fine settings. Brass wire is the standard wire electrode; tungsten and coated wires cut fine work. Because the electrode shrinks, a deep cavity needs a roughing electrode and one or more fresh finishing electrodes to hold size.

Die-sinking, wire EDM and process limits

In die-sinking (ram EDM), the tool electrode is a mirror shape of the cavity wanted, and it is sunk into the work: forging dies, injection moulds, extrusion dies. In wire EDM, the electrode is a brass wire 0.1 to 0.3 mm thick, travelling from a spool to a take-up reel so no part of it cuts twice. The work is usually a plate cut on a two-axis path, or four axes for taper. The cut is wider than the wire by the spark gap on each side; that extra width is the overcut.

Debris left in the gap causes stray sparks, so flushing matters. Side flushing jets dielectric between electrode and cavity wall; through-flushing pushes it down a hole in the electrode; suction pulls it out through the electrode; wire machines jet fluid from above and below the plate.

The recast layer is a thin resolidified skin, a few micrometres to tens of micrometres, left on the cut surface; it is hard and brittle and is often removed by a low-current finishing pass or by polishing.

Limits: conductive work only, slow compared with milling, electrode wear, recast layer. Uses: press tools and punches, forging dies, plastic moulds, carbide parts, turbine components, micro-holes such as fuel-injector nozzles.

Worked example

Question. An EDM run uses gap voltage 25 V, peak current 20 A, pulse on-time 100 µs and off-time 100 µs. Find the energy per spark, the pulse frequency, the duty cycle and the average power delivered to the gap.

  1. Given: Vg = 25 V, Ip = 20 A, ton = 100 µs = 100 × 10⁻⁶ s, toff = 100 µs = 100 × 10⁻⁶ s.
  2. Energy per spark: Es = Vg × Ip × ton = 25 × 20 × 100 × 10⁻⁶ = 0.05 J.
  3. Period of one cycle: T = ton + toff = 200 µs = 200 × 10⁻⁶ s.
  4. Frequency: f = 1 ÷ T = 1 ÷ (200 × 10⁻⁶) = 5000 sparks per second.
  5. Duty cycle = ton ÷ T = 100 ÷ 200 = 0.5, that is 50 %.
  6. Average power: Pavg = Es × f = 0.05 × 5000 = 250 W. Check: Vg × Ip × duty cycle = 25 × 20 × 0.5 = 250 W.

Answer. Each spark carries 0.05 J, the generator fires 5000 sparks per second, the duty cycle is 0.5 (50 %), and the average power into the gap is 250 W.

Exam traps

  • Thinking EDM cuts any material. The work must conduct electricity, so plastics and ordinary ceramics cannot be cut.
  • Mixing up wire EDM, where a travelling wire is the electrode, with die-sinking, where a shaped electrode is sunk into the work.
  • Writing duty cycle as ton ÷ toff. It is ton ÷ (ton + toff), and microsecond times must be converted to seconds before computing energy in joules.
  • Claiming higher current improves everything. It raises removal rate but makes the surface rougher and deepens the recast layer and overcut.
  • Forgetting the servo. A fixed down-feed cannot hold a gap of tens of micrometres, so gap voltage feedback is the answer to 'why servo control?'.

6.7 Abrasive water jet machining

Abrasive water jet machining (AWJM) cuts metal, glass, stone and composites with a jet of water moving faster than sound, carrying abrasive grains. Only the jet touches the work, so cutting force is very small, there is no heat affected zone, and light clamping is enough. A high-pressure pump and intensifier push water at a few hundred MPa through a tiny orifice; abrasive is drawn in below the orifice and accelerated down a mixing tube. The jet erodes a narrow slot as the nozzle traverses.

You need: Bernoulli's equation and continuity from fluid mechanics; surface finish comparison in Unit 5, grinding and finishing.

How the jet cuts

Water alone at high pressure cuts foam, rubber, cardboard and food: plain water jet cutting. Hard materials need abrasive. Garnet grains join the jet and strike at several hundred metres per second. Each grain chips a tiny fragment and the water carries debris out. Removal is erosion, not melting or shearing.

Near the top the jet is fast and coherent, cutting a slot about its own width. Deeper down it slows and loses coherence; only the core erodes, so the cut narrows. The top of the kerf (slot) is wider than the bottom, and jet lag shows as curved striations. Thick parts need slower traverse so the jet reaches the bottom.

The cut face is matt, a few micrometres roughness when cutting is slow. There is no recast layer, no dross burr like laser cutting, and no heat microcracks. Thin sheet may show a small exit burr, easily removed.

Building the pressure and the jet

A motor-driven pump takes water to about 20 MPa. A hydraulic intensifier multiplies this: a large-area hydraulic piston pushes a small-area plunger on the same rod, so output pressure is input pressure times the area ratio. A ratio of 15 gives 300 MPa from 20 MPa. Two intensifier cylinders alternate so one pumps while the other refills; a gas-charged accumulator absorbs pulses and steadies the jet.

Working pressure is 150 to 400 MPa, that is 1500 to 4000 bar. Compressed water at these pressures stores much energy; a pinhole leak can inject water through skin. Never put a hand near a pressurised line.

v = √(2P ÷ ρ)

v is jet velocity at the orifice exit in m/s; P is water pressure in Pa; ρ is water density in kg/m³, about 1000 kg/m³. This is Bernoulli's equation with upstream velocity taken as zero.

The orifice is a sapphire or diamond disc with a hole 0.1 to 0.4 mm across; it wears and is replaced. Below it the jet enters the mixing (focusing) tube: tungsten carbide or composite, 50 to 100 mm long, 0.5 to 1.5 mm bore. Abrasive from a hopper passes a metering valve into the mixing chamber, and the fast jet drags grains in by a venturi effect and accelerates them down the tube. Abrasive never enters the pump or orifice; it would destroy the high-pressure seals.

Standoff distance is the gap between mixing tube exit and work, usually 1 to 5 mm. Small standoff keeps the jet coherent, giving narrow kerf and good accuracy; too small and the nozzle can strike the work. Traverse rate (mm/min) sets dwell time, hence depth of cut and taper.

Garnet is the usual abrasive: hard, cheap, breaks into sharp fragments. Grain size uses FEPA or mesh scale, typically 80 mesh for fine finish and 60 or coarser for speed. Abrasive flow is about 0.2 to 0.6 kg/min: too little wastes jet energy, too much chokes the mixing tube.

Why it is used, and where it stops

  • No heat affected zone or thermal distortion: good for thin sheet, titanium and composites that burn under a laser.
  • Very small cutting force, so thin flexible parts need only light clamping.
  • Narrow kerf, often 0.8 to 1.5 mm: little material loss, easy nesting.
  • Cuts almost any material: metals, glass, ceramics, stone, composites, stacked layers.
  • Can pierce mid-sheet and follow any CNC contour.

Capital and running costs are high: the pump draws tens of kilowatts, orifice and mixing tube wear out in tens to hundreds of hours, and abrasive is consumed continuously. The process is essentially a through cut; blind pockets are slow. Accuracy about ±0.1 to ±0.2 mm and taper are poorer than milling. Noise can exceed 85 dB and the spray carries fine abrasive mist.

Against laser cutting: a laser is faster and more precise on thin sheet but leaves a heat affected zone and possible recast layer. AWJ is slower but cuts thick sections, reflective metals such as aluminium and copper, and composites without heat damage. A laser cannot cut thick stone; water jet can. Choose by material, thickness and whether heat damage matters, not by speed alone.

Applications include marble and stone slabs with decorative profiles, glass cut without chipping, aerospace composites and titanium, gaskets, and food or plastics cut by plain water jets. Some shops turn and mill with a small abrasive jet under CNC control, the nozzle held in a tool holder.

Worked example 2

Question. A 60 mesh garnet abrasive is fed at 0.30 kg/min into the mixing tube of the previous machine. Traverse rate is 120 mm/min and kerf width is 1.2 mm. (a) How much abrasive is used per metre of cut? (b) What area of new surface is created per second, counting one cut face only?

  1. Traverse rate = 120 mm/min = 2.0 mm/s, so one metre takes 1000 ÷ 120 = 8.333 min.
  2. Abrasive per metre = 0.30 kg/min × 8.333 min = 2.5 kg.
  3. New face per second = kerf width × traverse rate = 1.2 mm × 2.0 mm/s = 2.4 mm²/s, about 2.4 × 10⁻⁶ m²/s.
  4. That 2.5 kg garnet per metre is why abrasive consumption dominates running cost.

Answer. Abrasive use is 2.5 kg per metre of cut, and the cut face is created at 2.4 mm²/s.

Exam traps

  • Putting abrasive through the pump or orifice. It is entrained in the mixing tube, after the orifice, so it never touches high-pressure seals.
  • Unit slip on pressure: 300 MPa is 3000 bar, and 1 MPa = 10⁶ Pa, not 10⁵.
  • Confusing jet velocity with traverse rate: the jet moves at hundreds of m/s, the nozzle at a few mm/s.
  • Thinking a small standoff hurts accuracy. A standoff of 1-3 mm gives narrower kerf and less taper.
  • Claiming AWJ leaves a heat affected zone or recast layer. It erodes, so the work stays near room temperature; that is its main selling point over laser cutting.

Check yourself

Remember Name the components that raise the water pressure, and the one that steadies it, in an abrasive water jet machine. 2 marks

The high-pressure pump raises water to an intermediate pressure and the intensifier multiplies it to cutting pressure. The gas-charged accumulator absorbs pulses and steadies the flow.

Understand Why is abrasive added after the orifice rather than before it? 3 marks

Hard grains would abrade pump seals, valves and the small orifice and wear them out quickly. Adding abrasive in the mixing tube lets the clean high-speed jet draw grains in and accelerate them, so only the cheap replaceable tube sees the abrasive.

Understand Explain why an AWJ cut is slightly tapered, with the top wider than the bottom. 3 marks

Near the top the jet is fast and coherent, so it cuts a slot about the width of the jet. Deeper down it slows and loses coherence, only its core still erodes, and the cut narrows. So the top of the kerf is wider than the bottom, and jet lag shows as curved striations.

Apply Water at 250 MPa and density 1000 kg/m³ leaves an orifice. Find the jet velocity. 3 marks

v = √(2P ÷ ρ) = √(2 × 250 × 10⁶ ÷ 1000) = √(500 000) = 707.1 m/s, about twice the speed of sound in air.

Apply An intensifier receives oil at 18 MPa and must deliver water at 360 MPa. What area ratio is needed, and if the water plunger area is 30 mm², what is the piston area? 4 marks

Area ratio = 360 ÷ 18 = 20. Piston area = 20 × 30 mm² = 600 mm².

Analyze A shop must cut 25 mm thick carbon-fibre composite panels for an aircraft fairing. Compare abrasive water jet and laser cutting for this job and justify a choice. 5 marks

Laser cutting is fast and precise on thin sheet, but heat chars the resin, leaves a heat affected zone and can delaminate the composite, so the edge needs trimming. AWJ erodes at near room temperature: no charring, no heat delamination, no heat affected zone, and the small force does not distort the panel. AWJ is slower and consumes garnet, but for a 25 mm structural composite it gives an acceptable edge in one pass. Choose AWJ, with slower traverse and higher abrasive flow to control taper.

Analyze Increasing traverse rate raises productivity but reduces depth of cut and worsens finish, widening taper. Explain this trade-off and state what you would change to cut a thicker part at the same quality. 4 marks

A slow traverse lets the jet dwell, so it fully penetrates, the bottom of the cut catches up with the top, and the face is smoother with less taper. A fast traverse leaves the jet lagging: shallower cut, deeper striations, more taper. For a thicker part at the same quality, raise pressure, raise abrasive flow up to saturation, and reduce standoff, rather than only slowing the traverse, which costs productivity.

Beyond the syllabus

Not for the exam. Research models AWJ erosion with computational fluid dynamics coupled to particle tracking, so taper can be predicted and compensated in the CNC path. Five-axis machines tilt the nozzle to cancel taper, and some add a second angled jet. Micro-AWJ uses orifices below 0.1 mm for thin wafers and medical implants. Hybrid variants add a laser or cryogenic jet to soften the work ahead of the water. Search for 'AWJ taper compensation', 'abrasive water jet turning' and 'CFD erosion modelling'.

Takeaways

  1. Numerical control moved the instruction from a punched tape to a computer memory, and DNC moved it from the machine to a central computer.
  2. A CNC machine is a stiff structure with low-friction guideways, a spindle drive and a feed drive, all sized to hold position under cutting force.
  3. The controller turns a wanted path into a stream of axis position commands and compares each command with the measured position, correcting the error.
  4. Open loop with a stepper motor is cheap and suits light point-to-point work; closed loop with an encoder and servo is standard on contouring machines.
  5. A part program is a list of blocks, and each block says where to go, how fast, and with what spindle speed and tool.
  6. CAM software makes CL data from a CAD model, and a post-processor turns that CL data into G code for one specific machine.
  7. EDM removes metal by repeated sparks across a dielectric-filled gap, so there is no cutting force and the electrode never touches the work.
  8. Abrasive water jet machining erodes the work with a fast water jet carrying abrasive particles, giving a narrow heat-affected zone and no tool wear.

Remember and understand

Understand Trace the evolution from NC to CNC and then to DNC. Distinguish direct numerical control from distributed numerical control. 12 marks

Punched tape NC: fixed logic, tape re-read every part, no memory; CNC: stored program in memory, editable at the machine, one machine per controller; Direct NC: central computer feeds blocks to many machines in real time; Distributed NC: central host only downloads programs; each machine has its own computer and memory; Advantages: less tape handling, program editing, program library, production data collection; Typical uses: job shops with many part variants.

Understand Describe the main building blocks of a CNC turning centre and a machining centre: structure, guideways, spindle drive and feed drive. 12 marks

Machine bed and column: ribbed cast iron or welded steel, filled or polymer concrete for damping; Guideways: hardened box ways (friction, high damping) or linear recirculating-ball guideways (anti-friction, low stick-slip); Spindle drive: DC shunt motor or AC induction motor with vector drive, gearbox or belt, constant surface speed; Feed drive: ball screw or linear motor, stepper or servo motor, encoder feedback; Tool turret and automatic tool changer, with tool storage and identification; Sizing: thrust and torque must hold position within a few micrometres under cutting force.

Understand Explain open loop and closed loop control in CNC machine tools with block diagrams, and state where each is used. 12 marks

Open loop: controller to pulse counter to stepper motor to ball screw, no feedback; Error sources in open loop: lost steps, backlash, thermal growth; Closed loop: command compared with encoder measurement, error drives the servo amplifier; Elements: interpolator, position loop, velocity loop, current loop, tachogenerator and encoder; Choice: stepper for light, cheap, point-to-point; servo for contouring, heavy cuts, accuracy; Mention resonance, gain, and following error in contouring.

Understand Explain point-to-point, straight-cut and contouring control systems with a sketch of the tool path in each case. 10 marks

Point-to-point: final position only, path irrelevant, no cutting during move, used on drilling machines; Straight-cut (paraxial): one axis at a time in motion, giving lines parallel to axes, used on simple milling; Contouring: two or more axes coordinated continuously, straight lines and arcs at constant feed; Interpolator types: DDA hardware, software, reference-pulse and sampled-data; Effect on surface finish and feed-rate limits.

Apply Write a manual part program for a part with four holes on a rectangular pitch and one straight milled edge on a CNC machining centre. Explain each block. 13 marks

Apply Explain circular interpolation by the DDA method. Show how a straight line from (0,0) to (6,4) is generated in a few clock pulses. 13 marks

Principle: accumulate an increment in one register, overflow in the other axis register produces a step; For a line, increments proportional to axis displacement, so both axes finish together; Table of clock pulse, accumulator value, carry, step taken, position; For an arc, start and end point plus centre or radius given; increments change sign at quadrant points; Result: small quantised steps approximating the straight line, chord error set by resolution; Mention hardware DDA versus software interpolation in the controller.

Apply Describe computer-aided part programming. Show the flow from a CAD model to cutter location data and then to machine G code. 12 marks

Apply Explain the working principle of die-sinking EDM. Describe the function of the dielectric, the servo-controlled gap and the main process parameters. 13 marks

Spark across a small gap in dielectric; melting and vaporisation of a tiny volume; crater formed; Tool is the cathode, work is the anode in the usual connection; Dielectric: kerosene or deionised water; flushes debris, cools, insulates until breakdown; Gap voltage builds until breakdown, discharge, recovery; servo maintains gap around a few tens of micrometres; Parameters: peak current, on-time, off-time, gap voltage, flushing pressure, electrode material; No cutting force, so thin sections and hardened steel can be machined; electrode wear ratio matters; Surface finish and recast layer depend mainly on energy per spark.

Apply Explain wire EDM. How is the wire kept in tension and how is overcut compensated to obtain an accurate die opening? 10 marks

Thin brass or coated wire travels from a spool to a take-up reel, used once; Work is a plate mounted on a table; wire cuts a narrow kerf through it; Deionised water dielectric, flushing from top and bottom nozzles; Overcut equals half of kerf minus wire radius; tool path is offset by the wire radius plus gap; Multiple trim passes for finish and accuracy; corner control and taper cutting; Applications: press tool dies, punches, extrusion dies, hard conductive material.

Analyze and evaluate

Analyze Analyse how peak current, on-time and off-time affect metal removal rate, surface finish, wear ratio and recast layer in die-sinking EDM. 13 marks

Metal removed per spark grows with pulse energy, so MRR rises with peak current and on-time; Roughness rises with energy per spark: craters deeper and wider; Wear ratio worsens with long on-time and high current for a given electrode pair; Too short an off-time leaves debris in the gap, causes arcing and unstable cutting; Recast layer thickens with energy; may need finishing passes or post-machining; Trade-off: roughing with high current then finishing with low current.

Analyze Compare EDM and abrasive water jet machining with conventional milling on cutting force, tool wear, workpiece hardness, heat effects and accuracy. Then choose a process for cutting a 20 mm hardened tool steel plate with a curved profile. 14 marks

Force: near zero for EDM and AWJM, high for milling; Tool wear: electrode wear in EDM, abrasive nozzle wear in AWJM, cutter wear in milling; Hardness: EDM needs conductivity but not hardness; AWJM cuts almost any material; milling needs softer material and carbide tools; Heat: EDM leaves a recast layer, AWJM leaves a small heat-affected zone; Accuracy and finish: EDM tight with fine finish; AWJM has taper and wider kerf; Selection for the hardened conductive plate: wire EDM, with reasons; Spans both non-traditional chapters and CNC fundamentals of axis control.

Evaluate A shop must make 500 deep square pockets in hardened die blocks and also cut thin sheets of composite. Evaluate which of die-sinking EDM, wire EDM or abrasive water jet machining should be used, and justify with process limits. 14 marks

Deep square pocket with sharp internal corners: die-sinking EDM with a shaped electrode; wire EDM cannot start a blind pocket; Electrode manufacture and wear allowance; number of electrodes for 500 parts; Composite sheet: non-conductive, so EDM is not possible; AWJM cuts it without delamination; AWJM taper and kerf, abrasives and nozzle life; Combination route: EDM for the die, AWJM for the composite trimming; Cost, cycle time and surface integrity reasoning.

Analyze Analyse the sources of positioning error in a CNC machine and explain how encoders, gratings and a laser interferometer are used to measure and correct axis position. 13 marks

Error sources: ball screw pitch error, backlash, thermal growth, guideway friction and stick-slip, structural deflection; Incremental encoder: pulse counting, needs a reference mark; absolute encoder gives position at power-on; Linear grating on the slide measures true table position, closing the loop past the screw; Laser interferometer: compares a laser wavelength with slide travel, used for calibration and compensation tables; Pitch error and backlash compensation stored in the controller; Distinguish machine accuracy from part accuracy under cutting load; Spans machine building and the control chapter.

Evaluate Evaluate the claim that a closed-loop CNC machine is always better than an open-loop one for a small job shop in India facing frequent power cuts. 12 marks

Closed loop benefits: accuracy, contouring, heavy cuts, self-correction; Costs: servo motors, drives, encoders, tuning and maintenance; Open loop with stepper motors: cheaper, simple, but lost steps under overload; Power cut effects: position loss in open loop; absolute encoders or homing needed in closed loop; Work envelope, batch size, tolerance demanded decide the choice; Verdict depends on job mix, not a universal rule.

Glossary

Backlash
Lost motion when a screw or gear reverses direction, seen as a small position error on axis reversal.
Ball screw
A screw with recirculating steel balls between screw and nut, giving low-friction, near-zero-backlash motion.
Block
One line of a part program, containing a sequence number, motion words, feed and spindle words.
CNC
Computer numerical control: an NC machine in which a dedicated computer stores and executes the part program.
Dielectric
The insulating fluid in EDM that breaks down at the spark gap, flushes debris and cools the cut.
Feed drive
The motor, screw or linear motor and feedback that move a slide along one axis.
G code
A preparatory code that sets the mode of motion or a cycle, for example G01 straight feed or G81 drilling.
Garnet
A hard, cheap mineral abrasive commonly used in abrasive water jet machining.
Interpolator
The part of the controller that generates intermediate axis positions between two programmed points.
Kerf
The width of the slot cut by wire EDM or by an abrasive water jet.
M code
A miscellaneous code for machine functions such as spindle on, coolant on, tool change or program end.
Machine control unit
The electronics and software of a CNC that read the program, interpolate the path and drive the axes.
Numerical control (NC)
Control of a machine tool by a coded set of instructions that give positions, feeds and spindle speeds.
Off-time
The pause between two EDM pulses, in microseconds, during which the gap de-ionises and debris is flushed.
Part program
The ordered list of blocks of G and M codes that describes the tool path for a part.
Peak current
The maximum current of an EDM discharge, which sets the energy per spark and hence removal rate.
Position encoder
A sensor that converts axis position into a digital code, either incremental or absolute.
Rapid prototyping
Building a part layer by layer directly from a CAD model, without a mould or cutting tool.
Servo motor
A motor with feedback that follows a commanded speed or position, used in closed-loop drives.
Spindle drive
The motor and transmission that rotate the tool or work, often with constant surface speed control.
Stepper motor
A motor that turns a fixed angle for each input pulse, used for open-loop axis drives.
Stereolithography
Rapid prototyping in which a laser cures a liquid resin layer by layer.
Stored program
The complete part program held in memory so it can be run repeatedly and edited.
Wear ratio
The ratio of electrode volume worn to work volume removed in EDM.
