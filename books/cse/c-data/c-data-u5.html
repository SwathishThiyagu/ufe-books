5.1 Types of machine learning: supervised and unsupervised

Machine learning (ML) means building a model from data instead of writing the rules by hand. Nobody can write down every rule that separates a fraudulent UPI payment from a normal one, but a program can study a lakh of past payments that were marked "fraud" or "genuine" and find the pattern itself. When the past data comes with the right answers attached, the learning is supervised; when it does not, and the program must find structure on its own, it is unsupervised. This chapter sets up the words (features, labels, training set, overfitting) that the rest of the unit uses.

You need: the data science process and the idea of predictive analytics (Unit 1, Types of analytics), and clean, numeric features (Unit 2, Feature engineering and feature selection).

What "learning" means

Tom Mitchell's definition, in plain words: a program learns from experience E on a task T, measured by a score P, if its score on T improves with more E. For a spam filter, T is "label each email", E is the emails users have already marked, and P is the percentage labelled correctly. The vocabulary of every chapter:

  • Instance (example, record, row): one object in the data, such as one customer.
  • Features x (attributes, predictors): the measured inputs, such as monthly visits and spend; a row with p features is x = (x₁, …, xₚ).
  • Label or target y: the answer to predict, such as "bought".
  • Model: a function ŷ = f(x) with adjustable parameters (a slope, network weights); ŷ ("y-hat") is the prediction.
  • Training: choosing the parameters to fit the known data. Hyperparameters are set before training: a tree's depth, k in k-means, the learning rate.

Supervised and unsupervised learning

In supervised learning every training row is a pair (x, y). The algorithm learns f so that f(x) is close to y, then predicts y for new rows. The type of y decides the task:

  • Regression: y is a number, such as Chennai's electricity demand in megawatts or a flat's rent (Chapter 5.2).
  • Classification: y is a category, such as fraud or genuine, or which of ten digits (Chapters 5.3 to 5.5).

In unsupervised learning the rows have only x. There is no right answer to copy, so the algorithm looks for structure:

  • Clustering: put similar rows in the same group, such as customer segments (Chapter 5.6).
  • Dimensionality reduction: replace many correlated features with a few new ones (PCA, Chapter 5.7).
  • Association rules: find items that occur together, such as "customers who buy bread also buy butter".
  • Anomaly detection: flag rows far from the rest. They use the distances of Chapter 5.6.

Semi-supervised learning uses a few labelled rows and many unlabelled ones, since labelling costs money. In reinforcement learning an agent acts, receives a reward and learns a policy that earns more reward, as in game-playing programs.

Training, validation and testing

A model is useful only if it generalises: it predicts well on rows it has never seen. An underfit model is too simple and is wrong even on its training data (a straight line through a curve). An overfit model memorises the training rows, noise included, and does badly on new ones (a tree with one leaf per row). The first has high bias, the second high variance. So never judge a model on the rows it learned from. Split the data:

  1. Training set (often 60–80% of rows): the algorithm fits its parameters here.
  2. Validation set: compare models and tune hyperparameters here.
  3. Test set: keep it locked until the end, then score the chosen model on it once. That score is your honest estimate for new data.

When data is scarce, k-fold cross-validation replaces the single validation set: cut the non-test rows into k equal folds, train on k − 1 and validate on the remaining one, repeat so each fold validates once, and report the mean of the k scores (k = 5 or 10 is usual).

Exam traps

  • Clustering is unsupervised even though its output looks like class labels; it never sees a label.
  • The target decides regression versus classification, not the inputs. Logistic regression is a classification method despite its name.
  • Using the test set to choose between models makes its score too optimistic. Tune on validation data; touch the test set once.
  • Overfitting is diagnosed by the gap: low training error with high validation error. Both errors high means underfitting.
  • Parameters are learned (weights, slopes); hyperparameters are set before training (depth, k, learning rate). Examiners ask for two examples of each.

5.2 Linear and multiple regression; least squares fit

Regression predicts a number from one or more features by fitting a straight line (with several features, a flat plane) through the data. Least squares picks the line that makes the total of the squared vertical misses as small as possible. It is the most used predictive model, behind sales forecasts and price estimates, and the base on which logistic regression and neural networks are built.

You need: mean, variance and correlation (Unit 3, Correlation and covariance) and the t-test (Unit 4, z-tests and t-tests).

The line and the least-squares rule

The simple linear regression model is y = β₀ + β₁x + ε. Here x is the feature, y the target, β₀ (beta-zero) the intercept (y when x = 0), β₁ the slope (change in y per unit of x) and ε a random error with mean 0. From data we compute estimates b₀ and b₁, and the fitted value for row i is ŷᵢ = b₀ + b₁xᵢ. The residual eᵢ = yᵢ − ŷᵢ is how far the point lies above (+) or below (−) the line.

Least squares chooses b₀ and b₁ to minimise the sum of squared errors, SSE = Σ eᵢ² = Σ (yᵢ − b₀ − b₁xᵢ)². Squaring stops +5 and −5 cancelling, punishes big misses most, and gives a formula. Set both partial derivatives to zero:

∂SSE/∂b₀ = −2 Σ (yᵢ − b₀ − b₁xᵢ) = 0     →   Σyᵢ   = n·b₀ + b₁·Σxᵢ
∂SSE/∂b₁ = −2 Σ xᵢ(yᵢ − b₀ − b₁xᵢ) = 0   →   Σxᵢyᵢ = b₀·Σxᵢ + b₁·Σxᵢ²

Solving these two "normal equations":
   b₁ = Sxy / Sxx,     b₀ = ȳ − b₁·x̄
   where Sxy = Σ (xᵢ − x̄)(yᵢ − ȳ)  and  Sxx = Σ (xᵢ − x̄)²

x̄ and ȳ are the means and n the number of rows. From the first equation, the residuals add to zero and the line passes through (x̄, ȳ). Also b₁ = r·(s_y ÷ s_x), with r the correlation and s_x, s_y the standard deviations, so the slope has the sign of r.

Goodness of fit and testing the model

The total variation SST = Σ(yᵢ − ȳ)² splits into the part the line explains and the part it leaves: SST = SSR + SSE. The coefficient of determination is

R² = 1 − SSE / SST        (0 ≤ R² ≤ 1; for one feature, R² = r²)

R² = 0.85 means the line explains 85% of the variation in y. The standard error of estimate s_e = √(SSE ÷ (n − 2)) is the typical miss in the units of y (n − 2 because two numbers were estimated). In the residual plot (residual against x), random scatter is good, a curve means the relation is not linear, and a funnel means the spread grows with x.

The test is H₀: β₁ = 0 (x has no linear effect) against H₁: β₁ ≠ 0, using t = b₁ ÷ SE(b₁) with SE(b₁) = s_e ÷ √Sxx and n − 2 degrees of freedom. Some syllabi follow Allen Downey's Think Stats, which adds weighted resampling: draw rows with replacement (weighted by survey weights when some groups were over-sampled), refit, and repeat to see how much the slope varies. In Python, StatsModels' smf.ols("marks ~ hours", data=df).fit() fits the line, and its summary() prints b₀, b₁, their t- and p-values and R². NumPy's np.polyfit(hours, marks, 1) returns just the slope and intercept, 3.7 and 42.8 for the data of the worked example.

Multiple regression

With p features the model is y = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ + ε. With the data as a matrix X (one row per instance, a first column of 1s for the intercept) and y as a column, least squares solves XᵀX b = Xᵀy, so b = (XᵀX)⁻¹Xᵀy. Each coefficient bⱼ is the change in ŷ for one unit of xⱼ with the other features held fixed.

  • Adjusted R² = 1 − (1 − R²)(n − 1) ÷ (n − p − 1). Plain R² never falls when a feature is added, even a useless one, because least squares can give it a coefficient of 0; adjusted R² falls unless the feature earns its place.
  • Multicollinearity: strongly correlated features (area and number of rooms) make the coefficients unstable, though predictions may stay good.
  • Nonlinear relationships: add columns such as x² or log x. The model stays linear in the β's, so least squares still applies. A category (city) enters as 0/1 dummy columns.
  • Regularisation (L1 and L2): ridge minimises SSE + λΣβⱼ², lasso SSE + λΣ|βⱼ|, where λ ≥ 0 sets the penalty; lasso can push coefficients to exactly 0.

For very large data, SSE is minimised step by step with gradient descent (Chapter 5.5) instead of inverting XᵀX.

5.3 Logistic regression

Logistic regression predicts the probability that a case belongs to a class: will this student pass, will this loan default, is this payment fraud. It computes a linear score from the features, exactly as in Chapter 5.2, and then squeezes the score into the range 0 to 1 with an S-shaped curve called the sigmoid. Despite the name it is a classification method. It is the first model to try on any yes/no problem, because it is fast, rarely overfits badly, and its coefficients read directly as changes in the odds.

You need: the least-squares line (Chapter 5.2) and maximum likelihood (Unit 4, Parameter estimation).

From a straight line to the sigmoid

Code the target as y = 1 (pass) or y = 0 (fail). A straight line fitted to 0/1 values predicts −0.3 or 1.4 for extreme x, which cannot be probabilities. So logistic regression keeps the linear score but transforms it:

z = β₀ + β₁x₁ + β₂x₂ + … + βₚxₚ          (the linear score)
p = P(y = 1 | x) = σ(z) = 1 / (1 + e^(−z))   (the sigmoid, or logistic function)

σ (sigma) maps any z to a value between 0 and 1: σ(0) = 0.5, σ(z) → 1 as z → +∞ and σ(z) → 0 as z → −∞. Two useful facts: σ(−z) = 1 − σ(z), and the slope of the curve is σ′(z) = σ(z)(1 − σ(z)).

Turn the equation round and the meaning of z appears. The odds of passing are p ÷ (1 − p); p = 0.8 gives odds of 4, "4 to 1". Then

ln( p / (1 − p) ) = z = β₀ + β₁x₁ + … + βₚxₚ

The left side is the log-odds or logit. So the model is linear in the log-odds: one more unit of xⱼ adds βⱼ to the log-odds, which multiplies the odds by e^βⱼ, the odds ratio.

To classify, predict 1 when p ≥ a threshold, usually 0.5. Since σ(z) ≥ 0.5 exactly when z ≥ 0, the decision boundary is the set of points where β₀ + β₁x₁ + … + βₚxₚ = 0: a straight line with two features, a flat plane with more. Logistic regression is therefore a linear classifier. The threshold can move: a bank catching fraud may flag payments at p ≥ 0.2 to miss fewer frauds, at the cost of more false alarms (Chapter 5.8).

Estimating the parameters

Least squares is not used. Instead we pick the β's that make the observed labels most probable, which is maximum likelihood. Row i has probability pᵢ if yᵢ = 1 and 1 − pᵢ if yᵢ = 0, which one formula covers: pᵢ^yᵢ (1 − pᵢ)^(1 − yᵢ). Multiply over all rows, take logs and change sign, and maximising the likelihood becomes minimising the log-loss (binary cross-entropy):

J(β) = − Σ [ yᵢ ln pᵢ + (1 − yᵢ) ln(1 − pᵢ) ]

∂J/∂βⱼ = Σ (pᵢ − yᵢ) · xᵢⱼ          (xᵢ₀ = 1 for the intercept)

A confident wrong answer costs a lot: p = 0.01 for a student who passed adds −ln 0.01 = 4.6 to J, while p = 0.99 adds only 0.01. There is no closed-form solution, so J is minimised step by step:

  1. Start with all β = 0, so every pᵢ = 0.5.
  2. Compute every pᵢ = σ(zᵢ) and the gradient Σ(pᵢ − yᵢ)xᵢⱼ for each βⱼ.
  3. Update βⱼ ← βⱼ − η · ∂J/∂βⱼ, where η (eta) is the learning rate, a small number such as 0.1.
  4. Repeat until J stops falling. J is convex (bowl-shaped), so there is a single minimum and gradient descent reaches it.

StatsModels' Logit uses Newton's method, which takes fewer, larger steps, and scikit-learn's LogisticRegression adds an L2 penalty by default. For more than two classes, softmax (multinomial) regression gives one score per class and turns them into probabilities that add to 1.

Worked example

Question. A college fits P(pass) for its end-semester exam with z = −4 + 0.8x, where x is hours of revision. (a) Find P(pass) for 3, 5 and 7 hours. (b) Interpret the coefficient 0.8. (c) Where is the decision boundary at threshold 0.5? (d) How many hours give P(pass) = 0.9?

  1. (a) x = 3: z = −4 + 2.4 = −1.6, p = 1 ÷ (1 + e^1.6) = 1 ÷ (1 + 4.953) = 0.168. x = 5: z = 0, p = 0.5. x = 7: z = 1.6, p = 1 ÷ (1 + e^−1.6) = 1 ÷ 1.202 = 0.832.
  2. (b) Each extra hour adds 0.8 to the log-odds, so it multiplies the odds of passing by e^0.8 = 2.23. Check: the odds at 3 hours are 0.168 ÷ 0.832 = 0.202, and at 4 hours 0.202 × 2.23 = 0.449.
  3. (c) p = 0.5 when z = 0: −4 + 0.8x = 0 gives x = 5 hours. Predict "pass" for 5 hours or more.
  4. (d) p = 0.9 means odds = 0.9 ÷ 0.1 = 9, so z = ln 9 = 2.197. Then 0.8x = 4 + 2.197 = 6.197, so x = 7.75 hours.

Exam traps

  • The output is a probability; the class comes only after a threshold. Say both in an answer.
  • β is the change in log-odds, not in probability. How much p moves depends on where you are on the S.
  • Write σ(z) = 1 ÷ (1 + e^(−z)) with the minus sign; z = 0 must give 0.5.
  • The decision boundary is linear in the features. A curved boundary needs new features such as x².
  • Squared error is not used for training: with the sigmoid it is not convex, so gradient descent can stall. Log-loss is convex and comes from maximum likelihood.

5.4 Classification with decision trees

A decision tree classifies a case by asking it a series of questions about its features ("Is the weather rainy?", "Is income above ₹6 lakh?"), each answer leading down one branch, until a leaf names the class. It is learned from labelled data by choosing, at each step, the question that best separates the classes. Trees are popular because anyone can read them as IF–THEN rules, they need no scaling of features, and they mix numbers and categories freely. Built in hundreds, they become random forests and boosted trees, the strongest models for tabular data.

You need: supervised learning and overfitting (Chapter 5.1) and logarithms to base 2 (log₂ 8 = 3, log₂ 0.5 = −1).

Parts of a tree and how it is grown

The top node is the root. Each internal node tests one attribute, each branch is one outcome of the test, and each leaf holds a class label. The depth is the number of tests on the longest root-to-leaf path. Every path from the root to a leaf is one rule, such as IF Weather = Sunny AND Exam = No THEN Play.

Trees are grown top-down and greedily: choose the best test for the root, split the rows, and repeat inside each part. This is Ross Quinlan's ID3 algorithm (1986):

  1. If every row at the node has the same class, make it a leaf with that class.
  2. If no attributes are left (or the node is too small), make a leaf with the majority class.
  3. Otherwise compute the information gain of every remaining attribute and pick the largest.
  4. Make one branch per value of that attribute, send each row down its branch, and apply the steps again to each child.

For a numeric attribute such as income, sort its values, try each midpoint between neighbours as a threshold, and treat "income ≤ t" as a two-way test.

Measuring a good split: entropy, information gain and Gini

A good test produces children that are pure (mostly one class). Entropy measures impurity. For a set S in which class i has proportion pᵢ,

H(S) = − Σ pᵢ log₂ pᵢ                       (take 0·log₂0 = 0)
IG(S, A) = H(S) − Σᵥ ( |Sᵥ| / |S| ) · H(Sᵥ)
Gini(S) = 1 − Σ pᵢ²

For two classes, H is 0 for a pure set and 1 for a 50/50 set. The information gain IG(S, A) of attribute A is the parent's entropy minus the weighted average entropy of the children Sᵥ, one child per value v of A, each weighted by its share of rows |Sᵥ| ÷ |S|. The attribute with the largest IG is chosen.

The Gini index is a cheaper impurity measure, 0 when pure and at most 0.5 for two classes. CART (Breiman and others, 1984) uses Gini with only binary splits and also builds regression trees, whose leaves predict the mean of their rows. Quinlan's later C4.5 uses the gain ratio = IG ÷ SplitInfo, where SplitInfo = −Σ (|Sᵥ| ÷ |S|) log₂(|Sᵥ| ÷ |S|). This corrects a bias: an attribute such as roll number, unique to every row, gives pure children and the largest possible IG, yet predicts nothing.

Overfitting and pruning

A tree grown until every leaf is pure memorises the training data, noise included (Chapter 5.1). Two cures:

  • Pre-pruning: stop early, with a maximum depth, a minimum number of rows per leaf, or a minimum gain.
  • Post-pruning: grow the full tree, then replace a subtree with a leaf whenever that does not lower accuracy on validation data (reduced-error pruning). CART's cost-complexity pruning trades tree size against error.

Trees are fast and readable, but unstable: a few changed rows can give a very different tree. In Python, DecisionTreeClassifier(criterion="entropy", max_depth=3) from scikit-learn grows a pre-pruned tree.

5.5 Basics of neural networks and deep learning

A neural network is a stack of simple units called neurons. Each neuron adds up its inputs, each multiplied by a weight, and passes the total through a nonlinear activation function; the outputs of one layer are the inputs of the next. With enough neurons the network can learn very tangled patterns, and with many layers ("deep learning") it learns its own features from raw pixels, sound or text. That is how phones unlock by face and how speech becomes text. The weights are learned by backpropagation and gradient descent, the same descent you used for logistic regression.

You need: the sigmoid and gradient descent (Chapter 5.3) and the chain rule of differentiation.

The neuron and the perceptron

A neuron with inputs x₁, …, xₙ has weights w₁, …, wₙ and a bias b. It computes the net input z = w₁x₁ + … + wₙxₙ + b and outputs a = f(z), where f is the activation function:

  • Step: 1 if z ≥ 0, else 0. Used by the perceptron.
  • Sigmoid: σ(z) = 1 ÷ (1 + e^(−z)), range (0, 1). A sigmoid neuron is exactly a logistic regression.
  • tanh: range (−1, 1), centred on 0.
  • ReLU: max(0, z). The default in deep networks because it is cheap and its slope does not shrink for z > 0.

Frank Rosenblatt's perceptron (1958) is one step neuron. Its learning rule, for target t and output y, is wᵢ ← wᵢ + η(t − y)xᵢ and b ← b + η(t − y): weights change only when the answer is wrong. It finds a separating line whenever the two classes are linearly separable, but no single line separates XOR, a fact Minsky and Papert stressed in 1969.

Why the hidden layer matters

Put two step neurons between the inputs and the output: h₁ = step(x₁ + x₂ − 0.5) fires for OR, h₂ = step(x₁ + x₂ − 1.5) fires for AND, and y = step(h₁ − h₂ − 0.5) means "OR but not AND", which is XOR:

The hidden layer has re-drawn the data in new coordinates (h₁, h₂) where a single line works. The activation must be nonlinear: without it, two layers compute W₂(W₁x) = (W₂W₁)x, which is again one linear layer. The universal approximation theorem says that one hidden layer with enough sigmoid or ReLU units can approximate any continuous function on a bounded region; deep networks reach the same accuracy with far fewer units.

Training: forward pass, backpropagation, gradient descent

In a multilayer perceptron (MLP) every neuron of one layer feeds every neuron of the next. Training repeats four steps over the data:

  1. Forward pass: compute each layer's outputs from the inputs, up to the prediction o.
  2. Loss: compare with the target t, for example E = ½(t − o)² (cross-entropy for classification).
  3. Backward pass (backpropagation, made popular by Rumelhart, Hinton and Williams in 1986): apply the chain rule backwards through the network's computation graph. For a sigmoid output with squared error, the output's error signal is δₒ = (o − t)·o(1 − o). A hidden neuron j with output hⱼ and weight vⱼ to the output gets δⱼ = δₒ·vⱼ·hⱼ(1 − hⱼ). The gradient of any weight is (δ of the neuron it feeds) × (the input it carries).
  4. Update: w ← w − η·∂E/∂w for every weight, with learning rate η.

One pass over all training rows is an epoch; updating after each small group of rows is mini-batch gradient descent. Since the sigmoid's slope is at most 0.25, deltas shrink as they travel back through many sigmoid layers (the vanishing gradient), one more reason deep networks use ReLU.

Deep learning

A deep network has many hidden layers. Each layer builds features from the one below: in an image model, early layers detect edges, middle layers shapes, late layers whole objects. Hand-made features (Unit 2) are then less needed. Three families matter: convolutional networks (CNNs) slide small shared filters over an image; recurrent networks (RNNs, LSTMs) carry a memory along a sequence; transformers (2017) use attention and now power language models. Deep learning took off around 2012, when a CNN trained on GPUs won the ImageNet image contest by a wide margin. Deep networks overfit easily, so they are trained with dropout (randomly switching off units during training), early stopping and weight decay. An autoencoder is trained to reproduce its own input through a narrow middle layer; that middle layer is a compressed set of features (Chapter 5.7).

5.6 Clustering: k-means and hierarchical clustering

Clustering puts unlabelled rows into groups so that rows in the same group are alike and rows in different groups are not. Nobody supplies the right groups; the algorithm finds them from distances alone. Shops use it to find customer segments, news apps to group stories on the same event, and banks to spot transactions that fit no group. This chapter covers the two classic methods: k-means, which splits the data into a chosen number k of groups, and hierarchical clustering, which builds a whole tree of groups inside groups.

You need: unsupervised learning (Chapter 5.1) and feature scaling (Unit 2, Data transformation).

Distance comes first

Similarity is measured by distance. For rows x and y with p features, the Euclidean distance is d = √((x₁ − y₁)² + … + (xₚ − yₚ)²) and the Manhattan distance is |x₁ − y₁| + … + |xₚ − yₚ|. Scale the features first. If income is in rupees (differences of thousands) and age in years (differences of tens), income alone decides every distance; min-max or z-score scaling puts them on an equal footing.

k-means

k-means represents each cluster Cⱼ by its centroid μⱼ, the mean of its points, and seeks the clusters with the smallest within-cluster sum of squares, WCSS (also called SSE or inertia) = Σⱼ Σ over x in Cⱼ of ‖x − μⱼ‖², the total squared distance of points from their own centroid. Lloyd's algorithm:

  1. Choose k, the number of clusters.
  2. Pick k starting centroids, for example k random rows.
  3. Assign: put every point in the cluster of its nearest centroid.
  4. Update: move each centroid to the mean of the points now assigned to it.
  5. Repeat steps 3 and 4 until no point changes cluster.

Both steps can only lower WCSS, so the algorithm always stops, usually within a few iterations; each iteration costs about n × k distance computations for n points. But it stops at a local minimum that depends on the start, so libraries run it several times from different starts, and k-means++ picks starting centroids that are far apart.

To choose k, plot WCSS against k = 1, 2, 3, …: WCSS always falls, but after the right k it falls slowly, so the curve bends like an elbow (elbow method). Or use the silhouette of each point, s = (b − a) ÷ max(a, b), where a is its mean distance to its own cluster and b its mean distance to the nearest other cluster; s near 1 means well placed, near 0 on a border, negative probably in the wrong cluster. k-means also has limits: it expects round clusters of similar size, an outlier drags a centroid, and means need numeric features (k-medoids uses actual rows as centres and resists outliers).

Hierarchical clustering

Agglomerative (bottom-up) clustering starts with every point as its own cluster and repeatedly merges the two closest clusters until one is left. Divisive (top-down) clustering starts with one cluster and keeps splitting. "Closest clusters" needs a linkage rule:

  • Single: distance of the closest pair across the two clusters. Finds long, chain-like clusters.
  • Complete: distance of the farthest pair. Gives compact clusters.
  • Average: mean of all cross-pair distances. Ward's method merges the pair that raises the total WCSS least.

The history of merges is drawn as a dendrogram, a tree whose joins sit at the height of the merge distance. Cutting it with a horizontal line at some height gives the clusters, so k need not be fixed in advance. The price is an n × n distance matrix: memory grows as n², and a simple implementation takes time of order n³, fine for thousands of points but not for millions.

A distance-based outlier is a point whose k-th nearest neighbour is far away; the local outlier factor (LOF) compares a point's local density with its neighbours' densities, so a value well above 1 marks an outlier; and DBSCAN grows clusters through dense regions and labels points in sparse regions as noise.

5.7 Dimensionality reduction: PCA and LDA

Dimensionality reduction replaces many features with a few new ones that keep most of the useful information. A survey with 40 related questions, a sensor log with 300 readings per second, or a face image with 10,000 pixels can often be described well by 5 to 50 numbers. Fewer features mean faster models, less overfitting, less redundancy and data you can actually plot. Principal component analysis (PCA) keeps the directions in which the data varies most and ignores labels; linear discriminant analysis (LDA) uses the labels and keeps the directions that best separate the classes.

You need: variance and the covariance matrix (Unit 3, Correlation and covariance), feature selection (Unit 2), and eigenvalues of a 2 × 2 matrix.

Why reduce dimensions

As the number of features p grows, data spreads thin: to keep the same density of points you need exponentially more rows, and distances between points become nearly equal, which hurts k-means and nearest-neighbour methods. This is the curse of dimensionality. There are two ways out. Feature selection keeps a subset of the original columns (Unit 2. Feature extraction builds new columns as combinations of all the old ones; PCA, LDA and autoencoders do this.

Principal component analysis

A principal component is a direction in feature space. PC1 is the direction along which the data has the largest variance; PC2 has the largest variance among directions perpendicular to PC1; and so on, giving up to p components. These directions are the eigenvectors of the covariance matrix, and each one's eigenvalue λ (lambda) is the variance of the data along it. Karl Pearson described the method in 1901 and Harold Hotelling developed it in 1933. The steps:

  1. Centre each feature by subtracting its mean. If the features have different units, also divide by the standard deviation (standardise).
  2. Compute the p × p covariance matrix C, with Cᵢⱼ = Σ(xᵢ − x̄ᵢ)(xⱼ − x̄ⱼ) ÷ (n − 1).
  3. Solve C v = λ v for the eigenvalues λ₁ ≥ λ₂ ≥ … ≥ λₚ and unit-length eigenvectors v₁, v₂, ….
  4. The explained variance ratio of PC k is λₖ ÷ (λ₁ + … + λₚ). Keep the first k components whose ratios add to about 90–95%, or cut where the scree plot of eigenvalues bends.
  5. Project: the score of a row on PC k is vₖ · (its centred row). The n × k table of scores is the reduced data.

The components are uncorrelated with each other, and the eigenvalues add up to the total variance, so nothing is lost until you drop components. Libraries compute PCA through the singular value decomposition (SVD) of the centred data, which is more accurate than forming C. The costs: PCA finds only linear structure, each component mixes all the original features and is hard to name, and it never looks at labels, so it can throw away a low-variance direction that happens to separate the classes.

Linear discriminant analysis

LDA, from Ronald Fisher's 1936 paper, is supervised. For data with known classes, it seeks the direction w along which the class means are far apart relative to the spread inside each class, by maximising

J(w) = (wᵀ S_B w) / (wᵀ S_W w)

S_W = Σ over classes c  Σ over x in c  (x − μ_c)(x − μ_c)ᵀ     (within-class scatter)
S_B = Σ over classes c  n_c (μ_c − μ)(μ_c − μ)ᵀ                 (between-class scatter)
Two classes:  w ∝ S_W⁻¹ (μ₁ − μ₂)

Here μ_c is the mean vector of class c, n_c its size and μ the overall mean. With C classes LDA gives at most C − 1 useful directions, so two classes reduce to a single number per row, and a threshold on that number makes LDA a classifier too. The autoencoder (Chapter 5.5) is a network trained to rebuild its input through a narrow middle layer. With linear layers and squared error it finds the same subspace as PCA; with nonlinear layers it can follow curved structure.

Worked example: PCA

Question. Five students' maths and physics test scores (out of 10) are (2, 1), (3, 3), (4, 2), (5, 5), (6, 4). Find the principal components, the variance each explains, and every student's score on PC1.

  1. Means: x̄₁ = 20 ÷ 5 = 4 and x̄₂ = 15 ÷ 5 = 3. Centred rows: (−2, −2), (−1, 0), (0, −1), (1, 2), (2, 1).
  2. Covariance (divide by n − 1 = 4): var(x₁) = (4 + 1 + 0 + 1 + 4) ÷ 4 = 2.5; var(x₂) = (4 + 0 + 1 + 4 + 1) ÷ 4 = 2.5; cov = (4 + 0 + 0 + 2 + 2) ÷ 4 = 2.0. So C = [[2.5, 2.0], [2.0, 2.5]].
  3. Eigenvalues: det(C − λI) = (2.5 − λ)² − 2.0² = 0, so 2.5 − λ = ±2, giving λ₁ = 4.5 and λ₂ = 0.5.
  4. Eigenvectors: for λ₁, (2.5 − 4.5)a + 2b = 0 gives a = b, so v₁ = (1, 1) ÷ √2 = (0.707, 0.707). For λ₂, v₂ = (1, −1) ÷ √2 = (0.707, −0.707).
  5. Explained variance: PC1 = 4.5 ÷ (4.5 + 0.5) = 90%; PC2 = 10%.
  6. PC1 scores z = 0.707(x₁ − 4) + 0.707(x₂ − 3): −2.83, −0.71, −0.71, 2.12, 2.12. Check: their variance is (8 + 0.5 + 0.5 + 4.5 + 4.5) ÷ 4 = 4.5 = λ₁. PC1 is roughly "overall science ability"; one number per student keeps 90% of the information.

Worked example: two-class LDA

Question. Mangoes of variety A measure (weight in 100 g, sweetness score) (1, 2), (2, 3), (3, 3); variety B (5, 6), (6, 5), (7, 7). Find Fisher's direction and classify a mango at (4, 4).

  1. Means: μ_A = (2, 2.67), μ_B = (6, 6).
  2. Scatter of A (deviations (−1, −0.67), (0, 0.33), (1, 0.33)): [[2, 1], [1, 0.67]]. Scatter of B (deviations (−1, 0), (0, −1), (1, 1)): [[2, 1], [1, 2]]. S_W = [[4, 2], [2, 2.67]].
  3. det S_W = 4 × 2.67 − 2 × 2 = 6.67, so S_W⁻¹ = (1 ÷ 6.67)[[2.67, −2], [−2, 4]] = [[0.4, −0.3], [−0.3, 0.6]].
  4. w = S_W⁻¹(μ_A − μ_B) = S_W⁻¹(−4, −3.33) = (−1.6 + 1.0, 1.2 − 2.0) = (−0.6, −0.8). The sign does not matter, so take w = (0.6, 0.8).
  5. Projections w·x: A gives 2.2, 3.6, 4.2; B gives 7.8, 7.6, 9.8, so the classes no longer overlap. Projected means are 3.33 and 8.4; the midpoint threshold is (3.33 + 8.4) ÷ 2 = 5.87.
  6. New mango: 0.6 × 4 + 0.8 × 4 = 5.6 < 5.87, so variety A.

Exam traps

  • Standardise before PCA when units differ. Otherwise the feature in the largest units (income in rupees) becomes PC1 by itself.
  • PCA ignores labels; LDA needs them. LDA gives at most C − 1 components, so only one for two classes.
  • Explained variance comes from the eigenvalues, not from the entries of the eigenvectors.
  • Normalise eigenvectors to length 1 before computing scores; the sign of an eigenvector is arbitrary.
  • PCA is not feature selection: every component is built from all the original features.

5.8 Model evaluation: confusion matrix, precision, recall, ROC

A model is only as good as its measured performance on data it has not seen. For a classifier, every measure starts from the confusion matrix, a table that counts the right and wrong predictions of each kind. Accuracy, precision, recall, the F1 score and the ROC curve are all read from it. Picking the right measure matters: when only 1 payment in 100 is fraud, a model that calls every payment genuine is 99% accurate and catches no fraud at all.

You need: training and test sets (Chapter 5.1), thresholds on a predicted probability (Chapter 5.3), and Type I and Type II errors (Unit 4, Hypothesis testing).

The confusion matrix

For a two-class problem, call the class we care about (fraud, disease, spam) positive. Every test case lands in one of four cells:

Predicted positivePredicted negative
Actually positiveTP true positive: fraud, flaggedFN false negative: fraud, missed
Actually negativeFP false positive: genuine, flaggedTN true negative: genuine, passed

A false positive is a Type I error (a false alarm) and a false negative a Type II error (a miss), as in Unit 4. With C classes the matrix is C × C: row i, column j counts cases of class i predicted as class j, and the diagonal holds the correct ones.

Measures read from the matrix

Accuracy    = (TP + TN) / (TP + TN + FP + FN)
Precision   = TP / (TP + FP)          of the cases flagged, how many were right
Recall      = TP / (TP + FN)          of the real positives, how many were caught
            (also called sensitivity or true positive rate, TPR)
Specificity = TN / (TN + FP)          of the real negatives, how many were passed
FPR         = FP / (FP + TN) = 1 − specificity
F1          = 2 × Precision × Recall / (Precision + Recall)

F1 is the harmonic mean of precision and recall, so it is low if either one is low. Which measure to watch depends on which mistake costs more. In cancer screening a miss can kill, so recall comes first and false alarms are settled by a second test. A spam filter that throws away a job offer does real harm, so precision comes first. For many classes, compute precision and recall per class, then take the plain mean (macro average, every class counts equally) or pool all the counts (micro average, every case counts equally). Regression models are scored instead with MAE, RMSE and R² (Chapters 5.2 and 5.9).

ROC curve and AUC

Most classifiers output a score, such as a probability, and a threshold turns it into a class. Each threshold gives one confusion matrix, and so one pair (FPR, TPR). Lowering the threshold flags more cases, so both rates rise. The ROC curve (receiver operating characteristic, a name from radar engineering) plots TPR against FPR for every threshold. To draw it by hand for P positives and N negatives:

  1. Sort the cases by score, highest first, and start at the point (0, 0).
  2. Go down the list. For a positive, move up by 1 ÷ P; for a negative, move right by 1 ÷ N. (Tied scores of both kinds give a diagonal step.)
  3. Join the points; the walk ends at (1, 1).

The diagonal from (0, 0) to (1, 1) is what random guessing gives; the top-left corner (0, 1) is a perfect classifier. The AUC, the area under the ROC curve, sums the curve up in one number: 1 is perfect and 0.5 is random. It has a direct meaning: the AUC is the probability that a randomly chosen positive gets a higher score than a randomly chosen negative. AUC does not depend on the threshold and is not fooled by class imbalance the way accuracy is, but when positives are very rare the precision–recall curve shows the trade-off more clearly. Stratified k-fold cross-validation, which keeps the class proportions in every fold, gives steadier estimates of all these measures than one split.

Worked example: confusion matrix

Question. A bank tests a fraud model on 1,000 UPI transactions, of which 50 are fraud. The model flags 60, and 40 of those are fraud. Build the confusion matrix and find accuracy, precision, recall, specificity, FPR and F1. Compare with a model that flags nothing.

  1. TP = 40 (flagged fraud). FP = 60 − 40 = 20. FN = 50 − 40 = 10. TN = 1,000 − 40 − 20 − 10 = 930.
  2. Accuracy = (40 + 930) ÷ 1,000 = 97.0%.
  3. Precision = 40 ÷ (40 + 20) = 0.667: two in three alerts are real fraud.
  4. Recall = 40 ÷ (40 + 10) = 0.800: four in five frauds are caught.
  5. Specificity = 930 ÷ (930 + 20) = 0.979, so FPR = 20 ÷ 950 = 0.021.
  6. F1 = 2 × 0.667 × 0.800 ÷ (0.667 + 0.800) = 1.067 ÷ 1.467 = 0.727.
  7. A model that flags nothing has TP = 0, TN = 950, so accuracy = 95.0% but recall = 0. The real model beats it by only 2 points of accuracy yet catches 40 frauds: accuracy hides the difference that matters.

Question. A model scores ten test cases (P = positive, N = negative): 0.95 P, 0.85 P, 0.80 N, 0.70 P, 0.60 P, 0.55 N, 0.45 N, 0.40 P, 0.30 N, 0.20 N. Draw the ROC curve, find the AUC two ways, and give TPR and FPR at threshold 0.5.

  2. Walk down the list: (0, 0) → P (0, 0.2) → P (0, 0.4) → N (0.2, 0.4) → P (0.2, 0.6) → P (0.2, 0.8) → N (0.4, 0.8) → N (0.6, 0.8) → P (0.6, 1.0) → N (0.8, 1.0) → N (1.0, 1.0).

Exam traps

  • Precision divides by predicted positives (TP + FP); recall divides by actual positives (TP + FN). Swapping the denominators is the classic slip.
  • Check the layout of a given matrix. scikit-learn's confusion_matrix puts actual classes in rows and predicted in columns, sorted 0 then 1, so it prints [[TN, FP], [FN, TP]], the opposite corners from the table above.
  • High accuracy on imbalanced data proves nothing; always compare with the "predict the majority class" baseline.
  • The ROC x-axis is FPR = 1 − specificity, not specificity.
  • An AUC of 0.3 is not useless: flipping the predictions gives 0.7. An AUC below 0.5 usually means the labels were swapped.

5.9 Time series analysis and forecasting

A time series is a sequence of measurements taken at equal time steps: daily IRCTC bookings, monthly rainfall in Chennai, hourly electricity demand. Unlike the rows in earlier chapters, the order matters, because this month's value depends on last month's. Time series analysis separates a series into trend, seasonal pattern and noise; forecasting uses the past to predict the next values. Power companies, retailers, railways and banks plan stock, staff and money with these forecasts.

You need: least squares (Chapter 5.2), correlation (Unit 3) and missing-value handling (Unit 2, Data cleaning).

Components and decomposition

A series Yₜ (the value at time t) is seen as a mix of four parts:

  • Trend T: the long-run rise or fall, such as the steady growth of UPI payments.
  • Seasonality S: a pattern that repeats with a fixed period, such as air-conditioner sales peaking every summer or food orders rising every weekend.
  • Cycle: longer waves without a fixed period, such as business booms and slowdowns.
  • Irregular or residual R: the random part left over.

In the additive model Yₜ = Tₜ + Sₜ + Rₜ the seasonal swing has a constant size; in the multiplicative model Yₜ = Tₜ × Sₜ × Rₜ the swing grows with the level (taking logs turns it into the additive form). Decomposition is done classically in four steps:

  1. Estimate the trend with a centred moving average whose length equals the season (12 for monthly data).
  2. Remove it: Y − T (additive) or Y ÷ T (multiplicative).
  3. Average the detrended values for each season (all Januaries, all Februaries, …) to get the seasonal indices, adjusted to add to 0 (or to average 1).
  4. Whatever remains is the residual R.

StatsModels does this with seasonal_decompose(series, model="additive", period=12). A series whose mean and variance do not change over time is stationary. Many models need it, and differencing, replacing Yₜ by Yₜ − Yₜ₋₁, removes a trend.

Missing values, moving averages and smoothing

Deleting a missing month would break the equal spacing, so fill it instead: carry the last value forward, or interpolate linearly between neighbours. In pandas, for [120, missing, 128, 140], s.ffill() gives 120 for the gap and s.interpolate() gives 124.

The simplest forecasts smooth the recent past:

Moving average (k periods):   Fₜ₊₁ = (Yₜ + Yₜ₋₁ + … + Yₜ₋ₖ₊₁) / k
Simple exponential smoothing:  Fₜ₊₁ = α·Yₜ + (1 − α)·Fₜ        0 < α ≤ 1

Fₜ₊₁ is the forecast for the next period. A larger k gives a smoother but slower moving average. In exponential smoothing, unrolling the formula shows that past values get weights α, α(1 − α), α(1 − α)², …, which fade geometrically; a large α reacts fast to change, a small α smooths more. Both methods lag behind a trend, as the worked example shows. Holt's method adds a smoothed trend term, and Holt–Winters adds a seasonal term as well. In pandas:

import pandas as pd
s = pd.Series([120, 132, 128, 140, 152, 148, 160, 170],

Autocorrelation, regression and machine-learning forecasts

Values close in time are usually related. The lag-k autocorrelation of a series of length n with mean Ȳ is

rₖ = Σ (from t = k+1 to n) (Yₜ − Ȳ)(Yₜ₋ₖ − Ȳ)  ÷  Σ (from t = 1 to n) (Yₜ − Ȳ)²

A plot of r₁, r₂, r₃, … is the ACF plot or correlogram. Slowly fading bars mean a trend; a spike at lag 12 in monthly data means a yearly season; and the residuals of a good model should show no autocorrelation at all. ARIMA(p, d, q) models, from Box and Jenkins, regress the series on its own p past values (AR) after d differences (I), plus q past forecast errors (MA).

Regression: fit Yₜ = β₀ + β₁t plus 0/1 dummy columns for each month by least squares (Chapter 5.2). Machine learning: turn the series into a table with lag features (Yₜ₋₁, Yₜ₋₂, Yₜ₋₁₂, month number) and train a tree ensemble or a network (Chapters 5.4, 5.5). Evaluation must respect time: never shuffle; train on the earlier part, test on the later part, and use walk-forward validation (refit, forecast one step, move the origin forward). Measure errors eₜ = Yₜ − Fₜ with MAE = mean |eₜ|, RMSE = √(mean eₜ²) and MAPE = mean |eₜ ÷ Yₜ| × 100%.

Exam traps

  • A moving-average forecast uses only past values (Fₜ₊₁ from Yₜ and earlier); a centred moving average uses values on both sides and estimates the trend, not a forecast.
  • In exponential smoothing a large α means more weight on the latest value, not more smoothing.
  • Additive versus multiplicative: choose multiplicative when seasonal swings grow with the level.
  • Never shuffle time-series rows into random folds; the model would learn from the future.
  • MAPE breaks down when some actual values are 0 or near 0, because it divides by Yₜ.

Analyze A student evaluates a demand forecaster with random 5-fold cross-validation and gets a tiny error. What is wrong, and how should it be tested? 3 marks

Random folds put later months in training and earlier months in testing, so the model uses the future; the error is too optimistic. Use walk-forward validation: train on months 1 to t, forecast month t + 1, then move t forward.

Forecasting libraries such as StatsModels (ExponentialSmoothing, ARIMA), Prophet and sktime automate these methods, and gradient-boosted trees on lag features win many retail forecasting contests. Large pre-trained "foundation models" for time series are a recent research direction. The free online book Forecasting: Principles and Practice by Hyndman and Athanasopoulos covers this chapter in depth. Search "walk-forward validation" and "Holt-Winters"; this is not for the exam.

Takeaways

  1. Supervised learning predicts a known kind of label (a number for regression, a class for classification); unsupervised learning finds groups or directions in unlabelled data. Judge every model only on data it has not seen.
  2. Least squares gives b₁ = Sxy ÷ Sxx and b₀ = ȳ − b₁x̄. R², adjusted R², the residual plot and the slope's t-test say whether the line is any good.
  3. Logistic regression is a linear score passed through the sigmoid. Its coefficients change the log-odds, and it is trained by minimising log-loss, which comes from maximum likelihood.
  4. A decision tree splits on the attribute with the largest information gain (or lowest Gini) and must be pruned to avoid overfitting; many trees make a random forest.
  5. A neural network stacks neurons with nonlinear activations. Backpropagation applies the chain rule to get every gradient, and gradient descent updates the weights.
  6. k-means alternates "assign to nearest centroid" and "move centroid to the mean" until nothing changes; hierarchical clustering builds a dendrogram that you cut at a chosen height.
  7. PCA keeps the eigenvectors of the covariance matrix with the largest eigenvalues; LDA uses the labels to keep the direction that best separates the classes.
  8. Read a classifier from its confusion matrix. Protect recall when misses are costly and precision when false alarms are; AUC summarises all thresholds at once.
  9. A time series is trend plus season plus noise. Moving averages and exponential smoothing lag a trend; validate forecasts by walking forward in time, never by shuffling.

Analyze and evaluate

Analyze A bank wants to predict loan default from 20 features; only 2% of past loans defaulted, and refusals must be explainable. Design and justify the full modelling pipeline. 16 marks

Supervised classification (5.1); stratified train, validation and test split; baseline logistic regression for odds-ratio explanations (5.3); a pruned tree or random forest to compare (5.4); a network only if accuracy gains outweigh the loss of explanation (5.5); PCA only if features are many and correlated, noting the cost to interpretability (5.7); accuracy rejected because of 98% majority; recall, precision, ROC/AUC and a threshold chosen on rupee costs (5.8).

Analyze An e-commerce firm has 50 behaviour features for 2 lakh customers and wants segments for marketing, then a model that predicts which customers will churn. Plan and evaluate the approach. 16 marks

Scale features; PCA to about 90% variance for speed and to remove redundancy (5.7); k-means rather than agglomerative because of the n² memory cost, with k from the elbow and silhouette (5.6); describe segments by their centroids; for churn, supervised learning with the segment as an extra feature (5.1, 5.3, 5.4); evaluate with recall and precision on a time-based test set (5.8).

Evaluate Compare linear regression, logistic regression, decision trees and neural networks on output type, training method, interpretability, overfitting risk and data needed. Which would you choose for predicting crop yield in tonnes from soil and rainfall data for 300 farms? 13 marks

A comparison table across the five criteria; least squares, maximum likelihood, greedy splitting, backpropagation; trees and linear models are readable, networks least so; networks need the most data. For 300 farms and a numeric target: multiple regression (with x² terms if residuals curve) or a shallow regression tree; a network is not justified at this size.

Glossary

Activation function
The nonlinear function a neuron applies to its net input: step, sigmoid, tanh or ReLU.
Adjusted R²
R² corrected for the number of features, so it falls when a useless feature is added.
AUC
Area under the ROC curve; the probability that a random positive is scored above a random negative.
Autocorrelation
The correlation of a time series with its own values k steps earlier (lag k).
Backpropagation
Computing every weight's gradient by applying the chain rule backwards from the loss.
Centroid
The mean of the points in a cluster; k-means represents each cluster by it.
Confusion matrix
Table of actual against predicted classes, holding TP, FP, FN and TN for two classes.
Cross-validation
Rotating which fold of the data is held out, to estimate performance on unseen data.
Decision boundary
The set of feature values where a classifier switches from one class to the other.
Dendrogram
Tree diagram of hierarchical clustering; each join sits at its merge distance.
Eigenvalue (in PCA)
The variance of the data along a principal component.
Entropy
Impurity of a set of labels, −Σpᵢ log₂ pᵢ; 0 when pure.
Epoch
One complete pass of training over all the training rows.
Exponential smoothing
Forecasting with weights on past values that shrink geometrically: Fₜ₊₁ = αYₜ + (1 − α)Fₜ.
F1 score
Harmonic mean of precision and recall.
Feature
A measured input variable of a model; also called attribute or predictor.
Gini index
Impurity measure 1 − Σpᵢ², used by CART.
Gradient descent
Repeatedly moving parameters against the gradient of the loss, scaled by a learning rate.
Hyperparameter
A setting chosen before training, such as tree depth, k or learning rate.
Information gain
Fall in entropy from splitting a set on an attribute.
Least squares
Choosing coefficients that minimise the sum of squared residuals.
Linkage
Rule for the distance between two clusters: single, complete, average or Ward's.
Log-loss
Binary cross-entropy, −Σ[y ln p + (1 − y) ln(1 − p)], minimised by logistic regression.
Odds ratio
e^β: the factor by which one unit of a feature multiplies the odds in logistic regression.
Overfitting
Fitting noise in the training data, so performance on new data is poor.
Precision
TP ÷ (TP + FP): the share of predicted positives that are correct.
Principal component
A direction of maximum remaining variance; an eigenvector of the covariance matrix.
Recall
TP ÷ (TP + FN): the share of actual positives that are found; also sensitivity or TPR.
Residual
Observed minus predicted value, e = y − ŷ.
Seasonality
A pattern in a time series that repeats with a fixed period.
