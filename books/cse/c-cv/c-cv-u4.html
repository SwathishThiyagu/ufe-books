4.1 Detection of points, lines and edges

An isolated bright point, a thin line and an edge each change the 3×3 neighbourhood around a pixel in a different pattern. Tiny masks, each with weights summing to zero, measure those patterns: the Laplacian finds points, four line masks find line directions, and derivatives locate edges. The response is compared with a threshold T. This is the first step of segmentation in inspection, medical imaging and document scanning, where object boundaries must be found before shape or size can be measured.

You need: pixel neighbourhoods and connectivity from Unit 1, and correlation and convolution from Unit 2.

Masks, response and isolated points

Slide a 3×3 window over the image. Name the nine grey levels z1 to z9 and the nine mask weights w1 to w9. The response is the sum of the nine products. Mark the centre pixel if |R| > T, where T is a threshold in grey levels.

R = Σ w<sub>i</sub> z<sub>i</sub>, for i = 1 to 9

R is the mask response; wi is the weight at position i; zi is the grey level under that weight; the sum runs over the nine positions of the 3×3 window.

A flat region of any brightness gives R = 0 when the weights sum to zero. Check that sum first; a mask with non-zero sum reacts to brightness, not to the pattern. The point mask has 8 at the centre and −1 at all eight neighbours. Its weights sum to 8 − 8 = 0. For a lone bright pixel of value 5 on a black background, R = 8×5 − 0 = 40. A dark point gives −40, so use |R|. This Laplacian mask finds small isolated specks: stars, sensor dust, or defects on a metal sheet. A larger T keeps only stronger points.

Line masks and direction

Four 3×3 masks find thin lines. The horizontal mask has +2 in its middle row and −1 elsewhere. The vertical mask has +2 in its middle column. The 45° mask has +2 on the main diagonal, top-left to bottom-right. The −45° mask has +2 on the other diagonal. Every mask sums to zero: three +2 weights and six −1 weights give 6 − 6 = 0.

Apply all four masks at one pixel. If all four responses have |R| ≤ T, the pixel is not on a thin line. Otherwise the mask with the largest |R| gives the line direction. For the window 0 0 0 / 3 3 3 / 0 0 0, the horizontal response is 18 and the vertical response is 0. With T = 10 the pixel is marked as a horizontal line pixel. A perfect horizontal line gives zero on the diagonal masks, so the direction is clear. Full gradient operators such as Sobel are in 4.2. Some syllabi call this point, line and edge detection and start the unit here.

Edge models and derivatives

An edge is a boundary where brightness changes. Three ideal models are used. A step edge jumps from one level to another at one position. A ramp edge changes linearly over a short distance. A roof edge rises to a peak and falls, like a thin bright line.

Take a 1D row f(x). Approximate the first derivative by f′(x) ≈ f(x+1) − f(x), and the second derivative by f″(x) ≈ f(x+1) − 2f(x) + f(x−1). On a step, the first derivative is a single spike at the edge; the second derivative has opposite signs on the two sides and crosses zero at the edge. On a ramp, the first derivative is a broad pulse; the second derivative has a positive spike at the start and a negative spike at the end. On a roof, the first derivative is positive before the peak and negative after it; the second derivative has a strong spike at the peak.

So an edge detector looks for a peak in |f′| or a zero crossing in f″. The second derivative is more sensitive to noise. This is the basis of the Marr-Hildreth detector in 4.2.

Worked example

Question. A 3×3 neighbourhood reads, top row first, 0 0 0 / 3 3 3 / 0 0 0. (a) Find the response of the horizontal mask [−1 −1 −1; 2 2 2; −1 −1 −1] and the vertical mask [−1 2 −1; −1 2 −1; −1 2 −1]. Use T = 10 and state the result. (b) A centre value 5 with all eight neighbours 0 is tested with the point mask. Find its response and decide with T = 20.

  1. Write the window as z = [[0,0,0],[3,3,3],[0,0,0]].
  2. Horizontal: R = (−1×0 −1×0 −1×0) + (2×3 + 2×3 + 2×3) + (−1×0 −1×0 −1×0) = 0 + 18 + 0 = 18.
  3. Vertical: top row −1×0 + 2×0 −1×0 = 0; middle row −1×3 + 2×3 −1×3 = 0; bottom row 0. R = 0.
  4. |18| > 10, so the pixel is a horizontal line pixel. The vertical response does not exceed T.
  5. Point mask: R = 8×5 − (eight neighbours = 0) = 40.
  6. |40| > 20, so the centre is marked as an isolated point.

Answer. Horizontal response 18, vertical response 0, so the pixel is a horizontal line pixel at T = 10; the isolated point response is 40, so it is marked at T = 20.

Exam traps

  • Sum the mask weights before using it. A non-zero sum gives a large R on a flat bright area.
  • Use |R| before comparing with T; a dark point or a dark line gives a negative response.
  • For lines, compare all four |R| values. The first response above T is not enough to fix direction.
  • A roof edge is a thin bright line, not an isolated point. The two patterns differ in the eight neighbours, not only the centre.
  • On a step edge the first derivative peaks; the second derivative crosses zero. Do not say the first derivative crosses zero.

4.2 Edge detectors: gradient, Marr-Hildreth and Canny

An edge is where brightness changes fast. An edge detector measures a derivative and keeps only strong, well-placed responses. The gradient gives the change and its direction; the second derivative gives a zero crossing at the edge. Sobel, Marr-Hildreth and Canny are three ways to turn this idea into a clean edge map. They are used before object measurement, lane detection, defect inspection and any task that needs boundaries, such as finding a PCB track or a number plate in a photo.

You need: 4.1 for second-derivative masks and Unit 2, Image Enhancement and Filtering, for Gaussian smoothing and derivatives.

Gradient and Sobel masks

Let f(x, y) be the grey level at pixel (x, y). The gradient is the vector ∇f = [Gx, Gy]T. Gx is the change along x; Gy is the change along y.

|G| = √(G<sub>x</sub><sup>2</sup> + G<sub>y</sub><sup>2</sup>),  θ = atan2(G<sub>y</sub>, G<sub>x</sub>)

|G| is the gradient magnitude in grey levels per pixel. θ is the gradient direction in degrees, from 0° to 360°. atan2(Gy, Gx) means tan−1(Gy / Gx) with the quadrant fixed from the signs of Gy and Gx, so opposite directions give different angles. The edge itself runs at θ + 90°.

Masks estimate the derivatives over a small neighbourhood. Roberts uses two 2×2 masks and responds to diagonal edges. Prewitt uses 3×3 masks with equal weights. Sobel also uses 3×3 masks but gives the centre row and centre column a weight of 2. That extra weight is a mild smoothing across the edge; it lowers noise without moving the edge much.

After filtering, compare |G| with a threshold T. Keep pixels above T. A low T keeps noise; a high T breaks edges into pieces. Later chapters join those pieces into boundaries.

Second derivative: Laplacian, LoG and Marr-Hildreth

The Laplacian is the second derivative: ∇²f = ∂²f/∂x² + ∂²f/∂y². A common 3×3 mask is [0 1 0; 1 −4 1; 0 1 0]. A sharp edge gives a positive response on one side and a negative response on the other. The edge lies at the sign change, called a zero crossing.

A second derivative is noisier than a first derivative, so blur first. The Laplacian of Gaussian (LoG) is Gaussian blur followed by ∇². It is one mask with a positive centre and a negative ring. Some syllabi call Marr-Hildreth the “Mexican hat” operator because of that shape. The blur scale σ sets the smallest detail found: small σ finds fine detail and noise; large σ finds only broad edges.

  1. Choose σ and blur f(x, y) with a Gaussian.
  2. Apply ∇², or apply the LoG mask directly.
  3. Find pixels where the response changes sign between neighbours.
  4. Mark a sign-change pixel as an edge only if its local response is above a threshold.

The threshold matters. A sign change alone can come from noise or from slow shading, so Marr-Hildreth keeps only strong zero crossings.

Canny detector

Canny states three aims: good detection, meaning few missed edges and few false edges; good localisation, meaning the found edge is close to the true boundary; and one response per edge, meaning a thick edge becomes one pixel wide.

  1. Smooth the image with a Gaussian of scale σ.
  2. Compute Gx, Gy, |G| and θ, usually with Sobel 3×3 masks.
  3. Apply non-maximum suppression: compare each pixel with its two neighbours along the gradient direction θ. Keep it only if it is the local maximum; otherwise set it to zero.
  4. Apply double threshold: a pixel with |G| ≥ Thigh is strong; a pixel with Tlow ≤ |G| < Thigh is weak; below Tlow it is rejected.
  5. Apply hysteresis: keep a weak pixel only if it is 8-connected to a strong pixel, directly or through other kept weak pixels.

A common starting point is Tlow ≈ 0.4 to 0.5 × Thigh. Hysteresis is why Canny edges stay connected: a weak edge that touches a strong edge is kept, while an isolated weak response is dropped.

Worked example

Question. A 3×3 patch reads 10 10 50 / 10 10 50 / 10 10 50. Use the Sobel masks: Gx is right column minus left column with centre weight 2; Gy is bottom row minus top row with centre weight 2. Find Gx, Gy, |G| and θ. With Tlow = 50 and Thigh = 150 grey levels, is the pixel strong, weak or rejected?

  1. Gx = (50 + 2×50 + 50) − (10 + 2×10 + 10) = 200 − 40 = 160 grey levels per pixel.
  2. Gy = (10 + 2×10 + 50) − (10 + 2×10 + 50) = 80 − 80 = 0 grey levels per pixel.
  3. |G| = √(160² + 0²) = 160 grey levels per pixel.
  4. θ = atan2(0, 160) = 0°. The gradient points along +x, so the edge runs vertically.
  5. Compare 160 with the thresholds: 160 ≥ 150, so the pixel is strong.
  6. Hysteresis keeps every strong pixel, so this pixel is kept.

Answer. Gx = 160, Gy = 0, |G| = 160 grey levels per pixel, θ = 0°, and the pixel is strong because 160 ≥ 150.

Exam traps

  • The gradient direction is across the edge, not along it. The edge direction is θ + 90°.
  • Non-maximum suppression compares each pixel with two neighbours along the gradient direction, not with the pixels left and right or above and below.
  • Sobel signs matter for θ. Gx = right − left and Gy = bottom − top. Reversing a sign may keep |G| but changes the direction by 180°.
  • A Laplacian zero crossing is not enough for Marr-Hildreth. The local response must also be above a threshold, or noise and slow shading create false edges.
  • With double threshold, a weak Canny pixel is kept only if it is 8-connected to a strong pixel through a chain of kept weak pixels. An isolated weak pixel is discarded.

Modern systems often learn edges from data with deep networks, then use Canny-like thinning and linking as post-processing. 4.3 Edge linking, boundary detection and Hough transform

An edge detector rarely returns a complete boundary. It returns short fragments, broken by noise and weak contrast. Edge linking repairs this: neighbouring edge pixels are joined when their positions, strengths and directions agree. If the gaps are large, a global method votes every edge pixel into a parameter space; lines and circles appear as peaks. This chapter builds boundaries from edge maps, first locally, then with the Hough transform, and finally orders the linked pixels into a closed path. Number-plate readers, lane keepers and PCB inspectors all depend on this step.

You need Chapter 4.2 for gradient magnitude and direction, which give the edge points and their angles.

Local edge linking

A raw edge map is a set of pixels where the gradient is large. A true boundary may be split because one part is blurred or hidden. Local linking joins two edge pixels only when three tests pass: they are close, their gradient magnitudes are similar, and their gradient directions differ by less than a small angle. Use 8-connectivity, so a neighbour may touch by a side or a corner.

√((x₂−x₁)²+(y₂−y₁)²) ≤ T_d,   | |∇f(x₂,y₂)| − |∇f(x₁,y₁)| | ≤ T_m,   angle(∇f(x₁,y₁), ∇f(x₂,y₂)) ≤ T_a

(x₁,y₁) and (x₂,y₂) are pixel coordinates; ∇f is the gradient; |∇f| is edge strength in grey levels per pixel; T_d is the distance limit in pixels; T_m is the strength limit; T_a is the angle limit in degrees.

  1. Scan the edge map. For each edge pixel, look at edge pixels in a small window, say 5×5 pixels.
  2. Join the pixel to a neighbour when all three tests pass. Mark the pair as linked.
  3. Repeat until no new links form. Each group of linked pixels is an edge fragment.

Typical limits are T_d = 3 to 5 pixels, T_m = 10 to 20 grey levels per pixel, and T_a = 10° to 15°. The exact values depend on image noise. Linking fails when a gap is wider than the window; then use the global method in the next section.

Hough transform for lines

The Hough transform does not connect neighbours. It lets every edge pixel vote for all lines that could pass through it. A line is written in normal form, so vertical lines do not need a special case.

ρ = x cos θ + y sin θ

(x,y) is an edge pixel in pixels; ρ is the perpendicular distance from the image origin to the line, in pixels; θ is the angle of that perpendicular, in degrees, with 0° ≤ θ < 180°.

For an image W pixels wide and H pixels high, the useful ranges are θ from 0° to 179° and ρ from −D to +D, where D = √(W² + H²) is the diagonal in pixels. Quantise θ, often in 1° steps, and ρ in 1-pixel steps. Create an accumulator A(ρ,θ) filled with zeros.

  1. For every edge pixel (x,y) and every quantised θ, compute ρ = x cos θ + y sin θ.
  2. Round ρ to its nearest bin and add one vote: A(ρ,θ) = A(ρ,θ) + 1.
  3. After all pixels vote, search A for peaks. A peak is a bin with many votes.
  4. Read the peak (ρ,θ) as a line. Its equation is x cos θ + y sin θ = ρ.

A perfect line made of many edge pixels gives one strong peak. Noise and quantisation spread votes over neighbouring bins, so the peak is a cluster, not one cell. Take the centre of the cluster, or the weighted average of its cells.

From linked pixels to boundaries

Local linking gives fragments, not one closed curve. Boundary detection orders the linked pixels into a path. Pick a start pixel on a fragment. At each step choose an unvisited edge neighbour that keeps the direction change small. Stop when the path returns to the start; the result is a closed boundary. If gaps remain, keep the path as an open fragment. This ordered list is what chain codes compress into direction numbers.

The Hough idea also works for circles. A circle is (x−a)²+(y−b)²=r², where (a,b) is the centre in pixels and r is the radius in pixels. Each edge point votes for centres (a,b) at every allowed radius r. The accumulator A(a,b,r) is three-dimensional. A peak gives one circle. Iris detection and coin counting use this version.

Some syllabi put motion-based segmentation in this unit. Motion needs optical flow between frames; it is covered in Unit 5, Features, Camera Geometry and Motion.

Exam traps

  • (ρ,θ) and (−ρ,θ+180°) are the same line. Keep θ in [0°,180°) and do not count both as separate peaks.
  • The Hough peak is a spread of cells. Choosing one corner of the spread gives a shifted line; take the cluster centre.
  • A new origin at (x₀, y₀) changes ρ to ρ' = ρ − (x₀ cos θ + y₀ sin θ). The shift is constant only for one fixed θ, not for all θ, so the whole accumulator must be recomputed when the origin moves. The stronger rule is: always use one origin, the same one, for every edge pixel in the image.
  • Coarse θ or ρ bins merge two close lines; fine bins split one line into several peaks. Match the bin size to the expected line separation.
  • For lines, the edge point coordinates do the voting. Gradient direction can restrict θ, but gradient magnitude alone is not the Hough vote.

4.4 Thresholding: global thresholding and Otsu's method

Many images hold two things: something bright and something dark. Thresholding turns such an image into black and white by comparing every pixel with a single grey level T. It is the cheapest segmentation method — one comparison per pixel — and the first thing to try on scanned documents, parts on an inspection line, cells on a slide and CT slices. The hard part is choosing T. Otsu's method searches the histogram for the split that pushes the two classes farthest apart.

You need: Unit 1 histograms and Unit 2 histogram processing; Otsu's search runs on the histogram alone.

From grey image to binary image

Thresholding compares every pixel with one number T, the threshold, and outputs a binary image. Pixels above T become 1 (foreground), the rest 0. It is a point operation: it never looks at a neighbour.

g(x, y) = 1 if f(x, y) > T, else g(x, y) = 0

f(x, y) is the input grey level (0 to 255 for 8-bit); T is a grey level, not a pixel count; g(x, y) is the binary output.

The method exists because many scenes contain exactly two materials. On the histogram such an image is bimodal: one peak for the background, one for the object, and a valley between them. The valley is the natural T.

Light is the hidden assumption. A camera records f(x, y) = i(x, y) · r(x, y), where i is illumination and r is reflectance (0 to 1). Illumination does not change the object, but it shifts grey levels: a page lit from one corner is darker at the far corner, and one global T cuts paper as ink or loses part of a letter.

Uses: document binarisation before OCR, defect checks on a conveyor, counting stained cells, separating bone from soft tissue in a CT slice, and producing a mask for later steps such as region growing.

Basic global thresholding: iterate on the mean

When the valley is not obvious, an older iterative procedure finds T from the two class means.

  1. Set T to the mean grey level of the whole image.
  2. Split with T: pixels with f ≤ T go to G1, pixels with f > T go to G2.
  3. Compute μ1 and μ2, the means of G1 and G2.
  4. Set the new T = (μ1 + μ2) / 2.
  5. Repeat steps 2 to 4 until T changes by less than ΔT, often 1 grey level or 0.

Each pass pulls T towards the midpoint between the class means, roughly the valley. A clean bimodal image settles in a few passes. It is a heuristic, not an optimum: three peaks can lock it onto the wrong valley, and it still uses one T for the whole image.

Otsu's method: maximise the between-class variance

Otsu asks: which k makes the two classes cleanest? Build the normalised histogram p(i) = h(i)/(MN), where h(i) counts pixels at grey level i and MN is the pixel count. For candidate k, class 0 is levels 0 to k and class 1 is levels k+1 to L−1, with L = 256.

  • w0(k) = Σ p(i) for i = 0 to k, the fraction of pixels in class 0; w1(k) = 1 − w0(k).
  • μ0(k) = [Σ i · p(i) for i = 0 to k] / w0(k), the mean grey level of class 0; μ1(k) is the same sum over levels k+1 to L−1 divided by w1(k).

σB²(k) = w0(k) · w1(k) · [μ0(k) − μ1(k)]²

σB²(k) is the between-class variance in grey levels squared; w0, w1 are class fractions; μ0, μ1 are class means. The best threshold k* maximises σB²(k).

Search k from 0 to L−2, keep the largest σB², and set T = k*. Pixels with f ≤ k* become 0; pixels with f > k* become 1. The split rule matters: writing level k on the wrong side changes the binary image even when σB² is the same.

Within-class form: σW² = w0σ0² + w1σ1², and σT² = σW² + σB². σT² is fixed for a histogram, so minimising σW² gives the same k. One pass over L = 256 bins costs O(L) time and memory; after the histogram is built, the image is never touched again.

When one T is not enough

Otsu is global: it assumes a bimodal histogram and two classes of comparable size. Three common failures: one class covers a tiny part of the image, so the split barely changes w0 and w1; the histogram is unimodal, so the best split falls in a tail; illumination varies, so the same material gives two grey levels in two places.

The cheap fix is variable thresholding: split the image into blocks, say 32 × 32, run Otsu inside each, and interpolate the per-block thresholds across boundaries. A shadow is then handled locally instead of dragging the whole threshold with it.

4.5 Region growing, region splitting and merging

Thresholding picks one grey level for the whole image. Region segmentation does the opposite: it groups neighbouring pixels that already look alike. Region growing starts from one or more seed pixels and adds touching pixels that satisfy a rule. Region splitting starts with the whole image, cuts a region into four quadrants while it is not uniform, then merges adjacent pieces back. The output is a set of regions, useful for finding a tumour in a scan, land and crop patches in satellite data, or parts of a manufactured component on an inspection line.

You need: 4- and 8-connectivity from Unit 1 and the failure of a single cut from 4.4.

Region growing from a seed

Seed and predicate. Pick a seed pixel (x_s,y_s). Its grey value is f(x_s,y_s). A pixel is allowed when the predicate P is true:

P(x,y): |f(x,y) − f(x_s,y_s)| ≤ T

f(x,y) is the grey level at pixel (x,y); f(x_s,y_s) is the seed grey level; T is the tolerance in grey levels.

Here T=1 means values one grey level above or below the seed are accepted. Use 4-connectivity (up, down, left, right) or 8-connectivity (also diagonals) from Unit 1. A pixel enters the region only if it is already touching the region and P is true. Put accepted pixels in a queue and test their neighbours. Stop when the queue is empty. The result depends on the seed: a seed inside a dark object grows a dark region. With P fixed on the seed value, the accepted set is the connected component of the seed, so visit order does not change it. Order can change the result only when P uses statistics of the region grown so far, such as its running mean, or compares a pixel with its accepted neighbour instead of the seed.

Splitting with a quadtree

Splitting. Start with the whole image as one region R. Define a uniformity predicate Q(R). The strict form is Q(R)=true when every pixel in R has the same grey level. For a natural image with noise, use the mean μ_R and standard deviation σ_R:

μ_R = (1/|R|) Σ_{(x,y)∈R} f(x,y)

|R| is the number of pixels in R; f(x,y) is a grey level; μ_R is the mean grey level in R.

σ_R = √[(1/|R|) Σ_{(x,y)∈R} (f(x,y) − μ_R)²]

σ_R is the standard deviation of grey levels in R.

Q(R)=true if σ_R ≤ T_σ, where T_σ is a chosen tolerance in grey levels. A low σ_R means the region is nearly flat. If Q(R) is false, cut R into four equal quadrants. Test each quadrant with Q. Repeat. The cuts form a quadtree: the whole image is the root, and each split has four children. Stop a branch when Q is true or the region is one pixel.

Merging back and stopping

Merging. Splitting alone leaves many small flat pieces. Merge two regions only when they are adjacent and Q(R1 ∪ R2) is true. Adjacent here means they share an edge; touching only at a corner is not enough. The predicate is tested on the union, not on each region separately: two flat regions can have different means, and their union may fail Q. Repeat merging until no pair of adjacent regions can be merged. Then check for any region that still fails Q; if one exists, split it and merge again. Stop when no split or merge is possible. Merging order matters too; a greedy merge can block a better later merge. Splitting gives quadtree leaves. Merging combines adjacent leaves, possibly from different parents, so each final region is a union of quadtree leaves, not itself a node of the tree. This is the split-and-merge method. It is used when objects have smooth interiors and weak edges, where an edge map from 4.2 has gaps.

4.6 Watershed segmentation using morphology

Watershed segmentation imagines an image as a landscape. Grey level is height. Bright pixels are high ground and dark pixels are valleys. Rain falls and each valley fills with water. When two pools meet, a dam is built along the meeting line. That line is the watershed. The method separates touching coins, cells and machine parts. The input is usually a gradient image, not the raw photo, so flat object centres stay low and object edges form high ridges. Markers stop noise from creating thousands of tiny pools.

You need: <a href="#chapter-4.2">Chapter 4.2 for the gradient image, and Unit 2 and Unit 3 for the morphological opening and closing used to build markers.

The landscape model

Take a grey image f(x,y). x and y are pixel coordinates; f is the grey level. Treat f as height on a map. A bright pixel is a hill. A dark pixel is a valley. A regional minimum is a connected set of pixels with the same low value whose neighbours are all higher. Rain collects in each regional minimum. The set of pixels that drain to one minimum is a catchment basin. Where two basins touch, a dam is drawn. The dam is the watershed line. The line sits on ridges, not in valleys.

g(x,y) = √(Gx² + Gy²)

g is the gradient magnitude; Gx and Gy are the horizontal and vertical derivatives at pixel (x,y).

A raw photo is a poor landscape. A flat object interior may be dark and a flat background bright, so flooding starts inside the object and grows past the true boundary. The correct input is a gradient image. On this surface, flat object centres are valleys and object edges are ridges. Flooding then stops near edges. See <a href="#chapter-4.2">Chapter 4.2. Noise is the main danger. Every tiny dip in g becomes a regional minimum, and each one starts a basin. A noisy gradient can give hundreds of regions. This failure is over-segmentation.

Marker-controlled watershed

Markers are pixels known to lie inside an object or in the background. They tell the flood where to start. Internal markers mark object centres. External markers mark background. With markers, the algorithm does not flood from every regional minimum; it floods only from the marked minima. The watershed line then separates the marked objects.

Two common ways to find internal markers are the h-minima transform and a morphological opening. The h-minima transform removes regional minima whose depth is less than h. Depth is the height difference between the minimum and the lowest saddle that leads out of it. A larger h removes more shallow minima and gives fewer regions. Morphological opening is f ∘ b, with f the gradient image and b a small structuring element, often a disk or a 3×3 square. Opening deletes bright features smaller than b. On a gradient it erases thin bright ridges, so two nearby basins join and the shallower minimum disappears into the deeper one. Dark dips themselves are filled by a closing, not by an opening; the h-minima transform is the direct way to suppress them.

External markers can be found by taking the watershed of the gradient and keeping only the watershed lines as background seeds. Another route is the distance transform for a binary object. For each object pixel p, D(p)=min distance from p to a background pixel. D is small near the object border and large near the object centre. Touching objects have multiple maxima in D. Flood the negative distance transform, -D. The maxima of D become minima of -D. Flooding -D with watershed lines between the maxima is one way to split touching objects. Watershed itself is also called the watershed transformation, and some syllabi describe it through the Meyer flooding algorithm: scan grey levels from low to high, dilate labelled basins inside a mask, and build a dam where two labels meet.

A working recipe

  1. Smooth the image lightly to reduce noise. Do not remove real edges.
  2. Compute the gradient magnitude with <a href="#chapter-4.2">Chapter 4.2.
  3. Find internal markers. Use h-minima on the gradient, or an opening, or a distance transform for binary objects.
  4. Find external markers. One way is the watershed of the gradient; its lines are background seeds.
  5. Modify the gradient so the only minima are at the markers. A common rule is to set marker pixels to the minimum grey level.
  6. Run watershed flooding on the modified gradient.
  7. Remove very small regions and merge regions that are too similar. This is region merging, covered in <a href="#chapter-4.5">Chapter 4.5.

The output is a label image. Each basin has a different label. Watershed lines can have a separate label. Use the labels for counting cells, separating coins, or finding defects. A Chennai factory checking washers can use distance-transform watershed to separate washers that touch on a conveyor. A hospital can use marker-controlled watershed to split overlapping cells in a blood smear.

Exam traps

  • Forgetting that every shallow noise dip is a regional minimum. Smoothing alone does not remove all of them. Use h-minima, an opening, or markers to suppress shallow minima.
  • Using markers as seeds but leaving other minima in the gradient. Extra basins still appear. Marker-controlled watershed must make the markers the only minima, for example by setting marker pixels to the minimum grey level.

4.7 Active contour models

An active contour, or snake, is a closed curve placed near an object that slides and stretches itself until it settles on the boundary. It exists because edge maps are broken: gaps, noise and texture stop a raw edge detector from giving a clean outline, and the snake bridges those gaps by preferring to stay smooth. Medical imaging uses it to outline a tumour in an MRI slice, traffic software traces a lane, and a phone app uses it to cut a person out of a photo. This chapter builds the energy that drives the slide and the loop that minimises it.

You need: 4.2 for the gradient image that supplies the external energy, and Unit 2 for Gaussian smoothing before the gradient.

A curve with an energy

An edge detector gives you pixels where brightness changes fast (see 4.2). That set is not a boundary. It has gaps where the edge is faint and extra pixels where texture fires. A boundary is a different object: a closed, ordered curve that separates inside from outside.

A snake makes that curve explicit and then moves it. Write the curve as a parametric contour v(s) = (x(s), y(s)) with s from 0 to 1. Here v(s) is a point on the curve, x(s) and y(s) are its column and row, and s is not time but a label that runs along the curve. Because the contour is closed, v(0) = v(1). On a computer you store n sample points v₁ … vₙ, and the last joins back to the first.

The curve carries an energy. Low energy means a good curve, so the snake's whole job is to slide its points until the total energy is as small as it can get.

E = ∫₀¹ [ E_int(v(s)) + E_ext(v(s)) ] ds

E is the total snake energy; E_int is the internal energy, a cost for stretching and bending; E_ext is the external energy, a reward for lying on edges; ds is an infinitesimal piece of the parameter range.

Two desires pull against each other. The internal term wants a short, smooth loop. The external term wants it on the edges. The snake settles where the two costs balance. That balance explains why it can span a gap in the edge map: crossing the gap costs a little external energy, while detouring to chase noise would cost bending energy.

Internal and external energy

E_int = ½ ( α |v′(s)|² + β |v″(s)|² )

α (alpha, ≥ 0) is the elasticity weight and discourages stretching; β (beta, ≥ 0) is the rigidity weight and discourages bending; v′ = dv/ds is the tangent, whose size says how fast the curve runs; v″ = d²v/ds² is the curvature term; the ½ is a convention.

On sampled points the same idea becomes a sum over the n points, with indices wrapping around so that v₀ means vₙ.

E_int ≈ Σᵢ [ α |vᵢ₊₁ − vᵢ|² + β |vᵢ₊₁ − 2vᵢ + vᵢ₋₁|² ]

|vᵢ₊₁ − vᵢ| is the length of side i; the second difference vᵢ₊₁ − 2vᵢ + vᵢ₋₁ is large exactly where the curve bends sharply; the sum runs over all i.

  • Large α: the snake refuses to stretch, so it cuts corners and may ignore a dented boundary.
  • Large β: the snake refuses to bend, so it flattens and can shrink away from a weak edge.
  • Some textbooks halve the discrete sum. Halving every term does not change which curve has the least energy.

E_ext(x, y) = − |∇f(x, y)|²

f is the smoothed grey-level image; ∇f is its gradient, computed as in 4.2; |∇f| is edge strength; the minus sign means a strong edge gives a very negative, that is low, energy.

Smooth first with a Gaussian (Unit 2). On a raw image, sensor noise produces large gradients everywhere and the snake locks onto the noise instead of the object.

The iterative update

Minimising E exactly needs the calculus of variations. In practice you use a greedy loop that only ever accepts a move if the total energy falls.

  1. Smooth the image, then compute |∇f|² for every pixel.
  2. Place an initial closed contour near the object, by hand or from a coarse threshold (see 4.4).
  3. For each contour point, test small candidate moves: its 8 neighbours, or a 5×5 window if you expect fast motion.
  4. Evaluate E_int + E_ext for each candidate and move the point to the candidate with the lowest energy.
  5. Add a balloon weight γ (gamma): each point also takes one step along its outward unit normal when γ > 0, or inward when γ < 0. This constant pressure lets the curve cross faint edges and small gaps.
  6. Repeat whole passes until the total energy changes by less than a small threshold, or a fixed number of passes ends.

The result is a local minimum, not the global one. A snake started inside the object, started outside it, or started near the wrong edge gives different final curves. Gradient vector flow (GVF) is the usual fix: it diffuses the gradient over the whole image into a smooth vector field, so a point far from any edge still feels a weak pull towards it. Region-based models such as Chan-Vese push this further and use grey-level averages instead of gradients.

  • The external energy is negative, −|∇f|², because the snake minimises energy. Writing +|∇f|² makes the snake run away from edges and stop in flat dark regions.

4.8 Boundary representation: chain codes and boundary descriptors

A segmented region is a blob of pixels. Its boundary is the ordered line around it. Walk that line and write a direction number at every step; the boundary becomes a short string such as 00664422. That string is a chain code. It saves memory, makes matching cheap, and gives numbers for length, turns and shape. Scanners, defect inspection and shape sorting use it. The same object can start at a different boundary pixel or be rotated, so the raw string is normalised into a first difference and a shape number.

You need boundary linking from 4.3 and pixel connectivity from Unit 1.

Following the boundary and writing a chain code

Segmentation gives a set of region pixels. To get an ordered boundary, pick a start pixel, for example the topmost row and then the leftmost pixel in that row. Move around the region clockwise. At each step choose the next boundary pixel by a fixed neighbour order. Stop when you return to the start. The output is a list of boundary coordinates in order.

Instead of storing coordinates, store the direction from one boundary pixel to the next. In a 4-directional code the directions are 0 = east, 1 = north, 2 = west, 3 = south. In the 8-directional Freeman code the directions are 0 = east, 1 = north-east, 2 = north, 3 = north-west, 4 = west, 5 = south-west, 6 = south, 7 = south-east. Image rows run downwards, so north is one row up and south is one row down. Each code is one step to a neighbour.

  1. Find the start: topmost boundary pixel, then leftmost in that row.
  2. Set the current pixel to the start. At the first step, set the previous point to the outside neighbour above-left of the start pixel.
  3. Scan the eight neighbours of the current pixel clockwise starting from the previous point, skip the previous point itself, and take the first neighbour that belongs to the region.
  4. Append the direction code to that neighbour. Set the previous point to the current pixel and make the chosen neighbour the new current pixel.
  5. Stop when the start is reached again after at least one step.

A 4-directional code can only turn in right angles. A diagonal edge needs the 8-directional code. An N-pixel boundary needs N codes; in 8-direction each code fits in 3 bits.

Start point, first difference and shape number

The raw chain code depends on the start pixel, on the tracing direction and on rotation. The first difference removes rotations by multiples of 45 degrees, and the shape number removes the start pixel. Tracing direction is not removed, so always trace in the same direction (here clockwise) before comparing shape numbers.

d<sub>i</sub> = (a<sub>i</sub> − a<sub>i−1</sub>) mod 8, with a<sub>−1</sub> = a<sub>n−1</sub>

ai is the i-th chain code (0 to 7), n is the number of codes, and mod 8 keeps the result in 0 to 7. The first difference di is the turn at step i.

Use the last code as the code before the first. A rotation by a multiple of 45° adds the same constant to every ai; the subtraction cancels it, so the first difference does not change. The shape number is the smallest circular rotation of the first difference, comparing digit by digit. It removes the start point. It does not remove scale.

Resampling on a coarser grid changes the number of codes. Before comparing shapes, resample the boundary on a fixed grid spacing. Conventionally the resampling is done so that the number of codes is a power of 2 (8, 16, 32, ...), which keeps the grid square and makes the 45 degree rotations consistent. The figure uses a 3×3 ring. Its clockwise code is 0 0 6 6 4 4 2 2. The first difference is 6 0 6 0 6 0 6 0. Rotating it once gives 0 6 0 6 0 6 0 6, the smallest rotation, so the shape number is 06060606.

Boundary descriptors: length, shape and Fourier coefficients

Several numbers summarise a boundary without keeping every pixel.

  • Boundary length from the code: L = Ne + √2 No. Ne counts even codes 0, 2, 4, 6: each is a unit horizontal or vertical step. No counts odd codes 1, 3, 5, 7: each is a diagonal step of length √2. L is in pixel units.
  • Diameter: the largest Euclidean distance between any two boundary points.
  • Eccentricity: major axis length ÷ minor axis length of the best-fitting ellipse. A circle has eccentricity 1; a long shape has a large value.
  • Curvature: rate of change of the tangent direction with arc length. For a first difference d, read d as a signed turn: 0, 1, 2, 3 are left turns of 0, 45, 90, 135 degrees, and 5, 6, 7 are right turns of 135, 90, 45 degrees; 4 is a full reversal. The size of the bend is min(d, 8 − d) × 45 degrees, so 7 and 1 are gentle turns and 4 is the sharpest.
z(k) = x(k) + j y(k); Z(u) = Σ<sub>k=0</sub><sup>N−1</sup> z(k) e<sup>−j2πuk/N</sup>

x(k), y(k) are the coordinates of boundary point k, N is the number of points, j is the imaginary unit, u is the frequency index, and Z(u) is the DFT coefficient.

Keep only the first few Z(u), usually the low frequencies. They describe the overall shape; high frequencies describe fine detail. Except Z(0), the magnitudes |Z(u)| do not change under translation, rotation or a change of start point. Scaling multiplies every magnitude by the same factor, so divide by |Z(1)| to compare sizes. Skeletons are a regional descriptor and are covered in 4.9.

Exam traps

  • The first difference must be taken mod 8. Writing −2 instead of 6 for a step from 4 to 2 breaks the shape number.
  • The raw chain code depends on the start pixel and on clockwise versus anticlockwise tracing. State both when you give a raw code.
  • 4-directional and 8-directional codes use different meanings for the same number. In a 4-code 1 means north; in an 8-code 1 means north-east.
  • Boundary length is not just the number of codes for an 8-directional boundary. Odd codes are diagonal steps of length √2, not 1.
  • The shape number is the smallest circular rotation of the first difference, not of the raw chain code.

4.9 Regional, topological and texture descriptors

A region is a blob of pixels that belong together. A few numbers can describe it instead of a pixel list. Area and perimeter give size and roundness. Topology counts pieces and holes. Texture describes how grey levels are arranged inside. Vision programs use these numbers: a PCB inspector checks pad holes, a rice grader checks grain area and elongation, a fabric grader checks co-occurrence contrast, a cell counter checks nucleus roundness.

You need: 4.5 and 4.4 for getting the regions themselves, and 4.8 for the boundary numbers these descriptors build on.

Shape numbers for one region

Once thresholding or region growing gives a set of pixels, pass a few numbers, not the pixel list.

Area A is the pixel count, in pixels². Perimeter P is boundary length: count boundary pixels, or use chain-code length with √2 for each diagonal step.

compactness = P² / A

P is perimeter in pixels, A is area in pixels², and the result is dimensionless. A circle of radius r has P = 2πr and A = πr², so P²/A = 4π ≈ 12.57. Every other shape scores higher; a long thin streak scores in the hundreds.

Eccentricity uses second moments about the centroid (x̄, ȳ). These mix coordinates, so they capture orientation as well as spread.

μ_pq = Σ (x − x̄)^p (y − ȳ)^q

the sum runs over region pixels; μ20 and μ02 measure spread along x and y, μ11 measures tilt. The principal axis angle is θ = ½ atan2(2μ11, μ20 − μ02).

Along the principal axes the spreads are a and b, with a ≥ b. Eccentricity is e = √(1 − b²/a²): e = 0 for a disk, close to 1 for a rod.

Grey-level mean inside the region is m = (1/A) Σ f(x, y) and variance is σ² = (1/A) Σ (f(x, y) − m)², both summed over region pixels.

The skeleton, or medial axis, is the set of points with two nearest boundary points. It is one pixel wide, keeps topology, and is used for handwriting or blood-vessel tracing.

Topology: pieces and holes

Topology ignores size and shape. Only two counts matter.

  • C = number of connected components of the object.
  • H = number of holes, that is, background components fully enclosed by the object.
  • The Euler number is E = C − H.

Use 8-connectivity for the object and 4-connectivity for the background, or the reverse. Never the same rule for both. With 8 for both, a diagonal object chain and the diagonal background chain between them would each count as connected, and a closed loop would fail to separate inside from outside. One rule per side keeps C and H consistent, so E comes out the same either way.

E is the cheapest defect test in industry: a machined pad should have exactly one hole, so any change in E flags a broken or blocked hole. C counts rice grains on a conveyor or cells on a slide. These counts survive stretching, rotation and scaling.

Texture: how the grey levels are arranged

Texture is the pattern of grey levels inside the region, not a single pixel value. Sand and knitted cloth can share a mean grey of 128 and still look different.

First-order measures use only the histogram. Normalise it: p_i = n_i / N, the fraction of region pixels at level i, with N the pixel count.

  • Mean: m = Σ i p_i, in grey levels.
  • Variance: σ² = Σ (i − m)² p_i.
  • Smoothness: R = 1 − 1/(1 + σ²), which is 0 for a flat region and tends to 1 as spread grows.
  • Third moment: Σ (i − m)³ p_i, the skewness; negative means the histogram is skewed to the left: a long tail toward dark levels while most pixels are bright; positive means a tail toward bright levels.
  • Uniformity: U = Σ p_i², which is 1 when a single level dominates.
  • Entropy: H_e = −Σ p_i log₂ p_i, in bits; 0 for a flat region, maximal at log₂ L for L levels used equally.

Uniformity and entropy always move in opposite directions: one dominant level means high U and low H_e.

Second-order measures keep position. The grey-level co-occurrence matrix P(i, j | d, θ) holds the fraction of pixel pairs where one pixel has level i and the pixel at distance d and angle θ has level j; θ is 0°, 45°, 90° or 135°.

  • Contrast: Σ (i − j)² P(i, j) — large when neighbouring levels differ a lot.
  • Correlation: how linearly aligned i and j are; 1 for a perfect linear relation.
  • Energy: Σ P(i, j)² — high when the matrix is concentrated in a few cells.
  • Homogeneity: Σ P(i, j) / (1 + |i − j|) — high when pairs differ by little.

Exam traps

  • The Euler number is C − H, not C + H. Two pieces with no holes give E = 2, not 0.
  • Entropy uses log₂ to come out in bits; natural log gives nats and a different number.
  • Compactness squares the perimeter: P²/A, not P/√A. Dropping the square gives P/√A, and for a circle that is 2√π ≈ 3.54 instead of 12.57. Plain P/A is not dimensionless and changes with the size of the circle, so it is never used.

  • C and H need mixed connectivity — 8 for the object and 4 for the background, or the reverse. The same rule on both sides breaks the hole count.

  1. A 3×3 mask response separates an isolated point, a thin line and an edge because each has a different local pattern.
  2. Edge detectors respond to derivatives; Marr-Hildreth uses second-derivative zero crossings and Canny uses gradient plus thinning and hysteresis.

  7. An active contour balances smoothness against image attraction, so it can close a boundary across small edge gaps.
  8. Chain codes turn a boundary into a compact string, and normalisation makes it independent of start point and rotation.
  9. Region descriptors such as area, Euler number and texture summaries let a vision system compare objects without storing every pixel.

Glossary

Accumulator array
An array of bins that counts votes in the Hough transform.
Active contour
A deformable closed curve that minimises an energy to fit object boundaries.
Bimodal histogram
A histogram with two peaks, one for object and one for background.
Chain code
A string of direction numbers that traces a boundary step by step.
Co-occurrence matrix
A matrix counting pairs of grey levels at a fixed offset.
Edge
A boundary between regions where brightness changes rapidly.
Euler number
The number of connected components minus the number of holes.
Gradient magnitude
The quantity √(G_x²+G_y²), where G_x and G_y are first derivatives.
Hough parameter space
The space of shape parameters in which edge pixels cast votes.
Hysteresis thresholding
A rule that keeps strong edge pixels and weak pixels connected to them.
Image segmentation
Partitioning an image into non-overlapping regions that have similar properties.
Laplacian
The second-derivative operator ∇²f = ∂²f/∂x² + ∂²f/∂y².
Laplacian of Gaussian
A detector that smooths with a Gaussian and then applies the Laplacian.
Marker
A seed imposed in marker-controlled watershed segmentation.
Non-maximum suppression
A thinning step that keeps only local maxima along the gradient direction.
Otsu threshold
The threshold that maximises between-class variance.
Predicate
A rule that decides whether a pixel or region joins another region.
Quadtree
A recursive splitting of an image into four quadrants at each step.
Region growing
Starting from seeds and adding neighbouring pixels that satisfy a similarity predicate.
Shape number
A chain code rotated to a canonical start, often the smallest integer form.
Texture
The arrangement of grey levels over a region, beyond simple mean brightness.
Threshold
A grey level T used to divide pixels into classes.
Watershed
Segmentation by flooding the grey-level landscape and finding where basins meet.
Zero crossing
A sign change in a second-derivative response, often used as an edge location.
