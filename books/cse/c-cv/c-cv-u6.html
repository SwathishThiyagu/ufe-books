6.1 Object recognition: patterns and pattern classes

Recognition is the act of deciding which pattern class a measured feature vector belongs to. An object is measured, the measurements become numbers, and a classifier compares those numbers with what it learned from labelled examples. This exists because a raw image is too rich to compare directly; a short vector makes the decision cheap and repeatable. It is used in postal address reading, fruit grading, signature checking and medical screening. The same steps appear in modern deep models: an image becomes a vector, and a head names the class.

You need: Unit 4 for segmentation and descriptors, and Unit 1 for pixels and neighbourhoods.

Pattern, class and feature vector

A pattern is the set of measurements taken from one object. A pattern class, written ω₁, ω₂, …, ω_W, is a set of patterns that share the property we care about. W is the number of classes. One tomato is a pattern; all ripe tomatoes form one class. The class is not one sample.

The measurements are placed in a feature vector x = (x₁, x₂, …, xₙ). Each xᵢ is a number with a unit: area in pixels, mean intensity, perimeter in pixels, or compactness (unitless). n is the dimension. The set of all possible x is the feature space, usually Rⁿ. A recogniser maps x to one label from the W classes.

x = (x₁, x₂, …, xₙ)

x is the feature vector; xᵢ is the i-th measured feature; n is the number of features, so the vector has n dimensions.

Descriptors provide the raw material. Regional descriptors include area, perimeter, compactness and eccentricity. Topological descriptors include number of holes H, number of connected components C, and Euler number E = C − H. These are not the classifier; they are the numbers fed to it.

E = C − H

E is the Euler number; C is the number of connected components; H is the number of holes in the object.

Recognisers fall into two families. Decision-theoretic methods use the numeric vector and a decision function. Structural methods use relations between parts, usually a string or a graph of sub-patterns. A printed word can be a string of characters; a face can be a graph of eyes, nose and mouth.

Training, testing and separability

A training set is a group of samples with known class labels. A test set is a separate group used after training. Supervised learning uses the labels to fix a rule. Unsupervised learning groups unlabelled samples into clusters, and a human later names each cluster. Accuracy on the training set can be optimistic; the test set estimates how the rule works on new objects.

Two classes are separable if some rule puts every sample on the correct side. In one dimension this is a threshold. In two dimensions it is a line. In n dimensions it is a hyperplane. Classes are linearly separable if a straight boundary separates all samples. Overlap means no perfect rule exists, so we measure error rate and cost.

Feature numbers must be chosen with care. Area in pixels and mean intensity have different ranges, and one may hide the other unless scaled. If the descriptor misses the property that separates the classes, no classifier can recover it. The decision rules themselves are in 6.2.

Case study: printed character recognition

A form is scanned, binarised, and segmented into lines and characters. For each character we compute features: area, bounding-box width and height, number of holes, and counts of foreground pixels in fixed zones. These numbers form x. The classes are the letters and digits needed by the form. Training samples come from several fonts and scans; test samples come from unseen forms. A decision rule from 6.2 then assigns a label. A structural check can help: a character is a graph of strokes, and “8” has two holes, “0” has one, and “1” has none.

This case is used in postal sorting, cheque reading and form digitisation. Most errors come from broken strokes, touching characters and poor segmentation. A segmentation error appears later as a classification error, so the descriptor step and the classifier must be judged together.

Worked example

Question. A tomato-grading unit sorts fruit into ripe (ω₁) and unripe (ω₂) using two features: mean red intensity R and area A in pixels. Training samples are ω₁: (180, 40), (190, 42), (175, 38) and ω₂: (110, 41), (120, 39), (105, 43). (a) Write the pattern vector. (b) How many classes and what is n? (c) Does R alone separate the classes? Give a threshold. (d) Does A add anything here?

  1. The pattern vector is x = (R, A). R is mean red intensity and A is area in pixels. Here W = 2 classes and n = 2 features.
  2. Ripe R values are 180, 190, 175. Their minimum is 175 and maximum is 190. Unripe R values are 110, 120, 105. Their minimum is 105 and maximum is 120.
  3. The largest unripe R is 120. The smallest ripe R is 175. Since 120 < 175, no sample lies between them. Any threshold T with 120 < T < 175 separates all six samples.
  4. Take the midpoint: T = (120 + 175) / 2 = 147.5. Rule: call the fruit ripe if R > 147.5, else unripe. All six training samples are correct.
  5. Ripe area values are 40, 42, 38, giving range 38 to 42 pixels. Unripe area values are 41, 39, 43, giving range 39 to 43 pixels. The ranges overlap from 39 to 42, so A alone cannot separate the classes and is redundant for these samples.
  6. In the (R, A) plane the boundary R = 147.5 is a vertical line. It separates the two classes, so the classes are linearly separable.

Answer. x = (R, A); W = 2 classes; n = 2 features; R alone separates them, with threshold R = 147.5 (ripe if R > 147.5); area A is redundant here because its class ranges overlap.

Exam traps

  • A pattern class is a set of samples that share a property; it is not one sample.
  • A pattern is the set of measurements from one object, and the pattern vector (also called the feature vector) is those measurements written as an ordered list x = (x₁, …, xₙ). Do not confuse a pattern (one sample) with a pattern class (the set of samples sharing a property).
  • n is the number of features, and W is the number of classes. They are not the same symbol or the same count.
  • A feature is useful if it helps separate the classes, alone or together with other features. In the tomato example area is dropped because R alone already separates the classes and the area ranges overlap.
  • Segmentation and description come before classification. A descriptor builds x; the classifier only assigns the label.

6.2 Classifiers: minimum distance, k-NN and Bayes

A classifier turns labelled feature vectors into a rule that names a new vector's class. It does this by placing a decision boundary in feature space: minimum distance uses class means, k-nearest neighbour uses nearby stored samples, and Bayes uses probability densities and priors. These are the classical recognition rules used on small or medium feature sets such as colour histograms or short HOG summaries, and they still serve as baselines when a deep model is too heavy. This chapter shows how each rule draws its boundary and how the three relate.

You need: 6.1 for feature vectors and pattern classes.

Minimum distance classifier

Class ω_j has N_j labelled training vectors. Its prototype is the class mean: m_j = (1/N_j) Σ x, summed over the N_j samples in ω_j. A test vector x goes to the class whose prototype is nearest. The rule uses squared Euclidean distance. Expanding it gives the formula below; xᵀx is the same for every class, so it cannot change the ranking. The remaining score g_j(x) = m_jᵀx − ½m_jᵀm_j is a linear discriminant. Assign x to the class with the largest g_j. Between two classes the boundary g_i = g_j is a straight line, a hyperplane in higher dimensions. For two classes it is the perpendicular bisector of the segment joining m₁ and m₂. For example, with m₁=(0,2), m₂=(4,2) and x=(1.2,2): d₁=1.2, d₂=2.8, so x→ω₁. This rule assumes each class is a compact cloud around its mean. A long or unevenly spread class breaks that assumption.

d_j² = ‖x − m_j‖² = xᵀx − 2m_jᵀx + m_jᵀm_j

d_j² is the squared distance to class j; x is the test vector; m_j is the prototype of class j; ᵀ marks transpose; ‖·‖ is Euclidean length.

g_j(x) = m_jᵀx − ½ m_jᵀm_j

g_j is the linear discriminant for class j; the class with the largest g_j is chosen.

k-nearest neighbour (k-NN)

k-NN stores all labelled training vectors. For test x, compute distance to every stored vector, keep the k smallest, and take a majority vote of their labels. k=1 is the nearest neighbour rule: copy the label of the closest sample. For two classes use odd k so a tie cannot occur. Euclidean distance is usual; Manhattan distance is the sum of the absolute coordinate differences, Σ|xᵢ − yᵢ|, and is an option. Feature scaling is not optional. If one feature ranges over thousands and another over 0 to 1, the large-range feature controls every distance. Standardise each feature to zero mean and unit variance, or map it to [0,1], before k-NN. Training cost is only storage, O(Nd) for N vectors in d dimensions. Test cost is O(Nd), because no compact model is built. A large training set gives accuracy but slow prediction. Speed-ups index the vectors, for example with a k-d tree or approximate nearest neighbour search.

Bayes classifier

Bayes decision uses probabilities. Let P(ω_j) be the prior probability of class j, p(x|ω_j) the class-conditional density of x, and p(x) the evidence. The posterior is P(ω_j|x) = p(x|ω_j)P(ω_j)/p(x). With 0-1 loss, which charges 0 for a correct label and 1 for an error, choose the class with the largest posterior; this minimises the probability of error. The same choice maximises g_j(x)=ln p(x|ω_j)+ln P(ω_j), because p(x) is common. The Bayes error rate is the unavoidable error of this rule; it depends on how much the class densities overlap. For two classes a confusion matrix counts true positives, false positives, true negatives and false negatives on test data. For J classes it is a J×J table, and these four counts are read off one class at a time. It reports what the rule did, not the theoretical minimum. For Gaussian classes with equal, isotropic covariance Σ = σ²I and equal priors, the Bayes boundary is exactly the minimum distance boundary: the perpendicular bisector of the segment joining the means. With equal but general Σ the Bayes rule still has a linear boundary, but it uses the squared Mahalanobis distance (x−m_j)ᵀΣ⁻¹(x−m_j); that boundary is a straight line, not in general the perpendicular bisector. Unequal priors move the boundary toward the less likely class: a rare class needs stronger evidence. Unequal covariance matrices give a curved, quadratic boundary.

P(ω_j|x) = p(x|ω_j) P(ω_j) / p(x)

P(ω_j|x) is the posterior of class j; p(x|ω_j) is the class-conditional density; P(ω_j) is the prior; p(x) is the evidence.

g_j(x) = ln p(x|ω_j) + ln P(ω_j)

g_j is the Bayes discriminant; ln is natural logarithm; the largest g_j gives the minimum-error decision.

Exam traps

  • Unscaled features let a large-range feature dominate k-NN; standardise first.
  • An even k can tie with two classes; use odd k unless a tie rule is given.
  • Minimum distance is not Bayes in general; it is Bayes only for Gaussian classes with equal isotropic covariance σ²I and equal priors. With equal but general covariance the Bayes rule is nearest mean in Mahalanobis distance, and the boundary is a straight line but not the perpendicular bisector.
  • The prototype is the class mean, not the nearest training sample; k=1 uses the sample.
  • Bayes error is the theoretical minimum; a confusion matrix is measured test performance, not the same number.

6.3 CNNs for image classification: AlexNet, VGG, ResNet

A convolutional network learns its own features. Instead of hand-designed descriptors such as HOG or SIFT, it stacks small trainable filters and lets gradient descent decide what they detect. Depth buys accuracy, but plain deep stacks stop improving, so residual connections keep them trainable. These backbones sit under phone photo tagging, medical screening, and every detector later in this unit.

You need: Unit 2 for convolution, stride and padding, and 6.2 for the classifier idea that softmax and cross-entropy replace.

A convolution layer learns its own filters

An image enters as n × n pixels with C channels, three for colour. A convolution layer holds F filters, each a k × k × C block of weights. Every filter slides across the image and produces one output map, so the layer outputs F channels. The same weights are reused at every position — weight sharing — so a 3 × 3 filter learns 9 numbers per input channel, not one per pixel. Each output value sees only a k × k patch of the input: its local receptive field.

n_out = ⌊(n + 2p − k) ÷ s⌋ + 1

n is the input side in pixels, k the kernel side, s the stride in pixels per step, p the padding in pixels added on each side, and ⌊·⌋ is the floor. For a square input the same value applies to both sides.

After each convolution comes a ReLU, max(0, x), which keeps positive sums and zeroes negatives. A 2 × 2 max pool with stride 2 keeps the largest of four values, halving each side. Stacking conv–ReLU–pool grows the receptive field and shrinks the map, so filters become hierarchical: early layers fire on edges and colour blobs, middle layers on textures, deep layers on object parts and whole objects.

Fully connected layers flatten the last maps and mix them. A softmax turns final scores z into probabilities, ŷ_c = exp(z_c) ÷ Σ_j exp(z_j), and training minimises cross-entropy L = −Σ_c y_c log ŷ_c, where y_c is 1 for the true class and 0 for the rest, and ŷ_c is the predicted probability of class c.

AlexNet and VGG

AlexNet (2012) took a 227 × 227 × 3 image through 5 convolution layers and 3 fully connected layers to 1000 ImageNet classes. The first layer used 96 filters of 11 × 11 with stride 4. Three choices made it train: ReLU instead of sigmoid, dropout with rate 0.5 on the two large fully connected layers, and heavy augmentation — random crops, flips, colour jitter — over 1.2 million images. It held about 60 million parameters and was split across two GPUs. ZFNet kept the same layout and shrank the first-layer kernels to 7 × 7 with stride 2 after visualising them; a tuning win, not a new idea.

VGG repeats one pattern: every convolution is 3 × 3, stride 1, padding 1, so size is unchanged; every pool is 2 × 2, stride 2, so size halves. VGG-16 is 13 convolution plus 3 fully connected layers; VGG-19 is 16 plus 3. Two 3 × 3 convolutions see a 5 × 5 region and three see 7 × 7, with fewer weights and more ReLUs than one wide kernel. Almost all parameters sit in the first fully connected layer: 7 × 7 × 512 = 25,088 inputs into 4096 units is about 102.8 million weights, the bulk of roughly 138 million.

ResNet: the shortcut that made depth work

Plain networks got worse as they got deeper: training error rose too, which is degradation, not overfitting. A residual block learns a correction. Its output is y = F(x) + x, where x is the block input, F(x) is what two or three convolution layers compute, and y is the result. If the best behaviour is to do nothing, F only needs pushing to zero, which is easy. The identity shortcut carries x with no weights, so the block adds no parameters whenever the shapes match; only the projection shortcut adds a 1 × 1 convolution.

Batch normalisation follows each convolution: it rescales activations to zero mean and unit variance, then applies a learned scale and shift, which allows higher learning rates. When the shortcut crosses a channel change or a stride-2 downsample, a 1 × 1 convolution with matching stride projects x to the right shape. For 50, 101 and 152 layers the block is a bottleneck — 1 × 1 conv to shrink channels, 3 × 3 conv, 1 × 1 conv to restore — and the family runs from 18 to 152 layers (18, 34, 50, 101, 152). Gradients pass through the sum node, which eases the vanishing-gradient problem.

Inception, or GoogLeNet, runs several filter sizes in parallel inside one block and concatenates the outputs. DenseNet connects each layer to every later layer's input.

Recognition versus verification, and newer backbones

Recognition names the class of one image. Verification answers a yes/no question: are these two images the same identity? A Siamese network runs two copies of one CNN with shared weights and compares the two embeddings. Contrastive loss pulls a matching pair together and pushes a non-matching pair apart until a margin is reached.

L = max(0, d⁺ − d⁻ + margin)

d⁺ = ||f(a) − f(p)||₂ is the distance between an anchor a and a positive p of the same class, d⁻ = ||f(a) − f(n)||₂ is the distance to a negative n of another class, f is the embedding network, and margin is a chosen gap, often 0.2 to 0.5. A triplet already well separated gives zero.

Ranking loss is the general name for losses that only order distances. Vision Transformers cut the image into 16 × 16 patches, flatten each into a vector, add position embeddings, and let self-attention mix all patches. Swin Transformers restrict attention to shifted local windows. Only a few universities teach these; the convolution ideas above still apply.

6.4 Object detection with R-CNN, Fast and Faster R-CNN

A classifier names one object in an already-cropped image. Detection asks what objects are in the full picture and where. The answer is a list of bounding boxes, each with a class label and a score. One family of models made this practical: propose a few hundred candidate boxes, run a CNN over them, keep the best after suppression. R-CNN, Fast R-CNN and Faster R-CNN are three steps of one idea, each removing one bottleneck of the step before. They sit behind face unlock and toll-gate number plates.

You need: 6.3 for backbone CNNs and feature maps, and Unit 5, Histogram of oriented gradients (HOG), for the descriptor style that selective search builds on.

Boxes, IoU and non-maximum suppression

A detector outputs a list. Each item is a bounding box, a class name and a score between 0 and 1. A box is written (x, y, w, h) — top-left corner in pixels, width and height in pixels — or (x₁, y₁, x₂, y₂) — top-left and bottom-right corners. The ground-truth box is the one a human drew around the object.

To score a prediction we need a number saying how well it overlaps the ground truth. That number is intersection over union.

IoU = area(B_p ∩ B_g) ÷ area(B_p ∪ B_g)

B_p is the predicted box and B_g the ground-truth box, both in pixels; B_p ∩ B_g is the overlap and B_p ∪ B_g the region covered by either box; area is in px². IoU is 0 when the boxes do not touch and 1 when they are identical.

A detection counts as correct when its IoU with the ground truth is at least 0.5. Raise the threshold to 0.75 and you demand tighter boxes.

A detector proposes hundreds of overlapping boxes around one object. Non-maximum suppression (NMS) thins them down.

  1. Sort the predicted boxes of one class by score, highest first.
  2. Keep the top box and move it to the output list.
  3. Compute the IoU of every remaining box with the kept box.
  4. Delete each remaining box whose IoU is above the threshold, usually 0.5.
  5. Repeat from step 2 with the survivors until none are left.

NMS runs once per class, after scoring. Across all classes it would delete a genuine object that overlaps another, such as a rider on a bicycle.

R-CNN and Fast R-CNN

R-CNN (2014) made this work. Selective search, a classical region merger that joins neighbouring pixels by colour, texture, size and fill similarity, gives about 2000 class-independent proposals per image. Each is warped to 227×227 pixels and passed through AlexNet, giving a 4096-dimensional feature vector. On top sit one linear SVM per class, a linear box regressor, and NMS.

Two problems. The CNN sees 2000 overlapping crops per image, so the same pixels are convolved many times. And training has stages — fine-tune the CNN, train the SVMs, train the regressors — with features stored on disk.

Fast R-CNN removes the first. One convolution pass over the whole image gives a feature map. For each proposal, RoI pooling crops that map at the proposal's coordinates, splits the crop into a fixed 7×7 grid and takes the maximum in each cell. Every proposal becomes a fixed-size vector whatever its width and height. One network then carries two heads.

Head one is a softmax over C+1 classes: C object classes plus background. Head two gives 4 offset numbers per class, which move the proposal onto the object. Both heads share one loss.

L = L_cls + λ · L_box

L_cls is the cross-entropy log loss of the class head; L_box is the smooth L1 loss summed over the four box offsets; λ (often 1) balances the two.

smoothL1(x) = 0.5x² if |x| < 1, else |x| − 0.5

x is one box offset error, in pixels or log-scale units; quadratic near zero and linear far away, so a few wild boxes do not dominate training.

Fast R-CNN trains in one stage and is several times faster than R-CNN. But proposals still come from selective search on the CPU, and that now takes most of the time.

Faster R-CNN and mAP

Faster R-CNN (2015) removes selective search. The proposal step becomes a small network on the same feature map, the region proposal network (RPN).

The RPN slides a 3×3 window over the feature map. At every location it tests k anchor boxes. An anchor is a fixed reference box with a given scale and aspect ratio, typically 3 scales × 3 ratios = 9 anchors, from small squares to wide rectangles. For each anchor the RPN gives two objectness scores (object, background) and four offsets that move the anchor onto the object: 6k numbers per location.

Anchors get labels by IoU: above 0.7 with a ground truth is positive, below 0.3 is negative, the rest are ignored. The original paper trained in four alternating steps; later schemes train jointly in one pass.

One fix came later. RoI pooling rounds box coordinates to whole pixels, so the crop drifts from the true box by a pixel or two. RoI Align samples four points inside each grid cell with bilinear interpolation instead of rounding. The error is small for boxes and large for pixel-accurate masks, so the segmentation chapter uses it — see 6.6.

How is a detector scored? For one class, sort its detections by score and at each rank compute precision and recall. Average precision (AP) is the area under that precision-recall curve. Mean average precision (mAP) is the average of AP over all classes at a fixed IoU, usually 0.5.

One-stage detectors drop proposals and predict boxes straight from the image — see 6.5.

Worked example

Question. A detector predicts one box (30, 40, 110, 140) for the class 'car', and the ground-truth box is (50, 60, 130, 160). Both are (x₁, y₁, x₂, y₂) in pixels. (a) Compute the IoU. (b) Two boxes of the same class score 0.90 and 0.85, with IoU 0.6 between them. The NMS threshold is 0.5. Which boxes survive?

  1. Predicted area: width 110 − 30 = 80 px, height 140 − 40 = 100 px, area 8000 px².
  2. Ground-truth area: width 130 − 50 = 80 px, height 160 − 60 = 100 px, area 8000 px².
  3. Overlap in x: from max(30, 50) = 50 to min(110, 130) = 110, so 60 px.
  4. Overlap in y: from max(40, 60) = 60 to min(140, 160) = 140, so 80 px.
  5. Intersection = 60 × 80 = 4800 px².
  6. Union = 8000 + 8000 − 4800 = 11,200 px².
  7. IoU = 4800 ÷ 11,200 = 0.4286, about 0.43.
  8. (b) Sort by score: 0.90 kept. Its IoU with the 0.85 box is 0.6 > 0.5, so the 0.85 box is suppressed.
  9. Survivors: only the 0.90 box.

Answer. IoU = 4800 ÷ 11,200 = 0.4286 (about 0.43), a weak match; after NMS only the 0.90 box survives, because 0.6 > 0.5 suppresses the 0.85 box.

Exam traps

  • IoU uses areas, not centre distances. Boxes that look close on a sketch can still score 0.43.
  • NMS runs per class, after scoring. Suppressing across classes deletes a real object that overlaps another.
  • mAP is the mean of average precision over classes, not a mean of IoU values, and it is reported at a fixed IoU, usually 0.5.
  • Do not swap the sizes: R-CNN warps each proposal to 227×227 pixels, while Fast R-CNN pools each proposal to a 7×7 feature grid.
  • The class head has C+1 outputs. Forgetting background makes the softmax the wrong size.

6.5 Single-stage detectors: YOLO and SSD

A single-stage detector predicts boxes and class scores straight from the image in one forward pass. It does not propose regions first. YOLO cuts the image into a grid and lets each cell predict boxes; SSD predicts from feature maps at several scales; RetinaNet adds a loss that fixes the background imbalance. The speed makes these models common in live video, phone cameras, drones and CCTV, where a frame must be tagged before the next one arrives.

You need 6.4 for IoU, NMS and two-stage detection, and 6.3 for the convolutional backbone.

YOLO: one grid, one pass

YOLO divides the input into an S × S grid. In the first version S = 7, so the image is 7 cells across and 7 down. Each cell predicts B bounding boxes; B = 2. A box has five numbers: x, y, w, h and confidence. x and y are the box centre offsets inside that cell, scaled from 0 to 1. w and h are the box width and height as fractions of the whole image. The cell also gives C class probabilities, one per class. On PASCAL VOC, C = 20.

Confidence is Pr(object) × IoU with the truth box. Pr(object) is 1 if the object centre lies in the cell and 0 otherwise. IoU is intersection over union, the overlap between predicted and true boxes.

tensor depth = 5B + C

B is the number of boxes per cell; C is the number of classes. Total numbers = S × S × (5B + C). With S = 7, B = 2 and C = 20, the tensor is 7 × 7 × 30 and holds 1470 numbers.

Only the cell whose area contains the object centre is responsible for that object. Other cells are trained as no-object. This stops many cells from claiming the same object.

At test time, for each box multiply confidence by the class probability. Drop boxes below a confidence threshold. Apply non-maximum suppression, NMS, at IoU 0.5. NMS keeps the top score and removes overlapping boxes of the same class.

The training loss adds box, confidence and class terms. λ_coord = 5 raises the box term. λ_noobj = 0.5 lowers the confidence term for empty cells, so the many empty cells do not dominate.

SSD: many feature maps, default boxes

SSD, Single Shot MultiBox Detector, also skips proposals. A base convolutional network produces a first feature map. Extra convolutional layers produce smaller maps: 38×38, 19×19, 10×10, 5×5, 3×3 and 1×1 in a common SSD300 design with 300×300 input. Each map cell predicts a fixed set of default boxes, also called anchor boxes. The boxes have several aspect ratios, such as 1:1, 2:1 and 1:2, and more than one scale.

At each location, for each default box, the network outputs 4 offsets and C + 1 scores. The extra score is background. A 38×38 map with 4 default boxes and C = 20 gives 38×38×4 = 5776 box predictions at that scale alone.

Most default boxes are background, so SSD uses hard negative mining: sort background boxes by loss, keep only about 3 negatives for every positive, about 3:1. Train with smooth L1 for offsets and softmax for scores. At test, threshold scores and run NMS.

Early large maps catch small objects. Late small maps catch large objects.

RetinaNet and the speed-accuracy trade

RetinaNet is one-stage with feature pyramids. Its problem is class imbalance: a dense detector may see 1 object and 100000 background boxes. Focal loss reduces the loss of easy examples.

FL(p_t) = −α_t (1 − p_t)^γ log p_t

p_t is the probability of the true class; γ = 2 focuses training on hard examples; α_t balances classes.

  • YOLOv2 adds anchor boxes and batch normalisation.
  • YOLOv3 predicts at three scales.
  • Later YOLO versions use stronger backbones and better augmentation.
  • Two-stage detectors such as Faster R-CNN are better on small objects and accuracy, but slower.
  • One-stage detectors are faster, simpler to train, and weaker on very small objects unless they use multi-scale maps.

Worked example

Question. YOLO runs with S = 7, B = 2 and C = 20 on a 448×448 input. (a) What is the depth of the output tensor? (b) How many numbers are in the tensor? (c) How many boxes does the grid predict? (d) A cell contains an object and its best box has IoU 0.8 with the truth. That box's confidence is 0.8. What is the test-time score for class dog if the cell's dog probability is 0.9?

  1. Depth = 5B + C = 5×2 + 20 = 10 + 20 = 30 numbers.
  2. Total numbers = S × S × depth = 7 × 7 × 30 = 49 × 30 = 1470 numbers.
  3. Total boxes = S × S × B = 7 × 7 × 2 = 49 × 2 = 98 boxes.
  4. Test score = confidence × class probability = 0.8 × 0.9 = 0.72.

Answer. The tensor depth is 30, the tensor holds 1470 numbers, the grid predicts 98 boxes, and the dog score is 0.72.

Exam traps

  • The YOLO tensor depth is 5B + C, not 5 + B·C. With B = 2 and C = 20 the depth is 30, not 45.
  • x and y are offsets inside one cell; w and h are fractions of the full image. Mixing the two gives wrong boxes.
  • Only the cell holding the object centre is responsible for the object. Neighbouring cells stay no-object.
  • At test time use confidence × class probability, not confidence alone.
  • SSD scores are C + 1 because background is a class; hard negative mining keeps about 3 negatives per positive.

6.6 Semantic segmentation with fully convolutional networks

Semantic segmentation labels every pixel with a class: road, car, person, sky. A plain CNN classifier gives one label per image, so it loses location. A fully convolutional network keeps the spatial grid, replaces dense layers with 1×1 convolutions, and outputs a score for every class at every coarse cell. Upsampling then restores full resolution. It is used in self-driving lanes, medical scans, satellite land cover and phone background blur.

You need 6.3 for convolutional backbones and Unit 4 for classical thresholding and region segmentation that FCNs replace.

Three tasks, one pixel grid

Semantic segmentation assigns one class label to every pixel. It does not separate two cars of the same class; both become one car region. Instance segmentation detects objects and returns a separate mask per object, so two cars get two masks. Panoptic segmentation gives every pixel a class and, for countable things, an instance id; it joins stuff such as road and sky with things such as car and person.

A classifier CNN from 6.3 ends with fully connected layers and outputs one vector per image. An FCN removes those layers. A 1×1 convolution with C output channels acts like a dense layer at every position. The output is an H×W×C score map, where H and W are grid height and width and C is classes plus background. For a 224×224 input and five stride-2 pools, the map is 7×7×21 for 20 object classes plus background. Each cell corresponds to a 32×32 pixel patch of the input (its true receptive field is far larger), so the map is coarse: it knows what is present but not the exact boundary.

Upsampling and skip connections

Upsampling turns the coarse score map back to image size. FCNs use a transposed convolution, a learned upsample. It places a scaled copy of each input value through a kernel and sums overlaps. The side length follows H_out = (H_in − 1)s − 2p + k, where H_in and H_out are input and output side lengths, s is stride, p is padding and k is kernel side. For 7×7 to 224×224 with stride 32, k=64 and p=16 works: (7−1)×32 − 32 + 64 = 224.

A direct ×32 upsample gives blocky edges. FCN-16s first upsamples ×2 to 14×14×21, adds the pool4 score map of the same shape, then upsamples ×16. FCN-8s adds a pool3 skip too. Addition needs equal channel counts; a 1×1 convolution can match them. Concatenation, used in U-Net, needs equal spatial size instead. SegNet is an encoder-decoder: the encoder saves max-pooling indices, and the decoder uses them to unpool, so upsampling has no learned parameters. U-Net concatenates encoder features into the decoder; this preserves detail and works with few labelled medical images.

Loss, instance masks and metrics

Training uses per-pixel softmax cross-entropy, averaged over all N pixels: L = −(1/N) Σ_i log p(i, y_i). Here p(i, y_i) is the softmax probability the network gives to the true class y_i at pixel i. Every pixel contributes, including background. For a batch, average the image losses.

Mask R-CNN extends Faster R-CNN (see 6.4) for instance segmentation. It adds a small mask branch that predicts a binary mask for each proposal, and RoI Align samples features without rounding. Detection still supplies boxes and classes; the mask branch separates instances. The branch is small, so speed stays close to the detector.

Two metrics matter. Pixel accuracy is correct pixels divided by total pixels. Mean IoU is the average over classes of IoU_c = |P_c ∩ G_c| ÷ |P_c ∪ G_c|, where P_c is the set of pixels predicted as class c and G_c is the true set. Pixel accuracy can look high when background dominates; mean IoU exposes small classes.

Worked example

Question. An FCN uses a VGG backbone on 224×224×3 input and predicts 21 classes. (a) Find the deepest feature-map size after five stride-2 pools. (b) Find the score-map size after a 1×1 convolution to 21 classes. (c) Find a transposed convolution that turns 7×7 back to exactly 224×224 with stride 32.

  1. 1. Five stride-2 pools multiply stride by 2⁵ = 32. 224 / 32 = 7, so the deepest map is 7×7×512 for VGG.
  2. 2. A 1×1 convolution changes only channels. The spatial size stays 7×7, so the score map is 7×7×21.
  3. 3. For a transposed convolution, H_out = (H_in − 1)s − 2p + k. With H_in=7 and s=32, H_out = 192 − 2p + k.
  4. 4. Set k=64 and p=16: 192 − 32 + 64 = 224. So a 64×64 kernel, stride 32, padding 16 gives 224×224.
  5. 5. FCN-16s instead upsamples ×2 to 14×14×21, adds the pool4 map, then upsamples ×16.

Answer. The deepest map is 7×7×512, the score map is 7×7×21, and a 64×64 transposed convolution with stride 32 and padding 16 produces 224×224.

Exam traps

  • A transposed convolution is a learned upsample, not the mathematical inverse of a convolution; the name deconvolution is a misnomer.
  • Element-wise addition needs equal channel counts; concatenation needs equal spatial size. FCN skips use 1×1 convolutions to match channels when needed.
  • Semantic segmentation merges touching objects of the same class. Instance segmentation keeps them separate.
  • Pixel accuracy is misleading when one class dominates; mean IoU is the safer reported number.
  • The total upsample factor must equal the total stride: five stride-2 pools give a ×32 total, so FCN-16s uses ×2 then ×16 (still ×32 in total), not ×32 from the coarse map alone and never ×16 in total.

6.7 Video understanding and action recognition

Video understanding adds time to image recognition. A model must read what the scene looks like and how it moves, then name an action. A video is a stack of frames; a clip is a short run of them. Action recognition labels a clip, and temporal action localisation also gives start and end times. This is used in sports highlights, surveillance alerts, gesture interfaces and video search. The central problem is representation: appearance alone is not enough, because actions like sitting down are defined by change over time.

You need: 6.3 for the per-frame CNN and Optical flow and motion estimation for the flow images.

Video as a stack of frames

A video is a stack of T frames, each of size H×W×3. T is the number of frames; H and W are pixel height and width; 3 is the red, green and blue channels. Frame rate f is frames per second. A clip is a short run of L sampled frames. Frame sampling stride s is the step between kept frames: we keep frames 1, 1+s, 1+2s, … The number of sampled frames is N = ceil(T/s). Clip stride c is the step between the start positions of successive clips, counted in sampled frames. The number of clips of length L and clip stride c over N sampled frames is M = ⌊(N − L)/c⌋ + 1, for N ≥ L. Action recognition gives one label to a clip. Temporal action localisation gives a label and a start time and end time. Top-1 accuracy is the fraction of clips where the highest-scoring class is correct. This chapter uses the terms clip, frame, frame sampling stride and clip stride with these meanings throughout.

Three model families

3D convolution. A 2D kernel k×k slides over rows and columns. A 3D kernel k×k×k also slides over time, so one filter reads k consecutive frames, k rows and k columns. C3D uses 3×3×3 kernels and 3D pooling. The temporal receptive field is the number of input frames that can affect one output value; it grows with network depth. Two-stream. The spatial stream takes one RGB frame and a 2D CNN. The temporal stream takes a stack of optical flow images from Optical flow and motion estimation; each flow image stores horizontal and vertical displacement. The temporal stream has its own CNN. Each stream outputs a softmax score vector over C classes. Late fusion averages the two vectors: p = (p_spatial + p_temporal)/2. p is the final score vector, and its entries sum to 1. The label is argmax p. CNN + RNN. A CNN from 6.3 extracts one feature vector per sampled frame. An LSTM reads the sequence x₁, x₂, ..., x_L; the last hidden state h_L goes to a classifier. Temporal pooling is cheaper: average the feature vectors over time and classify once. I3D inflates 2D filters into 3D filters. UCF-101 has 101 action classes; Kinetics has several hundred. The metric is top-1 accuracy. At test time, several clips are sampled and their score vectors are averaged.

Test-time clips and scores

One clip is a short view of a longer video. At test time, sample several clips with overlap across the video and average their class score vectors. This is clip sampling at test time. Average scores, not features or pixels; the class order must stay fixed. The temporal stream needs optical flow, which is costly; some systems compute flow at low resolution or use an RGB-only 3D CNN. Action recognition returns one label for the clip. Temporal action localisation also returns start and end times. The two tasks share features but have different outputs. For a new video, fix the frame rate, frame sampling stride, clip length, clip stride and number of test clips before comparing models. Those numbers change the reported top-1 accuracy. A model trained on 16-frame clips is normally tested with 16-frame clips, because the classifier learned to read motion over exactly that many frames; changing the clip length changes what the network sees. Overlapping test clips reduce the chance that an action falls between clip boundaries.

Worked example

Question. A 10-second video at 30 frames per second. (a) How many frames? (b) If every 10th frame is kept, how many sampled frames? (c) With clip length 16 and clip stride 8 over the sampled frames, how many clips? (d) A spatial stream gives scores [0.7, 0.2, 0.1] and a temporal stream gives [0.4, 0.5, 0.1] for three actions. Which action wins after late fusion?

  1. (a) Frames = duration × frame rate = 10 s × 30 frames/s = 300 frames.
  2. (b) Sampling stride s = 10: sampled frames = ceil(300 / 10) = 30 frames.
  3. (c) Number of clips M = ⌊(N − L)/c⌋ + 1 = ⌊(30 − 16)/8⌋ + 1 = ⌊14/8⌋ + 1 = 1 + 1 = 2 clips.
  4. (d) Average scores per action: action 1 = (0.7 + 0.4)/2 = 0.55; action 2 = (0.2 + 0.5)/2 = 0.35; action 3 = (0.1 + 0.1)/2 = 0.1.
  5. The largest averaged score is 0.55 for action 1, so action 1 wins.

Exam traps

  • Classifying single frames and voting is not action recognition: 'sit down' contains standing and sitting poses, so the answer depends on order and motion.
  • Action recognition gives one label per clip; temporal action localisation gives start and end times as well. Do not write a time interval when the question asks only for a class.
  • Clip stride is in sampled frames, not seconds. The clip-count formula is M = ⌊(N − L)/c⌋ + 1; forgetting the +1 loses the last clip. Frame sampling stride s is a separate number, used in N = ceil(T/s).
  • Late fusion averages score vectors, not feature maps. Averaging features from two different CNNs is not the two-stream late-fusion rule.
  • Top-1 accuracy uses the highest score only; top-5 accuracy is different. Read which metric is asked.

6.8 Vision and language: image captioning and visual QA

Image captioning turns a picture into a sentence. Visual question answering (VQA) turns a picture plus a question into a short answer. Both put a language decoder after an image encoder: the encoder reads pixels, the decoder writes words or picks an answer. The same idea powers alt text for blind users, photo search in a phone gallery, and help desks that answer 'is the damage on the left side?'. Here is the encoder–decoder pipeline, soft attention, and why VQA is graded as classification.

You need: 6.3 for the CNN image encoder and a basic idea of sequence models; no other chapter is assumed.

Captioning: CNN encoder, word decoder

A captioning model has two parts. The image encoder is a CNN such as ResNet from 6.3. It gives either one pooled vector, for example 2048 numbers for the whole image, or a grid of 7×7 region vectors. Each region vector has 2048 numbers, so the grid has 7×7 = 49 vectors. The decoder is a sequence model: an LSTM (long short-term memory) or a Transformer. It writes one word at a time.

The decoder starts from a start token and stops when it emits an end token. At step t it reads the previous word's embedding and the image vector. It updates its hidden state ht and produces a score for every word in the vocabulary. A softmax turns the scores into probabilities.

p(wt | earlier words, v) = softmax(W ht + b)

wt is the word at step t; v is the image feature; ht is the decoder state after reading v and the earlier words; W and b are learned weights and bias; softmax gives a probability for each vocabulary word.

Training uses cross-entropy at every step. The true previous word is fed in, not the model's guess; this is teacher forcing. At test time the model uses its own past words. Greedy decoding takes the highest-probability word each step. Beam search keeps the best 3 to 5 partial sentences by total log-probability and returns the best finished sentence. Evaluation compares the generated sentence with reference sentences using BLEU, METEOR and CIDEr. BLEU counts matching word n-grams; METEOR adds recall and synonym matching; CIDEr weights n-grams by how informative they are across references.

Soft attention: where to look

A single pooled image vector loses location. Soft attention keeps the 49 region vectors v1 to v49 and lets the decoder choose where to look at each step. At step t the decoder has a hidden state ht−1. It scores each region with a learned comparison, for example si = ht−1T Wa vi.

αi = exp(si) / Σj exp(sj),  c = Σi αi vi

αi is the attention weight for region i; si is its score; c is the context vector; vi is region vector i; the softmax makes αi ≥ 0 and Σαi = 1. c is a weighted average of region vectors.

The context vector c is fed to the decoder along with the previous word. In a 'what colour is the shirt' question, weights move to the shirt region; in 'how many people', they spread over people. The weights are not a hard crop. They are a soft, differentiable average, so the whole model trains end to end.

Visual question answering

VQA input is an image plus a natural-language question. The image goes through a CNN to the same kind of features: one pooled vector or 49 region vectors. The question goes through word embeddings and an LSTM or Transformer to one question vector q, for example 1024 numbers.

  • Concatenation: [v; q], all numbers side by side.
  • Element-wise product: v ⊙ q, same length, shows matching dimensions.
  • Attention: q scores image regions, then c = Σαivi; the question decides where to look.

After combination, a small fully connected network and softmax classify the answer over a fixed answer vocabulary. The vocabulary has about one thousand to three thousand frequent answers, such as 'yes', 'no', 'two', 'red', 'left'. VQA is classification, not free generation. The model cannot produce a word outside that list.

This design has a known weakness: language priors and dataset bias. A language prior is a guess from the question text alone. A model may learn 'grass is green' and answer 'green' even when the image shows a blue car. A balanced test set and questions that need the image reduce this. Vision-language transformer models join image and text pretraining in one network; only a few universities teach that part, and it is outside this chapter.

Worked example

Question. A visual QA model uses 49 region vectors of 2048 numbers and a 1024-number question embedding. For one region, (a) what is the size of the concatenated vector used for the answer classifier? Three attention weights are 0.5, 0.3 and 0.2 over regions v1 = (1, 0), v2 = (0, 1), v3 = (1, 1). (b) Compute the context vector. (c) What must the three weights sum to?

  1. (a) The image part has 2048 numbers and the question part has 1024 numbers. Concatenation puts them side by side: 2048 + 1024 = 3072 numbers.
  2. (b) Use c = Σαivi. First component: 0.5×1 + 0.3×0 + 0.2×1 = 0.5 + 0 + 0.2 = 0.7. Second component: 0.5×0 + 0.3×1 + 0.2×1 = 0 + 0.3 + 0.2 = 0.5. So c = (0.7, 0.5).
  3. (c) 0.5 + 0.3 + 0.2 = 1.0. Softmax guarantees this before the weights are used, so the context vector is a weighted average.

Answer. (a) 3072 numbers. (b) c = (0.7, 0.5). (c) The weights sum to 1.0.

Exam traps

  • Attention weights are a softmax over locations, so they must sum to 1. A set that sums to 0.9 means the normalisation step was skipped.
  • VQA is graded by matching a short answer, not by how close a generated sentence looks.
  • Teacher forcing feeds the true previous word during training. At test time the model feeds its own past words, so a training-only habit can fail in inference.
  • A high BLEU score means n-gram overlap with references, not that the caption is true. A fluent generic sentence can score well and still miss the wrong detail.
  • Beam search with width 1 is greedy decoding. Width 3 to 5 keeps several partial sentences, but it does not guarantee the correct answer.

6.9 Generative models for images: GANs, VAEs, inpainting

Generative models learn the image distribution p(x) itself, not a label probability p(y|x). A GAN pits a generator against a discriminator; a VAE squeezes an image through a small latent vector and reconstructs it. Inpainting uses the same idea with a mask, so the model fills only the missing pixels. These tools remove objects and watermarks, restore old photographs, and complete damaged medical scans. This chapter shows the objectives, the training loop, and the failure modes that examiners test.

You need: convolutional encoders and decoders from 6.3, and upsampling layers from 6.6.

GAN: generator against discriminator

Discriminative models learn p(y|x): given pixels x, output a class y. Generative models learn p(x): the pattern of all images in the dataset, so they can draw new ones. A GAN does this with two networks. The generator G maps a noise vector z to an image G(z). Use z with 100 numbers drawn from a standard normal, mean 0 and variance 1. The discriminator D maps an image to a probability D(x) that the image is real, a number in [0,1].

Training alternates two steps. Step 1 fixes G and updates D to give high D(real) and low D(fake). Step 2 fixes D and updates G to make D(G(z)) high. A conditional GAN feeds extra information, a class label or a mask, to both G and D, so generation is controlled.

min over G max over D L(G,D) = E over real x [log D(x)] + E over noise z [log(1 − D(G(z)))]

L(G,D) is the minimax objective; D(x) is the discriminator probability that image x is real; G(z) is the fake image from noise z; E means average over the real dataset or the noise batch.

In code, use the non-saturating generator loss L_G = −log D(G(z)). Early in training D rejects fakes easily, so log(1 − D(G(z))) has a tiny gradient; −log D gives a strong gradient.

  • DCGAN rules in one line: strided convolutions in D, upsampling or transposed convolutions in G, batch normalisation, and no pooling.
  • Failure modes: unstable training, mode collapse where G repeats a few images, and loss values that do not measure image quality.

VAE: encoder, reparameterisation, KL

A VAE is an autoencoder with a probabilistic latent space. The encoder q(z|x) outputs μ and log σ² for each latent dimension, not one fixed vector. The decoder p(x|z) maps a latent vector back to an image. Sampling directly from N(μ, σ²) blocks gradients, so use reparameterisation: z = μ + σ ⊙ ε, where ε ~ N(0, I), σ = exp(0.5 log σ²), and ⊙ is elementwise multiplication. The random part is ε; gradients pass through μ and σ.

L_VAE = reconstruction + KL, with KL = −½ Σ (1 + log σ² − μ² − σ²)

reconstruction is binary cross-entropy or squared error summed over pixels; μ and σ² are the encoder outputs for one latent dimension; Σ sums over latent dimensions; log is natural log.

The KL term pulls q(z|x) toward N(0, I). It stops the encoder from giving every image a private, isolated latent point. A weight β on the KL term gives β-VAE; β > 1 gives more disentangled but blurrier samples. VAE samples are usually blurrier than GAN samples because squared-error or cross-entropy reconstruction averages plausible pixels. GANs can be sharp but unstable. VAEs are stable and give a usable latent space.

Inpainting: generation with a mask

Inpainting fills missing pixels. A binary mask M is 1 at known pixels and 0 at missing pixels. The model sees x ⊙ M, the image with holes set to zero, and M itself. Output is the completed image. This is generation conditioned on visible pixels: fill the missing part from the rest.

A context encoder is an encoder-decoder trained with two losses: reconstruction loss on the hole, and an adversarial loss from a discriminator that checks whether the completed image looks real. Reconstruction keeps the fill close to the original; the adversarial term makes it look natural, not just low error.

y = W · (x ⊙ M) / (1ᵀM) + b, then multiply by sum(1)/sum(M) if the window size must be preserved

y is the output at one location; W is the filter weights; x is the input patch; M is the mask patch; 1ᵀM counts the valid (known) pixels in the patch; b is the bias; sum(1)/sum(M) is a constant that restores the original window size when needed. Dividing by 1ᵀM renormalises the filter response so zeros from holes do not leak into the output.

  • Remove an object or a watermark from a photograph.
  • Restore an old family photograph with scratches or missing corners.
  • Fill missing regions in a medical scan before measurement.

Worked example

Question. A VAE has one latent dimension. The encoder gives μ = 0.5 and log σ² = −2; the sampled noise is ε = 1.2. (a) Find σ², σ and z. (b) Compute the KL term. (c) For the same batch, a GAN discriminator gives D(real) = 0.9 and D(fake) = 0.1. Compute the GAN objective log D(real) + log(1 − D(fake)) and the non-saturating generator loss −log D(fake). Use natural logarithms.

  1. (a) σ² = e^(−2) = 0.1353 ≈ 0.135.
  2. σ = √0.1353 = 0.3679 ≈ 0.368.
  3. z = μ + σ ε = 0.5 + 0.368 × 1.2 = 0.5 + 0.4416 = 0.9416 ≈ 0.942.
  4. (b) KL = −½ (1 + log σ² − μ² − σ²) = −½ (1 + (−2) − 0.5² − 0.135) = −½ (1 − 2 − 0.25 − 0.135) = −½ (−1.385) = 0.6925 ≈ 0.693.
  5. (c) log 0.9 = −0.1054. Also 1 − D(fake) = 0.9, so log(1 − D(fake)) = −0.1054. GAN objective = −0.1054 − 0.1054 = −0.2108 ≈ −0.211.
  6. Generator loss = −log 0.1 = −(−2.3026) = 2.3026 ≈ 2.303.

Answer. σ² ≈ 0.135, σ ≈ 0.368, z ≈ 0.942, KL ≈ 0.693, GAN objective ≈ −0.211, and generator loss ≈ 2.303, using natural logarithms.

Exam traps

  • Do not call a low discriminator loss good image quality. GAN loss measures separation between the current real and fake sets and has no absolute scale. Use FID or human inspection.
  • In the VAE loss, the KL term and reconstruction term pull in opposite directions. When the KL term dominates, the encoder's posterior collapses toward N(0, I), the latent vector stops carrying information about the image, and reconstructions turn blurry; when the reconstruction term dominates, the prior is ignored. Report both and look at samples.
  • Alternate the updates: do not update G and D in one combined step. D must be fixed while G updates, and G fixed while D updates.
  • A plain zero-filled mask leaks zeros through convolutions. Use partial convolution or gated convolution to renormalise by valid pixels.
  • log σ² is not σ². Exponentiate it: σ = exp(0.5 log σ²), not exp(log σ²).

Takeaways

  1. Recognition is a decision in feature space: pick the class whose region the measured vector falls into.
  2. Minimum distance needs only class means, k-NN needs all the training data, and Bayes needs class-conditional densities; they trade storage and assumption for accuracy.
  3. A CNN replaces hand-designed features with kernels learned by backpropagation, so the same network works on faces and on circuit-board defects.
  4. Depth helps only when gradients can flow; residual connections made very deep networks trainable and are the reason ResNet won ImageNet 2015.
  5. Two-stage detectors (R-CNN family) propose then classify, which is accurate; single-stage detectors (YOLO, SSD) classify and regress boxes on a grid in one pass, which is fast.
  6. Semantic segmentation is per-pixel classification: keep the feature map spatial, then upsample the coarse scores back to image size.
  7. Video needs motion as well as appearance, so models read stacks of frames, optical flow, or 3D convolutions over time.
  8. Captioning and visual QA join a vision encoder to a language decoder, turning a feature vector into a sequence of words.
  9. GANs and VAEs learn the image distribution itself; inpainting is the same model run with the surviving pixels fixed as the condition.

Glossary

Backpropagation
The chain rule applied layer by layer to get the gradient of the loss with respect to every weight.
Batch normalisation
Normalising layer inputs by the mini-batch mean and variance, then scaling and shifting with learned parameters.
Confidence score
The number a detector outputs for how likely a box is to contain an object of the predicted class.
Cross-entropy loss
The training loss −Σ y log ŷ that punishes confident wrong predictions the most.
Discriminant function
A function gᵢ(x) per class such that x is assigned to the class with the largest value.
Feature pyramid
Predicting at several resolutions of the same backbone so both small and large objects are found.
Focal loss
A loss that down-weights easy, numerous background examples so hard examples dominate training.
Instance segmentation
Labelling pixels per object instance as well as per class, for example Mask R-CNN.
Latent space
The low-dimensional vector space in which a generative model represents images.
Long short-term memory (LSTM)
A recurrent unit with gates that carries information across many time steps without vanishing gradients.
Mahalanobis distance
Distance scaled by the class covariance, d² = (x − m)ᵀΣ⁻¹(x − m), which removes correlation between features.
Mean average precision (mAP)
The mean over classes of the area under the precision–recall curve at a stated IoU threshold.
Mode collapse
The failure of a GAN generator to cover the data distribution, producing only a few kinds of output.
Padding
Extra border pixels added around the input so kernel sliding does not shrink the map.
Pooling
A fixed operation, usually max or average, over small windows that shrinks a feature map.
Recognition
Deciding which pattern class an observed feature vector belongs to.
Selective search
A classical region-proposal method that merges similar neighbouring segments into candidate boxes.
Semantic segmentation
Labelling every pixel of an image with a class, without separating individual instances.
Skip connection
Wiring a fine-resolution early feature map into a later layer to recover spatial detail.
Softmax
A layer turning K scores into probabilities that are positive and sum to one.
Stride
The step, in pixels, by which a kernel moves across the input; stride 2 halves the output size.
Supervised learning
Fitting a model from inputs paired with known correct labels.
Transfer learning
Starting from weights trained on a large dataset and fine-tuning them on a small target dataset.
Upsampling
Increasing the spatial size of a feature map, by interpolation or by a transposed convolution.
