3.1 3D object representation: polygon surfaces and tables

A 3D solid can be stored as a set of flat polygon faces. Instead of writing every face as its own list of points, keep one vertex table, one edge table and one polygon table. Each vertex, edge and face is listed once, and the other tables refer to it by index. A cube then needs 8 vertex records, not 24 point copies. Indexing saves memory, keeps shared edges consistent, and lets programs find neighbours quickly. Graphics cards, game engines and CAD tools use this idea.

You need Unit 1 for output primitives and Unit 2 for 3D coordinates.

Faces, vertices and the sharing problem

A polygon surface representation stores a solid as flat faces. A face is a closed loop of straight edges. Each edge joins two vertices. A vertex is a point (x, y, z). The simplest storage writes each face separately: P1 = (V1, V2, V3, V4). That is easy to draw but wasteful. A cube has 8 vertices, 12 edges and 6 faces. Written face by face it holds 6 × 4 = 24 vertex references, even though only 8 points exist.

The shared table fixes this. A vertex table lists each point once. An edge table lists each edge once, as two vertex indices. A polygon table lists each face as a list of edge indices. If two faces touch along an edge, both name the same edge record. No coordinate is copied. When you move one vertex, every face that uses it moves together. Indexed meshes are the normal form in file formats and graphics hardware.

The three tables and vertex ordering

The vertex table holds x, y, z per row. The edge table adds the two faces that share the edge. The polygon table adds face attributes: colour, surface normal, material and texture index. A row can also point to a plane equation; that belongs to 3.2.

List the face vertices counterclockwise as seen from outside the solid (right-hand rule in a right-handed x, y, z frame). Then (V2−V1)×(V3−V2), the cross product of the first two edge vectors, points outward. Reversing the order flips the normal and turns the face inside out. In a closed surface each edge has exactly two faces. An edge with one face is a boundary; an edge with three or more is non-manifold.

V − E + F = 2

V is the number of vertices, E the number of edges, F the number of faces, for a closed surface with no holes, shaped like a sphere.

Use this as a quick check after building the tables. A cube gives 8 − 12 + 6 = 2. A square pyramid gives 5 − 8 + 5 = 2. If the result is not 2, you missed a face, counted an edge twice, or the mesh has a hole.

Worked example

Question. A square pyramid has base vertices V1=(1,1,0), V2=(−1,1,0), V3=(−1,−1,0), V4=(1,−1,0) and apex V5=(0,0,3). Build the vertex, edge and polygon tables. Count the vertex references used by face-by-face storage, and check Euler's formula.

  1. Vertex table has 5 rows: V1=(1,1,0), V2=(−1,1,0), V3=(−1,−1,0), V4=(1,−1,0), V5=(0,0,3).
  2. Base edges: E1=V1V2, E2=V2V3, E3=V3V4, E4=V4V1. Slant edges: E5=V1V5, E6=V2V5, E7=V3V5, E8=V4V5. Edge table has 8 rows.
  3. Faces: base P1=(E4,E3,E2,E1). Sides: P2=(E1,E6,E5), P3=(E2,E7,E6), P4=(E3,E8,E7), P5=(E4,E5,E8). Polygon table has 5 rows.
  4. Edge-face links: E1→P1,P2; E2→P1,P3; E3→P1,P4; E4→P1,P5; E5→P2,P5; E6→P2,P3; E7→P3,P4; E8→P4,P5.
  5. Euler check: V−E+F = 5−8+5 = 2. The surface is closed.
  6. Face by face the coordinates are written 16 times (base 4, sides 3 each). The vertex table writes each of the 5 points once, so 11 coordinate triples are no longer duplicated. The index work moves elsewhere: the edge table stores 16 vertex indices (2 per edge) and the polygon table stores 16 edge indices (4 + 4×3). The gain is no duplicated coordinates and shared-edge consistency, not fewer numbers.

Answer. The pyramid uses 5 vertices, 8 edges and 5 faces; face-by-face storage writes 16 coordinate triples while the vertex table writes 5, and 5 − 8 + 5 = 2 confirms a closed surface. The edge and polygon tables store index entries instead.

Exam traps

  • Quoting 24 vertices for a cube instead of 8. The value 24 counts vertex references, not distinct points.
  • Storing every face as its own coordinate list, so a shared edge is duplicated and a later edit creates a crack.
  • Forgetting that Euler's V − E + F = 2 applies to a closed surface; an open box will not give 2.
  • Using clockwise order for one face and counterclockwise for another, so neighbouring normals disagree.
  • Treating the face references in an edge table as extra vertices; they are indices into the polygon table.

3.2 Polygon meshes and plane equations

A solid model is often a skin of flat polygons. Each face is planar, so it obeys Ax + By + Cz + D = 0. This gives the face normal, distances, and a side test. Renderers use it for back-face removal, shading (3.7), and BSP splitting (3.6).

You need Chapter 3.1 for vertex and polygon tables, and Unit 2 for 3D vectors, dot products and cross products.

Meshes as vertex and index arrays

A polygon mesh is a set of flat polygons sharing vertices and edges, so the surface has no gaps. A triangle mesh uses triangles; a quad mesh uses four-sided faces.

Store two arrays: a vertex array of 3D positions and an index array of integer triples. Each triple names one triangle's three vertices. A cube needs eight vertex entries, and each vertex is transformed once.

V − E + F = 2

V vertices, E edges, F faces of a closed surface with no holes; for a closed triangle mesh, E = 3V − 6 and F = 2V − 4, useful for buffer sizing.

The plane equation of one face

Three points P1, P2, P3 not on one line fix a plane. Edges u = P2 − P1 and v = P3 − P1 lie in it. Their cross product n = u × v is perpendicular to both, so it is the face normal.

n = (P2 − P1) × (P3 − P1) = (A, B, C); D = −(A x1 + B y1 + C z1); Ax + By + Cz + D = 0

(x1, y1, z1) is a face point such as P1; A, B, C are components of n.

List vertices counter-clockwise seen from outside. Then n is the outward normal. For eye E = (Ex, Ey, Ez), evaluate f(E) = A·Ex + B·Ey + C·Ez + D. If f(E) > 0, the eye is on the normal side: the face points toward the camera and is drawn. If f(E) < 0, it points away and can be culled.

Divide by |n| = √(A² + B² + C²). The unit normal is (A, B, C)/|n|. The true signed distance of point P is d_perp = (A·x + B·y + C·z + D)/|n|. At the origin the value is D, so the perpendicular distance from the origin to the plane is |D|/|n|.

A four-vertex face is planar only if all four points satisfy one equation. If not, split it into two triangles. Keep A, B, C, D: the same plane is reused for clipping and BSP splitting.

Worked example

Question. Find the plane through P1 = (1, 0, 0), P2 = (0, 1, 0), P3 = (0, 0, 1). Give A, B, C, D, unit normal, and test P4 = (0, 0, 0).

  1. u = P2 − P1 = (−1, 1, 0), v = P3 − P1 = (−1, 0, 1).
  2. n = u × v = (1, 1, 1), so A = B = C = 1.
  3. D = −(1×1 + 1×0 + 1×0) = −1; plane x + y + z − 1 = 0.
  4. |n| = √3 ≈ 1.732; unit normal (0.577, 0.577, 0.577).
  5. At P4: 0 + 0 + 0 − 1 = −1 < 0, so P4 is behind the face.

Answer. Plane x + y + z − 1 = 0, normal (1, 1, 1), unit normal (0.577, 0.577, 0.577); origin tests −1, behind.

Exam traps

  • Writing D = +n·P1 instead of D = −n·P1.
  • Reporting Ax + By + Cz + D as a distance. It equals |n| times the signed distance, so divide by |n| first.
  • Assuming every four-vertex face is planar; split non-coplanar quads.
  • Swapping cross-product order (P3−P1)×(P2−P1); this flips the normal and every side test.
  • Forgetting that the sign, not the size, of Ax + By + Cz + D decides the side.

3.3 Quadric surfaces and blobby objects

A quadric surface is a curved shape whose points satisfy a second-degree equation in x, y, z. A few numbers give a sphere, ellipsoid, cone or cylinder instead of thousands of polygons. A blobby object works the other way: each centre spreads a soft density cloud, the clouds add, and the surface appears where the total crosses a threshold. Both store and hit-test curved shapes cheaply, in CAD parts, game props, ray tracers and cartoon gel.

You need Chapter 3.2 for surface normals and the plane equation, and Unit 2 for the translation that moves a centre.

Quadrics: second-degree surfaces

A quadric is the set of points (x, y, z) that satisfy one polynomial equation of degree two.

Ax² + By² + Cz² + Dxy + Eyz + Fxz + Gx + Hy + Iz + J = 0

x, y, z are the point coordinates; A to J are constants, with at least one of A to F nonzero.

The coefficients decide the type. Centre the surface at the origin and drop the cross terms to get the standard forms below. For a moved surface, replace x by x − x₀ and so on.

  • The torus (a ring) satisfies a degree-four equation, so it is not a quadric.
  • Cones, cylinders, paraboloids and hyperboloids extend to infinity, so they must be clipped to a finite patch. The sphere and ellipsoid are bounded and need no clipping.

Blobby objects: a field cut at a threshold

A blob, also called a metaball, comes from a density field. Each centre cᵢ spreads a soft cloud e^(−d²), where d is the distance from the point to cᵢ. The clouds add, and the visible surface is the level where the total equals a chosen threshold T.

F(p) = Σᵢ e^(−|p − cᵢ|²) = T

p is a point in space, cᵢ is the i-th centre, T is the threshold. A larger T gives a smaller blob.

For one blob the sum is one term: e^(−r²) = T, so r = √(−ln T). At T = 0.5 this gives r = 0.833 units. Lowering T lets each blob grow.

Bring two centres close and their tails add. The field between them rises above T, and the separate blobs join with a smooth neck. That is why blobs suit water drops, jelly and cartoon characters. Superquadrics, which use |x|^n terms, are a cousin.

Worked example

Question. (a) Write the implicit equation of the sphere of radius 5 centred at (2, 3, 1), expanded into general quadric form. (b) Two blobs sit at (0,0,0) and (4,0,0), with density e^(−d²) and threshold T = 0.5. Find the radius of a single blob and the field value at the midpoint (2,0,0), and decide whether the blobs merge.

  1. Sphere form: (x − 2)² + (y − 3)² + (z − 1)² = 25.
  2. Expand: x² − 4x + 4 + y² − 6y + 9 + z² − 2z + 1 = 25.
  3. Collect: x² + y² + z² − 4x − 6y − 2z + 14 − 25 = 0.
  4. So x² + y² + z² − 4x − 6y − 2z − 11 = 0, that is A = B = C = 1, G = −4, H = −6, I = −2, J = −11.
  5. Single blob: e^(−r²) = 0.5 gives r² = 0.693, so r = 0.833 units.
  6. Midpoint (2,0,0) is distance 2 from each centre, so each term is e^(−4) = 0.01832.
  7. Sum at the midpoint: 0.01832 + 0.01832 = 0.0366, far below T = 0.5.
  8. The midpoint lies outside the surface, so the two blobs stay separate.

Answer. Sphere x² + y² + z² − 4x − 6y − 2z − 11 = 0; single blob radius 0.833 units; midpoint field 0.037, below 0.5, so the blobs stay separate.

Exam traps

  • Calling the torus a quadric. A ring needs a degree-four equation.
  • Forgetting to clip an unbounded quadric. A cone or cylinder then fills the whole scene.
  • Confusing the threshold with the radius. The radius comes from r = √(−ln T), and a smaller T gives a bigger blob.
  • A sign slip while expanding. The constant term is x₀² + y₀² + z₀² − r², here −11, not +11.
  • Treating two blobs as independent spheres. The field is a sum, so the surface bulges toward the other centre and merges when the midpoint value reaches T.

3.4 Bezier curves and surfaces

A Bezier curve is a smooth curve shaped by a small set of control points. The curve does not usually pass through the inner points; it is pulled toward them by blending functions. This gives designers an easy handle: move a point, and the curve bends. Bezier curves are used in font outlines, car body panels, animation paths and vector drawing software. The same idea extends to a Bezier surface, where a grid of control points shapes a smooth patch.

You need: 3.1 for how curves become polygon edges, and Unit 2 for affine transforms of control points.

Bernstein form

Take n+1 control points P0 to Pn in the plane or in space. The degree n Bezier curve is a weighted sum of these points. The weight of Pi at parameter t is the Bernstein polynomial. At t = 0 only P0 has weight 1, and at t = 1 only Pn has weight 1, so the curve always starts at P0 and ends at Pn.

B(t) = Σ<sub>i=0</sub><sup>n</sup> P<sub>i</sub> C(n,i) t<sup>i</sup> (1−t)<sup>n−i</sup>, 0 ≤ t ≤ 1

B(t) is the point on the curve at t; Pi is control point i; C(n,i) is the binomial coefficient n!/(i!(n−i)!); t is the parameter.

For n = 3 the binomial coefficients are C(3,0) = 1, C(3,1) = 3, C(3,2) = 3, C(3,3) = 1. These are the 1, 3, 3, 1 coefficients of a cubic. A cubic Bezier is therefore a weighted average of four points. The inner control points P1 and P2 pull the curve, but the curve normally does not pass through them.

B(t) = (1−t)<sup>3</sup>P<sub>0</sub> + 3t(1−t)<sup>2</sup>P<sub>1</sub> + 3t<sup>2</sup>(1−t)P<sub>2</sub> + t<sup>3</sup>P<sub>3</sub>

t is the curve parameter; P0 to P3 are the four control points.

De Casteljau construction

De Casteljau's algorithm evaluates a Bezier point by repeated linear interpolation. Start with the control polygon P0 to Pn. For each neighbouring pair, take the point a fraction t along the segment. This makes n new points. Repeat on the new list until one point remains. That last point is B(t). When t = 0.5, every step is a midpoint.

  1. List the n+1 control points P0, P1, ..., Pn.
  2. For each adjacent pair, form Pi(1) = (1−t)Pi + tPi+1. The superscript (1) is the level number, not an exponent.
  3. Replace the old list with the new list and repeat until one point remains.
  4. The final point is B(t). At t = 0.5 each step is just a midpoint.

The figure shows a cubic at t = 0.5. P0 to P3 give Q0, Q1, Q2; these give R0, R1; these give S0 = (2, 1.5), a point on the curve.

Properties, surfaces and joins

A Bezier curve has a fixed set of useful properties.

  • It interpolates its end points: B(0) = P0 and B(1) = Pn.
  • The tangent at t = 0 is along P1 − P0; the tangent at t = 1 is along Pn − Pn−1. For a cubic the derivatives are 3(P1 − P0) and 3(P3 − P2).
  • The curve lies inside the convex hull of its control points.
  • Affine invariance: apply a translation, rotation, scaling or shear to all control points, and the transformed curve is the same as transforming every curve point.
  • No local control: moving one control point changes the whole curve except the end points that are not moved, because every Bernstein weight is nonzero for 0 < t < 1.

A Bezier surface is the tensor product of two Bezier curves. A grid of control points, called a control net, replaces the control polygon.

B(u,v) = Σ<sub>i=0</sub><sup>m</sup> Σ<sub>j=0</sub><sup>n</sup> P<sub>i,j</sub> C(m,i) u<sup>i</sup>(1−u)<sup>m−i</sup> C(n,j) v<sup>j</sup>(1−v)<sup>n−j</sup>

Pi,j is a control point in the net; u and v run from 0 to 1; m and n are the degrees in the two directions.

Two Bezier curves join smoothly. C0 continuity needs the last point of the first curve to equal the first point of the second. For two cubics with P3 = Q0, C1 continuity needs Q1 − Q0 = P3 − P2, so the tangent vectors match. If only the tangent direction matches, that is weaker geometric continuity, not C1.

Worked example

Question. A cubic Bezier curve has control points P0 = (0, 0), P1 = (1, 2), P2 = (3, 2), P3 = (4, 0). Find the curve point at t = 0.5 using the Bernstein form. Verify it by de Casteljau. Give the tangent vectors at t = 0 and t = 1.

  1. Degree n = 3. The coefficients are C(3,0) = 1, C(3,1) = 3, C(3,2) = 3, C(3,3) = 1. At t = 0.5 the weights are 1/8, 3/8, 3/8, 1/8.
  2. Bernstein form: B(0.5) = (1/8)(P0 + 3P1 + 3P2 + P3).
  3. Compute terms: P0 = (0, 0); 3P1 = (3, 6); 3P2 = (9, 6); P3 = (4, 0). Sum = (16, 12). Multiply by 1/8: B(0.5) = (2, 1.5).
  4. De Casteljau at t = 0.5: Q0 = (P0 + P1)/2 = (0.5, 1); Q1 = (P1 + P2)/2 = (2, 2); Q2 = (P2 + P3)/2 = (3.5, 1).
  5. Next level: R0 = (Q0 + Q1)/2 = (1.25, 1.5); R1 = (Q1 + Q2)/2 = (2.75, 1.5). Final: S0 = (R0 + R1)/2 = (2, 1.5). This matches.
  6. Tangent at t = 0: B'(0) = 3(P1 − P0) = 3(1, 2) = (3, 6), direction (1, 2). Tangent at t = 1: B'(1) = 3(P3 − P2) = 3(1, −2) = (3, −6), direction (1, −2).

Answer. The point is (2, 1.5); tangents are (3, 6) at t = 0 and (3, −6) at t = 1.

Exam traps

  • Assuming the curve passes through every control point. A Bezier curve interpolates only its two end points. A repeated end point (P0 = P1) only makes the start tangent zero; it does not create a new interpolation point, and repeating an inner point does not make the curve pass through it.
  • Using degree n equal to the number of control points. With n+1 points, the degree is n, which is one less than the point count.
  • Dropping the 1, 3, 3, 1 coefficients in the cubic case. They come from the binomial coefficients and are not optional.
  • Forgetting the factor n in the derivative. The tangent at t = 0 is n(P1 − P0), not just P1 − P0.
  • Confusing a Bezier control polygon with a Bezier surface control net. The net is a grid for a tensor-product surface.

Moving an inner control point changes the whole interior of the Bezier curve, because the Bernstein weight of that point is nonzero for every t between 0 and 1. A B-spline has short-range basis functions, so only a small piece changes.

C0: P3 = Q0. C1: the derivatives match, so 3(P3 − P2) = 3(Q1 − Q0), giving Q1 − Q0 = P3 − P2.

Understand Why is de Casteljau's algorithm numerically stable? 3 marks

Every step is a convex combination of two points already in the convex hull. The values stay inside the hull, with no large cancellation or growth, so evaluation is stable.

3.5 B-spline curves and surfaces

A B-spline is a curve built from control points and a knot vector. Unlike a Bezier curve, each control point influences only a short span, so moving one point changes a small piece of the shape. The knot vector sets where the curve starts, ends and joins. This local control is why B-splines and their rational form NURBS are used in CAD, font outlines, car body design and animation paths.

You need: Chapter 3.4 for control points, blending and the Bezier special case, and Unit 2 for matrix forms.

Knot vector and counting rule

A B-spline of degree p has control points P₀, P₁, …, Pₙ and a knot vector U = (u₀, u₁, …, uₘ). The knots are non-decreasing: u₀ ≤ u₁ ≤ … ≤ uₘ. A knot span is the interval between two consecutive knots, written [ui, ui+1). The order is k = p + 1. A cubic curve has p = 3 and order 4.

C(t) = Σ<sub>i=0</sub><sup>n</sup> N<sub>i,p</sub>(t) P<sub>i</sub>

C(t) is the point at parameter t; Ni,p(t) is the degree-p basis for control point i; Pi is control point i; n+1 is the number of control points.

Counting rule: number of knots = number of control points + p + 1. In indices, m = n + p + 1, because U has m+1 entries and there are n+1 control points.

In the figure p = 3 and U has 9 knots, so m = 8. Then 8 = n + 3 + 1, n = 4, and there are 5 control points P₀ to P₄.

Uniform knots are equally spaced. Open or clamped knots repeat the first and last knot p+1 times; the curve then starts at P₀ and ends at Pₙ. Non-uniform knots have uneven spacing and allow tighter control in chosen regions.

Basis recursion and continuity

The basis functions are built by recursion. At degree 0, Ni,0(t) = 1 when ui ≤ t < ui+1, and 0 outside; the very last span is usually taken closed at the right end. For p > 0:

N<sub>i,p</sub>(t) = ((t − u<sub>i</sub>) / (u<sub>i+p</sub> − u<sub>i</sub>)) N<sub>i,p−1</sub>(t) + ((u<sub>i+p+1</sub> − t) / (u<sub>i+p+1</sub> − u<sub>i+1</sub>)) N<sub>i+1,p−1</sub>(t)

Ni,p(t) is the basis function; ui are knots; t is the curve parameter; a term with denominator 0 is taken as 0.

Take 0/0 as 0. Each Ni,p is nonzero only on p+1 knot spans. This short support gives local control: moving Pi changes the curve only where its basis is nonzero. A Bezier control point moves the whole curve.

At a knot of multiplicity s, the curve is C(p−s) when s ≤ p. For cubic p = 3: s = 1 gives C², s = 2 gives C¹, s = 3 gives C⁰, a corner. At an end, s = p+1 clamps the curve to the end control point.

A Bezier curve is the special case p = 3 with U = (0,0,0,0,1,1,1,1). The four knots at each end make the B-spline basis become the Bernstein basis.

Surfaces and NURBS

A B-spline surface is a tensor product of two B-spline curves. It has a control net Pi,j, degrees p in u and q in v, and knot vectors U and V.

S(u,v) = Σ<sub>i=0</sub><sup>n<sub>u</sub></sup> Σ<sub>j=0</sub><sup>n<sub>v</sub></sup> N<sub>i,p</sub>(u) N<sub>j,q</sub>(v) P<sub>i,j</sub>

S(u,v) is a point on the surface; Ni,p(u) and Nj,q(v) are basis functions; Pi,j is a 3D control point in the control net; p and q are the degrees in u and v; nu+1 and nv+1 are the numbers of control points in the u and v directions.

Continuity in u follows the same multiplicity rule; in v use q. Surfaces are used for car bodies, aircraft skins and character models.

CAD software often stores them as NURBS: Non-Uniform Rational B-Spline. A NURBS adds a weight wi to each control point and divides by the weighted sum. This lets one curve represent circles and free-form shapes exactly. We stop at that one line.

Worked example

Question. For a cubic B-spline with p = 3 and knot vector U = (0,0,0,0,1,2,2,2,2), find the number of control points and the continuity at each knot. State whether the ends are clamped.

  1. Degree p = 3. U has 9 entries, so highest index m = 8.
  2. Counting rule: m = n + p + 1. So 8 = n + 3 + 1 = n + 4, giving n = 4.
  3. Number of control points is n + 1 = 5, named P₀ to P₄.
  4. Multiplicities: 0 appears 4 times, 1 appears once, 2 appears 4 times.
  5. At u = 0, s = 4 = p+1, so the start is clamped and the curve begins at P₀.
  6. At u = 1, s = 1 ≤ p, so continuity is C(3−1) = C².
  7. At u = 2, s = 4 = p+1, so the end is clamped and the curve ends at P₄. It is an end knot, not an interior join.

Answer. 5 control points; C² at the interior knot u = 1; both ends u = 0 and u = 2 are clamped.

Exam traps

  • Degree p and order k are not the same: k = p + 1.
  • The knot count is not the control point count. For n+1 control points and degree p, the knot vector has n+p+2 entries, i.e. control points + p + 1.
  • A B-spline does not pass through all control points. Only clamped end points are interpolated; the rest pull the curve.
  • At a knot of multiplicity s, continuity is C^(p−s), not C^s. For cubic, s = 3 gives C⁰, not C³.
  • A Bezier curve is a clamped B-spline with end multiplicity p+1, not a uniform B-spline.

3.6 Hidden surface removal: Z-buffer and BSP trees

Every 3D scene has surfaces behind surfaces. Hidden surface removal decides which surface the eye sees at each pixel. The Z-buffer works in image space: it keeps one depth value per pixel beside the colour, and a new fragment replaces the old only if it is nearer. A BSP tree works in object space: polygon planes split space into front and back, so polygons are drawn back to front. Games, CAD viewers and map renderers use both.

You need: Chapter 3.2 for plane equations and face normals; Unit 2 for projection to screen coordinates.

Painter's algorithm and the Z-buffer

An object-space method decides visibility from polygon geometry. The painter's algorithm sorts polygons by distance and draws far to near, so near paint covers far paint. It is cheap but fails when three polygons overlap cyclically, because no single order is correct.

The Z-buffer is an image-space method. It stores a colour buffer and a depth buffer with one depth per pixel. If smaller z means nearer, initialise every depth to the far value z_far. Rasterise each polygon. At each pixel, compare the polygon's depth z with the stored depth. If z < depth[x,y], write the polygon's colour and set depth[x,y] = z. Otherwise keep the old pixel.

z = z₁ + (x − x₁)(z₂ − z₁) ÷ (x₂ − x₁)

x₁ and x₂ are scan-line endpoints; z₁ and z₂ are their depths; z is the interpolated depth at x.

  • No sorting: polygons may arrive in any order.
  • Works for interpenetrating polygons.
  • Costs one depth array, for example 1920 × 1080 × 4 bytes ≈ 8.3 MB.
  • Cannot blend transparency through one depth value; polygon edges alias.

BSP trees in object space

A BSP tree is built once for a static scene. Choose one polygon as root. Its plane Ax + By + Cz + D = 0 divides space; A, B, C are the normal components and D fixes the offset. Every other polygon is wholly in front, wholly behind, or crossing. A crossing polygon is split along the plane into two new polygons.

Put front polygons in the front subtree and back polygons in the back subtree; recurse. To display, find which side of each plane holds the eye. Draw the far subtree first, then the root polygon, then the near subtree. This gives back-to-front order without a depth buffer.

BSP build cost and extra polygons are paid once; per-frame sorting is avoided. It suits fixed geometry such as building interiors. Exam questions usually ask for classification and drawing order rather than full BSP construction with polygon splitting.

Worked example

Question. At pixel (5,5), polygon A gives z_A = 0.6 and polygon B gives z_B = 0.4. The depth buffer starts at 1.0; smaller z is nearer. (a) Trace both tests and give the final colour and depth. (b) P1 lies in plane x = 2, P2 at x = 5, P3 at x = 0. Build the BSP tree and give the drawing order for an eye at x = 10.

  1. Start: depth[5,5] = 1.0, colour empty.
  2. A: 0.6 < 1.0, so write A's colour, depth = 0.6.
  3. B: 0.4 < 0.6, so overwrite with B's colour, depth = 0.4.
  4. Final pixel: B's colour, depth 0.4.
  5. BSP root P1: P3 at x = 0 is back; P2 at x = 5 is front.
  6. Eye at x = 10 is front of P1, so draw back P3, root P1, front P2.
  7. Order: P3, P1, P2.

Answer. Final pixel: B's colour, depth z = 0.4; BSP drawing order P3, P1, P2.

Exam traps

  • Using larger z as nearer without stating the convention.
  • Not resetting the depth buffer to z_far each frame.
  • Forgetting that a BSP split creates two polygons and changes the count.
  • Believing the Z-buffer sorts polygons; it tests pixels.
  • Using one Z-buffer depth for transparent surfaces and expecting correct blending.

3.7 Lighting and shading: Phong and Gouraud

Lighting turns geometry and light into a colour. It needs the surface normal, the direction to each light and the direction to the eye. Shading spreads that colour over a polygon. Gouraud computes light at the vertices and interpolates the colours. Phong interpolates the vertex normals, normalises them at each pixel and lights that pixel. The difference decides whether a shiny object shows a clean highlight or a dull smear. Games, CAD viewers and phone 3D apps choose between these costs every frame.

You need: face normals from Chapter 3.2 and visibility from Chapter 3.6.

Light sources and the normal

Lighting starts from vectors, not pixels. At a surface point, N is the unit normal, L is the unit vector from the point towards a light, and V is the unit vector from the point towards the viewer. N·L is 1 when the surface faces the light directly and 0 at grazing light. Negative values mean the light is behind the surface and are clamped to 0. R is the mirror direction of L about N: R = 2(N·L)N − L. R·V is large when the eye lies near the mirror direction, which is where a highlight appears.

Three light types cover most scenes. Ambient light has no position or direction; it gives a constant base so faces in shadow are not black. A point light has a position; its intensity at distance d falls with attenuation, often 1/(a0+a1d+a2d²), where a0,a1,a2 are attenuation constants. A directional light is so far away that all rays are parallel; L is the same everywhere and there is no distance attenuation. Sunlight is treated as directional; a table lamp as point.

Phong reflection model

The Phong reflection model combines three responses. Ambient is a constant base. Diffuse is light scattered equally from a matte surface; it follows N·L. Specular is the mirror-like highlight; it follows R·V raised to n. The exponent n sets highlight size: small n gives a broad dull spot, large n gives a small sharp spot. ks sets highlight strength. Summing over lights allows several lamps.

I = k<sub>a</sub> I<sub>a</sub> + Σ [ k<sub>d</sub> I<sub>l</sub> (N·L) + k<sub>s</sub> I<sub>l</sub> (R·V)<sup>n</sup> ]

I is the final intensity (or colour channel); ka is the ambient reflection coefficient; Ia is ambient light intensity; kd is the diffuse coefficient; Il is the intensity of light l at the point (includes attenuation for a point light); ks is the specular coefficient; N is the unit surface normal; L is the unit vector to the light; R = 2(N·L)N − L; V is the unit vector to the viewer; n is the specular exponent. Use max(0, N·L) and max(0, R·V); the sum is over all lights l.

Use max(0, N·L) and max(0, R·V). If N·L is negative the light is behind the surface and contributes no diffuse term. Normalise N, L, R and V before taking dot products; a non-unit N changes the cosine and the highlight. For a point light, Il is reduced by attenuation; for directional light it is not. The ambient term is often added once, not once per light.

Flat, Gouraud and Phong shading

Flat shading uses one normal per face, computes one colour and fills the whole polygon with it. It is cheap and correct for a true flat face, but a curved mesh looks faceted. Gouraud shading computes the Phong model at each vertex using that vertex normal, then interpolates the vertex colours along edges and across the polygon. It is cheap and removes most faceting. It cannot create a highlight smaller than the polygon, because no vertex may lie in the highlight. Linear colour interpolation can also produce Mach bands, false bright or dark bands at intensity edges.

Phong shading interpolates the vertex normals across the polygon, normalises the interpolated normal at each pixel, and evaluates the reflection model there. It catches small highlights and gives smooth shading, at the cost of a lighting calculation per pixel. Gouraud needs one lighting calculation per vertex plus interpolation. Worked example

Question. A surface point has unit normal N = (0, 0.6, 0.8). A light direction is L = (0, 0, 1). Take ka Ia = 0.2, kd = 0.7, Il = 1.0, ks = 0.5, specular exponent n = 10 and R·V = 0.8. Find the Phong intensity. Also find the Gouraud intensity a quarter of the way along an edge whose vertex intensities are 0.2 and 0.6.

  1. Check N is unit: 0² + 0.6² + 0.8² = 0 + 0.36 + 0.64 = 1.00.
  2. Compute N·L = 0×0 + 0.6×0 + 0.8×1 = 0.80. It is positive, so the diffuse term is active.
  3. Ambient term = ka Ia = 0.2.
  4. Diffuse term = kd Il (N·L) = 0.7 × 1.0 × 0.80 = 0.56.
  5. Compute 0.8¹⁰ = 0.1074 (to 4 d.p.). Specular term = ks Il (R·V)¹⁰ = 0.5 × 1.0 × 0.1074 = 0.0537, about 0.054.
  6. Total I = 0.2 + 0.56 + 0.054 = 0.814.
  7. Gouraud: at 0.25 of the way from 0.2 to 0.6, I = 0.2 + 0.25 × (0.6 − 0.2) = 0.2 + 0.1 = 0.30.

Answer. The Phong intensity is about 0.814 (dimensionless, in [0,1]); the Gouraud interpolated intensity at the quarter point is 0.30.

  • Using N or L before normalising. A dot product of non-unit vectors is not a cosine and can exceed 1.
  • Thinking n changes brightness. n changes the size and falloff of the highlight; ks changes its strength.
  • Using one face normal for all vertices in Gouraud. That gives flat shading, not smooth shading.
  • Forgetting to clamp negative N·L or R·V to zero; also do not apply distance attenuation to a directional light.

3.8 Ray tracing for realistic images

Ray tracing makes a picture by asking, for every pixel, what the eye sees along one straight line. That line is a ray. It stops at the nearest surface, then child rays test shadows, mirrors and glass. Each pixel is computed separately, so reflections and transparency need no special tricks. Films, product visualisation and architectural walkthroughs use it when quality matters more than speed. The arithmetic here stays with spheres and planes.

You need: Chapter 3.7 for local lighting, Chapter 3.2 for plane equations and Chapter 3.3 for sphere equations.

The eye ray and the nearest hit

A ray is a half-line P = E + t d. E is the eye point, d is a unit direction through one pixel centre, and t ≥ 0 is distance.

Test every object and keep the nearest hit: the smallest t greater than 0. No hit gives the background colour.

|E + t d − C|² = r²

C is the sphere centre and r its radius. With unit d, expand to t² + 2d·(E − C)t + |E − C|² − r² = 0; keep the smaller positive root.

t = −(n·E + D)/(n·d)

n is the plane normal and D the constant in n·P + D = 0. If n·d = 0, the ray is parallel to the plane.

  1. Set t_best to infinity and the nearest object to none.
  2. For each object, compute its intersection t.
  3. If t is above a small epsilon and below t_best, store the object and t.
  4. Shade the stored hit, or use the background colour.

Shadows, mirrors and glass

At the hit point P, a shadow ray leaves towards each light. Start it at P + εn, where n is the unit surface normal and ε is a small number such as 0.001. This offset stops the ray hitting the surface it just left. If an object blocks the path before the light, that light adds no direct colour.

Local colour comes from the lighting model in Chapter 3.7. For a mirror, the reflected direction is r = d − 2(d·n)n. Here d is the incoming unit ray direction, n is the unit normal and r is the outgoing unit direction. Send a ray from P + εn along r and recurse with depth minus one.

I = I_local + k_r I_reflect + k_t I_refract

I is the returned colour, I_local the direct plus ambient part, I_reflect and I_refract the child-ray colours, and k_r, k_t the reflection and transmission coefficients between 0 and 1.

For glass, the refracted ray bends by Snell's law, n₁ sin θ₁ = n₂ sin θ₂, with n₁ and n₂ the refractive indices and θ₁, θ₂ measured from the normal. Stop at a depth limit, or two mirrors exchange rays forever.

Cost grows as pixels × objects × depth. For 800 × 600 pixels and 3 objects, primary rays alone need 480,000 × 3 = 1,440,000 tests; reflected rays repeat the loop.

Worked example

Question. An eye at E = (0,0,0) looks along d = (0,0,−1). A sphere has centre C = (0,0,−5) and radius 1. Find both ray–sphere intersections, the visible hit, and primary intersection tests for an 800 × 600 image with 3 objects.

  1. Write P = E + t d = (0,0,−t).
  2. Substitute: (0)² + (0)² + (−t + 5)² = 1.
  3. Expand: t² − 10t + 24 = 0.
  4. Factor: (t − 4)(t − 6) = 0, so t = 4 or 6.
  5. Smaller positive root is t = 4; hit point E + 4d = (0,0,−4).
  6. Pixels = 800 × 600 = 480,000; tests = 480,000 × 3 = 1,440,000.

Answer. The ray meets the sphere at t = 4 and t = 6 scene units; the visible hit is t = 4 at (0, 0, −4), and primary intersection tests number 1,440,000.

Exam traps

  • Taking the larger positive root for a sphere: it is the far side, so a nearer surface can be missed.
  • Accepting t < 0: that intersection lies behind the eye.
  • Starting a shadow ray without εn: it self-hits and everything looks shadowed.
  • Leaving out the depth limit: two mirrors keep sending rays forever.

Local controlIn a B-spline, moving one control point changes only the curve over the few knot spans covered by its basis functions.3.5
Z-buffer (depth buffer)An array of depth values, one per pixel, holding the nearest z seen so far; a new fragment is drawn only if its z is smaller.3.6
BSP treeA binary tree that splits space by polygon planes, used to draw polygons back to front without a depth buffer.3.6
Diffuse and specular termsLambert diffuse k_d (N · L) plus Phong specular k_s (R · V)ⁿ, with N surface normal, L light direction, R reflection direction, V view direction.3.7
Gouraud shadingVertex intensities are computed once and linearly interpolated across the polygon.3.7
Phong shadingVertex normals are interpolated across the polygon and the lighting model is evaluated at every pixel.3.7
Ray tracingFor each pixel a ray is cast from the eye; the nearest hit is shaded, then reflected and refracted rays are followed recursively.3.8

Takeaways

  1. Storing a solid as indexed vertex, edge and face tables saves memory and lets you find neighbours quickly.
  2. Every planar face gives a normal and a plane equation, which are the basis of inside-outside tests and lighting.
  3. Curved objects are stored either as exact quadric equations or as polygon meshes approximating them.
  4. Bezier curves pass through their end points and stay inside the convex hull, which makes them safe for design.
  5. B-splines trade the end-point interpolation of Bezier for local control and higher continuity.
  6. Hidden surface removal answers one question per pixel: which surface is nearest to the eye.
  7. Gouraud shading is cheap but blurs highlights; Phong shading costs more but keeps them sharp.
  8. Ray tracing is simple to describe and gives shadows, mirrors and glass naturally, but costs one ray tree per pixel.

Remember and understand

Understand Explain how a polygon surface is stored in a computer using a vertex table, an edge table and a polygon (face) table. Show with a small example how two faces share one edge without duplicating its coordinates. 13 marks

Vertex table: index, x, y, z for each point; Edge table: pairs of vertex indices, one entry per edge, flag for which faces use it; Polygon table: ordered list of edge or vertex indices per face, plus attributes (colour, normal); Shared edge stored once, referenced by both faces — saves memory, keeps the solid watertight; Small worked example: cube or two triangles sharing an edge.

Understand Starting from three vertices of a planar polygon, derive its plane equation Ax + By + Cz + D = 0. Explain the meaning of the normal and of D, and how the equation is used for the inside-outside test. 12 marks

Take three points P₁, P₂, P₃; form two edge vectors; Normal by cross product, A, B, C are its components; Substitute one point to find D; Normal pointing outward if vertices are in counter-clockwise order seen from outside; Inside test: sign of Ax + By + Cz + D for the point, consistent for all faces.

Understand List the common quadric surfaces with their equations — sphere, ellipsoid, torus, paraboloid — and explain why storing them as equations is cheaper than storing a polygon mesh. 13 marks

Sphere: (x − x₀)² + (y − y₀)² + (z − z₀)² = r²; Ellipsoid: (x/a)² + (y/b)² + (z/c)² = 1; Torus: (x² + y² + z² + R² − r²)² = 4R²(x² + y²); Paraboloid and hyperboloid forms; Few parameters, exact surface at any zoom, but need a surface-meshing step for polygon pipelines.

Understand What is a blobby object? Explain the scalar-field and threshold method, and how two blobs merge smoothly when they come close. 12 marks

Each blob contributes a Gaussian or similar bump fᵢ around its centre; Total field is the sum Σfᵢ(x, y, z); Surface is the implicit set f = T, the threshold; Sum makes nearby bumps add up and the surfaces join without a seam; Used for soft organic shapes — drops, clouds, modelling clay; Rendering by ray marching or by polygonising the field.

Understand State and explain the main properties of a Bezier curve: end-point interpolation, convex hull, tangent directions at the ends, and the effect of adding control points. 13 marks

Cubic form P(t) = (1 − t)³P₀ + 3t(1 − t)²P₁ + 3t²(1 − t)P₂ + t³P₃; Passes through P₀ and P₃, not through the middle points; Lies inside the convex hull of the control points; Tangent at t = 0 along P₁ − P₀, at t = 1 along P₃ − P₂; Degree rises with number of points, so high-order curves are hard to control; join cubic pieces instead.

Apply

Apply For the four control points P₀ = (0, 0), P₁ = (1, 2), P₂ = (3, 2), P₃ = (4, 0), write the cubic Bezier blending functions and compute the curve point at t = 0.5. Check that the result lies inside the convex hull. 12 marks

Blending functions B₀ = (1 − t)³, B₁ = 3t(1 − t)², B₂ = 3t²(1 − t), B₃ = t³; At t = 0.5 the weights are 0.125, 0.375, 0.375, 0.125; Weighted sum gives x = 2.0, y = 1.5; Point lies inside the hull of the four control points; Weights sum to 1 — affine invariance.

Apply Compare Bezier and B-spline curves on degree, local control, end-point interpolation, continuity and convex hull. Using a cubic B-spline with a knot vector, show how moving one control point affects only a small part of the curve. 14 marks

Bezier degree = number of control points − 1; B-spline degree fixed, say 3, independent of point count; Bezier: global change, passes through ends, C∞ smooth, inside hull of all points; B-spline: local change over about p + 1 knot spans, does not normally pass through ends, C² for cubic, inside hull of local points; Knot vector lists parameter values; basis function Nᵢ,ₚ is non-zero on a short span; Worked example: moving P₄ alters curve only between knots t₄ and t₈ for a cubic.

Apply Explain the Z-buffer (depth-buffer) hidden-surface algorithm step by step. Give the two arrays it needs, trace it on a simple example, and list its advantages and disadvantages. 13 marks

Frame buffer holds colour per pixel, depth buffer holds z per pixel; Initialise depth to the far value (or +∞); For each polygon, scan-convert it; for each covered pixel compute z; If z < stored depth, replace colour and depth; Advantages: works for any polygon order, simple hardware, handles intersections; Disadvantages: z-buffer memory, no transparency without extra work, aliasing unless supersampled.

Apply Explain how a BSP tree is built from a set of polygons and how it is used to paint them in back-to-front order. Give the traversal rule for the eye position. 13 marks

Choose a polygon as the splitting plane, put it at the root; Sort other polygons: front side, back side, or spanning; split spanning polygons; Recurse on each side to build the tree; Painter's order: draw polygons behind the eye plane first, then the plane, then those in front; Stable for static scenes, no per-pixel depth needed; Cost: splitting creates extra polygons, and the tree must be rebuilt if geometry moves.

Apply Write down the Phong illumination model with its ambient, diffuse and specular terms. Then compare Gouraud and Phong shading and explain why a sharp highlight on a coarse mesh looks wrong under Gouraud shading. 14 marks

I = k_a I_a + k_d I_l (N · L) + k_s I_l (R · V)ⁿ, each symbol defined; Gouraud: compute I at each vertex, interpolate I across the scan line — fast, hardware-friendly; Phong: interpolate N, compute I per pixel — slower, correct highlights; Gouraud averages away a highlight that falls between vertices; Mach-band artefacts on edges; Phong also handles large polygons better; modern GPUs do per-fragment Phong.

Analyze and evaluate

Analyze Describe ray tracing for image synthesis: ray generation through the pixel grid, intersection with sphere and polygon, nearest hit selection, and the secondary rays for shadow, reflection and refraction. Discuss the cost. 14 marks

Camera model, pixel centre gives ray origin and direction; Sphere intersection: quadratic in t, keep the smaller positive root; Polygon intersection: ray-plane then inside-polygon test; Keep the nearest hit along the ray; Shadow ray to each light; reflected ray about the normal; refracted ray by Snell's law; Recursion depth cut-off and its effect: fewer rays, less colour bleeding; Cost grows with pixels × objects × depth; acceleration by bounding volumes, octrees or BSP.

Evaluate Compare Z-buffer, BSP tree and ray tracing as hidden-surface methods: correctness, memory, dependence on scene order, handling of transparency, and typical use. 14 marks

Z-buffer: order independent, per-pixel memory, O(pixels + fragments), easy in hardware, weak for transparency; BSP: exact painter order, precomputed, extra polygon splitting, best for static scenes such as architectural walkthroughs; Ray tracing: pixel-by-pixel and order independent, handles transparency, mirror and shadow naturally, expensive per pixel; Recommendation table by scene type and hardware; Note that hidden-surface removal is the same visibility question in all three.

Evaluate You must build a simple 3D viewer that shows a rotating car body on a phone. Choose a representation for the body and for the wheels, a curve scheme for the roof line, a hidden-surface method and a shading model. Justify each choice on speed, memory and visual quality. 16 marks

Body as a polygon mesh with vertex, edge and face tables, triangulated for the GPU; Wheels as quadric tori or low-poly meshes, with plane equations for flat faces; Roof line as a piecewise cubic Bezier or B-spline, tessellated into polygons; Z-buffer in hardware for visibility — order independent and cheap; Per-fragment Phong shading for highlights on the curved body; Trade-offs: number of triangles, texture memory, battery cost of heavy shading; Mention when ray tracing would be preferred — offline high-quality stills, not live phone frames.

Glossary

Ambient light
A constant background illumination term that keeps unlit surfaces from being completely black.
Basis function
One of the short-range polynomials Nᵢ,ₚ(t) that weight a B-spline control point.
Blending function
The weight attached to each control point as a function of the curve parameter t.
Blobby object
A soft implicit shape whose surface is the threshold contour of a summed field of bumps.
BSP tree
A binary space-partitioning tree that splits a scene recursively by polygon planes.
Control point
A point that influences the shape of a spline curve without necessarily lying on it.
Convex hull
The smallest convex region containing a set of points; a Bezier curve never leaves it.
Depth buffer
An array storing, per pixel, the z value of the nearest fragment drawn so far.
Face normal
A vector perpendicular to a polygon face, usually scaled to unit length, used in lighting and visibility tests.
Gouraud shading
Shading that interpolates colour computed at the vertices across the polygon interior.
Hidden surface removal
The process of deciding, for each pixel, which surface is nearest to the viewer and therefore visible.
Implicit surface
A surface defined as the set of points where a function f(x, y, z) equals a constant, rather than by a mesh.
Inside-outside test
Checking the sign of the plane equation to decide whether a point lies inside or outside a closed polyhedron.
Knot
A parameter value in the knot vector where one basis function ends and another begins.
Knot vector
The non-decreasing sequence of parameter values that defines the B-spline basis functions.
Painter's algorithm
Drawing polygons from far to near so that nearer ones overwrite farther ones.
Parametric continuity
Smoothness at a join measured by matching derivatives, written C⁰, C¹, C² for value, slope, curvature.
Phong shading
Shading that interpolates vertex normals across the polygon and applies the lighting model per pixel.
Plane equation
Ax + By + Cz + D = 0, the set of all points lying on a flat plane with normal (A, B, C).
Polygon mesh
A connected collection of planar polygons that share edges and vertices to form a surface.
Quadric surface
A surface described by a polynomial equation of degree two in x, y and z.
Ray casting
Shooting one ray per pixel from the eye into the scene and keeping the nearest intersection.
Recursion depth
The maximum number of reflected or refracted rays followed from one primary ray.
Specular reflection
The mirror-like component of reflected light that forms highlights, controlled by the shininess exponent.
Spline
A piecewise polynomial curve that is smooth across the joins between its pieces.
Vertex
A point in 3D space, stored as (x, y, z), where polygon edges meet.
