4.1 Sequential versus combinational circuits; clocked circuits

A combinational circuit is a pure function: put the same inputs on it and the same outputs appear, every time, with no memory of what came before. A sequential circuit adds a stored state, so its output depends on the present inputs and on the history of past inputs. That is what makes a lift remember which floor was pressed, a UPI app remember the digits typed so far, and a processor remember where it is in a program. Almost every sequential circuit you will meet is clocked: a single square wave tells every memory element when it may change, which keeps a million flip-flops in step.

You need: logic gates and truth tables (Unit 2), and the idea of a combinational block such as an adder or multiplexer (Unit 3).

What memory adds

A full adder's Sum and Carry are fixed by A, B and Cin at that instant; remove the inputs and the outputs vanish. Now ask a question no such circuit can answer: "has the button been pressed an odd number of times?" The present value of the button is not enough; the circuit must hold a bit that records the past. That stored bit is the state.

Formally, a sequential circuit has inputs X, outputs Z and a state Q, described by two functions. The next-state function Q+ = f(X, Q) says what the state becomes. The output function Z = g(X, Q) (Mealy) or Z = g(Q) (Moore) says what comes out; Unit 5 develops the two models. The hardware always has the shape of Figure 4.1.1: a combinational block computes Q+ and Z, memory elements store Q, and a feedback path carries Q back to the block. That feedback path is the one wire no combinational circuit has.

Synchronous and asynchronous sequential circuits

In an asynchronous sequential circuit there is no clock: the memory elements change whenever their inputs change, after a gate delay. Such circuits are fast but fragile; two inputs changing at nearly the same time can land the circuit in a wrong state (a race), so the designer must account for every delay. Unit 5 treats them with flow tables and hazard-free design. NITC lists this split as "asynchronous versus synchronous sequential machines"; SRM says "clocked vs un-clocked".

In a synchronous (clocked) circuit every memory element is a flip-flop that changes only at a tick of a shared clock. Between ticks the inputs may glitch and settle; nothing is stored until the tick. This one rule removes most races and turns timing into a simple budget (Chapter 4.3). The price is speed: the clock must be slow enough for the slowest path to settle.

The clock and its vocabulary

  • Period T: one full cycle, in seconds. Frequency f = 1/T, in hertz. A 100 MHz clock has T = 1/(100 × 106) = 10 ns.
  • Rising (positive) edge: the 0→1 transition. Falling (negative) edge: 1→0.
  • Duty cycle: the fraction of the period the clock is high, D = thigh/T, usually as a percentage.
  • Clock skew (NITC): the difference in arrival time of one clock edge at two flip-flops, from unequal wires and buffers. It eats into the timing budget of Chapter 4.3; chips fight it with a balanced clock tree.

A level-triggered element (a latch, Chapter 4.2) follows its input for the whole time the clock is at its active level. An edge-triggered element (a flip-flop, Chapter 4.3) samples its input only at one edge. In symbols, a small triangle at the clock input means edge-triggered; a bubble before it means the falling edge. The clock itself (NITC: "clocks and oscillators") comes from a quartz crystal oscillator, 32.768 kHz in a watch or 16 MHz on an Arduino board, divided down by the counters of Chapters 4.7 and 4.8; a 555 timer gives a rough clock for lab work.

Worked example

Question. (a) A microcontroller runs from a 16 MHz crystal. Find the clock period. The clock is high for 5 ns in each cycle; find the duty cycle. (b) The circuit of Figure 4.1.1 has one input X and one state bit Q with next-state function Q+ = X ⊕ Q and output Z = Q. Starting from Q = 0, the input X takes the values 1, 1, 0, 1 on four successive clock edges. List Q and Z after each edge and say in words what the circuit does.

Solution.

(a) T = 1/f = 1/(16 × 106 Hz) = 62.5 × 10−9 s = 62.5 ns. Duty cycle D = thigh/T = 5 ns / 62.5 ns = 0.08 = 8 %. (A narrow pulse like this is fine for an edge-triggered flip-flop, which only needs the edge, but would starve a level-triggered latch of time to follow its input.)

(b) Apply Q+ = X ⊕ Q edge by edge, remembering that the output Z = Q is read after the state updates.

Z is 1 exactly when an odd number of 1s have arrived so far: the circuit is a parity tracker. No combinational circuit could do this: at edge 2 the input was the same as at edge 1, yet the answer differed, because the state decided. This Q+ = X ⊕ Q is the T flip-flop of Chapter 4.3 with X as its T input.

Exam traps

  • "Sequential" does not mean "has a clock". Asynchronous sequential circuits have memory and no clock; the defining feature is feedback of stored state.
  • Period and frequency are reciprocals: 1 GHz ↔ 1 ns, 1 MHz ↔ 1 µs. Students write 16 MHz → 16 ns; it is 62.5 ns.
  • Duty cycle is thigh/T, not thigh/tlow. A 25 % duty cycle at T = 40 ns means 10 ns high, 30 ns low.
  • When tracing a state table, compute Q+ from the old Q, then update. Updating Q midway through a row is the commonest tracing mistake in this unit.
  • Favourite short questions: "Distinguish combinational and sequential circuits with an example of each" (adder versus counter) and "Why are synchronous circuits preferred?" (predictable timing, no races).

A circuit whose outputs depend on present inputs and on stored state (past inputs). Next-state function Q+ = f(X, Q) and output function Z = g(X, Q) or g(Q).

Remember What is the duty cycle of a clock? 2 marks

The fraction of the period during which the clock is high, D = thigh/T, usually in percent.

Understand Why is a feedback path essential for memory? 3 marks

Without feedback, outputs are fixed by present inputs alone. Feeding the output back as an input lets a value keep itself in place after the input that caused it is removed.

Understand Give two advantages and one disadvantage of synchronous over asynchronous sequential circuits. 3 marks

Advantages: state changes only at clock edges, so glitches between edges are ignored and races avoided; timing reduces to one budget per clock period. Disadvantage: the clock must suit the slowest path, so it is slower than the best asynchronous design.

Apply A clock has period 25 ns and is low for 15 ns. Find the frequency and the duty cycle. 3 marks

f = 1/T = 1/(25 × 10−9) = 40 MHz. thigh = 25 − 15 = 10 ns, so D = 10/25 = 40 %.

Apply A circuit has Q+ = X + Q (OR) and Z = Q. From Q = 0, X = 0, 0, 1, 0, 0 on five edges. Give Z after each edge. 4 marks

Q⁺: 0, 0, 1, 1, 1 so Z = 0, 0, 1, 1, 1. Once X has been 1, Q sticks at 1: the circuit is a "has it ever happened" flag (a sticky bit).

Analyze A designer argues that a 4-bit adder "remembers" its inputs because its outputs stay fixed while the inputs are held. Is the adder sequential? Justify. 4 marks

No. The outputs persist only because the inputs persist; change or remove the inputs and the outputs follow immediately. There is no feedback path and no stored state, so the output is a function of present inputs only, which is the definition of combinational. Memory means holding a value after the cause is gone.

4.2 Latches: SR and gated latches; switch debouncing

Two NOR gates, each feeding the other, make the smallest circuit that remembers: the SR latch. Pulse S and it stores a 1; pulse R and it stores a 0; leave both at 0 and it holds. Add an enable input and you get the gated latch, the first circuit in this unit that listens to a clock. The same two gates, in NAND form, also fix a practical nuisance: a mechanical switch whose contacts bounce and deliver ten pulses when you pressed once.

You need: NOR and NAND truth tables (Unit 2) and the idea of feedback from Chapter 4.1.

The SR latch from two NOR gates

Figure 4.2.1 shows the circuit: gate 1 takes R and the output Q̄ of gate 2; gate 2 takes S and the output Q of gate 1. NITC calls it the binary cell, NITT the basic latch circuit. One fact about NOR drives everything: a 1 on any input forces the output to 0; only all-zero inputs give a 1.

  1. Set (S = 1, R = 0). Gate 2 sees S = 1, so Q̄ = 0. Gate 1 sees R = 0 and Q̄ = 0, so Q = 1.
  2. Hold (S = 0, R = 0). Gate 2 sees S = 0 and Q = 1, so Q̄ stays 0; gate 1 sees R = 0 and Q̄ = 0, so Q stays 1. The feedback keeps the state alive with no input: this is the memory.
  3. Reset (S = 0, R = 1). Gate 1 sees R = 1, so Q = 0; gate 2 sees S = 0 and Q = 0, so Q̄ = 1.
  4. Forbidden (S = 1, R = 1). Both gates are forced to 0, so Q = Q̄ = 0, breaking the promise that the outputs are complements. Worse, if S and R then return to 0 together, both gates race to go to 1 and the final state depends on which gate is faster: unpredictable. Designers never allow S = R = 1.

The NAND latch is the same circuit with NAND gates. A 0 on any NAND input forces a 1, so its inputs are active-low, written S̄ and R̄: S̄ = 0 sets, R̄ = 0 resets, S̄ = R̄ = 1 holds, and S̄ = R̄ = 0 is forbidden (both outputs 1). IC latches and the debouncer below use this form.

Gated SR latch and gated D latch

The basic latch reacts the instant S or R changes. To make it listen only when allowed, put an AND gate in front of each input and feed a common enable (EN, also called the clock) to both. With EN = 0 the latch sees S = R = 0 and holds; with EN = 1, S and R pass through and the latch behaves as in Figure 4.2.1. This is the gated SR latch (SRM: "operation and timing"). It is level-triggered: it can change at any moment while EN is high, so the inputs must stay steady for the whole high period.

The forbidden input can be designed away. Feed one input D to S and D through an inverter to R; S and R are then never both 1. While EN = 1, Q simply follows D (the latch is transparent); when EN drops to 0, Q freezes at the last D. This gated D latch is the storage cell inside most registers and the building block of the master-slave flip-flop in Chapter 4.5. In one line: Q+ = D when EN = 1, Q+ = Q when EN = 0.

Switch debouncing

A mechanical switch does not close cleanly: the contacts strike, spring apart and strike again for about 1 to 20 ms, so a logic input sees a burst of pulses instead of one edge and a counter clocked from a push-button advances several counts per press. The cure with a single-pole double-throw (SPDT) switch is the NAND latch of Figure 4.2.2. Each throw contact is pulled up to 5 V through a resistor, so an untouched contact reads 1 (hold). Moving the pole to contact A pulls S̄ to 0 and sets Q = 1. When the contact bounces open, S̄ returns to 1, which is only the hold input, so Q stays 1. The pole cannot reach contact B during a bounce, so R̄ stays 1 and nothing can reset the latch: the first touch wins. A single-throw push-button has no second contact, so it is debounced with an RC filter and a Schmitt trigger, or by software that waits about 20 ms and re-reads the pin.

Exam traps

  • NOR latch inputs are active-high (1 acts); NAND latch inputs are active-low (0 acts). Copying the NOR table for a NAND latch gets every row wrong. The forbidden output pair also differs: 0,0 for NOR, 1,1 for NAND.
  • "Forbidden" does not mean the outputs are undefined while S = R = 1 (both are 0 for NOR). The trouble is afterwards, when both inputs release together.
  • A gated latch is still level-triggered: it can change at any time during the enable level, so a feedback loop around it can change more than once per clock (Chapter 4.5). That is the answer to "why is a latch unsuitable as a clocked memory element?"
  • Latch debouncing needs an SPDT (three-terminal) switch. A two-terminal button needs an RC filter plus Schmitt trigger or a software delay.
  • Favourite drawing question: "Draw the SR latch using NOR gates and explain its operation with a truth table." The crossed feedback wires are where the marks are.

No. Untouched contacts now read 0, the active input of a NAND latch, so both inputs are asserted (forbidden) while the pole is between contacts, and a touched contact gives 1 (hold). Either use a NOR latch with the pull-downs, or return to pull-ups with the pole at 0 V.

Beyond the syllabus

Not for the exam. Inside an SRAM chip every bit is a six-transistor cell that is exactly this cross-coupled pair, with the gates shrunk to two inverters plus two access transistors; every processor cache is millions of these latches. High-performance pipelines use latches deliberately because transparency lets slow stages borrow time from fast ones (search: time borrowing). Arduino sketches debounce in software with a 20 to 50 ms timer; ICs such as the MAX6816 do it in hardware. Search "metastability" next: what happens to this latch when S and R release at almost the same instant, a real failure mode in every chip that samples an outside signal.

4.3 Flip-flops: SR, JK, D and T

A flip-flop is a latch that has been taught manners: it looks at its inputs only at one edge of the clock and ignores them the rest of the time. That single change makes it safe to wire thousands of memory elements to one clock, because each one changes exactly once per cycle, at the same instant. Four input styles exist. SR and JK take two control inputs, D takes the value to store, and T takes a toggle command; JK and D are the two you will actually use in registers and counters.

You need: the gated SR and D latches of Chapter 4.2 and clock edges from Chapter 4.1.

Edge triggering

A gated latch is transparent for the whole half-cycle that its enable is high. If its output feeds back through logic to its own input, as in every counter, the new value can run round the loop and change the latch again within the same half-cycle. An edge-triggered flip-flop closes that loophole: it samples its inputs during a vanishingly short window around the active clock edge, and the output changes once, shortly after. Figure 4.3.1 shows the difference for a D input. In the symbol, a small triangle on the clock input (written CLK, CP or >) marks edge triggering; a bubble before the triangle marks a negative-edge (falling-edge) device. Two constructions give edge behaviour: the master-slave pair of Chapter 4.5 and the three-latch circuit inside the 7474, which NITC's "design of a clocked flip-flop" item refers to.

The four types

Each type is a function from its inputs and present state Q to the next state Q+, applied at the active edge. Chapter 4.4 turns these into equations and excitation tables.

The JK flip-flop removes the SR restriction by feeding Q̄ back into the S side and Q into the R side, so J = K = 1 always drives the flip-flop to the opposite state. The D type is a JK with K = J̄, or an SR with R = S̄; it is the one used in almost every real register because it needs no logic to decide what to store. The T type is the natural counting element: with T = 1 it divides the clock frequency by two. Most IC families provide only D and JK packages (NITT's "integrated circuit flip-flops"): the 7474 dual positive-edge D, the 7476 dual JK, the 74112 dual negative-edge JK, with T made from JK by tying J to K.

Real packages also carry two asynchronous inputs, PRESET (PR, sets Q = 1) and CLEAR (CLR, sets Q = 0), usually active-low. They act immediately, ignoring the clock, and are used to put a counter into a known state at power-up. Both must be inactive (1) for normal clocked operation.

Timing parameters

NITK lists "timing parameters"; they decide how fast a clocked circuit may run.

  • Setup time tsu: the input must be stable for this long before the active edge.
  • Hold time th: the input must stay stable for this long after the edge.
  • Propagation delay tpd (clock-to-Q): the time from the edge until Q shows the new value.
  • Maximum clock frequency: in a loop where Q passes through combinational logic of delay tlogic back to a flip-flop input, one period must fit everything: T ≥ tpd + tlogic + tsu, so fmax = 1/(tpd + tlogic + tsu). Clock skew between the two flip-flops adds to the right-hand side.

If the input changes inside the setup-hold window the flip-flop may hang between 0 and 1 for an unpredictable time (metastability) before falling to either value. For a 74LS74 the National Semiconductor datasheet gives 20 ns setup, 0 ns hold, 25 to 30 ns maximum clock-to-Q and a 25 MHz maximum clock frequency (at 15 pF load); other makers quote a 5 ns hold.

Exam traps

  • "Latch" and "flip-flop" are not synonyms in an exam answer: a latch is level-triggered, a flip-flop edge-triggered. The bubble-and-triangle symbol tells you the edge.
  • J = K = 1 toggles; it is not forbidden. S = R = 1 is forbidden; it does not toggle.
  • When tracing, read J, K and the old Q at the edge. Input changes between edges do nothing to a flip-flop.
  • PRESET and CLEAR are usually active-low: a 0 acts. Leaving them floating or at 0 "freezes" the flip-flop in lab, a classic practical-exam fault.
  • fmax uses setup time, not hold time. Hold time constrains the shortest path, not the clock period.

Analyze A T flip-flop with T tied to 1 is clocked at 10 MHz. What is its output, and why is this not possible with a D flip-flop whose D is tied to 1? 4 marks

It toggles every edge: a 5 MHz square wave (divide-by-two). A D flip-flop with D = 1 stores 1 at the first edge and stays 1; to toggle it, D must be fed from Q̄, which turns it into a T flip-flop with T = 1.

4.4 Characteristic and excitation tables; flip-flop conversion

A flip-flop can be read in two directions. Forwards: given the inputs and the present state, what is the next state? That is the characteristic table, and its Boolean form is the characteristic equation. Backwards: given where the flip-flop is and where you want it to go, what inputs will take it there? That is the excitation table, and it is the tool for every design question in this unit, from converting one flip-flop type into another (this chapter) to designing counters (Chapter 4.8) and state machines (Unit 5).

You need: the four flip-flop types of Chapter 4.3 and K-map simplification with don't cares (Unit 2).

Characteristic tables and equations

The characteristic table lists Q+ for every combination of inputs and present state Q. Simplifying it with a K-map (Q as one variable, the inputs as the others) gives the characteristic equation:

SR:  Q⁺ = S + R̄·Q        (with the condition S·R = 0)
JK:  Q⁺ = J·Q̄ + K̄·Q
D:   Q⁺ = D
T:   Q⁺ = T·Q̄ + T̄·Q = T ⊕ Q

Read JK aloud: "J sets when Q is 0; K̄ keeps Q when Q is 1." With J = K = 1 it becomes Q+ = Q̄, the toggle. Put J = D and K = D̄ into the JK equation and it collapses to Q+ = D, which is why a D flip-flop is "a JK with an inverter". These equations are what you substitute into a circuit's logic to get its next-state equations in Unit 5.

Excitation tables

The excitation table answers the design question: for each of the four transitions Q → Q+, which inputs cause it? Don't cares (x) appear wherever two input values both work, and they are gold in a K-map.

Q → Q⁺S RJ KDT
0 → 00 x0 x00
0 → 11 01 x11
1 → 00 1x 101
1 → 1x 0x 010

Three patterns make the table easy to remember. For D, D is simply Q+. For T, T = 1 whenever the state changes, so T = Q ⊕ Q+. For JK, when Q = 0 only J matters (J = Q+, K = x) and when Q = 1 only K matters (K = Q̄+, J = x); JK has a don't care in every row, which is why JK designs come out with the fewest gates. SR is JK with two of the don't cares removed (0 → 1 needs R = 0, 1 → 0 needs S = 0, to avoid S = R = 1).

Converting one flip-flop into another

You have one type in the lab (the available flip-flop) and the design calls for another (the required type). The fix is a small combinational block in front of the available flip-flop, found by a fixed procedure.

  1. Write the characteristic table of the required flip-flop: its inputs and Q on the left, Q+ on the right.
  2. For each row, look up the transition Q → Q+ in the excitation table of the available flip-flop and add its inputs as extra columns.
  3. Draw a K-map for each available input with the required inputs and Q as variables; use the don't cares; read off the minimal expressions.
  4. Draw the circuit: the expressions feed the available flip-flop, whose Q (and Q̄) feed back into them. The clock goes straight through.

4.5 Race-around condition and master-slave flip-flops

Build a JK flip-flop the obvious way, as a clocked SR latch with Q and Q̄ fed back to its inputs, and it has a flaw: with J = K = 1 and the clock held high, the output toggles, the new output feeds back, and it toggles again, and again, for as long as the clock stays high. Nobody can say where it stops. This is the race-around condition. The classic cure is the master-slave flip-flop, two latches in series driven by opposite phases of the clock, so that the inputs are read while the clock is high but the output changes only when it falls.

You need: the gated SR latch of Chapter 4.2 and the JK rule of Chapter 4.3.

How the race-around happens

Call the clock pulse width tp (the time the clock is high), the clock period T, and the propagation delay of the flip-flop Δt (the time for a change at the inputs to reach Q). In a level-triggered JK with J = K = 1, the moment the clock goes high the inputs say "toggle". After Δt, Q flips. But the clock is still high and the fed-back Q̄, which is now the old Q, again says "toggle", so after another Δt it flips back. The output oscillates with period 2Δt until the clock falls. The number of toggles is roughly tp/Δt, and whether that number is even or odd decides the final state. Because Δt varies with temperature and from chip to chip, the final state is unpredictable.

Three conditions are needed together: J = K = 1, a level-triggered (pulse-triggered) clock, and tp > Δt. Remove any one and there is no race. Hence the three cures.

  1. Make the pulse shorter than the delay: tp < Δt < T. Then Q flips once and the clock is already low before the feedback arrives. In practice Δt is a few nanoseconds and a clock that narrow is hard to distribute, so this is a theoretical answer.
  2. Edge triggering (Chapter 4.3): the inputs are sampled only in a window around the edge, so the fed-back change arrives too late to matter. This is what modern ICs do.
  3. Master-slave construction: break the feedback loop in time so that the output cannot change while the inputs are being read.

The master-slave JK flip-flop

Figure 4.5.1 shows the structure. Two gated latches sit in series. The master is enabled when CLK = 1; the slave is enabled through an inverter, so when CLK = 0. J and K are gated with the slave's Q̄ and Q and enter the master. One clock cycle runs in two halves:

  • CLK = 1: the master follows J and K and settles to the next state. The slave is disabled, so Q does not move. Because the feedback comes from the slave's unchanging Q, the master receives one steady command and cannot race.
  • CLK = 0: the master is frozen; the slave is enabled and copies the master's value to Q. Any change at J, K now cannot reach the master.

So the output changes just after the falling edge, and only once per clock pulse. The device is called pulse-triggered; its symbol carries a small ¬ sign (the postponed-output indicator) at Q. SRM lists this as "master-slave architecture"; NITC lists the master-slave as a fifth flip-flop type beside RS, JK, D and T.

The master-slave is not an edge-triggered flip-flop, and its weakness is ones-catching (and zeros-catching). The master is a level-sensitive latch for the whole high half-cycle: if J glitches to 1 for even a few nanoseconds while CLK is high and K is 0, the master sets and nothing can reset it before the slave copies it. Figure 4.5.1's timing trace shows exactly that. The rule for using a master-slave device is therefore: hold J and K steady for the entire time the clock is high. Edge-triggered flip-flops have no such rule, which is why they replaced the master-slave in the 74-series catalogue (the 7476 is master-slave; the 74LS76A and 74112 are negative-edge-triggered, from memory; check).

Worked example

Question. A level-triggered JK flip-flop has propagation delay Δt = 8 ns and is clocked by a pulse of width tp = 50 ns at a period of 100 ns, with J = K = 1 and Q = 0 initially. (a) How many times does Q toggle during one pulse, and what is Q afterwards? (b) If Δt changes to 7 ns on a warm day, what is Q afterwards? (c) What pulse width would avoid the race, and why is it impractical? (d) How does a master-slave flip-flop behave with the same inputs?

Solution.

(a) Toggles occur every Δt while the clock is high: n = tp/Δt = 50/8 = 6.25, so 6 complete toggles (at 8, 16, 24, 32, 40, 48 ns). Even number: Q returns to 0.

(b) n = 50/7 = 7.14 → 7 toggles (at 7, 14, …, 49 ns). Odd: Q ends at 1. A 1 ns change in delay changed the answer, which is the race-around condition in one line: the final state depends on an uncontrolled delay.

(c) The race is avoided if tp < Δt, so tp < 8 ns, with Δt < T = 100 ns satisfied. A 2 ns pulse would do, but Δt is a guaranteed minimum on no datasheet, a pulse that narrow is distorted by wiring capacitance, and the pulse must still be long enough to operate the latch: impractical.

(d) With J = K = 1 the master toggles its stored value once while CLK = 1 (the feedback from the unchanging slave gives it one steady command, "go to Q̄ = 1"); at the falling edge the slave copies it. Q becomes 1 after the first pulse, 0 after the second, and so on: exactly one toggle per clock, a clean divide-by-two, independent of Δt and tp.

Exam traps

  • Race-around needs J = K = 1. With any other input the level-triggered JK settles once and stays, so "race-around occurs in every JK flip-flop" is wrong.
  • The condition is written tp < Δt < T, and students reverse the first inequality. The pulse must be shorter than the delay.
  • The master-slave output changes at the falling edge, but the device is pulse-triggered, not negative-edge-triggered. The difference is ones-catching: inputs must be steady for the whole high period.
  • Race-around (this chapter) and the "race" of asynchronous circuits (Unit 5) are different things. The first is an output chasing its own feedback; the second is two state variables changing at different speeds.
  • Favourite question: "What is race-around? Explain how the master-slave JK flip-flop overcomes it, with a diagram." The diagram must show the inverter on the slave clock.

4.6 Shift registers: SISO, SIPO, PISO, PIPO and universal

A register is a row of flip-flops that share one clock and hold one word. A shift register is a register whose flip-flops are chained, so every clock pulse moves the whole word one position sideways. That single trick converts serial data to parallel and back, which is how a UART turns the bits on a USB-to-serial cable into a byte, how an SPI display receives pixels, and how a calculator multiplies by two. The four names SISO, SIPO, PISO and PIPO only say how the data gets in and how it gets out; the universal shift register does all four under a two-bit mode control.

You need: the D flip-flop of Chapter 4.3 and the multiplexer of Unit 3.

The chain of D flip-flops

Figure 4.6.1 (top) shows a 4-bit right-shift register. Each stage is a positive-edge D flip-flop; the Q of one stage is the D of the next. At a clock edge every flip-flop copies its D at the same instant, so the bit in Q3 moves to Q2, Q2 to Q1, Q1 to Q0, and the serial input enters Q3. The bit that was in Q0 appears at the serial output and is lost unless something stores it. Edge triggering is essential: with transparent latches a bit would slide through all four stages in one clock.

4.7 Asynchronous (ripple) counters

Tie J and K to 1 and a JK flip-flop divides its clock by two. Feed its output into the clock of a second one and you divide by four; a third gives eight. Read the three outputs together and they count 0 to 7 in binary. This chain is the ripple counter: the cheapest counter there is, with no logic between stages at all. Its price is that the clock does not reach every stage at once; it ripples down the chain, one propagation delay per stage, so the count is briefly wrong after every edge and the counter has a hard speed limit.

You need: the T and JK flip-flops and the propagation delay tpd of Chapter 4.3.

How the ripple counter counts

Figure 4.7.1 shows a 3-bit ripple up counter built from negative-edge JK flip-flops with J = K = 1 (that is, T flip-flops with T = 1). Only FF0 receives the external clock. Q0 clocks FF1, Q1 clocks FF2. Each flip-flop toggles when its own clock input falls. Q0 toggles on every clock pulse; Q1 toggles when Q0 falls, which happens every second pulse; Q2 toggles when Q1 falls, every fourth. Reading Q2Q1Q0 gives 000, 001, 010, 011, 100, 101, 110, 111 and back to 000: a MOD-8 counter. In general n flip-flops give MOD-2n, and the last output is a square wave at fclk/2n; a counter is also a frequency divider. The name comes from the asynchronous way the stages change: no common clock, only a chain of causes.

Down counting. A binary count down requires a lower bit to toggle the next stage when it goes from 0 to 1 (a rising edge). With negative-edge flip-flops this is done by clocking each stage from the Q̄ of the previous stage, since Q̄ falls when Q rises. (With positive-edge flip-flops the rules swap: Q to the next clock counts down, Q̄ counts up.) An up/down ripple counter uses a mode input and a small mux to choose Q or Q̄ as the next clock.

Propagation delay and the speed limit

Every stage adds one flip-flop delay tpd. The worst case is the change where all bits flip, such as 0111 → 1000, which takes n·tpd to settle through false intermediate values (0110, 0100, 0000). For the count to be valid before the next clock edge, the period must exceed that settling time plus any decoding gate delay:

T ≥ n·t_pd + t_decode        f_max = 1 / (n·t_pd + t_decode)

Here n is the number of flip-flops and tpd the clock-to-Q delay of one. The false states are also decoding glitches: a gate that decodes "count = 0" will fire briefly during the 0111 → 1000 transition. This is why ripple counters are limited to slow counting (frequency division, timers) and why Chapter 4.8's synchronous counters exist.

MOD-n ripple counters by resetting

To count modulo some n that is not a power of two, use enough flip-flops for 2k ≥ n and clear them the instant the count reaches n. A NAND gate decodes the binary pattern of n and drives the active-low CLEAR inputs of all flip-flops. For MOD-6 (0 to 5, three flip-flops), n = 6 = 110, so NAND(Q2, Q1) → CLR: the moment the count becomes 110 the counter is wiped to 000. The state 6 exists for a few nanoseconds (one NAND delay plus the clear delay), which is invisible on a display but is another glitch on the outputs.

The 74LS90 that NITC names is the classic IC of this kind: a divide-by-2 flip-flop (clock A, output QA) and a divide-by-5 ripple section (clock B, outputs QBQCQD) in one package, with two reset-to-0 inputs R0(1), R0(2) and two set-to-9 inputs R9(1), R9(2), all needing both inputs high to act. Wire QA to clock B and you get a BCD (decade) counter, 0000 to 1001. Cascading: feed the most significant output of one counter into the clock of the next; a MOD-10 followed by a MOD-10 counts 0 to 99, and in general MOD-m × MOD-n = MOD-mn. That is how a digital clock divides a 32.768 kHz crystal down to seconds.

Worked example

Question. A 4-bit ripple counter uses negative-edge JK flip-flops with tpd = 20 ns each; a 10 ns NAND gate decodes its states. (a) Find the maximum clock frequency. (b) List the intermediate states as the counter goes from 0111 to 1000 and how long each lasts. (c) With a 1 MHz clock, find the frequency and duty cycle at Q3. (d) Modify the counter to count modulo 10 and show the reset logic.

Solution.

(a) Tmin = n·tpd + tdecode = 4 × 20 + 10 = 90 ns, so fmax = 1/90 ns ≈ 11.1 MHz. (Without decoding, 1/80 ns = 12.5 MHz.)

(b) At the clock edge Q0 falls after 20 ns, which clocks FF1; Q1 falls at 40 ns, Q2 at 60 ns, Q3 rises at 80 ns.

Exam traps

  • Up or down depends on both the edge and which output clocks the next stage. Negative-edge with Q → up; negative-edge with Q̄ → down; positive-edge swaps these. Write the rule you are using.
  • fmax = 1/(n·tpd) uses the number of flip-flops, not the modulus. A MOD-10 counter still has n = 4.
  • For the MOD-n reset, decode the pattern of n itself, not n − 1. MOD-6 decodes 110, MOD-10 decodes 1010. The last valid state is n − 1.
  • Decode only the 1-bits that first appear together at n (Q2Q1 for 6). Decoding all bits works but wastes inputs; decoding too few fires early.
  • Favourite questions: "Draw a 4-bit ripple counter and its timing diagram" and "Design a MOD-6 (or decade) ripple counter". Anna Univ, SRM, IITD and NITC all list it.

Beyond the syllabus

Not for the exam. The 7490 family is obsolete but its CMOS cousins, the 74HC4040 (12-stage ripple counter) and 74HC4060 (14 stages with a built-in oscillator), are still in every hobby kit. 4.8 Synchronous up/down and MOD-n counter design

Give every flip-flop the same clock and let logic decide which of them should toggle at the next edge: that is a synchronous counter. All outputs change together, one tpd after the edge, so there are no ripple delays, no false intermediate states, and the speed no longer falls with the number of stages. Better still, the counting sequence is whatever you design it to be: up, down, 0 to 9, or any list of states. The design method is the same excitation-table procedure every time, and it is the most reliable 16-mark question in this unit.

You need: excitation tables from Chapter 4.4, K-maps with don't cares (Unit 2), and the ripple counter of Chapter 4.7 for comparison.

Synchronous binary up and down counters

Look at a binary count. Bit 0 toggles on every edge. Bit 1 toggles when bit 0 is 1. Bit 2 toggles when bits 1 and 0 are both 1 (…011 → …100). In general bit i toggles exactly when all lower bits are 1. With T flip-flops (or JK with J = K) that is the whole design:

Up:    T₀ = 1,  T₁ = Q₀,  T₂ = Q₀·Q₁,  T₃ = Q₀·Q₁·Q₂
Down:  T₀ = 1,  T₁ = Q̄₀,  T₂ = Q̄₀·Q̄₁,  T₃ = Q̄₀·Q̄₁·Q̄₂   (bit i toggles when all lower bits are 0)

Figure 4.8.1 shows the 3-bit up counter. An up/down counter adds a mode input M (1 = up, 0 = down) and combines the two: Ti = M·Q0…Qi−1 + M̄·Q̄0…Q̄i−1. The AND terms can be built as a chain (each from the previous one and the next bit, called serial carry, slow) or each from scratch (parallel carry, fast but wider gates). A 4-bit synchronous counter with tpd = 20 ns and a 10 ns AND gate runs at 1/(20 + 10) ns ≈ 33 MHz regardless of width, against 12.5 MHz for the ripple version.

The design procedure for any sequence

  1. Write the required counting sequence and draw the state diagram: for MOD-n, states 0 to n − 1 in a loop.
  2. Choose the number of flip-flops k with 2k ≥ n, and the flip-flop type (JK gives the fewest gates; D matches HDL; T suits binary counts).
  3. Build the state table: present state Qk−1…Q0 → next state.
  4. Add the flip-flop input columns from the excitation table, one transition at a time.
  5. Draw a K-map for each flip-flop input in terms of the present state. Unused states (n to 2k − 1) are don't cares.
  6. Draw the circuit: the expressions feed the inputs; all flip-flops share the clock.
  7. Check the unused states: apply the equations to each and confirm it leads back into the sequence within a few clocks. If a state loops among the unused ones (lock-out), change a don't care or add a reset. A counter that recovers by itself is self-correcting.

Christ phrases this through "state diagram, state table, excitation table and maps, circuit implementation", which is the same list; the general state-machine version with inputs is Unit 5. Two ready-made variants that NITC names: the binary counter with parallel load (the 74163: count enable, synchronous load and clear), which makes any MOD-n by detecting n − 1 and loading 0, or by loading a start value; and the BCD counter, which is this procedure applied to the sequence 0 to 9.

4.9 Ring and Johnson counters

Close a shift register on itself and it becomes a counter. Feed the last output straight back to the first input and a single 1 circulates: the ring counter, whose n states need no decoding at all because exactly one output is high at a time. Feed the last output back inverted and the register fills with 1s and then empties: the Johnson (twisted-ring) counter, with 2n states that each decode with one two-input gate. Neither counts in binary, and that is the point: they trade flip-flops for simplicity and glitch-free timing signals, which is what a sequencer, a stepper-motor driver or a multi-phase clock needs.

You need: the shift register of Chapter 4.6 and the PRESET and CLEAR inputs of Chapter 4.3.

Ring counter

Figure 4.9.1 (top) is a 4-bit ring counter: four D flip-flops in a shift chain with Q3 wired back to D0. At power-up the register must be initialised with exactly one 1, by PRESET on FF0 and CLEAR on the others; a shift register full of 0s would shift 0s forever. Each clock moves the 1 one place: 1000 → 0100 → 0010 → 0001 → 1000. Four flip-flops, four states, MOD-4; in general n flip-flops give MOD-n, and each output is a pulse one clock wide, once every n clocks (frequency f/n, duty cycle 1/n). Because the state is "which output is high", the outputs are the decoded states: Q2 high means state 2, with no gate and no glitch. That makes the ring counter a natural sequencer: a control unit that must do step 1, step 2, step 3 in turn. The cost is flip-flops: n of them for n states, against ⌈log2 n⌉ for a binary counter. It is also not self-correcting: a noise pulse that leaves two 1s circulating stays wrong forever unless extra logic detects it.

Johnson (twisted-ring) counter

Now feed Q̄3 back to D0 instead (Figure 4.9.1, bottom). Start from 0000: Q̄3 = 1 enters, so the register fills from the left: 1000, 1100, 1110, 1111. Now Q3 = 1, so 0s enter: 0111, 0011, 0001, 0000. Eight states from four flip-flops: a Johnson counter has MOD-2n, twice the ring counter, and only one bit changes between consecutive states. Christ lists it as a "shift counter"; it is also called the switch-tail or Möbius counter. Each output is a square wave at f/2n with 50 % duty cycle, and the four outputs are the same wave shifted by one clock each, which is why Johnson counters generate multi-phase clocks. Decoding a state needs one two-input AND gate: look at the sequence and notice that each state is the only one with a particular pair of adjacent bits. For 4 bits: 0000 is Q̄0Q̄3, 1000 is Q0Q̄1, 1100 is Q1Q̄2, 1110 is Q2Q̄3, 1111 is Q0Q3, 0111 is Q̄0Q1, 0011 is Q̄1Q2, 0001 is Q̄2Q3. The 2n − 2n leftover states (8 of 16 here) form their own loops, so an unmodified Johnson counter is not self-correcting either; a common fix is to feed D0 from Q̄3 only when the register is in a legal pattern, or simply to use a power-on clear. The CD4017 "decade counter" IC is a 5-stage Johnson counter with its ten decoding gates built in.

Worked example

Question. (a) A 4-bit Johnson counter is clocked at 1 MHz. Find the frequency and duty cycle at Q3, and the phase shift between Q0 and Q1. (b) Give the decoding gate for state 1100 and for state 0011. (c) How many flip-flops are needed for 12 states as a ring, a Johnson and a binary counter? (d) Starting from 0000, what does the Johnson counter hold after 11 clocks?

Solution.

(a) A 4-bit Johnson counter has 2n = 8 states, so one full cycle takes 8 clocks: fQ3 = 1 MHz / 8 = 125 kHz. From the sequence, Q3 is 1 in states 1111, 0111, 0011, 0001 (4 of 8), so the duty cycle is 50 %. Q1 is Q0 delayed by one clock = 1 µs; on an 8 µs period that is 1/8 of a cycle, a phase shift of 45°.

(b) 1100 is the only state with Q1 = 1 and Q2 = 0, so decode with Q1·Q̄2. 0011 is the only state with Q1 = 0 and Q2 = 1: Q̄1·Q2. Check 0011 against 0001: that has Q2 = 0, so the gate stays off; against 0111: Q1 = 1, off. Two inputs suffice.

(c) Ring: N = 12 flip-flops. Johnson: N/2 = 6. Binary: ⌈log2 12⌉ = 4 (with 4 unused states). The ring costs three times the binary counter but needs no decoder.

(d) The sequence repeats every 8 clocks, so after 11 clocks the state is that after 11 − 8 = 3 clocks: 0000 → 1000 → 1100 → 1110.

Exam traps

  • Ring counter: n flip-flops, n states, feedback from Q. Johnson: n flip-flops, 2n states, feedback from Q̄. Swapping the two feedback connections swaps the names and halves or doubles the modulus.
  • A ring counter must be preset with exactly one 1. If the question says "all flip-flops cleared", a ring counter stays at 0000 forever; a Johnson counter starts counting.
  • Johnson decoding uses two inputs because of the sequence's structure, not because of fewer states. Write the pair for the state asked, and check it against the neighbours.
  • Johnson outputs have 50 % duty cycle; ring outputs have 1/n. Examiners ask for the waveform of one output; draw the right width.
  • Favourite questions: "Explain the 4-bit ring counter with a timing diagram", "Compare ring and Johnson counters", "Design a decade Johnson counter" (5 stages).

Beyond the syllabus

Not for the exam. Takeaways

  1. Memory is feedback: a sequential circuit's output depends on a stored state, and the clock decides when that state may change.
  2. Two cross-coupled NOR or NAND gates make the SR latch; the gated D latch (Q = D while enabled) is the practical storage cell.
  3. A flip-flop is edge-triggered: inputs matter only at the clock edge, which is what makes registers and counters safe to build.
  4. JK = SR with toggle; D stores its input; T toggles. Characteristic equations go forwards, excitation tables go backwards.
  5. Any flip-flop converts to any other: required type's characteristic table, available type's excitation table, K-maps.
  6. Race-around (J = K = 1, level clock, tp > Δt) is cured by edge triggering or the master-slave pair; the master-slave still suffers ones-catching.
  7. Shift registers move data one place per clock; SIPO and PISO are the two halves of every serial link; the universal register does hold, shift and load.
  8. Ripple counters are cheap but slow (fmax = 1/(n·tpd)) and glitchy; MOD-n comes from clearing at n.
  9. Synchronous counters change together; any MOD-n or sequence comes from the state-table, excitation-table, K-map procedure, finished with a lock-out check.
  10. Ring (MOD-n, no decoding) and Johnson (MOD-2n, two-input decoding) counters are shift registers closed on themselves and need initialisation.

Outline: 8-row characteristic table; K-map gives Q⁺ = JQ̄ + K̄Q; excitation table 0x, 1x, x1, x0; (a) required D, available JK: J = D, K = D̄; (b) required T, available D: D = T ⊕ Q; circuits drawn.

Q8. Design a MOD-6 synchronous counter using JK flip-flops. Show the state diagram, state table, K-maps, the logic equations and the circuit. Verify that the unused states 110 and 111 do not cause lock-out. (16 marks)

Outline: 3 flip-flops; table 000→001→…→101→000; JK excitation columns; maps with 110, 111 as x; J₂ = Q₁Q₀, K₂ = Q₀; J₁ = Q̄₂Q₀, K₁ = Q₀; J₀ = K₀ = 1; apply equations to 110 and 111 and show each returns to the sequence (110 → 111 → 000 with these equations); draw circuit with common clock.

Q9. Design a 3-bit synchronous up/down counter with a mode input M (M = 1 up, M = 0 down) using T flip-flops. (13 marks)

Outline: T₀ = 1; T₁ = MQ₀ + M̄Q̄₀; T₂ = MQ₀Q₁ + M̄Q̄₀Q̄₁; justification from the binary sequence (bit toggles when lower bits all 1 going up, all 0 going down); circuit with AND-OR per stage and shared clock; brief check of one up and one down transition.

Q10. A 4-bit ripple counter uses flip-flops with tpd = 25 ns. (a) Find the maximum clock frequency without and with a 15 ns decoding gate. (b) Draw the timing diagram for the transition 1111 → 0000 and list the intermediate states. (c) Convert it to a decade counter and draw the reset logic. (13 marks)

Outline: (a) 1/(4 × 25) = 10 MHz; 1/(100 + 15) ≈ 8.7 MHz; (b) 1111 → 1110 → 1100 → 1000 → 0000 at 25 ns steps; (c) NAND(Q₃, Q₁) to CLEAR; sequence 0 to 9; note the transient 1010.

Q11. Draw a 4-bit universal shift register using 4:1 multiplexers and D flip-flops and give its mode table. Starting from 1010, show the contents after: shift right with serial 1; parallel load 0111; shift left with serial 1; hold. (10 marks)

Outline: stage diagram as in Figure 4.6.1; table 00 hold, 01 right, 10 left, 11 load; 1010 → 1101 → 0111 → 1111 → 1111; mention 74194 and NITC's 74LS95/74LS195.

Q12. Explain the 74LS90 decade counter: its internal divide-by-2 and divide-by-5 sections, the R0 and R9 inputs, and how two of them are cascaded to count 0 to 99. (8 marks)

Outline: clock A → QA (÷2), clock B → QBQCQD (÷5); QA to clock B for BCD; R0(1)·R0(2) high resets to 0, R9(1)·R9(2) high sets to 9; cascade by feeding QD of the units counter to clock A of the tens counter; MOD-m × MOD-n = MOD-mn.

Analyze and evaluate

Q13. (Spans 4.2, 4.3, 4.5) A designer builds a 4-bit shift register from gated D latches, then from master-slave D flip-flops, then from edge-triggered D flip-flops. Analyse the behaviour of each and state which work. (10 marks)

Outline: latches: transparent during EN = 1, data races through all stages in one clock, fails; master-slave: master takes input during high, slave outputs at falling edge, works if inputs stable during the high period, ones-catching risk from glitches; edge-triggered: samples at the edge, works, needs th ≤ tpd of the previous stage which is normally satisfied.

Q14. (Spans 4.7, 4.8, 4.9) A system needs a MOD-12 counter whose state must be decoded without glitches to drive twelve indicator lamps at 5 MHz. Compare a ripple binary counter, a synchronous binary counter, a ring counter and a Johnson counter for this task and recommend one with reasons. (13 marks)

Outline: ripple: 4 flip-flops but decoding glitches and fmax limits, reject; synchronous binary: 4 flip-flops plus twelve 4-input decoders, no ripple glitches but multi-bit transitions can still glitch through the decoder; ring: 12 flip-flops, no decoding, glitch-free, needs preset, 5 MHz is easy; Johnson: 6 flip-flops, twelve 2-input gates, one-bit transitions so glitch-free, needs clear; recommend Johnson (or ring if flip-flops are cheap), with initialisation logic.

Q15. (Spans 4.3, 4.4) A lab has only D flip-flops but the counter design sheet is written with JK excitation tables. Explain two ways to proceed and compare the resulting gate counts for a MOD-5 counter. (10 marks)

Outline: way 1: convert each D into a JK with D = JQ̄ + K̄Q (two ANDs and an OR per flip-flop) and keep the JK design; way 2: redo the design with the D excitation table (D = next state) and K-maps; for MOD-5, D₂ = Q₁Q₀, D₁ = Q₁ ⊕ Q₀ (with x), D₀ = Q̄₂Q̄₀; the direct D design uses fewer gates than conversion plus JK logic; general lesson: design for the flip-flop you have.

Q16. Evaluate the statement "a synchronous counter is always better than a ripple counter" with reference to speed, power, glitches, hardware cost and the applications in a wristwatch and a microprocessor. (8 marks)

Outline: speed and glitch-free decoding favour synchronous; ripple has no inter-stage logic and lower power since only early stages toggle fast; wristwatch divider chain is ripple for microwatt power; processor counters synchronous for timing analysis; statement is true for performance, false as a universal rule.

Glossary

Asynchronous input
PRESET or CLEAR on a flip-flop; acts immediately, ignoring the clock.
Asynchronous sequential circuit
One with no clock; memory elements change whenever inputs change.
Binary cell
NITC's name for the basic SR latch, the one-bit memory element.
Characteristic equation
Boolean expression for the next state Q⁺ in terms of the inputs and Q.
Clock skew
Difference in arrival time of the same clock edge at two flip-flops.
Debouncing
Removing the burst of pulses a mechanical switch produces, with a latch, RC filter or software delay.
Duty cycle
Fraction of the clock period during which the clock is high.
Edge-triggered
Responds to inputs only at a clock transition (rising or falling edge).
Excitation table
Table giving the flip-flop inputs needed for each transition Q → Q⁺.
Flip-flop
An edge-triggered (or pulse-triggered) one-bit memory element.
Gated latch
A latch with an enable input; transparent while enabled.
Hold time
Minimum time an input must stay stable after the active clock edge.
Johnson counter
Shift register with the inverted last output fed back; 2n states from n flip-flops. Also twisted-ring or shift counter.
Latch
A level-sensitive one-bit memory element.
Lock-out
A counter stuck cycling among unused states, never entering the designed sequence.
Master-slave flip-flop
Two latches in series enabled by opposite clock levels; output changes at the trailing edge.
Metastability
A flip-flop output hanging between 0 and 1 after a setup or hold violation.
MOD-n counter
A counter with n distinct states; divides the clock frequency by n.
Ones-catching
A master-slave flip-flop latching a brief input pulse that occurs while the clock is high.
PIPO, PISO, SIPO, SISO
Shift register types named by parallel or serial input and output.
Propagation delay (tpd)
Time from the clock edge to the new value at Q.
Race-around condition
Repeated toggling of a level-triggered JK flip-flop with J = K = 1 while the clock is high.
Ring counter
Shift register with the last output fed back; a single 1 circulates through n states.
Ripple counter
Asynchronous counter in which each flip-flop clocks the next.
Self-correcting counter
One whose unused states lead back into the counting sequence.
Setup time
Minimum time an input must be stable before the active clock edge.
Synchronous counter
All flip-flops share one clock; logic decides which toggle.
Toggle
Change of a flip-flop to its opposite state (Q⁺ = Q̄).
Universal shift register
A register that can hold, shift left, shift right or load in parallel under a mode control (74194).
