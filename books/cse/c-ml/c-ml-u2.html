2.1 Linear regression: least squares, simple and multiple

A linear model predicts a number as a weighted sum of its inputs. Study hours go in, marks come out as ŷ = b₀ + b₁x. Least squares chooses the weights so that the squared gap between each actual y and its prediction ŷ is as small as possible. Banks score loan applicants this way, shops forecast demand from price and season, and booking sites estimate tomorrow's load from past days. The method is old, fast and readable: one closed-form answer, no training loop. This chapter builds it for one input, then for many.

You need: vectors, matrices, mean, variance and Σ notation from Unit 1, Foundations: Learning Problems and Concepts (math review).

One input: simple linear regression

Simple linear regression models one input x and one numeric output y. You have n pairs (xᵢ, yᵢ) — for example, hours studied and marks scored by n students.

ŷ = b₀ + b₁x

ŷ (y-hat) is the prediction; x is the input; b₀ is the intercept; b₁ is the slope.

b₁ is the slope: how many units ŷ moves when x rises by 1. b₀ is the intercept: the prediction when x = 0. In the worked example below, b₁ = 2 marks per hour and b₀ = 1 mark.

A real point rarely sits exactly on the line. The gap is the residual eᵢ = yᵢ − ŷᵢ. A positive residual means the model under-predicted. Write ŷ for a prediction and y for the observed value.

SSE = Σ (yᵢ − ŷᵢ)²

SSE is the sum of squared errors, in squared y-units; the sum runs over all n points; yᵢ is observed, ŷᵢ is predicted.

MSE = SSE / n

MSE is the mean squared error, also in squared y-units; n is the number of points.

With p inputs the same idea becomes multiple linear regression: ŷ = b₀ + b₁x₁ + b₂x₂ + … + bₚxₚ. Each bⱼ is the change in ŷ for a one-unit rise in xⱼ while the other inputs are held fixed. Some syllabi call this multivariate regression; the model still has one output and many inputs.

The weights b are unknown. Fitting means choosing them.

Least squares picks the weights

Least squares picks the b that make SSE as small as possible. Squaring does two jobs: it treats +2 and −2 errors as equally bad, and it punishes a large miss far more than a small one. Squaring also keeps the objective smooth, so calculus gives one clean answer.

b₁ = S<sub>xy</sub> / S<sub>xx</sub>,   b₀ = ȳ − b₁x̄

Sxy = Σ(xᵢ − x̄)(yᵢ − ȳ) is the cross-product sum; Sxx = Σ(xᵢ − x̄)²; x̄ and ȳ are the column means.

  1. Compute x̄ and ȳ, the means of the two columns.
  2. Centre every value: (xᵢ − x̄) and (yᵢ − ȳ).
  3. Sum the products for Sxy, and the squared x-gaps for Sxx.
  4. Divide: b₁ = Sxy / Sxx, then b₀ = ȳ − b₁x̄.
  5. Predict new points with ŷ = b₀ + b₁x.

Two facts fall out of the formulas. The line always passes through (x̄, ȳ), because b₀ = ȳ − b₁x̄. And Sxx > 0 unless every x is identical, so a fit exists whenever x varies.

SSE is 0 when every point lies on the line and grows as the points scatter. Squared error is the default loss because it has a closed-form answer; other losses need iterative search — see 2.2.

Many inputs: the normal equation

Stack the data. Put each input row in a matrix X with a leading 1 for the intercept, the weights in a vector w, and the outputs in a vector y. All n equations then become one matrix equation: y = Xw + e.

X is n × (p+1): n rows, one column per input, plus a constant column of 1s. w is (p+1) × 1. y and e are n × 1; e holds the residuals.

SSE = (y − Xw)T(y − Xw)

T means transpose; the product is a 1 × 1 number, the sum of squared residuals.

Set the derivative of SSE with respect to w to zero. What remains is the normal equation XTXw = XTy, solved for w:

w = (X<sup>T</sup>X)<sup>−1</sup>X<sup>T</sup>y

XTX is a (p+1) × (p+1) matrix that must be invertible; XTy is a (p+1) × 1 vector.

The inverse exists only when n ≥ p + 1 and no column is an exact linear combination of the others. A duplicated feature, or the constant column added twice, makes XTX singular. Ridge regression adds λI and repairs it — see 2.6.

Polynomial regression fits y = b₀ + b₁x + b₂x² + … . You build extra columns x², x³ from the same x. The curve is not linear in x, but it is linear in the weights, so it is still linear regression and the normal equation is unchanged. Some syllabi call this curvilinear regression.

The inverse costs about O(p³), which is fine for hundreds of features and too slow for millions; there you minimise SSE by gradient descent instead (2.2). One short note: when a model is nonlinear in the weights themselves, least squares has no closed form and needs iterative search. Only a few universities teach that under the name nonlinear least squares.

Worked example

Question. Five students studied x = 1, 2, 3, 4, 5 hours and scored y = 3, 5, 7, 9, 11 marks. (a) Fit the least-squares line ŷ = b₀ + b₁x. (b) Predict the marks for 6 hours of study. (c) State SSE.

  1. Means: x̄ = (1+2+3+4+5)/5 = 15/5 = 3 hours; ȳ = (3+5+7+9+11)/5 = 35/5 = 7 marks.
  2. Centred x: −2, −1, 0, 1, 2. Centred y: −4, −2, 0, 2, 4.
  3. Sxy = (−2)(−4) + (−1)(−2) + (0)(0) + (1)(2) + (2)(4) = 8 + 2 + 0 + 2 + 8 = 20.
  4. Sxx = (−2)² + (−1)² + 0² + 1² + 2² = 4 + 1 + 0 + 1 + 4 = 10.
  5. b₁ = Sxy / Sxx = 20/10 = 2 marks per hour.
  6. b₀ = ȳ − b₁x̄ = 7 − 2 × 3 = 1 mark.
  7. Line: marks = 2 × hours + 1. At x = 6 hours, ŷ = 2 × 6 + 1 = 13 marks.
  8. Every point lies on the line, so each residual is 0 and SSE = 0 marks².

Answer. marks = 2 × hours + 1, predicting 13 marks at 6 hours, with SSE = 0.

Worked example 2

Question. Three shops spent x = 1, 2, 3 thousand rupees on ads and sold y = 2, 2, 4 units. Fit ŷ = b₀ + b₁x, then compute SSE and MSE.

  1. Means: x̄ = (1+2+3)/3 = 2 thousand rupees; ȳ = (2+2+4)/3 = 8/3 ≈ 2.6667 units.
  2. Centred x: −1, 0, 1. Centred y: 2 − 8/3 = −2/3; 2 − 8/3 = −2/3; 4 − 8/3 = 4/3.
  3. Sxy = (−1)(−2/3) + (0)(−2/3) + (1)(4/3) = 2/3 + 0 + 4/3 = 2.
  4. Sxx = 1 + 0 + 1 = 2.
  5. b₁ = 2/2 = 1 unit per thousand rupees.
  6. b₀ = 8/3 − 1 × 2 = 2/3 ≈ 0.6667 units.
  7. Predictions: 5/3, 8/3, 11/3 ≈ 1.6667, 2.6667, 3.6667 units.
  8. Residuals: 2 − 5/3 = 1/3; 2 − 8/3 = −2/3; 4 − 11/3 = 1/3.
  9. SSE = 1/9 + 4/9 + 1/9 = 6/9 ≈ 0.6667 units². MSE = SSE/3 ≈ 0.2222 units².

Answer. ŷ = 0.6667 + 1 × x, with SSE ≈ 0.6667 units² and MSE ≈ 0.2222 units².

Exam traps

  • Swapping the columns: Sxy uses x-gaps times y-gaps. If you regress x on y instead of y on x you get a different line, with slope Sxy/Syy.
  • Dropping the constant column of 1s from X. Without it the line is forced through the origin, b₀ vanishes and the fit is no longer least squares with an intercept.
  • Reading SSE as MSE. SSE is a raw sum that grows with n; divide by n before comparing models on different numbers of points.
  • Claiming a good model from a high R² on training data. Overfitting can produce it, and extrapolating far outside the observed x is unsafe.
  • Calling a polynomial fit nonlinear regression. It is linear in the weights, so the normal equation still applies; nonlinear least squares means nonlinearity in the weights.

2.2 Loss functions and gradient descent, batch and stochastic

Training a model means choosing parameters that make total error small. You need a loss function that turns many errors into one number, and a rule that changes parameters so that number falls. Gradient descent is the rule: measure the loss's slope, step the other way, repeat. Linear regression, logistic regression and neural networks train this way, from UPI fraud detection to Chennai electricity-demand forecasting.

You need residuals and least squares from 2.1, and derivatives and vectors from Unit 1, Foundations.

Loss functions: turning error into one number

A loss L(ŷ, y) scores one prediction ŷ against true value y. It is near zero when they match, and grows as they separate. The cost J averages or sums the loss over all n training examples. Training chooses weights that minimise J.

MSE = (1/n) Σᵢ₌₁ⁿ (yᵢ − ŷᵢ)²

yᵢ is the true target of training example i, ŷᵢ is the prediction, n is the number of examples. Without 1/n this is SSE, the sum of squared errors. MAE = (1/n) Σ|yᵢ − ŷᵢ| replaces the square with a modulus.

Squared error is the default for regression for four reasons.

  • It is smooth, so a derivative exists everywhere and descent never sticks on a corner.
  • Squaring punishes large errors: an error of 10 costs 100, an error of 1 costs 1.
  • Its derivative 2(ŷ − y) is linear in the error, so steps shrink as the model improves.
  • It matches Gaussian noise around the true value.

MAE is safer with outliers, because one wild point cannot dominate. Its weakness is a corner at zero error, where slope jumps from −1 to +1; descent then uses only the error's sign. SSE and MSE differ by 1/n, which rescales the gradient and changes the learning rate you need.

The gradient and the update rule

Picture J as a surface above parameter w. The derivative dJ/dw is the slope at the current point. A positive slope means J rises to the right, so move left: subtract the slope.

w := w − α ∂J/∂w

w is one weight; α is the learning rate, a small positive number with no units; ∂J/∂w is the partial derivative of J with respect to w; := means 'is replaced by'. With many parameters, ∇J is the gradient vector and all components update at once.

If J is convex — one bowl, no false valleys — descent from any start reaches the single minimum for suitable α. MSE for a linear model is convex in the weights, which is why it is standard. A non-convex loss can trap descent in a local minimum.

The learning rate controls speed. Small α creeps over thousands of steps. Large α jumps across the valley and J can grow every step, so the run diverges. Batch gradient descent, some syllabi call it steepest descent, is the plain version:

  1. Start from any w, often zeros or small random values.
  2. Predict ŷᵢ for all n examples with current w.
  3. Compute J and its gradient ∇J over the whole training set.
  4. Update every parameter: w := w − α∇J.
  5. Repeat until J stops falling or a fixed iteration count ends.

Batch means one update per full pass. The gradient is exact, so the path is smooth, but one step costs n predictions.

Stochastic and mini-batch gradient descent

Stochastic gradient descent (SGD) takes one example, computes that loss's gradient, and updates immediately. The gradient is noisy, so the path zigzags, but each step is n times cheaper and you get n updates per pass. On large data SGD often reaches a good region in one pass where batch descent has barely started.

Mini-batch descent averages the gradient over b examples, typically 32 to 256. It is the practical compromise: less noise than SGD, and vectorised arithmetic fits hardware well.

An epoch is one complete pass through the training set. One epoch gives n updates for SGD, n/b for mini-batch, and 1 for batch. Shuffle before each epoch: sorted data biases early updates and the model wanders.

Convergence and feature scaling

Plot J against epoch. It usually drops steeply then flattens. Stop when one epoch's fall is below a small tolerance, when the gradient norm is near zero, or at a fixed epoch budget. Under SGD the loss jitters around the minimum, so decay α over time, for example α = α₀/(1 + kt) after t epochs.

Scale features before descent. If one input lies in 0–1 and another is annual income in rupees up to 10⁶, the cost surface is a long narrow valley: the gradient is huge on one axis and tiny on the other. One α either bounces across the steep wall or crawls along the floor. Standardise each feature to mean 0 and variance 1, or divide by its maximum; the valley becomes round. Then one α, often 0.001 to 1, trains all parameters at similar speed.

Try α = 0.001, 0.01, 0.1 and plot loss for each. Keep the curve that falls fastest without rising.

Worked example

Question. Minimise J(w) = (w − 3)² + 2 by gradient descent. Start at w₀ = 0 with learning rate α = 0.2. Carry out four updates, give J at w₀ and at w₄, and state the exact minimiser.

  1. Gradient: dJ/dw = 2(w − 3).
  2. J(w₀) = J(0) = (0 − 3)² + 2 = 11.
  3. Update 1: w₁ = 0 − 0.2×2(0 − 3) = 1.2; J(1.2) = (−1.8)² + 2 = 5.24.
  4. Update 2: w₂ = 1.2 − 0.2×2(1.2 − 3) = 1.92; J(1.92) = (−1.08)² + 2 = 3.1664.
  5. Update 3: w₃ = 1.92 − 0.2×2(1.92 − 3) = 2.352; J(2.352) = (−0.648)² + 2 = 2.4199.
  6. Update 4: w₄ = 2.352 − 0.2×2(2.352 − 3) = 2.6112; J(2.6112) = (−0.3888)² + 2 = 2.1512.
  7. Check: each step multiplies distance to minimum by (1 − 2α) = 0.6. Distance after 4 steps = −3×0.6⁴ = −0.3888, so w₄ = 3 − 0.3888 = 2.6112.
  8. Exact minimiser: set dJ/dw = 2(w − 3) = 0, giving w = 3 and J(3) = 2.

Answer. w₄ = 2.6112 with J = 2.1512, closing in on the minimum at w = 3 where J = 2.

Exam traps

  • Sign slip: descent subtracts the gradient. Adding climbs the loss surface.
  • Dropping the 2: derivative of (w − 3)² is 2(w − 3). A missing 2 halves the step.
  • Loss vs cost: L scores one example, J covers the training set. SSE and MSE differ by 1/n, rescaling the gradient and correct α.
  • Large α is not fast training: past a curvature limit, steps overshoot and J grows. With α = 1.1 on this bowl each step grows by 20%.
  • Epoch vs iteration: one epoch is one full pass; SGD makes n updates inside it, batch descent makes one.

2.3 Logistic regression for classification

Logistic regression answers a yes/no question with a probability. It takes the linear score w·x + b from chapter 2.1, passes it through the sigmoid so the output lies between 0 and 1, and then compares that probability against a threshold to give a class. Training maximises the likelihood of the observed 0/1 labels, which produces the binary cross-entropy loss. Banks use it to score loan defaults, hospitals to flag risk, and email systems to filter spam — anywhere you want a calibrated probability and an explainable linear boundary rather than just a label.

You need: the linear score w·x + b from 2.1, gradient descent from 2.2, and basic probability from Unit 1.

Why a straight line cannot be a probability

A linear model computes z = w·x + b, a score that can be any real number. Treating that score directly as a probability fails: it can come out as 1.7 or −0.4. Fitting a line to 0/1 labels by least squares is also badly behaved, because it punishes a confidently correct prediction — a label-1 point with score 3 has squared error 4, so the fit is dragged towards the middle.

σ(z) = 1 / (1 + e^(−z))

σ(z) is the predicted probability of class 1; z = w·x + b is the linear score; w is the weight vector; x is the feature vector; b is the bias; e ≈ 2.718 is the base of natural logarithms.

The sigmoid squashes any real number into the open interval (0, 1). At z = 0 it gives exactly 0.5. It rises towards 1 for large positive z and falls towards 0 for large negative z, never touching either end, so the odds stay finite. Equivalently, the log-odds are linear in x.

log(p / (1 − p)) = w·x + b

p is the probability of class 1; p/(1−p) is the odds; the left-hand side is the log-odds, also called the logit.

So logistic regression is linear in the log-odds, not in p. Some syllabi call it the logit model for exactly this reason. At p = 0.5 the logit is 0, which is why the score z = 0 and the 0.5 threshold line up.

Maximum likelihood gives the cross-entropy loss

Training asks which w and b make the observed labels most likely. For one example with true label y ∈ {0, 1} and predicted probability p, the model assigns probability p to label 1 and 1 − p to label 0. Both cases fit in one expression: p^y (1 − p)^(1−y).

Multiply that over all n training examples, take the natural log to turn the product into a sum, negate it, and divide by n. The result is the binary cross-entropy loss, also called log loss.

L = −(1/n) Σᵢ [ yᵢ ln pᵢ + (1 − yᵢ) ln(1 − pᵢ) ]

n is the number of training examples; yᵢ ∈ {0,1} is the true label of example i; pᵢ = σ(w·xᵢ + b) is its predicted probability; ln is the natural logarithm.

Differentiate and the gradient comes out simple: the derivative with respect to weight wⱼ is (1/n) Σᵢ (pᵢ − yᵢ) xᵢⱼ. That is average prediction error times the feature value, the same shape as the linear regression gradient. There is no closed-form solution, so we descend.

  1. Initialise w and b, usually to zeros.
  2. Compute zᵢ = w·xᵢ + b and pᵢ = σ(zᵢ) for every training example.
  3. Compute g_w = (1/n) Σ (pᵢ − yᵢ) xᵢ and g_b = (1/n) Σ (pᵢ − yᵢ).
  4. Update w ← w − α g_w and b ← b − α g_b, where α is the learning rate.
  5. Repeat until the loss stops falling. This is batch gradient descent from 2.2.

The boundary is linear, the threshold is your choice

To output a label, pick a threshold t and predict class 1 when p ≥ t. The default t = 0.5 is the same as testing z ≥ 0. The set of inputs where z = 0 is the decision boundary: a straight line in two dimensions, a plane in three, a hyperplane in general. Because z is linear in x, that boundary can never curve.

The threshold is a separate decision, not part of the fitted probability. Lower it to 0.2 in a cancer screen and you catch more cases at the price of false alarms. Raise it to 0.9 in a filter that silently deletes mail, because losing a real message costs more than letting spam through. Always state which threshold was used when you report accuracy.

Being linear, logistic regression cannot wrap around a ring of one class inside another. Polynomial features or kernels (Unit 3) fix that. For K classes, replace the sigmoid with the softmax over K scores, p_k = e^(z_k)/Σ_j e^(z_j), and train with categorical cross-entropy. 2.4 studies such linear boundaries directly.

Worked example

Question. A logistic regression model on a single input x has linear score z = −5 + 2x. (a) Find the predicted probability at x = 3. (b) Find the decision boundary for a 0.5 threshold. (c) Find the predicted probability at x = 1 and state the predicted class at threshold 0.5.

  1. Evaluate the score at x = 3: z = −5 + 2(3) = −5 + 6 = 1.
  2. Apply the sigmoid: p = 1 / (1 + e^(−1)) = 1 / (1 + 0.3679) = 1 / 1.3679 = 0.731.
  3. The boundary at threshold 0.5 is where p = 0.5, which means z = 0: −5 + 2x = 0, so 2x = 5 and x = 2.5.
  4. Evaluate the score at x = 1: z = −5 + 2(1) = −3.
  5. Apply the sigmoid: p = 1 / (1 + e^(3)) = 1 / (1 + 20.0855) = 1 / 21.0855 = 0.047.
  6. Compare with the threshold: 0.047 < 0.5, so the model predicts class 0 at x = 1.

Answer. p = 0.731 at x = 3; the 0.5 boundary is at x = 2.5; p = 0.047 at x = 1, which gives class 0.

Exam traps

  • Fitting w and b by least squares on 0/1 labels and calling the result logistic regression. That is a linear probability model: it can predict outside [0, 1] and is not maximum likelihood.
  • Treating p = 0.73 as the answer. The class label exists only after a threshold is fixed; the probability is the model's output, the label is your decision.
  • Forgetting that the threshold can move. Two teams with identical fitted weights can ship different classifiers by choosing t = 0.3 and t = 0.7.
  • Using log base 2 in the loss. The derivation and the neat gradient (p − y) both assume the natural logarithm, ln.

Analyze Show that the gradient of binary cross-entropy with respect to wⱼ is (1/n) Σ (pᵢ − yᵢ) xᵢⱼ. 6 marks

For one example, dL/dp = −y/p + (1 − y)/(1 − p). The sigmoid derivative is dp/dz = p(1 − p). Multiplying gives −y(1 − p) + (1 − y)p = p − y. Then dz/dwⱼ = xⱼ, so dL/dwⱼ = (p − y)xⱼ. Averaging over n examples gives (1/n) Σ (pᵢ − yᵢ) xᵢⱼ.

2.4 Linear classifiers: discriminant functions, binary and multiclass

A linear classifier scores each class with a weighted sum of the input features. The class with the largest score wins. For two classes one score is enough: a positive score means class +, a negative score means class −. The score is called a discriminant function because it separates classes by its sign or by which score is largest. These classifiers are fast, easy to read, and common as baselines in credit scoring, spam filtering, and handwritten digit recognition. The same score idea also appears inside logistic regression and support vector machines.

You need: vectors and dot products from Unit 1, and the linear score in <a href='#logistic-regression-for-classification'>2.3 Logistic regression.

Scores, weights and the binary sign rule

A linear classifier gives each class a score. For two classes, one score is enough. The score is g(x)=w·x+b. Here x=(x1,...,xd) is the feature vector, w=(w1,...,wd) is the weight vector, and b is the bias. The dot product is w·x=w1x1+...+wdxd. The weight wj says how much feature xj pushes the score toward class +. The bias b shifts the score up or down.

g(x) = w·x + b = w<sub>1</sub>x<sub>1</sub> + ... + w<sub>d</sub>x<sub>d</sub> + b

g(x) is the discriminant score; x is the feature vector; w is the weight vector; b is the bias; d is the number of features.

Predict class + if g(x)>0 and class − if g(x)<0. At g(x)=0 the two classes tie and the point lies on the decision boundary; a fixed tie-breaking rule must be chosen. The boundary is g(x)=0. In two dimensions it is a line, in three a plane, and in d dimensions a hyperplane. The vector w is normal to the boundary and points toward the positive side. Logistic regression uses the same score but converts it to a probability; see <a href='#logistic-regression-for-classification'>2.3.

Multiclass scores and argmax

For K classes, use one discriminant per class: gi(x)=wi·x+bi for i=1,...,K. Predict the class with the largest score: ŷ=argmaxi gi(x). The scores are real numbers. They are not probabilities and need not sum to 1. Argmax only compares sizes.

ŷ = argmax<sub>i</sub> g<sub>i</sub>(x),   g<sub>i</sub>(x) = w<sub>i</sub>·x + b<sub>i</sub>

ŷ is the predicted class label; gi(x) is the score for class i; wi is the weight vector for class i; bi is its bias; K is the number of classes.

The boundary between class i and class j is gi(x)=gj(x). This is linear in x. The region for class i is where gi is at least every other score. Such regions are convex. A constant added to every score does not change argmax, but changing one score can. Some syllabi call these linear discriminant functions. For example, scores g1=0.2, g2=1.1, g3=−0.4 give class 2 because 1.1 is largest. Multiclass logistic regression applies softmax to the same scores; the predicted class is still the argmax.

One-vs-rest, one-vs-one and least squares

One-vs-rest trains K binary classifiers. For classifier i, class i is positive and all other classes are negative. At prediction, compute all K scores and take the largest. This is simple but class imbalance can hurt. The K scores are not calibrated probabilities and need not sum to 1.

One-vs-one trains one classifier for each pair of classes. It needs K(K−1)/2 classifiers. Each classifier votes for one class and the class with most votes wins. Each problem is smaller, but there are more models.

A least-squares classifier fits a linear regression to class labels. For two classes, encode class + as +1 and class − as −1. Fit y=w·x+b by least squares, then predict the sign of the fitted value. For K classes, fit K regressions with +1 for the own class and 0 or −1 for others, then take argmax. This gives a linear discriminant but no probability.

Data are linearly separable if some w,b give g(x)>0 for every positive point and g(x)<0 for every negative point. Many boundaries may then exist. If no line separates the classes, a linear classifier must make errors. XOR is the standard non-separable example. Training rules are elsewhere: the perceptron is in Unit 5, maximum margin and kernels in Unit 3, and LDA in Unit 4.

Worked example

Question. A binary linear classifier uses g(x)=2x1+3x2−6, with class + if g(x)>0 and class − if g(x)<0. (a) Find the boundary equation. (b) Classify x=(2,1). (c) Classify x=(0,0).

  1. Set g(x)=0 for the boundary: 2x1+3x2−6=0, so 2x1+3x2=6.
  2. For x=(2,1): g=2(2)+3(1)−6=4+3−6=1. Since 1>0, predict class +.
  3. For x=(0,0): g=2(0)+3(0)−6=0+0−6=−6. Since −6<0, predict class −.

Answer. The boundary is 2x1+3x2=6; (2,1) is class + and (0,0) is class −.

Exam traps

  • Sign slip: write the boundary as g(x)=0, not g(x)=1. The sign rule threshold is 0.
  • Bias: dropping b forces the boundary through the origin and changes every score.
  • Scale: raw weights cannot be compared across features in different units. A weight of 10 per metre is not comparable to 10 per rupee.
  • Multiclass: one-vs-rest scores are not probabilities and need not sum to 1; choose the largest score only.
  • Look-alike: g(x) is a score, not a probability. Logistic regression applies a sigmoid to g(x) before thresholding at 0.5.

2.5 Overfitting, underfitting and the bias-variance trade-off

A model that fits training data too closely learns noise, not the pattern. A model that is too simple misses the pattern. Both fail on new data. We compare training error with validation error to see which is happening. As model complexity rises, training error usually falls, but validation error falls then rises. The bias-variance decomposition explains this shape: bias is error from wrong assumptions, variance is error from sensitivity to the training sample, and σ² is noise no model can remove. This idea guides model choice in regression and classification.

You need: 2.1 Linear regression for model fitting and 2.2 Loss functions and gradient descent for training loss.

Training error versus validation error

Training error is the average loss on the data used to fit the model. Validation error is the average loss on held-out data that the model never saw during fitting. Training error is optimistic: a flexible model can lower it by memorising noise. Validation error estimates performance on new cases, so it is the number to use for model choice. For a curved pattern, a degree-1 polynomial has high training and high validation error: underfitting. A degree-9 polynomial on eight points can drive training error near zero but has high validation error: overfitting. The degree-3 model has the lowest validation error. Training error usually falls as complexity rises, so a small training error alone proves nothing. Dataset size changes the picture: a complex model that overfits 20 points may generalise well with 20,000 points, because more data reduces variance. A learning curve plots training and validation error against training-set size and shows whether collecting more data is likely to help.

Bias-variance decomposition

Let f(x) be the true regression function and f̂(x) the model fitted from a training set D. At a test point x, the expected squared prediction error over random training sets and noise is:

E[(y − f̂(x))²] = bias² + variance + σ²

y is the observed target; f̂(x) is the fitted prediction; E[·] is expectation over training sets and noise; bias = E[f̂(x)] − f(x); variance = E[(f̂(x) − E[f̂(x)])²]; σ² is the variance of irreducible noise.

High bias means the average model is far from the truth: underfitting. High variance means the fitted model changes a lot when the training set changes: overfitting. A simple model has high bias and low variance; a complex model has low bias and high variance. Some syllabi call the need to balance them the bias-variance dilemma. Noise σ² stays even for the true model, so validation MSE cannot be zero. More training data usually reduces variance without raising bias much, which is why data collection is a strong fix for overfitting.

Diagnosing with learning curves

  1. Split the data into a training set and a validation set (see 2.7 for cross-validation).
  2. Fit models of increasing complexity, such as polynomial degrees 1, 3 and 9.
  3. Record training MSE and validation MSE for each model.
  4. Pick the complexity with the lowest validation MSE.
  5. If both errors are high, the model underfits: add features, raise complexity, or reduce regularization.
  6. If training error is low and validation error is high, the model overfits: add data, lower complexity, or regularize (see 2.6).

Plot validation error against complexity. The minimum is the turning point. The training curve alone keeps falling and cannot locate it. Learning curves repeat the same logic against dataset size: if the curves meet at a high error, more data will not help; if a gap remains, more data may reduce variance. The same logic applies to any complexity knob, such as polynomial degree, tree depth, or number of neighbours in kNN (see Unit 3).

Worked example

Question. Eight points are sampled from a smooth curve. Three polynomial models are fitted to the same training set. Degree 1: training MSE 4.2, validation MSE 4.5. Degree 3: training MSE 1.1, validation MSE 1.4. Degree 9: training MSE 0.01, validation MSE 6.8. Compute each generalisation gap (validation MSE minus training MSE). Identify underfitting and overfitting, and choose the model.

  1. Degree 1 gap = 4.5 − 4.2 = 0.3.
  2. Degree 3 gap = 1.4 − 1.1 = 0.3.
  3. Degree-1 gap is also 0.3, but both errors are high (4.2 and 4.5), so the small gap means underfitting, not a good fit. A small gap shows a healthy model only when the errors themselves are small; this is why the next step compares validation MSE levels.
  4. Degree 9 gap = 6.8 − 0.01 = 6.79.
  5. Validation MSEs are 4.5, 1.4 and 6.8. The smallest is 1.4 at degree 3.
  6. Degree 1 has high training and validation error: underfitting, high bias.
  7. Degree 9 has near-zero training error and high validation error, gap 6.79: overfitting, high variance.

Answer. Choose the middle model (degree 3), with validation MSE 1.4; the degree-1 model underfits and the degree-9 model overfits.

Exam traps

  • Judging overfitting by training error. Training error almost always falls as complexity rises; use validation error.
  • Calling a high validation error overfitting. If training error is also high, the model underfits.
  • Mixing bias with the intercept in linear regression. In this chapter bias is systematic error from wrong model assumptions.
  • Expecting validation MSE to reach zero. The noise term σ² remains even for the true function.
  • Choosing complexity on the test set. Choose on validation data; use the test set once for the final report.

2.6 Regularization: ridge and lasso

Regularization adds a penalty for large weights to a model's loss. A model that fits training data too closely can have huge coefficients and high variance. The penalty keeps weights small, trading a little training error for better generalisation. Ridge uses a squared penalty; lasso uses an absolute penalty. Ridge shrinks weights smoothly; lasso can set some weights exactly to zero and select features. Both are used in credit scoring, demand forecasting and any regression with many correlated inputs. The strength is set by λ, a non-negative number.

You need 2.1 least squares and 2.5 overfitting and bias-variance.

Objective: loss plus penalty

Write the linear model as ŷ = b + Σ_j w_j x_j. The target is y, the input vector is x, w_j is the weight on feature j, b is the bias or intercept, and ŷ is the prediction. Ordinary least squares minimises squared error L(w)=½Σ_i(y_i−ŷ_i)². Regularization changes the training objective to J(w)=L(w)+penalty. The penalty is large when weights are large, so the optimizer prefers smaller weights.

J_ridge(w) = ½Σ_i(y_i−ŷ_i)² + ½λΣ_j w_j²    J_lasso(w) = ½Σ_i(y_i−ŷ_i)² + λΣ_j|w_j|

λ ≥ 0 is the regularization strength; w_j is the weight of feature j; y_i and ŷ_i are the actual and predicted targets. The bias b is not in the penalty. The ½ in the ridge term is a convention that keeps derivatives clean.

Ridge is also called L2 regularization because it uses the squared L2 norm. Lasso is L1 regularization because it uses the L1 norm. At λ=0 both reduce to ordinary least squares. As λ rises, weights are pulled toward zero, the model becomes less flexible, variance falls and bias rises. This is the trade-off from 2.5. The penalty must be applied after features are on comparable scales; otherwise the same λ means different things for different columns.

Ridge regression: closed form

For centred data and no penalty on b, ridge minimises J(w)=½||y−Xw||²+½λ||w||². X is the n×d design matrix, each row is one example, y is the n×1 target vector, w is the d×1 weight vector, and I is the d×d identity matrix.

w = (XᵀX + λI)⁻¹Xᵀy

Xᵀ is the transpose of X; λI adds λ to each diagonal entry; the inverse exists for λ>0. This is the normal equation of 2.1 with λI added.

The closed form exists because the ridge objective is strictly convex for λ>0. At λ=0 it is least squares. As λ→∞, w→0. Ridge keeps every feature, so it does not select features. It is useful when many inputs are correlated: the penalty shares weight among them instead of letting least squares produce large opposing coefficients.

Lasso: sparsity and soft threshold

Lasso minimises J(w)=½Σ_i(y_i−ŷ_i)² + λΣ_j|w_j|. The absolute value has no derivative at zero. For a single weight with unregularized value a=3, the objective is ½(w−3)²+λ|w|. If w>0, derivative is (w−3)+λ=0, so w=3−λ. If w<0, derivative is (w−3)−λ=0, so w=3+λ. The pieces meet at zero when λ≥3.

w_lasso = S_λ(a) = sign(a) max(|a|−λ, 0)

S_λ is the soft-threshold function; a is the least-squares value; λ ≥ 0 is the penalty strength. For a=3 and λ=1, w=2. For λ≥3, w=0.

The soft threshold is why lasso is sparse. A coefficient can become exactly zero, so the feature is dropped. Ridge only shrinks toward zero and does not usually reach zero. Use lasso when you suspect only a few inputs matter; use ridge when many inputs are useful and correlated. Feature selection is studied further in Unit 4.

Scaling, tuning and elastic net

Standardise each feature before regularization: subtract its mean and divide by its standard deviation, or scale to unit L2 norm. Then w_j is the change in prediction for a one-standard-deviation change in x_j. Without scaling, a feature measured in rupees and a feature measured in lakhs produce different weight sizes for the same effect. The penalty then lands unevenly across features, and a λ that works for one column may over-penalise another.

Choose λ by cross-validation, not on the training set. Training error always falls as λ falls; validation error has a U shape. The value with best validation error is used to refit on all data. This belongs to 2.7. Never regularize the bias b: shifting predictions by a constant should not be penalised.

Elastic net combines both penalties: J=L+λ(αΣ_j|w_j|+(1−α)Σ_j w_j²), where α∈[0,1]. α=1 is lasso, α=0 is ridge, and middle values keep some sparsity while handling correlated groups.

Worked example

Question. A single weight has unregularized least-squares value w = 3. The regularization strength is λ = 1. Ridge minimises ½(w−3)² + ½λw². Lasso minimises ½(w−3)² + λ|w|. Solve both objectives and compare.

  1. Ridge objective with λ = 1: J_R(w)=½(w−3)² + ½(1)w².
  2. Differentiate ridge: dJ_R/dw = (w−3) + w = 2w−3.
  3. Set 2w−3 = 0, so w = 1.5. The second derivative is 2 > 0, so this is a minimum.
  4. Lasso objective with λ = 1: J_L(w)=½(w−3)² + 1·|w|.
  5. At the optimum w > 0, so |w| = w. Differentiate: dJ_L/dw = (w−3) + 1 = w−2.
  6. Set w−2 = 0, so w = 2. Check w = 2 > 0, so the positive case is valid.
  7. Soft-threshold check: w = sign(3) max(|3|−1, 0) = 1 × 2 = 2.
  8. Compare: ridge gives 1.5 and lasso gives 2.0. Lasso can set weights exactly to zero when λ is large enough; ridge does not.

Answer. Ridge gives w = 1.5 and lasso gives w = 2.0.

Exam traps

  • Regularizing b: the intercept shifts every prediction and should not be penalised.
  • Comparing λ without scaling features: penalty size depends on units, so coefficients and λ values are not comparable.
  • Saying ridge sets weights exactly to zero: ridge shrinks smoothly; lasso has exact zeros, and elastic net can too.
  • Dropping the sign in soft threshold: w=sign(a)max(|a|−λ,0), so a negative a stays negative.
  • Confusing λ with learning rate: λ is penalty strength, not the gradient-descent step size.

2.7 Cross-validation, evaluation metrics and model selection

A model that scores 95% on the data it learned from may fail tomorrow. Cross-validation estimates error on unseen data by rotating which part is held out. Metrics turn those held-out errors into numbers: MAE and RMSE for regression, accuracy, precision, recall and F1 for classification. You use them to choose a model, a threshold or a feature set before spending money on real deployment. The test set is a final exam, not a practice ground.

You need: linear regression, logistic regression and overfitting and bias-variance.

Hold-out splits and k-fold cross-validation

Generalisation error is the error on new cases. You cannot see it directly, so you hold data back. A hold-out split has three parts: train (fit weights), validation (choose hyperparameters, threshold or features) and test (report once). A single split is noisy: a lucky test set flatters the model.

  1. Shuffle the cases and cut them into k equal folds; k = 5 or k = 10 is common.
  2. For j = 1 to k: train on the other k−1 folds, score on fold j.
  3. Average the k scores. Report the mean and the standard deviation.
  • Stratified k-fold keeps the positive-class fraction the same in every fold; use it when one class is rare.
  • Leave-one-out sets k = n: train on n−1 cases, test on one. It is slow for large n.
  • The test set is touched once, after all choices.

Regression metrics: MAE, MSE, RMSE and R²

Regression metrics measure the gap between actual yᵢ and prediction ŷᵢ for n cases; ȳ is the mean of the actual values.

MAE = (1/n) Σ |yᵢ − ŷᵢ|

MAE is mean absolute error; yᵢ is the actual target for case i; ŷᵢ is the predicted target; n is the number of cases. MAE is in the target's units.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²

MSE is mean squared error; each error is squared before averaging. Its unit is the square of the target unit.

RMSE = √MSE

RMSE is root mean squared error. It returns to target units and punishes large errors more than MAE.

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²

R² is the fraction of variance explained; ȳ is the mean actual target. R² = 1 is perfect; R² = 0 means predicting ȳ; negative R² is worse than the mean.

Classification metrics and model selection

Classification starts with a confusion matrix at one threshold: TP true positives, FP false positives, FN false negatives, TN true negatives. Some syllabi call this whole step model assessment.

Accuracy = (TP + TN) / (TP + FP + FN + TN)

Accuracy is the share of all cases classified correctly.

Precision = TP / (TP + FP); Recall = TP / (TP + FN); Specificity = TN / (TN + FP)

Precision asks: when the model says positive, how often is it right? Recall asks: of real positives, how many were found? Specificity is the true-negative rate.

F1 = 2 × Precision × Recall / (Precision + Recall)

F1 is the harmonic mean of precision and recall. It balances the two.

ROC plots recall (true-positive rate) against 1−specificity (false-positive rate) as the threshold moves. AUC is the area under it: 0.5 is random, 1.0 is perfect. Class imbalance breaks accuracy. If 5% are fraud, a model that always says no fraud is 95% accurate and catches nothing. Use precision, recall, F1 or AUC, and stratified folds. For model selection, compare models by mean CV score on the same folds; prefer the simpler model when scores are close. Tune on validation folds, then test once. Domain shift warning: a model trained on old UPI fraud patterns can fail when fraud changes; recheck on fresh data.

Worked example

Question. A classifier is tested on 200 cases: TP = 40, FP = 10, FN = 20, TN = 130. Compute accuracy, precision, recall, specificity and F1. Separately, five-fold CV accuracies are 0.80, 0.82, 0.78, 0.84, 0.81; compute the mean.

  1. Total cases = 40 + 10 + 20 + 130 = 200.
  2. Accuracy = (40 + 130) / 200 = 170 / 200 = 0.850.
  3. Precision = 40 / (40 + 10) = 40 / 50 = 0.80.
  4. Recall = 40 / (40 + 20) = 40 / 60 = 0.667.
  5. Specificity = 130 / (130 + 10) = 130 / 140 = 0.929.
  6. F1 = 2 × 0.80 × 0.667 / (0.80 + 0.667) = 1.0667 / 1.4667 = 0.727.
  7. Mean CV accuracy = (0.80 + 0.82 + 0.78 + 0.84 + 0.81) / 5 = 4.05 / 5 = 0.81.

Answer. Accuracy 0.850, precision 0.80, recall 0.667, specificity 0.929, F1 0.727; mean CV accuracy 0.81.

Exam traps

  • Tuning on the test set. The test set is scored once, after all choices; otherwise it becomes a validation set and your reported score is optimistic.
  • Reporting accuracy on imbalanced data. A 95% accurate classifier can miss every positive case when positives are rare.
  • Confusing precision and recall. Precision divides by predicted positives (TP + FP); recall divides by actual positives (TP + FN).
  • Forgetting units and scale. MSE is in squared target units; RMSE and MAE are in target units, so compare them with the target's range.
  • Data leakage in cross-validation. Scaling, imputing or selecting features before the fold split lets test information leak into training; fit those steps inside each fold.

Check yourself

Remember Define k-fold cross-validation. 2 marks

Split the data into k folds; for each fold, train on the other k−1 folds and score on the held-out fold; average the k scores.

Understand Why use stratified folds when positives are 5% of the data? 3 marks

Plain random folds can put very few or no positives in a fold, so the score is unstable. Stratified folds keep the 5% positive share in every fold.

Apply A test set has TP = 30, FP = 20, FN = 10, TN = 140. Compute precision, recall and F1. 4 marks

Precision = 30/(30+20) = 0.60. Recall = 30/(30+10) = 0.75. F1 = 2×0.60×0.75/(0.60+0.75) = 0.90/1.35 = 0.667.

Analyze Model A has five-fold accuracy 0.90 with SD 0.01; model B has 0.92 with SD 0.05 on the same folds. What should you check before choosing B? 5 marks

Check fold-by-fold differences, whether B's gain is consistent, and the cost of errors. B's high SD means its mean may not generalise; prefer A if scores overlap and simplicity matters.

Apply A regression model has SSE = 200 and SST = 800 on test data. Compute R². 3 marks

R² = 1 − SSE/SST = 1 − 200/800 = 1 − 0.25 = 0.75.

Understand Why is AUC useful when classes are imbalanced? 3 marks

AUC measures ranking across all thresholds, not one accuracy cut. It does not reward a model that always predicts the majority class.

Analyze A fraud model scores AUC 0.95 on last year's UPI data but fails this year. Give one likely cause and one check. 4 marks

Domain shift: fraud patterns changed. Recheck on fresh labelled data and compare recent precision, recall and AUC before deployment.

Takeaways

  1. Least squares has a closed-form solution and is the baseline every regression model is compared against.
  2. Gradient descent is the general training recipe: batch uses all data per step, stochastic uses one point, mini-batch sits between them.
  3. Logistic regression is linear in log-odds, and the 0.5 probability threshold is what turns it into a classifier.
  4. A linear classifier simply picks the class whose linear discriminant score is largest; multiclass problems become several binary scores.
  5. Overfitting is diagnosed by the gap between training and validation error, never by low training error alone.
  6. Bias and variance pull in opposite directions, so model complexity is chosen to balance them, not to minimise either.
  7. Ridge shrinks all weights smoothly; lasso drives some weights to exactly zero and therefore selects features.
  8. Cross-validation estimates test error from limited data, and the chosen metric must match the real cost of mistakes.

Remember and understand

Understand Define simple linear regression. Derive the least-squares estimates of the slope and intercept for one input variable, and state what each symbol means. 10 marks

Model ŷ = w₀ + w₁x and residual eᵢ = yᵢ − ŷᵢ; Minimise RSS = Σ(yᵢ − w₀ − w₁xᵢ)²; Set partial derivatives to zero; w₁ = Σ(xᵢ − x̄)(yᵢ − ȳ) / Σ(xᵢ − x̄)², w₀ = ȳ − w₁x̄; Interpret w₁ as change in ŷ per unit change in x.

Understand Explain gradient descent. Compare batch gradient descent and stochastic gradient descent in cost per step, smoothness of the path and convergence. 10 marks

Update rule w ← w − η ∇L(w); Gradient is the direction of steepest increase; move opposite; Batch: gradient over all n points, stable, expensive per step; SGD: gradient over one point, cheap but noisy, often needs decaying η; Mini-batch as the practical compromise.

Understand Explain logistic regression. Why is a sigmoid used, what does the log-odds form mean, and where is the decision boundary for a 0.5 threshold? 10 marks

Linear score z = wᵀx, probability p = σ(z); σ(z) = 1/(1+e⁻ᶻ) keeps p in (0,1); log(p/(1−p)) = wᵀx, so weights act on log-odds; Decision boundary wᵀx = 0 for threshold 0.5; Cross-entropy loss and its gradient.

Understand Define overfitting and underfitting, sketch the typical training and validation error curves against model complexity, and explain the bias–variance trade-off. 12 marks

Definitions and symptoms of each; Training error falls with complexity; validation error is U-shaped; Bias = error from wrong assumptions; variance = sensitivity to the training sample; Decomposition E[(y − f̂)²] = bias² + variance + σ²; Choose complexity at the validation minimum, then regularise.

Understand Explain ridge and lasso regression. Give the objective functions and explain why the L1 penalty produces sparse solutions while L2 does not. 10 marks

Ridge: RSS + λ Σ wⱼ²; Lasso: RSS + λ Σ |wⱼ|; λ ≥ 0 controls penalty strength; λ = 0 is ordinary least squares; Geometric argument: L1 constraint diamond has corners on axes; Lasso sets some coefficients exactly to zero; ridge only shrinks; Effect on variance and on interpretability.

Analyze A model with 200 features fits the training set to 100% accuracy but scores 62% on held-out data. Diagnose the problem and propose a full plan using regularisation, cross-validation and a baseline. 14 marks

Evaluate A bank wants to flag fraudulent UPI transactions, which are 1 in 1000. Explain why accuracy is a poor metric, build the confusion matrix, and choose between precision, recall, F1 and ROC-AUC for this task. 12 marks

Predicting all transactions as genuine gives 99.9% accuracy; Define TP, FP, FN, TN in this context; Precision = TP/(TP+FP); recall = TP/(TP+FN); False negatives cost money, so recall matters; F1 balances both; ROC-AUC summarises ranking across thresholds; Choose threshold from the cost of FP versus FN.

Evaluate Derive the bias–variance decomposition for squared loss and use it to explain how the ridge penalty λ changes bias and variance. State how you would pick λ in practice. 14 marks

Model y = f(x) + ε with E[ε] = 0, Var(ε) = σ²; E[(y − f̂)²] = bias² + variance + σ²; Bias = E[f̂] − f; variance = E[(f̂ − E[f̂])²]; λ = 0 gives low bias, high variance; large λ raises bias, lowers variance; Pick λ by k-fold cross-validation on a standardised design matrix; Report the chosen λ and the validation curve.

Glossary

Convex function
A function whose graph lies below every chord; any local minimum is global, as in least squares and logistic loss.
Decision boundary
The surface in input space where the predicted class changes, for logistic regression the line wᵀx = 0 at threshold 0.5.
Epoch
One full pass over the training data during gradient descent.
F1 score
The harmonic mean 2PR/(P + R) of precision and recall.
Feature
An input variable xⱼ used by the model.
Hold-out set
Data kept aside and used only once, to estimate final test error.
Hyperparameter
A setting chosen before training, such as λ or the learning rate, not learned from the gradient.
Intercept
The weight w₀, the predicted value when all inputs are zero.
L1 norm
‖w‖₁ = Σ |wⱼ|, the quantity used in the lasso penalty.
L2 norm
‖w‖₂ = √(Σ wⱼ²), the quantity squared in the ridge penalty.
Mean absolute error (MAE)
(1/n) Σ|yᵢ − ŷᵢ|, an error measure less sensitive to outliers than RMSE.
Mini-batch
A small group of examples used for one gradient step, between batch and stochastic.
Normal equation
w = (XᵀX)⁻¹Xᵀy, the closed-form least-squares solution for multiple regression.
Odds
p/(1−p), the ratio of the probability of an event to the probability of no event.
Precision
TP/(TP + FP), the fraction of predicted positives that are correct.
Recall
TP/(TP + FN), the fraction of actual positives that were found.
Regression
Predicting a numeric output from one or more inputs.
Residual sum of squares (RSS)
Σ(yᵢ − ŷᵢ)², the quantity least squares minimises.
RMSE
√((1/n) Σ(yᵢ − ŷᵢ)²), root mean squared error in the units of y.
Shrinkage
Pulling weight estimates towards zero to reduce variance.
Stratified k-fold
k-fold cross-validation where each fold keeps roughly the same class proportions.
Target
The output y the model is trained to predict.
Validation set
Data used to tune hyperparameters and compare models during development.
Weight vector
The collection w = (w₀, w₁, …, w_d) of coefficients learned by a linear model.
