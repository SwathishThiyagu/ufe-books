3.1 Decision tree learning: ID3, entropy, information gain

Decision‑tree learning builds a classifier by repeatedly splitting the training set on an attribute that best separates the classes. The split quality is measured by information gain, which uses entropy – a measure of class impurity. ID3 is the classic algorithm that selects the attribute with highest gain at each node and recurses until the node is pure or no attributes remain. Decision trees are used in credit scoring, medical diagnosis, and many Indian apps such as loan‑approval bots or churn prediction for telecom customers.

You need: basic probability and the definition of entropy from Unit 1 .

Entropy and information gain

Entropy quantifies the uncertainty of a random variable. For a classification problem with classes C₁…Cₖ and probabilities pᵢ, entropy H is defined as

H = - Σ pᵢ log₂ pᵢ

H is measured in bits; pᵢ is the proportion of records belonging to class Cᵢ; Σ runs over all classes.

If a node contains only one class, H = 0 because the outcome is certain. When classes are equally mixed, H reaches its maximum of log₂ k.

When we split a node into children, the impurity of the split is the weighted average of the children’s entropies. Information gain (IG) is the reduction in impurity:

IG = H(parent) - Σ (N_child / N_parent) H(child)

N_parent is the number of records at the parent node; N_child is the number of records in a child; H(child) is the entropy of that child.

  • Higher IG means a better attribute for separating classes.
  • IG is always non‑negative because splitting cannot increase uncertainty.
  • When two attributes give the same IG, ID3 breaks the tie arbitrarily.

ID3 algorithm

  1. Start with the whole training set at the root.
  2. For every attribute that has not been used, compute its information gain.
  3. Select the attribute with the highest gain and create a branch for each of its possible values.
  4. Partition the training set according to the chosen attribute and recurse on each branch.
  5. Stop recursion when the node is pure (entropy = 0) or when no unused attributes remain.

Some syllabi refer to related methods such as CART or C4.5. CART usually selects splits using the Gini impurity (or sometimes entropy), while C4.5 extends ID3 by handling continuous attributes and adding pruning. The greedy selection of the best split is common, but the impurity measure differs for CART.

  • CART can split on numeric thresholds, while ID3 works with categorical values only.
  • C4.5 extends ID3 by handling continuous attributes and pruning the tree.

Python program.

def entropy(pos, neg):
    import math
    total = pos + neg
    if total == 0:
        return 0.0
    p_pos = pos / total
    p_neg = neg / total
    h = 0.0
    if p_pos > 0:
        h -= p_pos * math.log2(p_pos)
    if p_neg > 0:
        h -= p_neg * math.log2(p_neg)
    return h

3.2 Bayes theorem, MAP and maximum likelihood estimation

Bayes theorem tells how to update a belief (prior probability) when new evidence arrives. It gives a posterior probability that combines the prior with the likelihood of the evidence. In classification we use the posterior to pick the most probable class (MAP) or we estimate model parameters that make the observed data most likely (MLE). These ideas appear in spam filters, medical diagnosis, and any system that must learn from data while handling uncertainty.

You need: basic probability from Unit 1. Decision tree learning concepts are useful for understanding information gain, but not required here.

Bayes theorem

Bayes theorem relates four probabilities: the prior P(C), the likelihood P(X|C), the evidence P(X), and the posterior P(C|X). It is written as P(C|X)=P(X|C)·P(C)÷P(X). Here C is a class label and X is a feature vector. The theorem shows how to revise the prior belief about a class after observing X.

P(C|X)=P(X|C)×P(C)÷P(X)

P(C|X) is the posterior probability of class C given data X; P(X|C) is the likelihood of observing X if class C is true; P(C) is the prior probability of class C; P(X) is the marginal probability of X over all classes.

When we compare two classes, P(X) is the same for both and cancels out. Therefore we can rank classes by the product P(X|C)·P(C) without computing P(X). This cancellation is the key to fast MAP classification.

  • Prior P(C) reflects knowledge before seeing the data.
  • Likelihood P(X|C) measures how well the data fits the class.
  • Posterior P(C|X) combines both to give updated belief.

Bayes theorem is the foundation of many classifiers, such as the Naive Bayes model (chapter 3.3) and Bayesian belief networks (chapter 3.5).

Maximum a posteriori (MAP) decision rule

MAP chooses the class with the highest posterior probability. Formally, we select Ĉ = arg max_C P(C|X). Using Bayes theorem and cancelling P(X), this becomes Ĉ = arg max_C P(X|C)·P(C). The term P(C) is called the prior; if all classes are equally likely, MAP reduces to the maximum likelihood rule.

  1. Compute the prior P(C) for each class (may come from training frequencies).
  2. Compute the likelihood P(X|C) for the observed X.
  3. Multiply prior and likelihood for each class.
  4. Pick the class with the largest product.

A common exam mistake is to forget that P(X) cancels when comparing classes, leading to an extra denominator that changes the ranking.

Ĉ = arg max_C P(X|C)×P(C)

Ĉ is the predicted class; P(X|C) is the class‑conditional likelihood; P(C) is the prior probability of class C.

Maximum likelihood estimation (MLE)

MLE finds the parameter values θ that make the observed data most probable. For a data set X={x₁,…,x_n} the likelihood is L(θ)=∏_{i=1}^{n} P(x_i|θ). The MLE θ̂ maximises L(θ) or, equivalently, the log‑likelihood ℓ(θ)=∑ log P(x_i|θ).

  1. Write the probability model P(x|θ).
  2. Form the likelihood L(θ)=∏ P(x_i|θ).
  3. Take the natural log to obtain ℓ(θ)=∑ log P(x_i|θ).
  4. Differentiate ℓ(θ) with respect to θ and set the derivative to zero.
  5. Solve for θ̂.

For a Bernoulli coin with unknown bias θ, the likelihood after observing h heads and t tails is θ^{h}(1-θ)^{t}. Differentiating the log‑likelihood gives θ̂ = h/(h+t). This is the familiar frequency estimate.

  • MLE does not use a prior; it only depends on the observed data.
  • If a prior is added, the resulting estimate is called MAP.
  • MLE can be biased for small samples; MAP often reduces bias.

Worked example

Question. A biased coin is tossed 10 times and shows 7 heads. (a) Find the maximum likelihood estimate of the coin's bias θ. (b) Assuming a Beta(2,2) prior for θ (Laplace smoothing), compute the MAP estimate.

C program.

#include <stdio.h>
int main(){
    int h=7, n=10;
    double mle = (double)h/n;
    double map = (double)(h+1)/(n+2);
    printf("MLE = %.3f\n", mle);
    printf("MAP = %.3f\n", map);
    return 0;
}
  1. MLE: θ̂_MLE = number of heads ÷ total tosses = 7 ÷ 10 = 0.7.
  2. Beta(2,2) prior (Laplace smoothing) adds one pseudo‑count to each outcome.
  3. MAP under Beta(2,2) is (h+1)/(n+2) = (7+1)/(10+2) = 8/12 ≈ 0.667.
  4. Therefore MLE = 0.7 and MAP ≈ 0.667.

Output

MLE = 0.700
MAP = 0.667

Answer. MLE of the bias is 0.7; MAP estimate with a Beta(2,2) prior (Laplace smoothing) is 0.667.

Exam traps

  • Treating P(X) as a constant but forgetting to cancel it when comparing class posteriors leads to wrong MAP rankings.
  • Confusing the uniform prior (Beta(1,1)) with Laplace smoothing; the former gives MAP = MLE, while Laplace adds one pseudo‑count to each outcome.
  • Using the number of heads divided by total tosses for MAP without adding the prior pseudo‑counts, which yields the same value as MLE and may be marked incorrect if the question expects Laplace smoothing.
  • Neglecting to convert percentages to fractions before plugging into formulas, causing unit errors.

3.3 Naive Bayes classifier

Naive Bayes classifier predicts a class by multiplying a prior probability with the likelihood of each feature assuming the features are independent. It is fast, works well with text and sensor data, and is used in spam filters, sentiment analysis, and medical diagnosis.

You need: Bayes theorem and MAP from Chapter 3.2.

Naive Bayes principle

Given a feature vector X = (x₁, x₂, …, xₙ) and a set of classes C₁ … Cₖ, we want the posterior probability P(Cⱼ|X). Bayes theorem gives P(Cⱼ|X) = P(Cⱼ)·P(X|Cⱼ) / P(X).

The naïve assumption says the features are conditionally independent given the class. Therefore P(X|Cⱼ) = ∏_{i=1}^{n} P(xᵢ|Cⱼ).

P(Cⱼ|X) = P(Cⱼ)·∏_{i=1}^{n} P(xᵢ|Cⱼ) ÷ P(X)

P(Cⱼ) is the prior probability of class Cⱼ; P(xᵢ|Cⱼ) is the likelihood of feature xᵢ under class Cⱼ; P(X) is a normalising constant common to all classes.

Because P(X) is the same for every class, we can compare the numerators only. The predicted class is argmax_{Cⱼ} P(Cⱼ)·∏ P(xᵢ|Cⱼ).

  • Fast to train – only count frequencies.
  • Works with high‑dimensional data – the product can be computed in log space. Computing log probabilities avoids numerical underflow because the product of many small numbers becomes a sum of negative logs, which stays within floating‑point range.
  • Often surprisingly accurate despite the independence assumption.

Training: counting and Laplace smoothing

Training a multinomial Naive Bayes model for text is a matter of counting word occurrences in each class.

  1. Count total documents in each class → N_{Cⱼ}.
  2. Count total word tokens in each class → N_{Cⱼ}^{tot}.
  3. For each word w, count occurrences in class Cⱼ → N_{w,Cⱼ}.

P(w|Cⱼ) = (N_{w,Cⱼ}+α) ÷ (N_{Cⱼ}^{tot}+α·V)

α is the Laplace smoothing constant (usually 1); V is the vocabulary size; N_{w,Cⱼ} is the count of word w in class Cⱼ; N_{Cⱼ}^{tot} is the total word count in class Cⱼ.

Without smoothing, a word unseen in a class gives probability zero and forces the whole product to zero. Adding α > 0 avoids this problem.

  • α = 1 is called Laplace smoothing.
  • α < 1 (e.g., 0.5) is called Lidstone smoothing.
  • Choose α by cross‑validation if data are scarce.

Variants and practical tips

When features are continuous, we replace the discrete likelihood with a Gaussian density.

P(xᵢ|Cⱼ) = 1 ÷ (√(2πσ_{Cⱼ}²)) · exp( - (xᵢ-μ_{Cⱼ})² ÷ (2σ_{Cⱼ}²) )

μ_{Cⱼ} and σ_{Cⱼ}² are the mean and variance of feature xᵢ computed over the training samples that belong to class Cⱼ.

Multinomial NB is best for word count vectors. Bernoulli NB treats each word as a binary feature (present / absent).

  • Scaling numeric features before using Gaussian NB is optional; do it when features have very different units or for numerical stability.
  • Remove stop‑words and apply stemming for text data.
  • Use log probabilities to avoid underflow: compute log P(C) + Σ log P(xᵢ|C).

Naive Bayes is a baseline for many competitions. It is also used in real‑time systems because classification is O(number of features).

Question. A spam filter uses a multinomial Naive Bayes model. The vocabulary consists of the words "free" and "win" only (V = 2). In the training set, spam messages contain 30 occurrences of "free" and 20 of "win" out of a total of 100 word tokens. Ham messages contain 5 occurrences of "free" and 2 of "win" out of a total of 200 word tokens. Using Laplace smoothing with α = 1, compute the posterior probability that a new message containing both words (one occurrence each) is spam.

C program.

#include <stdio.h>
int main(){
    double prior_spam = 40.0/120.0;
    double prior_ham = 80.0/120.0;
    double P_free_spam = (30.0+1)/(100.0+2);
    double P_win_spam = (20.0+1)/(100.0+2);
    double P_free_ham = (5.0+1)/(200.0+2);
    double P_win_ham = (2.0+1)/(200.0+2);
    double score_spam = prior_spam * P_free_spam * P_win_spam;
    double score_ham = prior_ham * P_free_ham * P_win_ham;
    double post_spam = score_spam / (score_spam + score_ham);
    printf("%0.3f\n", post_spam);
    return 0;
}
  1. Compute prior probabilities based on document counts:
  2. prior_spam = 40 / (40+80) = 0.3333, prior_ham = 80 / (40+80) = 0.6667.
  3. Compute smoothed likelihoods for each word:
  4. P(free|spam) = (30+1) / (100+1·2) = 31 / 102 = 0.3039.
  5. P(win|spam) = (20+1) / (100+2) = 21 / 102 = 0.2059.
  6. P(free|ham) = (5+1) / (200+2) = 6 / 202 = 0.0297.
  7. P(win|ham) = (2+1) / (200+2) = 3 / 202 = 0.0149.
  8. Compute unnormalised scores:
  9. Score_spam = prior_spam·P(free|spam)·P(win|spam) = 0.3333·0.3039·0.2059 ≈ 0.0209.
  10. Score_ham = prior_ham·P(free|ham)·P(win|ham) = 0.6667·0.0297·0.0149 ≈ 0.0003.
  11. Normalize:
  12. P(spam|msg) = Score_spam / (Score_spam+Score_ham) ≈ 0.0209 / (0.0209+0.0003) ≈ 0.986.

3.4 Bayes optimal classifier and Gibbs algorithm

The Bayes optimal classifier picks the class that minimizes expected 0‑1 loss under the posterior distribution of hypotheses given the data. It gives the lowest possible error for any classifier that uses the same posterior. The Gibbs algorithm samples a single hypothesis from that posterior and uses its prediction; it is a simple way to approximate Bayesian model averaging and is useful when exact averaging is costly.

You need: understanding of posterior probabilities from Naive Bayes classifier.

Bayes optimal classifier

Given a set of hypotheses \(h\) and a posterior distribution \(P(h\mid D)\) after seeing data \(D\), the expected 0‑1 loss of a deterministic classifier that always outputs label \(y\) for an input \(x\) is \(L(y) = \sum_h P(h\mid D)\,\mathbf I\big[h(x) \neq y\big]\). Here \(\mathbf I\) is 1 when the condition is true and 0 otherwise.

L(y) = Σ_h P(h|D)·I[h(x)≠y]

L(y) is expected 0‑1 loss if we always predict y; P(h|D) is posterior of hypothesis h; I[…] is the indicator of mis‑prediction.

The Bayes optimal classifier chooses the label \(y^*\) that minimizes this loss: \(y^* = \arg\min_y L(y)\). For binary classification this is equivalent to picking the majority class under the posterior predictive distribution.

  1. Compute the posterior predictive probability of each class: \(p_y = \sum_h P(h|D)\,\mathbf I[h(x)=y]\).
  2. Select the class with larger \(p_y\).
  3. Report the expected error as \(1-\max_y p_y\).

The posterior predictive probability \(p_y\) is a weighted vote of all hypotheses. Each hypothesis contributes its own prediction weighted by its posterior probability.

In an Indian UPI fraud detection system, each hypothesis may represent a different pattern of fraudulent behaviour. The Bayes optimal rule will flag a transaction if the weighted vote for the fraud class exceeds the vote for the legitimate class.

  • The Bayes optimal error is a lower bound for any classifier that uses the same posterior.
  • It assumes the loss is 0‑1; other losses change the formula but the idea stays the same.
  • Exact computation requires summing over all hypotheses. When the hypothesis space is large, approximation methods are needed.

When the hypothesis space is exponential, dynamic programming or sampling can reduce the cost. The Gibbs algorithm is one such sampling method.

Gibbs algorithm

The Gibbs algorithm draws a single hypothesis \(h\) from the posterior \(P(h\mid D)\) and uses its prediction for the input. It is a stochastic classifier that approximates the Bayesian model average without computing the full weighted vote.

  1. Sample \(h \sim P(h\mid D)\).
  2. Output the label \(h(x)\).

The expected 0‑1 loss of Gibbs is \(L_{Gibbs}=\sum_h P(h\mid D)\,\mathrm{err}(h)\) where \(\mathrm{err}(h)\) is the error of hypothesis \(h\) on the true distribution. Because the sample may be a sub‑optimal hypothesis, \(L_{Gibbs}\ge L_{Bayes}\).

L_Gibbs = Σ_h P(h|D)·err(h)

err(h) is the probability that h mis‑classifies a random example.

In practice Gibbs is useful when the hypothesis space is huge. Sampling can be done by Markov chain Monte Carlo or by simple categorical draw if the posterior is explicit.

During a Chennai power cut, a quick decision may be needed to reroute traffic. Gibbs sampling can give a fast prediction by drawing one hypothesis instead of waiting for a full Bayesian average.

  • Gibbs introduces variance because each run may select a different hypothesis.
  • The variance can be reduced by averaging predictions over multiple independent Gibbs draws.
  • When the posterior is sharply peaked, Gibbs error approaches Bayes error.

Worked example

Question. Two hypotheses for a binary classification task are given: \(h₁\) predicts class 0 with posterior probability 0.6 and \(h₂\) predicts class 1 with posterior probability 0.4. Compute (a) the Bayes optimal error, (b) the Gibbs error, and (c) explain which error is lower and why.

C program.

#include <stdio.h>
int main() {
    double p0 = 0.6, p1 = 0.4;
    double bayes_error = 1.0 - (p0 > p1 ? p0 : p1);
    double err_h1 = 0.4; // h1 predicts 0, error is prob(true=1)
    double err_h2 = 0.6; // h2 predicts 1, error is prob(true=0)
    double gibbs_error = 0.6 * err_h1 + 0.4 * err_h2;

}

3.5 Bayesian belief networks

Bayesian belief networks (BBNs) represent a joint probability distribution as a directed acyclic graph. Each node is a random variable. An edge points from a parent variable to a child that depends directly on it. The graph plus conditional probability tables (CPTs) encode all needed probabilities. BBNs are used for diagnosis, fault detection, and decision support where reasoning under uncertainty is required, for example in medical tests or network failure analysis.

You need Bayes theorem, MAP and maximum likelihood estimation and the Naive Bayes classifier.

Basic concepts

A node represents a random variable X that can take a finite set of values. An arrow X → Y means Y’s distribution depends on X. The graph must contain no directed cycles.

For each node Y, a conditional probability table (CPT) lists P(Y = y | Parents(Y) = p) for every combination of parent values p and every value y of Y.

The joint distribution factorises as

P(X1,…,Xn) = ∏_{i=1}^{n} P(Xi | Parents(Xi))

Xi are the variables; Parents(Xi) are the direct predecessors of Xi in the graph.

The factorisation reduces the number of parameters compared with a full table. For a network with n binary variables and at most two parents per node, at most 4n independent numbers are needed (instead of 2^n).

  • Node = random variable
  • Edge = direct dependence
  • CPT = conditional probabilities
  • Joint distribution = product of the conditional probabilities given by the CPTs

Independence and d‑separation

Two variables A and B are independent given a set Z if every path between A and B is blocked when Z is observed. This graphical test is called d‑separation.

  • Chain A → C → B : conditioning on C blocks the path.
  • Fork A ← C → B : conditioning on C blocks the path.
  • Collider A → C ← B : conditioning on C opens the path; otherwise it stays blocked.

d‑separation lets us read conditional independences directly from the graph, which guides efficient inference.

Variable elimination for exact inference

Variable elimination computes a marginal probability by successively summing out hidden variables while keeping intermediate factors compact.

  1. List all factors (CPTs) that involve any of the variables in the network (including Q, evidence E, and hidden variables).
  2. Choose an elimination order for the non‑query, non‑evidence variables.
  3. For each variable V in the order, multiply all factors that contain V.
  4. Sum out V from the product to create a new factor.
  5. After all eliminations, multiply the remaining factors and normalise.

The algorithm is exact because the product of all CPTs equals the full joint distribution. Normalisation guarantees the result sums to 1.

P(Q = q | E = e) = α × Σ_{V1} … Σ_{Vk} ∏_{f∈F} f

α is a normalising constant; V1…Vk are eliminated variables; F is the set of all CPT factors after evidence is incorporated.

3.6 k-nearest neighbour and instance-based learning

k‑Nearest neighbour (kNN) classifies a new point by looking at the k training points that are closest in feature space and letting them vote. It is simple, needs no training phase, and works well when similar examples have the same label. kNN is used in recommendation systems, handwriting recognition, and fraud detection where a quick similarity check is enough.

You need: Unit 2 distance metrics and basic geometry (see Unit 2).

Euclidean distance and the neighbourhood

For two points x = (x1, x2, …, xm) and y = (y1, y2, …, ym) the Euclidean distance is d(x, y) = √ Σi=1^m (xi - yi)². The square root keeps the distance in the same physical units as the original features. When features have different numeric scales, normalising them is necessary before computing the distance.

d(x, y) = √ Σ (x_i - y_i)²

d(x, y) is the distance; x_i, y_i are the i‑th coordinates of the two points; Σ runs over all feature dimensions.

In the plot of the chapter the query point Q = (3, 4) is compared with six training points. The distances are computed one by one, then sorted to find the nearest neighbours.

  1. Take the coordinates of Q and a training point.
  2. Subtract the coordinates component‑wise.
  3. Square each difference.
  4. Sum the squares.
  5. Take the square root.

If the features are measured in different units (e.g., rupees and kilometres) the raw Euclidean distance can be misleading. Normalising each feature to zero mean and unit variance restores fairness.

Choosing k and voting schemes

The parameter k decides how many neighbours influence the decision. Small k (k = 1) follows the training data very closely and can over‑fit noisy points. Large k smooths the decision surface but may ignore local structure. Typical practice is to try odd values (1, 3, 5, 7) and pick the one with highest cross‑validation accuracy.

  • Majority vote: each neighbour contributes one vote for its class.
  • Distance‑weighted vote: a neighbour at distance d contributes weight 1/d (or 1/d²).
  • Tie‑breaking: choose the class of the nearest neighbour among the tied classes.

Weighted voting can improve accuracy when points are unevenly spaced. Using weight 1/d makes the two Class B neighbours (distances 1.414 and 2.000) outweigh the single Class A neighbour (distance 1.414).

Python program.

import math

def euclidean(p, q):
    return math.sqrt(sum((a-b)**2 for a, b in zip(p, q)))

train = [((1,2),'A'), ((2,3),'A'), ((3,1),'A'),
         ((4,5),'B'), ((5,4),'B'), ((5,6),'B')]
query = (3,4)

# k = 3, distance‑weighted vote
k = 3
neighbors = sorted(train, key=lambda t: euclidean(t[0], query))[:k]
weights = {}
for pt, label in neighbors:
    d = euclidean(pt, query)
    w = 1/d if d != 0 else 1e9
    weights[label] = weights.get(label, 0) + w
pred = max(weights, key=weights.get)
print('Prediction:', pred)

Voronoi view and practical tips

If k = 1, the decision region of each training point is its Voronoi cell: the set of locations that are closer to that point than to any other. Increasing k merges cells of the same class, producing smoother boundaries.

  • Scale features before computing distances.
  • Remove duplicate points to avoid ties.
  • Use efficient data structures (KD‑tree, ball‑tree) for large datasets; these are described in the leave‑out section.

Some syllabi call this whole approach *instance‑based learning* because the model consists of the training instances themselves. The method is non‑parametric: it does not assume any underlying probability distribution.

  1. Normalize or standardize all features.
  2. Choose an odd k by cross‑validation.
  3. Decide on plain or distance‑weighted voting.
  4. Classify each new query using the steps in the earlier section.

3.7 Support vector machines: maximum margin and kernels

Support Vector Machines (SVM) look for the separating hyper‑plane that leaves the largest possible gap, called the margin, between the two classes. A larger margin reduces the chance that small measurement errors will flip a prediction. SVMs are used in text classification, handwriting recognition, and credit‑card fraud detection where a clear decision boundary is needed.

You need linear algebra basics from Unit 1 and distance concepts from 3.6 k‑nearest neighbour.

Maximum margin principle

For a binary problem each training point is (x_i , y_i) where x_i ∈ ℝ^d and y_i ∈ {+1 , –1}. A linear classifier has the form f(x)=w·x + b. The decision boundary is the hyper‑plane w·x + b = 0. The distance of a point to the hyper‑plane equals |w·x + b| / ‖w‖.

margin = 2 / ‖w‖

‖w‖ is the Euclidean norm of the weight vector; the factor 2 comes from the distance between the two parallel margin lines.

The SVM chooses w and b that maximise this margin while keeping all points on the correct side of the margin. This is written as a constrained optimisation problem.

minimise ½‖w‖²   subject to   y_i (w·x_i + b) ≥ 1  for all i

½‖w‖² is the objective to be minimised; the constraints enforce that every point lies outside or on its class‑specific margin line.

Points that satisfy the constraint with equality (y_i (w·x_i + b) = 1) lie exactly on a margin line. These are the support vectors. Removing any other point does not change the solution.

Optimization and support vectors

The problem above is a convex quadratic program. Using Lagrange multipliers α_i ≥ 0 we obtain the dual form

maximise Σ_i α_i – ½ Σ_i Σ_j α_i α_j y_i y_j (x_i·x_j)

α_i are the dual variables; the term (x_i·x_j) is the dot product of two training vectors.

Only α_i > 0 correspond to the support vectors. After solving for α, the primal variables are recovered as

w = Σ_i α_i y_i x_i

w is the weight vector; the sum runs over all support vectors.

b = y_k – w·x_k   for any support vector (x_k , y_k)

b is the bias term; pick any support vector to compute it.

Because the optimisation depends only on dot products, we can replace every dot product by a kernel function K(x_i , x_j). This gives the kernel trick.

Kernel trick and common kernels

A kernel K maps the original space into a higher‑dimensional feature space without computing the coordinates explicitly. The SVM dual becomes

maximise Σ_i α_i – ½ Σ_i Σ_j α_i α_j y_i y_j K(x_i , x_j)

K(x_i , x_j) replaces the dot product; all other steps stay unchanged.

  • Linear kernel: K(x_i , x_j) = x_i·x_j. Gives the original linear SVM.
  • Polynomial kernel: K(x_i , x_j) = (γ x_i·x_j + r)^d, with degree d ≥ 2.
  • Radial‑basis‑function (RBF) kernel: K(x_i , x_j) = exp(‑γ‖x_i – x_j‖²), γ > 0.

Choosing a kernel lets the SVM separate data that are not linearly separable in the original space. For example, a credit‑card transaction dataset may be linearly inseparable in raw amount features, but an RBF kernel can create a smooth non‑linear boundary that isolates fraudulent patterns.

  • Confusing the full margin (distance between the two margin lines) with the half‑margin (distance from the hyper‑plane to a margin line). The optimisation minimises ½‖w‖², not the margin directly.
  • Using the kernel K(x_i,x_j)=‖x_i‑x_j‖² instead of the proper RBF expression exp(-γ‖x_i‑x_j‖²) gives a non‑positive‑definite kernel and breaks the quadratic program.
  • Points with α_i = 0 are not support vectors and lie outside the margin (or on the margin only in the degenerate soft‑margin case where the slack variable is zero).

3.8 Ensembles: bagging, boosting and random forests

Ensembles join several weak learners to lower error and increase stability. Bagging builds each learner on a random bootstrap sample and merges predictions by majority vote. Random forests add random feature selection at each split, decorrelating trees. Boosting (AdaBoost) trains learners sequentially, re‑weighting samples so later models focus on hard cases, and combines them with weighted votes. These methods are used in credit scoring, fraud detection, and Indian e‑commerce recommendation systems where a single model may over‑fit noisy data.

You need: decision trees (3.1) and k‑NN (3.6) for base learners.

Bagging

Bagging stands for bootstrap aggregating. A bootstrap sample is drawn with replacement from the training set; its size equals the original set. Each base learner, often a decision tree, is trained on one such sample. Because samples differ, the trees differ. After training, a new instance is sent to every tree. Each tree outputs a class label. The final prediction is the class that appears most often – majority vote.

For regression, bagging averages the numeric predictions of the base learners instead of voting.

ŷ = argmax_c Σ_i 1{h_i(x)=c}

ŷ is the ensemble prediction; c runs over all classes; h_i(x) is the label given by tree i for input x; 1{·} is 1 if the condition holds, 0 otherwise.

  • Bagging reduces variance of high‑variance learners such as deep trees.
  • It does not change bias much; bias stays similar to a single tree.
  • Some syllabi call bootstrap aggregating simply bagging.
  1. Draw B bootstrap samples from the training data.
  2. Train a base learner on each sample.
  3. For a test point, collect all B predictions.
  4. Return the class with the highest vote count.

Random Forests

A random forest is bagging plus random feature selection. When a tree splits a node, it does not examine all attributes. Instead it picks a random subset of m features (m << total). The best split among this subset is used. This decorrelates trees because different features are chosen at different nodes.

m = √p (for classification)

p is the total number of input features; √p is the integer square‑root, a common default.

For regression tasks a typical default is m = p/3.

  • Each tree sees a different sample and a different feature set.
  • Out‑of‑bag (OOB) samples – those not selected in a bootstrap – give an internal estimate of error.
  • Random forests are widely used in credit scoring and churn prediction in Indian telecom.
  1. For each of B trees, draw a bootstrap sample.
  2. At each node, randomly choose m features.
  3. Select the feature with highest information gain among the m.
  4. Grow the tree to full depth or stop early.
  5. Combine predictions by majority vote.

Boosting (AdaBoost)

AdaBoost builds learners sequentially. It keeps a weight w_j for every training sample j. Initially all weights are equal: w_j = 1/N, where N is the number of samples. A learner is trained on the weighted data. After prediction, the error ε is the sum of weights of mis‑classified samples. The learner’s vote weight α = ½ log((1‑ε)/ε). We then increase weights of mis‑classified samples and decrease weights of correctly classified ones using the explicit formula w_j ← w_j · exp(−α_t y_j h_t(x_j)). The process repeats for T rounds.

α_t = ½ log((1‑ε_t)/ε_t)

α_t is the vote weight for learner t; ε_t is its weighted error.

w_j ← w_j · exp(−α_t y_j h_t(x_j))

y_j ∈ {+1,‑1} is the true label; h_t(x_j) ∈ {+1,‑1} is learner t’s prediction; the product y_j h_t(x_j) is +1 if correct, –1 if wrong.

  • Boosting reduces both bias and variance.
  • The final classifier is sign( Σ_t α_t h_t(x) ).
  • AdaBoost is used for spam detection in Indian email services.
  1. Initialize w_j = 1/N for all j.
  2. Train base learner on weighted data.
  3. Compute weighted error ε.
  4. Compute α = ½ log((1‑ε)/ε).
  5. Update each w_j ← w_j · exp(−α y_j h(x_j)).
  6. Normalize weights so Σ_j w_j = 1.
  7. Repeat for the desired number of rounds.

Worked example

Question. A training set has 4 samples with labels y = [+1, +1, -1, -1]. AdaBoost runs for two rounds using decision stumps that output h₁ = [+1, +1, +1, -1] and h₂ = [+1, -1, -1, -1]. Compute the weight of each sample after round 1, the vote weight α₁, and the final combined prediction for a new point that receives h₁ = +1 and h₂ = -1.

Python program.

# AdaBoost weight update demonstration
import math

# data
y = [1, 1, -1, -1]
h1 = [1, 1, 1, -1]
h2 = [1, -1, -1, -1]
N = len(y)

# init weights
w = [1/N]*N

def round_weights(h, w, y):
    err = sum(w[i] for i in range(N) if h[i]!=y[i])
    alpha = 0.5*math.log((1-err)/err)
    w_new = [w[i]*math.exp(-alpha*y[i]*h[i]) for i in range(N)]
    s = sum(w_new)
    w_new = [v/s for v in w_new]
    return alpha, w_new, err

alpha1, w1, err1 = round_weights(h1, w, y)
alpha2, w2, err2 = round_weights(h2, w1, y)

print('alpha1', alpha1)
print('weights after round1', w1)
print('alpha2', alpha2)
print('final prediction sign', 1 if (alpha1*1 + alpha2*(-1))>0 else -1)
  1. Initialize w_j = 1/4 = 0.25 for j=1..4.
  2. Round 1: compute weighted error ε₁ = sum of weights where h₁ ≠ y.
  3. Mis‑classifications: sample 3 (h₁=+1, y=-1) only. ε₁ = 0.25.
  4. α₁ = ½ log((1‑0.25)/0.25) = ½ log(0.75/0.25) = ½ log(3) ≈ 0.5493.
  5. Update weights: w_j ← w_j · exp(−α₁ y_j h₁(x_j)).
  6. For correctly classified samples (1,2,4): exponent = −α₁·(+1)·(+1) = −0.5493, so new w = 0.25·e^(−0.5493) ≈ 0.25·0.577 = 0.1443.
  7. For mis‑classified sample 3: exponent = −α₁·(−1)·(+1) = +0.5493, new w = 0.25·e^(0.5493) ≈ 0.25·1.732 = 0.4330.
  8. Normalize: total = 0.1443*3 + 0.4330 ≈ 0.866. Divide each by 0.866 → w₁=w₂=w₄≈0.1667, w₃≈0.5.
  9. Round 2: compute weighted error ε₂ using h₂ and the normalized weights.
  10. Mis‑classifications: sample 2 (h₂=-1, y=+1) only. ε₂ = w₂ ≈ 0.1667.
  11. α₂ = ½ log((1‑0.1667)/0.1667) = ½ log(5) ≈ 0.8047.
  12. Final combined prediction for a new point: sign(α₁·(+1) + α₂·(‑1)) = sign(0.5493‑0.8047) = -1.

3.9 Locally weighted regression, RBF networks, case-based reasoning

Locally weighted regression builds a simple model that focuses on data near the query point. It is useful when the relationship changes across the input space, such as predicting demand for a festival ticket in different cities. RBF networks implement the same idea with fixed radial basis functions, and case‑based reasoning retrieves similar past cases to make a new prediction.

You need: linear regression from Unit 2 and a distance metric from 3.6.

Idea of locally weighted regression

Given a query input x, assign each training point x_i a weight w_i that decays with distance. A common choice is the Gaussian weight w_i = exp(-‖x‑x_i‖² /(2σ²)). σ controls the neighbourhood size.

w_i = exp(-‖x‑x_i‖² /(2σ²))

‖·‖ is Euclidean distance, σ > 0 is a bandwidth parameter, and exp denotes the exponential function.

The weighted points are used in an ordinary linear regression. The model y = a + b·x is fitted by minimizing the weighted sum of squared errors Σ w_i (y_i – a – b x_i)².

  1. Compute all weights w_i for the query x.
  2. Form the weighted design matrix Xᵀ W X where W = diag(w_i). Include a column of ones in X to represent the intercept, so each row is [1, x_i].
  3. Solve (Xᵀ W X)⁻¹ Xᵀ W y for the coefficient vector [a, b]ᵀ.

The result is a line that follows the local trend of the data. If σ is very small, only the nearest points matter; if σ is very large, the method reduces to ordinary least squares.

Weighted linear regression formulas

For a single‑feature case the closed‑form solution can be written with weighted means.

x̄_w = Σ w_i x_i / Σ w_i ,  ȳ_w = Σ w_i y_i / Σ w_i

x̄_w and ȳ_w are the weighted averages of the inputs and outputs.

b = Σ w_i (x_i‑x̄_w)(y_i‑ȳ_w) / Σ w_i (x_i‑x̄_w)²

b is the local slope.

a = ȳ_w – b·x̄_w

a is the local intercept.

After computing a and b, the prediction for the query x is ŷ = a + b·x.

  • Choose σ based on cross‑validation.
  • Normalize inputs before computing distances.
  • Weights can be used directly; scaling all weights by the same constant does not affect the solution, so explicit normalisation is not required.

Radial basis function networks and case‑based reasoning

An RBF network replaces the explicit weight computation with a fixed set of centres c_j. Each centre produces a radial basis φ(‖x‑c_j‖). A common φ is the Gaussian φ(r) = exp(-r² /(2σ²)).

ŷ(x) = Σ α_j φ(‖x‑c_j‖)

α_j are trainable linear weights, c_j are centre vectors, and φ is the Gaussian basis.

Training an RBF network consists of (1) selecting centres (often by k‑means), (2) fixing σ, and (3) solving a linear regression for the α_j coefficients.

Case‑based reasoning (CBR) is an instance‑based method that stores past cases (x_i, y_i). To answer a new query, CBR retrieves the k most similar cases using the same distance metric, weighs them (often with the same Gaussian), and returns a weighted average. This is essentially locally weighted regression without fitting a line.

  • CBR is called instance‑based regression in some syllabi.
  • RBF networks can be seen as a parametric version of CBR.
  • Both methods are useful when data are scarce or highly non‑linear.

Worked example

Question. A student wants to predict the price y (in rupees ×10⁴) of a used smartphone based on its age x (in years). The training data are (1,2), (2,3), (3,5), (4,4), (5,6). Use locally weighted regression with σ = 1 and query x = 3. Compute the Gaussian weights, the weighted slope b, intercept a, and the predicted price ŷ.

C program.

#include <stdio.h>
#include <math.h>
int main(){
    double xs[5]={1,2,3,4,5};
    double ys[5]={2,3,5,4,6};
    double sigma=1.0, xq=3.0;
    double w[5];
    double S=0, x_bar=0, y_bar=0;
    for(int i=0;i<5;i++){
        w[i]=exp(-pow(xq-xs[i],2)/(2*sigma*sigma));
        S+=w[i];
        x_bar+=w[i]*xs[i];
        y_bar+=w[i]*ys[i];
    }
    x_bar/=S; y_bar/=S;
    double S_xy=0, S_xx=0;
    for(int i=0;i<5;i++){
        S_xy+=w[i]*(xs[i]-x_bar)*(ys[i]-y_bar);
        S_xx+=w[i]*pow(xs[i]-x_bar,2);
    }
    double b=S_xy/S_xx;
    double a=y_bar - b*x_bar;
    double y_pred=a + b*xq;
    printf("%.2f\n%.2f\n%.2f\n", b, a, y_pred);
    return 0;
}

  2. w₁ = exp(-4/2) = 0.1353, w₂ = exp(-1/2) = 0.6065, w₃ = 1, w₄ = 0.6065, w₅ = 0.1353.
  3. Weighted sums: Σw = 2.4836, Σw·x = 7.4508, Σw·y = 10.3279.
  4. Weighted means: x̄_w = 7.4508 / 2.4836 = 3.00, ȳ_w = 10.3279 / 2.4836 = 4.16.
  5. Compute weighted covariance S_xy = Σ w_i (x_i‑x̄_w)(y_i‑ȳ_w) = 1.690.
  6. Compute weighted variance S_xx = Σ w_i (x_i‑x̄_w)² = 2.295.
  7. Slope b = S_xy / S_xx = 0.74 (rounded to two decimals).
  8. Intercept a = ȳ_w – b·x̄_w = 1.95.
  9. Prediction ŷ = a + b·x = 1.95 + 0.74·3 = 4.16 (≈ ₹41,600).

Class label that appears most frequently among selected neighbours.
MAP estimate
Hypothesis with highest posterior probability.
margin
Shortest distance from the decision hyperplane to the nearest training sample.
maximum likelihood
Parameter values that maximise the probability of observed data.
Naive Bayes
Classifier that assumes conditional independence of features given the class.
posterior probability
Updated probability of a hypothesis after incorporating data.
prior probability
Initial belief about a hypothesis before seeing data.
radial basis function
Kernel that depends only on distance from a centre, commonly Gaussian-shaped.
random forest
Bagging of decision trees with random feature selection at each split.
