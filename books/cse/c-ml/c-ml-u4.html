4.1 Unsupervised learning and types of clustering

Unsupervised learning groups data without using class labels. It is needed when a business has many observations but no predefined categories. The technique discovers hidden patterns, such as customer segments, fraud clusters, or topics in text. It is widely used in retail for market segmentation, in finance for anomaly detection, and in telecom for usage‑pattern analysis.

You need: basic vector notation and Euclidean distance from Unit 1 foundations.

Why unsupervised learning?

In many real‑world problems the data collector records many attributes but does not have a label indicating the class of each record. Supervised models cannot be trained because the target variable is missing. Unsupervised learning fills this gap by finding structure that exists purely in the feature space.

The main motivation is to turn raw data into actionable insight. For a retailer, clustering can reveal groups of customers that spend similarly, enabling targeted promotions. In a power‑grid, clustering can identify regions that experience similar outage patterns, helping planners allocate resources.

  • No need for costly labeling effort.
  • Helps explore data before building predictive models.
  • Provides a basis for downstream tasks such as recommendation or anomaly detection.

Three families of clustering

Clustering algorithms are grouped into three conceptual families. Each family follows a different principle for forming groups.

  • Partitioning: Directly splits the data set into a pre‑specified number K of clusters. The most common examples are K‑means, which iteratively updates cluster centroids to minimise the within‑cluster sum of squares, and K‑medoids, which uses actual data points as centres, making it robust to outliers. A soft/fuzzy partitioning method such as fuzzy C‑means assigns each point a degree of membership to each cluster.
  • Hierarchical: Builds a tree of nested clusters. Agglomerative methods start with each point as its own cluster and repeatedly merge the two closest clusters. Divisive methods start with all points in one cluster and recursively split it. The result is a dendrogram that can be cut at any level.
  • Model‑based: Assumes the data are generated from a mixture of probability distributions. Gaussian mixture models (GMM) treat each cluster as a Gaussian component and use the Expectation‑Maximisation (EM) algorithm to estimate parameters.

Other names you may encounter are partitional clustering for the partitioning family and soft clustering for methods that allow overlapping memberships, such as fuzzy clustering.

Choosing a clustering family – a retailer example

A small retailer has six customers with monthly spend (in rupees): 1200, 1300, 1250, 5000, 5200, 5100. The business wants to separate low‑spend from high‑spend customers. Which clustering family is the most natural choice?

  1. The goal is to obtain two distinct groups, one for low spend and one for high spend.
  2. A partitioning method such as K‑means with K = 2 directly creates two clusters and gives a clear numeric centre for each group.
  3. Hierarchical clustering would also work but produces a full dendrogram that is unnecessary for a simple binary split.
  4. Model‑based methods like GMM could model the data as two Gaussians, but they require estimating variances and are more complex than needed.

Therefore the partitioning family, and specifically K‑means, is the most appropriate for this binary segmentation task.

4.2 K-means clustering algorithm

K‑means clustering partitions data into K groups by finding K centroids that minimise the total within‑cluster sum of squared Euclidean distances. It is used when you need fast, simple grouping such as segmenting customers for a marketing campaign, clustering sensor readings in a smart‑grid, or grouping players by performance in a cricket league.

You need: Euclidean distance and basic vector arithmetic from Unsupervised learning and types of clustering.

Objective function and Lloyd’s iteration

The K‑means objective is to minimise the within‑cluster sum of squares (WCSS): Σᵢ ‖xᵢ‑c_{a(i)}‖² where xᵢ is a data point, c_{a(i)} is the centroid assigned to point i, and ‖·‖ denotes Euclidean distance. A lower value means points are tighter around their centroids.

  1. Initialise K centroids (randomly or by a seeding rule).
  2. Assign each point to the nearest centroid using Euclidean distance.
  3. Recompute each centroid as the arithmetic mean of all points assigned to it.
  4. Repeat the assign‑and‑recompute steps until assignments no longer change or WCSS stops decreasing.

The repeat loop is called Lloyd’s algorithm. Each full pass over the data is one iteration. The algorithm always converges to a local minimum because WCSS strictly decreases at every reassignment unless the solution is already stable.

  • Complexity per iteration is O(n·K) where n is the number of points.
  • Typical number of iterations i is small (often < 20).
  • Overall cost is O(n·K·i).

A better initialisation, K‑means++, chooses the first centroid uniformly at random and each subsequent centroid with probability proportional to the squared distance from the nearest existing centroid. This reduces the chance of poor local minima.

4.3 Hierarchical clustering: agglomerative and divisive

Hierarchical clustering builds a tree of nested clusters. It is used when the number of clusters is not known in advance. The tree, called a dendrogram, shows how points merge or split at different distance levels. It helps in market segmentation, gene expression analysis, and grouping similar cities for logistics planning.

You need: basic distance concepts from Unsupervised learning and types of clustering and matrix handling from K-means clustering algorithm.

Linkage criteria

Linkage defines the distance between two clusters. Single linkage uses the smallest pairwise distance. Complete linkage uses the largest pairwise distance. Average linkage uses the mean of all pairwise distances.

d_single(C_i,C_j)=min_{x∈C_i, y∈C_j} distance(x,y)

d_single is the single‑linkage distance; C_i and C_j are clusters; distance(x,y) is the chosen metric, e.g., Euclidean.

d_complete(C_i,C_j)=max_{x∈C_i, y∈C_j} distance(x,y)

d_complete is the complete‑linkage distance.

<code>d_average(C_i,C_j)= ( Σ_{x∈C_i} Σ_{y∈C_j} distance(x,y) ) ÷ (|C_i|·|C_j|)</code>

d_average is the average‑linkage distance; |C_i| is the number of points in C_i; |C_j| is the number of points in C_j.

Single linkage tends to produce long, chain‑like clusters. Complete linkage gives compact, spherical clusters. Average linkage balances the two.

Agglomerative bottom‑up algorithm

  1. Start with each point as a separate cluster.
  2. Compute the distance matrix between all clusters.
  3. Find the pair with the smallest linkage distance.
  4. Merge the pair into a new cluster.
  5. Update the distance matrix using the chosen linkage rule.
  6. Repeat until only one cluster remains.

The distance matrix is symmetric. After a merge, only the row and column of the new cluster need to be recomputed.

  • Matrix size reduces by one after each merge.
  • The algorithm runs in O(n³) time for naive implementation.
  • Efficient implementations can achieve O(n²) time, for example using the Lance‑Williams update with a priority queue.

Dendrogram interpretation and brief note on divisive clustering

A dendrogram plots the merge distance on the vertical axis. Cutting the tree at a height h yields all clusters whose merge distance is ≤ h.

Divisive clustering starts with all points in one cluster and splits recursively. It is less common because it requires a good splitting criterion.

In practice, agglomerative clustering is used for customer segmentation, image segmentation, and arranging railway stations by travel time.

Worked example

Question. Four cities A, B, C, D have road distances (km): A‑B = 10, A‑C = 20, A‑D = 30, B‑C = 15, B‑D = 25, C‑D = 12. Using agglomerative single‑linkage clustering, list the merges and the distance at which each merge occurs.

Python program.

import sys
# Simple single‑linkage agglomerative clustering for four points
points = ['A','B','C','D']
# distance matrix as dict of tuple -> value
D = {('A','B'):10,('A','C'):20,('A','D'):30,('B','C'):15,('B','D'):25,('C','D'):12}
clusters = [{p} for p in points]
merges = []
while len(clusters) > 1:
    # find closest pair of clusters
    min_dist = float('inf')
    pair = None
    for i in range(len(clusters)):
        for j in range(i+1, len(clusters)):
            # single linkage distance = min over all pairs
            d = min(D.get(tuple(sorted((x,y))) ) for x in clusters[i] for y in clusters[j])
            if d < min_dist:
                min_dist = d
                pair = (i,j)
    i,j = pair
    new_cluster = clusters[i] | clusters[j]
    merges.append((clusters[i], clusters[j], min_dist))
    # remove old clusters and add new
    clusters = [c for k,c in enumerate(clusters) if k not in (i,j)]
    clusters.append(new_cluster)
for a,b,dist in merges:
    print('Merge',a,'and',b,'at',dist)

  4. Smallest remaining distance is 12 (C‑D). Merge C and D into cluster CD at distance 12.

4.4 Gaussian mixture models and the EM algorithm

Gaussian mixture models (GMMs) treat a data set as a weighted sum of several Gaussian distributions. They are used when a single Gaussian cannot capture the shape of the data, such as separating overlapping clusters in speech signals or customer spending patterns. The Expectation‑Maximisation (EM) algorithm finds the component weights, means and covariances that maximise the likelihood, without needing labelled data.

You need: basic probability from Chapter 1.

Gaussian mixture model definition

A GMM with K components represents the probability density of a d‑dimensional vector x as p(x)=∑_{j=1}^{K} π_j 𝒩(x|μ_j,Σ_j). Here π_j is the mixture weight (π_j≥0 and ∑π_j=1), μ_j is the mean vector of component j, and Σ_j is its covariance matrix (positive‑definite). 𝒩 denotes the multivariate Gaussian density.

p(x)=∑_{j=1}^{K} π_j 𝒩(x|μ_j,Σ_j)

π_j is the weight of component j; μ_j is its mean; Σ_j is its covariance; 𝒩(x|μ,Σ)= (2π)^{-d/2}|Σ|^{-1/2} exp[−½(x−μ)ᵀΣ^{-1}(x−μ)]

  • Mixture weights control the size of each cluster.
  • Means locate the centre of each Gaussian.
  • Covariances shape the spread and orientation.

Expectation‑Maximisation algorithm

EM alternates between estimating which component likely generated each data point (E‑step) and updating the parameters to best fit those soft assignments (M‑step). The algorithm guarantees that the data likelihood never decreases.

  1. E‑step: Compute responsibility γ_{ij}=π_j 𝒩(x_i|μ_j,Σ_j) / ∑_{l=1}^{K} π_l 𝒩(x_i|μ_l,Σ_l) for every data point i and component j. Ensure Σ_j γ_{ij}=1 for each i.
  2. M‑step: Update parameters using the responsibilities:
  3. π_j^{new}= (1/N)∑_{i=1}^{N} γ_{ij}
  4. μ_j^{new}= (∑_{i} γ_{ij} x_i) / (∑_{i} γ_{ij})
  5. Σ_j^{new}= (∑_{i} γ_{ij} (x_i−μ_j^{new})(x_i−μ_j^{new})ᵀ) / (∑_{i} γ_{ij})

N is the number of data points. The updates are closed‑form because the Gaussian family is an exponential family distribution.

Convergence and practical tips

EM stops when the increase in log‑likelihood between iterations falls below a small threshold (e.g., 10^{-6}) or after a maximum number of iterations. Random initialisation can lead to local optima; running EM several times and picking the best likelihood is common practice.

  • Check that responsibilities are normalised after the E‑step.
  • If a covariance becomes singular, add a tiny value (e.g., 10^{-6}) to its diagonal.
  • For high‑dimensional data, diagonal covariances reduce computation.

4.5 Dimensionality reduction with principal component analysis

Principal Component Analysis (PCA) reduces the number of variables by projecting data onto orthogonal directions that capture the largest variance. It removes redundancy, speeds up learning algorithms, and helps visualise high‑dimensional data. PCA is used in image compression, finance (risk factors), and sensor data preprocessing.

You need: linear algebra basics from Chapter 1.

What PCA does

PCA finds a new coordinate system for the data. The first axis, called the first principal component, points in the direction where the data vary the most. The second axis is orthogonal to the first and captures the next largest variation, and so on. Because the axes are orthogonal, the variance captured by each component is independent of the others.

  • Maximum variance → most information retained
  • Orthogonal axes → no redundancy
  • Ordered by importance → easy to truncate

Other names for the same technique are the Karhunen‑Loève transform and eigenface method (when applied to face images).

Step‑by‑step computation

  1. Collect the data matrix X of size n × d (n samples, d features).
  2. Compute the mean vector μ = (1/n) Σ_{i=1}^{n} x_i.
  3. Subtract the mean: Z = X – 1·μᵀ (mean centering). Note: μ is subtracted from every sample (row) of X.
  4. Form the covariance matrix Σ = (1/(n‑1)) Z^T Z.
  5. Solve the eigenvalue problem Σv = λv to obtain eigenvalues λ₁ ≥ λ₂ ≥ … ≥ λ_d and eigenvectors v₁, v₂, …, v_d.
  6. Pick the top k eigenvectors; stack them as the matrix W_k (d × k).
  7. Project the centered data: Y = Z W_k.

Σ = (1/(n‑1)) Z^T Z

Σ is the d × d covariance matrix; Z is the mean‑centered data; n is the number of samples.

Y = Z W_k

Y is the n × k matrix of projected coordinates; W_k contains the k selected eigenvectors as columns.

The eigenvalues indicate how much variance each component carries. The total variance equals Σ_{j=1}^{d} λ_j. If we keep only the first k components, the reconstruction error equals Σ_{j=k+1}^{d} λ_j.

Interpretation, error and applications

When k = d, reconstruction is exact because Y W_k^T + μ = X. Since Y = Z W_k, we have Y W_k^T = Z, and Z + μ = X, so reconstruction is exact. When k < d, we approximate each original point by projecting back: X̂ = Y W_k^T + μ. The difference X – X̂ has squared error equal to the sum of the discarded eigenvalues.

  • Choosing k such that Σ_{j=1}^{k} λ_j / Σ_{j=1}^{d} λ_j ≥ 0.90 retains at least 90 % of the variance.
  • In image compression, each image pixel vector is reduced to a few coefficients, saving storage.
  • In finance, the first few components can be interpreted as market factors.

Because PCA is linear, it cannot capture curved manifolds. Non‑linear extensions such as Kernel PCA exist, but they are beyond the scope of this chapter.

4.6 Feature selection and correlation analysis

Feature selection removes irrelevant or redundant variables so that the model stays simple, runs faster and often predicts better. It is needed when data have many columns, such as sensor logs, transaction records or text vectors. Selecting a small, informative subset is useful for regression, classification and even clustering, because it reduces noise and the risk of over‑fitting.

You need the regression basics from Unit 2.

Motivation and basic filter ideas

A filter method evaluates each feature independently of any learning algorithm. The simplest filter is a variance threshold. If a feature varies little across the data set, it cannot help to distinguish outcomes. Compute the variance σ² = Σ (x_i‑μ)² ÷ N. For a sample of data the unbiased estimator uses N‑1 in the denominator. Drop any feature with σ² below a chosen cut‑off, for example 0.01 when values are normalised.

Another common filter uses the Pearson correlation coefficient between a feature x and the target y.

r = Σ (x_i‑μₓ)(y_i‑μ_y) ÷ ((N‑1)·σₓ·σ_y)

μₓ and μ_y are means of x and y; σₓ and σ_y are standard deviations computed with N‑1 in the denominator; the sum runs over all N samples.

The absolute value |r| measures linear association. A typical rule keeps features with |r| ≥ 0.6 because they explain a large part of the variance in y.

  • Variance filter removes constant or near‑constant columns.
  • Correlation filter removes weakly related columns.
  • Both are fast: O(N·d) where d is the number of features.

Wrapper and embedded approaches

Wrapper methods evaluate subsets of features by training a model repeatedly. Forward selection starts with no feature, adds the one that improves validation error the most, and repeats until no improvement occurs. Forward selection evaluates at most d + (d‑1) + … + 1 ≈ d²/2 models, i.e., O(d²), which is much cheaper than exhaustive search but still more expensive than a single embedded method. Because the model is retrained each time, wrappers capture interactions that simple filters miss, but they are computationally expensive.

Embedded methods incorporate selection into the learning algorithm. L1 regularisation (Lasso) adds a penalty λ Σ |w_j| to the loss. During optimisation many weights w_j become exactly zero, automatically discarding the corresponding features.

  1. Choose a base learner (e.g., linear regression).
  2. Add an L1 penalty term with λ chosen by cross‑validation.
  3. Fit the model; coefficients that shrink to zero are removed.

Multicollinearity occurs when two or more retained features are highly correlated (|r| close to 1). It inflates variance of coefficient estimates and can make the model unstable. Detect it by computing a correlation matrix and drop one of each highly correlated pair.

Putting the steps together

A practical pipeline often mixes filters and an embedded method. First apply a variance filter to drop constant columns. Next compute Pearson r with the target and keep those above the threshold. Finally train a Lasso model to prune any remaining redundant features. The result is a compact, well‑behaved feature set ready for any downstream algorithm.

  • Filter → fast, model‑agnostic, may miss interactions.
  • Wrapper → accurate, expensive, model‑specific.
  • Embedded → balanced, leverages optimisation.

4.7 Linear discriminant analysis

Linear discriminant analysis (LDA) finds a single linear combination of features that separates two or more labelled groups as well as possible. It is used when a classification problem needs a low‑dimensional representation that keeps class information, for example to visualise credit‑card fraud patterns, to compress speech features before a neural net, or to speed up a nearest‑neighbour search on a mobile phone.

You need: basic linear algebra and the definition of class mean from PCA and the concept of scatter matrices from earlier classification chapters.

Scatter matrices and the Fisher criterion

Assume the data set has C classes. For class c let N_c be the number of samples, μ_c the class mean vector, and μ the overall mean of all samples. The within‑class scatter matrix S_W measures how points spread around their own class mean. It is defined as S_W = Σ_{c=1}^{C} Σ_{x∈c} (x‑μ_c)(x‑μ_c)ᵀ. The between‑class scatter matrix S_B measures how far each class mean lies from the global mean: S_B = Σ_{c=1}^{C} N_c (μ_c‑μ)(μ_c‑μ)ᵀ.

Fisher’s idea is to choose a projection vector w that makes the ratio of the projected between‑class variance to the projected within‑class variance as large as possible. This ratio is called the Fisher criterion J(w) = (wᵀS_B w) / (wᵀS_W w). Maximising J leads to the generalized eigenvalue problem S_B v = λ S_W v, or equivalently to solving for the eigenvectors of S_W⁻¹S_B.

  • If S_W is singular, regularisation adds a small multiple of the identity matrix.
  • For two classes the optimal w is proportional to S_W⁻¹(μ_1‑μ_2).
  • For more than two classes, the eigenvectors corresponding to the largest eigenvalues form a projection matrix.

J(w) = (wᵀS_B w) ÷ (wᵀS_W w)

w is the projection direction; S_B and S_W are defined above.

Compared with PCA, which ignores class labels and maximises total variance, LDA explicitly uses the label information. PCA may keep directions that are noisy for classification, while LDA discards those directions and keeps only the axes that separate the classes.

Practical considerations and common pitfalls

When the number of features exceeds the number of samples, S_W becomes singular. Regularisation (adding λI) or using a prior dimensionality reduction such as PCA before LDA avoids numerical failure. Multi‑class problems often keep only the top C‑1 eigenvectors because the rank of S_B is at most C‑1.

  • Standardise each feature before computing scatter matrices; otherwise units dominate the direction.
  • Cross‑validate the number of retained LDA components to prevent over‑fitting.
  • LDA assumes each class is Gaussian with equal covariance; violations may reduce performance.

In many Indian banking applications, LDA is used to compress transaction descriptors into a few discriminant scores that feed a rule‑engine for fraud detection. The same idea appears in speech‑recognition pipelines where a bank of phoneme features is reduced before a hidden‑Markov model.

4.8 Evaluating clustering algorithms

Clustering creates groups without labels. To know if the groups are meaningful we need evaluation measures. Internal measures look at the data itself, external measures compare to a known class label. They help choose the number of clusters K and check stability. Only a few universities teach these advanced validation techniques.

You need: Unsupervised learning basics, K‑means, and basic linear algebra.

Internal validation indices

Silhouette measures how well a point fits its own cluster compared to the nearest other cluster. For a point i, a(i) is the average distance to all other points in the same cluster. b(i) is the average distance to points in the nearest different cluster. The silhouette s(i) = (b(i)‑a(i)) ÷ max(a(i),b(i)). The value lies between –1 and 1. A high positive value means the point is well placed.

s(i) = (b(i)‑a(i)) ÷ max(a(i),b(i))

s(i) is silhouette of point i; a(i) is intra‑cluster average distance; b(i) is nearest‑cluster average distance.

Davies‑Bouldin (DB) uses the ratio of intra‑cluster scatter to inter‑cluster separation. For each cluster i, compute S_i = average distance of points in i to its centroid. Compute M_ij = distance between centroids of i and j. DB = (1/K) Σ_i max_{j≠i} (S_i + S_j) ÷ M_ij. Lower DB means better clustering.

DB = (1/K) Σ_i max_{j≠i} (S_i + S_j) ÷ M_ij

K is number of clusters; S_i is scatter of cluster i; M_ij is centroid distance between i and j.

  • Silhouette is easy to compute for any distance metric.
  • DB works with numeric features and can use any distance metric; Euclidean distance is the most common choice.
  • Both indices assume compact, spherical clusters.

External validation indices

When true class labels are available, external indices compare the clustering to the ground truth.

  • Adjusted Rand Index (ARI) counts pairs of points that are placed together or apart in both the clustering and the true labeling, corrected for chance. ARI ranges from –1 to 1; 1 means perfect agreement.
  • Purity assigns each cluster to the most frequent true class in it and measures the fraction of correctly assigned points. Purity is between 0 and 1. It ignores the number of clusters.
  • Normalised Mutual Information (NMI) measures shared information between the clustering and the true labeling, normalised by the average entropy. NMI also ranges from 0 to 1.
ARI = (RI – Expected_RI) ÷ (Max_RI – Expected_RI)

RI is Rand Index; Expected_RI is its expected value for random labeling; Max_RI = 1.

NMI = 2 I(C;K) ÷ (H(C) + H(K))

I(C;K) is mutual information between true classes C and clusters K; H(.) is entropy.

Choosing K and checking stability

The elbow method plots an internal index versus K. The point where improvement slows is the elbow. For silhouette, the peak often indicates the best K.

  1. Run the clustering algorithm for K = 2 up to a chosen maximum K (for example, 10).
  2. Compute the average silhouette for each K.
  3. Plot K on the x‑axis and silhouette on the y‑axis.
  4. Select K at the highest silhouette or where the curve flattens.

Stability tests use resampling. Split the data, cluster each subset, and compare the two clusterings with ARI or NMI. High agreement means the result is robust to data variation.

  • Do not rely on a single index; combine silhouette with DB or external scores.
  • For high‑dimensional data, reduce dimensions first (e.g., PCA) before computing distances.

Question. Six points are clustered into two groups: {A,B,C} and {D,E,F}. Their coordinates are A(0,0), B(1,0), C(0,1), D(5,5), E(6,5), F(5,6). Compute the average Silhouette score using Euclidean distance.

Python program.

# This program reproduces the Silhouette calculation above
import math
pts = {
  'A': (0,0), 'B': (1,0), 'C': (0,1),
  'D': (5,5), 'E': (6,5), 'F': (5,6)
}
clusters = {'A':'C1','B':'C1','C':'C1','D':'C2','E':'C2','F':'C2'}

def dist(p,q):
    return math.hypot(p[0]-q[0], p[1]-q[1])

sil = []
for i in pts:
    same = [dist(pts[i], pts[j]) for j in pts if j!=i and clusters[j]==clusters[i]]
    other = [dist(pts[i], pts[j]) for j in pts if clusters[j]!=clusters[i]]
    a = sum(same)/len(same)
    b = sum(other)/len(other)
    s = (b-a)/max(a,b)
    sil.append(s)
print('Average Silhouette:', sum(sil)/len(sil))
  1. Compute pairwise Euclidean distances.
  2. For each point, calculate a(i) = average distance to points in the same cluster.
  3. For each point, calculate b(i) = average distance to points in the other cluster.
  4. Compute s(i) = (b(i)‑a(i)) ÷ max(a(i),b(i)).
  5. Average s(i) over all six points.

4.9 Fuzzy clustering

Fuzzy C‑means lets each data point belong to every cluster with a degree between 0 and 1. It softens the hard assignment of K‑means, so points near a boundary can share clusters. The method is used in image segmentation, market segmentation where customers may fit several profiles, and in sensor fusion where measurements are noisy.

You need: K‑means basics and basic linear algebra from Unit 1.

Fuzzy C‑means formulation

Each point x_i has a membership u_{ij} to cluster j. For each data point i, the memberships sum to one: Σ_j u_{ij}=1. The fuzzifier m>1 controls how soft the clustering is; m=2 is the usual choice.

J = Σ_i Σ_j u_{ij}^m ‖x_i‑c_j‖²

J is the objective to minimise; u_{ij} is the membership of point i in cluster j; m is the fuzzifier; c_j is the centroid of cluster j; ‖·‖ is Euclidean distance.

Minimising J gives two update rules that are applied alternately until the centroids stop moving.

  1. Update each centroid: c_j = Σ_i u_{ij}^m x_i ÷ Σ_i u_{ij}^m
  2. Update each membership: u_{ij} = 1 ÷ Σ_k (‖x_i‑c_j‖ / ‖x_i‑c_k‖)^{2/(m‑1)}

If a distance becomes zero, the corresponding membership is set to 1 and all others to 0, avoiding division by zero.

  • Only a few universities teach this advanced soft clustering.
  • The algorithm converges to a local minimum of J.

Worked example on a line

Points on a line: 1, 2, 4, 5. Choose two clusters (K=2), fuzzifier m=2, and initialise centroids c₁=1, c₂=5.

  1. Compute distances:
  2. d(1,c₁)=0, d(1,c₂)=4; d(2,c₁)=1, d(2,c₂)=3; d(4,c₁)=3, d(4,c₂)=1; d(5,c₁)=4, d(5,c₂)=0.
  3. Compute memberships (zero‑distance rule gives u₁₁=1, u₄₂=1). For x=2:
  4. denom = (1/1)² + (1/3)² = 1 + 1/9 = 10/9, so u₂₁ = 1/denom = 9/10 = 0.9, u₂₂ = 0.1.
  5. For x=4:
  6. denom = (3/3)² + (3/1)² = 1 + 9 = 10, so u₄₁ = 0.1, u₄₂ = 0.9.
  7. Square memberships (m=2):
  8. u₁₁²=1, u₁₂²=0; u₂₁²=0.81, u₂₂²=0.01; u₃₁²=0.01, u₃₂²=0.81; u₄₁²=0, u₄₂²=1.
  9. Here the index 3 corresponds to the third listed point (x=4).
  10. Update centroids:
  11. c₁ = (1·1 + 0.81·2 + 0.01·4) ÷ (1 + 0.81 + 0.01) = 2.66 ÷ 1.82 ≈ 1.46.
  12. c₂ = (0·1 + 0.01·2 + 0.81·4 + 1·5) ÷ (0 + 0.01 + 0.81 + 1) = 8.26 ÷ 1.82 ≈ 4.54.

After one iteration the clusters have moved toward the middle of the data. Repeating the steps will converge to centroids around 1.5 and 4.5.

Python program.

points = [1, 2, 4, 5]
centroids = [1.0, 5.0]
m = 2.0
for _ in range(1):
    # distances
    d = [[abs(p - c) for c in centroids] for p in points]
    # memberships
    u = []
    for i, dist in enumerate(d):
        if 0.0 in dist:
            # zero distance case
            row = [1.0 if d_ == 0 else 0.0 for d_ in dist]
        else:
            row = []
            for j in range(2):
                denom = sum((dist[j] / dist[k]) ** (2 / (m - 1)) for k in range(2))
                row.append(1.0 / denom)
        u.append(row)
    # update centroids
    for j in range(2):
        num = sum((u[i][j] ** m) * points[i] for i in range(4))
        den = sum(u[i][j] ** m for i in range(4))
        centroids[j] = num / den
print('centroids', centroids)

Worked example

Question. Four customers spend Rs.100, Rs.150, Rs.300 and Rs.350 per month. Use fuzzy C‑means with K=2, m=2, initial centroids 100 and 350. Compute the memberships after the first iteration and the new centroids.

C program.

#include <stdio.h>
#include <math.h>
int main(){
    double points[4] = {100,150,300,350};
    double c[2] = {100.0,350.0};
    double m = 2.0;
    double u[4][2];
    for(int iter=0; iter<1; ++iter){
        for(int i=0;i<4;i++){
            double d0 = fabs(points[i]-c[0]);
            double d1 = fabs(points[i]-c[1]);
            if(d0==0){u[i][0]=1; u[i][1]=0;}
            else if(d1==0){u[i][0]=0; u[i][1]=1;}
            else{
                double denom0 = pow(d0/d0,2) + pow(d0/d1,2);
                double denom1 = pow(d1/d0,2) + pow(d1/d1,2);
                u[i][0] = 1.0/denom0;
                u[i][1] = 1.0/denom1;
            }
        }
        for(int j=0;j<2;j++){
            double num=0, den=0;
            for(int i=0;i<4;i++){
                double w = pow(u[i][j], m);
                num += w*points[i];
                den += w;
            }
            c[j] = num/den;
        }
    }
    printf("%0.1f %0.1f\n", c[0], c[1]);
    return 0;
}
  1. Distances: |100‑100|=0, |100‑350|=250; |150‑100|=50, |150‑350|=200; |300‑100|=200, |300‑350|=50; |350‑100|=250, |350‑350|=0.
  2. Memberships: for 100 → (1,0); for 350 → (0,1).
  3. For 150: denom = (50/50)² + (50/200)² = 1 + (0.25)² = 1 + 0.0625 = 1.0625 → u₁=1/1.0625=0.941, u₂=0.059.
  4. For 300: denom = (200/200)² + (200/50)² = 1 + 4² = 1 + 16 = 17 → u₁=1/17≈0.0588, u₂≈0.9412.
  5. Square memberships and compute new centroids:
  6. c₁ = (1·100 + 0.941²·150 + 0.0588²·300) ÷ (1 + 0.941² + 0.0588²) ≈ 123.8.
  7. c₂ = (0·100 + 0.059²·150 + 0.9412²·300 + 1·350) ÷ (0 + 0.059² + 0.9412² + 1) ≈ 326.2.
