4.1 Unsupervised learning and types of clustering

Unsupervised learning looks for pattern in data that has no answer column. Each row is only a set of features; nobody supplies a label. Clustering is the common unsupervised task: put points that are close under a chosen distance into the same group. Shops use it to segment customers, telecom firms to find call patterns, and image tools to group similar pictures. The method is only as good as the distance and the scaling you choose, because the groups are defined by that choice.

You need Unit 1 on types of learning, especially supervised vs unsupervised, and the math review of vectors and distances (see Unit 1, Foundations: Learning Problems and Concepts).

Unlabeled data and the clustering goal

Unsupervised learning learns structure from data with no target value. A row is an unlabeled record: features only, no class and no numeric target. The algorithm cannot be scored by accuracy, because there is no correct answer to compare with. It can still find groups, low-dimensional structure, or unusual points.

Clustering (some syllabi say cluster analysis) puts records into groups so that records in one group are more similar to each other than to records outside. Similarity is a number that says how alike two records are. A distance is the opposite idea: small distance means high similarity. You must choose it before clustering; it decides what 'close' means.

Two customer records: spend ₹1200 with 2 visits, and spend ₹1500 with 3 visits. If spend is in rupees and visits in single digits, spend dominates any raw distance. A ₹300 gap is huge beside a 1-visit gap. Standardise features or weight them deliberately. The grouping is not a fact about the data alone; it is a fact about data plus distance.

Distance decides similarity

The Euclidean distance is the straight-line gap between two points. In two dimensions, for P=(1,2) and Q=(4,6), the horizontal gap is 3 and the vertical gap is 4. The straight-line gap is 5. The Manhattan distance adds the absolute gaps along each feature: 3+4=7. It is the taxi distance along grid streets. x and y are two features in the same unit for this table.

Both measures treat the two features as comparable. If one feature is spend in rupees and the other is visits, the sum mixes units. A ₹300 difference can swamp a 5-visit difference. Standardise each feature to zero mean and unit variance, or scale visits to a comparable range, before you compute distances. The same data can give different clusters after scaling.

Other distances exist for text counts, sets, and correlation, but Euclidean and Manhattan cover most introductory clustering questions. The distance is a design choice, not a law.

Families of clustering

Clustering methods are classified on three useful axes. The axes are independent; one method can sit on several.

  • Partitional vs hierarchical. Partitional methods split points into k non-overlapping groups in one level. k-means is the standard example. Hierarchical methods build a tree of groups, merging bottom-up or splitting top-down; a dendrogram shows the tree. See hierarchical clustering.
  • Hard vs soft. Hard clustering gives each point one cluster. Soft or fuzzy clustering gives each point a membership degree in every cluster. See fuzzy clustering. A Gaussian mixture is model-based and gives probabilities rather than hard labels.
  • Density-based vs model-based. Density-based methods treat dense regions separated by sparse regions as clusters; DBSCAN is the common one. Some syllabi list DBSCAN as density-based. Model-based methods assume points come from a statistical model, such as a mixture of Gaussians; GMM and EM fit that model.

k-means is hard and partitional. DBSCAN is hard and density-based, and it can leave noise points unassigned. Hierarchical clustering is usually hard. Fuzzy clustering is soft. Name the axis when you answer, because hard does not mean partitional and density-based does not mean k-means.

Exam traps

  • Clustering is not supervised learning. If labels exist, the task is classification or supervised grouping; do not report accuracy on unlabeled data as if it were a label score.
  • Clusters have no target by default. Use cohesion and separation (see evaluation) or external labels only when they are truly available; do not invent ground truth.
  • Raw distance is scale-sensitive. A rupee feature with range thousands will dominate a visits feature with range single digits; standardise or weight features.
  • Hard does not mean partitional. Hard/soft describes membership; partitional/hierarchical describes group structure; density-based/model-based describes what defines a group.
  • DBSCAN is not k-means. It is density-based and can leave noise points unassigned; it does not force every point into one of k groups.

4.2 K-means clustering algorithm

K-means is an unsupervised clustering algorithm. It divides n unlabeled points into k groups called clusters. Each cluster is represented by its centroid, the mean of the points in it. K-means alternates two moves: assign every point to the nearest centroid, then recompute each centroid from its assigned points. It stops when assignments stop changing. The method minimises within-cluster sum of squares, so it produces compact clusters. It is used for customer segments, image colour compression, document grouping, and sensor readings. It is fast, but the answer depends on initial centroids and feature scaling.

You need: Chapter 4.1 for clustering and distance, and Unit 1 vectors and Euclidean distance.

Clusters, centroids and the cost

Take n points x₁, x₂, …, xₙ. Each point is a vector of d features; in the worked example d = 2. A cluster Cⱼ is a set of points. Its centroid μⱼ is the average of those points. The centroid need not be one of the original points. K-means tries to make every point close to its own centroid.

μⱼ = (1/|Cⱼ|) Σ_{x ∈ Cⱼ} x

μⱼ is the centroid of cluster j; |Cⱼ| is the number of points in cluster j; the sum runs over every point x in Cⱼ.

The quality measure is the within-cluster sum of squares, also called SSE or inertia. Small SSE means tight clusters. K-means minimises SSE, but it does not guarantee the global minimum.

SSE = Σ_{j=1}^{k} Σ_{x ∈ Cⱼ} ||x − μⱼ||²

k is the number of clusters chosen before the run; ||x − μⱼ||² is squared Euclidean distance, Σ_{i=1}^{d} (xᵢ − μⱼᵢ)²; SSE is in squared feature units.

Lloyd's algorithm step by step

Some syllabi call this Lloyd's algorithm. It is the standard batch k-means loop.

  1. Choose k, the number of clusters, before the run.
  2. Initialise k centroids. A common choice is k random data points; k-means++ chooses later centroids far from earlier ones, with probability proportional to squared distance.
  3. Assignment step: put each point x in the cluster whose centroid μⱼ is nearest, using squared Euclidean distance ||x − μⱼ||².
  4. Update step: replace each centroid by the mean of the points assigned to it, μⱼ = (1/|Cⱼ|) Σ_{x ∈ Cⱼ} x.
  5. Repeat assignment and update until no point changes cluster, or centroid movement is below a small tolerance. Return the clusters and centroids.

Assignment never increases SSE for fixed centroids, and the mean update never increases SSE for fixed assignments. The run therefore converges. It can converge to a local minimum, so different initial centroids can give different final clusters. If a cluster receives no points, keep its old centroid, reinitialise it, or remove it.

Scaling, outliers and choosing k

  • Scale features first, usually to zero mean and unit variance. Otherwise a feature measured in rupees or kilometres dominates one measured in years.
  • Outliers pull a centroid because the centroid is a mean. One extreme point can shift a cluster. Inspect or trim outliers before clustering when the application allows it.
  • Choose k before the run. The elbow method plots SSE against k and looks for a bend; silhouette, a different criterion, is covered in Chapter 4.8.
  • K-means assumes compact, roughly spherical clusters of similar size. Long curved clusters need another method, such as the hierarchical approach in Chapter 4.3.
  • In a tool, for example scikit-learn, KMeans(n_clusters=k, n_init=10, random_state=0).fit(X) runs this loop and stores labels_ and cluster_centers_.

Exam traps

  • The number of clusters k is not the number of iterations. A run with k = 2 may take 3, 10 or more assignment-update passes.
  • SSE uses squared distances from points to their own centroid after assignment. The centroid update uses the arithmetic mean, not the median or a random point.
  • Do not skip feature scaling. A feature with a large numeric range, such as income in rupees, can dominate distance and hide the real cluster structure.
  • K-means can stop at a local minimum. Two runs on the same data with different initial centroids can return different clusters; report the initialisation and n_init.
  • An outlier pulls a centroid toward itself. Check for extreme points before interpreting clusters, because one point can change the final partition.

4.3 Hierarchical clustering: agglomerative and divisive

Hierarchical clustering builds a tree of clusters instead of one fixed partition. It matters when you do not know k, the number of clusters, in advance or want to see how groups form at different distance scales. Agglomerative clustering starts with every point alone and merges the closest pair again and again; divisive clustering starts with all points together and splits. The tree, called a dendrogram, records the height of every merge or split. It is used in customer segmentation, gene expression analysis, document grouping and fault diagnosis on a network.

You need: Chapter 4.1 for clusters and distances, and the distance review in Unit 1.

Agglomerative clustering: merge from the bottom

Agglomerative clustering is bottom-up. Start with n points. Put each point in its own singleton cluster, so there are n clusters. Define a linkage rule that gives a distance between any two clusters. At every step, find the pair of clusters with the smallest linkage distance. Merge that pair and record the distance as the merge height. Repeat until one cluster remains. This takes n − 1 merges.

  1. Start: n singleton clusters, one per point.
  2. Compute the linkage distance for every cluster pair.
  3. Merge the pair with the smallest distance.
  4. Record that distance as the height of the new join.
  5. Stop when one cluster remains, or earlier if a cut is chosen.
d<sub>single</sub>(A,B) = min d(a,b) for a in A, b in B

A and B are clusters; a and b are points; d(a,b) is the point distance, such as Euclidean distance.

The first merge joins the two closest points. Every later merge joins two groups, not just two points. The order of merges and their heights form the cluster tree, drawn as a dendrogram.

Linkage choices change the tree

The linkage rule decides what closest means between two clusters. A different rule can give a different tree from the same data. Four rules are common.

  • Single linkage: use the smallest distance between any point in A and any point in B. It can chain long clusters.
  • Complete linkage: use the largest distance between any point in A and any point in B. It prefers compact clusters.
  • Average linkage: use the average of all cross distances between points in A and points in B.
  • Ward linkage: merge the pair that gives the smallest increase in the total within-cluster sum of squares.
ΔSSE = (|A| |B| / (|A| + |B|)) ||μ<sub>A</sub> − μ<sub>B</sub>||²

ΔSSE is the increase in within-cluster sum of squares if A and B merge; |A| and |B| are cluster sizes; μA and μB are cluster means; ||x|| is Euclidean length.

Ward works with squared Euclidean distance and tends to make equal-sized, compact clusters. Single linkage can follow a chain of points. Complete and average sit between these extremes.

Divisive clustering and reading a dendrogram

Divisive clustering is top-down. Start with all n points in one cluster. At each step, choose one cluster and split it into two. A common split runs a flat method such as k-means inside that cluster, or removes the longest links in a minimum spanning tree. Stop when every point is alone, or when a stopping rule is met. Divisive clustering needs a rule for which cluster to split and how to split it.

A dendrogram is the picture of the merge or split history. Leaves are the original points. A join is a merge; its height is the distance at which the merge happened. For the five points 1, 2, 4, 8, 9 under single linkage, p1 and p2 join at height 1, p8 and p9 also join at height 1, p4 joins {1,2} at height 2, and the two groups {1,2,4} and {8,9} join at height 4.

To get clusters, cut the dendrogram with a horizontal line at height h. Each vertical line crossed by the cut is one cluster. The cut height is a distance, not a cluster count. Choose h from the problem, or compare cuts with cluster evaluation in Chapter 4.8. Some syllabi call this hierarchical cluster analysis.

  • A cut height is a distance, not a cluster count. At h=3 the five-point example gives two clusters, but at h=1.5 it gives three.

4.4 Gaussian mixture models and the EM algorithm

A Gaussian mixture model (GMM) says the data comes from several Gaussian bells added together with weights. Each bell is a component with its own mean and covariance. The hidden part is which component produced each point. The EM algorithm estimates those hidden memberships and the component parameters together. GMMs are used for soft clustering, density estimation, speaker recognition and anomaly detection. They fit blobs of different shapes and sizes, which k-means cannot do.

You need: Chapter 4.1 for clustering, Unit 1 for probability distributions, and Unit 3 for Bayes and maximum likelihood.

The Gaussian mixture model

A Gaussian mixture model (GMM) writes the probability density of a point x as a weighted sum of K Gaussian densities. The weights are called mixing weights. Each Gaussian is one component of the mixture.

p(x) = Σ<sub>k=1</sub><sup>K</sup> π<sub>k</sub> N(x | μ<sub>k</sub>, Σ<sub>k</sub>)

K is the number of components; πk is the mixing weight of component k, with πk ≥ 0 and Σk πk = 1; μk is its mean vector; Σk is its covariance matrix; N is the Gaussian density.

N(x | μ, Σ) = 1 / ((2π)<sup>d/2</sup> |Σ|<sup>1/2</sup>) × exp(−½ (x − μ)<sup>T</sup> Σ<sup>−1</sup> (x − μ))

d is the number of features; |Σ| is the determinant of the covariance matrix; Σ−1 is its inverse; (x − μ)T is the transpose of the vector x − μ.

The model has a generative story. First pick component k with probability πk. Then draw x from that component's Gaussian. The component label zi is hidden. You see xi only. The label zi takes one value from 1 to K but is not in the data.

Because each component has its own covariance matrix, a GMM can fit elongated, tilted and overlapping blobs. A single Gaussian cannot. K-means, covered in Chapter 4.2, uses hard round-ish clusters instead.

The EM algorithm

EM treats the hidden labels as missing data. It repeats two steps from an initial θ = (π, μ, Σ). The E-step computes each point's responsibility: the probability that component k produced point i, given the current parameters.

r<sub>ik</sub> = π<sub>k</sub> N(x<sub>i</sub> | μ<sub>k</sub>, Σ<sub>k</sub>) ÷ Σ<sub>j=1</sub><sup>K</sup> π<sub>j</sub> N(x<sub>i</sub> | μ<sub>j</sub>, Σ<sub>j</sub>)

rik is the responsibility of component k for point i; for each point i, the responsibilities over all k sum to 1.

  1. Initialise π, μ and Σ for all K components. Random values or a k-means result both work.
  2. E-step: compute rik for every point i and component k from the current parameters.
  3. M-step: update the parameters using the responsibilities as soft counts: πk = (1/n) Σi=1n rik, the average responsibility of component k; μk = Σi=1n rik xi ÷ Σi=1n rik, a responsibility-weighted mean; Σk = Σi=1n rik (xi − μk)(xi − μk)T ÷ Σi=1n rik, a responsibility-weighted covariance.
  4. Compute the log-likelihood. Stop if it changes by less than a small threshold; otherwise go back to the E-step.
L(θ) = Σ<sub>i=1</sub><sup>n</sup> log( Σ<sub>k=1</sub><sup>K</sup> π<sub>k</sub> N(x<sub>i</sub> | μ<sub>k</sub>, Σ<sub>k</sub>) )

L(θ) is the log-likelihood of the observed data under parameters θ; n is the number of points. EM never decreases L at an iteration.

Soft GMM versus hard k-means

K-means gives each point one hard label: the nearest centroid. A GMM gives each point a probability in every component. That is a soft assignment. If you need a hard cluster after EM, take the component with the largest responsibility for each point.

GMMs are more flexible than k-means. Components can have different weights, different spreads and tilted covariance shapes. K-means tends to split round, similar-sized clusters and can struggle when clusters overlap. When all components share one spherical covariance and equal weights, EM behaves much like soft k-means.

  • A GMM is a probabilistic model, so it also gives a density value p(x). K-means gives only cluster labels.
  • Fuzzy clustering in Chapter 4.9 also uses memberships, but its memberships are not probabilities from a Gaussian model.
  • Evaluation of the final clusters is a separate step; see Chapter 4.8.

Worked example

Question. Three one-dimensional points are x = 0, 1, 4. Fit a two-component GMM with equal weights π1 = π2 = 0.5 and with the variances fixed at σ12 = σ22 = 1. Initial means are μ1 = 0 and μ2 = 4. Do one E-step and one M-step for the means. Give the responsibilities for component 1 and the updated means.

Exam traps

  • An unconstrained variance can collapse to zero when a component owns one point. Add a small value to the diagonal or use a prior/minimum variance.
  • Mixing weights πk are not the same as hard cluster sizes. They are model probabilities and must sum to 1.

4.5 Dimensionality reduction with principal component analysis

Principal component analysis (PCA) changes coordinates. It replaces the original features with new, uncorrelated axes called principal components. The first axis points along the largest spread in the data, the second along the next largest spread at right angles to the first, and so on. Keeping only the first few axes gives a smaller feature set with most of the information. PCA is used to compress data, remove redundancy, plot high-dimensional data in two dimensions, and speed up models before classification or clustering.

You need: Chapter 4.1 for unlabeled data, and Unit 1 for vectors, matrices, eigenvalues and eigenvectors.

Centre the data, then measure spread

PCA starts with a data matrix X. It has n rows, one per sample, and d columns, one per feature. The symbol d is the original number of features. A row might hold a customer's age and monthly spend; a column is one feature across all customers.

Subtract the mean of each column. After this, every column has mean zero. Centring matters because PCA studies spread around the mean, not distance from zero.

C = (1/(n−1)) XᵀX

X is the n×d mean-centred matrix; Xᵀ is its transpose; C is the d×d covariance matrix. The diagonal entry C_jj is the variance of feature j, and C_jk is the covariance between features j and k.

The covariance matrix is symmetric. It records how features move together. A positive off-diagonal entry means two features rise together; a negative entry means one rises while the other falls. PCA now looks for directions in which this matrix shows large spread.

  1. Mean-centre each feature. Scale each feature to unit variance if the features use different units.
  2. Form the covariance matrix C.
  3. Find the eigenvalues and eigenvectors of C.
  4. Sort the eigenvectors by their eigenvalues, largest first.
  5. Keep the first k eigenvectors as columns of V_k and compute Z = X V_k.

Eigenvalues give the variance

An eigenvector v of C is a direction that C does not rotate. It only stretches v by a number λ, the eigenvalue. Write this as C v = λ v. For PCA, take v as a unit vector, so vᵀv = 1.

C v_i = λ_i v_i

C is the d×d covariance matrix; v_i is the i-th unit eigenvector; λ_i is its eigenvalue.

Because C is symmetric, its eigenvectors are orthogonal. The first principal component v_1 has the largest λ_1. The variance of the data along v_1 equals λ_1. The second component v_2 is the direction of next largest variance among directions at right angles to v_1, and so on.

Total variance is the sum of all eigenvalues, Σ λ_i. The explained variance ratio of component i is λ_i / Σ λ_j. If the first three ratios are 0.50, 0.30 and 0.10, the first three components keep 90% of the variance. The remaining components carry 10%.

explained variance ratio_i = λ_i / Σ_j λ_j

λ_i is the eigenvalue of component i; the denominator sums all d eigenvalues.

Some syllabi call this transform the Karhunen–Loève transform. The name changes; the calculation is the same.

Project, scale and compute safely

The projection is Z = X V_k. X is the centred n×d matrix. V_k is the d×k matrix whose columns are the first k unit eigenvectors. Z is the n×k score matrix: each row is the same sample written in k new coordinates. The columns of Z are uncorrelated.

Scaling is a separate choice. If one feature is income in rupees and another is height in metres, income variance may be huge only because of its unit. Standardise each column to mean zero and standard deviation one before PCA. If all features share a unit and a meaningful scale, centring alone is often enough.

For large d, do not build C. Use the singular value decomposition X = U S Vᵀ. The columns of V are the principal directions, and the squared singular values divided by n−1 are the eigenvalues of C. Software libraries follow this route because it is numerically stable.

PCA is unsupervised: it never sees class labels. It keeps directions of high variance, which may or may not separate classes. For a supervised projection that uses labels, see Chapter 4.7.

Worked example

Question. A two-feature dataset is already mean-centred. Its covariance matrix is C = [[4, 3], [3, 4]]. Find both eigenvalues, the unit eigenvector for the first principal component, and the explained variance ratio of the first component.

  1. The characteristic equation is det(C − λI) = 0. For this 2×2 matrix: (4−λ)(4−λ) − 3×3 = 0, so λ² − 8λ + 7 = 0.
  2. Solve λ² − 8λ + 7 = 0. The roots are λ = (8 ± √(64−28))/2 = (8 ± 6)/2. Thus λ₁ = 7 and λ₂ = 1.
  3. For λ₁ = 7, solve (C − 7I)v = 0. The first row gives (4−7)x + 3y = 0, so −3x + 3y = 0, hence x = y. A unit vector is v₁ = (1, 1)/√2.
  4. For λ₂ = 1, the first row gives (4−1)x + 3y = 0, so 3x + 3y = 0, hence y = −x. A unit vector is v₂ = (1, −1)/√2.
  5. Total variance is λ₁ + λ₂ = 7 + 1 = 8. The first explained variance ratio is λ₁/8 = 7/8 = 0.875 = 87.5%.

Exam traps

  • PCA uses variance only and ignores class labels. A high-variance direction can be useless for separating classes. Use LDA (Chapter 4.7) when labels exist.
  • Always mean-centre before PCA. Without centring, the first component may point toward the mean of the data rather than along its spread.
  • Standardise when features use different units. A feature measured in rupees can dominate a feature measured in metres only because its variance is larger.
  • The covariance matrix here uses 1/(n−1). Some texts use 1/n; eigenvalues then differ by a constant factor, but the explained variance ratios stay the same.
  • An eigenvector and its negative are the same direction. Software signs can flip between runs. Do not treat a sign change as a different principal component.

4.6 Feature selection and correlation analysis

Feature selection keeps a smaller set of the original columns before a model is trained. It exists because extra features add noise, cost and overfitting risk. Correlation analysis checks how features move with the target and with each other, so redundant or weak columns can be spotted. It is used in credit scoring, churn prediction, medical tests and sensor data. The tools are filter, wrapper and embedded selection, with Pearson correlation as the main filter.

You need: Chapter 4.5 for dimensionality reduction, and Unit 2, Regularization: ridge and lasso, for the L1 penalty.

Feature selection: the idea

Feature selection chooses a subset of the original features and drops the rest. A feature is a column such as age, income or a sensor reading. The target is the value to predict, for example loan default. The output is a smaller table with the same rows and fewer columns. No new column is created. This separates it from PCA, which builds new axes.

Why? More features increase training time and memory. Some are noisy or duplicated. A model can fit noise in training data and fail on new data. Selection also makes a model easier to explain; a bank can say which few applicant details drove a decision.

Merits: faster models, less overfitting, clearer reports. Demerits: information in dropped features is lost, selection can be unstable on small data, and a wrong filter can remove a feature that only helps in combination.

A common warning is data leakage. Choose features using training data only, then apply the same list to test data. Some syllabi call this feature subset selection.

Correlation analysis

Correlation analysis measures how two numeric variables move together. For features, compute it in two directions: each feature with the target y, and each feature with every other feature. A high absolute value with y marks a useful linear feature. A high absolute value between two features marks redundancy.

r = cov(X,Y) / (σX σY)

r is the Pearson correlation; cov(X,Y) is the covariance of X and Y; σX and σY are their standard deviations. r lies from −1 to 1.

r = 1 means a perfect positive straight-line relation; r = −1 means a perfect negative one; r = 0 means no linear association. A filter computes r(Xj, y) and keeps features with |r| ≥ threshold. 0.5 is common but data-dependent. Variance threshold drops near-constant columns. Chi-square tests a categorical feature against a class. Mutual information captures nonlinear dependence.

The figure is a correlation matrix. X1 has r = 0.82 with y, X2 has 0.05, X3 has −0.78, and X1 and X3 have −0.91. X1 and X3 pass a 0.5 filter; X2 does not. X1 and X3 are also redundant as a pair.

Pearson r measures linear association only. A feature can have r ≈ 0 with y and still help through a curve or an interaction. Also, r is not causation.

Wrapper and embedded methods

Filter methods are fast and model-free. Wrapper methods use a model's accuracy to score subsets. Forward selection starts with no features and adds the best one each round. Backward elimination starts with all features and removes the worst. RFE, recursive feature elimination, fits a model, removes the weakest features, and repeats.

Wrappers catch interactions but are expensive: each round retrains the model. Use cross-validation inside the loop, or small data can make the choice unstable.

Embedded methods select during training. L1 lasso adds λΣ|wj| to the loss; it pushes some weights exactly to zero, so those features leave a linear model. See Unit 2, Regularization: ridge and lasso. Tree importance from a random forest ranks features by impurity reduction; permutation importance measures the drop when a feature is shuffled.

Choose by budget. A filter is good for many columns and a quick first pass. A wrapper is good when accuracy matters and training is cheap. L1 is good for a linear model with many features. Always fit selection on training data and apply the same list to test data.

Worked example

Question. A dataset has three features X1, X2, X3 and target y. The correlations with y are r(X1,y)=0.82, r(X2,y)=0.05 and r(X3,y)=−0.78. Also r(X1,X3)=−0.91. A filter keeps a feature when |r(feature,y)| ≥ 0.5. List the selected features, and flag any redundancy using |r| ≥ 0.5 between features.

Exam traps

  • Use |r| when comparing a negative correlation with a positive one. −0.8 is stronger than 0.3.
  • r(X,Y) is not causation and not a model score. A feature can correlate with y through another feature.
  • Two features can be redundant for a linear model but still useful in a tree or interaction model; do not delete blindly.
  • Compute correlations and selection on training data only. Using the full data leaks test information.

4.7 Linear discriminant analysis

Linear discriminant analysis (LDA) is a supervised way to project labelled data onto fewer dimensions. It chooses directions where the class means are far apart compared with the spread inside each class. PCA (Chapter 4.5) looks only at variance; LDA uses the labels. The result is a small set of features that a classifier can separate more easily. LDA is used in face recognition, medical diagnosis, and as a preprocessing step before a linear classifier.

You need: Chapter 4.5 for PCA and projection, and Unit 2 for linear classifiers and discriminant functions.

Scatter matrices and the LDA goal

Take n labelled points x in R^d. Each point belongs to one of C classes, numbered c = 1, ..., C. Let n_c be the number of points in class c, and let μ_c be the class mean: μ_c = (1/n_c) Σ_{x in c} x. Let μ be the overall mean of all points.

Two scatter matrices measure spread. The within-class scatter S_W adds the spread of each class around its own mean. The between-class scatter S_B measures how far the class means are from the overall mean. S_W is d×d; a large trace (sum of diagonal entries) means the classes are wide around their own means. S_B is also d×d; a large value means class means differ.

S_W = Σ_c Σ_{x∈c} (x − μ_c)(x − μ_c)ᵀ

S_W is the within-class scatter matrix; c runs over classes; x runs over points in class c; μ_c is the mean of class c.

S_B = Σ_c n_c (μ_c − μ)(μ_c − μ)ᵀ

S_B is the between-class scatter matrix; n_c is the number of points in class c; μ_c is the class mean; μ is the overall mean.

LDA looks for a unit vector w, a direction in feature space, that makes the projected class means far apart and each projected class narrow. It maximises the ratio of between-class spread to within-class spread after projection. Some syllabi call this Fisher's linear discriminant.

J(w) = (wᵀ S_B w) / (wᵀ S_W w)

w is a unit direction; wᵀ is its transpose; S_B and S_W are the between-class and within-class scatter matrices; J(w) is large when classes separate well.

Eigenvalue solution and C−1 directions

To maximise J(w), take its derivative with respect to w and set it to zero. This gives the generalised eigenvalue problem S_B w = λ S_W w. If S_W is invertible, rewrite it as S_W⁻¹ S_B w = λ w. Then w is an eigenvector of S_W⁻¹ S_B, and λ is its eigenvalue. The largest λ gives the best separation.

S_W⁻¹ S_B w = λ w

S_W⁻¹ is the inverse of the within-class scatter; S_B is between-class scatter; λ is an eigenvalue; w is its eigenvector, the LDA direction.

For C classes, S_B = Σ_c n_c (μ_c − μ)(μ_c − μ)ᵀ is a sum of C rank-one matrices. The C vectors (μ_c − μ) are linearly dependent because Σ_c n_c (μ_c − μ) = 0. So at most C−1 of them are linearly independent, and rank(S_B) ≤ C−1. LDA therefore gives at most C−1 useful discriminant directions. Two classes give only one direction. The procedure is: compute class means, build S_W and S_B, solve the eigenproblem, keep the top m ≤ C−1 eigenvectors, and project.

  1. Compute each class mean μ_c and the overall mean μ.
  2. Build S_W from within-class deviations and S_B from class-mean deviations.
  3. Solve S_W⁻¹ S_B w = λ w and sort eigenvalues from largest to smallest.
  4. Keep m ≤ C−1 eigenvectors and place them as columns of W.
  5. Project each point: z = Wᵀ x.

z = Wᵀ x

x is a d-dimensional input point; W has the chosen LDA eigenvectors as columns; z is the m-dimensional projected point.

LDA versus PCA and practical checks

PCA is unsupervised. It finds axes of maximum variance and ignores labels. A high-variance direction may mix classes badly. LDA is supervised. It uses class labels and finds axes that separate class means relative to within-class spread. Use PCA when you want compression or denoising without labels. Use LDA when labels exist and the goal is classification.

The simple LDA classifier assumes that classes share one covariance matrix. If each class has a very different covariance, quadratic discriminant analysis may fit better. LDA also needs enough samples. If d is large or features are highly correlated, S_W can be singular. Add a small ridge term εI to S_W, or use a pseudo-inverse. Standardise features first; otherwise a feature with a large numeric scale can dominate S_W.

Fisher's LDA is the projection step. The projection alone does not assign labels; a classifier is trained on the projected features, such as logistic regression or a linear classifier from Unit 2. Because LDA uses labels, do not use it as a clustering method. Keep at most C−1 components, and check that the chosen directions are stable across cross-validation folds.

Worked example

Question. Two classes in two dimensions have means μ1 = (0,0)ᵀ and μ2 = (4,4)ᵀ. Both have within-class scatter S_W = I, the identity matrix. Using the two-class form S_B = (μ2 − μ1)(μ2 − μ1)ᵀ, find the LDA direction w as a unit vector and the projected class means onto w.

  1. Form the mean difference: μ2 − μ1 = (4−0, 4−0)ᵀ = (4,4)ᵀ.
  2. For two classes the full S_B is (n1n2/n)(μ1 − μ2)(μ1 − μ2)ᵀ. Dropping the positive scalar n1n2/n leaves the eigenvectors unchanged, so we use S_B = (μ2 − μ1)(μ2 − μ1)ᵀ = [[16,16],[16,16]].
  3. Solve S_W⁻¹ S_B w = λw. Since S_W = I, this is S_B w = λw.
  4. Every nonzero column of S_B is a multiple of (1,1)ᵀ, so the eigenvector is w = (1,1)ᵀ.
  5. Normalise: ||(1,1)|| = √(1²+1²) = √2, so w = (1,1)ᵀ/√2 ≈ (0.71,0.71)ᵀ.
  6. Project class mean 1: wᵀμ1 = 0.71×0 + 0.71×0 = 0.0.
  7. Project class mean 2: wᵀμ2 = (4 + 4)/√2 = 8/√2 = 4√2 ≈ 5.66.

Answer. The LDA direction is w = (1,1)ᵀ/√2 ≈ (0.71,0.71)ᵀ. The projected class means are 0.0 and 5.66.

Exam traps

  • LDA is supervised and needs class labels. Do not use it as a clustering method on unlabelled data.
  • For C classes, keep at most C−1 components. Two classes give exactly one discriminant direction, not d directions.
  • S_W can be singular when features outnumber samples or features are correlated. Add a small ridge term εI or use a pseudo-inverse.
  • Do not confuse LDA with PCA. PCA maximises variance; LDA maximises between-class scatter relative to within-class scatter.
  • The simple LDA classifier assumes equal covariance across classes. If covariances differ strongly, quadratic discriminant analysis may be better.

Understand Why does LDA give at most C−1 components for C classes? 3 marks

S_B = Σ_c n_c(μ_c−μ)(μ_c−μ)ᵀ is a sum of C rank-one matrices, but the C vectors (μ_c−μ) are linearly dependent because Σ_c n_c(μ_c−μ)=0. So at most C−1 of them are linearly independent and rank(S_B) ≤ C−1. Thus S_W⁻¹S_B has at most C−1 nonzero eigenvalues, giving at most C−1 useful directions.

Apply Two class means are (0,0)ᵀ and (0,4)ᵀ, with S_W = I. Find the LDA unit direction and the projected class means. 4 marks

Mean difference is (0,4)ᵀ, so w = (0,1)ᵀ. Projection gives wᵀ(0,0)ᵀ = 0 and wᵀ(0,4)ᵀ = 4. The projected means are 0 and 4.

Apply A labelled dataset has C = 5 classes and d = 20 features. What is the maximum number of LDA components you should keep? 2 marks

At most C−1 = 4 components.

Analyze Explain when PCA may be a poorer choice than LDA for preprocessing before classification. 4 marks

PCA ignores labels and may keep a high-variance direction that mixes classes. LDA uses labels and keeps directions with large between-class separation relative to within-class spread, so it can make classes easier to classify.

Analyze What goes wrong if S_W is singular, and how can you fix it? 4 marks

S_W⁻¹ does not exist, so S_W⁻¹S_Bw = λw cannot be solved directly. Fix by adding a ridge term εI to S_W, removing correlated features, or using a pseudo-inverse.

Beyond the syllabus

Not for the exam. LDA remains a standard baseline in face recognition and medical imaging. Sparse LDA and regularised LDA handle high-dimensional data with many features. Kernel LDA extends the same ratio in a feature space. Search next for Fisher discriminant analysis and regularised LDA.

4.8 Evaluating clustering algorithms

Clustering has no target label by default, so you cannot score it like a classifier. Evaluation asks two questions: are points inside a cluster close, and are different clusters far apart? Internal measures answer this using distances only. External measures compare clusters with known true labels. These scores guide the choice of k, distance and algorithm in market segmentation, image grouping and document sorting. Advanced: only a few universities teach this.

You need: K-means and hierarchical clustering, plus Euclidean distance from Unit 1.

Internal measures: cohesion and separation

Cohesion measures how tight a cluster is. Separation measures how far clusters lie from each other. For a point i, let a(i) be the mean distance from i to the other points in its own cluster. Let b(i) be the smallest mean distance from i to all points in any other cluster. Small a is good; large b is good.

s(i) = (b(i) − a(i)) / max(a(i), b(i))

s(i) is the silhouette of point i; a(i) is the mean distance to its own cluster; b(i) is the smallest mean distance to another cluster. The value lies in [−1, 1]. Near 1: point is closer to its own cluster. Near 0: point is on a boundary. Negative: point may be in the wrong cluster. The cluster silhouette is the mean of s(i).

Davies–Bouldin (DB) averages, over clusters, the worst ratio of within-cluster spread to between-cluster separation. Lower DB is better. Calinski–Harabasz (CH) is between-cluster dispersion divided by within-cluster dispersion, scaled by (n−k)/(k−1); higher CH is better. Here n is the number of points and k is the number of clusters.

External measures: labels as ground truth

External measures need a true class for each point. Purity gives each cluster the label of its majority class, then counts correct points divided by n. It rises easily when k is large, so it is a rough check.

The Rand index compares every pair of points. A pair is an agreement if both cluster and truth put the pair together, or both keep it apart. RI = agreements / all pairs, in [0, 1]. Adjusted Rand index (ARI) subtracts the agreement expected by chance; 0 means random, 1 is perfect. Normalised mutual information (NMI) compares the cluster partition with the label partition; 0 to 1, higher is better.

Use internal measures when labels are absent. Use external measures only when true labels exist and are trusted. Neither score alone proves a clustering is meaningful; check stability and the business use.

Worked example

Question. Points A(0,0) and B(0,1) are in cluster 1; C(4,4) is in cluster 2. Using Euclidean distance, compute the silhouette score of A. Use a = mean distance to other points in its own cluster and b = smallest mean distance to another cluster.

  1. Own cluster of A is {A, B}. The only other point is B. a = distance(A,B) = √((0−0)²+(1−0)²) = 1.
  2. The other cluster is {C}. Mean distance from A to {C} is distance(A,C) = √((4−0)²+(4−0)²) = √32 = 5.6569. Since there is one other cluster, b = 5.6569.
  3. max(a,b) = max(1, 5.6569) = 5.6569.
  4. s(A) = (b − a) / max(a,b) = (5.6569 − 1) / 5.6569 = 4.6569 / 5.6569 = 0.8232.

Answer. The silhouette score of A is 0.8232; A is much closer to its own cluster than to the other cluster.

Exam traps

  • Do not use purity or ARI when you have no true labels; they need ground truth.
  • Silhouette is bounded by −1 and 1, not 0 and 1; a negative value is a warning, not a calculation error.
  • Davies–Bouldin is lower-is-better; Calinski–Harabasz and silhouette are higher-is-better.
  • Silhouette needs a distance. Changing the distance changes a(i), b(i) and the score.
  • High purity can come from many small clusters; compare at the same k and with ARI.

Not for the exam. Practitioners check cluster stability by re-running on bootstrap samples and measuring how often pairs stay together. The gap statistic compares within-cluster dispersion with that of a null reference. Consensus clustering combines many runs. 4.9 Fuzzy clustering

Fuzzy clustering assigns every point a membership degree in every cluster, not one hard label. A point near a boundary can be 0.7 in one cluster and 0.3 in another. This is useful when groups overlap, as in medical image regions, customer segments, or noisy sensor readings. Only a few universities teach this advanced topic. The standard method is fuzzy c-means.

You need: hard k-means from Chapter 4.2, distance from Unit 1, and soft assignments from Chapter 4.4.

Membership and the partition constraint

Hard k-means gives each point i one cluster label. Fuzzy clustering instead gives uik, the membership of point i in cluster k. Each uik lies in [0,1]. The membership matrix U has n rows and c columns.

For n points and c clusters, each point's memberships sum to one: Σk=1c uik = 1. Here c is the number of clusters, and ck is centre k. The rule says a point has total belonging one, shared across clusters.

Membership is a weight, not a probability. It records overlap: a point at x=1 with centres 0 and 4 can be 0.90 in cluster 1 and 0.10 in cluster 2. Hard k-means would force 1 and 0.

Use fuzzy clustering when groups overlap, for example tissue regions in a scan, customer groups with mixed behaviour, or noisy sensor readings.

Fuzzy c-means objective and updates

The fuzzy c-means objective is the weighted squared distance to every centre.

J = Σ<sub>i=1</sub><sup>n</sup> Σ<sub>k=1</sub><sup>c</sup> u<sub>ik</sub><sup>m</sup> d<sub>ik</sub><sup>2</sup>,  m > 1

J is the objective; uik is membership; m is the fuzzifier; dik is the distance from point xi to centre ck.

A larger m makes memberships softer. As m → 1, fuzzy c-means approaches hard k-means. As m grows, memberships move toward 1/c.

Alternating minimisation gives the update equations.

u<sub>ik</sub> = 1 / Σ<sub>j=1</sub><sup>c</sup> (d<sub>ik</sub>/d<sub>jk</sub>)<sup>2/(m−1)</sup>

j runs over all clusters; dik and djk are distances from the same point i to centres k and j.

c<sub>k</sub> = Σ<sub>i=1</sub><sup>n</sup> u<sub>ik</sub><sup>m</sup> x<sub>i</sub> / Σ<sub>i=1</sub><sup>n</sup> u<sub>ik</sub><sup>m</sup>

xi is the data point; the denominator is the cluster's total fuzzy weight.

  1. Initialise c centres, for example by random choice from the data.
  2. Compute every distance dik from point i to centre k.
  3. Update all memberships uik with the membership formula.
  4. Update every centre ck with the centre formula.
  5. Repeat until memberships or centres change less than a small threshold.

If a distance is zero, put that point fully in that cluster. Recompute distances after each centre update. Stop when memberships or centres change less than a small threshold.

Worked example

Question. For point x=1, centres c1=0 and c2=4, and fuzzifier m=2, compute fuzzy memberships u1 and u2 using Euclidean distance.

  1. Distance to centre 1: d1 = |1 − 0| = 1.
  2. Distance to centre 2: d2 = |1 − 4| = 3.
  3. Exponent is 2/(m−1) = 2/(2−1) = 2.
  4. u1 = 1 / [1 + (d1/d2)²] = 1 / [1 + (1/3)²] = 1 / (1 + 1/9) = 0.90.
  5. u2 = 1 / [1 + (d2/d1)²] = 1 / [1 + 3²] = 1 / 10 = 0.10.
  6. Check: u1 + u2 = 0.90 + 0.10 = 1.00.

Answer. The memberships are u1 = 0.90 and u2 = 0.10; they sum to 1.00.

Exam traps

  • Memberships sum to 1 for each point; checking columns instead is a common mistake.
  • m must be greater than 1. m=1 is not fuzzy c-means in this form.
  • uik is not a probability unless a probabilistic model is added.
  • The update divides by distance; if dik=0, handle that point as full membership in cluster k.
  • A very large m can hide real cluster separation.

Takeaways

  1. Unsupervised learning has no labels, so the distance or similarity you choose decides what a cluster means.
  2. K-means alternates assign and update steps to reduce WCSS; it is fast but needs k in advance and assumes round, similar-sized clusters.
  3. Hierarchical clustering builds a whole tree at once, so you can cut it at any height and read the merges from a dendrogram.
  4. A Gaussian mixture is a soft, model-based version of k-means that allows elliptical clusters of different size and orientation.
  5. EM fits a mixture by repeating two steps: estimate hidden memberships, then re-estimate parameters from those memberships.
  6. PCA rotates the axes to the directions of maximum variance, so a few components can replace many correlated features.
  7. Feature selection keeps original columns while PCA creates new ones; correlation analysis is the quick test for redundant columns.
  8. LDA uses class labels to find a projection that separates classes, and gives at most c − 1 components for c classes.
  9. Clustering quality is judged by cohesion and separation when no labels exist, and by agreement scores when labels do exist.
  10. Fuzzy clustering replaces the single assignment with membership degrees, which suits data where clusters overlap.

Analyze and evaluate

Analyze Compare k-means and a Gaussian mixture model for the same data set. Explain when k-means gives wrong groupings and how GMM fixes that, including the cost paid. 13 marks

Analyze Compare PCA and LDA for dimensionality reduction. Why is LDA limited to c − 1 components, and when would you prefer PCA? 13 marks

Glossary

Centroid
The vector of feature-wise means of the points in a cluster.
Cluster
A set of data points judged more similar to each other than to points outside the set.
Covariance matrix
A square matrix whose entry (i, j) is the covariance between features i and j; its diagonal holds the variances.
Curse of dimensionality
In many dimensions, distances between points become nearly equal, so clustering and nearest-neighbour methods lose power.
Davies–Bouldin index
Average over clusters of the ratio of within-cluster spread to distance between cluster centres; lower is better.
Defuzzification
Turning membership degrees into a single decision, usually by assigning each point to the cluster with the highest membership.
Dendrogram cut
A horizontal line drawn across the tree; the number of branches it crosses is the number of clusters returned.
Density-based clustering
Clustering that grows clusters as connected regions having at least a minimum number of points within a radius, and marks the rest as noise.
Distance metric
A function giving a non-negative similarity gap between two points, satisfying symmetry and the triangle inequality.
Eigenvalue
A scalar λ for which S v = λ v has a non-zero solution v; for a covariance matrix it equals the variance along v.
Eigenvector
A non-zero direction v that a matrix only stretches, not rotates, when multiplied.
Elbow method
Plotting WCSS against k and choosing the k where the curve stops falling steeply.
Fuzzifier
The exponent m > 1 in fuzzy c-means that controls how much overlap between clusters is allowed.
k-means++
Initialisation that picks the first centroid at random and later ones with probability proportional to squared distance from the nearest chosen centroid.
Medoid
The actual data point of a cluster that has the smallest total distance to the other members.
Mixing coefficient
The weight πₖ of component k in a mixture, equal to the prior probability that a random point comes from it.
Multicollinearity
Strong correlation among input features, which makes regression coefficients unstable and hard to interpret.
Orthogonal
At right angles, meaning the dot product of the two vectors is zero.
Purity
External clustering score equal to the total, over clusters, of the majority-class count divided by n.
Responsibility
The posterior probability that a given point was generated by a particular mixture component.
Scree plot
A bar or line chart of the eigenvalues in decreasing order, used to decide how many components to keep.
Single linkage
Cluster distance taken as the smallest distance between any member of one cluster and any member of the other.
Ward linkage
Merge rule that picks the pair whose merging causes the smallest increase in total within-cluster sum of squares.
Whitening
Scaling PCA components to unit variance so the transformed features are uncorrelated and equally spread.
