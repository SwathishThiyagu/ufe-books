5.1 Biological neuron and the McCulloch-Pitts model

A neuron can be modelled as a binary threshold unit. The model captures the essential decision behaviour of a cell that receives many signals, adds them with different strengths, and fires only if the total exceeds a threshold. This abstraction is the basis of early neural‑network theory and appears in many introductory courses.

You need: binary variables from Unit 1 concepts of binary variables.

Anatomy of a biological neuron

A biological neuron has a cell body called the soma. Dendrites branch out from the soma and collect electrical signals from other neurons. The axon carries the signal away from the soma. At the end of the axon, synapses transmit the signal to dendrites of the next neuron. The strength of each synapse varies; this is called the synaptic weight.

  • Dendrites = input branches
  • Synapse weight = how strongly a signal influences the next cell
  • Axon = output cable
  • Threshold = membrane potential needed to fire

In engineering terms the cell body integrates incoming currents, compares the result with a threshold, and then generates an all‑or‑none spike. The spike is a binary event: either the neuron fires (output = 1) or it stays silent (output = 0).

From biology to the McCulloch‑Pitts model

Some syllabi call this the MP model. The model replaces the complex biophysics of a neuron with a weighted sum and a threshold comparison. Each input x_i is a binary value (0 or 1). Each input has an associated weight w_i that can be positive or negative. The neuron computes the sum S = Σ w_i·x_i. A threshold term θ (theta) is compared directly with the weighted sum.

y = { 1 if Σ w_i·x_i ≥ θ ; 0 otherwise }

y is the binary output; Σ w_i·x_i is the weighted sum; θ is the threshold.

  1. Collect binary inputs x₁…xₙ.
  2. Multiply each input by its weight w₁…wₙ.
  3. Add the products to obtain the sum S.
  4. Compare S with the threshold θ.
  5. Set output y to 1 if S ≥ θ, else set y to 0.

The MP neuron can represent logical functions such as AND, OR, and NAND by choosing appropriate weights and threshold. This capability makes it the first building block of artificial neural networks.

Properties and limitations of the MP neuron

The MP neuron is a linear classifier. The decision boundary is a hyperplane defined by the equation Σ w_i·x_i = θ. Anything that cannot be separated by a single hyperplane, such as the XOR function, cannot be represented by a single MP unit. Stacking several MP units creates multilayer perceptrons, which can represent non‑linear mappings; this is covered in Section 5.3.

  • Binary inputs and output simplify analysis.
  • Weights can be fractional, allowing fine control.
  • A single MP unit cannot solve non‑linearly separable problems.
  • Training a network of MP units requires a learning rule (see Section 5.2).

Worked example

Question. Given three binary inputs x₁=1, x₂=0, x₃=1, weights w₁=0.5, w₂=‑0.7, w₃=0.9, and threshold θ=0.2, compute the MP neuron output y.

Exam traps

  • Ignoring the bias term θ and comparing the weighted sum directly to zero.
  • Using the wrong sign for a negative weight; the product w₂·x₂ must be negative when w₂ is negative and x₂ is 1.
  • Treating the threshold as a weight to be added instead of a value to compare against.
  • Assuming the output can be any real number; the MP neuron always produces 0 or 1.
  • Confusing the order of inputs and weights; each weight must multiply its corresponding input.

5.2 Perceptron learning and its limitations

The perceptron is the simplest neural model that can learn a linear decision boundary from labeled data. It exists to show how a single layer of weighted sums and a step activation can separate two classes when they are linearly separable. It is used in early pattern‑recognition tasks, in hardware implementations of binary classifiers, and as a building block to understand deeper networks.

You need: basic linear algebra and binary classification from Biological neuron and the McCulloch‑Pitts model.

Linear decision boundary

A perceptron computes a weighted sum w·x plus a bias b. The step activation f(z) outputs 1 if z ≥ 0 and 0 otherwise. The set of points where w·x + b = 0 forms a straight line in two dimensions. All points on one side of the line are classified as 1, the others as 0.

y = f(w·x + b)

y is the predicted label; w is the weight vector; x is the input vector; b is the bias; f is the step function.

  • If the data are linearly separable, a line exists that puts all class‑1 points on one side and all class‑0 points on the other.
  • If the data are not separable, the perceptron will never converge to a perfect classifier.

Perceptron learning rule

During training the perceptron updates its weights after each example. The update uses the error (target t minus prediction y) and a learning rate η.

Δw = η (t‑y) x

Δw is the change added to w; η is a small positive number called the learning rate; t is the true label; y is the current prediction; x is the input vector.

  1. Compute the weighted sum s = w·x + b.
  2. Apply the step function to get y = f(s).
  3. Calculate the error e = t‑y.
  4. Update each weight: w_i ← w_i + η e x_i.
  5. Update bias: b ← b + η e.

Python program.

def perceptron_update(w, b, x, t, eta=1.0):
    s = sum(w_i * x_i for w_i, x_i in zip(w, x)) + b
    y = 1 if s >= 0 else 0
    e = t - y
    w_new = [w_i + eta * e * x_i for w_i, x_i in zip(w, x)]
    b_new = b + eta * e
    return w_new, b_new

# Example run for (2,2) with target 1
w, b = [0, 0], 0
w, b = perceptron_update(w, b, [2, 2], 1)
print(w, b)  # prints [0.0, 0.0] 0.0

Output

[0.0, 0.0] 0.0

Convergence theorem and XOR limitation

The perceptron convergence theorem states that if a dataset is linearly separable, the update rule will find a weight vector that classifies all examples correctly after a finite number of steps.

  • The theorem assumes a fixed learning rate η > 0.
  • The number of updates is bounded by (R/γ)², where R is the maximum norm of any input and γ is the margin of separation.

When the data are not linearly separable, the perceptron may cycle forever. The classic XOR problem is a minimal example of non‑linear separability. Because a single line cannot separate the XOR truth table, a single‑layer perceptron fails, motivating the use of hidden layers and deep networks.

Worked example

Question. A training set contains two points: x₁ = (2, 2) with target t₁ = 1 and x₂ = (‑2, ‑1) with target t₂ = 0. Start with weight vector w = (0, 0) and bias b = 0. Use learning rate η = 1. Perform one pass over the data in the order given and report the final weight vector and bias.

C program.

#include <stdio.h>
int main() {
    double w[2] = {0, 0};
    double b = 0;
    double eta = 1.0;
    double x1[2] = {2, 2};
    int t1 = 1;
    double s = w[0]*x1[0] + w[1]*x1[1] + b;
    int y = (s >= 0) ? 1 : 0;
    int e = t1 - y;
    w[0] += eta * e * x1[0];
    w[1] += eta * e * x1[1];
    b += eta * e;
    double x2[2] = {-2, -1};
    int t2 = 0;
    s = w[0]*x2[0] + w[1]*x2[1] + b;
    y = (s >= 0) ? 1 : 0;
    e = t2 - y;
    w[0] += eta * e * x2[0];
    w[1] += eta * e * x2[1];
    b += eta * e;
    printf("%g %g %g\n", w[0], w[1], b);
    return 0;
}
  1. Compute s₁ = w·x₁ + b = 0·2 + 0·2 + 0 = 0.
  2. Apply step: y₁ = 1 because s₁ ≥ 0 (the step function returns 1 for non‑negative sums).
  3. Error e₁ = t₁ – y₁ = 1 – 1 = 0. No change: w stays (0,0), b stays 0.
  4. Compute s₂ = w·x₂ + b = 0·(‑2) + 0·(‑1) + 0 = 0.
  5. Step gives y₂ = 1 (since s₂ = 0).
  6. Error e₂ = t₂ – y₂ = 0 – 1 = ‑1.
  7. Update weights: w_i ← w_i + η e₂ x₂_i → w = (0 + 1·(‑1)·(‑2), 0 + 1·(‑1)·(‑1)) = (2, 1).
  8. Update bias: b ← b + η e₂ = 0 + 1·(‑1) = ‑1.
  9. Final weight vector is (2, 1) and bias is ‑1.

5.3 Multilayer feedforward networks and hidden layers

Stacking layers makes a neural network able to model non‑linear relationships. A single perceptron can only separate data with a straight line. By adding a hidden layer of perceptrons, the network can bend the decision surface and solve problems such as digit recognition, credit‑card fraud detection, or predicting power‑cut zones in Chennai.

You need: the perceptron basics from Chapter 5.2.

Network architecture

A multilayer feed‑forward network (often called an MLP) has three groups of units. The input group receives raw features such as pixel values or sensor readings. The hidden group contains perceptrons with a bias term. Each hidden unit computes a weighted sum of the inputs, adds its bias, and applies a step or sigmoid function. The output group produces the final prediction, for example a class label or a regression value.

  • Input layer: no computation, just forwards the feature vector.
  • Hidden layer: each unit is a perceptron with bias.
  • Output layer: can have one or many units depending on the task.

h_j = φ( Σ_i w_{ij}·x_i + b_j )

h_j is the j‑th hidden activation; x_i is the i‑th input; w_{ij} is the weight from input i to hidden j; b_j is the bias of hidden j; φ is the activation function (step, sigmoid, ReLU, …).

y_k = φ_o( Σ_j v_{jk}·h_j + c_k )

y_k is the k‑th output; v_{jk} is the weight from hidden j to output k; c_k is the output bias; φ_o is the output activation (often step for classification).

The network is called feed‑forward because data moves only from left to right, never looping back. Training adjusts all weights w_{ij} and v_{jk} to minimise a loss defined on the output.

Mathematical description of a two‑layer example

Consider a network with two inputs, one hidden unit, and one output unit. The hidden bias is –0.1, the output bias is 0.2. The weights are w_{1,1}=0.6, w_{2,1}=‑0.4 (from inputs to hidden) and v_{1,1}=1.0 (from hidden to output).

  1. Compute hidden sum: s_h = 0.6·x₁ + (‑0.4)·x₂ + (‑0.1).
  2. Apply step activation: h = 1 if s_h ≥ 0 else 0.
  3. Compute output sum: s_o = 1.0·h + 0.2.
  4. Apply step activation: y = 1 if s_o ≥ 0 else 0.

If the input vector is (1, 0), then s_h = 0.6·1 + (‑0.4)·0 – 0.1 = 0.5, so h = 1. The output sum becomes s_o = 1·1 + 0.2 = 1.2, giving y = 1. This simple calculation shows how the hidden bias shifts the decision boundary.

Universal approximation property

Some syllabi state that an MLP with at least one hidden layer and non‑linear activation can approximate any continuous function on a compact domain to arbitrary accuracy. The theorem does not say that training is easy; it only guarantees the existence of suitable weights.

  • Non‑linearity is essential; without it the network collapses to a single linear model.
  • The number of hidden units controls the expressive power.
  • In practice, regularisation and optimisation strategies are needed to reach a good approximation.

Because of this property, multilayer networks are used in image classification, speech‑to‑text conversion, and forecasting electricity demand during a Chennai power cut.

Question. A two‑layer MLP has inputs x₁=1 and x₂=0. Hidden bias = –0.1, output bias = 0.2. Weights: w_{1,1}=0.6, w_{2,1}=‑0.4 to the hidden unit; v_{1,1}=1.0 from hidden to output. Use a step activation (output 1 if sum ≥ 0, else 0). Compute the final output y.

5.4 Activation functions and loss functions

Activation functions turn a neuron's weighted sum into a signal that can be passed to the next layer. Loss functions compare the network's output with the true target and tell the optimizer how far off the prediction is. Together they give a neural network the ability to learn complex patterns from data, whether the task is image classification, fraud detection, or predicting electricity demand during a Chennai power cut.

You need: understanding of weighted sums from Multilayer feedforward networks and hidden layers.

Sigmoid and Tanh

The sigmoid function maps any real input z to the interval (0,1). It is defined as σ(z)=1/(1+exp(-z)). Because its output can be interpreted as a probability, sigmoid is used in binary classification heads.

σ(z) = 1 ÷ (1 + exp(-z))

z is the pre‑activation value (weighted sum plus bias); exp is the exponential function.

The hyperbolic tangent (tanh) is a scaled version of sigmoid that outputs in the range (-1,1). It is defined as tanh(z)= (exp(z)-exp(-z)) ÷ (exp(z)+exp(-z)).

tanh(z) = (exp(z) - exp(-z)) ÷ (exp(z) + exp(-z))

z is the pre‑activation value.

  • Derivative of sigmoid: σ'(z)=σ(z)·(1-σ(z))
  • Derivative of tanh: tanh'(z)=1- tanh(z)²
  1. Compute z = Σ w_i·x_i + b.
  2. Apply σ(z) or tanh(z) to obtain the activation a.
  3. During back‑propagation, multiply the upstream gradient by the derivative shown above.

ReLU and Softmax

Rectified Linear Unit (ReLU) is defined as ReLU(z)=max(0, z). It is zero for negative inputs and linear for positive inputs, which speeds up training and reduces vanishing‑gradient problems.

ReLU(z) = max(0, z)

z is the pre‑activation value.

The Softmax function converts a vector of raw scores z⃗ into a probability distribution p⃗ over K classes.

Softmax(z_i) = exp(z_i) ÷ Σ_{j=1}^{K} exp(z_j)

z_i is the i‑th element of the score vector; the denominator sums over all K classes.

  • Derivative of ReLU: ReLU'(z)=1 if z>0 else 0
  • Derivative of Softmax combined with cross‑entropy simplifies to (p_i - t_i) where t_i is the true label.
  1. Compute raw scores z for each class.
  2. Apply Softmax to obtain probabilities p.
  3. Use p in the cross‑entropy loss.

Loss Functions

Mean‑squared error (MSE) is used for regression. For a single output a and target t, MSE = (a - t)² ÷ 2. The division by 2 simplifies the gradient to (a - t).

MSE = (a - t)² ÷ 2

a is the network output; t is the true value.

Cross‑entropy loss is the standard for classification with Softmax. For a true class vector t and predicted probability vector p, the loss is L = - Σ t_i·log(p_i). When t is one‑hot, this reduces to -log(p_{true}).

Cross‑entropy = - Σ t_i·log(p_i)

log is the natural logarithm; p_i is the predicted probability for class i; t_i ∈ {0,1}.

  • MSE works well when errors are symmetric and Gaussian.
  • Cross‑entropy heavily penalises confident wrong predictions, encouraging better calibrated probabilities.
  1. Choose the appropriate loss for the problem (regression vs classification).
  2. Compute the loss using the formula above.
  3. Back‑propagate the gradient of the loss to update weights.

Worked example

Question. A two‑class classification problem uses a Softmax output layer. The true class vector is t=[0,1]. The network produces raw scores z=[0.4, 1.2]. Compute the Softmax probabilities and the cross‑entropy loss.

C program.

5.5 Backpropagation training

Back‑propagation computes the gradient of the loss with respect to every weight in a multilayer network. It exists because a naïve computation of all partial derivatives would be too slow for realistic networks. The algorithm is used to train feed‑forward neural nets for image classification, speech recognition, fraud detection and many other Indian industry tasks.

You need: multilayer‑feedforward networks, activation and loss functions.

Error signal for output units

For a supervised task the network produces an output vector ŷ and the training data give a target vector t. The loss L measures the mismatch; a common choice is mean‑squared error L = ½ Σ (t‑ŷ)². The error signal δ for an output unit j is the derivative of L with respect to the net input z_j of that unit.

δ_j = (ŷ_j – t_j) · f'(z_j)

ŷ_j is the unit output; t_j is the target; f' is the derivative of the activation function f at net input z_j.

  1. Compute the forward pass to obtain ŷ and the net inputs z.
  2. Subtract the target from the output.
  3. Multiply by the activation derivative to get δ.
  • If the activation is the sigmoid, f'(z)=ŷ·(1‑ŷ).
  • If the activation is linear, f'(z)=1.

Propagating the error to hidden units

Hidden units do not have a direct loss term. Their error signal is obtained by the chain rule: each hidden unit i receives contributions from all units k in the next layer that it feeds.

δ_i = f'(z_i) · Σ_k w_{ik} δ_k

w_{ik} is the weight from hidden unit i to next‑layer unit k; δ_k is the error signal of unit k.

  1. For each hidden unit, multiply the outgoing weights by the downstream δ values.
  2. Sum the products over all downstream units.
  3. Multiply the sum by the hidden activation derivative.
  • The same formula works for any number of layers; apply it layer by layer from output back to input.

Weight update and vector form

Gradient descent changes each weight w_{ij} opposite to the gradient of the loss. Using the error signal δ_j of the destination unit, the update rule is simple.

w_{ij} ← w_{ij} – η · δ_j · a_i

η is the learning rate; a_i is the activation of the source unit i (the input to the weight).

In matrix notation, let A be the column vector of activations from layer ℓ and δ be the column vector of error signals for layer ℓ+1. The weight matrix W updates as

W ← W – η · (δ · A^T)

δ·A^T is the outer product producing a matrix of partial derivatives.

  1. Compute δ for the current layer (output or hidden).
  2. Form the outer product of δ and the previous‑layer activations.
  3. Scale by η and subtract from the old weight matrix.

5.6 Gradient-based optimizers and regularization for networks

Gradient‑based optimizers change the network weights using the loss gradient. They exist because plain gradient descent can be slow or unstable on deep nets. The same ideas also appear in finance (optimising portfolios) and in control systems. In practice they are used for image classification, speech‑to‑text, and any task where a deep network must learn from large data.

You need: Backpropagation training and basic calculus from Unit 2.

Batch, stochastic and mini‑batch gradient descent

Batch gradient descent computes the gradient ∇J over the whole training set before a weight update. It gives a true descent direction but needs a full pass over the data each step, which is costly for millions of images.

Stochastic gradient descent (SGD) uses a single training example to estimate ∇J. The update is fast but noisy; the loss curve wiggles. Mini‑batch SGD averages the gradient over a small batch (typically 32‑256 examples). It balances speed and stability.

w ← w – η ∇J_batch

w is the weight vector; η is the learning rate (step size); ∇J_batch is the gradient of the loss J summed over the batch.

  • Batch GD: one update per epoch, stable, high memory.
  • SGD: many updates per epoch, fast, high variance.
  • Mini‑batch: common choice for deep nets, works well with GPUs.

All three variants are described in Syllabus A and Syllabus E. The choice of η is critical; a too‑large η makes the loss diverge, a too‑small η makes learning painfully slow.

Momentum, RMSProp and Adam

Momentum adds a velocity term v that accumulates past gradients. The update rule is

v ← β v + η ∇J

β ∈ [0,1) is the momentum coefficient; η is the learning rate; ∇J is the current gradient.

The weight is then changed by the velocity:

w ← w – v

w is the weight after the current step.

  1. Compute the gradient ∇J for the current mini‑batch.
  2. Update the velocity v using the momentum formula.
  3. Update the weight w by subtracting v.

RMSProp keeps a moving average s of the squared gradients. It scales the learning rate for each weight:

s ← ρ s + (1‑ρ) (∇J)²

ρ is the decay rate (≈0.9); (∇J)² is element‑wise square of the gradient.

w ← w – η ∇J / (√s + ε)

ε ≈ 10⁻⁸ avoids division by zero.

Adam combines momentum and RMSProp. It maintains two moving averages: m for the gradient and v for the squared gradient.

m ← β₁ m + (1‑β₁) ∇J

β₁ ≈ 0.9.

v ← β₂ v + (1‑β₂) (∇J)²

β₂ ≈ 0.999.

Bias‑corrected estimates are m̂ = m/(1‑β₁^t) and v̂ = v/(1‑β₂^t). The final update is

w ← w – η m̂ / (√v̂ + ε)

t is the iteration count.

Only a few universities cover Adam in depth, but it is the default optimizer in most deep‑learning libraries because it works well with little tuning.

Regularisation: weight decay, dropout and batch normalisation

Regularisation reduces over‑fitting by limiting the capacity of the network.

  • L2 weight decay adds λ‖w‖² to the loss. The gradient of this term is λ w, so the update becomes w ← w – η (∇J + λ w).
  • Dropout randomly zeroes a fraction p of activations during training. In the common inverted dropout implementation, the remaining activations are scaled by 1/(1‑p) during training, so that at inference time no scaling is required.
  • Batch normalisation normalises each layer’s pre‑activations to zero mean and unit variance, then learns a scale γ and shift β. It stabilises training and acts as a regulariser.

Using η for the momentum update is fine, but when applying L2 weight decay you must multiply λ by η (Δ = η·λ·w). Forgetting the η factor makes decay too small, while applying weight decay after the momentum step without including η makes it too large. The worked example follows the correct practice by using Δ = η·λ·w₁.

Dropout is rarely used in convolutional layers because spatial correlation is important, but it is popular in fully‑connected layers of image classifiers.

Batch normalisation can be folded into the preceding convolution at inference time, which saves memory on mobile devices such as a Chennai smartphone during a power cut.

5.7 From shallow to deep networks: deep learning vs ANNs

Depth lets a network learn features layer by layer. A shallow network with one hidden layer can only combine raw inputs once. Adding many hidden layers builds a hierarchy: low‑level edges, mid‑level shapes, high‑level concepts. The hierarchy improves performance on images, speech and medical data, but deeper stacks create the vanishing‑gradient problem. When sigmoid units saturate, gradients shrink exponentially and learning stalls. ReLU units keep the gradient alive, making very deep nets trainable.

You need: back‑propagation (5.5) and optimizers (5.6).

Shallow versus deep stacks

A multilayer perceptron with one hidden layer is called shallow. It maps inputs x to outputs y through a single non‑linear transformation h = σ(W₁x + b₁) and y = σ(W₂h + b₂). The hidden units σ are usually sigmoid or tanh. The network can approximate any continuous function but may need many hidden units, which increases parameters and over‑fits easily.

A deep network stacks several hidden layers: x → h¹ → h² → … → hᴸ → y. Each layer extracts a higher‑level representation from the previous one. For image pixels, the first layer may detect edges, the second layer corners, the third layer object parts, and so on.

y = σ(Wᴸ·σ(Wᴸ⁻¹·…·σ(W₁x + b₁)…) + bᴸ)

σ is the activation function used in hidden layers; Wᵢ and bᵢ are weight matrix and bias vector of layer i; L is the number of hidden layers.

Here σ denotes the activation used in hidden layers. The output may use a different activation φ, e.g., y = φ(Wᴸ·σ(...)).

  • More layers give hierarchical features.
  • More layers increase training difficulty.
  • Parameter count grows roughly with total neurons.

Deep stacks are used in computer vision, speech recognition, and medical diagnosis where raw data contain rich structure.

Vanishing gradient and the ReLU remedy

During back‑propagation the gradient ∂L/∂Wᵢ is the product of derivatives of all later layers. For a sigmoid σ(z)=1/(1+e⁻ᶻ) the derivative σ'(z)=σ(z)(1‑σ(z)) ≤ 0.25. If the output gradient at the last layer is g₀ = 0.8, each sigmoid layer multiplies the gradient by at most 0.25 (a typical non‑saturated value). After three hidden layers the gradient becomes g = 0.8·0.25³ = 0.0125. The signal is almost lost; weight updates are tiny and learning stalls.

Rectified Linear Unit (ReLU) defined as ReLU(z)=max(0,z) has derivative 1 for positive z and 0 otherwise. In the active region the gradient passes unchanged. Using ReLU, the same three‑layer stack keeps the gradient at g = 0.8·1·1·1 = 0.8, allowing fast learning even with many layers.

  1. Compute forward pass to obtain activations.
  2. Calculate loss derivative at output (given as 0.8).
  3. For each sigmoid layer multiply by 0.25.
  4. For each ReLU layer multiply by 1.

5.8 Convolutional neural networks: convolution and pooling

Convolution and pooling turn raw pixel grids into compact feature maps. Convolution extracts patterns such as edges using a small learnable kernel that slides over the image. Pooling reduces the spatial size, making the representation robust to small shifts. These operations are the core of modern vision systems like LeNet, AlexNet and VGG, and they also appear in audio and time‑series analysis.

You need: Chapter 3 and Chapter 4.

Discrete convolution

A 1‑D discrete convolution computes a weighted sum of neighbouring input values. For an input vector x and a kernel k, the output at position i is (x∗k)[i]= Σ_{s=0}^{|k|-1} x[i+s·stride]·k[s] . Stride determines how many input positions are skipped between successive kernel placements. Padding adds zeros to the borders so that the output length can be kept equal to the input length.

(x∗k)[i]= Σ_{s=0}^{|k|-1} x[i+s·stride]·k[s]

x is the input vector; k is the kernel; i is the output index; stride is the step size; padding adds zeros before the first and after the last input element. If padding = p, the input index becomes x[i + s·stride - p].

  1. Place the kernel at the leftmost valid position.
  2. Multiply overlapping input and kernel entries.
  3. Sum the products to obtain one output value.
  4. Shift the kernel by the stride and repeat until the right border is reached.

If the kernel is reversed before sliding, the operation is called true convolution. In deep‑learning libraries the kernel is usually *not* flipped; the operation is called cross‑correlation, but the name convolution is kept for historical reasons.

Python program.

def conv1d(x, k, stride=1, padding=0):
    x = [0]*padding + x + [0]*padding
    out = []
    for i in range(0, len(x)-len(k)+1, stride):
        out.append(sum(x[i+j]*k[j] for j in range(len(k))))
    return out

Pooling operations

Pooling reduces the spatial resolution of a feature map while keeping the most important information. Max‑pooling selects the largest value in each non‑overlapping window; average‑pooling computes the mean. A pool size of p and stride p are typical, so windows do not overlap.

y[i]= max_{j∈W_i} x[j]

y[i] is the pooled output at position i; W_i is the set of indices covered by the i‑th pooling window; x[j] are the input values inside that window.

  • Reduces number of parameters in later layers.
  • Provides translation invariance – a shifted edge still produces the same pooled value.
  • Helps control over‑fitting by discarding precise locations.

Python program.

def max_pool1d(x, size, stride=None):
    if stride is None:
        stride = size
    out = []
    for i in range(0, len(x)-size+1, stride):
        out.append(max(x[i:i+size]))
    return out

Advanced variations (optional)

Dilated convolution inserts zeros between kernel elements, expanding the receptive field without increasing parameters. With dilation d, the kernel samples input at positions i + s·d. This is useful in segmentation networks where context from a larger area is needed.

(x∗_d k)[i]= Σ_{s=0}^{|k|-1} x[i+s·d]·k[s]

d is the dilation factor; other symbols as in ordinary convolution.

  1. Choose dilation d > 1.
  2. When applying the kernel, treat the spacing between successive kernel taps as d samples, i.e., insert d‑1 zeros between the positions where the kernel samples the input.
  3. Apply the standard convolution formula on the expanded kernel.

5.9 Recurrent neural networks

Recurrent neural networks (RNNs) handle data that arrives in a sequence, such as speech, text, or sensor readings. They keep an internal hidden state that is updated at each time step, allowing the network to remember past information. This memory makes RNNs suitable for language modelling, stock‑price prediction, and time‑series forecasting, where the order of inputs matters.

You need: back‑propagation training , activation functions , and multilayer feed‑forward networks .

Simple RNN cell

A single RNN cell receives an input vector xₜ at time step t and the hidden vector h₍ₜ₋₁₎ from the previous step. It computes a new hidden vector hₜ by a linear transformation followed by a non‑linear activation.

hₜ = f(Wₓ·xₜ + Wₕ·h₍ₜ₋₁₎ + b)

hₜ is the hidden state at time t; xₜ is the input at time t; Wₓ and Wₕ are weight matrices; b is a bias vector; f is an activation such as tanh.

All time steps share the same matrices Wₓ, Wₕ and bias b. Sharing forces the network to treat the sequence uniformly, which is why a recurrent network can generalise to longer or shorter sequences than seen during training.

  • Weight sharing reduces the number of parameters.
  • The hidden state acts as a short‑term memory.
  • Choosing tanh or ReLU changes the range of hₜ.

Example: let Wₓ=0.5, Wₕ=0.3, b=0.1, f=tanh, x₁=1, h₀=0. Then h₁ = tanh(0.5·1 + 0.3·0 + 0.1)=tanh(0.6)=0.537. For x₂=0, h₂ = tanh(0.5·0 + 0.3·0.537 + 0.1)=tanh(0.261)=0.255.

Unfolding in time and back‑propagation through time

To train an RNN we unroll the recurrent computation for T steps. The unrolled graph looks like a deep feed‑forward network where each layer corresponds to one time step.

  1. Draw T copies of the RNN cell.
  2. Connect h₍ₜ₋₁₎ of step t‑1 to the input of step t.
  3. Share the same parameters across all copies.

During back‑propagation we compute gradients of the loss L with respect to each parameter by summing contributions from all time steps. The gradient for Wₓ is Σₜ ∂L/∂hₜ · ∂hₜ/∂Wₓ.

∂L/∂θ = Σₜ=1^T ∂L/∂hₜ · ∂hₜ/∂θ   (θ ∈ {Wₓ,Wₕ,b})

∂L/∂hₜ is the error signal arriving at time t; ∂hₜ/∂θ is the local Jacobian of the cell.

If the product of Jacobians becomes very small, gradients vanish and learning stalls for long sequences. If the product grows, gradients explode and cause numerical instability.

Python program.

def bptt(x, h0, Wx, Wh, b, T):
    h = h0
    grads = {'Wx':0.0,'Wh':0.0,'b':0.0}
    for t in range(T):
        h = np.tanh(Wx*x[t] + Wh*h + b)
        # dummy loss L = 0.5*h**2
        dLdh = h
        grads['Wx'] += dLdh * (1 - h**2) * x[t]
        grads['Wh'] += dLdh * (1 - h**2) * h
        grads['b']  += dLdh * (1 - h**2)
    return grads

LSTM and GRU – gated recurrent units

Standard RNN cells struggle with long‑range dependencies. Long Short‑Term Memory (LSTM) cells add three gates that control the flow of information: input, forget and output.

  • Input gate decides how much new input to write.
  • Forget gate decides how much of the previous cell state to keep.
  • Output gate decides how much of the cell state to expose as hidden state.

A Gated Recurrent Unit (GRU) combines the input and forget gates into an update gate and merges the cell state with the hidden state. GRU has fewer parameters and is often faster to train.

Both LSTM and GRU are listed in many Indian syllabi under the heading “Recurrent networks”. They are the default choice for language translation, speech‑to‑text, and video captioning tasks.

Worked example

Question. Given a single‑layer RNN with tanh activation, Wₓ=0.5, Wₕ=0.3, b=0.1, initial hidden state h₀=0, and input sequence x₁=1, x₂=0, compute h₁ and h₂. Then compute the mean‑squared error loss if the target outputs are y₁=0.5 and y₂=0.2.

C program.

#include <stdio.h>
#include <math.h>
int main(){
    double Wx=0.5, Wh=0.3, b=0.1;
    double h0=0.0, x1=1.0, x2=0.0;
    double h1 = tanh(Wx*x1 + Wh*h0 + b);
    double h2 = tanh(Wx*x2 + Wh*h1 + b);
    double y1=0.5, y2=0.2;
    double loss = ((y1-h1)*(y1-h1) + (y2-h2)*(y2-h2))/2.0;
    printf("h1 = %.3f\n", h1);
    printf("h2 = %.3f\n", h2);
    printf("loss = %.4f\n", loss);
    return 0;
}
  1. Step 1: Compute the pre‑activation for t=1: a₁ = 0.5·1 + 0.3·0 + 0.1 = 0.6.
  2. Step 2: Apply tanh: h₁ = tanh(0.6) ≈ 0.537.
  3. Step 3: Compute the pre‑activation for t=2: a₂ = 0.5·0 + 0.3·0.537 + 0.1 = 0.261.
  4. Step 4: Apply tanh: h₂ = tanh(0.261) ≈ 0.255.
  5. Step 5: Compute squared errors: (y₁‑h₁)² = (0.5‑0.537)² ≈ 0.001369, (y₂‑h₂)² = (0.2‑0.255)² ≈ 0.003025.
  6. Step 6: Average them: L = (0.001369 + 0.003025)/2 ≈ 0.002197.

Exam traps

  • Treating each time step as a separate network and using different weight matrices breaks the principle of weight sharing.
  • Confusing the hidden state hₜ with the cell state cₜ of an LSTM; they are not the same.
  • Using sigmoid activation for the hidden state in a vanilla RNN; tanh or ReLU are the standard choices.
  • Forgetting to divide the sum of squared errors by the number of time steps when computing MSE.

Takeaways

  1. A single linear neuron can only solve linearly separable problems.
  2. Hidden layers give neural networks the ability to approximate any continuous function.
  3. Choosing appropriate activation and loss functions is crucial for effective learning.
  4. Backpropagation efficiently provides the gradient needed for weight updates.
  5. Optimizers such as SGD with momentum accelerate convergence and improve stability.
  6. Regularisation techniques like dropout and weight decay reduce over‑fitting.
  7. Depth enables hierarchical feature learning but introduces training challenges like vanishing gradients.
  8. Convolution and pooling exploit spatial locality, making CNNs ideal for image data.

Glossary

Batch normalization
Technique that normalises layer inputs across a mini‑batch to speed up training.
Bias
Offset added to the weighted sum before applying activation.
Chain rule
Mathematical rule for differentiating composite functions, used in backpropagation.
Dropout rate
Probability p of setting a neuron's output to zero during a training step.
Epoch
One full pass over the entire training dataset.
Exploding gradient
Phenomenon where gradients grow exponentially large, causing unstable updates.

Output of a convolutional layer representing filtered image information.
Fine‑tuning
Adjusting a pretrained model's weights on a new dataset, usually with a small learning rate.
Gate
Component in LSTM that controls information flow (input, forget, output).
Gradient clipping
Technique to limit the magnitude of gradients to avoid exploding gradients.
Gradient descent
Optimization algorithm that moves parameters opposite to the gradient of loss.
Hierarchical feature learning
Process where lower layers learn simple patterns and higher layers combine them into complex concepts.
Hyperplane
Geometric object of dimension one less than its space; used as decision boundary.
Jacobian
Matrix of all first‑order partial derivatives of a vector‑valued function.
Kernel
Small matrix of learnable weights used in convolution.
Learning rate
Step size η controlling how much weights change during training.
Learning schedule
Plan for changing the learning rate during training.
Linear separability
Property of a dataset that can be divided by a straight line (or hyperplane).

Subset of training examples used to compute an approximate gradient.
Neuron
Basic computing unit that receives weighted inputs and produces an output.

When a model learns noise in training data and performs poorly on unseen data.

Adding extra border pixels to preserve spatial dimensions after convolution.
Parameter
Any trainable variable in a network, such as weights or biases.
