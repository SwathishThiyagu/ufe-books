5.1 Biological neuron and the McCulloch-Pitts model

A neuron receives signals, adds them with different strengths, and fires when the total is large enough. The McCulloch–Pitts (MP) unit turns this into arithmetic: weighted inputs, a bias, a threshold, and a binary output. It is the first mathematical model of a neuron and the ancestor of the perceptron. One MP unit can act as AND, OR or NOT, showing how computing can be built from neuron-like parts.

You need: Basic algebra (sums and inequalities) and the idea of a function from Unit 1, Foundations: Learning Problems and Concepts.

From biological neuron to a unit

A biological neuron has parts with clear jobs. The table gives names and rough roles. The MP unit borrows these names as an analogy; it does not model chemistry, timing or graded voltages.

Two points keep the analogy honest. A real neuron fires in many patterns and synapses change with time; the MP unit uses fixed numbers. Its output is all-or-nothing, 0 or 1, which makes it easy to analyse as a logic gate.

The McCulloch–Pitts unit

An MP unit has n inputs x₁, x₂, …, xₙ. Each input is 0 or 1 and has a weight wᵢ, a real number saying how strongly it pushes the unit. A bias b is added. The unit computes net input z, compares z with threshold θ, and outputs y.

z = Σᵢ wᵢxᵢ + b, y = 1 if z ≥ θ, else 0

xᵢ is input i (0 or 1); wᵢ is its weight; b is the bias; θ is the threshold; z is the net input; y is the output (0 or 1).

y = step(Σᵢ wᵢxᵢ + b − θ)

step(a) = 1 if a ≥ 0, else 0; b is bias; θ is threshold. Setting b = 0 gives y = step(Σᵢ wᵢxᵢ − θ), used in the examples. Only the difference θ − b decides the boundary.

Weights and threshold are set by hand. There is no training rule; the designer chooses numbers for the wanted gate. Learning from data starts in chapter 5.2.

One unit as AND, OR and NOT

Set weights by hand and the MP unit becomes a logic gate. For two inputs, choose w₁ = w₂ = 1 and b = 0. With θ = 2, it fires only when both inputs are 1, so it computes AND. With θ = 1, it fires when at least one input is 1, so it computes OR. For NOT x₁, choose w₁ = −1, w₂ = 0, b = 0 and θ = 0: x₁ = 0 gives net 0 and output 1; x₁ = 1 gives net −1 and output 0.

These settings show the model's power and limit. Power: a neuron-like unit computes a logical function. Limit: every setting is manual; the unit cannot adjust wᵢ or θ from examples. That is the perceptron's job in chapter 5.2. A single MP unit also cannot separate patterns needing a bent boundary, which is why hidden layers appear in chapter 5.3.

Worked example

Question. A McCulloch–Pitts unit has two inputs x₁, x₂ ∈ {0,1}. (a) Using w₁ = w₂ = 1, b = 0 and θ = 2, write the output y for all four input pairs. (b) Keep the same weights and bias but change θ to 1; write y for all four pairs. (c) Choose weights, bias and threshold so the same unit computes NOT x₁, and list y for x₁ = 0 and x₁ = 1.

  1. z = w₁x₁ + w₂x₂ + b = x₁ + x₂. Rule: y = 1 if z ≥ θ, else 0.
  2. θ = 2: (0,0) z=0→y=0; (0,1) z=1→y=0; (1,0) z=1→y=0; (1,1) z=2→y=1. This is AND.
  3. θ = 1: (0,0) z=0→y=0; (0,1) z=1→y=1; (1,0) z=1→y=1; (1,1) z=2→y=1. This is OR.
  4. For NOT x₁ choose w₁=−1, w₂=0, b=0, θ=0. Then z=−x₁. x₁=0: z=0≥0→y=1. x₁=1: z=−1<0→y=0.

Answer. The outputs are 0, 0, 0, 1 for AND; 0, 1, 1, 1 for OR; and 1, 0 for NOT x₁.

Exam traps

  • The MP unit does not learn. Weights and threshold are fixed by hand; 'updates its weights' is wrong. Weight updating is the perceptron rule in chapter 5.2.
  • Check the inequality. y = 1 when net ≥ θ is not net > θ. At net exactly θ, output is 1 under ≥ and 0 under >. State your convention.
  • A bias b is a weight on a constant input 1; it shifts z by a fixed amount. Since y = 1 if Σwᵢxᵢ + b ≥ θ, only θ − b matters. To compare the weighted sum with 0, move both to one side: y = step(Σwᵢxᵢ + b − θ).
  • Negative weights are allowed. Weight −1 lowers the net input; it does not mean 'no connection'.
  • MP neuron and perceptron both have weights and a threshold, but only the perceptron has a learning rule that changes weights from data.

5.2 Perceptron learning and its limitations

The perceptron learns from mistakes: one unit adds weighted inputs, fires when the total is positive, and changes weights only when wrong. The rule adds η(t − y)x to each weight. If a straight line separates the classes, it finds one in finitely many steps. It is the building block of neural networks and the standard model that fails on XOR.

You need: Chapter 5.1 for the weighted sum, the threshold and the step function.

The unit: weighted sum, step, one straight boundary

The perceptron takes the McCulloch–Pitts unit and adds a bias and a learning rule. For inputs x₁, …, xₙ with weights w₁, …, wₙ and bias b, it computes a weighted sum and passes it through a step.

net = Σᵢ wᵢxᵢ + b, y = 1 if net > 0, else 0

xᵢ is input i; wᵢ is the weight of input i; b is the bias, a constant added to the sum; net is the weighted sum; y is the output, 0 or 1.

Some texts write y = sign(net), giving −1 or +1. The arithmetic is the same; the labels are names. The tie at net = 0 also varies; here the unit fires only when net > 0.

The points where net = 0 form a line in two dimensions, a plane in three, a hyperplane in general. Weights set the tilt; bias slides the line from the origin. Without b the boundary passes through the origin, so x₁ AND x₂ — true only at (1,1), boundary x₁ + x₂ = 1.5 — cannot be split.

So one perceptron is a linear classifier. AND, OR and NOT are easy. Any problem a single straight line cannot separate is out of reach.

The learning rule: change weights only on an error

Learning fixes w and b from labelled data. Start with any weights, usually zeros. Show one sample (x, t), compute y, change nothing if y = t. If wrong, apply the rule.

wᵢ ← wᵢ + η(t − y)xᵢ, b ← b + η(t − y)

t is the target (0 or 1); y is the current output; η is the learning rate, a small positive number; ← means 'becomes'. All weights are updated together, then the bias.

Target tOutput yt − yWhat happens
10+1w moves towards x, b grows
01−1w moves away from x, b shrinks
1 or 0same as t0nothing changes

Geometry explains the sign. The vector (w, b) points into the firing side. A false 0 gives t − y = +1, so add x and tilt the boundary until the sample fires. A false 1 gives −1, so subtract x. η sets step length, often between 0 and 1 for inputs of size about 1. A large η can jump past the answer; (t − y) fixes the direction.

  1. Pick the next sample (x, t), or cycle through the data in a fixed order.
  2. Compute net = Σ wᵢxᵢ + b and y = step(net).
  3. Set e = t − y. If e = 0, move to the next sample.
  4. Update wᵢ ← wᵢ + η e xᵢ for every i, then b ← b + η e.
  5. Stop when a full pass makes no update.

No derivative and no loss function appear. That separates this rule from Unit 2's gradient methods and why it cannot simply extend to many layers.

Convergence, and why XOR is impossible

Rosenblatt's convergence theorem: if the data is linearly separable — some (w, b) classifies every sample correctly — the rule makes finitely many updates and stops at such (w, b), whatever the starting values and positive η. Updates are roughly bounded by (R/γ)², where R is the longest input length and γ the margin, the smallest distance from a sample to the boundary. Separability is the condition; η scales w, not halting.

XOR breaks it. Inputs (0,0), (0,1), (1,0), (1,1) have targets 0, 1, 1, 0. Correct behaviour needs b ≤ 0 and w₁ + w₂ + b ≤ 0, but also w₁ + b > 0 and w₂ + b > 0. The last two give w₁ > −b and w₂ > −b, so w₁ + w₂ + b > −b ≥ 0, contradicting the second condition. No numbers satisfy all four; training longer just cycles the weights.

The root cause is the single hyperplane. Add a hidden layer and XOR becomes two lines plus an AND (Chapter 5.3). For noisy data, the pocket algorithm keeps the best weights seen; the averaged perceptron averages weights over updates and often generalises better.

Exam traps

  • XOR with one perceptron never converges, however long you train. 'More epochs will fix it' is wrong.
  • Watch sign: correction uses (t − y). Using (y − t) moves boundary the wrong way and weights grow without limit.
  • Check threshold: some texts fire at net ≥ 0, others net > 0. A sample at net = 0 changes the update sequence.
  • Learning rate does not rescue non-separable data. It scales the step; convergence needs linear separability.
  • Do not confuse perceptron rule with delta rule or logistic regression. Those minimise squared or cross-entropy loss by gradient; perceptron uses no derivative.
  • An n-input perceptron's boundary is a hyperplane, not a curve. Curved boundaries need hidden layers or a kernel.

Analyze Prove that a single perceptron cannot compute XOR. 5 marks

Correct XOR needs b ≤ 0 from (0,0)→0, and w₁ + w₂ + b ≤ 0 from (1,1)→0. It also needs w₁ + b > 0 and w₂ + b > 0 from the two unit inputs mapping to 1. Those give w₁ > −b and w₂ > −b, hence w₁ + w₂ + b > −b ≥ 0, contradicting the second requirement. So no weights exist.

Analyze Two students train on the same separable data, one with η = 0.1 and one with η = 10. Does the larger learning rate need fewer updates? 4 marks

Not in general. With a fixed positive η the convergence bound does not depend on η; a large η only scales weights up and can make the boundary overshoot between corrections. The number of updates is governed by the margin of the data.

5.3 Multilayer feedforward networks and hidden layers

One neuron draws a straight boundary. Stack neurons in layers and the network can bend space: a hidden layer builds intermediate features, and the output layer combines them. This is a multilayer feedforward network. Signals move one way, input to output, with no loops. The same idea powers spam filters, credit-risk scores, speech recognisers and image taggers. A UPI fraud score can use layers of this kind. The gain is representation: hidden units create new descriptions of the input, so a later layer can solve a problem that no single straight line can. Some syllabi call the trained model a multilayer perceptron, or MLP.

You need Chapter 5.1 for the weighted-sum neuron and Chapter 5.2 for why one perceptron fails on XOR.

Layers, fan-in and fan-out

Arrange units in columns. The input layer holds the raw features x₁, x₂, ... and does no arithmetic, so it carries no weights. A hidden layer holds units whose values are not seen in the data. The output layer gives the prediction. Each unit in one layer connects to every unit in the next; this is a fully connected or dense layer.

Fan-in is the number of inputs arriving at a unit; fan-out is the number of units it feeds. A hidden unit with fan-in 2 and fan-out 3 sees two numbers and sends its result to three units.

Depth is the number of weight-carrying layers; width is the number of units in a layer. A 2–3–1 network has two inputs, three hidden units and one output: depth 2, maximum width 3. The input layer is not counted because it has no weights.

a = σ(W a_prev + b)

a is the activation vector of the layer; a_prev is the previous layer's activation vector; W is the weight matrix with shape n × m for m inputs and n units; b is the bias vector with n entries; σ is the nonlinear activation function.

For layer l, write Wˡ and bˡ. Start with a⁰ = x. Compute a¹, a², ..., aᴸ in order. The last vector aᴸ is the prediction. The activation σ is covered in Chapter 5.4.

Parameter counting and capacity

Every weight and bias is a learnable parameter. For a dense link from m units to n units, weights form an n × m matrix, so there are m×n weights and n biases. Total m n + n = n(m+1).

Use the 2–3–1 network. Input to hidden: m=2, n=3, so 2×3=6 weights and 3 biases, 9 parameters. Hidden to output: m=3, n=1, so 3×1=3 weights and 1 bias, 4 parameters. Total 13 parameters.

Width and depth trade off. A wider single hidden layer can fit many shapes. Depth often reaches the same accuracy with fewer parameters because early layers build simple parts and later layers combine them. Universal approximation says one hidden layer with enough units can approximate any continuous function on a bounded region to any desired accuracy. It does not say how many units are needed, or that training will find the weights.

Parameter count is a rough guide to capacity. Too few parameters underfit; too many overfit; see Unit 2, Overfitting and bias-variance.

Why XOR needs a hidden layer

A single perceptron computes step(w₁x₁ + w₂x₂ + b), one straight boundary. XOR puts (0,0) and (1,1) on one side and (0,1), (1,0) on the other. No single straight line separates them, as Chapter 5.2 shows.

Two hidden units build a new description. Let h₁ = step(x₁ + x₂ − 0.5), an OR gate that fires when at least one input is 1. Let h₂ = step(x₁ + x₂ − 1.5), an AND gate that fires only when both inputs are 1. The output y = step(h₁ − h₂ − 0.5) fires when h₁=1 and h₂=0. That happens for exactly one input on, which is XOR.

The hidden layer has changed the geometry: the four input points become (h₁,h₂) = (0,0), (1,0), (1,0), (1,1). The output now needs only a straight line in this new space. The output unit is still a perceptron; the hidden layer supplies it with a better input.

Exam traps

  • Depth counts layers with weights, not the input layer. The 2–3–1 network is a two-layer network, not three.
  • A hidden layer with a linear activation is wasted: W²(W¹x + b¹) + b² = (W²W¹)x + (W²b¹ + b²), which is one linear map. The activation must be nonlinear.
  • In parameter counts, each unit has its own bias. For m→n, count m n weights plus n biases, not m n biases.
  • Universal approximation is an existence statement. One huge hidden layer may need far more units than a deep network, and training may still fail.
  • The XOR thresholds are fixed: step(−0.5)=0 and step(0.5)=1. A sign slip turns OR into AND or reverses the output.

5.4 Activation functions and loss functions

A neural network learns by passing numbers forward and comparing its output with a target. The activation function decides what each unit passes on; the loss function measures how wrong the output is. Both must be differentiable at almost all points (or have a usable subgradient), because gradient descent needs a derivative where it is applied; a few functions are differentiable only piecewise. This chapter gives the common activation functions—step, sigmoid, tanh, ReLU, leaky ReLU and softmax—and the common losses: squared error, binary cross-entropy, categorical cross-entropy and hinge. The same ideas appear in spam filters, UPI fraud detection and image classifiers.

You need: Chapter 5.3 for where these functions sit in a network, and Unit 2 for the basic idea of a loss function.

Activation functions decide the output of a unit

A unit first computes a weighted sum z = Σ wᵢxᵢ + b, where wᵢ are weights, xᵢ are inputs, and b is the bias. The activation function f turns z into output a = f(z). It decides what the unit passes to the next layer. Training by gradient descent needs f to have a derivative, because backpropagation multiplies these derivatives.

The step function gives 1 when z ≥ 0 and 0 otherwise. It matches the McCulloch–Pitts neuron from Chapter 5.1. Its derivative is zero almost everywhere, so a network built only from steps cannot learn hidden weights by gradients.

σ(z) = 1/(1 + e⁻ᶻ)

z is the weighted input; e ≈ 2.718; σ(z) lies in (0,1). Derivative: σ(z)(1 − σ(z)), largest 0.25 at z = 0.

Sigmoid is used at an output unit for a yes/no probability, such as whether a transaction is fraud. For large positive or negative z the curve is flat; this is saturation, and the derivative becomes tiny.

tanh(z) = (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ)

range is (−1,1); derivative is 1 − tanh²(z). It is zero-centred, so hidden units train better than with sigmoid in shallow networks.

Tanh also saturates at both ends. For large |z| its derivative goes to zero, so deep networks with tanh hidden units learn slowly.

ReLU, leaky ReLU and softmax

ReLU (rectified linear unit) is f(z) = max(0, z). For z > 0 the output is z; for z < 0 the output is 0. Its derivative is 1 for z > 0 and 0 for z < 0. At exactly z = 0 it is not differentiable; code picks 0 or 1. ReLU is cheap and does not saturate for positive z, so it is the default in hidden layers of deep networks.

f(z) = max(0, z)

z is the weighted input; derivative is 1 if z > 0 and 0 if z < 0.

Leaky ReLU is f(z) = max(αz, z), where α is a small slope such as 0.01. On the negative side the output is αz, so the derivative is α instead of 0. This keeps a small gradient flowing.

For K classes, softmax is yᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}, where zᵢ is the logit (raw score) for class i and j runs over all K classes. Every yᵢ is positive and Σ yᵢ = 1, so the outputs act as class probabilities. Softmax sits at the output layer of a multiclass classifier, not in hidden layers.

Loss functions measure how wrong the output is

Loss L compares prediction y with target t. Regression uses squared error: L = ½(y − t)². Its derivative with respect to y is y − t. It punishes large errors strongly.

Binary classification with a sigmoid output uses binary cross-entropy: L = −[t log y + (1 − t) log(1 − y)]. Here t is 0 or 1 and y is the predicted probability. If t = 1 and y is near 0, the loss is large.

Multiclass classification with softmax uses categorical cross-entropy: L = −Σᵢ tᵢ log yᵢ. Here t is a one-hot vector with 1 for the true class and 0 elsewhere. Only the true-class term survives, but write the sum over all classes.

Hinge loss is L = max(0, 1 − t y), where t is ±1 and y is the raw score. It is used in support vector machines (Unit 3).

The derivative matters: backpropagation gives ∂L/∂w, and optimizers use it to update weights. A zero derivative from saturation stops learning.

Worked example

Question. A classifier gives logits z = (2, 1, 0) for three classes. Compute the softmax probabilities. If the true class is the first one, find the categorical cross-entropy loss; if the true class were the third, find the loss.

  1. Compute exponentials: e² = 7.389, e¹ = 2.718, e⁰ = 1.
  2. Sum = 7.389 + 2.718 + 1 = 11.107.
  3. Probabilities: 7.389/11.107 = 0.665; 2.718/11.107 = 0.245; 1/11.107 = 0.090. They add to 1.
  4. True class first: loss = −ln(0.665) = 0.408.
  5. True class third: loss = −ln(0.090) = 2.408.

Answer. The softmax probabilities are 0.665, 0.245 and 0.090; the loss is 0.408 for the first class and 2.408 for the third class.

Exam traps

  • Sigmoid with binary cross-entropy is for two classes; softmax with categorical cross-entropy is for more than two. Swapping them gives a wrong loss.
  • Categorical cross-entropy is −Σ tᵢ log yᵢ, not −log of the largest raw score. Apply softmax first; never put logits into log.
  • ReLU is not differentiable at exactly z = 0. State which value your code uses, 0 or 1, for that point.
  • Sigmoid and tanh saturate. For large |z| their derivatives go to zero, so deep networks learn slowly; ReLU is common in hidden layers for this reason.
  • A high probability for the true class gives a small loss. Do not report accuracy as loss; they measure different things.

5.5 Backpropagation training

A network learns by nudging every weight a little in the direction that lowers the loss. With thousands of weights you cannot do this one weight at a time, so you need the gradient of the loss for all of them at once. Backpropagation produces that gradient in one backward sweep by applying the chain rule layer by layer, from the loss towards the input. Every network you meet in use — a UPI fraud filter, a speech recogniser — was trained this way.

You need: 5.3 and 5.4, plus partial derivatives and the chain rule.

What δ means and why the sweep runs backwards

A forward pass turns input x into output a and gives a loss L, one number measuring the error. Training must know how L changes when each weight w changes, that is the partial derivative ∂L/∂w. There are far too many weights to test one at a time, so the whole gradient is computed in a single sweep running from the loss back to the input. That sweep is backpropagation.

The trick is to carry one intermediate number per unit. Define δ for a unit as ∂L/∂z: the derivative of the loss with respect to that unit's pre-activation z, the weighted sum computed just before the activation function. Read δ as the unit's share of the blame for the error.

Two notations come up. The Hadamard product of two vectors, written u ⊙ v, multiplies them element by element: (u ⊙ v)ᵢ = uᵢ vᵢ. The Jacobian of a vector function is the matrix holding all its first partial derivatives; for a single unit it is just the number σ′(z), the slope of the activation.

Backpropagation is cheap because it reuses work. The forward pass already computed and stored z and a for every unit. The backward pass reads those stored values and builds each δ from the δ of the layer above, so no derivative is ever computed twice.

The chain rule, layer by layer

Number the layers 1 to L, with L the output layer, and write a⁽⁰⁾ = x. Layer l holds weight matrix W⁽ˡ⁾, bias vector b⁽ˡ⁾ and activation σ. The forward pass is two lines per layer.

z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾, a⁽ˡ⁾ = σ(z⁽ˡ⁾)

W⁽ˡ⁾ is the weight matrix of layer l, b⁽ˡ⁾ its bias vector, a⁽ˡ⁻¹⁾ the activations coming in from the layer below, z⁽ˡ⁾ the pre-activation and a⁽ˡ⁾ what the layer passes on.

Backward starts at the loss. At the output layer the blame is the loss slope multiplied by the activation slope.

δ⁽ᴸ⁾ = ∂L/∂a⁽ᴸ⁾ ⊙ σ′(z⁽ᴸ⁾)

∂L/∂a⁽ᴸ⁾ is how fast the loss changes with the output; σ′(z⁽ᴸ⁾) is the activation slope at the pre-activation z⁽ᴸ⁾, not at a⁽ᴸ⁾.

For a hidden layer the same rule applies, with the signal arriving from above. The transpose W⁽ˡ⁺¹⁾ᵀ sends the blame back through the same weights the forward pass used.

δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾ᵀ δ⁽ˡ⁺¹⁾) ⊙ σ′(z⁽ˡ⁾)

W⁽ˡ⁺¹⁾ᵀ is the transpose of the next layer's weights, δ⁽ˡ⁺¹⁾ the blame one layer above, and σ′(z⁽ˡ⁾) the local slope at layer l.

Once the δ values are known the weight gradients follow. A weight that multiplies input aᵢ and feeds unit j gets gradient δⱼ × aᵢ, so the whole matrix is an outer product.

∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ (a⁽ˡ⁻¹⁾)ᵀ, ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾

δ⁽ˡ⁾ is the blame vector of layer l and (a⁽ˡ⁻¹⁾)ᵀ is the previous activation written as a row, so the product has the shape of W⁽ˡ⁾. The bias gradient is δ itself because ∂z/∂b = 1.

The update, the cost, and computation graphs

Gradient descent then sets w ← w − η ∂L/∂w for every weight, where η is the learning rate, a small positive number such as 0.1 or 0.5. The minus sign matters: the weight moves against the gradient, so a negative gradient raises the weight.

  1. Forward: for l = 1 to L, compute z⁽ˡ⁾ and a⁽ˡ⁾ and store both.
  2. Loss: compute L from the final a⁽ᴸ⁾ and the target.
  3. Output blame: δ⁽ᴸ⁾ = ∂L/∂a⁽ᴸ⁾ ⊙ σ′(z⁽ᴸ⁾).
  4. Hidden blame: for l = L−1 down to 1, δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾ᵀ δ⁽ˡ⁺¹⁾) ⊙ σ′(z⁽ˡ⁾).
  5. Gradients: ∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ (a⁽ˡ⁻¹⁾)ᵀ and ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾.
  6. Update: w ← w − η ∂L/∂w for every weight and bias.

Cost. The forward pass does one multiply-add per weight, about Σ nₗ nₗ₋₁ of them for layer sizes nₗ. The backward pass does roughly twice that, one pass for Wᵀδ and one for δ aᵀ. So a training step costs about three forward passes, and the memory cost is the stored activations.

Each forward operation can be drawn as a node in a computation graph, with arrows from inputs to output. Walking the graph in reverse order applies the chain rule once per node. That is why one short loop over layers trains a network of any depth, with no new formula per layer. Older syllabi say error back propagation for the same idea.

Worked example

Question. A single sigmoid unit has weight w = 1, bias b = 0, input x = 1 and target t = 1. The loss is L = ½(a − t)². Compute z, a, L, ∂L/∂a, σ′(z), δ = ∂L/∂z and ∂L/∂w, then take one gradient step with learning rate η = 0.5 and give the new w and b.

  1. Forward pre-activation: z = w x + b = 1 × 1 + 0 = 1.000000.
  2. Activation: a = 1/(1 + e^(−1)) = 0.731059.
  3. Loss: L = ½(0.731059 − 1)² = ½(−0.268941)² = 0.036165.
  4. Loss slope at the output: ∂L/∂a = a − t = −0.268941.
  5. Activation slope at z = 1: σ′(z) = a(1 − a) = 0.731059 × 0.268941 = 0.196612.
  6. Blame: δ = ∂L/∂a × σ′(z) = −0.268941 × 0.196612 = −0.052877.
  7. Weight gradient: ∂L/∂w = δ × x = −0.052877 × 1 = −0.052877. Bias gradient: ∂L/∂b = δ = −0.052877.
  8. Update: w ← 1 − 0.5 × (−0.052877) = 1.026439; b ← 0 − 0.5 × (−0.052877) = 0.026439.

Answer. After one step the weight is w = 1.026439 and the bias is b = 0.026439; both rose because the gradient was negative.

Exam traps

  • Evaluate σ′ at the pre-activation z, never at a or at the loss. For a sigmoid, σ′(z) = a(1 − a) is computed from the stored a, which is why activations are kept.
  • Forgetting a_prev: ∂L/∂W = δ a_prevᵀ, not δ alone. The bias gradient is δ alone, because the bias adds no input factor.
  • Sign slip: gradient descent subtracts the gradient, so a negative gradient increases the weight. If your loss rises after the update, check the sign first.
  • δ is not ∂L/∂a. They differ by the factor σ′(z); the output layer δ is the product of the two.
  • Gradients accumulate if not reset. In loop-based code, clear the gradient buffers before each new backward pass.

5.6 Gradient-based optimizers and regularization for networks

Training a network means changing weights to reduce a loss. Plain gradient descent uses one fixed step size, so progress is slow along flat directions and overshoots along steep ones. And training with no penalty on too little data can overfit, which is why training also uses regularization. Modern training uses better update rules—momentum, RMSProp, Adam—and penalties that keep weights small. The same loop runs: mini-batch, backprop, an update, repeat. You meet it in every deep-learning library, from image classifiers to speech models.

You need: the gradients from Chapter 5.5, and overfitting plus ridge and lasso from Unit 2.

Batch, stochastic and mini-batch updates

A batch update computes the gradient over all N training examples, then takes one step. It is stable but one step costs a full pass, so training is slow on large data.

Stochastic gradient descent (SGD) uses one example per step. The gradient is noisy; the noise lets weights jump out of shallow regions and often generalizes well, but the loss jumps around.

Mini-batch SGD uses B examples, usually 32 to 256. The gradient is an average, so it is less noisy than SGD and cheaper per step than batch. Shuffle the data each epoch and walk through all mini-batches; one epoch is one full pass.

g = (1/B) Σ<sub>i=1</sub><sup>B</sup> ∇<sub>w</sub> L(x<sub>i</sub>, y<sub>i</sub>; w)

g is the mini-batch gradient; B is the batch size; L is the loss; xi, yi are one example and its label; w is the weight vector; ∇w is the gradient with respect to w.

Momentum, RMSProp and Adam

Plain SGD follows the current gradient only. In a long narrow valley it zig-zags across the valley and crawls along it. Momentum adds a running velocity.

v ← βmomv + g, then w ← w − ηv

v is velocity; βmom is the momentum coefficient (the subscript marks it as the momentum one), often 0.9; g is the gradient; η is the learning rate; w is a weight.

At the first step v = g. Later v keeps part of the old direction. With βmom = 0.9 the velocity remembers about ten recent gradients; it speeds up along consistent directions and damps zig-zag.

RMSProp divides the step by a running root of squared gradients, so each weight gets its own effective step size. Large recent gradients get smaller steps.

s ← ρs + (1 − ρ)g², then w ← w − η g / √(s + ε)

s is the running mean of squared gradients; ρ is a decay rate, often 0.9; ε is a tiny number such as 10⁻⁸ that avoids division by zero.

Adam combines momentum and RMSProp, with bias correction for the first steps.

m ← β₁m + (1 − β₁)g;  v ← β₂v + (1 − β₂)g²;  m̂ = m/(1 − β₁<sup>t</sup>);  v̂ = v/(1 − β₂<sup>t</sup>);  w ← w − η m̂/(√v̂ + ε)

m is the first moment, a smoothed gradient; v is the second moment, a smoothed squared gradient; t is the step number; β₁ = 0.9 and β₂ = 0.999 are typical; m̂ and v̂ are bias-corrected values; ε is small.

Bias correction matters because m and v start at zero. Typical Adam defaults are η = 0.001, β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸. Only a few universities teach Adam's correction terms in detail; know the shape and the defaults.

Regularization and tuning

L2 weight decay adds λ‖w‖² to the loss. For one weight the penalty is λw²; its gradient is 2λw, so each step shrinks w by 2ηλw. λ controls strength. Regularize weights, not biases.

L1 adds λ|w|; its gradient is λ sign(w). It pushes small weights to exactly zero, giving a sparse network.

Early stopping watches validation loss and stops when it rises, keeping the best weights.

Dropout randomly sets each hidden unit to zero with probability 1 − p during training; p is the keep probability. At prediction time dropout is off. To keep the expected output the same, weights are multiplied by p, or activations are divided by p during training.

Batch normalization normalizes each mini-batch's pre-activation z to zero mean and unit variance, then scales and shifts: ẑ = (z − μ)/√(σ² + ε), y = γẑ + β. Here μ and σ² are the batch mean and variance; γ and β are learned. This β is a learned shift and has nothing to do with the momentum coefficient βmom of Section 2. Batch norm and Adam together are advanced for this unit.

Tune η, λ, layer widths and batch size on a validation split, never on the test set.

Question. A weight starts at w = 1, with η = 0.1 and βmom = 0.9. The gradient is g = 0.4 at each of three steps. (a) Apply plain SGD for three steps. (b) Apply momentum v ← βmomv + g, w ← w − ηv. (c) For L2 with λ = 0.01 at w = 2, give the penalty and its gradient contribution.

  1. Plain SGD, step 1: w = 1 − 0.1×0.4 = 0.96.
  2. Plain SGD, step 2: w = 0.96 − 0.04 = 0.92.
  3. Plain SGD, step 3: w = 0.92 − 0.04 = 0.88.

  • Never tune η or λ on the test set; use a validation split.
  • Switch dropout off at prediction time, or the output becomes random.
  • In Adam, v is the second moment of the gradient, not velocity; momentum's v is velocity.
  • The L2 gradient is 2λw, not λw.

5.7 From shallow to deep networks: deep learning vs ANNs

A shallow network has one or two hidden layers. A deep network has many, and each layer builds its features from the layer below: edges become parts, parts become objects. The catch is that backpropagation through many sigmoid layers multiplies the gradient by a small fraction at every layer, so the early layers barely learn. ReLU units, careful initialization and shortcut connections keep that gradient alive. Most modern image, speech and medical-imaging models build on these ideas in some form, usually combined with normalization and skip connections.

You need: hidden layers and activation functions from chapters 5.3 and 5.4, and the chain rule of backpropagation from 5.5.

What depth buys

Take an image of a chest X-ray. The first hidden layer responds to short dark or bright edges. The second combines those edges into corners and blobs. The third combines blobs into shapes such as a rib line or a heart border. Later layers combine shapes into a diagnosis. Nobody wrote those features by hand; backpropagation found them. That is the main claim of deep learning: features composed from features, learned from data.

Older computer vision built features by hand, such as edge filters and texture histograms, and fed the numbers to a separate classifier. A deep network replaces that pipeline with many layers of simple units and trains the whole thing end to end.

The wording matters in exams. An artificial neural network (ANN) is any network of artificial neurons, and a single perceptron counts. Deep learning is the practice of training networks with many hidden layers, where the representations are learned, using large datasets and GPU hardware. Depth is the number of layers on the longest path from input to output, not the number of weights: a very wide one-hidden-layer network is still shallow. Deep networks can represent some functions with far fewer units than a shallow network needs; that is a representational advantage. The practical arrival of deep networks came from large datasets, GPU hardware and better training tricks.

Unit saturation: the vanishing gradient

Backpropagation multiplies local derivatives along the path from the loss back to a weight. For a sigmoid unit σ(z) = 1/(1+e^(−z)) the local derivative is σ′(z) = σ(z)(1 − σ(z)). It is largest at z = 0, where σ = 0.5 and σ′ = 0.25. So the best a sigmoid layer can do is pass one quarter of the gradient. Every extra layer multiplies the signal by at most 0.25.

∂L/∂W₁ = (∂L/∂a_L) × Π_{l=2..L} [σ′(z_l) · W_l]

L is the loss, W₁ the weights of the first layer, a_L the last activation, z_l the pre-activation of layer l, W_l its weight matrix, σ′ the sigmoid derivative, and Π_{l=2..L} the product taken from the last layer back to layer 2. Every layer in the product contributes both its sigmoid derivative and its weight matrix.

Five layers give 0.25⁵ ≈ 0.001. Ten layers give about 9.5×10⁻⁷. The gradient reaching the first layer is practically zero, so those weights stop moving. Older texts call this unit saturation: when |z| is large the sigmoid is flat, σ′ → 0, and the unit is saturated, meaning it neither learns nor passes gradient.

The reverse case is exploding gradients. If the weight matrices are large, the same product of terms above 1 grows without bound and the weights jump around instead of settling. One product of many numbers causes both effects. Saturated sigmoid units are the usual cause, and the vanishing gradient is the effect seen across many layers.

ReLU and the fixes

ReLU(z) = max(0, z). Its derivative is 1 for z > 0 and 0 for z < 0. On the active side the layer passes the gradient unchanged, so a chain of active ReLU units has factor 1^L = 1 and the first layer learns as fast as the last. It is also cheap: one comparison, no exponential.

  • Leaky ReLU uses 0.01z for z < 0, so a negative unit still carries a small gradient; ELU and its relatives smooth that corner.
  • ReLU has its own failure. A unit whose pre-activation is negative for every input passes zero gradient, so its weights never change again. That is a dead unit. Leaky ReLU and a sensible learning rate reduce it.
  • Xavier (Glorot) initialization sets the weight variance to 2/(fan_in + fan_out) for sigmoid and tanh layers. He initialization sets it to 2/fan_in for ReLU layers, because about half the units are silent. fan_in is the number of inputs to a unit.

Residual connection: instead of a block computing y = F(x), it computes y = F(x) + x. The gradient now has a path with derivative 1 straight back to the input, so it no longer has to survive every layer as a product. Only a few curricula teach this at this level; most exams ask for the one-line statement.

Worked example

Question. A network has five sigmoid layers between a weight w in the first layer and the loss. The gradient of the loss with respect to the output activation is 1.0. (a) Give the best-case shrink factor over the five layers. (b) Give the gradient that reaches w. (c) With learning rate η = 0.1, how far does w move in one step? (d) Repeat (b) and (c) for five ReLU layers whose pre-activations are all positive.

  1. Best case for one sigmoid layer: z = 0, so σ′ = σ(1−σ) = 0.5 × 0.5 = 0.25.
  2. Five layers multiply the factor: 0.25² = 0.0625, 0.25³ = 0.015625, 0.25⁴ = 0.00390625, 0.25⁵ = 0.0009765625.
  3. (b) Gradient arriving at w: 1.0 × 0.0009765625 = 0.0009765625, about 9.77×10⁻⁴.
  4. (c) Weight step: Δw = η × gradient = 0.1 × 0.0009765625 = 9.765625×10⁻⁵, about 0.0001 per step.
  5. (d) ReLU: derivative is 1 for z > 0, so the factor is 1⁵ = 1. The gradient arrives as 1.0 × 1 = 1.0.
  6. Weight step with ReLU: Δw = 0.1 × 1.0 = 0.1, which is 1024 times larger than the sigmoid step.

Answer. The sigmoid stack delivers 0.00098 of a gradient of 1.0 and moves the weight by 9.77×10⁻⁵ per step, while the ReLU stack delivers 1.0 and moves it by 0.1.

Exam traps

  • Deep learning is not more epochs or a bigger batch. Trained for 500 epochs, a one-hidden-layer network is still shallow. Depth means layers of learned features.
  • The maximum slope of a sigmoid is 0.25, but the maximum slope of tanh is 1.0. Mixing the two turns the correct factor 0.25^L into a wrong 1/L.
  • ReLU does not remove vanishing gradients everywhere. A unit with z < 0 for all inputs has derivative 0, receives nothing and stays dead on its own.
  • Vanishing and exploding gradients are the same product: factors below 1 shrink it, factors above 1 blow it up. Neither is caused by the loss function alone.
  • Depth is counted in layers, not parameters. A wide shallow network can hold more weights than a small deep one and still be called shallow.

5.8 Convolutional neural networks: convolution and pooling

A convolutional neural network (CNN) is a feedforward network built for grid data such as images. Instead of connecting every input pixel to every unit, it slides a small filter over the image and reuses the same weights at every position. This is convolution. A pooling step then shrinks the map. The two together cut the number of weights by a large factor while keeping local patterns. CNNs are used in face unlock, medical imaging, document scanning and defect detection on factory lines.

You need: activation functions (ReLU, softmax), backpropagation to see how filters are trained, and deep network basics.

Convolution: a small filter that slides

An image is a grid of numbers: height × width × channels. A dense layer connected to every pixel needs a huge weight matrix. For a 224×224 colour image, one dense layer of 1000 units would need 224×224×3×1000 weights, about 150 million. A convolution layer avoids this by using a small filter, also called a kernel, and sliding it over the grid.

At each position, the filter and the input patch under it are multiplied element by element and summed. That single number becomes one cell of the output map. The patch is the local receptive field of that output cell. The same filter weights are reused at every position; this is weight sharing. A 3×3 filter has 9 weights, not one weight per pixel. In strict signal-processing terms this sliding sum without flipping the filter is cross-correlation; deep-learning libraries call it convolution, and that is the meaning used here.

h_out = floor((n + 2p − f) / s) + 1

n is the input side in pixels, p is the padding (extra zero rows and columns on each side), f is the filter side, s is the stride (pixels moved per step), h_out is the output side, and floor means round down to the integer below.

For a 5×5 input, a 3×3 filter, no padding and stride 1: floor((5 + 0 − 3)/1) + 1 = 3, so the output is 3×3. Padding p = 1 on the same input gives floor((5 + 2 − 3)/1) + 1 = 5, so the map keeps the input size. A stride of 2 skips positions and shrinks the map faster.

params = f × f × C_in × K + K

C_in is the number of input channels, K is the number of filters, and the final +K is one bias per filter. For one 3×3 filter on a 1-channel image: 3×3×1×1 + 1 = 10 parameters.

With 3 input channels (red, green, blue) and 16 filters of size 3×3, the count is 3×3×3×16 + 16 = 448. The filter depth must equal C_in; a 3×3 filter on an RGB image is really 3×3×3.

Filters, ReLU and pooling

Filter values are learnable weights. Backpropagation adjusts them from the loss, as in any network (see backpropagation). Early filters often become edge or blob detectors. A vertical-edge filter such as rows 1 0 −1 / 1 0 −1 / 1 0 −1 gives a large positive response where the image is bright on the left and dark on the right, and a negative response where it is dark on the left and bright on the right.

After convolution, a ReLU replaces every negative value with 0 and keeps positives. This adds non-linearity without changing the map size (see activation functions).

Pooling shrinks each map. A 2×2 max-pooling window with stride 2 takes the largest value in each non-overlapping 2×2 block. Average pooling takes the mean instead. Pooling has no weights and no bias; it only has a window size and a stride. Its output size uses the same size formula.

p_out = floor((n + 2p − f) / s) + 1

n is the input side, f is the pooling window side, s is the pooling stride, p is padding (usually 0), and p_out is the pooled side.

For a 5×5 map with 2×2 pooling and stride 2: floor((5 − 2)/2) + 1 = 2, so the pooled map is 2×2. The four windows cover rows 1–2 and 3–4, and columns 1–2 and 3–4; row 5 and column 5 are dropped. Pooling lowers computation and gives small shift tolerance: if a feature moves by one pixel, it often stays inside the same window.

A CNN pipeline is: conv → ReLU → pool → (repeat conv-ReLU-pool) → flatten → dense → softmax. Flatten turns the final maps into one vector. Dense layers combine that vector, and softmax turns the final scores into class probabilities.

CNN architectures and transfer learning

A CNN usually stacks several conv-ReLU-pool blocks. As depth increases, spatial size falls and the number of filters rises, so later layers see larger patterns with more channels. The final maps are flattened and passed to one or more dense layers.

  • LeNet-5: an early small CNN for handwritten digit recognition; convolution, pooling and dense layers.
  • AlexNet: a deeper CNN with ReLU and dropout that won the ImageNet image-classification challenge in 2012.
  • VGG: a simple design that repeats 3×3 convolutions in blocks; easy to describe but heavy in parameters.
  • ResNet: adds skip connections that let a signal bypass a block, so very deep networks train without the gradient vanishing.

Transfer learning reuses a model trained on a large dataset, such as ImageNet, and fine-tunes it on a small new dataset. The early conv filters often detect general edges and textures, so they transfer well.

  • ReLU changes values but not shape. Flatten comes after the final pooling stage, before the dense layers, not before pooling.

5.9 Recurrent neural networks

A feedforward network sees one input and forgets it. A recurrent neural network (RNN) adds a hidden state ht that acts as memory: it is updated at every step from input xt and previous state ht−1. The same weights are reused at all steps, so any sequence length uses one small parameter set. This is how phone keyboards guess the next word, how speech is transcribed, and how sensor or UPI transaction streams are modelled. The update rule, unrolling, gradient decay and LSTM fix follow.

You need: 5.5 (chain rule), 5.7 (vanishing gradients), and 5.4 (tanh, sigmoid).

The recurrent unit and unrolling

A feedforward layer maps one input to one output. A sequence x1,...,xT needs an output at every step and memory of earlier steps. An RNN keeps a hidden vector ht of fixed size d. The state is overwritten each step, not stored as a list. At run time the state is one vector of size d, so memory is O(d); during BPTT training the unrolled graph keeps the ht for all T steps, so memory grows as O(T·d). The parameter count alone is independent of T.

h<sub>t</sub> = tanh(W x<sub>t</sub> + U h<sub>t−1</sub> + b),   y<sub>t</sub> = V h<sub>t</sub>

xt is the input vector of size m; ht is the hidden state of size d; W is d×m, U is d×d, V is k×d; b is a bias vector of size d; yt is the output vector of size k; tanh acts element by element.

The same W, U, V and b are used at every time step. To train, unroll the network: draw a copy of the cell for t=1,...,T, with ht−1 feeding ht. This is only a drawing aid; there is one set of weights. The parameter count is d×m + d×d + k×d + d, independent of T. A 1000-step sequence and a 10-step sequence have the same number of trainable weights.

  1. Start with h0 = 0, or a learned initial state.
  2. For t = 1 to T, compute pre-activation at = W xt + U ht−1 + b, then ht = tanh(at).
  3. Compute yt = V ht, then a loss such as cross-entropy for the next symbol.
  4. Sum the losses over t; backpropagate through the unrolled graph to get gradients for W, U, V, b.

Backpropagation through time and gradient size

Training a recurrent net uses backpropagation through time (BPTT). It is ordinary backpropagation on the unrolled graph. Because W and U appear at every step, their gradients are sums of contributions from all T steps. A long sequence gives a long chain of Jacobian products.

For one step the Jacobian is ∂ht/∂ht−1 = diag(1 − ht²) U. In the backward pass the gradient is carried by the transpose: ∂L/∂ht−1 = Uᵀ diag(1 − ht²) ∂L/∂ht. The tanh derivative 1 − ht² lies between 0 and 1. Over k steps the forward Jacobian multiplies k such matrices. If the largest singular value of U is below 1, the product shrinks exponentially: this is the vanishing gradient problem. If it is above 1, the product grows and gradients explode. Saturation of tanh, where ht is near ±1, makes the slope near zero and speeds the shrink.

∂h<sub>T</sub>/∂h<sub>t</sub> = ∏<sub>i=t+1</sub><sup>T</sup> diag(1 − h<sub>i</sub>²) U

U is d×d; diag(1 − hi²) is the diagonal matrix of tanh slopes at step i; the product is a matrix product with the i = T factor leftmost and i = t+1 rightmost; the factors do not commute.

Gradient clipping handles exploding gradients. Compute the gradient vector g for all parameters; if its norm ||g|| is larger than a threshold c, replace g by c g / ||g||. This keeps the step bounded but does not create memory. For vanishing gradients, use gated units (LSTM, GRU), a ReLU-style nonlinearity where suitable, or shorter truncated sequences.

LSTM and GRU: gated memory

A plain RNN overwrites ht at every step. An LSTM (long short-term memory) adds a cell state ct that runs along time with only elementwise changes, and gates that decide what to keep, write and read. A gate is a sigmoid layer: σ(z)=1/(1+e−z), so each gate value is between 0 and 1.

f<sub>t</sub> = σ(W<sub>f</sub>[h<sub>t−1</sub>, x<sub>t</sub>] + b<sub>f</sub>),   i<sub>t</sub> = σ(W<sub>i</sub>[h<sub>t−1</sub>, x<sub>t</sub>] + b<sub>i</sub>),   c̃<sub>t</sub> = tanh(W<sub>c</sub>[h<sub>t−1</sub>, x<sub>t</sub>] + b<sub>c</sub>),   c<sub>t</sub> = f<sub>t</sub> ⊙ c<sub>t−1</sub> + i<sub>t</sub> ⊙ c̃<sub>t</sub>,   o<sub>t</sub> = σ(W<sub>o</sub>[h<sub>t−1</sub>, x<sub>t</sub>] + b<sub>o</sub>),   h<sub>t</sub> = o<sub>t</sub> ⊙ tanh(c<sub>t</sub>)

ft, it, ot are the forget, input and output gates; ct is the cell state; c̃t is the candidate cell value; ht is the hidden output; [ht−1, xt] is concatenation; ⊙ is elementwise multiplication; Wf, Wi, Wc, Wo and bf, bi, bc, bo are gate weights and biases; σ is the sigmoid.

The key line is ct = ft ⊙ ct−1 + it ⊙ c̃t. Its derivative with respect to ct−1 is just ft, an elementwise factor. When ft is near 1, the gradient passes many steps without being multiplied by a weight matrix and a tanh slope at every step. The forget gate near 0 deletes old memory; the input gate near 1 writes new information; the output gate controls how much of tanh(ct) becomes ht.

A GRU (gated recurrent unit) uses two gates, update and reset, and one state vector instead of separate h and c, so it has fewer parameters. Uses include next-word prediction on a phone keyboard, speech recognition, time-series forecasting such as electricity load, and sequence labelling in text. For very long sequences, attention-based models are now common, but the recurrent idea is still the base.

Exam traps

  • Do not multiply the parameter count by T. The unrolled steps share W, U, V, b; there is one weight set, only the graph is longer.
  • BPTT is not a separate learning rule. It is backpropagation on the unrolled graph, with gradients summed over time because weights are shared.
  • A vanishing gradient is not the same as a small loss. It means early-step derivatives become tiny, so early words or inputs get almost no update.
  • In an LSTM, ft near 1 keeps the old cell state and ft near 0 erases it. The cell state ct is not the hidden output ht.
  • Clipping prevents exploding gradients, not vanishing ones. It rescales a large gradient; it cannot restore a signal that has already decayed.

Hidden stateIn an RNN, the vector hₜ that is passed from step t to step t+1 and summarises the sequence seen so far.5.9

Takeaways

  1. A single McCulloch–Pitts unit already computes AND, OR and NOT, because a weighted sum compared with a threshold is a linear decision.
  2. The perceptron learns only from its mistakes, and it is guaranteed to finish only when the two classes are linearly separable.
  3. One hidden layer is enough to represent XOR and any continuous function, so depth removes the straight-line restriction.
  4. Training needs differentiable activation and loss functions, because the gradient must flow through both.
  5. Backpropagation is not a separate algorithm from gradient descent; it is the efficient way to compute the gradient that gradient descent then uses.
  6. Plain gradient descent is slow and overfits on networks, so momentum, RMSProp and Adam are used together with L2, dropout and early stopping.
  7. Deep networks fail with sigmoid units because the gradient vanishes; ReLU and good initialization keep it alive.
  8. A CNN replaces millions of dense weights with a small shared filter, which is why it works on images.
  9. An RNN reuses one weight matrix at every time step, so one model handles sequences of any length.

Glossary

Backpropagation through time
Backpropagation applied to an unrolled recurrent network, summing gradients over all time steps.
Batch
A small group of training examples whose gradients are averaged before one weight update.
Batch normalization
Normalising a layer's pre-activations to zero mean and unit variance per mini-batch, then rescaling with learned parameters.
Bias
A learnable constant added to a unit's weighted sum; it shifts the activation curve left or right.
Distributed representation
Encoding a concept across a pattern of activity in many units rather than in a single unit.
Early stopping
Ending training when validation loss starts to rise, keeping the weights from the best epoch.
Epoch
One complete pass of the training algorithm over the whole training set.
Feature map
The output of one filter applied across the whole input in a convolutional layer.
Gradient
The vector of partial derivatives of the loss with respect to each parameter; it points in the direction of steepest increase.
Hyper-parameter
A setting chosen before training, such as learning rate, layer size or dropout rate, not learned from the data.
Learning rate
The step size η used when a weight is moved against the gradient.
Long short-term memory
A recurrent cell with input, forget and output gates that lets information survive many time steps.
Loss function
A number that measures how far the network's output is from the target for one example.
Mean squared error
L = (1/n)Σ(yᵢ − tᵢ)², the usual loss for regression outputs.
Neuron (unit)
A small computing element that multiplies its inputs by weights, adds them with a bias and passes the result through an activation function.
Padding
Extra zeros added around an input so a convolution can keep the output the same size as the input.
Parameter sharing
Using the same weights at many positions or time steps, as in convolution and recurrent layers.
Regularization
Any penalty or constraint added to training that reduces overfitting, such as an L2 term λΣw².
Saturation
The state where a sigmoid or tanh unit sits far from zero and its derivative is near zero, so the gradient barely passes.
Softmax
A function that converts a vector of scores into probabilities that are positive and sum to one.
Stochastic gradient descent
Gradient descent that updates weights using one example or a small mini-batch instead of the full dataset.
Stride
The number of input positions a convolution filter moves between two dot products.
Transfer learning
Reusing a network trained on a large dataset and fine-tuning it for a new, smaller task.
Weight
A learnable number that says how strongly one input affects one unit.
