1.1 History and future of quantum computation

A classical computer stores information in bits, each 0 or 1, and moves them with logic gates. A quantum computer stores information in qubits, unit vectors in a two-dimensional complex vector space, and moves them with unitary gates. Different physics gives a different cost model: a few problems need exponentially fewer steps, most do not. The history below shows how that trade was found and why the machines are hard to build. Quantum key distribution already runs over fibre; chemistry, factoring and optimisation wait on larger machines.

You need nothing beyond school algebra; the complex numbers and vector spaces used here are built in 1.2 and 1.3.

Bits, qubits and what changes

A classical bit is a physical device with two stable states, written 0 and 1. A register of n bits holds one of 2ⁿ strings. A gate turns one string into another, and reading the register gives that string back.

A qubit is a unit vector in C², the space of pairs of complex numbers. It is written α|0⟩ + β|1⟩, where α and β are complex numbers called amplitudes, and |α|² + |β|² = 1. You cannot read α and β off one qubit. Measurement gives 0 with probability |α|² and 1 with probability |β|².

A register of n qubits is a unit vector in the tensor product of n copies of C², so it is fixed by 2ⁿ complex amplitudes. Measurement returns one n-bit string, with probability equal to the squared magnitude of its amplitude. That one sentence explains both facts of the field: the state list is exponentially large, so classical simulation is hard, yet gates still act on it in polynomial time, so new algorithms exist.

How the field started

The field grew from one question: can a machine whose parts obey quantum mechanics do something a classical machine cannot do cheaply?

  • 1982, Feynman: simulating a quantum system on a classical computer seems to cost exponential time in the number of particles, so a machine built from quantum parts could do it naturally. He proposed no algorithm; he asked what such a machine is for.
  • 1984, Bennett and Brassard, BB84: two parties agree on a secret key by sending single photons. An eavesdropper disturbs the states and is caught. This was the first working quantum information task; see Unit 5.
  • 1985, Deutsch: the universal quantum computer, one machine that can simulate any other quantum machine, the quantum version of the universal Turing machine. He also gave a first small algorithm, right only half the time, that hinted at a quantum advantage; see Unit 4.
  • 1994, Shor: integer factoring and discrete logarithms in polynomial time on a quantum computer. RSA and Diffie–Hellman rest on these problems being hard.
  • 1996, Grover: search of an unordered list of N items in about √N steps, a quadratic speedup.

Quantum error correction followed in the mid-1990s. It turned the subject from a curiosity into an engineering target, because a machine that corrects its own errors can in principle run long circuits.

The two models side by side

Compare the models the way you compare algorithms: by the resources each spends.

Information unitbit, 0 or 1qubit, unit vector in C²
State of n unitsone of 2ⁿ strings2ⁿ complex amplitudes
Operationlogic gate, strings to stringsunitary matrix, reversible

Unitary gates are reversible, so a quantum circuit has no built-in erasure; a classical AND throws a bit away and a quantum gate cannot. Interference is the working tool: an algorithm arranges amplitudes so that wrong answers cancel and the right answer adds up. Entanglement makes two qubits behave as one system with no separate descriptions, and it is what makes teleportation and dense coding work (Unit 3).

The last row of the table is the honest summary. Quantum computing is not a faster processor for the same programs; it is a different resource that only some problems can spend.

Where it is going

  • Better qubits: superconducting circuits, trapped ions, neutral atoms and photons. Each trades gate speed against coherence time and connectivity.
  • Error correction: many physical qubits encode one logical qubit, and gates must stay below a threshold error rate for the code to help rather than hurt.
  • Scaling: today's machines are small and noisy. Roadmaps track qubit count, gate error and coherence time together, because one number alone means little.
  • Algorithms: fewer proven speedups exist than headlines suggest. Factoring, search, simulation of chemistry and some linear algebra are the solid cases (Unit 4).
  • Applications and security: chemistry, materials and optimisation (Unit 6), plus migration to post-quantum cryptography before large machines arrive (Unit 5).

Worked example

Question. A quantum computer keeps an n-qubit register as a list of complex amplitudes. Take n = 50 and store each amplitude as 16 bytes (two 8-byte floating-point numbers). (a) How many amplitudes are there? (b) How many bytes of memory? (c) How many petabytes, taking 1 PB = 10¹⁵ bytes? (d) State one consequence.

  1. Number of amplitudes = 2ⁿ = 2⁵⁰, because each of the 50 qubits contributes a factor of 2.
  2. 2⁵⁰ = 1,125,899,906,842,624 amplitudes, about 1.126 × 10¹⁵.
  3. Memory = 1,125,899,906,842,624 × 16 bytes = 18,014,398,509,481,984 bytes, about 1.801 × 10¹⁶ bytes.
  4. In petabytes: 1.801 × 10¹⁶ ÷ 10¹⁵ = 18.01 PB.
  5. Consequence: a classical machine simulating a generic 50-qubit state needs 18.01 PB just for the amplitudes, so simulation stops being practical far below the qubit counts that laboratories discuss.

Answer. 2⁵⁰ = 1,125,899,906,842,624 amplitudes, which need 18,014,398,509,481,984 bytes, that is 18.01 PB.

Worked example 2

Question. Grover's search finds one marked item among N = 1,000,000 unordered items. About how many steps does it need, and how many does a classical linear search need on average?

  1. Grover's step count is about (π/4)√N.
  2. √N = √1,000,000 = 1000.
  3. (π/4) × 1000 = 0.7854 × 1000 = 785.4, so about 785 steps.
  4. Classical linear search checks N/2 items on average = 1,000,000 ÷ 2 = 500,000 steps.
  5. Speedup factor = 500,000 ÷ 785 ≈ 637, roughly the expected √N ÷ const factor.

Answer. About 785 quantum steps against 500,000 classical steps on average, a quadratic speedup.

Exam traps

  • Do not write that a quantum computer tries all 2ⁿ answers and returns the best one. Amplitudes are complex and can cancel; measurement gives one outcome with probability |amplitude|².
  • Do not mix the two famous algorithms: Shor (1994) factors and solves discrete logs with exponential speedup; Grover (1996) searches with a quadratic speedup of about √N.
  • BB84 distributes a key. It does not encrypt a message by itself and cannot signal faster than light.
  • A qubit is not a bit that secretly holds both values. Written α|0⟩ + β|1⟩, its amplitudes are not readable, and one measurement gives 0 or 1.
  • An exponential number of amplitudes is not exponential speedup. The list is never written down; only measured probabilities and interference between paths matter.

1.2 Complex numbers and vector spaces

Quantum states are lists of complex numbers, so complex arithmetic and complex vector spaces decide what a qubit can do. A complex vector space is the real vector space you know with complex scalars. That change makes rotation free, doubles dimension over R, and makes independence subtler. Amplitude, phase and interference live here.

You need first-year engineering mathematics: real vectors, real matrices, basic trigonometry. Section 1.1 explains why physics uses complex amplitudes.

Complex numbers: two real numbers and one rule

A complex number is z = a + bi. a is Re(z), b is Im(z), both real. The symbol i obeys i² = −1. So z is a pair (a, b) with a multiplication rule.

Addition adds parts: (a + bi) + (c + di) = (a + c) + (b + d)i. Multiplication expands and replaces i² by −1.

(a + bi)(c + di) = (ac − bd) + (ad + bc)i

a, b, c, d are real; ac − bd is the real part of the product and ad + bc is the imaginary part.

The conjugate flips the imaginary sign: z̄ = a − bi. The modulus is length |z| = √(a² + b²). Then z z̄ = a² + b² = |z|², real and ≥ 0, zero only for z = 0. Division: z / w = z w̄ / |w|².

For z = 3 + 4i, |z| = √(9 + 16) = 5. It is a plane point, 3 right and 4 up. Quantum amplitudes are such points, so 1 + (−1) cancels but 1 + i does not.

Polar form and why i is a quarter turn

Polar form names a point by distance and angle. Let r = |z| ≥ 0 and θ = arg z be the anticlockwise angle from the positive real axis in radians. Then a = r cos θ, b = r sin θ, and Euler gives z = r(cos θ + i sin θ) = r eiθ.

z = r eiθ = r(cos θ + i sin θ)

r = |z| = √(a² + b²) is the modulus and θ = arg z is the argument in radians; θ + 2πk gives the same z for every whole number k.

Multiplication multiplies lengths and adds angles: z₁z₂ = r₁r₂ ei(θ₁+θ₂). Since i = eiπ/2, multiplying by i keeps length and adds π/2 rad. Multiplication by i is a quarter turn.

Phase gates rotate amplitude arrows. Section 3 uses the same quarter turn to decide independence.

Vector spaces over C, span, independence, dimension

A vector space over C is a set V with addition u + v and complex scalar multiplication cv, obeying the usual axioms (most textbooks list ten): closure under addition and under scaling; u + v = v + u; (u + v) + w = u + (v + w); a zero vector; an inverse −v; 1v = v; c(u + v) = cu + cv; (c + d)v = cv + dv; (cd)v = c(dv).

The standard example is Cⁿ: ordered n-tuples (z₁, …, zₙ), added and scaled coordinate by coordinate. C² is one qubit's state space (Unit 2, Qubits, Postulates and Entanglement).

A linear combination is c₁v₁ + … + cₖvₖ with cⱼ in C. Its span is all such combinations. v₁, …, vₖ are independent if c₁v₁ + … + cₖvₖ = 0 forces all cⱼ = 0. A basis is an independent spanning set. Dimension is its size; every basis has the same size. Thus dim Cⁿ = n over C.

In C² take v = (1, i), w = (i, −1). Try w = cv. The first coordinate gives c = i. The second gives ci = i² = −1, which matches. So w = i v and {v, w} is dependent over C. Over R, a v + b w = 0 gives a + bi = 0 and ai − b = 0, so a = b = 0. Same vectors, independent over R. Check the allowed field.

Worked example

Question. In C² let v = (1, i) and w = (i, −1). (a) Find a complex scalar c with w = cv. (b) Is {v, w} independent over C? (c) Is it independent over R? (d) Give |c| and the rotation angle.

  1. Suppose w = cv, so (i, −1) = c(1, i) = (c, ci).
  2. First coordinate: c = i.
  3. Second coordinate: ci = i · i = i² = −1, which matches w.
  4. So c = i ≠ 0 and w = i v. The set {v, w} is dependent over C.
  5. Over R, set a v + b w = 0. This gives (a + bi, ai − b) = (0, 0), so a = b = 0. The set is independent over R.
  6. c = i has |c| = 1 and angle θ = π/2 rad = 90°, so c rotates by a quarter turn.

Answer. c = i gives w = i v, so {v, w} is dependent over C but independent over R; |c| = 1 and the rotation is π/2 rad (90°).

Exam traps

  • Independence depends on allowed scalars: (1, i) and (i, −1) are independent over R, dependent over C.
  • Conjugate is not negative: a + bi has conjugate a − bi, while its negative is −a − bi.
  • Modulus is not square: |3 + 4i| = 5, not 25; |z|² = z z̄.
  • Euler form has period 2π: θ and θ + 2π give the same z; eiθ is never 0.
  • Dimension depends on field: Cⁿ is n over C but 2n over R.

1.3 Hilbert spaces, bases and Dirac notation

An inner product takes two complex vectors and returns a complex number. It gives length, angle and orthogonality. A complex vector space with an inner product, and with no missing limit points, is a Hilbert space. Dirac notation writes a vector as a ket |ψ⟩ and its partner as a bra ⟨φ|. The bracket ⟨φ|ψ⟩ is the inner product. Quantum states, gates and measurements use this language, so it is the working notation of quantum computing.

You need: complex numbers and vector spaces; this chapter adds an inner product to that stage.

Inner product, norm and Hilbert space

Start with a vector space over the complex numbers C, as in 1.2. An inner product is a rule that takes an ordered pair (|φ⟩, |ψ⟩) and returns a complex number, written ⟨φ|ψ⟩. It must obey three rules.

  • Conjugate symmetry: ⟨ψ|φ⟩ = ⟨φ|ψ⟩*. The star means complex conjugate.
  • Linearity in the second slot: ⟨φ|aψ+bχ⟩ = a⟨φ|ψ⟩+b⟨φ|χ⟩ for complex numbers a and b.
  • Positive definite: ⟨ψ|ψ⟩ is real and ≥0, and equals 0 only for |ψ⟩=0.

Some books put linearity in the first slot; keep one convention and check the star.

||ψ|| = √⟨ψ|ψ⟩

||ψ|| is the norm (length) of |ψ⟩; ⟨ψ|ψ⟩ is real and non-negative.

Two vectors are orthogonal when ⟨φ|ψ⟩=0. A vector is normalized when ||ψ||=1. A Hilbert space is a complete inner-product space: every Cauchy sequence of vectors converges to a vector in the space. In finite dimensions, Cⁿ is automatically complete, so every finite-dimensional complex inner-product space is a Hilbert space. That is enough for qubits and gates here; infinite dimensions need extra analysis.

Kets, bras and brackets

Write a ket |ψ⟩ as a column vector of complex numbers. In C², |ψ⟩ = α|0⟩+β|1⟩, where α and β are complex coefficients. The computational basis is |0⟩=(1,0)ᵀ and |1⟩=(0,1)ᵀ. The symbol ᵀ means transpose.

The bra ⟨ψ| is the conjugate transpose: turn the column into a row and conjugate every entry. For |ψ⟩ above, ⟨ψ| = α*⟨0|+β*⟨1|. The bra is the dual partner of the ket.

For |φ⟩=γ|0⟩+δ|1⟩, the bracket is ⟨φ|ψ⟩ = γ*α+δ*β. This is one complex number, not a vector. Order matters: ⟨φ|ψ⟩ and ⟨ψ|φ⟩ are conjugates, not generally equal.

Measurement probabilities use |α|² and |β|²; see Unit 2, Quantum measurement.

Orthonormal bases and completeness

A basis {|i⟩} is orthonormal when ⟨i|j⟩=δᵢⱼ: 1 if i=j, 0 if i≠j. Any vector expands as |ψ⟩ = Σᵢ cᵢ|i⟩. Taking the inner product with ⟨j| gives cⱼ=⟨j|ψ⟩, because only the j term survives.

Σᵢ |i⟩⟨i| = I

I is the identity operator; the sum runs over every vector in an orthonormal basis; |i⟩⟨i| is an outer product.

Acting on |ψ⟩, the term |i⟩⟨i|ψ⟩ keeps the coefficient along |i⟩. The sum rebuilds |ψ⟩. This is why an orthonormal basis is a complete set of projectors. For a qubit, |0⟩⟨0|+|1⟩⟨1| gives I; inserting this sum anywhere does not change the state.

In C² the computational basis is one orthonormal basis. Other bases, such as the Hadamard basis in Unit 3, are equally valid. Coefficients change with the basis; the vector does not. Completeness is used whenever we insert a basis between operators.

Worked example

Question. Let |ψ⟩ = (1/√2)|0⟩ + (i/√2)|1⟩ in C². (a) Find ⟨ψ|ψ⟩ and ||ψ||. (b) Find ⟨0|ψ⟩ and ⟨1|ψ⟩. (c) Check the coefficients using the orthonormal-basis rule.

  1. The coefficients are α=1/√2 and β=i/√2.
  2. The bra is ⟨ψ| = (1/√2)⟨0| − (i/√2)⟨1|, because i* = −i.
  3. ⟨ψ|ψ⟩ = |α|²+|β|² = |1/√2|²+|i/√2|² = 1/2+1/2 = 1.
  4. ||ψ|| = √1 = 1.
  5. ⟨0|ψ⟩ = α = 1/√2 ≈ 0.7071. ⟨1|ψ⟩ = β = i/√2 ≈ 0.7071 i.
  6. For an orthonormal basis, cᵢ=⟨i|ψ⟩. The values c₀=1/√2 and c₁=i/√2 match the given coefficients.

Answer. The state is normalized: ⟨ψ|ψ⟩=1 and ||ψ||=1. The inner products are ⟨0|ψ⟩=1/√2≈0.7071 and ⟨1|ψ⟩=i/√2≈0.7071 i.

Exam traps

  • The bra is the conjugate transpose, not just the transpose. For |ψ⟩=α|0⟩+β|1⟩, ⟨ψ|=α*⟨0|+β*⟨1|.
  • Reversing the order conjugates the bracket: ⟨ψ|φ⟩=⟨φ|ψ⟩*. Do not swap the two vectors without the star.
  • The inner product is linear in the second slot and conjugate-linear in the first: ⟨aφ|bψ⟩=a*b⟨φ|ψ⟩.
  • The norm is √⟨ψ|ψ⟩, not ⟨ψ|ψ⟩. Measurement uses squared modulus |α|², which is not the same as α.
  • The completeness relation Σ|i⟩⟨i|=I holds for an orthonormal basis, not for an arbitrary list of vectors.

1.4 Matrices, linear operators, eigenvalues and eigenvectors

A linear operator is a rule that stretches, rotates or reflects vectors while preserving sums and scalar multiples. Choose a basis and the operator becomes a matrix, so matrix algebra is operator algebra in coordinates. Eigenvalues and eigenvectors are the directions the operator does not turn, only scales. This is used wherever a quantum gate, a measurement or a time evolution must be written as a matrix.

You need: 1.2 for vector spaces over C and 1.3 for bases and Dirac notation.

Linear operators and their matrices

A linear operator A on a vector space acts on vectors and returns vectors. It is linear when A(αu + βv) = αAu + βAv for all vectors u, v and all scalars α, β. Here α and β are numbers, real or complex. Linearity means the operator respects addition and scaling.

A(αu + βv) = αAu + βAv

A is a linear operator; u and v are vectors; α and β are scalars.

Fix a basis e1, e2. The matrix of A in this basis has columns equal to the coordinates of A e1 and A e2. For the standard basis e1=(1,0), e2=(0,1), write A = [[a,b],[c,d]]. Then A e1 = (a,c) and A e2 = (b,d). The same operator has different matrices in different bases, but its action on vectors is unchanged.

Use 2×2 matrices in this chapter. A Pauli matrix such as σz = [[1,0],[0,−1]] is a linear operator on C². Its quantum meaning as an observable or a gate belongs to Unit 2 and Unit 3, not here. Some syllabi call this topic matrices and operators.

Matrix algebra and determinant

Matrices of the same size add entry by entry, and a scalar multiplies every entry. Composition of operators becomes matrix multiplication. If C = AB, then (AB)ij = Σk Aik Bkj. Here i is the row, j is the column, and k runs over the shared dimension. Matrix product is not commutative in general: AB ≠ BA.

The identity matrix I = [[1,0],[0,1]] satisfies AI = IA = A. An inverse A−1 exists only when det(A) ≠ 0, and it satisfies AA−1 = A−1A = I. For A = [[a,b],[c,d]], the determinant is det(A) = ad − bc. The inverse is A−1 = (1/det(A)) [[d,−b],[−c,a]]. If det(A) = 0, A is singular and has no inverse.

det(A) = ad − bc

A = [[a,b],[c,d]]; a,b,c,d are entries; det(A) is the determinant.

These rules are the same for complex matrices. They let you solve A x = b by x = A−1b when the inverse exists.

Eigenvalues, eigenvectors and diagonalization

An eigenvector v of A is a nonzero vector that A only scales: A v = λ v. The scalar λ is the eigenvalue. Rewrite as (A − λI)v = 0. A nonzero solution v exists only when det(A − λI) = 0. This is the characteristic equation. For 2×2 A, it is a quadratic in λ.

A v = λ v

A is the operator; v is a nonzero eigenvector; λ is the eigenvalue.

Solve det(A − λI) = 0 for λ. Put each λ back into (A − λI)v = 0 and solve for v. Scale v freely; (2,2) is the same eigenvector as (1,1).

If A has two independent eigenvectors v1, v2 with eigenvalues λ1, λ2, then A = P D P−1. Here P has columns v1, v2, and D = diag(λ1, λ2). This is diagonalization. It fails when there are not enough independent eigenvectors, for example a repeated eigenvalue with only one eigenvector.

Eigenvectors give the directions an operator does not turn, and eigenvalues give the scale factor along each one. That is why they matter for quantum measurement and time evolution; see 1.5.

Worked example

Question. Let A = [[2,1],[1,2]]. Find both eigenvalues and one eigenvector for each eigenvalue. Verify A v = λ v for each pair.

  1. Write A − λI = [[2−λ,1],[1,2−λ]].
  2. Compute det(A − λI) = (2−λ)(2−λ) − 1·1 = (2−λ)² − 1.
  3. Expand: (4 − 4λ + λ²) − 1 = λ² − 4λ + 3.
  4. Factor: (λ − 3)(λ − 1) = 0, so λ1 = 3 and λ2 = 1.
  5. For λ = 3: A − 3I = [[−1,1],[1,−1]]. Solve (−1)x + 1y = 0, so y = x. Take v1 = (1,1). Check A v1 = (2·1 + 1·1, 1·1 + 2·1) = (3,3) = 3v1.
  6. For λ = 1: A − 1I = [[1,1],[1,1]]. Solve x + y = 0, so y = −x. Take v2 = (1,−1). Check A v2 = (2·1 + 1·(−1), 1·1 + 2·(−1)) = (1,−1) = 1v2.

Answer. The eigenvalues are 3 and 1; eigenvectors are (1,1) for 3 and (1,−1) for 1.

Exam traps

  • An eigenvector cannot be the zero vector. v=0 makes Av=λv true for every λ, so it carries no information.
  • Do not divide by v. Write (A−λI)v=0 and set det(A−λI)=0; v is a vector, not a number.
  • det(A−λI)=0 gives eigenvalues. Substituting λ back gives eigenvectors; keep the two steps separate.
  • A repeated eigenvalue may have only one independent eigenvector; then the matrix cannot be diagonalized. Do not assume two eigenvectors.
  • det(A−λI) is not det(A)−λ. Expand the determinant after subtracting λ from the diagonal entries.

1.5 Hermitian and unitary matrices

Every quantum experiment ends with a number you can read off, and every quantum gate must be undoable. Two matrix tests capture those demands. A matrix equal to its own conjugate transpose is Hermitian. It has real eigenvalues, so it can stand for something measurable. A matrix whose conjugate transpose is its inverse is unitary. It keeps lengths and angles, so it can stand for a gate or a time step. Pauli X, Y, Z and Hadamard pass both tests, which is why they fill the first page of every qubit circuit.

You need matrices, eigenvalues and Dirac notation from 1.4 and 1.3.

The dagger and Hermitian matrices

The conjugate transpose of a matrix flips it across the main diagonal and complex-conjugates every entry. Write it A† and read it "A dagger".

A† = (A*)ᵀ

A* is the matrix with each entry replaced by its complex conjugate; ᵀ means transpose, so entry (i, j) of A† is the conjugate of entry (j, i) of A.

A square matrix is Hermitian when A = A†. Real symmetric matrices are the easy case: conjugation changes nothing, so plain symmetry is enough. The 2×2 matrix A = [[1, i], [−i, 2]] is Hermitian. Conjugate the entries to get [[1, −i], [i, 2]], then transpose and you are back at [[1, i], [−i, 2]].

  • Every diagonal entry of a Hermitian matrix is real, because a = conj(a) forces its imaginary part to zero.
  • Off-diagonal entries come in conjugate pairs: entry (j, i) is the conjugate of entry (i, j).
  • For every vector |ψ⟩ the number ⟨ψ|A|ψ⟩ is real when A is Hermitian.

That last point is why physicists care. A measurement gives a real number, so the operator for a measurable quantity, called an observable, must produce real values on every state. Energy, position and spin are all Hermitian operators. See Unit 2, Quantum measurement, for how those values become probabilities.

Real eigenvalues and the spectral decomposition

The eigenvalues of a Hermitian matrix are always real. Here is the reason in two lines. Start from A|λ⟩ = λ|λ⟩. Multiply on the left by ⟨λ| to get ⟨λ|A|λ⟩ = λ⟨λ|λ⟩. The left side is real, the inner product ⟨λ|λ⟩ is real and positive, so λ must be real too.

Eigenvectors belonging to different eigenvalues are orthogonal, and after scaling they form an orthonormal basis of the whole space. That basis gives the spectral decomposition.

A = Σᵢ λᵢ|λᵢ⟩⟨λᵢ|

λᵢ are the real eigenvalues, |λᵢ⟩ are the matching orthonormal eigenvectors, and |λᵢ⟩⟨λᵢ| is the projector onto the direction of |λᵢ⟩.

Take the Pauli Z matrix, Z = [[1, 0], [0, −1]]. Its eigenvalues are +1 and −1. The eigenvectors are |0⟩ = (1, 0) and |1⟩ = (0, 1). The decomposition reads Z = (+1)|0⟩⟨0| + (−1)|1⟩⟨1|, which multiplies out to the same matrix.

The spectral theorem runs both ways: a matrix is Hermitian exactly when it has real eigenvalues and a full set of orthonormal eigenvectors. In matrix form A = UΛU†, where Λ is diagonal and real and U is unitary.

Unitary matrices and reversible gates

A square matrix U is unitary when U†U = UU† = I, where I is the identity. The conjugate transpose is the inverse.

U†U = I ⟺ U⁻¹ = U†

U† is the conjugate transpose, I is the identity matrix, and U⁻¹ is the inverse of U.

  • Inner products survive: ⟨Ux|Uy⟩ = ⟨x|y⟩ for any vectors x and y.
  • Lengths survive, since a norm is the square root of an inner product with itself.
  • Every eigenvalue has modulus 1, so it sits on the unit circle as e^(iθ) with θ in radians.
  • A product of unitary matrices is unitary, and so is U†.

Keeping the inner product is exactly what a quantum gate must do. States have norm 1, and probabilities come from squared inner products, so a gate that changed lengths would break the sum of probabilities. Reversibility comes free: U† undoes U. That is why circuits are built from unitary gates only; see Unit 3, Single-qubit gates: Pauli, Hadamard and phase.

On a large space, a two-level unitary acts on just two basis states and leaves every other state alone. Any unitary on n qubits can be written as a product of two-level unitaries, which is how a compiler turns an abstract gate into hardware pulses. A one-qubit gate is the smallest case: a 2×2 unitary matrix.

  2. All entries are real, so the conjugate H* equals H.
  3. Transposing gives (H*)ᵀ = [[0.7071067812, 0.7071067812], [0.7071067812, −0.7071067812]], which is H again. So H† = H and H is Hermitian.
  4. Entry (1,1) of H²: (0.7071067812)(0.7071067812) + (0.7071067812)(0.7071067812) = 0.5 + 0.5 = 1.
  5. Entry (1,2): (0.7071067812)(0.7071067812) + (0.7071067812)(−0.7071067812) = 0.5 − 0.5 = 0.
  6. Entry (2,1): (0.7071067812)(0.7071067812) + (−0.7071067812)(0.7071067812) = 0.5 − 0.5 = 0.
  7. Entry (2,2): (0.7071067812)(0.7071067812) + (−0.7071067812)(−0.7071067812) = 0.5 + 0.5 = 1.
  8. So H² = I. Because H† = H, this also says H†H = H² = I, so H is unitary and H⁻¹ = H† = H.

Exam traps

  • Hermitian and unitary are separate tests. The real symmetric matrix [[2, 0], [0, 3]] is Hermitian but not unitary, and the phase gate S = [[1, 0], [0, i]] is unitary but not Hermitian. Check both properties, never one.
  • Forgetting the complex conjugate. With real entries the dagger is just the transpose, so students transpose and stop. Pauli Y gives the counterexample: Yᵀ = [[0, i], [−i, 0]] = −Y, but Y† = Y.
  • Order and reversal: (AB)† = B†A†, not A†B†. For a unitary both U†U and UU† equal I, but for a general matrix they differ.
  • Eigenvalues of a unitary matrix are not all 1. They have modulus 1, so they look like e^(iθ); the phase gate S has eigenvalues 1 and i.
  • The identity matrix is both Hermitian and unitary, so it never separates the two ideas. Pick a non-trivial matrix when you are asked for an example that is one but not the other.

1.6 Tensor products of vector spaces

A quantum computer with many qubits is described by one state vector, and that vector is built from smaller spaces. The tensor product V ⊗ W does the building: it produces a space whose dimension is the product of the two dimensions, with basis vectors written |ij⟩. A gate that acts on one qubit at a time is a matrix formed by the Kronecker product; a gate that acts on several qubits jointly, such as CNOT, is a general 4×4 unitary that need not be any single Kronecker product. Every circuit is a walk through this larger space. This chapter defines the construction, gives the product basis of two qubits, and shows how operators combine.

You need: 1.2 for complex vector spaces, 1.3 for bases and Dirac notation, and 1.4 for operators written as matrices.

Building one space from two

Two quantum systems described together need one state vector, not two. That vector lives in a space built from the two separate spaces by the tensor product, written V ⊗ W.

Let V be a complex vector space of dimension m and W one of dimension n, where the dimension is the number of vectors in a basis. The tensor product V ⊗ W is a new complex vector space. It is spanned by symbols |v⟩ ⊗ |w⟩, one for every pair of vectors, and the symbol is linear in each slot separately. That rule is called bilinearity.

(α|v⟩) ⊗ |w⟩ = α(|v⟩ ⊗ |w⟩) = |v⟩ ⊗ (α|w⟩)

α is a complex number, |v⟩ is a vector in V, |w⟩ is a vector in W. A scalar may sit on either side of the ⊗ or outside the bracket.

(|v<sub>1</sub>⟩ + |v<sub>2</sub>⟩) ⊗ |w⟩ = |v<sub>1</sub>⟩ ⊗ |w⟩ + |v<sub>2</sub>⟩ ⊗ |w⟩

the same rule holds in the second slot; with the scalar rule, this is bilinearity.

Bilinearity is the whole point. It says amplitudes multiply rather than add: (2|v⟩) ⊗ |w⟩ is 2(|v⟩ ⊗ |w⟩). Quantum mechanics needs exactly this, because a joint amplitude is the product of the two single-system amplitudes, and a sum inside one slot must spread across the joint state.

Dimension follows from the bases. If |0⟩,…,|m−1⟩ is a basis of V and |0⟩,…,|n−1⟩ is a basis of W, the mn vectors |i⟩ ⊗ |j⟩ form a basis of V ⊗ W.

dim(V ⊗ W) = dim V × dim W = m·n

dim V is the number of basis vectors of V, dim W is the number for W, so the product space has dimension mn (a single number).

So two qubits live in C² ⊗ C², of dimension 2 × 2 = 4, and three qubits in a space of dimension 8. Each extra qubit doubles the number of amplitudes. That doubling is the source of both the power and the cost of quantum computing.

The product basis and the |ij⟩ shorthand

We shorten |i⟩ ⊗ |j⟩ to |ij⟩. In C² ⊗ C² the four basis vectors are |00⟩, |01⟩, |10⟩, |11⟩. The left symbol is the first qubit, the right symbol the second.

A general vector is a complex combination of all mn product basis vectors.

|Ψ⟩ = Σ<sub>i=0</sub><sup>m−1</sup> Σ<sub>j=0</sub><sup>n−1</sup> c<sub>ij</sub>|ij⟩

cij is the complex amplitude of the basis vector |ij⟩, and the double sum runs over all mn pairs.

For two qubits this reads |Ψ⟩ = c00|00⟩ + c01|01⟩ + c10|10⟩ + c11|11⟩: four complex amplitudes in place of the two that one qubit needs.

⟨ij|kl⟩ = ⟨i|k⟩⟨j|l⟩ = δ<sub>ik</sub>δ<sub>jl</sub>

δ is 1 when the two indices are equal and 0 otherwise, so the product basis is orthonormal whenever the factor bases are. A physical state then needs Σ|cij|² = 1.

Most vectors in V ⊗ W are not of the form |v⟩ ⊗ |w⟩. The joint state (|00⟩ + |11⟩)/√2 is the standard example: no single choice of |v⟩ and |w⟩ reproduces it. Such states are called entangled; Unit 2, Composite systems, reduced and mixed states, takes them up.

Operators and the Kronecker product

Let A act on V and B act on W. Their joint operator A ⊗ B acts on product vectors by (A ⊗ B)(|i⟩ ⊗ |j⟩) = (A|i⟩) ⊗ (B|j⟩), and on sums by linearity.

⟨ij|A ⊗ B|kl⟩ = AikBjl

Aik is the entry in row i, column k of A; Bjl is the entry in row j, column l of B. For 2×2 factors this gives a 4×4 matrix.

In matrix language this is the Kronecker product: take A and replace each entry aik by the whole block aikB. Block row i is the first qubit label, block column k is its column index, and inside each block the second qubit is indexed as usual.

A gate on the first qubit alone is A ⊗ I2, where I2 is the 2×2 identity; a gate on the second alone is I2 ⊗ A. These are different 4×4 matrices whenever A is not the identity. For instance X ⊗ I2 sends |00⟩ to |10⟩ and |01⟩ to |11⟩, flipping only the first label. Such matrices are unitary, as 1.5 requires of any gate.

An operator acting on both qubits jointly need not split as A ⊗ B at all; CNOT is the standard case, and multi-qubit gates appear in Unit 3, Quantum Gates and Circuits. What stays true is that operators on different qubits commute: (A ⊗ I2)(I2 ⊗ B) = A ⊗ B = (I2 ⊗ B)(A ⊗ I2).

Exam traps

  • Dimension multiplies, not adds. Three qubits give 2 × 2 × 2 = 8 amplitudes, not 2 + 2 + 2 = 6.
  • Order matters. |0⟩ ⊗ |1⟩ = |01⟩ is a different basis state from |10⟩ = |1⟩ ⊗ |0⟩. The two are not interchangeable.
  • A ⊗ B is not the ordinary matrix product AB. With 2×2 factors, A ⊗ B is 4×4, while AB stays 2×2 and needs both matrices to act on the same space.
  • Only a scalar slides across the ⊗: α(|v⟩ ⊗ |w⟩) = (α|v⟩) ⊗ |w⟩ = |v⟩ ⊗ (α|w⟩). A sum in one slot does not slide; it splits into two product terms.
  • The examiner's favourite: not every two-qubit operator equals A ⊗ B. CNOT is a 4×4 unitary that cannot be written as one Kronecker product.

(A ⊗ I₂)(I₂ ⊗ B) = (AI₂) ⊗ (I₂B) = A ⊗ B, and (I₂ ⊗ B)(A ⊗ I₂) = (I₂A) ⊗ (BI₂) = A ⊗ B. Both products equal A ⊗ B, so the order is irrelevant: the two operators act on different qubits.

Understand What is ⟨01|10⟩ in C² ⊗ C²? 2 marks

0. ⟨01|10⟩ = ⟨0|1⟩⟨1|0⟩ = 0 × 0 = 0, because the product basis is orthonormal.

Beyond the syllabus

Not for the exam. The Kronecker product is standard in numerical linear algebra and signal processing, where it describes separable transforms on images and grids. In machine learning and condensed-matter physics, tensor networks such as matrix product states compress the exponentially large joint vectors of many-body systems (2ⁿ amplitudes for n qubits) so they fit in memory. Quantum chemists use tensor products to build many-electron spaces from one-electron orbitals. Two useful search terms are Kronecker product and matrix product state; the physics that the product space allows is the subject of Unit 2.

1.7 Operator functions

Operators are matrices, and a calculation often needs not just A but A squared, a polynomial in A, a square root of A, or the exponential e^A. These are defined through the eigenvalues: keep the eigenvectors and push each eigenvalue through the ordinary function. For a Hermitian A written as A = Σ λ|λ⟩⟨λ|, the rule is f(A) = Σ f(λ)|λ⟩⟨λ|. One consequence runs through all of quantum mechanics: the time-evolution operator is the matrix exponential U(t) = e^(−iHt/ħ), and it is unitary.

You need: 1.4 for eigenvalues and eigenvectors, and 1.5 for Hermitian and unitary matrices.

Powers, polynomials and power series

A square matrix A can be multiplied by itself: A² = AA, A³ = A²A, and A⁰ = I, the identity matrix. A polynomial in A means p(A) = a₀I + a₁A + a₂A² + ⋯ + a_d Ad for p(x) = a₀ + a₁x + ⋯ + a_d xd. The constant term a₀ multiplies I; it never sits alone as the number a₀.

Infinite series extend the same way. For f(x) = Σk ck xk, set f(A) = Σk ck Ak. So eA = I + A + A²/2! + A³/3! + ⋯, and sin A and cos A are defined by their series. The matrix series converges when the number series converges at every eigenvalue of A, so the eigenvalues decide whether f(A) exists.

Quantum computing uses these objects constantly: time evolution is an exponential of the energy operator, and rotation gates are exponentials of Pauli matrices (Unit 3).

  1. Find the eigenvalues λk and an orthonormal eigenbasis |λk⟩ of A.
  2. Check that f(λk) is defined and finite at every eigenvalue.
  3. Write A in spectral form A = Σk λk|λk⟩⟨λk|.
  4. Replace each λk by f(λk), giving f(A) = Σk f(λk)|λk⟩⟨λk|.
  5. Multiply out in the original basis if the answer must be a matrix.

The spectral definition

A normal operator satisfies AA† = A†A; every Hermitian or unitary operator is normal. Such an operator has an orthonormal eigenbasis, so A = Σk λk|λk⟩⟨λk|, where each Pk = |λk⟩⟨λk| is a projector: Pk² = Pk, PkPj = 0 for k ≠ j, and Σk Pk = I.

f(A) = Σ<sub>k</sub> f(λ<sub>k</sub>) |λ<sub>k</sub>⟩⟨λ<sub>k</sub>|

λk are the eigenvalues of A; |λk⟩ are the matching unit eigenvectors; f(λk) is the ordinary function evaluated at the number λk; the sum runs over all distinct eigenvalues.

Read the formula as a recipe. f never touches the eigenvectors; it only rescales each eigenvalue. So f(A) has the same eigenvectors as A, and its eigenvalues are f(λk).

For a diagonal matrix the rule collapses to entry-by-entry work: if A = diag(λ₁, …, λn), then f(A) = diag(f(λ₁), …, f(λn)). This shortcut is valid only after you are in the eigenbasis.

  • tr f(A) = Σk f(λk) and det f(A) = Πk f(λk).
  • If A is Hermitian and f is real on the real line, then f(A) is Hermitian.
  • If |f(λk)| = 1 for every eigenvalue, then f(A) is unitary.
  • f(A) commutes with A, because both are diagonal in the same eigenbasis.

The matrix exponential and time evolution

The exponential is the most used operator function. Its series is eA = Σk Ak/k! = I + A + A²/2! + A³/3! + ⋯, with k! = 1·2·3⋯k. For a diagonal A you apply exp to each diagonal entry; for a general Hermitian A you use the spectral form.

U(t) = e−iHt/ħ

H is the Hamiltonian, a Hermitian operator with units of energy (joules); t is time in seconds; ħ = h/2π = 1.054571817×10⁻³⁴ J·s is the reduced Planck constant; i is the imaginary unit; U(t) is the dimensionless time-evolution operator.

Why is U(t) unitary? H is Hermitian, so its eigenvalues λ are real numbers. The eigenvalues of −iHt/ħ are then −iλt/ħ, which are purely imaginary, and each number e−iλt/ħ has modulus 1. By the rule above, U(t) has eigenvalues of modulus 1, so it is unitary. A unitary U keeps ⟨ψ|ψ⟩ unchanged, which is conservation of probability.

Two cautions. First, eA+B = eAeB only when AB = BA. Second, the sign carries meaning: e−iHt/ħ moves a state forward in time, and its adjoint e+iHt/ħ moves it backward.

Worked example

Question. A two-dimensional operator is A = diag(0, π). (a) Write A in spectral form with its projectors. (b) Using operator functions, compute e^(iA). (c) Show that e^(iA) is unitary. (d) State the eigenvalues of e^(iA) and their moduli.

  1. A is diagonal, so its eigenvalues are the diagonal entries: λ₁ = 0 with eigenvector |λ₁⟩ = (1, 0), and λ₂ = π with eigenvector |λ₂⟩ = (0, 1).
  2. The projectors are P₁ = |λ₁⟩⟨λ₁| = diag(1, 0) and P₂ = |λ₂⟩⟨λ₂| = diag(0, 1). Spectral form: A = 0·P₁ + π·P₂.
  3. Here f(x) = e^(ix). So f(λ₁) = e^(i·0) = cos 0 + i sin 0 = 1, and f(λ₂) = e^(iπ) = cos π + i sin π = −1 + 0i = −1.
  4. Apply f to each eigenvalue: e^(iA) = 1·P₁ + (−1)·P₂ = diag(1, 0) + diag(0, −1) = diag(1, −1). On a diagonal matrix the same answer comes entry by entry: diag(e^(i0), e^(iπ)) = diag(1, −1).
  5. Unitarity: (e^(iA))† = diag(1, −1) because both entries are real, so (e^(iA))†(e^(iA)) = diag(1·1, (−1)·(−1)) = diag(1, 1) = I.
  6. The eigenvalues of e^(iA) are 1 and −1, and |1| = 1, |−1| = 1. Both moduli equal 1, which is the eigenvalue test for unitarity.

Answer. e^(iA) = diag(1, −1), which is unitary; its eigenvalues are 1 and −1, both of modulus 1.

Exam traps

  • Applying f entry by entry to a non-diagonal matrix. For X = [[0, 1], [1, 0]], entry-by-entry would give [[1, e], [e, 1]], which is wrong; the correct value is cosh(1)I + sinh(1)X.
  • Forgetting that the constant term of a polynomial multiplies I: p(A) = a₀I + a₁A + ⋯, never a₀ + a₁A + ⋯.
  • Writing time evolution as e^(−Ht/ħ) or e^(+iHt/ħ). The forward evolution is e^(−iHt/ħ); the plus sign gives the adjoint, which runs time backward.
  • Assuming e^(A+B) = e^A e^B always. It needs AB = BA, and most quantum operators do not commute.
  • Applying √ or log without checking the spectrum: √A needs every eigenvalue ≥ 0 and log A needs every eigenvalue > 0, otherwise f(λ) is not a finite number.

Remember State the definition of f(A) for a Hermitian operator A and name each symbol. 2 marks

With A = Σ λk|λk⟩⟨λk| over orthonormal eigenvectors, f(A) = Σ f(λk)|λk⟩⟨λk|. λk is an eigenvalue, |λk⟩ its unit eigenvector, and f is applied to the number λk.

Understand Why can you not compute f(A) by applying f to each matrix entry when A is not diagonal? 3 marks

Matrix entries depend on the chosen basis, and the off-diagonal entries carry the mixing action of A. Applying f entry by entry ignores that mixing and disagrees with the power series. The spectral rule is basis-independent and agrees with the series.

Apply For A = diag(1, 4), compute A², √A and eA. 4 marks

A² = diag(1², 4²) = diag(1, 16). √A = diag(√1, √4) = diag(1, 2). eA = diag(e¹, e⁴) ≈ diag(2.718, 54.598).

Apply For A = diag(0, π/2), compute eiA and check unitarity. 4 marks

eiA = diag(ei0, eiπ/2) = diag(1, i). Its adjoint is diag(1, −i), so the product is diag(1, (−i)(i)) = diag(1, 1) = I; the eigenvalues 1 and i both have modulus 1.

Analyze Show that U = e−iHt/ħ is unitary when H is Hermitian and t is real. 5 marks

Write H = Σ λ|λ⟩⟨λ| with real λ, since H is Hermitian. Then U = Σ e−iλt/ħ|λ⟩⟨λ|. The exponent −λt/ħ is real, so each eigenvalue has modulus 1. Hence U†U = Σ |e−iλt/ħ|²|λ⟩⟨λ| = Σ |λ⟩⟨λ| = I.

Analyze For X = [[0, 1], [1, 0]] and real θ, show that eiθX = cos θ I + i sin θ X. 5 marks

X has eigenvalues +1 and −1, so X = P₊ − P₋ with P₊ + P₋ = I. Apply f(x) = eiθx: eiθX = eiθP₊ + e−iθP₋ = cos θ (P₊ + P₋) + i sin θ (P₊ − P₋) = cos θ I + i sin θ X.

Takeaways

  1. Quantum computing is a different model of information, not a faster version of the same classical model.
  2. A qubit is a unit vector in a complex Hilbert space, and its amplitudes are complex numbers.
  3. Dirac notation writes vectors, dual vectors, and inner products without matrix indices.
  4. A linear operator is a matrix only after a basis is chosen.
  5. Hermitian operators have real eigenvalues and describe observables.
  6. Unitary operators preserve inner products and describe reversible gates and closed time evolution.
  7. The tensor product builds multi-part state spaces and allows entangled states that are not product states.
  8. Functions of an operator act on eigenvalues, and the matrix exponential turns a Hermitian Hamiltonian into a unitary evolution.
  9. The history of quantum computing shows both the promise of quantum algorithms and the difficulty of controlling quantum coherence.

Glossary

Amplitude
A complex coefficient in a superposition whose squared modulus gives a probability.
Basis
A linearly independent set of vectors that spans the space, so every vector has a unique coordinate list.
Bra
The dual vector ⟨ψ| that acts on kets to produce inner products.
Complete space
A metric space in which every Cauchy sequence converges to a point in the space.
Complex conjugate
For z = a + ib, the number z* = a − ib.
Conjugate transpose
The transpose of a matrix followed by complex conjugation, written A†.
Dimension
The number of vectors in any basis of a vector space.
Dual vector
A linear functional on a vector space; in Dirac notation it is a bra.
Eigenvalue
A scalar λ such that A|v⟩ = λ|v⟩ for some nonzero vector |v⟩.
Eigenvector
A nonzero vector |v⟩ whose direction is unchanged by A up to the scalar factor λ.
Entanglement
A property of a composite state that cannot be written as a tensor product of states of the parts.
Hermitian operator
An operator equal to its conjugate transpose, A† = A; it has real eigenvalues.
Hilbert space
A complete complex vector space with an inner product.
Inner product
A map ⟨u|v⟩ to ℂ that is conjugate-symmetric, linear in one argument, and positive definite.
Ket
A vector |ψ⟩ in a complex Hilbert space.
Linear operator
A map A on a vector space that satisfies A(αu + βv) = αAu + βAv.
Matrix exponential
The series e^A = Σ_{n=0}^{∞} Aⁿ/n!, defined for square matrices.
Norm
The length of a vector, ||ψ|| = √⟨ψ|ψ⟩.
Observable
A Hermitian operator whose eigenvalues are the possible outcomes of a measurement.
Orthonormal basis
A basis whose vectors satisfy ⟨i|j⟩ = δ_ij.
Pauli matrices
The three standard 2×2 Hermitian and unitary matrices X, Y, Z used to describe one qubit.
Qubit
A quantum two-level system whose pure state is a unit vector in ℂ².
Spectrum
The set of eigenvalues of an operator.
Superposition
A state written as a complex linear combination of basis states.
Tensor product
A construction that combines vector spaces V and W into V⊗W of dimension (dim V)(dim W).
Unitary operator
An operator satisfying U†U = I; it preserves inner products and norms.
