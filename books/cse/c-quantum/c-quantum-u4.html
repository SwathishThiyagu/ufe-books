4.1 Quantum parallelism and phase kickback

A quantum circuit with n Hadamards can present all 2ⁿ inputs to a function in one oracle call. Measurement still returns one input, not the whole table. Phase kickback supplies the rest: set the target to |−⟩ and each f(x) becomes a sign (−1)ᶠ⁽ˣ⁾ on the matching input state. The signs stay invisible until interference turns them into probabilities. Deutsch-Jozsa, Bernstein-Vazirani, Simon, Grover and phase estimation all rest on this pair of ideas.

You need: superposition and measurement (Unit 2, Qubits, Postulates and Entanglement), the Hadamard and CNOT gates and the circuit model (Unit 3, Quantum Gates and Circuits), and the reversible oracle used in 4.2.

Quantum parallelism: all inputs in one call

A classical program that wants f on every n-bit input must call f about 2ⁿ times. A quantum circuit prepares all inputs at once with n Hadamard gates and one oracle call.

H<sup>⊗n</sup>|0<sup>n</sup>⟩ = (1/√(2<sup>n</sup>)) Σ<sub>x</sub> |x⟩

n = number of input qubits; |0n⟩ = all-zero state on those qubits; H⊗n = one Hadamard on each qubit; the sum runs over all 2ⁿ bit strings x; each input has amplitude 1/√(2n).

With one ancilla in |0⟩, one call of Uf gives (1/√(2n)) Σx |x⟩|f(x)⟩. This is quantum parallelism: f is evaluated at every input in one pass. The amplitude on each |x⟩|f(x)⟩ is physically present, and the registers are entangled when f is not constant.

Measurement ruins it. Reading the first register returns one string x with probability 1/2ⁿ, and the second shows f(x). One call yields one table line. Testing all 2ⁿ inputs this way needs 2ⁿ runs, no better than classical. Useful algorithms do not measure here.

The oracle Uf and why it needs two registers

The oracle is a unitary gate that computes f reversibly. It reads an n-bit input x and a one-bit target y, and XORs the answer into the target.

Uf|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

x = n-bit input string; y = one ancilla bit, 0 or 1; f(x) ∈ {0,1}; ⊕ = XOR (addition mod 2). Since y ⊕ f(x) ⊕ f(x) = y, Uf is its own inverse, so the computation is reversible. Uf maps each basis state |x⟩|y⟩ to another basis state and never merges two, so it is a permutation of the basis; a permutation matrix is unitary, hence Uf is a valid quantum gate.

An n-bit input usually needs extra workspace qubits inside the oracle. They start in |0⟩, end in |0⟩ and are ignored outside.

xf(x) = x₁⊕x₂state after U_f, from |x⟩|0⟩
000|00⟩|0⟩
011|01⟩|1⟩
101|10⟩|1⟩
110|11⟩|0⟩

The table is parity on n = 2 inputs, used again in the worked example. f is added into the target, never written over it; that is what keeps the gate reversible.

Phase kickback: moving f(x) into a sign

Set the ancilla to |−⟩ = (|0⟩ − |1⟩)/√2 and run the same oracle. Because |−⟩ is a superposition, both XOR branches occur.

  1. Write the ancilla as (|0⟩ − |1⟩)/√2 and apply Uf to |x⟩|−⟩.
  2. XOR adds f(x) to each branch: (|x⟩|f(x)⟩ − |x⟩|1⊕f(x)⟩)/√2.
  3. If f(x)=0 the bracket is |0⟩−|1⟩=√2|−⟩. If f(x)=1 it is |1⟩−|0⟩=−√2|−⟩.
  4. Both cases give Uf|x⟩|−⟩ = (−1)ᶠ⁽ˣ⁾|x⟩|−⟩.
U<sub>f</sub>|x⟩|−⟩ = (−1)<sup>f(x)</sup> |x⟩|−⟩

(−1)f(x) = +1 when f(x)=0 and −1 when f(x)=1; the ancilla comes out unchanged. Its phase was kicked back onto the input register, hence phase kickback (some syllabi write phase kick-back).

With the input in uniform superposition the oracle applies every f value at once as signs: Uf(1/√(2n)) Σx|x⟩|−⟩ = (1/√(2n)) Σx(−1)f(x)|x⟩|−⟩. The ancilla can then be dropped; what matters is the signed superposition of inputs.

A −1 in front of the whole state is a global phase: |ψ⟩ and −|ψ⟩ are the same physical state and no measurement separates them. A sign that differs between basis states is a relative phase; it changes interference and is measurable. Kickback gives a relative phase whenever f takes both 0 and 1. If f is constant, all signs are equal, the factor is global and unobservable, so constant versus balanced needs interference. Measuring now still gives x with probability 1/2ⁿ, so nothing is visible. The signs pay off only after a further gate layer, usually a second Hadamard, turns them into unequal amplitudes.

Where the pair is used

Phase kickback drives the algorithms that follow. 4.2 uses it so interference reads out f(0)⊕f(1). 4.3 turns signs of a hidden dot product into a measurable string. Grover (4.7) uses the same trick with an f that marks one item. Phase estimation (4.5) is the general form: an eigenstate of a unitary collects its eigenvalue as a phase, and the QFT (4.4) reads it out.

Worked example

Question. Take n = 2 input qubits, the parity function f(x) = x₁⊕x₂ where x = x₁x₂, the ancilla in |−⟩, and the input register starting as |00⟩. Apply H to each input qubit, then one call of U_f. Write the state after each stage and give the sign in front of each of the four input basis states.

  1. Start: input |00⟩, ancilla |−⟩ = (|0⟩−|1⟩)/√2, so the joint state is |00⟩|−⟩.
  2. Hadamards: 1/√4 = 1/2, so H on both qubits gives (1/2)(|00⟩+|01⟩+|10⟩+|11⟩)|−⟩.
  3. Evaluate f: f(00)=0, f(01)=1, f(10)=1, f(11)=0.
  4. Kickback signs (−1)ᶠ: +1, −1, −1, +1 on |00⟩, |01⟩, |10⟩, |11⟩.
  5. Final joint state: (1/2)(|00⟩−|01⟩−|10⟩+|11⟩)|−⟩. The ancilla stays |−⟩ because it is an eigenstate of U_f with eigenvalue (−1)ᶠ⁽ˣ⁾.
  6. Check the norm: (1/2)²×4 = 1, so probabilities are still 1/4 each.

Answer. The state is (1/2)(|00⟩ − |01⟩ − |10⟩ + |11⟩)|−⟩, with signs +1, −1, −1, +1 on |00⟩, |01⟩, |10⟩, |11⟩ respectively.

Exam traps

  • Thinking one call lets you read f(0), f(1), … by measuring. Measurement collapses to one x; every useful algorithm interferes before measuring.
  • Using |0⟩ as ancilla and expecting a sign. With |0⟩ the result is |x⟩|f(x)⟩ — a bit in the second register, no relative phase. Kickback needs |−⟩.
  • Confusing global and relative phase. A single −1 on the whole state is unobservable; the useful sign differs between basis states.
  • Saying kickback changes the ancilla. |−⟩ is an eigenstate, so it comes out unchanged; only a phase attaches to |x⟩.
  • Overwriting instead of XOR: Uf|x⟩|y⟩ = |x⟩|f(x)⟩ is not reversible for general f. Examiners look for ⊕.

4.2 Deutsch and Deutsch-Jozsa algorithms

Deutsch and Deutsch-Jozsa answer a yes/no question about a hidden Boolean function with one oracle call. The function is promised to be either constant or balanced. Classically, a deterministic check may need many inputs. The quantum circuit uses Hadamards to create a uniform superposition, calls the oracle once, and uses a second Hadamard layer. Phase kickback turns the function values into relative signs. Interference then sends a constant function to the all-zero output and a balanced function away from it. This is the smallest working example of the sign-to-bit trick used in later quantum algorithms.

You need: phase kickback from 4.1 and the Hadamard and controlled gates from Unit 3.

Deutsch's problem and the one-qubit circuit

The Deutsch problem gives one black-box function f:{0,1}→{0,1}. The promise says f is either constant, so f(0)=f(1), or balanced, so f(0)≠f(1). The task is to decide which with one oracle query. The oracle is a unitary U_f that maps |x⟩|y⟩ to |x⟩|y⊕f(x)⟩; x and y are one-bit labels and ⊕ is XOR.

  1. Prepare |0⟩|1⟩: first qubit as input, second as ancilla.
  2. Apply H to both qubits. The input becomes (|0⟩+|1⟩)/√2 and the ancilla becomes (|0⟩−|1⟩)/√2.
  3. Apply U_f once. The ancilla state stays |−⟩=(|0⟩−|1⟩)/√2 and the input picks up the sign (−1)^f(x).
  4. Apply H to the first qubit only.
  5. Measure the first qubit: 0 means constant, 1 means balanced.

a₀ = (1/2)[(−1)^f(0) + (−1)^f(1)]

a₀ is the amplitude for measuring the first qubit as 0; f(x) is the promised Boolean function; (−1)^f(x) is +1 when f(x)=0 and −1 when f(x)=1.

Deutsch-Jozsa: n input qubits

The Deutsch-Jozsa problem extends the promise to f:{0,1}^n→{0,1}. Balanced now means f(x)=1 on exactly half of the 2^n inputs, and constant means f(x) is the same for all inputs. The circuit uses n input qubits and one ancilla.

  1. Start in |0^n⟩|1⟩.
  2. Apply H^⊗n to the input register and H to the ancilla; H^⊗n means H on each of the n input qubits.
  3. Apply U_f once, where U_f|x⟩|y⟩=|x⟩|y⊕f(x)⟩.
  4. Apply H^⊗n again to the input register.
  5. Measure the input register in the standard basis.

a_{0^n} = (1/2^n) Σ_{x∈{0,1}^n} (−1)^f(x)

a_{0^n} is the amplitude for measuring all n input qubits as 0; x runs over all 2^n bit strings; f(x) is the promised function; the probability of the all-zero outcome is |a_{0^n}|².

Why the promise and the second Hadamard matter

For a constant function, every term (−1)^f(x) has the same sign. The sum in the amplitude is ±2^n, so a_{0^n}=±1 and the all-zero probability is 1. For a balanced function, exactly 2^{n−1} terms are +1 and 2^{n−1} terms are −1. The sum is 0, so a_{0^n}=0 and the all-zero probability is 0.

The final H^⊗n is essential. Before it, the function values sit as relative signs between branches. A direct measurement would sample a uniformly random x and reveal almost nothing about constant versus balanced. The final Hadamards make the branches interfere. Constructive interference goes to the all-zero outcome only for a constant function; destructive interference removes it for a balanced function.

The promise is also essential. Without it, the same circuit still produces a probability distribution, but the all-zero outcome is not forced to be 1 or 0. A function that is neither constant nor balanced can give an intermediate amplitude, so one query cannot decide the property with certainty. Deutsch-Jozsa is a promise problem, not a general function classifier.

Worked example

Question. A two-qubit Deutsch-Jozsa test uses the promised function f(00)=0, f(01)=1, f(10)=1, f(11)=0. After the final Hadamards, what is the probability of measuring 00? Is f constant or balanced?

  1. List the four inputs and values: f(00)=0, f(01)=1, f(10)=1, f(11)=0. The target outcome is 00 on the two input qubits.
  2. The amplitude for outcome 00 is a₀₀ = (1/2²) Σ_x (−1)^f(x). Here 2²=4 inputs and x runs over 00,01,10,11.
  3. Compute the signs: (−1)^0=+1 for 00, (−1)^1=−1 for 01, (−1)^1=−1 for 10, (−1)^0=+1 for 11.
  4. Sum the signs: 1−1−1+1=0.
  5. Divide by 4: a₀₀=0/4=0. The probability is |a₀₀|²=0²=0.0.
  6. The all-zero outcome has probability 0.0, so it never occurs. Under the promise, f is balanced. It has two ones among four inputs.

Answer. The probability of measuring 00 is 0.0; f is balanced.

Exam traps

  • Leaving out the final Hadamard layer. The signs are not visible to a standard measurement until interference converts them into an output bit.
  • Mixing the one-qubit Deutsch circuit with the n-qubit Deutsch-Jozsa circuit. Deutsch uses one input qubit; Deutsch-Jozsa uses n input qubits and H^⊗n.
  • Ignoring the promise. Deutsch-Jozsa decides constant versus balanced only under the promise; it is not a general classifier of arbitrary Boolean functions.
  • Using f(x) instead of (−1)^f(x) in the amplitude sum. The oracle writes a sign, so the term is +1 for f(x)=0 and −1 for f(x)=1.
  • Preparing the ancilla in |0⟩. The standard circuit starts the ancilla in |1⟩ so that H makes |−⟩ and phase kickback works.

4.3 Bernstein-Vazirani and Simon's algorithms

Bernstein-Vazirani and Simon's algorithms are the two cleanest examples of a quantum circuit beating a classical machine on a promise problem. In Bernstein-Vazirani a hidden n-bit string sits inside a function, and one oracle query plus a Hadamard layer reads all n bits at once. Simon's algorithm finds a hidden period of a function in about n queries where a classical machine needs exponentially many. Both grow directly out of the Deutsch-Jozsa circuit, and Simon's equation-solving step is the seed of Shor's factoring algorithm.

You need: the Deutsch-Jozsa circuit and phase kickback from 4.2, and the Hadamard gate and oracle construction from Unit 3.

Bernstein-Vazirani: the hidden string in one query

An n-bit string s is hidden inside a function f: {0,1}ⁿ → {0,1}. The promise is f(x) = s·x mod 2 for every input x, and the task is to find s. The dot is the bitwise inner product modulo 2: multiply matching bits, then add the results mod 2.

f(x) = s·x = s₁x₁ ⊕ s₂x₂ ⊕ … ⊕ sₙxₙ (mod 2)

s = s₁s₂…sₙ is the hidden n-bit string; x = x₁x₂…xₙ is the input; ⊕ is XOR, that is, addition mod 2; the result is the single bit f(x).

Classically, n queries are needed. Ask x = 10…0 and the reply is s₁. Ask x = 01…0 and the reply is s₂. After n such queries the whole string is known, and since one answer carries only one bit, no classical method does better.

The quantum circuit is exactly the Deutsch-Jozsa circuit of 4.2. Only the promise changes.

  1. Start with n input qubits in |0⟩^⊗n and one ancilla qubit in |1⟩.
  2. Apply H to the ancilla, giving |−⟩ = (|0⟩ − |1⟩)/√2.
  3. Apply H^⊗n to the input register. The state becomes (1/√2ⁿ) Σₓ |x⟩|−⟩, summed over all 2ⁿ inputs.
  4. Apply the oracle U_f. By phase kickback (see 4.1) each |x⟩ picks up the sign (−1)^(s·x).
  5. Apply H^⊗n to the input register a second time.
  6. Measure the input register in the computational basis.

Why the last layer leaves exactly s: the amplitude on the output string y is (1/2ⁿ) Σₓ (−1)^(x·(s⊕y)), where ⊕ is bitwise XOR and the exponent is taken mod 2. When y = s every term is +1, so the amplitudes add to 1. For any other y, exactly half the terms are +1 and half are −1, so they cancel. The measurement therefore returns |s⟩ with probability 1, after a single query.

Simon's problem: a hidden period

Here f maps n bits to n bits, f: {0,1}ⁿ → {0,1}ⁿ. The promise is that some nonzero n-bit string s exists such that f(x) = f(y) exactly when y = x or y = x⊕s. In words, f takes the same value on the pair x and x⊕s and on no other input. The string s is called the period, and the task is to find it.

Classically this is hard. Random inputs must be queried until two of them collide in the same pair, which by the birthday bound takes about 2^(n/2) queries. The quantum circuit needs only about n.

  1. Prepare two n-qubit registers, both in |0ⁿ⟩.
  2. Apply H^⊗n to the first register: (1/√2ⁿ) Σₓ |x⟩|0ⁿ⟩.
  3. Apply U_f once: it maps |x⟩|0⟩ to |x⟩|f(x)⟩.
  4. Group the inputs in pairs {x, x⊕s}, which share one output. The state is (1/√2ⁿ) Σ_pairs (|x⟩ + |x⊕s⟩)|f(x)⟩.
  5. Apply H^⊗n to the first register again.
  6. Measure the first register and record the n-bit result y.

The pair |x⟩ + |x⊕s⟩ becomes Σ_y (−1)^(x·y) (1 + (−1)^(s·y)) |y⟩. The bracket is 2 when s·y = 0 mod 2 and 0 when s·y = 1. So a measurement never returns a y with s·y = 1. Every run hands you one random string y satisfying y·s = 0 mod 2. The result y = 0ⁿ is possible and tells you nothing.

From measurements to s

Each measured y is one linear equation over the field of two elements, GF(2): the bits of y weight the unknown bits of s, and the sum is 0 mod 2. Collect about n of these equations and solve them by Gaussian elimination, using XOR where ordinary elimination uses subtraction. If the rows have rank n − 1, the only solutions are 0ⁿ and s, so s is fixed. If the rank is lower, run the circuit a few more times.

y₁s₁ ⊕ y₂s₂ ⊕ … ⊕ yₙsₙ = 0 (mod 2)

y = y₁…yₙ is one measured output string; s = s₁…sₙ is the unknown period; the equation says the inner product y·s is even.

A small walk-through. Take n = 3 and s = 011. The condition is y₂ ⊕ y₃ = 0, so the nonzero strings that can ever be measured are 011, 100 and 111. Suppose the machine returns y = 100 and y = 011. From 100 you get s₁ = 0. From 011 you get s₂ ⊕ s₃ = 0, so s₂ = s₃. Since s is not 0ⁿ, s = 011, which is correct.

This period-finding pattern, repeated measurements giving equations on a hidden string, is the direct ancestor of order finding and of Shor's algorithm (see 4.6).

Worked example

Question. Bernstein-Vazirani with n = 3 and secret string s = 101, so f(x) = x₁ ⊕ x₃ mod 2. The ancilla is prepared in |−⟩. The input register starts in |000⟩, receives H^⊗3, then U_f, then H^⊗3. What is measured, and with what probability?

  1. n = 3 gives 2³ = 8 inputs, x = 000 to 111. The secret s = 101 is the integer 5.
  2. After H^⊗3 the state is (1/√8) Σₓ |x⟩|−⟩. Each of the 8 terms has amplitude 1/√8 ≈ 0.3536.
  3. The oracle applies the phase (−1)^(s·x) with s·x = x₁ ⊕ x₃. The sign is −1 for 001, 011, 100, 110 and +1 for 000, 010, 101, 111 — four inputs each.
  4. The final H^⊗3 gives amplitude (1/8) Σₓ (−1)^(x·(s⊕y)) on output string y. At y = 101 all eight terms are +1, giving 8/8 = 1. For every other y the eight terms cancel to 0.
  5. Measurement therefore returns |101⟩ with probability 1, that is, the integer 5 — in one query, where a classical machine needs 3.

Answer. The register is measured as |101⟩ (decimal 5) with probability 1, using one oracle query.

Exam traps

  • Believing Simon's algorithm outputs s directly. It outputs a random y with y·s = 0; you must repeat and solve a linear system.
  • Forgetting the Bernstein-Vazirani promise f(x) = s·x mod 2. Without that promise the final Hadamards do not concentrate on a single string and the answer is meaningless.
  • Mixing up the two promises: Deutsch-Jozsa returns one bit (constant versus balanced), Bernstein-Vazirani returns the whole n-bit string, and the constant function is just the case s = 0ⁿ.
  • Sign slip in Simon: the surviving condition is y·s = 0 mod 2, not 1. It comes from 1 + (−1)^(s·y) being zero when s·y = 1.
  • Dropping the second Hadamard layer, or forgetting that a measured y = 0ⁿ in Simon is a valid result that gives no equation at all.

f: {0,1}ⁿ → {0,1}ⁿ, and there is a nonzero string s with f(x) = f(y) exactly when y = x or y = x⊕s. The task is to find s.

Understand Why does the final H^⊗n layer in Bernstein-Vazirani leave exactly |s⟩ in the input register? 3 marks

The amplitude on y is (1/2ⁿ) Σₓ (−1)^(x·(s⊕y)). For y = s every term is +1 and the amplitudes add to 1; for any other y, half the terms are +1 and half are −1, so they cancel. All probability sits on |s⟩.

The final Hadamards leave |1011⟩, so the result is 1011 (decimal 11) with probability 1. Classically 4 queries are needed, one per bit.

y = 110 gives s₁ ⊕ s₂ = 0, so s₁ = s₂. y = 011 gives s₂ ⊕ s₃ = 0, so s₂ = s₃. All three bits are equal, and s ≠ 0ⁿ, so s = 111.

Analyze Why does Simon's algorithm need about n repetitions while Bernstein-Vazirani needs only one? 6 marks

Bernstein-Vazirani's promise is linear in s, so the final interference moves all amplitude onto the single string s. In Simon the measured y depends on s only through the constraint y·s = 0, which is one equation in n unknowns; about n − 1 independent equations are needed to fix s.

Analyze In Simon's algorithm, why does measuring the second register not help find s? 5 marks

The second register holds f(x). Measuring it collapses the first register to (|x⟩ + |x⊕s⟩)/√2 for a random x, which shows only the pairing structure and no bit of s. The useful information comes from the first register after the second Hadamard layer.

Beyond the syllabus

Not for the exam. Simon's condition y·s = 0 is a special case of the hidden subgroup problem: a function constant on cosets of a hidden subgroup H of a group G, with the task of finding H. 4.4 Quantum Fourier transform and its applications

The quantum Fourier transform (QFT) is a basis change on n qubits. It turns a hidden period in the input indices into a phase that can be measured. For N = 2^n basis states it maps |j⟩ to a superposition whose amplitudes are e^(2πijk/N)/√N. Classical Fourier transforms are common in signal processing; the QFT does the same job on quantum amplitudes. It is the engine inside phase estimation, period finding and Shor's factoring algorithm. It does not print the full Fourier vector; it prepares a state that later interference and measurement can use.

You need complex numbers and tensor products from Unit 1, and Hadamard, controlled phase gates and qubit order from Unit 3; phase kickback from Chapter 4.1 helps with applications.

Definition and inverse

Take n qubits. The number of basis states is N = 2^n. Label the states |0⟩, |1⟩, ..., |N−1⟩ by an integer j. The QFT maps the basis state |j⟩ to a superposition of all |k⟩ with k from 0 to N−1.

QFT|j⟩ = (1/√N) Σ<sub>k=0</sub><sup>N−1</sup> e<sup>2πijk/N</sup>|k⟩

N = 2^n is the number of basis states; j is the input index (0 ≤ j ≤ N−1); k is the output index; i is the imaginary unit, with i² = −1; e is Euler's number; the factor 1/√N keeps the vector length 1.

The inverse QFT is the conjugate transpose. It uses the same circuit with the exponent negated, or the forward QFT run backwards.

QFT†|k⟩ = (1/√N) Σ<sub>j=0</sub><sup>N−1</sup> e<sup>−2πijk/N</sup>|j⟩

QFT† is the inverse; the minus sign in the exponent undoes the plus sign.

For N = 2, the QFT is just a Hadamard. For N > 2, extra controlled phase gates are needed. The transform is unitary, so QFT†QFT = I.

Circuit: Hadamards, controlled phases, swaps

Write j in binary as j = j1j2...jn, with j1 the most significant bit. The circuit applies Hadamards and controlled phase gates, then swaps qubits.

  1. Apply H to qubit 1. Then apply controlled R2 from qubit 1 to qubit 2, R3 from 1 to 3, and so on up to Rn from 1 to n.
  2. Apply H to qubit 2. Then apply controlled R2 from 2 to 3, R3 from 2 to 4, and so on.
  3. Continue for qubits 3 to n. A controlled Rk gate adds phase e2πi/2k only when both qubits are 1.
  4. The operations leave the qubits in reverse order. Swap qubit 1 with n, qubit 2 with n−1, and so on.
  5. The final state is the QFT of the input, up to the chosen bit-order convention.

The product form shows the tensor structure. For input bits j1...jn:

QFT|j<sub>1</sub>...j<sub>n</sub>⟩ = (1/√N) (|0⟩ + e<sup>2πi0.j<sub>n</sub></sup>|1⟩) ⊗ (|0⟩ + e<sup>2πi0.j<sub>n−1</sub>j<sub>n</sub></sup>|1⟩) ⊗ ... ⊗ (|0⟩ + e<sup>2πi0.j<sub>1</sub>...j<sub>n</sub></sup>|1⟩)

0.jm...jn means jm/2 + ... + jn/2n−m+1; ⊗ is the tensor product; n is the number of qubits and N = 2^n.

Hadamards alone give a uniform superposition with equal phases. The controlled phases create the relative phases e2πijk/N. That is why the QFT needs both gates and swaps.

Applications

The QFT changes basis so a hidden period becomes a measurable phase. In phase estimation, an eigenphase φ appears in the amplitudes; an inverse QFT converts it into a binary readout. See Chapter 4.5.

Period finding applies this to a function with hidden period r. The QFT peaks at multiples of N/r, so measurement gives information about r. Simon's algorithm uses a related Hadamard trick to find a hidden period; see Chapter 4.3.

Shor's factoring algorithm uses period finding for the map x → ax mod N; see Chapter 4.6. The QFT is not a fast classical Fourier transform by itself. A measurement returns one sample from the Fourier state, not all N amplitudes. Its power comes from using interference inside a larger algorithm.

The abbreviation QFT is standard; some texts write F or FN for the same transform on N = 2n states.

Worked example

Question. For N = 4 (n = 2), find QFT|01⟩.

  1. N = 4, so √N = 2 and the prefactor is 1/2. The input index is j = 1.
  2. The amplitude of |k⟩ is (1/2)e2πi·1·k/4 = (1/2)eiπk/2.
  3. For k = 0: e0 = 1, so the coefficient is 0.5 + 0.0i.
  4. For k = 1: eiπ/2 = i, so the coefficient is 0.0 + 0.5i.
  5. For k = 2: eiπ = −1, so the coefficient is −0.5 + 0.0i.
  6. For k = 3: ei3π/2 = −i, so the coefficient is 0.0 − 0.5i.
  7. Therefore QFT|01⟩ = (1/2)|00⟩ + (i/2)|01⟩ − (1/2)|10⟩ − (i/2)|11⟩.

Answer. The state is (1/2)|00⟩ + (i/2)|01⟩ − (1/2)|10⟩ − (i/2)|11⟩; its coefficients in order |00⟩, |01⟩, |10⟩, |11⟩ are 0.5 + 0.0i, 0.0 + 0.5i, −0.5 + 0.0i, 0.0 − 0.5i.

Exam traps

  • Using only Hadamards for n > 1. The QFT needs controlled phase gates; Hadamards alone give equal amplitudes and no Fourier phases.
  • Dropping the minus sign in the inverse QFT. The inverse uses e−2πijk/N, not e+2πijk/N.
  • Mixing qubit order. Some circuits output qubits reversed; swaps or relabelling are needed before comparing with the formula.
  • Confusing the QFT with measurement of the full spectrum. One run gives one outcome; repeated runs sample the distribution.
  • Forgetting N = 2^n. If N is not a power of 2, pad with zeros or use a different transform; the circuit is defined for N = 2^n.

4.5 Phase estimation and order finding

Phase estimation measures the hidden angle inside an eigenvalue. A unitary U acts on an eigenvector |u⟩ by a phase: U|u⟩ = e^(2πiφ)|u⟩. φ is the eigenphase. The circuit reads the first t bits of φ using controlled powers of U and an inverse quantum Fourier transform. It drives order finding, which powers Shor's factoring algorithm (see 4.6). Quantum counting and chemistry simulations use the same block.

You need the quantum Fourier transform (see 4.4), phase kickback (see 4.1), and controlled gates from Unit 3.

The phase estimation circuit

A unitary eigenvalue has modulus 1, so it can be written e^(2πiφ) with 0 ≤ φ < 1. φ is the eigenphase. The circuit does not measure the complex eigenvalue; it measures φ in binary.

U|u⟩ = e^(2πiφ)|u⟩

U is a unitary operator; |u⟩ is an eigenvector of U; φ is the eigenphase, a real number with 0 ≤ φ < 1; i is the imaginary unit; e is Euler's number.

Two registers: the first has t qubits, starts in |0^t⟩ and carries the answer; the second holds |u⟩ and is not measured. Larger t gives more bits of φ.

  1. Apply H to each of the t qubits: H^⊗t|0^t⟩ = (1/√M) Σ_y |y⟩, with M = 2^t and y = 0, …, M−1.
  2. For control qubit j = 0, …, t−1, apply controlled-U^(2^j). The |1⟩ branch picks up phase e^(2πiφ·2^j) by phase kickback.
  3. The joint state is (1/√M) Σ_y e^(2πiφy)|y⟩ ⊗ |u⟩.
  4. Apply QFT† to the first register. It maps the state to |Mφ⟩.
  5. Measure the first register. Outcome y gives φ ≈ y/M.

φ ≈ y / 2^t

y is the measured integer with 0 ≤ y ≤ 2^t − 1; t is the number of qubits in the first register; φ is the eigenphase in [0, 1).

If φ = s/2^t for some integer s, the answer is exact and the register reads s with certainty. Otherwise the measurement gives the nearest integer to 2^t φ with probability at least 4/π² ≈ 0.4, so one run is not reliable. Repeat the circuit a few times and keep the most frequent outcome; the estimate is then good to about 1/2^t.

From t bits to a fraction

The measurement returns y, and y/M estimates φ with M = 2^t. In order finding φ = s/r, where r is the unknown order. y/M only approximates s/r, so recover s/r from it.

Use continued fractions. Expand y/M as a continued fraction. Its convergents p/q have small denominators that approach y/M. Since r < N, take convergents with denominator q < N, smallest first, and test each one.

y/2^t ≈ s/r  →  convergent p/q  →  test a^q ≡ 1 (mod N)

y is the measured integer; t is the first-register size; s and r are the numerator and denominator of the exact eigenphase; q is a candidate order; N is the number being factored.

t must be large enough that the correct fraction is the closest one with a small denominator. A common rule is t = 2⌈log₂ N⌉, twice the bit length of N. The measurement shows s/r, not r; r appears only after the continued-fraction step.

Order finding

Fix N and a with gcd(a, N) = 1. The order of a modulo N is the smallest positive r with a^r ≡ 1 (mod N). It exists because powers a⁰ = 1, a¹, a², … repeat with period r modulo N.

Define U|x⟩ = |a x mod N⟩ for 0 ≤ x ≤ N−1. Multiplication by a permutes the residues, so U is a permutation matrix and unitary. Its eigenstates and eigenvalues have closed form.

|u_s⟩ = (1/√r) Σ_{k=0}^{r−1} e^(−2πi s k / r) |a^k mod N⟩,  U|u_s⟩ = e^(2πi s/r)|u_s⟩

r is the order of a modulo N; s = 0, 1, …, r−1 labels the eigenvector; k indexes powers of a; i is the imaginary unit.

We do not know r, so we cannot write |u_s⟩. And the circuit needs a real input. Put |1⟩ in the second register: |1⟩ = (1/√r) Σ_s |u_s⟩. Phase estimation on it returns s/r, with s uniformly random in 0 to r−1.

  1. Check gcd(a, N) = 1. If not, gcd(a, N) is already a factor; stop.
  2. Choose t = 2⌈log₂ N⌉ and build controlled powers of U|x⟩ = |a x mod N⟩.
  3. Run phase estimation with |1⟩ in the second register; measure the first register to get y.
  4. Apply continued fractions to y/2^t; keep the smallest denominator q < N.
  5. Test a^q ≡ 1 (mod N). If true, r = q. If not, try the next convergent or rerun.

The order r is not yet a factor of N. Turning r into factors needs a gcd step; that is Shor's algorithm (see 4.6).

Worked example

Question. For N = 15 and a = 2, phase estimation with t = 3 returns y = 2. Recover the order by continued fractions, confirm it, and state the eigenphase.

  1. gcd(2, 15) = 1, so the order exists.
  2. M = 2³ = 8, so y/M = 2/8 = 1/4.
  3. The continued fraction of 2/8 is 1/4; its denominator q = 4 is below N = 15.
  4. Test q = 4: 2⁴ = 16 ≡ 1 (mod 15), so r = 4.
  5. The measured fraction is s/r; here 1/4, so s = 1 and φ = 1/4 = 0.25.

Exam traps

  • Reporting y/2^t as the order. The measurement approximates s/r; continued fractions produce r.
  • Ignoring gcd(s, r). If s and r share a factor, s/r reduces and the recovered denominator is a proper divisor of r; test a^q ≡ 1 and retry.
  • Choosing a not coprime to N. Then the order does not exist, but gcd(a, N) is already a nontrivial factor.
  • Confusing eigenphase φ with eigenvalue e^(2πiφ). φ is real in [0, 1); the eigenvalue has modulus 1.
  • Forgetting that the second register must be |1⟩ or an eigenvector. A basis state |x⟩ sits in an orbit whose length L divides r; when L is a proper divisor of r, phase estimation returns j/L and the recovered denominator divides r and is too small (for N = 15, a = 2, |5⟩ has orbit 5 → 10 → 5, length 2, not 4).

4.6 Shor's factoring algorithm

Shor's algorithm factors a whole number N by turning factoring into order finding. For a base a coprime to N, the order r is the smallest positive power with a^r ≡ 1 mod N. A quantum phase-estimation circuit finds r. Then simple gcd calculations turn the order into factors. Classical computers have no known fast method for this task, so RSA-style cryptography uses large N. Shor's algorithm is the standard example of a quantum speed-up for a concrete problem. Some syllabi call it Shor's factorization algorithm.

You need: phase estimation and order finding from 4.5; the quantum Fourier transform from 4.4; and modular arithmetic from Unit 1, Foundations.

Why an order gives factors

Pick N to factor. Pick a with 1 < a < N. Compute gcd(a,N), the greatest common divisor. If gcd(a,N) > 1, it is already a nontrivial factor of N. Stop. Otherwise gcd(a,N) = 1, so a is coprime to N.

The order of a modulo N is the smallest positive integer r with a^r ≡ 1 (mod N). The notation x ≡ y (mod N) means N divides x − y. Example: 2^4 = 16 and 16 − 1 = 15, so 2^4 ≡ 1 (mod 15). The order of 2 modulo 15 is 4.

If r is odd, this order gives no split. If r is even, write the difference of squares below. Because a^r ≡ 1, N divides the left side. N may divide part of each bracket. The gcd pulls out the shared part. If neither gcd is 1 or N, both are nontrivial factors.

a<sup>r</sup> − 1 = (a<sup>r/2</sup> − 1)(a<sup>r/2</sup> + 1)

a is the chosen base; r is the order of a modulo N; N is the number being factored.

The extra check matters. If ar/2 ≡ −1 (mod N), then ar/2 + 1 is divisible by N. One gcd is N; the other is 1. That is a trivial split. Here −1 (mod N) means N − 1. Retry with another a. The whole classical step is: even r, nontrivial half-power, then two gcds.

Order finding on a quantum computer

Define a unitary U on basis states |y> for 0 ≤ y < N by U|y> = |a y mod N>. For states outside this range, set U|y> = |y>. For s = 0, 1, …, r−1, the state below is an eigenstate of U with eigenvalue e2πi s/r. Here x0 is coprime to N and i is the imaginary unit. The eigenphase is s/r.

|u<sub>s</sub>> = (1/√r) Σ<sub>k=0</sub><sup>r−1</sup> e<sup>−2πi s k/r</sup> |a<sup>k</sup> x<sub>0</sub> mod N>

|us> is eigenstate number s; r is the order; x0 is a starting value coprime to N; i is √−1.

Phase estimation from 4.5 estimates this phase. The QFT from 4.4 turns it into a measurable bit pattern. A measurement gives an integer m. The ratio m/2t is close to s/r, where t is the number of phase-estimation qubits. Continued fractions on m/2t give a candidate r.

The candidate is checked classically: compute ar mod N. If it is not 1, repeat. With more phase-estimation qubits the error in s/r shrinks. Several runs are cheap compared with the quantum step. The order-finding output feeds the checks above. On failure, choose a new a.

Success and cost

For odd N with at least two distinct prime factors, a random a coprime to N succeeds with probability at least 1/2. This bound assumes the order-finding step returns r exactly. Phase estimation can return a wrong candidate, so check it. A few repeats make failure unlikely.

Factoring N by classical trial division costs about √N steps. Shor's quantum part runs in time polynomial in log₂ N, the number of bits needed to write N. The gcd steps are classical and cheap. Small N can be factored on paper; the quantum advantage grows with N.

Special cases before the quantum part: if N is even, divide out factors of 2 first; if N is a perfect power pk, Shor's gcd step cannot split it, so test for perfect powers classically before running the quantum part.

The algorithm does not output a factor directly. It outputs a candidate order r, and the gcd step outputs factors. A failed parity check, a half-power equal to −1, or a gcd equal to 1 or N sends the run back to a new base a.

Worked example

Question. Factor N = 15 using Shor's classical post-processing with base a = 2. Find the order, check the conditions, and compute the factors.

  1. N = 15 and a = 2. gcd(2,15) = 1, so there is no immediate factor.
  2. Powers of 2 modulo 15: 2^1 = 2, 2^2 = 4, 2^3 = 8, 2^4 = 16 ≡ 1 (mod 15). The smallest such power is 4, so the order is r = 4.
  3. r = 4 is even, so the half exponent is r/2 = 2. The half-power is a^(r/2) = 2^2 = 4 (mod 15).
  4. Check the trivial root: 4 ≠ −1 (mod 15), because −1 ≡ 14 (mod 15). The check passes.
  5. First gcd: gcd(4 − 1, 15) = gcd(3, 15) = 3.
  6. Second gcd: gcd(4 + 1, 15) = gcd(5, 15) = 5.
  7. Both factors are nontrivial: 3 > 1, 5 > 1, and 3 × 5 = 15.

Answer. The factors of 15 are 3 and 5.

Exam traps

  • Using a^r ± 1 instead of a^(r/2) ± 1. The split needs the half-power.
  • Forgetting the two conditions: r must be even and a^(r/2) must not be −1 mod N.
  • Calling r a factor. The order is an exponent, not a divisor of N.
  • Computing only one gcd. Compute both gcd(a^(r/2)−1,N) and gcd(a^(r/2)+1,N).
  • Skipping gcd(a,N). If it exceeds 1, no quantum step is needed.

4.7 Grover's quantum search algorithm

Grover's algorithm searches an unstructured list of N items for one marked item using about √N quantum queries instead of N classical checks. Here N=2n, and n is the number of qubits. An oracle flips the sign of the marked item. A diffusion operator then inverts all amplitudes about their mean. Repeating the pair boosts the marked amplitude. This is a quadratic speedup, not an exponential one. Some syllabi call it Grover's quantum search algorithm. It is used for search, constraint solving and brute-force tasks where no structure gives a faster classical method.

You need: phase kickback from 4.1, and Hadamard gates and oracle construction from Unit 3.

The unstructured search problem

A list has N items, labelled x=0,1,...,N−1. Exactly one item w is marked. A classical algorithm that checks one item per query needs N queries in the worst case, and about N/2 on average. The list has no order, so binary search does not apply. Grover uses n=log₂N qubits, so N=2n. The input state is the uniform superposition |s⟩ = (1/√N) Σx |x⟩.

The quantum query is an oracle. It changes only the sign of the marked item; all other items keep their sign. Phase kickback from 4.1 turns a Boolean oracle into this sign flip.

U<sub>w</sub>|x⟩ = (−1)<sup>f(x)</sup>|x⟩, with f(x)=1 if x=w and f(x)=0 otherwise

Uw is the oracle; x is a list index from 0 to N−1; w is the marked index; f(x) is the marking function.

Diffusion inverts about the mean

In the first iteration, after the oracle the marked amplitude is 1/√N in magnitude and negative, and all other amplitudes are positive. Let the current amplitudes be ax. The diffusion operator D maps ax to 2⟨a⟩ − ax, where ⟨a⟩ is the mean of all N amplitudes. A negative marked amplitude pulls the mean down slightly. In that first iteration, the map turns the marked amplitude positive and larger, and turns each unmarked amplitude slightly smaller.

In matrix form D = 2|s⟩⟨s| − I, where |s⟩ is the uniform superposition and I is the identity. The circuit builds D as H⊗n(2|0⟩⟨0|−I)H⊗n. One oracle plus one D is one Grover iteration G = D Uw. The state stays in the plane spanned by |w⟩ and the uniform superposition of all unmarked items; the other N−2 directions are never populated.

The Grover iteration as a rotation

Define |α⟩ = (1/√(N−1)) Σx≠w |x⟩, the uniform state over unmarked items. The start state is |s⟩ = sin θ |w⟩ + cos θ |α⟩, with sin θ = 1/√N. The angle θ = arcsin(1/√N) is measured in radians. One Grover iteration rotates the state by 2θ in this plane.

P(k) = sin²((2k+1)θ), sin θ = 1/√N

P(k) is the probability of measuring the marked item after k iterations; θ is the angle with sin θ = 1/√N; N is the number of items; k is the number of Grover iterations.

After k iterations, the amplitude of |w⟩ is sin((2k+1)θ), so the success probability is P(k). Set (2k+1)θ ≈ π/2 for the first peak. Then kopt ≈ (π/4)√N − 1/2, which is about (π/4)√N for large N.

  1. Start in |0...0⟩ with n qubits.
  2. Apply H⊗n to make |s⟩.
  3. Repeat k times: apply the oracle Uw, then the diffusion operator D.
  4. Measure all qubits in the computational basis.

Cost, limits and use

Grover needs about (π/4)√N oracle calls and about the same number of diffusion steps. The classical worst case is N checks, so the speedup is quadratic: N=1012 needs about 106 Grover steps, not 1012. This is not exponential. The oracle must be a real quantum circuit whose cost is counted; a classical check of each item gains nothing.

The method is used for unstructured search, for brute-force search over candidate solutions, and as amplitude amplification inside larger algorithms. Extra iterations reduce the success probability after the first peak, so k is chosen in advance. Quantum counting and the √N lower bound are in 4.8.

Worked example

Question. N=16 items, one marked item. Use θ=arcsin(1/√16). Find the success probability after k=0,1,2,3 Grover iterations. Which k in this set is best, and what is P at that k?

  1. Compute θ = arcsin(1/√16) = arcsin(0.25) = 0.252680 rad ≈ 0.2527 rad.
  2. For each k, the angle is (2k+1)θ: k=0: 0.2527 rad; k=1: 0.7580 rad; k=2: 1.2634 rad; k=3: 1.7688 rad.
  3. Take sine squared: k=0: sin²(0.2527)=0.0625; k=1: sin²(0.7580)=0.4727; k=2: sin²(1.2634)=0.9084; k=3: sin²(1.7688)=0.9613.
  4. Compare: 0.0625 < 0.4727 < 0.9084 < 0.9613. Best k=3.
  5. At k=3, P=0.9613, so measurement returns the marked item with probability 96.13%.

Answer. For N=16 the best k is 3, with success probability P≈0.9613 (96.13%).

Exam traps

  • Stopping at the first peak matters. Running more than kopt rotations moves the state past |w⟩ and lowers P(k).
  • The oracle is a unitary quantum query. A classical loop that checks each item is not a Grover oracle and gives no speedup.
  • Do not mix N and n. N is the number of items; n=log₂N is the number of qubits; θ uses √N.
  • The formula is sin²((2k+1)θ), not sin²(2kθ). At k=0 it must give 1/N.
  • Diffusion is inversion about the mean, not about zero. The negative sign on the marked amplitude is what makes the mean shift.

4.8 Quantum counting and optimality of quantum search

Grover search finds one marked item in about √N steps. Quantum counting asks a different question: how many marked items are there? It never looks for them. It takes the operator that Grover search is built from, reads that operator's rotation angle by phase estimation, and turns the angle into a count. The same angle tells you how many Grover iterations a search would need. A matching lower bound of Ω(√N) oracle queries says that no unstructured search can do much better than Grover. Counting is used to estimate numbers of solutions, and to decide whether a search is worth running.

You need: Grover's quantum search for the iteration and its two-dimensional rotation picture, and phase estimation for reading an eigenphase with the inverse QFT.

Counting is a different question from searching

Take a list of N = 2ⁿ items and mark M of them, with 0 < M < N. The oracle O flips the sign of a marked item and leaves every other item alone. Write |α⟩ for the normalised sum of the M marked items and |β⟩ for the normalised sum of the other N − M items. The uniform superposition is then |s⟩ = sin θ |α⟩ + cos θ |β⟩, where sin θ = √(M/N).

Grover's operator is G = (2|s⟩⟨s| − I)O. It keeps the state inside the plane spanned by |α⟩ and |β⟩, and inside that plane it rotates by 2θ toward |α⟩. A rotation by 2θ has eigenvalues e^(+2iθ) and e^(−2iθ). Read those eigenvalues and you know θ; know θ and you know M = N sin²θ.

  • The angle gives M directly. Finding which items are marked is a separate job, needing about (π/4)√(N/M) Grover iterations.
  • If M = 0 nothing is marked and no search can succeed; a large M means a short search. Counting tells you which case you are in before you spend any queries.
  • Counting returns a number only. It never names a marked item.

Phase estimation on the Grover operator

Phase estimation writes the eigenphase of a unitary into a register of t qubits. Feed it the Grover operator G.

  1. Start with a t-qubit phase register in state |0⟩^⊗t and an n-qubit search register in state |s⟩.
  2. Apply H to all t phase qubits, so every t-bit value gets equal amplitude.
  3. From phase qubit j, apply controlled-G^(2^j) to the search register, for j = 0, 1, …, t−1.
  4. Apply the inverse QFT to the phase register and measure it as an integer y, with 0 ≤ y < 2^t.
  5. Convert y into a count.

M ≈ N sin²(π y / 2^t)

N is the number of items in the list; M is the number of marked items; t is the number of phase qubits, so 2^t is the resolution of the measurement; y is the measured integer; πy/2^t is the estimate of θ in radians.

Both eigenvalues give the same count, because sin²(π − x) = sin²x. So y and 2^t − y lead to the same M, and using sin² removes that ambiguity.

δM ≈ 2π √(M(N − M)) / 2^t

δM is the typical error in the count. It follows from dM/dθ = N sin 2θ = 2√(M(N − M)), together with a phase error of about π/2^t in θ (one unit in y), giving δM ≈ 2π√(M(N − M))/2^t.

Cost. The controlled-G^(2^j) blocks use about 2^t Grover applications in total. Choosing 2^t ≈ √N leaves an error of order √M and costs O(√N) oracle calls, each of O(log N) gates. Classical counting needs Θ(N) calls, so counting is quadratically faster too.

Why no algorithm beats Ω(√N)

The lower bound lives in the oracle model. The list is a black box, and cost is counted in queries to that box, not in gates. Any quantum algorithm that finds a marked item, or decides that one exists, with success probability at least 2/3 needs Ω(√N) queries. Grover uses ⌈π√N/4⌉ ≈ 0.79√N queries, so it is optimal up to a constant.

The adversary idea behind the proof: run the algorithm twice, once with an oracle that marks nothing and once with an oracle that marks item j. Both runs start from the same state. Each query changes the difference between the two states by at most about 2 times the amplitude on item j, and those amplitudes add up to at most k/√N, so after k queries the two states differ by at most about 2k/√N. To answer correctly with probability 2/3 the two states must be nearly orthogonal, which forces k to reach order √N. The argument is then averaged over all j. A second proof, the polynomial method, reaches the same bound.

  • The bound is on oracle queries. A gate-level bound must add the O(log N) gates per query.
  • It assumes bounded error, success probability at least 2/3. Under a zero-error requirement the complexity is Θ(N) queries: exact unstructured search has no √N speed-up.
  • It holds for unstructured lists. A promised structure, such as knowing the marked item lies in a small subset, can beat it.
  • Estimating M to constant relative accuracy costs Θ(√(N/M)) queries: take 2^t ≈ 2π√(N/M) so that δM is of order M. This equals the search bound Ω(√N) only when M is a small constant; in general counting is optimal at Θ(√(N/M)).

Worked example

Question. A list has N = 100 items and M = 9 of them are marked. (a) Find θ. (b) Using t = 8 phase qubits, find the integer y closest to 256θ/π. (c) Reconstruct M from y and check the error against δM = 2π√(M(N−M))/2^t.

  8. Round to 9, which is the true count. The error 0.12 is well inside δM = 2π√(9 × 91)/256 = 0.7.

Exam traps

  • Counting gives the number of marked items, not their identity. If the question asks which items are marked, you must run Grover search; a count cannot answer it.
  • y and 2^t − y give the same M, because sin² is symmetric about π/2. Reporting two different counts from one measurement is wrong.
  • M = 0 gives θ = 0 and M = N gives θ = π/2. Both are still read out correctly (y = 0 gives M = 0, y = 2^(t−1) gives M = N). The counting circuit is defined for 0 < M < N because at the boundary the two eigenvalues coincide and, for M = 0, there is no search problem at all.
  • The angle inside sin² is πy/2^t in radians, not y/2^t and not degrees. A missing factor of π or a degree slip moves M far from the truth.
  • The Ω(√N) bound is on oracle queries in the unstructured model. The sentence 'no quantum algorithm can search faster than √N' is false once the list has promised structure.

4.9 Quantum complexity: BQP and NP-complete problems

BQP is the set of yes-or-no problems that a quantum computer can settle in polynomial time with small error. It is the honest yardstick for what quantum hardware can do fast. Shor's algorithm puts integer factoring inside BQP, so quantum machines beat the best known classical methods there. But nobody has placed an NP-complete problem inside BQP. This chapter defines the class, draws the inclusions that are proved, and explains why Grover's quadratic speedup does not turn an exponential search into a polynomial one.

You need: Shor's factoring algorithm, Grover's search, and the big-O notation from Unit 1 (Foundations).

P, NP and BQP in plain terms

A complexity class is a set of decision problems, that is, problems whose answer is yes or no. Problems are grouped by the resources needed to solve them. The resource here is time, counted as a function of the input length n, which is the number of input bits.

P holds every problem that a classical deterministic computer can settle in time O(nk) for some fixed k. Adding two n-bit numbers is in P.

NP holds every problem whose YES answer can be checked in polynomial time from a short certificate. A Boolean formula with n variables and m clauses is satisfiable when some assignment makes it true; the assignment is the certificate and checking it costs O(m) steps for clauses of bounded length (as in 3-SAT), and O(total formula length) in general. A problem is NP-complete when it lies in NP and every NP problem reduces to it in polynomial time. Satisfiability (SAT) is the standard example.

BQP is the quantum class: bounded-error quantum polynomial time. A decision problem is in BQP when a polynomial-size quantum circuit decides it with error at most 1/3. In words, measuring the output qubit gives the correct answer with probability at least 2/3. The circuit family must be uniform: a classical polynomial-time algorithm must produce the circuit for each input length n.

Pr[correct] ≥ 1 − ε, with ε ≤ 1/3 and circuit size ≤ poly(n)

Pr[correct] is the probability that measuring the circuit's output qubit equals the true answer; ε is the allowed error; poly(n) means at most c·nk for fixed constants c and k, with n the number of input bits.

The 1/3 is not special. Running the circuit 2r+1 times and taking the majority answer pushes the error down to roughly e−cr, so any fixed error below 1/2 describes the same class. Some syllabi call BQP bounded quantum polynomial time; both names mean this one class.

The inclusion ladder, and the rung we cannot place

P ⊆ BQP. Classical reversible gates such as Toffoli are quantum gates. A quantum circuit can therefore replay any polynomial-size classical circuit gate by gate and measure at the end. Everything easy classically is easy quantumly.

BQP ⊆ PSPACE. PSPACE holds the problems solvable with polynomial memory, with no limit on running time. A classical machine can compute one output amplitude of a poly-size circuit by summing over all computational paths that lead to it. That sum is exponentially long but needs only polynomial working memory, so every BQP problem sits inside PSPACE. Quantum computers are fast, not unlimited.

The classical ladder P ⊆ NP ⊆ PSPACE is standard. BQP crosses NP in a way nobody has pinned down: neither BQP ⊆ NP nor NP ⊆ BQP has been proved.

P ⊆ BQP ⊆ PSPACE and P ⊆ NP ⊆ PSPACE

P is polynomial-time classical; NP is polynomial-time verifiable; BQP is bounded-error quantum polynomial time; PSPACE is polynomial memory, unlimited time. The relation between BQP and NP is unknown.

Factoring is not NP-complete, and Grover is only quadratic

Shor's algorithm decides in polynomial time whether N has a factor below a given bound; this is the decision version of factoring. So factoring ∈ BQP. Factoring is also in NP, because a factor is a short certificate. It is not known to be NP-complete, and most researchers believe it is not.

The gap matters. If factoring were NP-complete, then BQP would contain one NP-complete problem. Since every NP problem reduces to it quickly, all of NP would land inside BQP. Nobody expects such a collapse from a problem with the tight algebraic structure of factoring.

For NP-complete problems the best general quantum tool is Grover search. If the search space has N = 2n candidates for n Boolean variables, Grover finds a marked one in about (π/4)√N oracle calls. Chapter 4.8 shows that no black-box quantum algorithm can do much better.

(π/4)·√(2<sup>n</sup>) = (π/4)·2<sup>n/2</sup> ≈ 0.79·2<sup>n/2</sup> oracle calls

n is the number of Boolean variables; 2n is the number of candidate assignments; π/4 ≈ 0.785 is the constant from the optimal Grover iteration count.

The exponent halves; it does not vanish. A quadratic speedup buys real time on small instances, but it does not move an NP-complete problem into BQP. Advertisements that a quantum computer "solves NP-complete problems" usually hide this one step.

Worked example

Question. A Boolean satisfiability instance has n = 50 variables. Compare classical brute-force search with Grover's algorithm. Give the number of assignments classically checked and the number of oracle calls Grover needs, and say whether either count is polynomial in n.

Exam traps

  • BQP is a class of decision problems with bounded error, not a label for anything a quantum computer can attempt. Saying "BQP includes all quantum algorithms" is wrong.

Grover's algorithmFinds one marked item in an unstructured list of N items using about (π/4)√N oracle calls.4.7
Grover diffusion operatorThe reflection 2|s⟩⟨s| − I about the uniform state; oracle plus diffusion rotates the state by 2θ per step.4.7
Quantum countingPhase estimation applied to the Grover operator G to estimate M, the number of marked items.4.8
BQPBounded-error quantum polynomial time: decision problems a quantum computer solves in polynomial time with error ≤ 1/3.4.9
NP-completeThe hardest problems in NP; a polynomial-time solution to any one of them solves all of NP.4.9

Takeaways

  1. Quantum parallelism fills a state with all values f(x), but phase kickback is what moves those values into signs that interference can later read.
  2. Deutsch and Deutsch–Jozsa replace exponentially many classical queries with one quantum query by turning phase into a measurable amplitude.
  3. Bernstein–Vazirani recovers a whole hidden bit string in one query; Simon needs about n queries because it must collect n−1 independent linear equations.
  4. The quantum Fourier transform is the basis change that turns a hidden period r into sharp peaks at multiples of N/r.
  5. Phase estimation is the reusable engine behind order finding, Shor's factoring and quantum counting.
  6. Shor factors N in polynomial time because order finding is efficient and gcd turns a suitable order into a nontrivial factor.
  7. Grover's speedup is quadratic, not exponential: about √N oracle calls instead of N/2.
  8. Quantum counting reads the Grover rotation angle with phase estimation to learn how many marked items exist.
  9. The Ω(√N) query lower bound shows Grover's algorithm is optimal up to a constant factor.
  10. Factoring sits inside BQP, but nobody has shown that an NP-complete problem lies in BQP.

Remember and understand

Understand Explain quantum parallelism and phase kickback. Write the state of the two-qubit circuit that applies U_f to (H⊗H)|01⟩ and show where f(x) appears. 10 marks

Define U_f|x⟩|y⟩ = |x⟩|y⊕f(x)⟩; Prepare data qubit in H|0⟩ and target in H|1⟩ = |−⟩; After U_f the state is Σ_x (−1)^f(x)|x⟩|−⟩/√2, so the value sits in the sign; Note that the two f values are present at once before measurement; Distinguish global phase (unobservable) from relative phase (observable by interference).

Remember Define global phase and relative phase. Why can a relative phase be detected while a global phase cannot? 8 marks

Global phase multiplies the entire state vector; probabilities |amplitude|² are unchanged; Relative phase is a difference between amplitudes of terms in one superposition; Interference terms 2 Re(a*b) depend on that difference; Give the example |0⟩+|1⟩ versus |0⟩−|1⟩, which are orthogonal and give different H outcomes.

Understand State and explain Deutsch's algorithm. Show that the final measurement of the data qubit gives 0 for a constant f and 1 for a balanced f. 10 marks

Promise: f:{0,1}→{0,1} is constant or balanced; Circuit: H on both qubits, one U_f, H on the data qubit, measure; Final amplitude of |0⟩ is (1/2)Σ_x (−1)^f(x), which is ±1 for constant and 0 for balanced; One query beats the two classical queries needed in the worst case; Explain why the ancilla stays in |−⟩ and can be ignored.

Understand Describe the Deutsch–Jozsa algorithm for n input qubits. Why does measuring 0ⁿ prove the function is constant? 10 marks

State the promise: constant or balanced over all 2ⁿ inputs; Circuit: H^⊗n on |0⟩ⁿ, ancilla in |−⟩, one U_f, H^⊗n, measure; Amplitude of |0⟩ⁿ is (1/2ⁿ)Σ_x (−1)^f(x); Balanced makes the sum cancel exactly to 0; constant makes it ±1; Any other outcome is impossible, so one query suffices while classically 2ⁿ⁻¹+1 queries can be needed.

Apply

Apply For n=2, trace the Deutsch–Jozsa circuit for f(x₁x₂)=x₁⊕x₂ and for f = 0. Give the final state and measurement outcome in each case. 12 marks

Start from |00⟩|1⟩, apply H^⊗2 and H to get (1/2)Σ_x|x⟩|−⟩; Kickback: coefficients become (−1)^f(x); For f=0 the state is unchanged; H^⊗2 returns |00⟩; For f=x₁⊕x₂ the signs give a product state that H^⊗2 maps to |11⟩; Conclude: 00 means constant, 11 means balanced, other answers cannot occur.

Apply In Bernstein–Vazirani with f(x)=s·x mod 2 and hidden s=101, trace the circuit and show the final measurement gives 101. 12 marks

Prepare (1/√8)Σ_x|x⟩|−⟩; After U_f the phase is (−1)^(s·x), so the state is (1/√8)Σ_x (−1)^(s·x)|x⟩; H^⊗3 maps this to |s⟩ exactly; Measurement gives 101 with probability 1, in one query; Contrast with the three classical queries a bit-by-bit probe needs.

Apply In Simon's algorithm with n=3, the measured equations are y₁=101, y₂=011. Find the hidden string s and explain why one more run may be needed. 13 marks

Each measurement gives y with y·s = 0 mod 2; Write the two equations: s₁⊕s₃=0 and s₂⊕s₃=0; Gives s = 000 or s = 111; the nonzero solution is s=111; Repeat until n−1 independent equations are collected to fix s uniquely; Query count is O(n); classical post-processing solves a GF(2) linear system.

Apply Write the action of the quantum Fourier transform on n qubits. Show its circuit uses Hadamards and controlled phase gates, and give the inverse used in phase estimation. 10 marks

Definition |j⟩ → (1/√N)Σ_k e^(2πijk/N)|k⟩ with N=2ⁿ; Product form over qubits with controlled phase gates R_k; Bit-reversal swap at the end; Inverse QFT is the conjugate, applied to the ancilla register in phase estimation; Note the classical FFT costs O(N log N); the quantum circuit uses O(n²) gates.

Apply Draw the phase estimation circuit and show how the first register holds an n-bit approximation of θ in U|ψ⟩ = e^(2πiθ)|ψ⟩. 13 marks

Ancilla in |0⟩ⁿ, target in eigenstate |ψ⟩; Hadamards on ancilla, controlled-U^(2^j) operations write phases into ancilla; State becomes (1/√N)Σ_k e^(2πiθk)|k⟩|ψ⟩; Inverse QFT converts that to a peak near θ·2ⁿ; Measurement gives n bits of θ; accuracy improves with more ancilla qubits.

Apply Use Shor's algorithm to factor N=15 with base a=7. Find the order, then the factors, stating every step. 14 marks

Powers mod 15: 7, 4, 13, 1, so r=4; r is even, so compute a^(r/2) = 7² = 49 ≡ 4 (mod 15); Check 4 ≢ −1 (mod 15), so the step is valid; gcd(4−1,15)=gcd(3,15)=3 and gcd(4+1,15)=gcd(5,15)=5; Conclude 15 = 3 × 5; mention the retry needed when r is odd or a^(r/2) ≡ −1.

Apply A list has N=2²⁰ items with exactly one marked. Estimate the number of Grover iterations and oracle calls needed, and compare with classical search. 12 marks

N = 2²⁰ ≈ 1.05×10⁶; Optimal iterations ≈ (π/4)√N ≈ 0.785 × 1024 ≈ 804; Each iteration uses one oracle call plus one diffusion step; Classical expected checks = N/2 ≈ 524288; So the quantum method is about 650 times fewer oracle calls, a quadratic speedup.

Analyze and evaluate

Analyze Explain quantum counting. Show how phase estimation on the Grover operator gives the number of marked items M, and why this also times the search. 14 marks

Grover operator G has eigenvalues e^(±2iθ) with sin θ = √(M/N); Apply phase estimation to G with t ancilla qubits; Measured value gives θ to t bits, hence M ≈ N sin²θ; Running the circuit also reveals the optimal iteration count, so the search can be run blindly; Contrast with the exact-count problem, which is as hard as search.

Evaluate State the Ω(√N) lower bound for unstructured search. Why does it show Grover's algorithm cannot be improved beyond a constant factor? 14 marks

Any quantum algorithm needs Ω(√N) oracle calls to find a marked item; The bound is proved by a polynomial (or hybrid) argument on the state after few queries; Grover achieves (π/4)√N, matching the bound up to constant factors; Consequence: the speedup is provably at most quadratic; no exponential search speedup exists for unstructured data; Mention that structure in the data can change the bound.

Evaluate Compare Deutsch–Jozsa, Simon's algorithm, order finding and Shor's algorithm as instances of the hidden subgroup problem. Explain which group each uses and what the classical post-processing does. 16 marks

All four prepare a superposition, query f, apply a Fourier transform over the relevant group, and measure; Deutsch–Jozsa uses Z₂ⁿ, where the subgroup is trivial or the whole group; Simon uses Z₂ⁿ with the subgroup {0, s}; post-processing solves GF(2) equations; Order finding and Shor use Z over the multiplication map x → a^x mod N; post-processing is a continued-fraction step; Shor then adds a number-theory stage: gcd(a^(r/2)±1, N); The unifying view explains why the same circuit pattern keeps reappearing.

Analyze Define BQP. Explain what is known about its relation to P, PSPACE and NP, and why factoring does not prove BQP contains NP-complete problems. 14 marks

BQP: polynomial-time quantum computation with bounded error ≤ 1/3; Known: P ⊆ BQP ⊆ PSPACE; Factoring and discrete log are in BQP; they are in NP but not known to be NP-complete; If any NP-complete problem were in BQP then NP ⊆ BQP, which is not known and widely doubted; Grover at best gives a quadratic speedup, so it does not put NP-complete problems in BQP.

Evaluate Grover's algorithm is said to give a quadratic speedup while Shor's gives an exponential one. Justify both claims with query counts and gate costs. 14 marks

Classical search: Θ(N) queries; Grover: Θ(√N); lower bound Ω(√N) makes this optimal; Best classical factoring is sub-exponential (number field sieve); Shor is polynomial in log N; Shor's cost is dominated by modular exponentiation, still polynomial in log N; Exponential speedup is possible only because the problem has algebraic structure, not just a black-box oracle; State the caveat: both assume a working fault-tolerant quantum computer.

Glossary

Amplitude amplification
The general technique of boosting the amplitude of good states by repeated reflection, of which Grover is one case.
Ancilla
A helper qubit used inside a circuit and usually measured or discarded at the end.
BQP
The class of decision problems solvable in polynomial time on a quantum computer with error probability at most 1/3.
Continued fractions
A classical method that recovers the rational r from a measured phase close to a multiple of 1/r.
Controlled unitary
A gate that applies U to a target only when the control qubit is 1.
Diffusion step
The reflection 2|s⟩⟨s| − I about the uniform superposition that inverts amplitudes about their mean.
Eigenphase
The angle θ in the eigenvalue e^(2πiθ) of a unitary operator.
Eigenstate
A state |ψ⟩ with U|ψ⟩ = λ|ψ⟩ for some eigenvalue λ.
Greatest common divisor
The largest positive integer dividing both inputs; computed by Euclid's algorithm in polynomial time.
Grover operator
The product of the oracle reflection and the diffusion reflection, one step of the search.
Hadamard gate
The single-qubit gate H that maps |0⟩ to (|0⟩+|1⟩)/√2 and |1⟩ to (|0⟩−|1⟩)/√2.
Hidden subgroup problem
Given f constant on cosets of an unknown subgroup, find that subgroup; many quantum algorithms fit this pattern.
Interference
The adding of amplitudes so that some outcomes grow and others cancel.
Inverse QFT
The adjoint of the QFT, used to read phases as bit strings in phase estimation.
Marked item
The list element the oracle flags with a phase flip or a 1 output.
NP
The class of decision problems whose yes answers can be checked in polynomial time given a certificate.
Order modulo N
The smallest r>0 such that a^r ≡ 1 (mod N); it exists when gcd(a,N)=1.
Phase estimation
A routine that measures the eigenphase of a unitary to a chosen number of bits.
Phase kickback
The transfer of a function value into the relative phase of the data register when the target is |−⟩.
Quantum Fourier transform
The unitary basis change |j⟩ → (1/√N)Σ_k e^(2πijk/N)|k⟩ with N=2ⁿ.
Query complexity
The number of oracle calls an algorithm makes, counted separately from other gates.
Superposition
A state that is a weighted sum of basis states, such as (|0⟩+|1⟩)/√2.
