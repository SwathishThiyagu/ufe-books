1.1 Alphabets, strings and formal languages

Input to a program is a finite sequence of symbols from a fixed set. Formal language theory keeps only three objects: an alphabet, a string, and a set of strings. That set is a language. The definitions are small, but they make one question precise: given a string and a language, does the string belong? Every machine in this unit answers that question for selected languages.

Alphabet, string, length

An alphabet is a finite, non-empty set, written Σ. Its members are symbols. Binary input uses Σ={0,1}. A string (some syllabi say word) is a finite sequence of symbols from Σ. The string 010 has symbols 0,1,0 in that order. The empty string ε has no symbols. The length |w| is the number of symbols: |010|=3 and |ε|=0. A symbol is not a string; write '0' for the one-symbol string when needed. Σ* is the set of all finite strings over Σ, including ε; Σ⁺ = Σ*−{ε} is the set of all non-empty strings.

Concatenation joins strings: if x=01 and y=10 then xy=0110, and |xy|=|x|+|y|. Powers repeat: w⁰=ε, w¹=w, wⁿ=wwⁿ⁻¹, so (01)²=0101. The reverse wᴿ lists symbols backwards: (0110)ᴿ=0110. A prefix is an initial part, a suffix is a final part, and a substring is any contiguous part. For 0110, 01 is a prefix, 10 is a suffix, and 11 is a substring but neither prefix nor suffix. Prefix and suffix may be ε or the whole string.

Languages and operations

A language over Σ is any subset of Σ*. It may be finite, such as {00,01,10,11}; infinite, such as {0ⁿ1ⁿ : n≥0}; or one of ∅ and Σ*. A language is a set, not a machine and not a grammar. Those are descriptions of languages.

  • union: L∪M={w : w∈L or w∈M}
  • intersection: L∩M={w : w∈L and w∈M}
  • complement relative to Σ*: L̄=Σ*−L
  • difference: L−M={w : w∈L and w∉M}
  • concatenation: LM={xy : x∈L, y∈M}

Powers are repeated concatenation: L⁰={ε}, Lⁿ=LLⁿ⁻¹ for n≥1. The Kleene star is L* = L⁰ ∪ L¹ ∪ L² ∪ … . The Kleene plus is L⁺ = L¹ ∪ L² ∪ … . Also L⁺=LL*=L*L. Do not write L⁺=L*−{ε} unless ε∉L. For L=∅, every positive power is ∅, while ∅⁰={ε}. Hence ∅*={ε} and ∅⁺=∅.

Membership and counting

The membership problem for L asks: given a string w, decide whether w∈L. This unit builds machines that answer it. A DFA answers with a finite state memory; an NFA allows several moves at once and accepts if one run succeeds. Membership must be decided for every input string, and the procedure must halt; guessing is not a decision.

Σ* is infinite but countable. List strings by length 0,1,2,..., and within each length in dictionary order. Each length has finitely many strings, so the list is countable. The set of all languages over Σ is the power set of Σ*, so it is uncountable. A finite machine or finite description can name only countably many languages. Therefore most languages have no machine at all. The machines in this unit cover a small, useful part of this huge set.

Worked example

Question. Let Σ = {0, 1} and L = {w ∈ Σ* : |w| = 2}. (a) List L. (b) Find L². (c) Find L*. (d) Find the complement of L relative to Σ*.

  1. L has all two-symbol strings over {0,1}. There are 2²=4 choices, so L={00,01,10,11} and |L|=4.
  2. L²={uv:u∈L,v∈L}. There are 4 choices for u and 4 for v, hence 4×4=16 ordered pairs.
  3. Every uv has length 2+2=4. Every length-4 string splits after two symbols into u∈L and v∈L. So L² is all 16 strings of length 4.
  4. The pairs are distinct: if uv=u′v′, the first two symbols give u=u′, then v=v′. So no duplicates.
  5. L* = L⁰ ∪ L¹ ∪ L² ∪ … . L⁰={ε}; L¹ has length 2; L² has length 4; Lⁿ has length 2n. The union is exactly all even-length strings, including ε. An even length 2k splits into k blocks of two; an odd length is not a sum of 2s.
  6. L̄ = Σ*−L is all strings whose length is not 2: ε, every length 1, every length 3, and lengths 4,5,6,... . It is not only odd lengths; 0000 has length 4 and is in L̄.

Answer. L={00,01,10,11}, |L|=4; L² is the 16 strings of length 4; L* is all even-length strings; L̄ is all strings of length not 2.

Exam traps

  • ε is a string of length 0, {ε} is a one-element language, and ∅ is the empty language. They are different objects; ∅*={ε}, not ∅.
  • A symbol is not a string. 0 is a symbol, '0' is a string, and {0} is a language.
  • L⁺ is not always L*−{ε}. If ε∈L then ε∈L⁺. Use L⁺=L¹ ∪ L² ∪ … .
  • Complement is relative to Σ*. For L = all length-2 strings, L̄ also contains ε and length 4, not only odd lengths.
  • L* always contains ε, even when L does not; L⁺ contains ε only when ε∈L.

1.2 Deterministic finite automata (DFA)

A deterministic finite automaton (DFA) is a machine with finite memory. It reads an input string one symbol at a time. Its whole memory is one state, chosen from a finite set. The state stores only what the past has done that can change the future. A DFA is used to check patterns: does a login name end in 01, is the number of a's divisible by 3, does a protocol frame contain the flag 01. It is the simplest full model of a computer with no extra storage.

You need 1.1: alphabets, strings, languages, Σ*, and the empty string ε.

The five parts of a DFA

A DFA is a 5-tuple M = (Q, Σ, δ, q0, F). Each part has one job. The tuple is the machine. The diagram is only a picture of the tuple.

M = (Q, Σ, δ, q0, F)

Q is the finite non-empty set of states; Σ is the input alphabet; δ is the transition function; q0 is the start state; F is the set of final states.

  • Q: finite and non-empty. Each state is one possible value of the machine's memory.
  • Σ: a finite set of input symbols. The input string is a word in Σ*.
  • δ: Q × Σ → Q. Read δ(p, a) = q as: from state p on symbol a, go to state q.
  • q0 ∈ Q: the state before any symbol is read.
  • F ⊆ Q: the final or accepting states. A run that ends in F accepts.

For example, Q = {A, B, C}, Σ = {0, 1}, q0 = A, F = {C} is a DFA once δ is given for all six pairs. A table with one row per state and one column per symbol can list δ. A diagram with circles and labelled arrows is shorthand for the same tuple. Some syllabi call the diagram itself the simplified notation; it is not a separate definition.

One move, no choice

Determinism means exactly one next state for each state and each symbol. δ is a function, not a relation. There is no choice and no ε-move. A DFA cannot change state without reading a symbol from Σ.

A run on w = a1a2…an is the state sequence r0, r1, …, rn. Here r0 = q0 and ri = δ(ri−1, ai) for i = 1 to n. Each ai is one input symbol.

L(M) = { w ∈ Σ* : the run on w ends in a state of F }

L(M) is the language accepted by M; w is an input string; F is the set of final states.

The empty string ε is accepted exactly when q0 ∈ F. Acceptance depends only on the final state of the run. Earlier states do not matter. The extended transition function δ̂, which gives the final state directly, is in 1.3.

A dead state, also called a trap state, is a non-final state that loops to itself on every symbol. Add a dead state whenever a transition is missing. A table with a blank cell is not a DFA, because δ must be total.

Design by remembering the least

To design a DFA, list the questions about the past that change the future. Each answer is a state. Store nothing else. This one rule covers most exam designs.

Strings ending in ab over Σ = {a, b}: remember whether the last symbol was a. Use states for no a yet or last symbol not a, last symbol a, and the final state for the suffix ab.

Strings containing 01 over Σ = {0, 1}: use states for no 0 seen, a 0 seen but no 01 yet, and found 01. The found state is final and loops to itself on 0 and 1.

Number of a's divisible by 3 over Σ = {a, b}: use states 0, 1, 2 for the count modulo 3. On a, move i to (i + 1) mod 3. On b, stay at i. State 0 is both start and final.

Strings with no two consecutive 1s: use states for no 1 yet or last symbol 0, last symbol 1, and a dead state after 11. From the last-symbol-1 state, a 1 goes to the dead state. The first state (no 1 yet, or last symbol 0) is start and final; the last-symbol-1 state is final; the dead state after 11 is not final.

Worked example

Question. Design a DFA over Σ = {0, 1} that accepts exactly the strings ending in 01. Test it on 1001 and 110.

  1. The future depends on the longest suffix of the input that is also a prefix of the target 01. The prefixes are ε, 0, 01.
  2. Name the states by that suffix: A = ε (start), B = 0, C = 01 (final). So Q = {A, B, C}, q0 = A, F = {C}.
  3. Fill each transition by appending the symbol and keeping the longest suffix that is a prefix of 01.
  4. A on 1: suffix 1, longest prefix ε, so go to A. A on 0: suffix 0, so go to B.
  5. B on 0: suffix 00, longest prefix 0, so go to B. B on 1: suffix 01, so go to C.
  6. C on 0: suffix 010, longest prefix 0, so go to B. C on 1: suffix 011, longest prefix ε, so go to A.
  7. Read 1001: A, A, B, B, C. The run ends in C, and C ∈ F, so 1001 is accepted.
  8. Read 110: A, A, A, B. The run ends in B, and B ∉ F, so 110 is rejected.

Answer. The DFA has Q = {A, B, C}, q0 = A, F = {C}, and the six transitions above; it accepts 1001 and rejects 110.

Exam traps

  • A table with missing entries is not a DFA. δ must be total, so add a dead state rather than leaving a cell blank.
  • The start state may itself be final. Then ε is accepted, even though no symbol has been read.
  • A final state still needs all its outgoing moves. Final means accepting, not stopping.
  • Ends in 01 is not the same as contains 01. For ends in, C on 1 goes back to A. For contains, the final state loops on both 0 and 1.
  • ε is not an input symbol of a DFA. Only symbols from Σ appear on arrows.

Analyze A machine has a transition table with one blank cell and no dead state. Is it a DFA under the formal definition? Explain. 3 marks

No. δ must be a total function from Q × Σ to Q. A blank cell means δ is undefined for that state-symbol pair. The run on some strings would have no next state, so the formal definition fails.

Analyze Why can a DFA not count an arbitrary number of a's and then compare with another count? 4 marks

A DFA has only finitely many states. Each state can store only a fixed amount of information, such as a count modulo a fixed number. An arbitrary count needs unbounded memory, so no finite state set can hold it. Extra memory needs a pushdown automaton or a Turing machine.

Understand What is a trap state, and when do you add one? 2 marks

A trap state is a non-final state that loops to itself on every input symbol. Add one when a transition would otherwise be missing, so that δ becomes total.

1.3 Transition diagrams, tables and extended transition function

A DFA is easy to draw as a picture and easy to write as a table. The picture is a transition diagram: circles for states, an arrow into the start state, double circles for final states, and labelled edges for moves. The table has one row per state and one column per symbol. To talk about a whole string, not just one symbol, we extend the transition function to δ̂. It answers the question 'where do I finish after reading this string?' and gives the formal definition of the language accepted by the machine. Compilers, hardware controllers and text search use the same table.

You need: 1.1 for strings and languages, and 1.2 for the DFA model.

Transition diagram and transition table

A transition diagram is a directed graph. Each state is a circle. The start state q₀ has a short incoming arrow with no source. Each final state has a double circle. For each state q and symbol a, a directed edge goes from q to δ(q, a) and is labelled a. If two symbols cause the same move, draw two parallel edges, one per symbol. Some books combine them as one edge with labels separated by commas; both mean the same.

A transition table gives the same facts in rows. One row per state, one column per symbol. The entry in row q and column a is the state δ(q, a). Mark the start state with → and each final state with *. A DFA table has exactly one entry in every cell.

The extended transition function δ̂

δ reads one symbol. A string contains many symbols. Define δ̂ (some books write δ*) from states × Σ* to states. It says: δ̂(q, ε) = q, and δ̂(q, wa) = δ(δ̂(q, w), a). Here q is a state, w is a string, a is a symbol, ε is the empty string, and δ is the one-step transition function.

δ̂(q, ε) = q; δ̂(q, wa) = δ(δ̂(q, w), a)

q is a state; w is a string; a is a symbol; ε is the empty string; δ is the one-step transition function.

The second equation peels the last symbol a. To process wa, first process the prefix w, then take one more step on a. Reading a string a₁a₂...aₙ from left to right gives δ(...δ(δ(q, a₁), a₂)..., aₙ).

The language accepted by M is L(M) = { w ∈ Σ* : δ̂(q₀, w) ∈ F }.

L(M) = { w ∈ Σ* : δ̂(q₀, w) ∈ F }

Σ is the alphabet; q₀ is the start state; F is the set of final states; δ̂ is the extended transition function.

  1. Claim: δ̂(q, xy) = δ̂(δ̂(q, x), y) for all strings x and y.
  2. Base: |y| = 0, so y = ε. δ̂(q, xε) = δ̂(q, x) = δ̂(δ̂(q, x), ε).
  3. Step: assume the claim for y. Then δ̂(q, x(ya)) = δ̂(q, (xy)a) = δ(δ̂(q, xy), a) = δ(δ̂(δ̂(q, x), y), a) = δ̂(δ̂(q, x), ya).

Tracing a string column by column

To compute δ̂(q₀, w), write the current state above each prefix of w. Start with q₀ for prefix ε. For each new symbol a, look up the row of the current state and the column a. Move to that entry. After the last symbol, the current state is δ̂(q₀, w). Accept exactly when this state is in F.

The figure shows δ̂(A, 1001). The rows are prefixes, not separate runs. The last row gives C, a final state, so 1001 is accepted.

For 110: A on ε, A on 1, A on 11, then B on 110. B is not final, so 110 is rejected. This is the whole decision procedure for a DFA: one pass, left to right, no backtracking.

Worked example

Question. For the DFA with states A, B, C, start state A, final state C, and transitions δ(A,0)=B, δ(A,1)=A, δ(B,0)=B, δ(B,1)=C, δ(C,0)=C, δ(C,1)=C, compute δ̂(A, 1001) and δ̂(A, 110). Decide whether each string is accepted.

  1. δ̂(A, ε) = A.
  2. δ̂(A, 1) = δ(A, 1) = A.
  3. δ̂(A, 10) = δ(A, 0) = B.
  4. δ̂(A, 100) = δ(B, 0) = B.
  5. δ̂(A, 1001) = δ(B, 1) = C. C is final, so 1001 is accepted.
  6. For 110: δ̂(A, ε)=A; δ̂(A, 1)=δ(A, 1)=A; δ̂(A, 11)=δ(A, 1)=A; δ̂(A, 110)=δ(A, 0)=B. B is not final, so 110 is rejected.

Exam traps

  • δ takes one symbol; δ̂ takes a whole string. Never write δ(q, w) for a string w.
  • The definition δ̂(q, wa) = δ(δ̂(q, w), a) peels the last symbol in the equation, but the computation still reads the string from left to right.
  • In a DFA transition table every entry is exactly one state. A set of states appears only for an NFA, in the next chapter.
  • Two parallel edges labelled with different symbols and one edge labelled with both symbols mean the same machine. Use the drawing style your exam follows.

1.4 Nondeterministic finite automata (NFA)

A nondeterministic finite automaton (NFA) is a finite-state machine that may have zero, one or many moves on the same input symbol. It accepts a string when at least one possible run ends in a final state. This freedom makes NFAs compact for patterns such as “the string contains 01” or “the third symbol from the right is 1”. They are used in text search, lexical analysers and regular-expression engines. The cost is that a run is a specification of allowed choices, not a step-by-step program. A DFA is the deterministic cousin, with exactly one move per symbol.

You need: 1.2 Deterministic finite automata for the state idea, and 1.3 Transition diagrams, tables and extended transition function for reading a transition table.

What changes from a DFA

In a DFA, δ(q, a) is one state. In an NFA, δ(q, a) is a set of states. The machine may stay in q, move to another state, or have no move at all. That set is the whole difference.

M = (Q, Σ, δ, q₀, F),  δ: Q × Σ → 2<sup>Q</sup>

Q is the finite set of states; Σ is the input alphabet; q₀ ∈ Q is the start state; F ⊆ Q is the set of final states; δ(q, a) is the set of states the NFA may enter from q on symbol a; 2Q is the power set of Q, the set of all subsets of Q.

The power set contains every subset of Q, including Q itself and the empty set. So δ(q, a) = ∅ is a legal entry. It means no move, not an error. A state may also have no outgoing arrow for a symbol.

In a table, every cell is a set. The figure shows q0 looping on 0 and 1 and also having an arrow to q1 on 1. On input 1 from q0 the machine may stay in q0 or jump to q1. That jump is a choice. The next chapter adds ε-moves in 1.5 NFA with epsilon transitions.

Runs and the computation tree

A run is a sequence of states s₀, s₁, …, sₙ. Here s₀ = q₀, and for each input symbol aᵢ, the next state sᵢ satisfies sᵢ ∈ δ(sᵢ₋₁, aᵢ). For input w = a₁a₂…aₙ, the NFA accepts w if some run has sₙ ∈ F. One accepting run is enough.

Draw all runs together as a computation tree. The root is q₀. Each level reads one input symbol. A state q at one level gets a child for every state in δ(q, a) at the next level.

  1. Put the start state q₀ at the root.
  2. For each input symbol a, give every state q in the current level a child for each state in δ(q, a).
  3. After the last symbol, look at the leaves. Accept if any leaf is in F. Reject if no leaf is in F.

A leaf may have no children when δ(q, a) = ∅. That branch dies. A dead branch does not reject the string by itself, because another branch may still reach a final state. The extended transition function on sets is δ̂(P, a) = ⋃q ∈ P δ(q, a), where P is a set of states and ⋃ is set union.

Designing an NFA: make a guess

Nondeterminism is often called perfect guessing. The machine guesses the right moment to jump to a new state. It is a specification of allowed choices, not a program that flips coins. All choices are explored at once in the computation tree.

  • Strings containing 01 over {0, 1}: use q0 for “no 01 yet”, q1 for “saw a 0 waiting for 1”, and q2 final for “saw 01”. Set δ(q0, 0) = {q0, q1}, δ(q0, 1) = {q0}, δ(q1, 1) = {q2}, δ(q2, 0) = δ(q2, 1) = {q2}, and other entries ∅. The move to q1 on 0 guesses that this 0 starts the 01.
  • Strings ending in ab over {a, b}: q0 loops on a and b; on a it may also go to q1. From q1, b goes to q2 final. Set δ(q0, a) = {q0, q1}, δ(q0, b) = {q0}, δ(q1, b) = {q2}, δ(q1, a) = ∅, δ(q2, ·) = ∅. The jump guesses the last a.
  • The third symbol from the right is 1: use the figure. q0 loops on 0 and 1, and on 1 it may also jump to q1. Then q1 goes to q2 on any symbol, and q2 goes to q3 final on any symbol. The jump guesses that the current 1 is third from the right. A wrong guess dies; another run may survive.

Some syllabi write “non-deterministic finite automaton”. NFAs are no stronger than DFAs: every NFA language is also a DFA language. The subset construction in 1.6 Equivalence of NFA and DFA proves it. NFAs are often smaller and easier to design.

Exam traps

  • δ(q, a) is a set. Writing q2 instead of {q2} is wrong, and writing a blank instead of ∅ is wrong.

1.5 NFA with epsilon transitions

A real machine does one thing at a time. A design is easier to write if the machine may also switch state without reading a symbol. That switch is the ε-transition: an edge labelled ε that consumes no input. It lets us glue two small automata together, or drop in a sub-machine for a regular expression, without matching symbols at the joint. This chapter defines the ε-NFA, the ε-closure needed to run one, and the recipe that deletes every ε-edge without changing the language accepted.

You need: 1.4 NFA and the extended transition function from 1.3.

An edge that reads nothing

An ε-NFA is a five-tuple (Q, Σ, δ, q0, F) just like an NFA, with one change: the transition function also accepts the symbol ε.

δ: Q × (Σ ∪ {ε}) → 2Q

Q is the finite set of states; Σ is the input alphabet; q0 is the start state; F ⊆ Q is the set of final states; 2Q (the power set of Q) is the set of all subsets of Q, because δ returns a set of states, possibly empty.

ε is not a letter of Σ. δ(p, ε) = {q} means: while sitting in p, jump to q without looking at the input. Some syllabi call these finite automata with ε-moves.

Why allow it?

  • Glueing: two small machines joined by one ε-edge behave as a sequence, with no need to copy states or align symbols at the joint.
  • Patterns: when a regular expression is turned into a machine mechanically, ε-edges let each operator be fitted on without rewriting the parts (see Unit 2).
  • Short descriptions: a language that needs many states without ε may need very few with it.

Acceptance does not change. The machine reads the whole string, may take ε-edges at any moment, and accepts if at least one run ends in F. ε-edges only add paths; they never take input away.

The ε-closure

Before the first symbol is read, the machine is not in one state — it is in every state it can slide into for free. That set is the ε-closure.

ECLOSE(q) = { p ∈ Q | p is reachable from q by a path of ε-edges only }

q is a state; a path of zero edges is allowed, so q always belongs to ECLOSE(q). For a set S, ECLOSE(S) = ∪ ECLOSE(q) over all q in S.

  1. Put q in a set; that is the seed.
  2. Pick any state in the set and add every state joined to it by one ε-edge.
  3. Repeat until no new state appears; the set is ECLOSE(q).
  4. For a set of states, take the union of the closures of its members.

Closure is one-way reachability, never symmetric. In the figure, ECLOSE(q0) = {q0, q1} but ECLOSE(q1) = {q1}, because that ε-edge points from q0 to q1 only.

Running it: δ̂ with closures

δ̂(q, ε) = ECLOSE(q)        δ̂(q, wa) = ECLOSE( ∪ δ(p, a) ) over p ∈ δ̂(q, w)

q is a state, w a string, a a single symbol, δ̂(q, w) the set of states reachable after reading w, and δ(p, a) the set of states reached from p by one non-ε edge labelled a. The union runs over every state p in the current set; the outer ECLOSE adds the free moves.

  1. Start with S = ECLOSE(q0).
  2. For the next symbol a, collect the a-moves out of every state in S.
  3. Take the ε-closure of that collection; this is the new S.
  4. Repeat for every symbol, then accept if S ∩ F is not empty.
L(M) = { w ∈ Σ* | δ̂(q<sub>0</sub>, w) ∩ F ≠ ∅ }

Σ* is the set of all strings over Σ; the condition says at least one state in the final set is accepting.

Removing the ε-edges

Any ε-NFA M = (Q, Σ, δ, q0, F) can be rewritten as an ordinary NFA M' = (Q, Σ, δ', q0, F') with no ε-edges and the same language.

  • δ'(q, a) = δ̂(q, a) for every state q and symbol a. One symbol of the new machine does the work of an ε-slide, a symbol, and another ε-slide.
  • F' = { q ∈ Q | ECLOSE(q) ∩ F ≠ ∅ }. A state is final in M' if the old machine could reach an old final state from it without reading input.
  • States and start state stay the same; only edges and finals change. δ'(q, a) may be empty.

The consequence is the headline result: ε-NFAs accept exactly the regular languages. They add convenience, not power. Making M' deterministic is the subset construction of 1.6.

1.6 Equivalence of NFA and DFA: subset construction

An NFA can have many runs on one input. The subset construction turns that choice into bookkeeping: after reading a string, the DFA remembers the set of all NFA states any run could be in. One deterministic state stands for a whole set. This removes nondeterminism without changing the accepted language. Compilers and text tools use it to turn pattern NFAs into fast DFA scanners. It also proves the central result that nondeterministic and deterministic finite automata accept exactly the same languages.

You need: 1.4 for NFA runs and 1.5 for ε-closures.

One DFA state holds a set

After reading a prefix, an NFA may sit in many states at once. The subset construction makes that whole set one DFA state. Two runs that end in the same set of NFA states have the same possible futures, so the set is enough memory. The DFA state space is Q_D = 2^{Q_N}, the set of all subsets of the NFA states.

δ_D(S, a) = ECLOSE( ∪_{p ∈ S} δ_N(p, a) )

S is a DFA state, a subset of Q_N; a is an input symbol; δ_N(p, a) is the set of NFA states p can enter on a; the union collects every state any run in S can reach; ECLOSE adds states reachable by ε-transitions; δ_D(S, a) is the next DFA state. ECLOSE(∅) = ∅.

The start state is q_D0 = ECLOSE({q₀}). The final states are F_D = { S ⊆ Q_N : S ∩ F_N ≠ ∅ }. A set is final when it contains at least one final NFA state, because the NFA accepts if some run accepts.

Build only what you can reach

Do not write all 2^n subsets. Start from q_D0 and follow transitions; only reachable subsets become states. This keeps the table small for real machines.

  1. Find ECLOSE({p}) for every NFA state p, or compute ECLOSE on demand.
  2. Set q_D0 = ECLOSE({q₀}) and mark it unprocessed.
  3. Take an unprocessed subset S. For each symbol a in Σ, compute T = ECLOSE(∪_{p∈S} δ_N(p, a)).
  4. Add the transition S --a--> T. If T is new, add it as a DFA state, including T = ∅ when it is reached.
  5. Repeat until no unprocessed subset remains. Mark S final if S ∩ F_N ≠ ∅.

Proof and worst case

Claim: for every string w, δ̂_D(q_D0, w) = δ̂_N(q₀, w), where q_D0 = ECLOSE({q₀}) and δ̂_N(q₀, w) is the set of all NFA states reachable from q₀ by some run reading w. Base: w = ε. δ̂_D(q_D0, ε) = q_D0 = ECLOSE({q₀}) = δ̂_N(q₀, ε). Step: assume the claim for w. For symbol a, δ̂_D(q_D0, wa) = δ_D(δ̂_D(q_D0, w), a) = ECLOSE(∪_{p∈δ̂_N(q₀,w)} δ_N(p, a)) = δ̂_N(q₀, wa). The middle equality is the definition of δ_D; the last is one more NFA step followed by ε-closure.

So a string w is accepted by D exactly when δ̂_D(q_D0, w) meets F_N, which happens exactly when some NFA run on w ends in F_N. Hence L(D) = L(N). Equivalence means equal languages, not equal state counts.

Q_D has at most 2^n subsets, so D has at most 2^n states when N has n. This bound is achievable: some n-state NFAs need 2^n DFA states, so the blow-up is real, not loose counting.

Some syllabi first eliminate ε-transitions, then run subset construction on the ε-free NFA. The formula above folds ε-closure into each step, so it gives the same DFA. Reducing the result goes to 1.7.

1.7 Minimization of DFA: table-filling algorithm

Two DFA states are equivalent when no input string can tell them apart. If a string is accepted from one state and rejected from the other, that string distinguishes the pair. The table-filling algorithm finds every distinguishable pair, round by round, starting from pairs with one final and one non-final state. The unmarked pairs then merge, giving a DFA with no redundant states. This matters because the minimal DFA is the cleanest machine for a regular language, and it is unique up to renaming. Tools that build scanners, pattern matchers and protocol checkers use this reduction to keep state tables small.

You need 1.3 for the extended transition function δ̂ and 1.2 for DFA notation; 1.6 gives the wider idea of equivalent machines.

Equivalent states and distinguishability

Fix a DFA M = (Q, Σ, δ, q0, F). Q is the finite state set, Σ is the input alphabet, δ: Q × Σ → Q is the transition function, q0 is the start state, and F ⊆ Q is the set of final states. For a state p and a string w, δ̂(p, w) is the state reached from p after reading all of w. This is the extended transition function from 1.3.

Two states p and q are distinguishable if some string w ∈ Σ* sends exactly one of δ̂(p, w) and δ̂(q, w) into F. That w is a distinguishing string. If no such string exists, p and q are equivalent, written p ≡ q. Equivalently, p ≡ q iff for every w ∈ Σ*, δ̂(p, w) ∈ F ⇔ δ̂(q, w) ∈ F.

The empty string is a valid test: it separates p and q when one is final and the other is not. Longer strings test the future. The relation ≡ is reflexive, symmetric and transitive, so it splits Q into classes. States in one class accept exactly the same strings: for every w, either both end in F or neither does. Merging a class into one state therefore cannot change the language.

The table-filling algorithm

The table-filling algorithm uses a triangular table. Each unordered pair {p, q} with p ≠ q appears once. A mark means 'these two are distinguishable'.

  1. Delete every state not reachable from q0 by any string.
  2. Mark every pair with one final and one non-final state. These are distinguished by the empty string.
  3. Repeat a full pass over all unmarked pairs. For pair (p, q) and each a ∈ Σ, look at (δ(p, a), δ(q, a)). If that pair is already marked, mark (p, q). A pass that adds no mark stops the algorithm.
  4. After stopping, all unmarked pairs are equivalent. Merge them into classes.

Why it works: pass 0 handles distinguishing strings of length 0. If pass k−1 has marked every pair separated by a string of length at most k−1, then pass k marks a pair separated by a first symbol a followed by such a string. When a pass adds nothing, no finite string can separate any remaining pair. Some syllabi describe the inner test as distinguishing one string from another.

Quotient DFA and minimality

Build the quotient DFA from the classes. The start state is [q0], the class containing q0. For a class [p] and symbol a, set δ'([p], a) = [δ(p, a)]. This is well defined: if p ≡ q, then δ(p, a) ≡ δ(q, a), otherwise a would distinguish p and q. A class is final if it contains a final state. All states in a class agree on finality.

Let Q_min be the set of classes. The quotient has |Q_min| states, and it accepts the same language as M. It has no pair of equivalent states, so it is minimal. Any minimal DFA for the same language is isomorphic to it: same state count, same transitions after renaming states. This is the uniqueness statement. The classes are exactly the right-invariant equivalence classes of the Myhill-Nerode relation: two strings x and y are equivalent when no continuation z makes xz accepted and yz rejected. The full theorem and proof are in Unit 2; here you only need the algorithm and the merge.

  2. List the unordered pairs once: q0q1, q0q2, q0q3, q1q2, q1q3, q2q3.
  3. Pass 0: F = {q0,q3}. Mixed pairs are marked: q0q1, q0q2, q1q3, q2q3. The pairs q0q3 and q1q2 stay unmarked because both states in each pair are both final or both non-final.

  6. Classes: A = {q0,q3}, B = {q1}, C = {q2}. Quotient transitions: A on a → B, A on b → A; B on a → C, B on b → B; C on a → A, C on b → C. Start state is A; final state is A.

Answer. The minimal DFA has 3 states: A={q0,q3} (start and final), B={q1}, C={q2}; it accepts exactly strings whose number of a's is divisible by 3.

Exam traps

  • Delete unreachable states first. A final state that no input can reach would otherwise survive as an extra class and inflate the minimal DFA.
  • Do not stop after pass 0 or after one loop. Run until a complete pass marks nothing new; otherwise some equivalent-looking pairs stay wrongly merged.
  • Two states that are both final, or both non-final, can still be distinguishable. Finality is only the length-0 test; later symbols can separate them.
  • Always treat δ(p,a) and δ(q,a) as an unordered pair when checking marks. The pair q2q0 is the same as q0q2, and order must not hide a mark.
  • A merge is valid only when every symbol keeps the pair inside one class. If δ(p,a) and δ(q,a) fall in different classes, p and q were distinguishable and must not be merged.

1.8 Moore and Mealy machines

A Moore machine prints a symbol every time it enters a state. A Mealy machine prints a symbol every time it takes a transition. Both are transducers: they turn an input string over Σ into an output string over Δ, and neither has final states. They matter because many devices must produce output, not just accept or reject: a vending machine returns change, a traffic light changes lamps, a compiler scanner turns characters into tokens. The two models are equally powerful and convert into each other.

You need: DFA and transition diagrams and δ̂.

Moore machine: print on the state

A Moore machine is a DFA with output attached to states. When the machine enters a state, it prints that state's symbol immediately.

M = (Q, Σ, Δ, δ, λ, q₀)

Q is the finite set of states; Σ is the input alphabet; Δ is the output alphabet; δ: Q × Σ → Q is the transition function; λ: Q → Δ is the output function; q₀ ∈ Q is the start state.

There is no set of final states. Every input string is processed fully and produces an output string. The start state prints before any input symbol is read.

λ(q₀) λ(q₁) … λ(qₙ)

qᵢ is the state after reading the first i input symbols a₁…aₙ, with qᵢ = δ(qᵢ₋₁, aᵢ). The output has n + 1 symbols for an input of n symbols.

That extra first symbol is part of the definition. If a problem wants exactly n output symbols, it usually says to ignore the first printed symbol.

Mealy machine: print on the edge

A Mealy machine is a DFA with output attached to transitions. When the machine reads a symbol and moves, it prints the output written on that edge.

M = (Q, Σ, Δ, δ, λ, q₀), λ: Q × Σ → Δ

Q, Σ, Δ, δ and q₀ mean the same as for a Moore machine; λ now takes a state and an input symbol and returns the output symbol printed on that transition.

An edge is labelled a / b: read input symbol a, print output symbol b, and go to the next state. There is no output for the start state because no transition has been taken yet.

For an input of n symbols, a Mealy machine prints exactly n symbols. It has no final states either.

Converting one into the other

Moore to Mealy is direct. Move each state's output onto every transition that enters that state.

λ′(q, a) = λ(δ(q, a))

λ′ is the Mealy output function; q is the current state; a is the input symbol; δ(q, a) is the next Moore state; λ of that next state is the symbol printed on the transition. This conversion loses the first printed symbol, so the Mealy output equals the Moore output with λ(q₀) removed.

Mealy to Moore needs more states. A Moore state must remember both the old Mealy state and the output printed on entering it.

  1. For every Mealy state q and every output symbol x that some transition prints on entering q, make a Moore state (q, x). Its Moore output is x.
  2. Add a Moore transition from (p, r) on input a to (q, x) when the Mealy transition is p on a to q printing x.
  3. Use start state (q₀, c), where c is a chosen initial output, often 0, because no transition entered q₀.
  4. Keep only reachable states. The construction may create more states than the Mealy machine, but the two print the same symbols in the same order once you allow for that leading symbol: Moore output = c followed by the Mealy output.

The two models are equally powerful. A Mealy machine can sometimes use fewer states because the last printed symbol is carried on the edge, not stored in a state.

1.9 Two-way finite automata

A two-way finite automaton is a DFA whose read head may step left as well as right. The input sits on a tape with a left end marker ⊢ and a right end marker ⊣, so the head cannot fall off the ends. The extra freedom feels powerful, yet it buys nothing: two-way and one-way machines accept exactly the same languages, the regular ones. The proof idea, the crossing sequence, survives in space-bounded complexity and in streaming lower bounds. Only a few universities teach the topic.

You need: DFA (1.2), NFA (1.4) and the transition notation of 1.3.

The machine, the tape and the markers

A two-way finite automaton is the tuple (Q, Σ, δ, q₀, F): Q is a finite set of states, Σ the input alphabet, q₀ the start state, F ⊆ Q the final states. The new part is the transition function δ: Q × (Σ ∪ {⊢, ⊣}) → Q × {L, R}. It takes a state and a tape symbol and returns a next state plus a direction, L for one cell left, R for one cell right. The function may be partial: when δ is undefined for the current state and tape symbol, the machine halts. For a nondeterministic 2FA the transition function becomes a relation, δ ⊆ Q × (Σ ∪ {⊢, ⊣}) × Q × {L, R}, so several moves may be possible from one configuration; the machine accepts if some run halts in F.

The input string of length n occupies cells 1 to n of a tape. Cell 0 holds the left end marker ⊢, cell n+1 the right end marker ⊣. The markers are not in Σ. The head starts on ⊢. A legal 2FA never moves left from ⊢ or right from ⊣; if δ is undefined for the current state and marker, the run halts. Unlike a DFA, a 2FA may read the same cell many times, so it keeps no count of input consumed.

A configuration is a state together with a head position. The machine accepts when a run halts in a state of F. A deterministic 2FA may also loop forever on some input; a loop is neither acceptance nor rejection.

Why two-way movement adds no power

Theorem. Deterministic two-way FAs, nondeterministic two-way FAs and ordinary DFAs accept exactly the same class: the regular languages. Every DFA is a 2FA that never moves left, so one direction is free. The other direction is the surprise: every 2FA can be simulated by a DFA.

The reason is the crossing sequence. Cut the tape between two cells and watch the head cross that cut. The crossing sequence is the ordered list of states in which the head crosses, left to right or right to left. For a fixed machine only finitely many such lists exist. A DFA can remember, cut by cut, which lists are possible, and that finite record decides acceptance.

The simulating DFA can be exponentially larger than the 2FA: an n-state 2FA may need a DFA with exponentially many states (roughly 2cn for some constant c). That blow-up is why the proof is skipped in this unit.

Worked example

Question. Using the machine in the figure (states q0, q1, q2, qf, d), trace the inputs aba and abb on the tape, give the state and head position after each move, and state the accepted language. The input alphabet is {a, b}.

  1. aba. Tape ⊢ a b a ⊣. δ(q0, ⊢) = (q1, R): the head moves to cell 1, holding a.
  2. q1 loops on a and b with R. The head crosses a, b, a and lands on ⊣, still in q1.
  3. δ(q1, ⊣) = (q2, L): the head steps back onto the last symbol a.
  4. δ(q2, a) = (qf, R). qf ∈ F, so aba is accepted.
  5. abb. Tape ⊢ a b b ⊣. The same run reaches q2 with the head on the last symbol, now b.
  6. δ(q2, b) = (d, R), and d ∉ F. abb is rejected.
  7. Only the last cell matters, so L = { w ∈ {a, b}⁺ : w ends in a }. The empty input ⊢ ⊣ leaves the head in q2 on ⊢, a non-final halt, so it is rejected too.

Answer. aba is accepted into qf, abb is rejected into d, and the machine accepts exactly the non-empty strings over {a, b} that end in a.

Exam traps

  • Two-way movement adds no power. Writing that a 2FA accepts aⁿbⁿ is the classic wrong answer.
  • Two-way is not two-tape. One tape, one head; only the direction is free.
  • δ may be partial. If the head is on ⊢ or ⊣ in a state with no move, the run halts there; a legal machine either has the move or halts and never walks off the tape.
  • The equivalent DFA exists but may be exponentially larger, so no small DFA is promised.
  • A deterministic 2FA can loop. Not rejected yet is not accepted; acceptance needs halting in F.

Takeaways

  1. An alphabet is a finite set of symbols, a string is a finite sequence of them, and a language is just a set of strings.
  2. A DFA keeps exactly one state, which is all the memory it needs about the past to decide the future.
  3. Acceptance is defined with the extended transition function: w ∈ L(M) exactly when δ̂(q₀, w) ∈ F.
  4. An NFA is a convenient way to write a pattern; its many runs are all simulated at once by the subset construction.
  5. ε-transitions add no accepting power, because ε-closures can be computed and the ε-NFA converted to a DFA.
  6. Two states are equivalent when no string tells them apart, and the table-filling algorithm finds every distinguishable pair.
  7. A Moore machine prints on entering a state, a Mealy machine prints on taking a transition, and each can be converted to the other.
  8. A two-way head looks more powerful but still recognises only regular languages.
  9. Every question in this unit is a variation of one question: does this finite-memory machine accept this string?

The string uv formed by writing the symbols of v after those of u.
Configuration
A snapshot of a machine during a run, here simply its current state.
Deterministic finite automaton
A five-part machine with one next state for every state and input symbol.
Distinguishable states
Two states for which some string leads exactly one of them to a final state.
Empty string
The unique string of length 0, written ε or λ.
Equivalent states
Two states that no string can tell apart; they can be merged.
Extended transition function
δ̂(q, w), the state reached after reading the whole string w from q.
Kleene plus
Σ⁺, the set of all non-empty strings over Σ.
Kleene star
Σ*, the set of all strings over Σ including ε.
Language
A set of strings over some alphabet; equivalently a subset of Σ*.
Length of a string
The number of symbols in the string, written |w|.
Mealy machine
A transition-output machine whose output depends on the current state and the input symbol.
Minimal DFA
The DFA for a language with the fewest states, unique up to renaming of states.
Moore machine
A state-output machine whose output at each step depends only on the state entered.
Nondeterministic finite automaton
A finite automaton whose transition rule may give several next states.
Regular language
A language accepted by some finite automaton.
String
A finite sequence of symbols from some alphabet.
Subset construction
The method that turns an NFA into a DFA whose states are sets of NFA states.
Symbol
A single object belonging to an alphabet, such as the character a.
Transition function
The rule δ giving the next state (DFA) or set of next states (NFA).
Two-way finite automaton
A finite automaton whose head may also move left and re-read earlier input.
ε-closure
The set of states reachable from a state using only ε-transitions, including the state itself.
ε-transition
A move that changes state without consuming an input symbol.
