4.1 Meaning representation and first-order logic

A computer cannot reason over English words directly. It needs a sentence's meaning written in a formal language with exact syntax and exact semantics. Such a language is a meaning representation, and first-order logic is the standard one. Each sentence maps to a logical form. Inference is now a search over those forms rather than over English. In full FOL that search is not guaranteed to halt, which is why deployed systems use restricted languages where it does. The same machinery drives question answering over databases and ontology reasoners.

You need: Unit 1 on levels of language analysis; Unit 3 on syntax trees helps but is not required.

What a meaning representation must do

A sentence is only a string of words until its meaning is stored in a form a machine can compute with. That form is a meaning representation (MR): a formal language with fixed syntax and fixed semantics. Semantic analysis maps each sentence to one expression of it, the sentence's logical form. Inference works on logical forms, never on English.

  • Verifiability: decide against a database whether the expression is true or false.
  • Unambiguity: one expression, one reading; word-sense and attachment ambiguity settled before mapping.
  • Canonical form: sentences that mean the same get the same form. 'Gita sold the car to Ravi' and 'Ravi bought the car from Gita' should map to one predicate with the same argument slots, say Sell(Gita, car, Ravi), possibly linked by meaning postulates between buy and sell. The equivalence comes from that shared form, not from the connectives.
  • Inferencing: new expressions follow from old ones, so questions never stored can still be answered.
  • Expressiveness: can state every, some, negation, time without losing distinctions.

The requirements pull against each other. A richer language says more but makes inference slower; a poorer one is fast but cannot express 'every' or 'some'. First-order logic (FOL) is the usual compromise, and most semantic parsers output it or a close variant.

First-order logic: terms, predicates, quantifiers

FOL builds expressions from a small vocabulary. Constants name fixed individuals: Ravi, book1, chennai. Variables are stand-ins: x, y, e. A function takes terms and returns a term, as in FatherOf(Ravi). Constants, variables and function applications are terms; a term denotes an object, never a truth value.

Predicates take terms and return a truth value: Student(Ravi), Reads(Ravi, book1). A predicate applied to the right number of terms is an atomic formula. Atomic formulae combine with the connectives ¬ (not), ∧ (and), ∨ (or), → (implies) and ↔ (if and only if), with brackets fixing grouping.

Quantifiers bind variables. ∀x means 'for every object x in the domain'; ∃x means 'there is at least one'. The formula a quantifier attaches to is its scope. An occurrence inside its own quantifier's scope is bound, otherwise free. In ∀x(Student(x) → Reads(x, y)) the x is bound and the y is free. A formula with a free variable is not a sentence: it is true or false only once each free variable is given a value by a variable assignment; without an assignment it has no truth value. A formula with no free variables is closed, or a sentence.

Models, interpretation and entailment

Syntax alone is empty; meaning comes from a model M = (D, F). D is the non-empty domain of objects. F is the interpretation function: it sends each constant to one element of D, each n-ary predicate to a set of n-tuples from D, and each function symbol to a mapping from n-tuples to elements.

Take D = {Ravi, Meera, book1}, with F(Student) = {Ravi, Meera} and F(Reads) = {(Ravi, book1), (Meera, book1)}. Reads is a set of 2-tuples. An atomic formula is true exactly when its argument tuple lies in the relation.

M satisfies φ, written M ⊨ φ, when φ comes out true under F. Entailment: KB ⊨ φ when every model that satisfies the knowledge base KB also satisfies φ. That is the formal 'φ follows from what we know'. The direction matters — KB ⊨ φ does not give φ ⊨ KB. A formula true in every model is valid; one true in at least one model is satisfiable.

Restricted quantifiers, events and description logics

English quantifiers are restricted. 'Every student reads a book' quantifies over students, not over everything. Write the restriction with →:

∀x(Student(x) → ∃y(Book(y) ∧ Reads(x, y)))

Student(x) means x is a student; Book(y) means y is a book; Reads(x, y) means x reads y; → is implication and ∧ is conjunction.

Inside ∀ use →; inside ∃ use ∧. Writing ∀x(Student(x) ∧ Reads(x, book1)) says every object in the whole domain is a student who reads book1. Writing ∃y(Book(y) → Reads(Ravi, y)) is nearly always true, because any non-book satisfies it for free.

Verbs need arguments beyond their surface ones. Davidson's event representation adds a hidden event variable. In Davidson's original form the verb keeps its own arguments: 'Meera read a book in the library on Monday' becomes ∃e(Read(e, Meera, book1) ∧ Place(e, library) ∧ Time(e, Monday)). A fully separated variant, the neo-Davidsonian style, splits them into Reader(e, Meera) and Object(e, book1). Either way each modifier is a separate conjunct, so adding 'slowly' adds Slowly(e) without changing any predicate's arity. This is the bridge to semantic roles, see 4.6.

Description logics (DL) are decidable fragments of FOL used for ontologies. They split the vocabulary into concepts (classes, like unary predicates) and roles (binary relations). Schema statements go in the TBox; facts about individuals go in the ABox. The key inference is subsumption: Student ⊑ ∃reads.Book says every student reads at least one book, and a reasoner checks whether one concept is subsumed by another. Only a few syllabi teach this in detail; know the vocabulary and this example.

Worked example

Question. Represent 'Every student reads a book' in first-order logic. Domain D = {Ravi, Meera, Gita, book1, book2}. Student = {Ravi, Meera}; Book = {book1, book2}; Reads = {(Ravi, book1), (Meera, book2)}. (a) Write the formula. (b) Show that the model satisfies it. (c) Change Reads to {(Ravi, book1)} and say why the formula is false. (d) Explain why ∃y(Book(y) ∧ ∀x(Student(x) → Reads(x,y))) entails the original formula but the original does not entail it.

  1. (a) ∀x(Student(x) → ∃y(Book(y) ∧ Reads(x, y))).
  2. (b) x = Ravi: Student(Ravi) true, so find y. y = book1: Book(book1) true and (Ravi, book1) ∈ Reads. Satisfied. x = Meera: y = book2 works. x = Gita, book1, book2: Student false, so each implication is true with no obligation. 2 of 2 students have a book, so M ⊨ formula.
  3. (c) Reads = {(Ravi, book1)}: x = Ravi still holds. For x = Meera, Student(Meera) is true but no y gives Book(y) ∧ Reads(Meera, y), so that implication is false and the ∀ fails. 1 of 2 students has a book.
  4. (d) The swapped form needs one book read by every student: 0 books qualify here. But if some book b is read by all students, every student reads b, so the original holds. Hence the swapped form entails the original, and not the reverse.

Answer. ∀x(Student(x) → ∃y(Book(y) ∧ Reads(x,y))); true in the model because 2 of 2 students have a book, false when Reads = {(Ravi, book1)} because only 1 of 2 does, and the swapped form is strictly stronger since 0 books are read by every student.

Exam traps

  • ∀ pairs with → and ∃ pairs with ∧. ∀x(Student(x) ∧ Reads(x, book1)) forces every object in the domain to be a student.
  • ∀x∃y is not ∃y∀x. The first lets the book depend on the student; the second demands one book for everybody.
  • A formula with a free variable is not a sentence. Without a variable assignment it has no truth value.
  • KB ⊨ φ is not φ ⊨ KB. Entailment runs from the knowledge base to the query.
  • True in one model is not valid. Valid means true in every model; satisfiable means true in at least one.

4.2 Syntax-driven semantic analysis

Syntax-driven semantic analysis gives every grammar rule a meaning attachment, so a parse tree computes the sentence's logical form as it combines words. The idea exists because meaning is productive: familiar parts in a new structure still make sense. It is used in database query front ends, question answering, and any system that turns an English sentence into a checkable formula. This chapter shows the attachments, the lambda notation that writes them, and how quantifier scope follows from the same machinery.

You need: Chapter 4.1 for first-order logic, and Unit 3 for CFG rules and parse trees.

Meaning follows the rule

Compositionality says the meaning of a sentence is a function of the meanings of its parts and the way they combine. Syntax-driven semantic analysis makes the second half precise: every context-free grammar rule carries a semantic attachment. The rule-to-rule hypothesis states that for every syntactic rule there is one semantic rule. Lexical rules give base meanings to words; phrase-structure rules say how child meanings combine.

A parse tree becomes a recipe. Leaves hold lexical meanings. Each internal node applies the attachment of its rule to the meanings of its children. For rule S → NP VP, the attachment is given below. Here [[X]] is the semantic value of node X.

[[S]] = [[NP]]([[VP]])

[[X]] is the semantic value of node X; [[NP]] is a function that takes the VP meaning and returns a truth value.

The design exists because language is productive. A speaker understands a new sentence by combining familiar words in a familiar structure. Attaching meaning to rules also keeps grammar and semantics aligned: a change in syntax is a change in the combination rule, not a patch to a word list. Semantic features can carry agreement or countability; Unit 3 covers feature structures, so the main work here is done by attachments.

Lambda calculus for attachments

Lambda calculus is the notation for attachments. The term λx.Student(x) means the function that maps an entity x to true when x is a student. The λ binds x inside its body. An occurrence of x is bound if it sits under a λx; otherwise it is free. In λx.P(x,y), x is bound and y is free, so the term still waits for a value for y.

Application writes a function next to its argument: (λx.Student(x))(Ravi). Beta-reduction replaces every bound occurrence of x with the argument.

(λx.φ)(a) → φ[x := a]

φ is the lambda body; a is the argument; φ[x := a] is the result of substituting a for x. Only bound occurrences change.

Types stop nonsense combinations. Let e be the type of an entity and t the type of a truth value. Student is e → t. Every is (e → t) → ((e → t) → t). Reads is e → (e → t), because it first takes the object and then the subject. If f has type A → B and a has type A, then f(a) has type B. Applying a quantifier to an entity is a type error.

  1. Collect the semantic values of the children.
  2. Check that each function's argument type matches.
  3. Apply the function and beta-reduce.
  4. Pass the result to the parent rule.

Quantifiers, scope and the pipeline

Determiners like every and a do not name an entity. They are generalized quantifiers. For a property P and a property Q, the two meanings are below. P is the noun meaning and Q is the verb-phrase meaning.

every(P)(Q) = ∀x(P(x) → Q(x)); a(P)(Q) = ∃y(P(y) ∧ Q(y))

P is the property denoted by the noun; Q is the property denoted by the VP; x and y are bound entity variables.

Quantifier scope is not fixed by surface order. Every student reads a book allows two logical forms. Surface scope: ∀x(Student(x) → ∃y(Book(y) ∧ Reads(x,y))). Inverse scope: ∃y(Book(y) ∧ ∀x(Student(x) → Reads(x,y))). The first says each student may have a different book. The second says one book is read by every student.

A fixed attachment order on a CFG produces one reading. To keep both, a system can use underspecification: store a scope constraint such as every outscopes a, or a outscopes every, without choosing. A later stage resolves the constraint using context. This delays the choice instead of losing it.

The pipeline is parser to parse tree, parse tree to attached meanings, beta-reduction to logical form, then a model checker or database query. Some systems use typed feature grammars, some use categorial grammar, some use dependency-to-logic rules. All share this parser-to-logical-form pipeline.

Exam traps

  • Attach meaning only to words, not to rules: then every student has no combination rule.
  • Apply λy.λx in the wrong order for a transitive verb: reads first wants the object, then the subject. Swapping gives Reads(book, student).
  • Treat quantifier scope as fixed by word order: Every student reads a book also allows one book for all students.
  • Skip type checking: applying a quantifier to an entity is a type error, not a bad style choice.
  • Substitute free variables during beta-reduction: only bound occurrences of the lambda variable change.

4.3 Lexical semantics: word senses and their relations

A word form is the string you write or say, such as bank. A sense is one meaning that form can carry, such as a financial institution or the side of a river. Lexical semantics studies senses and the stable links among them: synonymy, antonymy, hyponymy and meronymy. These links let a computer compare words, choose the right meaning, and answer questions without treating every string as unrelated. Search engines, translators, chatbots and dictionary apps use them. This chapter defines the terms, shows how to test polysemy against homonymy, and gives the standard thesaurus-based similarity formulas.

You need Unit 1 on word forms and morphology; no parsing is needed.

Word forms, lexemes and senses

A lexeme is the abstract vocabulary item behind a set of word forms. The word form bank can realise one lexeme with several related senses, or two lexemes that happen to share a spelling. Sense enumeration lists the distinct meanings separately: bank as a financial institution, bank as the land beside a river, bank as a tilt. The first two are usually homonyms: same form, historically unrelated meanings. Polysemy is one lexeme with related senses, as in head of a person and head of a department; the second extends the first by metaphor.

Three tests separate them. Etymology checks history: common origin points to polysemy; unrelated origin points to homonymy. Relatedness asks whether speakers feel a connection. The zeugma test coordinates both uses under one predicate: The bank was steep and charged fees sounds odd, so the two bank senses are homonyms. She has a good head and a good head for numbers is less odd, so those senses are polysemous. Sense enumeration and these tests matter because a dictionary entry or a word-sense disambiguation model must know whether it is splitting one lexeme or merging two.

Relations between senses

Two senses are synonyms when different word forms express the same meaning in a context: car and automobile, buy and purchase. Absolute synonyms are rare; a synonym need not fit every register or collocation. Antonyms are opposites of three main kinds. Gradable antonyms sit on a scale with middle values: hot/cold, fast/slow. Complementary antonyms leave no middle: alive/dead, true/false. Reversive antonyms name opposite changes: open/close, tie/untie.

Hyponymy is the is-a relation. A hyponym is a more specific sense; its hypernym is the more general sense. Dog is a hyponym of mammal; mammal is the hypernym of dog. Direction matters: dog is not a hypernym of animal. Meronymy is the part-of relation: wheel is a meronym of car, and car is the holonym of wheel. For verbs, troponymy is manner hyponymy: whisper is a troponym of speak because whispering is a way of speaking. Lexical relations link word senses inside a language; conceptual relations link concepts in an ontology and can be language-independent. The same labels often appear in both, but the objects differ.

Thesaurus similarity

A thesaurus such as WordNet is a graph: senses are nodes, and relations are edges. Similarity compares two senses by their position. Path length uses the shortest route between them. Lowest common subsumer (LCS, also least common subsumer) is the deepest node that is a hypernym of both senses. Depth of a node is the number of edges from the root; root depth is 0.

sim_path(s1, s2) = 1 / (1 + d(s1, s2))

d(s1, s2) is the number of edges on the shortest path between senses s1 and s2 in the thesaurus; d = 0 gives similarity 1.

sim_WP(s1, s2) = 2 × depth(LCS(s1, s2)) / (depth(s1) + depth(s2))

LCS is the lowest common subsumer; depth counts edges from the root, with root depth 0.

sim_Res(s1, s2) = IC(LCS(s1, s2)) = −log₂ P(LCS(s1, s2))

P(c) is the probability that a random word occurrence falls under concept c, estimated from a corpus; IC is information content in bits.

sim_Lin(s1, s2) = 2 × IC(LCS(s1, s2)) / (IC(s1) + IC(s2))

IC(s) = −log₂ P(s); the formula rewards a close, informative common subsumer and divides by the information of each sense.

Wu-Palmer is popular because it needs only the tree, not corpus counts. Resnik and Lin need P(c) from a corpus or from sense frequencies. Distributional similarity from nearby words is covered in Unit 5; here the thesaurus supplies the structure.

Exam traps

  • Hyponymy has a direction: dog is a hyponym of animal; animal is the hypernym. Reversing them loses marks.
  • Homonymy is unrelated senses; polysemy is related senses. Use etymology, relatedness and the zeugma test, not spelling alone.

4.4 WordNet, FrameNet and lexical knowledge networks

WordNet and FrameNet turn lexical knowledge into reusable networks. WordNet links word senses by semantic relations: car is a hyponym of vehicle. FrameNet links predicate senses to the roles they take: buy evokes a commerce frame with a buyer, goods and seller. Such networks give NLP systems a stable sense inventory, so a program can compare senses, follow IS-A links, or fill role slots without retraining from raw text. They are used in word sense disambiguation, information extraction, question answering, machine translation and multilingual dictionary building.

WordNet: synsets and pointers

WordNet is a lexical database for English. It groups word forms by sense into synsets. A synset is a set of synonymous lemmas that can stand for the same concept in some context. A lemma is a word form as it appears in a synset, such as car or auto. A gloss is the definition attached to a synset, often with an example. The sense inventory is the full set of synsets. A sense number is the index of a lemma's sense, written car#1; it is a listing order, not a promise of corpus frequency. Lexicographer files group synsets by subject, for example noun.artifact, where car synsets sit.

Most pointers link synsets: hypernym, hyponym, meronym, holonym and entailment. Hypernym means IS-A: car → motor vehicle. Hyponym is the reverse. Part meronym means part-of: wheel is a meronym of car. Entailment links a verb sense to an implied activity, as snore entails sleep. Two pointer types, antonym and derivation, link lemmas: hot is the antonym of cold, buy is derivationally related to buyer. The noun hierarchy is rooted at entity. It is a graph because a synset may have several hypernyms.

path_sim(s1, s2) = 1 / (dist(s1, s2) + 1)

dist is the number of edges on the shortest path between synset s1 and synset s2.

wu_palmer(s1, s2) = 2 × depth(LCS) / (depth(s1) + depth(s2))

depth is edges from the root; LCS is the lowest common subsumer; s1 and s2 are synsets.

FrameNet: frames and frame elements

FrameNet is a lexical database built on frame semantics. A frame is a schematic event or situation with participants and props. A frame element (FE) is a role in that frame. Core FEs define the frame; remove one and the event changes. Peripheral FEs add time, place or purpose but do not define the event. A lexical unit (LU) is a lemma in one sense that evokes a frame, such as buy.v in Commerce_buy.

The sentence “Meera bought a scooter from Ravi for ₹60,000” evokes Commerce_buy. Buyer is Meera, Goods is a scooter, Seller is Ravi, and Money is ₹60,000. Buyer, Goods and Seller are core FEs; Time and Place would be peripheral. Frame elements are close to semantic roles in Chapter 4.6, but FrameNet ties each role to a named frame.

Frames link to frames. Inheritance passes FEs from a general frame to a specific one. Perspective presents the same event from another side: Commerce_buy and Commerce_sell view one exchange from buyer and seller. A subframe is a step inside a larger frame. A synset and a frame are different. A synset groups word forms with the same sense. A frame groups predicates that describe the same event and its roles. One word sense can sit in one synset and evoke one frame, but the two inventories answer different questions.

Indian language wordnets and multilingual dictionaries

An Indian language wordnet, in the IndoWordNet style, treats a synset as an interlingual concept. Each concept has a synset ID, an integer. Every language has its own lemma set, gloss and examples under that ID. Hindi कार and Tamil கார் can carry the same car synset ID while keeping different word forms, scripts and usage notes. English often acts as the pivot language: a new language links to an English synset, and other languages reach it through the same ID.

A multilingual dictionary built this way links senses, not exact translations. Two words may be translation equivalents in one context and differ in another. The synset ID says “same concept”; it does not say “same word in every sentence.” Word sense disambiguation, covered in Chapter 4.5, chooses which synset fits a context.

Metaphor is a short advanced topic; only a few universities teach it. A conceptual metaphor understands one domain through another. ARGUMENT IS WAR appears in “she attacked my position” and “he defended his claim.” The words come from war, but the topic is argument. Metaphor processing is left to advanced courses.

Exam traps

4.5 Word sense disambiguation

A word like bank can mean a place that keeps money or the sloping ground beside a river. Word sense disambiguation (WSD) decides which listed sense a particular use carries. It needs a sense inventory such as WordNet, a context window around the target, and a decision rule: gloss overlap, a graph measure over the sense network, or a classifier trained on sense-tagged sentences. Machine translation, search and question answering all call WSD, because a wrong sense poisons everything downstream.

You need: Chapter 4.3 for word senses and their relations, Chapter 4.4 for WordNet synsets and glosses, and Unit 5 for Naive Bayes if your course has covered it.

The task and the sense inventory

Word sense disambiguation (WSD) picks the sense a word carries in one particular use. The input is the target word, its sentence, and a sense inventory — a fixed list of the senses that word may have. The output is one label from that list.

The inventory fixes the granularity. Chapter 4.3 defines senses as distinct meanings of a word form; Chapter 4.4 shows WordNet storing each sense as a synset. Two systems are comparable only if they use the same inventory.

Lexical sample WSD disambiguates a few target words in many hand-tagged sentences. All-words WSD disambiguates every content word of a running text. Benchmark campaigns run both settings.

Context is the main evidence, taken from the words, their part-of-speech tags and their syntactic relations around the target. The context window is k words to each side of the target, with k usually between 5 and 10 in supervised systems; the whole sentence can be used when data are scarce. The word river near bank is strong evidence; the word the is none.

The most frequent sense baseline answers with the commonest sense of that word in a reference corpus. Senses are very unevenly distributed, so this baseline scores well above chance and every system must report it. WordNet lists senses roughly by frequency, so sense 1 is a ready-made guess.

Dictionary and knowledge-based methods

The Lesk algorithm compares the dictionary gloss (definition) of each candidate sense with the words of the context, and picks the sense with the largest overlap.

score(s) = |words(gloss(s)) ∩ words(context)|

s is one candidate sense of the target word; gloss(s) is the dictionary definition of s; context is the window text; |·| counts distinct content words.

  1. Collect the content words of the context, dropping stop words and the target word.
  2. Collect the content words of the gloss of each candidate sense.
  3. Count the shared words for each sense and choose the largest count; break ties by a fixed rule.

Extended Lesk also uses glosses of senses related to each candidate — hypernyms, hyponyms, meronyms — so a short definition is backed by its neighbours. The gain in evidence brings extra noise.

Glosses hold six to ten words, so raw overlap is often zero and ties are common; a longer gloss then wins by accident. Two fixes: weight each shared word by how rare it is in a corpus, and normalise the score by gloss length.

Graph-based methods make nodes of the WordNet senses and edges of a similarity. Path length is one such similarity: fewer edges between two synsets means closer senses. The whole sentence is decoded at once — each sense starts with its gloss overlap and passes score to its neighbours until the values settle.

Supervised WSD

Supervised WSD trains a classifier on sentences whose target words are already sense-tagged. SemCor, a part of the Brown corpus tagged with WordNet senses, is a standard training source.

  • Words in a window of about ±5 to ±10, with stop words removed.
  • Part-of-speech tags of the neighbours; the tag of the target itself separates noun bank from verb bank.
  • Collocations and bigrams such as bank account or river bank.
  • Syntactic features from a dependency parse (Unit 3): head word, subject or object slot.

Naive Bayes needs little data but assumes features are independent given the sense. A decision tree gives readable rules. An SVM handles thousands of sparse features well. Unit 5 covers training.

Feature selection keeps features with high mutual information with the sense label and drops rare ones. Without it the feature vector is mostly zeros and training slows down.

Semi-supervised learning, evaluation and multilingual WSD

Bootstrapping starts from a few seed examples per sense, trains a classifier, labels unlabelled sentences, adds the most confident ones and repeats. Self-training uses one classifier. Co-training splits the features into two views — local collocations (the words right next to the target) and the wider topical context of the passage — and lets each classifier label data for the other.

One sense per discourse: a word usually keeps one sense through a document. Decoding the document jointly, choosing the assignment with the best total score, removes many isolated errors.

P = TP / (TP + FP)      R = TP / (TP + FN)      F1 = 2PR / (P + R)

TP is the items of a sense assigned correctly, FP items of other senses wrongly given that label, FN items of that sense given another label, P precision, R recall, F1 their harmonic mean.

accuracy = correct items / all items

correct items counts every test item whose predicted sense equals the gold sense.

Standard test sets come from the Senseval and SemEval campaigns, in lexical sample and all-words form. Report per-sense F1 and overall accuracy, and never tune on the test set. In cross-lingual WSD a parallel corpus supplies evidence: the translation chosen in another language narrows the sense, and multilingual wordnets give matching labels.

Worked example

Question. Disambiguate bank in 'The fisherman sat on the bank of the river.' (a) Run Lesk with glosses bank1 'a financial institution that accepts deposits' and bank2 'sloping land beside a river'. Exam traps

  • Skipping the most frequent sense baseline. A system that beats it by two points has done real work; without the baseline the number means nothing.
  • Tuning on the test set. Choosing k, the classifier or the tie rule by looking at test accuracy inflates the score; use a development split.
  • Letting gloss length decide. Lesk ties often go to the longer gloss, which had more chances to overlap. Normalise or weight the overlap.
  • Comparing accuracies across systems that used different sense inventories or granularity. The numbers are not on the same scale.
  • Stopping at the sentence. One sense per discourse means that another occurrence of the same word three sentences later can still correct the sense, so a document-level pass often helps.

4.6 Semantic roles and selectional restrictions

Semantic roles name the part each phrase plays in the event a verb describes: who does it, what is affected, what tool is used, where and when. Selectional restrictions state what kind of word sense may fill each slot. Together they connect syntax to meaning: the parse gives slots, roles label them, restrictions filter odd fillers. Search engines, question answering, machine translation and information extraction use them to tell who did what to whom and to reject impossible readings. This chapter shows the common role names, their grids, and why role inventories differ across theories.

You need: word senses from Chapter 4.3 and subcategorisation and grammatical relations from Unit 3.

Roles, grids and alternations

A predicate is the word that describes an event or state, usually a verb. Its arguments are the phrases it needs. A semantic role, also called a thematic role, labels the part an argument plays in that event.

  • Agent: the doer, often animate. Ravi in Ravi broke the window.
  • Patient: the entity affected or changed. window in the same sentence.
  • Theme: an entity moved or located, less affected. book in The book is on the table.
  • Experiencer: one who perceives or feels. Meera in Meera fears dogs.
  • Goal: the endpoint. to Chennai.
  • Source: the starting point. from Delhi.
  • Instrument: the tool. with a stone.
  • Benefactive: the one helped. for Ravi.
  • Location: the place. in Chennai.
  • Time: the when. yesterday.

Thematic grid: the roles a verb sense requires or allows. Break takes Agent, Patient and optional Instrument. Subcategorisation: the syntactic slots, such as NP NP PP. The grid is meaning; subcategorisation is syntax.

Diathesis alternations change syntax while roles mostly stay. Active/passive: Ravi broke the window; The window was broken by Ravi. The subject becomes Patient. Dative: Ravi gave the book to Meera; Ravi gave Meera the book. Locative: Ravi loaded stones into the truck; Ravi loaded the truck with stones. In 'Ravi loaded stones into the truck', stones is Theme and the truck is Goal (Location). In 'Ravi loaded the truck with stones', the truck is Patient and stones is the material (Theme; some texts say Instrument). The roles shift, so check the verb sense.

Inventories differ

No single role list is universal. Case Grammar uses cases such as Agentive, Objective and Instrumental. PropBank numbers arguments: Arg0, Arg1, Arg2. FrameNet names frame elements for each frame, such as Eater and Food.

Some frames do reuse the names Agent, Patient and Instrument, but those names are defined inside the frame, not as universal labels. So a label from one inventory need not match another. Use the inventory your syllabus names and keep the mapping explicit.

Selectional restrictions

A selectional restriction is a semantic constraint on the word sense that fills an argument slot. Eat requires an animate subject and an edible object. Break requires a breakable physical object as its object. The restriction is checked against the sense, not the spelling: bank as a financial institution and bank as a river side accept different fillers.

  • Selectional preference: a graded expectation, not a hard rule. The child ate the cake is normal; The goat ate the newspaper is odd but possible; The stone ate the cake strongly violates.
  • Violation: the sentence remains grammatical in form but is semantically odd. A parser can flag it as low plausibility.
  • Coercion: context repairs the type. The ham sandwich is waiting for his bill treats a food order as a customer.
  • Metonymy: a related word stands for another. The Chennai branch called uses branch for its staff; The White House announced uses building for administration.

NLP systems use selectional preferences as soft scores in word sense disambiguation, semantic role labeling and machine translation. They help choose between readings: The crane flew over the lake favours the bird sense; The crane lifted the load favours the machine sense.

4.7 Discourse segmentation, coherence and cohesion

Discourse is language beyond one sentence: a paragraph, a news report, a support chat. An utterance is one sentence used in context. A discourse is coherent when a reader can infer how its parts relate; it is cohesive when surface words and forms tie the parts together. Segmentation finds the units that carry those links. Summarisers, essay graders, chatbots and search engines use it to decide where one topic or move ends and the next begins.

You need Chapter 4.1 for proposition meaning, Chapter 4.2 for sentence meaning, and Chapter 4.6 for predicate-argument links.

Cohesion: the surface ties

Cohesion is the visible glue between sentences. Halliday and Hasan list five types.

Reference points by a pronoun, demonstrative or article: 'Ravi missed the bus. He ran.' He refers back to Ravi. This is a cohesive device; finding Ravi as antecedent is coreference, covered in Chapter 4.8.

Substitution replaces one item with another: 'I wanted the window seat, but I got the aisle one.' One substitutes seat.

Ellipsis leaves a gap: 'Ravi ordered tea; Meera, coffee.' The second verb is omitted.

Conjunction links with a connector: 'It rained, so the match stopped.' So marks result.

Lexical cohesion uses word choice: repetition ('bus ... bus'), synonymy ('late ... delayed'), and collocation ('bus ... conductor').

Cohesion is not coherence. 'Ravi missed the bus. He was a mango.' has a pronoun but no sensible relation. Coherence is the inferred relation; cohesion is its surface marking. In 'Ravi missed the bus. He reached late.' the causal link is not marked by any conjunction; only the pronoun 'he' ties the two sentences, so cohesion is thin while the coherence is supplied by inference.

Writers use cohesion to guide the reader; readers use it to recover relations quickly. A machine can measure pronoun density, repeated words and connectors as features for coherence scoring.

Coherence relations and RST

A coherence relation names how two spans of text relate. Common names are Evidence, Result, Cause, Elaboration and Contrast. In Rhetorical Structure Theory (RST), most relations are asymmetric. The nucleus is the central span; the satellite supports it.

Take 'Ravi missed the bus. As a result, he reached the office late.' The first sentence gives the cause; the second gives the result. The relation is Result. The first sentence is the nucleus; the second is the satellite. The pronoun he is a cohesive link to Ravi, not the relation itself.

An RST tree groups spans. Leaves are elementary units, often sentences. Each internal node is a relation over a span. For this text the root is Result with two children. Spans are contiguous ranges of text: [1] and [2], then [1-2]. A larger report would nest more relations.

Names shift with the question. 'Ravi reached late because he missed the bus' can be labelled Cause; the facts are the same, but the nucleus is now the result. Evidence supports a claim: 'Ravi is late. He missed the bus.' Elaboration adds detail: 'Ravi missed the bus, the 7:10 to T. Nagar.' Contrast sets two spans against each other: 'Ravi missed the bus. Meera caught it.'

Contrast is one of the few multinuclear relations, so neither span is nucleus or satellite; both carry equal weight. Relations such as Evidence, Result, Cause and Elaboration are nucleus-satellite relations.

Cue phrases and segmentation

Cue phrases signal relations: because, so, however, for example, in fact, as a result. They help label relations and place boundaries. Ambiguity is common. 'Since' can mark time ('since Monday') or cause ('since he left early'). 'While' can mark time or contrast. 'And' can add or contrast. 'So what?' has so but no Result relation. A relation may also be implicit, with no cue at all. Discourse markers are cue phrases in talk, such as well, okay, you know; they manage turns and attention as well as relations.

Discourse segmentation cuts text into units that carry relations: sentences, clauses, paragraphs or topic blocks. Paragraph breaks help but are not always boundaries; a writer may break a paragraph in the middle of one argument. Cue-phrase segmentation starts a new unit at a strong cue such as 'However'. It is simple, but it misses implicit cues and can overfire inside quotations.

TextTiling uses lexical cohesion. Split the text into fixed-size token blocks. Score each pair of adjacent blocks by word overlap. A low score is a candidate boundary. TextTiling then computes a depth score at each gap from the drop in similarity against its neighbours and marks a boundary only where the depth score crosses a threshold. A standard score is cosine over word frequencies:

sim(b_i, b_j) = Σ_w tf(w, b_i) × tf(w, b_j) ÷ (√Σ_w tf(w, b_i)² × √Σ_w tf(w, b_j)²)

tf(w,b) is the count of word w in block b; the sums run over the vocabulary; sim is between 0 and 1.

Supervised segmentation treats each gap as a classification: features from words, cue phrases, punctuation and syntax predict boundary or not. Training needs labelled texts. Lexical chains track repeated related words across sentences; a chain break or a switch to a new chain can mark a new segment.

Worked example

Question. Segment this text into two units and draw an RST tree: 'Ravi missed the bus. As a result, he reached the office late.' Name the coherence relation and list two cohesive devices. Say whether removing 'As a result' changes the relation.

  1. Sentence boundaries give two units: U1 = 'Ravi missed the bus.' and U2 = 'As a result, he reached the office late.'
  2. The cue phrase 'As a result' marks a result; the relation is Result.
  3. RST tree: root Result, left child U1 with edge nucleus, right child U2 with edge satellite. The span of the root is U1-U2.
  4. Cohesive devices: (a) reference: he refers to Ravi; (b) conjunction: As a result links the sentences. Lexical repetition is absent.
  5. Remove 'As a result': the two sentences remain coherent for most readers, because missing a bus and arriving late invite a causal inference. The relation is still Result, but now it is implicit, not cued. A strict system may label it Unknown without the cue.

Answer. Two units U1 and U2; root Result with nucleus U1 and satellite U2; devices are reference (he → Ravi) and conjunction (As a result); removing the cue keeps the inferred Result relation but removes the explicit cue.

Exam traps

  • Cohesion is not coherence: pronouns can appear in nonsense.
  • RST relations are not sentence-level grammar relations; a causal clause can be inside one sentence or across two.
  • Cue phrases are ambiguous: 'since' can mark time or cause.
  • A paragraph break can be stylistic, not a discourse boundary.
  • A relation label depends on the writer's intended span, not only on word order.

4.8 Coreference and anaphora resolution

Coreference links two mentions that point to the same entity. Anaphora resolution finds the antecedent that an anaphor such as a pronoun depends on. The work matters for summarization, question answering, translation and chatbots that must track who did what. The chapter covers chains, Hobbs' algorithm, Centering Theory, mention-pair models, clustering, and precision, recall and F1. It also notes Indian-language zero pronouns.

You need: Chapter 4.7 for discourse links, Chapter 4.6 for semantic roles, and Unit 3 for parse trees.

Mentions, entities and chains

A mention is a span of text that refers to an entity: a name, a pronoun, a noun phrase, or a dropped element. An entity is the thing in the world being talked about. A coreference chain is the set of all mentions that point to one entity. In the figure, Ravi and He form one chain; Meera and She form a second; report and it form a third.

An anaphor is a mention whose meaning depends on another mention, its antecedent. 'He' is an anaphor, and 'Ravi' is its antecedent. In cataphora the antecedent comes later: in 'After she paid, Meera left', she points forward to Meera. An expletive it carries no referent: 'It is raining' has no antecedent for it.

Zero anaphora is a missing pronoun that the reader recovers from context or agreement. Hindi 'Ravi aaya aur ___ baith gaya' means 'Ravi came and sat'; the subject of sat is dropped. Indian languages use this often.

Hobbs' algorithm and Centering Theory

Hobbs' algorithm resolves a pronoun by searching the parse tree. It is syntactic and cheap, and it uses number, gender and person agreement.

  1. Start at the pronoun node in the parse tree.
  2. Climb to the first NP or S above it; call it X.
  3. Search the branches below X to the left of the path from the pronoun, left-to-right, breadth-first, proposing NP nodes that agree in number, gender and person; never propose the pronoun's own NP. If X is an S node, also search the branches to the right of the path in the same way, stopping at any NP or S you meet.
  4. If no antecedent is found and X is not the topmost S of the sentence, climb to the next NP or S and repeat, skipping branches already visited. If no antecedent is found and X is the topmost S of the sentence, repeat the whole search in the previous sentences, most recent first.
  5. Stop at the first agreeing NP and return it as the antecedent.

Centering Theory adds discourse focus. Each utterance has a ranked list of discourse entities, the forward-looking centers Cf, most salient first. The backward-looking center Cb is the entity that links the current utterance to the previous one. Transition types describe how Cb and the top-ranked Cf move: Continue: Cb stays and Cb is the top-ranked Cf. Retain: Cb stays but is not the top-ranked Cf. Smooth-shift: Cb changes and becomes the top-ranked Cf. Rough-shift: Cb changes and is not the top-ranked Cf. Rule 1 of Centering says: if any element of Cf of the previous utterance is realised as a pronoun in the current utterance, then Cb of the current utterance must be realised as a pronoun too. So a pronoun normally points to Cb, and centering constrains the search.

Mention-pair models, clustering and evaluation

A mention-pair model scores a pair (mention m, candidate antecedent a) with features and keeps the best antecedent. An entity-based model scores adding m to a whole cluster. Features include number, gender and person agreement; distance in sentences; salience such as subject or first mention; syntactic role; string match; and semantic compatibility. WordNet sense compatibility can help, but sense is not coreference; see Chapter 4.5.

  • Clustering: link accepted pairs, then take transitive closure. Over-merging is a risk, so add cannot-link constraints.
  • Indian languages: dropped pronouns need a zero-pronoun step; rich verb agreement gives number, gender and person, which supplies the missing features.
  • Cross-lingual: English pronouns may vanish in Hindi or Tamil, and reappear in translation, so alignment must track entities, not words.
P = C ÷ N_pred, R = C ÷ N_gold, F1 = 2PR ÷ (P + R)

C is the number of correct links; N_pred is the number of predicted links; N_gold is the number of gold links; P is precision and R is recall.

Evaluation: precision P = correct links ÷ predicted links. Recall R = correct links ÷ gold links. F1 balances them. Some metrics count links, as in MUC-style scoring; some score whole entities, as in CEAF; and some average per-mention scores, as in the CoNLL shared-task metric. Entity F1 and mention F1 are not interchangeable.

Exam traps

  • Anaphora is not coreference: an expletive it has no antecedent, and a bridging description can depend on discourse without sharing an entity.
  • Do not pick the nearest noun by default; agreement and discourse focus can point farther back.
  • Links are unordered pairs; define them before computing precision and recall. Entity F1 differs from mention F1.
  • Gender and number features can mislead with collective nouns, titles and names used for either gender.
  • Zero pronouns are not 'no referent'; in Hindi or Tamil the verb agreement may carry the missing features.

Takeaways

  1. A meaning representation must be unambiguous, canonical and expressive enough for the computer to draw inferences.
  2. First-order logic gives predicates, constants, variables and quantifiers; description logics cut expressiveness to keep reasoning decidable.
  3. Davidson's event variable turns time, place and manner into separate predicates over one event.
  4. Semantic attachments make meaning compositional: the parse tree builds the logical form rule by rule from the leaves up.
  5. Word senses are linked by stable relations, and WordNet stores them as a graph whose nodes are synsets.
  6. FrameNet describes meaning through frames and frame elements, which is closer to an event scene than a list of words.
  7. Word sense disambiguation needs three things: a sense inventory, a context window, and evidence from a dictionary or from labelled data.
  8. Thematic roles and selectional restrictions turn a predicate's argument list into a small scene with expected fillers.
  9. Discourse is coherent through relations between segments and cohesive through surface ties; segmentation finds the spans that carry these links.
  10. Coreference resolution groups mentions of one entity; anaphora resolution picks the single antecedent a pronoun depends on.

Glossary

Anaphora
A mention that depends on an earlier mention for its meaning, as a pronoun depends on a name.
Antecedent
The earlier mention that an anaphor refers back to.
Bootstrapping
Training that starts from a small seed set and adds the system's own confident predictions as new labelled data.
Cataphora
An anaphor that appears before the mention it depends on.
Coherence
The property that a text makes sense as a whole because its sentences are linked by discourse relations.
Context window
The fixed number of words on each side of a target word that a disambiguation system uses as evidence.
Discourse segment
A contiguous stretch of text treated as one unit for coherence analysis.
Distributional similarity
Similarity computed from the contexts in which two words occur, without using a dictionary.
Frame element
A role inside a FrameNet frame, such as Eater and Food for the Ingestion frame.
Holonym
The whole in a part-of relation; car is the holonym of wheel.
Homonymy
Two unrelated senses that happen to share a word form, as the two nouns bank.
Hypernym
The more general sense in a hyponymy pair; vehicle is the hypernym of car.
Lesk algorithm
A word sense disambiguation method that picks the dictionary sense whose gloss overlaps most with the context words.
Lexeme
A word form treated as one vocabulary item, carrying its own set of senses.
Metaphor
Describing one thing in terms of another, so the intended meaning goes beyond the literal senses of the words.
Multilingual WordNet
A set of WordNets for different languages whose synsets are linked by shared identifiers.
Ontology
A formal, shared description of the concepts in a domain and the relations among them.
Pragmatics
Meaning that depends on context and speaker intention, over and above literal sentence meaning.
Quantifier scope
The order in which ∀ and ∃ are applied, which changes the truth conditions of a sentence.
Rhetorical relation
A named link between two discourse segments, such as Elaboration or Contrast.
Semantic role labelling
The task of assigning a thematic role to each argument of a predicate in a sentence.
Synset
A set of word forms that share one sense in WordNet, such as {car, auto, automobile}.
