6.1 Autoencoders and encoder-decoder architectures

An autoencoder is a network that learns to rebuild its own input. It first squeezes the input x through an encoder q(z|x) into a small latent code z, then a decoder p(x|z) produces a reconstruction x-hat. Training makes x-hat close to x. The narrow middle forces the model to keep the main structure and drop noise. Autoencoders are used for denoising, feature extraction, compression and anomaly detection, and the encoder-decoder pattern is the base of variational autoencoders (VAEs), discussed in 6.3. GANs use an entirely different adversarial training scheme.

You need: the multilayer perceptron and backpropagation from Unit 1, and optimizers and regularization from Unit 2.

The bottleneck idea

An autoencoder has two functions. The encoder q(z|x) maps an input vector x with n real values to a latent vector z with m values. The decoder p(x|z) maps z back to x-hat, a vector of n values. The network is trained so that x-hat copies x. The code z is the only path between the two sides.

When m < n, the autoencoder is undercomplete. The code is narrower than the input, so the model cannot pass every pixel or feature through. It must learn a compact description that keeps what is needed for reconstruction. When m ≥ n, the autoencoder is overcomplete. A wide code can copy the input, so low loss alone does not prove that z is useful.

The encoder-decoder pattern is larger than autoencoders. In machine translation, an encoder reads a source sentence and a decoder writes the target sentence (see Unit 4). In image segmentation, an encoder downsamples and a decoder upsamples to pixel labels (see Unit 3). An autoencoder is the special case where the target is the input itself.

  1. Take a mini-batch of inputs x.
  2. Encode: z = encoder(x).
  3. Decode: x-hat = decoder(z).
  4. Compute reconstruction loss between x and x-hat.
  5. Backpropagate the loss and update encoder and decoder weights.

Losses and variants

The loss depends on the input type. For real values, such as temperatures or pixel intensities scaled to [0,1], use mean squared error.

L_MSE = (1/n) Σᵢ (xᵢ − x̂ᵢ)²

n is the number of input features; xᵢ is the i-th input value; x̂ᵢ is its reconstruction; the sum runs i = 1 to n.

For binary values, such as black/white pixels or presence/absence bits, use binary cross-entropy.

L_BCE = −Σᵢ [xᵢ log x̂ᵢ + (1 − xᵢ) log(1 − x̂ᵢ)]

xᵢ ∈ {0,1} is the i-th input bit; x̂ᵢ is the predicted probability that bit is 1; add a small ε inside each log to avoid log 0.

A denoising autoencoder adds noise to x before encoding. The noise can be Gaussian noise or random pixel masking. The decoder is trained to output the clean x, not the noisy version. The code must remove the corruption, so it learns robust features. At test time, the same network can clean a noisy input.

A sparse autoencoder adds a penalty to the loss, for example λ Σⱼ |zⱼ|. zⱼ is the j-th code unit and λ ≥ 0 controls penalty strength. A KL penalty can instead keep the average activation of each code unit near a small target ρ. The code stays wide but only a few units fire for each input.

A contractive autoencoder adds ||∂z/∂x||_F², the squared Frobenius norm of the Jacobian. This penalizes a code that changes sharply when x changes slightly. Only a few universities teach this variant in detail. Probabilistic encoders and decoders lead to variational autoencoders in 6.3.

Linear autoencoders and PCA

Make the encoder and decoder linear: z = W_e x + b_e and x-hat = W_d z + b_d. W_e has size m×n, W_d has size n×m, b_e has m values, and b_d has n values. With squared error and zero biases, training finds an m-dimensional linear subspace that captures the data. The subspace spanned by the columns of W_d matches the subspace of the top m principal components of the data. The columns of W_d need not equal the PCA eigenvectors; any basis of the same subspace gives the same reconstruction error. This is the link between linear autoencoders and PCA.

The compression ratio is n/m, the input dimension divided by the latent dimension. A 1,000-pixel input with a 32-unit code has ratio 1,000/32 = 31.25:1. The ratio measures size reduction, not information kept. For image editing and inpainting with autoencoders, see 6.6.

Worked example

Question. An autoencoder takes a 1,000-pixel input and uses a 32-unit bottleneck. The encoder has a 1,000×32 weight matrix and 32 biases. The decoder has a 32×1,000 weight matrix and 1,000 biases. Compute the total number of trainable parameters and the compression ratio.

  1. Encoder weight count = input units × latent units = 1,000 × 32 = 32,000.
  2. Encoder bias count = latent units = 32.
  3. Decoder weight count = latent units × input units = 32 × 1,000 = 32,000.
  4. Decoder bias count = input units = 1,000.
  5. Total parameters = 32,000 + 32 + 32,000 + 1,000 = 65,032.
  6. Compression ratio = input units / latent units = 1,000 / 32 = 31.25.

Answer. The model has 65,032 trainable parameters, and the compression ratio is 31.25:1.

Exam traps

  • A wide bottleneck can copy the input. Low reconstruction loss does not prove a useful code. Always report bottleneck size and test reconstruction on held-out data.
  • MSE and BCE are not interchangeable. Use MSE for real values and BCE for 0/1 pixels. Pair BCE with a sigmoid output so x-hat is a probability.
  • Compression ratio is not accuracy. A 31.25:1 ratio says the code is smaller; it does not say how much information survives.
  • Tied weights mean W_d = W_eᵀ, which is always possible since W_e is m×n and W_eᵀ is n×m. The two bias vectors b_e and b_d stay separate. Tied weights are optional, not a defining feature of autoencoders.
  • A linear autoencoder with squared error learns a PCA-like subspace, not necessarily the PCA eigenvectors. Any basis of the same subspace gives the same reconstruction error.

6.2 Latent variables and maximum likelihood learning

A latent variable model says the data you see is produced by hidden causes you do not see. A photo of a face has pose, light and expression as hidden variables; pixels are observed. The model writes the joint density of hidden and observed variables, then sums or integrates the hidden part away to get p(x). Maximum likelihood chooses parameters that make the observed data most probable under that marginal. This idea underlies variational autoencoders, restricted Boltzmann machines and many generative models used for image editing and inpainting.

You need: Unit 1 probability and loss functions, and Chapter 6.1 for encoder-decoder notation.

Hidden cause, observed data, marginal likelihood

A latent variable model separates what is observed from what is hidden. Let x be the observed data: a pixel image, a word, or a cricket score. Let z be the latent variable: a compact hidden cause such as pose, topic or style. The parameter vector θ contains the model weights. The model gives a prior p(z) and a conditional p(x|z), often called the decoder. Their product is the joint density p(x,z)=p(z)p(x|z). The data density is the marginal p(x)=∫ p(z)p(x|z) dz, or p(x)=Σ_z p(z)p(x|z) when z is discrete. The sum or integral removes z, so only x remains.

For N independent observations x₁,...,x_N, maximum likelihood chooses θ to maximize log L(θ)=Σ_{i=1}^N log p(x_i;θ). This is the same as minimizing negative log-likelihood. The integral is often over many z dimensions and has no closed form. A Monte Carlo estimate draws M samples z_m~p(z) and uses p(x)≈(1/M)Σ_{m=1}^M p(x|z_m;θ). EM is an alternative: it iterates between a posterior over z and a parameter update. The estimate is noisy but unbiased for fixed θ.

Local independence and the RBM

A Markov network encodes independence through missing edges. A node is independent of all non-neighbouring nodes given its neighbours. In a latent-variable graph, z has no parent and x is its child. Conditional on z, x is independent of other latent causes not connected to it. This local independence assumption makes p(x|z) factorize.

A restricted Boltzmann machine is a latent-variable model with visible units v and hidden units h. Its energy is E(v,h)=-aᵀv-bᵀh-vᵀWh. Here a is the visible bias vector, b is the hidden bias vector, W is the weight matrix, and the superscript ᵀ means transpose. The joint probability is p(v,h)=exp(-E(v,h))/Z, where Z=Σ_{v,h} exp(-E(v,h)) is the partition function. To get p(v), sum over h: p(v)=Σ_h p(v,h). Because v and h form a bipartite graph with no visible-visible or hidden-hidden edges, conditional samples are easy: p(h|v) and p(v|h) factorize over units. Training usually uses contrastive divergence, which starts from data, samples h, reconstructs v, and moves parameters to lower the data energy relative to the reconstruction. Only a few universities require the full derivation.

What maximum likelihood does and does not mean

Maximum likelihood does not ask which single z produced a point. It asks how much probability the model assigns to x after summing over all z. Two models can have the same decoder p(x|z) and different priors p(z); their marginals differ. The likelihood also penalizes a model that puts high mass on hidden states that rarely produce the observed x.

Once trained, the model supports sampling and inference. To generate, draw z~p(z), then x~p(x|z). To edit, condition on part of x and infer plausible z. To evaluate, report average log-likelihood per data point, (1/N)Σ log p(x_i), or bits per pixel/dimension. On held-out data, a higher average log-likelihood means a better density model, though image quality can still be poor. Chapter 6.3 replaces the intractable integral with a learned lower bound. GANs in Chapter 6.4 avoid likelihood entirely.

Worked example

Question. A latent variable z takes value 1 with probability 0.6 and value 2 with probability 0.4. Given z, a binary observation x has p(x=1|z=1)=0.9 and p(x=1|z=2)=0.2. Assume p(x=0|z)=1-p(x=1|z). (a) Find p(x=1) and p(x=0). (b) For observations [1,1,0], find the likelihood L and log-likelihood ln L. Use natural log.

  1. Prior: p(z=1)=0.6 and p(z=2)=0.4. These are dimensionless probabilities.
  2. Emissions: p(x=1|z=1)=0.9, p(x=1|z=2)=0.2, p(x=0|z=1)=0.1, p(x=0|z=2)=0.8.
  3. Marginal for x=1: p(x=1)=Σ_z p(z)p(x=1|z)=0.6×0.9 + 0.4×0.2 = 0.54+0.08 = 0.62.
  4. Marginal for x=0: p(x=0)=1-p(x=1)=1-0.62=0.38. Check: 0.6×0.1 + 0.4×0.8 = 0.06+0.32 = 0.38.
  5. For independent observations [1,1,0], L=p(x=1)×p(x=1)×p(x=0)=0.62×0.62×0.38. First 0.62×0.62=0.3844; then 0.3844×0.38=0.146072.
  6. Log-likelihood: ln L=ln(0.146072)=-1.9237, which rounds to -1.924.

Answer. p(x=1)=0.62, p(x=0)=0.38, L=0.146 (dimensionless), and ln L≈-1.924.

Exam traps

  • Do not maximize the joint p(x,z) for a guessed z and call it maximum likelihood of x. The likelihood of x needs the sum or integral over all z.
  • Do not use the prior p(z) as if it were the posterior p(z|x). The marginal p(x) weights p(x|z) by the prior p(z).
  • In a Monte Carlo estimate of p(x), sample z from the prior p(z), not from the posterior p(z|x), unless you correct with importance weights.
  • For binary x, remember p(x=0)=1-p(x=1). A common slip is to use p(x=1) again for the zero observation.
  • In an RBM, the joint has exp(-E), not exp(E), and Z sums over both visible and hidden states. A sign error reverses the probability ordering.

6.3 Variational autoencoders (VAEs)

A variational autoencoder (VAE) is a generative model: it learns a distribution over data so you can draw new samples. It keeps the encoder–decoder shape of an autoencoder but replaces the single code with a distribution. The encoder q_φ(z|x) outputs a Gaussian over a latent vector z, a short list of hidden numbers; the decoder p_θ(x|z) turns a code back into data. Training maximizes a lower bound on log p(x) called the ELBO. Uses include image sampling, interpolation, molecule design and speech or text front ends.

You need: 6.1 autoencoders for the encoder–decoder shape, 6.2 latent variables and likelihood for p(x) = ∫ p(x|z) p(z) dz, and Unit 2 on backpropagation and gradient descent.

Why the code must become a distribution

A plain autoencoder (6.1) maps input x to one code vector and back to x̂. Nothing forces codes of unseen inputs anywhere useful, so decoding a random code gives noise. Generation needs a distribution over codes, not a lookup table.

The VAE fix has two parts. The encoder outputs q_φ(z|x) instead of a point: given x, it says where z is likely. φ is the encoder weights. A fixed prior p(z) = N(0, I) says codes should sit near the origin with unit variance per direction. z has D numbers (D is latent dimension) and I is the identity matrix, so the D dimensions are independent standard normals.

The decoder p_θ(x|z) maps a code to a distribution over inputs; θ is the decoder weights. Together they define p_θ(x) = ∫ p_θ(x|z) p(z) dz. This integral over R^D has no closed form, so maximum likelihood (6.2) cannot be applied directly.

Instead maximize a lower bound. For any q(z|x):

log p_θ(x) ≥ E_{z~q_φ(z|x)}[log p_θ(x|z)] − KL(q_φ(z|x) ‖ p(z))

Left side: log-likelihood of one x. First right term: expected reconstruction log-likelihood, decoding codes sampled from the encoder and scoring x. Second: KL divergence from encoder distribution to prior, in nats; it measures drift from N(0, I). The right side is the ELBO (evidence lower bound). The gap to the left is KL(q_φ(z|x) ‖ p_θ(z|x)), which shrinks as the encoder better approximates the true posterior.

The Gaussian encoder and the closed-form KL

Make q_φ(z|x) a diagonal Gaussian. The encoder ends in two heads of size D: mean vector μ and log-variance vector. Log form keeps output unconstrained and stops variance from going negative; recover σ² = exp(log σ²). Then q_φ(z|x) = N(μ, diag(σ²)).

One sampled z gives an unbiased estimate of E_q[log p_θ(x|z)]. With a Gaussian decoder centred at x̂ with fixed variance c, the term is −‖x − x̂‖²/(2c) plus a constant, so training uses mean squared error. With a Bernoulli decoder over pixels it becomes binary cross-entropy, the same loss as a binary classifier.

For a diagonal Gaussian against N(0, I), the KL has a closed form:

KL(q_φ(z|x) ‖ p(z)) = ½ Σ_{j=1}^{D} (σ_j² + μ_j² − 1 − ln σ_j²)

μ_j and σ_j² are mean and variance of latent dimension j, for j = 1 to D; ln is natural logarithm, so the answer is in nats. The −1 and −ln σ_j² come from the entropy and normalizing constant of the two Gaussians. σ_j² is variance, not standard deviation.

Training minimizes −ELBO summed over the mini-batch. The terms pull against each other: reconstruction wants codes to carry information, KL wants all codes near the prior. That balance keeps the latent space smooth enough to sample new data.

Reparameterization, variants and uses

Backpropagation needs a deterministic path from parameters to loss. Drawing z ~ N(μ, diag(σ²)) is random; no gradient flows through it. The reparameterization trick moves randomness outside:

z = μ + σ ⊙ ε, ε ~ N(0, I)

σ = √σ² is the standard deviation vector, ⊙ is element-wise multiplication, and ε is noise with no parameters. z is now a smooth function of μ and σ, so ∂z/∂μ = 1 and ∂z/∂σ = ε, and gradients reach the encoder.

  1. Forward the mini-batch through the encoder to get μ and log σ², both length D.
  2. Compute σ = exp(½ log σ²).
  3. Draw ε ~ N(0, I), one noise vector per data point.
  4. Set z = μ + σ ⊙ ε and decode to x̂.
  5. Loss = reconstruction error + KL; backprop through μ and σ; update φ and θ.

β-VAE multiplies the KL term by β. β > 1 presses codes harder toward the prior and often disentangles dimensions (one dimension per factor such as smile or pose) at some cost in sharpness; β < 1 favours reconstruction. Conditional VAE (CVAE) feeds label c into both networks, learning q_φ(z|x, c) and p_θ(x|z, c), so you can ask for a digit of class 7.

Sampling: draw z ~ N(0, I) and decode. Interpolation: encode two inputs and decode along the straight line between their μ vectors; outputs morph smoothly because the prior fills the gap. Latent traversal: move one coordinate z_j by a fixed step, hold the rest, and watch which attribute changes.

Worked example

Question. A VAE has one latent dimension (D = 1). For an input x the encoder outputs μ = 1 and σ² = 4, and the prior is p(z) = N(0, 1). Compute KL(q(z|x) ‖ p(z)) in nats and say whether this code is close to the prior.

  1. With D = 1 the KL sum has one term: KL = ½(σ² + μ² − 1 − ln σ²).
  2. Substitute: μ = 1 so μ² = 1; σ² = 4, so σ = 2. The formula takes variance, so 4 goes in.
  3. ln σ² = ln 4 = 1.3863.
  4. Bracket: 4 + 1 − 1 − 1.3863 = 2.6137.
  5. KL = ½ × 2.6137 = 1.3069 ≈ 1.307 nats.
  6. A KL of 1.307 nats is well above 0, so the code is not close to the prior: it is too wide (variance 4 against 1) and shifted (mean 1 against 0). Training pushes μ toward 0 and pulls σ² toward 1: here μ = 1 comes down and σ² = 4 comes down toward 1. (If σ² had been below 1, the KL term would push it up.)

Answer. KL(q(z|x) ‖ p(z)) = 1.307 nats, so the code is far from the prior.

Exam traps

  • Variance, not standard deviation. The KL uses σ². Putting σ = 2 in as if variance gives ½(2 + 1 − 1 − ln 2) = 0.65 nats, half the right answer. Encoders output log σ² for this reason: exponentiate once and label the result σ².
  • KL direction. The ELBO has KL(q(z|x) ‖ p(z)), not KL(p(z) ‖ q(z|x)). These differ, and only the first has this simple closed form.
  • The bound is not the likelihood. Maximizing the ELBO maximizes a lower bound on log p(x); the gap is KL(q(z|x) ‖ p_θ(z|x)) and is zero only if the encoder is exact.
  • Gradients do not flow into ε. In z = μ + σ ⊙ ε, ε is noise, not a parameter, so no gradient flows into ε; gradients flow only into μ and σ. σ is not redrawn, it is recomputed by the encoder; what is redrawn each step is ε. Treating sampled z as a plain network output breaks training.
  • Calling it a plain autoencoder. A plain autoencoder has no prior and no KL term, so sampling its latent space is unjustified. The KL term is exactly what makes generation possible, and examiners ask for it.

Analyze What happens if β in a β-VAE is set very large? 5 marks

The KL term dominates. The encoder's q(z|x) collapses toward N(0, I) and the decoder learns to ignore z, giving posterior collapse: reconstructions become blurry or averaged. Reconstruction quality falls (reconstruction error rises). Only moderate β > 1 tends to give more independent, interpretable dimensions; at very large β the code is uninformative and interpretability is lost.

Analyze Two VAEs train on the same greyscale digits, one with a Bernoulli decoder and one with a Gaussian decoder of fixed variance. Which reconstruction loss does each use, and why? 5 marks

Bernoulli: pixels scaled to [0, 1] are treated as probabilities, so loss is binary cross-entropy. Gaussian: the term is −‖x − x̂‖²/(2c) plus a constant, so loss is mean squared error. The choice follows the data range and whether pixels behave like counts or real numbers.

The same ELBO trains diffusion models, where the encoder is a fixed noising process, so time on KL and reparameterization pays off twice. Conditional VAEs generate molecules with requested properties. Search terms: posterior collapse, disentanglement, VQ-VAE, ELBO in diffusion models.

6.4 Generative adversarial networks: architecture and training

A generative adversarial network (GAN) learns to make new data by playing a game. A generator G turns random noise z into a fake sample G(z). A discriminator D looks at real data x and fake samples and outputs a probability that its input is real. G tries to fool D; D tries to tell them apart. Training alternates between the two. GANs are used for face and product image synthesis, image-to-image translation, and data augmentation. They often give sharper images than VAEs, but training is less stable.

You need: 6.2 for latent variables and likelihood, Unit 2 for gradient-based optimization, and Unit 3 for CNN layers used in image GANs.

Architecture and the minimax game

The generator G(z; θ_g) maps a noise vector z ~ p_z to a fake sample. θ_g are the generator weights. Typical z is 100 random numbers from a normal or uniform distribution. The discriminator D(x; θ_d) maps a sample x to a scalar probability in [0, 1], usually after a sigmoid. θ_d are the discriminator weights. For images, both are CNNs: G uses upsampling or transpose convolutions, and D uses strided convolutions. G never sees real data directly; it learns only from D's gradients. D sees both real and fake data.

V(D,G) = Ex∼p_data[log D(x)] + Ez∼p_z[log(1 − D(G(z)))]

V is the value of the game; D(x) is the probability D gives to real x; G(z) is the fake sample; p_data is the real data distribution; p_z is the noise distribution; E is expectation; log is natural log.

D wants high D(x) and low D(G(z)), so D maximizes V. G wants high D(G(z)), so G minimizes V. With one real and one fake sample, V = log D(real) + log(1 − D(fake)). For fixed G, the best D is D*(x) = p_data(x) / (p_data(x) + p_g(x)), where p_g is the distribution of G(z). If p_g = p_data, then D*(x) = 1/2. Only a few universities ask you to derive this.

Training loop and non-saturating loss

  1. Sample m real examples x from the data and m noise vectors z from p_z.
  2. Compute fake examples G(z). Keep G fixed and update D by ascending the gradient of (1/m)Σ[log D(x) + log(1 − D(G(z)))].
  3. Sample fresh noise z. Keep D fixed and update G by descending the gradient of its own loss.
  4. Repeat both updates for many iterations.
LG = −Ez∼p_z[log D(G(z))]

L_G is the non-saturating generator loss; D(G(z)) is the discriminator's probability that a fake sample is real; lower L_G means G is fooling D better.

Early in training, D can reject fakes easily, so D(G(z)) is near 0. The term log(1 − D(G(z))) then saturates near 0 and G's gradient vanishes. The non-saturating loss −log D(G(z)) avoids this flat region. It has the same fixed point as the minimax game but a stronger gradient. The two losses are not identical during training. D's output is a probability, not a hard label.

Failures and useful variants

Mode collapse means G maps many different z to a few similar samples. D cannot force G to cover every mode of the data. This is not overfitting; it is a failure of the game. Instability is the other common problem. If D becomes too strong, G gets weak gradients. If D is too weak, G gets no useful signal. Careful learning rates, batch normalization, label smoothing, and extra D updates can help. GAN samples can be sharp, but judging sample quality is hard.

  • Conditional GAN: G(z, y) and D(x, y) both receive a class label y or text. This lets you ask for a specific digit or object class.
  • CycleGAN: two generators A→B and B→A plus two discriminators. A cycle loss ‖F(G(a)) − a‖₁ keeps content. It works on unpaired sets, such as horse↔zebra, not on paired before/after images.
  • Progressive GAN: start at low resolution, then add layers as training stabilizes, up to 1024×1024 faces. This makes high-resolution training more stable.

Image editing, inpainting, and super-resolution use GANs as conditional priors; see 6.6. Bias and deepfakes are ethical risks; see 6.7.

Worked example

Question. For one real sample x and one fake sample G(z), D(x) = 0.8 and D(G(z)) = 0.3. Compute the discriminator maximization objective V for this pair and the non-saturating generator loss. State whether G wants the loss lower or higher. Use natural log.

  1. V = ln D(x) + ln(1 − D(G(z))).
  2. D(x) = 0.8, so ln 0.8 = −0.2231.
  3. D(G(z)) = 0.3, so 1 − 0.3 = 0.7 and ln 0.7 = −0.3567.
  4. V = −0.2231 + (−0.3567) = −0.5798 ≈ −0.580. D wants larger V.
  5. Generator loss L_G = −ln D(G(z)) = −ln 0.3.
  6. ln 0.3 = −1.2040, so L_G = 1.2040 ≈ 1.204.
  7. G minimizes this loss, so lower is better. D(G(z)) closer to 1 gives lower L_G.

Answer. V ≈ −0.580 and the non-saturating generator loss L_G ≈ 1.204; G wants lower L_G.

Exam traps

  • Do not update the generator with the discriminator's real-data term; the generator sees only fake samples.
  • Do not flip the sign: D maximizes V, while G minimizes V or minimizes the non-saturating loss −log D(G(z)).
  • D output 0.5 does not mean training has failed; it means D cannot separate real from fake for that input.
  • Mode collapse is not overfitting. The generator has lost data modes; it is not memorizing training points.
  • CycleGAN is for unpaired data. Pix2pix-style paired translation is a different setting.

6.5 Autoregressive models, PixelRNN and normalizing flows

Some generative models need an exact probability for every possible image, not just a realistic-looking sample. An autoregressive model writes the joint density as a product of one-variable conditionals in a fixed order; PixelRNN and PixelCNN apply this order to pixels. A normalizing flow instead maps data through an invertible function and corrects the density with a Jacobian term. Both give exact likelihoods, so they train by maximum likelihood. They appear in image and audio generation, density estimation and anomaly detection.

You need: 6.2 for maximum likelihood, and Unit 4 sequence models for the RNN view.

Autoregressive factorization

Take a data vector x = (x1, x2, ..., xD) with D entries. In an image each entry is one pixel value; in audio each entry is one sample. The chain rule of probability writes the joint density as a product of conditionals, one per entry, in a fixed order. An autoregressive model chooses that order once and learns every conditional. The order is part of the model: a later entry may depend on all earlier entries, never on later ones.

p(x) = ∏i=1D p(xi | x1:i−1)

D is the number of entries; xi is entry i; x1:i−1 = (x1, ..., xi−1) are the earlier entries in the chosen order.

For pixels, a common order is row by row, left to right inside each row. Then x1 is the top-left pixel and xD is the bottom-right pixel. Training uses maximum likelihood: maximize Σn log p(x(n)), which becomes Σn Σi log p(xi(n) | x1:i−1(n)). Each conditional is a small classifier: for a binary pixel it outputs p(xi=1 | earlier pixels); for an 8-bit pixel it outputs 256 probabilities. Sampling is sequential: draw x1, insert it, draw x2 given x1, and continue. This is exact but slow, because D draws cannot be parallel.

PixelRNN and PixelCNN

PixelRNN and PixelCNN are autoregressive models for images. They keep a fixed pixel order and use a neural network to compute each conditional from earlier pixels. PixelRNN uses recurrent layers along the pixel sequence, so a hidden state carries information from earlier pixels (see Unit 4, Recurrent Networks and Sequence Models). PixelCNN uses masked convolutions. A convolution kernel is multiplied by a mask that sets weights for the current pixel and later pixels to zero. The output at a pixel depends only on pixels before it in the fixed order.

The mask follows the order. A pixel in the current row can see earlier pixels in that row and all pixels in previous rows. The first pixel of a row sees only previous rows. Build the mask once and keep it fixed. Training feeds a whole image and computes one conditional per pixel in parallel; the loss is the sum of negative log probabilities. Sampling generates pixel 1, inserts it, generates pixel 2, and continues, so it is sequential. Some syllabi call these models fully visible belief nets because every pixel is observed in training. Training and sampling must use the same order; otherwise the product is invalid.

Normalizing flows

A normalizing flow models x through an invertible function f. Start with a simple base density pZ(z), often a standard normal. Set z = f(x). The change-of-variables formula gives the data density.

log pX(x) = log pZ(f(x)) + log |det ∂f/∂x|

pX(x) is the data density at x; pZ is the base density; f is invertible; det ∂f/∂x is the Jacobian determinant at x.

The determinant corrects for local volume change. For sampling, invert: draw z from pZ, then compute x = f−1(z). Training maximizes Σ log pX(x) over data, so this is exact likelihood, not a lower bound. A full Jacobian is expensive in high dimensions. Coupling layers make it cheap. Split x into xA and xB. Leave xA unchanged. Transform xB using functions s and t of xA: yA = xA and yB = xB × exp(s(xA)) + t(xA). The Jacobian is triangular, so the log determinant is Σ s(xA). The inverse subtracts t and divides by exp(s). Stack coupling layers and alternate which part is transformed. Unlike a VAE, a flow has no encoder sampling noise and no bound. Only a few universities require full Jacobian derivations; for most exams, know the formula and the coupling determinant.

Exam traps

  • A conditional may use only earlier entries. Conditioning on a later pixel breaks the product and makes the density invalid.
  • The mask must match the chosen order. Changing the scan order without rebuilding masks and retraining gives wrong conditionals.
  • In a flow the Jacobian term is added with a plus sign and an absolute determinant: log pX = log pZ + log|det J|, not minus.
  • Autoregressive models give exact likelihood. Do not call their objective a variational lower bound; that belongs to VAEs.
  • PixelCNN training is parallel, sampling is sequential. An examiner may ask why training can see the whole image while sampling cannot.

6.6 Applications: image editing, inpainting and super-resolution

Generative models can act as conditional priors for images. A prior supplies plausible missing content; a condition ties that content to the pixels you already have. For image editing you move in latent space or pass an attribute label. For inpainting you pass a mask and visible pixels. For super-resolution you pass a low-resolution image. The same generator then predicts an edited, filled or upscaled image. Phone galleries, e-commerce catalogue clean-up, medical scan enhancement and CCTV restoration use these tasks.

You need autoencoders (6.1), VAEs (6.3), GANs (6.4) and autoregressive priors (6.5).

Image editing by moving in latent space

An encoder maps image x to a latent vector z; a decoder maps z back to pixels. If the model is trained well, nearby z values give similar images. An attribute direction d is a vector in latent space. Adding it shifts one property. Common choices are smile, hair colour, age or season. A simple estimate takes the mean encoded vector of images with the attribute minus the mean without it, then normalises to unit length. Large step size changes more but risks artifacts.

z′ = z + α d

z′ is the edited latent code; z is the original latent code; α is the step size in latent units; d is the unit attribute direction.

Conditional GANs and VAEs learn the edit directly. The generator sees a condition c, such as “add glasses”, a sketch, or a reference photo, and samples G(z,c). Paired training data has target images. The loss combines reconstruction, adversarial and sometimes identity losses. CycleGAN handles unpaired style change: two generators map domain A to B and back, and a cycle loss ‖F(G(x)) − x‖₁ keeps content. It is used for photo-to-sketch or summer-to-winter looks.

  1. Encode the image to z.
  2. Pick a direction d or a condition c.
  3. Decode z + α d or G(z,c).
  4. Check identity and artifacts; reduce α if needed.

Inpainting: predict the missing region

Inpainting fills a hole in an image. The input is a visible image x and a binary mask m. m = 1 marks missing pixels. The model predicts the hole from context: p(y | x ⊙ (1 − m), m), where y is the full target image, x is the observed image, m is a binary mask with m = 1 at missing pixels, and ⊙ is the elementwise product. A context encoder is an encoder-decoder trained to reconstruct the whole image but scored mainly on the hole. The mask is passed as an extra channel so the network knows what to ignore. A plain L1 or L2 loss gives a blurry average fill; a GAN or perceptual decoder adds texture.

  1. Make a mask that covers the object or damage.
  2. Feed the masked image and mask channel to the generator.
  3. Predict the full image.
  4. Composite: output = m ⊙ prediction + (1 − m) ⊙ input.
  5. Train with hole-only pixel loss plus adversarial or perceptual loss.
  6. Evaluate on held-out holes with PSNR/SSIM and human inspection.

Super-resolution and honest evaluation

Single-image super-resolution maps a low-resolution image to a high-resolution one. A CNN or ResNet predicts missing high-frequency detail; a GAN sharpens texture. Pixel loss alone gives smooth, safe outputs. Perceptual loss compares deep features from a pretrained network and usually looks sharper. SSIM compares local luminance, contrast and structure; it takes values up to 1 (typically between 0 and 1), and equals 1 for identical images. PSNR can rank a blurry result above a sharp one, so report SSIM or a perceptual metric too. Deep image prior is a side note: an untrained network's structure itself favours natural images, so it can denoise or inpaint without training data.

PSNR = 10 log₁₀(MAX² ÷ MSE)

MAX is the maximum pixel value (255 for 8-bit images); MSE is the mean squared error between the output and the target.

The same conditional setup appears in security restoration of CCTV frames. Ethical misuse of restored or edited media belongs to 6.7.

Worked example

Question. A 256×256 8-bit image has a 64×64 masked square. (a) What fraction and percentage of the image is missing? (b) The filled region has MSE = 16 in pixel-level squared error on 8-bit pixels. Compute PSNR. Take MAX = 255.

  1. Total pixels = 256 × 256 = 65,536 pixels.
  2. Missing pixels = 64 × 64 = 4,096 pixels.
  3. Missing fraction = 4,096 ÷ 65,536 = 0.0625.
  4. Missing percentage = 0.0625 × 100 = 6.25%.
  5. PSNR = 10 log₁₀(255² ÷ 16) = 10 log₁₀(65,025 ÷ 16) = 10 log₁₀(4,064.0625).
  6. log₁₀(4,064.0625) ≈ 3.609, so PSNR ≈ 36.09 dB.

Answer. 6.25% of the image is missing, and the PSNR is 36.09 dB.

Exam traps

  • Higher PSNR does not always mean a better-looking image; PSNR rewards smooth blur. Report SSIM or a perceptual metric as well.
  • In inpainting, fix the mask polarity: m = 1 means missing, not visible. Composite with m ⊙ prediction + (1 − m) ⊙ input.
  • Super-resolution input is low-resolution. Evaluate on held-out low/high-resolution pairs, not on training patches, and build the low-resolution training inputs with the same downscaling (degradation) you will meet at test time.
  • CycleGAN's cycle loss preserves content; adversarial loss alone can change identity. A latent edit's step size α is in latent units, not pixels.

6.7 Ethics in generative AI: bias, toxicity and deepfakes

Generative models learn from data people wrote or labelled. That data carries history: skewed samples, harsh language, few faces of some groups. A model can repeat and scale those patterns in text, images, voice and video. This chapter treats evaluation and mitigation as part of the model, not an afterthought: measure per-group errors, filter toxic output, mark synthetic media, protect private data and document limits. It is used in chatbots, image tools and media checks.

You need: 6.4 GANs and 6.6 applications; for text models, Unit 5 on large language models.

Bias is a measurable error pattern

Bias in a generative model is a group-dependent error or stereotype. It enters through training data and through the objective. If a group is rare in the data, the model sees fewer examples and may learn a coarse or wrong pattern. If the objective rewards average accuracy, the model can ignore the small group and still score well. A face generator trained mostly on one skin tone may distort others; a text model trained on skewed web text may link a profession to one gender.

Measure bias per group. For a classifier, report accuracy, false positive rate and false negative rate for each group. FPR = FP ÷ (FP + TN): the share of truly negative cases wrongly flagged. FNR = FN ÷ (FN + TP): the share of truly positive cases missed. These numbers expose harm that one overall score hides.

DPD = max(s₁, …, s_k) − min(s₁, …, s_k)

s_g is the share of group g that receives a positive decision; k is the number of groups; DPD is the demographic parity difference. DPD = 0 means equal selection rates, not equal error rates.

Mitigation starts before release: rebalance or reweight data, test per group, choose thresholds with the harm in mind, and document trade-offs. Fairness definitions conflict. Equal selection rates can coexist with unequal false positive rates. The team must state which definition it targets and why. Audits repeat these tests on fresh data.

Toxicity and deepfakes

Toxicity is harmful content: insults, threats, hate, harassment. A generative text model can produce it when a prompt pushes it. Red-teaming is adversarial testing: people try prompts, typos and role-play to break the model. Findings feed filters, refusal rules, training data cleanup and human review. Filters act on input and output, but they make false positives; context matters, and a blocked medical term is not the same as a slur.

A deepfake is synthetic image, voice or video made to look real. GANs and diffusion models make faces; voice cloning copies speech; video models animate a still face. Harms include fraud, non-consensual intimate images and political deception. Consent is central: a person's face or voice should not be used without permission. Provenance records where media came from; a watermark embeds a signal in the output. Detection uses classifiers trained to spot artefacts, but it is an arms race and never perfect.

Controls combine law, platform policy and technical checks. Technical checks include watermark detection, provenance metadata and human verification for high-stakes claims. A detector gives evidence, not proof. The worked example shows how to score one.

Privacy, model cards and audits

Generative models can memorize training data. A text model may repeat a phone number or a private message; an image model may copy a face. Mitigation: remove personal data, deduplicate, limit epochs, and use differential privacy, which adds noise so one record changes the output little. Test with extraction prompts that ask the model to repeat rare strings.

A model card is a short document released with a model. It states intended use, out-of-scope use, training data summary, evaluation metrics including per-group results, limitations and ethical risks. An audit is an independent test of those claims: bias probes, toxicity red-teaming, privacy extraction and deepfake checks. Documentation does not fix a model, but it makes harm visible and gives users a basis to choose.

Responsible AI is the process that ties these pieces together: define harms, measure them, mitigate, document and monitor after release. Some syllabi call this responsible AI; text-model courses may place it under LLM ethics, see Unit 5. The key exam point: evaluation and mitigation are part of the model, not an optional appendix.

Worked example

Question. A deepfake detector tests 1,000 real and 1,000 fake videos. It flags 50 real videos as fake and misses 100 fake videos. Compute false positive rate, false negative rate and precision.

  1. Real videos = 1,000. False positives FP = 50. True negatives TN = 1,000 − 50 = 950. FPR = 50 ÷ (50 + 950) = 50 ÷ 1,000 = 0.05 = 5%.
  2. Fake videos = 1,000. False negatives FN = 100. True positives TP = 1,000 − 100 = 900. FNR = 100 ÷ (100 + 900) = 100 ÷ 1,000 = 0.10 = 10%.
  3. Flagged videos = FP + TP = 50 + 900 = 950. Precision = TP ÷ (TP + FP) = 900 ÷ 950 = 0.94737 ≈ 94.7%.

Answer. FPR = 5%, FNR = 10%, precision = 94.7%.

Exam traps

  • High overall accuracy hides harm when one group is small; report per-group false positive and false negative rates.
  • False positive rate is FP ÷ (FP + TN), not FP ÷ (FP + TP); precision is TP ÷ (TP + FP).
  • Demographic parity means equal selection rates, not equal error rates; a model can satisfy parity and still have unequal FPR.
  • A detector's precision depends on the base rate; 99% accuracy can mean low precision when fakes are rare.
  • A watermark proves origin only if it is present and intact; it is not detection of every fake.

Key terms and formulas

TermMeaning or formulaChapter
AutoencoderA network trained to copy its input to its output through a narrow hidden layer, so the hidden layer must keep only the useful structure of the data.6.1
Bottleneck (latent code)The narrow layer between encoder and decoder; its width fixes how many numbers describe each input.6.1
Reconstruction lossThe penalty for the output not matching the input, usually mean squared error for real-valued data and cross-entropy for binary or pixel data: L = (1/n)Σ‖xᵢ − x̂ᵢ‖².6.1
Denoising autoencoderAn autoencoder fed a corrupted copy of x but asked to reconstruct the clean x, which forces the code to keep real structure and drop noise.6.1
Latent variableAn unobserved variable z that is assumed to generate the observed data x; the model is written p(x, z) = p(z)p(x|z).6.2
Marginal likelihoodThe probability of the observed data after hiding z: p(x) = ∫ p(x|z)p(z) dz, a sum or integral over all values of z.6.2
Maximum likelihood learningChoosing parameters θ to maximise Σᵢ log pθ(xᵢ), the total log-probability of the training data.6.2
Evidence lower bound (ELBO)A lower bound on log p(x): ELBO = E_q[log p(x|z)] − KL(q(z|x) ‖ p(z)), where q is any distribution over z.6.3
KL divergenceA non-negative measure of how much one distribution differs from another: KL(q‖p) = E_q[log(q(x)/p(x))], equal to zero only when q = p.6.3
Reparameterisation trickWriting a sample z ~ N(μ, σ²) as z = μ + σ·ε with ε ~ N(0, 1), so gradients can flow through μ and σ.6.3
Generative adversarial network (GAN)A generator G and a discriminator D trained together: D learns to tell real from fake, G learns to fool D.6.4

Autoregressive modelA density factorised by the chain rule as p(x) = Πᵢ p(xᵢ | x₁, …, xᵢ₋₁), one variable at a time.6.5

Takeaways

  1. An autoencoder learns a compressed code by being forced to rebuild its own input, and the same encoder–decoder shell later becomes a generative model.
  2. Generative modelling means learning a probability distribution over data; anything hidden that explains the data is a latent variable and must be summed or integrated out.
  3. The VAEs objective is a lower bound on log-likelihood, and it is tractable because the expectation is taken over a cheap approximate posterior rather than the true one.
  4. A GAN replaces an explicit likelihood with a learned test: the discriminator, which is why samples look sharp but training is unstable.
  5. Autoregressive models and normalising flows give exact likelihoods, the first by ordering the variables and the second by stacking invertible transforms.
  6. Editing, inpainting and super-resolution are all the same trick: condition the model on the part of the image you already know.
  7. Generative models inherit the biases of their training data and can be used to make convincing fake media, so evaluation and mitigation are part of the design, not an afterthought.
  8. The choice of model family is a trade-off: exact likelihood versus sharp samples versus stable training versus a usable latent space.

Remember and understand

Understand Explain the encoder–decoder structure of an autoencoder. Draw the block diagram, name each part, and state what the bottleneck layer does to the data. 10 marks

Encoder maps input x to code h = f(x); decoder maps h back to x̂ = g(h); Training minimises reconstruction loss such as mean squared error or binary cross-entropy over pixels; The bottleneck is narrower than the input, so the network cannot copy; it must keep the main factors of variation; A linear autoencoder with squared error spans the same subspace as PCA; If the bottleneck is wider than the input, the network can learn the identity and becomes useless — this motivates denoising, sparse and variational variants.

Remember Define a latent variable model. Write the marginal likelihood for continuous z and explain every term. 8 marks

z is unobserved, x is observed; joint is p(x, z) = p(z)p(x|z); p(x) = ∫ p(x|z)p(z) dz for continuous z, and p(x) = Σ_z p(x|z)p(z) for discrete z; p(z) is the prior over causes; p(x|z) is the likelihood or decoder; The integral has no closed form for a neural decoder, so exact maximum likelihood is hard; Maximum likelihood picks θ maximising Σᵢ log pθ(xᵢ).

Understand State the GAN minimax objective and explain the role of the generator and the discriminator in the two-player game. 10 marks

Objective: min_G max_D E_{x~data}[log D(x)] + E_{z~p(z)}[log(1 − D(G(z)))] with D(x) a probability; Discriminator maximises the objective: it wants D(x) near 1 for real and near 0 for fake; Generator minimises it: it wants D(G(z)) near 1, i.e. fakes judged real; At the optimum, for a fixed G the best D is p_data(x)/(p_data(x) + p_g(x)), and the game drives p_g towards p_data; Training alternates: k steps of D, one step of G, using gradients through D into G.

Understand Describe the chain-rule factorisation used by autoregressive image models such as PixelRNN, and explain why the pixel ordering matters. 10 marks

p(x) = Πᵢ p(xᵢ | x₁, …, xᵢ₋₁) by the chain rule; no approximation is made; Pixels are ordered in raster scan: top-left to bottom-right, row by row; Each conditional is a neural net (recurrent for PixelRNN, masked convolution for PixelCNN) with a softmax over 256 intensity values per channel; The order fixes the conditioning set; a different order gives a different (still valid) factorisation; Likelihood is exact and training is plain cross-entropy, but sampling is sequential and slow, and no simple low-dimensional latent code exists.

Understand What is a normalising flow? Give the change-of-variables formula and state the requirements on the transform. 8 marks

x = f(z) with z ~ p_z(z), f invertible, z = f⁻¹(x); log p_x(x) = log p_z(f⁻¹(x)) + log |det ∂f⁻¹/∂x|; The Jacobian determinant must be cheap to compute, which is why coupling layers with triangular Jacobians are used; f must be invertible and both f and f⁻¹ must be differentiable; Stacking flows gives an exact likelihood, unlike VAEs, and gives both sampling and inference in one model.

Apply

Apply Starting from log p(x), derive the evidence lower bound used to train a VAE, showing every step. 12 marks

Write log p(x) = log ∫ p(x|z)p(z) dz; Introduce any distribution q(z|x) and multiply and divide inside the integral; Use Jensen's inequality (or the KL decomposition) to get log p(x) ≥ E_q[log p(x|z)] + E_q[log p(z) − log q(z|x)]; Identify the second bracket as −KL(q(z|x)‖p(z)); Final form: ELBO = E_q[log p(x|z)] − KL(q(z|x)‖p(z)), with gap equal to KL(q(z|x)‖p(z|x)); Reconstruction term trains the decoder; KL term pulls the encoder output towards the prior.

Apply For a Gaussian encoder q(z|x) = N(μ, σ²) and a standard normal prior p(z) = N(0, 1), write the closed-form KL term and explain how the sampling step is made differentiable. 10 marks

For one dimension: KL = ½(σ² + μ² − 1 − log σ²), summed over latent dimensions; It is zero when μ = 0 and σ² = 1, i.e. the encoder output matches the prior; Reparameterisation: sample ε ~ N(0,1), set z = μ + σ ⊙ ε; Gradients now flow through μ and σ, so backpropagation works through a random node; The encoder outputs log σ² rather than σ² for numerical stability.

Apply A VAE is trained on face images. Explain how you would edit an image by moving in the latent space, and what you must check before trusting the result. 12 marks

Encode the image: z = μ(x), or sample z ~ q(z|x); Find a direction d for the attribute (smile, age) by averaging latent differences between labelled pairs; Decode z + αd for increasing α and watch the attribute change while identity stays fixed; Large α leaves the region covered by the prior and produces unrealistic images, because the decoder was never trained there; Check disentanglement: one attribute should change, others should stay; otherwise the direction is entangled; Report both the reconstruction and the KL term; a collapsed posterior gives weak edits.

Apply Describe how to inpaint a missing region of an image using a pretrained generative model, and how the mask changes the objective. 10 marks

Split the image into known pixels x_k and missing pixels x_m with mask M; Sample from the conditional p(x_m | x_k), not the unconditional p(x); With a VAE, optimise the latent code so the decoded known region matches x_k, then fill x_m from the same decode; With a GAN, train or use a conditional GAN whose loss is weighted by the mask, plus a context loss on known pixels; Fill must be consistent at the boundary; check for blur and for multiple plausible completions.

Apply Design a super-resolution pipeline for old scanned photographs using a generative model. State the losses and the evaluation you would use. 10 marks

Downsample high-resolution images to make paired low/high training data, or use unpaired data with a CycleGAN-style setup; Generator: an encoder–decoder or residual CNN that upsamples by the scale factor; Pixel loss (L1 or L2) keeps colours and structure; adversarial loss adds sharp texture; perceptual loss on pretrained features keeps identity; Mean squared error alone gives blurry output because it averages over plausible high-frequency details; Evaluate with PSNR and SSIM for fidelity plus a human or feature-based check for realism; State the failure mode: the model may hallucinate detail that was never in the original, which matters for forensic or medical use.

Analyze and evaluate

Analyze Compare VAEs and GANs on likelihood, sample sharpness, training stability and usefulness of the latent space. 13 marks

VAE maximises a lower bound on likelihood; GANs give no explicit likelihood and only an implicit density; VAE samples are often blurry because the Gaussian decoder and the averaged reconstruction loss smooth detail; GAN samples are sharp; GAN training is a saddle-point game with no guaranteed convergence and suffers mode collapse; VAE training is a single stable objective; VAE gives a smooth, continuous latent space that supports interpolation and editing; the GAN latent space is usable but less directly probabilistic; VAE has the KL term to control the code; a too-strong KL term causes posterior collapse; Choose VAE for density-based or editing tasks, GAN for photorealism; combination models such as VAE–GAN hybrids and diffusion models try to get both.

Evaluate A GAN produces only a handful of distinct faces from many noise vectors. Diagnose the problem and evaluate three remedies. 13 marks

Diagnosis: mode collapse — many z map to the same output, and the discriminator's gradient stops pushing towards missing modes; Remedy 1: minibatch features so D sees the whole batch and penalises low variety; Remedy 2: Wasserstein loss with weight clipping or gradient penalty, giving smoother gradients everywhere; Remedy 3: unrolled GAN or experience replay to reduce the game's oscillation; Also: check the architecture and learning rates, and add a diversity metric (e.g. FID plus a coverage measure) to the evaluation; Evaluate each remedy on sample variety, not only on visual quality, and state the extra compute cost.

Analyze Why is exact maximum likelihood easy for autoregressive models and normalising flows but hard for VAEs? Compare the three families on this point. 12 marks

Autoregressive: the chain rule gives an exact factorisation, and each conditional is a neural softmax; log-likelihood is a direct sum; Flows: invertible transforms plus the Jacobian determinant give an exact log-density in closed form; VAE: the integral over z is intractable, so we optimise a lower bound; the gap is KL(q(z|x)‖p(z|x)); Cost: autoregressive sampling is sequential and slow; flows need invertible, dimension-preserving architectures; VAEs sample fast in one pass but only bound the likelihood; Implication: comparing log-likelihood numbers across families is not apples to apples for VAEs.

Evaluate A start-up launches a face-editing and voice-cloning app built on a GAN. Evaluate the bias, toxicity and deepfake risks and propose concrete mitigations. 14 marks

Bias: training data under-represents some groups, so edits and reconstructions fail or distort them; measure error per group, not only overall averages; Toxicity: the model can be steered to abusive content; filter training data, add input and output classifiers, and provide reporting; Deepfakes: realistic fake video enables fraud, non-consensual imagery and disinformation; add consent checks, visible or invisible watermarking, and provenance metadata; Legal and platform context: consent for face and voice data, age limits, takedown process, and logs of model use; Evaluation is part of the model: red-team before release, publish a model card, monitor after release; Trade-off: stronger output filters reduce misuse but also block legitimate uses; state the policy explicitly.

Glossary

Autoencoder
A neural network trained to reconstruct its input through a narrow hidden code.
Autoregressive model
A density model that predicts each variable from the variables before it in a fixed order.
Bottleneck
The narrowest layer of an autoencoder, which holds the compressed code.
Deepfake
Synthetic media that realistically depicts a person saying or doing something they did not.
Denoising autoencoder
An autoencoder trained to recover clean input from a corrupted version of it.
Discriminator
The network in a GAN that scores how likely a sample is to be real rather than generated.
ELBO
A tractable lower bound on log p(x) used as the VAE training objective.
Generator
The network in a GAN that turns a noise vector into a fake sample.
Inpainting
Filling in a missing or masked region of an image in a way that agrees with its surroundings.
KL divergence
A non-negative measure of the difference between two probability distributions, zero only when they match.
Latent space
The space of hidden codes z in which each input becomes a point or a distribution.
Latent variable model
A model that explains observed data through unobserved variables, p(x, z) = p(z)p(x|z).
Marginal likelihood (evidence)
The probability of the data after integrating out the latent variable, p(x) = ∫ p(x|z)p(z) dz.
Mode collapse
A GAN failure where the generator produces only a few distinct outputs.
Normalising flow
A density model built from a stack of invertible, differentiable transforms with tractable Jacobian determinants.
PixelRNN
An autoregressive image model that generates pixels one at a time in raster order using a recurrent network.
Posterior
The distribution p(z|x) of the latent variable given the observed data.
Posterior collapse
The failure where a VAE's encoder ignores the input and q(z|x) equals the prior, so z carries no information.
Prior
The distribution p(z) assumed over the latent variable before seeing any data.
Reconstruction error
The difference between the input and the autoencoder's output, used as the training loss.
Reparameterisation trick
Rewriting a random sample as a deterministic function of the parameters plus fixed noise, so gradients pass through.
Super-resolution
Generating a high-resolution image from a low-resolution input.
Undercomplete autoencoder
An autoencoder whose code is smaller than the input, so it must discard information.
Variational inference
Approximating a hard posterior p(z|x) with a simpler, tractable family q(z|x).
