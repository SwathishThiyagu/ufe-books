4.1 Sequence learning problems and sequential data

Sequential data is a list where position matters: x₁, x₂, …, x_T. A sequence learning problem takes such a list and returns one label, a label for every step, or a new list. The length T can change from one example to the next. Text, speech, sensor logs and video all arrive in this form. This chapter fixes the vocabulary, separates the three output shapes, and shows how to cut a series into supervised examples without cheating by looking into the future.

You need: Unit 1 for supervised learning and labels; Unit 3 for CNN features if video is mentioned. The recurrent model that consumes order is in 4.2.

Order, time steps and length

A sequence is data where the index carries meaning. We write xt for the value at time step t. The length is T, so the sequence is x₁, x₂, …, xT. A sensor may record x₁ = 2, x₂ = 4, x₃ = 6 at three time steps.

Length is often variable. One sentence has T = 8 words, another has T = 21 words. A speech clip has T frames, and a sensor log has T samples. T can differ for every example in the dataset.

Order matters. If you shuffle the sensor values [2, 4, 6, 8, 10], the rising trend disappears. In text, “dog bites man” and “man bites dog” contain the same words in a different order and mean different things. A model that ignores t treats both sentences as one bag of words.

A sequence learning problem learns a function from x₁ … xT to an output. The output can be one label y, a label for every step y₁ … yT, or a new sequence y₁ … yU. The output length U may equal T or may differ.

Video adds two dimensions, space and time. CNN features plus a recurrent layer is one way to model video, but spatio-temporal action recognition is advanced; only a few universities teach it in detail, so it stays a one-line note here and in 4.7.

Three output shapes

  • Many-to-one classification. The whole sequence gives one label. A review gives sentiment positive or negative. A sensor log gives fault or no-fault. The model reads all T steps and produces a fixed-size output, often from the last hidden state in 4.2.
  • Many-to-many labelling, same length. Every input step gets a tag. Part-of-speech tagging labels each word as noun, verb, adjective and so on. Named-entity recognition labels each word as person, place, organisation or other. Input length T equals output length T, and step t aligns with tag yt.
  • Many-to-many sequence-to-sequence. The input is one sequence and the output is another sequence, often with U ≠ T. Translation reads an English sentence of length T and writes a Tamil sentence of length U. Speech-to-text reads audio frames and writes words. The encoder-decoder model in 4.5 handles this shape.

The same data can be framed in more than one way. A product review can be classified as positive or negative, or every word can be tagged as complaint or praise. Choose the shape by what you must predict and what information is available at prediction time. For translation, no target words are known before generation starts. For tagging, every input word is visible.

Windows, padding and time-based splits

For forecasting, turn one series into supervised pairs with a sliding window. Pick a window length w. The input is [xt, xt+1, …, xt+w−1] and the target is the next value xt+w. Slide the window one step to the right and repeat. The figure shows w = 3 on five values.

Npairs = N − w

N is the number of values in the series; w is the window length; Npairs is the number of (input window, next value) pairs.

Models train on rectangular batches, so short sequences are padded to the maximum length in the batch. Padding adds dummy steps, often zeros or a special pad token. A mask marks real steps and padded steps. The loss ignores padded steps; without a mask the model learns to predict padding.

Split sequential data by time, not by random rows. Train on earlier time, validate and test on later time. Keep every window inside one split. A window that crosses the split boundary carries future values into training. Do not shuffle time steps before splitting; that leaks future information into the training set.

Worked example

Question. A sensor records x = [2, 4, 6, 8, 10] at t = 1 … 5. Use windows of length 3 to predict the next value. List every (input window, target) pair and give the number of pairs.

  1. The series has N = 5 values and the window length is w = 3.
  2. First window starts at t = 1: input [x₁, x₂, x₃] = [2, 4, 6]. The next value is x₄ = 8. Pair: ([2, 4, 6] → 8).
  3. Slide one step. Second window starts at t = 2: input [x₂, x₃, x₄] = [4, 6, 8]. The next value is x₅ = 10. Pair: ([4, 6, 8] → 10).
  4. A third window would start at t = 3 and need x₆, which does not exist. Stop.
  5. Number of pairs: N − w = 5 − 3 = 2.

Exam traps

  • Shuffling time steps or splitting a time series by random rows leaks future values into training. Split by time and keep windows inside each split.
  • Padding without a mask changes the loss: the model is rewarded for predicting pad tokens. Mask padded steps so only real steps count.
  • Many-to-one classification returns one label for the whole sequence. Seq2seq returns a new sequence and can have a different output length U. Do not use the names as synonyms.
  • For a next-value task with N values and window length w, the number of pairs is N − w. Counting N − w + 1 includes a window that has no target.
  • Variable length is normal. Padding makes a batch rectangular but does not change the true length T of each example.

4.2 Recurrent neural networks and unfolding in time

A feedforward network sees one input and forgets it. Many problems are sequences: words in a sentence, frames of a video, a sensor reading each second. A recurrent neural network (RNN) keeps a small vector called the hidden state, which carries what the network has seen so far. At each step it mixes the new input with the old state. One cell and one set of weights serve every time step. Language modelling, speech recognition and video tagging all start here.

You need: Unit 1 for tanh and matrix multiplication, and 4.1 for how a sequence is written x₁ … x_T and padded into batches.

The RNN equations

A sequence is x₁, x₂, …, x_T, one vector per step (see 4.1). A feedforward layer would treat each xt alone, with no idea what came before. An RNN adds one thing: a hidden state that travels from step to step.

ht = tanh(Wxh xt + Whh ht−1 + bh),   yt = Why ht + by

xt is the input vector at step t of length d (shape B×d for a batch of B sequences); ht is the hidden state of length H, the number of hidden units (shape B×H); Wxh is the input-to-hidden matrix of shape d×H; Whh is the recurrent matrix of shape H×H; bh is a bias vector of length H; Why is H×k and by is length k, giving output yt of length k; tanh acts element by element and squashes values into (−1, 1). For k-class prediction, apply softmax to yt.

The same three matrices are used at every step. Step 1 and step 100 share Wxh, Whh and Why. That sharing is the whole point: the model learns one rule for mixing past and present, and applies it however long the sequence runs.

h0 has no step before it, so you initialise it yourself, usually to a zero vector of shape B×H. Some books write U for Whh, W for Wxh and V for Why. The letters change; the equation does not. This cell is commonly called the vanilla RNN or the simple RNN. Both names are standard, so use either one in an answer.

Unfolding in time

Draw the cell once per time step and connect the copies. That picture is the unfolded RNN.

The figure unfolds two steps with x₁ = 1 and x₂ = 2. At each step x(t) and h(t−1) enter the cell, tanh mixes them, and h(t) leaves. One copy of h(t) can go to an output head (the figure draws only y₂, at the last step); another goes to the next step. The arrow from h(t) to h(t+1) carries exactly the same matrix as the arrow from h(t−1) to h(t). Unfolding adds no parameters. It is the same model, drawn deep.

Why draw it? After unfolding, the network is an ordinary feedforward graph whose depth equals the sequence length T, and gradient descent on such a graph is ordinary backpropagation. That training pass is called backpropagation through time and is the subject of 4.3.

Unfolding also shows the cost. Each step multiplies the input by a d×H matrix, the state by an H×H matrix, and the result by an H×k output matrix. A forward pass over T steps is about O(T·(d·H + H·H + H·k)) multiply-adds; ignoring the small output head, the recurrent part is O(T·H·(d+H)). Long sequences cost more, and their gradients stretch back further; the gated cells of 4.4 exist to handle the second problem.

Output heads: one-to-many, many-to-one, many-to-many

The recurrent body, the chain of hidden states, is the same in every task. What changes is where you read the output and how many steps you run.

  • Many-to-one: run T steps, read y only at the last step. Use it for the sentiment of a review or a label for a video clip.
  • One-to-many: feed one input, such as an image vector from a CNN, then keep the state running with dummy inputs and emit a word at each step. Use it for image captioning.
  • Many-to-many, aligned: emit yt at every step, as in part-of-speech tagging where input and output have equal length.
  • Many-to-many, shifted: read the whole input, then emit an output of a different length one token at a time, feeding the previous output back as the next input. This is the encoder-decoder pattern of 4.5.

For video, a CNN from Unit 3 turns each frame into a feature vector; the RNN then consumes those vectors in order and predicts a label or a caption.

One more variant: a bidirectional RNN runs two cells, one left to right and one right to left, and concatenates their states at each step. Then ht depends on past and future inputs. That helps tagging, but it cannot be used for step-by-step generation, where the future does not exist yet.

Worked example

Question. A scalar RNN has W_xh = 1, W_hh = 0.5, b_h = 0, W_hy = 1, b_y = 0 and h_0 = 0. The inputs are x_1 = 1 and x_2 = 2. Compute h_1, h_2 and y_2, rounded to two decimals.

  1. Write the scalar equations: h_t = tanh(1·x_t + 0.5·h_{t−1}) and y_t = 1·h_t + 0.
  2. Step 1: the weighted sum is 1×1 + 0.5×0 = 1.000. h_1 = tanh(1.000) = 0.7616, so h_1 ≈ 0.76.
  3. Step 2: the input term is 1×2 = 2.000; the state term is 0.5×0.7616 = 0.3808; their sum is 2.3808. h_2 = tanh(2.3808) = 0.9830, so h_2 ≈ 0.98.
  4. Output: y_2 = 1×0.9830 + 0 = 0.9830, so y_2 ≈ 0.98.

Answer. h_1 = 0.76, h_2 = 0.98 and y_2 = 0.98, to two decimals.

Exam traps

  • h_t at each time step is not a separate learned parameter. Only W_xh, W_hh, W_hy, b_h and b_y are learned; h_t is computed.
  • h_0 must be initialised. A zero vector is the usual choice; leaving it undefined makes the first step impossible.
  • Do not confuse h_t, the internal state, with y_t, the output. The state is passed forward; the output is what the loss is computed on.
  • Shape slip: W_hh is H×H, not d×H, because it multiplies h_{t−1} of length H. In a batch, h_t has shape B×H and y_t has shape B×k.
  • tanh is not sigmoid. tanh(0) = 0 and the range is (−1, 1); sigmoid(0) = 0.5 and the range is (0, 1). Examiners test this.

4.3 Backpropagation through time

Backpropagation through time is ordinary backpropagation applied to an RNN after unfolding it into a chain of repeated cells. The chain has one copy of the cell per time step, all sharing the same weights. A loss at each step adds a term to the total loss. Gradients from every term flow back through the chain and are summed into the shared weights. BPTT trains language models, speech recognisers, and any model that predicts from a sequence.

You need 4.2 for the RNN equations, Unit 1 for the chain rule, and Unit 2 for gradient clipping.

Unfolding turns time into depth

An RNN repeats one cell. At step t it reads x_t and the previous state h_{t-1}, and produces h_t. Unfolding draws a copy of the cell for every t and connects the copies in a line. The copy at t uses the same weight matrix W_hh as every other copy.

L = Σ_{t=1}^{T} L_t

L_t is the loss at time step t; T is the sequence length; L is the total training loss.

Each L_t depends on h_t, and h_t depends on h_{t-1}, which depends on h_{t-2}, and so on back to h_0. Training needs ∂L/∂W_hh. The parameter is shared, so every L_t contributes. BPTT computes all contributions in one backward sweep over the unfolded chain. This is the same algorithm as backpropagation in a deep feedforward network, with two changes: the weight matrices are tied across layers, and the “layers” are time steps. The forward pass stores h_t and x_t for every t; the backward pass needs them. Some syllabi call the method BPTT; the name only records that the backward pass runs through time.

The backward recursion and the Jacobian

Write the recurrence h_t = tanh(W_xh x_t + W_hh h_{t-1} + b_h). h_t is a vector of d_h hidden units; W_hh is the shared d_h × d_h recurrent matrix. The Jacobian J_t = ∂h_t/∂h_{t-1} has entry (i,j) equal to ∂h_t[i]/∂h_{t-1}[j]. For tanh, J_t = diag(1 − h_t²) W_hh, where 1 − h_t² is a vector and diag makes a diagonal matrix from it.

Let δ_t = ∂L/∂h_t. The loss at t gives a direct term ∂L_t/∂h_t. Future losses reach h_t through h_{t+1}. The backward recursion is

δ_t = ∂L_t/∂h_t + J_{t+1}ᵀ δ_{t+1}

δ_t is the gradient of the total loss with respect to h_t; J_{t+1} = ∂h_{t+1}/∂h_t; δ_{T+1} = 0.

The parameter gradient sums every path from each loss to the shared weight:

∂L/∂W_hh = Σ_{t=1}^{T} Σ_{k=1}^{t} (J_t J_{t-1} ⋯ J_{k+1})ᵀ (∂L_t/∂h_t) (∂h_k/∂W_hh)

∂L_t/∂h_t is a column vector; J_j = ∂h_j/∂h_{j-1}; the product J_t J_{t-1} ⋯ J_{k+1} is the identity matrix when k = t (the empty product); ∂h_k/∂W_hh is the local derivative of step k holding h_{k-1} fixed.

This double sum is the BPTT sum. For each L_t it walks every path back to W_hh, including paths through earlier hidden states.

Long products, truncation and clipping

The product Π J_j causes the main difficulty. If the Jacobians are repeatedly below 1 in norm, the product shrinks exponentially with distance and the gradient from early steps becomes too small. If they are above 1, the product grows and the gradient explodes. The spectral radius ρ(J_t) is the largest absolute eigenvalue of the Jacobian. It gives local intuition: if ρ < 1 the product contracts, and if ρ > 1 it expands. In a tanh RNN the activation derivative is at most 1, but W_hh can still produce small singular values or large ones.

  • Gradient clipping: if ||g|| > c, replace g by c·g/||g||. This keeps the direction and caps the step size.
  • Truncated BPTT: split a long stream into chunks of length k. Forward-propagate through a chunk, backpropagate k steps, update, carry h forward, and detach it from the graph at the chunk boundary. The model still sees long context in the forward state, but gradients do not cross the boundary. This bounds memory and compute and avoids a product of thousands of Jacobians.

Gated cells in 4.4 change J_t; optimizers in Unit 2 consume the gradient computed here.

Worked example

Question. An RNN has scalar hidden state h_t = tanh(x_t + u h_{t-1}), output y = h_2, and loss L = 0.5(y − 1)². Use h_0 = 0.2, x_1 = x_2 = 0.5, and u = 1. (a) Compute h_1, h_2 and L. (b) Compute ∂L/∂u by BPTT. Split the answer into the direct path and the path through h_1.

  1. Step 1: h_1 = tanh(x_1 + u h_0) = tanh(0.5 + 1×0.2) = tanh(0.7) = 0.6044.
  2. Step 2: h_2 = tanh(x_2 + u h_1) = tanh(0.5 + 1×0.6044) = tanh(1.1044) = 0.8021.
  3. Step 3: L = 0.5(h_2 − 1)² = 0.5(−0.1979)² = 0.0196 ≈ 0.020.
  4. Step 4: derivative at the output: dL/dh_2 = h_2 − 1 = −0.1979.
  5. Step 5: local tanh derivative: 1 − h_2² = 1 − 0.8021² = 0.3566.
  6. Step 6: direct path. Treat h_1 as constant: ∂h_2/∂u_direct = (1 − h_2²)h_1 = 0.3566×0.6044 = 0.2156. Contribution = −0.1979×0.2156 = −0.0427 ≈ −0.043.
  7. Step 7: path through h_1. ∂h_1/∂u = (1 − h_1²)h_0 = (1 − 0.6044²)×0.2 = 0.1269. ∂h_2/∂u_via = (1 − h_2²)u∂h_1/∂u = 0.3566×1×0.1269 = 0.0453. Contribution = −0.1979×0.0453 = −0.0090 ≈ −0.009.
  8. Step 8: sum paths. ∂L/∂u = −0.0427 − 0.0090 = −0.0517 ≈ −0.052.

Answer. h_1 ≈ 0.604, h_2 ≈ 0.802, L ≈ 0.020; ∂L/∂u ≈ −0.052, made of −0.043 from the direct path and −0.009 through h_1.

Exam traps

  • Backpropagating only through the last step. BPTT sums every path from each L_t to W_hh, including paths through earlier hidden states.
  • Confusing δ_t = ∂L/∂h_t with the parameter gradient. δ_t includes future losses through J_{t+1}ᵀ δ_{t+1}.
  • Forgetting the tanh local derivative 1 − h_t² in J_t, or using W_hh alone as the Jacobian.
  • Treating truncated BPTT as ignoring the past in the forward pass. The hidden state is carried forward; only the gradient is cut at the chunk boundary.
  • Sign slip: ∂L/∂u = −0.052 means increasing u reduces L, so gradient descent adds a small positive update after subtracting the negative gradient.

4.4 Long short-term memory (LSTM) and gated units

An LSTM is a recurrent cell with gates that decide what to keep, what to write, and what to show. A plain RNN overwrites its hidden state at every step, so information from many steps ago fades. LSTM adds a cell state and sigmoid gates that act like taps. The same idea powers speech recognition, language modelling, handwriting recognition and time-series prediction, especially where the useful signal is many steps behind the current input.

You need: recurrence and unfolding in 4.2, gradients through time in 4.3, and sigmoid and tanh from Unit 1.

Gates around a cell state

A plain RNN has one hidden state and overwrites it at every step. LSTM adds a second state, the cell state c_t, and three gates. A gate is a vector with entries between 0 and 1. It works like a tap: 0 blocks, 1 passes. Each gate is computed from the input x_t and the previous hidden state h_{t-1}.

The forget gate f_t scales the old cell state. The input gate i_t scales a new candidate c~_t. The output gate o_t scales the squashed cell state to form h_t.

f_t = σ(W_f x_t + U_f h_{t-1} + b_f)

f_t is the forget gate vector at step t; x_t is the input; h_{t-1} is the previous hidden state; W_f and U_f are weight matrices; b_f is a bias vector; σ(z) = 1/(1 + e^(−z)) gives entries in (0,1).

i_t = σ(W_i x_t + U_i h_{t-1} + b_i)
c~_t = tanh(W_c x_t + U_c h_{t-1} + b_c)
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c~_t
o_t = σ(W_o x_t + U_o h_{t-1} + b_o)
h_t = o_t ⊙ tanh(c_t)

i_t is the input gate; c~_t is the candidate cell state; c_t is the new cell state; c_{t-1} is the previous cell state; o_t is the output gate; h_t is the new hidden state; ⊙ is elementwise multiplication; tanh squashes each entry to (−1,1); W_i, U_i, W_c, U_c, W_o, U_o are weight matrices; b_i, b_c, b_o are bias vectors.

Why the additive cell path helps

The cell state uses addition, not a matrix product: c_t = f_t⊙c_{t-1} + i_t⊙c~_t. During backpropagation through time, error can travel from c_t to c_{t-1} through the factor f_t. If f_t is near 1, that factor is near 1, so the error is not shrunk at every step. The network can learn to hold a value across many steps.

A forget gate near 1 means keep; near 0 means erase. This is the main defence against vanishing gradients. It is not a guarantee. If f_t stays near 0, old information is erased. If σ saturates, its gradient is small. The cell state gives a short gradient path, but training still needs good initialisation and optimisation. See 4.3 for the full gradient computation.

GRU and peephole LSTM

A gated recurrent unit (GRU) uses two gates and no separate cell state. The reset gate r_t controls how much of h_{t-1} enters the candidate. The update gate z_t mixes the old hidden state and the candidate.

z_t = σ(W_z x_t + U_z h_{t-1} + b_z)
r_t = σ(W_r x_t + U_r h_{t-1} + b_r)
h~_t = tanh(W_h x_t + U_h (r_t ⊙ h_{t-1}) + b_h)
h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h~_t

z_t is the update gate; r_t is the reset gate; h~_t is the candidate hidden state; h_t is the new hidden state; W_z, U_z, W_r, U_r, W_h, U_h are weight matrices; b_z, b_r, b_h are bias vectors; σ is the sigmoid; ⊙ is elementwise multiplication. With z_t near 1, h_t is mostly the candidate; with z_t near 0, h_t keeps the old state.

A GRU has fewer parameters than an LSTM, so it can train faster on small data. It has no output gate and no protected cell state, so it may forget differently. Some syllabi call these gated recurrent units. Peephole LSTM lets the gates see c_{t-1} directly; it is an advanced variant, and only a few universities teach it. Neither LSTM nor GRU wins on every task.

Worked example

Question. An LSTM cell at time t has forget gate f_t = 0.731, input gate i_t = 0.622, candidate c~_t = 0.762, previous cell state c_{t-1} = 0.5 and output gate o_t = 0.5. Compute c_t and h_t using h_t = o_t·tanh(c_t). Use tanh(0.839) ≈ 0.6853.

  1. Write the cell update: c_t = f_t·c_{t-1} + i_t·c~_t.
  2. Forget term: 0.731 × 0.5 = 0.3655.
  3. Input term: 0.622 × 0.762 = 0.473964.
  4. Add the two terms: c_t = 0.3655 + 0.473964 = 0.839464 ≈ 0.839.
  5. Squash the cell state: tanh(0.839) ≈ 0.6853.
  6. Apply the output gate: h_t = 0.5 × 0.6853 = 0.343.

Answer. The new cell state is c_t ≈ 0.839 and the new hidden state is h_t ≈ 0.343.

Exam traps

  • Do not add the gates before multiplying: the forget gate multiplies c_{t-1}, and the input gate multiplies c~_t. c_t is the sum of two products.
  • Do not apply tanh before the output gate multiplies. Use h_t = o_t⊙tanh(c_t), not tanh(o_t⊙c_t).
  • ⊙ is elementwise multiplication. Writing a matrix product changes the gate mechanism and the dimensions.
  • A forget gate near 1 keeps the old cell state; near 0 erases it. Do not reverse this.
  • σ and tanh are not interchangeable: gates use σ to give values in (0,1), while the candidate and output squash use tanh to give values in (−1,1).

4.5 Encoder-decoder sequence-to-sequence models

An encoder-decoder model turns one sequence into another sequence of a different length. The encoder reads the source and compresses it into a context vector c. The decoder starts from c and generates the target one token at a time, feeding each produced token back as the next input. This design powers translation, speech-to-text, summarisation and image captioning. It exists because plain RNNs predict same-length tags or next tokens, while many tasks need a full source sentence read before a full target sentence is written. Some syllabi call it seq2seq or sequence-to-sequence.

You need: 4.2 for RNN cells and 4.1 for sequence tasks.

Encoder, context and decoder

A sequence-to-sequence task maps a source sequence x₁ … xT to a target sequence y₁ … yU. Lengths T and U can differ. Translation is the standard case: an English sentence of 7 words can become a Tamil sentence of 9 words. A same-length tagger from 4.1 does not need this split.

The encoder is an RNN, often an LSTM from 4.4. It reads x₁ … xT in order. Its final hidden state hT becomes the context vector c. Some models use a small summary network on hT, but the basic idea is one fixed-size vector.

P(y₁ … yU | x₁ … xT) = Πt=1U P(yt | y₁ … yt−1, c)

c is the encoder context vector; yt is the target token at step t; y₁ … yt−1 are earlier target tokens; P(yt | ...) is the decoder softmax probability for token yt.

The decoder is a second RNN. It starts with c and a start token. At step t it takes the previous target token and the previous decoder state. It outputs logits zt over the vocabulary. Softmax turns zt into probabilities. The model either picks the highest-probability token or samples.

The fixed vector c is a bottleneck. Every detail of the source must pass through the same c. Long source sentences lose information. The symptom is that translation quality drops as input length grows. Attention in Unit 5 lets the decoder look back at all encoder states instead of only c.

Training: teacher forcing

Training uses pairs of source and target sequences. At decoder step t, the correct previous target yt−1 is fed as input. This is teacher forcing. The decoder never sees its own wrong guess during training, so gradients are stable.

L = −Σt=1U log P(yt = true token | y₁ … yt−1, c)

L is the total cross-entropy loss over the target sequence; log is natural log; true token is the target token at step t.

Backpropagation through time from 4.3 flows through decoder and encoder. The encoder learns a c that helps the decoder.

Teacher forcing creates a mismatch. At inference the true previous token is not available, so the decoder must use its own previous output. A small early error then changes later inputs. Scheduled sampling reduces this: with probability ε feed the true token, with probability 1−ε feed the model's token. ε is often decreased over training.

  • Training input at step t: true yt−1.
  • Inference input at step t: predicted previous token.
  • Never mix the two unless scheduled sampling is explicit.

Inference: greedy and beam search

Inference starts with c and a start token. Greedy decoding picks the token with the largest probability at each step, appends it, and feeds it back. It stops at an end token or at a maximum length. Greedy is fast but one bad early choice cannot be undone.

  1. Set decoder state from c; input the start token.
  2. Compute logits and softmax probabilities.
  3. Pick the argmax token; append it to the output.
  4. If the token is an end token or the length limit is reached, stop; otherwise feed the token back.

Beam search keeps k partial sequences, called beams. Each beam has a score: the sum of log probabilities of its tokens. At each step expand every beam with all vocabulary tokens, keep the k highest scores, and continue. k is beam width. k = 1 is greedy. Beam search costs about k times more than greedy.

score(y₁ … yt) = Σi=1t log P(yi | y₁ … yi−1, c)

score is the log-probability of a partial output; log is natural log; a higher score means a more likely sequence.

Use greedy for quick demos and beam search when quality matters. Older RNN translation systems often used beam width 4 to 10. Length normalisation is needed because log probabilities are negative and longer sequences get lower scores; its variants are left to Unit 5.

Exam traps

  • Feeding the true previous target token at inference is teacher forcing; a model trained that way but run without it must use its own previous output. Mixing the two in one decoding pass is a common exam error.
  • The basic encoder's context is the final hidden state hT, not the full list h₁ … hT. The full list is used by attention in Unit 5.
  • Do not call logits probabilities. Greedy argmax is the same on logits or softmax, but beam scores add log probabilities; applying softmax twice changes the values.
  • Input and output lengths need not match. Seq2seq supports T ≠ U; a same-length tagger does not.
  • The context c is a vector, not a single token or scalar; its size is fixed by the encoder hidden size.

4.6 Word embeddings: word2vec, CBOW and skip-gram

A word embedding turns each word into a short dense vector learned from text, so that words used in similar contexts get similar vectors. word2vec trains these vectors with one small prediction task: CBOW predicts the centre word from its neighbours, skip-gram predicts each neighbour from the centre. One matrix holds a vector per vocabulary word. The vectors are cheap to store, quick to compare with cosine similarity, and serve as the input layer for the recurrent models of this unit. Search ranking, review sentiment and text filters on UPI transaction notes all begin from such vectors.

You need: 4.1 for tokens and sequences, and Unit 1 for the softmax function.

Why words need vectors

A neural network cannot read the word 'cricket'. It needs numbers. The simple encoding is one-hot: number the vocabulary V, of size |V|, and give word w a vector of length |V| holding a single 1. With |V| = 50,000 each vector is 50,000 long, and every pair of words is equally far apart. No meaning is stored.

A word embedding replaces this with a short dense vector of d numbers, usually d = 100 to 300, learned from text. All vectors sit in one embedding matrix E of shape |V| × d; row i is the vector of the i-th word. Write u_w for the input vector of word w.

The distributional hypothesis says words that appear in similar contexts tend to have similar meanings. 'Cricket' and 'IPL' both appear near 'match', 'score' and 'bat'. A model trained to predict words from their neighbours is forced to place such words close in vector space. word2vec is that prediction task.

CBOW: context predicts the centre word

Take a sentence and a centre position t. The context window of size m is the m words on each side: wt−m … wt−1 and wt+1 … wt+m. m is small, often 2 to 5.

CBOW (continuous bag of words) hides the centre word and predicts it from the average of the context vectors, h = (1/2m) Σk ut+k. 'Bag' means order inside the window is ignored.

  1. Pick the 2m context words around position t.
  2. Look up their input vectors u in E.
  3. Average them into the hidden vector h.
  4. Score every vocabulary word: sj = vj · h.
  5. Softmax the scores over all of V.
  6. Loss is −log P(wt | h); backpropagate into E and E′.

Scoring uses a second matrix E′ of output vectors. A candidate word w has output vector v_w; its score against h is the dot product v_w · h. The softmax turns scores into a probability over the whole vocabulary.

P(w | h) = exp(v_w · h) ÷ Σj ∈ V exp(v_j · h)

P(w | h) is the probability the model gives to word w as the centre word; v_w is the output vector of w, a row of E′; h is the hidden vector, the average of the context input vectors in CBOW; · is the dot product; the denominator sums over every word j of V.

Skip-gram reverses the direction: from the centre vector u_c it predicts each context word separately, P(wt+k | u_c) for each k. A sentence of L words gives about L training pairs for CBOW but 2mL for skip-gram. More pairs means more updates for rare words, so skip-gram often gives better vectors for them, but it trains slower; CBOW is faster and slightly better on frequent words.

Negative sampling, GloVe and cosine similarity

The softmax denominator sums over |V| words, which is 50,000 dot products per step when |V| = 50,000. Negative sampling avoids this: keep the true (context, centre) pair as a positive example, draw k random words (k = 5 to 20) as negatives, and train a logistic classifier to accept the positive pair and reject the negatives. Each step then touches only k + 1 output vectors.

GloVe takes a different route. Count co-occurrences Xij, the number of times word j falls in the window of word i, then fit vectors so that v_i · v_j + b_i + b_j ≈ log Xij, weighting down very frequent pairs. It uses global counts once instead of streaming windows. Both methods give static embeddings: one vector per word, identical in every sentence.

cos(u, v) = (u · v) ÷ (‖u‖ ‖v‖)

u and v are two word vectors; u · v is the dot product; ‖u‖ = √(u · u) is the Euclidean length; the value lies in [−1, 1], and 1 means the same direction.

Cosine similarity also supports meaning arithmetic: vking − vman + vwoman lands closest to vqueen in a well-trained space. It works often, not always.

Exam traps

  • Reversing the tasks: CBOW predicts the centre word from the context; skip-gram predicts each context word from the centre.
  • Putting only the window words in the softmax denominator. It sums over the whole vocabulary V, which is exactly why training is costly.
  • Treating the raw scores s_w = v_w · h as probabilities. They are unbounded; only after exp and division by Z are they probabilities.
  • Quoting the output matrix E′ as the word vectors. The vectors people use and compare are the input rows u_w of E.
  • Assuming one vector per meaning. word2vec gives one vector per word type, so 'bank' gets a single blended vector.

4.7 Applications: language modeling, translation and image captioning

A recurrent network that predicts the next word is the engine behind three headline tasks. Language modelling learns the probability of a sentence. Translation reads one sequence and writes another. Image captioning turns a picture into a short sentence. The core loop is identical in all three: keep a hidden state, produce a probability over the vocabulary, score or pick the next token. Only the encoder that fills the first state and the head that reads it change. That is why one unit covers all of them.

You need: the RNN hidden state, encoder-decoder models, word embeddings, and CNN feature vectors from Unit 3.

Language modelling: chain rule, cross-entropy, perplexity

A language model gives a probability to every sentence. Storing one number per sentence is impossible, so the sentence is broken into next-word predictions with the chain rule of probability.

P(w1, w2, …, wT) = ∏t=1T P(wt | w1, …, wt−1)

wt is the token at position t; T is the number of tokens; P(wt | w1…wt−1) is the softmax probability the model gives to the true token at step t.

An RNN computes each factor. The embedding of the previous word and the previous hidden state give the new hidden state ht. A softmax over the vocabulary V turns ht into a probability for every possible next word. In training the true previous words are fed in (teacher forcing) and the loss is taken on the correct next word.

L = −(1/T) Σt=1T ln P(wt | w1…wt−1),   perplexity = exp(L)

L is the average negative log-likelihood per token, in nats; ln is the natural logarithm; exp(L) = eL; perplexity is the effective number of equally likely words the model is choosing between.

Lower perplexity is better. A model that puts probability 1 on every true word has L = 0 and perplexity 1. A perplexity of 3 means the model is as unsure as a fair guess among 3 words. The same model sits inside phone keyboard suggestions, speech-recognition rescoring, and the decoder half of a translator.

Translation and sequence labelling

In translation the input and output are different sequences, often of different lengths. The encoder-decoder from 4.5 handles this. An encoder LSTM reads the source sentence into a context vector c. A decoder LSTM starts from c and emits target words until an end-of-sentence token appears.

P(y1…yM | x1…xN) = ∏t=1M P(yt | y1…yt−1, c)

x1…xN is the source sentence of length N; y1…yM is the target of length M; c is the encoder's context vector; each factor is one decoder softmax.

Training uses the same per-token cross-entropy as language modelling. At test time the true previous target is unknown, so the decoder feeds back its own last output. Small errors can then push the state away from anything seen in training.

BLEU scores a generated sentence against one or more human references. It counts matching n-grams (single words, pairs, triples), takes precision for each order, combines the orders with a geometric mean, and applies a brevity penalty so a short, safe output cannot win. BLEU lies between 0 and 1, and higher is better. It is an evaluation metric, not the loss you train on.

Sequence labelling is the many-to-many case: part-of-speech tagging and named-entity recognition read T words and emit T tags. The recurrent stack is unchanged. Only the head changes, to a per-step softmax over the tag set.

Image captioning

A picture is not a sequence; a caption is. The bridge is a CNN from Unit 3. A pretrained network such as VGG or ResNet reads the image and outputs a fixed feature vector v of a few hundred to a couple of thousand numbers. The decoder RNN takes v as its first input and then generates words one step at a time.

x0 = Wvv + bv,   ht = tanh(Whht−1 + Wxxt + b),   P(wt) = softmax(Woht)

v is the CNN feature vector; Wv projects it to the RNN input size; xt is the embedding of the previous word for t ≥ 1; ht is the hidden state; Wo maps the state to one score per vocabulary word.

Everything else is a language model. Training pairs each image with its human caption and minimises the per-word cross-entropy. At test time the decoder starts from v and a start token, picks the most likely word (greedy) or keeps a few candidate sentences alive (beam search), and stops at the end token. BLEU is also used to score captions against references.

Why a feature and not raw pixels: a 224×224 colour image is 150,528 input numbers, most of them redundant. A CNN vector of about 512 numbers already encodes objects and scene. The decoder then only has to learn language.

Video and time series: the advanced end

A video is a sequence of frames, so the captioning recipe extends to it. Run a CNN on each frame or clip and feed the frame features to an RNN that outputs an action label. Adding time inside the convolution gives 3D CNNs and two-stream models that see appearance and motion separately. Only a few universities teach these spatio-temporal models in detail. The same many-to-one RNN forecasts sensor time series, such as hourly electricity load or daily UPI transaction counts.

Worked example

Question. An RNN language model scores the sentence 'the cat sat' as follows: P(the) = 0.5 at step 1, P(cat | the) = 0.4 at step 2, and P(sat | the cat) = 0.2 at step 3. The sentence ends after 'sat'. (a) Find the probability of the whole sentence. (b) Find the average cross-entropy loss in nats per token. (c) Find the perplexity. Use natural logarithms.

  1. Chain rule: P(the cat sat) = P(the) × P(cat | the) × P(sat | the cat) = 0.5 × 0.4 × 0.2.
  2. Multiply: 0.5 × 0.4 = 0.20; then 0.20 × 0.2 = 0.04. So the sentence probability is 0.04, that is 4%.
  3. Take natural logs: ln 0.5 = −0.6931, ln 0.4 = −0.9163, ln 0.2 = −1.6094. Their sum is −3.2189 nats.
  4. Average negative log-likelihood: L = 3.2189 / 3 = 1.0730 nats per token.
  5. Perplexity = exp(L) = exp(1.0730) = 2.92. Check: (1/0.04)^(1/3) = 25^(1/3) = 2.92.

Output

0.04
1.073
2.92

Answer. Sentence probability P = 0.04 (4%), average loss L = 1.073 nats per token, and perplexity = 2.92.

Exam traps

  • Perplexity is exp of the average negative log-likelihood, not the product of probabilities. For the worked example, 25 = 1/0.04 is the reciprocal probability; 25^(1/3) = 2.92 is the perplexity.
  • Lower perplexity is better. A perplexity of 1 is a perfect model, and perplexity cannot be compared across models that use different tokenizers or vocabulary sizes.
  • Image captioning feeds a CNN feature vector into the decoder, never raw pixels. The CNN is the encoder; the RNN only writes words.
  • Teacher forcing is a training trick: the true previous word is supplied. At inference the model eats its own output, so the two settings are not the same.
  • BLEU is an evaluation metric, not the training loss, and a higher BLEU is better. The brevity penalty exists so that a short output with few words cannot get high precision for free.

Check yourself

Remember State the chain rule that a language model uses to score a sentence of T tokens. 2 marks

P(w1…wT) = ∏ P(wt | w1…wt−1). Each factor is a next-word probability produced by the softmax at step t.

Remember Define perplexity and say whether a lower or higher value is better. 2 marks

Perplexity = exp(L), where L is the average negative log-likelihood per token in nats. It is the effective number of equally likely words the model is choosing among. Lower is better; 1 is perfect.

Understand Why does an image captioning model pass a CNN feature vector to the decoder instead of raw pixels? 3 marks

Raw pixels for a 224×224 colour image are 150,528 numbers and mostly redundant. The CNN compresses them to a few hundred numbers that already encode objects and scene. The decoder then only learns language, which trains faster and generalises better.

Understand Why does BLEU include a brevity penalty on top of n-gram precision? 3 marks

Precision alone rewards very short outputs, because one correct word out of one gives precision 1. The brevity penalty shrinks the score when the output is much shorter than the reference, so recall matters too.

Apply A model gives P(a) = 0.8, P(b | a) = 0.5 and P(c | a b) = 0.5, and the sentence ends after c. Find the sentence probability and the perplexity. 4 marks

P = 0.8 × 0.5 × 0.5 = 0.2. Logs: ln 0.8 = −0.2231, ln 0.5 = −0.6931 twice, sum = −1.6094; L = 1.6094/3 = 0.5365 nats; perplexity = exp(0.5365) = 1.71, which equals 5^(1/3).

Analyze A translator is trained with teacher forcing but used without it. Explain the mismatch and give one visible symptom. 5 marks

In training the decoder always receives the correct previous word, so it never learns to recover from its own errors. At test time it conditions on its own output, and one wrong word moves the hidden state off the training distribution. Symptom: the first words look fine and the sentence then degrades, drifts or repeats.

Analyze Model A has perplexity 20 and model B has 18 on the same test text. Which is better, and why can two models with different vocabularies not be compared by perplexity? 4 marks

B is better, because lower perplexity means a higher average probability per token. Perplexity is defined per token; if the tokenizers or vocabulary sizes differ, the same text becomes a different number of tokens, so the numbers sit on different scales and cannot be compared.

Takeaways

  1. Sequence problems differ by shape — many-to-one, same-length many-to-many, and sequence-to-sequence — not by the kind of data.
  2. An RNN is one cell reused at every step, so the number of parameters stays fixed while the sequence length changes.
  3. Unfolding turns the loop into a chain; that chain is what makes backpropagation through time possible.
  4. BPTT sums gradients from every time step into the same shared weights, which is exactly why long sequences are hard to train.
  5. The vanishing gradient is a product of many small factors; gated cells replace that product with an additive path and a sigmoid gate that learns to stay near 1.
  6. Exploding gradients are cheap to fix — clip the norm — while vanishing gradients need an architectural change such as LSTM or GRU gates.
  7. An encoder–decoder splits the job in two: read the whole input, then write the output one token at a time.
  8. Word2vec learns meaning from co-occurrence alone; similar words end up with similar vectors, and vector arithmetic starts to make sense.
  9. Language modelling, translation and image captioning share the same recurrent stack; only the encoder and the output head change.

Exam question bank

Long answers here are usually graded on the unfolded diagram with correct shapes, the BPTT gradient sum written out, the LSTM gate equations with the additive cell state, and the encoder–decoder data flow.

Remember and understand

Understand Explain the three shapes of sequence learning problems with one example each, and say what the loss looks like in each case. 12 marks

Many-to-one: one label for the whole sequence, loss on the last hidden state (sentiment); Many-to-many same length: one tag per step, loss summed over T steps (POS tagging, NER); Many-to-many sequence-to-sequence: lengths differ, loss summed over the target steps only (translation); Note that the network can be identical; only the output head and the loss change; Mention variable length and padding or bucketing.

Understand Draw an RNN cell and its unfolding over three time steps. Write the forward equations and explain why the weights are shared. 12 marks

h_t = tanh(W_x x_t + W_h h_{t−1} + b), y_t = softmax(W_y h_t); Define each symbol with its shape: x_t is d×1, W_x is k×d, W_h is k×k; Unfolded graph: same cell drawn T times, h_{t−1} → h_t edge between copies; Weight sharing keeps parameter count independent of T and lets one pattern be learned at any position; The stored hidden state is the only thing passed between steps at inference.

Remember State the LSTM forward equations for the forget, input, output gates and the cell state, and define every symbol. 12 marks

f_t = σ(W_f [h_{t−1}, x_t] + b_f), i_t, o_t similarly; Candidate g_t = tanh(W_g [h_{t−1}, x_t] + b_g); C_t = f_t ⊙ C_{t−1} + i_t ⊙ g_t; h_t = o_t ⊙ tanh(C_t); σ is the logistic sigmoid giving values in (0,1); ⊙ is element-wise product; Say what each gate does: erase, write, expose.

Understand What is the vanishing gradient problem in an RNN? Show where the repeated product comes from and why gating helps. 12 marks

∂h_t/∂h_{t−1} contains W_hᵀ diag(tanh′(·)); the chain over T steps multiplies these; Products of many factors below 1 shrink to zero; above 1 they explode; Effect: the model cannot learn dependencies spanning many steps; Gating gives an additive path ∂C_t/∂C_{t−1} = f_t, so the gate can hold near 1 and keep the gradient alive; Mention that this is mitigation, not a cure.

Apply

Apply A character-level RNN is trained on a 50-symbol alphabet with a hidden size of 128. Work out the parameter count of the cell and of the output layer. 10 marks

Input weights: 128 × 50 = 6400; hidden weights: 128 × 128 = 16384; bias 128; Cell total 22,912 parameters; Output layer 50 × 128 + 50 = 6450; Total about 29,362 — and it does not change when the sequence length grows; Contrast with a fully connected layer over a fixed window, where it would.

Apply Describe how you would train a sequence-to-sequence translator for English to Tamil. Cover data preparation, teacher forcing, decoding and evaluation. 14 marks

Tokenise both sides, build vocabularies, append start and end tokens, pad batches; Encoder reads the source and its final state becomes the context vector; Decoder input at each step is the previous target token during training (teacher forcing); the loss is cross-entropy on target tokens only, padding masked; Decoding at test time: greedy or beam search, feeding back the model's own output; Evaluate with BLEU; note exposure bias from teacher forcing; Mention clipping and gradient accumulation for long batches.

Apply Explain how word2vec skip-gram is trained with negative sampling. Give the objective and say why negative sampling is used. 12 marks

For a centre word w and a true context word c, maximise σ(u_c · v_w); For each of k sampled noise words c′, maximise σ(−u_{c′} · v_w); Objective: Σ log σ(u_c·v_w) + Σ log σ(−u_{c′}·v_w); Full softmax over a 10⁵-word vocabulary is too expensive, so K negative pairs replace it; Negative words drawn from a unigram distribution raised to the 3/4 power; Resulting vectors show semantic similarity and analogy structure.

Apply Show how an image captioning system is built from a CNN and an RNN. Label the shape of every tensor at the join. 12 marks

CNN (for example ResNet) turns the image into a feature map; global pooling gives a vector of size D; That vector seeds the RNN's first hidden state, or is fed as x₀ at every step; The word sequence is embedded to dimension E and fed step by step; the output head is a softmax over the vocabulary; Trained with cross-entropy using teacher forcing on caption–image pairs; Decoding with greedy or beam search gives the caption.

Analyze and evaluate

Analyze Compare LSTM and GRU cells: equations, parameter count and when you would choose one over the other. 12 marks

GRU: z_t = σ(W_z[h_{t−1},x_t]), r_t = σ(W_r[h_{t−1},x_t]), h̃ = tanh(W[r_t⊙h_{t−1},x_t]), h_t = (1−z)⊙h_{t−1} + z⊙h̃; Two gates and no separate cell state, so fewer parameters — roughly three quarters of an LSTM of the same width; LSTM's separate cell state gives a cleaner additive path and better very-long memory; GRU trains faster on small data; differences are often small and data-dependent; Both are replaced by attention or transformers when the sequence is long or the data is large.

Evaluate A deep RNN shows smooth training loss but the validation loss suddenly jumps to NaN. Diagnose the cause and list the remedies in order. 12 marks

NaN loss points to exploding gradients, not overfitting; Confirm by logging the gradient norm per step; First fix: clip the gradient norm to a threshold such as 1 to 5; Then lower the learning rate, and consider a smaller hidden size; Architectural: use LSTM or GRU, add layer normalisation; Data: shorter truncated backprop windows, batch-size sanity check.

Evaluate Why does a plain encoder–decoder fail on very long sentences, and how does attention change the picture? Refer to query, key and value. 14 marks

The whole source is squeezed into one fixed-size context vector; detail is lost as length grows; Attention keeps every encoder state and lets the decoder look back at all of them; Query from the decoder state, keys and values from the encoder states; Scores q·k scored, softmaxed into weights, then the weighted sum of values is the context; Gradients reach distant source positions directly, shortening the path; Mention multi-head attention and the move to transformers.

Analyze Explain backpropagation through time in full: the unfolded graph, the gradient recursion, and truncated BPTT. 14 marks

Unfold to T steps; each copy has its own local gradient but shares weights; ∂L/∂W_h = Σ_t ∂L_t/∂W_h, summed over steps because of weight sharing; Recursion: δ_t = (W_hᵀ δ_{t+1}) ⊙ (1 − h_t²) + output term; Cost is O(T) memory and time; forward states must be kept for the backward pass; Truncated BPTT splits long sequences into windows and carries the state forward; Link the recursion's repeated product to vanishing and exploding gradients.

Evaluate Word embeddings learned on a news corpus are used in a hospital's report classifier. Discuss what can go wrong and how you would evaluate the vectors before trusting them. 12 marks

Domain shift: clinical vocabulary and abbreviations are unseen or wrongly placed; Bias encoded from the corpus: gender or caste associations carried into the vectors; Out-of-vocabulary words get no vector; subword models reduce this; Evaluate on intrinsic tasks (similarity, analogy) and extrinsic tasks (the classifier itself); Inspect nearest neighbours of sensitive words; Fine-tune on in-domain text or use contextual models instead of static vectors.

Glossary

Attention
A weighted lookup where a query is compared with keys and the weights are applied to values.
Backpropagation through time
Backpropagation applied to the unfolded RNN graph, summing gradients over time steps into the shared weights.
Beam search
Decoding that keeps the k best partial sequences at each step instead of only the best one.
CBOW
Continuous bag of words; the word2vec variant that predicts a centre word from its context words.
Cell state
The LSTM's long-term memory line, changed additively by the forget and input gates.
Context vector
A fixed-size vector summarising the input sequence, passed from encoder to decoder.
Decoder
The network that produces the output sequence one token at a time from the encoder's representation.
Encoder
The network that reads the input sequence and produces a representation of it.
Exploding gradient
A gradient that grows without bound through many steps, producing NaN or Inf in training.
Forget gate
Decides what fraction of the previous cell state to keep.
Gate
A sigmoid layer whose outputs between 0 and 1 scale how much of a signal passes through.
Gradient clipping
Rescaling the gradient to a maximum norm before the update, the standard cure for exploding gradients.
GRU
Gated recurrent unit; a two-gate cell with a reset gate and an update gate and no separate cell state.
Hidden state
The vector an RNN passes from one step to the next, summarising everything seen so far.
Image captioning
Generating a sentence that describes an image, usually with a CNN encoder and a recurrent decoder.
Input gate
Decides how much of the new candidate memory to write into the cell state.
Negative sampling
Training shortcut that replaces the full softmax with a few true and a few random noise pairs.
Output gate
Decides how much of the cell state to expose as the hidden state.
Perplexity
The exponential of the average negative log-likelihood per token; lower is better.
Skip-gram
The word2vec variant that predicts context words from one centre word.
Teacher forcing
Feeding the true previous target token to the decoder during training instead of its own prediction.
Token
One unit of a sequence — a character, a word or a subword piece.
Truncated BPTT
Running BPTT on fixed-length windows of a long sequence and carrying the hidden state forward between windows.
Unfolding
Redrawing a recurrent network as one copy of the cell per time step, joined in a chain.
Vanishing gradient
A gradient that shrinks toward zero as it travels back through many steps, so early steps barely learn.
Word embedding
A dense learned vector for a word, in which distance reflects similarity of use.
