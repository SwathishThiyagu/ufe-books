3.1 The convolution operation: kernels, padding and stride

The convolution operation slides a small kernel over an image and sums products to build a feature map. The map records where a pattern such as an edge occurs. A phone photo is a height × width × colour-channel tensor. A kernel is a tiny learnable tensor. Convolution is the main layer of a CNN: low layers detect edges, deeper layers detect parts. It is used in face unlock, medical scans and road-sign reading.

You need matrix multiplication and forward propagation from Unit 1, plus gradients from Unit 2; training comes in 3.3.

Sliding a kernel over an image

An image tensor X has shape H × W × C. H is height in pixels, W is width, C is channels: 3 for RGB, 1 for grey. A kernel K has shape K_h × K_w × C and one bias b. Some syllabi call a kernel a filter or a mask.

Place the kernel on a patch. Multiply each weight by the pixel under it, sum all products, add b. The result is one cell of the feature map Y. Slide and repeat.

Strict mathematics flips the kernel before sliding. Libraries do not flip; they compute cross-correlation. Everyone still says convolution. The flip would only mirror learned weights.

y[i,j] = b + Σ<sub>u=0</sub><sup>K_h−1</sup> Σ<sub>v=0</sub><sup>K_w−1</sup> Σ<sub>c=0</sub><sup>C−1</sup> K[u,v,c] × X[iS+u, jS+v, c]

y[i,j] is one output cell at output row i, column j; b is bias; K[u,v,c] is kernel weight at row u, column v, channel c; X[...] is input pixel; S is stride.

The feature map records where the kernel pattern occurs. A 3×3 vertical-edge kernel with left column +1 and right column −1 gives a high value at a vertical edge.

Padding, stride and output size

Padding P adds P rows and P columns on every side, so 2P extra rows and columns. Stride S is the step between kernel positions. S=2 skips one pixel each move.

H_out = floor((H + 2P − K_h)/S) + 1

H_out is output height; H is input height; P is padding per side; K_h is kernel height; S is stride; floor rounds down. Use W, W_out and K_w for width.

Only complete windows count, so take floor. P=0 is valid padding. Stride reduces output size; padding can keep it.

  • Padding same keeps H_out=H when S=1 and K_h,K_w are odd.
  • Use P=(K−1)÷2: K=3 gives P=1; K=5 gives P=2.
  • Border pixels get fewer visits, so padding protects edge information.

Channels, filters and parameter count

Multi-channel input has a kernel of the same depth C. The formula sums over c. A colour edge detector has three 3×3 slices, one per channel.

One kernel gives one output channel. F kernels give F output channels. The output tensor is H_out × W_out × F.

N<sub>params</sub> = K_h × K_w × C<sub>in</sub> × C<sub>out</sub> + C<sub>out</sub>

Nparams is learnable parameter count; K_h, K_w are kernel height and width; Cin is input channels; Cout is number of filters; the last Cout is one bias per filter.

Example: 3×3 kernel, Cin=3, Cout=16 gives 3×3×3×16+16 = 448 parameters.

A 1×1 convolution has K_h=K_w=1. It cannot see neighbours; it mixes channels at each pixel. It is used to change channel count cheaply.

Visualization draws each kernel as a small grid. Early kernels look like edge or blob detectors; deeper kernels are less readable. See 3.7.

Worked example

Question. An input image slice is I = [[1,2,3,0],[0,1,2,3],[3,2,1,0],[0,1,2,1]]. A kernel is K = [[1,0,−1],[1,0,−1],[1,0,−1]]. Use stride S = 1 and padding P = 0. Find the output size and compute the full feature map.

  1. H=4, W=4, K=3, S=1, P=0. H_out=floor((4+0−3)/1)+1=2; W_out=2. Output is 2×2.
  2. Top-left window rows 0–2, columns 0–2: [[1,2,3],[0,1,2],[3,2,1]]. Row products: 1−3=−2; 0−2=−2; 3−1=2. Sum = −2−2+2 = −2. y[0,0]=−2.
  3. Top-right window rows 0–2, columns 1–3: [[2,3,0],[1,2,3],[2,1,0]]. Row products: 2; −2; 2. Sum = 2−2+2 = 2. y[0,1]=2.
  4. Bottom-left window rows 1–3, columns 0–2: [[0,1,2],[3,2,1],[0,1,2]]. Row products: −2; 2; −2. Sum = −2+2−2 = −2. y[1,0]=−2.
  5. Bottom-right window rows 1–3, columns 1–3: [[1,2,3],[2,1,0],[1,2,1]]. Row products: −2; 2; 0. Sum = −2+2+0 = 0. y[1,1]=0.

Answer. The output size is 2×2 and the feature map is [[−2, 2], [−2, 0]]; bias is 0.

Exam traps

  • Using (H−K)/S without floor; 4×4 with K=3, S=2 gives floor(0.5)+1=1, not 1.5.
  • Adding P once instead of 2P. One pixel border on both sides adds 2 to H and W.
  • Forgetting depth Cin in parameter count. A 3×3 kernel on RGB has 27 weights per filter, not 9.
  • Mixing stride with kernel size: stride is the step between windows, not the window width.
  • Thinking deep learning flips the kernel. It computes cross-correlation and calls it convolution.

3.2 Pooling layers and non-linearities

Pooling shrinks each feature map by summarising small windows, so later layers see fewer numbers and a wider view of the image. Non-linearities, usually ReLU, let a CNN learn curved boundaries instead of only straight sums. Together they cut computation and add the power that makes a stack of convolutions more than one big linear filter. You meet them in every image classifier, from a phone camera to a hospital scan. This chapter shows the window arithmetic, the common pooling types and the activation that follows each convolution.

You need: 3.1 for feature maps, kernels, padding and stride, and Unit 1 for the activation functions sigmoid, tanh and ReLU.

Pooling shrinks a feature map

After a convolution layer, each channel holds a feature map: a grid of numbers that says how strongly a pattern appears at each position. A pooling layer reduces that grid. It slides a window of side p pixels over the map, just as convolution slides a kernel. Pool size p is the window side in cells; stride s is how far the window moves between outputs. A pooling layer usually uses s = p and no padding, so windows do not overlap and the map shrinks by the same factor on each side.

Max pooling outputs the largest value in each window. Average pooling outputs the mean. Both have no learnable weights: the operation is fixed. If the input side is n, the output side is O = floor((n − p)/s) + 1. Here n is input height or width in cells, p is pool size, s is stride, and floor rounds down. The same formula works for height and width separately. For n = 4, p = 2, s = 2, O = floor((4 − 2)/2) + 1 = 2.

O = floor((n − p)/s) + 1

O is the output side in cells; n is the input side in cells; p is the pool window side; s is the stride. This assumes no padding.

Global average pooling is the extreme case: it averages the whole H × W map and gives one number per channel. A classifier can then use one value per channel instead of a long flattened vector. Some syllabi call pooling subsampling or downsampling. The name changes; the window arithmetic does not.

Max, average and global pooling

Max pooling keeps the strongest response in a window. If a window holds [1, 3, 5, 6], max pooling writes 6. Average pooling writes (1 + 3 + 5 + 6) / 4 = 3.75. Max pooling is common in image classification because a strong edge or texture survives small shifts; average pooling keeps a smoother summary.

Pooling has no weights, but backpropagation still needs a rule. For max pooling, the gradient from the output goes only to the input cell that was the maximum; all other cells in that window get zero gradient. If two cells tie, share the gradient or send it to the first, consistently. For average pooling, the gradient is divided equally over the window, so each cell gets output gradient / (p × p).

Global average pooling averages over the full map: for a channel of height H and width W, it adds all H × W values and divides by H × W. Modern classifiers often end with global average pooling, then a dense layer. It has no weights and forces one summary per channel.

Non-linearities after convolution

A convolution is linear: it multiplies inputs by kernel weights and adds. Two convolution layers with no non-linearity between them collapse into one linear operation, so depth buys nothing. A non-linearity is a fixed elementwise function applied after the convolution (and often after pooling). It bends the output, so the network can fit curved boundaries.

The standard choice is ReLU: f(x) = max(0, x). For each input x, ReLU returns x if x > 0 and 0 otherwise. Its derivative is 1 for x > 0 and 0 for x < 0; at x = 0 pick 0 or 1 in code. ReLU is cheap and does not saturate for large positive values. Leaky ReLU is f(x) = max(αx, x) with a small α such as 0.01, so negative inputs keep a small slope. Sigmoid σ(x) = 1 / (1 + e^(−x)) and tanh squash values into (0, 1) and (−1, 1); they appear in older blocks and in gates, but plain sigmoid can saturate.

Non-linearities have no learnable weights. They are applied per cell, so the feature map shape does not change. In code, a convolution block is often Conv → ReLU → Pool; see 3.3 for the full stack.

Worked example

Question. An input feature map is the 4×4 matrix [[1,3,2,4],[5,6,1,2],[0,2,7,1],[3,1,4,8]]. Apply max pooling with a 2×2 window and stride 2. Give the output matrix and its shape.

  1. The window side is p = 2 and stride is s = 2, so the four windows do not overlap. Output side is O = floor((4 − 2)/2) + 1 = 2, so the answer is a 2 × 2 grid.
  2. Top-left window (rows 1–2, columns 1–2): values 1, 3, 5, 6; maximum = 6.
  3. Top-right window (rows 1–2, columns 3–4): values 2, 4, 1, 2; maximum = 4.
  4. Bottom-left window (rows 3–4, columns 1–2): values 0, 2, 3, 1; maximum = 3.
  5. Bottom-right window (rows 3–4, columns 3–4): values 7, 1, 4, 8; maximum = 8.
  6. Place the four maxima in reading order: row 1 = [6, 4], row 2 = [3, 8].

Answer. The max-pooled output is [[6, 4], [3, 8]], a 2 × 2 matrix.

Exam traps

  • Pooling has no learnable weights, but p and s still change the output shape; do not call pooling a convolution.
  • Max pooling and average pooling are different reductions: for the window [1,3,5,6], max gives 6 and average gives 3.75.
  • ReLU is not pooling: ReLU changes values cell by cell and keeps the shape; pooling reduces the spatial shape.
  • In the output-size formula, use floor((n − p)/s) + 1. With n = 4, p = 2, s = 2 the output side is 2, not 4.
  • During backprop, max pooling sends gradient only to the maximum cell; average pooling spreads it equally over the window.

Analyze Compare the gradient flow of max pooling and average pooling. 5 marks

Max pooling passes the output gradient only to the input cell that was the maximum; other cells get zero. Average pooling divides the output gradient equally over all cells in the window. Ties need a consistent rule, such as sharing the gradient.

3.3 CNN architecture: building a basic CNN

A basic CNN turns an image into a class score by stacking simple blocks. Each block applies convolution to find local patterns, ReLU to keep positive responses, and pooling to shrink the map. After two or three such blocks, the small feature maps are flattened into a vector and passed through dense layers. A final softmax gives one probability per class. The same design classifies hand-written digits, product photos and medical images. This chapter follows one small network from a 32×32×3 input to 10 output classes, tracking shapes and parameter counts at each layer.

You need 3.1 and 3.2, plus softmax and cross-entropy from Unit 1.

The repeated block: Conv, ReLU, Pool

A basic CNN is a stack of layers in a fixed order. A convolution layer holds small learnable kernels. It slides each kernel over the input and writes a feature map. With C_in input channels and C_out kernels, the layer outputs C_out maps. ReLU then applies max(0, x) element by element. It adds no weights. Max pooling with a 2×2 window and stride 2 takes the largest value in each non-overlapping 2×2 patch, so H and W halve.

The block Conv → ReLU → Pool repeats. Early blocks see edges and colour patches; later blocks combine them into parts such as corners, wheels or leaf shapes. After the last pool, Flatten turns a 3-D tensor H×W×C into a vector of length H·W·C. Dense layers multiply that vector by weight matrices. The last dense layer has one unit per class. Softmax converts its scores into probabilities that sum to 1. For 10 classes, the final layer has 10 units. Some syllabi call this the architecture of a CNN.

Tracking shape and parameter count

Write the input as H×W×C. A convolution with a K×K kernel, padding P and stride S gives a new height:

H_out = floor((H + 2P − K)/S) + 1

H is input height; K is kernel size; P is padding pixels added to each side; S is stride; floor rounds down. Use W in place of H for width.

params = K×K×C_in×C_out + C_out

C_in is input channels; C_out is number of filters; the last C_out is one bias per filter. Drop it if bias is off.

Pooling uses the same size formula with K = 2, P = 0 and S = 2. It has no weights. The table tracks one small network with input 32×32×3 and 10 classes.

Why each layer exists

Each layer type has one job. Convolution layers learn filters; backpropagation adjusts their numbers to lower the loss. ReLU adds a bend so stacked convolutions can model non-linear patterns. Pooling has no weights; it shrinks the map and makes small shifts less harmful. Flatten only changes the layout. Dense layers mix features from all positions, and the final softmax turns scores into class probabilities. In a 10-class problem the last dense layer has 10 units; softmax does not change the count.

Channels usually grow while height and width shrink. The example uses 16 then 32 filters. A 32×32×3 input keeps compute small. Larger models follow the same plan with more blocks; see 3.4. Training uses backpropagation and an optimizer from Unit 2.

Conv B uses 32 filters of size 3×3, padding 1, stride 1, then another 2×2 max pool with stride 2. Find the output shape after each block, the flatten vector length, and the number of parameters in Conv A.

  1. Input: H = 32, W = 32, C = 3.
  2. Conv A: H_out = floor((32 + 2×1 − 3)/1) + 1 = 32. W_out = 32. C_out = 16. Shape = 32×32×16.

  • Forgetting input channels in parameter count: a 3×3 kernel with 3 input channels and 16 filters has 3×3×3×16 weights, not 3×3×16.
  • Forgetting channels in the flatten size: 8×8×32 is 2048, not 64.
  • Padding 1 with a 3×3 kernel keeps H and W only when stride is 1; stride 2 halves them.
  • Pooling layers have no weights and no biases; do not add them to the parameter total.
  • Softmax does not change the number of outputs; a dense layer with 10 units still has 10 scores before softmax.

3.4 Classic architectures: AlexNet, ZFNet and VGG

In 2012 a deep CNN called AlexNet won ImageNet and beat hand-designed features. ImageNet classification has 1000 classes. AlexNet showed a recipe: many convolution layers, ReLU, dropout, data augmentation and max pooling. ZFNet tuned AlexNet by shrinking the first kernel. VGG then showed that repeating small 3×3 kernels builds a deeper, cleaner network. These three models mark the shift from feature engineering to learned features. You meet them in exams because they explain why modern CNNs look the way they do.

You need 3.3 for the basic convolution–ReLU–pool stack and 3.1 for kernel size, padding and stride.

AlexNet: the ImageNet breakthrough

AlexNet is the 2012 ImageNet winner that made deep CNNs practical. ImageNet classification has 1000 classes. The network takes an image and outputs 1000 softmax scores. AlexNet has 5 convolution layers and 3 fully connected layers. The last fully connected layer feeds the softmax.

Its recipe matters more than exact layer counts. Convolution layers and the first two fully connected layers use ReLU, not sigmoid or tanh. ReLU trains faster and avoids flat gradients. The first convolution uses a large 11×11 kernel with stride 4. Later convolutions use smaller kernels. Max pooling shrinks the feature maps. Dropout switches off random hidden units in the fully connected layers during training. Data augmentation makes extra training images by cropping and flipping. These choices reduce overfitting on a large network.

AlexNet beat hand-designed features such as SIFT and HOG. That result told the field: learn features from data instead of designing them by hand. The basic convolution–ReLU–pool stack is in 3.3; AlexNet is that stack at ImageNet scale.

ZFNet: a tuned AlexNet

ZFNet is a tuned AlexNet. It keeps the same overall 5 convolution + 3 fully connected layout. The main change is the first convolution: a 7×7 kernel with stride 2, not AlexNet's 11×11 with stride 4. The first convolution has 96 filters. A smaller kernel and a smaller stride keep more detail in the early feature maps.

The team used visualization to see what filters learned and then adjusted the architecture. That visualization method is covered in 3.7. ZFNet won ImageNet 2013. It shows architecture design as inspection and tuning, not guesswork. In exams, remember the first kernel sizes: AlexNet 11×11, ZFNet 7×7, VGG 3×3. Do not swap them.

VGG: deeper with small kernels

VGG asks a simple question: what if every convolution is small? VGG16 uses only 3×3 convolutions with stride 1 and pad 1, plus 2×2 max pooling with stride 2. Pad 1 keeps the height and width unchanged after each 3×3 convolution. The pool then halves both.

VGG16 has five convolution blocks. The channel counts are 64, 128, 256, 512, 512. Each block repeats convolutions before pooling. The block pattern is: two conv64, pool; two conv128, pool; three conv256, pool; three conv512, pool; three conv512, pool. After the last pool the tensor is 7×7×512. It is flattened and passed to three fully connected layers: 4096, 4096, 1000. The 1000 outputs go to softmax. VGG16 has 13 convolution layers and 3 fully connected layers, so 16 weight layers in total.

Why small kernels? A stack of three 3×3 convolutions sees a 7×7 region. It has 27C² weights for C channels, while one 7×7 convolution has 49C². The stack uses fewer parameters and has three ReLUs instead of one. This is the main design lesson: depth plus small kernels gives a large receptive field with less weight.

VGG16 is simple and uniform, so it is easy to describe and reuse. It is also expensive: about 138 million parameters, mostly in the fully connected layers. It is a common pretrained backbone for 3.6.

Design trends

Read the three models as a trend. AlexNet has 8 weight layers, a first kernel of 11×11 and stride 4. ZFNet has 8 weight layers, a first kernel of 7×7 and stride 2. VGG16 has 16 weight layers, and every kernel is 3×3 with stride 1 and pad 1. The direction is deeper and smaller kernels. The cost is more parameters and more compute.

The first convolution alone shows the change. AlexNet: 11×11×3×96 + 96 = 34,944 parameters. ZFNet: 7×7×3×96 + 96 = 14,208. VGG: 3×3×3×64 + 64 = 1,792. Smaller first kernels spend fewer weights on raw pixels and leave more capacity for deeper layers. Some syllabi call this the evolution of CNN architectures. The next step is parallel branches and shortcuts, covered in 3.5.

Worked example

Question. VGG16 takes a 224×224×3 image. Its first block is: Conv 3×3 with 64 filters, pad 1, stride 1; Conv 3×3 with 64 filters, pad 1, stride 1; MaxPool 2×2 with stride 2. Find the output shape after the block. Find the number of parameters in the first Conv layer, including bias.

  1. Input is H=224, W=224, C=3. The first convolution has kernel k=3, pad p=1, stride s=1, and F=64 filters.
  2. Output height = (H + 2p − k)/s + 1 = (224 + 2 − 3)/1 + 1 = 224. Output width is also 224. Channels = F = 64. Shape after Conv 1 is 224×224×64.
  3. Conv 2 has the same k=3, p=1, s=1, F=64. It keeps the shape: 224×224×64.
  4. MaxPool has kernel 2×2 and stride 2. Output height = floor(224/2) = 112. Output width = 112. Channels stay 64. Shape after the block is 112×112×64.
  5. First Conv parameters: each filter has 3×3×3 = 27 weights. 64 filters give 64×27 = 1728 weights. Add 64 biases: 1728 + 64 = 1792 parameters.

Answer. The block output is 112×112×64, and the first Conv layer has 1,792 parameters.

Exam traps

  • VGG16 counts 16 weight layers, not 16 convolution layers. It has 13 convolution layers and 3 fully connected layers. VGG19 has 16 convolution layers and 3 fully connected layers.
  • Do not swap the first kernels: AlexNet uses 11×11 with stride 4, ZFNet uses 7×7 with stride 2, VGG uses 3×3 with stride 1 and pad 1.
  • AlexNet and ZFNet each have 5 convolution layers and 3 fully connected layers. The '5' is convolution layers only; total weight layers are 8.
  • In VGG, pad 1 with a 3×3 convolution keeps height and width unchanged. Only the 2×2 pool with stride 2 halves them.
  • ImageNet classification has 1000 classes. The softmax layer outputs 1000 scores, not 100.

3.5 Deeper architectures: Inception and ResNet

Very deep CNNs hit two problems: many kernel sizes may matter, and gradients vanish. Inception runs 1×1, 3×3, 5×5 convolutions and pooling in parallel, then concatenates the results, so one block sees small and large patterns. ResNet adds a shortcut that carries the input around a block: y = F(x) + x. The shortcut gives gradients a short path, so 50 to 152 layers train. These blocks power ImageNet classifiers and pretrained backbones used in transfer learning.

You need: 3.3, 3.4, and the vanishing-gradient section in Unit 2.

ResNet: add the input back

A plain CNN can be made deeper by stacking more 3×3 layers. Past a point, training error rises even on the training set. This is the degradation problem, not overfitting. The extra layers are hard to optimize: an identity mapping should be easy, yet many layers fail to learn it.

ResNet makes identity easy. A residual block computes a convolution path F(x) and adds the input x. If F is near zero, the block passes x unchanged. Gradients also flow through the addition, a short path back. This is separate from the vanishing-gradient fixes in Unit 2; it gives depth a highway.

y = F(x) + x

x is the block input feature map; F(x) is the output of the convolution path; y is the block output after the addition and ReLU.

The bottleneck block uses 1×1 conv to reduce channels, 3×3 conv to work at low channel count, and 1×1 conv to expand back. ResNet-50, ResNet-101 and ResNet-152 stack these blocks. A basic block uses two 3×3 convs instead.

  • An identity shortcut works when F(x) and x have the same height, width and channels.
  • If channels change or stride is greater than 1, use a 1×1 projection W_s with matching stride: y = F(x) + W_s x.

Inception: parallel kernels, one output

Inception asks which kernel size is right. A 1×1, 3×3 and 5×5 kernel see different scales. Instead of choosing, run all in parallel. An input feature map of size H×W×C goes to four branches: a 1×1 conv; a 1×1 conv then a 3×3 conv; a 1×1 conv then a 5×5 conv; and a 3×3 max pool then a 1×1 conv.

Each branch outputs H×W×c_i, where c_i is that branch's channel count. Concatenate along the channel axis to get H×W×(c1+c3+c5+cp). The 1×1 convs before the 3×3 and 5×5 branches are bottlenecks: they cut C to a small number, so a 5×5 conv does not cost C×25×C_out.

Y = concat(Y1, Y3, Y5, Yp)

Y1, Y3, Y5 and Yp are the branch outputs with the same H and W; concat joins them along the channel axis.

Padding keeps H and W unchanged in every branch. The pooling branch also uses padding. Inception concatenates branch outputs; it never adds them. GoogLeNet is Inception v1. Later versions factorize large kernels, but the parallel idea stays.

DenseNet and the comparison

DenseNet connects each layer to every later layer inside a dense block. Layer l receives the concatenation of all earlier feature maps in that block. With L layers there are L(L+1)/2 direct connections. Each layer adds only a few new channels, called the growth rate k; common values are 12 to 32. Features are reused, so parameters can be smaller.

A transition layer after each dense block reduces channels and spatial size. This keeps the concatenated tensor from growing too fast. The main exam idea is the connection pattern, not the full DenseNet schedule.

Compare the tensor operation. Inception concatenates parallel branches inside one block. ResNet adds a shortcut across a block. DenseNet concatenates across depth. All three improve gradient flow and feature mixing, but add and concatenate are not interchangeable.

Worked example

Question. A ResNet bottleneck receives a 56×56×64 feature map. A 1×1 conv makes 16 channels, a 3×3 conv with 16 filters and pad 1 keeps the size, and a 1×1 conv makes 64 channels. An identity shortcut skips the three convs. Find the output shape and the total parameters of the three conv layers, counting weights and biases.

  1. Input size is H=56, W=56, C=64. Conv1 is 1×1 with 16 filters: output is 56×56×16. Its parameters are 1×1×64×16 weights plus 16 biases = 1024 + 16 = 1040.
  2. Conv2 is 3×3 with 16 input channels, 16 filters, stride 1 and pad 1. Output is 56×56×16. Parameters are 3×3×16×16 weights plus 16 biases = 2304 + 16 = 2320.
  3. Conv3 is 1×1 with 16 input channels and 64 filters. Output is 56×56×64. Parameters are 1×1×16×64 weights plus 64 biases = 1024 + 64 = 1088.
  4. The identity shortcut needs the same shape as the conv path output. Both are 56×56×64, so the addition is valid. Total parameters = 1040 + 2320 + 1088 = 4448.

Exam traps

  • A shortcut adds tensors; Inception concatenates branch outputs along channels. Writing that Inception adds its branches loses marks.
  • Addition needs identical shapes. When channels change or stride is 2, use a 1×1 projection shortcut with matching stride; a plain identity shortcut will not broadcast.
  • In a 1×1 conv from C_in to C_out, parameters are C_in×C_out + C_out, not H×W×C_in×C_out. Bias is one per output channel.
  • The degradation problem is higher training error in a deeper plain network, not overfitting. ResNet fixes optimization, not just test-set variance.
  • Inception's 3×3 and 5×5 branches use padding to keep H and W equal; otherwise concatenation along channels fails.

3.6 Transfer learning and fine-tuning pretrained models

Transfer learning reuses a network trained on a large dataset, such as ImageNet, and adapts it to a new task. Early layers already detect edges, colours and textures; later layers detect object parts. You keep those learned filters and train a small new classifier on your own data. This saves labelled images, time and GPU cost. It is used in medical imaging, factory defect checks, crop disease apps and phone photo apps. Fine-tuning goes one step further and adjusts some pretrained layers.

You need: 3.4 and 3.5 for CNN blocks, and Unit 2 for learning rate and regularization.

Feature extraction: freeze the convolution base

A pretrained model is a network whose weights were learned on a large source dataset. ImageNet is the common source: about a million photographs labelled with 1,000 object classes. The convolution base is the stack of convolution and pooling layers. The classifier head is the final fully connected layer, often with softmax. The base turns an image into a feature vector.

In feature extraction, you freeze the base. Frozen means the weights do not change during backpropagation. You delete the old 1,000-way head and attach a new head for your K classes. For ResNet-50, global average pooling gives F = 2,048 features per image. The new fully connected layer has F inputs and K outputs.

P = F × K + K

P is the number of parameters in the new fully connected layer; F is the number of input features (2,048 for ResNet-50 after global pooling); K is the number of new classes (10 in the example).

  1. Load the pretrained weights.
  2. Remove the original classifier head.
  3. Freeze every convolution and pooling layer.
  4. Add global pooling and a new K-way fully connected layer.
  5. Train only the new head with cross-entropy loss.

Feature extraction is fast because the frozen base can run once and store features. It works well when the new task is similar to the source, such as classifying flowers or machine parts. It needs fewer labelled images than training from scratch.

Fine-tuning: unfreeze the top, train slowly

Fine-tuning unfreezes some top blocks of the base and trains them with the new head. Top blocks hold task-specific parts, so they adapt best. Use a small learning rate, often 10 to 100 times smaller than training from scratch. A large rate can overwrite useful filters in a few updates.

The amount you unfreeze depends on data size. Small dataset: freeze more. Large dataset: unfreeze more.

New datasetTrainable partLearning rate
2,000 imagesNew head only1e-3 for head

Batch normalization layers need care. When the base is frozen, keep each BN layer in evaluation mode. It then uses stored running mean and variance instead of batch statistics. This stops small batches from changing the base's normalization.

Match preprocessing and replace the head

The pretrained base expects the same input recipe used in pretraining. Match three things: input size, colour order, and per-channel mean and standard deviation. A common ImageNet recipe resizes to 224×224, scales pixels to [0,1], and subtracts mean [0.485, 0.456, 0.406] with standard deviation [0.229, 0.224, 0.225] for RGB. A different recipe shifts the feature values and lowers accuracy.

Always replace the old head. Its 1,000 outputs do not match your classes. Some syllabi call the freeze and unfreeze choices fine-tuning strategies. Domain adaptation uses the same idea when source and target images differ, such as daytime road images to night images.

A safe order is: train the new head with the base frozen; check validation accuracy; then unfreeze the last block with a smaller learning rate; stop when validation loss rises.

Worked example

Question. A ResNet-50 pretrained on ImageNet has 1,000 output classes. Its global average pooling layer produces 2,048 features. (b) State a training plan for 2,000 new images. (c) What changes if the new dataset grows to 50,000 images?

  1. Remove the old 1,000-way classifier head. Keep the convolution base and global pooling.
  2. The new fully connected layer has a weight matrix of size 10 × 2,048. Number of weights = 10 × 2,048 = 20,480.
  3. The new layer has one bias per class: 10 biases.
  4. Total parameters = 20,480 weights + 10 biases = 20,490 parameters.
  5. For 2,000 images, freeze the convolution base and train only the new 10-way head. Use the pretrained input size, mean and standard deviation.

Exam traps

  • Do not fine-tune all layers with a large learning rate; that destroys pretrained features.
  • Replace the head and keep the same preprocessing: input size, colour order, mean and standard deviation.
  • When counting FC parameters, include the biases. A 2,048-to-10 layer has 20,490 parameters, not 20,480.
  • Do not update batch normalization running statistics on very small batches while the base is frozen; keep BN in evaluation mode.
  • Do not confuse feature extraction with fine-tuning: feature extraction freezes the whole base, while fine-tuning trains some top base blocks.

3.7 Visualizing CNNs: kernels, deconvolution and Deep Dream

A trained CNN is not a black box if you look at what its kernels detect and which pixels drive a class score. Visualization shows first-layer kernels as edge and colour detectors, maps feature maps back to image space with deconvolution, and amplifies learned patterns with Deep Dream. Engineers use these tools to debug models, audit decisions and explain predictions in medicine and safety-critical systems.

You need: 3.1, 3.3, 3.5, and backpropagation from Unit 2.

Kernels and deconvolution

Visualization asks two questions: what pattern does a kernel detect, and which pixels caused an activation? A kernel is the small weight grid that slides over the input in convolution. In a trained image CNN, first-layer kernels often look like edge or colour detectors: a bright bar next to a dark bar at some angle, or a red-green boundary. To view one, normalise its weights to 0–255 and draw them as a small image. Deeper kernels respond to textures and object parts, not single edges. Feature maps are the activation grids produced by those kernels.

Deconvolution (transposed convolution) is the layer used in a deconvnet; backprop-to-image is a related gradient visualization method, not another name for the layer. The layer maps a feature map back to image space. It uses a kernel to spread each activation over a larger area. The operation is the gradient of a normal convolution with respect to its input, not an exact inverse. A deconv network for visualization attaches unpooling, rectification and deconv layers to a trained CNN. Unpooling uses the switch positions saved during max pooling. Rectification applies ReLU. Zeiler and Fergus used this to show that lower layers capture edges and colour, middle layers capture textures, and higher layers capture object parts.

  1. Choose a layer and a feature map.
  2. Keep that map, set the other maps to zero.
  3. Pass it through the deconv network.
  4. Read the reconstruction as the pattern that excites the unit.

Deep Dream

Deep Dream makes a network's learned features visible by changing the input image, not the weights. Pick a layer and a channel. Let a be the mean activation of that channel over space, and I the image. Compute the gradient ∂a/∂I by backpropagation. Update I ← I + η ∂a/∂I, where η is a small step size. This is gradient ascent: it increases the activation. The weights stay frozen. After some steps, edges and textures that the layer likes become stronger and repeat. If you start from a photo of clouds, the result may show animal faces because those patterns already push the chosen units.

Octaves make the effect stronger. Resize the image to a small scale, run several ascent steps, enlarge it, and repeat. At each scale the network sees different sizes of the same pattern. The final image has detail at many scales, which looks like a dream. Deep Dream is not classification; it is an inspection tool.

Grad-CAM and style transfer

Class activation mapping (CAM) shows where a class score comes from. Take the final convolution feature maps A^k, where k indexes the map. For class c, CAM multiplies each map by a class weight w_k^c and sums the weighted maps. This gives L^c. If negatives are clamped to zero for display, that is optional post-processing, not part of the CAM definition. CAM needs a global average pooling layer before the classifier.

L^c = Σ_k w_k^c A^k

L^c is the class activation map; w_k^c is the class weight for feature map k; A^k is feature map k.

Grad-CAM removes CAM's architecture requirement. It weights each feature map by the average gradient of the class score y^c with respect to that map: α_k^c = (1/Z) Σ_i Σ_j ∂y^c/∂A_{ij}^k. Here Z is the number of pixels in the map, i,j index its rows and columns, and ReLU(x) = max(0, x). The Grad-CAM heat map is L^c = ReLU(Σ_k α_k^c A^k). Up-sample L^c to the input size to overlay it on the image. Grad-CAM weights are gradients of the class score, not raw kernel weights.

Neural style transfer uses a content loss and a style loss. The content loss compares feature maps of a generated image with a content image. The style loss compares Gram matrices, which capture correlations between feature channels, with a style image. Some syllabi cover only this outline, not the full derivation.

3.8 CNNs for object detection: R-CNN and YOLO

An image classifier says what is in a picture. A detector says what is in it and where. It returns boxes, each with a class and a score. Face unlock, number-plate reading and PCB defect spotting are detection. This chapter builds detectors from CNN blocks: R-CNN proposals to YOLO's single regression over a grid.

You need 3.3 to 3.5 for the CNN backbone, plus softmax and cross-entropy from Unit 2.

What detection asks for

Classification gives one label. Localization gives one box. Detection gives a variable number of boxes and labels: a photo may hold zero, two or twenty objects.

A box is (x, y, w, h): x and y are the centre, w and h are width and height. Some systems use the top-left corner. State your convention; mixing them shifts every box by half its size.

Compare predicted box Bp with true box Bg by intersection over union.

IoU = area(B<sub>p</sub> ∩ B<sub>g</sub>) ÷ area(B<sub>p</sub> ∪ B<sub>g</sub>)

Bp is the predicted box; Bg is the ground-truth box; ∩ is the overlap; ∪ is the combined area, counting overlap once. IoU is 0 when boxes miss and 1 when they match exactly.

A model emits many overlapping boxes. Non-maximum suppression (NMS) is a fixed rule. Sort by score, keep the best, delete boxes whose IoU with it is above a threshold (0.5 is common), and repeat.

Precision and recall at several IoU thresholds, averaged, give mean average precision (mAP). It is the standard detector score.

R-CNN: proposals then classify

R-CNN (2014) has two stages. Stage one proposes regions. Stage two classifies each region with a CNN.

  1. Run selective search: merge similar neighbouring pixel regions and return about 2,000 candidate boxes.
  2. Warp each box to a fixed 224×224 image.
  3. Push each warp through a CNN, such as AlexNet, and keep the feature vector.
  4. Classify the vector with one SVM per class, and regress a small box correction.
  5. Apply NMS.

The CNN runs about 2,000 times per image, and proposals come from a separate hand-made algorithm.

Fast R-CNN convolves the whole image once. Each proposal is projected onto the shared feature map and cropped by ROI pooling: divide the region into fixed bins and max-pool each bin, so every region becomes the same small tensor. A softmax head and box regressor share it.

Faster R-CNN replaces selective search with a region proposal network (RPN). A small net slides over the feature map. At each position it scores anchor boxes of a few sizes and shapes and regresses their offsets. Proposals and detection train together as one network.

YOLO: detection as one regression

YOLO (You Only Look Once, 2016) drops proposals. Divide the image into an S×S grid. The cell containing an object's centre is responsible for that object.

Each cell predicts B boxes. Each box has 5 numbers: x, y, w, h and confidence. Here x and y are offsets inside the cell, scaled to 0–1; w and h are sizes relative to the whole image. Confidence is estimated as Pr(object) × IoU with the truth box. It measures objectness, not class probability.

Each cell also predicts C class scores. At test time, multiply class score by box confidence to get the per-class score for that box. One forward pass produces every prediction.

depth = B × 5 + C

depth is numbers predicted per grid cell; B is boxes per cell; 5 is x, y, w, h and confidence; C is the number of classes.

The output tensor is S×S×depth. After the network, drop boxes below a confidence threshold and run NMS. YOLO is fast because the CNN runs once, but the coarse grid limits it: one cell predicts only B objects, so a tight flock of small birds is missed. Later versions add anchors, several scales and stronger backbones.

SSD, RetinaNet and the vocabulary

SSD predicts boxes from several feature maps: deep maps for large objects, shallow maps for small ones, using default boxes of many shapes. RetinaNet keeps a feature pyramid and adds focal loss. Focal loss multiplies the usual loss by (1 − pt)γ, where pt is the probability given to the true class and γ (gamma, 2 is standard) is a focusing constant. Thousands of easy background boxes then contribute little, and rare hard boxes dominate the gradient.

Detectors with a separate proposal step are two-stage; detectors that regress boxes straight from the feature map are one-stage. Some syllabi use these names for the R-CNN and YOLO families.

Worked example 2

Question. Two boxes in centre form: predicted box Bp has centre (2, 2) with w = 4, h = 4; true box Bg has centre (4, 2) with w = 4, h = 4. All values are in the same pixel units. Find the IoU.

  1. Bp spans x from 0 to 4 and y from 0 to 4. Area = 4 × 4 = 16 square units.
  2. Bg spans x from 2 to 6 and y from 0 to 4. Area = 16 square units.
  3. Overlap in x: 2 to 4, width 2. Overlap in y: 0 to 4, height 4. Intersection area = 2 × 4 = 8.
  4. Union area = 16 + 16 − 8 = 24.
  5. IoU = 8 ÷ 24 = 0.333.

Answer. IoU = 0.333, so the boxes overlap by about one third.

Exam traps

  • YOLO's x and y are offsets inside the responsible cell, not image pixels; w and h are fractions of the full image, not the cell.
  • Confidence is objectness times IoU with the truth box. It is not class probability; class probability is the separate C-way score, multiplied only at test time.
  • NMS is a rule applied after the network. It has no weights and is not trained; it is not a learned layer.
  • Faster R-CNN's RPN only proposes regions. The classifier head decides the class, so do not credit the RPN with final labels.
  • IoU divides by union area, not by the sum of the two areas; the overlap is counted once in the union.

3.9 CNNs for segmentation and Siamese networks

A classifier says what is in an image. A segmenter says what is at every pixel. Semantic segmentation labels each pixel with a class; instance segmentation also separates objects of the same class. Siamese networks take two inputs, pass both through one shared network, and decide same or different. These ideas cover medical scans, road masks, satellite maps, face unlock and duplicate-photo cleanup.

You need: 3.3 and 3.1 for convolution shapes, 3.5 for skip connections, 3.8 for Mask R-CNN, and the loss functions of Unit 2.

Semantic segmentation and the fully convolutional network

Semantic segmentation gives every pixel a class. A classifier gives one label per image; a detector gives boxes; a segmenter gives a mask with the same height and width as the input. It does not separate two cows in a field — every cow pixel gets the class cow. Instance segmentation does separate them: cow 1 and cow 2 become different masks.

H_out = ⌊(H_in + 2p − k) / s⌋ + 1

H_out is the output height in pixels, H_in the input height, k the kernel size, p the padding and s the stride; ⌊ ⌋ means round down.

A dense layer blocks segmentation because it fixes the input size and flattens the spatial grid. On a 7×7×512 feature map, a 4096-unit dense layer is a 7×7 convolution with 4096 filters. Replace dense layers this way and the whole network becomes fully convolutional (FCN). Its output is a grid of class scores, for example 16×16×21 for 21 classes; it then enlarges the coarse grid back to input resolution.

Enlarging uses a deconvolution (transposed convolution): a learnable kernel that writes one input value into a k×k output patch. Stride 2 doubles each spatial side — 64 becomes 128. Channel count comes from filters, never stride.

Pooling discards position detail, so boundaries blur. An FCN adds an early high-resolution score map to the upsampled coarse map, restoring sharp edges. SegNet stores the argmax index of each 2×2 max-pool window and reuses it while decoding; its upsampling has no parameters.

U-Net and Mask R-CNN

U-Net is an encoder-decoder with a skip into every level. The encoder repeats conv 3×3 + ReLU, then 2×2 max pool; each pool halves both spatial sides and the next block doubles channels. The decoder upsamples by 2 and concatenates the matching encoder map on the channel axis. A final 1×1 convolution gives one score per class per pixel.

  1. Conv 3×3, pad 1, 64 filters on 128×128×3 gives 128×128×64.
  2. Max pool 2×2, stride 2 gives 64×64×64.
  3. Upsample 2×2, stride 2 gives 128×128×64.
  4. Concatenate with the step 1 map: 64 + 64 = 128 channels, so 128×128×128.
  5. 1×1 conv with 5 filters gives 128×128×5 scores; softmax runs across the 5 channels of each pixel.

Training minimises pixel-wise cross-entropy over all 16 384 pixels. Skips carry fine detail that pooling destroyed, so U-Net learns from a few hundred images — useful in medical imaging, where one 128×128 MRI slice can be split into 5 tissue classes.

Mask R-CNN adds a mask branch to Faster R-CNN. ROIPool rounds proposal coordinates and bin edges to the integer feature-map grid, so pooled features can be off by up to one feature-map pixel — several image pixels at stride 16. ROIAlign samples at exact floating-point positions with bilinear interpolation, so a pixel-accurate mask lines up. A small conv head outputs a 28×28 mask for each class in each region. Loss = classification + box regression + per-pixel binary cross-entropy on the mask.

Siamese networks: same or different

A Siamese network answers: are these two inputs the same? Two branches with identical architecture and shared weights map each input to an embedding f(x). One parameter set is applied twice, so the count does not double. The embeddings are compared by distance.

d = ‖f(x₁) − f(x₂)‖₂

d is the Euclidean distance between the two embeddings, f is the shared network, x₁ and x₂ are the two inputs.

At test time pick a threshold τ: if d ≤ τ the pair is the same, otherwise different. Training uses pairs with contrastive loss or triplets with triplet loss.

L = ½(1 − y)·d² + ½·y·max(0, m − d)²

y = 0 for a matching pair and y = 1 for a non-matching pair, d is the embedding distance and m is the margin in the same units as d.

The first term pulls matching inputs together. The second pushes non-matching inputs apart, but only until d reaches m; beyond the margin the loss is zero and no gradient is spent.

L = max(0, d(a, p) − d(a, n) + α)

a is the anchor, p a positive of the same identity, n a negative of a different identity, d the distance and α the margin.

Triplet loss is zero when the negative is farther than the positive by at least α. Ranking loss states the same ordering with a margin; only a few syllabi teach it in detail. Siamese training powers face unlock, signature verification, one-shot recognition and duplicate-photo search.

Worked example

Question. A U-Net takes a 128×128×3 image. Encoder: 3×3 convolution, 64 filters, pad 1, stride 1; then 2×2 max pool, stride 2; then 2×2 upsample, stride 2. Concatenate the result with the encoder output. A final 1×1 convolution with 5 filters makes the mask. Give every tensor shape and the last convolution's parameter count.

  1. Conv 3×3, pad 1, stride 1: H_out = ⌊(128 + 2 − 3)/1⌋ + 1 = 128. Shape 128×128×64.
  2. Max pool 2×2, stride 2: 128/2 = 64. Shape 64×64×64; pooling keeps channels.
  3. Upsample 2×2, stride 2: 64 × 2 = 128. Shape 128×128×64.
  4. Concatenate on channels with the encoder map: 64 + 64 = 128. Shape 128×128×128.
  5. 1×1 conv with 5 filters: shape 128×128×5.
  6. Last conv parameters: 1×1×128×5 = 640 weights + 5 biases = 645.

Answer. Channels after concatenation = 128; final mask 128×128×5; last 1×1 convolution has 645 parameters.

Exam traps

  • Segmentation output is one label per pixel, not one label per image: a 128×128 mask over 5 classes is a 128×128×5 tensor, not a vector of 5 numbers.
  • U-Net skips concatenate channels (64 + 64 = 128). FCN skips add equal-shaped tensors: the 2× upsampled coarse score map is summed with the score map predicted from the earlier layer. ResNet shortcuts also add. Mixing the rules loses marks.
  • Siamese branches share one set of weights — it is a single network applied twice. Writing two separately trained networks doubles the parameter count and is wrong.
  • State your label convention before writing contrastive loss. Here y = 0 means a matching pair; many texts use y = 1. The examiner marks your declared convention, not someone else's notes.
  • A 2×2 upsample with stride 2 doubles each spatial side but leaves channels unchanged; only the later 1×1 convolution changes channels.

Remember Define semantic segmentation and instance segmentation in one line each. 2 marks

Semantic segmentation assigns one class label to every pixel but does not separate two objects of the same class. Instance segmentation outputs a separate mask for each individual object.

Understand Why does an FCN replace fully connected layers with convolutions? 3 marks

A dense layer fixes input size and flattens the spatial grid. A convolution keeps the grid, so the output is a spatial class-score map whose size follows the input and the same filters slide over any image size.

Understand What does the margin α do in the triplet loss L = max(0, d(a,p) − d(a,n) + α)? 3 marks

It sets how much closer the positive must be than the negative before loss hits zero. A larger α demands a wider gap and produces gradients for harder triplets; α = 0 accepts equal distances.

Apply A triplet has d(a,p) = 0.4, d(a,n) = 0.9 and margin α = 0.3. Compute the triplet loss and say what the gradient is. 4 marks

L = max(0, 0.4 − 0.9 + 0.3) = max(0, −0.2) = 0. The negative is already farther than the positive by 0.5, which exceeds α = 0.3, so the triplet is satisfied and the gradient is zero.

Apply A U-Net input is 256×256×3. The encoder uses 3×3 conv with 32 filters and pad 1, then 2×2 max pool. The decoder upsamples 2×2, concatenates the encoder map and applies a 1×1 conv with 10 filters. Give every shape. 4 marks

Analyze Why does Mask R-CNN use ROIAlign instead of ROIPool for the mask branch? 5 marks

ROIPool rounds proposal boundaries and bin edges to integer feature-map grid coordinates, so pooled features shift by up to one feature-map pixel — several image pixels at stride 16 — and a pixel-accurate mask shows that shift. ROIAlign samples at exact floating-point positions with bilinear interpolation and keeps the mask aligned.

Analyze Why does a U-Net skip concatenate instead of adding, and what does it cost? 5 marks

Concatenation keeps encoder detail and decoder semantics side by side; the next convolution learns to mix them. Addition would force one shared channel and require matching counts. Cost: the next convolution sees 128 input channels, not 64.

Takeaways

  1. Convolution replaces hand-written features with kernels whose weights are learned, and the feature map records where a pattern was found.
  2. Stride and padding are the two dials that set the output size of every convolution layer.
  3. Pooling shrinks the map and buys small translation tolerance, while ReLU supplies the non-linearity that convolution alone lacks.
  4. A basic CNN is just a stack of convolution–ReLU–pool blocks ending in a flatten and a few fully connected layers.
  5. AlexNet, ZFNet and VGG showed that depth, ReLU, dropout and small 3×3 kernels beat hand-designed image features.
  6. Inception widens a layer by running several kernel sizes in parallel; ResNet goes deep by adding identity shortcuts that keep gradients alive.
  7. Transfer learning lets a small team with one GPU and a few thousand images reuse ImageNet features instead of training from scratch.
  8. Visualization methods such as deconvolution, DeepDream and Grad-CAM turn a trained CNN from a black box into something you can inspect.
  9. Detection answers what and where: R-CNN-style methods propose regions then classify, YOLO does both in a single forward pass.
  10. Segmentation labels every pixel, and Siamese networks reuse one network twice to answer same-or-different.

Glossary

AlexNet
The 2012 ImageNet-winning 8-layer CNN that popularised ReLU and dropout for vision.
Batch normalisation
Normalising layer inputs by batch mean and variance, then scaling and shifting with learned parameters.
Contrastive loss
A loss that pulls embeddings of similar pairs together and pushes dissimilar pairs apart by a margin.
Convolution
An operation that slides a kernel over an input and computes a dot product at every position to build a feature map.
Deconvolution
A transposed convolution that maps a feature map back towards image space.
DeepDream
An image generated by gradient ascent on the input to amplify patterns the network detects.
Dropout
Randomly zeroing activations during training to reduce overfitting.
Feature map
The output grid produced by one kernel over the whole input.
Fine-tuning
Continuing training of pretrained layers on new data, usually with a small learning rate.
Flatten
Reshaping a 3-D feature map into a 1-D vector before fully connected layers.
Global average pooling
Averaging each feature map to one number, often used instead of a flatten layer.
Grad-CAM
A class-specific heat map built from gradients flowing into the last convolution layer.
Inception module
A block that runs several kernel sizes in parallel and concatenates their outputs.
Kernel
A small matrix of learnable weights applied by convolution.
Max pooling
A downsampling operation that keeps the maximum value in each window.
Padding
Border rows and columns added to the input, usually zeros, to control output size.
Parameter sharing
Using the same weights at every spatial position, which is what makes convolution cheap.
Receptive field
The region of the original input that a given neuron's value depends on.
Region proposal
A candidate bounding box suggested before classification in R-CNN-style detectors.
ReLU
The activation max(0, x) applied elementwise.
Residual block
A block whose output is F(x) + x through an identity shortcut.
Semantic segmentation
Assigning a class label to every pixel of an image.
Siamese network
Two copies of one network with shared weights that produce embeddings for two inputs to compare them.
Softmax
A function that turns a vector of scores into probabilities that sum to 1.
Stride
The step size, in pixels, by which the kernel moves between positions.
Transfer learning
Reusing knowledge, in practice weights, learned on one task for another task.
VGG
A deep CNN family built from repeated 3×3 convolutions and max pooling.
ZFNet
The 2013 ImageNet winner, a tuned AlexNet guided by feature visualisation.
