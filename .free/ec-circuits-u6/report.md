## Reviewer notes (after any revision)

- ch 1 [high] Exam traps, third trap ("A four-terminal network is not automatically a two-port; a shared ground that carries current breaks the port condition"): This contradicts Section 1, where the transistor is correctly described as a two-port with the emitter shared between both ports. A three-terminal network whose common terminal returns both port currents does satisfy the port condition: at port 1, I1 enters the base and I1 leaves the emitter; at port 2, I2 enters the collector and I2 leaves the emitter. A student reading both statements cannot tell which one is true.
- ch 1 [low] Section 1, third paragraph ("A two-port is linear when its equations contain no powers or products of the port variables. It has no independent sources inside. Any initial stored energy... is zero"): Three separate requirements are stacked in three sentences, and "It" reads as if the linearity definition itself demands no internal sources. Linearity and the source-free / zero-energy conditions are different conditions; only together do they give fixed constants.
- ch 1 [low] Section 3, paragraph listing parameter sets ("Choosing V2 and I2 gives the ABCD parameters"): The chapter defines I2 as entering port 2, but standard ABCD (transmission) parameters are written with the current leaving port 2, so the equations and the sign of B and D differ from the textbook form. A student who learned the convention above will get a sign error in ABCD work.
- ch 2 [low] Section 2, conversion formula block: The block reads "...y₂₂ = z₁₁/Δz, where Δz = z₁₁z₂₂ − z₁₂z₂₁ where: Δz is the determinant of the Z matrix, in Ω²." The word "where" appears twice in a row, which reads as a typo and breaks the otherwise clean formula-then-glossary pattern used in Sections 1 and 2.
- ch 2 [low] Section 3, second bullet: "A passive T network of ordinary elements never hits this" is too strong. It is true only for networks of positive resistors. A passive lossless LC T network does reach Δz = 0 at a particular frequency: with Z₁ = Z₂ = jωL and Z₃ = 1/(jωC), Δz = −ω²L² + 2L/C, which is zero at ω = √(2/(LC)). At that frequency the input impedance with port 2 shorted is zero, so y₁₁ is infinite and no finite Y matrix exists, although the Z matrix is still finite.
- ch 3 [high] Section 1 (formula annotation and the load-sign paragraph): The port-2 current direction is stated wrongly and contradicts the sign rule that follows. The chapter says I₂ is 'taken flowing out of port 2' and then writes the passive load as V₂ = −I₂Z_L. If I₂ really left port 2, the current through Z_L would be I₂ and V₂ would be +I₂Z_L. The standard h convention is that I₂ enters port 2; that is the only convention in which the transistor numbers quoted later make sense (h₂₁ = h_fe = +β, and for a reciprocal network h₁₂ = −h₂₁, giving h₂₁ = −z₂₁/z₂₂). As written, a student following the text would get h₂₁ = −β for a common-emitter device and would set the load sign wrong.
- ch 3 [low] Exam traps, second bullet (unit slip): The example 'h21 in amperes per ampere' is misleading: A/A is dimensionless, so writing h₂₁ with A/A is not a unit error and would not cost marks. Only h₁₁ (Ω) and h₂₂ (S) carry units.
- ch 4 [high] Exam traps, first bullet: The bullet says that if you take I2 as pointing out of port 2, then B and D change sign. That is false. The parameters A, B, C, D are properties of the network and do not depend on which way you draw I2. If you draw I2 leaving port 2 and write [V1; I1] = [[A, B], [C, D]][V2; I2], the numbers for B and D stay the same as in the chapter; only the sign inside the equation changes. B and D flip sign only if you keep I2 as entering port 2 but drop the minus sign, i.e. write [V1; I1] = [[A, B], [C, D]][V2; I2]. As written, a student will wrongly believe the measured B and D values change when the arrow on I2 is reversed.
- ch 5 [high] Section 1, ABCD formula (and the sign convention used by the table and worked example): The text says I2 is the current leaving port 2, but the minus-sign ABCD equations, the conversion table and the worked example all use I2 entering port 2. With the stated leaving convention, the signs of B and C are wrong.
- ch 5 [low] Quiz Q4 answer: For z21 = 0, every table route to ABCD also has a zero divisor whenever the other parameter set exists: y21 = h21 = g21 = 0. So 'use another parameter set' will not give an ABCD matrix; the answer only identifies the Z→ABCD failure.
- ch 6 [high] Section 3 (cascade), first paragraph after the heading: The sentence 'Writing the port 2 current as drawn outward, the chain matrix T of a network satisfies [V1; I1] = T [V2; −I2]' uses the opposite convention to the sentence before it, which says I2a = −I1b. The standard ABCD matrix is defined with I2 entering port 2: V1 = A V2 − B I2 and I1 = C V2 − D I2. If I2 were really drawn outward (leaving port 2 into the load), the correct relation would be [V1; I1] = T [V2; I2], and the cascade step would read I2a = I1b, not −I1b. As printed, a student who follows the words 'drawn outward' gets every cascade sign wrong.
- ch 6 [low] Beyond paragraph: 'A subcircuit call in SPICE is a cascade' is not true. A subcircuit call pastes a block of element equations into the netlist at the named nodes; SPICE then builds one nodal matrix for the whole circuit and solves it. It does not multiply ABCD matrices stage by stage. The previous sentence, 'RF design tools use exactly these rules', also sits oddly next to the chapter's own point that S-parameter chains need a scattering transfer matrix, not a plain product.
- ch 6 [low] Quiz Q4, answer: The same letters A, B, C and D name both the individual section and the combined pair ('A = A² + BC = 4 + 3 = 7', 'B = AB + BD = 6 + 6 = 12 Ω'). The numbers are right, but the symbols are ambiguous and a student copying this into an exam answer can lose marks for unclear working.
- ch 6 [low] Lead: The lead says every rule 'carries a condition that must be checked first', but Section 3 and the table both state that cascade needs no port condition. The contradiction is small but it is the kind of sentence a student quotes back in a viva.
- ch 7 [high] Section 1: The two open-circuit measurements are labelled with the wrong Z parameters. Driving port 1 with port 2 open gives V2/I1, which by definition is z21, not z12. Driving port 2 with port 1 open gives V1/I2, which is z12, not z21. The stated conclusion z12 = z21 still holds, but a student learns the two definitions reversed, and this contradicts every standard table of Z-parameter definitions.
- ch 7 [high] Lead: A general two-port needs four independent parameters (for example z11, z12, z21, z22), not six. Saying the tests cut 'the six independent parameters' down is a wrong count a student may memorise.
- ch 7 [low] Section 1, note after the formula: The note says the minus sign in h12 = −h21 comes from I2 leaving port 2, 'while the other sets use a current entering'. That is true of z and y, but in ABCD parameters I2 is also defined as leaving port 2 (flowing into the load), so the generalisation to 'the other sets' is inaccurate.
- ch 8 [high] Section 1 and Quiz Q1: The positive-real test is incomplete. A rational Z(s) with real coefficients and Re Z(jω) ≥ 0 for all ω can still have a pole in the right half-plane and be non-passive. The standard PR definition also requires no poles in Re s > 0, equivalently Re Z(s) ≥ 0 for Re s > 0.
- ch 8 [high] Section 2: The pole-zero location rules are stated too absolutely. An LC impedance may have a pole at infinity, for example Z(s)=sL. An RC impedance may have a pole at s=0, as the chapter's own K0/s term shows, and may have a zero at infinity. As written, these valid one-ports fail the stated tests.
- ch 8 [high] Quiz Q3: The answer is wrong. Z(s)=(s²+4)/(s(s²+1)) has poles at 0 and ±j1, and zeros at ±j2. On the positive jω axis the order is pole at 0, pole at 1, zero at 2, so they do not alternate. Its partial fractions give Z(s)=4/s − 3s/(s²+1), with a negative residue, so it is not an LC impedance. It is the reciprocal of the worked-example LC impedance, hence an LC admittance.
- ch 8 [low] Quiz Q2: The explanation says alternation keeps Re Z(jω) from becoming negative. For an LC impedance, Re Z(jω)=0 at all non-pole frequencies, so this does not explain alternation.
