## Reviewer notes (after any revision)

- ch 1 [high] Section 1 (amplitude sentence and joint-state formula), Section 3 (probability line and the two-register kickback formula), Quiz Q1 (formula and amplitude): The normalisation factor is written as 1/√(2n), which equals 1/√(2·n), not the required 1/√(2ⁿ). The state formula at the top of Section 1 correctly uses 2<sup>n</sup>, but every later occurrence drops the superscript, and the line |±1/√(2n)|² = 1/2ⁿ is then self-contradictory. A student copying 1/√(2n) would get a non-normalised state and a wrong amplitude for every input string.
- ch 1 [high] Section 2 (why U_f is unitary): "Uf is its own inverse and therefore unitary" is a false implication: plenty of maps are self-inverse and not unitary, and being involutive says nothing about preserving inner products. The reversibility argument and the unitarity argument are being merged into one wrong step.
- ch 1 [low] Section 3, global versus relative phase paragraph: "Kickback always makes the second kind, one sign per input" is not true when f is constant: then every sign is the same and the result is a global phase, exactly the case Quiz Q6 describes. The absolute "always" clashes with Q6.
- ch 2 [low] Lead paragraph: The classical cost is left vague ('may need many inputs'). For Deutsch-Jozsa the standard worst-case deterministic count is exact and small enough to state: 2^(n−1)+1 queries (and 2 queries for the one-bit Deutsch case). Leaving it out weakens the speed-up claim students are asked to remember.
- ch 2 [low] Figure (Deutsch-Jozsa circuit), node 'uf': The note on the oracle node says 'oracle with ancilla |1⟩'. At the moment the oracle acts, the ancilla has already passed through H and is |−⟩=(|0⟩−|1⟩)/√2, not |1⟩. A student reading the figure left to right will picture U_f acting on |1⟩ and miss the phase-kickback preparation, which the exam traps themselves stress.
- ch 3 [low] Section 2, the line 'The pair |x⟩ + |x⊕s⟩ becomes Σ_y (−1)^(x·y) (1 + (−1)^(s·y)) |y⟩': The stated state has no normalising prefactor, so the expression is only proportional to the true state. A student who adds amplitudes directly will get a total probability of 2ⁿ instead of 1.
- ch 3 [low] Exam traps, third trap: 'the constant function is just the case s = 0ⁿ' can mislead: only the constant-zero function fits the Bernstein-Vazirani promise f(x) = s·x. The constant-one function cannot be written as s·x for any s.
- ch 4 [high] Section 2 (circuit bullets, R_k gate) and Quiz Q5: The phase of a controlled R_k gate is written as e2πi/2k, which reads as e^(2πi/(2k)) with 2·k in the denominator. The standard gate is R_k = diag(1, 1, 1, e^(2πi/2^k)), so R_3 adds e^(2πi/8), not e^(2πi/6). As written, students get the wrong phase for every k ≥ 3. The exponent on the 2 has been lost (some other formulas in the chapter do use the <sup> tag, e.g. e^(2πijk/N)).
- ch 4 [high] Section 3 (Shor's factoring): The order-finding map is written as x → ax mod N, which is plain multiplication by a and has no hidden period to find. Shor's period finding uses the exponentiated map x → a^x mod N, whose period is the order of a modulo N.
- ch 4 [low] Section 2 (definition of 0.j_m...j_n): The definition reads "j_m/2 + ... + j_n/2n−m+1", so the last denominator appears as 2n − m + 1 instead of a power of two. A student can misread the binary-fraction definition and get the product form wrong.
- ch 4 [low] Section 3 (final sentence): "Some syllabi call this the quantum Fourier transform (QFT); the abbreviation is standard" says nothing useful and can confuse a reader into thinking another name for the transform is being introduced. The chapter has already introduced both the full name and the abbreviation.
- ch 5 [high] Quiz Q7: The premise is false for the state chosen. For N = 15 and a = 2, the orbit of 3 under multiplication by 2 is 3 → 6 → 12 → 9 → 3, so its length is 4, which equals r. A student loading |3⟩ gets the full order, so the question as posed has no correct answer and the given explanation (recovered denominator smaller than r) does not apply to this state.
- ch 5 [high] Exam traps, last bullet: "A general basis state sits in a shorter orbit" is wrong. A basis state |x⟩ sits in an orbit whose length L divides r, and L can equal r. Example: for N = 15, a = 2, the state |3⟩ has orbit 3 → 6 → 12 → 9 → 3 of length 4 = r. The statement contradicts the corrected Q7 and would mislead a student into thinking any basis state gives a too-small denominator.
- ch 5 [low] Section 1, last paragraph: "The measurement is the nearest integer to 2^t φ with high probability" overstates the guarantee. For a general φ a single run gives the nearest integer with probability only about 4/π² ≈ 0.40, which is not high; the success rate rises only after repeated runs or a larger t.
- ch 5 [low] Worked example 1, output block: The output block lists 4, 8, 0.25, 2, 4 with no labels, which does not match the seven rows of the dry-run table: the 3-bit value 010 and the continued fraction 1/4 are missing, and a reader cannot tell which number is which.
- ch 5 [low] Worked example 1, setup and steps 2-4: The example is circular: the reader is handed φ = s/r with s = 1, which already assumes r = 4, and step 2 then computes r = 4 by brute-force powers. The phase-estimation step therefore demonstrates nothing; it only re-derives a number already found classically.
- ch 6 [high] Section 1, first paragraph: The sentence is broken: "Pick a with 1  1, it is already a nontrivial factor of N." The base-range condition and the gcd test have lost the < and > symbols, so a student cannot read the starting rule.
- ch 6 [high] Section 2, first sentence: "Define a unitary U on basis states |y> for 0 ≤ y  = |a y mod N>" is garbled. The range bound and the action of U run together, so the definition of U is lost.
- ch 6 [high] Section 2, phase-estimation paragraph: "The ratio m/2t is close to s/r" reads as m divided by (2 times t). The denominator must be 2 to the power t, the size of the phase-estimation register. As written the formula is wrong.
- ch 6 [high] Section 1 (extra-check paragraph) and Section 2 (candidate check): The half-power and the full power appear as "ar/2" and "ar", which read as a times r divided by 2, and a times r. Subscripts/superscripts are missing in the two places where the reader must compute a<sup>r/2</sup> and a<sup>r</sup>.
- ch 6 [low] Section 2, eigenstate paragraph: The eigenvalue is printed as e2πi s/r, which reads as e times 2πi times s/r rather than e raised to the power 2πi s/r.
- ch 6 [low] Figure spec, node 'check': The note 'half = 4' is ambiguous: 4 is the half-power a<sup>2</sup>, not the half exponent, which is r/2 = 2. A student may read it as r/2 = 4.
- ch 6 [low] Section 3, cost paragraph: Saying log N is "the number of bits of N" is loose. The number of bits is about log₂ N, and the polynomial is in that bit count.
- ch 6 [low] Section 3 (missing condition): The chapter never says what happens when N is a prime power (for example N = 9 or 25). For such N the order step always ends in a trivial split, so choosing a new base a never helps; the reader is told only to retry with a new a.
- ch 7 [high] Section 4 (cost): The exponents are lost: the text reads "N=1012 needs about 106 Grover steps, not 1012", which literally says N equals one thousand and twelve and that Grover needs only 106 steps.
- ch 7 [high] Lead and Section 1: "N=2n" is written without the exponent, so it reads as N = 2 times n. The definition N = 2 to the power n is the basis of the whole chapter (n qubits, N items), and a student will misread it.
- ch 7 [high] Quiz Q8: The exponent is lost again: "For a search space of size 2m, Grover still needs about 2m/2 queries" reads as size 2m and 2m/2 = m queries, which is wrong and destroys the point of the answer.
- ch 7 [low] Figure data (N=16 plot): Two plotted points do not match P(k)=sin²((2k+1)θ) with θ=0.252680 rad: the plot gives P(4)=0.585 (true value 0.5817) and P(5)=0.124 (true value 0.1255). The other points (0.0625, 0.472, 0.908, 0.961, 0.020) are correct.
- ch 7 [low] Section 2: "After the oracle, the marked amplitude is negative and all other amplitudes are positive" and "turns each unmarked amplitude slightly smaller" are true only for the first iteration. Later, once (2k+1)θ passes π/2, the unmarked amplitude cos((2k+1)θ) turns negative, so the signs described are wrong mid-search.
- ch 7 [low] Quiz Q8: Cross-reference mismatch: Section 4 says quantum counting and the √N lower bound are in 4.8, but Q8 sends the reader to 4.9 for the same limitation topic.
- ch 8 [high] Section 3, bullets under the lower bound: The bullet 'It assumes bounded error. Demanding certainty changes the constant, not the √N' is false. Exact (zero-error) search of an unstructured list needs Θ(N) oracle queries; the √N bound is a bounded-error statement only.
- ch 8 [high] Section 3, last bullet ('Estimating M to constant relative accuracy also needs Ω(√N) queries, so counting is optimal as well.'): Wrong as stated, and it contradicts the chapter's own error formula. Constant relative accuracy on M means δM ≈ M, which from δM ≈ 2π√(M(N−M))/2^t needs 2^t ≈ 2π√(N/M), i.e. Θ(√(N/M)) queries, not Θ(√N). When M is a constant fraction of N (say M = N/2) even a handful of random samples gives constant relative accuracy, so Ω(√N) cannot hold. The Ω(√N) statement is true only for small M, e.g. M = 1.
- ch 8 [high] Section 2, the δM formula and the sentence after it: The derivation step is off by a factor 2 and does not reproduce the stated result. Since θ ≈ πy/2^t, one unit of error in y shifts θ by π/2^t, not 2π/2^t. Multiplying dM/dθ = 2√(M(N−M)) by 2π/2^t would give 4π√(M(N−M))/2^t, twice the formula printed.
- ch 8 [low] Exam traps, third trap (M = 0 or M = N): The reason given is wrong. For M = 0, G = 2|s⟩⟨s| − I has eigenvalue 1 on |s⟩ and phase estimation returns y = 0, giving M = 0 correctly. For M = N, O = −I and G = I − 2|s⟩⟨s| has eigenvalue −1 on |s⟩, so y = 2^(t−1) and M = N. Both boundary cases are read out correctly; what really degenerates is that the two eigenvalues coincide, so the 'two eigenvalues give the same count' argument has nothing to resolve.
- ch 8 [low] Section 3, adversary paragraph: The per-query figure and the k-query figure do not match: one query moving the states apart by 'about 1/√N' over k queries gives k/√N, not the 2k/√N stated.
- ch 8 [low] Quiz Q3 answer: 'One application of G changes no measurable quantity' is inaccurate: applying G once does change the state, and a computational-basis measurement then returns a marked item with probability sin²3θ instead of sin²θ. The real reason is that a single outcome carries no angle information and the marked subspace is unknown.
- ch 9 [high] Section 3, Grover paragraph and its formula note: The exponent is lost twice: 'the search space has N = 2n candidates for n Boolean variables' and 'where: ... 2n is the number of candidate assignments'. As printed N = 2n means 100 candidates for n = 50, which destroys the whole point (the space is 2ⁿ). The formula above it correctly writes 2<sup>n</sup>, so the two sentences contradict it.
- ch 9 [low] Section 1, definition of P, the BQP formula note, and the majority-vote sentence: Three exponents are missing, so powers read as products: 'O(nk)' should be n^k, 'c·nk' should be c·n^k, and 'roughly e−ck' should be e^(−ck). Read literally, O(nk) and c·nk are just linear, which makes P look trivial.
- ch 9 [low] Quiz Q7 answer: 'Quantum computers cannot decide problems that need more than polynomial memory' overstates the inclusion. BQP ⊆ PSPACE bounds only what a quantum computer can do in polynomial time; a quantum machine allowed exponential time may well need, and use, more than polynomial memory.
- ch 9 [low] Quiz Q3 answer: 'a quantum circuit of the same size' is not right: an irreversible classical gate such as AND is not unitary, so it is rebuilt from Toffoli gates plus ancillas, which costs a constant factor per gate, not exactly the same gate count.
- ch 9 [low] Section 1, SAT example: 'checking it costs O(m) steps' holds only when each clause has bounded length. For a general formula with n variables and m clauses the cost is proportional to the total number of literals, which can be as large as n·m.
- ch 9 [low] Exam traps, last bullet: 'Any answer that claims BQP ⊆ NP or NP ⊆ BQP as a theorem is false' can be misread as saying those inclusions are false. They are open, not false.
- ch 9 [low] Section 1, BQP definition: The definition omits uniformity. A class defined by 'a polynomial-size quantum circuit' without saying the circuit family must be constructible in polynomial classical time is not the standard BQP.
